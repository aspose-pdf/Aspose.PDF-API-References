## Metadata PDF functions

| Nome | Descrição |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | Defina informações (metadados) em um arquivo PDF. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | Obtenha informações (metadados) de um arquivo PDF. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | Obtenha a lista de fontes de um arquivo PDF. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | Remova metadados de um arquivo PDF. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | Obtenha a contagem de palavras e caracteres em um arquivo PDF. |
| [AsposePdfGetPagesLayers](./asposepdfgetpageslayers/) | Obtenha a lista de camadas de um arquivo PDF. |


## Detailed Description

Funções para trabalhar com arquivos PDF de metadados.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
ou
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
