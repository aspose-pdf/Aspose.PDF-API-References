## Security PDF functions

| Nome | Descrição |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | Criptografe um arquivo PDF. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | Descriptografe um arquivo PDF. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | Assine um arquivo PDF com assinaturas digitais. |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | Assine um arquivo PDF com assinaturas digitais destacadas. |
| [AsposePdfChangePassword](./asposepdfchangepassword/) | Altere as senhas do arquivo PDF. |

## Detailed Description

Funções para trabalhar com recursos de segurança de arquivos PDF.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
ou
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
```
