## Core PDF functions

| Nome | Descrição |
| -------------- | -------------- |
| [New](./new/) | Criar um novo documento PDF. |
| [Open](./open/) | Abrir um documento PDF com o nome do arquivo. |
| [Save](./save/) | Salvar o documento PDF aberto anteriormente. |
| [SaveAs](./saveas/) | Salvar o documento PDF aberto anteriormente com um novo nome de arquivo. |
| [Close](./close/) | Liberar recursos alocados para o documento PDF. |
| [SetLicense](./setlicense/) | Definir licença com o nome do arquivo. |
| [ExtractText](./extracttext/) | Retornar o conteúdo do documento PDF como texto simples. |
| [WordCount](./wordcount/) | Retornar a contagem de palavras no documento PDF. |
| [CharacterCount](./charactercount/) | Retornar a contagem de caracteres no documento PDF. |
| [Append](./append/) | Anexar páginas de outro documento PDF. |
| [AppendPages](./appendpages/) | Anexar páginas selecionadas de outro documento PDF. |
| [MergeDocuments](./mergedocuments/) | Criar um novo documento PDF mesclando os documentos PDF fornecidos. |
| [SplitDocument](./splitdocument/) | Criar vários novos documentos PDF extraindo páginas do documento PDF de origem. |
| [Split](./split/) | Criar vários novos documentos PDF extraindo páginas do documento PDF atual. |
| [SplitAtPage](./splitatpage/) | Dividir o documento PDF em dois novos documentos PDF. |
| [SplitAt](./splitat/) | Dividir o documento PDF atual em dois novos documentos PDF. |
| [Bytes](./bytes/) | Retornar o conteúdo do documento PDF como um slice de bytes. |
| [GetMetaInfo](./getmetainfo/) | Obter o valor da informação meta do documento PDF.. |
| [SetMetaInfo](./setmetainfo/) | Definir o valor da informação meta do documento PDF.. |
| [ClearMetaInfo](./clearmetainfo/) | Limpar todos os valores de informação meta do documento PDF.. |
| [IsLinearized](./islinearized/) | Obtenha um valor que indica se o documento está linearizado. |
| [PageAdd](./pageadd/) | Adicione uma nova página no documento PDF. |
| [PageInsert](./pageinsert/) | Insira uma nova página na posição especificada no documento PDF. |
| [PageDelete](./pagedelete/) | Exclua a página especificada no documento PDF. |
| [PageCount](./pagecount/) | Retorne a contagem de páginas no documento PDF. |
| [PageWordCount](./pagewordcount/) | Retorne a contagem de palavras na página especificada do documento PDF. |
| [PageCharacterCount](./pagecharactercount/) | Retorne a contagem de caracteres na página especificada do documento PDF. |
| [PageIsBlank](./pageisblank/) | Retorne se a página está em branco no documento PDF. |
