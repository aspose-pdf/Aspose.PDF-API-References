## RichTextFontStyles enumeration

Opções para estilizar fragmentos de texto em RichText.

```csharp
[Flags]
public enum RichTextFontStyles
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| ClearExisting | `1` | Se definido, limpa todos os estilos existentes antes de aplicar estilos adicionais. Quando combinado com outras bandeiras de estilo (por exemplo, Bold), primeiro redefine os estilos e, em seguida, aplica os especificados. Sem essa bandeira, novos estilos são adicionados aos estilos existentes. |
| Bold | `2` | Opção que especifica negrito. |
| Italic | `4` | Opção que especifica itálico. |
| Underline | `8` | Opção que especifica sublinhado. |
