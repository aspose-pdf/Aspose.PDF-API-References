## TextReplaceOptions.FontSizeAdjustment enumeration

Especifica uma política de como o tamanho da fonte do texto deve ser ajustado para caber em uma área contêiner.

```csharp
public enum FontSizeAdjustment
```

### Valores

| Nome | Valor | Descrição |
| --- | --- | --- |
| None | `0` | O tamanho da fonte não é alterado. |
| ShrinkToFit | `1` | O tamanho da fonte é reduzido se o texto for muito grande para caber nos limites. O tamanho da fonte nunca é aumentado se o texto for menor que os limites. |
| ScaleToFill | `2` | O tamanho da fonte é ajustado (tanto reduzindo quanto aumentando) para que o texto preencha os limites do retângulo o máximo possível. |
