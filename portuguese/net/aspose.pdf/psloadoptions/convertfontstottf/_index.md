## PsLoadOptions.ConvertFontsToTTF property

Especifica se deve salvar fontes non-TrueType em TTF. Isso diminui significativamente o volume do documento resultante na conversão de PS para PDF e aumenta a velocidade de conversão de arquivos PS com grande quantidade de texto em fontes non-TrueType para qualquer formato de saída. No entanto, há um pequeno deslocamento vertical do texto ao converter um arquivo PostSctipt para imagem.

```csharp
public bool ConvertFontsToTTF { get; set; }
```
