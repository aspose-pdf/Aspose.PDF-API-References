## AutoTaggingSettings.EnableAutoTagging property

Obtém ou define um valor que indica se a funcionalidade de auto-tagging está habilitada.

```csharp
public bool EnableAutoTagging { get; set; }
```

## Observações

Quando habilitado, a funcionalidade de autoetiquetagem gera automaticamente conteúdo marcado para o documento PDF, o que pode melhorar a acessibilidade e a estrutura.
