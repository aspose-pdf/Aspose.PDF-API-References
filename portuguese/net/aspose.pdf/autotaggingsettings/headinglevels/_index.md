## AutoTaggingSettings.HeadingLevels property

Obtém ou define os níveis de cabeçalho usados para determinar a estrutura dos cabeçalhos em um documento PDF.

```csharp
public HeadingLevels HeadingLevels { get; set; }
```

## Observações

A propriedade `HeadingLevels` permite configurar o mapeamento de tamanhos de fonte para níveis de título. Isso é usado durante o processo de auto-tagging para identificar e atribuir níveis de título apropriados com base no tamanho da fonte dos elementos de texto no documento.
