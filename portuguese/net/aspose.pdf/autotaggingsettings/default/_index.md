## AutoTaggingSettings.Default property

Obtém as configurações padrão para a funcionalidade de auto-tagging em documentos PDF.

```csharp
public static AutoTaggingSettings Default { get; }
```

## Observações

As configurações padrão habilitam o auto-tagging e utilizam a estratégia automática para reconhecimento de títulos. Essas configurações podem ser usadas como uma configuração de base para conversão de formato PDF ou outras operações que requerem a marcação automática do conteúdo PDF.
