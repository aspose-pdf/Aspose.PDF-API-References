## ITaggedContent.Save method

Salva o estado atual do conteúdo marcado no documento PDF associado.

```csharp
public void Save()
```

## Observações

Este método garante que todos os elementos de conteúdo marcado sejam atualizados e salvos corretamente dentro do documento PDF. Ele executa as operações necessárias, como atualizar o MCID para elementos MCR, definir operadores BDC e garantir a conformidade com os padrões PDF/UA.
