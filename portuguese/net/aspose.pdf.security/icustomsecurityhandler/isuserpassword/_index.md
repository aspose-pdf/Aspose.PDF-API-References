## ICustomSecurityHandler.IsUserPassword method

Verifique se a senha pertence ao usuário (senha para abrir o Document). O método é chamado após Initialize. A chamada do método é usada na API PDF.

```csharp
public bool IsUserPassword(string password)
```

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| password | String | A senha. |

### Valor de retorno

True, se for uma senha para abrir o documento.
