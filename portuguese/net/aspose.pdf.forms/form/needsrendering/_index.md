## Form.NeedsRendering property

Obtém um valor que indica se o documento requer a remoção do formulário XFA dinâmico. Esta propriedade foi introduzida para determinar se [`IgnoreNeedsRendering`](../ignoreneedsrendering/) deve ser usado para remover o formulário XFA nos casos em que o formulário XFA está presente e `NeedsRendering` é falso.

```csharp
public bool NeedsRendering { get; }
```
