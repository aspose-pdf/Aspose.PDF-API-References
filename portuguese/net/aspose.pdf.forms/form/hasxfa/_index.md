## Form.HasXfa property

Obtém um valor que indica se o documento contém formulário XFA. Esta propriedade foi introduzida para determinar se [`IgnoreNeedsRendering`](../ignoreneedsrendering/) deve ser usado para remover o formulário XFA nos casos em que o formulário XFA está presente e [`NeedsRendering`](../needsrendering/) é falso.

```csharp
public bool HasXfa { get; }
```
