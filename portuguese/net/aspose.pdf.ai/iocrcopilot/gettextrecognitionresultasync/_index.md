## IOcrCopilot.GetTextRecognitionResultAsync method

Recupera assincronamente os resultados de reconhecimento de texto para os documentos PDF e arquivos de imagem. Os tipos de imagem suportados: PNG (.png), JPEG (.jpeg e .jpg), WEBP (.webp), GIF não animado (.gif).

```csharp
public Task<List<TextRecognitionResult>> GetTextRecognitionResultAsync(
    CancellationToken? cancellationToken = default)
```

| Parâmetro | Tipo | Descrição |
| --- | --- | --- |
| cancellationToken | Nullable`1 | Um token de cancelamento opcional para cancelar a operação. |

### Valor de retorno

Uma tarefa que representa a operação assíncrona. O resultado da tarefa contém uma lista de [`TextRecognitionResult`](../../textrecognitionresult/).
