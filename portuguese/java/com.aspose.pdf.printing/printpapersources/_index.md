Fornece um conjunto de instâncias {@link PrintPaperSource} predefinidas que representam fontes de papel comuns. Esta classe não pode ser herdada.

## Campos

| Campo | Descrição |
| --- | --- |
| [AutomaticFeed](#AutomaticFeed) | Representa uma fonte de papel de alimentação automática. |
| [Cassette](#Cassette) | Representa a cassete de papel da impressora. |
| [Envelope](#Envelope) | Representa uma fonte de papel de alimentação automática de envelope. |
| [FormSource](#FormSource) | Representa o compartimento padrão da impressora. |
| [LargeCapacity](#LargeCapacity) | Representa o compartimento de grande capacidade da impressora. |
| [LargeFormat](#LargeFormat) | Representa o compartimento para papel de formato maior. |
| [Lower](#Lower) | Representa o compartimento inferior da impressora. |
| [Manual](#Manual) | Representa uma fonte de papel de alimentação manual. |
| [ManualFeedEnvelope](#ManualFeedEnvelope) | Representa uma fonte de papel de alimentação manual de envelope. |
| [Middle](#Middle) | Representa o compartimento do meio da impressora. |
| [SmallFormat](#SmallFormat) | Representa o compartimento para papel de formato menor. |
| [TractorFeed](#TractorFeed) | Representa uma fonte de papel contínuo de alimentação por trator. |
| [Upper](#Upper) | Representa o compartimento mais alto da impressora, ou o compartimento padrão se a impressora tiver apenas um compartimento. |
