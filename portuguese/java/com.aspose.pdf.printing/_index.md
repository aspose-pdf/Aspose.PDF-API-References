O pacote com.aspose.pdf.printing fornece classes que são usadas para configurar o processo de impressão.

## Classes

| Classe | Descrição |
| --- | --- |
| [CustomPrintEventArgs](./customprinteventargs/) | Fornece dados para o evento PdfViewer.getCustomPrintDelegate(). |
| [DuplexKind](./duplexkind/) | Especifica a configuração duplex da impressora. |
| [PdfPrinterResolution](./pdfprinterresolution/) | Representa a resolução suportada por uma impressora. |
| [PdfPrinterResolutionKind](./pdfprinterresolutionkind/) | Especifica uma resolução de impressora. |
| [PdfPrinterSettings](./pdfprintersettings/) | Especifica informações sobre como um documento é impresso, incluindo a impressora que o imprime. |
| [PdfPrintRange](./pdfprintrange/) | Especifica a parte do documento a ser impressa. |
| [PrinterMargins](./printermargins/) | Especifica as dimensões das margens de uma página impressa. |
| [PrinterPaperKind](./printerpaperkind/) | Especifica os tamanhos de papel padrão. |
| [PrintPageSettings](./printpagesettings/) | Especifica configurações que se aplicam a uma única página impressa. |
| [PrintPaperSize](./printpapersize/) | Especifica o tamanho de uma folha de papel. |
| [PrintPaperSizes](./printpapersizes/) | Representa os tamanhos de papel padrão. |
| [PrintPaperSource](./printpapersource/) | Especifica a bandeja de papel da qual a impressora obtém papel. |
| [PrintPaperSourceKind](./printpapersourcekind/) | Fontes de papel padrão. |
| [PrintPaperSources](./printpapersources/) | Fornece um conjunto de instâncias {@link PrintPaperSource} predefinidas que representam fontes de papel comuns. Esta classe não pode ser herdada. |
