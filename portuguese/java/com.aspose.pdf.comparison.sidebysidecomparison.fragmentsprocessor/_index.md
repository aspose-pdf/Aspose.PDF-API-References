## Classes

| Classe | Descrição |
| --- | --- |
| [ExtractedFragmentsProcessorBase](./extractedfragmentsprocessorbase/) | Representa uma classe base para processadores de fragmentos extraídos. |
| [IgnoreSpacesFragmentsProcessor](./ignorespacesfragmentsprocessor/) | Representa uma classe para processar fragmentos de texto no modo de ignorar espaços. Esta classe ignora todos os espaços em branco, destacando palavras individuais como fragmentos. |
| [NormalFragmentProcessor](./normalfragmentprocessor/) | Representa uma classe para processar fragmentos de texto no modo normal. Esta classe considera apenas os espaços em branco dentro dos fragmentos. |
| [ParseSpacesFragmentsProcessor](./parsespacesfragmentsprocessor/) | Representa uma classe para processar fragmentos de texto no modo de analisar espaços. Esta classe reconhece os espaços entre fragmentos de texto com base na distância entre eles. |
