### updatePagination {#updatePagination-com.aspose.pdf.PageCollection-}
Atualiza os números de página e datas do cabeçalho e rodapé para todas as páginas. Isso funcionará se o documento possuir ao menos um artefato de paginação com dados de configurações especiais. Todas as páginas na coleção serão atualizadas com o artefato de origem de acordo com suas configurações.
