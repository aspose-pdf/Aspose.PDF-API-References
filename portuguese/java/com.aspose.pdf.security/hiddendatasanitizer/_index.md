### HiddenDataSanitizer {#HiddenDataSanitizer-com.aspose.pdf.security.HiddenDataSanitizationOptions-}
Fornece funcionalidade para sanitizar dados ocultos de um documento PDF, garantindo que informações sensíveis ou desnecessárias, como metadados, anotações, JavaScripts ou conteúdo privado, sejam removidas ou transformadas.

### sanitize {#sanitize-com.aspose.pdf.Document-}
Sanitiza um documento PDF fornecido removendo ou transformando dados ocultos.

### sanitizeAllToImages {#sanitizeAllToImages-com.aspose.pdf.Document-}
Substitui o conteúdo da página por imagens e remove outros dados ocultos. Permite remover texto oculto com uma cor de fundo, bem como texto oculto sob imagens. Também remove completamente todos os elementos interativos. O documento é convertido em imagens como está e, em seguida, limpo de quaisquer dados ocultos restantes. Se precisar limpar primeiro e depois converter, use o método da classe principal.

### sanitizeAllToImages {#sanitizeAllToImages-com.aspose.pdf.Document-int-}
Substitui o conteúdo da página por imagens e remove outros dados ocultos. Permite remover texto oculto com uma cor de fundo, bem como texto oculto sob imagens. Também remove completamente todos os elementos interativos. O documento é convertido em imagens como está e, em seguida, limpo de quaisquer dados ocultos restantes. Se precisar limpar primeiro e depois converter, use o método da classe principal.
