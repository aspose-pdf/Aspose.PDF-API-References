## Classes

| Classe | Descrição |
| --- | --- |
| [HiddenDataSanitizationOptions](./hiddendatasanitizationoptions/) | Representa as opções de configuração para sanitizar dados ocultos dentro de um documento. |
| [HiddenDataSanitizer](./hiddendatasanitizer/) | Representa uma classe para sanitizar dados ocultos. |
| [UnsignedContentAbsorber](./unsignedcontentabsorber/) | Representa uma classe para extrair conteúdo não assinado de um arquivo PDF gerenciado por assinaturas digitais. |
| [UnsignedContentAbsorber.Result](./unsignedcontentabsorber.result/) | Encapsula o resultado de uma operação que tenta extrair conteúdo não assinado de um documento PDF. Esta classe fornece informações sobre o sucesso da operação, detalhes do conteúdo não assinado, uma mensagem descrevendo o resultado e o status de cobertura das assinaturas do documento. |
| [UnsignedContentAbsorber.UnsignedContent](./unsignedcontentabsorber.unsignedcontent/) | Encapsula elementos de conteúdo não assinado extraídos de um documento PDF. Esta classe fornece acesso a páginas, campos de formulário, XForms e anotações que fazem parte do conteúdo não assinado dentro do documento. |
