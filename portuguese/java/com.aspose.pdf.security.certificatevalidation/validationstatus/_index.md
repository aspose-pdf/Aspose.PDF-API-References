Representa o status de validação de um certificado. Esta enumeração define os possíveis resultados da validação de certificado: - Valid: Indica que o certificado foi validado com sucesso. - Invalid: Indica que a validação do certificado falhou. - Undefined: Indica que o processo de validação foi inconclusivo ou não realizado.
