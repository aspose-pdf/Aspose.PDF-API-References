Representa uma classe para verificar assinaturas comprometidas do documento. O detector verifica apenas formas conhecidas de comprometimento de assinaturas. A verificação não pode garantir 100% a ausência de comprometimento de assinaturas e pode gerar um resultado falso‑negativo para novos métodos de comprometimento desconhecidos, diferentes dos que estão sendo testados.
