O namespace com.aspose.pdf.markdownoptions contém classes de opções específicas para uma conversão markdown.

## Classes

| Classe | Descrição |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | Define os estilos de serialização disponíveis para ênfase e ênfase forte. Para a especificação, veja CommonMark - Emphasis and strong emphasis. |
| [HeadingLevels](./headinglevels/) | Representa uma classe para trabalhar com níveis de cabeçalho baseados no tamanho da fonte. |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | Representa tipos de estratégias de reconhecimento de cabeçalho. |
| [HeadingStyle](./headingstyle/) | Define os estilos de serialização disponíveis para títulos. Para a especificação, veja CommonMark - ATX headings, respectivamente CommonMark - Setext headings. |
| [LineBreakStyle](./linebreakstyle/) | Representa os possíveis estilos de quebra de linha para um arquivo. |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Representa a classe de opção de salvamento de documento no formato markdown. |
