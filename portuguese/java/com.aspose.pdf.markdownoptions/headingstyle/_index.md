Define os estilos de serialização disponíveis para títulos. Para a especificação, veja CommonMark - ATX headings, respectivamente CommonMark - Setext headings.

## Campos

| Campo | Descrição |
| --- | --- |
| [Atx](#Atx) | Prefixe os títulos com '#' |
| [Setext](#Setext) | Use sublinhado nos títulos de nível 1 e 2 com "======" respectivamente "------". Títulos Setext estão disponíveis apenas para níveis 1 e 2. Mesmo com o estilo de título definido como Setext, o estilo Atx será usado para títulos de nível 3 ou superior. |

### Setext {#Setext}
```
public static final int Setext
```

Use sublinhado nos títulos de nível 1 e 2 com "======" respectivamente "------". Títulos Setext estão disponíveis apenas para níveis 1 e 2. Mesmo com o estilo de título definido como Setext, o estilo Atx será usado para títulos de nível 3 ou superior.
