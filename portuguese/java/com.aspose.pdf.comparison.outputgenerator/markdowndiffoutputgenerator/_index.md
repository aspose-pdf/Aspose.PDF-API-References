Representa uma classe para gerar representação Markdown das diferenças de textos. Devido à sintaxe Markdown, não é possível mostrar alterações nos caracteres de espaço em branco. A seleção de alterações faz a adição de caracteres de espaço em branco ao redor da formatação, caso contrário o visualizador Markdown não exibirá o texto corretamente. Quebras de linha excluídas são indicadas por - marca de parágrafo.
