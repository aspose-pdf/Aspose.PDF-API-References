Define o modo de posicionamento. Valores possíveis incluem Legacy (compatibilidade retroativa) e Current (método atualizado de cálculo de posição de texto).

## Campos

| Campo | Descrição |
| --- | --- |
| [Current](#Current) | O espaçamento entre linhas atualizado e o cálculo da posição vertical são feitos com base no canto superior esquerdo, em vez do canto inferior esquerdo. |
| [Legacy](#Legacy) | Posicionamento de texto legado |
| [ModernLineSpacing](#ModernLineSpacing) | O espaçamento entre linhas atualizado, o cálculo da posição vertical é feito pelas regras antigas (ou seja, o texto é posicionado em relação ao canto inferior esquerdo do retângulo especificado) |
