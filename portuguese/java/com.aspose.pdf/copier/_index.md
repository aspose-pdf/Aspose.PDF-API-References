### getUseStubs {#getUseStubs--}
```
public boolean getUseStubs()
```

Indica se stubs devem ser usados durante o processo de duplicação. Se a opção estiver ativada, os streams serão copiados; caso contrário, será usado um link para o stream de origem. Isso não permitirá fechar o documento copiado, mas economiza no processo de cópia e na memória.
