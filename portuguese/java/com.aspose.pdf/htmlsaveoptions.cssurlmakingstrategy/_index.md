Você pode atribuir a esta propriedade um delegate criado a partir de um método personalizado que implemente a criação da URL do CSS referenciado no documento HTML gerado. Por exemplo, se você quiser que o CSS seja referenciado no HTML como "otherPage.ASPX?CssID=zjjkklj", então essa estratégia personalizada deve retornar "otherPage.ASPX?CssID=zjjkklj"
