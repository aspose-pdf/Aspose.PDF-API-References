Representa o objeto PKCS#7 que está em conformidade com a especificação PKCS#7 na RFC 2315 da Internet, PKCS #7: Cryptographic Message Syntax, Versão 1.5. O digest da mensagem assinada original sobre o intervalo de bytes do documento é incorporado como o campo SignedData normal do PKCS#7. Nenhum dado deve ser encapsulado no campo SignedData do PKCS#7.
