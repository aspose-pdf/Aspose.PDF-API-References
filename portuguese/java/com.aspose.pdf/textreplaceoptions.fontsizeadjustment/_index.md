Especifica uma política de como o tamanho da fonte do texto deve ser ajustado para caber dentro de uma área contêiner.

## Campos

| Campo | Descrição |
| --- | --- |
| [None](#None) | O tamanho da fonte não foi alterado. |
| [ScaleToFill](#ScaleToFill) | O tamanho da fonte é ajustado (tanto reduzindo quanto aumentando) para que o texto preencha os limites do retângulo o máximo possível. |
| [ShrinkToFit](#ShrinkToFit) | O tamanho da fonte é reduzido se o texto for muito grande para caber nos limites. |
