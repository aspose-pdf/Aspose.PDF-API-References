Enumera modos que podem ser usados para salvar fontes referenciadas no PDF salvo.

## Campos

| Campo | Descrição |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | Todas as fontes referenciadas serão salvas e referenciadas como fontes EOT. |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | Todas as fontes referenciadas serão salvas e referenciadas como fontes TTF. |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | Todas as fontes referenciadas serão salvas e referenciadas como fontes WOFF. |
| [DontSave](#DontSave) | Todas as fontes referenciadas não serão salvas. |
| [SaveInAllFormats](#SaveInAllFormats) | Todas as fontes referenciadas serão salvas (e referenciadas no CSS) como 3 arquivos independentes: EOT, TTH, WOFF. Isso aumenta o tamanho dos dados de saída, mas torna a saída adequada para a grande maioria dos navegadores web. |
