Enumera os estilos de terminação de linha a serem usados ao desenhar a linha.

## Campos

| Campo | Descrição |
| --- | --- |
| [Butt](#Butt) | Uma linha curta no ponto final perpendicular à própria linha. |
| [Circle](#Circle) | Um círculo preenchido com a cor interior da anotação, se houver. |
| [ClosedArrow](#ClosedArrow) | Duas linhas curtas que se encontram em um ângulo agudo como no estilo OpenArrow e conectadas por uma terceira linha para formar uma ponta de seta triangular fechada preenchida com a cor interior da anotação, se houver. |
| [Diamond](#Diamond) | Uma forma de diamante preenchida com a cor interior da anotação, se houver. |
| [None](#None) | Sem terminação de linha. |
| [OpenArrow](#OpenArrow) | Duas linhas curtas que se encontram em um ângulo agudo para formar uma ponta de seta aberta. |
| [RClosedArrow](#RClosedArrow) | Uma ponta de seta triangular fechada na direção oposta à ClosedArrow. |
| [ROpenArrow](#ROpenArrow) | Duas linhas curtas na direção oposta à OpenArrow. |
| [Slash](#Slash) | Uma linha curta no ponto final aproximadamente 30 graus no sentido horário a partir da perpendicular à própria linha. |
| [Square](#Square) | Um quadrado preenchido com a cor interior da anotação, se houver. |
