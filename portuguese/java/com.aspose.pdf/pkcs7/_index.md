Representa o objeto PKCS#7 que está em conformidade com a especificação PKCS#7 na RFC 2315 da Internet, PKCS #7: Cryptographic Message Syntax, Versão 1.5. O digest SHA1 do intervalo de bytes do documento é encapsulado no campo SignedData do PKCS#7.
