## Symbology enumeration

Uma simbologia (Código de Barras) define os detalhes técnicos de um tipo específico de código de barras:<br/>            a largura das barras, conjunto de caracteres, método de codificação, especificações de checksum, etc.

## Members
| Nome do membro | Descrição |
| :- | :- |
| PDF417 | Uma simbologia 2D de múltiplas linhas e comprimento variável com alta capacidade de dados e capacidade de correção de erros. |
| QR_CODE | QR code (abreviação de Quick Response) é um código de barras matricial específico (código 2D), <br/>            legível por leitores de código QR dedicados e telefones com câmera. |
| DATA_MATRIX | Uma simbologia matricial 2D composta por módulos quadrados pretos e brancos dispostos em um padrão quadrado ou <br/>            retangular. |
