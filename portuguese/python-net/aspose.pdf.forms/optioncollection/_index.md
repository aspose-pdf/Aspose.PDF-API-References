## OptionCollection class

Classe que representa a coleção de opções do campo de escolha.

| Nome | Descrição |
| :- | :- |
| is_synchronized | Retorna verdadeiro se o objeto está sincronizado. |
| sync_root | Objeto de sincronização da coleção. |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém a opção por índice. |
## Métodos
| Nome | Descrição |
| :- | :- |
