## IconFit class

Descreve como o ícone da anotação de widget deve ser exibido dentro de seu retângulo de anotação.

O tipo IconFit expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| scaling_reason | Obtém ou define o motivo de dimensionamento. |
| scaling_mode | O tipo de dimensionamento que deve ser usado.        /// |
| leftover_left | Obtém ou define o espaço a ser alocado à esquerda do ícone. |
| leftover_bottom | Obtém ou define o espaço a ser alocado na parte inferior do ícone. |
| spread_on_border | Se verdadeiro, indica que a aparência do botão deve ser dimensionada para caber totalmente dentro dos limites da anotação sem levar em consideração a largura da linha da borda. |
## Métodos
| Nome | Descrição |
| :- | :- |
| name_to_scaling_reason(reason) | Converte o nome do motivo de dimensionamento em um objeto ScalingReason. |
| scaling_reason_to_name(reason) | Converte o objeto de motivo de dimensionamento para nome. |
| name_to_scaling_mode(mode) | Converte o nome do modo de dimensionamento em objeto **ScalingMode**. |
| scaling_mode_to_name(mode) | Converte o objeto de modo de dimensionamento em nome. |
