## ImageCompressionVersion enumeration

Descreve versões do algoritmo de compressão de imagem.

## Members
| Nome do membro | Descrição |
| :- | :- |
| STANDARD | Algoritmo padrão. Valor padrão. |
| FAST | Algoritmo aprimorado, mais rápido que o padrão, mas não aplicável a todos os casos. |
| MIXED | Use o algoritmo rápido quando possível e o padrão para os demais casos. Pode ser mais lento que "Fast", mas pode produzir melhor compressão. |
