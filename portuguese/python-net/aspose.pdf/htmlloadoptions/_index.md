## HtmlLoadOptions class

Representa opções para carregar/importar arquivo HTML em documento PDF.

O tipo HtmlLoadOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| HtmlLoadOptions() | Cria opções de carregamento para converter html em documento pdf com caminho base vazio. |
| HtmlLoadOptions(base_path) | Inicializa uma nova instância da classe HtmlLoadOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| warning_handler | Retorno de chamada para lidar com quaisquer avisos gerados. <br/>            O WarningHandler retorna o item enum ReturnAction especificando Continue ou Abort. <br/>            Continue é a ação padrão e a operação de Load continua, porém o usuário também pode retornar Abort, caso em que a operação de Load deve ser interrompida. |
| load_format | Representa o formato de arquivo que [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) descreve. |
| is_render_to_single_page | Obtém ou define a renderização de todo o documento em uma única página |
| is_embed_fonts | Obtém ou define a incorporação de fontes no documento resultante |
| page_layout_option | Obtém ou define a opção de layout. |
| html_media_type | Obtém ou define os tipos de mídia possíveis usados durante a renderização. |
| input_encoding | Obtém ou define o atributo que especifica a codificação usada para este documento no momento da análise. Se esse atributo for nulo, a codificação será determinada a partir do conjunto de caracteres do documento. |
| base_path | O caminho/base ou URL para o arquivo html. |
| page_info | Obtém ou define informações da página do documento |
