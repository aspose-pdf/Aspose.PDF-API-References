## Metadata class

Fornece acesso ao fluxo de metadados XMP.

O tipo Metadata expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| is_fixed_size | Verifica se a coleção tem tamanho fixo. |
| chaves | Obtém a coleção de chaves de metadados. |
| valores | Obtém os valores nos metadados. |
| is_synchronized | Verifica se a coleção está sincronizada. |
| sync_root | Obtém o objeto de sincronização da coleção. |
