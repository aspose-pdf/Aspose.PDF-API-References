## ExtractImageMode enumeration

Define diferentes modos que podem ser usados ao extrair imagens de documentos.

## Members
| Nome do membro | Descrição |
| :- | :- |
| DEFINED_IN_RESOURCES | Define o modo de extração de imagens no qual todas as imagens definidas nos recursos para a página específica são extraídas. |
| ACTUALLY_USED | Define o modo de extração de imagens no qual somente as imagens que são realmente exibidas em uma página são extraídas. |
