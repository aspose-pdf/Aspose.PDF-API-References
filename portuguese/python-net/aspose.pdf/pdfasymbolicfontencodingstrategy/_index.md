## PdfASymbolicFontEncodingStrategy class

Esta classe descreve regras que podem ser usadas para ajustar o processo de cópia de dados de codificação para casos<br/>            quando a fonte simbólica TrueType tem mais de uma codificação.<br/>            Alguns documentos PDF após a conversão para o formato PDF/A podem apresentar o erro <br/>            \"More than one encoding in symbolic TrueType font's cmap\". <br/>            Qual é a razão desse erro? Todas as fontes simbólicas TrueType têm a tabela especial \"cmap\"<br/>            em seus dados internos. Esta tabela mapeia códigos de caracteres para índices de glifos. <br/>            E esta tabela pode conter diferentes subtabelas de codificação que<br/>            descrevem as codificações usadas. Veja informações avançadas sobre tabelas cmap em<br/>            https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6cmap.html.<br/>            Normalmente a tabela cmap contém várias subtabelas de codificação, mas o padrão PDF/A exige<br/>            que apenas uma subtabela de codificação (3,0) seja mantida para esta fonte no documento PDF/A. <br/>            E a questão principal aqui - quais dados devem ser extraídos de outras subtabelas para copiar para<br/>            a tabela de codificação de destino (3,0)? A maioria das fontes possui tabelas cmap 'bem formadas' onde<br/>            cada subtabela de codificação é totalmente consistente com outra subtabela. Mas algumas fontes<br/>            têm tabelas cmap com colisões - onde, por exemplo, uma subtabela tem índice de glifo <br/>            100 para unicode 100, mas outra subtabela tem índice de glifo 200 para o mesmo unicode 100.<br/>            Para resolver esses problemas, é necessária uma estratégia especial. <br/>            Por padrão, a seguinte estratégia é usada: <br/>            a subtabela mac(1,0) é procurada.
