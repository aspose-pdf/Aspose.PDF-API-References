## ColumnInfo class

Esta classe representa informações de colunas.

O tipo ColumnInfo expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| ColumnInfo() | Inicializa uma nova instância da classe ColumnInfo |
## Propriedades
| Nome | Descrição |
| :- | :- |
| column_widths | Obtém ou define uma string que contém a largura das colunas. <br/>            O valor de cada coluna deve ser separado por espaço em branco. A unidade padrão é ponto,<br/>            mas cm, polegada e porcentagem da largura disponível também são suportados.<br/>            Por exemplo,"120 2.5cm 1.5inch" |
| column_spacing | Obtém ou define uma string que contém o espaçamento entre colunas. <br/>            O valor de cada espaçamento deve ser separado por espaço em branco. A unidade padrão é ponto,<br/>            mas cm e polegada também são suportados. Por exemplo,"120 2.5cm 1.5inch". |
| column_count | Obtém ou define um valor inteiro que indica o número de colunas. |
