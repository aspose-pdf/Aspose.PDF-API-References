## Resources class

Classe que representa recursos da página.

O tipo Resources expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| forms | Obtém a coleção de formulários [forms](/pdf/python-net/aspose.pdf/resources/) |
| images | Obtém a coleção de imagens [images](/pdf/python-net/aspose.pdf/resources/) |
| fonts | Obtém a coleção de recursos de fontes [fonts](/pdf/python-net/aspose.pdf/resources/) |
## Métodos
| Nome | Descrição |
| :- | :- |
| get_fonts(create_if_absent) | Retorna a coleção de fontes. Se os recursos não contiverem a entrada de fontes, ela será criada dependendo da flag CreateIfAbsent. |
