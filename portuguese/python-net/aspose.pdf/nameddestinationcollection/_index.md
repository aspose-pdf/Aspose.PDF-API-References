## NamedDestinationCollection class

O tipo NamedDestinationCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| count | Contagem de destinos nomeados. |
| names | Lista de nomes dos destinos. |
## Métodos
| Nome | Descrição |
| :- | :- |
| remove(name) | Excluir destino nomeado. |
| add(name, appointment) | Adicionar novo destino nomeado. |
