## XmpPdfAExtensionValueType class

O esquema ValueType do PDF/A é requerido para todos os tipos de valor de propriedade que não estão definidos na especificação XMP 2004, ou seja, para tipos de valor fora da lista a seguir:<br/>            - Tipos de array (são tipos contêiner que podem conter um ou mais campos): Alt, Bag, Seq<br/>            - Tipos de valor básicos: Boolean, Choice (aberto e fechado), Date, Dimensions, Integer, Lang Alt, Locale, MIMEType, ProperName, Real, Text, Thumbnail, URI, URL, XPath<br/>            - Tipos de valor de Gerenciamento de Mídia: AgentName, RenditionClass, ResourceEvent, ResourceRef, Version<br/>            - Tipo de valor básico de Trabalho/Fluxo: Job<br/>            - Tipos de valor do esquema EXIF: Flash, CFAPattern, DeviceSettings, GPSCoordinate, OECF/SFR, Rational<br/>            URI do namespace do esquema: http://www.aiim.org/pdfa/ns/type#<br/>            Prefixo de namespace do esquema requerido: pdfaType
