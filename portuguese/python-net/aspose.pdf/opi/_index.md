## Opi class

Representa a Open Prepress Interface (OPI), que é um mecanismo para criar marcadores de posição de baixa resolução, ou proxies,<br/>            para tais imagens de alta resolução.

O tipo Opi expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| Opi(xform) | Inicializa uma nova instância da classe Opi |
## Propriedades
| Nome | Descrição |
| :- | :- |
| version | Obtém a versão do OPI à qual este dicionário se refere. |
| file_specification | Obtém o arquivo externo que contém a imagem proxy de baixa resolução. |
| position | Obtém um array de oito números no formato que especifica a localização na página da imagem recortada. |
