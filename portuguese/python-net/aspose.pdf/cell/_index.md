## Cell class

Representa uma célula da linha da tabela.

O tipo Cell expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| Cell(rect) | Inicializa uma nova instância da classe Cell |
| Cell() | Inicializa uma nova instância da classe Cell. |
## Propriedades
| Nome | Descrição |
| :- | :- |
| is_no_border | Obtém ou define se a célula tem borda. |
| margem | Obtém ou define o preenchimento. |
| borda | Obtém ou define a borda. |
| background_color | Obtém ou define a cor de fundo. |
| background_image_file | Obtém ou define o arquivo de imagem de fundo. |
| background_image | Obtém ou define a imagem de fundo |
| alinhamento | Obtém ou define o alinhamento. |
| default_cell_text_state | Obtém ou define o estado de texto padrão da célula. |
| is_override_by_fragment | Define que a propriedade TextState da célula é sobrescrita pela propriedade TextState do TextFragment. |
| paragraphs | Obtém ou define o texto formatado da célula. |
| is_word_wrapped | Obtém ou define se o texto da célula está com quebra de linha. |
| vertical_alignment | Obtém ou define o alinhamento vertical. |
| col_span | Obtém ou define a extensão da coluna. |
| row_span | Obtém ou define a extensão da linha. |
| largura | Obtém ou define a largura da coluna. |
## Métodos
| Nome | Descrição |
| :- | :- |
| clone() | Clona a célula. |
