## ImagePlacement class

Representa as características de uma imagem colocada na página de documento PDF.

O tipo ImagePlacement expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| matrix | Matriz de transformação atual para esta imagem. |
| rectangle | Obtém o retângulo da Image. |
| operador | Operador usado para exibir a imagem. |
| rotation | Obtém o ângulo de rotação da Image. |
| resolution | Obtém a resolução da Image. |
| image | Obtém o objeto de recurso XImage relacionado. |
| página | Obtém a página que contém a imagem. |
| compositing_parameters | Obtém os parâmetros de composição do estado gráfico ativo para a imagem colocada na página. |
## Métodos
| Nome | Descrição |
| :- | :- |
| save(stream) | Salva a imagem com as transformações correspondentes: dimensionamento, rotação e resolução. |
| save(stream, format) | Salva a imagem com as transformações correspondentes: dimensionamento, rotação e resolução. |
| hide() | Exclui a imagem da página. |
| replace(image) | Substitui a imagem na coleção por outra imagem. |
