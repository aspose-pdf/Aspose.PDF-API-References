## PageMode enumeration

A classe descreve os componentes usados da página do documento.

## Members
| Nome do membro | Descrição |
| :- | :- |
| USE_NONE | Não use nenhum componente. |
| USE_OUTLINES | Contorno do documento visível. |
| USE_THUMBS | Miniaturas visíveis. |
| FULL_SCREEN | FullScreenModo de tela cheia, sem barra de menus, controles de janela ou qualquer outra janela visível. |

| USE_ATTACHMENTS | Painel de anexos visível. |
