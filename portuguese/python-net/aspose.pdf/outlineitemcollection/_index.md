## OutlineItemCollection class

Representa a entrada de contorno na hierarquia de contorno de documento PDF.

O tipo OutlineItemCollection expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| OutlineItemCollection(outlines) | Inicializa uma nova instância da classe OutlineItemCollection |
## Propriedades
| Nome | Descrição |
| :- | :- |
| visible_count | Obtém o número total de itens de contorno em todos os níveis na hierarquia de contorno do documento. |
| title | Obtém ou define o título deste item de contorno. |
| destination | Obtém ou define o destino deste item de contorno. |
| ação | Obtém ou define a ação deste item de contorno. |
| cor | Obtém ou define a cor do texto do título deste item de contorno. |
| itálico | Obtém ou define o indicador itálico para o texto do título deste item de contorno |
| negrito | Obtém ou define o indicador negrito para o texto do título deste item de contorno |
| first | Obtém o item de contorno que representa o primeiro item de nível superior na hierarquia de contorno. |
| último | Obtém o item de contorno que representa o último item de nível superior na hierarquia de contorno. |
| anterior | Obtém o item de contorno que representa o item anterior em relação a este item na hierarquia de contorno. |
| próximo | Obtém o item de contorno que representa o próximo item em relação a este item na hierarquia de contorno. |
| has_next | Verifica se o item de contorno representa o próximo item em relação a este item na hierarquia de contorno. |
| pai | Obtém o objeto pai deste item de contorno na hierarquia de contorno. |
| is_synchronized | Obtém o valor que indica se o acesso a esta coleção é sincronizado (thread safe). |
| sync_root | Obtém o objeto que pode ser usado para sincronizar o acesso a esta coleção. |
| open | Obtém ou define o status aberto (true/false) para o item de contorno. |
| level | Obtém o nível hierárquico do item de contorno. |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém o item de contorno da coleção usando o índice. |
## Métodos
| Nome | Descrição |
| :- | :- |
| delete() | Exclui este item de contorno da hierarquia de contorno do documento. |
| delete(name) | Exclui a entrada de contorno com o nome especificado da hierarquia de contorno do documento. |
| insert(index, outline) | Insere o item de contorno na coleção no local especificado. |
