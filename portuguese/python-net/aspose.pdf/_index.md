| [PdfASymbolicFontEncodingStrategy](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) | Esta classe descreve regras que podem ser usadas para ajustar o processo de cópia de dados de codificação para casos<br/>            quando a fonte simbólica TrueType tem mais de uma codificação.<br/>            Alguns documentos PDF após a conversão para o formato PDF/A podem apresentar o erro <br/>            \"More than one encoding in symbolic TrueType font's cmap\". <br/>            Qual é a razão desse erro? Todas as fontes simbólicas TrueType têm a tabela especial \"cmap\"<br/>            em seus dados internos. Esta tabela mapeia códigos de caracteres para índices de glifos. <br/>            E esta tabela pode conter diferentes subtabelas de codificação que<br/>            descrevem as codificações usadas. Veja informações avançadas sobre tabelas cmap em<br/>            https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6cmap.html.<br/>            Normalmente a tabela cmap contém várias subtabelas de codificação, mas o padrão PDF/A exige<br/>            que apenas uma subtabela de codificação (3,0) seja mantida para esta fonte no documento PDF/A. <br/>            E a questão principal aqui - quais dados devem ser extraídos de outras subtabelas para copiar para<br/>            a tabela de codificação de destino (3,0)? A maioria das fontes possui tabelas cmap 'bem formadas' onde<br/>            cada subtabela de codificação é totalmente consistente com outra subtabela. Mas algumas fontes<br/>            têm tabelas cmap com colisões - onde, por exemplo, uma subtabela tem índice de glifo <br/>            100 para unicode 100, mas outra subtabela tem índice de glifo 200 para o mesmo unicode 100.<br/>            Para resolver esses problemas, é necessária uma estratégia especial. <br/>            Por padrão, a seguinte estratégia é usada: <br/>            a subtabela mac(1,0) é procurada. Se esta tabela for encontrada, apenas esses dados são usados para preencher a<br/>            tabela (3,0). Se a subtabela mac não for encontrada, então todas as subtabelas exceto (3,0) são iteradas <br/>            e usadas para copiar dados para a subtabela de destino (3,0). Também o mapeamento para cada unicode (unicode, índice de glifo)<br/>            é copiado para a tabela de destino somente se a tabela de destino ainda não contiver esse unicode no momento atual. <br/>            Assim, por exemplo, se a primeira subtabela tem índice de glifo 100 para unicode 100, e a próxima subtabela tem<br/>            índice 200 para o mesmo unicode 100, somente os dados da primeira subtabela (unicode=100, índice de glifo = 100) serão copiados. <br/>            Portanto, cada subtabela anterior tem precedência sobre a seguinte. <br/>            As propriedades desta classe [PdfASymbolicFontEncodingStrategy](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) ajudam a ajustar o comportamento padrão. <br/>            Se a propriedade [preferred_cmap_encoding_table](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) do tipo [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            estiver definida, então a subtabela relevante será usada com precedência sobre a subtabela mac(1,0). O valor 'MacTable' da<br/>            enumeração [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/) não faz sentido neste caso, pois ele <br/>            aponta para a mesma subtabela mac (1,0) que será usada por padrão. <br/>            A propriedade [None](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) descarta todas as prioridades para qualquer subtabela.<br/>            Se esta propriedade for definida, então somente as subtabelas da fila declarada serão usadas na ordem especificada.<br/>            Se as subtabelas especificadas não forem encontradas, então a iteração padrão de todas as subtabelas e a estratégia de cópia descrita acima<br/>            será usada.<br/>            O objeto [QueueItem](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy/queueitem/) especifica a subtabela de codificação usada. Esta subtabela pode ser definida<br/>            por combinação de membros (PlatformID, PlatformSpecificId) ou via enumeração [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            . |
