## FileParams class

Define um dicionário de parâmetros de arquivo incorporado que deve conter informações adicionais específicas do arquivo.

O tipo FileParams expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| FileParams(spec) | Inicializa uma nova instância da classe FileParams |
## Propriedades
| Nome | Descrição |
| :- | :- |
| size | O tamanho do arquivo incorporado descompactado, em bytes. |
| creation_date | A data e hora em que o arquivo incorporado foi criado. |
| mod_date | A data e hora em que o arquivo incorporado foi modificado pela última vez. |
| check_sum | Uma string de 16 bytes que é a soma de verificação dos bytes do arquivo incorporado descompactado. <br/>            A soma de verificação é calculada aplicando o algoritmo padrão de digestão de mensagem MD5 <br/>            aos bytes do fluxo do arquivo incorporado. |
