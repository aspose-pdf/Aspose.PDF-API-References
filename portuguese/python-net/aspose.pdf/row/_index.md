## Row class

Representa uma linha da tabela.

O tipo Row expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| Row() | Inicializa uma nova instância da classe Row |
## Propriedades
| Nome | Descrição |
| :- | :- |
| background_color | Obtém ou define a cor de fundo. |
| borda | Obtém ou define a borda. |
| cells | Obtém as células da linha. |
| default_cell_border | Obtém a borda padrão da célula; |
| min_row_height | Obtém a altura da linha; |
| fixed_row_height | Obtém a altura fixa da linha - a linha pode ter altura fixa; |
| is_in_new_page | Obtém se a linha fixa está em nova página - a página com esta propriedade deve ser impressa na página seguinte Default false; |
| is_row_broken | Obtém se a linha pode ser quebrada entre duas páginas |
| default_cell_text_state | Obtém ou define o estado de texto padrão para as células da linha |
| default_cell_padding | Obtém ou define a margem padrão para as células da linha |
| vertical_alignment | Obtém ou define o alinhamento vertical. |
## Métodos
| Nome | Descrição |
| :- | :- |
| clone() | Clona a linha. |
