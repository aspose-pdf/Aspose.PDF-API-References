## PdfANonSpecificationFlags class

Esta classe contém flags para controlar a conversão PDF/A em casos em que o documento PDF de origem não <br/>            corresponde à especificação PDF. Se as flags desta classe forem usadas, isso diminui o desempenho <br/>            mas é necessário quando o documento PDF de origem não pode ser convertido para o formato PDF/A da maneira usual. <br/>            Por padrão, todas as flags são definidas como false.

O tipo PdfANonSpecificationFlags expõe os seguintes membros:

| :- | :- |
| check_different_names_in_font_dictionaries | Alguns documentos PDF contêm fontes que têm nomes diferentes nos dados internos. <br/>            O uso desta flag impõe lógica de processamento especial para casos em que os campos <br/>            BaseFont e FontDescriptor.FontName são diferentes. |
