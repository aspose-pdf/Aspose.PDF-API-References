## ArtifactCollection class

Classe representa coleção de artefatos.

O tipo ArtifactCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| is_synchronized | Este objeto está sincronizado. |
| sync_root | Obtém o objeto de sincronização da coleção. |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém o artefato por índice. O índice começa em 1. |
## Métodos
| Nome | Descrição |
| :- | :- |
| delete(artifact) | Exclui o artefato especificado. |
| delete(index) | Exclui o artefato pelo seu índice. |
| find_by_value(name, expected_value) | Encontra artefatos por valor personalizado. |
| update(artifact) | Atualiza o artefato dentro da coleção. |
