## HtmlPageLayoutOption enumeration

Especifica flags que, junto com outras opções, determinam tamanhos e layouts das páginas.

## Members
| Nome do membro | Descrição |
| :- | :- |
| NONE | Valor padrão que indica que o HtmlPageLayoutOption não afetará os tamanhos e layouts das páginas. |
| FIT_TO_WIDEST_CONTENT_WIDTH | Indica que a largura da página é determinada pelo tamanho do conteúdo em si, não pela largura de página especificada. |
| SCALE_TO_PAGE_WIDTH | Indica que o conteúdo do documento será dimensionado para caber na página. |
