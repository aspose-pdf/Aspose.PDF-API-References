## XForm class

Classe representa XForm

O tipo XForm expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| b_box | Obtém ou define a caixa delimitadora do formulário. |
| nome | Obtém ou define o nome do formulário. O nome do formulário é o nome usado para referenciar o formulário no dicionário XObject nos recursos da página. |
| conteúdo | Obtém os operadores do formulário. |
| opi | Obtém a Open Prepress Interface (OPI). |
| matrix | Obtém ou define a matriz do formulário. |
| resources | Obtém os recursos do Form XObject. |
| rectangle | Obtém ou define o retângulo do formulário. |
## Métodos
| Nome | Descrição |
| :- | :- |
| get_resources(allow_create) | Retorna os recursos do Form X-Object |
| get_resources() | Retorna os recursos do Form X-Object |
| create_new_form(source, document) | Cria um XForm que duplica o conteúdo da página. |
| free_memory() | Limpa os dados em cache |
