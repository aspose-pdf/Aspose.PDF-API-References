## ProgressEventType enumeration

Este enum descreve os tipos possíveis de eventos de progresso<br/>            que podem ocorrer durante a conversão

## Members
| Nome do membro | Descrição |
| :- | :- |
| TOTAL_PROGRESS | significa que o evento ocorrido informa sobre o progresso total da conversão |
| SOURCE_PAGE_ANALYSED | significa que o evento ocorrido informa sobre o fim da análise de uma das páginas antes da conversão |
| RESULT_PAGE_CREATED | significa que o evento ocorrido informa sobre a criação de uma página de resultado antes da exportação física |
| RESULT_PAGE_SAVED | significa que o evento ocorrido informa sobre a conclusão da gravação de uma página de resultado |
