## PdfSaveOptions class

Opções de salvamento para exportação para o formato Pdf

O tipo PdfSaveOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| PdfSaveOptions() | Inicializa uma nova instância da classe PdfSaveOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| warning_handler | Retorno de chamada para lidar com quaisquer avisos gerados. <br/>            O WarningHandler retorna o item enum ReturnAction especificando Continue ou Abort. <br/>            Continue é a ação padrão e a operação Save continua, porém o usuário também pode retornar Abort, caso em que a operação Save deve ser interrompida. |
| save_format | Formato de salvamento de dados. |
| close_response | Obtém ou define um valor booleano que indica se o objeto Response será fechado após o documento ser salvo na resposta. |
| temp_path | Caminho para arquivos temporários. |
| default_font_name | Nome da fonte usado por padrão para fontes que estão ausentes no computador.<br/>            Quando o documento PDF que é salvo contém fontes que não estão disponíveis <br/>            no próprio documento e no dispositivo, a API substitui essas fontes pela <br/>            fonte padrão (se a fonte com [default_font_name](/pdf/python-net/aspose.pdf/pdfsaveoptions/) for encontrada no dispositivo) |
