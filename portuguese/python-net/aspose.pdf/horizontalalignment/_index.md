## HorizontalAlignment enumeration

Descreve o alinhamento horizontal.

## Members
| Nome do membro | Descrição |
| :- | :- |
| NONE | Sem alinhamento. |
| LEFT | Alinhar à esquerda. |
| CENTER | Alinhamento central. |
| RIGHT | Alinhar à direita. |
| JUSTIFY | Alinhamento justificado. O texto será alinhado nas margens esquerda e direita. |
| FULL_JUSTIFY | Semelhante ao alinhamento 'Justify', exceto que a última linha ficará apenas <br/>            alinhada à esquerda no modo 'Justify', enquanto no modo 'FullJustify' todas as linhas ficarão<br/>            alinhadas à esquerda e à direita. |
