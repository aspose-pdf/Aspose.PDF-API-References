## XImageCollection class

Classe que representa a coleção XImage.

O tipo XImageCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| is_synchronized | Retorna true se o objeto estiver sincronizado. |
| sync_root | Retorna o objeto de sincronização. |
| names | Obtém a matriz de nomes de imagens. |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém a imagem da coleção pelo seu índice. |
## Métodos
| Nome | Descrição |
| :- | :- |
| add(image) | Adiciona nova imagem à lista de Imagens. Este método adiciona a imagem como referência ao mesmo PdfObject (o que permite diminuir o tamanho do arquivo) |
| add(image) | Adiciona a entidade ao final da coleção, de modo que a entidade possa ser acessada pelo último índice. |
| add(image, filter_type) | Adiciona a entidade ao final da coleção, de modo que a entidade possa ser acessada pelo último índice. |
| add(image, quality) | Adiciona a entidade ao final da coleção, de modo que a entidade possa ser acessada pelo último índice. |
| delete(index) | Remove o índice da coleção por índice. |
| delete(index, action) | Remove a imagem da coleção por índice executando a ação especificada pelo parâmetro action. |
| delete(name) | Remove o item da coleção por nome. |
| delete(name, action) | Remove o item da coleção por nome. |
| delete() | Remove o índice da coleção por índice. |
| replace(index, stream) | Substitui a imagem na coleção por outra imagem. |
| replace(index, stream, quality, is_black_and_white) | Substitui a imagem na coleção por outra imagem. |
| replace(index, stream, quality) | Substitui a imagem na coleção por outra imagem. |
| get_image_name(image) | Retorna o nome na lista de imagens que é a chave da imagem fornecida. |
