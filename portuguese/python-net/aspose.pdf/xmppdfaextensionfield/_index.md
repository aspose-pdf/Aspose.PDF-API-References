## XmpPdfAExtensionField class

Este esquema descreve um campo em um tipo estruturado. É muito semelhante ao esquema de Tipo de Valor de Propriedade PDF/A <br/>            mas define um campo em uma estrutura ao invés de uma propriedade.<br/>            URI do namespace do esquema: http://www.aiim.org/pdfa/ns/field#<br/>            Prefixo de namespace do esquema requerido: pdfaField.
