## HtmlSaveOptions class

Opções de salvamento para exportação para o formato HTML

O tipo HtmlSaveOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| HtmlSaveOptions() | Inicializa uma nova instância da classe [HtmlSaveOptions](/pdf/python-net/aspose.pdf/htmlsaveoptions/). |
| HtmlSaveOptions(document_type) | Inicializa uma nova instância da classe HtmlSaveOptions |
| HtmlSaveOptions(fixed_layout) | Inicializa uma nova instância da classe HtmlSaveOptions |
| HtmlSaveOptions(document_type, fixed_layout) | Inicializa uma nova instância da classe HtmlSaveOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| warning_handler | Retorno de chamada para lidar com quaisquer avisos gerados. <br/>            O WarningHandler retorna o item enum ReturnAction especificando Continue ou Abort. <br/>            Continue é a ação padrão e a operação Save continua, porém o usuário também pode retornar Abort, caso em que a operação Save deve ser interrompida. |
| save_format | Formato de salvamento de dados. |
| close_response | Obtém ou define um valor booleano que indica se o objeto Response será fechado após o documento ser salvo na resposta. |
| extract_ocr_sublayer_only | Nenhum |
| try_merge_adjacent_same_background_images | Nenhum |
| document_type | Obtém ou define o [HtmlDocumentType](/pdf/python-net/aspose.pdf/htmldocumenttype/). |
| compress_svg_graphics_if_any | Obtém ou define a bandeira que indica se<br/>            os gráficos SVG encontrados (se houver) serão comprimidos (zipados) <br/>            no formato SVGZ durante a gravação |
| split_css_into_pages | Quando o modo multipágina está selecionado (ou seja, 'SplitIntoPages' é 'true'), <br/>            então este atributo define se deve ser criado um arquivo CSS separado<br/>            para cada página HTML resultante.<br/>            Por padrão, este atributo é false, portanto, será criado<br/>            um grande CSS comum para todas as páginas criadas. O tamanho total de todos<br/>            os CSS gerados neste modo (um CSS por página) costuma<br/>            ser muito maior que o tamanho de um único CSS grande, porque no caso anterior <br/>            as classes CSS são duplicadas em vários arquivos CSS para cada página.<br/>            Assim, esta configuração deve ser usada apenas quando você está interessado<br/>            no processamento futuro de cada página HTML de forma independente, e, portanto, o tamanho<br/>            do CSS de cada página individual é a questão mais crítica. |
| split_into_pages | Obtém ou define a bandeira que indica se cada página do documento <br/>            fonte será convertida em seu próprio documento HTML de destino, <br/>            ou seja, se o HTML resultante será dividido em várias páginas HTML. |
| explicit_list_of_saved_pages | Com esta propriedade você pode definir explicitamente <br/>            quais páginas do documento devem ser convertidas.<br/>            As páginas nesta lista devem ter números baseados em 1. Ou seja, <br/>            os números válidos de páginas devem ser retirados do intervalo (1...[NumberOfPagesInConvertedDocument])<br/>            A ordem de aparição das páginas nesta lista não afeta a<br/>            ordem nas páginas HTML resultantes – nas páginas resultantes sempre seguirão a ordem em que estão <br/>            presentes no PDF de origem.<br/>            Se esta lista for nula (como é o padrão), todas as páginas serão convertidas.<br/>            Se algum número de página desta lista estiver fora do intervalo das páginas presentes (1-[amountOfPagesInDocument])<br/>            uma exceção será lançada. |
| fixed_layout | Obtém ou define um valor que indica se o HTML é criado como layout fixo. |
| image_resolution | Obtém ou define a resolução para renderização de imagens. |
| default_font_name | Especifica o nome de uma fonte instalada que é usada para substituir<br/>            qualquer fonte do documento que não esteja incorporada e não esteja instalada no sistema. <br/>            Se for null, então a fonte de substituição padrão será usada. |
| batch_size | Define o tamanho do lote se a conversão em lote for aplicável<br/>            ao par de formatos de origem e destino. |
| font_sources | Fontes de fontes pré-salvas. |
| additional_margin_width_in_points | Se o atributo 'SplitOnPages=false', então todo o HTML que representa todas as páginas PDF de entrada não será<br/>            dividido em diferentes páginas HTML, mas será colocado em um único arquivo HTML de resultado grande.<br/>            Contudo, cada página PDF de origem será representada com sua própria <br/>            área retangular em HTML (se necessário, essas áreas podem ser contornadas para mostrar as bordas do papel da página<br/>            com o atributo especial 'PageBorderIfAny'.<br/>            Este parâmetro define a largura da margem que será forçadamente deixada ao redor dessas áreas HTML de saída<br/>            que representam as páginas do documento PDF de origem. Em essência, define o intervalo garantido entre<br/>            as representações HTML das páginas \"paper\" do PDF nesse modo de conversão. |
| use_z_order | Se o atributo UseZORder estiver definido como true, gráficos e texto são adicionados ao documento HTML resultante<br/>            de acordo com a ordem Z no documento PDF original. Se este atributo for false, todos os gráficos são colocados<br/>            como uma única camada, o que pode causar efeitos indesejados em objetos sobrepostos. |
| convert_marked_content_to_layers | Se o atributo ConvertMarkedContentToLayers estiver definido como true, então todos os elementos dentro de um conteúdo marcado PDF<br/>            (camada) serão colocados em um div HTML com o atributo "data-pdflayer" especificando um nome de camada.<br/>            Esse nome de camada será extraído das propriedades opcionais do conteúdo marcado PDF.<br/>            Se este atributo for false (por padrão), nenhuma camada será criada a partir do conteúdo marcado PDF. |
| minimal_line_width | Este atributo define a largura mínima da linha do caminho gráfico.<br/>            Se a espessura da linha for menor que 1px, o Adobe Acrobat a arredonda para este valor. Portanto, este atributo pode<br/>            ser usado para emular esse comportamento em navegadores HTML. |
| prevent_glyphs_grouping | Este atributo ativa o modo em que os glifos de texto não serão agrupados em palavras e cadeias<br/>            Esse modo permite manter a máxima precisão ao posicionar os glifos na página e pode ser<br/>            usado para converter documentos com notas musicais ou glifos que devem ser colocados separadamente uns dos outros.<br/>            Este parâmetro será aplicado ao documento somente quando o valor do atributo FixedLayout for true. |
| simple_textbox_mode_grouping | Este atributo especifica um agrupamento sequencial de glifos e palavras em cadeias<br/>            Por exemplo, tags e palavras têm ordem diferente no HTML convertido e você deseja que correspondam.<br/>            Este parâmetro será aplicado ao documento somente quando o valor do atributo FixedLayout for true. |
| flow_layout_paragraph_full_width | Este atributo especifica texto de parágrafo em largura total para o modo Flow, FixedLayout = false |
| render_text_as_image | Se o atributo RenderTextAsImage estiver definido como true, o texto da fonte se torna uma imagem em HTML.<br/>            Pode ser útil para tornar o texto não selecionável<br/>            ou quando o texto HTML não é renderizado corretamente. |
| save_full_font | Indica que a fonte completa será salva, suporta apenas fontes True Type.<br/>            Por padrão, SaveFullFont = false e o conversor salva o subconjunto da fonte inicial<br/>            necessário para exibir o texto do documento. |
| antialiasing_processing | Este parâmetro define as medidas de antialiasing necessárias durante a conversão de imagens de fundo compostas de PDF para HTML |
| save_transparent_texts | O PDF pode conter textos transparentes que podem ser selecionados para a área de transferência (geralmente isso ocorre quando o documento contém imagens e textos extraídos por OCR).<br/>            Esta configuração indica ao conversor se devemos salvar esses textos como textos transparentes<br/>            selecionáveis no HTML resultante. |
| save_shadowed_texts_as_transparent_texts | Pdf pode conter textos que são sombreado por outros elementos (por exemplo, por imagens) mas <br/>            podem ser selecionados para a área de transferência no Acrobat Reader (geralmente isso acontece quando o documento contém imagens e textos OCR extraídos dele).<br/>            Esta configuração indica ao conversor se precisamos salvar tais textos como textos transparentes<br/>            selecionáveis no HTML resultante para imitar o comportamento do Acrobat Reader (caso contrário, esses textos geralmente são salvos como ocultos, não disponíveis para cópia para a área de transferência) |
| font_saving_mode | Define o modo de salvamento de fontes que será usado ao salvar o PDF para o formato desejado |
| page_border_if_any | Este atributo representa um conjunto de configurações usadas para desenhar a borda (se houver)<br/>            no documento HTML resultante ao redor da área que representa a página PDF de origem.<br/>            Essencialmente, trata da exibição das margens de papel da página,<br/>            não da borda da página referenciada no próprio PDF. |
| page_margin_if_any | Este atributo representa um conjunto de margens de página extras (se houver)<br/>            no documento HTML resultante ao redor da área que representa a página PDF de origem. |
| letters_positioning_method | Define o modo de posicionamento das letras nas palavras no HTML resultante |
| exclude_font_name_list | Lista de nomes de fontes incorporadas no PDF que não devem ser incorporadas no HTML. |
| special_folder_for_svg_images | Obtém ou define o caminho para o diretório onde apenas imagens SVG devem ser salvas se forem <br/>            encontradas durante a conversão do documento para HTML. Se o parâmetro estiver vazio ou nulo<br/>            então os arquivos SVG (se houver) serão salvos junto com os demais arquivos de imagem (próximos ao arquivo de saída)<br/>            ou em pasta especial para imagens (se especificada na opção SpecialImagesFolderIfAny).<br/>            Não afeta nada se a propriedade CustomImageSavingStrategy<br/>            foi usada com sucesso para processar o arquivo de imagem relevante. |
| special_folder_for_all_images | Obtém ou define o caminho para o diretório onde quaisquer imagens devem ser salvas se forem <br/>            encontradas durante a conversão do documento para HTML. Se o parâmetro estiver vazio ou nulo<br/>            então os arquivos de imagem (se houver) serão salvos junto com os demais arquivos vinculados ao HTML<br/>            Não afeta nada se a propriedade CustomImageSavingStrategy<br/>            foi usada com sucesso para processar o arquivo de imagem relevante. |
| css_class_names_prefix | Quando o conversor PDFtoHTML gera os CSS resultantes, os nomes de classes CSS<br/>            (algo como ".stl_01 {}" ... ".stl_NN {}") são gerados<br/>            e usados no CSS resultante. Esta propriedade permite definir forçadamente o prefixo dos nomes de classe<br/>            Por exemplo, se você quiser que todos os nomes de classe comecem com 'my_prefix_'<br/>            (ou seja, algo como 'my_prefix_1' ... 'my_prefix_NNN'), <br/>            basta atribuir 'my_prefix_' a esta propriedade antes da conversão.<br/>            Se esta propriedade permanecer inalterada (ou seja, null será mantido como valor), então<br/>            o conversor gerará os nomes de classe por conta própria <br/>            (será algo como ".stl_01 {}" ... ".stl_NN {}") |
| parts_embedding_mode | Define se os arquivos referenciados (HTML, Fontes, Imagens, CSSes)<br/>            serão incorporados ao arquivo HTML principal ou serão gerados como entidades binárias separadas |
| html_markup_generation_mode | Às vezes há requisitos específicos para a geração de marcação HTML.<br/>            Este parâmetro define os modos de preparação de HTML que podem ser usados<br/>            durante a conversão de PDF para HTML para atender a esses requisitos específicos. |
| raster_images_saving_mode | O PDF convertido pode conter imagens raster<br/>            Este parâmetro define como elas devem ser tratadas<br/>            durante a conversão de PDF para HTML |
| remove_empty_areas_on_top_and_bottom | Define se nas HTML criadas será removida a área vazia superior e inferior sem nenhum conteúdo (se houver). |
| font_encoding_strategy | Define regra especial de codificação para ajustar a decodificação de PDF para o documento atual. |
| pages_flow_type_depends_on_viewers_screen_size | Se o atributo 'SplitOnPages=false', então todo o HTML que representa todas as páginas PDF de entrada será <br/>            colocado em um único grande arquivo HTML de resultado. <br/>            Esta flag define se o HTML de resultado será gerado de forma<br/>            que o fluxo das áreas que representam as páginas PDF no HTML de resultado dependa<br/>            da resolução de tela do visualizador. <br/>            Suponha que a largura da tela no lado do visualizador seja grande o suficiente para colocar 2 ou mais páginas próximas<br/>            uma da outra na direção horizontal. Se esta flag estiver definida como true, então essa oportunidade<br/>            será usada (quantas páginas puderem ser mostradas na direção horizontal próximas umas das outras<br/>            o máximo possível, então o próximo grupo horizontal de páginas será exibido abaixo do primeiro).<br/>            Caso contrário, as páginas fluirão da seguinte forma: a próxima página sempre ficará abaixo da anterior. |
| try_save_text_underlining_and_strikeouting_in_css | O próprio PDF não contém marcadores de sublinhado para textos. Ele é emulado com uma linha situada sob o texto.<br/>            Esta opção permite que o conversor tente adivinhar que esta ou aquela linha é um sublinhado de texto<br/>            e coloque essa informação no CSS em vez de desenhar o sublinhado graficamente |
