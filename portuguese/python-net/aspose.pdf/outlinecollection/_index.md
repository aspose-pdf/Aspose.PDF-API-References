## OutlineCollection class

Representa a hierarquia de contorno do documento.

O tipo OutlineCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| visible_count | Count é a soma do número de itens de contorno descendentes visíveis em todos os níveis. Observação: por favor, não confunda com Count, que é o número de itens na coleção. |
| first | Obtém um item de contorno que representa o primeiro item de nível superior no contorno. |
| último | Obtém um item de contorno que representa o último item de nível superior no contorno. |
| is_synchronized | Obtém um valor que indica se o acesso a esta coleção está sincronizado (thread safe). |
| sync_root | Obtém um objeto que pode ser usado para sincronizar o acesso a esta coleção. |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém o item de contorno da coleção por índice. |
## Métodos
| Nome | Descrição |
| :- | :- |
| delete() | Exclui todos os itens de contorno do contorno do documento. |
| delete(name) | Exclui o item de contorno com o título especificado do contorno do documento. |
