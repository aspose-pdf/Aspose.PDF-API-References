## EmbeddedFileCollection class

Classe que representa a coleção de arquivos incorporados.

O tipo EmbeddedFileCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| is_synchronized | Obtém um valor que indica se o acesso a esta coleção está sincronizado (thread safe). |
| sync_root | Obtém um objeto que pode ser usado para sincronizar o acesso a esta coleção. |
| chaves | Retorna a lista de chaves de anexos de arquivo. |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém o arquivo incorporado pelo seu índice. |
## Métodos
| Nome | Descrição |
| :- | :- |
| delete(name) | Exclui o arquivo da coleção pela sua chave na coleção. |
| delete() | Exclui o arquivo da coleção pela sua chave na coleção. |
| add(key, file) | Adiciona o arquivo aos arquivos incorporados com a chave especificada. |
| delete_by_key(key) | Exclui o arquivo da coleção pela sua chave na coleção. |
| find_by_name(name) | Retorna o arquivo incorporado pelo seu nome. |
