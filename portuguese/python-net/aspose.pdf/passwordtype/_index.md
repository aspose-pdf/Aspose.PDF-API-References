## PasswordType enumeration

Este enum representa tipos de senha conhecidos usados para documentos PDF protegidos por senha.

## Members
| Nome do membro | Descrição |
| :- | :- |
| NONE | O documento PDF não está protegido por senha. |
| USER | O documento PDF foi aberto usando a senha de abertura do documento (acesso restrito). |
| OWNER | O documento PDF foi aberto usando a senha de alteração de permissões (acesso total). |
| INACESSÍVEL | O documento PDF está protegido por senha, mas as senhas de usuário e de proprietário não estão vazias e <br/>            nenhuma das senhas foi definida ou a senha fornecida estava incorreta. Portanto, é impossível deduzir o tipo da senha. |
