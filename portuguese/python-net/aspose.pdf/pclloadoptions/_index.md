## PclLoadOptions class

Representa opções para carregar (importar) arquivo PCL em documento PDF.

O tipo PclLoadOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| PclLoadOptions() | Inicializa uma nova instância da classe PclLoadOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| warning_handler | Retorno de chamada para lidar com quaisquer avisos gerados. <br/>            O WarningHandler retorna o item enum ReturnAction especificando Continue ou Abort. <br/>            Continue é a ação padrão e a operação de Load continua, porém o usuário também pode retornar Abort, caso em que a operação de Load deve ser interrompida. |
| load_format | Representa o formato de arquivo que [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) descreve. |
| batch_size | Define o tamanho do lote se a conversão em lote for aplicável<br/>            ao par de formatos de origem e destino. |
| conversion_engine | Define o mecanismo de conversão que será usado para a conversão |
| supress_errors | Obtém ou define o valor booleano que indica se os erros de conversão PCL devem ser suprimidos. |
