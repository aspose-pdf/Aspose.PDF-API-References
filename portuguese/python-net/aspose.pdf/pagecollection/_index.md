## PageCollection class

Coleção de páginas de documento PDF.

O tipo PageCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| is_synchronized | Retorna true se o objeto está sincronizado. |
| sync_root | Obtém o objeto de sincronização da coleção. |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém a página por índice. |
## Métodos
| Nome | Descrição |
| :- | :- |
| add(entidade) | Adiciona página à coleção. |
| add() | Adiciona página à coleção. |
| add(pages) | Adiciona à coleção todas as páginas da lista. |
| add(pages) | Adiciona à coleção todas as páginas do array. |
| delete(index) | Exclui a página especificada. |
| delete() | Exclui a página especificada. |
| delete(pages) | Exclui as páginas cujos números são especificados no array. |
| accept(visitor) | Aceita o objeto visitante [AnnotationSelector](/pdf/python-net/aspose.pdf.annotations/annotationselector/) que fornece funcionalidade para trabalhar com anotações. |
| accept(visitor) | Aceita o objeto visitante [ImagePlacementAbsorber](/pdf/python-net/aspose.pdf/imageplacementabsorber/) que fornece funcionalidade para trabalhar com objetos de posicionamento de imagem. |
| accept(visitor) | Aceita o objeto visitante [TextFragmentAbsorber](/pdf/python-net/aspose.pdf.text/textfragmentabsorber/) que fornece funcionalidade para trabalhar com objetos de texto. |
| accept(visitor) | Aceita o objeto visitante [TextAbsorber](/pdf/python-net/aspose.pdf.text/textabsorber/) que fornece funcionalidade para trabalhar com objetos de texto. |
| insert(page_number) | Insere página vazia na coleção na posição especificada. |
| insert(page_number, entity) | Insere página vazia na coleção na posição especificada. |
| insert(page_number, pages) | Insere páginas da coleção no documento. |
| insert(page_number, pages) | Insere páginas do array no documento. |
| index_of(entity) | Retorna o índice da página especificada. |
| flatten() | Remove todos os campos localizados nas páginas e coloca seus valores no lugar. |
| free_memory() | Limpa os dados em cache |
