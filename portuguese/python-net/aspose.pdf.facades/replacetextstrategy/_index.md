## ReplaceTextStrategy class

Esta classe contém parâmetros que definem o comportamento do PdfContentEditor quando a operação ReplaceText é executada.

O tipo ReplaceTextStrategy expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| ReplaceTextStrategy() | Inicializa uma nova instância da classe ReplaceTextStrategy |
## Propriedades
| Nome | Descrição |
| :- | :- |
| is_regular_expression_used | Se false, a string a ser encontrada é um texto simples. Se true, a string a ser encontrada é uma expressão regular. |
| no_character_behavior | Ação que é executada quando nenhuma fonte apropriada é encontrada para o texto alterado<br/>            (Lançar exceção / Substituir por outra fonte / Substituir mesmo assim). |
| replace_scope | Escopo da operação de substituição (substituir a primeira ocorrência ou substituir todas as ocorrências). |
