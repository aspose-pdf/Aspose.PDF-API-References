## TextProperties class

Representa propriedades de texto como: tamanho do texto, cor, estilo etc.

O tipo TextProperties expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TextProperties(text_size) | Inicializa uma nova instância da classe TextProperties |
## Propriedades
| Nome | Descrição |
| :- | :- |
| cor | Obtém ou define a cor do texto. |
| is_color_specified | Obtém ou define um valor que indica se a propriedade [color](/pdf/python-net/aspose.pdf.facades/textproperties/) está especificada. |
| text_size | Obtém ou define o tamanho do texto. |
| is_text_size_specified | Obtém ou define um valor que indica se a propriedade [text_size](/pdf/python-net/aspose.pdf.facades/textproperties/) está especificada. |
