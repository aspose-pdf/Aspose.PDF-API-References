## FormFieldFacade class

Classe para representar propriedades de campo.

O tipo FormFieldFacade expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| FormFieldFacade() | Inicializa uma nova instância da classe FormFieldFacade |
## Propriedades
| Nome | Descrição |
| :- | :- |
| border_color | A cor da borda de um campo. |
| border_style | O estilo da borda de um campo. |
| border_width | A largura da borda de um campo. |
| font | O tipo de fonte do texto de um campo. |
| custom_font | Obtém ou define o nome da fonte quando esta não é padrão (outras que as 14 fontes padrão). |
| font_size | O tamanho do texto de um campo. |
| text_color | A cor do texto do campo. |
| text_encoding | O tipo de codificação de texto do campo. |
| alinhamento | O alinhamento do texto de um campo, o padrão é alinhamento à esquerda. |
| rotation | A rotação do texto de um campo. |
| caption | A legenda normal do campo de formulário. |
| button_style | O estilo do campo de caixa de seleção ou botão de opção, definido por FormFieldFacade.CheckBoxStyle*. |
| box | Um objeto retângulo que contém a localização do campo. |
| position | Um objeto retângulo que contém a localização do campo. |
| page_number | Um valor inteiro que contém o número da página onde o campo está localizado. |
| items | Uma matriz de strings, cada uma representando uma opção de um campo de caixa de combinação/lista/botão de opção. |
| export_items | As opções para adicionar uma lista/caixa de combinação/botão de opção |
| background_color | A cor de fundo de um campo, o padrão é branco. |

| BORDER_STYLE_SOLID | Define um estilo de borda sólido. |
| BORDER_STYLE_DASHED | Define um estilo de borda tracejado. |
| BORDER_STYLE_BEVELED | Define um estilo de borda chanfrado. |
