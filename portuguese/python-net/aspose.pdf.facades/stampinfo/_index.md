## StampInfo class

Classe que representa informações de carimbo.

O tipo StampInfo expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| stamp_id | Obtém o identificador do selo. |
| index_on_page | Obtém o índice do selo na página. |
| stamp_type | Obtém o tipo de selo (imagem / formulário). |
| rectangle | Obtém o retângulo onde o selo está colocado. |
| image | Obtém a imagem do selo. Pode ser nulo se o selo não contiver imagens (por exemplo, para selo de texto). |
| formulário | Obtém XForm do selo. |
| text | Obtém o texto no selo. |
| visível | Obtém a visibilidade do selo. Se false então o selo está oculto (com HideStampById). O selo oculto pode ser restaurado por ShowStampById. |
