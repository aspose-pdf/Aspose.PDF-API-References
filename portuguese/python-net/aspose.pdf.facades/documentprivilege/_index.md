## DocumentPrivilege class

Representa os privilégios para acessar um arquivo PDF. Consulte [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             Existem 4 maneiras de usar esta classe:<br/>             1. Usando privilégio predefinido diretamente.<br/>             2. Baseado em um privilégio predefinido e alterando algumas permissões específicas.<br/>             3. Baseado em um privilégio predefinido e alterando alguma combinação específica de permissões do Adobe Professional.<br/>             4. Mistura as maneiras 2 e 3.

O tipo DocumentPrivilege expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| allow_print | Define a permissão que permite imprimir ou não. <br/>            true permite e false proíbe. |
| allow_degraded_printing | Define a permissão que permite impressão degradada ou não. <br/>            true permite e false proíbe. |
| allow_modify_contents | Define a permissão que permite modificar o conteúdo ou não. <br/>            true permite e false proíbe. |
| allow_copy | Define a permissão que permite copiar ou não. <br/>            true permite e false proíbe. |
| allow_modify_annotations | Define a permissão que permite modificar anotações ou não. <br/>            true permite e false proíbe. |
| allow_fill_in | Define a permissão que permite preencher formulários ou não. <br/>            true permite e false proíbe. |
| allow_screen_readers | Define a permissão que permite leitores de tela ou não. <br/>            true permite e false proíbe. |
| allow_assembly | Define a permissão que permite montagem ou não. <br/>            true permite e false proíbe. |
| degraded_printing | Permite impressão degradada. |
| print | Permite imprimir o arquivo. |
| modify_contents | Permite modificar o arquivo. |
| copy | Permite copiar o arquivo. |
| modify_annotations | Permite modificar anotações do arquivo. |
| fill_in | Permite preencher formulários no arquivo. |
| screen_readers | Permite apenas leitura na tela. |
| assembly | Permite montar o arquivo. |
| allow_all | Tudo permitido. |
| forbid_all | Tudo proibido. |
