## ViewerPreference class

Descreve as preferências do visualizador (modo de página, modo de página não em tela cheia, layout da página).

O tipo ViewerPreference expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| ViewerPreference() | Inicializa uma nova instância da classe ViewerPreference |
## Propriedades
| Nome | Descrição |
| :- | :- |
| PAGE_MODE_USE_OC | Painel de grupo de conteúdo opcional visível. |
| DISPLAY_DOC_TITLE | Um sinalizador que especifica se a barra de título da janela deve exibir o título do documento |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | Painel de grupo de conteúdo opcional visível. |
| PAGE_LAYOUT_SINGLE_PAGE | Exibe uma página por vez. |
| PAGE_LAYOUT_ONE_COLUMN | Exibe as páginas em uma coluna. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | Exibir as páginas em duas colunas, com páginas ímpares à direita |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | Exibir as páginas em duas colunas, com páginas ímpares à direita. |
| PAGE_MODE_USE_NONE | Nem o contorno do documento nem as miniaturas são visíveis |
| PAGE_MODE_USE_OUTLINES | Contorno do documento visível. |
| PAGE_MODE_USE_THUMBS | Miniaturas visíveis. |
| PAGE_MODE_FULL_SCREEN | Modo de tela cheia, sem barra de menus, controles de janela ou qualquer outra janela visível. |
| PAGE_MODE_USE_ATTACHMENT | Modo de página com anexos. |
| HIDE_TOOLBAR | Um sinalizador que especifica se deve ocultar as barras de ferramentas do leitor compatível quando o documento está ativo. |
| HIDE_MENUBAR | Um sinalizador que especifica se deve ocultar a barra de menus do leitor compatível quando o documento está ativo. |
| HIDE_WINDOW_UI | Um sinalizador que especifica se deve ocultar os elementos da interface do usuário na janela do documento (como barras de rolagem e controles de navegação), deixando apenas o conteúdo do documento exibido. |
| FIT_WINDOW | Um sinalizador que especifica se deve redimensionar a janela do documento para se ajustar ao tamanho da primeira página exibida. |
| CENTER_WINDOW | Um sinalizador que especifica se deve posicionar a janela do documento no centro da tela. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | Nem o contorno do documento nem as imagens em miniatura são visíveis. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | Contorno do documento visível. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | Imagens em miniatura visíveis |
| DIRECTION_L2R | Ordem de leitura do texto da esquerda para a direita. |
| DIRECTION_R2L | Ordem de leitura do texto da direita para a esquerda. |
| SIMPLEX | Imprimir em um lado apenas. |
| DUPLEX_FLIP_SHORT_EDGE | Duplex e virar na borda curta da folha. |
| DUPLEX_FLIP_LONG_EDGE | Duplex e virar na borda curta da folha. |
