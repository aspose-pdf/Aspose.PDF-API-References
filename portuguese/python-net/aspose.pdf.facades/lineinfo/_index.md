## LineInfo class

Representa as informações da linha.

O tipo LineInfo expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| LineInfo() | Inicializa uma nova instância da classe LineInfo |
## Propriedades
| Nome | Descrição |
| :- | :- |
| vertice_coordinate | Obtém ou define um array de números que representam as coordenadas horizontais e verticais alternadas, respectivamente, de cada vértice. |
| line_color | Obtém ou define a cor de uma linha. |
| line_width | Obtém ou define a largura de uma linha. |
| visibility | Obtém ou define a visibilidade de uma linha. |
| line_dash_pattern | Obtém ou define o padrão de traço de uma linha. |
| border_style | Obtém ou define o estilo de borda de uma linha, 0 representa sólido, 1 representa tracejado, 2 representa beleved, 3 representa inserção, 4 representa sublinhado. |
