## Bookmark class

Representa um marcador.

O tipo Bookmark expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| Bookmark() | Inicializa uma nova instância da classe Bookmark |
## Propriedades
| Nome | Descrição |
| :- | :- |
| ação | Obtém ou define a ação vinculada ao bookmark.<br/>            Se PageNumber for apresentado, a ação não pode ser especificada.<br/>            O tipo de ação inclui: "GoTo", "GoToR", "Launch", "Named". |
| bold_flag | Obtém ou define o indicador de negrito do título do bookmark. |
| child_item | Obtém ou define os filhos do bookmark. |
| child_items | Obtém ou define os filhos do bookmark. |
| destination | Obtém ou define a página de destino do marcador. Obrigatório se a ação for definida como string.Empty. |
| italic_flag | Obtém ou define a flag itálico do título do marcador. |
| level | Obtém ou define o nível hierárquico do marcador. |
| page_display | Obtém ou define o tipo de exibição da página de destino do marcador. |
| page_display_bottom | Obtém ou define a coordenada inferior da exibição da página. |
| page_display_left | Obtém ou define a coordenada esquerda da exibição da página. |
| page_display_right | Obtém ou define a coordenada direita da exibição da página. |
| page_display_top | Obtém ou define a coordenada superior da exibição da página. |
| page_display_zoom | Obtém ou define o fator de zoom da exibição da página. |
| page_number | Obtém ou define o número da página de destino do marcador. |
| remote_file | Obtém ou define o arquivo (caminho) necessário para a ação "GoToR" do marcador. |
| title | Obtém ou define o título do marcador. |
| title_color | Obtém ou define a cor do título do marcador. |
| open | Obtém ou define o estado do marcador (aberto, fechado). |
