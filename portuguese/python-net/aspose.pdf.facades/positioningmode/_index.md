## PositioningMode enumeration

Define o modo de posicionamento.<br/>            Valores possíveis incluem Legacy (compatibilidade retroativa) e <br/>            Current (método atualizado de cálculo de posição de texto)

## Members
| Nome do membro | Descrição |
| :- | :- |
| LEGACY | Posicionamento de texto legado |
| MODERN_LINE_SPACING | Espaçamento de linha atualizado, o cálculo da posição vertical é feito pelas regras antigas <br/>            (ou seja, o texto é posicionado em relação ao canto inferior esquerdo do retângulo especificado) |
| CURRENT | Espaçamento de linha atualizado e o cálculo da posição vertical é feito com base no canto superior esquerdo em vez do canto inferior esquerdo. |
