## KeySize enumeration

Define diferentes tamanhos de chave que podem ser usados para criptografar documentos PDF.

## Members
| Nome do membro | Descrição |
| :- | :- |
| X40 | Chave de 40 bits. Esse tamanho de chave é usado com o algoritmo RC4 e fornece baixo nível de segurança. <br/>            No entanto, as versões antigas de documentos PDF só podem ser criptografadas com essas chaves (v. 1.3 e inferiores); |
| X128 | Chave de 128 bits. Tanto os algoritmos RC4 quanto AES podem usar esse tamanho de chave. |
| X256 | Chave de 256 bits. Esse tamanho de chave pode ser usado apenas com AES e é reconhecido nas versões mais recentes do Adobe Reader (a partir da v.9). |
