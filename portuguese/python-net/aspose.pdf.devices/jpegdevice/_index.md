## JpegDevice class

Representa um dispositivo de imagem que ajuda a salvar as páginas de documentos PDF em jpeg.

O tipo JpegDevice expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| JpegDevice() | Inicializa uma nova instância da classe [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) com resolução padrão e qualidade máxima. |
| JpegDevice(resolution) | Inicializa uma nova instância da classe JpegDevice |
| JpegDevice(quality) | Inicializa uma nova instância da classe JpegDevice |
| JpegDevice(resolution, quality) | Inicializa uma nova instância da classe JpegDevice |
| JpegDevice(width, height) | Inicializa uma nova instância da classe JpegDevice |
| JpegDevice(page_size) | Inicializa uma nova instância da classe JpegDevice |
| JpegDevice(width, height, resolution) | Inicializa uma nova instância da classe JpegDevice |
| JpegDevice(page_size, resolution) | Inicializa uma nova instância da classe JpegDevice |
| JpegDevice(width, height, resolution, quality) | Inicializa uma nova instância da classe JpegDevice |
| JpegDevice(page_size, resolution, quality) | Inicializa uma nova instância da classe JpegDevice |
## Propriedades
| Nome | Descrição |
| :- | :- |
| coordinate_type | Obtém ou define o tipo de coordenada da página (caixas Media/Crop). O valor CropBox é usado por padrão. |
| rendering_options | Obtém ou define as opções de renderização. |
| form_presentation_mode | Obtém ou define o modo de apresentação do formulário. |
| resolution | Obtém a resolução da imagem. |
| largura | Obtém a largura de saída da imagem. |
| altura | Obtém a altura de saída da imagem. |
## Métodos
| Nome | Descrição |
| :- | :- |
| process(page, output) | Converte a página em jpeg e a salva no fluxo de saída. |
| process(page, output_file_name) | Converte a página em jpeg e a salva no fluxo de saída. |
