## ImageDevice class

Uma classe abstrata para dispositivos de imagem.

O tipo ImageDevice expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| coordinate_type | Obtém ou define o tipo de coordenada da página (caixas Media/Crop). O valor CropBox é usado por padrão. |
| rendering_options | Obtém ou define as opções de renderização. |
| form_presentation_mode | Obtém ou define o modo de apresentação do formulário. |
| resolution | Obtém a resolução da imagem. |
| largura | Obtém a largura de saída da imagem. |
| altura | Obtém a altura de saída da imagem. |
## Métodos
| Nome | Descrição |
| :- | :- |
| process(page, output) | Executa alguma operação na página fornecida, por exemplo, converte a página em uma imagem gráfica. |
| process(page, output_file_name) | Executa alguma operação na página fornecida e salva os resultados no arquivo. |
