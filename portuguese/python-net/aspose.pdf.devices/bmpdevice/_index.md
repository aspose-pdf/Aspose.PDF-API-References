## BmpDevice class

Representa um dispositivo de imagem que ajuda a salvar as páginas de documentos PDF em bmp.

O tipo BmpDevice expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| BmpDevice() | Inicializa uma nova instância da classe [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) com resolução padrão. |
| BmpDevice(resolution) | Inicializa uma nova instância da classe BmpDevice |
| BmpDevice(width, height, resolution) | Inicializa uma nova instância da classe BmpDevice |
| BmpDevice(page_size, resolution) | Inicializa uma nova instância da classe BmpDevice |
| BmpDevice(width, height) | Inicializa uma nova instância da classe BmpDevice |
| BmpDevice(page_size) | Inicializa uma nova instância da classe BmpDevice |
## Propriedades
| Nome | Descrição |
| :- | :- |
| coordinate_type | Obtém ou define o tipo de coordenada da página (caixas Media/Crop). O valor CropBox é usado por padrão. |
| rendering_options | Obtém ou define as opções de renderização. |
| form_presentation_mode | Obtém ou define o modo de apresentação do formulário. |
| resolution | Obtém a resolução da imagem. |
| largura | Obtém a largura de saída da imagem. |
| altura | Obtém a altura de saída da imagem. |
## Métodos
| Nome | Descrição |
| :- | :- |
| process(page, output) | Converte a página para bmp e a salva no fluxo de saída. |
| process(page, output_file_name) | Converte a página para bmp e a salva no fluxo de saída. |
