## Propriedades
| Nome | Descrição |
| :- | :- |
| margens | Obtém as margens. |
| skip_blank_pages | Obtém ou define um valor que indica se deve pular páginas em branco. |
| compressão | Obtém ou define o tipo da compressão. |
| profundidade | Obtém ou define a profundidade de cor. |
| forma | Obtém ou define o tipo da forma. |
| brilho | Obtém ou define um limite de valor da transformação de cores em branco e preto.<br/>            Este parâmetro pode ser aplicado com EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle ou ColorDepth.Format1bpp == 1 |
| coordinate_type | Obtém ou define o tipo de coordenada da página (caixas Media/Crop). O valor CropBox é usado por padrão. |
