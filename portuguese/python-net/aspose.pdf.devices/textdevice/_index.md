## TextDevice class

Representa a classe para converter páginas do documento PDF em texto.

O tipo TextDevice expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TextDevice(extraction_options) | Inicializa uma nova instância da classe TextDevice |
| TextDevice() | Inicializa uma nova instância do [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) com o modo de formatação de texto bruto e codificação de texto Unicode. |
| TextDevice(encoding) | Inicializa uma nova instância da classe TextDevice |
| TextDevice(extraction_options, encoding) | Inicializa uma nova instância da classe TextDevice |
## Propriedades
| Nome | Descrição |
| :- | :- |
| extraction_options | Obtém ou define opções de extração de texto. |
| codificação | Obtém ou define a codificação do texto extraído. |
