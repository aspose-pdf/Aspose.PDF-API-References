## PngDevice class

Representa o dispositivo de imagem que ajuda a salvar páginas do documento PDF em PNG.

O tipo PngDevice expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| PngDevice() | Inicializa uma nova instância da classe [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) com resolução padrão. |
| PngDevice(resolution) | Inicializa uma nova instância da classe PngDevice |
| PngDevice(width, height, resolution) | Inicializa uma nova instância da classe PngDevice |
| PngDevice(page_size, resolution) | Inicializa uma nova instância da classe PngDevice |
| PngDevice(width, height) | Inicializa uma nova instância da classe PngDevice |
| PngDevice(page_size) | Inicializa uma nova instância da classe PngDevice |
## Propriedades
| Nome | Descrição |
| :- | :- |
| coordinate_type | Obtém ou define o tipo de coordenada da página (caixas Media/Crop). O valor CropBox é usado por padrão. |
| rendering_options | Obtém ou define as opções de renderização. |
| form_presentation_mode | Obtém ou define o modo de apresentação do formulário. |
| resolution | Obtém a resolução da imagem. |
| largura | Obtém a largura de saída da imagem. |
| altura | Obtém a altura de saída da imagem. |
| transparent_background | Obtém ou define se a imagem tem fundo transparente. |
## Métodos
| Nome | Descrição |
| :- | :- |
| process(page, output) | Converte a página em png e a salva no fluxo de saída. |
| process(page, output_file_name) | Converte a página em png e a salva no fluxo de saída. |
