## ThumbnailDevice class

Representa o dispositivo de imagem que salva páginas do documento PDF em imagem miniatura.

O tipo ThumbnailDevice expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| ThumbnailDevice() | Inicializa uma nova instância da classe [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) <br/>            com tamanho padrão da imagem miniatura (200x200 pixels). |
| ThumbnailDevice(width, height) | Inicializa uma nova instância da classe ThumbnailDevice |
## Propriedades
| Nome | Descrição |
| :- | :- |
| coordinate_type | Obtém ou define o tipo de coordenada da página (caixas Media/Crop). O valor CropBox é usado por padrão. |
| rendering_options | Obtém ou define as opções de renderização. |
| form_presentation_mode | Obtém ou define o modo de apresentação do formulário. |
| resolution | Obtém a resolução da imagem. |
| largura | Obtém a largura de saída da imagem. |
| altura | Obtém a altura de saída da imagem. |
## Métodos
| Nome | Descrição |
| :- | :- |
| process(page, output) | Converte a página para imagem miniatura png e a salva no fluxo de saída. |
| process(page, output_file_name) | Converte a página para imagem miniatura png e a salva no fluxo de saída. |
