## CompressionType enumeration

Usado para especificar o valor do parâmetro passado para um dispositivo de imagem TIFF.

## Members
| Nome do membro | Descrição |
| :- | :- |
| LZW | Especifica o esquema de compressão LZW. Pode ser passado para o codificador Tiff como um parâmetro que pertence à categoria Compressão. |
| CCITT4 | Especifica o esquema de compressão CCITT4. Pode ser passado para o codificador CCITT4 como um parâmetro que pertence à categoria Compressão. |
| CCITT3 | Especifica o esquema de compressão CCITT3. Pode ser passado para o codificador CCITT3 como um parâmetro que pertence à categoria Compressão. |
| RLE | Especifica o esquema de compressão RLE. Pode ser passado para o codificador RLE como um parâmetro que pertence à categoria Compressão. |
| NONE | Especifica nenhuma compressão. Pode ser passado para o codificador Tiff como um parâmetro que pertence à categoria compressão. |
