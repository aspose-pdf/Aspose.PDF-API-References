## EmfDevice class

Representa um dispositivo de imagem que ajuda a salvar as páginas de documentos PDF em emf.

O tipo EmfDevice expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| EmfDevice() | Inicializa uma nova instância da classe [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) com resolução padrão da imagem raster gravada em emf. |
| EmfDevice(resolution) | Inicializa uma nova instância da classe EmfDevice |
| EmfDevice(width, height) | Inicializa uma nova instância da classe EmfDevice |
| EmfDevice(page_size) | Inicializa uma nova instância da classe EmfDevice |
| EmfDevice(width, height, resolution) | Inicializa uma nova instância da classe EmfDevice |
| EmfDevice(page_size, resolution) | Inicializa uma nova instância da classe EmfDevice |
## Propriedades
| Nome | Descrição |
| :- | :- |
| coordinate_type | Obtém ou define o tipo de coordenada da página (caixas Media/Crop). O valor CropBox é usado por padrão. |
| rendering_options | Obtém ou define as opções de renderização. |
| form_presentation_mode | Obtém ou define o modo de apresentação do formulário. |
| resolution | Obtém a resolução da imagem. |
| largura | Obtém a largura de saída da imagem. |
| altura | Obtém a altura de saída da imagem. |
## Métodos
| Nome | Descrição |
| :- | :- |
| process(page, output) | Converte a página em emf e a salva no fluxo de saída. |
| process(page, output_file_name) | Converte a página em emf e a salva no fluxo de saída. |
