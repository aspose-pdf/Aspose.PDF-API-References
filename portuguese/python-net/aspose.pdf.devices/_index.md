O namespace aspose.pdf.devices fornece classes usadas para representar o documento como imagem(s) ou texto simples. Assim, o documento pode ser enviado para dispositivos textuais ou gráficos variados, o que significa que queremos obter sua representação textual ou gráfica.

## Classes
| Classe | Descrição |
| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | Representa um dispositivo de imagem que ajuda a salvar as páginas de documentos PDF em bmp. |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | Classe abstrata para todos os tipos de dispositivos. O dispositivo é usado para representar o documento PDF em algum formato.<br/>            Por exemplo, a página do documento pode ser representada como imagem ou texto. |
| [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) | Representa um dispositivo de imagem que ajuda a salvar as páginas de documentos PDF no formato Dicom. |
| [DocumentDevice](/pdf/python-net/aspose.pdf.devices/documentdevice/) | Classe abstrata para todos os dispositivos que são usados para processar todo o documento PDF. |
| [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) | Representa um dispositivo de imagem que ajuda a salvar as páginas de documentos PDF em emf. |
| [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) | Representa um dispositivo de imagem que ajuda a salvar as páginas de documentos PDF em gif. |
| [ImageDevice](/pdf/python-net/aspose.pdf.devices/imagedevice/) | Uma classe abstrata para dispositivos de imagem. |
| [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) | Representa um dispositivo de imagem que ajuda a salvar as páginas de documentos PDF em jpeg. |
| [Margins](/pdf/python-net/aspose.pdf.devices/margins/) | Esta classe representa as margens de uma imagem. |
| [PageDevice](/pdf/python-net/aspose.pdf.devices/pagedevice/) | Classe abstrata para todos os dispositivos que são usados para processar determinada página do documento PDF. |
| [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) | Representa o dispositivo de imagem que ajuda a salvar páginas do documento PDF em PNG. |
| [Resolution](/pdf/python-net/aspose.pdf.devices/resolution/) | Representa a classe que mantém a resolução da imagem. |
| [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) | Representa a classe para converter páginas do documento PDF em texto. |
| [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) | Representa o dispositivo de imagem que salva páginas do documento PDF em imagem miniatura. |
| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | Esta classe ajuda a salvar páginas do documento PDF, uma a uma, em uma única imagem TIFF. |
| [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) | Esta classe representa as configurações para importar PDF para TIFF. |
