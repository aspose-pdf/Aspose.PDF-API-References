## AnnotationElement class

Representa uma classe base para elementos de estrutura de anotação na estrutura lógica.

O tipo AnnotationElement expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| parent_element | Nenhum |
| child_elements | Nenhum |
| default_attribute_owner | Obtém |
| atributos | Obtém |
| structure_type | Obtém o tipo do elemento de estrutura. |
| id | Obtém o ID do elemento de estrutura. |
| title | Obtém ou define o título do elemento de estrutura. |
| idioma | Obtém ou define o idioma para o elemento de estrutura. |
| alternative_text | Obtém ou define o texto alternativo para o elemento de estrutura. |
| expansion_text | Obtém ou define o texto de expansão para o elemento de estrutura. |
| actual_text | Obtém ou define o texto real para o elemento de estrutura. |
| alternate_descriptions | Obtém ou define as Descrições Alternativas para a anotação.<br/>                Texto que deve ser exibido para a anotação ou, se este tipo de anotação não exibir texto, uma descrição alternativa do conteúdo da anotação em forma legível por humanos. |
## Métodos
| Nome | Descrição |
| :- | :- |
| append_child(element) | Nenhum |
| change_parent_element(new_parent_element) | Alterar o elemento pai para o elemento de estrutura atual |
| generate_id() | Gerar ID para o elemento de estrutura. |
| set_id(id) | Define o ID para o elemento de estrutura. |
| clear_id() | Limpar ID para o elemento de estrutura. |
| set_tag(new_tag) | Define a tag personalizada para o elemento de estrutura. |
