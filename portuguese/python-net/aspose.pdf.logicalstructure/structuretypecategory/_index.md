## StructureTypeCategory class

Representa as Categorias de Tipos de Estrutura Padrão.

O tipo StructureTypeCategory expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| GROUPING_ELEMENTS | Elementos de agrupamento agrupam outros elementos em sequências ou hierarquias, mas não contêm conteúdo diretamente e não têm efeito direto no layout. |
| BLS_ES | Elementos de estrutura em nível de bloco (BLSEs) descrevem o layout geral do conteúdo na página, avançando na direção de progressão de bloco. |
| ILS_ES | Elementos de estrutura em nível inline (ILSEs) descrevem o layout do conteúdo dentro de um BLSE, avançando na direção de progressão inline. |
| ILLUSTRATION_ELEMENTS | Elementos de ilustração são sequências compactas de conteúdo, na ordem de conteúdo da página, que são considerados objetos unitários em relação ao layout da página. Uma ilustração pode ser tratada como um BLSE ou um ILSE. |
