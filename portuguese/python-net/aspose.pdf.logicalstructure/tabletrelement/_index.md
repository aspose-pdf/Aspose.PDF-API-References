## TableTRElement class

Representa o elemento de estrutura TR na estrutura lógica da tabela.

O tipo TableTRElement expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| parent_element | Nenhum |
| child_elements | Nenhum |
| default_attribute_owner | Obtém |
| atributos | Obtém |
| structure_type | Obtém o tipo do elemento de estrutura. |
| id | Obtém o ID do elemento de estrutura. |
| title | Obtém ou define o título do elemento de estrutura. |
| idioma | Obtém ou define o idioma para o elemento de estrutura. |
| alternative_text | Obtém ou define o texto alternativo para o elemento de estrutura. |
| expansion_text | Obtém ou define o texto de expansão para o elemento de estrutura. |
| actual_text | Obtém ou define o texto real para o elemento de estrutura. |
| background_color | Obtém ou define a cor de fundo da linha. |
| borda | Obtém ou define a borda da linha. |
| default_cell_border | Obtém a borda padrão da célula. |
| min_row_height | Obtém a altura da linha. |
| fixed_row_height | Obtém a altura fixa da linha – a linha pode ter altura fixa. |
| is_in_new_page | Obtém se a linha fixa está em uma nova página – a página com esta propriedade deve ser impressa na página seguinte. Padrão falso. |
| is_row_broken | Obtém se a linha pode ser quebrada entre duas páginas. |
| default_cell_text_state | Obtém ou define o estado de texto padrão para as células da linha |
| default_cell_padding | Obtém ou define a margem padrão para as células da linha. |
| vertical_alignment | Obtém ou define o alinhamento vertical. |
## Métodos
| Nome | Descrição |
| :- | :- |
| append_child(element) | Nenhum |
| change_parent_element(new_parent_element) | Alterar o elemento pai para o elemento de estrutura atual |
| generate_id() | Gerar ID para o elemento de estrutura. |
| set_id(id) | Define o ID para o elemento de estrutura. |
| clear_id() | Limpar ID para o elemento de estrutura. |
| set_tag(new_tag) | Define a tag personalizada para o elemento de estrutura. |
| create_th() | Cria [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/) e o adiciona à tabela atual. |
| create_td() | Cria [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/) e o adiciona à tabela atual. |
