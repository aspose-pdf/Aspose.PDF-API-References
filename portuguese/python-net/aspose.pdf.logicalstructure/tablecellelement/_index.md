## TableCellElement class

Representa uma classe base para elementos de célula de tabela (TH e TD) na estrutura lógica.

O tipo TableCellElement expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| parent_element | Nenhum |
| child_elements | Nenhum |
| default_attribute_owner | Obtém |
| atributos | Obtém |
| structure_type | Obtém o tipo do elemento de estrutura. |
| id | Obtém o ID do elemento de estrutura. |
| title | Obtém ou define o título do elemento de estrutura. |
| idioma | Obtém ou define o idioma para o elemento de estrutura. |
| alternative_text | Obtém ou define o texto alternativo para o elemento de estrutura. |
| expansion_text | Obtém ou define o texto de expansão para o elemento de estrutura. |
| actual_text | Obtém ou define o texto real para o elemento de estrutura. |
| background_color | Obtém ou define a cor de fundo da célula. |
| borda | Obtém ou define a borda da célula. |
| is_no_border | Obtém ou define se a célula tem borda. |
| margem | Obtém ou define o preenchimento. |
| alinhamento | Obtém ou define o alinhamento da célula. |
| default_cell_text_state | Obtém ou define o estado de texto padrão da célula. |
| is_word_wrapped | Obtém ou define se o texto da célula está com quebra de linha. |
| vertical_alignment | Obtém ou define o alinhamento vertical. |
| col_span | Obtém ou define a extensão da coluna. |
| row_span | Obtém ou define a extensão da linha. |
| structure_text_state | Obtém |
## Métodos
| Nome | Descrição |
| :- | :- |
| append_child(element) | Nenhum |
| change_parent_element(new_parent_element) | Alterar o elemento pai para o elemento de estrutura atual |
