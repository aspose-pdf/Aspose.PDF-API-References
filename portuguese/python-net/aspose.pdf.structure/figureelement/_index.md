## FigureElement class

Classe que representa a figura da estrutura lógica.

O tipo FigureElement expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| children | Obtém a coleção de elementos filhos. |
| lang | (Opcional; PDF 1.4) Um idioma que especifica a língua natural para todo o texto<br/>            no elemento de estrutura, exceto onde for substituído por especificações de idioma para elementos de estrutura aninhados<br/>            ou conteúdo marcado. |
| actual_text | (Opcional; PDF 1.4) Texto que é uma substituição exata para o elemento de estrutura e seus filhos.<br/>            Este texto de substituição (que deve ser aplicado ao menor trecho de conteúdo possível)<br/>            é útil ao extrair o conteúdo do documento em apoio à acessibilidade para usuários<br/>            com deficiência ou para outros fins. |
| alt | (Opcional) Uma descrição alternativa do elemento de estrutura e seus filhos em<br/>            forma legível por humanos, que é útil ao extrair o conteúdo do documento em apoio<br/>            à acessibilidade para usuários com deficiência ou para outros fins. |
| e | (Opcional; PDF 1.5) A forma expandida de uma abreviação. |
| image | Obtém o valor do elemento de estrutura de figura. |
