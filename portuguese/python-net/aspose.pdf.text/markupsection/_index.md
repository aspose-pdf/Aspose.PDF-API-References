## MarkupSection class

Representa uma seção de marcação - a região retangular de uma página que contém texto e pode ser visualmente separada de outros blocos de texto.

O tipo MarkupSection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| rectangle | Retângulo da seção |
| fragments | Coleção de objetos [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) não vazios que estão dentro da seção. |
| paragraphs | Coleção de objetos [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) que estão dentro da seção. |
