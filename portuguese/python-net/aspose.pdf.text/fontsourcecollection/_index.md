## FontSourceCollection class

Representa a coleção de origens de fontes.

O tipo FontSourceCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| sync_root | Obtém um objeto que pode ser usado para sincronizar o acesso à coleção. |
| is_synchronized | Obtém um valor que indica se o acesso à coleção está sincronizado (thread safe). |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém o elemento de fonte no índice especificado. |
## Métodos
| Nome | Descrição |
| :- | :- |
| delete(font_source) | Exclui o elemento de fonte. |
