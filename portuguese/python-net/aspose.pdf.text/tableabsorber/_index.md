## TableAbsorber class

Representa um objeto absorvedor de elementos de tabela.<br/>            Executa busca e fornece acesso aos resultados da busca via coleção [table_list](/pdf/python-net/aspose.pdf.text/tableabsorber/).

O tipo TableAbsorber expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TableAbsorber(text_search_options) | Inicializa uma nova instância da classe TableAbsorber |
| TableAbsorber() | Inicializa uma nova instância do [TableAbsorber](/pdf/python-net/aspose.pdf.text/tableabsorber/). |
## Propriedades
| Nome | Descrição |
| :- | :- |
| text_search_options | Obtém ou define as opções de pesquisa de texto. |
| table_list | Retorna IList somente leitura contendo as tabelas que foram encontradas |
| use_flow_engine | * Ativar uma versão alfa inicial do mecanismo alternativo de reconhecimento de tabelas que pode ser usado para converter tabelas <br/>            sem bordas.<br/>            Ainda não suporta edição de tabelas e obtenção de estilos de texto. O valor padrão é false; |
