## TextReplaceOptions class

Representa opções de substituição de texto

O tipo TextReplaceOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TextReplaceOptions(scope) | Inicializa uma nova instância da classe TextReplaceOptions |
| TextReplaceOptions(adjustment) | Inicializa uma nova instância da classe TextReplaceOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| replace_scope | Obtém ou define um escopo onde a operação de substituição de texto é aplicada |
| replace_adjustment_action | Obtém ou define uma ação que será executada após a substituição do fragmento de texto para algo mais curto. |
| adjustment_new_line_spacing | Obtém ou define o valor do espaçamento entre linhas que é usado se o ajuste de substituição for forçado a criar uma nova linha de texto.<br/>            O valor esperado é um multiplicador do tamanho da fonte do texto substituído. O padrão é 1.2. |
