## TextSegment class

Representa um segmento de texto PDF.

O tipo TextSegment expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TextSegment() | Cria um objeto TextSegment. |
| TextSegment(text) | Inicializa uma nova instância da classe TextSegment |
## Propriedades
| Nome | Descrição |
| :- | :- |
| start_char_index | Obtém o índice do caractere inicial do segmento atual no operador de exibição de texto (Tj, TJ) do segmento. |
| end_char_index | Obtém o índice do caractere final do segmento atual no operador de exibição de texto (Tj, TJ) do segmento. |
| text | Obtém ou define o objeto de texto string que o objeto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) representa. |
| text_state | Obtém ou define o estado do texto para o texto que o objeto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) representa. |
| position | Obtém a posição do texto para o texto, representado pelo objeto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| rectangle | Obtém o retângulo do TextSegment |
| baseline_position | Obtém a posição do texto para o texto, representado pelo objeto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/).<br/>            O YIndent da estrutura Position representa a coordenada da linha de base do segmento de texto. |
| text_edit_options | Obtém ou define opções de edição de texto. As opções definem comportamento especial quando o símbolo solicitado não pode ser escrito com a fonte. |
| caracteres | Obtém a coleção de objetos CharInfo que representam informações sobre os caracteres no segmento de texto. |
| hiperlink | Obtém ou define o hyperlink do segmento (para gerador de PDF). |
