## TextFormattingOptions class

Representa opções de formatação de texto

O tipo TextFormattingOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TextFormattingOptions(wrap_mode) | Inicializa uma nova instância da classe TextFormattingOptions |
| TextFormattingOptions() | Inicializa uma nova instância do objeto [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) com modo de quebra de linha indefinido. |
## Propriedades
| Nome | Descrição |
| :- | :- |
| wrap_mode | Obtém ou define o modo de quebra de linha.<br/>            O valor padrão é WordWrapMode.NoWrap |
| line_spacing | Obtém ou define o modo de espaçamento de linha.<br/>            O valor padrão é LineSpacingMode.FontSize |
| hyphen_symbol | Obtém ou define o símbolo de hífen usado no processo de hifenização. |
| subsequent_lines_indent | Obtém ou define o valor de recuo das linhas subsequentes. |
| first_line_indent | Obtém ou define o valor de recuo da primeira linha. |
