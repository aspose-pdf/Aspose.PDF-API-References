## TextEditOptions class

Descreve opções de operações de edição de texto.

O tipo TextEditOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TextEditOptions(no_character_behavior) | Inicializa uma nova instância da classe TextEditOptions |
| TextEditOptions(font_replace_behavior) | Inicializa uma nova instância da classe TextEditOptions |
| TextEditOptions(allow_language_transformation) | Inicializa uma nova instância da classe TextEditOptions |
| TextEditOptions(language_transformation_behavior) | Inicializa uma nova instância da classe TextEditOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| replacement_font | Obtém ou define a fonte usada para substituição caso a fonte do usuário não contenha o caractere necessário |
| no_character_behavior | Obtém ou define o modo que define o comportamento caso as fontes não contenham os caracteres solicitados. |
| font_replace_behavior | Obtém o modo que define o comportamento para cenários de substituição de fontes. |
| allow_language_transformation | Obtém ou define o valor que permite o uso de transformação de idioma durante a adição ou edição de texto.<br/>            true - a transformação de idioma será aplicada se necessário (valor padrão).<br/>            false - a transformação de idioma NÃO será aplicada. |
| language_transformation_behavior | Obtém o modo que define o comportamento para cenários de transformação de idioma. |
| clipping_paths_processing | Obtém o modo para o processamento do caminho de recorte do texto editado. |
| to_attempt_get_underline_from_source | Obtém ou define o valor que permite a busca por sublinhado de texto na página do documento de origem.<br/>            (Obsoleto) Por favor, use TextSearchOptions.SearchForTextRelatedGraphics em vez disso. |
