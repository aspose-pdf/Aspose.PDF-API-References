## TextExtractionOptions class

Representa opções de extração de texto

O tipo TextExtractionOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TextExtractionOptions(formatting_mode) | Inicializa uma nova instância da classe TextExtractionOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| formatting_mode | Obtém o modo de formatação. |
| scale_factor | Obtém ou define o fator que será aplicado para escalar o tamanho da fonte durante a extração no modo puro.<br/>            Definir um valor menor resulta em mais espaços no texto extraído.<br/>            O valor padrão é 1 - sem escala;<br/>            Definir o valor como zero permite que o algoritmo escolha a escala automaticamente. |
