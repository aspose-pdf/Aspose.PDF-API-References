## TextExtractionError class

Descreve o erro de extração de texto que apareceu no documento PDF.

O tipo TextExtractionError expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| summary | Descrição breve do erro. |
| descrição | Descrição expandida do erro. |
| location | Localização do erro. |
| font_key | Chave (nome PDF) do objeto Font usado para exibir o texto que causa o erro de extração. |
| font_name | Nome legível (interno) do objeto Font usado para exibir o texto que causa o erro de extração. |
| extracted_text | Texto que foi realmente extraído. |
