## MarkupParagraph class

Representa um parágrafo.

O tipo MarkupParagraph expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| pontos | Pontos do polígono que descreve o parágrafo.<br/>            O ponto inicial está no canto inferior esquerdo do parágrafo. E os próximos pontos estão em sequência anti-horária. |
| secondary_points | Pontos do polígono secundário que descrevem a continuação do parágrafo. Não será nulo se o parágrafo for continuado na próxima coluna ou página.<br/>            O ponto inicial está no canto inferior esquerdo do parágrafo. E os próximos pontos estão em sequência anti-horária. |
| continuation_page_numbers | Lista de números de página nos quais o parágrafo é continuado. Corresponderá à página onde o parágrafo começou se ele continuar na próxima coluna na mesma página. |
| fragments | Coleção de objetos [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) não vazios do parágrafo. |
| linhas | Linhas do parágrafo. Cada linha é representada por uma lista de fragmentos de texto. |
| text | Obtém o objeto de texto string que o objeto [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) representa. |
