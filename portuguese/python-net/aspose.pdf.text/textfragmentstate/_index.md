## TextFragmentState class

Representa o estado de texto de um fragmento de texto.

O tipo TextFragmentState expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| TextFragmentState(fragment) | Inicializa uma nova instância da classe TextFragmentState |
## Propriedades
| Nome | Descrição |
| :- | :- |
| character_spacing | Obtém ou define o espaçamento de caracteres do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| line_spacing | Obtém ou define o espaçamento entre linhas do texto. |
| horizontal_scaling | Obtém ou define a escala horizontal do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| subscript | Obtém ou define o subscrito do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| superscript | Obtém ou define o sobrescrito do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| word_spacing | Obtém ou define o espaçamento entre palavras do texto. |
| invisível | Obtém ou define a invisibilidade do texto. |
| rendering_mode | Obtém ou define o modo de renderização do texto. |
| font_size | Obtém ou define o tamanho da fonte do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font | Obtém ou define a fonte do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| foreground_color | Obtém ou define a cor de primeiro plano do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| stroking_color | Obtém ou define as operações de traçado de cor da renderização do [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) (texto em traço, borda do retângulo) |
| underline | Obtém ou define o sublinhado para o texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| strike_out | Define o tachado para o texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| background_color | Define a cor de fundo do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font_style | Define o estilo da fonte do texto, representado pelo objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| horizontal_alignment | Obtém ou define o alinhamento horizontal para o texto. |
| TAB_TAG | Você pode colocar esta tag no texto para declarar tabulação. |
| TABSTOP_DEFAULT_VALUE | Valor padrão da tabulação nas larguras do caractere de espaço da fonte padrão. |
| tab_stops | Obtém os tabstops do texto. |
| formatting_options | Obtém ou define opções de formatação.<br/>            A definição das opções será efetiva apenas em cenários de gerador. |
| rotation | Obtém ou define o ângulo de rotação em graus. |
| draw_text_rectangle_border | Obtém ou define se a bandeira de desenho da borda do retângulo de texto está ativada. |
## Métodos
