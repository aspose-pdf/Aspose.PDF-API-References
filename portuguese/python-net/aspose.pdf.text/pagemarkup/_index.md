## PageMarkup class

Marcação de página representada por coleções de [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) e [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/).

O tipo PageMarkup expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| número | Obtém o número da página processada. |
| rectangle | Obtém o retângulo da página processada. |
| sections | Obtém a coleção de [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) que foi encontrada na página. |
| paragraphs | Obtém a coleção de [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) que foi encontrada na página. |
| text_fragments | Obtém a coleção de [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) que foi encontrada na página. |
| is_multicolumn_paragraphs_allowed | Obtém ou define o valor que indica se as linhas de texto iniciais de uma próxima seção podem ser tratadas como continuação do último parágrafo de uma seção anterior. |
