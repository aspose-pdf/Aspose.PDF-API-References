## TextRenderingMode enumeration

O modo de renderização de texto, Tmode, determina se a exibição do texto deve fazer com que os contornos dos glifos sejam traçados, preenchidos, usados como limite de recorte ou alguma combinação dos três.

## Members
| Nome do membro | Descrição |
| :- | :- |
| FILL_TEXT | Preencher texto. |
| STROKE_TEXT | Contornar texto. |
| FILL_THEN_STROKE_TEXT | Preencher, depois contornar texto. |
| INVISIBLE | Nem preenche nem contorna texto (invisível). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Preencher texto e adicionar ao caminho para recorte (veja 9.3.6, "Text Rendering Mode,"). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Contornar texto e adicionar ao caminho para recorte. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Preencher, depois contornar texto e adicionar ao caminho para recorte. |
| ADD_PATH_TO_CLIPPING | Adicionar texto ao caminho para recorte. |
