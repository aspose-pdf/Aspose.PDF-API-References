## SystemFontsSubstitution class

Representa uma classe para estratégia de substituição de fontes que substitui fontes por fontes do sistema.

O tipo SystemFontsSubstitution expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| SystemFontsSubstitution(font_categories) | Inicializa uma nova instância da classe SystemFontsSubstitution |
## Propriedades
| Nome | Descrição |
| :- | :- |
| font_categories | Obtém ou define categorias de fontes de substituição que devem ser substituídas por fontes do sistema. |
| default_font | Obtém ou define a fonte de substituição padrão.<br/>            A fonte é usada quando nenhuma outra substituição válida foi encontrada, mas a fonte inicial pertence à categoria de substituição alvo ([font_categories](/pdf/python-net/aspose.pdf.text/systemfontssubstitution/)). |
