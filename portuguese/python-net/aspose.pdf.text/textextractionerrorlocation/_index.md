## TextExtractionErrorLocation class

Representa a localização no documento PDF onde o erro de extração de texto apareceu.

O tipo TextExtractionErrorLocation expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| path | Localização do documento PDF onde ocorreu o erro de extração de texto. |
| page_number | Número da página do documento onde o erro de extração de texto está localizado. |
| object_type | Tipo do objeto PDF (Page ou xForm) no qual o erro de extração de texto do fluxo de conteúdo está localizado. |
| form_key | Chave (nome) do PDF Form XObject no qual o erro de extração de texto do fluxo de conteúdo está localizado. Não vazia se ObjectType == 'xForm'. |
| operator_index | Índice do operador que exibe texto no fluxo de conteúdo (coleção de operadores) que causa o erro de extração de texto. |
| operator_string | Operador que exibe texto que causa o erro de extração de texto. |
| font_used_key | Chave (nome) do objeto PDF Font que é usado para exibir o operador que causa erro de extração de texto. |
| text_start_point | Chave (nome) do objeto PDF Font que é usado para exibir o operador que causa erro de extração de texto. |
