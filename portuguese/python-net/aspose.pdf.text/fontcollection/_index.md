## FontCollection class

Representa a coleção de fontes.

O tipo FontCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| sync_root | Obtém um objeto que pode ser usado para sincronizar o acesso à coleção. |
| is_synchronized | Obtém um valor que indica se o acesso à coleção está sincronizado (thread safe). |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | Obtém o elemento de fonte no índice especificado. |
## Métodos
| Nome | Descrição |
| :- | :- |
| add(new_font, res_name) | Adiciona uma nova fonte aos recursos de fontes e retorna o nome atribuído automaticamente ao recurso de fonte. |
