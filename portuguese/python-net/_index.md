## Espaços de nomes

| Espaço de nomes | Descrição |
| :- | :- |
| [aspose.pdf](/pdf/python-net/aspose.pdf/) | O aspose.pdf é um espaço de nomes raiz para todas as classes da biblioteca Aspose.Pdf que estão nele diretamente, como Document, ou indiretamente através de vários sub‑namespaces. |
| [aspose.pdf.annotations](/pdf/python-net/aspose.pdf.annotations/) | O namespace aspose.pdf.annotations fornece classes para trabalhar com vários tipos de ações, destinos e outros recursos do documento que tradicionalmente são chamados de interativos, proporcionando meios para que o usuário possa interagir com ele. |
| [aspose.pdf.devices](/pdf/python-net/aspose.pdf.devices/) | O namespace aspose.pdf.devices fornece classes usadas para representar o documento como imagem(s) ou texto simples. Assim, o documento pode ser enviado para dispositivos textuais ou gráficos variados, o que significa que queremos obter sua representação textual ou gráfica. |
| [aspose.pdf.drawing](/pdf/python-net/aspose.pdf.drawing/) | O namespace aspose.pdf.drawing fornece classes que descrevem primitivas gráficas como arco, linha, círculo etc. Os objetos correspondentes podem ser usados para criar novos documentos. |
| [aspose.pdf.facades](/pdf/python-net/aspose.pdf.facades/) | O namespace aspose.pdf.facades fornece classes que originalmente vieram do Aspose.Pdf.Kit. Essas classes são usadas para manipular documentos realizando operações como concatenação, marcação, assinatura, anotação etc., mas em um nível alto, sem acesso à estrutura interna do documento. |
| [aspose.pdf.forms](/pdf/python-net/aspose.pdf.forms/) | O namespace aspose.pdf.forms possui classes que descrevem formulários (padrão, estático, dinâmico) e vários tipos de campos como caixa de texto, caixa de lista, botão de opção etc. |
| [aspose.pdf.groupprocessor](/pdf/python-net/aspose.pdf.groupprocessor/) | O namespace aspose.pdf.groupprocessor fornece classes usadas para trabalhar com texto e fontes. |
| [aspose.pdf.groupprocessor.creators](/pdf/python-net/aspose.pdf.groupprocessor.creators/) | O namespace aspose.pdf.groupprocessor.creators fornece classes usadas para criar instâncias das classes GroupProcessor. |
| [aspose.pdf.logicalstructure](/pdf/python-net/aspose.pdf.logicalstructure/) | O aspose.pdf.logicalstructure é um namespace para classes de Estrutura Lógica de PDF. |
| [aspose.pdf.operators](/pdf/python-net/aspose.pdf.operators/) | O aspose.pdf.operators é um namespace para implementações de Operadores. Essas classes descrevem operadores usados no conteúdo das páginas PDF. |
| [aspose.pdf.optimization](/pdf/python-net/aspose.pdf.optimization/) | O aspose.pdf.optimization é um namespace para classes que gerenciam o processo de otimização de documentos. |
| [aspose.pdf.pdfaoptionclasses](/pdf/python-net/aspose.pdf.pdfaoptionclasses/) | O aspose.pdf.pdfaoptionclasses é um namespace para opções de conversão PDF/A. |
| [aspose.pdf.sanitization](/pdf/python-net/aspose.pdf.sanitization/) | O aspose.pdf.sanitization é um namespace para operações de sanitização. |
| [aspose.pdf.structure](/pdf/python-net/aspose.pdf.structure/) | O namespace aspose.pdf.structure fornece classes que ajudam a trabalhar com a estrutura lógica de um documento, que apresenta a organização do documento em capítulos e seções ou a identificação de elementos especiais como figuras, tabelas e notas de rodapé. |
| [aspose.pdf.tagged](/pdf/python-net/aspose.pdf.tagged/) | O aspose.pdf.tagged é um namespace para classes que dão suporte a documentos PDF Tagged. |
| [aspose.pdf.text](/pdf/python-net/aspose.pdf.text/) | O namespace aspose.pdf.text fornece classes que permitem extrair texto, adicionar texto, manipular o texto existente de um documento. Também contém classes que permitem extrair, substituir e trocar fontes de um documento. |
| [aspose.pdf.xfaconverter](/pdf/python-net/aspose.pdf.xfaconverter/) | O namespace aspose.pdf.xfaconverter fornece classes que permitem converter XFA. |
