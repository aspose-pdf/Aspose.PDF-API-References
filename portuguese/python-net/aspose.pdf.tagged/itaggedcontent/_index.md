## ITaggedContent class

Representa a interface para trabalhar com o conteúdo TaggedPdf do documento.

O tipo ITaggedContent expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| structure_text_state | Obtenha as configurações de [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) para todo o documento. |
| struct_tree_root_element | Obtém o [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/) do documento PDF. |
| root_element | Obtém o elemento raiz [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) da estrutura lógica do documento PDF. |
