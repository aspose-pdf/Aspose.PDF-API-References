## AnnotationState enumeration

A enumeração dos estados nos quais a anotação original pode ser definida.

## Members
| Nome do membro | Descrição |
| :- | :- |
| UNDEFINED | Estado não definido. |
| MARKED | A anotação foi marcada pelo usuário. |
| UNMARKED | A anotação não foi marcada pelo usuário. |
| ACCEPTED | O usuário concorda com a alteração. |
| REJECTED | O usuário discorda da alteração. |
| CANCELLED | A alteração foi cancelada. |
| CONCLUÍDO | A alteração foi concluída. |
| NONE | O usuário não indicou nada sobre a alteração. |
