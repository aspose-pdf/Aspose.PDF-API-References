## SoundData class

Representa dados de som que definem o áudio a ser reproduzido quando a anotação é ativada.

O tipo SoundData expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| rate | Obtém ou define a taxa de amostragem, em amostras por segundo. |
| canais | Obtém ou define o número de canais de áudio. |
| bits | Obtém ou define o número de bits por valor de amostra por canal. |
| conteúdo | Obtém o fluxo do som a ser reproduzido quando a anotação é ativada. |
| codificação | Obtém ou define o formato de codificação dos dados de amostra. |
