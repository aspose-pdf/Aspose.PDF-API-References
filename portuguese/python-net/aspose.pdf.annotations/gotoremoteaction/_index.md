## GoToRemoteAction class

Representa uma ação ir-para remota que é semelhante a uma ação ir-para comum, mas salta para um destino em outro arquivo PDF em vez do arquivo atual.

O tipo GoToRemoteAction expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| GoToRemoteAction(remote_pdf, remote_page_number) | Inicializa uma nova instância da classe GoToRemoteAction |
| GoToRemoteAction(remote_pdf, destination) | Inicializa uma nova instância da classe GoToRemoteAction |
## Propriedades
| Nome | Descrição |
| :- | :- |
| próximo | Próximas ações em sequência. |
| destination | Obtém ou define o destino para o qual pular. |
| file | Obtém ou define a especificação do arquivo no qual o destino está localizado. |
