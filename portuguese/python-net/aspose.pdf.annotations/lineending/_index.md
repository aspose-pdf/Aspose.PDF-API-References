## LineEnding enumeration

Enumera os estilos de terminação de linha a serem usados ao desenhar a linha.

## Members
| Nome do membro | Descrição |
| :- | :- |
| NONE | Sem terminação de linha. |
| QUADRADO | Um quadrado preenchido com a cor interior da anotação, se houver. |
| CIRCLE | Um círculo preenchido com a cor interior da anotação, se houver. |
| DIAMANTE | Uma forma de diamante preenchida com a cor interior da anotação, se houver. |
| OPEN_ARROW | Duas linhas curtas que se encontram em um ângulo agudo para formar uma ponta de seta aberta. |
| CLOSED_ARROW | Duas linhas curtas que se encontram em um ângulo agudo como no estilo OpenArrow e conectadas por uma terceira linha para formar uma ponta de seta fechada triangular preenchida com a cor interior da anotação, se houver. |
| BUTT | Uma linha curta no ponto final perpendicular à própria linha. |
| R_OPEN_ARROW | Duas linhas curtas na direção oposta ao OpenArrow. |
| R_CLOSED_ARROW | Uma ponta de seta fechada triangular na direção oposta ao ClosedArrow. |
| SLASH | Uma linha curta no ponto final aproximadamente 30 graus no sentido horário a partir da perpendicular à própria linha. |
