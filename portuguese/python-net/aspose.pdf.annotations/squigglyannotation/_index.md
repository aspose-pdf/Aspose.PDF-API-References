## SquigglyAnnotation class

Representa a anotação ondulada que aparece como um sublinhado irregular no texto de um documento.

O tipo SquigglyAnnotation expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| SquigglyAnnotation(page, rect) | Inicializa uma nova instância da classe SquigglyAnnotation |
