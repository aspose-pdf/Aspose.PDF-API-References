## DefaultAppearance class

Descreve a aparência padrão do campo (fonte, tamanho do texto e cor).

O tipo DefaultAppearance expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| DefaultAppearance() | Construtor de DefaultAppearance. |
| DefaultAppearance(font_name, font_size, text_color) | Inicializa uma nova instância da classe DefaultAppearance |
| DefaultAppearance(font, font_size, text_color) | Inicializa uma nova instância da classe DefaultAppearance |
## Propriedades
| Nome | Descrição |
| :- | :- |
| font_size | Obtém o tamanho da fonte na aparência padrão. |
| text_color | Obtém ou define a cor do texto na aparência padrão. |
| font_name | Obtém o nome da fonte na aparência padrão. |
| font_resource_name | Obtém o nome da fonte na aparência padrão. |
| font | Obtém a fonte especificada como padrão para texto. |
| text | Obtém a lista de operadores pdf que representam a aparência. |
