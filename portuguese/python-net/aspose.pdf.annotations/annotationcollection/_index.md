## AnnotationCollection class

Classe que representa a coleção de anotações.

O tipo AnnotationCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| is_synchronized | Obtém um valor que indica se o acesso ao Aspose.Pdf.Annotations.AnnotationCollection está sincronizado (thread safe). |
| sync_root | Obtém um objeto que pode ser usado para sincronizar o acesso ao Aspose.Pdf.Annotations.AnnotationCollection. |
## Indexer
| Nome | Descrição |
| :- | :- |
| [index] | O índice do elemento a ser obtido. |
## Métodos
| Nome | Descrição |
| :- | :- |
| delete(index) | Exclui a anotação da coleção por índice. |
| delete() | Exclui a anotação da coleção por índice. |
| delete(annotation) | Exclui a anotação da coleção por índice. |
| add(annotation, consider_rotation) | Adiciona anotação à coleção. Se a página estiver girada, então o retângulo da anotação será recalculado de acordo. |
| accept(visitor) | Aceita visitante para processar a anotação. |
| find_by_name(name) | Retorna a anotação pelo seu nome. |
