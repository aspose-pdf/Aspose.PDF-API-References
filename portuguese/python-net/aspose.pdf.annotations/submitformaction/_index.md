## SubmitFormAction class

Classe que descreve a ação submit-form.

O tipo SubmitFormAction expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| SubmitFormAction() | Inicializa o objeto SubmitFormAction. |
## Propriedades
| Nome | Descrição |
| :- | :- |
| próximo | Próximas ações em sequência. |
| sinalizadores | Obtém ou define as flags da ação de envio. |
| url | URL de destino. |
| EXCLUDE | Se limpo, o array Fields especifica quais campos incluir na submissão. |
| INCLUDE_NO_VALUE_FIELDS | Se definido, todos os campos designados pelo array Fields e pela flag Include/Exclude serão enviados. |
| EXPORT_FORMAT | Se definido, os nomes e valores dos campos serão enviados no formato HTML Form. |
| GET_METHOD | Se definido, os nomes e valores dos campos serão enviados usando uma requisição HTTP GET. |
| SUBMIT_COORDINATES | Se definido, as coordenadas do clique do mouse que causou a ação submit-form serão transmitidas como parte dos dados do formulário. |
| XFDF | Se definido, os nomes e valores dos campos serão enviados como XFDF. |
| INCLUDE_APPEND_SAVES | Se definido, o arquivo FDF enviado incluirá o conteúdo de todas as atualizações incrementais. |
| INCLUDE_ANNOTATIONS | Se definido, o arquivo FDF enviado incluirá todas as anotações de marcação no documento PDF subjacente. |
| SUBMIT_PDF | Se definido, o documento será enviado como PDF, usando o tipo de conteúdo MIME application/pdf. |
| CANONICAL_FORMAT | Se definido, quaisquer valores de campo enviados que representem datas serão convertidos para o formato padrão. |
| EXCL_NON_USER_ANNOTS | Se definido, incluirá apenas as anotações de marcação cujo campo T corresponda ao nome do usuário atual. |
| EXCL_F_KEY | Se definido, o FDF enviado excluirá a entrada F. |
| EMBED_FORM | Se definido, a entrada F do FDF enviado será uma especificação de arquivo contendo um <br/>            fluxo de arquivo incorporado que representa o arquivo PDF do qual o FDF está sendo enviado. |
