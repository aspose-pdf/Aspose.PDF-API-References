## AnnotationActionCollection class

Representa a coleção de ações de anotação.

O tipo AnnotationActionCollection expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| on_enter | Obtém ou define uma ação a ser executada quando o cursor entra na área ativa da anotação. |
| on_exit | Obtém ou define uma ação a ser executada quando o cursor sai da área ativa da anotação. |
| on_press_mouse_btn | Obtém ou define uma ação a ser executada quando o botão do mouse é pressionado dentro da área ativa da anotação. |
| on_release_mouse_btn | Obtém ou define uma ação a ser executada quando o botão do mouse é liberado dentro da área ativa da anotação. |
| on_receive_focus | Obtém ou define uma ação a ser executada quando a anotação recebe o foco de entrada. |
| on_open_page | Obtém ou define uma ação a ser executada quando a página que contém a anotação é aberta. |
| on_close_page | Obtém ou define uma ação a ser executada quando a página que contém a anotação é fechada. |
| on_show_page | Obtém ou define uma ação a ser executada quando a página que contém a anotação se torna visível na interface do usuário do aplicativo visualizador. |
| on_hide_page | Obtém ou define uma ação a ser executada quando a página que contém a anotação não está mais visível na interface do usuário da aplicação visualizadora. |
| on_lost_focus | Obtém ou define uma ação a ser executada quando a anotação perde o foco de entrada. |
| on_modify_character | Obtém ou define uma ação a ser executada quando o usuário modifica o caractere do campo. |
| on_validate | Obtém ou define uma ação a ser executada quando o usuário altera o conteúdo do campo. |
| on_format | Obtém ou define uma ação a ser executada para formatar o valor do campo. |
| on_calculate | Obtém ou define uma ação para calcular o valor do campo. |
## Métodos
| Nome | Descrição |
| :- | :- |
| remove_actions() | Remove todas as ações da anotação. |
