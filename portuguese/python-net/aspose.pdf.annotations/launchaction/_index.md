## LaunchAction class

Representa uma ação de lançamento que inicia um aplicativo ou abre ou imprime um documento.

O tipo LaunchAction expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| LaunchAction(file) | Inicializa uma nova instância da classe LaunchAction |
| LaunchAction(document, file) | Inicializa uma nova instância da classe LaunchAction |
## Propriedades
| Nome | Descrição |
| :- | :- |
| próximo | Próximas ações em sequência. |
| file | Obtém ou define o aplicativo a ser iniciado ou o documento a ser aberto ou impresso. |
| new_window | Obtém ou define um sinalizador que especifica se o documento de destino deve ser aberto em uma nova janela (afeta apenas documentos PDF). |
