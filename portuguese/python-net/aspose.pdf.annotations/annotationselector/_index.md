## AnnotationSelector class

Esta classe é usada para selecionar anotações usando a ideia de modelo Visitor.

O tipo AnnotationSelector expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| AnnotationSelector() | Inicializa uma nova instância da classe AnnotationSelector. |
| AnnotationSelector(annotation) | Inicializa uma nova instância da classe AnnotationSelector |
## Propriedades
| Nome | Descrição |
| :- | :- |
| selecionado | A lista de objetos selecionados. |
