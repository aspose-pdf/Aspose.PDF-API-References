## HighlightingMode enumeration

Enumera o modo de realce da anotação, o efeito visual a ser usado quando o botão do mouse é pressionado ou mantido dentro de sua área ativa.

## Members
| Nome do membro | Descrição |
| :- | :- |
| NONE | Sem realce. |
| INVERT | Inverte o conteúdo do retângulo da anotação. |
| OUTLINE | Inverte a borda da anotação. |
| PUSH | Exibe a aparência inferior da anotação, se houver. Se nenhuma aparência inferior estiver definida, desloca o conteúdo do retângulo da anotação para que pareça estar sendo empurrado abaixo da superfície da página. |
| TOGGLE | Mesmo que Push (que é o preferido). |
