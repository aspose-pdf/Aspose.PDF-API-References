## XfaParserOptions class

classe para manipular a encapsulação de dados relacionados

O tipo XfaParserOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| XfaParserOptions(page_size) | Inicializa uma nova instância da classe XfaParserOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| page_size | Obtém ou define o tamanho da página. |
| assinado | Se esta propriedade for verdadeira, o documento será convertido usando o fluxo de formulário xfa (se existir).<br/>            Se for falsa, o fluxo de formulário xfa será ignorado.<br/>            Esta propriedade foi introduzida porque não está claro como calcular a soma de verificação usada para validar a assinatura. |
| emulate_requierd_groups | Se esta propriedade for verdadeira, retângulos vermelhos adicionais serão desenhados para os "grupos excluídos" Xfa necessários<br/>            Esta propriedade foi introduzida devido à ausência de equivalentes dos grupos excluídos durante a conversão da representação Xfa dos formulários <br/>            para o padrão.<br/>            É falsa por padrão. |
| base_path | Obtém ou define o caminho base. |
