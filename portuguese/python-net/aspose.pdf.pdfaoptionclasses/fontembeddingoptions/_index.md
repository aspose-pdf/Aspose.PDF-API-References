## FontEmbeddingOptions class

O padrão PDF/A requer que todas as fontes sejam incorporadas ao documento.<br/>            Esta classe inclui sinalizadores para casos em que não é possível incorporar alguma fonte porque essa fonte está ausente <br/>            no PC de destino.

O tipo FontEmbeddingOptions expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| FontEmbeddingOptions() | Inicializa uma nova instância da classe FontEmbeddingOptions |
## Propriedades
| Nome | Descrição |
| :- | :- |
| use_default_substitution | Declara a substituição de fonte não incorporada usando a estratégia padrão de substituição de fontes. Por padrão, false; |
