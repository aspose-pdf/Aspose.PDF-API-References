## BasicSetColorOperator class

Classe base para operadores set color.

O tipo BasicSetColorOperator expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| índice | Índice do operador na lista de operadores da página. |
| r | Obtém o componente vermelho da cor |
| g | Obtém o componente verde da cor |
| b | Obtém o componente vermelho da cor |
| c | Obtém o componente ciano da cor CMYK. |
| m | Obtém o componente magenta da cor CMYK. |
| y | Obtém o componente amarelo da cor CMYK. |
| k | Obtém o componente preto da cor CMYK. |
| grey | Obtém o componente preto da cor cinza. |
| cor | Obtém a matriz de componentes de cor. |
## Métodos
| Nome | Descrição |
| :- | :- |
| accept(visitor) | Aceita o visitante IOperatorSelector que fornece o processamento de operadores. |
| is_text_show_operator(op) | Determina se o operador é o operador responsável pela saída de texto (Tj, TJ, etc) |
| get_color() | Retorna a cor especificada pelo operador. |
