## Re class

Classe que representa o operador re (adiciona retângulo ao caminho).

## Construtores
| Nome | Descrição |
| :- | :- |
| Re() | Inicializa o operador. |
| Re(x, y, width, height) | Inicializa uma nova instância da classe Re |
## Propriedades
| Nome | Descrição |
| :- | :- |
| índice | Índice do operador na lista de operadores da página. |
| x | Coordenada X do lado mais esquerdo do retângulo. |
| y | Coordenada Y do lado inferior do retângulo. |
