## SetColor class

Representa a classe para o operador sc (define a cor para operações sem traçado).

O tipo SetColor expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| SetColor() | Inicializa o operador. |
| SetColor(g) | Inicializa uma nova instância da classe SetColor |
| SetColor(r, g, b) | Inicializa uma nova instância da classe SetColor |
| SetColor(c, m, y, k) | Inicializa uma nova instância da classe SetColor |
| SetColor(color) | Inicializa uma nova instância da classe SetColor |
## Propriedades
| Nome | Descrição |
| :- | :- |
| índice | Nenhum |
| r | Obtém o componente vermelho da cor |
| g | Obtém o componente verde da cor |
| b | Obtém o componente vermelho da cor |
| c | Obtém o componente ciano da cor CMYK. |
| m | Obtém o componente magenta da cor CMYK. |
| y | Obtém o componente amarelo da cor CMYK. |
| k | Obtém o componente preto da cor CMYK. |
| grey | Obtém o componente preto da cor cinza. |
| cor | Obtém a matriz de componentes de cor. |
