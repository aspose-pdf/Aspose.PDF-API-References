## Do class

Classe representando o operador Do (Invocar XObject).

O tipo Do expõe os seguintes membros:
## Construtores
| Nome | Descrição |
| :- | :- |
| Do(name) | Inicializa uma nova instância da classe Do |
| Do() | Constrói um novo operador Do. <br/>            Usado para recuperar todos os operadores Do, ou seja, sem verificar seus nomes de argumento. |
## Propriedades
| Nome | Descrição |
| :- | :- |
| índice | Índice do operador na lista de operadores da página. |
| nome | Nome do argumento XObject do operador. |
## Métodos
| Nome | Descrição |
| :- | :- |
| accept(visitor) | Aceita objeto visitante para processar o operador. |
| is_text_show_operator(op) | Determina se o operador é o operador responsável pela saída de texto (Tj, TJ, etc) |
