## IPdfTypeExtractor class

Representa a interface para interagir com o extrator.

O tipo IPdfTypeExtractor expõe os seguintes membros:
## Propriedades
| Nome | Descrição |
| :- | :- |
| page_count | Retorna a contagem de páginas. |
| version | Retorna a versão. |
| is_fast_extraction_used | Retorna se o mecanismo de extração rápida foi usado. |
## Métodos
| Nome | Descrição |
| :- | :- |
| extract_all_text() | Retorna a coleção de valores de texto extraídos. |
| extract_page_text(page_number) | Retorna o texto da página. |
| dispose() | Liberar. |
