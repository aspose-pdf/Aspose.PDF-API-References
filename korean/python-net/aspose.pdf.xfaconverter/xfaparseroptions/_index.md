## XfaParserOptions class

관련 데이터 캡슐화를 처리하는 클래스

XfaParserOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| XfaParserOptions(page_size) | XfaParserOptions 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| page_size | 페이지 크기를 가져오거나 설정합니다. |
| signed | 이 속성이 true이면 문서는 xfa 폼 스트림(존재하는 경우)을 사용하여 변환됩니다.<br/>            false인 경우 xfa 폼 스트림은 무시됩니다.<br/>            이 속성은 서명을 확인하는 데 사용되는 체크섬을 계산하는 방법이 명확하지 않아 도입되었습니다. |
| emulate_requierd_groups | 이 속성이 true이면 필수 Xfa "excluded groups"에 대해 추가 빨간 사각형이 그려집니다.<br/>            이 속성은 양식의 Xfa 표현을 표준으로 변환하는 동안 excluded groups의 유사 항목이 없기 때문에 도입되었습니다.<br/>            기본값은 false입니다. |
| base_path | 기본 경로를 가져오거나 설정합니다. |
