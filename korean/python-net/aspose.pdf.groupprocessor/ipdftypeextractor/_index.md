## IPdfTypeExtractor class

추출기와 상호 작용하기 위한 인터페이스를 나타냅니다.

IPdfTypeExtractor 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| page_count | 페이지 수를 반환합니다. |
| version | 버전을 반환합니다. |
| is_fast_extraction_used | 빠른 추출 메커니즘이 사용되었는지 반환합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| extract_all_text() | 추출된 텍스트 값들의 컬렉션을 반환합니다. |
| extract_page_text(page_number) | 페이지 텍스트를 반환합니다. |
| dispose() | 해제합니다. |
