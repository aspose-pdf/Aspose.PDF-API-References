## FigureElement class

논리 구조 도형을 나타내는 클래스.

FigureElement 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| children | 자식 요소 컬렉션을 가져옵니다. |
| lang | (Optional; PDF 1.4) 구조 요소의 모든 텍스트에 대한 자연어를 지정하는 언어이며,<br/>            중첩 구조 요소 또는 표시된 콘텐츠에 대한 언어 지정으로 재정의되는 경우는 제외됩니다. |
| actual_text | (Optional; PDF 1.4) 구조 요소와 그 자식에 대한 정확한 대체 텍스트입니다.<br/>            이 대체 텍스트는 (가능한 한 작은 콘텐츠 조각에 적용되어야 하며)<br/>            장애가 있는 사용자를 위한 접근성 지원이나 기타 목적을 위해 문서 내용을 추출할 때 유용합니다. |
| alt | (Optional) 구조 요소와 그 하위 요소에 대한 대체 설명을 <br/>            인간이 읽을 수 있는 형태로 제공하며, 장애가 있는 사용자를 위한 접근성 <br/>            지원이나 기타 목적을 위해 문서 내용을 추출할 때 유용합니다. |
| e | (Optional; PDF 1.5) 약어의 전체 형태. |
| image | 그림 구조 요소의 값을 가져옵니다. |
