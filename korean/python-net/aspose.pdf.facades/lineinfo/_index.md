## LineInfo class

선에 대한 정보를 나타냅니다.

LineInfo 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| LineInfo() | LineInfo 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| vertice_coordinate | 각 정점의 교대로 가로 및 세로 좌표를 각각 나타내는 숫자 배열을 가져오거나 설정합니다. |
| line_color | 선의 색상을 가져오거나 설정합니다. |
| line_width | 라인의 너비를 가져오거나 설정합니다. |
| visibility | 라인의 가시성을 가져오거나 설정합니다. |
| line_dash_pattern | 라인의 대시 패턴을 가져오거나 설정합니다. |
| border_style | 라인의 테두리 스타일을 가져오거나 설정합니다. 0은 실선, 1은 대시, 2는 beleved, 3은 insert, 4는 underline을 나타냅니다. |
