## ReplaceTextStrategy class

이 클래스는 ReplaceText 작업이 수행될 때 PdfContentEditor 동작을 정의하는 매개변수를 포함합니다.

ReplaceTextStrategy 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ReplaceTextStrategy() | ReplaceTextStrategy 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| is_regular_expression_used | false이면 찾을 문자열은 일반 텍스트입니다. true이면 찾을 문자열은 정규식입니다. |
| no_character_behavior | 변경된 텍스트에 적절한 글꼴이 없을 때 수행되는 작업<br/>            (예외 발생 / 다른 글꼴 대체 / 그대로 교체). |
| replace_scope | 교체 작업의 범위 (첫 번째 발생만 교체하거나 모든 발생을 교체). |
