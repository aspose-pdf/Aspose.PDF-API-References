## StampInfo class

스탬프 정보를 나타내는 클래스입니다.

The StampInfo 유형은 다음 멤버를 제공합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| stamp_id | 스탬프의 식별자를 가져옵니다. |
| index_on_page | 페이지에서 스탬프 인덱스를 가져옵니다. |
| stamp_type | 스탬프 유형을 가져옵니다 (이미지 / 양식). |
| rectangle | 스탬프가 배치된 사각형을 가져옵니다. |
| image | 스탬프의 이미지를 가져옵니다. 스탬프에 이미지가 포함되지 않은 경우(예: 텍스트 스탬프) null일 수 있습니다. |
| form | 스탬프의 XForm을 가져옵니다. |
| text | 스탬프의 텍스트를 가져옵니다. |
| visible | 스탬프의 가시성을 가져옵니다. false이면 스탬프가 숨겨집니다(HideStampById 사용). 숨겨진 스탬프는 ShowStampById로 복원할 수 있습니다. |
