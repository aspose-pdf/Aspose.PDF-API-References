## FormFieldFacade class

필드 속성을 나타내는 클래스.

FormFieldFacade 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| FormFieldFacade() | FormFieldFacade 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| border_color | 필드 테두리의 색상입니다. |
| border_style | 필드 테두리의 스타일입니다. |
| border_width | 필드 테두리의 너비입니다. |
| font | 필드 텍스트의 글꼴 유형입니다. |
| custom_font | 표준이 아닌 경우(14개의 표준 글꼴 외) 글꼴 이름을 가져오거나 설정합니다. |
| font_size | 필드 텍스트의 크기입니다. |
| text_color | 필드 텍스트의 색상입니다. |
| text_encoding | 필드 텍스트의 텍스트 인코딩 유형입니다. |
| 정렬 | 필드 텍스트의 정렬이며, 기본값은 왼쪽 정렬입니다. |
| rotation | 필드 텍스트의 회전입니다. |
| caption | 폼 필드의 일반 캡션입니다. |
| button_style | FormFieldFacade.CheckBoxStyle*에 의해 정의된 체크 박스 또는 라디오 박스 필드의 스타일입니다. |
| box | 필드 위치를 보유하는 사각형 객체입니다. |
| position | 필드 위치를 보유하는 사각형 객체입니다. |
| page_number | 필드가 위치한 페이지 번호를 보유하는 정수 값입니다. |
| items | 콤보 박스/리스트/라디오 박스 필드의 옵션을 각각 나타내는 문자열 배열입니다. |
| export_items | 리스트/콤보/라디오 박스를 추가하기 위한 옵션입니다. |
| background_color | 필드 배경의 색상이며, 기본값은 흰색입니다. |
| backgroud_color | 사용되지 않는 속성입니다. BackgroundColor를 사용하십시오. |
| BORDER_WIDTH_UNDIFIED | 정의되지 않은 테두리 두께입니다. |
| BORDER_WIDTH_UNDEFINED | 정의되지 않은 테두리 두께입니다. |
| BORDER_WIDTH_THIN | 얇은 테두리 두께를 정의합니다. |
| BORDER_WIDTH_MEDIUM | 중간 두께의 테두리 너비를 정의합니다. |
| BORDER_WIDTH_THICK | 두꺼운 테두리 너비를 정의합니다. |
| BORDER_STYLE_SOLID | 실선 테두리 스타일을 정의합니다. |
| BORDER_STYLE_DASHED | 대시(점선) 테두리 스타일을 정의합니다. |
| BORDER_STYLE_BEVELED | 베벨(경사) 테두리 스타일을 정의합니다. |
| BORDER_STYLE_INSET | 삽입된 테두리 스타일을 정의합니다. |
| BORDER_STYLE_UNDERLINE | 밑줄이 있는 테두리 스타일을 정의합니다. |
| BORDER_STYLE_UNDEFINED | 정의되지 않은 테두리 스타일. |
| ALIGN_LEFT | 왼쪽 정렬 스타일을 정의합니다. |
| ALIGN_CENTER | 가운데 정렬 스타일을 정의합니다. |
| ALIGN_RIGHT | 오른쪽 정렬 스타일을 정의합니다. |
| ALIGN_UNDEFINED | 정의되지 않은 정렬 스타일. |
| ALIGN_JUSTIFIED | 텍스트 양쪽 맞춤 정렬 스타일을 정의합니다. |
| ALIGN_TOP | 수직 정렬을 상단 스타일로 정의합니다. |
| ALIGN_MIDDLE | 수직 정렬을 중간 스타일로 정의합니다. |
| ALIGN_BOTTOM | 수직 정렬을 하단 스타일로 정의합니다. |
| CHECK_BOX_STYLE_CIRCLE | 원형 체크 박스 스타일을 정의합니다. |
| CHECK_BOX_STYLE_CHECK | 체크 박스가 선택된 경우 필드의 모양을 정의합니다. |
| CHECK_BOX_STYLE_CROSS | 십자형 체크 박스 스타일을 정의합니다. |
| CHECK_BOX_STYLE_DIAMOND | 다이아몬드 체크 박스 스타일을 정의합니다. |
| CHECK_BOX_STYLE_STAR | 별 모양 체크 박스 스타일을 정의합니다. |
| CHECK_BOX_STYLE_SQUARE | 사각형 체크 박스 스타일을 정의합니다. |
| CHECK_BOX_STYLE_UNDEFINED | 정의되지 않은 체크 박스 스타일을 정의합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| reset() | 모든 시각적 속성을 빈 값으로 재설정합니다. |
