## DocumentPrivilege class

PDF 파일에 접근하기 위한 권한을 나타냅니다. [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/)를 참조하십시오.<br/>             이 클래스를 사용하는 4가지 방법이 있습니다:<br/>             1. 미리 정의된 권한을 직접 사용합니다.<br/>             2. 미리 정의된 권한을 기반으로 일부 특정 권한을 변경합니다.<br/>             3. 미리 정의된 권한을 기반으로 특정 Adobe Professional 권한 조합을 변경합니다.<br/>             4. 방법 2와 방법 3을 혼합합니다.

DocumentPrivilege 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| allow_print | 인쇄를 허용할지 여부를 설정합니다. <br/>            true는 허용, false는 금지입니다. |
| allow_degraded_printing | 저품질 인쇄를 허용할지 여부를 설정합니다. <br/>            true는 허용, false는 금지입니다. |
| allow_modify_contents | 내용 수정을 허용할지 여부를 설정합니다. <br/>            true는 허용, false는 금지입니다. |
| allow_copy | 복사를 허용할지 여부를 설정합니다. <br/>            true는 허용, false는 금지됩니다. |
| allow_modify_annotations | 주석 수정을 허용할지 여부를 설정합니다. <br/>            true는 허용, false는 금지됩니다. |
| allow_fill_in | 양식 입력을 허용할지 여부를 설정합니다. <br/>            true는 허용, false는 금지됩니다. |
| allow_screen_readers | 스크린 리더를 허용할지 여부를 설정합니다. <br/>            true는 허용, false는 금지됩니다. |
| allow_assembly | 조립을 허용할지 여부를 설정합니다. <br/>            true는 허용, false는 금지됩니다. |
| degraded_printing | 품질이 낮은 인쇄를 허용합니다. |
| print | 파일 인쇄를 허용합니다. |
| modify_contents | 파일 수정을 허용합니다. |
| copy | 파일 복사를 허용합니다. |
| modify_annotations | 파일의 주석 수정을 허용합니다. |
| fill_in | 파일 내 양식 입력을 허용합니다. |
| screen_readers | 스크린에서만 읽기를 허용합니다. |
| assembly | 파일 조립을 허용합니다. |
| allow_all | 모두 허용되었습니다. |
| forbid_all | 모두 금지되었습니다. |
