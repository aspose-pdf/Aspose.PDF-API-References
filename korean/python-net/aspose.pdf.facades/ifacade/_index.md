## IFacade class

IFacade 유형은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| bind_pdf(src_file) | PDF 문서를 편집용으로 바인딩합니다. |
| bind_pdf(src_stream) | PDF 문서를 편집용으로 바인딩합니다. |
| bind_pdf(src_doc) | PDF 문서를 편집용으로 바인딩합니다. |
| close() | 현재 파사드와 연관된 모든 리소스를 해제합니다. |
