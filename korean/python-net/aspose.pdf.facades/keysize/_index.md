## KeySize enumeration

PDF 문서를 암호화하는 데 사용할 수 있는 다양한 키 크기를 정의합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| X40 | 40비트 키. 이러한 키 크기는 RC4 알고리즘에 사용되며 낮은 수준의 보안을 제공합니다. <br/>            그럼에도 불구하고, PDF 문서의 오래된 버전은 이러한 키(버전 1.3 이하)만으로 암호화될 수 있습니다; |
| X128 | 128비트 키. RC4와 AES 알고리즘 모두 이러한 키 크기를 사용할 수 있습니다. |
| X256 | 256비트 키. 이러한 키 크기는 AES에서만 사용할 수 있으며 최신 Adobe Reader 버전(v.9부터)에서 인식됩니다. |
