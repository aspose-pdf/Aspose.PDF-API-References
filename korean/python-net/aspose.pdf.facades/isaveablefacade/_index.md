## ISaveableFacade class

모든 저장 가능한 파사드에 공통적인 메서드를 정의하는 파사드 인터페이스.

ISaveableFacade 유형은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| save(dest_file) | 결과 PDF 문서를 파일에 저장합니다. |
| save(dest_stream) | 결과 PDF 문서를 스트림에 저장합니다. |
| bind_pdf(src_file) | PDF 문서를 편집용으로 바인딩합니다. |
| bind_pdf(src_stream) | PDF 문서를 편집용으로 바인딩합니다. |
| bind_pdf(src_doc) | PDF 문서를 편집용으로 바인딩합니다. |
| close() | 현재 파사드와 연관된 모든 리소스를 해제합니다. |
