## TextProperties class

텍스트 크기, 색상, 스타일 등과 같은 텍스트 속성을 나타냅니다.

TextProperties 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextProperties(text_size) | TextProperties 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| 색상 | 텍스트 색상을 가져오거나 설정합니다. |
| is_color_specified | 지정된 [color](/pdf/python-net/aspose.pdf.facades/textproperties/) 속성인지 여부를 나타내는 값을 가져오거나 설정합니다. |
| text_size | 텍스트 크기를 가져오거나 설정합니다. |
| is_text_size_specified | 지정된 [text_size](/pdf/python-net/aspose.pdf.facades/textproperties/) 속성인지 여부를 나타내는 값을 가져오거나 설정합니다. |
