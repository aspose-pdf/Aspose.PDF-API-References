## Bookmark class

북마크를 나타냅니다.

Bookmark 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Bookmark() | Bookmark 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| action | 북마크에 바인딩된 동작을 가져오거나 설정합니다.<br/>            PageNumber가 지정된 경우 동작을 지정할 수 없습니다.<br/>            동작 유형에는: "GoTo", "GoToR", "Launch", "Named"이 포함됩니다. |
| bold_flag | 북마크 제목의 굵게 표시 플래그를 가져오거나 설정합니다. |
| child_item | 북마크의 자식 항목을 가져오거나 설정합니다. |
| child_items | 북마크의 자식 항목을 가져오거나 설정합니다. |
| destination | 북마크의 대상 페이지를 가져오거나 설정합니다. action이 string.Empty로 설정된 경우 필수입니다. |
| italic_flag | 북마크 제목의 이탤릭 플래그를 가져오거나 설정합니다. |
| level | 북마크의 계층 레벨을 가져오거나 설정합니다. |
| page_display | 북마크 대상 페이지를 표시하는 유형을 가져오거나 설정합니다. |
| page_display_bottom | 페이지 표시의 아래 좌표를 가져오거나 설정합니다. |
| page_display_left | 페이지 표시의 왼쪽 좌표를 가져오거나 설정합니다. |
| page_display_right | 페이지 표시의 오른쪽 좌표를 가져오거나 설정합니다. |
| page_display_top | 페이지 표시의 위쪽 좌표를 가져오거나 설정합니다. |
| page_display_zoom | 페이지 표시의 확대 비율을 가져오거나 설정합니다. |
| page_number | 북마크의 대상 페이지 수를 가져오거나 설정합니다. |
| remote_file | 북마크의 "GoToR" 동작에 필요한 파일(경로)을 가져오거나 설정합니다. |
| 제목 | 북마크의 제목을 가져오거나 설정합니다. |
| title_color | 북마크 제목의 색상을 가져오거나 설정합니다. |
| open | 북마크 상태(열림, 닫힘)를 가져오거나 설정합니다. |
