## ViewerPreference class

뷰어 환경설정(페이지 모드, 전체 화면이 아닌 페이지 모드, 페이지 레이아웃)을 설명합니다.

ViewerPreference 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ViewerPreference() | ViewerPreference 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| PAGE_MODE_USE_OC | 옵션 콘텐츠 그룹 패널이 표시됩니다. |
| DISPLAY_DOC_TITLE | 창의 제목 표시줄에 문서 제목을 표시할지 여부를 지정하는 플래그 |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | 옵션 콘텐츠 그룹 패널이 표시됩니다. |
| PAGE_LAYOUT_SINGLE_PAGE | 한 번에 한 페이지를 표시합니다. |
| PAGE_LAYOUT_ONE_COLUMN | 페이지를 한 열에 표시합니다. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | 페이지를 두 열에 표시하며, 홀수 페이지는 오른쪽에 배치합니다. |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | 페이지를 두 열에 표시하며, 홀수 페이지는 오른쪽에 배치합니다. |
| PAGE_MODE_USE_NONE | 문서 개요와 썸네일 이미지가 모두 표시되지 않습니다. |
| PAGE_MODE_USE_OUTLINES | 문서 개요가 표시됩니다. |
| PAGE_MODE_USE_THUMBS | 썸네일 이미지가 표시됩니다. |
| PAGE_MODE_FULL_SCREEN | 전체 화면 모드이며, 메뉴 바, 창 제어 버튼 또는 다른 창이 표시되지 않습니다. |
| PAGE_MODE_USE_ATTACHMENT | 첨부 파일이 포함된 페이지 모드입니다. |
| HIDE_TOOLBAR | 문서가 활성화될 때 해당 리더의 도구 모음을 숨길지 여부를 지정하는 플래그입니다. |
| HIDE_MENUBAR | 문서가 활성화될 때 해당 리더의 메뉴 바를 숨길지 여부를 지정하는 플래그입니다. |
| HIDE_WINDOW_UI | 문서 창에서 사용자 인터페이스 요소(스크롤 바 및 탐색 컨트롤 등)를 숨길지 여부를 지정하는 플래그이며, 문서 내용만 표시됩니다. |
| FIT_WINDOW | 첫 번째 표시된 페이지 크기에 맞게 문서 창의 크기를 조정할지 여부를 지정하는 플래그입니다. |
| CENTER_WINDOW | 문서 창을 화면 중앙에 배치할지 여부를 지정하는 플래그입니다. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | 문서 개요와 썸네일 이미지가 모두 표시되지 않습니다. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | 문서 개요가 표시됩니다. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | 썸네일 이미지가 표시됩니다 |
| DIRECTION_L2R | 텍스트 읽기 순서가 왼쪽에서 오른쪽으로 됩니다. |
| DIRECTION_R2L | 텍스트 읽기 순서가 오른쪽에서 왼쪽으로 됩니다. |
| SIMPLEX | 단면 인쇄. |
| DUPLEX_FLIP_SHORT_EDGE | 시트의 짧은 가장자리를 기준으로 양면 인쇄 및 뒤집기. |
| DUPLEX_FLIP_LONG_EDGE | 시트의 짧은 가장자리를 기준으로 양면 인쇄 및 뒤집기. |
