## PositioningMode enumeration

위치 지정 모드를 정의합니다.<br/>            가능한 값에는 레거시(이전 호환성)와 <br/>            현재(업데이트된 텍스트 위치 계산 방법)가 포함됩니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| LEGACY | 레거시 텍스트 배치 |
| MODERN_LINE_SPACING | 라인 간격이 업데이트되었으며, 수직 위치 계산은 이전 규칙에 따라 수행됩니다 <br/>            (즉, 텍스트가 지정된 사각형의 왼쪽 하단 모서리를 기준으로 배치됩니다) |
| CURRENT | 라인 간격이 업데이트되었으며, 수직 위치 계산이 왼쪽 하단이 아니라 왼쪽 상단을 기준으로 수행됩니다. |
