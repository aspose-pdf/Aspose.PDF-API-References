## ITaggedContent class

문서의 TaggedPdf 콘텐츠와 작업하기 위한 인터페이스를 나타냅니다.

ITaggedContent 유형은 다음 멤버를 제공합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| structure_text_state | 전체 문서에 대한 [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) 설정을 가져옵니다. |
| struct_tree_root_element | PDF 문서의 [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/)을 가져옵니다. |
| root_element | PDF 문서 논리 구조의 루트 [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/)을 가져옵니다. |
