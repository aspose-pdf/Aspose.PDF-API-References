## ButtonField class

클래스는 푸시 버튼 필드를 나타냅니다.

ButtonField 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ButtonField() | Generator용 버튼 필드 생성자. |
| ButtonField(page, rect) | ButtonField 클래스의 새 인스턴스를 초기화합니다 |
| ButtonField(doc, rect) | ButtonField 클래스의 새 인스턴스를 초기화합니다 |

| fit_into_rectangle | true인 경우 텍스트가 지정된 사각형에 맞도록 글꼴 크기가 줄어듭니다. |
| max_font_size | 필드 내용에 사용할 수 있는 최대 글꼴 크기. -1이면 크기를 확인하지 않음. |
| min_font_size | 필드 내용에 사용할 수 있는 최소 글꼴 크기. -1이면 크기를 확인하지 않음. |

| rollover_caption | 버튼의 롤오버 캡션을 가져오거나 설정합니다. 이 캡션은 사용자가 마우스 버튼을 누르지 않고 커서를 <br/>            활성 영역으로 이동할 때 표시됩니다. |
| alternate_caption | 버튼의 대체 캡션을 가져오거나 설정합니다. 이 캡션은 마우스 버튼을 활성 영역 내에서 눌렀을 때 <br/>            표시됩니다. |
| normal_icon | 버튼이 사용자와 상호 작용하지 않을 때 표시되는 일반 아이콘을 가져오거나 설정합니다. |
| rollover_icon | 버튼의 롤오버 아이콘을 가져오거나 설정합니다. 이 아이콘은 사용자가 마우스 버튼을 누르지 않고 커서를 <br/>            활성 영역으로 이동할 때 표시됩니다. |
| alternate_icon | 활성 영역 내에서 마우스 버튼이 눌렸을 때 표시되는 대체 아이콘을 가져오거나 설정합니다. |
| icon_fit | 위젯 주석의 아이콘이 주석 사각형 내에서 어떻게 표시될지 지정하는 icon fit 객체를 가져옵니다. |
| ic_position | 아이콘 캡션 위치를 가져오거나 설정합니다. |
