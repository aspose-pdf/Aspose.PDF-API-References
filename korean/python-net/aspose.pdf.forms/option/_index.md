## Option class

선택 필드 옵션을 나타내는 클래스입니다.

Option 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| 값 | 옵션 내보내기 값을 가져오거나 설정합니다. |
| 이름 | 옵션의 이름을 가져오거나 설정합니다. |
| 선택됨 | 옵션의 선택 상태를 가져오거나 설정합니다. 옵션이 선택된 경우 true를 반환합니다. |
| 인덱스 | 옵션의 인덱스를 가져옵니다. |
