## IconFit class

위젯 주석 아이콘이 주석 사각형 내에 어떻게 표시되는지 설명합니다.

IconFit 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| scaling_reason | 스케일링 이유를 가져오거나 설정합니다. |
| scaling_mode | 사용될 스케일링 유형입니다.        /// |
| leftover_left | 아이콘 왼쪽에 할당할 공간을 가져오거나 설정합니다. |
| leftover_bottom | 아이콘 하단에 할당할 공간을 가져오거나 설정합니다. |
| spread_on_border | true인 경우, 버튼 외관이 테두리 선 두께를 고려하지 않고 주석 경계 내에 완전히 맞도록 스케일링되어야 함을 나타냅니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| name_to_scaling_reason(reason) | 스케일링 이유의 이름을 ScalingReason 객체로 변환합니다. |
| scaling_reason_to_name(reason) | 스케일링 이유 객체를 이름으로 변환합니다. |
| name_to_scaling_mode(mode) | 스케일링 모드 이름을 ScalingMode 객체로 변환합니다. |
| scaling_mode_to_name(mode) | 스케일링 모드 객체를 이름으로 변환합니다. |
