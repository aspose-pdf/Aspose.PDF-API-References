## TextBoxField class

TextBoxField 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextBoxField(doc) | TextBoxField 클래스의 새 인스턴스를 초기화합니다. |
| TextBoxField() | TextBoxField 인스턴스를 생성합니다. |
| TextBoxField(page, rect) | TextBoxField 클래스의 새 인스턴스를 초기화합니다. |
| TextBoxField(doc, rect) | TextBoxField 클래스의 새 인스턴스를 초기화합니다. |

| min_font_size | 필드 내용에 사용할 수 있는 최소 글꼴 크기. -1이면 크기를 확인하지 않음. |

| spell_check | 필드의 spellcheck 플래그를 가져오거나 설정합니다. true이면 필드가 맞춤법 검사를 수행합니다. |
