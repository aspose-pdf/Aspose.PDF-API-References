## OptionCollection class

선택 필드 옵션 컬렉션을 나타내는 클래스입니다.

OptionCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_synchronized | 객체가 동기화된 경우 true를 반환합니다. |
| sync_root | 컬렉션의 동기화 객체입니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 인덱스로 옵션을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get(index) | 인덱스로 옵션을 가져옵니다. |
| get(name) | 옵션 이름으로 컬렉션에서 옵션을 가져옵니다. |
