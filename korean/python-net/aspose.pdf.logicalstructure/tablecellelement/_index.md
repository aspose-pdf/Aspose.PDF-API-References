## TableCellElement class

논리 구조에서 테이블 셀 요소 (TH 및 TD)를 위한 기본 클래스를 나타냅니다.

TableCellElement 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| parent_element | 없음 |
| child_elements | 없음 |
| default_attribute_owner | 가져옵니다 |
| attributes | 가져옵니다 |
| structure_type | 구조 요소의 유형을 가져옵니다. |
| id | 구조 요소의 ID를 가져옵니다. |
| 제목 | 구조 요소의 제목을 가져오거나 설정합니다. |
| language | 구조 요소의 언어를 가져오거나 설정합니다. |
| alternative_text | 구조 요소의 대체 텍스트를 가져오거나 설정합니다. |
| expansion_text | 구조 요소의 확장 텍스트를 가져오거나 설정합니다. |
| actual_text | 구조 요소의 실제 텍스트를 가져오거나 설정합니다. |
| background_color | 셀 배경 색상을 가져오거나 설정합니다. |
| 테두리 | 셀 테두리를 가져오거나 설정합니다. |
| is_no_border | 셀에 테두리가 있는지를 가져오거나 설정합니다. |
| margin | 패딩을 가져오거나 설정합니다. |
| 정렬 | 셀 정렬을 가져오거나 설정합니다. |
| default_cell_text_state | 기본 셀 텍스트 상태를 가져오거나 설정합니다. |
| is_word_wrapped | 셀의 텍스트 줄 바꿈 여부를 가져오거나 설정합니다. |
| vertical_alignment | 수직 정렬을 가져오거나 설정합니다. |
| col_span | 열 범위를 가져오거나 설정합니다. |
| row_span | 행 범위를 가져오거나 설정합니다. |
| structure_text_state | 가져옵니다 |
## 메서드
| 이름 | 설명 |
| :- | :- |
| append_child(element) | 없음 |
| change_parent_element(new_parent_element) | 현재 구조 요소의 부모 요소를 변경합니다 |
| generate_id() | 구조 요소의 ID를 생성합니다. |
| set_id(id) | 구조 요소의 ID를 설정합니다. |
| clear_id() | 구조 요소의 ID를 지웁니다. |
| set_tag(new_tag) | 구조 요소에 사용자 정의 태그를 설정합니다. |
| set_text(text) | 현재 텍스트 요소에 텍스트 내용을 추가합니다. |
