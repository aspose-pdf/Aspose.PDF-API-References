## StructureAttribute class

구조 요소의 속성을 나타냅니다.

StructureAttribute 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| StructureAttribute(attribute_key) | StructureAttribute 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| key | 속성 키를 가져옵니다. |
| is_initialized_value | 구조 속성 값의 상태를 가져옵니다. 값이 설정된 경우 true입니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_name_value() | 값 이름을 가져옵니다. |
| get_string_value() | 값 문자열을 가져옵니다. |
| get_number_value() | 값 숫자를 가져옵니다. |
| get_array_value() | 값 이름 배열을 가져옵니다. |
| get_array_number_value() | 값 번호 배열을 가져옵니다. |
| set_name_value(name) | 값 이름을 설정합니다. |
| set_string_value(value) | 값 문자열을 설정합니다. |
| set_number_value(number) | 값 번호를 설정합니다. |
| set_array_value(array) | 값 이름 배열을 설정합니다. |
| set_array_number_value(array_number) | 값 번호 배열을 설정합니다. |
| set_color_value(color) | 값 색상을 설정합니다. |
| set_rectangle_value(rectangle) | 값 사각형을 설정합니다. |
