## TableTRElement class

테이블의 논리 구조에서 TR 구조 요소를 나타냅니다.

TableTRElement 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| parent_element | 없음 |
| child_elements | 없음 |
| default_attribute_owner | 가져옵니다 |
| attributes | 가져옵니다 |
| structure_type | 구조 요소의 유형을 가져옵니다. |
| id | 구조 요소의 ID를 가져옵니다. |
| 제목 | 구조 요소의 제목을 가져오거나 설정합니다. |
| language | 구조 요소의 언어를 가져오거나 설정합니다. |
| alternative_text | 구조 요소의 대체 텍스트를 가져오거나 설정합니다. |
| expansion_text | 구조 요소의 확장 텍스트를 가져오거나 설정합니다. |
| actual_text | 구조 요소의 실제 텍스트를 가져오거나 설정합니다. |
| background_color | 행 배경색을 가져오거나 설정합니다. |
| 테두리 | 행 테두리를 가져오거나 설정합니다. |
| default_cell_border | 기본 셀 테두리를 가져옵니다. |
| min_row_height | 행의 높이를 가져옵니다. |
| fixed_row_height | 고정 행 높이를 가져옵니다 - 행은 고정 높이를 가질 수 있습니다. |
| is_in_new_page | 고정 행이 새 페이지에 있는지 가져옵니다 - 이 속성이 있는 페이지는 다음 페이지에 인쇄되어야 합니다. 기본값은 false입니다. |
| is_row_broken | 행이 두 페이지 사이에 나뉠 수 있는지 가져옵니다. |
| default_cell_text_state | 행 셀에 대한 기본 텍스트 상태를 가져오거나 설정합니다. |
| default_cell_padding | 행 셀에 대한 기본 여백을 가져오거나 설정합니다. |
| vertical_alignment | 수직 정렬을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| append_child(element) | 없음 |
| change_parent_element(new_parent_element) | 현재 구조 요소의 부모 요소를 변경합니다 |
| generate_id() | 구조 요소의 ID를 생성합니다. |
| set_id(id) | 구조 요소의 ID를 설정합니다. |
| clear_id() | 구조 요소의 ID를 지웁니다. |
| set_tag(new_tag) | 구조 요소에 사용자 정의 태그를 설정합니다. |
| create_th() | 현재 테이블에 [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/)을 생성하고 추가합니다. |
| create_td() | 현재 테이블에 [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/)을 생성하고 추가합니다. |
