## MCRElement class

논리 구조에서 마크된 콘텐츠 참조 객체를 나타냅니다.

MCRElement 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| parent_element | 부모 요소를 가져옵니다. |
| child_elements | 다음의 자식 컬렉션을 가져옵니다 |
| image_src | 없음 |
| content | 없음 |
| mcid | 마크된 콘텐츠 참조 객체의 MCID를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| append_child(element) | 추가 |
