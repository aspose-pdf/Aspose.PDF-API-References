## StructureTypeCategory class

표준 구조 유형의 카테고리를 나타냅니다.

StructureTypeCategory 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| GROUPING_ELEMENTS | 그룹화 요소는 다른 요소들을 시퀀스나 계층 구조로 그룹화하지만 직접적인 콘텐츠를 보유하지 않으며 레이아웃에 직접적인 영향을 주지 않습니다. |
| BLS_ES | 블록 수준 구조 요소(BLSE)는 페이지의 전체 콘텐츠 레이아웃을 설명하며, 블록 진행 방향으로 진행됩니다. |
| ILS_ES | 인라인 수준 구조 요소(ILSE)는 BLSE 내부의 콘텐츠 레이아웃을 설명하며, 인라인 진행 방향으로 진행됩니다. |
| ILLUSTRATION_ELEMENTS | 일러스트레이션 요소는 페이지 콘텐츠 순서대로 배치된 압축된 콘텐츠 시퀀스로, 페이지 레이아웃 관점에서 단일 객체로 간주됩니다. 일러스트레이션은 BLSE 또는 ILSE 중 하나로 취급될 수 있습니다. |
