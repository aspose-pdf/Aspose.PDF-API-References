## TableElement class

논리 구조에서 Table 구조 요소를 나타냅니다.

TableElement 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| parent_element | 없음 |
| child_elements | 없음 |
| default_attribute_owner | 가져옵니다 |
| attributes | 가져옵니다 |
| structure_type | 구조 요소의 유형을 가져옵니다. |
| id | 구조 요소의 ID를 가져옵니다. |
| 제목 | 구조 요소의 제목을 가져오거나 설정합니다. |
| language | 구조 요소의 언어를 가져오거나 설정합니다. |
| alternative_text | 구조 요소의 대체 텍스트를 가져오거나 설정합니다. |
| expansion_text | 구조 요소의 확장 텍스트를 가져오거나 설정합니다. |
| actual_text | 구조 요소의 실제 텍스트를 가져오거나 설정합니다. |
| background_color | 테이블 배경색을 가져오거나 설정합니다. |
| 테두리 | 테이블 테두리를 가져오거나 설정합니다. |
| 정렬 | 테이블 정렬을 가져오거나 설정합니다. |
| corner_style | 테두리 모서리 스타일을 가져오거나 설정합니다 |
| broken | 테이블 수직 파손을 가져오거나 설정합니다; |
| column_adjustment | 테이블 열 조정을 가져오거나 설정합니다. |
| column_widths | 테이블의 열 너비를 가져옵니다. |
| default_cell_border | 기본 셀 테두리를 가져옵니다. |
| default_cell_padding | 기본 셀 패딩을 가져오거나 설정합니다. |
| default_cell_text_state | 기본 셀 텍스트 상태를 가져오거나 설정합니다. |
| default_column_width | 기본 열 너비를 가져오거나 설정합니다. |
| is_broken | 테이블이 파손되었는지 가져오거나 설정합니다 - 다음 페이지에서 잘릴 것입니다. |
| is_borders_included | 열 너비에 포함된 테두리를 가져오거나 설정합니다. |
| left | 테이블 왼쪽 좌표를 가져오거나 설정합니다. |
| top | 테이블 상단 좌표를 가져오거나 설정합니다. |
| repeating_columns_count | 테이블에 대한 최대 열 수를 가져오거나 설정합니다. |
| repeating_rows_count | 여러 페이지에 반복되는 첫 번째 행 수를 가져옵니다. |
| repeating_rows_style | 반복 행에 대한 스타일을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| append_child(element) | 없음 |

| set_id(id) | 구조 요소의 ID를 설정합니다. |
