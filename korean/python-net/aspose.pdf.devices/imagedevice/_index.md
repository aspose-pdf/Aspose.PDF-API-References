## ImageDevice class

이미지 장치를 위한 추상 클래스입니다.

ImageDevice 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| coordinate_type | 페이지 좌표 유형 (Media/Crop 박스)을 가져오거나 설정합니다. 기본값으로 CropBox 값이 사용됩니다. |
| rendering_options | 렌더링 옵션을 가져오거나 설정합니다. |
| form_presentation_mode | 폼 프레젠테이션 모드를 가져오거나 설정합니다. |
| resolution | 이미지 해상도를 가져옵니다. |
| width | 이미지 출력 너비를 가져옵니다. |
| 높이 | 이미지 출력 높이를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| process(page, output) | 주어진 페이지에 대해 일부 작업을 수행합니다. 예: 페이지를 그래픽 이미지로 변환합니다. |
| process(page, output_file_name) | 주어진 페이지에 대해 일부 작업을 수행하고 결과를 파일에 저장합니다. |
