## JpegDevice class

PDF 문서 페이지를 jpeg 형식으로 저장하는 데 도움이 되는 이미지 장치를 나타냅니다.

JpegDevice 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| JpegDevice() | 기본 해상도와 최대 품질을 사용하여 [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(resolution) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(quality) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(resolution, quality) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(width, height) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(page_size) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(width, height, resolution) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(page_size, resolution) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(width, height, resolution, quality) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
| JpegDevice(page_size, resolution, quality) | JpegDevice 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| coordinate_type | 페이지 좌표 유형 (Media/Crop 박스)을 가져오거나 설정합니다. 기본값으로 CropBox 값이 사용됩니다. |
| rendering_options | 렌더링 옵션을 가져오거나 설정합니다. |
| form_presentation_mode | 폼 프레젠테이션 모드를 가져오거나 설정합니다. |
| resolution | 이미지 해상도를 가져옵니다. |
| width | 이미지 출력 너비를 가져옵니다. |
| 높이 | 이미지 출력 높이를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| process(page, output) | 페이지를 jpeg로 변환하고 출력 스트림에 저장합니다. |
| process(page, output_file_name) | 페이지를 jpeg로 변환하고 출력 스트림에 저장합니다. |
