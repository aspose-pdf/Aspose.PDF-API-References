## TextDevice class

PDF 문서 페이지를 텍스트로 변환하는 클래스를 나타냅니다.

TextDevice 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextDevice(extraction_options) | TextDevice 클래스의 새 인스턴스를 초기화합니다 |
| TextDevice() | [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/)의 새 인스턴스를 Raw 텍스트 포맷 모드와 Unicode 텍스트 인코딩으로 초기화합니다 |
| TextDevice(encoding) | TextDevice 클래스의 새 인스턴스를 초기화합니다 |
| TextDevice(extraction_options, encoding) | TextDevice 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| extraction_options | 텍스트 추출 옵션을 가져오거나 설정합니다. |
| 인코딩 | 추출된 텍스트의 인코딩을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| process(page, output) | 페이지를 변환하고 텍스트 스트림으로 저장합니다. |
| process(page, output_file_name) | 페이지를 변환하고 텍스트 스트림으로 저장합니다. |
