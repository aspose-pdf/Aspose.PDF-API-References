## TiffSettings class

이 클래스는 PDF를 TIFF로 가져오기 위한 설정을 나타냅니다.

TiffSettings 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TiffSettings() | [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) 클래스의 새 인스턴스를 초기화합니다. |
| TiffSettings(shape_type) | TiffSettings 클래스의 새 인스턴스를 초기화합니다 |
| TiffSettings(compression_type) | TiffSettings 클래스의 새 인스턴스를 초기화합니다 |
| TiffSettings(color_depth) | TiffSettings 클래스의 새 인스턴스를 초기화합니다 |
| TiffSettings(margins) | TiffSettings 클래스의 새 인스턴스를 초기화합니다 |
| TiffSettings(compression_type, color_depth, margins) | TiffSettings 클래스의 새 인스턴스를 초기화합니다 |
| TiffSettings(compression_type, color_depth, margins, skip_blank_pages) | TiffSettings 클래스의 새 인스턴스를 초기화합니다 |
| TiffSettings(compression_type, color_depth, margins, skip_blank_pages, shape_type) | TiffSettings 클래스의 새 인스턴스를 초기화합니다 |
| TiffSettings(skip_blank_pages) | TiffSettings 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| margins | 여백을 가져옵니다. |
| skip_blank_pages | 빈 페이지를 건너뛸지 여부를 나타내는 값을 가져오거나 설정합니다. |
| compression | 압축 유형을 가져오거나 설정합니다. |
| depth | 색 깊이를 가져오거나 설정합니다. |
| shape | shape의 유형을 가져오거나 설정합니다. |
| brightness | 흰색과 검은색으로 색 변환의 값 경계를 가져오거나 설정합니다.<br/>            이 매개변수는 EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle 또는 ColorDepth.Format1bpp == 1와 함께 적용할 수 있습니다. |
| coordinate_type | 페이지 좌표 유형 (Media/Crop 박스)을 가져오거나 설정합니다. 기본값으로 CropBox 값이 사용됩니다. |
