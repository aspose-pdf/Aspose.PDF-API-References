## Resolution class

Resolution 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Resolution(value) | Resolution 클래스의 새 인스턴스를 초기화합니다. |
| Resolution(value_x, value_y) | Resolution 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| x | 수평 이미지 해상도를 가져오거나 설정합니다. |
| y | 수직 이미지 해상도를 가져오거나 설정합니다. |
