## Margins class

이 클래스는 이미지의 여백을 나타냅니다.

Margins 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Margins(left, right, top, bottom) | Margins 클래스를 새 인스턴스로 초기화합니다 |
| Margins() | 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| left | 왼쪽을 가져오거나 설정합니다. |
| 오른쪽 | 오른쪽을 가져오거나 설정합니다. |
| top | 위쪽을 가져오거나 설정합니다. |
| bottom | 하단을 가져오거나 설정합니다. |
