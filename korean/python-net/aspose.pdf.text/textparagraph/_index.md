## TextParagraph class

텍스트 단락을 다중 행 텍스트 객체로 나타냅니다.

TextParagraph 유형은 다음 멤버를 제공합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextParagraph() | TextParagraph 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| vertical_alignment | 단락의 [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) 내부 텍스트에 대한 수직 정렬을 가져오거나 설정합니다. |
| subsequent_lines_indent | 후속 줄 들여쓰기 값을 가져오거나 설정합니다.<br/>            0이 아닌 값으로 설정하면 FormattingOptions.SubsequentLinesIndent 값보다 유리합니다. |
| first_line_indent | 후속 줄 들여쓰기 값을 가져오거나 설정합니다.<br/>            0이 아닌 값으로 설정하면 FormattingOptions.SubsequentLinesIndent 값보다 유리합니다. |
| justify | 텍스트가 양쪽 정렬인지 여부의 값을 가져오거나 설정합니다. |
| horizontal_alignment | 단락의 [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) 내부 텍스트에 대한 수평 정렬을 가져오거나 설정합니다. |
| formatting_options | 서식 옵션을 가져오거나 설정합니다. |
| position | 단락의 위치를 가져오거나 설정합니다. |
| text_rectangle | 단락에 배치된 텍스트의 사각형을 가져옵니다. |
| rectangle | 단락의 사각형을 가져오거나 설정합니다. |
| margin | 패딩을 가져오거나 설정합니다. |
| rotation | 회전 각도를 도 단위로 가져오거나 설정합니다. |
