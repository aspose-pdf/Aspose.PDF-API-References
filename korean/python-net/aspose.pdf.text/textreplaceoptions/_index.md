## TextReplaceOptions class

텍스트 교체 옵션을 나타냅니다.

TextReplaceOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextReplaceOptions(scope) | TextReplaceOptions 클래스의 새 인스턴스를 초기화합니다 |
| TextReplaceOptions(adjustment) | TextReplaceOptions 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| replace_scope | 텍스트 교체 작업이 적용되는 범위를 가져오거나 설정합니다 |
| replace_adjustment_action | 텍스트 조각을 더 짧게 교체한 후 수행될 동작을 가져오거나 설정합니다 |
| adjustment_new_line_spacing | 교체 조정이 강제로 새로운 텍스트 줄을 만들 때 사용되는 행간 값을 가져오거나 설정합니다.<br/>            예상값은 교체된 텍스트의 글꼴 크기 배수이며, 기본값은 1.2입니다. |
