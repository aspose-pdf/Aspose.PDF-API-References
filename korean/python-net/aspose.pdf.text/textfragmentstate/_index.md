## TextFragmentState class

텍스트 조각의 텍스트 상태를 나타냅니다.

TextFragmentState 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextFragmentState(fragment) | TextFragmentState 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| character_spacing | 텍스트의 문자 간격을 가져오거나 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| line_spacing | 텍스트의 줄 간격을 가져오거나 설정합니다. |
| horizontal_scaling | 텍스트의 수평 스케일링을 가져오거나 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| subscript | 텍스트의 아래 첨자를 가져오거나 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| superscript | 텍스트의 위 첨자를 가져오거나 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| word_spacing | 텍스트의 단어 간격을 가져오거나 설정합니다. |
| 보이지 않음 | 텍스트의 보이지 않음 속성을 가져오거나 설정합니다. |
| rendering_mode | 텍스트의 렌더링 모드를 가져오거나 설정합니다. |
| font_size | 텍스트의 글꼴 크기를 가져오거나 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| font | 텍스트의 글꼴을 가져오거나 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| foreground_color | 텍스트의 전경 색상을 가져오거나 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| stroking_color | 텍스트 스트로크 작업(텍스트 스트로크, 사각형 테두리)의 색상을 가져오거나 설정합니다. [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 렌더링 |
| underline | 텍스트에 대한 밑줄을 가져오거나 설정합니다. 이는 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체로 표현됩니다. |
| strike_out | 텍스트에 대한 취소선을 설정합니다. 이는 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체로 표현됩니다. |
| background_color | 텍스트의 배경 색상을 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| font_style | 텍스트의 글꼴 스타일을 설정합니다. 이 값은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체에 의해 표현됩니다. |
| horizontal_alignment | 텍스트의 수평 정렬을 가져오거나 설정합니다. |
| TAB_TAG | 텍스트에 이 태그를 삽입하여 탭을 선언할 수 있습니다. |
| TABSTOP_DEFAULT_VALUE | 기본 글꼴의 공백 문자 너비에서 탭의 기본값입니다. |
| tab_stops | 텍스트의 탭 스톱을 가져옵니다. |
| formatting_options | 서식 옵션을 가져오거나 설정합니다.<br/>            옵션 설정은 생성기 시나리오에서만 적용됩니다. |
| rotation | 회전 각도를 도 단위로 가져오거나 설정합니다. |
| draw_text_rectangle_border | 텍스트 사각형 테두리 그리기 플래그를 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| apply_changes_from(text_state) | 다른 textState의 설정을 적용합니다. |
| measure_string(str) | 문자열의 길이를 측정합니다. |
