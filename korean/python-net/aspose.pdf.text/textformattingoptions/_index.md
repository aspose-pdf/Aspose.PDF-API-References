## TextFormattingOptions class

텍스트 서식 옵션을 나타냅니다.

TextFormattingOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextFormattingOptions(wrap_mode) | TextFormattingOptions 클래스의 새 인스턴스를 초기화합니다 |
| TextFormattingOptions() | 정의되지 않은 단어 줄 바꿈 모드로 [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) 객체의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| wrap_mode | 단어 줄 바꿈 모드를 가져오거나 설정합니다.<br/>            기본값은 WordWrapMode.NoWrap입니다 |
| line_spacing | 줄 간격 모드를 가져오거나 설정합니다.<br/>            기본값은 LineSpacingMode.FontSize입니다 |
| hyphen_symbol | 하이픈 처리 과정에서 사용되는 하이픈 기호를 가져오거나 설정합니다. |
| subsequent_lines_indent | 다음 줄 들여쓰기 값을 가져오거나 설정합니다. |
| first_line_indent | 첫 번째 줄 들여쓰기 값을 가져오거나 설정합니다. |
