## TextEditOptions class

텍스트 편집 작업 옵션을 설명합니다.

TextEditOptions 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextEditOptions(no_character_behavior) | TextEditOptions 클래스의 새 인스턴스를 초기화합니다 |
| TextEditOptions(font_replace_behavior) | TextEditOptions 클래스의 새 인스턴스를 초기화합니다 |
| TextEditOptions(allow_language_transformation) | TextEditOptions 클래스의 새 인스턴스를 초기화합니다 |
| TextEditOptions(language_transformation_behavior) | TextEditOptions 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| replacement_font | 필요한 문자를 포함하지 않는 경우 교체에 사용되는 글꼴을 가져오거나 설정합니다 |
| no_character_behavior | 요청된 문자를 포함하지 않는 경우 동작을 정의하는 모드를 가져오거나 설정합니다 |
| font_replace_behavior | 글꼴 교체 시나리오에 대한 동작을 정의하는 모드를 가져옵니다 |
| allow_language_transformation | 텍스트를 추가하거나 편집하는 동안 언어 변환 사용을 허용하는 값을 가져오거나 설정합니다.<br/>            true - 필요에 따라 언어 변환이 적용됩니다 (기본값).<br/>            false - 언어 변환이 적용되지 않습니다. |
| language_transformation_behavior | 언어 변환 시나리오에 대한 동작을 정의하는 모드를 가져옵니다 |
| clipping_paths_processing | 편집된 텍스트의 클리핑 경로를 처리하기 위한 모드를 가져옵니다 |
| to_attempt_get_underline_from_source | 소스 문서 페이지에서 텍스트 밑줄을 검색하도록 허용하는 값을 가져오거나 설정합니다.<br/>            (Obsolete) 대신에 TextSearchOptions.SearchForTextRelatedGraphics를 사용하십시오. |
