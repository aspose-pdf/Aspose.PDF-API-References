## TextExtractionErrorLocation class

텍스트 추출 오류가 발생한 PDF 문서 내 위치를 나타냅니다.

TextExtractionErrorLocation 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| path | 텍스트 추출 오류가 발생한 PDF 문서의 위치. |
| page_number | 텍스트 추출 오류가 발생한 문서 페이지 번호. |
| object_type | 내용 스트림 텍스트 추출 오류가 발생한 PDF 객체(페이지 또는 xForm)의 유형. |
| form_key | 내용 스트림 텍스트 추출 오류가 발생한 PDF Form XObject의 키(이름). ObjectType이 'xForm'인 경우 비어 있지 않습니다. |
| operator_index | 텍스트 추출 오류를 일으키는 내용 스트림(연산자 컬렉션) 내 텍스트 표시 연산자의 인덱스. |
| operator_string | 텍스트 추출 오류를 일으키는 텍스트 표시 연산자. |
| font_used_key | 텍스트 추출 오류를 일으키는 연산자를 표시하는 데 사용되는 PDF Font 객체의 키(이름). |
| text_start_point | 텍스트 추출 오류를 일으키는 연산자를 표시하는 데 사용되는 PDF Font 객체의 키(이름). |
