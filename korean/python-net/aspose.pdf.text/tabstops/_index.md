## TabStops class

TabStops 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TabStops() | TabStops 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| is_read_only | 이 [TabStops](/pdf/python-net/aspose.pdf.text/tabstops/) 인스턴스가 이미 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/)에 연결되어 읽기 전용이 되었음을 나타내는 값을 가져옵니다. |
| count | 지정된 위치와 <br/>            함께 [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) 클래스를 새 인스턴스로 초기화하고 TabStops 컬렉션에 추가합니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | TabStop 인덱스에 따라 컬렉션에서 [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) 객체를 가져오거나 설정합니다. |

| add(position) | 지정된 위치와 <br/>            함께 [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) 클래스를 새 인스턴스로 초기화하고 TabStops 컬렉션에 추가합니다. |
| add(tab_stop) | 새 인스턴스로 [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) 클래스를 초기화하고 <br/>            TabStops 컬렉션에 추가합니다. |
