## TabStop class

단락 내 사용자 정의 탭 정지 위치를 나타냅니다.

TabStop 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TabStop() | [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) 클래스의 새 인스턴스를 초기화합니다. |
| TabStop(position) | TabStop 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| position | 탭 정지 위치를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| leader_type | [TabLeaderType](/pdf/python-net/aspose.pdf.text/tableadertype/) 열거형을 가져오거나 설정하여 탭 리더 유형을 나타냅니다. |
| alignment_type | [alignment_type](/pdf/python-net/aspose.pdf.text/tabstop/) 열거형을 가져오거나 설정하여 탭 정렬 유형을 나타냅니다. |
| is_read_only | 이 [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) 인스턴스가 이미 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/)에 연결되어 읽기 전용이 되었음을 나타내는 값을 가져옵니다. |
