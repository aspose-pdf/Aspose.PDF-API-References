## MarkupParagraph class

단락을 나타냅니다.

MarkupParagraph 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| points | 단락을 설명하는 다각형의 점들.<br/>            시작점은 단락의 왼쪽 아래 모서리이며, 다음 점들은 반시계 방향 순서입니다. |
| secondary_points | 단락 연속을 설명하는 보조 다각형의 점들. 단락이 다음 열이나 페이지에 계속될 경우 null이 아닙니다.<br/>            시작점은 단락의 왼쪽 아래 모서리이며, 다음 점들은 반시계 방향 순서입니다. |
| continuation_page_numbers | 단락이 계속되는 페이지 번호 목록입니다. 동일 페이지의 다음 열에 계속되는 경우, 시작 페이지와 일치합니다. |
| fragments | 단락의 비어 있지 않은 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 객체 컬렉션입니다. |
| lines | 단락의 줄들. 각 줄은 텍스트 조각 목록으로 표현됩니다. |
| text | [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) 객체가 나타내는 문자열 텍스트 객체를 가져옵니다. |
