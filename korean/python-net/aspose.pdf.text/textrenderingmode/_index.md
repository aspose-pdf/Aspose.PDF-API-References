## TextRenderingMode enumeration

텍스트 렌더링 모드인 Tmode는 텍스트 표시가 글리프 윤곽선을 스트로크하거나, 채우거나, 클리핑 경계로 사용하거나, 이 세 가지의 조합 중 어느 것이 될지를 결정합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| FILL_TEXT | 텍스트를 채웁니다. |
| STROKE_TEXT | 텍스트를 스트로크합니다. |
| FILL_THEN_STROKE_TEXT | 텍스트를 채우고, 그 다음 스트로크합니다. |
| INVISIBLE | 텍스트를 채우지도 스트로크하지도 않음(보이지 않음). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | 텍스트를 채우고 클리핑을 위해 경로에 추가합니다 (9.3.6, "Text Rendering Mode" 참조). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | 텍스트에 스트로크를 적용하고 클리핑을 위해 경로에 추가합니다. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | 텍스트를 채우고, 그 다음 스트로크를 적용한 뒤 클리핑을 위해 경로에 추가합니다. |
| ADD_PATH_TO_CLIPPING | 텍스트를 클리핑을 위해 경로에 추가합니다. |
