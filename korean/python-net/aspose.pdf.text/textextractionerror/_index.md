## TextExtractionError class

PDF 문서에 나타난 텍스트 추출 오류를 설명합니다.

TextExtractionError 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| summary | 오류에 대한 간략한 설명. |
| description | 오류에 대한 확장된 설명. |
| location | 오류 위치. |
| font_key | 추출 오류를 일으키는 텍스트를 표시하는 데 사용되는 Font 객체의 키(PDF 이름). |
| font_name | 추출 오류를 일으키는 텍스트를 표시하는 데 사용되는 Font 객체의 읽을 수 있는(내부) 이름. |
| extracted_text | 실제로 추출된 텍스트. |
