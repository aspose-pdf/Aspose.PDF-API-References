## FontCollection class

글꼴 컬렉션을 나타냅니다.

FontCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| sync_root | 컬렉션에 대한 접근을 동기화하는 데 사용할 수 있는 객체를 가져옵니다. |
| is_synchronized | 컬렉션에 대한 접근이 동기화되는지(스레드 안전) 여부를 나타내는 값을 가져옵니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 지정된 인덱스의 글꼴 요소를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| add(new_font, res_name) | 새 글꼴을 글꼴 리소스에 추가하고 자동으로 할당된 글꼴 리소스 이름을 반환합니다. |
