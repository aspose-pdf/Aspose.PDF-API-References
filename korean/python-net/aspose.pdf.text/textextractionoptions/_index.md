## TextExtractionOptions class

텍스트 추출 옵션을 나타냅니다.

TextExtractionOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextExtractionOptions(formatting_mode) | TextExtractionOptions 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| formatting_mode | 포맷팅 모드를 가져옵니다. |
| scale_factor | 순수 모드에서 추출 중에 글꼴 크기를 조정하는 데 적용되는 계수를 가져오거나 설정합니다.<br/>            값이 낮을수록 추출된 텍스트에 더 많은 공백이 생깁니다.<br/>            기본값은 1이며, 스케일링이 적용되지 않습니다;<br/>            값을 0으로 설정하면 알고리즘이 자동으로 스케일링을 선택합니다. |
