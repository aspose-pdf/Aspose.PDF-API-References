## TextBuilder class

텍스트 객체를 PDF 페이지에 추가합니다.

TextBuilder 타입은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextBuilder(page) | TextBuilder 클래스의 새 인스턴스를 초기화합니다. |
| TextBuilder(page, operator_collection) | TextBuilder 클래스의 새 인스턴스를 초기화합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| append_text(text_fragment) | 텍스트 조각을 Pdf 페이지에 추가합니다. |
| append_text(text_fragments) | 텍스트 조각 목록을 Pdf 페이지에 추가합니다. |
| append_paragraph(text_paragraph) | 텍스트 단락을 Pdf 페이지에 추가합니다. |
