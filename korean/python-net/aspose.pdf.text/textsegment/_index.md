## TextSegment class

PDF 텍스트 세그먼트를 나타냅니다.

TextSegment 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextSegment() | TextSegment 객체를 생성합니다. |
| TextSegment(text) | TextSegment 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| start_char_index | 현재 세그먼트의 표시 텍스트 연산자 (Tj, TJ) 세그먼트에서 시작 문자 인덱스를 가져옵니다. |
| end_char_index | 현재 세그먼트의 표시 텍스트 연산자 (Tj, TJ) 세그먼트에서 끝 문자 인덱스를 가져옵니다. |
| text | 해당 [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) 객체가 나타내는 문자열 텍스트 객체를 가져오거나 설정합니다. |
| text_state | 해당 [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) 객체가 나타내는 텍스트의 텍스트 상태를 가져오거나 설정합니다. |
| position | 해당 [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) 객체로 표현된 텍스트의 위치를 가져옵니다. |
| rectangle | TextSegment의 사각형을 가져옵니다. |
| baseline_position | 해당 [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) 객체로 표현된 텍스트의 위치를 가져옵니다.<br/>            Position 구조의 YIndent는 텍스트 세그먼트의 기준선 좌표를 나타냅니다. |
| text_edit_options | 텍스트 편집 옵션을 가져오거나 설정합니다. 이 옵션은 요청된 기호를 해당 폰트로 쓸 수 없을 때의 특수 동작을 정의합니다. |
| characters | 텍스트 세그먼트의 문자에 대한 정보를 나타내는 CharInfo 객체 컬렉션을 가져옵니다. |
| hyperlink | 세그먼트 하이퍼링크( PDF 생성기용)를 가져오거나 설정합니다. |
