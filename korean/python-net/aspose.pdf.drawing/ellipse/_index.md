## Ellipse class

타원을 나타냅니다.

Ellipse 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Ellipse(left, bottom, width, height) | Ellipse 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| graph_info | 그래프 정보(예: 색상,<br/>            선 너비 등)를 나타내는 [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) 객체를 가져오거나 설정합니다. |
| text | 도형에 대한 텍스트를 가져오거나 설정합니다. |
| left | 타원의 왼쪽 위치를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| bottom | 타원의 아래쪽 위치를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| width | 타원의 너비를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| 높이 | 타원의 높이를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
