## Curve class

베지어 곡선을 나타냅니다.

The Curve 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Curve(position_array) | Curve 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| graph_info | 그래프 정보(예: 색상,<br/>            선 너비 등)를 나타내는 [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) 객체를 가져오거나 설정합니다. |
| text | 도형에 대한 텍스트를 가져오거나 설정합니다. |
| position_array | float 위치 배열을 가져오거나 설정합니다. |
