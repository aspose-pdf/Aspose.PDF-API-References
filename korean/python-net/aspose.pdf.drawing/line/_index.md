## Line class

선을 나타냅니다.

Line 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Line(position_array) | Line 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| graph_info | 그래프 정보(예: 색상,<br/>            선 너비 등)를 나타내는 [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) 객체를 가져오거나 설정합니다. |
| text | 도형에 대한 텍스트를 가져오거나 설정합니다. |
| position_array | 위치 배열을 나타내는 [position_array](/pdf/python-net/aspose.pdf.drawing/line/) 객체를 가져오거나 설정합니다. 배열은 <br/>            선의 각 제어점 좌표로 구성됩니다. <br/>            직접. |
