## Path class

호를 나타냅니다.

Path 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Path(shapes) | Path 클래스의 새 인스턴스를 초기화합니다 |
| Path() | [Path](/pdf/python-net/aspose.pdf.drawing/path/) 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| graph_info | 그래프 정보(예: 색상,<br/>            선 너비 등)를 나타내는 [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) 객체를 가져오거나 설정합니다. |
| text | 도형에 대한 텍스트를 가져오거나 설정합니다. |
| shapes | shapes 컬렉션을 가져오거나 설정합니다 |
