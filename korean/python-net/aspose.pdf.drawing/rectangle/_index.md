## Rectangle class

사각형을 나타냅니다.

Rectangle 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Rectangle(left, bottom, width, height) | Rectangle 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| graph_info | 그래프 정보(예: 색상,<br/>            선 너비 등)를 나타내는 [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) 객체를 가져오거나 설정합니다. |
| text | 도형에 대한 텍스트를 가져오거나 설정합니다. |
| rounded_corner_radius | 사각형 모서리 반경을 나타내는 float 값을 가져오거나 설정합니다. |
| left | 사각형의 왼쪽 위치를 나타내는 float 값을 가져오거나 설정합니다. |
| bottom | 사각형의 아래쪽 위치를 나타내는 float 값을 가져오거나 설정합니다. |
| width | 사각형의 너비를 나타내는 float 값을 가져오거나 설정합니다. |
| 높이 | 사각형의 높이를 나타내는 float 값을 가져오거나 설정합니다. |
