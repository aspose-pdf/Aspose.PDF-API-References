## Arc class

호를 나타냅니다.

Arc 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Arc 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| graph_info | 그래프 정보(예: 색상,<br/>            선 너비 등)를 나타내는 [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) 객체를 가져오거나 설정합니다. |
| text | 도형에 대한 텍스트를 가져오거나 설정합니다. |
| pos_x | 호의 중심 x좌표를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| pos_y | 호의 중심 y좌표를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| radius | 호의 반경을 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| alpha | 호의 시작 각도(도)를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| beta | 호의 종료 각도(도)를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
