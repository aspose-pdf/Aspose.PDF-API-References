## FitVExplicitDestination class

명시적 목적지를 나타내며, 페이지를 표시할 때 수평 좌표 left가 창의 왼쪽 가장자리에 위치하고 페이지 내용이 페이지 전체 높이가 창 안에 맞도록 충분히 확대됩니다. left에 null 값을 지정하면 해당 매개변수의 현재 값이 그대로 유지됩니다.
