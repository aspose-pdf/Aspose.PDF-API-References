## ReplyType enumeration

주석과 InReplyTo에 의해 지정된 주석 간의 관계 종류(‘답변 유형’)를 열거합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| UNDEFINED | 정의되지 않은 관계. |
| REPLY | 이 주석은 InReplyTo에 지정된 주석에 대한 답글로 간주됩니다. 뷰어 애플리케이션은 주석에 대한 답글을 개별적으로 표시하지 말고 스레드형 댓글 형태로 함께 표시해야 합니다. |
| GROUP | 이 주석은 InReplyTo에 지정된 주석과 그룹화됩니다. |
