## FitExplicitDestination class

명시적 목적지를 나타내며, 페이지를 표시할 때 내용이 가로와 세로 모두 창 안에 전체 페이지가 맞도록 충분히 확대됩니다. 필요한 가로 및 세로 확대 비율이 다르면 두 비율 중 작은 값을 사용하고, 다른 차원에서는 페이지를 창 중앙에 배치합니다.

FitExplicitDestination 유형은 다음 멤버를 노출합니다:

| 이름 | 설명 |
| :- | :- |
| FitExplicitDestination(page) | FitExplicitDestination 클래스의 새 인스턴스를 초기화합니다 |
| FitExplicitDestination(document, page_number) | FitExplicitDestination 클래스의 새 인스턴스를 초기화합니다 |
| FitExplicitDestination(page_number) | FitExplicitDestination 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| page | 대상 페이지 객체를 가져옵니다 |
| page_number | 대상 페이지 번호를 가져옵니다 |
## 메서드

| :- | :- |
| create_destination(page, type, values) | ExplicitDestination 파생 클래스의 인스턴스를 생성합니다. |
| create_destination(doc, page_number, type, values) | ExplicitDestination 파생 클래스의 인스턴스를 생성합니다. |
| create_destination(page_number, type, values) | ExplicitDestination 파생 클래스의 인스턴스를 생성합니다. |
