## HighlightingMode enumeration

주석의 강조 모드, 즉 활성 영역 내에서 마우스 버튼을 누르거나 유지할 때 사용되는 시각 효과를 열거합니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| NONE | 하이라이트 없음. |
| INVERT | 주석 사각형의 내용을 반전시킵니다. |
| OUTLINE | 주석의 테두리를 반전시킵니다. |
| PUSH | 주석의 아래 외관이 있으면 표시합니다. 아래 외관이 정의되지 않은 경우, 주석 사각형의 내용을 오프셋하여 페이지 표면 아래로 눌린 것처럼 보이게 합니다. |
| TOGGLE | Push와 동일합니다(권장됨). |
