## AnnotationState enumeration

원본 주석을 설정할 수 있는 상태들의 열거형입니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| UNDEFINED | 정의되지 않은 상태입니다. |
| MARKED | 주석이 사용자에 의해 표시되었습니다. |
| UNMARKED | 주석이 사용자에 의해 표시되지 않았습니다. |
| ACCEPTED | 사용자가 변경에 동의합니다. |
| REJECTED | 사용자가 변경에 동의하지 않습니다. |
| CANCELLED | 변경이 취소되었습니다. |
| COMPLETED | 변경이 완료되었습니다. |
| NONE | 사용자가 변경에 대해 아무것도 표시하지 않았습니다. |
