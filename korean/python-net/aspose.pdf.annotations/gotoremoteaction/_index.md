## GoToRemoteAction class

일반 이동 액션과 유사하지만 현재 파일이 아닌 다른 PDF 파일의 목적지로 이동하는 원격 이동 액션을 나타냅니다.

GoToRemoteAction 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| GoToRemoteAction(remote_pdf, remote_page_number) | GoToRemoteAction 클래스의 새 인스턴스를 초기화합니다. |
| GoToRemoteAction(remote_pdf, destination) | GoToRemoteAction 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| 다음 | 시퀀스의 다음 작업들. |
| destination | 점프할 대상지를 가져오거나 설정합니다. |
| file | 대상이 위치한 파일의 사양을 가져오거나 설정합니다. |
| new_window | 대상 문서를 새 창에서 열지 여부를 지정하는 플래그를 가져오거나 설정합니다. |
