## DefaultAppearance class

필드의 기본 외관(글꼴, 텍스트 크기 및 색상)을 설명합니다.

DefaultAppearance 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| DefaultAppearance() | DefaultAppearance의 생성자입니다. |
| DefaultAppearance(font_name, font_size, text_color) | DefaultAppearance 클래스의 새 인스턴스를 초기화합니다 |
| DefaultAppearance(font, font_size, text_color) | DefaultAppearance 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| font_size | 기본 외관에서 글꼴 크기를 가져옵니다. |
| text_color | 기본 외관에서 텍스트 색상을 가져오거나 설정합니다. |
| font_name | 기본 외관에서 글꼴 이름을 가져옵니다. |
| font_resource_name | 기본 외관에서 글꼴 이름을 가져옵니다. |
| font | 텍스트에 대한 기본값으로 지정된 글꼴을 가져옵니다. |
| text | 외관을 나타내는 PDF 연산자 목록을 가져옵니다. |
