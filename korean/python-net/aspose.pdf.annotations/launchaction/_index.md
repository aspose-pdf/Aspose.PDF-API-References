## LaunchAction class

응용 프로그램을 실행하거나 문서를 열거나 인쇄하는 실행 액션을 나타냅니다.

LaunchAction 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| LaunchAction(file) | LaunchAction 클래스의 새 인스턴스를 초기화합니다 |
| LaunchAction(document, file) | LaunchAction 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| 다음 | 시퀀스의 다음 작업들. |
| file | 시작할 애플리케이션 또는 열거나 인쇄할 문서를 가져오거나 설정합니다. |
| new_window | 대상 문서를 새 창에서 열지 여부를 지정하는 플래그를 가져오거나 설정합니다 (PDF 문서에만 적용됩니다). |
