## SoundData class

주석이 활성화될 때 재생될 사운드를 정의하는 사운드 데이터를 나타냅니다.

SoundData 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| rate | 샘플링 속도(초당 샘플 수)를 가져오거나 설정합니다. |
| channels | 음성 채널 수를 가져오거나 설정합니다. |
| bits | 채널당 샘플 값당 비트 수를 가져오거나 설정합니다. |
| 내용 | 주석이 활성화될 때 재생될 사운드 스트림을 가져옵니다. |
| 인코딩 | 샘플 데이터의 인코딩 형식을 가져오거나 설정합니다. |
