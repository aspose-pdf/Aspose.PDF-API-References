## Measure class

Measure 좌표계를 설명하는 클래스.

Measure 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Measure(annotation) | Measure 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| scale_ratio | 도면의 축척 비율을 나타내는 텍스트 문자열입니다. |
| x_format | xaxis를 따라 변화 측정을 위한 숫자 형식 배열이며, Y가 없을 경우 y axis를 따라 또한 측정합니다. |
| y_format | y axis를 따라 변화 측정을 위한 숫자 형식 배열입니다. |
| distance_format | 어떤 방향이든 거리 측정을 위한 숫자 형식 배열입니다. |
| area_format | 면적 측정을 위한 숫자 형식 배열입니다. |
| angle_format | 각도 측정을 위한 숫자 형식 배열입니다. |
| slope_format | 선의 기울기 측정을 위한 숫자 형식 배열입니다. |
| origin | 측정 좌표계의 원점을 기본 사용자 공간 좌표계에서 지정하는 포인트입니다. |
| xy_factor | y axis를 따라 가장 큰 단위를 x axis를 따라 가장 큰 단위로 변환하는 데 사용되는 계수입니다. |
