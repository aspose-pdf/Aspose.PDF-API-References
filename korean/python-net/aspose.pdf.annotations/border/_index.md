## Border class

주석 테두리 특성을 나타내는 클래스입니다.

Border 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Border(parent) | Border 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| h_corner_radius | 수평 코너 반경을 가져오거나 설정합니다. |
| v_corner_radius | 수직 코너 반경을 가져오거나 설정합니다. |
| width | 테두리 너비를 가져오거나 설정합니다. |
| effect_intensity | 효과 강도를 가져오거나 설정합니다. 값의 유효 범위는 [0..2]입니다. |
| style | 테두리 스타일을 가져오거나 설정합니다. |
| effect | 테두리 효과를 가져오거나 설정합니다. |
| dash | 대시 패턴을 가져오거나 설정합니다. |
