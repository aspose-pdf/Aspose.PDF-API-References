## AnnotationActionCollection class

주석 동작 컬렉션을 나타냅니다.

AnnotationActionCollection 유형은 다음 멤버를 제공합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| on_enter | 커서가 주석의 활성 영역에 들어갈 때 수행되는 동작을 가져오거나 설정합니다. |
| on_exit | 커서가 주석의 활성 영역을 벗어날 때 수행되는 동작을 가져오거나 설정합니다. |
| on_press_mouse_btn | 마우스 버튼이 주석의 활성 영역 안에서 눌릴 때 수행되는 동작을 가져오거나 설정합니다. |
| on_release_mouse_btn | 마우스 버튼이 주석의 활성 영역 안에서 놓일 때 수행되는 동작을 가져오거나 설정합니다. |
| on_receive_focus | 주석이 입력 포커스를 받을 때 수행되는 동작을 가져오거나 설정합니다. |
| on_open_page | 주석이 포함된 페이지가 열릴 때 수행되는 동작을 가져오거나 설정합니다. |
| on_close_page | 주석이 포함된 페이지가 닫힐 때 수행되는 동작을 가져오거나 설정합니다. |
| on_show_page | 주석이 포함된 페이지가 뷰어 애플리케이션의 사용자 인터페이스에 표시될 때 수행되는 동작을 가져오거나 설정합니다. |
| on_hide_page | 주석이 포함된 페이지가 뷰어 애플리케이션의 사용자 인터페이스에서 더 이상 표시되지 않을 때 수행되는 동작을 가져오거나 설정합니다. |
| on_lost_focus | 주석이 입력 포커스를 잃을 때 수행되는 동작을 가져오거나 설정합니다. |
| on_modify_character | 사용자가 필드의 문자를 수정할 때 수행되는 동작을 가져오거나 설정합니다. |
| on_validate | 사용자가 필드의 내용을 변경할 때 수행되는 동작을 가져오거나 설정합니다. |
| on_format | 필드 값을 형식화하기 위해 수행되는 동작을 가져오거나 설정합니다. |
| on_calculate | 필드 값을 계산하기 위한 작업을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| remove_actions() | 주석의 모든 작업을 제거합니다. |
