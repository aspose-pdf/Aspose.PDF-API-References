## AnnotationFlags enumeration

주석의 다양한 특성을 지정하는 플래그 집합입니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| DEFAULT | 기본값. |
| INVISIBLE | 설정된 경우, 표준 주석 유형 중 하나에 속하지 않고 주석 핸들러가 없는 경우 주석을 표시하지 않습니다.<br/>            해제된 경우, 해당 외부 사전이 지정한 외관 스트림이 있는 경우(있는 경우) 해당 알 수 없는 주석을 표시합니다. |
| HIDDEN | 설정된 경우, 주석 유형이나 주석 핸들러의 존재 여부와 관계없이 주석을 표시하거나 인쇄하지 않으며 사용자가 상호 작용할 수 없게 합니다.<br/>            화면 공간이 제한된 경우, 주석을 선택적으로 숨기고 표시하는 기능을 외관 스트림과 결합하여 온라인 도움말 시스템과 유사한 보조 팝업 정보를 표시하는 데 사용할 수 있습니다. |
| 인쇄 | 설정된 경우, 페이지가 인쇄될 때 주석을 인쇄합니다. 해제된 경우, 화면에 표시 여부와 관계없이 주석을 절대 인쇄하지 않습니다.<br/>            예를 들어, 인쇄된 페이지에서는 의미가 없는 대화형 푸시버튼을 나타내는 주석에 유용할 수 있습니다. |
| NO_ZOOM | 설정된 경우, 페이지 확대에 맞추어 주석의 외관을 확대하지 않습니다.<br/>            주석이 페이지에 위치하는 위치(주석 사각형의 왼쪽 위 모서리로 정의됨)는 페이지 확대와 관계없이 고정됩니다. |
| NO_ROTATE | 설정된 경우, 페이지 회전에 맞추어 주석의 외관을 회전하지 않습니다.<br/>            주석 사각형의 왼쪽 위 모서리는 페이지 회전과 관계없이 페이지의 고정된 위치에 유지됩니다. |
| NO_VIEW | 설정된 경우, 화면에 주석을 표시하지 않으며 사용자가 상호 작용할 수 없게 합니다.<br/>            주석은 인쇄될 수 있습니다(Print 플래그 설정에 따라).<br/>            그러나 화면 표시 및 사용자 상호 작용 측면에서는 숨겨진 것으로 간주되어야 합니다. |
| READ_ONLY | 설정된 경우, 주석이 사용자와 상호 작용하지 못하도록 합니다. 주석은 표시되거나 인쇄될 수 있습니다(NoView 및 Print 플래그 설정에 따라)하지만 마우스 클릭에 반응하거나 마우스 움직임에 따라 외관이 변하지 않아야 합니다. 이 플래그는 위젯 주석에 대해서는 무시되며, 해당 기능은 연관된 양식 필드의 ReadOnly 플래그에 의해 대체됩니다. |
| LOCKED | 설정된 경우, 사용자가 주석을 삭제하거나 속성(위치 및 크기 포함)을 수정하지 못하도록 합니다. 그러나 이 플래그는 양식 필드 값과 같은 주석 내용의 변경은 제한하지 않습니다. |
| TOGGLE_NO_VIEW | 설정된 경우, 특정 이벤트에 대해 NoView 플래그의 해석을 반전시킵니다.<br/>            일반적인 사용 예는 마우스 커서를 올려 놓은 경우에만 나타나는 주석을 만드는 것입니다. |
| LOCKED_CONTENTS | 설정된 경우, 사용자가 주석의 내용을 수정하지 못하도록 합니다.<br/>            이 플래그는 주석 삭제나 위치 및 크기와 같은 다른 주석 속성의 변경을 제한하지 않습니다. |
