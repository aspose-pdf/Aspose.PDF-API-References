## PdfActionCollection class

PdfActionCollection 유형은 다음 멤버를 제공합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| count | 동작 수를 가져옵니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 인덱스로 동작을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| delete(index) | 인덱스로 동작을 제거합니다. |
| add(action) | 동작을 동작 목록에 추가합니다. |
