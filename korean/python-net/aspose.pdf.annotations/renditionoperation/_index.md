## RenditionOperation enumeration

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| PLAY_STOP | 주석에 rendition이 연결되지 않은 경우, 지정된 rendition을 재생하고 annotation에 연결합니다. annotation에 이미 rendition이 연결되어 있는 경우, 해당 rendition을 중지하고 새 rendition을 annotation에 연결합니다. |

| PLAY_RESUME | 지정된 rendition을 재생하고 annotation에 연결합니다. annotation에 이미 rendition이 연결되어 있는 경우, 해당 rendition이 일시 중지된 경우 재개합니다. |
| UNDEFINED | 작업이 정의되지 않았습니다. |
