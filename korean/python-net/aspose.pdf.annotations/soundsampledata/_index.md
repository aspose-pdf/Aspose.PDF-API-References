## SoundSampleData class

사운드 객체에 특화된 추가 항목을 나타냅니다 (Section 9.2 PDF1-7).

SoundSampleData 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| SoundSampleData(sampling_rate) | SoundSampleData 클래스의 새 인스턴스를 초기화합니다. |
| SoundSampleData(sampling_rate, number_of_sound_channels) | SoundSampleData 클래스의 새 인스턴스를 초기화합니다. |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel) | SoundSampleData 클래스의 새 인스턴스를 초기화합니다. |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel, sound_sample_data_encoding_format) | SoundSampleData 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| sampling_rate | 샘플링 속도를 가져오거나 설정합니다. |
| number_of_sound_channels | 음성 채널 수를 가져오거나 설정합니다. |
| bits_per_channel | 채널당 샘플 값당 비트 수를 가져오거나 설정합니다. |
| encoding_format | 인코딩 형식을 가져오거나 설정합니다. |
| DEFAULT_SAMPLING_RATE | SamplingRate의 기본값. |
| DEFAULT_OF_SOUND_CHANNELS | Channels 매개변수의 기본값. |
| DEFAULT_OF_BITS_PER_CHANNEL | BitsPerchannel 매개변수의 기본값. |
| DEFAULT_ENCODING_FORMAT | 인코딩 형식의 기본값. |
