## AnnotationCollection class

주석 컬렉션을 나타내는 클래스입니다.

AnnotationCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_synchronized | Aspose.Pdf.Annotations.AnnotationCollection에 대한 접근이 동기화(스레드 안전)되는지를 나타내는 값을 가져옵니다. |
| sync_root | Aspose.Pdf.Annotations.AnnotationCollection에 대한 접근을 동기화하는 데 사용할 수 있는 객체를 가져옵니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 가져올 요소의 인덱스. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| delete(index) | 인덱스로 컬렉션에서 주석을 삭제합니다. |
| delete() | 인덱스로 컬렉션에서 주석을 삭제합니다. |
| delete(annotation) | 인덱스로 컬렉션에서 주석을 삭제합니다. |
| add(annotation, consider_rotation) | 주석을 컬렉션에 추가합니다. 페이지가 회전된 경우 주석 사각형이 그에 맞게 재계산됩니다. |
| accept(visitor) | 주석을 처리하기 위해 방문자를 수락합니다. |
| find_by_name(name) | 이름으로 주석을 반환합니다. |
