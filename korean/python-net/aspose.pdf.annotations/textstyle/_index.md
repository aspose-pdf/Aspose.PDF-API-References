## TextStyle class

주석 내 텍스트 스타일을 나타내는 클래스입니다.

TextStyle 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| font_name | 폰트 이름. |
| font_size | 폰트 크기. |
| 정렬 | 텍스트의 수평 정렬을 가져오거나 설정합니다. |
| horizontal_alignment | 텍스트 정렬. 유효한 값은: Left, Center, Rigth. |
| 색상 | 텍스트 색상. |
