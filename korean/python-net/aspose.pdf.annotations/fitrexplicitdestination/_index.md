## FitRExplicitDestination class

명시적 목적지를 나타내며, 페이지를 표시할 때 내용이 좌표 left, bottom, right, top으로 지정된 사각형이 가로와 세로 모두 창 안에 완전히 맞도록 충분히 확대됩니다. 필요한 가로 및 세로 확대 비율이 다르면 두 비율 중 작은 값을 사용하고, 다른 차원에서는 사각형을 창 중앙에 배치합니다. 매개변수 중 하나라도 null 값을 지정하면 예측할 수 없는 동작이 발생할 수 있습니다.

FitRExplicitDestination 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| FitRExplicitDestination(page, left, bottom, right, top) | FitRExplicitDestination 클래스의 새 인스턴스를 초기화합니다. |
| FitRExplicitDestination(document, page_number, left, bottom, right, top) | FitRExplicitDestination 클래스의 새 인스턴스를 초기화합니다. |
| FitRExplicitDestination(page_number, left, bottom, right, top) | FitRExplicitDestination 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| page | 대상 페이지 객체를 가져옵니다 |
| page_number | 대상 페이지 번호를 가져옵니다 |
| left | 보이는 사각형의 왼쪽 수평 좌표를 가져옵니다. |
| bottom | 보이는 사각형의 아래쪽 수직 좌표를 가져옵니다. |
| 오른쪽 | 보이는 사각형의 오른쪽 수평 좌표를 가져옵니다. |
| top | 보이는 사각형의 위쪽 수직 좌표를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| create_destination(page, type, values) | ExplicitDestination 파생 클래스의 인스턴스를 생성합니다. |
| create_destination(doc, page_number, type, values) | ExplicitDestination 파생 클래스의 인스턴스를 생성합니다. |
| create_destination(page_number, type, values) | ExplicitDestination 파생 클래스의 인스턴스를 생성합니다. |
| to_string() | 객체 상태를 문자열 값으로 변환합니다. 예: "1 FitR 100 200 300 400". |
