## DocumentActionCollection class

클래스는 문서와 관련된 일부 작업에 수행되는 동작을 설명합니다

DocumentActionCollection 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| DocumentActionCollection(document) | DocumentActionCollection 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| before_saving | 문서 저장 전에 수행되는 작업을 가져오거나 설정합니다. |
| before_closing | 문서 닫기 전에 수행될 작업을 가져오거나 설정합니다. |
| after_saving | 문서 저장 후에 수행될 작업을 가져오거나 설정합니다. |
| before_printing | 문서 인쇄 전에 수행될 작업입니다. |
| after_printing | 문서 인쇄 후에 수행될 작업입니다. |
