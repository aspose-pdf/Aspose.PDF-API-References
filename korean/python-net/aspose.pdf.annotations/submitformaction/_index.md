## SubmitFormAction class

submit-form 작업을 설명하는 클래스입니다.

SubmitFormAction 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| SubmitFormAction() | SubmitFormAction 객체를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| 다음 | 시퀀스의 다음 작업들. |
| flags | 제출 작업의 플래그를 가져오거나 설정합니다. |
| url | 대상 URL. |
| EXCLUDE | clear인 경우, Fields 배열은 제출에 포함할 필드를 지정합니다. |
| INCLUDE_NO_VALUE_FIELDS | 설정된 경우, Fields 배열과 Include/Exclude 플래그에 의해 지정된 모든 필드가 제출됩니다. |
| EXPORT_FORMAT | 설정된 경우, 필드 이름과 값이 HTML Form 형식으로 제출됩니다. |
| GET_METHOD | 설정된 경우, 필드 이름과 값이 HTTP GET 요청을 사용하여 제출됩니다. |
| SUBMIT_COORDINATES | 설정된 경우, submit-form 동작을 일으킨 마우스 클릭 좌표가 폼 데이터의 일부로 전송됩니다. |
| XFDF | 설정된 경우, 필드 이름과 값이 XFDF 형식으로 제출됩니다. |
| INCLUDE_APPEND_SAVES | 설정된 경우, 제출된 FDF 파일은 모든 증분 업데이트의 내용을 포함해야 합니다. |
| INCLUDE_ANNOTATIONS | 설정된 경우, 제출된 FDF 파일은 기본 PDF 문서에 있는 모든 마크업 주석을 포함해야 합니다. |
| SUBMIT_PDF | 설정된 경우, 문서는 MIME 콘텐츠 유형 application/pdf를 사용하여 PDF 형식으로 제출되어야 합니다. |
| CANONICAL_FORMAT | 설정된 경우, 날짜를 나타내는 모든 제출된 필드 값은 표준 형식으로 변환되어야 합니다. |
| EXCL_NON_USER_ANNOTS | 설정된 경우, 현재 사용자의 이름과 일치하는 T 항목을 가진 마크업 주석만 포함해야 합니다. |
| EXCL_F_KEY | 설정된 경우, 제출된 FDF는 F 항목을 제외해야 합니다. |
| EMBED_FORM | 설정된 경우, 제출된 FDF의 F 항목은 <br/>            제출된 FDF가 생성된 PDF 파일을 나타내는 임베드된 파일 스트림을 포함하는 파일 사양이어야 합니다. |
