## TextPlaceOperator class

TextPlaceOperator 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TextPlaceOperator() | TextPlaceOperator를 초기화합니다. |
| TextPlaceOperator(text_properties) | TextPlaceOperator 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| 인덱스 | 페이지 연산자 목록에서 연산자 인덱스. |

| 이름 | 설명 |
| :- | :- |
| accept(visitor) | 연산자를 처리하기 위해 방문자 객체를 수락합니다. |
| is_text_show_operator(op) | 연산자가 텍스트 출력(Tj, TJ 등)을 담당하는 연산자인지 판단합니다. |
