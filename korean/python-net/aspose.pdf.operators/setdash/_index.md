## SetDash class

선 대시 패턴을 설정하는 d 연산자를 나타내는 클래스.

SetDash 타입은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| SetDash(pattern, phase) | SetDash 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| 인덱스 | 페이지 연산자 목록에서 연산자 인덱스. |
| 패턴 | 대시 패턴. 배열의 요소는 대시와 간격을 교대로 지정하는 길이를 나타내는 숫자여야 합니다.<br/>            요소가 하나인 배열의 경우 대시와 간격 길이가 동일합니다. |
| 위상 | 대시 위상. 경로를 스트로크하기 시작하기 전에 대시 배열을 순환하면서 대시와 간격의 길이를 합산합니다.<br/>            누적된 길이가 대시 위상에 지정된 값과 같아지면 경로 스트로크가 시작되고,<br/>            그 시점부터 대시 배열이 순환적으로 사용됩니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| accept(visitor) | 연산자를 처리하기 위해 방문자 객체를 수락합니다. |
| is_text_show_operator(op) | 연산자가 텍스트 출력(Tj, TJ 등)을 담당하는 연산자인지 판단합니다. |
