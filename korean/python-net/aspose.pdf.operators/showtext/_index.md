## ShowText class

ShowText 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ShowText(index, text) | ShowText 클래스의 새 인스턴스를 초기화합니다. |
| ShowText(text) | ShowText 클래스의 새 인스턴스를 초기화합니다. |
| ShowText(text, font) | ShowText 클래스의 새 인스턴스를 초기화합니다. |
| ShowText() | Tj 연산자를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| 인덱스 | 없음 |
