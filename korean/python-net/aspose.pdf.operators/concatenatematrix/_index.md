## ConcatenateMatrix class

cm 연산자 (concatenate matrix to current transformation matrix)를 나타내는 클래스.

ConcatenateMatrix 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ConcatenateMatrix(a, b, c, d, e, f) | ConcatenateMatrix 클래스의 새 인스턴스를 초기화합니다 |
| ConcatenateMatrix(m) | ConcatenateMatrix 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| 인덱스 | 페이지 연산자 목록에서 연산자 인덱스. |
| matrix | 연산자의 행렬 인수. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| accept(visitor) | 연산자를 처리하기 위해 방문자 객체를 수락합니다. |
| is_text_show_operator(op) | 연산자가 텍스트 출력(Tj, TJ 등)을 담당하는 연산자인지 판단합니다. |
