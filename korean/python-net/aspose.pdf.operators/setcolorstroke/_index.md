## SetColorStroke class

스트로크 색상 연산자를 위한 색상을 설정하는 SC 연산자를 나타내는 클래스.

SetColorStroke 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| SetColorStroke() | 연산자를 초기화합니다. |
| SetColorStroke(g) | SetColorStroke 클래스의 새 인스턴스를 초기화합니다 |
| SetColorStroke(r, g, b) | SetColorStroke 클래스의 새 인스턴스를 초기화합니다 |
| SetColorStroke(color) | SetColorStroke 클래스의 새 인스턴스를 초기화합니다 |
| SetColorStroke(c, m, y, k) | SetColorStroke 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| 인덱스 | 없음 |
| r | 색상의 빨간색 구성 요소를 가져옵니다 |
| g | 색상의 초록색 구성 요소를 가져옵니다 |
| b | 색상의 빨간색 구성 요소를 가져옵니다 |
| c | CMYK 색상의 시안 구성 요소를 가져옵니다. |
| m | CMYK 색상의 마젠타 구성 요소를 가져옵니다. |
| y | CMYK 색상의 노란색 구성 요소를 가져옵니다. |
| k | CMYK 색상의 검은색 구성 요소를 가져옵니다. |
| grey | gray 색상의 검은색 구성 요소를 가져옵니다. |
| 색상 | 색상 구성 요소 배열을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| accept(visitor) | 연산자를 처리하기 위해 방문자 객체를 수락합니다. |
| is_text_show_operator(op) | 없음 |
| get_color() | 연산자에 의해 지정된 색상을 반환합니다. |
