## Re class

re 연산자를 나타내는 클래스 (경로에 사각형 추가).

Re 타입은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Re() | 연산자를 초기화합니다. |
| Re(x, y, width, height) | Re 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| 인덱스 | 페이지 연산자 목록에서 연산자 인덱스. |
| x | 사각형 가장 왼쪽 측면의 X 좌표. |
| y | 사각형 아래쪽 측면의 Y 좌표. |
| width | 사각형의 너비. |
| 높이 | 사각형의 높이. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| accept(visitor) | 연산자를 처리하기 위해 방문자 객체를 수락합니다. |
| is_text_show_operator(op) | 연산자가 텍스트 출력(Tj, TJ 등)을 담당하는 연산자인지 판단합니다. |
