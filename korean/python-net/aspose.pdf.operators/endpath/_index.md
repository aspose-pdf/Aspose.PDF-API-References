## EndPath class

## 생성자
| 이름 | 설명 |
| :- | :- |
| EndPath() | 연산자를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| 인덱스 | 페이지 연산자 목록에서 연산자 인덱스. |
