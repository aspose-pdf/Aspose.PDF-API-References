## Operator class

연산자를 나타내는 추상 클래스.

Operator 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| 인덱스 | 페이지 연산자 목록에서 연산자 인덱스. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| accept(visitor) | 연산자 처리를 제공하는 IOperatorSelector 방문자를 수락합니다. |
| is_text_show_operator(op) | 연산자가 텍스트 출력(Tj, TJ 등)을 담당하는 연산자인지 판단합니다. |
