## XmpPdfAExtensionField class

이 스키마는 구조화된 타입의 필드를 설명합니다. PDF/A Property Value Type <br/>            스키마와 매우 유사하지만, 속성이 아니라 구조 내에 필드를 정의합니다.<br/>            스키마 네임스페이스 URI: http://www.aiim.org/pdfa/ns/field#<br/>            필요한 스키마 네임스페이스 접두사: pdfaField.
