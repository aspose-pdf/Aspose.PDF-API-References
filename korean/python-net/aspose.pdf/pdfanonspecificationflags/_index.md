## PdfANonSpecificationFlags class

이 클래스는 원본 PDF 문서가 PDF 사양에 맞지 않을 경우 PDF/A 변환을 제어하는 플래그를 보유합니다.<br/>            해당 플래그를 사용하면 성능이 저하되지만, 일반적인 방법으로 원본 PDF 문서를 PDF/A 형식으로 변환할 수 없을 때 필요합니다.<br/>            기본값으로 모든 플래그는 false로 설정됩니다.
