## GraphInfo class

그래픽 정보를 나타냅니다.

GraphInfo 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| GraphInfo() | GraphInfo 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| line_width | 그래프의 선 너비를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| color | 그래프의 색상을 나타내는 [color](/pdf/python-net/aspose.pdf/graphinfo/) 객체를 가져오거나 설정합니다. |
| dash_array | 대시 배열을 가져오거나 설정합니다. |
| dash_phase | 대시 위상을 가져오거나 설정합니다. |
| fill_color | 그래프의 채우기 색상을 나타내는 [color](/pdf/python-net/aspose.pdf/graphinfo/) 객체를 가져오거나 설정합니다. |
| is_doubled | 테두리가 두 배인지 여부를 가져오거나 설정합니다. |
| skew_angle_x | 좌표계를 변환할 때 x 좌표의 기울기 각도를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| skew_angle_y | 좌표계를 변환할 때 y 좌표의 기울기 각도를 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| scaling_rate_x | 좌표계를 변환할 때 x 좌표의 스케일 비율을 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| scaling_rate_y | 좌표계를 변환할 때 y 좌표의 스케일 비율을 나타내는 부동 소수점 값을 가져오거나 설정합니다. |
| rotation_angle | 좌표계를 변환할 때 좌표계의 회전 각도를 나타내는 부동 소수점 값을 가져오거나 설정합니다 <br/>            좌표계를 변환할 때. |
