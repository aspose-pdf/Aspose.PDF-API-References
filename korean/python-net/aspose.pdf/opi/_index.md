## Opi class

OPI(Open Prepress Interface)는 저해상도 자리표시자 또는 프록시를 생성하는 메커니즘이며,<br/>            이러한 고해상도 이미지에 사용됩니다.

Opi 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Opi(xform) | Opi 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| version | 이 사전이 참조하는 OPI 버전을 가져옵니다. |
| file_specification | 저해상도 프록시 이미지를 포함하는 외부 파일을 가져옵니다. |
| position | 잘린 이미지의 페이지 내 위치를 지정하는 형식의 8개 숫자 배열을 가져옵니다. |
