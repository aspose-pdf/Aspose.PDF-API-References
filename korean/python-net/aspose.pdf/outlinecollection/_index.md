## OutlineCollection class

문서 개요 계층 구조를 나타냅니다.

OutlineCollection 형식은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| visible_count | Count는 모든 레벨에서 보이는 하위 개요 항목 수의 합계입니다. 참고: 컬렉션의 항목 수를 나타내는 Count와 혼동하지 마세요. |
| first | 개요에서 첫 번째 최상위 항목을 나타내는 개요 항목을 가져옵니다. |
| last | 개요에서 마지막 최상위 항목을 나타내는 개요 항목을 가져옵니다. |
| is_synchronized | 이 컬렉션에 대한 접근이 동기화(스레드 안전)되는지 여부를 나타내는 값을 가져옵니다. |
| sync_root | 이 컬렉션에 대한 접근을 동기화하는 데 사용할 수 있는 객체를 가져옵니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 인덱스로 컬렉션에서 개요 항목을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| delete() | 문서 개요에서 모든 개요 항목을 삭제합니다. |
| delete(name) | 지정된 제목을 가진 개요 항목을 문서 개요에서 삭제합니다. |
