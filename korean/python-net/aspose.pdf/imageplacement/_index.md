## ImagePlacement class

PDF 문서 페이지에 배치된 이미지의 특성을 나타냅니다.

ImagePlacement 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| matrix | 이 이미지에 대한 현재 변환 행렬입니다. |
| rectangle | 이미지의 사각형을 가져옵니다. |
| operator | 이미지를 표시하는 데 사용되는 연산자입니다. |
| rotation | 이미지의 회전 각도를 가져옵니다. |
| resolution | 이미지의 해상도를 가져옵니다. |
| image | 관련 XImage 리소스 객체를 가져옵니다. |
| page | 이미지를 포함하는 페이지를 가져옵니다. |
| compositing_parameters | 페이지에 배치된 이미지에 대해 활성화된 그래픽 상태의 합성 매개변수를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| save(stream) | 이미지를 해당 변환(스케일링, 회전 및 해상도)과 함께 저장합니다. |
| save(stream, format) | 이미지를 해당 변환(스케일링, 회전 및 해상도)과 함께 저장합니다. |
| hide() | 페이지에서 이미지를 삭제합니다. |
| replace(image) | 컬렉션의 이미지를 다른 이미지로 교체합니다. |
