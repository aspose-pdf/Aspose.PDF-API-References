## Row class

테이블의 행을 나타냅니다.

Row 타입은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Row() | Row 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| background_color | 배경 색을 가져오거나 설정합니다. |
| 테두리 | 테두리를 가져오거나 설정합니다. |
| 셀 | 행의 셀을 가져옵니다. |
| default_cell_border | 기본 셀 테두리를 가져옵니다; |
| min_row_height | 행의 높이를 가져옵니다; |
| fixed_row_height | 고정 행 높이를 가져옵니다 - 행에 고정 높이가 있을 수 있습니다; |
| is_in_new_page | 고정 행이 새 페이지에 있는지 가져옵니다 - 이 속성이 있는 페이지는 다음 페이지에 인쇄되어야 합니다 기본값은 false; |
| is_row_broken | 행이 두 페이지 사이에 나뉘어질 수 있는지 가져옵니다 |
| default_cell_text_state | 행 셀에 대한 기본 텍스트 상태를 가져오거나 설정합니다. |
| default_cell_padding | 행 셀의 기본 여백을 가져오거나 설정합니다 |
| vertical_alignment | 수직 정렬을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| clone() | 행을 복제합니다. |
