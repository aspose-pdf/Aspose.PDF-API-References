## XImageCollection class

XImage 컬렉션을 나타내는 클래스입니다.

XImageCollection 유형은 다음 멤버를 제공합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_synchronized | 객체가 동기화된 경우 true를 반환합니다. |
| sync_root | 동기화 객체를 반환합니다. |
| names | 이미지 이름 배열을 가져옵니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 인덱스로 컬렉션에서 이미지를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| add(image) | 이미지 목록에 새 이미지를 추가합니다. 이 메서드는 이미지를 동일한 PdfObject에 대한 참조로 추가하여 파일 크기를 줄일 수 있습니다. |
| add(image) | 엔터티를 컬렉션 끝에 추가하여 마지막 인덱스로 엔터티에 접근할 수 있게 합니다. |
| add(image, filter_type) | 엔터티를 컬렉션 끝에 추가하여 마지막 인덱스로 엔터티에 접근할 수 있게 합니다. |
| add(image, quality) | 엔터티를 컬렉션 끝에 추가하여 마지막 인덱스로 엔터티에 접근할 수 있게 합니다. |
| delete(index) | 컬렉션에서 지정된 인덱스의 항목을 제거합니다. |
| delete(index, action) | 컬렉션에서 인덱스로 이미지를 제거하고, action 매개변수에 지정된 동작을 수행합니다. |
| delete(name) | 컬렉션에서 이름으로 항목을 제거합니다. |
| delete(name, action) | 컬렉션에서 이름으로 항목을 제거합니다. |
| delete() | 컬렉션에서 지정된 인덱스의 항목을 제거합니다. |
| replace(index, stream) | 컬렉션의 이미지를 다른 이미지로 교체합니다. |
| replace(index, stream, quality, is_black_and_white) | 컬렉션의 이미지를 다른 이미지로 교체합니다. |
| replace(index, stream, quality) | 컬렉션의 이미지를 다른 이미지로 교체합니다. |
| get_image_name(image) | 주어진 이미지의 키인 이미지 목록에서 이름을 반환합니다. |
