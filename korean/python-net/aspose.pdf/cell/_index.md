## Cell class

테이블 행의 셀을 나타냅니다.

Cell 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Cell(rect) | Cell 클래스의 새 인스턴스를 초기화합니다 |
| Cell() | Cell 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| is_no_border | 셀에 테두리가 있는지를 가져오거나 설정합니다. |
| margin | 패딩을 가져오거나 설정합니다. |
| 테두리 | 테두리를 가져오거나 설정합니다. |
| background_color | 배경 색을 가져오거나 설정합니다. |
| background_image_file | 배경 이미지 파일을 가져오거나 설정합니다. |
| background_image | 배경 이미지를 가져오거나 설정합니다 |
| 정렬 | 정렬을 가져오거나 설정합니다. |
| default_cell_text_state | 기본 셀 텍스트 상태를 가져오거나 설정합니다. |
| is_override_by_fragment | 셀의 TextState 속성이 TextFragment TextState 속성에 의해 재정의되도록 설정합니다. |
| paragraphs | 셀의 서식이 지정된 텍스트를 가져오거나 설정합니다. |
| is_word_wrapped | 셀의 텍스트 줄 바꿈 여부를 가져오거나 설정합니다. |
| vertical_alignment | 수직 정렬을 가져오거나 설정합니다. |
| col_span | 열 범위를 가져오거나 설정합니다. |
| row_span | 행 범위를 가져오거나 설정합니다. |
| width | 열 너비를 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| clone() | 셀을 복제합니다. |
