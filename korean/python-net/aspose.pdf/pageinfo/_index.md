## PageInfo class

페이지 정보를 나타냅니다.

PageInfo 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PageInfo() | PageInfo 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| any_margin | 첫 페이지를 제외한 모든 페이지의 여백을 가져오거나 설정합니다. |
| default_text_state | 기본 글꼴을 가져오거나 설정합니다. |
| 높이 | 페이지 높이를 가져오거나 설정합니다. |
| pure_height | 여백 없이 페이지 순수 높이를 가져오거나 설정합니다. |
| is_landscape | 페이지가 가로 모드인지 여부를 가져오거나 설정합니다. |
| margin | 페이지 여백을 가져오거나 설정합니다. |
| width | 페이지 너비를 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| clone() | 페이지 정보를 복제합니다. |
