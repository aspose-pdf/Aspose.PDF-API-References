## FileParams class

추가 파일별 정보를 포함해야 하는 임베디드 파일 매개변수 사전을 정의합니다.

FileParams 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| FileParams(spec) | FileParams 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| size | 압축되지 않은 포함된 파일의 크기(바이트 단위)입니다. |
| creation_date | 포함된 파일이 생성된 날짜와 시간입니다. |
| mod_date | 포함된 파일이 마지막으로 수정된 날짜와 시간입니다. |
| check_sum | 압축되지 않은 포함된 파일 바이트의 체크섬인 16바이트 문자열입니다. <br/>            체크섬은 표준 MD5 메시지 다이제스트 알고리즘을 적용하여 <br/>            포함된 파일 스트림의 바이트에 대해 계산됩니다. |
