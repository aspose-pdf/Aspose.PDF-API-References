## TimestampSettings class

서명 과정에서 사용되는 OCSP 설정을 나타냅니다.

TimestampSettings 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| TimestampSettings(server_url, basic_auth_credentials, digest_hash_algorithm) | TimestampSettings 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| server_url | 타임스탬프 서버 URL을 가져오거나 설정합니다. |
| basic_auth_credentials | 기본 인증 자격 증명을 가져오거나 설정합니다. 사용자 이름과 비밀번호는 "username:password" 문자열로 결합됩니다. |
| digest_hash_algorithm | 내부 해시 함수에 사용할 다이제스트 알고리즘을 가져오거나 설정합니다. |
