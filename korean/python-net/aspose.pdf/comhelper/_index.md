## ComHelper class

COM 클라이언트가 Aspose.Pdf에 문서를 로드할 수 있도록 메서드를 제공합니다.

ComHelper 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ComHelper() | ComHelper 클래스의 새 인스턴스를 초기화합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| open_stream(input) | 새 Document 인스턴스를 초기화하고 반환합니다. |
| open_stream(input, password) | 새 Document 인스턴스를 초기화하고 반환합니다. |
| open_stream(input, is_managed_stream) | 새 Document 인스턴스를 초기화하고 반환합니다. |
| open_stream(input, password, is_managed_stream) | 새 Document 인스턴스를 초기화하고 반환합니다. |
| open_stream(input, options) | 스트림에서 기존 문서를 열어 반환하고, PDF 문서를 얻기 위해 필요한 변환을 제공합니다. |
| open_file(filename) | Document를 사용하여 단순히 생성하고 반환합니다. |
| open_file(filename, password) | Document를 사용하여 단순히 생성하고 반환합니다. |
| open_file(filename, password, is_managed_stream) | 암호화된 문서를 작업하기 위해 [Document](/pdf/python-net/aspose.pdf/document/) 클래스의 새 인스턴스를 초기화합니다. |
| open_file(filename, options) | 파일에서 기존 문서를 열어 PDF 문서를 얻기 위해 필요한 변환 옵션을 제공합니다. |
