## Note class

이 클래스는 생성기 단락 노트를 나타냅니다.

Note 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Note() | 새로운 [Note](/pdf/python-net/aspose.pdf/note/) 클래스 인스턴스를 초기화합니다. |
| Note(content) | Note 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| paragraphs | FootNote의 모든 단락을 나타내는 컬렉션을 가져오거나 설정합니다. |
| text | 노트 텍스트를 가져오거나 설정합니다. |
| text_state | 노트 텍스트 상태를 가져오거나 설정합니다. |
