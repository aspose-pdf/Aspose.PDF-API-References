## ColumnInfo class

이 클래스는 열 정보를 나타냅니다.

ColumnInfo 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| ColumnInfo() | ColumnInfo 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| column_widths | 열 너비를 포함하는 문자열을 가져오거나 설정합니다. <br/>            각 열의 값은 공백으로 구분되어야 합니다. 기본 단위는 포인트이며,<br/>            cm, 인치 및 사용 가능한 너비의 백분율도 지원됩니다.<br/>            예시: \"120 2.5cm 1.5inch\" |
| column_spacing | 열 사이의 간격을 포함하는 문자열을 가져오거나 설정합니다. <br/>            각 간격 값은 공백으로 구분되어야 합니다. 기본 단위는 포인트이며,<br/>            cm와 인치도 지원됩니다. 예시: \"120 2.5cm 1.5inch\". |
| column_count | 열 수를 나타내는 정수 값을 가져오거나 설정합니다. |
