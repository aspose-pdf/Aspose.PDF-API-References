## ArtifactCollection class

클래스는 아티팩트 컬렉션을 나타냅니다.

ArtifactCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_synchronized | 이 객체가 동기화되었습니까. |
| sync_root | 컬렉션의 동기화 객체를 가져옵니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 인덱스로 아티팩트를 가져옵니다. 인덱스는 1부터 시작합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| delete(artifact) | 지정된 아티팩트를 삭제합니다. |
| delete(index) | 인덱스로 아티팩트를 삭제합니다. |
| find_by_value(name, expected_value) | 사용자 지정 값으로 아티팩트를 찾습니다. |
| update(artifact) | 컬렉션 내의 아티팩트를 업데이트합니다. |
