## DocumentInfo class

PDF 문서의 메타 정보를 나타냅니다.

DocumentInfo 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| DocumentInfo(document) | DocumentInfo 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| 제목 | 문서 제목을 가져오거나 설정합니다. |
| creator | 문서 작성자를 가져오거나 설정합니다. |
| author | 문서 저자를 가져오거나 설정합니다. |
| subject | 문서의 주제를 가져오거나 설정합니다. |
| keywords | 문서의 키워드를 가져오거나 설정합니다. |
| producer | 문서 제작자를 가져오거나 설정합니다. |
| creation_date | 문서 생성 날짜를 가져오거나 설정합니다. |
| creation_time_zone | 생성 날짜의 시간대. |
| mod_time_zone | 수정 날짜의 시간대. |
| mod_date | 문서 수정 날짜를 가져오거나 설정합니다. |
| trapped | trapped 플래그를 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| add(key, value) | 지정된 키와 값으로 요소를 컬렉션에 추가합니다. |
| remove(key) | 지정된 키를 가진 요소를 컬렉션에서 제거합니다. |
| clear_custom_data() | 사용자 정의 데이터만 지우고, 다른 모든 미리 정의된 값(Title, Author 등)은 그대로 둡니다. |
| is_predefined_key(key) | 키가 미리 정의된 것인지(Title, Author 등) 확인하고, 사용자 정의가 아닌지 판단합니다. |
