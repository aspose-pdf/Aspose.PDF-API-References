## Point class

소수 좌표를 가진 점을 나타냅니다.

Point 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Point(x, y) | Point 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| x | X 좌표 값. |
| y | Y 좌표 값. |
| 사소한 | 좌표가 0인 점을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| to_point() | point를 System.Drawing.PointF 객체로 변환합니다. |
