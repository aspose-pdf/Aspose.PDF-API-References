## CompositingParameters class

현재 그래픽 상태의 그래픽 합성 매개변수를 포함하는 객체를 나타냅니다.

CompositingParameters 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| CompositingParameters(blend_mode) | CompositingParameters 클래스의 새 인스턴스를 초기화합니다 |
| CompositingParameters(blend_mode, filter_type) | CompositingParameters 클래스의 새 인스턴스를 초기화합니다 |
| CompositingParameters(blend_mode, filter_type, is_masked) | CompositingParameters 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| blend_mode | 현재 그래픽 상태의 블렌드 모드를 가져옵니다. |
| filter_type | 이미지 필터 유형을 가져옵니다. |
| is_masked | 마스크 플래그를 가져옵니다. |
