## PageLabelCollection class

클래스는 페이지 레이블 컬렉션을 나타냅니다.

PageLabelCollection 형식은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_label(page_index) | 페이지 인덱스로 페이지 레이블을 가져옵니다 (페이지 인덱스는 0부터 시작합니다). |
| update_label(page_index, page_label) | 주어진 페이지 인덱스에 대한 레이블을 업데이트합니다 (페이지 인덱스는 0부터 시작합니다). |
| remove_label(page_index) | 페이지 인덱스로 레이블을 제거합니다 (페이지 인덱스는 0부터 시작합니다). |
| get_pages() | 컬렉션에서 페이지 인덱스를 가져옵니다. |
