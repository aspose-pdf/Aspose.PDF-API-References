## PageCollection class

PDF 문서 페이지의 컬렉션입니다.

PageCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_synchronized | 객체가 동기화된 경우 true를 반환합니다. |
| sync_root | 컬렉션의 동기화 객체를 가져옵니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 인덱스로 페이지를 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| add(entity) | 컬렉션에 페이지를 추가합니다. |
| add() | 컬렉션에 페이지를 추가합니다. |
| add(pages) | 목록의 모든 페이지를 컬렉션에 추가합니다. |
| add(pages) | 배열의 모든 페이지를 컬렉션에 추가합니다. |
| delete(index) | 지정된 페이지를 삭제합니다. |
| delete() | 지정된 페이지를 삭제합니다. |
| delete(pages) | 배열에 지정된 번호의 페이지를 삭제합니다. |
| accept(visitor) | 주석 작업 기능을 제공하는 방문자 객체인 [AnnotationSelector](/pdf/python-net/aspose.pdf.annotations/annotationselector/)를 허용합니다. |
| accept(visitor) | 이미지 배치 객체 작업 기능을 제공하는 방문자 객체인 [ImagePlacementAbsorber](/pdf/python-net/aspose.pdf/imageplacementabsorber/)를 허용합니다. |
| accept(visitor) | 텍스트 객체 작업 기능을 제공하는 방문자 객체인 [TextFragmentAbsorber](/pdf/python-net/aspose.pdf.text/textfragmentabsorber/)를 허용합니다. |
| accept(visitor) | 텍스트 객체 작업 기능을 제공하는 방문자 객체인 [TextAbsorber](/pdf/python-net/aspose.pdf.text/textabsorber/)를 허용합니다. |
| insert(page_number) | 지정된 위치에 빈 페이지를 컬렉션에 삽입합니다. |

| insert(page_number, pages) | 컬렉션의 페이지를 문서에 삽입합니다. |
| insert(page_number, pages) | 배열의 페이지를 문서에 삽입합니다. |
| index_of(entity) | 지정된 페이지의 인덱스를 반환합니다. |
| flatten() | 페이지에 위치한 모든 필드를 제거하고 그 대신 값을 배치합니다. |
| free_memory() | 캐시된 데이터를 지웁니다 |
