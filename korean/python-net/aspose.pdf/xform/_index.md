## XForm class

클래스는 XForm을 나타냅니다.

XForm 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| b_box | 폼 경계 상자를 가져오거나 설정합니다. |
| 이름 | 폼 이름을 가져오거나 설정합니다. 폼 이름은 페이지 리소스의 XObejct 사전에서 폼을 참조하는 데 사용되는 이름입니다. |
| 내용 | 폼의 연산자를 가져옵니다. |
| opi | Open Prepress Interface (OPI)를 가져옵니다. |
| matrix | 폼의 매트릭스를 가져오거나 설정합니다. |
| resources | 폼 XObject 리소스를 가져옵니다. |
| rectangle | 폼의 사각형을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_resources(allow_create) | Form X-Object의 리소스를 반환합니다. |
| get_resources() | Form X-Object의 리소스를 반환합니다. |
| create_new_form(source, document) | 페이지 내용을 복제하는 XForm을 생성합니다. |
| free_memory() | 캐시된 데이터를 지웁니다 |
