## OutlineItemCollection class

PDF 문서의 개요 계층 구조에 있는 개요 항목을 나타냅니다.

OutlineItemCollection 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| OutlineItemCollection(outlines) | OutlineItemCollection 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| visible_count | 문서 개요 계층 구조의 모든 수준에서 개요 항목 총 수를 가져옵니다. |
| 제목 | 이 개요 항목의 제목을 가져오거나 설정합니다. |
| destination | 이 개요 항목의 목적지를 가져오거나 설정합니다. |
| action | 이 개요 항목의 동작을 가져오거나 설정합니다. |
| 색상 | 이 개요 항목의 제목 텍스트 색상을 가져오거나 설정합니다. |
| 기울임 | 이 개요 항목의 제목 텍스트에 대한 이탤릭 플래그를 가져오거나 설정합니다. |
| 굵게 | 이 개요 항목의 제목 텍스트에 대한 굵게 플래그를 가져오거나 설정합니다. |
| first | 개요 계층 구조에서 첫 번째 최상위 항목을 나타내는 개요 항목을 가져옵니다. |
| last | 개요 계층 구조에서 마지막 최상위 항목을 나타내는 개요 항목을 가져옵니다. |
| 이전 | 개요 계층 구조에서 이 항목에 상대적으로 이전 항목을 나타내는 개요 항목을 가져옵니다. |
| 다음 | 개요 계층 구조에서 이 항목에 상대적으로 다음 항목을 나타내는 개요 항목을 가져옵니다. |
| has_next | 개요 계층 구조에서 이 항목에 상대적으로 다음 항목을 나타내는 개요 항목이 있는지 확인합니다. |
| parent | 개요 계층 구조에서 이 개요 항목의 상위 객체를 가져옵니다. |
| is_synchronized | 이 컬렉션에 대한 접근이 동기화(스레드 안전)되는지 여부를 나타내는 값을 가져옵니다. |
| sync_root | 이 컬렉션에 대한 접근을 동기화하는 데 사용할 수 있는 객체를 가져옵니다. |
| open | 개요 항목에 대한 열림 상태(참/거짓)를 가져오거나 설정합니다. |
| level | 개요 항목의 계층 레벨을 가져옵니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 인덱스를 사용하여 컬렉션에서 개요 항목을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| delete() | 문서 개요 계층 구조에서 이 개요 항목을 삭제합니다. |
| delete(name) | 문서 개요 계층 구조에서 지정된 이름을 가진 개요 항목을 삭제합니다. |
| insert(index, outline) | 지정된 위치에 개요 항목을 컬렉션에 삽입합니다. |
