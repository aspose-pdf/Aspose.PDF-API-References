## Matrix3D class

클래스는 변환 행렬을 나타냅니다.

Matrix3D 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Matrix3D() | Constructor<br/>            표준 1 대 1 행렬을 생성합니다:<br/>            [ A B C D E F G H I Tx Ty Tz] = [ 1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0 , 0] |
| Matrix3D(matrix_3d_array) | Matrix3D 클래스의 새 인스턴스를 초기화합니다 |
| Matrix3D(matrix) | Matrix3D 클래스의 새 인스턴스를 초기화합니다 |
| Matrix3D(a, b, c, d, e, f, g, h, i, tx, ty, tz) | Matrix3D 클래스의 새 인스턴스를 초기화합니다 |
