## Rows class

테이블의 행 컬렉션을 나타냅니다.

Rows 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| Rows() | Rows 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| count | 항목 수. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | row를 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| add() | 컬렉션에 row를 추가합니다. |
| add(row) | 컬렉션에 row를 추가합니다. |
| index_of(row) | 컬렉션에서 row의 인덱스를 반환합니다. |
| remove(row) | 컬렉션에서 row를 제거합니다. |
| remove_at(index) | 컬렉션에서 지정된 위치의 row를 제거합니다. |
| remove_range(index, count) | 컬렉션에서 row 집합을 제거합니다. |
| dispose() | 해제합니다. |
