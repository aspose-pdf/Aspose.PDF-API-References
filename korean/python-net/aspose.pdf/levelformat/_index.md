## LevelFormat class

목차의 형식을 나타냅니다.

LevelFormat 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| LevelFormat() | LevelFormat 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| line_dash | 목차 라인 대시 스타일을 가져오거나 설정합니다. |
| margin | 목록 수준 여백을 가져오거나 설정합니다. |
| subsequent_lines_indent | 다음 줄 들여쓰기를 가져오거나 설정합니다. |
| text_state | 목록 수준 텍스트 상태를 가져오거나 설정합니다. |
