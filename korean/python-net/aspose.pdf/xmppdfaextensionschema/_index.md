## XmpPdfAExtensionSchema class

PDF/A-1에서 제공하는 XMP 확장 스키마를 설명합니다.

XmpPdfAExtensionSchema 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| XmpPdfAExtensionSchema(description) | XmpPdfAExtensionSchema 클래스의 새 인스턴스를 초기화합니다 |

| DEFAULT_SCHEMA_NAMESPACE_PREFIX | 기본 스키마 네임스페이스 접두사. |
