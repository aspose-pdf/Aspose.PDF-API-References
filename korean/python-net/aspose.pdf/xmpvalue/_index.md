## 속성
| 이름 | 설명 |
| :- | :- |
| is_string | 값이 문자열이면 true를 반환합니다. |
| is_integer | 값이 정수이면 true를 반환합니다. |
| is_double | 값이 부동 소수점 값이면 true를 반환합니다. |
| is_date_time | 값이 DateTime이면 true를 반환합니다. |
| is_field | XmpValue가 필드인 경우 true를 반환합니다. |
| is_named_value | XmpValue가 명명된 값인 경우 true를 반환합니다. |
| is_raw | 값이 지원되지 않거나 알 수 없으며 원시 XML 코드가 제공됩니다. |
| is_named_values | XmpValue가 명명된 값을 나타내면 true를 반환합니다. |
| is_structure | XmpValue가 구조를 나타내면 true를 반환합니다. |
| is_array | XmpValue가 배열이면 true를 반환합니다. |
