## PasswordType enumeration

이 열거형은 암호로 보호된 PDF 문서에 사용되는 알려진 비밀번호 유형을 나타냅니다.

## Members
| 멤버 이름 | 설명 |
| :- | :- |
| NONE | PDF 문서는 암호로 보호되지 않았습니다. |
| 사용자 | Pdf 문서는 문서 열기 비밀번호(제한된 접근)를 사용하여 열렸습니다. |
| 소유자 | Pdf 문서는 권한 변경 비밀번호(전체 접근)를 사용하여 열렸습니다. |
| 접근 불가 | Pdf 문서는 비밀번호로 보호되어 있지만 사용자와 소유자 비밀번호가 모두 비어 있지 않으며 <br/>            비밀번호가 정의되지 않았거나 제공된 비밀번호가 올바르지 않습니다. 따라서 비밀번호 유형을 추론할 수 없습니다. |
