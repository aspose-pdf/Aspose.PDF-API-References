## Resources class

페이지 리소스를 나타내는 클래스입니다.

Resources 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| forms | 가져옵니다 [forms](/pdf/python-net/aspose.pdf/resources/) 폼 컬렉션 |
| images | 가져옵니다 [images](/pdf/python-net/aspose.pdf/resources/) 이미지 컬렉션 |
| fonts | 가져옵니다 [fonts](/pdf/python-net/aspose.pdf/resources/) 폰트 리소스 컬렉션 |
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_fonts(create_if_absent) | 폰트 컬렉션을 반환합니다. 리소스에 폰트 항목이 없으면 CreateIfAbsent 플래그에 따라 생성됩니다. |
