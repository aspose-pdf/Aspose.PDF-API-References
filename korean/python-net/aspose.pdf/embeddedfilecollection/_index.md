## EmbeddedFileCollection class

임베디드 파일 컬렉션을 나타내는 클래스.

EmbeddedFileCollection 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| is_synchronized | 이 컬렉션에 대한 접근이 동기화(스레드 안전)되는지 여부를 나타내는 값을 가져옵니다. |
| sync_root | 이 컬렉션에 대한 접근을 동기화하는 데 사용할 수 있는 객체를 가져옵니다. |
| keys | 파일 첨부 키 목록을 반환합니다. |
## Indexer
| 이름 | 설명 |
| :- | :- |
| [index] | 인덱스로 포함 파일을 가져옵니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| delete(name) | 컬렉션에서 키를 사용하여 파일을 삭제합니다. |
| delete() | 컬렉션에서 키를 사용하여 파일을 삭제합니다. |
| add(key, file) | 지정된 키로 파일을 임베디드 파일에 추가합니다. |
| delete_by_key(key) | 컬렉션에서 키를 사용하여 파일을 삭제합니다. |
| find_by_name(name) | 이름으로 임베디드 파일을 반환합니다. |
