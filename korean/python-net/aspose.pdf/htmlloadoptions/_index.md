## HtmlLoadOptions class

HTML 파일을 PDF 문서에 로드/임포트하기 위한 옵션을 나타냅니다.

The HtmlLoadOptions 형식은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| HtmlLoadOptions() | 빈 기본 경로를 사용하여 html을 pdf 문서로 변환하기 위한 로드 옵션을 생성합니다. |
| HtmlLoadOptions(base_path) | HtmlLoadOptions 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| warning_handler | 생성된 모든 경고를 처리하기 위한 콜백입니다. <br/>            WarningHandler는 Continue 또는 Abort 중 하나를 지정하는 ReturnAction 열거형 항목을 반환합니다. <br/>            Continue는 기본 동작이며 로드 작업이 계속되지만, 사용자가 Abort를 반환하면 로드 작업이 중단되어야 합니다. |
| load_format | 파일 형식을 나타내며, [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/)에서 설명합니다. |
| is_render_to_single_page | 전체 문서를 단일 페이지로 렌더링하도록 가져오거나 설정합니다. |
| is_embed_fonts | 결과 문서에 폰트를 포함하도록 가져오거나 설정합니다. |
| page_layout_option | 레이아웃 옵션을 가져오거나 설정합니다. |
| html_media_type | 렌더링 중에 사용되는 가능한 미디어 유형을 가져오거나 설정합니다. |
| input_encoding | 구문 분석 시 이 문서에 사용되는 인코딩을 지정하는 속성을 가져오거나 설정합니다. 이 속성이 null인 경우 인코딩은 문서 문자 집합 속성에서 결정됩니다. |
| base_path | html 파일의 기본 경로/URL입니다. |
| page_info | 문서 페이지 정보를 가져오거나 설정합니다. |
