## BorderInfo class

이 클래스는 그래픽 요소의 테두리를 나타냅니다.

BorderInfo 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| BorderInfo(border_side, border_color) | BorderInfo 클래스의 새 인스턴스를 초기화합니다. |
| BorderInfo() | 새 인스턴스를 초기화합니다. [BorderInfo](/pdf/python-net/aspose.pdf/borderinfo/) 클래스. |
| BorderInfo(border_side) | BorderInfo 클래스의 새 인스턴스를 초기화합니다. |
| BorderInfo(border_side, border_width) | BorderInfo 클래스의 새 인스턴스를 초기화합니다. |
| BorderInfo(border_side, border_width, border_color) | BorderInfo 클래스의 새 인스턴스를 초기화합니다. |
| BorderInfo(border_side, info) | BorderInfo 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| left | 테두리 왼쪽을 나타내는 객체를 가져오거나 설정합니다. |
| 오른쪽 | 테두리 오른쪽을 나타내는 객체를 가져오거나 설정합니다. |
| top | 테두리 상단을 나타내는 객체를 가져오거나 설정합니다. |
| bottom | 테두리 하단을 나타내는 객체를 가져오거나 설정합니다. |
| rounded_border_radius | 둥근 테두리 반경을 가져오거나 설정합니다. |
## 메서드
| 이름 | 설명 |
| :- | :- |
| clone() | 새 BorderInfo 객체를 복제합니다. |
