## XmpField class

XMP 필드를 나타냅니다.

XmpField 유형은 다음 멤버를 노출합니다:
## 속성
| 이름 | 설명 |
| :- | :- |
| 비어 있음 | 빈 xmp 필드를 가져옵니다. |
| lang | xml:lang 한정자를 가져옵니다. |
| prefix | 접두사를 가져옵니다. |
| namespace_uri | 네임스페이스 URI를 가져옵니다. |
| local_name | 로컬의 이름을 가져오거나 설정합니다. |
| 이름 | 이름을 가져옵니다. |
| 값 | 값을 가져옵니다. |
| field_type | 필드의 유형을 가져옵니다. |
| is_empty | 이 인스턴스가 비어 있는지 여부를 나타내는 값을 가져옵니다. |
## 메서드

| :- | :- |
