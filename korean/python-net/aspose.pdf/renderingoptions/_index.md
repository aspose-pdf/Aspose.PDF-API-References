## RenderingOptions class

렌더링 옵션을 나타냅니다.

RenderingOptions 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| RenderingOptions() | RenderingOptions 클래스의 새 인스턴스를 초기화합니다. |
## 속성
| 이름 | 설명 |
| :- | :- |
| barcode_optimization | 바코드 최적화 모드를 가져오거나 설정합니다. |
| optimize_dimensions | 최적화 차원 모드를 가져오거나 설정합니다. |
| system_fonts_native_rendering | 시스템 글꼴이 네이티브로 렌더링되는 모드를 가져오거나 설정합니다. |
| use_new_imaging_engine | 새 이미지 엔진을 사용할지 여부를 결정하는 플래그를 가져오거나 설정합니다. |
| width_extra_units | AppendRectangle 연산자에 대한 사각형의 너비를 늘리거나 줄이는 데 사용되는 값을 가져오거나 설정합니다. |
| height_extra_units | AppendRectangle 연산자에 대한 사각형의 너비를 늘리거나 줄이는 데 사용되는 값을 가져오거나 설정합니다. |
| convert_fonts_to_unicode_ttf | 모든 글꼴이 TTF 유니코드 버전으로 변환된다는 것을 나타냅니다. 이는 호환성 <br/>             이유와 글꼴 사용을 최적화하는 데 유용합니다. 새로운 TTF 글꼴은 원본 글꼴의 모든 기호를 포함하지 않고, 텍스트에서 사용된 기호만 포함하기 때문입니다. |
| use_font_hinting | 이 플래그를 사용하면 글꼴 힌팅 메커니즘이 활성화됩니다. 글꼴 힌팅은 외곽선 글꼴의 표시를 조정하기 위한 수학적 명령을 사용하는 것입니다. <br/>            경우에 따라 이 플래그를 켜면 텍스트 가독성 문제를 해결할 수 있습니다. <br/>            현재 이 플래그의 사용은 소스 문서에서 TTF 글꼴이 사용되는 경우에만 효과를 줄 수 있습니다. |
| scale_images_to_fit_page_width | 페이지의 너비에 맞게 페이지의 모든 이미지를 스케일링하는 데 사용되는 값을 가져오거나 설정합니다. |
| interpolation_high_quality | 보간을 위한 고품질 모드를 가져오거나 설정합니다. |
| max_fonts_cache_size | 글꼴 캐시의 최대 글꼴 수입니다. 기본값은 10입니다. |
| max_symbols_cache_size | 심볼 캐시의 최대 심볼 수입니다. 기본값은 100입니다. |
| default_font_name | 누락된 글꼴을 대체하는 데 사용되는 기본 글꼴 이름을 가져오거나 설정합니다. |
| ignore_resource_font_errors | 글꼴이 없을 때 발생하는 오류를 무시하도록 표시를 가져오거나 설정합니다.<br/>            true - 글꼴이 없을 때 발생하는 오류를 무시함을 의미합니다. 잘못된 리소스를 참조하는 텍스트 세그먼트는 처리 중에 건너뛰어집니다.<br/>            기본값은 false |
