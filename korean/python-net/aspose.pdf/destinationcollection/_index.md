## DestinationCollection class

클래스는 PDF 문서에서 모든 목적지(이름 문자열을 목적지에 매핑하는 이름 트리(12.3.2.3, \"Named Destinations\" 및 7.7.4, \"Name Dictionary\" 참조))의 컬렉션을 나타냅니다.

DestinationCollection 유형은 다음 멤버를 노출합니다:
## 메서드
| 이름 | 설명 |
| :- | :- |
| get_page_number(destiname_name, use_cache) | 지정된 이름으로 목적지의 페이지 번호를 반환합니다. |
| get_explicit_destination(destiname_name, use_cache) | 지정된 이름으로 명시적 목적지를 반환합니다. |
