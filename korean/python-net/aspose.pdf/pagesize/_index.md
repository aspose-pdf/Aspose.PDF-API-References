## PageSize class

클래스는 PDF 문서의 페이지 크기를 나타냅니다.

PageSize 유형은 다음 멤버를 노출합니다:
## 생성자
| 이름 | 설명 |
| :- | :- |
| PageSize(x, y) | PageSize 클래스의 새 인스턴스를 초기화합니다 |
## 속성
| 이름 | 설명 |
| :- | :- |
| width | 페이지 너비를 가져오거나 설정합니다. |
| 높이 | 페이지 높이를 가져오거나 설정합니다. |
| is_landscape | 페이지 방향을 가져옵니다. 가로 방향이면 true, 세로 방향이면 false를 반환합니다. |
| a0 | A0 크기 (1189x840 mm). |
| a1 | A1 크기 (840x594 mm). |
| a2 | A2 크기 (594x420 mm). |
| a3 | A3 크기 (420x297 mm). |
| a4 | A4 크기 (297x210 mm). |
| a5 | A5 크기 (210x148 mm). |
| a6 | A6 크기 (148x105 mm). |
| b5 | B5 크기 (250x176 mm). |
| page_letter | 레터 크기 (279x216 mm). |
| page_legal | 레터럴 크기 (356x216 mm). |
| page_ledger | 레저 크기 (432x279 mm). |
| p11x17 | 11x17 인치 형식. |
