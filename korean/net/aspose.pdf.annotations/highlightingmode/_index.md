## HighlightingMode enumeration

주석의 하이라이트 모드를 열거하며, 활성 영역 내에서 마우스 버튼을 누르거나 눌러 있을 때 사용되는 시각 효과를 나타냅니다.

```csharp
public enum HighlightingMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | `0` | 하이라이팅 없음. |
| Invert | `1` | Annotation 사각형의 내용을 반전시킵니다. |
| Outline | `2` | Annotation의 테두리를 반전시킵니다. |
| Push | `3` | Annotation의 다운 외관이 있으면 표시합니다. 다운 외관이 정의되지 않은 경우, Annotation 사각형의 내용을 오프셋하여 페이지 표면 아래로 눌린 것처럼 보이게 합니다. |
| Toggle | `4` | Push와 동일합니다 (선호되는 방식). |
