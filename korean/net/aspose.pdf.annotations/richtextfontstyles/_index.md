## RichTextFontStyles enumeration

```csharp
[Flags]
public enum RichTextFontStyles
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| ClearExisting | `1` | 설정하면 추가 스타일을 적용하기 전에 기존 스타일을 모두 지웁니다. 다른 스타일 플래그(예: Bold)와 결합될 경우 먼저 스타일을 초기화한 다음 지정된 스타일을 적용합니다. 이 플래그가 없으면 새로운 스타일이 기존 스타일에 추가됩니다. |
| Bold | `2` | 굵게 지정하는 옵션입니다. |
| Italic | `4` | 이탤릭체를 지정하는 옵션입니다. |
| Underline | `8` | 밑줄을 지정하는 옵션입니다. |
