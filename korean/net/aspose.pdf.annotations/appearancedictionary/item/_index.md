## AppearanceDictionary indexer

모양 스트림을 가져오기 위한 편리한 형태를 나타냅니다.

```csharp
public XForm this[string key] { get; set; }
```

| 매개변수 | 설명 |
| --- | --- |
| key | appearance 스트림에 대한 경로를 나타냅니다. appearance 사전에 하위 사전이 있는 경우 경로는 2개의 부분을 포함해야 합니다([`Keys`](../keys/)), 그렇지 않으면 경로는 한 부분만 가집니다. |

### 반환 값

주어진 키에 해당하는 XForm 객체(appearance 스트림)입니다.
