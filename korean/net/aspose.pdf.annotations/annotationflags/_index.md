## AnnotationFlags enumeration

주석의 다양한 특성을 지정하는 플래그 집합입니다.

```csharp
[Flags]
public enum AnnotationFlags
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| Default | `0` | 기본값. |
| Invisible | `1` | 설정된 경우, 표준 주석 유형 중 하나에 속하지 않고 주석 핸들러가 없는 경우 주석을 표시하지 않습니다. 해제된 경우, 해당 외형 사전이 지정한 외형 스트림이 있는 경우, 알려지지 않은 주석을 표시합니다. |
| Hidden | `2` | 설정된 경우, 주석 유형이나 주석 핸들러의 존재 여부와 관계없이 주석을 표시하거나 인쇄하지 않으며 사용자와의 상호 작용을 허용하지 않습니다. 화면 공간이 제한된 경우, 외형 스트림과 결합하여 선택적으로 주석을 숨기고 표시함으로써 온라인 도움말 시스템과 유사한 기능의 보조 팝업 정보를 표시할 수 있습니다. |
| Print | `4` | 설정된 경우, 페이지가 인쇄될 때 주석을 인쇄합니다. 해제된 경우, 화면에 표시 여부와 관계없이 주석을 절대 인쇄하지 않습니다. 예를 들어, 인쇄된 페이지에서는 의미가 없는 대화형 푸시버튼을 나타내는 주석에 유용할 수 있습니다. |
| NoZoom | `8` | 설정된 경우, 페이지 확대 배율에 맞게 주석의 외형을 확대/축소하지 않습니다. 주석 사각형의 왼쪽 위 모서리로 정의되는 페이지상의 주석 위치는 페이지 확대 배율과 관계없이 고정됩니다. |
| NoRotate | `10` | 설정된 경우, 페이지 회전에 맞게 주석의 외형을 회전하지 않습니다. 주석 사각형의 왼쪽 위 모서리는 페이지 회전과 관계없이 페이지상의 고정된 위치에 유지됩니다. |
| NoView | `20` | 설정된 경우, 주석을 화면에 표시하지 않으며 사용자와 상호 작용하도록 허용하지 않습니다. 주석은 인쇄될 수 있지만( Print 플래그 설정에 따라) 화면 표시 및 사용자 상호 작용 목적상 숨겨진 것으로 간주되어야 합니다. |
| ReadOnly | `40` | 설정된 경우, 주석이 사용자와 상호 작용하는 것을 허용하지 않습니다. 주석은 NoView 및 Print 플래그 설정에 따라 표시되거나 인쇄될 수 있지만 마우스 클릭에 반응하거나 마우스 움직임에 따라 외관이 변경되지 않아야 합니다. 이 플래그는 위젯 주석에 대해 무시되며, 해당 기능은 연관된 양식 필드의 ReadOnly 플래그에 의해 대체됩니다. |
| Locked | `80` | 설정된 경우, 사용자가 주석을 삭제하거나 해당 속성(위치 및 크기 포함)을 수정하는 것을 허용하지 않습니다. 그러나 이 플래그는 양식 필드 값과 같은 주석 내용의 변경은 제한하지 않습니다. |
| ToggleNoView | `100` | 설정된 경우, 특정 이벤트에 대해 NoView 플래그의 해석을 반전시킵니다. 일반적인 사용 예는 마우스 커서를 올려놓은 상태에서만 주석이 표시되도록 하는 것입니다. |
| LockedContents | `200` | 설정된 경우, 사용자가 주석의 내용을 수정하는 것을 허용하지 않습니다. 이 플래그는 주석 삭제나 위치 및 크기와 같은 다른 주석 속성의 변경을 제한하지 않습니다. |
