## TextSearchOptions.IgnoreShadowText property

검색 중에 일반 텍스트의 그림자를 나타내는 텍스트 조각을 무시하도록 표시를 가져오거나 설정합니다. true - 그림자 텍스트가 검색되지 않음을 의미합니다(텍스트 검색이 근접 위치에서 중복 조각을 반환할 경우 시도해 보세요). false - 그림자 텍스트가 일반 텍스트와 함께 검색됨을 의미합니다(기본값).

```csharp
public bool IgnoreShadowText { get; set; }
```
