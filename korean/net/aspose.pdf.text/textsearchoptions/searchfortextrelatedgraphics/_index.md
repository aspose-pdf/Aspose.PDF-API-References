## TextSearchOptions.SearchForTextRelatedGraphics property

텍스트 검색 중에 텍스트와 관련된 그래픽(밑줄, 배경 등)을 검색하도록 허용하는 값을 가져오거나 설정합니다. true - 텍스트와 관련된 그래픽 검색이 수행됩니다(기본값). false - 원본 document에 존재할 수 있는 그래픽 요소가 무시됩니다. 성능 문제가 있거나 밑줄, 배경, 클리핑을 처리할 필요가 없을 경우 이 값을 설정하십시오.

```csharp
public bool SearchForTextRelatedGraphics { get; set; }
```
