## AbsorbedRow.CompareTo method

현재 AbsorbedRow 객체를 다른 AbsorbedRow 객체와 비교하고, 현재 객체가 정렬 순서에서 앞선, 뒤에 있거나 동일한 위치에 있는지를 나타내는 정수를 반환합니다.

```csharp
public int CompareTo(AbsorbedRow other)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| other | AbsorbedRow | 이 객체와 비교할 AbsorbedRow 객체. |

### 반환 값

비교되는 객체들의 상대 순서를 나타내는 값입니다. 반환값은 다음과 같은 의미를 가집니다: -1: 이 객체가 정렬 순서에서 다른 객체보다 앞섭니다. 0: 이 객체가 다른 객체와 같은 위치에 있습니다. 1: 이 객체가 정렬 순서에서 다른 객체보다 뒤에 있습니다.
