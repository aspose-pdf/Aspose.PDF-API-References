## TextRenderingMode enumeration

텍스트 렌더링 모드인 Tmode는 텍스트를 표시할 때 글리프 윤곽선을 스트로크하거나, 채우거나, 클리핑 경계로 사용하거나, 이 세 가지의 조합 중 어느 것이 적용될지를 결정합니다.

```csharp
public enum TextRenderingMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| FillText | `0` | 텍스트를 채웁니다. |
| StrokeText | `1` | 텍스트를 스트로크합니다. |
| FillThenStrokeText | `2` | 텍스트를 채운 다음 스트로크합니다. |
| Invisible | `3` | 텍스트를 채우지도 스트로크하지도 않습니다 (보이지 않음). |
| FillTextAndAddPathToClipping | `4` | 텍스트를 채우고 클리핑을 위해 경로에 추가합니다 (9.3.6, \"Text Rendering Mode,\" 참조). |
| StrokeTextAndAddPathToClipping | `5` | 텍스트를 스트로크하고 클리핑을 위해 경로에 추가합니다. |
| FillThenStrokeTextAndAddPathToClipping | `6` | 텍스트를 채운 다음 스트로크하고 클리핑을 위해 경로에 추가합니다. |
| AddPathToClipping | `7` | 텍스트를 클리핑을 위해 경로에 추가합니다. |
