## TextExtractionOptions.ScaleFactor property

순수 모드에서 추출 중에 글꼴 크기를 스케일링하는 데 적용되는 계수를 가져오거나 설정합니다. 값이 낮을수록 추출된 텍스트에 공백이 더 많이 생깁니다. 기본값은 1이며 스케일링이 적용되지 않습니다; 값을 0으로 설정하면 알고리즘이 자동으로 스케일링을 선택합니다.

```csharp
public double ScaleFactor { get; set; }
```
