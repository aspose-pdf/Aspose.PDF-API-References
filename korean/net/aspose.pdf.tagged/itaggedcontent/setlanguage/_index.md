## ITaggedContent.SetLanguage method

pdf 문서의 자연어를 설정합니다.

문서의 모든 텍스트에 대한 자연어를 지정하는 언어 식별자이며, 구조 요소 또는 마크된 콘텐츠에 대한 언어 지정에 의해 재정의되는 경우를 제외합니다.

```csharp
public void SetLanguage(string lang)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| lang | String | 언어 식별자는 언어를 알 수 없음을 나타내는 빈 문자열이거나, RFC 3066에서 정의된 언어 태그(언어 식별을 위한 태그) 중 하나여야 합니다. |
