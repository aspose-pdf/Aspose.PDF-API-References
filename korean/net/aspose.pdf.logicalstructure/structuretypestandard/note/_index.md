## StructureTypeStandard.Note field

(Note) 문서 본문에서 참조되는 각주나 미주와 같은 설명 텍스트 항목입니다. 자식으로 레이블(structure type Lbl)을 가질 수 있습니다. 이 주석은 이를 참조하는 본문 텍스트의 구조 요소의 자식으로 포함될 수도 있고, 다른 위치(예: 미주 섹션)에 포함되어 참조(structure type Reference)를 통해 접근될 수도 있습니다.

Tagged PDF는 페이지 콘텐츠 순서에서 각주의 배치를 규정하지 않습니다. 각주는 인라인으로 배치되거나 페이지 끝에 배치될 수 있으며, 이는 호환 작성자의 재량에 따릅니다.

```csharp
public static readonly StructureTypeStandard Note;
```
