## StructureTypeStandard.BibEntry field

(Bibliography entry) 인용된 콘텐츠의 외부 출처를 식별하는 참고 문헌입니다. 자식으로 레이블(structure type Lbl)을 포함할 수 있습니다.

비록 서지 항목에 인용된 콘텐츠의 저자, 작업, 출판사 등을 식별하는 구성 요소가 포함될 가능성이 높지만, 이 수준의 상세도에서는 표준 구조 유형이 정의되어 있지 않습니다.

```csharp
public static readonly StructureTypeStandard BibEntry;
```
