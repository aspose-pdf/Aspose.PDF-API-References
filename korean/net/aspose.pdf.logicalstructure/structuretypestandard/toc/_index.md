## StructureTypeStandard.TOC field

(Table of contents) 목차 항목 엔트리(structure type TOCI)와/또는 다른 중첩 목차 엔트리(TOC)로 구성된 목록입니다.

TOCI 엔트리만 포함하는 TOC 항목은 평면 계층 구조를 나타냅니다. 다른 중첩된 TOC 엔트리(및 가능하면 TOCI 엔트리)를 포함하는 TOC 항목은 보다 복잡한 계층 구조를 나타냅니다. 이상적으로는 최상위 TOC 항목의 계층 구조가 문서 본문의 구조를 반영합니다.

```csharp
public static readonly StructureTypeStandard TOC;
```
