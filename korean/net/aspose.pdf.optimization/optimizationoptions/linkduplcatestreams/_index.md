## OptimizationOptions.LinkDuplcateStreams property

이 플래그가 true로 설정되면 Resource 스트림이 분석됩니다. 중복 스트림이 발견되면(예: 스트림 내용이 동일한 경우) 해당 스트림은 하나의 객체로 저장됩니다. 이는 경우에 따라 문서 크기를 줄이는 데 도움이 됩니다(예: 동일한 문서를 여러 번 연결한 경우).

```csharp
public bool LinkDuplcateStreams { get; set; }
```
