## OptimizationOptions.RemoveUnusedStreams property

이 플래그가 true로 설정되면 모든 리소스가 사용 여부에 따라 검사됩니다. 리소스가 사용되지 않으면 해당 리소스가 제거됩니다. 이는 예를 들어 페이지가 문서에서 추출된 경우와 같이 문서 크기를 감소시킬 수 있습니다.

```csharp
public bool RemoveUnusedStreams { get; set; }
```
