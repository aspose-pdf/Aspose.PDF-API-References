## ImageCompressionOptions.Version property

압축 알고리즘의 버전입니다. 가능한 값은: 1. 표준 압축, 2. fast (표준보다 빠른 향상된 압축이지만 모든 이미지에 적용되지 않을 수 있음), 3. mixed (표준 압축이 더 빠른 알고리즘으로 압축할 수 없는 이미지에 적용되며, 이는 최상의 압축을 제공하지만 \"fast\" 알고리즘보다 느립니다. \"Fast\" 버전은 이미지 크기 조정에 적용되지 않으며 (표준 방법이 사용됩니다). 기본값은 \"Standard\"입니다.)

```csharp
public ImageCompressionVersion Version { get; set; }
```
