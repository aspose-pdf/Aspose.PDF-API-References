## AddOption(string) {#addoption}

체크 박스 그룹에 새 체크 박스를 추가합니다. 이 그룹에서는 동시에 하나의 체크 박스만 선택될 수 있습니다. 새 체크 박스는 그룹의 하단에 추가됩니다.

```csharp
public void AddOption(string optionName)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| optionName | String | 추가된 체크박스가 나타내는 옵션의 값. |
