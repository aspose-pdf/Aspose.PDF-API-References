## Signature.DefaultSignatureLength property

서명 데이터의 기본 길이(바이트)를 가져오거나 설정합니다.

```csharp
public int DefaultSignatureLength { get; set; }
```

## 비고

이는 서명의 바이트 길이에 대한 추정값입니다. [`CustomSignHash`](../customsignhash/)를 통해 서명할 때, [`AvoidEstimatingSignatureLength`](../avoidestimatingsignaturelength/) 매개변수가 설정된 경우에 사용됩니다. 기본값은 3000입니다.
