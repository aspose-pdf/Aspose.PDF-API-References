## Field.IsSharedField property

Generator 지원을 위한 속성입니다. 필드가 헤더 또는 푸터에 추가될 때 사용됩니다. true인 경우, 이 필드는 한 번만 생성되며 그 외관이 모든 Document 페이지에 표시됩니다. false인 경우, 각 Document 페이지마다 별도의 필드가 생성됩니다.

```csharp
public bool IsSharedField { get; set; }
```
