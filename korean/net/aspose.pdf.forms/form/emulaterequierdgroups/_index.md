## Form.EmulateRequierdGroups property

이 속성이 true이면 필수 Xfa exclGroup 요소 컨테이너에 대해 추가 빨간 경계 사각형이 그려집니다. 이 속성은 exclGroup에 대한 유사 항목이 없어서 Xfa 양식을 표준으로 변환할 때 도입되었습니다. 기본값은 false입니다.

```csharp
public bool EmulateRequierdGroups { get; set; }
```
