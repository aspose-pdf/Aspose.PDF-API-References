## BarcodeField.XSymHeight property

두 바코드 모듈 사이의 수직 거리를 픽셀 단위로 가져옵니다. 비율 XSymHeight/XSymWidth는 정수 값이어야 합니다. PDF417의 경우 허용 비율 범위는 1에서 4 사이입니다. QRCode 및 DataMatrix의 경우 이 비율은 항상 1이어야 합니다.

public int XSymHeight { get; }
