## ValidationOptions.CheckCertificateChain property

검증 과정에서 인증서 체인을 확인할지 여부를 나타내는 값을 가져오거나 설정합니다.

```csharp
public bool CheckCertificateChain { get; set; }
```

## 비고

속성이 설정되면 인증서 체인의 존재 여부를 확인합니다. 체인이 없으면 검증 결과가 Undefined가 되며, 이는 Adobe Acrobat의 동작과 동일합니다. 온라인에서 폐기 상태만 확인하려면 해당 필드를 `false` 로 설정하십시오. 기본값은 `false` 입니다.
