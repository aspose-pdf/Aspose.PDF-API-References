## ValidationMode enumeration

PDF 서명 검증 프로세스에 대한 검증 모드를 지정합니다.

```csharp
public enum ValidationMode
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | `0` | 검증이 수행되지 않는 모드를 나타냅니다. |
| OnlyCheck | `1` | 검증이 수행되지만 그 결과가 디지털 서명의 검증에 영향을 주지 않는 모드를 나타냅니다. 검증 결과는 직접 확인할 수 있습니다. |
| Strict | `2` | 검증이 수행되고 그 결과가 디지털 서명의 검증에 영향을 미치는 모드를 나타냅니다. 인증서를 확인할 수 없으면 디지털 서명이 유효하지 않은 것으로 간주됩니다. 검증 결과는 직접 확인할 수 있습니다. |
