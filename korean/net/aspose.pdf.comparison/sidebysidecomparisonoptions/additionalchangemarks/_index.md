## SideBySideComparisonOptions.AdditionalChangeMarks property

추가 변경 표시기가 표시되는지를 결정하는 속성을 가져오고 설정합니다. 설정하면 현재 페이지에 없지만 다른 페이지에 존재하는 변경 표시를 표시합니다. 변경이 단어 사이에 위치하는 경우, 표시가 공백 문자에 정확히 맞춰지지 않을 수 있습니다. 기본값은 `false`입니다.

```csharp
public bool AdditionalChangeMarks { get; set; }
```
