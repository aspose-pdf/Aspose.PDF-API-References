## PdfExtractor.Resolution property

추출된 이미지의 해상도를 설정하거나 가져옵니다. 기본값은 150입니다. 해상도 값이 높을수록 이미지가 더 선명해집니다. 그러나 해상도 값을 높이면 이미지 추출에 필요한 시간과 메모리가 증가합니다. 일반적으로 선명한 이미지를 얻으려면 해상도를 150 또는 300으로 설정하면 충분합니다.

```csharp
public int Resolution { get; set; }
```
