## FormDataConverter.Table property

중간 데이터 컨테이너인 DataTable을 가져오거나 설정합니다. 한 형식에서 다른 형식으로 데이터를 변환하기 전에 정의되어야 합니다. DataTable의 Columns와 TableName을 정의해야 합니다. TableName은 데이터베이스의 테이블 이름입니다. 각 열의 ColumnName은 pdf의 정규화된 필드 이름이며, 각 열의 Caption은 데이터베이스 테이블의 열 이름입니다. 필드 이름이 테이블 열 이름과 동일한 경우 Caption을 지정할 필요가 없습니다.

```csharp
public DataTable Table { get; set; }
```
