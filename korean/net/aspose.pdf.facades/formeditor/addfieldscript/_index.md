## FormEditor.AddFieldScript method

PushButton 필드에 대한 JavaScript를 추가합니다. 기존 이벤트가 있으면 새 이벤트가 그 뒤에 추가됩니다.

```csharp
public bool AddFieldScript(string fieldName, string script)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| fieldName | String | 전체 한정된 필드 이름. |
| 스크립트 | String | PushButton 필드에 추가/배치될 Java 스크립트. |

### 반환 값

스크립트가 성공적으로 추가된 경우 True.
