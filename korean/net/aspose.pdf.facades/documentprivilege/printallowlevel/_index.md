## DocumentPrivilege.PrintAllowLevel property

문서 권한의 인쇄 수준을 가져오고 설정합니다. Adobe Professional의 'Printing Allowed' 설정과 동일합니다. 0: 없음. 1: 저해상도 (150 dpi). 2: 고해상도.

```csharp
public int PrintAllowLevel { get; set; }
```

## 비고

속성 값이 -1이면, 해당 수준은 정의되지 않습니다.
