## DocumentPrivilege.ChangeAllowLevel property

문서 권한의 변경 수준을 가져오고 설정합니다. Adobe Professional의 'Changes Allowed' 설정과 동일합니다. 0: 없음. 1: 페이지 삽입, 삭제 및 회전. 2: 양식 필드 채우기 및 기존 서명 필드 서명. 3: 주석 달기, 양식 필드 채우기 및 기존 서명 필드 서명. 4: 페이지 추출을 제외한 모든 작업.

```csharp
public int ChangeAllowLevel { get; set; }
```

## 비고

속성 값이 -1이면, 해당 수준은 정의되지 않습니다.
