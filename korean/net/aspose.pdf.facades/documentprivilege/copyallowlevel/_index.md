## DocumentPrivilege.CopyAllowLevel property

문서 권한의 복사 수준을 가져오고 설정합니다. Adobe Professional의 권한 설정과 동일합니다. 0: 없음. 1: 시각 장애인을 위한 화면 판독기 장치에 텍스트 접근 허용. 2: 텍스트, 이미지 및 기타 콘텐츠 복사 허용.

```csharp
public int CopyAllowLevel { get; set; }
```

## 비고

속성 값이 -1이면, 해당 수준은 정의되지 않습니다.
