## PdfFileEditor.MergeDuplicateLayers property

이 속성이 true이면 동일한 이름을 가진 연결된 문서의 선택적 내용이 결과 문서의 하나의 레이어로 병합됩니다. 그렇지 않으면 동일한 이름의 레이어가 결과 문서에서 별개의 레이어로 저장됩니다.

```csharp
public bool MergeDuplicateLayers { get; set; }
```
