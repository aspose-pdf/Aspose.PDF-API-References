**Aspose.Pdf.DataEditor**는 문서 내 데이터를 편집하기 위한 도구를 포함합니다.

## 클래스

| 클래스 | 설명 |
| --- | --- |
| [CosPdfBoolean](./cospdfboolean/) | 이 클래스는 부울 타입을 나타냅니다. |
| [CosPdfDictionary](./cospdfdictionary/) | 객체의 사전에 접근하기 위한 클래스입니다. |
| [CosPdfName](./cospdfname/) | 이 클래스는 Pdf Name 객체를 나타냅니다. |
| [CosPdfNumber](./cospdfnumber/) | 이 클래스는 Pdf Number 타입을 나타냅니다. |
| [CosPdfPrimitive](./cospdfprimitive/) | 이 클래스는 기본 공개 타입 [`CosPdfPrimitive`](../aspose.pdf.dataeditor/cospdfprimitive/)을 나타냅니다. |
| [CosPdfString](./cospdfstring/) | 이 클래스는 Pdf String 객체를 나타냅니다. |
| [DictionaryEditor](./dictionaryeditor/) | 문서 트리 사전(문서 사전, 페이지 사전, 리소스 사전)에 접근하기 위한 클래스입니다. |
