## VectorStore class

file_ids를 사용하여 벡터 저장소를 생성하고 이 스레드에 연결하는 도우미입니다. 스레드에 연결될 수 있는 벡터 저장소는 최대 1개입니다.

| [FileIds](../../aspose.pdf.ai/vectorstore/fileids/) { get; set; } | 벡터 스토어에 추가할 파일 ID 목록을 가져오거나 설정합니다. 벡터 스토어당 최대 10,000개의 파일을 포함할 수 있습니다. |
