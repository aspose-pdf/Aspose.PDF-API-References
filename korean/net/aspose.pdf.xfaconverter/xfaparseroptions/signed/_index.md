## XfaParserOptions.Signed property

이 속성이 true이면 (존재하는 경우) xfa 폼 스트림을 사용하여 문서를 변환합니다. false이면 xfa 폼 스트림이 무시됩니다. 이 속성은 서명을 확인하는 데 사용되는 체크섬을 계산하는 방법이 명확하지 않아 도입되었습니다.

```csharp
public bool Signed { get; set; }
```
