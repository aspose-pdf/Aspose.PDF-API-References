## XfaParserOptions.EmulateRequierdGroups property

이 속성이 true이면 필수 Xfa "excluded groups"에 대해 추가 빨간 사각형이 그려집니다. 이 속성은 양식의 Xfa 표현을 표준으로 변환하는 동안 제외 그룹의 유사물이 없기 때문에 도입되었습니다. 기본값은 false입니다.

```csharp
public bool EmulateRequierdGroups { get; set; }
```
