## AutoTaggingSettings.HeadingRecognitionStrategy property

자동 태깅 중 문서의 헤딩을 인식하는 데 사용되는 전략을 가져오거나 설정합니다.

```csharp
public HeadingRecognitionStrategy HeadingRecognitionStrategy { get; set; }
```

## 비고

`HeadingRecognitionStrategy` 속성은 문서에서 제목을 식별하는 방법을 결정합니다. 사용 가능한 전략에는 개요를 기반으로 제목을 인식하는 것, 휴리스틱 분석, 자동 감지가 포함됩니다. 이 속성을 None으로 설정하면 제목 인식이 비활성화됩니다.
