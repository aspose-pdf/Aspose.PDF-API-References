## AutoTaggingSettings.HeadingLevels property

PDF 문서에서 제목 구조를 결정하는 데 사용되는 헤딩 레벨을 가져오거나 설정합니다.

```csharp
public HeadingLevels HeadingLevels { get; set; }
```

## 비고

`HeadingLevels` 속성은 글꼴 크기를 제목 레벨에 매핑하도록 구성할 수 있게 합니다. 이는 자동 태깅 과정에서 문서 내 텍스트 요소의 글꼴 크기에 따라 적절한 제목 레벨을 식별하고 할당하는 데 사용됩니다.
