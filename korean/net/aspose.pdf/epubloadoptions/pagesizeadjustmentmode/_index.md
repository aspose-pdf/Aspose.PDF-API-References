## EpubLoadOptions.PageSizeAdjustmentMode field

주의! 이 기능은 구현되었지만 샘플 문서에서 OSHARED 레이어의 차단 이슈가 발견되어 아직 공개 API에 반영되지 않았습니다. 변환 중 페이지 크기 사용 모드를 나타냅니다. HTML, EPUB 등과 같은 포맷은 일반적으로 유동적인 디자인을 가지고 있어 필요한 페이지 크기에 맞출 수 있습니다. 그러나 경우에 따라 콘텐츠에 지정된 가로 위치나 크기가 있어 필요한 페이지 크기에 맞추기 어려울 수 있습니다. 이러한 경우(예: 콘텐츠 크기가 결과 PDF 문서의 초기 페이지 크기에 맞지 않을 때) 어떻게 처리할지 정의할 수 있습니다.

```csharp
public PageSizeAdjustmentModes PageSizeAdjustmentMode;
```
