## HtmlSaveOptions.FontSavingModes enumeration

저장된 PDF에서 참조된 글꼴을 저장하는 데 사용할 수 있는 모드를 열거합니다.

```csharp
public enum FontSavingModes
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| AlwaysSaveAsWOFF | `0` | 모든 참조된 글꼴은 WOFF 글꼴로 저장되고 참조됩니다. |
| AlwaysSaveAsTTF | `1` | 모든 참조된 글꼴은 TTF-글꼴로 저장되고 참조됩니다. |
| AlwaysSaveAsEOT | `2` | 모든 참조된 글꼴은 EOT-글꼴로 저장되고 참조됩니다. |
| SaveInAllFormats | `3` | 모든 참조된 글꼴은 (CSS에서 참조되도록) 3개의 독립 파일인 EOT, TTH, WOFF로 저장됩니다. 이는 출력 데이터 크기를 증가시키지만 대부분의 웹 브라우저에 적합한 출력을 만들 수 있습니다. |
| DontSave | `4` | 모든 참조된 글꼴은 저장되지 않습니다. |
