## HtmlSaveOptions.IgnoreResourceFontErrors property

폰트가 없을 때 발생하는 오류를 무시하도록 표시하는 값을 가져오거나 설정합니다. true - 폰트가 없을 때 발생하는 오류를 무시함을 의미합니다. 잘못된 리소스를 참조하는 텍스트 세그먼트는 처리 중에 건너뛰어집니다. 기본값은 false입니다.

```csharp
public bool IgnoreResourceFontErrors { get; set; }
```
