## HtmlSaveOptions.PagesFlowTypeDependsOnViewersScreenSize field

속성 'SplitOnPages=false'인 경우, 모든 입력 PDF 페이지를 나타내는 전체 HTML이 하나의 큰 결과 HTML 파일에 넣어집니다. 이 플래그는 결과 HTML이 PDF 페이지를 나타내는 영역의 흐름이 뷰어의 화면 해상도에 따라 달라지도록 생성될지 여부를 정의합니다. 예를 들어 뷰어 측 화면 폭이 충분히 넓어 가로 방향으로 두 페이지 이상을 나란히 배치할 수 있다고 가정합니다. 이 플래그가 true로 설정되면 이러한 기회가 활용되어 가능한 한 많은 페이지가 가로 방향으로 나란히 표시되고, 다음 가로 그룹의 페이지는 첫 번째 그룹 아래에 표시됩니다. 반대로 페이지는 항상 이전 페이지 아래에 이어서 흐르게 됩니다.

```csharp
public bool PagesFlowTypeDependsOnViewersScreenSize;
```
