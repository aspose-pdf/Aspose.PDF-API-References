## HtmlSaveOptions.SaveFullFont property

전체 글꼴이 저장됨을 나타내며, True Type 글꼴만 지원합니다. 기본값은 SaveFullFont = false이며, 변환기는 문서 텍스트를 표시하는 데 필요한 초기 글꼴의 부분 집합만 저장합니다.

```csharp
public bool SaveFullFont { get; set; }
```
