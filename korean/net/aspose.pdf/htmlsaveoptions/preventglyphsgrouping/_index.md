## HtmlSaveOptions.PreventGlyphsGrouping property

이 속성은 텍스트 글리프가 단어나 문자열로 그룹화되지 않는 모드를 켭니다. 이 모드는 페이지에서 글리프 위치 지정 시 최대 정밀도를 유지하도록 하며, 악보 기호나 서로 별도로 배치되어야 하는 글리프가 포함된 문서 변환에 사용할 수 있습니다. 이 매개변수는 FixedLayout 속성 값이 true인 경우에만 문서에 적용됩니다.

```csharp
public bool PreventGlyphsGrouping { get; set; }
```
