## HtmlSaveOptions.SimpleTextboxModeGrouping property

이 속성은 글리프와 단어를 순차적으로 문자열로 그룹화하도록 지정합니다. 예를 들어 변환된 HTML에서 태그와 단어의 순서가 다르고 이를 일치시키고 싶을 때 사용할 수 있습니다. 이 매개변수는 FixedLayout 속성 값이 true인 경우에만 문서에 적용됩니다.

```csharp
public bool SimpleTextboxModeGrouping { get; set; }
```
