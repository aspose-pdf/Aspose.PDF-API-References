## HtmlSaveOptions.SaveTransparentTexts field

PDF에는 클립보드로 선택할 수 있는 투명 텍스트가 포함될 수 있습니다(보통 문서에 이미지와 OCR로 추출된 텍스트가 포함된 경우 발생합니다). 이 설정은 변환기에 이러한 텍스트를 결과 HTML에서 투명하고 선택 가능한 텍스트로 저장할지 여부를 알려줍니다.

```csharp
public bool SaveTransparentTexts;
```
