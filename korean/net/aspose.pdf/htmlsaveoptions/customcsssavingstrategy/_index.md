## HtmlSaveOptions.CustomCssSavingStrategy field

이 필드는 Pdf를 Html로 변환하는 동안 전체 생성된 HTML 문서 또는 페이지별(HTML 페이지가 여러 개 생성된 경우) CSS 저장을 처리하기 위해 사용해야 하는 저장 전략을 포함할 수 있습니다(존재하는 경우). CSS 파일을 특정 방식으로 처리하려면 해당 메서드를 생성하고 해당 메서드에서 만든 대리자를 이 속성에 할당하십시오.

```csharp
public CssSavingStrategy CustomCssSavingStrategy;
```
