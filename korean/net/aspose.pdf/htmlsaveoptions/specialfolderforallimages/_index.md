## HtmlSaveOptions.SpecialFolderForAllImages field

Document를 HTML로 저장하는 동안 이미지가 발견될 경우 저장해야 할 디렉터리 경로를 가져오거나 설정합니다. 매개변수가 비어 있거나 null인 경우 이미지 파일(있는 경우)이 HTML에 연결된 다른 파일과 함께 저장됩니다. 관련 이미지 파일을 처리하기 위해 CustomImageSavingStrategy 속성이 성공적으로 사용된 경우에는 아무 영향도 없습니다.

```csharp
public string SpecialFolderForAllImages;
```
