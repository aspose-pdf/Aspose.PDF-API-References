## HtmlSaveOptions.SpecialFolderForSvgImages field

Document를 HTML로 저장하는 동안 SVG 이미지가 발견될 경우 해당 SVG 이미지만 저장해야 할 디렉터리 경로를 가져오거나 설정합니다. 매개변수가 비어 있거나 null인 경우 SVG 파일(있는 경우)이 다른 이미지 파일과 함께(출력 파일 근처에) 저장되거나 SpecialImagesFolderIfAny 옵션에 지정된 경우 이미지 전용 폴더에 저장됩니다. 관련 이미지 파일을 처리하기 위해 CustomImageSavingStrategy 속성이 성공적으로 사용된 경우에는 아무 영향도 없습니다.

```csharp
public string SpecialFolderForSvgImages;
```
