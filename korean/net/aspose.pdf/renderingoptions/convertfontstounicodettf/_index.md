## RenderingOptions.ConvertFontsToUnicodeTTF property

모든 글꼴이 TTF 유니코드 버전으로 변환됨을 나타냅니다. 이는 호환성 및 글꼴 사용 최적화를 위해 유용합니다. 새로운 TTF 글꼴은 원본 글꼴의 모든 기호가 아니라 텍스트에서 사용된 기호만 포함하게 됩니다.

```csharp
public bool ConvertFontsToUnicodeTTF { get; set; }
```
