## DocSaveOptions.ConvertType3Fonts property

Type3 글꼴에 대한 변환을 가져오거나 설정합니다. Type 3 글꼴에서는 글리프가 그래픽 연산자 스트림으로 정의됩니다. 이는 DOC/DOCX 출력에서 텍스트 대신 이미지가 표시된다는 의미입니다. 이 플래그를 true로 설정하면 Type3 글꼴을 TTF로 변환하여 결과 파일에 텍스트를 얻을 수 있습니다.

```csharp
public bool ConvertType3Fonts { get; set; }
```
