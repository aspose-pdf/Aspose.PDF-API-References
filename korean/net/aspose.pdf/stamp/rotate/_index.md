## Stamp.Rotate property

스탬프 내용의 회전을 [`Rotation`](../../rotation/) 값에 따라 설정하거나 가져옵니다. 참고: 이 속성은 0, 90, 180, 270도와 같이 90도의 배수인 각도를 설정하기 위한 것입니다. 임의 각도를 설정하려면 RotateAngle 속성을 사용하십시오. ArbitraryAngle로 설정된 각도가 90도의 배수가 아니면 Rotate 속성은 Rotation.None을 반환합니다.

```csharp
public Rotation Rotate { get; set; }
```
