## UnifiedSaveOptions.ExtractOcrSublayerOnly property

이 속성은 OCR 하위 레이어를 사용하여 PDF Document에서 이미지 또는 텍스트를 추출하는 기능을 활성화합니다.

```csharp
public bool ExtractOcrSublayerOnly { get; set; }
```

### Property Value

`true` 텍스트는 결과 문서에서 추출됩니다; 그렇지 않으면 `false`.
