## TeXLoadOptions.Repeat property

입력 TeX 파일에 참조가 있는 경우와 같이 TeX 작업을 두 번 실행해야 하는지 여부를 나타내는 플래그를 가져오거나 설정합니다. 일반적으로 이 동작은 엔진이 조판 과정에서 데이터를 수집하여 첫 번째 실행 시 보조 파일에 저장하고, 두 번째 실행 시 해당 데이터를 사용해야 할 때 유용합니다.

```csharp
public bool Repeat { get; set; }
```
