## HtmlSaveOptions.HtmlMarkupGenerationModes enumeration

때때로 생성된 HTML에 대한 특정 요구 사항이 존재합니다. 이 열거형은 PDF를 HTML로 변환하는 동안 이러한 특정 요구 사항에 맞추기 위해 사용할 수 있는 HTML 준비 모드를 정의합니다.

```csharp
public enum HtmlMarkupGenerationModes
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| WriteAllHtml | `0` | 특정 요구 사항이 없는 경우 기본 모드가 사용됩니다. 특별한 추가 처리 없이 HTML의 모든 부분을 포함하는 출력이 생성됩니다. |
| WriteOnlyBodyContent | `1` | HTML 본문 밖에 있는 모든 HTML 콘텐츠가 제거됩니다. 즉, \c \ \c \ 태그 안에 있는 콘텐츠만 남게 됩니다. |
