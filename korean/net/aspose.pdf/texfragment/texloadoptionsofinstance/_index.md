## TeXFragment.TeXLoadOptionsOfInstance property

이 클래스 인스턴스로 LaTeX를 로드(및 렌더링)하는 데 사용될 TeXLoadOptions를 가져오거나 설정합니다. 특정 인스턴스에 대해 LaTeX 가져오기 설정이 필요할 때 사용하십시오(예: 해당 인스턴스가 가져온 LaTeX에 대해 특정 BasePath를 사용하거나 외부 리소스 로더를 사용해야 하는 경우). 매개변수가 기본값(null)인 경우 표준 LaTeX 로드 옵션이 사용됩니다.

```csharp
public TeXLoadOptions TeXLoadOptionsOfInstance { get; set; }
```
