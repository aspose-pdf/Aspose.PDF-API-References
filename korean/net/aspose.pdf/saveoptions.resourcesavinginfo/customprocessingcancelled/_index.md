## SaveOptions.ResourceSavingInfo.CustomProcessingCancelled field

이 플래그는 특정 이유로 제안된 파일을 사용자 정의 코드가 아니라 컨버터의 코드 자체로 표준 방식에 따라 처리해야 하는 경우 사용자 정의 코드에서 "true"로 설정해야 합니다. 따라서 설정을 true로 하면 사용자 정의 코드가 해당 파일을 처리하지 않았으며 컨버터가 자체적으로 파일을 저장하고 파일명을 지정하는 등 모든 작업을 처리해야 함을 의미합니다.

```csharp
public bool CustomProcessingCancelled;
```
