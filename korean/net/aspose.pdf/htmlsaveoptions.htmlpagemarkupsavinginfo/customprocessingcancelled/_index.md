## HtmlSaveOptions.HtmlPageMarkupSavingInfo.CustomProcessingCancelled field

필요한 경우 사용자 지정 코드에서 설정해야 합니다. 이 플래그는 특정 이유로 제공된 html-markup을 사용자 지정 코드가 아니라 변환기의 코드 자체로 표준 변환 방식으로 처리해야 할 경우 사용자 지정 코드에서 "true"로 설정해야 합니다. 따라서 사용자 지정 코드에서 이 플래그를 설정하면 해당 파일을 사용자 지정 코드가 처리하지 않았으며 변환기가 직접 처리해야 함을 의미합니다.

```csharp
public bool CustomProcessingCancelled;
```
