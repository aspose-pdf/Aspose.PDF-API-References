## OptimizedMemoryStream.Write method

파생 클래스에서 재정의될 때, 현재 스트림에 바이트 시퀀스를 쓰고 쓰여진 바이트 수만큼 이 스트림 내 현재 위치를 이동합니다.

```csharp
public override void Write(byte[] buffer, int offset, int count)
```

| 매개변수 | 유형 | 설명 |
| --- | --- | --- |
| 버퍼 | Byte[] | 바이트 배열입니다. 이 메서드는 *count* 바이트를 *buffer*에서 현재 스트림으로 복사합니다. |
| 오프셋 | Int32 | *buffer*에서 현재 스트림으로 바이트 복사를 시작할 제로 기반 바이트 오프셋입니다. |
| 개수 | Int32 | 현재 스트림에 기록될 바이트 수입니다. |
