## PasswordType enumeration

이 열거형은 암호로 보호된 PDF 문서에 사용되는 알려진 암호 유형을 나타냅니다.

```csharp
public enum PasswordType
```

### 값

| 이름 | 값 | 설명 |
| --- | --- | --- |
| None | `0` | Pdf document은 암호로 보호되지 않습니다. |
| User | `1` | Pdf document은 문서 열기 암호(제한된 접근)를 사용하여 열렸습니다. |
| Owner | `2` | Pdf document은 권한 변경 암호(전체 접근)를 사용하여 열렸습니다. |
| Inaccessible | `3` | Pdf document은 암호로 보호되어 있지만 사용자와 소유자 암호가 비어 있지 않으며, 암호가 정의되지 않았거나 제공된 암호가 올바르지 않습니다. 따라서 암호 유형을 추론할 수 없습니다. |
