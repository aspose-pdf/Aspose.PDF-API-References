## PdfFormatConversionOptions.OptimizeFileSize property

PDF/A 문서의 파일 크기를 줄이기 위한 특수 변환 모드를 활성화/비활성화하는 플래그를 가져오거나 설정합니다. 현재 이 플래그는 PDF 문서에 사용된 글꼴 최적화에 영향을 주며, 향후에는 그래픽과 같은 다른 데이터 구조에 대한 최적화를 켜는 데에도 사용될 수 있습니다. 이 플래그와 모드의 조합은 파일 크기를 크게 줄일 수 있지만 동시에 변환 성능을 크게 저하시킬 수 있습니다.

```csharp
public bool OptimizeFileSize { get; set; }
```
