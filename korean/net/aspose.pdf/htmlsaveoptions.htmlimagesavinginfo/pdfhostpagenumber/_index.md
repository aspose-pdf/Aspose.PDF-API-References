## HtmlSaveOptions.HtmlImageSavingInfo.PdfHostPageNumber field

저장된 이미지가 원본 PDF 문서의 어느 페이지에 해당하는지 사용자 지정 코드에 알려줍니다. 원본 문서의 모든 페이지가 저장되지 않을 수 있기 때문에 이 값은 원본 PDF에서 호스트 페이지 번호를 나타냅니다. 원본 페이지 번호가 알 수 없는 경우 항상 '1'을 반환합니다.

```csharp
public int PdfHostPageNumber;
```
