## ToUnicodeProcessingRules.MapNonLinkedSymbolsOnSpace property

일부 글꼴은 특정 텍스트 기호에 대한 유니코드 정보를 제공하지 않습니다. 이러한 정보 부족은 "Text cannot be mapped to Unicode" 오류를 발생시킵니다. 이 플래그를 사용하여 연결되지 않은 기호를 유니코드 "space"(코드 32)로 매핑합니다.

```csharp
public bool MapNonLinkedSymbolsOnSpace { get; set; }
```
