## Document.AllowReusePageContent property

Page 내용을 병합하여 문서 크기를 최적화할 수 있습니다. 사용하면 서로 다른 중복 Page가 동일한 콘텐츠 객체를 참조할 수 있습니다. 이 모드가 다른 Page가 변경될 때 Page 내용이 변경되는 등 부작용을 일으킬 수 있다는 점에 유의하세요.

```csharp
public bool AllowReusePageContent { get; set; }
```
