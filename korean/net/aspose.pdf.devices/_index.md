**Aspose.Pdf.Devices** 네임스페이스는 문서를 이미지 또는 일반 텍스트로 표현하는 데 사용되는 클래스를 제공합니다. 따라서 문서를 텍스트 또는 다양한 그래픽 장치로 전송하여 텍스트 또는 그래픽 형태로 변환할 수 있습니다.

| [Device](./device/) | 모든 유형의 장치를 위한 추상 클래스입니다. 장치는 pdf 문서를 특정 형식으로 표현하는 데 사용됩니다. 예를 들어, 문서 페이지를 이미지 또는 텍스트로 표현할 수 있습니다. |

| [DocumentDevice](./documentdevice/) | 전체 pdf 문서를 처리하는 데 사용되는 모든 장치를 위한 추상 클래스입니다. |

| [ThumbnailDevice](./thumbnaildevice/) | pdf 문서 페이지를 썸네일 이미지로 저장하는 이미지 장치를 나타냅니다. |
| [TiffDevice](./tiffdevice/) | 이 클래스는 pdf 문서 페이지를 하나의 tiff 이미지로 페이지별 저장하는 데 도움이 됩니다. |
