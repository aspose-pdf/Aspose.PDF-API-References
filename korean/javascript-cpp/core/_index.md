## Core Functions

| 이름 | 설명 |
| -------------- | -------------- |
| [AsposePdfPrepare](./asposepdfprepare/) | 처리를 위해 Memory FS에 BLOB을 저장합니다. |
| [AsposePdfPrepareBase64](./asposepdfpreparebase64/) | 처리를 위해 Memory FS에 문자열 표현 BLOB을 저장합니다. |

## Detailed Description

PDF 파일 작업을 위한 핵심 함수.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
또는
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
