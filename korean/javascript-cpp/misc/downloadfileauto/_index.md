_HTML에서 파일을 다운로드할 수 있는 링크를 만들고 2초 후에 다운로드를 시작합니다._

```js
function DownloadFileAuto(
    filename,
    mime 
)
```

**Parameters**:

* **fileName** file name
* **mime** string "mime/type"

**Doesn't work in Web Worker.**
