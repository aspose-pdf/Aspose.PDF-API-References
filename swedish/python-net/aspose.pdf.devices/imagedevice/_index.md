## ImageDevice class

En abstrakt klass för bildenheter.

Typen ImageDevice exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| coordinate_type | Hämtar eller anger sidans koordinattyp (Media/Crop-boxar). CropBox-värdet används som standard. |
| rendering_options | Hämtar eller anger renderingsalternativ. |
| form_presentation_mode | Hämtar eller anger formulärets presentationsläge. |
| resolution | Hämtar bildens upplösning. |
| bredd | Hämtar bildens utskriftsbredd. |
| höjd | Hämtar bildens utskriftshöjd. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| process(page, output) | Utför någon operation på den angivna sidan, t.ex. konverterar sidan till en grafisk bild. |
| process(page, output_file_name) | Utför någon operation på den angivna sidan och sparar resultatet i filen. |
