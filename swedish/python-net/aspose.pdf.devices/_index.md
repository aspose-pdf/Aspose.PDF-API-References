aspose.pdf.devices‑namnrymden tillhandahåller klasser som används för att representera dokumentet som bild(er) eller vanlig text. Så kan dokumentet skickas till textbaserade eller olika grafiska enheter, vilket innebär att vi vill få en textuell eller grafisk representation.

| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | Representerar bildenhet som hjälper till att spara pdf-dokumentets sidor som bmp. |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | Abstrakt klass för alla typer av enheter. Enheten används för att representera pdf-dokument i något format.<br/>            Till exempel kan dokumentsidan representeras som bild eller text. |

| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | Denna klass hjälper till att spara pdf-dokument sida för sida i en enda tiff-bild. |
