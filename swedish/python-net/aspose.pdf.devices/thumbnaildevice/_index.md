## ThumbnailDevice class

Representerar bildenhet som sparar pdf-dokumentets sidor som miniatyrbild.

Typen ThumbnailDevice exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ThumbnailDevice() | Initierar en ny instans av klassen [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) <br/>            med standardstorlek för miniatyrbild (200x200 pixlar). |
| ThumbnailDevice(width, height) | Initierar en ny instans av klassen ThumbnailDevice |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| coordinate_type | Hämtar eller anger sidans koordinattyp (Media/Crop-boxar). CropBox-värdet används som standard. |
| rendering_options | Hämtar eller anger renderingsalternativ. |
| form_presentation_mode | Hämtar eller anger formulärets presentationsläge. |
| resolution | Hämtar bildens upplösning. |
| bredd | Hämtar bildens utskriftsbredd. |
| höjd | Hämtar bildens utskriftshöjd. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| process(page, output) | Konverterar sidan till en miniatyrbild i png och sparar den i utdataflödet. |
| process(page, output_file_name) | Konverterar sidan till en miniatyrbild i png och sparar den i utdataflödet. |
