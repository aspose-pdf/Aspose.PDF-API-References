## PageDevice class

Abstrakt klass för alla enheter som används för att bearbeta en viss sida i pdf-dokumentet.

Typen PageDevice exponerar följande medlemmar:
## Metoder
| Namn | Beskrivning |
| :- | :- |
| process(page, output) | Utför någon operation på den angivna sidan, t.ex. konverterar sidan till en grafisk bild. |
| process(page, output_file_name) | Utför någon operation på den angivna sidan och sparar resultatet i filen. |
