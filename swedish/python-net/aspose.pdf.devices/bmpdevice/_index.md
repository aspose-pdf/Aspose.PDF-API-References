## BmpDevice class

Representerar bildenhet som hjälper till att spara pdf-dokumentets sidor som bmp.

BmpDevice-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| BmpDevice() | Initierar en ny instans av [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) klassen med standardupplösning. |
| BmpDevice(resolution) | Initierar en ny instans av BmpDevice-klassen |
| BmpDevice(width, height, resolution) | Initierar en ny instans av BmpDevice-klassen |
| BmpDevice(page_size, resolution) | Initierar en ny instans av BmpDevice-klassen |
| BmpDevice(width, height) | Initierar en ny instans av BmpDevice-klassen |
| BmpDevice(page_size) | Initierar en ny instans av BmpDevice-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| coordinate_type | Hämtar eller anger sidans koordinattyp (Media/Crop-boxar). CropBox-värdet används som standard. |
| rendering_options | Hämtar eller anger renderingsalternativ. |
| form_presentation_mode | Hämtar eller anger formulärets presentationsläge. |
| resolution | Hämtar bildens upplösning. |
| bredd | Hämtar bildens utskriftsbredd. |
| höjd | Hämtar bildens utskriftshöjd. |
