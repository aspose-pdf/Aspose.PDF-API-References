## PngDevice class

Representerar bildenhet som hjälper till att spara pdf-dokumentets sidor i png.

Typen PngDevice exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| PngDevice() | Initierar en ny instans av klassen [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) med standardupplösning. |
| PngDevice(resolution) | Initierar en ny instans av klassen PngDevice |
| PngDevice(width, height, resolution) | Initierar en ny instans av klassen PngDevice |
| PngDevice(page_size, resolution) | Initierar en ny instans av klassen PngDevice |
| PngDevice(width, height) | Initierar en ny instans av klassen PngDevice |
| PngDevice(page_size) | Initierar en ny instans av klassen PngDevice |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| coordinate_type | Hämtar eller anger sidans koordinattyp (Media/Crop-boxar). CropBox-värdet används som standard. |
| rendering_options | Hämtar eller anger renderingsalternativ. |
| form_presentation_mode | Hämtar eller anger formulärets presentationsläge. |
| resolution | Hämtar bildens upplösning. |
| bredd | Hämtar bildens utskriftsbredd. |
| höjd | Hämtar bildens utskriftshöjd. |
| transparent_background | Hämtar eller anger om bilden har transparent bakgrund. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| process(page, output) | Konverterar sidan till png och sparar den i utdataflödet. |
| process(page, output_file_name) | Konverterar sidan till png och sparar den i utdataflödet. |
