## TiffSettings class

Denna klass representerar inställningar för att importera pdf till Tiff.

TiffSettings-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TiffSettings() | Initierar en ny instans av klassen [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/). |
| TiffSettings(shape_type) | Initierar en ny instans av TiffSettings-klassen |
| TiffSettings(compression_type) | Initierar en ny instans av TiffSettings-klassen |
| TiffSettings(color_depth) | Initierar en ny instans av TiffSettings-klassen |
| TiffSettings(margins) | Initierar en ny instans av TiffSettings-klassen |
| TiffSettings(compression_type, color_depth, margins) | Initierar en ny instans av TiffSettings-klassen |
| TiffSettings(compression_type, color_depth, margins, skip_blank_pages) | Initierar en ny instans av TiffSettings-klassen |
| TiffSettings(compression_type, color_depth, margins, skip_blank_pages, shape_type) | Initierar en ny instans av TiffSettings-klassen |
| TiffSettings(skip_blank_pages) | Initierar en ny instans av TiffSettings-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| margins | Hämtar marginalerna. |
| skip_blank_pages | Hämtar eller anger ett värde som indikerar om tomma sidor ska hoppas över. |
| compression | Hämtar eller anger kompressionstypen. |
| depth | Hämtar eller anger färgdjupet. |
| shape | Hämtar eller anger formens typ. |
| brightness | Hämtar eller anger ett värdegräns för färgtransformeringen mellan vitt och svart.<br/>            Denna parameter kan tillämpas med EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle eller ColorDepth.Format1bpp == 1 |
| coordinate_type | Hämtar eller anger sidkoordinattypen (Media/Crop-boxar). CropBox‑värdet används som standard. |
