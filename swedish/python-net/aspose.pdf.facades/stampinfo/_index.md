## StampInfo class

Klass som representerar stämpelinformation.

Typen StampInfo exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| stamp_id | Hämtar identifieraren för stämpeln. |
| index_on_page | Hämtar stämpelns index på sidan. |
| stamp_type | Hämtar stämpeltyp (bild / formulär). |
| rectangle | Hämtar rektangeln där stämpeln är placerad. |
| image | Hämtar bild av stämpeln. Kan vara null om stämpeln inte innehåller bilder (till exempel för textstämpel). |
| formulär | Hämtar XForm av stämpeln. |
| text | Hämtar text i stämpeln. |
| synlig | Hämtar synlighet för stämpeln. Om falskt är stämpeln dold (med HideStampById). Dold stämpel kan återställas med ShowStampById. |
