## ViewerPreference class

Beskriver visningsinställningar (sidläge, icke‑fullskärms sidläge, sidlayout).

Typen ViewerPreference exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ViewerPreference() | Initierar en ny instans av klassen ViewerPreference |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| PAGE_MODE_USE_OC | Panel för valfritt innehållsgrupp synlig. |
| DISPLAY_DOC_TITLE | En flagga som anger om fönstrets titelrad ska visa dokumenttiteln |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | Panel för valfritt innehållsgrupp synlig. |
| PAGE_LAYOUT_SINGLE_PAGE | Visa en sida åt gången. |
| PAGE_LAYOUT_ONE_COLUMN | Visa sidorna i en kolumn. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | Visa sidorna i två kolumner, med udda sidnummer till höger |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | Visa sidorna i två kolumner, med udda sidnummer till höger. |
| PAGE_MODE_USE_NONE | Varken dokumentöversikt eller miniatyrbilder är synliga |
| PAGE_MODE_USE_OUTLINES | Dokumentöversikt synlig. |
| PAGE_MODE_USE_THUMBS | Miniatyrbilder synliga. |
| PAGE_MODE_FULL_SCREEN | Fullskärmsläge, utan menyrad, fönsterkontroller eller något annat fönster synligt. |
| PAGE_MODE_USE_ATTACHMENT | Sidläge med bilagor. |
| HIDE_TOOLBAR | En flagga som anger om verktygsfält för den kompatibla läsaren ska döljas när dokumentet är aktivt. |

| CENTER_WINDOW | En flagga som anger om dokumentets fönster ska placeras i mitten av skärmen. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | Varken dokumentöversikt eller miniatyrbilder synliga. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | Dokumentöversikt synlig. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | Miniatyrbilder synliga |
| DIRECTION_L2R | Textläsningsordning från vänster till höger. |
| DIRECTION_R2L | Textläsningsordning från höger till vänster. |
| SIMPLEX | Skriv ut enkelsidig. |
