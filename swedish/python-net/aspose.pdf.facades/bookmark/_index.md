## Bookmark class

Representerar ett bokmärke.

Typen Bookmark exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Bookmark() | Initierar en ny instans av Bookmark-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| action | Hämtar eller anger åtgärden som är bunden till bokmärket.<br/>            Om PageNumber är angivet kan åtgärden inte specificeras.<br/>            Åtgärdstypen inkluderar: \"GoTo\", \"GoToR\", \"Launch\", \"Named\". |
| bold_flag | Hämtar eller anger fetstilflaggan för bokmärkets titel. |
| child_item | Hämtar eller anger bokmärkets barn. |
| child_items | Hämtar eller anger bokmärkets barn. |
| destination | Hämtar eller anger bokmärkets destinationssida. Krävs om åtgärden är satt till string.Empty. |
| italic_flag | Hämtar eller anger den kursiva flaggan för bokmärkets titel. |
| level | Hämtar eller anger bokmärkets hierarkinivå. |
| page_display | Hämtar eller anger typen av visning för bokmärkets destinationssida. |
| page_display_bottom | Hämtar eller anger den nedre koordinaten för sidvisning. |
| page_display_left | Hämtar eller anger den vänstra koordinaten för sidvisning. |
| page_display_right | Hämtar eller anger den högra koordinaten för sidvisning. |
| page_display_top | Hämtar eller anger den övre koordinaten för sidvisning. |
| page_display_zoom | Hämtar eller anger zoomfaktorn för sidvisning. |
| page_number | Hämtar eller anger numret på bokmärkets destinationssida. |
| remote_file | Hämtar eller anger filen (sökvägen) som krävs för "GoToR"-åtgärden för bokmärket. |
| titel | Hämtar eller anger bokmärkets titel. |
| title_color | Hämtar eller anger färgen på bokmärkets titel. |
| öppna | Hämtar eller anger bokmärkesstatus (öppen, stängd). |
