## ISaveableFacade class

Facade‑gränssnitt som definierar metoder gemensamma för alla sparbara facader.

Typen ISaveableFacade exponerar följande medlemmar:
## Metoder
| Namn | Beskrivning |
| :- | :- |
| save(dest_file) | Sparar det resulterande PDF-dokumentet till en fil. |
| save(dest_stream) | Sparar det resulterande PDF-dokumentet till en ström. |
| bind_pdf(src_file) | Binder PDF-dokument för redigering. |
| bind_pdf(src_stream) | Binder PDF-dokument för redigering. |
| bind_pdf(src_doc) | Binder PDF-dokument för redigering. |
| close() | Frigör alla resurser som är associerade med den aktuella fasaden. |
