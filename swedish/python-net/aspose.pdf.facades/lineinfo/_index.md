## LineInfo class

Representerar informationen om en rad.

Typen LineInfo exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LineInfo() | Initierar en ny instans av klassen LineInfo |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| vertice_coordinate | Hämtar eller anger en matris av tal som representerar de växlande horisontella och vertikala koordinaterna för varje hörn, respektive. |
| line_color | Hämtar eller anger färgen på en linje. |
| line_width | Hämtar eller anger bredden på en linje. |
| visibility | Hämtar eller anger synligheten för en linje. |
| line_dash_pattern | Hämtar eller anger streckmönstret för en linje. |
| border_style | Hämtar eller anger kantstilen för en linje, 0 representerar solid, 1 representerar streckad, 2 representerar beleved, 3 representerar infogad, 4 representerar understruken. |
