## DocumentPrivilege class

Representerar behörigheterna för åtkomst till Pdf‑filen. Se [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             Det finns 4 sätt att använda denna klass:<br/>             1. Använda fördefinierad behörighet direkt.<br/>             2. Baserat på en fördefinierad behörighet och ändra vissa specifika rättigheter.<br/>             3. Baserat på en fördefinierad behörighet och ändra en viss kombination av Adobe Professional‑rättigheter.<br/>             4. Blander way2 och way3.

Typen DocumentPrivilege exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| allow_print | Ställer in behörigheten som tillåter utskrift eller inte. <br/>            true betyder tillåten och false betyder förbjuden. |
| allow_degraded_printing | Ställer in behörigheten som tillåter degraderad utskrift eller inte. <br/>            true betyder tillåten och false betyder förbjuden. |
| allow_modify_contents | Ställer in behörigheten som tillåter modifiering av innehåll eller inte. <br/>            true betyder tillåten och false betyder förbjuden. |
| allow_copy | Ställer in behörigheten som tillåter kopiering eller inte. <br/>            true betyder tillåten och false betyder förbjuden. |
| allow_modify_annotations | Ställer in behörigheten som tillåter modifiering av annotationer eller inte. <br/>            true betyder tillåten och false betyder förbjuden. |
| allow_fill_in | Ställer in behörigheten som tillåter ifyllning av formulär eller inte. <br/>            true betyder tillåten och false betyder förbjuden. |
| allow_screen_readers | Ställer in behörigheten som tillåter skärmläsare eller inte. <br/>            true betyder tillåtet och false betyder förbjudet. |
| allow_assembly | Ställer in behörigheten som tillåter montering eller inte. <br/>            true betyder tillåtet och false betyder förbjudet. |
| degraded_printing | Tillåter nedsatt utskrift. |
| print | Tillåter utskrift av fil. |
| modify_contents | Tillåter ändring av fil. |
| copy | Tillåter kopiering av fil. |
| modify_annotations | Tillåter ändring av filens annotationer. |
| fill_in | Tillåter ifyllning av formulär i fil. |
| screen_readers | Tillåter endast läsning på skärmen. |
| assembly | Tillåter montering av fil. |
| allow_all | Allt tillåtet. |
| forbid_all | Allt förbjudet. |
