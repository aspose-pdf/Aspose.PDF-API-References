## XslFoLoadOptions class

Representerar alternativ för att ladda/importera XSL-FO-fil till pdf-dokument.

Typen XslFoLoadOptions exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| XslFoLoadOptions() | Skapar [XslFoLoadOptions](/pdf/python-net/aspose.pdf/xslfoloadoptions/) objekt utan xsl-data. |
| XslFoLoadOptions(xsl_file) | Initierar en ny instans av klassen XslFoLoadOptions |
| XslFoLoadOptions(xsl_stream) | Initierar en ny instans av klassen XslFoLoadOptions |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| warning_handler | Återanrop för att hantera eventuella genererade varningar. <br/>            WarningHandler returnerar ReturnAction‑enum‑värde som specificerar antingen Continue eller Abort. <br/>            Continue är standardåtgärden och Load‑operationen fortsätter, men användaren kan också returnera Abort, varvid Load‑operationen ska avbrytas. |
| load_format | Representerar filformat som [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) beskriver. |
| xsl_stream | Hämtar xsl-data för att konvertera xml till pdf-dokument. |
| base_path | Basvägen/URL:en från vilken relativa sökvägar till externa resurser (om några) som refereras i den inlästa SVG-filen söks. |
| parsing_errors_handling_type | Källdokumentet XSLFO kan innehålla formateringsfel. Denna enum listar möjliga strategier för hantering av dessa fel. |
