## HtmlPageLayoutOption enumeration

Anger flaggor som tillsammans med andra alternativ bestämmer storlekar och layouter för sidor.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Standardvärde som indikerar att HtmlPageLayoutOption inte kommer att påverka sidornas storlekar och layouter. |
| FIT_TO_WIDEST_CONTENT_WIDTH | Indikerar att sidans bredd bestäms av innehållets storlek själv, inte av den angivna sidbredden. |
| SCALE_TO_PAGE_WIDTH | Indikerar att dokumentets innehåll kommer att skalas för att passa sidan. |
