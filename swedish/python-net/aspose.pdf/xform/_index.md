## XForm class

Klassen representerar XForm

Typen XForm visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| b_box | Hämtar eller anger formens avgränsningsruta. |
| name | Hämtar eller anger formulärets namn. Formnamnet är det namn som används för att referera till formuläret i XObject-ordboken i sidresurserna. |
| innehåll | Hämtar operatorer för formuläret. |
| opi | Hämtar Open Prepress Interface (OPI). |
| matrix | Hämtar eller anger formulärets matris. |
| resources | Hämtar Form XObject-resurser. |
| rectangle | Hämtar eller anger formulärets rektangel. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| get_resources(allow_create) | Returnerar resurser för Form X-Object |
| get_resources() | Returnerar resurser för Form X-Object |
| create_new_form(source, document) | Skapar XForm som duplicerar sidans innehåll. |
| free_memory() | Rensar cachad data. |
