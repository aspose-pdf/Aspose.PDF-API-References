## INamedDestinationCollection class

Samling av namngivna destinationer.

INamedDestinationCollection-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| count | Returnerar antalet destinationer. |
| names | Hämtar en array med namn på destinationerna. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| remove(name) | Tar bort destinationen med dess namn. |
| add(name, appointment) | Lägger till en ny namngiven destination. |
