## GraphInfo class

Representerar grafikinformation.

Typen GraphInfo exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| GraphInfo() | Initierar en ny instans av klassen GraphInfo |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| line_width | Hämtar eller anger ett flyttal som indikerar linjebredden på grafen. |
| color | Hämtar eller anger ett [color](/pdf/python-net/aspose.pdf/graphinfo/) objekt som indikerar grafens färg. |
| dash_array | Hämtar eller anger en streckarray. |
| dash_phase | Hämtar eller anger en streckfas. |
| fill_color | Hämtar eller anger ett [color](/pdf/python-net/aspose.pdf/graphinfo/) objekt som indikerar fyllningsfärgen på grafen. |
| is_doubled | Hämtar eller anger om kanten är fördubblad. |
| skew_angle_x | Hämtar eller anger ett flyttal som indikerar snedvinkeln för x-koordinaten vid transformation av ett koordinatsystem. |
| skew_angle_y | Hämtar eller anger ett flyttal som indikerar snedvinkeln för y-koordinaten vid transformation av ett koordinatsystem. |
| scaling_rate_x | Hämtar eller anger ett flyttal som indikerar skalningsfaktorn för x-koordinaten vid transformation av ett koordinatsystem. |
| scaling_rate_y | Hämtar eller anger ett flyttal som indikerar skalningsfaktorn för y-koordinaten när ett koordinatsystem transformeras. |
| rotation_angle | Hämtar eller anger ett flyttal som indikerar rotationsvinkeln för koordinatsystemet <br/>            när ett koordinatsystem transformeras. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| clone() | Klona grafikinformationen. |
