## HtmlLoadOptions class

Representerar alternativ för inläsning/import av HTML-fil till PDF-dokument.

Typen HtmlLoadOptions exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| HtmlLoadOptions() | Skapar laddningsalternativ för att konvertera html till pdf-dokument med tom basväg. |
| HtmlLoadOptions(base_path) | Initierar en ny instans av klassen HtmlLoadOptions |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| warning_handler | Återanrop för att hantera eventuella genererade varningar. <br/>            WarningHandler returnerar ReturnAction‑enum‑värde som specificerar antingen Continue eller Abort. <br/>            Continue är standardåtgärden och Load‑operationen fortsätter, men användaren kan också returnera Abort, varvid Load‑operationen ska avbrytas. |
| load_format | Representerar filformat som [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) beskriver. |
| is_render_to_single_page | Hämtar eller anger renderingen av hela dokumentet till en enda sida |
| is_embed_fonts | Hämtar eller anger inbäddning av teckensnitt i resultatdokumentet |
| page_layout_option | Hämtar eller anger layoutalternativ. |
| html_media_type | Hämtar eller anger möjliga mediatyper som används under rendering. |
| input_encoding | Hämtar eller anger attributet som specificerar kodningen som används för detta dokument vid parsning. Om detta attribut är null bestäms kodningen från dokumentets teckenuppsättningsattribut. |
| base_path | Basvägen/URL för HTML-filen. |
| page_info | Hämtar eller anger dokumentets sidinformation |
