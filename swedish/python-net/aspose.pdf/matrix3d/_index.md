| Matrix3D() | Konstruktor<br/>            skapar en standard 1 till 1-matris:<br/>            [ A B C D E F G H I Tx Ty Tz] = [ 1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0 , 0] |
