## ImagePlacement class

Representerar egenskaperna för en bild placerad på en PDF-dokumentsida.

Typen ImagePlacement visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| matrix | Aktuell transformationsmatris för den här bilden. |
| rectangle | Hämtar rektangeln för bilden. |
| operator | Operator som används för att visa bilden. |
| rotation | Hämtar rotationsvinkeln för bilden. |
| resolution | Hämtar upplösningen för bilden. |
| image | Hämtar relaterat XImage-resursobjekt. |
| sida | Hämtar sidan som innehåller bilden. |
| compositing_parameters | Hämtar sammansättningsparametrar för grafikstatus som är aktiv för bilden placerad på sidan. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| save(stream) | Sparar bilden med motsvarande transformationer: skalning, rotation och upplösning. |
| save(stream, format) | Sparar bilden med motsvarande transformationer: skalning, rotation och upplösning. |
| hide() | Ta bort bilden från sidan. |
| replace(image) | Ersätt bilden i samlingen med en annan bild. |
