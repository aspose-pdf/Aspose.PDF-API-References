## ArtifactCollection class

Klassen representerar artefaktssamling.

Typen ArtifactCollection visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_synchronized | Är detta objekt synkroniserat. |
| sync_root | Hämtar synkroniseringsobjektet för samlingen. |
## Indexer
| Namn | Beskrivning |
| :- | :- |
| [index] | Hämtar artefakt efter index. Indexet börjar på 1. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| delete(artifact) | Tar bort specificerad artefakt. |
| delete(index) | Tar bort artefakt efter dess index. |
| find_by_value(name, expected_value) | Hittar artefakter efter anpassat värde. |
| update(artifact) | Uppdatera artefakt i samlingen. |
