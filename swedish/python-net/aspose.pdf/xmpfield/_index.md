## XmpField class

Representerar XMP-fält.

Typen XmpField exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| empty | Hämtar ett tomt xmp-fält. |
| lang | Hämtar xml:lang-kvalificeraren. |
| prefix | Hämtar prefixet. |
| namespace_uri | Hämtar namnrymdens URI. |
| local_name | Hämtar eller anger det lokala namnet. |
| name | Hämtar namnet. |
| value | Hämtar värdet. |
| field_type | Hämtar fältets typ. |
| is_empty | Hämtar ett värde som indikerar om detta objekt är tomt. |
