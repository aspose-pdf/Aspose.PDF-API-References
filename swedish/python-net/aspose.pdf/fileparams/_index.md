## FileParams class

Definierar en inbäddad filparametordictionary som ska innehålla ytterligare filspecifik information.

Typen FileParams exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| FileParams(spec) | Initierar en ny instans av klassen FileParams |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| storlek | Storleken på den okomprimerade inbäddade filen, i byte. |
| creation_date | Datum och tid då den inbäddade filen skapades. |
| mod_date | Datum och tid då den inbäddade filen senast ändrades. |
| check_sum | En 16-byte sträng som är kontrollsumman för bytevärden i den okomprimerade inbäddade filen. <br/>            Kontrollsumman beräknas genom att tillämpa den standardiserade MD5-meddelandedigestalgoritmen <br/>            på bytevärdena i den inbäddade filströmmen. |
