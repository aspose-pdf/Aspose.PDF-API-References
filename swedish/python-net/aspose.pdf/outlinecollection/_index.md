## OutlineCollection class

Representerar dokumentets dispositionshierarki.

Typen OutlineCollection exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| visible_count | Count är summan av antalet synliga underordnade konturposter på alla nivåer. Obs: förväxla inte med Count som är antalet poster i samlingen. |
| first | Hämtar ett konturobjekt som representerar det första top‑nivåobjektet i konturen. |
| last | Hämtar ett konturobjekt som representerar det sista top‑nivåobjektet i konturen. |
| is_synchronized | Hämtar ett värde som indikerar om åtkomst till denna samling är synkroniserad (trådsäker). |
| sync_root | Hämtar ett objekt som kan användas för att synkronisera åtkomst till denna samling. |
## Indexer
| Namn | Beskrivning |
| :- | :- |
| [index] | Hämtar outline‑objekt från samlingen efter index. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| delete() | Tar bort alla outline‑objekt från dokumentets outline. |
| delete(name) | Tar bort outline‑objektet med angiven titel från dokumentets outline. |
