## PclLoadOptions class

Representerar alternativ för att läsa in (importera) PCL-fil till pdf-dokument.

Typen PclLoadOptions exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| PclLoadOptions() | Initierar en ny instans av klassen PclLoadOptions |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| warning_handler | Återanrop för att hantera eventuella genererade varningar. <br/>            WarningHandler returnerar ReturnAction‑enum‑värde som specificerar antingen Continue eller Abort. <br/>            Continue är standardåtgärden och Load‑operationen fortsätter, men användaren kan också returnera Abort, varvid Load‑operationen ska avbrytas. |
| load_format | Representerar filformat som [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) beskriver. |
| batch_size | Definierar batch‑storlek om batch‑konvertering är tillämplig<br/>            för käll‑ och målformatpar. |
| conversion_engine | Definierar konverteringsmotor som kommer att användas för konvertering |
| supress_errors | Hämtar eller anger ett booleskt värde som indikerar om PCL-konverteringsfel ska undertryckas. |
