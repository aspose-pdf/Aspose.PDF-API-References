## NamedDestinationCollection class

Klassen representerar samlingen av alla destinationer (ett namntre som mappar namnsträngar till destinationer (se 12.3.2.3, \"Named Destinations\") och (se 7.7.4, \"Name Dictionary\")) i pdf-dokumentet.

Typen NamedDestinationCollection visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| count | Antal namngivna destinationer. |
| names | Lista över namn på destinationerna. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| remove(name) | Ta bort namngiven destination. |
| add(name, appointment) | Lägg till ny namngiven destination. |
