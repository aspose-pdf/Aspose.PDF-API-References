## PasswordType enumeration

Denna enum representerar kända lösenordstyper som används för lösenordsskyddade PDF-dokument.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Pdf-dokumentet är inte lösenordsskyddat. |
| USER | Pdf-dokumentet öppnades med dokumentets öppningslösenord (begränsad åtkomst). |
| OWNER | Pdf-dokumentet öppnades med lösenord för att ändra behörigheter (full åtkomst). |
| INACCESSIBLE | Pdf-dokumentet är lösenordsskyddat men både användar- och ägarlösenorden är inte tomma och <br/>            ingen av lösenorden definierades eller angivet lösenord var felaktigt. Så det är omöjligt att fastställa typen av lösenord. |
