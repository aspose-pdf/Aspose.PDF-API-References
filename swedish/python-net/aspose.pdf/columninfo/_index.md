## ColumnInfo class

Denna klass representerar kolumninformation.

Typen ColumnInfo exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ColumnInfo() | Initierar en ny instans av klassen ColumnInfo |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| column_widths | Hämtar eller anger en sträng som innehåller kolumnernas bredd. <br/>            Värdet för varje kolumn ska separeras med blanksteg. Standardenheten är punkt,<br/>            men cm, tum och procent av tillgänglig bredd stöds också.<br/>            Till exempel,"120 2.5cm 1.5inch" |
| column_spacing | Hämtar eller anger en sträng som innehåller avståndet mellan kolumner. <br/>            Värdet för varje avstånd ska separeras med blanksteg. Standardenheten är punkt,<br/>            men cm och tum stöds också. Till exempel,"120 2.5cm 1.5inch". |
| column_count | Hämtar eller anger ett heltalsvärde som indikerar antalet kolumner. |
