## EmbeddedFileCollection class

Klass som representerar samling av inbäddade filer.

Typen EmbeddedFileCollection visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_synchronized | Hämtar ett värde som indikerar om åtkomst till denna samling är synkroniserad (trådsäker). |
| sync_root | Hämtar ett objekt som kan användas för att synkronisera åtkomst till denna samling. |
| nycklar | Returnerar en lista med nycklar för filbilagor. |
## Indexer
| Namn | Beskrivning |
| :- | :- |
| [index] | Hämtar inbäddad fil efter dess index. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| delete(name) | Tar bort filen från samlingen med dess nyckel i samlingen. |
| delete() | Tar bort filen från samlingen med dess nyckel i samlingen. |
| add(key, file) | Lägger till fil i inbäddade filer med den angivna nyckeln. |
| delete_by_key(key) | Tar bort filen från samlingen med dess nyckel i samlingen. |
| find_by_name(name) | Returnerar inbäddad fil efter dess namn. |
