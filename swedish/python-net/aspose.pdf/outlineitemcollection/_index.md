## OutlineItemCollection class

Representerar en dispositionspost i dispositionshierarkin för PDF-dokumentet.

OutlineItemCollection-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| OutlineItemCollection(outlines) | Initierar en ny instans av OutlineItemCollection-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| visible_count | Hämtar det totala antalet outline-poster på alla nivåer i dokumentets outline-hierarki. |
| titel | Hämtar eller anger titeln för detta dispositionsobjekt. |
| destination | Hämtar eller anger destinationen för detta dispositionsobjekt. |
| action | Hämtar eller anger åtgärden för detta dispositionsobjekt. |
| färg | Hämtar eller anger färgen för titeltexten i detta dispositionsobjekt. |
| kursiv | Hämtar eller anger kursivflagga för titeltexten i detta dispositionsobjekt |
| fet | Hämtar eller anger fetflagga för titeltexten i detta dispositionsobjekt |
| first | Hämtar dispositionsobjektet som representerar det första toppnivåobjektet i dispositionshierarkin. |
| last | Hämtar dispositionsobjektet som representerar det sista toppnivåobjektet i dispositionshierarkin. |
| föregående | Hämtar dispositionsobjektet som representerar föregående objekt relativt detta objekt i dispositionshierarkin. |
| nästa | Hämtar dispositionsobjektet som representerar nästa objekt relativt detta objekt i dispositionshierarkin. |
| har_nästa | Kontrollera om dispositionsobjektet representerar nästa objekt relativt detta objekt i dispositionshierarkin. |
| förälder | Hämtar föräldraobjektet för detta dispositionsobjekt i dispositionshierarkin. |
| is_synchronized | Hämtar värdet som indikerar om åtkomst till denna samling är synkroniserad (trådsäker). |
| sync_root | Hämtar objektet som kan användas för att synkronisera åtkomst till denna samling. |
| öppna | Hämtar eller anger öppetillstånd (true/false) för dispositionsobjektet. |
| level | Hämtar hierarkinivå för dispositionsobjektet. |
## Indexer
| Namn | Beskrivning |
| :- | :- |
| [index] | Hämtar dispositionsobjektet från samlingen med hjälp av index. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| delete() | Tar bort detta dispositionsobjekt från dokumentets dispositionshierarki. |
| delete(name) | Tar bort dispositionsposten med angivet namn från dokumentets dispositionshierarki. |
| insert(index, outline) | Infogar dispositionsobjektet i samlingen på den angivna platsen. |
