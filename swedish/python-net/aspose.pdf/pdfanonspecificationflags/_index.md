## PdfANonSpecificationFlags class

Denna klass innehåller flaggor för att styra PDF/A-konvertering för fall då källdokumentet PDF inte <br/>            motsvarar PDF-specifikationen. Om flaggorna i denna klass används minskar prestandan <br/>            men det är nödvändigt när källdokumentet PDF inte kan konverteras till PDF/A-format på vanligt sätt. <br/>            Som standard är alla flaggor satta till false.
