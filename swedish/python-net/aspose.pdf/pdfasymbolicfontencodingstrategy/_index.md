## PdfASymbolicFontEncodingStrategy class

Denna klass beskriver regler som kan användas för att finjustera processen för att kopiera kodningsdata i fall<br/>            när TrueType-symboliska teckensnitt har mer än en kodning.<br/>            Vissa PDF-dokument efter konvertering till PDF/A-format kan ha fel <br/>            "More than one encoding in symbolic TrueType font's cmap". <br/>            Vad är orsaken till detta fel? Alla TrueType-symboliska teckensnitt har en speciell tabell "cmap"<br/>            i sin interna data. Denna tabell mappar teckenkoder till glyfindex. <br/>            Och denna tabell kan innehålla olika kodningundertabeller som<br/>            beskriver använda kodningar. Se avancerad information om cmap-tabeller på<br/>            https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6cmap.html.<br/>            Vanligtvis innehåller cmap-tabellen flera kodningundertabeller, men PDF/A-standarden kräver<br/>            att endast en kodningundertabell (3,0) får lämnas för detta teckensnitt i PDF/A-dokumentet. <br/>            Och den centrala frågan här – vilka data måste tas från andra undertabeller för att kopieras till<br/>            destinationskodningstabellen (3,0)? Majoriteten av teckensnitt har "välformade" cmap-tabeller där<br/>            varje kodningundertabell är helt konsekvent med en annan undertabell. Men vissa teckensnitt<br/>            har cmap-tabeller med kollisioner – där till exempel en undertabell har glyfindex <br/>            100 för unicode 100, men en annan undertabell har glyfindex 200 för samma unicode 100.<br/>            För att lösa dessa problem behövs en speciell strategi. <br/>            Som standard används följande strategi: <br/>            mac-undersubtabell(1,0) söks. Om denna tabell hittas används endast dessa data för att fylla destinations<br/>            tabellen (3,0). Om mac-undersubtabell inte hittas itereras alla undertabeller förutom (3,0) <br/>            och används för att kopiera data till destinations- (3,0) undertabell. Även mappning för varje unicode (unicode, glyfindex)<br/>            kopieras till destinations-tabellen endast om destinations-tabellen för närvarande inte har denna unicode. <br/>            Så, till exempel om den första undertabellen har glyfindex 100 för unicode 100, och nästa undertabell har glyf<br/>            index 200 för samma unicode 100, kopieras endast data från den första undertabellen (unicode=100, glyfindex = 100). <br/>            Så varje föregående undertabell har företräde framför nästa. <br/>            Egenskaperna för denna klass [PdfASymbolicFontEncodingStrategy](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) hjälper till att finjustera standardbeteendet. <br/>            Om egenskapen [preferred_cmap_encoding_table](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) av typen [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            är satt, kommer relevant undertabell att användas i företräde framför mac-undersubtabell(1,0). Värdet 'MacTable' från<br/>            uppräkningen [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/) har ingen mening i detta fall, eftersom den <br/>            pekar på samma mac-undersubtabell (1,0) som används som standard. <br/>            Egenskapen [None](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) förkastar alla prioriteringar för någon undertabell.<br/>            Om denna egenskap är satt, används endast undertabeller från den deklarerade könen i angiven ordning.<br/>            Om specificerade undertabeller inte hittas används standarditeration av alla undertabeller och kopieringsstrategin som beskrivits ovan<br/>            .<br/>            Objektet [QueueItem](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy/queueitem/) specificerar den använda kodningsundertabellen. Denna undertabell kan sättas<br/>            via kombination av medlemmar (PlatformID, PlatformSpecificId) eller via [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            uppräkning.
