## XfaParserOptions class

klass för att hantera relaterad datainkapsling

XfaParserOptions-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| XfaParserOptions(page_size) | Initierar en ny instans av klassen XfaParserOptions |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| page_size | Hämtar eller anger sidans storlek. |
| signerad | Om den här egenskapen är sann kommer dokumentet att konverteras med användning av xfa-formulärströmmen (om den finns).<br/>            Om den är falsk kommer xfa-formulärströmmen att ignoreras.<br/>            Denna egenskap infördes eftersom det inte är tydligt hur man beräknar kontrollsumman som används för att kontrollera signaturen. |
| emulate_requierd_groups | Om den här egenskapen är sann kommer ytterligare röda rektanglar att ritas för de obligatoriska Xfa "exkluderade grupperna"<br/>            Denna egenskap infördes eftersom avsaknaden av motsvarigheter till exkluderade grupper under konvertering av Xfa-representationen av formulär <br/>            till standard.<br/>            Den är falsk som standard. |
| base_path | Hämtar eller anger basvägen. |
