## ToUnicodeProcessingRules class

Denna klass beskriver regler som kan användas för att lösa Adobe Preflight‑felet <br/>            \"Text kan inte mappas till Unicode\".

Typen ToUnicodeProcessingRules exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| ToUnicodeProcessingRules() | Konstruktor |
| ToUnicodeProcessingRules(remove_spaces) | Initierar en ny instans av klassen ToUnicodeProcessingRules |
| ToUnicodeProcessingRules(remove_spaces, map_non_linked_unicodes_on_space) | Initierar en ny instans av klassen ToUnicodeProcessingRules |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| remove_spaces_from_c_map_names | Vissa teckensnitt har ToUnicode-teckenkodkartor med mellanslag i namn. Dessa mellanslag kan orsaka fel<br/>            vid unicode-textmappning. Denna flagga instruerar att ta bort mellanslag från namn på ToUnicode-teckenkodkartor.<br/>            Standardvärdet är falskt. |
| map_non_linked_symbols_on_space | Vissa teckensnitt tillhandahåller inte information om unicode för vissa textsymboler. <br/>            Detta informationsbrist orsakar felet "Text kan inte mappas till Unicode".<br/>            Använd denna flagga för att mappa icke‑länkade symboler till unicode "space"(kod 32). |
