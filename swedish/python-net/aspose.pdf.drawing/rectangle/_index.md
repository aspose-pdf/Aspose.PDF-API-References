## Rectangle class

Representerar rektangel.

Rektangeltypen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Rectangle(left, bottom, width, height) | Initierar en ny instans av klassen Rectangle |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| graph_info | Hämtar eller anger ett [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/)‑objekt som indikerar grafinformation, såsom färg,<br/>            linjebredd, osv. |

| rounded_corner_radius | Hämtar eller anger ett flyttalsvärde som indikerar radien på rektangelns hörn. |
| left | Hämtar eller anger ett flyttalsvärde som indikerar rektangelns vänstra position. |
| bottom | Hämtar eller anger ett flyttalsvärde som indikerar rektangelns nedre position. |
| bredd | Hämtar eller anger ett flyttal som indikerar rektangelns bredd. |
| höjd | Hämtar eller anger ett flyttal som indikerar rektangelns höjd. |
