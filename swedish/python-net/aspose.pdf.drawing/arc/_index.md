## Arc class

Representerar båge.

Arc-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Initierar en ny instans av Arc-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| graph_info | Hämtar eller anger ett [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/)‑objekt som indikerar grafinformation, såsom färg,<br/>            linjebredd, osv. |
| text | Hämtar eller anger en text för formen |
| pos_x | Hämtar eller anger ett flyttal som indikerar x-koordinaten för bågens centrum. |
| pos_y | Hämtar eller anger ett flyttal som indikerar y-koordinaten för bågens centrum. |
| radius | Hämtar eller anger ett flyttal som indikerar bågens radie. |
| alpha | Hämtar eller anger ett flyttal som indikerar startvinkeln i grader för bågen. |
| beta | Hämtar eller anger ett flyttal som indikerar slutvinkeln i grader för bågen. |
