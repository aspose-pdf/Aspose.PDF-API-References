## Measure class

Klass som beskriver Measure‑koordinatsystemet.

Typen Measure exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Measure(annotation) | Initierar en ny instans av Measure-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| scale_ratio | En textsträng som uttrycker skala-förhållandet för ritningen. |
| x_format | En talformatarray för mätning av förändring längs x-axeln och, om Y inte finns, även längs y-axeln. |
| y_format | En talformatarray för mätning av förändring längs y-axeln. |
| distance_format | En talformatarray för mätning av avstånd i alla riktningar. |
| area_format | En talformatarray för mätning av yta. |
| angle_format | En talformatarray för mätning av vinklar. |
| slope_format | En talformatarray för mätning av lutningen på en linje. |
| origin | Punkt som ska specificera ursprunget för mätsystemets koordinater i standardanvändarens rymdkoordinater. |
| xy_factor | En faktor som ska användas för att konvertera de största enheterna längs y-axeln till de största enheterna längs x-axeln. |
