## AnnotationCollection class

Klass som representerar annoteringssamling.

Typen AnnotationCollection exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| is_synchronized | Hämtar ett värde som indikerar om åtkomst till Aspose.Pdf.Annotations.AnnotationCollection är synkroniserad (trådsäker). |
| sync_root | Hämtar ett objekt som kan användas för att synkronisera åtkomst till Aspose.Pdf.Annotations.AnnotationCollection. |
## Indexer
| Namn | Beskrivning |
| :- | :- |
| [index] | Indexet för elementet som ska hämtas. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| delete(index) | Tar bort annotation från samlingen med index. |
| delete() | Tar bort annotation från samlingen med index. |
| delete(annotation) | Tar bort annotation från samlingen med index. |
| add(annotation, consider_rotation) | Lägger till annotation i samlingen. Om sidan är roterad kommer annoteringsrektangeln att beräknas om därefter. |
| accept(visitor) | Accepterar besökare för att bearbeta annotation. |
| find_by_name(name) | Returnerar annotation efter dess namn. |
