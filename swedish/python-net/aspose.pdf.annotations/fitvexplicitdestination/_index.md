## FitVExplicitDestination class

Representerar en explicit destination som visar sidan med den horisontella koordinaten left placerad vid fönstrets vänstra kant och sidans innehåll förstorat precis tillräckligt för att passa hela sidans höjd inom fönstret. Ett null‑värde för left anger att det aktuella värdet för den parametern ska behållas oförändrat.
