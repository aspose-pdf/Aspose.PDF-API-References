## TextStyle class

Klass som representerar stil för text i annotationen.

Typen TextStyle exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| font_name | Fontens namn. |
| font_size | Fontstorlek. |
| justering | Hämtar eller anger horisontell justering av texten. |
| horizontal_alignment | Textjustering. Giltiga värden är: Left, Center, Rigth. |
| färg | Färg på texten. |
