| NONE | Ingen radslut. |
| KVADRAT | En fyrkant fylld med annotationens inre färg, om någon. |
| CIRCLE | En cirkel fylld med annotationens inre färg, om någon. |
| DIAMANT | En romformad figur fylld med annotationens inre färg, om någon. |
| OPEN_ARROW | Två korta linjer som möts i en spetsig vinkel för att bilda ett öppet pilhuvud. |
