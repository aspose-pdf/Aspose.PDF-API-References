## LaunchAction class

Representerar en launch‑åtgärd som startar ett program eller öppnar eller skriver ut ett dokument.

Typen LaunchAction visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| LaunchAction(file) | Initierar en ny instans av klassen LaunchAction |
| LaunchAction(document, file) | Initierar en ny instans av klassen LaunchAction |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| nästa | Nästa åtgärder i sekvens. |
| fil | Hämtar eller anger programmet som ska startas eller dokumentet som ska öppnas eller skrivas ut. |
| nytt_fönster | Hämtar eller anger en flagga som specificerar om destinationsdokumentet ska öppnas i ett nytt fönster (gäller endast PDF-dokument). |
