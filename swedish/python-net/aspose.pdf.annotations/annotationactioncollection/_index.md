## AnnotationActionCollection class

Representerar samlingen av annoteringsåtgärder.

Typen AnnotationActionCollection exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| on_enter | Hämtar eller anger en åtgärd som ska utföras när markören går in i annoteringens aktiva område. |
| on_exit | Hämtar eller anger en åtgärd som ska utföras när markören lämnar annoteringens aktiva område. |
| on_press_mouse_btn | Hämtar eller anger en åtgärd som ska utföras när musknappen trycks ned i annoteringens aktiva område. |
| on_release_mouse_btn | Hämtar eller anger en åtgärd som ska utföras när musknappen släpps inom annotationens aktiva område. |
| on_receive_focus | Hämtar eller anger en åtgärd som ska utföras när annotationen får inmatningsfokus. |
| on_open_page | Hämtar eller anger en åtgärd som ska utföras när sidan som innehåller annotationen öppnas. |
| on_close_page | Hämtar eller anger en åtgärd som ska utföras när sidan som innehåller annotationen stängs. |
| on_show_page | Hämtar eller anger en åtgärd som ska utföras när sidan som innehåller annotationen blir synlig i visningsapplikationens användargränssnitt. |
| on_hide_page | Hämtar eller anger en åtgärd som ska utföras när sidan som innehåller annotationen inte längre är synlig i visningsapplikationens användargränssnitt. |
| on_lost_focus | Hämtar eller anger en åtgärd som ska utföras när annotationen förlorar inmatningsfokus. |
| on_modify_character | Hämtar eller anger en åtgärd som ska utföras när användaren ändrar tecken i fältet. |
| on_validate | Hämtar eller anger en åtgärd som ska utföras när användaren ändrar innehållet i fältet. |
| on_format | Hämtar eller anger en åtgärd som ska utföras för att formatera fältvärdet. |
| on_calculate | Hämtar eller anger en åtgärd för att beräkna fältvärdet. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| remove_actions() | Tar bort alla åtgärder för annotationen. |
