## FitBHExplicitDestination class

Representerar en explicit destination som visar sidan med den vertikala koordinaten top placerad vid fönstrets övre kant och sidans innehåll förstorat precis tillräckligt för att passa hela bredden av dess omgivningsruta inom fönstret. Ett null‑värde för top anger att det aktuella värdet för den parametern ska behållas oförändrat.
