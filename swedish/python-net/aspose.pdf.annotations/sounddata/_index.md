## SoundData class

Representerar ljuddata som definierar ljudet som ska spelas när annotationen aktiveras.

SoundData-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| rate | Hämtar eller anger samplingsfrekvensen, i prover per sekund. |
| channels | Hämtar eller anger antalet ljudkanaler. |
| bits | Hämtar eller anger antalet bitar per samplingsvärde per kanal. |
| innehåll | Hämtar ljudströmmen som ska spelas när annotationen aktiveras. |
| kodning | Hämtar eller anger kodningsformatet för samplingsdata. |
