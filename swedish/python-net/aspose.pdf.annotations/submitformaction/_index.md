## SubmitFormAction class

Klass som beskriver submit-form‑åtgärd.

Typen SubmitFormAction visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| SubmitFormAction() | Initierar SubmitFormAction-objektet. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| nästa | Nästa åtgärder i sekvens. |
| flaggor | Hämtar eller anger flaggor för submit‑åtgärden |
| url | Destinations‑URL. |
| EXCLUDE | Om tom, specificerar Fields‑arrayen vilka fält som ska inkluderas i inlämningen. |
| INCLUDE_NO_VALUE_FIELDS | Om angivet, ska alla fält som anges av Fields‑arrayen och Include/Exclude‑flaggan skickas. |
| EXPORT_FORMAT | Om angivet, ska fältnamn och värden skickas i HTML‑formulärformat. |
| GET_METHOD | Om angivet, ska fältnamn och värden skickas med en HTTP‑GET‑begäran. |
| SUBMIT_COORDINATES | Om angivet, ska koordinaterna för musklicken som orsakade submit‑form‑åtgärden överföras som en del av formulärdata. |
| XFDF | Om angivet, ska fältnamn och värden skickas som XFDF. |
| INCLUDE_APPEND_SAVES | Om angivet, ska den inskickade FDF‑filen inkludera innehållet i alla inkrementella uppdateringar. |
| INCLUDE_ANNOTATIONS | Om angivet, ska den inskickade FDF‑filen inkludera alla markup‑annotationer i det underliggande PDF‑dokumentet. |
| SUBMIT_PDF | Om den är inställd ska dokumentet skickas som PDF med MIME-innehållstypen application/pdf. |
| CANONICAL_FORMAT | Om den är inställd ska alla inskickade fältvärden som representerar datum konverteras till standardformatet. |
| EXCL_NON_USER_ANNOTS | Om den är inställd ska den endast inkludera de markup-anteckningarna vars T-post matchar namnet på den aktuella användaren. |
| EXCL_F_KEY | Om den är inställd ska den inskickade FDF:n utesluta F-posten. |
| EMBED_FORM | Om den är inställd ska F-posten i den inskickade FDF:n vara en filspecificering som innehåller en <br/>            inbäddad filström som representerar PDF-filen som FDF:n skickas från. |
