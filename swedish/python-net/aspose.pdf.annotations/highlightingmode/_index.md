## HighlightingMode enumeration

Enumererar annotationens markeringsläge, den visuella effekt som ska användas när musknappen trycks ned eller hålls ned inom dess aktiva område.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| NONE | Ingen markering. |
| INVERT | Invertera innehållet i annoteringsrektangeln. |
| OUTLINE | Invertera annotationens kant. |
| PUSH | Visa annotationens nedre utseende, om något finns. Om inget nedre utseende är definierat, förskjut innehållet i annoteringsrektangeln så att det ser ut som om det trycks ner under sidans yta. |
| TOGGLE | Samma som Push (vilket föredras). |
