## TextElement class

Allmänt textelement i dokumentets logiska struktur.

Typen TextElement exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| barn | Hämtar samling av underordnade element. |
| lang | (Valfritt; PDF 1.4) Ett språk som specificerar det naturliga språket för all text<br/>i strukturelementet förutom där det åsidosätts av språkspecifikationer för nästlade strukturelement<br/>eller markerat innehåll. |
| actual_text | (Valfritt; PDF 1.4) Text som är en exakt ersättning för strukturelementet och dess barn.<br/>Denna ersättningstext (som bör tillämpas på så liten en del av innehållet som möjligt)<br/>är användbar vid extrahering av dokumentets innehåll för att stödja tillgänglighet för användare<br/>med funktionsnedsättningar eller för andra ändamål. |
| alt | (Valfritt) En alternativ beskrivning av strukturelementet och dess barn i<br/>mänskligt läsbar form, vilket är användbart vid extrahering av dokumentets innehåll för att stödja<br/>tillgänglighet för användare med funktionsnedsättningar eller för andra ändamål. |
| e | (Valfritt; PDF 1.5) Den utökade formen av en förkortning. |
| text | Hämtar värdet för textstrukturelementet. |
