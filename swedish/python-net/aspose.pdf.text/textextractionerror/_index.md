## TextExtractionError class

Beskriver att textutdragsfelet har uppstått i PDF‑dokumentet.

Typen TextExtractionError exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| summary | Kort beskrivning av felet. |
| description | Utökad beskrivning av felet. |
| location | Plats för felet. |
| font_key | Nyckel (PDF-namn) för Font-objektet som används för att visa text som orsakar extraktionsfel. |
| font_name | Läsbart (internt) namn för Font-objektet som används för att visa text som orsakar extraktionsfel. |
| extracted_text | Text som faktiskt extraherades. |
