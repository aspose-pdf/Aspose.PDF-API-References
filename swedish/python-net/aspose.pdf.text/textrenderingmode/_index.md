## TextRenderingMode enumeration

Textrenderingsläget, Tmode, bestämmer om visning av text ska leda till att glyfkonturer streckas, fylls, används som en beskärningsgräns, eller någon kombination av de tre.

## Members
| Medlemsnamn | Beskrivning |
| :- | :- |
| FILL_TEXT | Fyll text. |
| STROKE_TEXT | Konturera text. |
| FILL_THEN_STROKE_TEXT | Fyll, sedan konturera text. |
| INVISIBLE | Varken fyll eller konturera text (osynlig). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Fyll text och lägg till i sökväg för beskärning (se 9.3.6, "Text Rendering Mode,"). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Stryk text och lägg till i sökväg för beskärning. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Fyll, sedan stryk text och lägg till i sökväg för beskärning. |
| ADD_PATH_TO_CLIPPING | Lägg till text i sökväg för beskärning. |
