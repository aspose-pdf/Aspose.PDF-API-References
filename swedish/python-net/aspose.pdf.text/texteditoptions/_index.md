## TextEditOptions class

Beskriver alternativ för textredigeringsoperationer.

Typen TextEditOptions exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TextEditOptions(no_character_behavior) | Initierar en ny instans av klassen TextEditOptions |
| TextEditOptions(font_replace_behavior) | Initierar en ny instans av klassen TextEditOptions |
| TextEditOptions(allow_language_transformation) | Initierar en ny instans av klassen TextEditOptions |
| TextEditOptions(language_transformation_behavior) | Initierar en ny instans av klassen TextEditOptions |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| replacement_font | Hämtar eller anger font som används för ersättning om användarens font inte innehåller det erforderliga tecknet |
| no_character_behavior | Hämtar eller anger läge som definierar beteendet om teckensnitt inte innehåller de begärda tecknen. |
| font_replace_behavior | Hämtar läge som definierar beteendet för scenarier med teckensnittsersättning. |
| allow_language_transformation | Hämtar eller anger värde som tillåter användning av språköversättning vid tillägg eller redigering av text.<br/>            true - språköversättning kommer att tillämpas om nödvändigt (standardvärde).<br/>            false - språköversättning kommer INTE att tillämpas. |
| language_transformation_behavior | Hämtar läge som definierar beteendet för scenarier med språköversättning. |
| clipping_paths_processing | Hämtar läge för bearbetning av beskärningsväg för den redigerade texten. |
| to_attempt_get_underline_from_source | Hämtar eller anger värde som tillåter sökning efter understrykning av text på sidan i källdokumentet.<br/>            (Föråldrad) Använd TextSearchOptions.SearchForTextRelatedGraphics istället för detta. |
