## TextState class

Representerar ett texttillstånd för en text

TextState-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TextState() | Skapar ett texttillståndsobjekt. |
| TextState(font_size) | Initierar en ny instans av TextState-klassen |
| TextState(foreground_color) | Initierar en ny instans av TextState-klassen |
| TextState(foreground_color, font_size) | Initierar en ny instans av TextState-klassen |
| TextState(font_family) | Initierar en ny instans av TextState-klassen |
| TextState(font_family, bold, italic) | Initierar en ny instans av TextState-klassen |
| TextState(font_family, font_size) | Initierar en ny instans av TextState-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| character_spacing | Hämtar eller anger teckenavstånd för texten. |
| line_spacing | Hämtar eller anger radavstånd för texten. |
| horizontal_scaling | Hämtar eller anger horisontell skalning av texten. |
| subscript | Hämtar eller anger nedsänkt för texten. |
| superscript | Hämtar eller anger upphöjd för texten. |
| word_spacing | Hämtar eller anger ordavstånd för texten. |
| invisible | Hämtar eller anger textens osynlighet. Detta speglar i princip [rendering_mode](/pdf/python-net/aspose.pdf.text/textstate/)‑tillståndet, förutom vissa speciella fall (som beskärning). |
| rendering_mode | Hämtar eller anger renderingsläge för texten. |
| font_size | Hämtar eller anger teckenstorlek för texten. |
| font | Hämtar eller anger teckensnitt för texten. |
| foreground_color | Hämtar eller anger förgrundsfärg för texten. |
| stroking_color | Hämtar eller anger förgrundsfärg för texten. |
| underline | Hämtar eller anger understrykning för texten, representerad av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| strike_out | Anger genomstrykning för texten, representerad av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| background_color | Anger bakgrundsfärg för texten. |
| font_style | Anger teckensnittsstil för texten. |
| horizontal_alignment | Hämtar eller anger horisontell justering för texten. |
| TAB_TAG | Du kan placera denna tagg i texten för att ange tabulering. |
| TABSTOP_DEFAULT_VALUE | Standardvärde för tabulering i bredden av mellanslagstecknet för standardteckensnittet. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| apply_changes_from(text_state) | Tillämpar inställningar från ett annat textState. |
| measure_string(str) | Mäter strängen. |
