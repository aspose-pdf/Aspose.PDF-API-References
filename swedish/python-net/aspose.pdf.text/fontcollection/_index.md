## FontCollection class

Representerar teckensnittssamling.

Typen FontCollection exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| sync_root | Hämtar ett objekt som kan användas för att synkronisera åtkomst till samlingen. |
| is_synchronized | Hämtar ett värde som indikerar om åtkomst till samlingen är synkroniserad (trådsäker). |
## Indexer
| Namn | Beskrivning |
| :- | :- |
| [index] | Hämtar teckenselementet på det angivna indexet. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| add(new_font, res_name) | Lägger till ett nytt teckensnitt i teckensnittresurserna och returnerar det automatiskt tilldelade namnet på teckensnittresursen. |
