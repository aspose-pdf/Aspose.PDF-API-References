## TextFragmentState class

Representerar ett texttillstånd för ett textfragment.

Typen TextFragmentState exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TextFragmentState(fragment) | Initierar en ny instans av klassen TextFragmentState |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| character_spacing | Hämtar eller anger teckenavståndet för texten, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| line_spacing | Hämtar eller anger radavstånd för texten. |
| horizontal_scaling | Hämtar eller anger horisontell skalning av texten, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| subscript | Hämtar eller anger nedsänkt text, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| superscript | Hämtar eller anger upphöjd text, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| word_spacing | Hämtar eller anger ordavstånd för texten. |
| osynlig | Hämtar eller anger osynlighet för texten. |
| rendering_mode | Hämtar eller anger renderingsläge för texten. |
| font_size | Hämtar eller anger teckenstorlek för texten, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font | Hämtar eller anger teckensnitt för texten, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| foreground_color | Hämtar eller anger förgrundsfärg för texten, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| stroking_color | Hämtar eller anger färgstrokoperationer för rendering av [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) (streckad text, rektangelram) |
| underline | Hämtar eller anger understrykning för texten, representerad av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| strike_out | Anger genomstrykning för texten, representerad av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| background_color | Anger bakgrundsfärg för texten, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font_style | Anger teckensnittsstil för texten, representerat av objektet [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| horizontal_alignment | Hämtar eller anger horisontell justering för texten. |
| TAB_TAG | Du kan placera denna tagg i texten för att ange tabulering. |
| TABSTOP_DEFAULT_VALUE | Standardvärde för tabulering i bredden av mellanslagstecknet för standardteckensnittet. |
| tab_stops | Hämtar tabbstopp för texten. |
| formatting_options | Hämtar eller anger formateringsalternativ.<br/>            Inställning av alternativen kommer endast att vara effektiv i generator-scenarier. |
| rotation | Hämtar eller anger rotationsvinkeln i grader. |
| draw_text_rectangle_border | Hämtar eller anger om flaggan för att rita textrutans ram är satt. |
