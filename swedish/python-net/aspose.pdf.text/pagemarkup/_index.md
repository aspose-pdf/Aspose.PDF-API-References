## PageMarkup class

Sidans markup representeras av samlingar av [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) och [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/).

PageMarkup-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| nummer | Hämtar bearbetat sidnummer. |
| rectangle | Hämtar den bearbetade sidrektangeln. |
| sections | Hämtar samlingen av [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) som hittades på sidan. |
| paragraphs | Hämtar samlingen av [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) som hittades på sidan. |
| text_fragments | Hämtar samlingen av [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) som hittades på sidan. |
| is_multicolumn_paragraphs_allowed | Hämtar eller anger värdet som indikerar om startlinjerna i en nästa sektion kan behandlas som en fortsättning på det sista stycket i en föregående sektion. |
