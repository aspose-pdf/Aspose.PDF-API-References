## TextExtractionErrorLocation class

Representerar platsen i PDF‑dokumentet där textutdragsfelet har uppstått.

Typen TextExtractionErrorLocation exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| path | Plats för PDF-dokumentet där fel vid textutdragning har uppstått. |
| page_number | Nummer på dokumentsidan där fel vid textutdragning har uppstått. |
| object_type | Typ av PDF-objektet (Page eller xForm) i vilket fel i innehållsströmmen för textutdragning har uppstått. |
| form_key | Nyckel (namn) för PDF Form XObject i vilket fel i innehållsströmmen för textutdragning har uppstått. Inte tom om ObjectType == 'xForm'. |
| operator_index | Index för textvisande operator i innehållsströmmen (operator-samling) som orsakar fel vid textutdragning. |
| operator_string | Textvisande operator som orsakar fel vid textutdragning. |
| font_used_key | Nyckel (namn) för PDF Font-objektet som används för att visa operatorn som orsakar fel vid textutdragning. |
| text_start_point | Nyckel (namn) för PDF Font-objektet som används för att visa operatorn som orsakar fel vid textutdragning. |
