## TextSegment class

Representerar segment av Pdf-text.

Typen TextSegment exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TextSegment() | Skapar TextSegment-objekt. |
| TextSegment(text) | Initierar en ny instans av klassen TextSegment |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| start_char_index | Hämtar startteckenindex för det aktuella segmentet i show‑text‑operatorn (Tj, TJ) segment. |
| end_char_index | Hämtar slutteckenindex för det aktuella segmentet i show‑text‑operatorn (Tj, TJ) segment. |
| text | Hämtar eller anger strängtextobjektet som [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/)‑objektet representerar. |
| text_state | Hämtar eller anger texttillståndet för den text som [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/)‑objektet representerar. |
| position | Hämtar textposition för texten, representerad med [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/)‑objekt. |
| rectangle | Hämtar rektangeln för TextSegment |
| baseline_position | Hämtar textposition för texten, representerad med [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/)‑objekt.<br/>            YIndent i Position‑strukturen representerar baslinjekoordinationen för textsegmentet. |
| text_edit_options | Hämtar eller anger alternativ för textredigering. Alternativen definierar speciellt beteende när begärt tecken inte kan skrivas med teckensnittet. |
| tecken | Hämtar en samling av CharInfo-objekt som representerar information om tecken i textsegmentet. |
| hyperlänk | Hämtar eller anger segmentets hyperlänk (för PDF‑generator). |
