## MarkupParagraph class

Representerar ett stycke.

Typen MarkupParagraph exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| points | Punkter i polygonen som beskriver stycket.<br/>            Startpunkten är det nedre vänstra hörnet av stycket. Och efterföljande punkter är i moturs sekvens. |
| secondary_points | Punkter i sekundär polygon som beskriver styckets fortsättning. Den kommer inte att vara null om stycket fortsätts i nästa kolumn eller på nästa sida.<br/>            Startpunkten är det nedre vänstra hörnet av stycket. Och efterföljande punkter är i moturs sekvens. |
| continuation_page_numbers | Lista över sidnummer där stycket fortsätts. Den kommer att matcha med sidan där stycket startade om det fortsätter i nästa kolumn på samma sida. |
| fragments | Samling av icke tomma [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) objekt för stycket. |
| lines | Rader i stycket. Varje rad representeras av en lista med textfragment. |
| text | Hämtar strängtextobjektet som [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) objektet representerar. |
