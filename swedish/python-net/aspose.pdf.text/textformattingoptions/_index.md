## TextFormattingOptions class

Representerar alternativ för textformatering

Typen TextFormattingOptions exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| TextFormattingOptions(wrap_mode) | Initierar en ny instans av klassen TextFormattingOptions |
| TextFormattingOptions() | Initierar en ny instans av [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) objektet med odefinierat radbrytningsläge. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| wrap_mode | Hämtar eller anger radbrytningsläge.<br/>            Standardvärdet är WordWrapMode.NoWrap |
| line_spacing | Hämtar eller anger radavståndsläge.<br/>            Standardvärdet är LineSpacingMode.FontSize |
| hyphen_symbol | Hämtar eller anger bindestreckssymbol som används i avstavningsprocessen. |
| subsequent_lines_indent | Hämtar eller anger indenteringsvärde för efterföljande rader. |
| first_line_indent | Hämtar eller anger indenteringsvärde för första raden. |
