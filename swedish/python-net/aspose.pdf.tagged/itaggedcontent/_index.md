## ITaggedContent class

Representerar gränssnitt för arbete med TaggedPdf-innehåll i dokumentet.

ITaggedContent-typen exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| structure_text_state | Hämta [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) inställningar för hela dokumentet. |
| struct_tree_root_element | Hämtar [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/) för PDF-dokumentet. |
| root_element | Hämtar rot-[StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) för den logiska strukturen i PDF-dokumentet. |
