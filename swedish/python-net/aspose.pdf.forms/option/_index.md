## Option class

Klass representerar alternativ för valfält.

Typen Option exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| value | Hämtar eller anger exportvärde för alternativet. |
| name | Hämtar eller anger namn på alternativet. |
| selected | Hämtar eller anger markeringsstatus för alternativet. Returnerar true om alternativet är markerat. |
| index | Hämtar index för alternativet. |
