## IconFit class

Beskriver hur widget‑annotationens ikon ska visas inom dess annotationsrektangel.

Typen IconFit exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| scaling_reason | Hämtar eller anger skalningsorsak. |
| scaling_mode | Typen av skalning som ska användas.        /// |
| leftover_left | Hämtar eller anger utrymme att tilldela till vänster om ikonen. |
| leftover_bottom | Hämtar eller anger utrymme att tilldela under ikonen. |
| spread_on_border | Om true indikerar att knappens utseende ska skalas för att helt passa inom annoteringens gränser utan att ta hänsyn till kantlinjens bredd. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| name_to_scaling_reason(reason) | Konverterar namn på skalningsorsak till ett ScalingReason-objekt. |
| scaling_reason_to_name(reason) | Konverterar skalningsorsaksobejct till namn. |
| name_to_scaling_mode(mode) | Konverterar skalningslägesnamn till ScalingMode-objekt. |
| scaling_mode_to_name(mode) | Konverterar skalningslägesobjekt till namn. |
