## StructureTextState class

Representerar texttillståndsinställningar för Text Structure Elements och TaggedContent (ITextElement, ITaggedContent)

Typen StructureTextState exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| font | Hämtar eller anger teckensnittet för text. |
| font_size | Hämtar eller anger teckenstorlek för texten. |
| font_style | Hämtar eller anger teckensnittsstilen för texten. |
| foreground_color | Hämtar eller anger förgrundsfärg för texten. |
| background_color | Hämtar eller anger bakgrundsfärgen för texten. |
| underline | Hämtar eller anger understrykning för texten. |
| strike_out | Hämtar eller anger genomstrykning för texten. |
| superscript | Hämtar eller anger upphöjd för texten. |
| subscript | Hämtar eller anger nedsänkt för texten. |
| horizontal_scaling | Hämtar eller anger horisontell skalning av texten. |
| line_spacing | Hämtar eller anger radavstånd för texten. |
| character_spacing | Hämtar eller anger teckenavstånd för texten. |
| word_spacing | Hämtar eller anger ordavstånd för texten. |
| margin_info | Hämtar eller anger marginal för blockstrukturselement. |
