## AnnotationElement class

Representerar en basklass för annoteringsstrukturelement i logisk struktur.

Typen AnnotationElement exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| föräldra_element | Ingen |
| barn_element | Ingen |
| standard_attributägare | Hämtar |
| attribut | Hämtar |
| struktur_typ | Hämtar typ av strukturelement. |
| id | Hämtar ID för strukturelement. |
| titel | Hämtar eller anger titeln för strukturelement. |
| språk | Hämtar eller anger språket för strukturelement. |
| alternativ_text | Hämtar eller anger den alternativa texten för strukturelement. |
| expansions_text | Hämtar eller anger expansionstexten för strukturelement. |
| actual_text | Hämtar eller anger den faktiska texten för strukturelement. |
| alternativa_beskrivningar | Hämtar eller anger de alternativa beskrivningarna för annotation.<br/>                Text som ska visas för annotationen eller, om denna typ av annotation inte visar text, en alternativ beskrivning av annotationens innehåll i mänskligt läsbar form. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| append_child(element) | Ingen |
| change_parent_element(new_parent_element) | Ändra föräldraelement för aktuellt strukturelement |
| generate_id() | Generera ID för strukturelement. |
| set_id(id) | Ställer in ID för strukturelementet. |
| clear_id() | Rensa ID för strukturelementet. |
| set_tag(new_tag) | Ställer in anpassad tagg för strukturelementet. |
