## StructureTypeCategory class

Representerar kategorier av standardstrukturtyper.

StructureTypeCategory-typen visar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| GROUPING_ELEMENTS | Grupperingselement grupperar andra element i sekvenser eller hierarkier men har inget eget innehåll och har ingen direkt effekt på layouten. |
| BLS_ES | Blocknivåstruktur-element (BLSEs) beskriver den övergripande layouten av innehållet på sidan och fortskrider i block‑progressionsriktningen. |
| ILS_ES | Inline‑nivåstruktur-element (ILSEs) beskriver layouten av innehållet inom ett BLSE och fortskrider i inline‑progressionsriktningen. |
| ILLUSTRATION_ELEMENTS | Illustrationselement är kompakta sekvenser av innehåll, i sidans innehållsordning, som betraktas som enhetliga objekt med avseende på sidlayouten. En illustration kan behandlas som antingen ett BLSE eller ett ILSE. |
