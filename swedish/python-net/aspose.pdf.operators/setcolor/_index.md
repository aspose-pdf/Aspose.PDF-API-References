## SetColor class

Representerar klass för sc-operatorn (sätt färg för icke-strokande operationer).

Typen SetColor exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| SetColor() | Initierar operatören. |
| SetColor(g) | Initierar en ny instans av klassen SetColor |
| SetColor(r, g, b) | Initierar en ny instans av klassen SetColor |
| SetColor(c, m, y, k) | Initierar en ny instans av klassen SetColor |
| SetColor(color) | Initierar en ny instans av klassen SetColor |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| index | Ingen |
| r | Hämtar den röda komponenten i färgen |
| g | Hämtar den gröna komponenten i färgen |
| b | Hämtar den röda komponenten i färgen |
| c | Hämtar cyan-komponenten i CMYK-färgen. |
| m | Hämtar magenta-komponenten i CMYK-färgen. |
| y | Hämtar den gula komponenten i CMYK-färgen. |
| k | Hämtar den svarta komponenten i CMYK-färgen. |
| grå | Hämtar den svarta komponenten i den grå färgen. |
| färg | Hämtar en array av färgkomponenter. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| accept(visitor) | Accepterar besökarobjekt för att bearbeta operatorn. |
| is_text_show_operator(op) | Ingen |
| get_color() | Returnerar färg som specificerats av operatorn. |
