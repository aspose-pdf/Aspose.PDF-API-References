## SetDash class

Klass som representerar d-operatorn (sätt linjestreckmönster).

Typen SetDash visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| SetDash(pattern, phase) | Initierar en ny instans av klassen SetDash |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| index | Operatörsindex i sidans operatörslista. |
| pattern | Dash-mönster. Arrayens element ska vara tal som specificerar längderna på alternerande streck och mellanrum.<br/>            Om arrayen har ett element är streck- och mellanrumslängderna lika. |
| phase | Dash-fas. Innan en bana börjar ritas med streck, ska dash-arrayen cyklas igenom och längderna på streck och mellanrum summeras. <br/>            När den ackumulerade längden är lika med det värde som anges av dash-fasen, ska ritning av banan påbörjas, <br/>            och dash-arrayen ska användas cykliskt från den punkten och framåt. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| accept(visitor) | Accepterar besökarobjekt för att bearbeta operatorn. |
| is_text_show_operator(op) | Avgör om operatören är den operatör som ansvarar för textutmatning (Tj, TJ, osv). |
