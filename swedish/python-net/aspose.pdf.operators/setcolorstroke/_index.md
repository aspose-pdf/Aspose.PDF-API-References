## SetColorStroke class

Klassen representerar SC-operatorn (sätt färg för strokande färgoperatorer).

SetColorStroke-typen exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| SetColorStroke() | Initierar operatören. |
| SetColorStroke(g) | Initierar en ny instans av SetColorStroke-klassen |
| SetColorStroke(r, g, b) | Initierar en ny instans av SetColorStroke-klassen |
| SetColorStroke(color) | Initierar en ny instans av SetColorStroke-klassen |
| SetColorStroke(c, m, y, k) | Initierar en ny instans av SetColorStroke-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| index | Ingen |
| r | Hämtar den röda komponenten i färgen |
| g | Hämtar den gröna komponenten i färgen |
| b | Hämtar den röda komponenten i färgen |
| c | Hämtar cyan-komponenten i CMYK-färgen. |
| m | Hämtar magenta-komponenten i CMYK-färgen. |
| y | Hämtar den gula komponenten i CMYK-färgen. |
| k | Hämtar den svarta komponenten i CMYK-färgen. |
| grå | Hämtar den svarta komponenten i den grå färgen. |
| färg | Hämtar en array av färgkomponenter. |
## Metoder
| Namn | Beskrivning |
| :- | :- |

| is_text_show_operator(op) | Ingen |
| get_color() | Returnerar färg som specificerats av operatorn. |
