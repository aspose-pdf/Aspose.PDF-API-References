## Do class

Klass som representerar Do-operatorn (anropa XObject).

Typen Do exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Do(name) | Initierar en ny instans av klassen Do |
| Do() | Skapar en ny Do-operator. <br/>            Används för att hämta alla Do-operatorer, d.v.s. utan att kontrollera deras argumentnamn. |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| index | Operatörsindex i sidans operatörslista. |
| name | Namn på XObject-argumentet för operatorn. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| accept(visitor) | Accepterar besökarobjekt för att bearbeta operatorn. |
| is_text_show_operator(op) | Avgör om operatören är den operatör som ansvarar för textutmatning (Tj, TJ, osv). |
