## GS class

Klass som representerar gs-operatorn (sätt parametrar från grafikstatusens parameterordbok).

Typen GS exponerar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| GS(name) | Initierar en ny instans av GS-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| index | Operatörsindex i sidans operatörslista. |
| name | Hämtar eller anger namn på grafikstatusresurs. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| accept(visitor) | Accepterar besökarobjekt för att bearbeta operatorn. |
| is_text_show_operator(op) | Avgör om operatören är den operatör som ansvarar för textutmatning (Tj, TJ, osv). |
