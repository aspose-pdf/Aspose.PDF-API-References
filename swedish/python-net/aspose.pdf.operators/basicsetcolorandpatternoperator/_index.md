## BasicSetColorAndPatternOperator class

Basoperator för alla Set Color-operatorer.

Typen BasicSetColorAndPatternOperator exponerar följande medlemmar:
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| index | Ingen |
| r | Hämtar den röda komponenten i färgen |
| g | Hämtar den gröna komponenten i färgen |
| b | Hämtar den röda komponenten i färgen |
| c | Hämtar cyan-komponenten i CMYK-färgen. |
| m | Hämtar magenta-komponenten i CMYK-färgen. |
| y | Hämtar den gula komponenten i CMYK-färgen. |
| k | Hämtar den svarta komponenten i CMYK-färgen. |
| grå | Hämtar den svarta komponenten i den grå färgen. |
| färg | Hämtar en array av färgkomponenter. |
| pattern_name | Hämtar Pattern Name. |
