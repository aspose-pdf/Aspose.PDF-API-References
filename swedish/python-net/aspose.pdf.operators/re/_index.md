## Re class

Klassen representerar re-operatorn (lägg till rektangel till banan).

Re-typen visar följande medlemmar:
## Konstruktörer
| Namn | Beskrivning |
| :- | :- |
| Re() | Initierar operatören. |
| Re(x, y, width, height) | Initierar en ny instans av Re-klassen |
## Egenskaper
| Namn | Beskrivning |
| :- | :- |
| index | Operatörsindex i sidans operatörslista. |
| x | X-koordinat för den mest vänstra sidan av rektangeln. |
| y | Y-koordinat för den nedre sidan av rektangeln. |
| bredd | Bredden på rektangeln. |
| höjd | Höjden på rektangeln. |
## Metoder
| Namn | Beskrivning |
| :- | :- |
| accept(visitor) | Accepterar besökarobjekt för att bearbeta operatorn. |
| is_text_show_operator(op) | Avgör om operatören är den operatör som ansvarar för textutmatning (Tj, TJ, osv). |
