Representerar en klass för att kontrollera komprometterade signaturer i dokumentet. Detektorn kontrollerar endast kända sätt att kompromettera signaturer. Verifiering kan inte ge en 100 % garanti för avsaknad av signaturkompromettering och kan ge ett falskt negativt resultat för nya, okända komprometteringsmetoder som skiljer sig från de som testas.
