```
public interface ITociElement
```

Representerar ett element som kan fungera som ett innehållsförteckningspost (TOCI) i ett taggat PDF‑dokument. Detta gränssnitt abstraherar både standard‑TOCI‑element och List Item (LI)‑element som används i nästlade innehållsförteckningsstrukturer.

## Metoder

| Metod | Beskrivning |
| --- | --- |
| [getGetElement](#getGetElement--) | Hämtar det underliggande PDF-elementet som representerar denna TOCI-struktur. |

### getGetElement {#getGetElement--}
```
StructureElement getGetElement()
```

Hämtar det underliggande PDF-elementet som representerar denna TOCI-struktur.

**Returns:**
Elementet som bildar den strukturella representationen av denna innehållsförteckningspost.
