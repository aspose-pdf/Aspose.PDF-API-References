Enumererar lägen som kan användas för att spara teckensnitt som refereras i sparad PDF.

## Fält

| Fält | Beskrivning |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | Alla refererade typsnitt kommer att sparas och refereras som EOT-typsnitt. |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | Alla refererade typsnitt kommer att sparas och refereras som TTF-typsnitt. |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | Alla refererade typsnitt kommer att sparas och refereras som WOFF-typsnitt. |
| [DontSave](#DontSave) | Alla refererade typsnitt kommer inte att sparas. |
| [SaveInAllFormats](#SaveInAllFormats) | Alla refererade typsnitt kommer att sparas (och refereras i CSS) som 3 oberoende filer: EOT, TTH, WOFF. Det ökar storleken på utdata men gör utdata lämplig för den överväldigande majoriteten av webbläsare. |
