Du kan tilldela den här egenskapen en delegat skapad från en anpassad metod som implementerar skapandet av URL för CSS som refereras i det genererade HTML‑dokumentet. T.ex. om du vill göra CSS refererad i HTML som "otherPage.ASPX?CssID=zjjkklj" måste en sådan anpassad strategi returnera "otherPage.ASPX?CssID=zjjkklj".
