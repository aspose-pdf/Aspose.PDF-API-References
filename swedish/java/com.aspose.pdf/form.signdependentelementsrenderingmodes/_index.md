Formulär kan innehålla signeringsinformation och kan vara signerade eller osignerade. Ibland måste visningen av formulär i visaren bero på om formuläret är signerat eller inte. Denna enum listar möjliga renderingslägen under konvertering av formulärtypen med avseende på signatur.
