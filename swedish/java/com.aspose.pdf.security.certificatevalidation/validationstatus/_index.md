Representerar valideringsstatusen för en certifikatvalidering. Denna uppräkning definierar möjliga utfall av certifikatvalidering: - Valid: Anger att certifikatet har validerats framgångsrikt. - Invalid: Anger att certifikatvalideringen misslyckades. - Undefined: Anger att valideringsprocessen var oavgjord eller inte utförd.
