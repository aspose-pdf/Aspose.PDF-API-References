## Klasser

| Klass | Beskrivning |
| --- | --- |
| [ValidationMethod](./validationmethod/) | Representerar en enum som definierar metoden som används för certifikatvalidering. |
| [ValidationMode](./validationmode/) | Anger valideringsläget för PDF‑signaturvalideringsprocesser. |
| [ValidationOptions](./validationoptions/) | Representerar alternativ för att validera en digital signatur i ett PDF‑dokument. |
| [ValidationResult](./validationresult/) | Representerar resultatet av en valideringsprocess för ett certifikat. Klassen ValidationResult tillhandahåller information om utfallet av certifikatvalideringen, inklusive dess status och ett meddelande som beskriver eventuella problem som uppstod under valideringen. |
| [ValidationStatus](./validationstatus/) | Representerar valideringsstatusen för en certifikatvalidering. Denna uppräkning definierar möjliga utfall av certifikatvalidering: - Valid: Anger att certifikatet har validerats framgångsrikt. - Invalid: Anger att certifikatvalideringen misslyckades. - Undefined: Anger att valideringsprocessen var oavgjord eller inte utförd. |
