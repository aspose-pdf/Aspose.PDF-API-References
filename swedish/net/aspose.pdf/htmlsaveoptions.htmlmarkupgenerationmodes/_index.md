## HtmlSaveOptions.HtmlMarkupGenerationModes enumeration

Ibland finns specifika krav för att skapa HTML. Detta enum definierar HTML-förberedelselägen som kan användas under konvertering av PDF till HTML för att matcha sådana specifika krav.

```csharp
public enum HtmlMarkupGenerationModes
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| WriteAllHtml | `0` | Standardläge när inga specifika krav finns. Det genererade resultatet kommer att innehålla alla delar av HTML utan någon särskild extra bearbetning. |
| WriteOnlyBodyContent | `1` | allt HTML-innehåll som ligger utanför HTML:s body kommer att tas bort, dvs. endast innehåll som finns inom \c \ \c \-taggarna kommer att kvarstå. |
