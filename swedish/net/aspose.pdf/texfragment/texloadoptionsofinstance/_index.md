## TeXFragment.TeXLoadOptionsOfInstance property

Hämtar eller sätter TeXLoadOptions som kommer att användas för inläsning (och rendering) av LaTeX i detta klass‑instans. Använd den när det är nödvändigt att använda specifika inställningar för import av LaTeX för denna eller den där instansen (t.ex. när denna eller den där instansen ska använda en specifik BasePath för importerad LaTeX eller ska använda en specifik laddare för externa resurser). Om parametern är standard (null) kommer standardalternativen för LaTeX‑inläsning att användas.

```csharp
public TeXLoadOptions TeXLoadOptionsOfInstance { get; set; }
```
