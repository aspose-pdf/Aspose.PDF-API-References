## HtmlSaveOptions.FontSavingModes enumeration

Enumererar lägen som kan användas för att spara teckensnitt som refereras i sparad PDF.

```csharp
public enum FontSavingModes
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| AlwaysSaveAsWOFF | `0` | Alla refererade teckensnitt kommer att sparas och refereras som WOFF-teckensnitt. |
| AlwaysSaveAsTTF | `1` | Alla refererade teckensnitt kommer att sparas och refereras som TTF-teckensnitt. |
| AlwaysSaveAsEOT | `2` | Alla refererade teckensnitt kommer att sparas och refereras som EOT-teckensnitt. |
| SaveInAllFormats | `3` | Alla refererade teckensnitt kommer att sparas (och refereras i CSS) som 3 separata filer: EOT, TTH, WOFF. Det ökar storleken på utdata men gör utdata lämplig för en överväldigande majoritet av webbläsare. |
| DontSave | `4` | Alla refererade teckensnitt kommer inte att sparas. |
