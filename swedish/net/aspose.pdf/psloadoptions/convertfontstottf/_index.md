## PsLoadOptions.ConvertFontsToTTF property

Anger om icke‑TrueType‑typsnitt ska sparas som TTF. Det minskar avsevärt volymen på det resulterande dokumentet vid PS‑till‑PDF‑konvertering och ökar hastigheten för konvertering av PS‑filer med stor mängd text i icke‑TrueType‑typsnitt till vilket output‑format som helst. Däremot uppstår en liten vertikal förskjutning av texten när en PostSctipt‑fil konverteras till bild.

```csharp
public bool ConvertFontsToTTF { get; set; }
```
