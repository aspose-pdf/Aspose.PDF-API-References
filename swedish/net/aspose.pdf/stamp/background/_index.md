## Stamp.Background property

Ställer in eller hämtar ett booleskt värde som indikerar att innehållet är stämplat som bakgrund. Om värdet är true läggs stämpelns innehåll längst ner. Som standard är värdet false, och stämpelns innehåll läggs överst.

public bool Background { get; set; }
