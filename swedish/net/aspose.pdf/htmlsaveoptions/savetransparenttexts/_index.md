## HtmlSaveOptions.SaveTransparentTexts field

PDF kan innehålla transparenta texter som kan markeras till urklipp (vanligtvis sker detta när dokumentet innehåller bilder och OCR‑extraherade texter). Denna inställning talar om för konverteraren huruvida vi ska spara sådana texter som transparenta markerbara texter i resultat‑HTML.

```csharp
public bool SaveTransparentTexts;
```
