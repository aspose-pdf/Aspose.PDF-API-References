## HtmlSaveOptions.ConvertMarkedContentToLayers property

Om attributet ConvertMarkedContentToLayers är satt till true placeras alla element inom ett PDF-märkt innehåll (lager) i en HTML-div med attributet "data-pdflayer" som specificerar ett lagernamn. Detta lagernamn extraheras från valfria egenskaper för PDF-märkt innehåll. Om detta attribut är false (standard) skapas inga lager från PDF-märkt innehåll.

```csharp
public bool ConvertMarkedContentToLayers { get; set; }
```
