## Document.AllowReusePageContent property

Tillåter att slå ihop page‑innehåll för att optimera document‑storlek. Om den används kan olika men duplicerade pages referera till samma innehållsobjekt. Observera att detta läge kan orsaka bieffekter som att ändra page‑innehåll när en annan page ändras.

public bool AllowReusePageContent { get; set; }
