## ColumnInfo.ColumnSpacing property

Hämtar eller anger en sträng som innehåller avståndet mellan kolumner. Värdet för varje avstånd bör separeras med blanksteg. Standardenheten är punkt, men cm och tum stöds också. Till exempel, "120 2.5cm 1.5inch".

```csharp
public string ColumnSpacing { get; set; }
```

## Anmärkningar

Om denna egenskap inte är angiven används standardvärdet 0 för varje avstånd.
