## PasswordType enumeration

Denna enum representerar kända lösenordstyper som används för lösenordsskyddade pdf-dokument.

```csharp
public enum PasswordType
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | `0` | Pdf-dokumentet är inte lösenordsskyddat. |
| User | `1` | Pdf-dokumentet öppnades med dokumentöppningslösenord (begränsad åtkomst). |
| Owner | `2` | Pdf-dokumentet öppnades med lösenord för att ändra behörigheter (full åtkomst). |
| Inaccessible | `3` | Pdf-dokumentet är lösenordsskyddat men både användar- och ägarlösenorden är inte tomma och inget av lösenorden var definierat eller angivet lösenord var felaktigt. Så det är omöjligt att avgöra vilken typ av lösenord som används. |
