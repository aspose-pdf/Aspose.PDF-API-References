## AutoTaggingSettings.EnableAutoTagging property

Hämtar eller anger ett värde som indikerar om den automatiska taggningsfunktionen är aktiverad.

```csharp
public bool EnableAutoTagging { get; set; }
```

## Anmärkningar

När den är aktiverad genererar den automatiska taggningsfunktionen automatiskt taggat innehåll för PDF-dokumentet, vilket kan förbättra tillgänglighet och struktur.
