## OptimizedMemoryStream.Write method

När den åsidosätts i en avledd klass, skriver den en sekvens av byte till den aktuella strömmen och flyttar den aktuella positionen i strömmen framåt med antalet skrivna byte.

```csharp
public override void Write(byte[] buffer, int offset, int count)
```

| Parameter | Typ | Beskrivning |
| --- | --- | --- |
| buffert | Byte[] | En array av byte. Denna metod kopierar *count* byte från *buffer* till den aktuella strömmen. |
| offset | Int32 | Det nollbaserade byteoffsetet i *buffer* där kopieringen av byte till den aktuella strömmen ska börja. |
| antal | Int32 | Antalet byte som ska skrivas till den aktuella strömmen. |
