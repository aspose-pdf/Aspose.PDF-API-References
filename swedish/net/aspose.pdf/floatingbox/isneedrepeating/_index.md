## FloatingBox.IsNeedRepeating property

Hämtar eller anger ett booleskt värde som indikerar om stycket ska upprepas på nästa sida. Standardvärdet är false. Attributet är endast giltigt när själva stycket och det objekt som dess ReferenceParagraphID refererar till båda ingår i RepeatingRows.

```csharp
public bool IsNeedRepeating { get; set; }
```
