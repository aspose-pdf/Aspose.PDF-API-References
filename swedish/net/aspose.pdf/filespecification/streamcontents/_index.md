## FileSpecification.StreamContents property

Hämtar filens innehåll som en ström. Innehållet laddas inte in i minnet, vilket möjliggör minskad minnesanvändning. Men denna ström stöder inte positionering och Length-egenskapen. Om du behöver dessa funktioner, använd egenskapen Contents istället.

```csharp
public Stream StreamContents { get; }
```
