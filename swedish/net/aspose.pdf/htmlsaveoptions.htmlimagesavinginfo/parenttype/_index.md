## HtmlSaveOptions.HtmlImageSavingInfo.ParentType field

Den sparade bilden kan hänvisa till HTML själv eller kan extraheras från SVG som är inbäddad i HTML. Denna egenskap kan berätta för anpassad kod vilken typ av förälder den bearbetade bilden har. Den sätts av konverteraren och kan användas i anpassad kod för att avgöra vad som ska göras med bilden (t.ex. kan anpassad kod bestämma var bilden ska sparas eller hur den ska refereras i förälderns innehåll).

```csharp
public ImageParentTypes ParentType;
```
