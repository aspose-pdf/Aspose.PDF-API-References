## RenderingOptions.ConvertFontsToUnicodeTTF property

Indikerar att alla teckensnitt kommer att konverteras till TTF-unicode-versioner. Detta är användbart av kompatibilitetsskäl och för att optimera teckensnittsanvändning, eftersom varje nytt TTF-teckensnitt bara innehåller de symboler som används i texten, inte alla symboler från källteckensnittet.

```csharp
public bool ConvertFontsToUnicodeTTF { get; set; }
```
