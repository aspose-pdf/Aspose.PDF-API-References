Namnområdet **Aspose.Pdf.Security** innehåller klasser som används för kryptering och digital signering.

## Klasser

| Klass | Beskrivning |
| --- | --- |
| [CertificateEncryptionOptions](./certificateencryptionoptions/) | Representerar en klass för krypteringsalternativ för ett PDF-dokument med en certifikatbaserad krypteringsmetod. Används för att öppna krypterade PDF-dokument. |
| [DsaAlgorithmInfo](./dsaalgorithminfo/) | Representerar en klass för information om DSA-signaturalgoritmen. |
| [EcdsaAlgorithmInfo](./ecdsaalgorithminfo/) | Representerar en klass för information om ECDSA-signaturalgoritmen. |
| [EncryptionParameters](./encryptionparameters/) | Representerar en klass för krypteringsparametrar. |
| [KeyedSignatureAlgorithmInfo](./keyedsignaturealgorithminfo/) | Representerar en klass för information om en nyckelbaserad signaturalgoritm. |
| [RsaAlgorithmInfo](./rsaalgorithminfo/) | Representerar en klass för information om RSA-signaturalgoritmen. |
| [SignatureAlgorithmInfo](./signaturealgorithminfo/) | Representerar en klass för information om en signaturalgoritm, inklusive dess typ, kryptografiska standard och hash-algoritm för digest. |
| [SignatureLengthMismatchException](./signaturelengthmismatchexception/) | Representerar fel som uppstår under PDF-signering. Uppstår om [`SignHash`](../aspose.pdf.forms/signhash/) används för att signera ett dokument och den faktiska längden på signaturen är större än den som anges i alternativet [`DefaultSignatureLength`](../aspose.pdf.forms/signature/defaultsignaturelength/). |
| [TimestampAlgorithmInfo](./timestampalgorithminfo/) | Representerar en klass för information om tidsstämpel-signaturalgoritmen. |
| [UnknownSignatureAlgorithmInfo](./unknownsignaturealgorithminfo/) | Representerar en klass för information om en okänd signaturalgoritm. |
| [ValidationOptions](./validationoptions/) | Representerar alternativ för validering av en digital signatur i ett PDF-dokument. |
| [ValidationResult](./validationresult/) | Representerar resultatet av en valideringsprocess för ett certifikat. |
