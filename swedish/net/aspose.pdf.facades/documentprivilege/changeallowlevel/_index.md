## DocumentPrivilege.ChangeAllowLevel property

Hämtar och anger ändringsnivån för dokumentets behörighet. På samma sätt som Adobe Professionals inställning för tillåtna ändringar. 0: Ingen. 1: Infoga, ta bort och rotera sidor. 2: Fyll i formulärfält och signera befintliga signaturfält. 3: Kommentera, fylla i formulärfält och signera befintliga signaturfält. 4: Allt förutom att extrahera sidor.

```csharp
public int ChangeAllowLevel { get; set; }
```

## Anmärkningar

Om egenskapen har värdet -1 är nivån odefinierad.
