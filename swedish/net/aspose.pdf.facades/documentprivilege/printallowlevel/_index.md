## DocumentPrivilege.PrintAllowLevel property

Hämtar och anger utskriftsnivån för dokumentets behörighet. På samma sätt som Adobe Professionals inställning för tillåten utskrift. 0: Ingen. 1: Låg upplösning (150 dpi). 2: Hög upplösning.

```csharp
public int PrintAllowLevel { get; set; }
```

## Anmärkningar

Om egenskapen har värdet -1 är nivån odefinierad.
