## PdfViewer.AutoResize property

Hämtar eller anger ett booleskt värde som indikerar om filen ska skrivas ut med optimerad storlek.  Om falskt skrivs sidan ut utan skalning. Om sant skrivs sidan ut med skalning för att passa det utskrivbara området.

public bool AutoResize { get; set; }
