## PdfViewer.PrintAsImage property

Anger eller hämtar ett läge för PdfViewer att skriva ut som bild.

```csharp
public bool PrintAsImage { get; set; }
```

## Anmärkningar

Om true skrivs alltid ut som bild (genererar en bild som skrivs ut). Om false skrivs direkt till enhet om alla funktioner stöds. Om dokumentet innehåller funktioner som inte stöds kan systemet automatiskt besluta att skriva ut som bild. Standardvärdet är false.
