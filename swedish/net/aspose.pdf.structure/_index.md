Namnområdet **Aspose.Pdf.Structure** tillhandahåller klasser som hjälper till att arbeta med ett dokuments logiska struktur, vilket presenterar dokumentets organisation i kapitel och sektioner samt identifiering av speciella element som figurer, tabeller och fotnoter.

| Klass | Beskrivning |
| --- | --- |
| [Element](./element/) | Klassen som representerar baselementet i den logiska strukturen. |
| [ElementCollection](./elementcollection/) | Samling av baslogiska strukturelement. |
| [FigureElement](./figureelement/) | Klass som representerar logisk strukturell figur. |
| [RootElement](./rootelement/) | Rotstrukturselement. |
| [StructElement](./structelement/) | Allmänt strukturselement. |
| [TextElement](./textelement/) | Allmänt textelement i dokumentets logiska struktur. |
