## FitHExplicitDestination class

Representerar en explicit destination som visar sidan med den vertikala koordinaten top placerad vid fönstrets övre kant och sidans innehåll förstorat precis så att hela sidans bredd får plats i fönstret. Ett null-värde för top anger att det aktuella värdet för den parametern ska behållas oförändrat.

```csharp
public sealed class FitHExplicitDestination : ExplicitDestination
```
