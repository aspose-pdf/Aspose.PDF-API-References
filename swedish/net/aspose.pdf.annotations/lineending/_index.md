
### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | `0` | Ingen linjeändning. |
| Square | `1` | En kvadrat fylld med annoteringens inre färg, om någon. |
| Circle | `2` | En cirkel fylld med annoteringens inre färg, om någon. |
| Diamond | `3` | En diamantform fylld med annoteringens inre färg, om någon. |

| ClosedArrow | `5` | Två korta linjer som möts i en spetsig vinkel enligt OpenArrow-stilen och kopplas ihop av en tredje linje för att bilda ett triangulärt slutet pilhuvud fyllt med annoteringens inre färg, om någon. |
| Butt | `6` | En kort linje vid ändpunkten vinkelrät mot själva linjen. |
| ROpenArrow | `7` | Två korta linjer i motsatt riktning från OpenArrow. |
| RClosedArrow | `8` | Ett triangulärt slutet pilhuvud i motsatt riktning från ClosedArrow. |
| Slash | `9` | En kort linje vid ändpunkten ungefär 30 grader medurs från vinkelrät mot själva linjen. |
