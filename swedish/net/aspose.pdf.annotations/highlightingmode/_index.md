## HighlightingMode enumeration

Enumererar annotationens markeringsläge, den visuella effekten som ska användas när musknappen trycks ned eller hålls ned i dess aktiva område.

```csharp
public enum HighlightingMode
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | `0` | Ingen markering. |
| Invert | `1` | Invertera innehållet i annoteringsrektangeln. |
| Outline | `2` | Invertera annoteringens kant. |
| Push | `3` | Visa annoteringens nedre utseende, om något finns. Om inget nedre utseende är definierat, förskjut innehållet i annoteringsrektangeln så att det ser ut som om det trycks ner under sidans yta. |
| Toggle | `4` | Samma som Push (vilket föredras). |
