## BaseListQueryParameters.Before property

Hämtar eller anger en markör för användning i paginering. before är ett objekt‑ID som definierar din position i listan. Till exempel, om du gör en listförfrågan och får 100 objekt, avslutade med obj_foo, kan ditt efterföljande anrop inkludera before=obj_foo för att hämta föregående sida av listan.

public string Before { get; set; }
