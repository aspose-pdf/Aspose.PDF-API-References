## CompletionCreateRequest.ResponseFormat property

Hämtar eller anger ett objekt som specificerar det format som modellen måste producera. Kompatibel med GPT-4 Turbo och alla GPT-3.5 Turbo-modeller nyare än gpt-3.5-turbo-1106. Att sätta till { \"type\": \"json_object\" } aktiverar JSON-läge, vilket garanterar att meddelandet som modellen genererar är giltig JSON.
