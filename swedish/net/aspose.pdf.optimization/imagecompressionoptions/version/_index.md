## ImageCompressionOptions.Version property

Version av komprimeringsalgoritmen. Möjliga värden är: 1. standardkomprimering, 2. fast (förbättrad komprimering som är snabbare än standard men kan vara otillämplig för vissa bilder), 3. blandad (standardkomprimering tillämpas på bilder som inte kan komprimeras av den snabbare algoritmen, detta kan ge bästa komprimering men är långsammare än \"fast\"-algoritmen. Versionen \"Fast\" är inte tillämplig för att ändra bildstorlek (standardmetoden kommer att användas). Standard är \"Standard\".

public ImageCompressionVersion Version { get; set; }
