## OptimizationOptions.RemoveUnusedObjects property

Om denna flagga är satt till true kommer alla document-objekt att kontrolleras och oanvända objekt (dvs. objekt som inte har någon referens) tas bort från document.

```csharp
public bool RemoveUnusedObjects { get; set; }
```
