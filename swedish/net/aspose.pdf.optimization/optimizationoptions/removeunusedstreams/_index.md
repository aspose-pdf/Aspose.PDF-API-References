## OptimizationOptions.RemoveUnusedStreams property

Om denna flagga är satt till true kontrolleras varje resource för dess användning. Om en resource aldrig används tas resource bort. Detta kan minska dokumentets storlek, till exempel när sidor har extraherats från document.

```csharp
public bool RemoveUnusedStreams { get; set; }
```
