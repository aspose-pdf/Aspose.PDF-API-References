## OptimizationOptions.LinkDuplicateStreams property

Om denna flagga är satt till true kommer Resource streams att analyseras. Om dubblettströmmar hittas (dvs. om strömmens innehåll är lika) kommer dessa strömmar att lagras som ett objekt. Detta möjliggör att minska dokumentets storlek i vissa fall (till exempel när samma dokument har concatenedted flera gånger).

```csharp
public bool LinkDuplicateStreams { get; set; }
```
