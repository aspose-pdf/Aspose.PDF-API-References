## PdfAOptionsBase.FontEmbeddingOptions property

Hämtar alternativ för att bearbeta teckensnitt som inte kan bäddas in i dokumentet.

```csharp
public FontEmbeddingOptions FontEmbeddingOptions { get; }
```

### Property Value

Alternativen för typsnittsinbäddning.

## Anmärkningar

PDF/A‑standarden kräver att alla typsnitt måste bäddas in i dokumentet. Denna egenskap ger alternativ för att hantera situationer där vissa typsnitt inte kan bäddas in eftersom de saknas på mål‑PC:n.
