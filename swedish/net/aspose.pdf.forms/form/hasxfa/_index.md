## Form.HasXfa property

Hämtar ett värde som indikerar om dokumentet innehåller XFA-formulär. Denna egenskap introducerades för att avgöra om [`IgnoreNeedsRendering`](../ignoreneedsrendering/) ska användas för att ta bort XFA-formuläret i fall där XFA-formuläret är närvarande och [`NeedsRendering`](../needsrendering/) är falskt.

```csharp
public bool HasXfa { get; }
```
