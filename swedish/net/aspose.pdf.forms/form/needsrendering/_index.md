## Form.NeedsRendering property

Hämtar ett värde som indikerar om dokumentet kräver borttagning av det dynamiska XFA-formuläret. Denna egenskap introducerades för att avgöra om [`IgnoreNeedsRendering`](../ignoreneedsrendering/) ska användas för att ta bort XFA-formuläret i fall där XFA-formuläret är närvarande och `NeedsRendering` är falskt.

```csharp
public bool NeedsRendering { get; }
```
