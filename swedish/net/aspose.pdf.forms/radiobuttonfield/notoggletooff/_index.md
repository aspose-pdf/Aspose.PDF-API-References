## RadioButtonField.NoToggleToOff property

Hämtar eller anger flaggan som tillåter radioknappen att ha inget valt värde. Om `true` ska exakt en radioknapp vara vald hela tiden; att välja den redan valda knappen har ingen effekt. Om `false` avmarkerar ett klick på den valda knappen den, så att ingen knapp är vald.

```csharp
public bool NoToggleToOff { get; set; }
```

## Anmärkningar

Vissa PDF-läsare (inklusive Adobe Acrobat) kan ignorera flaggans `false`-tillstånd.
