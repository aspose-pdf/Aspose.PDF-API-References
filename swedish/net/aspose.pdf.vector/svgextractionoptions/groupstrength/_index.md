## SvgExtractionOptions.GroupStrength property

Hämtar och anger ett alternativ Styrkan för gruppering av delvägar till bilder. Tillåter dig att konfigurera graden av gruppering av delvägar. Värdet varierar från 0 till 1. Ett värde på 0 motsvarar att alternativet [`ExtractEverySubPathToSvg`](../extracteverysubpathtosvg/) är aktiverat. Ett värde på 1 skapar en enda bild för alla vektorpågar på sidan. Alternativet har effekt när [`AutoGrouping`](../autogrouping/) är falskt. Standardvärdet är `0.8`.

```csharp
public double GroupStrength { get; set; }
```
