## SvgExtractionOptions.MinStrokeWidth property

Hämtar eller anger den minsta streckbredden som kommer att användas i den resulterande SVG:n. Om PDF använder en tunnare streckbredd ersätts den med denna bredd. Standardvärdet är 0.5.

```csharp
public double MinStrokeWidth { get; set; }
```

## Anmärkningar

Värdet uttrycks i transformerade enheter i användarutrymmet för den konverterade PDF‑sidan. Som standard är 1 enhet i användarutrymmet 1/72 tum (0,35 mm), men detta kan åsidosättas av PDF‑dokumentet. Transformationer kan påverka den faktiska minsta bredden i den genererade SVG‑filen.
