## SideBySideComparisonOptions.ExcludeAreas1 property

Hämta och ange de exkluderade områdena. Används för den första sidan eller dokumentet i jämförelsemetoden. Detta alternativ kan ställas in tillsammans med [`ExcludeTables`](../excludetables/). Detta alternativ kan inte ställas in tillsammans med [`ComparisonArea1`](../comparisonarea1/)-alternativet.

public Rectangle[] ExcludeAreas1 { get; set; }
