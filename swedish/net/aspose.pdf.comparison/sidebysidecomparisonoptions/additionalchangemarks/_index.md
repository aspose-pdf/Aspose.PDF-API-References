## SideBySideComparisonOptions.AdditionalChangeMarks property

Hämta och ange egenskapen som bestämmer om ytterligare ändringsmarkörer visas. Om den är satt visas ändringsmarkörer som inte finns på den aktuella sidan men som finns på en annan sida. Om ändringen ligger mellan ord kan markören eventuellt inte placeras exakt i förhållande till blankstegstecknet. Standardvärdet är `false`.

```csharp
public bool AdditionalChangeMarks { get; set; }
```
