## SideBySideComparisonOptions.ExcludeAreas2 property

Hämta och ange de exkluderade områdena. Används för den andra sidan eller dokumentet i jämförelsemetoden. Detta alternativ kan ställas in tillsammans med [`ExcludeTables`](../excludetables/). Detta alternativ kan inte ställas in tillsammans med [`ComparisonArea2`](../comparisonarea2/)-alternativet.

public Rectangle[] ExcludeAreas2 { get; set; }
