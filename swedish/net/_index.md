## Namnområden

| Namnområde | Beskrivning |
| --- | --- |
| [Aspose.Pdf](./aspose.pdf/) | Den **Aspose.Pdf** är ett rot‑namnområde för alla klasser i Aspose.Pdf‑biblioteket som antingen finns direkt i det, som **Document**, eller indirekt via flera undernamnområden. |
| [Aspose.Pdf.AI](./aspose.pdf.ai/) | Namnområdet **Aspose.Pdf.AI** tillhandahåller klasser för AI‑funktioner, inklusive API‑klienter och intelligenta assistenter. |
| [Aspose.Pdf.Annotations](./aspose.pdf.annotations/) | Namnområdet **Aspose.Pdf.Annotations** tillhandahåller klasser för att arbeta med olika typer av åtgärder, destinationer och andra funktioner i dokumentet som traditionellt kallas interaktiva och ger användaren möjlighet att kommunicera med det. |
| [Aspose.Pdf.Comparison](./aspose.pdf.comparison/) | Namnområdet **Aspose.Pdf.Comparison** tillhandahåller klasser som används för dokumentjämförelse. |
| [Aspose.Pdf.DataEditor](./aspose.pdf.dataeditor/) | Den **Aspose.Pdf.DataEditor** innehåller verktyg för att redigera data i ett dokument. |
| [Aspose.Pdf.Devices](./aspose.pdf.devices/) | Namnområdet **Aspose.Pdf.Devices** tillhandahåller klasser som används för att representera ett dokument som bild(er) eller ren text. Så kan dokumentet skickas till text‑ eller olika grafiska enheter, vilket innebär att vi får en textuell eller grafisk representation. |
| [Aspose.Pdf.Drawing](./aspose.pdf.drawing/) | Namnområdet **Aspose.Pdf.Drawing** tillhandahåller klasser som beskriver grafiska primitiv som båge, linje, cirkel etc. Motsvarande objekt kan användas för att skapa nya dokument. |
| [Aspose.Pdf.Facades](./aspose.pdf.facades/) | Namnområdet **Aspose.Pdf.Facades** tillhandahåller klasser som ursprungligen kom från Aspose.Pdf.Kit. Dessa klasser används för att manipulera dokument genom operationer som sammanslagning, stämpling, signering, annotering etc., men på en hög nivå utan åtkomst till dokumentets interna struktur. |
| [Aspose.Pdf.Forms](./aspose.pdf.forms/) | Namnområdet **Aspose.Pdf.Forms** har klasser som beskriver formulär (standard, statiska, dynamiska) och olika typer av fält som textruta, listruta, radioknapp etc. |
| [Aspose.Pdf.LogicalStructure](./aspose.pdf.logicalstructure/) | Namnområdet **Aspose.Pdf.Tagged.LogicalStructure** är ett namnrum för klasser för PDF‑logisk struktur. |
| [Aspose.Pdf.Multithreading](./aspose.pdf.multithreading/) | Namnområdet **Aspose.Pdf.Multithreading** tillhandahåller klasser som är avsedda att användas i multitrådade scenarier. |
| [Aspose.Pdf.Operators](./aspose.pdf.operators/) | Namnområdet **Aspose.Pdf.Operators** är ett namnrum för implementationer av operatorer. Dessa klasser beskriver operatorer som används i PDF‑sidinnehåll. |
| [Aspose.Pdf.Optimization](./aspose.pdf.optimization/) | Namnområdet **Aspose.Pdf.Optimization** är ett namnrum för klasser som hanterar dokumentoptimeringsprocessen. |
| [Aspose.Pdf.Plugins](./aspose.pdf.plugins/) | Namnområdet **Aspose.Pdf.Plugins** är ett rot‑namnområde för alla klasser i Aspose.Pdf.Plugins som antingen finns direkt i det, som **PdfOrganizer**, eller indirekt via flera undernamnområden. |
| [Aspose.Pdf.Printing](./aspose.pdf.printing/) | Namnområdet **Aspose.Pdf.Printing** tillhandahåller klasser och funktioner för att hantera PDF‑utskriftsoperationer, inklusive skrivarinställningar, sidinställningar och tillägg för att hantera utskriftsrelaterade konfigurationer. |
| [Aspose.Pdf.Sanitization](./aspose.pdf.sanitization/) | Namnområdet **Aspose.Pdf.Sanitization** är ett namnrum för saneringsoperationer. |
| [Aspose.Pdf.Security](./aspose.pdf.security/) | Namnområdet **Aspose.Pdf.Security** innehåller klasser som används för kryptering och digital signering. |
| [Aspose.Pdf.Signatures](./aspose.pdf.signatures/) | Namnområdet **Aspose.Pdf.Signatures** innehåller klasser som används för att upptäcka komprometterade signaturer. |
| [Aspose.Pdf.Structure](./aspose.pdf.structure/) | Namnområdet **Aspose.Pdf.Structure** tillhandahåller klasser som hjälper till att arbeta med ett dokuments logiska struktur, vilket presenterar dokumentets organisation i kapitel och sektioner samt identifiering av speciella element som figurer, tabeller och fotnoter. |
| [Aspose.Pdf.Tagged](./aspose.pdf.tagged/) | Den **Aspose.Pdf.Tagged** är ett namnrymd för klasser för stöd av Tagged PDF-dokument. |
| [Aspose.Pdf.Text](./aspose.pdf.text/) | Den **Aspose.Pdf.Text** namnrymden tillhandahåller klasser som möjliggör att extrahera text, lägga till text, manipulera befintlig text i ett dokument. Den innehåller också klasser som möjliggör att extrahera, ersätta och byta ut teckensnitt i ett dokument. |
| [Aspose.Pdf.Vector](./aspose.pdf.vector/) | Den **Aspose.Pdf.Vector** är ett rot‑namnrymd för grafikoperationer. |
| [Aspose.Pdf.XfaConverter](./aspose.pdf.xfaconverter/) | Den **Aspose.Pdf.XfaConverter** namnrymden tillhandahåller klasser som möjliggör att konvertera XFA. |
