## ParagraphAbsorberOptions.SectionUnbreakingVerticalOverride property

Hämtar eller anger den maximala längden på zonen med 'zero filling level' som inte kommer att behandlas som ett faktiskt vertikalt sektionsavbrott (som en bråkdel av sidans bredd / höjd). Standardvärdet är 0,005.

public double SectionUnbreakingVerticalOverride { get; set; }
