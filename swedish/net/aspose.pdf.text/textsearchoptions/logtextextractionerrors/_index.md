## TextSearchOptions.LogTextExtractionErrors property

Hämtar eller anger indikation på att fel vid textutvinning (avkodning) ska loggas i text (fragment) absorberaren. true - betyder att fel vid textutvinning (avkodning) kommer att loggas. Detta kan minska prestandan. false (standard) - ingen felloggning.

public bool LogTextExtractionErrors { get; set; }
