## TextSearchOptions.IgnoreShadowText property

Hämtar eller anger indikation på att textfragment som representerar skuggan av normal text ska ignoreras under sökning. true - betyder att skuggtext inte kommer att hittas (prova detta om textsökning returnerar duplicerade fragment på nära positioner). false - betyder att skuggtext kommer att hittas lika med normal text (standardvärde).

```csharp
public bool IgnoreShadowText { get; set; }
```
