## TextSearchOptions.UseFontEngineEncoding property

Hämtar eller anger indikation på att text kommer att sökas med teckensnittsmotorns kodning. true – betyder att teckensnittsmotorns kodning kommer att användas (försök detta om textsökning misslyckas på grund av bristfällig kodning i dokumentet). false – betyder att dokumentets teckensnittskodning kommer att användas (standardvärde).

```csharp
public bool UseFontEngineEncoding { get; set; }
```
