## CustomFontSubstitutionBase.OriginalFontSpecification.IsSubstitutionUnavoidable property

Hämtar ett värde som indikerar att ersättningen är oundviklig.

```csharp
public bool IsSubstitutionUnavoidable { get; }
```

## Anmärkningar

Returnerar true om ersättningen begärdes på grund av att det ursprungliga teckensnittet saknas eller om det ursprungliga teckensnittet inte kan användas i samband med någon uppgift. Om användaren ignorerar flaggan och inte ersätter teckensnittet - utförs standardproceduren för teckensnittsersättning. Men det ger möjlighet för användaren att byta standardproceduren för teckensnittsersättning och ange ett bättre teckensnitt till systemet. Returnerar false om det ursprungliga teckensnittet finns, är giltigt, men det är tillåtet för användaren att ersätta det.
