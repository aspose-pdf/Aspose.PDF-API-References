## TextReplaceOptions.FontSizeAdjustment enumeration

Anger en policy för hur teckensnittsstorleken på texten ska justeras för att passa inom ett omgivande område.

```csharp
public enum FontSizeAdjustment
```

### Värden

| Namn | Värde | Beskrivning |
| --- | --- | --- |
| None | `0` | Teckensnittsstorleken ändras inte. |
| ShrinkToFit | `1` | Teckensnittsstorleken minskas om texten är för stor för att passa inom gränserna. Teckensnittsstorleken ökas aldrig om texten är mindre än gränserna. |
| ScaleToFill | `2` | Teckensnittsstorleken justeras (både minskning och ökning) för att få texten att fylla rektangelns gränser så mycket som möjligt. |
