## ThumbnailDevice class

Representa un dispositivo de imagen que guarda las páginas del documento pdf en una imagen en miniatura.

El tipo ThumbnailDevice expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ThumbnailDevice() | Inicializa una nueva instancia de la clase [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) <br/>            con el tamaño predeterminado de la imagen miniatura (200x200 píxeles). |
| ThumbnailDevice(width, height) | Inicializa una nueva instancia de la clase ThumbnailDevice |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| coordinate_type | Obtiene o establece el tipo de coordenadas de la página (cajas Media/Crop). El valor CropBox se usa por defecto. |
| rendering_options | Obtiene o establece las opciones de renderizado. |
| form_presentation_mode | Obtiene o establece el modo de presentación del formulario. |
| resolution | Obtiene la resolución de la imagen. |
| ancho | Obtiene el ancho de salida de la imagen. |
| alto | Obtiene la altura de salida de la imagen. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| process(page, output) | Convierte la página a imagen miniatura png y la guarda en el flujo de salida. |
| process(page, output_file_name) | Convierte la página a imagen miniatura png y la guarda en el flujo de salida. |
