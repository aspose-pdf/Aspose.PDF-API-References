## TextDevice class

Representa una clase para convertir las páginas del documento pdf en texto.

El tipo TextDevice expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextDevice(extraction_options) | Inicializa una nueva instancia de la clase TextDevice |
| TextDevice() | Inicializa una nueva instancia de [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) con el modo de formato de texto sin procesar y codificación de texto Unicode. |
| TextDevice(encoding) | Inicializa una nueva instancia de la clase TextDevice |
| TextDevice(extraction_options, encoding) | Inicializa una nueva instancia de la clase TextDevice |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| extraction_options | Obtiene o establece las opciones de extracción de texto. |
| codificación | Obtiene o establece la codificación del texto extraído. |
## Métodos
| Nombre | Descripción |
| :- | :- |

| process(page, output_file_name) | Convierte la página y la guarda como flujo de texto. |
