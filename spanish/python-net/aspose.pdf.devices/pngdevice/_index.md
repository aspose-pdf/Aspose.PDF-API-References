## PngDevice class

Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en png.

El tipo PngDevice expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PngDevice() | Inicializa una nueva instancia de la clase [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) con resolución predeterminada. |
| PngDevice(resolution) | Inicializa una nueva instancia de la clase PngDevice |
| PngDevice(width, height, resolution) | Inicializa una nueva instancia de la clase PngDevice |
| PngDevice(page_size, resolution) | Inicializa una nueva instancia de la clase PngDevice |
| PngDevice(width, height) | Inicializa una nueva instancia de la clase PngDevice |
| PngDevice(page_size) | Inicializa una nueva instancia de la clase PngDevice |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| coordinate_type | Obtiene o establece el tipo de coordenadas de la página (cajas Media/Crop). El valor CropBox se usa por defecto. |
| rendering_options | Obtiene o establece las opciones de renderizado. |
| form_presentation_mode | Obtiene o establece el modo de presentación del formulario. |
| resolution | Obtiene la resolución de la imagen. |
| ancho | Obtiene el ancho de salida de la imagen. |
| alto | Obtiene la altura de salida de la imagen. |
| transparent_background | Obtiene o establece si la imagen tiene fondo transparente. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| process(page, output) | Convierte la página a png y la guarda en el flujo de salida. |
| process(page, output_file_name) | Convierte la página a png y la guarda en el flujo de salida. |
