## DocumentDevice class

Clase abstracta para todos los dispositivos que se usan para procesar todo el documento pdf.

El tipo DocumentDevice expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| process(document, from_page, to_page, output) | Cada dispositivo representa alguna operación en el documento, p. ej. podemos convertir un documento pdf a otro formato. |
| process(document, output) | Cada dispositivo representa alguna operación en el documento, p. ej. podemos convertir un documento pdf a otro formato. |
| process(document, output_file_name) | Procesa todo el documento y guarda los resultados en el archivo. |
| process(document, from_page, to_page, output_file_name) | Procesa ciertas páginas del documento y guarda los resultados en el archivo. |
| binarize_bradley(input_image_stream, output_image_stream, threshold) | Realiza binarización Bradley para el flujo de entrada. |
