## PageDevice class

Clase abstracta para todos los dispositivos que se utiliza para procesar ciertas páginas del documento pdf.

El tipo PageDevice expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| process(page, output) | Realiza alguna operación en la página dada, p. ej. convierte la página en una imagen gráfica. |
| process(page, output_file_name) | Realiza alguna operación en la página dada y guarda los resultados en el archivo. |
