## ColorDepth enumeration

Se usa para especificar el valor del parámetro pasado a un dispositivo de imagen Tiff.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| DEFAULT | Profundidad de color predeterminada.<br/>            Se usa una profundidad de 32 bits por defecto. |
| FORMAT_8BPP | 8 bits por píxel. Igual |
| FORMAT_4BPP | 4 bits por píxel. Igual |
| FORMAT_1BPP | 1 bit por píxel. Igual |
