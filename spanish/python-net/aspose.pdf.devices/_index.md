El espacio de nombres aspose.pdf.devices proporciona clases que se utilizan para representar el documento como imagen(es) o texto plano. Así, el documento puede enviarse a dispositivos textuales o gráficos, lo que significa que queremos obtener su representación textual o gráfica.

## Clases
| Clase | Descripción |
| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en bmp. |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | Clase abstracta para todos los tipos de dispositivos. El dispositivo se usa para representar un documento pdf en algún formato.<br/>            Por ejemplo, la página del documento puede representarse como imagen o texto. |
| [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) | Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en formato Dicom. |
| [DocumentDevice](/pdf/python-net/aspose.pdf.devices/documentdevice/) | Clase abstracta para todos los dispositivos que se usan para procesar todo el documento pdf. |
| [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) | Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en emf. |
| [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) | Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en gif. |
| [ImageDevice](/pdf/python-net/aspose.pdf.devices/imagedevice/) | Una clase abstracta para dispositivos de imagen. |
| [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) | Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en jpeg. |
| [Margins](/pdf/python-net/aspose.pdf.devices/margins/) | Esta clase representa los márgenes de una imagen. |
| [PageDevice](/pdf/python-net/aspose.pdf.devices/pagedevice/) | Clase abstracta para todos los dispositivos que se utiliza para procesar ciertas páginas del documento pdf. |
| [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) | Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en png. |
| [Resolution](/pdf/python-net/aspose.pdf.devices/resolution/) | Representa una clase para mantener la resolución de la imagen. |
| [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) | Representa una clase para convertir las páginas del documento pdf en texto. |
| [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) | Representa un dispositivo de imagen que guarda las páginas del documento pdf en una imagen en miniatura. |
| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | Esta clase ayuda a guardar el documento pdf página por página en una única imagen tiff. |
| [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) | Esta clase representa la configuración para importar pdf a Tiff. |
