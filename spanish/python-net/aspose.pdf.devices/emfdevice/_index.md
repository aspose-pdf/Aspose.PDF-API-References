## EmfDevice class

Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en emf.

El tipo EmfDevice expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| EmfDevice() | Inicializa una nueva instancia de la clase [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) con la resolución predeterminada de la imagen raster escrita en emf. |
| EmfDevice(resolution) | Inicializa una nueva instancia de la clase EmfDevice |
| EmfDevice(width, height) | Inicializa una nueva instancia de la clase EmfDevice |
| EmfDevice(page_size) | Inicializa una nueva instancia de la clase EmfDevice |
| EmfDevice(width, height, resolution) | Inicializa una nueva instancia de la clase EmfDevice |
| EmfDevice(page_size, resolution) | Inicializa una nueva instancia de la clase EmfDevice |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| coordinate_type | Obtiene o establece el tipo de coordenadas de la página (cajas Media/Crop). El valor CropBox se usa por defecto. |
| rendering_options | Obtiene o establece las opciones de renderizado. |
| form_presentation_mode | Obtiene o establece el modo de presentación del formulario. |
| resolution | Obtiene la resolución de la imagen. |
| ancho | Obtiene el ancho de salida de la imagen. |
| alto | Obtiene la altura de salida de la imagen. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| process(page, output) | Convierte la página a emf y la guarda en el flujo de salida. |
| process(page, output_file_name) | Convierte la página a emf y la guarda en el flujo de salida. |
