## Propiedades
| Nombre | Descripción |
| :- | :- |
| margins | Obtiene los márgenes. |
| skip_blank_pages | Obtiene o establece un valor que indica si se deben omitir páginas en blanco. |
| compression | Obtiene o establece el tipo de compresión. |
| depth | Obtiene o establece la profundidad de color. |
| shape | Obtiene o establece el tipo de forma. |
| brightness | Obtiene o establece un límite de valor de la transformación de colores en blanco y negro.<br/>            Este parámetro puede aplicarse con EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle o ColorDepth.Format1bpp == 1 |
| coordinate_type | Obtiene o establece el tipo de coordenada de página (cajas Media/Crop). El valor CropBox se usa por defecto. |
