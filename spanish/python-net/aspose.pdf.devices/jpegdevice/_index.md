## JpegDevice class

Representa un dispositivo de imagen que ayuda a guardar las páginas del documento pdf en jpeg.

El tipo JpegDevice expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| JpegDevice() | Inicializa una nueva instancia de la clase [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) con resolución predeterminada y calidad máxima. |
| JpegDevice(resolution) | Inicializa una nueva instancia de la clase JpegDevice |
| JpegDevice(quality) | Inicializa una nueva instancia de la clase JpegDevice |
| JpegDevice(resolution, quality) | Inicializa una nueva instancia de la clase JpegDevice |
| JpegDevice(width, height) | Inicializa una nueva instancia de la clase JpegDevice |
| JpegDevice(page_size) | Inicializa una nueva instancia de la clase JpegDevice |
| JpegDevice(width, height, resolution) | Inicializa una nueva instancia de la clase JpegDevice |
| JpegDevice(page_size, resolution) | Inicializa una nueva instancia de la clase JpegDevice |
| JpegDevice(width, height, resolution, quality) | Inicializa una nueva instancia de la clase JpegDevice |
| JpegDevice(page_size, resolution, quality) | Inicializa una nueva instancia de la clase JpegDevice |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| coordinate_type | Obtiene o establece el tipo de coordenadas de la página (cajas Media/Crop). El valor CropBox se usa por defecto. |
| rendering_options | Obtiene o establece las opciones de renderizado. |
| form_presentation_mode | Obtiene o establece el modo de presentación del formulario. |
| resolution | Obtiene la resolución de la imagen. |
| ancho | Obtiene el ancho de salida de la imagen. |
| alto | Obtiene la altura de salida de la imagen. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| process(page, output) | Convierte la página a jpeg y la guarda en el flujo de salida. |
| process(page, output_file_name) | Convierte la página a jpeg y la guarda en el flujo de salida. |
