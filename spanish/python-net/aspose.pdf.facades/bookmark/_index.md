## Bookmark class

Representa un marcador.

El tipo Bookmark expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Bookmark() | Inicializa una nueva instancia de la clase Bookmark |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| action | Obtiene o establece la acción vinculada al marcador.<br/>            Si se presenta PageNumber, la acción no puede especificarse.<br/>            El tipo de acción incluye: "GoTo", "GoToR", "Launch", "Named". |
| bold_flag | Obtiene o establece la bandera de negrita del título del marcador. |
| child_item | Obtiene o establece los hijos del marcador. |
| child_items | Obtiene o establece los hijos del marcador. |
| destino | Obtiene o establece la página de destino del marcador. Requerido si la acción se establece como string.Empty. |
| italic_flag | Obtiene o establece la bandera itálica del título del marcador. |
| nivel | Obtiene o establece el nivel de jerarquía del marcador. |
| page_display | Obtiene o establece el tipo de visualización de la página de destino del marcador. |
| page_display_bottom | Obtiene o establece la coordenada inferior de la visualización de la página. |
| page_display_left | Obtiene o establece la coordenada izquierda de la visualización de la página. |
| page_display_right | Obtiene o establece la coordenada derecha de la visualización de la página. |
| page_display_top | Obtiene o establece la coordenada superior de la visualización de la página. |
| page_display_zoom | Obtiene o establece el factor de zoom de la visualización de la página. |
| page_number | Obtiene o establece el número de la página de destino del marcador. |
| remote_file | Obtiene o establece el archivo (ruta) que se requiere para la acción "GoToR" del marcador. |
| title | Obtiene o establece el título del marcador. |
| title_color | Obtiene o establece el color del título del marcador. |
| abrir | Obtiene o establece el estado del marcador (abierto, cerrado). |
