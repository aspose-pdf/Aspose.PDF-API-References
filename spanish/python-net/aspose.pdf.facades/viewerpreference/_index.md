## ViewerPreference class

Describe las preferencias del visor (modo de página, modo de página sin pantalla completa, diseño de página).

El tipo ViewerPreference expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ViewerPreference() | Inicializa una nueva instancia de la clase ViewerPreference |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| PAGE_MODE_USE_OC | Panel de grupo de contenido opcional visible. |
| DISPLAY_DOC_TITLE | Una bandera que especifica si la barra de título de la ventana debe mostrar el título del documento. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | Panel de grupo de contenido opcional visible. |
| PAGE_LAYOUT_SINGLE_PAGE | Muestra una página a la vez. |
| PAGE_LAYOUT_ONE_COLUMN | Muestra las páginas en una columna. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | Muestra las páginas en dos columnas, con las páginas impares a la derecha |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | Muestra las páginas en dos columnas, con las páginas impares a la derecha. |
| PAGE_MODE_USE_NONE | Ni el esquema del documento ni las miniaturas son visibles |
| PAGE_MODE_USE_OUTLINES | Esquema del documento visible. |
| PAGE_MODE_USE_THUMBS | Miniaturas visibles. |
| PAGE_MODE_FULL_SCREEN | Modo de pantalla completa, sin barra de menús, controles de ventana o cualquier otra ventana visible. |
| PAGE_MODE_USE_ATTACHMENT | Modo de página con archivos adjuntos. |
| HIDE_TOOLBAR | Una bandera que indica si se deben ocultar las barras de herramientas del lector compatible cuando el documento está activo. |
| HIDE_MENUBAR | Una bandera que indica si se debe ocultar la barra de menús del lector compatible cuando el documento está activo. |
| HIDE_WINDOW_UI | Una bandera que indica si se deben ocultar los elementos de la interfaz de usuario en la ventana del documento (como barras de desplazamiento y controles de navegación), dejando solo el contenido del documento visible. |
| FIT_WINDOW | Una bandera que indica si se debe redimensionar la ventana del documento para ajustarse al tamaño de la primera página mostrada. |
| CENTER_WINDOW | Una bandera que indica si se debe posicionar la ventana del documento en el centro de la pantalla. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | Ni el esquema del documento ni las imágenes en miniatura son visibles. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | Esquema del documento visible. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | Imágenes en miniatura visibles |
| DIRECTION_L2R | Orden de lectura del texto de izquierda a derecha. |
| DIRECTION_R2L | Orden de lectura del texto de derecha a izquierda. |
| SIMPLEX | Imprimir a una cara. |
| DUPLEX_FLIP_SHORT_EDGE | Dúplex y voltear por el borde corto de la hoja. |
| DUPLEX_FLIP_LONG_EDGE | Dúplex y voltear por el borde corto de la hoja. |
