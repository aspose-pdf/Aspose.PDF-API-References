## PositioningMode enumeration

Define el modo de posicionamiento.<br/>            Los valores posibles incluyen Legacy (compatibilidad hacia atrás) y <br/>            Current (método actualizado de cálculo de posición de texto)

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| LEGACY | Posicionamiento de texto heredado |
| MODERN_LINE_SPACING | Espaciado de línea actualizado, el cálculo de la posición vertical se realiza según las reglas antiguas <br/>            (es decir, el texto se posiciona relativo a la esquina inferior izquierda del rectángulo especificado) |
| CURRENT | El espaciado de línea actualizado y el cálculo de la posición vertical se realizan basándose en la esquina superior izquierda en lugar de la esquina inferior izquierda. |
