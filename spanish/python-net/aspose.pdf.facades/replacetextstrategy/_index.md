## ReplaceTextStrategy class

Esta clase contiene parámetros que definen el comportamiento de PdfContentEditor cuando se realiza la operación ReplaceText.

El tipo ReplaceTextStrategy expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ReplaceTextStrategy() | Inicializa una nueva instancia de la clase ReplaceTextStrategy |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_regular_expression_used | Si es false, la cadena a buscar es un texto simple. Si es true, la cadena a buscar es una expresión regular. |
| no_character_behavior | Acción que se realiza cuando no se encuentra una fuente apropiada para el texto modificado<br/>            (Lanzar excepción / Sustituir por otra fuente / Reemplazar de todos modos). |
| replace_scope | Ámbito de la operación de reemplazo (reemplazar la primera ocurrencia o reemplazar todas las ocurrencias). |
