## StampInfo class

Clase que representa la información del sello.

El tipo StampInfo expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| stamp_id | Obtiene el identificador del sello. |
| index_on_page | Obtiene el índice del sello en la página. |
| stamp_type | Obtiene el tipo de sello (imagen / formulario). |
| rectangle | Obtiene el rectángulo donde se coloca el sello. |
| image | Obtiene la imagen del sello. Puede ser nulo si el sello no contiene imágenes (por ejemplo, para un sello de texto). |
| formulario | Obtiene XForm del sello. |
| text | Obtiene el texto del sello. |
| visible | Obtiene la visibilidad del sello. Si es false entonces el sello está oculto (con HideStampById). El sello oculto puede ser restaurado con ShowStampById. |
