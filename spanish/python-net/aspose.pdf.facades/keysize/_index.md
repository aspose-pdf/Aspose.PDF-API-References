## KeySize enumeration

Define diferentes tamaños de clave que pueden usarse para cifrar documentos pdf.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| X40 | Clave de 40 bits. Este tamaño de clave se usa con el algoritmo RC4 y proporciona un bajo nivel de seguridad. <br/>            Sin embargo, las versiones antiguas de documentos pdf solo pueden cifrarse con este tipo de claves (v. 1.3 y anteriores); |
| X128 | Clave de 128 bits. Tanto los algoritmos RC4 como AES pueden usar este tamaño de clave. |
| X256 | Clave de 256 bits. Este tamaño de clave solo puede usarse con AES y es reconocido por las últimas versiones de Adobe Reader (a partir de la v.9). |
