## ISaveableFacade class

Interfaz de fachada que define métodos comunes para todas las fachadas guardables.

El tipo ISaveableFacade expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| save(dest_file) | Guarda el documento PDF resultante en un archivo. |
| save(dest_stream) | Guarda el documento PDF resultante en una secuencia. |
| bind_pdf(src_file) | Vincula el documento PDF para su edición. |
| bind_pdf(src_stream) | Vincula el documento PDF para su edición. |
| bind_pdf(src_doc) | Vincula el documento PDF para su edición. |
| close() | Libera cualquier recurso asociado con la fachada actual. |
