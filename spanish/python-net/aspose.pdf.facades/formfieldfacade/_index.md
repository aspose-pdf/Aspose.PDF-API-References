## FormFieldFacade class

Clase para representar propiedades de campo.

El tipo FormFieldFacade expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| FormFieldFacade() | Inicializa una nueva instancia de la clase FormFieldFacade |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| border_color | El color del borde de un campo. |
| border_style | El estilo de un borde de campo. |
| border_width | El ancho de un borde de campo. |
| font | El tipo de fuente del texto del campo. |
| custom_font | Obtiene o establece el nombre de la fuente cuando esta no es estándar (además de las 14 fuentes estándar). |
| font_size | El tamaño del texto del campo. |
| text_color | El color del texto del campo. |
| text_encoding | El tipo de codificación de texto del campo. |
| alineación | La alineación del texto del campo, por defecto es alineación a la izquierda. |
| rotation | La rotación del texto del campo. |
| caption | El título normal del campo de formulario. |
| button_style | El estilo del campo de casilla de verificación o botón de opción, definido por FormFieldFacade.CheckBoxStyle*. |
| box | Un objeto rectángulo que contiene la ubicación del campo. |
| position | Un objeto rectángulo que contiene la ubicación del campo. |
| page_number | Un valor entero que indica el número de página en la que se encuentra el campo. |
| items | Una matriz de cadenas, cada una representando una opción de un campo de cuadro combinado/lista/botón de opción. |
| export_items | Las opciones para agregar una lista/cuadro combinado/botón de opción |
| background_color | El color del fondo del campo, por defecto es blanco. |
| backgroud_color | Propiedad obsoleta. Use BackgroundColor. |
| BORDER_WIDTH_UNDIFIED | Ancho de borde indefinido. |
| BORDER_WIDTH_UNDEFINED | Ancho de borde indefinido. |
| BORDER_WIDTH_THIN | Define un ancho de borde delgado. |
| BORDER_WIDTH_MEDIUM | Define un ancho de borde medio. |
| BORDER_WIDTH_THICK | Define un ancho de borde grueso. |
| BORDER_STYLE_SOLID | Define un estilo de borde sólido. |
| BORDER_STYLE_DASHED | Define un estilo de borde discontinuo. |
| BORDER_STYLE_BEVELED | Define un estilo de borde biselado. |
| BORDER_STYLE_INSET | Define un estilo de borde incrustado. |
| BORDER_STYLE_UNDERLINE | Define un estilo de borde subrayado. |
| BORDER_STYLE_UNDEFINED | Estilo de borde indefinido. |
| ALIGN_LEFT | Define la alineación a la izquierda. |
| ALIGN_CENTER | Define la alineación al estilo centrado. |
| ALIGN_RIGHT | Define la alineación al estilo derecho. |
| ALIGN_UNDEFINED | Estilo de alineación indefinido. |
| ALIGN_JUSTIFIED | Define el estilo de alineación de justificación de texto. |
| ALIGN_TOP | Define la alineación vertical como estilo superior. |
| ALIGN_MIDDLE | Define la alineación vertical como estilo medio. |
| ALIGN_BOTTOM | Define la alineación vertical como estilo inferior. |
| CHECK_BOX_STYLE_CIRCLE | Define un estilo de casilla de verificación circular. |
| CHECK_BOX_STYLE_CHECK | Define la forma del campo de casilla de verificación cuando está marcado. |
| CHECK_BOX_STYLE_CROSS | Define un estilo de casilla de verificación con cruz. |
| CHECK_BOX_STYLE_DIAMOND | Define un estilo de casilla de verificación diamante. |
| CHECK_BOX_STYLE_STAR | Define un estilo de casilla de verificación estrella. |
| CHECK_BOX_STYLE_SQUARE | Define un estilo de casilla de verificación cuadrada. |
| CHECK_BOX_STYLE_UNDEFINED | Define un estilo de casilla de verificación indefinido. |
