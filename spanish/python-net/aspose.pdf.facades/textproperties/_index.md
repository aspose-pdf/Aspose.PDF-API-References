## TextProperties class

Representa propiedades de texto como: tamaño de texto, color, estilo, etc.

El tipo TextProperties expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextProperties(text_size) | Inicializa una nueva instancia de la clase TextProperties |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| color | Obtiene o establece el color del texto. |
| is_color_specified | Obtiene o establece un valor que indica si la propiedad [color](/pdf/python-net/aspose.pdf.facades/textproperties/) está especificada. |
| text_size | Obtiene o establece el tamaño del texto. |
| is_text_size_specified | Obtiene o establece un valor que indica si la propiedad [text_size](/pdf/python-net/aspose.pdf.facades/textproperties/) está especificada. |
