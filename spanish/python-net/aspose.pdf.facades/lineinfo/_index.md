## LineInfo class

Representa la información de una línea.

El tipo LineInfo expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LineInfo() | Inicializa una nueva instancia de la clase LineInfo |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| vertice_coordinate | Obtiene o establece una matriz de números que representan las coordenadas horizontales y verticales alternadas, respectivamente, de cada vértice. |
| line_color | Obtiene o establece el color de una línea. |
| line_width | Obtiene o establece el ancho de una línea. |
| visibility | Obtiene o establece la visibilidad de una línea. |
| line_dash_pattern | Obtiene o establece el patrón de guiones de una línea. |
| border_style | Obtiene o establece el estilo de borde de una línea, 0 representa sólido, 1 representa con guiones, 2 representa beleved, 3 representa insert, 4 representa subrayado. |
