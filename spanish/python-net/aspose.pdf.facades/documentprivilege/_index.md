## DocumentPrivilege class

Representa los privilegios para acceder a un archivo Pdf. Consulte [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             Hay 4 formas de usar esta clase:<br/>             1.Usar el privilegio predefinido directamente.<br/>             2.Basado en un privilegio predefinido y cambiar algunos permisos específicos.<br/>             3.Basado en un privilegio predefinido y cambiar alguna combinación específica de permisos de Adobe Professional.<br/>             4.Mezcla la forma 2 y la forma 3.

El tipo DocumentPrivilege expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| allow_print | Establece el permiso que permite imprimir o no. <br/>            true permite y false prohíbe. |
| allow_degraded_printing | Establece el permiso que permite la impresión degradada o no. <br/>            true permite y false prohíbe. |
| allow_modify_contents | Establece el permiso que permite modificar el contenido o no. <br/>            true permite y false prohíbe. |
| allow_copy | Establece el permiso que permite copiar o no. <br/>            true permite y false prohíbe. |
| allow_modify_annotations | Establece el permiso que permite modificar anotaciones o no. <br/>            true permite y false prohíbe. |
| allow_fill_in | Establece el permiso que permite rellenar formularios o no. <br/>            true permite y false prohíbe. |
| allow_screen_readers | Establece el permiso que permite lectores de pantalla o no. <br/>            true permite y false prohíbe. |
| allow_assembly | Establece el permiso que permite ensamblar o no. <br/>            true permite y false prohíbe. |
| degraded_printing | Permite la impresión degradada. |
| print | Permite imprimir el archivo. |
| modify_contents | Permite modificar el archivo. |
| copy | Permite copiar el archivo. |
| modify_annotations | Permite modificar anotaciones del archivo. |
| fill_in | Permite rellenar formularios en el archivo. |
| screen_readers | Permite leer solo en pantalla. |
| assembly | Permite ensamblar el archivo. |
| allow_all | Todo permitido. |
| forbid_all | Todo prohibido. |
