## IPdfTypeExtractor class

Representa una interfaz para interactuar con el extractor.

El tipo IPdfTypeExtractor expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| page_count | Devuelve el recuento de páginas. |
| version | Devuelve la versión. |
| is_fast_extraction_used | Devuelve si se utilizó el mecanismo de extracción rápida. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| extract_all_text() | Devuelve una colección de valores de texto extraídos. |
| extract_page_text(page_number) | Devuelve el texto de la página. |
| dispose() | Liberar. |
