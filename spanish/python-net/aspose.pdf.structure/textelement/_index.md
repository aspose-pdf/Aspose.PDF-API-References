## TextElement class

Elemento de texto general de la estructura lógica del documento.

El tipo TextElement expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| children | Obtiene la colección de elementos hijos. |
| lang | (Optional; PDF 1.4) Un idioma que especifica la lengua natural para todo el texto<br/> en el elemento de estructura excepto donde sea sobrescrito por especificaciones de idioma para elementos de estructura anidados<br/> o contenido marcado. |
| actual_text | (Optional; PDF 1.4) Texto que es un reemplazo exacto del elemento de estructura y sus hijos.<br/> Este texto de reemplazo (que debe aplicarse a la menor cantidad posible de contenido)<br/> es útil al extraer el contenido del documento en apoyo a la accesibilidad para usuarios<br/> con discapacidades o para otros propósitos. |
| alt | (Optional) Una descripción alternativa del elemento de estructura y sus hijos en<br/> forma legible por humanos, que es útil al extraer el contenido del documento en apoyo<br/> a la accesibilidad para usuarios con discapacidades o para otros propósitos. |
| e | (Optional; PDF 1.5) La forma expandida de una abreviatura. |
| text | Obtiene el valor del elemento de estructura de texto. |
