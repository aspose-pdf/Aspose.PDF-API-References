## FileParams class

Define un diccionario de parámetros de archivo incrustado que debe contener información adicional específica del archivo.

El tipo FileParams expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| FileParams(spec) | Inicializa una nueva instancia de la clase FileParams |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| tamaño | El tamaño del archivo incrustado descomprimido, en bytes. |
| creation_date | La fecha y hora en que se creó el archivo incrustado. |
| mod_date | La fecha y hora en que el archivo incrustado fue modificado por última vez. |
| check_sum | Una cadena de 16 bytes que es la suma de verificación de los bytes del archivo incrustado descomprimido. <br/>            La suma de verificación se calcula aplicando el algoritmo estándar de resumen de mensaje MD5 <br/>            a los bytes del flujo del archivo incrustado. |
