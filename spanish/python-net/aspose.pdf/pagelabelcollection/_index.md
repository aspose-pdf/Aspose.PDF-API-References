## PageLabelCollection class

Clase que representa la colección de etiquetas de página.

El tipo PageLabelCollection expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_label(page_index) | Obtiene la etiqueta de página por índice de página (el índice de página comienza en 0). |
| update_label(page_index, page_label) | Actualiza la etiqueta para el índice de página dado (el índice de página comienza en 0). |
| remove_label(page_index) | Eliminar etiqueta por índice de página (el índice de página comienza en 0). |
| get_pages() | Obtiene los índices de página en la colección. |
