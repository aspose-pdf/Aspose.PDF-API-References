## Rows class

Representa una colección de filas de la tabla.

El tipo Rows expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Rows() | Inicializa una nueva instancia de la clase Rows |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| count | El recuento de elementos. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene o establece la fila. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add() | Agregar fila a la colección. |
| add(row) | Agregar fila a la colección. |
| index_of(row) | Devuelve el índice de la fila en la colección. |
| remove(row) | Eliminar fila de la colección. |
| remove_at(index) | Eliminar fila en la posición de la colección. |
| remove_range(index, count) | Eliminar conjunto de filas de la colección. |
| dispose() | Liberar. |
