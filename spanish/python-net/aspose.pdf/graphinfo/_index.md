## GraphInfo class

Representa información gráfica.

El tipo GraphInfo expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| GraphInfo() | Inicializa una nueva instancia de la clase GraphInfo |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| line_width | Obtiene o establece un valor float que indica el ancho de línea del gráfico. |
| color | Obtiene o establece un objeto [color](/pdf/python-net/aspose.pdf/graphinfo/) que indica el color del gráfico. |
| dash_array | Obtiene o establece una matriz de guiones. |
| dash_phase | Obtiene o establece una fase de guiones. |
| fill_color | Obtiene o establece un objeto [color](/pdf/python-net/aspose.pdf/graphinfo/) que indica el color de relleno del gráfico. |
| is_doubled | Obtiene o establece si el borde está duplicado. |
| skew_angle_x | Obtiene o establece un valor float que indica el ángulo de sesgo de la coordenada x al transformar un sistema de coordenadas. |
| skew_angle_y | Obtiene o establece un valor float que indica el ángulo de sesgo de la coordenada y al transformar un sistema de coordenadas. |
| scaling_rate_x | Obtiene o establece un valor float que indica la tasa de escala de la coordenada x al transformar un sistema de coordenadas. |
| scaling_rate_y | Obtiene o establece un valor float que indica la tasa de escala de la coordenada y al transformar un sistema de coordenadas. |
| rotation_angle | Obtiene o establece un valor float que indica el ángulo de rotación del sistema de coordenadas <br/>            al transformar un sistema de coordenadas. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| clone() | Clona la información gráfica. |
