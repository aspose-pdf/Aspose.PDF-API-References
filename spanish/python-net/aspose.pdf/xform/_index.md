## XForm class

Clase que representa XForm

El tipo XForm expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| b_box | Obtiene o establece el cuadro delimitador del formulario. |
| name | Obtiene o establece el nombre del formulario. El nombre del formulario es el nombre que se usa para referenciar el formulario en el diccionario XObject en los recursos de la página. |
| contenidos | Obtiene los operadores del formulario. |
| opi | Obtiene la Interfaz de Preimpresión Abierta (OPI). |
| matrix | Obtiene o establece la matriz del formulario. |
| resources | Obtiene los recursos del XObject del formulario. |
| rectangle | Obtiene o establece el rectángulo del formulario. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_resources(allow_create) | Devuelve los recursos del Form X-Object |
| get_resources() | Devuelve los recursos del Form X-Object |
| create_new_form(source, document) | Crea un XForm que duplica el contenido de la página. |
| free_memory() | Borra los datos en caché |
