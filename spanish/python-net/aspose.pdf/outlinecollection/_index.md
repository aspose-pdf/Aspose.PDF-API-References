## OutlineCollection class

Representa la jerarquía del esquema del documento.

El tipo OutlineCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| visible_count | Count es la suma del número de elementos de esquema descendentes visibles en todos los niveles. Nota: por favor, no confunda con Count que es el número de elementos en la colección. |
| first | Obtiene un elemento de esquema que representa el primer elemento de nivel superior en el esquema. |
| último | Obtiene un elemento del esquema que representa el último elemento de nivel superior en el esquema. |
| is_synchronized | Obtiene un valor que indica si el acceso a esta colección está sincronizado (seguro para subprocesos). |
| sync_root | Obtiene un objeto que puede usarse para sincronizar el acceso a esta colección. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene el elemento del esquema de la colección por índice. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| delete() | Elimina todos los elementos del esquema del documento. |
| delete(name) | Elimina el elemento del esquema con el título especificado del esquema del documento. |
