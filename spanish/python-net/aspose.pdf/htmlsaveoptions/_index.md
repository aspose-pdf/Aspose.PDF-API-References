## HtmlSaveOptions class

El tipo HtmlSaveOptions expone los siguientes miembros:

| :- | :- |

| HtmlSaveOptions(document_type) | Inicializa una nueva instancia de la clase HtmlSaveOptions |
| HtmlSaveOptions(fixed_layout) | Inicializa una nueva instancia de la clase HtmlSaveOptions |

| save_format | Formato de guardado de datos. |

| extract_ocr_sublayer_only | Ninguno |

| split_css_into_pages | Cuando se selecciona el modo multipágina (es decir, 'SplitIntoPages' es 'true'), <br/>            este atributo define si debe crearse un archivo CSS separado<br/>            para cada página HTML resultante.<br/>            Por defecto este atributo es false, por lo que se creará<br/>            un gran CSS común para todas las páginas creadas. El tamaño total de todos<br/>            los CSS generados en este modo (un CSS por página) suele<br/>            mucho mayor que el tamaño de un único CSS grande, porque en el caso anterior <br/>            las clases CSS se duplican en varios archivos CSS para cada página.<br/>            Por lo tanto, esta configuración es peor y solo debe usarse cuando usted está interesado<br/>            en el procesamiento futuro de cada página HTML de forma independiente, y por lo tanto el tamaño<br/>            del CSS de cada página individual es el problema más crítico. |
| split_into_pages | Obtiene o establece la bandera que indica si cada página del documento fuente <br/>            será convertida en su propio documento HTML de destino, <br/>            es decir, si el HTML resultante se dividirá en varias páginas HTML. |
| explicit_list_of_saved_pages | Con esta propiedad puede definir explícitamente <br/>            qué páginas del documento deben convertirse.<br/>            Las páginas en esta lista deben tener números basados en 1. Es decir, <br/>            los números válidos de páginas deben tomarse del rango (1...[NumberOfPagesInConvertedDocument])<br/>            El orden de aparición de las páginas en esta lista no afecta su<br/>            orden en la(s) página(s) HTML resultante(s) - en las páginas resultantes siempre se mantendrá el orden en que aparecen <br/>            en el PDF fuente.<br/>            Si esta lista es nula (como es por defecto), se convertirán todas las páginas.<br/>            Si algún número de página de esta lista está fuera del rango de páginas presentes (1-[amountOfPagesInDocument])<br/>            se lanzará una excepción. |
| fixed_layout | Obtiene o establece un valor que indica si el HTML se crea como diseño fijo. |
| image_resolution | Obtiene o establece la resolución para la renderización de imágenes. |
| default_font_name | Especifica el nombre de una fuente instalada que se utiliza para sustituir<br/>            cualquier fuente del documento que no esté incrustada y no esté instalada en el sistema. <br/>            Si es nulo, se utilizará la fuente de sustitución predeterminada. |
| batch_size | Define el tamaño del lote si la conversión por lotes es aplicable<br/>            al par de formatos de origen y destino. |
| font_sources | Fuentes de origen de fuentes preguardadas. |

En esencia, define el intervalo garantizado entre<br/>            las representaciones HTML de las páginas \"paper\" del PDF en este modo de conversión. |
| use_z_order | Si el atributo UseZORder está configurado a true, los gráficos y el texto se añaden al documento HTML resultante<br/>            de acuerdo con el orden Z en el documento PDF original. Si este atributo es false, todos los gráficos se colocan<br/>            como una sola capa, lo que puede causar efectos innecesarios en objetos superpuestos. |
| convert_marked_content_to_layers | Si el atributo ConvertMarkedContentToLayers está configurado a true, entonces todos los elementos dentro de un contenido marcado PDF<br/>            (capa) se colocarán en un div HTML con el atributo \"data-pdflayer\" que especifica el nombre de la capa.<br/>            Este nombre de capa se extraerá de las propiedades opcionales del contenido marcado PDF.<br/>            Si este atributo es false (por defecto), no se crearán capas a partir del contenido marcado PDF. |
| minimal_line_width | Este atributo establece el ancho mínimo de la línea de ruta gráfica.<br/>            Si el grosor de la línea es inferior a 1px, Adobe Acrobat lo redondea a este valor. Por lo tanto, este atributo puede<br/>            usarse para emular este comportamiento en navegadores HTML. |
| prevent_glyphs_grouping | Este atributo activa el modo en el que los glifos de texto no se agruparán en palabras y cadenas<br/>            Este modo permite mantener la máxima precisión al posicionar los glifos en la página y puede ser<br/>            utilizado para convertir documentos con notas musicales o glifos que deben colocarse por separado entre sí.<br/>            Este parámetro se aplicará al documento solo cuando el valor del atributo FixedLayout sea true. |
| simple_textbox_mode_grouping | Este atributo especifica un agrupamiento secuencial de glifos y palabras en cadenas<br/>            Por ejemplo, las etiquetas y las palabras tienen un orden diferente en el HTML convertido y deseas que coincidan.<br/>            Este parámetro se aplicará al documento solo cuando el valor del atributo FixedLayout sea true. |
| flow_layout_paragraph_full_width | Este atributo especifica texto de párrafo de ancho completo para el modo Flujo, FixedLayout = false |
| render_text_as_image | Si el atributo RenderTextAsImage está configurado a true, el texto de la fuente se convierte en una imagen en HTML.<br/>            Puede ser útil para hacer que el texto no sea seleccionable<br/>            o cuando el texto HTML no se renderiza correctamente. |
| save_full_font | Indica que se guardará la fuente completa, solo admite fuentes True Type.<br/>            Por defecto SaveFullFont = false y el conversor guarda el subconjunto de la fuente inicial<br/>            necesario para mostrar el texto del documento. |
| antialiasing_processing | Este parámetro define las medidas de antialiasing requeridas durante la conversión de imágenes de fondo compuestas de PDF a HTML |
| save_transparent_texts | El PDF puede contener textos transparentes que pueden seleccionarse al portapapeles (normalmente ocurre cuando el documento contiene imágenes y textos OCR extraídos de ellas).<br/>            Esta configuración indica al conversor si debemos guardar dichos textos como textos transparentes<br/>            seleccionables en el HTML resultante |
| save_shadowed_texts_as_transparent_texts | Pdf puede contener textos que están ocultos por otros elementos (p.ej. por imágenes) pero <br/>            pueden ser seleccionados al portapapeles en Acrobat Reader (normalmente ocurre cuando el documento contiene imágenes y textos OCR extraídos de ellas).<br/>            Esta configuración indica al convertidor si necesitamos guardar dichos textos como textos transparentes<br/>            seleccionables en el HTML resultante para imitar el comportamiento de Acrobat Reader (de lo contrario, dichos textos suelen guardarse como ocultos, no disponibles para copiar al portapapeles) |
| font_saving_mode | Define el modo de guardado de fuentes que se utilizará al guardar el PDF en el formato deseado |
| page_border_if_any | Este atributo representa un conjunto de configuraciones usadas para dibujar el borde (si lo hay)<br/>            en el documento HTML resultante alrededor del área que representa la página PDF de origen.<br/>            En esencia se refiere a la visualización de los bordes del papel de la página,<br/>            no al borde de la página referenciado en la propia página PDF. |
| page_margin_if_any | Este atributo representa un conjunto de márgenes de página adicionales (si los hay)<br/>            en el documento HTML resultante alrededor del área que representa la página PDF de origen. |
| letters_positioning_method | Establece el modo de posicionamiento de las letras en las palabras en el HTML resultante |
| exclude_font_name_list | Lista de nombres de fuentes incrustadas en PDF que no se incrustarán en HTML. |

| special_folder_for_all_images | Obtiene o establece la ruta al directorio en el que se deben guardar todas las imágenes si se <br/>            encuentran durante el guardado del documento como HTML. ".stl_NN {}") y se usan en el CSS resultante. 'my_prefix_NNN'), <br/>            simplemente asigna 'my_prefix_' a esta propiedad antes de la conversión.<br/>            Si esta propiedad permanece sin tocar (es decir, se deja null como valor), entonces el convertidor generará los nombres de clase por sí mismo <br/>            (será algo como ".stl_01 {}" ... ".stl_NN {}") |
