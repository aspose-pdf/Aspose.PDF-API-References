## Matrix3D class

La clase representa una matriz de transformación.

El tipo Matrix3D expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Matrix3D() | Constructor<br/>            crea una matriz estándar 1 a 1:<br/>            [ A B C D E F G H I Tx Ty Tz] = [ 1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0 , 0] |
| Matrix3D(matrix_3d_array) | Inicializa una nueva instancia de la clase Matrix3D |
| Matrix3D(matrix) | Inicializa una nueva instancia de la clase Matrix3D |
| Matrix3D(a, b, c, d, e, f, g, h, i, tx, ty, tz) | Inicializa una nueva instancia de la clase Matrix3D |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| a | Un miembro de la matriz de transformación. |
| b | Miembro B de la matriz de transformación. |
| c | Miembro C de la matriz de transformación. |
| d | Miembro D de la matriz de transformación. |
| e | Miembro E de la matriz de transformación. |
| f | Miembro F de la matriz de transformación. |
| g | Miembro G de la matriz de transformación. |
| h | Miembro H de la matriz de transformación. |
| i | Miembro I de la matriz de transformación. |
| tx | Miembro Tx de la matriz de transformación. |
| ty | Miembro Ty de la matriz de transformación. |
| tz | Miembro Tz de la matriz de transformación. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_angle(rotation) | Traduce la rotación a ángulo (grados) |
| add(other) | Añade la matriz a otra matriz. |
