## PdfANonSpecificationFlags class

Esta clase contiene banderas para controlar la conversión a PDF/A en casos en que el documento PDF de origen no <br/>            corresponda a la especificación PDF. Si se usan las banderas de esta clase, disminuye el rendimiento <br/>            pero es necesario cuando el documento PDF de origen no puede convertirse al formato PDF/A de la manera habitual. <br/>            Por defecto, todas las banderas están establecidas en false.
