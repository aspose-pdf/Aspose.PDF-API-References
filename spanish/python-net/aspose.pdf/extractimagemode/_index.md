## ExtractImageMode enumeration

Define diferentes modos que pueden usarse al extraer imágenes de documentos.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| DEFINED_IN_RESOURCES | Define el modo de extracción de imágenes en el que se extraen todas las imágenes definidas en los recursos para una página determinada. |
| ACTUALLY_USED | Define el modo de extracción de imágenes en el que solo se extraen aquellas imágenes que se muestran realmente en una página. |
