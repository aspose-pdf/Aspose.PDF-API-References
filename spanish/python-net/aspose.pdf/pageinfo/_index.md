## PageInfo class

Representa la información de la página.

El tipo PageInfo expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PageInfo() | Inicializa una nueva instancia de la clase PageInfo |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| any_margin | Obtiene o establece el margen de página para cualquier página excepto la primera. |
| default_text_state | Obtiene o establece la fuente predeterminada. |
| alto | Obtiene o establece la altura de la página. |
| pure_height | Obtiene o establece la altura pura de la página sin márgenes. |
| is_landscape | Obtiene o establece si la página está en modo paisaje. |
| margen | Obtiene o establece el margen de la página. |
| ancho | Obtiene o establece el ancho de la página. |
