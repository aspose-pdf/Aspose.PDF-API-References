## DocumentInfo class

Representa la información meta del documento PDF.

El tipo DocumentInfo expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| DocumentInfo(document) | Inicializa una nueva instancia de la clase DocumentInfo |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| title | Obtiene o establece el título del documento. |
| creator | Obtiene o establece el creador del documento. |
| author | Obtiene o establece el autor del documento. |
| subject | Obtiene o establece el asunto del documento. |
| keywords | Obtiene o establece las palabras clave del documento. |
| producer | Obtiene o establece el productor del documento. |
| creation_date | Obtiene o establece la fecha de creación del documento. |
| creation_time_zone | Zona horaria de la fecha de creación. |
| mod_time_zone | Zona horaria de la fecha de modificación. |
| mod_date | Obtiene o establece la fecha de modificación del documento. |
| trapped | Obtiene o establece la bandera trapped. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add(key, value) | Agrega un elemento con la clave y el valor especificados a la colección. |
| remove(key) | Elimina el elemento con la clave especificada de la colección. |
| clear_custom_data() | Borra solo los datos personalizados, dejando todos los demás valores predefinidos (Title, Author, etc.). |
| is_predefined_key(key) | Determina si la clave está predefinida (Title, Author, etc.), no personalizada. |
