## PageCoordinateType enumeration

Describe el tipo de coordenada de página.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| MEDIA_BOX | El MediaBox se utiliza para especificar el ancho y la altura de la página. <br/>            Para el usuario promedio, esto probablemente equivale al tamaño real de la página. <br/>            El MediaBox es el cuadro de página más grande en un PDF. Los demás cuadros de página pueden ser iguales al <br/>            tamaño del MediaBox pero no pueden ser más grandes. |
| CROP_BOX | El CropBox define la región a la que se recortará el contenido de la página. <br/>            Acrobat utiliza este tamaño para la visualización en pantalla e impresión. |
