## Row class

Representa una fila de la tabla.

El tipo Row expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Row() | Inicializa una nueva instancia de la clase Row |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| background_color | Obtiene o establece el color de fondo. |
| borde | Obtiene o establece el borde. |
| cells | Obtiene las celdas de la fila. |
| default_cell_border | Obtiene el borde predeterminado de la celda; |
| min_row_height | Obtiene la altura de la fila; |
| fixed_row_height | Obtiene la altura fija de la fila - la fila puede tener altura fija; |
| is_in_new_page | Obtiene si la fila está en una nueva página - la página con esta propiedad debe imprimirse en la página siguiente Predeterminado false; |
| is_row_broken | Obtiene si la fila puede dividirse entre dos páginas |
| default_cell_text_state | Obtiene o establece el estado de texto predeterminado para las celdas de la fila |
| default_cell_padding | Obtiene o establece el margen predeterminado para las celdas de la fila |
| vertical_alignment | Obtiene o establece la alineación vertical. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| clone() | Clona la fila. |
