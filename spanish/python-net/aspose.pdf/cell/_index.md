## Cell class

Representa una celda de la fila de la tabla.

El tipo Cell expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Cell(rect) | Inicializa una nueva instancia de la clase Cell |
| Cell() | Inicializa una nueva instancia de la clase Cell. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_no_border | Obtiene o establece si la celda tiene borde. |
| margen | Obtiene o establece el relleno. |
| borde | Obtiene o establece el borde. |
| background_color | Obtiene o establece el color de fondo. |
| background_image_file | Obtiene o establece el archivo de imagen de fondo. |
| background_image | Obtiene o establece la imagen de fondo |
| alineación | Obtiene o establece la alineación. |
| default_cell_text_state | Obtiene o establece el estado de texto predeterminado de la celda. |
| is_override_by_fragment | Establece que la propiedad TextState de la celda es sobrescrita por la propiedad TextState de TextFragment. |
| paragraphs | Obtiene o establece el texto formateado de la celda. |
| is_word_wrapped | Obtiene o establece si el texto de la celda está envuelto por palabras. |
| vertical_alignment | Obtiene o establece la alineación vertical. |
| col_span | Obtiene o establece la extensión de columna. |
| row_span | Obtiene o establece la extensión de fila. |
| ancho | Obtiene o establece el ancho de columna. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| clone() | Clona la celda. |
