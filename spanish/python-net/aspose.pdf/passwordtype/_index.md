## PasswordType enumeration

Este enumerado representa los tipos de contraseña conocidos utilizados para documentos PDF protegidos con contraseña.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | El documento PDF no está protegido con contraseña. |
| USER | El documento PDF se abrió usando la contraseña de apertura del documento (acceso restringido). |
| OWNER | El documento PDF se abrió usando la contraseña de cambio de permisos (acceso total). |
| INACCESIBLE | El documento PDF está protegido con contraseña, pero ambas contraseñas de usuario y propietario no están vacías y <br/>            ninguna de las contraseñas fue definida o la contraseña suministrada era incorrecta. Por lo tanto es imposible deducir el tipo de contraseña. |
