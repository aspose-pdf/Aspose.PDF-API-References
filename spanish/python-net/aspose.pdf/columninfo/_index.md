## ColumnInfo class

Esta clase representa información de columnas.

El tipo ColumnInfo expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| ColumnInfo() | Inicializa una nueva instancia de la clase ColumnInfo |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| column_widths | Obtiene o establece una cadena que contiene el ancho de las columnas. <br/>            El valor de cada columna debe estar separado por un espacio en blanco. La unidad predeterminada es punto,<br/>            pero también se admiten cm, pulgada y porcentaje del ancho disponible.<br/>            Por ejemplo,"120 2.5cm 1.5inch" |
| column_spacing | Obtiene o establece una cadena que contiene el espaciado entre columnas. <br/>            El valor de cada espaciado debe estar separado por un espacio en blanco. La unidad predeterminada es punto,<br/>            pero también se admiten cm y pulgada. Por ejemplo,"120 2.5cm 1.5inch". |
| column_count | Obtiene o establece un valor entero que indica el número de columnas. |
