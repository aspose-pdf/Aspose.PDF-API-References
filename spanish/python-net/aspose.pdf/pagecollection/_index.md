## PageCollection class

Colección de páginas de documentos PDF.

El tipo PageCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_synchronized | Devuelve true si el objeto está sincronizado. |
| sync_root | Obtiene el objeto de sincronización de la colección. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene la página por índice. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add(entity) | Agrega página a la colección. |
| add() | Agrega página a la colección. |
| add(pages) | Agrega a la colección todas las páginas de la lista. |
| add(pages) | Agrega a la colección todas las páginas del arreglo. |
| delete(index) | Elimina la página especificada. |
| delete() | Elimina la página especificada. |
| delete(pages) | Elimina las páginas especificadas cuyos números están indicados en el arreglo. |
| accept(visitor) | Acepta el objeto visitante [AnnotationSelector](/pdf/python-net/aspose.pdf.annotations/annotationselector/) que proporciona funcionalidad para trabajar con anotaciones. |
| accept(visitor) | Acepta el objeto visitante [ImagePlacementAbsorber](/pdf/python-net/aspose.pdf/imageplacementabsorber/) que proporciona funcionalidad para trabajar con objetos de colocación de imágenes. |
| accept(visitor) | Acepta el objeto visitante [TextFragmentAbsorber](/pdf/python-net/aspose.pdf.text/textfragmentabsorber/) que proporciona funcionalidad para trabajar con objetos de texto. |
| accept(visitor) | Acepta el objeto visitante [TextAbsorber](/pdf/python-net/aspose.pdf.text/textabsorber/) que proporciona funcionalidad para trabajar con objetos de texto. |
| insert(page_number) | Inserta una página vacía en la colección en la posición especificada. |
| insert(page_number, entity) | Inserta una página vacía en la colección en la posición especificada. |
| insert(page_number, pages) | Inserta páginas de la colección en el documento. |
| insert(page_number, pages) | Inserta páginas del arreglo en el documento. |
| index_of(entity) | Devuelve el índice de la página especificada. |
| flatten() | Elimina todos los campos ubicados en las páginas y coloca sus valores en su lugar. |
| free_memory() | Borra los datos en caché |
