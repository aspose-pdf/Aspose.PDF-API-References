## Resources class

Clase que representa recursos de página.

El tipo Resources expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| forms | Obtiene la colección de formularios [forms](/pdf/python-net/aspose.pdf/resources/) |
| images | Obtiene la colección de imágenes [images](/pdf/python-net/aspose.pdf/resources/) |
| fonts | Obtiene la colección de fuentes [fonts](/pdf/python-net/aspose.pdf/resources/) |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_fonts(create_if_absent) | Devuelve la colección de fuentes. Si los recursos no contienen una entrada de fuentes, se creará dependiendo de la bandera CreateIfAbsent. |
