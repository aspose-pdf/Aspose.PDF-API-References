## PdfASymbolicFontEncodingStrategy class

Esta clase describe reglas que pueden usarse para ajustar el proceso de copiar datos de codificación para casos<br/>            cuando una fuente TrueType simbólica tiene más de una codificación.<br/>            Algunos documentos PDF después de la conversión al formato PDF/A pueden presentar el error <br/>            "More than one encoding in symbolic TrueType font's cmap". <br/>            ¿Cuál es la razón de este error? Todas las fuentes TrueType simbólicas tienen una tabla especial "cmap"<br/>            en sus datos internos. Esta tabla asigna códigos de caracteres a índices de glifos. <br/>            Y esta tabla puede contener diferentes subtablas de codificación que<br/>            describen las codificaciones usadas. Consulte información avanzada sobre las tablas cmap en<br/>            https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6cmap.html.<br/>            Normalmente la tabla cmap contiene varias subtablas de codificación, pero la norma PDF/A requiere<br/>            que solo una subtabla de codificación (3,0) permanezca para esta fuente en el documento PDF/A. <br/>            Y la pregunta clave aquí: ¿qué datos deben tomarse de otras subtablas para copiar en<br/>            la tabla de codificación de destino (3,0)? La mayoría de las fuentes tienen tablas cmap 'bien formadas' donde<br/>            cada subtabla de codificación es totalmente coherente con otra subtabla. Pero algunas fuentes<br/>            tienen tablas cmap con colisiones, por ejemplo una subtabla tiene el índice de glifo <br/>            100 para unicode 100, pero otra subtabla tiene el índice de glifo 200 para el mismo unicode 100.<br/>            Para resolver estos problemas se necesita una estrategia especial. <br/>            Por defecto se utiliza la siguiente estrategia: <br/>            se busca la subtabla mac(1,0). Si se encuentra esta tabla, solo se usan esos datos para rellenar la tabla de destino<br/>            (3,0). Si no se encuentra la subtabla mac, entonces se iteran todas las subtablas excepto (3,0) <br/>            y se usan para copiar datos a la subtabla de destino (3,0). Además, el mapeo para cada unicode (unicode, índice de glifo)<br/>            se copia a la tabla de destino solo si la tabla de destino no contiene ese unicode en ese momento. <br/>            Así, por ejemplo, si la primera subtabla tiene el índice de glifo 100 para unicode 100, y la siguiente subtabla tiene<br/>            el índice de glifo 200 para el mismo unicode 100, solo se copiarán los datos de la primera subtabla (unicode=100, índice de glifo = 100). <br/>            Por lo tanto, cada subtabla anterior tiene precedencia sobre la siguiente. <br/>            Las propiedades de esta clase [PdfASymbolicFontEncodingStrategy](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) ayudan a ajustar el comportamiento predeterminado. <br/>            Si la propiedad [preferred_cmap_encoding_table](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) de tipo [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            está establecida, entonces la subtabla relevante se usará con precedencia sobre la subtabla mac(1,0). El valor 'MacTable' de<br/>            la enumeración [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/) no tiene sentido en este caso, ya que<br/>            apunta a la misma subtabla mac (1,0) que se usará por defecto. <br/>            La propiedad [None](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) descarta todas las prioridades para cualquier subtabla.<br/>            Si esta propiedad está establecida, solo se usarán las subtablas de la cola declarada en el orden especificado.<br/>            Si las subtablas especificadas no se encuentran, entonces se utilizará la iteración predeterminada de todas las subtablas y la estrategia de copia descrita arriba<br/>            .<br/>            El objeto [QueueItem](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy/queueitem/) especifica la subtabla de codificación usada. Esta subtabla puede establecerse<br/>            mediante una combinación de miembros (PlatformID, PlatformSpecificId) o mediante la enumeración [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            .
