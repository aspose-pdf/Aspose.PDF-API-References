## OutlineItemCollection class

Representa una entrada del esquema en la jerarquía del esquema de un documento PDF.

El tipo OutlineItemCollection expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| OutlineItemCollection(outlines) | Inicializa una nueva instancia de la clase OutlineItemCollection |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| visible_count | Obtiene el número total de elementos de esquema en todos los niveles de la jerarquía de esquema del documento. |
| title | Obtiene o establece el título de este elemento de esquema. |
| destino | Obtiene o establece el destino de este elemento de esquema. |
| action | Obtiene o establece la acción de este elemento de esquema. |
| color | Obtiene o establece el color del texto del título de este elemento de esquema. |
| italic | Obtiene o establece la bandera italic para el texto del título de este elemento de esquema |
| bold | Obtiene o establece la bandera bold para el texto del título de este elemento de esquema |
| first | Obtiene el elemento de esquema que representa el primer elemento de nivel superior en la jerarquía de esquema. |
| último | Obtiene el elemento de esquema que representa el último elemento de nivel superior en la jerarquía de esquema. |
| prev | Obtiene el elemento de esquema que representa el elemento anterior relativo a este elemento en la jerarquía de esquema. |
| next | Obtiene el elemento de esquema que representa el siguiente elemento relativo a este elemento en la jerarquía de esquema. |
| has_next | Comprueba si el elemento de esquema representa el siguiente elemento relativo a este elemento en la jerarquía de esquema. |
| padre | Obtiene el objeto padre de este elemento de esquema en la jerarquía de esquema. |
| is_synchronized | Obtiene el valor que indica si el acceso a esta colección está sincronizado (seguro para subprocesos). |
| sync_root | Obtiene el objeto que puede usarse para sincronizar el acceso a esta colección. |
| abrir | Obtiene o establece el estado abierto (true/false) del elemento de esquema. |
| nivel | Obtiene el nivel de jerarquía del elemento de esquema. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene el elemento de esquema de la colección usando el índice. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| delete() | Elimina este elemento del esquema del documento de la jerarquía de esquemas. |
| delete(name) | Elimina la entrada del esquema con el nombre especificado de la jerarquía del esquema del documento. |
| insert(index, outline) | Inserta el elemento del esquema en la colección en el lugar especificado. |
