## NamedDestinationCollection class

La clase representa la colección de todos los destinos (un árbol de nombres que asigna cadenas de nombres a destinos (ver 12.3.2.3, "Named Destinations") y (ver 7.7.4, "Name Dictionary")) en el documento pdf.

El tipo NamedDestinationCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| count | Recuento de destinos nombrados. |
| names | Lista de nombres de los destinos. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| remove(name) | Eliminar destino nombrado. |
| add(name, appointment) | Agregar nuevo destino nombrado. |
