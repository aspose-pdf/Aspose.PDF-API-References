## ImagePlacement class

Representa las características de una imagen colocada en una página de documento Pdf.

El tipo ImagePlacement expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| matrix | Matriz de transformación actual para esta imagen. |
| rectangle | Obtiene el rectángulo de la Imagen. |
| operador | Operador usado para mostrar la imagen. |
| rotation | Obtiene el ángulo de rotación de la Imagen. |
| resolution | Obtiene la resolución de la Imagen. |
| image | Obtiene el objeto de recurso XImage relacionado. |
| página | Obtiene la página que contiene la imagen. |
| compositing_parameters | Obtiene los parámetros de composición del estado gráfico activo para la imagen colocada en la página. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| save(stream) | Guarda la imagen con las transformaciones correspondientes: escalado, rotación y resolución. |
| `save(stream, format)` | Guarda la imagen con las transformaciones correspondientes: escalado, rotación y resolución. |
| `hide()` | Elimina la imagen de la página. |
| `replace(image)` | Reemplaza la imagen en la colección con otra imagen. |
