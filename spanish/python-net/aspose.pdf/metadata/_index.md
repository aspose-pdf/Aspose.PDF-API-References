## Metadata class

Proporciona acceso al flujo de metadatos XMP.

El tipo Metadata expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_fixed_size | Comprueba si la colección tiene tamaño fijo. |
| keys | Obtiene la colección de claves de metadatos. |
| values | Obtiene los valores en los metadatos. |
| is_synchronized | Comprueba si la colección está sincronizada. |
| sync_root | Obtiene el objeto de sincronización de la colección. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| register_namespace_uri(prefix, namespace_uri) | Registra el URI del espacio de nombres. |
| register_namespace_uri(prefix, namespace_uri, schema_description) | Registra el URI del espacio de nombres. |
| add(key, value) | Añade un valor a los metadatos. |
| add(key, value) | Añade un valor a los metadatos. |
| add(prefix, value) | Añade la extensión pdf a los metadatos. |
| get_namespace_uri_by_prefix(prefix) | Devuelve el URI del espacio de nombres por prefijo. |
| get_prefix_by_namespace_uri(namespace_uri) | Devuelve el prefijo por URI del espacio de nombres. |
| contains(key) | Comprueba si la clave está contenida en los metadatos. |
| remove(key) | Elimina la entrada de los metadatos. |
| contains_key(key) | Determina si este diccionario contiene la clave especificada. |
| try_get_value(key, value) | Intenta encontrar la clave en el diccionario y recupera el valor si se encuentra. |
