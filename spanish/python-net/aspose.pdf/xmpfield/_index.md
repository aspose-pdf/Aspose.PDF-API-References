## XmpField class

Representa el campo XMP.

El tipo XmpField expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| empty | Obtiene un campo xmp vacío. |
| lang | Obtiene el calificador xml:lang. |
| prefix | Obtiene el prefijo. |
| namespace_uri | Obtiene el URI del espacio de nombres. |
| local_name | Obtiene o establece el nombre del local. |
| name | Obtiene el nombre. |
| value | Obtiene el valor. |
| field_type | Obtiene el tipo del campo. |
| is_empty | Obtiene un valor que indica si esta instancia está vacía. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| to_structure() | Obtiene el valor como una estructura. |
| to_array() | Obtiene el valor como una matriz. |
