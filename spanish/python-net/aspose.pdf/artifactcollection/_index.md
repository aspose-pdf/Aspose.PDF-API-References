## ArtifactCollection class

Clase representa la colección de artefactos.

El tipo ArtifactCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_synchronized | ¿Está este objeto sincronizado? |
| sync_root | Obtiene el objeto de sincronización de la colección. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene el artefacto por índice. El índice comienza en 1. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| delete(artifact) | Elimina el artefacto especificado. |
| delete(index) | Elimina el artefacto por su índice. |
| find_by_value(name, expected_value) | Busca artefactos por valor personalizado. |
| update(artifact) | Actualiza el artefacto dentro de la colección. |
