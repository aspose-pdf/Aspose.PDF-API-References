## EmbeddedFileCollection class

Clase que representa la colección de archivos incrustados.

El tipo EmbeddedFileCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_synchronized | Obtiene un valor que indica si el acceso a esta colección está sincronizado (seguro para subprocesos). |
| sync_root | Obtiene un objeto que puede usarse para sincronizar el acceso a esta colección. |
| keys | Devuelve una lista de claves de archivos adjuntos. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene el archivo incrustado por su índice. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| delete(name) | Elimina el archivo de la colección por su clave en la colección. |
| delete() | Elimina el archivo de la colección por su clave en la colección. |
| add(key, file) | Agrega el archivo a los archivos incrustados con la clave especificada. |
| delete_by_key(key) | Elimina el archivo de la colección por su clave en la colección. |
| find_by_name(name) | Devuelve el archivo incrustado por su nombre. |
