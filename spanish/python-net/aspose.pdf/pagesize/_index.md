## PageSize class

Clase que representa el tamaño de la página en un documento PDF.

El tipo PageSize expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| PageSize(x, y) | Inicializa una nueva instancia de la clase PageSize |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| ancho | Obtiene o establece el ancho de la página. |
| alto | Obtiene o establece la altura de la página. |
| is_landscape | Obtiene la orientación de la página. Devuelve true si es orientación horizontal y false si es vertical. |
| a0 | Tamaño A0 (1189x840 mm). |
| a1 | Tamaño A1 (840x594 mm). |
| a2 | Tamaño A2 (594x420 mm). |
| a3 | Tamaño A3 (420x297 mm). |
| a4 | Tamaño A4 (297x210 mm). |
| a5 | Tamaño A5 (210x148 mm). |
| a6 | Tamaño A6 (148x105 mm). |
| b5 | Tamaño B5 (250x176 mm). |
| page_letter | Tamaño Letter (279x216 mm). |
| page_legal | Tamaño Legal (356x216 mm). |
| page_ledger | Tamaño Ledger (432x279 mm). |
| p11x17 | Formato de 11x17 pulgadas. |
