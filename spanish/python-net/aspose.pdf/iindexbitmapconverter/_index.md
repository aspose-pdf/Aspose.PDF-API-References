## IIndexBitmapConverter class

Esta interfaz está declarada para la personalización de algoritmos de cuantización. <br/>            Los usuarios pueden implementar su propia realización de estos algoritmos (por ejemplo, algoritmos basados en código no administrado).

El tipo IIndexBitmapConverter expone los siguientes miembros:
## Métodos
| Nombre | Descripción |
| :- | :- |
| get_1_bpp_image(src) | Devuelve la representación de mapa de bits de 1Bpp |
| get_4_bpp_image(src) | Devuelve la representación de mapa de bits de 4Bpp |
| get_8_bpp_image(src) | Devuelve la representación de mapa de bits de 8Bpp |
