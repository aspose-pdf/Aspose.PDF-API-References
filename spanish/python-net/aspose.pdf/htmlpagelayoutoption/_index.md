## HtmlPageLayoutOption enumeration

Especifica banderas que, junto con otras opciones, determinan tamaños y disposiciones de las páginas.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | Valor predeterminado que indica que la HtmlPageLayoutOption no afectará los tamaños y diseños de las páginas. |
| FIT_TO_WIDEST_CONTENT_WIDTH | Indica que el ancho de la página se determina a partir del tamaño del contenido mismo, no del ancho de página especificado. |
| SCALE_TO_PAGE_WIDTH | Indica que el contenido del documento se escalará para ajustarse a la página. |
