## INamedDestinationCollection class

Colección de Destinos con Nombre.

El tipo INamedDestinationCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| count | Devuelve el número de destinos. |
| names | Obtiene una matriz de nombres de los destinos. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| remove(name) | Elimina el destino por su nombre. |
| add(name, appointment) | Agrega un nuevo destino con nombre. |
