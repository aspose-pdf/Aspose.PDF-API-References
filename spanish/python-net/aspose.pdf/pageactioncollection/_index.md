## PageActionCollection class

Esta clase describe acciones de página

El tipo PageActionCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| on_open | Una acción que se ejecutará cuando la página se abra. |
| on_close | Una acción que se ejecutará cuando la página se cierre. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| remove_actions() | Elimina todas las acciones de la anotación. |
