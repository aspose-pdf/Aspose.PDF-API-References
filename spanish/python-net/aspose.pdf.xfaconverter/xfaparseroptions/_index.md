## XfaParserOptions class

clase para manejar la encapsulación de datos relacionados

El tipo XfaParserOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| XfaParserOptions(page_size) | Inicializa una nueva instancia de la clase XfaParserOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| page_size | Obtiene o establece el tamaño de la página. |
| signed | Si esta propiedad es verdadera, el documento se convertirá utilizando el flujo de formulario xfa (si existe).<br/>            Si es falsa, el flujo de formulario xfa será ignorado.<br/>            Esta propiedad se introdujo porque no está claro cómo calcular la suma de verificación que se usa para comprobar la firma. |
| emulate_requierd_groups | Si esta propiedad es verdadera, se dibujarán rectángulos rojos adicionales para los "grupos excluidos" Xfa requeridos<br/>            Esta propiedad se introdujo porque la ausencia de análogos de los grupos excluidos durante la conversión de la representación Xfa de los formularios <br/>            al estándar.<br/>            Es falsa por defecto. |
| base_path | Obtiene o establece la ruta base. |
