## MarkupSection class

Representa una sección de marcado - la región rectangular de una página que contiene texto y puede dividirse visualmente de otros bloques de texto.

El tipo MarkupSection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| rectangle | Rectángulo de sección |
| fragments | Colección de objetos [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) no vacíos que están dentro de la sección. |
| paragraphs | Colección de objetos [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) que están dentro de la sección. |
