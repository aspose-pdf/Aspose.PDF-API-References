## TextSegment class

Representa un segmento de texto PDF.

El tipo TextSegment expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextSegment() | Crea un objeto TextSegment. |
| TextSegment(text) | Inicializa una nueva instancia de la clase TextSegment |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| start_char_index | Obtiene el índice del carácter inicial del segmento actual en el operador de mostrar texto (Tj, TJ). |
| end_char_index | Obtiene el índice del carácter final del segmento actual en el operador de mostrar texto (Tj, TJ). |
| text | Obtiene o establece el objeto de texto de cadena que representa el objeto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| text_state | Obtiene o establece el estado del texto para el texto que representa el objeto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| position | Obtiene la posición del texto, representado con el objeto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| rectangle | Obtiene el rectángulo del TextSegment |
| baseline_position | Obtiene la posición del texto, representado con el objeto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/).<br/>            El YIndent de la estructura Position representa la coordenada de la línea base del segmento de texto. |
| text_edit_options | Obtiene o establece las opciones de edición de texto. Las opciones definen un comportamiento especial cuando el símbolo solicitado no puede escribirse con la fuente. |
| caracteres | Obtiene una colección de objetos CharInfo que representan información sobre los caracteres en el segmento de texto. |
| hipervínculo | Obtiene o establece el hipervínculo del segmento (para generador de PDF). |
