## TextParagraph class

Representa párrafos de texto como un objeto de texto multilínea.

El tipo TextParagraph expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextParagraph() | Inicializa una nueva instancia de la clase TextParagraph |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| vertical_alignment | Obtiene o establece la alineación vertical del texto dentro del [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) del párrafo. |
| subsequent_lines_indent | Obtiene o establece el valor de sangría de líneas subsecuentes.<br/>            Si se establece en un valor distinto de cero, tiene una ventaja sobre el valor FormattingOptions.SubsequentLinesIndent. |
| first_line_indent | Obtiene o establece el valor de sangría de líneas subsecuentes.<br/>            Si se establece en un valor distinto de cero, tiene una ventaja sobre el valor FormattingOptions.SubsequentLinesIndent. |
| justify | Obtiene o establece el valor que indica si el texto está justificado. |
| horizontal_alignment | Obtiene o establece la alineación horizontal del texto dentro del [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) del párrafo. |
| formatting_options | Obtiene o establece opciones de formato. |
| position | Obtiene o establece la posición del párrafo. |
| text_rectangle | Obtiene el rectángulo del texto colocado en el párrafo. |
| rectangle | Obtiene o establece el rectángulo del párrafo. |
| margen | Obtiene o establece el relleno. |
| rotation | Obtiene o establece el ángulo de rotación en grados. |
