## TextExtractionError class

Describe el error de extracción de texto que ha aparecido en el documento PDF.

El tipo TextExtractionError expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| summary | Breve descripción del error. |
| descripción | Descripción ampliada del error. |
| location | Ubicación del error. |
| font_key | Clave (nombre PDF) del objeto Font que se utiliza para mostrar el texto que causa el error de extracción. |
| font_name | Nombre legible (interno) del objeto Font que se utiliza para mostrar el texto que causa el error de extracción. |
| extracted_text | Texto que se extrajo realmente. |
