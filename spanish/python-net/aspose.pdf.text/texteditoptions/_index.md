## TextEditOptions class

Describe las opciones de operaciones de edición de texto.

El tipo TextEditOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextEditOptions(no_character_behavior) | Inicializa una nueva instancia de la clase TextEditOptions |
| TextEditOptions(font_replace_behavior) | Inicializa una nueva instancia de la clase TextEditOptions |
| TextEditOptions(allow_language_transformation) | Inicializa una nueva instancia de la clase TextEditOptions |
| TextEditOptions(language_transformation_behavior) | Inicializa una nueva instancia de la clase TextEditOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| replacement_font | Obtiene o establece la fuente utilizada para reemplazar si la fuente del usuario no contiene el carácter requerido |
| no_character_behavior | Obtiene o establece el modo que define el comportamiento en caso de que las fuentes no contengan los caracteres solicitados. |
| font_replace_behavior | Obtiene el modo que define el comportamiento para escenarios de reemplazo de fuentes. |
| allow_language_transformation | Obtiene o establece el valor que permite el uso de la transformación de idioma durante la adición o edición de texto.<br/>            true - la transformación de idioma se aplicará si es necesario (valor predeterminado).<br/>            false - la transformación de idioma NO se aplicará. |
| language_transformation_behavior | Obtiene el modo que define el comportamiento para escenarios de transformación de idioma. |
| clipping_paths_processing | Obtiene el modo para procesar la ruta de recorte del texto editado. |
| to_attempt_get_underline_from_source | Obtiene o establece el valor que permite buscar subrayado de texto en la página del documento fuente.<br/>            (Obsoleto) Por favor use TextSearchOptions.SearchForTextRelatedGraphics en su lugar. |
