## TextExtractionOptions class

Representa opciones de extracción de texto

El tipo TextExtractionOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextExtractionOptions(formatting_mode) | Inicializa una nueva instancia de la clase TextExtractionOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| formatting_mode | Obtiene el modo de formato. |
| scale_factor | Obtiene o establece el factor que se aplicará para escalar el tamaño de fuente durante la extracción en modo puro.<br/>            Establecer un valor menor genera más espacios en el texto extraído.<br/>            El valor predeterminado es 1 - sin escalado;<br/>            Establecer el valor a cero permite que el algoritmo elija el escalado automáticamente. |
