## FontCollection class

Representa una colección de fuentes.

El tipo FontCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| sync_root | Obtiene un objeto que puede usarse para sincronizar el acceso a la colección. |
| is_synchronized | Obtiene un valor que indica si el acceso a la colección está sincronizado (seguro para subprocesos). |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene el elemento de fuente en el índice especificado. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| add(new_font, res_name) | Agrega una nueva fuente a los recursos de fuentes y devuelve el nombre asignado automáticamente al recurso de fuente. |
