## PageMarkup class

El marcado de página está representado por colecciones de [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) y [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/).

El tipo PageMarkup expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| número | Obtiene el número de página procesado. |
| rectangle | Obtiene el rectángulo de página procesado. |
| sections | Obtiene una colección de [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) que se encontró en la página. |
| paragraphs | Obtiene una colección de [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) que se encontró en la página. |
| text_fragments | Obtiene una colección de [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) que se encontró en la página. |
| is_multicolumn_paragraphs_allowed | Obtiene o establece el valor que indica si las líneas de texto iniciales de una sección siguiente pueden tratarse como continuación del último párrafo de una sección anterior. |
