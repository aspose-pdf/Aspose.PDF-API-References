## TextFormattingOptions class

Representa opciones de formato de texto

El tipo TextFormattingOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextFormattingOptions(wrap_mode) | Inicializa una nueva instancia de la clase TextFormattingOptions |
| TextFormattingOptions() | Inicializa una nueva instancia del objeto [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) con modo de ajuste de línea indefinido. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| wrap_mode | Obtiene o establece el modo de ajuste de línea.<br/>            El valor predeterminado es WordWrapMode.NoWrap |
| line_spacing | Obtiene o establece el modo de interlineado.<br/>            El valor predeterminado es LineSpacingMode.FontSize |
| hyphen_symbol | Obtiene o establece el símbolo de guión que se usa en el proceso de separación silábica. |
| subsequent_lines_indent | Obtiene o establece el valor de sangría de líneas subsiguientes. |
| first_line_indent | Obtiene o establece el valor de sangría de la primera línea. |
