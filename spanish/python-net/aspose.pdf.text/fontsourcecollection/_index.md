## FontSourceCollection class

Representa la colección de fuentes.

El tipo FontSourceCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| sync_root | Obtiene un objeto que puede usarse para sincronizar el acceso a la colección. |
| is_synchronized | Obtiene un valor que indica si el acceso a la colección está sincronizado (seguro para subprocesos). |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene el elemento de fuente en el índice especificado. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| delete(font_source) | Elimina el elemento de origen de fuente. |
