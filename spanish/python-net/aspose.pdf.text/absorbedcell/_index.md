## AbsorbedCell class

Representa una celda de tabla que existe en la página

El tipo AbsorbedCell expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| text_fragments | Obtiene una colección de objetos [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) que describen el texto contenido en la celda |
| rectangle | Obtiene el rectángulo que describe la posición de la celda en la página |
