## TextRenderingMode enumeration

El modo de renderizado de texto, Tmode, determina si al mostrar texto se deben trazar los contornos de los glifos, rellenarlos, usarlos como límite de recorte, o alguna combinación de los tres.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| FILL_TEXT | Rellenar texto. |
| STROKE_TEXT | Trazar texto. |
| FILL_THEN_STROKE_TEXT | Rellenar, luego trazar el texto. |
| INVISIBLE | Ni rellenar ni trazar el texto (invisible). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Rellenar texto y añadir al trazado para recorte (ver 9.3.6, "Text Rendering Mode,"). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Trazar texto y añadir al trazado para recorte. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Rellenar, luego trazar el texto y añadir al trazado para recorte. |
| ADD_PATH_TO_CLIPPING | Añadir texto al trazado para recorte. |
