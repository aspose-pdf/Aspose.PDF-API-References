## TextReplaceOptions class

Representa opciones de reemplazo de texto

El tipo TextReplaceOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextReplaceOptions(scope) | Inicializa una nueva instancia de la clase TextReplaceOptions |
| TextReplaceOptions(adjustment) | Inicializa una nueva instancia de la clase TextReplaceOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| replace_scope | Obtiene o establece el alcance donde se aplica la operación de reemplazo de texto |
| replace_adjustment_action | Obtiene o establece una acción que se realizará después de reemplazar el fragmento de texto por uno más corto. |
| adjustment_new_line_spacing | Obtiene o establece el valor del interlineado que se usa si el ajuste de reemplazo obliga a crear una nueva línea de texto.<br/>            El valor esperado es un multiplicador del tamaño de fuente del texto reemplazado. El valor predeterminado es 1.2. |
