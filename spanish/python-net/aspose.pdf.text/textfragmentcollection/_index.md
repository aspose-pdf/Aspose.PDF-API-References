## TextFragmentCollection class

Representa una colección de fragmentos de texto

El tipo TextFragmentCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| sync_root | Obtiene un objeto que puede usarse para sincronizar el acceso a la colección. |
| is_synchronized | Obtiene un valor que indica si el acceso a la colección está sincronizado (seguro para subprocesos). |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene el elemento fragmento de texto en el índice especificado. |
