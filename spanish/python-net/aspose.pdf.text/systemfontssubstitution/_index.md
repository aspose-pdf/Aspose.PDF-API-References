## SystemFontsSubstitution class

Representa una clase para una estrategia de sustitución de fuentes que reemplaza fuentes con fuentes del sistema.

El tipo SystemFontsSubstitution expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SystemFontsSubstitution(font_categories) | Inicializa una nueva instancia de la clase SystemFontsSubstitution |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| font_categories | Obtiene o establece las categorías de fuentes de sustitución que deben ser reemplazadas por fuentes del sistema. |
| default_font | Obtiene o establece la fuente de sustitución predeterminada.<br/>            La fuente se usa cuando no se encontró ninguna otra sustitución válida pero la fuente inicial pertenece a la categoría de sustitución objetivo ([font_categories](/pdf/python-net/aspose.pdf.text/systemfontssubstitution/)). |
