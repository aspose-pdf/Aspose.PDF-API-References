## AbsorbedTable class

Representa una tabla que existe en la página

El tipo AbsorbedTable expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| row_list | Obtiene una IList de solo lectura que contiene las filas de la tabla |
| rectangle | Obtiene el rectángulo que describe la posición de la tabla en la página |
| page_num | Obtiene el número de la página que contiene esta tabla |
