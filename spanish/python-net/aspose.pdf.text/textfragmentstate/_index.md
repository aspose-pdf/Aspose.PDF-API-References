## TextFragmentState class

Representa el estado de texto de un fragmento de texto.

El tipo TextFragmentState expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| TextFragmentState(fragment) | Inicializa una nueva instancia de la clase TextFragmentState |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| character_spacing | Obtiene o establece el espaciado de caracteres del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| line_spacing | Obtiene o establece el espaciado de líneas del texto. |
| horizontal_scaling | Obtiene o establece la escala horizontal del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| subscript | Obtiene o establece el subíndice del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| superscript | Obtiene o establece el superíndice del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| word_spacing | Obtiene o establece el espaciado de palabras del texto. |
| invisible | Obtiene o establece la invisibilidad del texto. |
| rendering_mode | Obtiene o establece el modo de renderizado del texto. |
| font_size | Obtiene o establece el tamaño de fuente del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font | Obtiene o establece la fuente del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| foreground_color | Obtiene o establece el color de primer plano del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| stroking_color | Obtiene o establece el color de las operaciones de trazo de la representación de [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) (trazar texto, borde del rectángulo) |
| underline | Obtiene o establece el subrayado del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| strike_out | Establece el tachado del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| background_color | Establece el color de fondo del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font_style | Establece el estilo de fuente del texto, representado por el objeto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| horizontal_alignment | Obtiene o establece la alineación horizontal del texto. |
| TAB_TAG | Puedes colocar esta etiqueta en el texto para declarar tabulación. |
| TABSTOP_DEFAULT_VALUE | Valor predeterminado de la tabulación en anchuras del carácter de espacio de la fuente predeterminada. |
| tab_stops | Obtiene los tabuladores para el texto. |
| formatting_options | Obtiene o establece opciones de formato.<br/>            La configuración de las opciones será efectiva solo en escenarios de generador. |
| rotation | Obtiene o establece el ángulo de rotación en grados. |
| draw_text_rectangle_border | Obtiene o establece la bandera que indica si se dibuja el borde del rectángulo de texto. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| apply_changes_from(text_state) | Aplica configuraciones desde otro textState. |
| measure_string(str) | Mide la cadena. |
