## MarkupParagraph class

Representa un párrafo.

El tipo MarkupParagraph expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| puntos | Puntos del polígono que describe el párrafo.<br/>            El punto inicial es la esquina inferior izquierda del párrafo. Y los siguientes puntos están en secuencia antihoraria. |
| puntos_secundarios | Puntos del polígono secundario que describen la continuación del párrafo. No será nulo si el párrafo continúa en la siguiente columna o página.<br/>            El punto inicial es la esquina inferior izquierda del párrafo. Y los siguientes puntos están en secuencia antihoraria. |
| números_de_página_de_continuación | Lista de números de página en los que el párrafo continúa. Coincidirá con la página donde comenzó el párrafo si continúa en la siguiente columna de la misma página. |
| fragments | Colección de objetos [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) no vacíos del párrafo. |
| líneas | Líneas del párrafo. Cada línea está representada por una lista de fragmentos de texto. |
| text | Obtiene el objeto de texto cadena que representa el objeto [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/). |
