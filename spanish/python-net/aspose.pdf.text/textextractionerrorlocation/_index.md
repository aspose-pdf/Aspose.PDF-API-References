## TextExtractionErrorLocation class

Representa la ubicación en el documento PDF donde ha aparecido el error de extracción de texto.

El tipo TextExtractionErrorLocation expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| path | Ubicación del documento PDF donde ha aparecido el error de extracción de texto. |
| page_number | Número de la página del documento donde se ha localizado el error de extracción de texto. |
| object_type | Tipo del objeto PDF (Page o xForm) en el que se ha localizado el error de extracción de texto del flujo de contenido. |
| form_key | Clave (nombre) del PDF Form XObject en el que se ha localizado el error de extracción de texto del flujo de contenido. No está vacío si ObjectType == 'xForm'. |
| operator_index | Índice del operador que muestra texto en el flujo de contenido (colección de operadores) que causa el error de extracción de texto. |
| operator_string | Operador que muestra texto que causa el error de extracción de texto. |
| font_used_key | Clave (nombre) del objeto PDF Font que se utiliza para mostrar el operador que provoca un error de extracción de texto. |
| text_start_point | Clave (nombre) del objeto PDF Font que se utiliza para mostrar el operador que provoca un error de extracción de texto. |
