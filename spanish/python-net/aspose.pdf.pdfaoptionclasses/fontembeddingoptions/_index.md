## FontEmbeddingOptions class

El estándar PDF/A requiere que todas las fuentes estén incrustadas en el documento.<br/>            Esta clase incluye indicadores para los casos en que no es posible incrustar alguna fuente porque esa fuente está ausente <br/>            en el PC de destino.

El tipo FontEmbeddingOptions expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| FontEmbeddingOptions() | Inicializa una nueva instancia de la clase FontEmbeddingOptions |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| use_default_substitution | Declara sustituir fuentes no incrustadas usando la estrategia de sustitución de fuentes predeterminada. Por defecto false; |
