## SetColor class

Representa una clase para el operador sc (establece el color para operaciones sin trazo).

El tipo SetColor expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SetColor() | Inicializa el operador. |
| SetColor(g) | Inicializa una nueva instancia de la clase SetColor |
| SetColor(r, g, b) | Inicializa una nueva instancia de la clase SetColor |
| SetColor(c, m, y, k) | Inicializa una nueva instancia de la clase SetColor |
| SetColor(color) | Inicializa una nueva instancia de la clase SetColor |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| index | Ninguno |
| r | Obtiene el componente rojo del color |
| g | Obtiene el componente verde del color |
| b | Obtiene el componente rojo del color |
| c | Obtiene el componente cian del color CMYK. |
| m | Obtiene el componente magenta del color CMYK. |
| y | Obtiene el componente amarillo del color CMYK. |
| k | Obtiene el componente negro del color CMYK. |
| grey | Obtiene el componente negro del color gris. |
| color | Obtiene una matriz de componentes de color. |
