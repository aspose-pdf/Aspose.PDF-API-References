## Do class

Clase que representa el operador Do (Invocar XObject).

El tipo Do expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Do(name) | Inicializa una nueva instancia de la clase Do |
| Do() | Construye un nuevo operador Do. <br/>            Se usa para recuperar todos los operadores Do, es decir, sin comprobar sus nombres de argumento. |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| index | Índice del operador en la lista de operadores de la página. |
| name | Nombre del argumento XObject del operador. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| accept(visitor) | Acepta un objeto visitante para procesar el operador. |
| is_text_show_operator(op) | Determina si el operador es el operador responsable de la salida de texto (Tj, TJ, etc) |
