## DP class

Clase que representa el operador DP (punto de contenido marcado designado).

El tipo DP expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| DP(tag) | Inicializa una nueva instancia de la clase DP |
## Propiedades
| Nombre | Descripción |
| :- | :- |

| tag | Obtiene o establece la etiqueta de contenido marcado |
## Métodos
| Nombre | Descripción |
| :- | :- |
