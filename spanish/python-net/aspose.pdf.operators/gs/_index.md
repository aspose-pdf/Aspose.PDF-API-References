## GS class

Clase que representa el operador gs (establecer parámetros desde el diccionario de parámetros del estado gráfico).

El tipo GS expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |

## Propiedades
| Nombre | Descripción |
| :- | :- |
