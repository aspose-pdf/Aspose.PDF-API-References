## SetCharWidthBoundingBox class

Clase que representa el operador d1 (establece el glifo y el cuadro delimitador).

El tipo SetCharWidthBoundingBox expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| index | Índice del operador en la lista de operadores de la página. |
| wx | Desplazamiento horizontal del glifo. |
| wy | Desplazamiento vertical del glifo. |
| llx | Coordenada horizontal inferior izquierda del rectángulo delimitador. |
| lly | Coordenada vertical inferior izquierda del rectángulo delimitador. |
| urx | Coordenada horizontal superior derecha del rectángulo delimitador. |
| ury | Coordenada vertical superior derecha del rectángulo delimitador. |
