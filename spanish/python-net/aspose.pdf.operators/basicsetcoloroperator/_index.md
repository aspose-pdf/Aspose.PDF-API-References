## BasicSetColorOperator class

Clase base para los operadores set color.

El tipo BasicSetColorOperator expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| index | Índice del operador en la lista de operadores de la página. |
| r | Obtiene el componente rojo del color |
| g | Obtiene el componente verde del color |
| b | Obtiene el componente rojo del color |
| c | Obtiene el componente cian del color CMYK. |
| m | Obtiene el componente magenta del color CMYK. |
| y | Obtiene el componente amarillo del color CMYK. |
| k | Obtiene el componente negro del color CMYK. |
| grey | Obtiene el componente negro del color gris. |
| color | Obtiene una matriz de componentes de color. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| accept(visitor) | Acepta el visitante IOperatorSelector que proporciona el procesamiento de operadores. |
| is_text_show_operator(op) | Determina si el operador es el operador responsable de la salida de texto (Tj, TJ, etc) |
| get_color() | Devuelve el color especificado por el operador. |
