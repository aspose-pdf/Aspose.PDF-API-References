## ImageCompressionVersion enumeration

Describe versiones del algoritmo de compresión de imágenes.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| STANDARD | Algoritmo estándar. Valor predeterminado. |
| FAST | Algoritmo mejorado, más rápido que el estándar pero no aplicable a todos los casos. |
| MIXED | Utilice el algoritmo rápido cuando sea posible y el estándar para otros casos. Puede ser más lento que "Fast" pero puede producir una mejor compresión. |
