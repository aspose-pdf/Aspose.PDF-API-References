## TableTRElement class

Representa el elemento de estructura TR en la estructura lógica de la tabla.

El tipo TableTRElement expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| parent_element | Ninguno |
| child_elements | Ninguno |
| default_attribute_owner | Obtiene |
| atributos | Obtiene |
| structure_type | Obtiene el tipo del elemento de estructura. |
| id | Obtiene el ID del elemento de estructura. |
| title | Obtiene o establece el título del elemento de estructura. |
| language | Obtiene o establece el idioma del elemento de estructura. |
| alternative_text | Obtiene o establece el texto alternativo del elemento de estructura. |
| expansion_text | Obtiene o establece el texto de expansión del elemento de estructura. |
| actual_text | Obtiene o establece el texto real del elemento de estructura. |
| background_color | Obtiene o establece el color de fondo de la fila. |
| borde | Obtiene o establece el borde de la fila. |
| default_cell_border | Obtiene el borde predeterminado de la celda. |
| min_row_height | Obtiene la altura de la fila. |
| fixed_row_height | Obtiene la altura fija de la fila - la fila puede tener altura fija. |
| is_in_new_page | Obtiene si la fila fija está en una nueva página - la página con esta propiedad debe imprimirse en la página siguiente. Valor predeterminado false. |
| is_row_broken | Obtiene si la fila puede romperse entre dos páginas. |
| default_cell_text_state | Obtiene o establece el estado de texto predeterminado para las celdas de la fila |
| default_cell_padding | Obtiene o establece el margen predeterminado para las celdas de la fila. |
| vertical_alignment | Obtiene o establece la alineación vertical. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| append_child(element) | Ninguno |
| change_parent_element(new_parent_element) | Cambiar el elemento padre para el elemento de estructura actual |
| generate_id() | Generar ID para el elemento de estructura. |
| set_id(id) | Establece el ID para el elemento de estructura. |
| clear_id() | Borrar el ID del elemento de estructura. |
| set_tag(new_tag) | Establece una etiqueta personalizada para el elemento de estructura. |
| create_th() | Crea [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/) y lo agrega a la tabla actual. |
| create_td() | Crea [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/) y lo agrega a la tabla actual. |
