## TableElement class

Representa el elemento de estructura Table en la estructura lógica.

El tipo TableElement expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| parent_element | Ninguno |
| child_elements | Ninguno |
| default_attribute_owner | Obtiene |
| atributos | Obtiene |
| structure_type | Obtiene el tipo del elemento de estructura. |
| id | Obtiene el ID del elemento de estructura. |
| title | Obtiene o establece el título del elemento de estructura. |
| language | Obtiene o establece el idioma del elemento de estructura. |
| alternative_text | Obtiene o establece el texto alternativo del elemento de estructura. |
| expansion_text | Obtiene o establece el texto de expansión del elemento de estructura. |
| actual_text | Obtiene o establece el texto real del elemento de estructura. |
| background_color | Obtiene o establece el color de fondo de la tabla. |
| borde | Obtiene o establece el borde de la tabla. |
| alineación | Obtiene o establece la alineación de la tabla. |
| corner_style | Obtiene o establece los estilos de las esquinas del borde |
| broken | Obtiene o establece la rotura vertical de la tabla; |
| column_adjustment | Obtiene o establece el ajuste de columna de la tabla. |
| column_widths | Obtiene los anchos de columna de la tabla. |
| default_cell_border | Obtiene el borde predeterminado de la celda. |
| default_cell_padding | Obtiene o establece el relleno predeterminado de la celda. |
| default_cell_text_state | Obtiene o establece el estado de texto predeterminado de la celda. |
| default_column_width | Obtiene o establece el ancho predeterminado de la columna. |
| is_broken | Obtiene o establece si la tabla está rota - se truncará para la página siguiente. |
| is_borders_included | Obtiene o establece el borde incluido en los anchos de columna. |
| left | Obtiene o establece la coordenada izquierda de la tabla. |
| top | Obtiene o establece la coordenada superior de la tabla. |
| repeating_columns_count | Obtiene o establece el número máximo de columnas para la tabla. |
| repeating_rows_count | Obtiene la cantidad de primeras filas repetidas en varias páginas. |
| repeating_rows_style | Obtiene el estilo para las filas repetidas. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| append_child(element) | Ninguno |
| change_parent_element(new_parent_element) | Cambiar el elemento padre para el elemento de estructura actual |
| generate_id() | Generar ID para el elemento de estructura. |
| set_id(id) | Establece el ID para el elemento de estructura. |
| clear_id() | Borrar el ID del elemento de estructura. |
| set_tag(new_tag) | Establece una etiqueta personalizada para el elemento de estructura. |
| create_t_head() | Crea [TableTHeadElement](/pdf/python-net/aspose.pdf.logicalstructure/tabletheadelement/) y lo agrega a la tabla actual. |
