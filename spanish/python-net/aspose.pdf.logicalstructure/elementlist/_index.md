## ElementList class

Representa una colección ordenada de elementos.

El tipo ElementList expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| count | Obtiene el número de elementos en el ElementList. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Devuelve un elemento en el índice especificado. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| item(index) | Recupera un elemento en el índice dado. |
