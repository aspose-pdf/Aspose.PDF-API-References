## Rectangle class

Representa un rectángulo.

El tipo Rectángulo expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Rectangle(left, bottom, width, height) | Inicializa una nueva instancia de la clase Rectángulo |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| graph_info | Obtiene o establece un objeto [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) que indica la información del gráfico, como color,<br/>            ancho de línea, etc. |
| text | Obtiene o establece un texto para la forma |
| rounded_corner_radius | Obtiene o establece un valor float que indica el radio de las esquinas del rectángulo. |
| left | Obtiene o establece un valor float que indica la posición izquierda del rectángulo. |
| bottom | Obtiene o establece un valor float que indica la posición inferior del rectángulo. |
| ancho | Obtiene o establece un valor float que indica el ancho del rectángulo. |
| alto | Obtiene o establece un valor float que indica la altura del rectángulo. |
