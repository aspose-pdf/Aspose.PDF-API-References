## Circle class

Representa un círculo.

El tipo Circle expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Circle(pos_x, pos_y, radius) | Inicializa una nueva instancia de la clase Circle |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| graph_info | Obtiene o establece un objeto [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) que indica la información del gráfico, como color,<br/>            ancho de línea, etc. |
| text | Obtiene o establece un texto para la forma |
| pos_x | Obtiene o establece un valor float que indica la coordenada x del centro del círculo. |
| pos_y | Obtiene o establece un valor float que indica la coordenada y del centro del círculo. |
| radius | Obtiene o establece un valor float que indica el radio del círculo. |
