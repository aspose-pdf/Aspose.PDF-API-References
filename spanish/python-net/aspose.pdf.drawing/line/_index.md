## Line class

Representa una línea.

El tipo Line expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Line(position_array) | Inicializa una nueva instancia de la clase Line |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| graph_info | Obtiene o establece un objeto [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) que indica la información del gráfico, como color,<br/>            ancho de línea, etc. |
| text | Obtiene o establece un texto para la forma |
| position_array | Obtiene o establece un objeto [position_array](/pdf/python-net/aspose.pdf.drawing/line/) que indica la matriz de posiciones. La matriz está <br/>            compuesta por coordenadas de cada punto de control de la línea. <br/>            directamente. |
