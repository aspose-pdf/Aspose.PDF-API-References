## Arc class

Representa un arco.

El tipo Arc expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Inicializa una nueva instancia de la clase Arc |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| graph_info | Obtiene o establece un objeto [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) que indica la información del gráfico, como color,<br/>            ancho de línea, etc. |
| text | Obtiene o establece un texto para la forma |
| pos_x | Obtiene o establece un valor float que indica la coordenada x del centro del arco. |
| pos_y | Obtiene o establece un valor float que indica la coordenada y del centro del arco. |
| radius | Obtiene o establece un valor float que indica el radio del arco. |
| alpha | Obtiene o establece un valor float que indica el ángulo inicial en grados del arco. |
| beta | Obtiene o establece un valor float que indica el ángulo final en grados del arco. |
