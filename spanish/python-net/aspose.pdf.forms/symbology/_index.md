## Symbology enumeration

Una simbología (Código de barras) define los detalles técnicos de un tipo particular de código de barras:<br/>            el ancho de las barras, conjunto de caracteres, método de codificación, especificaciones de suma de verificación, etc.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| PDF417 | Una simbología 2D de varias filas y longitud variable con alta capacidad de datos y capacidad de corrección de errores. |
| QR_CODE | El código QR (abreviatura de Quick Response) es un código de barras matricial específico (código 2D), <br/>            legible por lectores de códigos QR dedicados y teléfonos con cámara. |
| DATA_MATRIX | Una simbología matricial 2D que consiste en módulos cuadrados negros y blancos dispuestos en un patrón cuadrado o <br/>            rectangular. |
