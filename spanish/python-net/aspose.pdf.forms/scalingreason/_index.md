## ScalingReason enumeration

Las circunstancias bajo las cuales el icono debe escalarse dentro del rectángulo de anotación.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| ALWAYS | Escalar siempre. |
| ICON_IS_BIGGER | Escalar solo cuando el ícono es más grande que el rectángulo de anotación. |
| ICON_IS_SMALLER | Escalar solo cuando el ícono es más pequeño que el rectángulo de anotación. |
| NEVER | Nunca escalar. |
