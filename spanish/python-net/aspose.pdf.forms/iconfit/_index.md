## IconFit class

Describe cómo se debe mostrar el ícono de la anotación del widget dentro de su rectángulo de anotación.

El tipo IconFit expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| scaling_reason | Obtiene o establece la razón de escalado. |
| scaling_mode | El tipo de escalado que se debe usar.        /// |
| leftover_left | Obtiene o establece el espacio a asignar a la izquierda del ícono. |
| leftover_bottom | Obtiene o establece el espacio a asignar en la parte inferior del ícono. |
| spread_on_border | Si es verdadero, indica que la apariencia del botón debe escalarse para ajustarse completamente dentro de los límites de la anotación sin tener en cuenta el ancho de línea del borde. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| name_to_scaling_reason(reason) | Convierte el nombre de la razón de escalado en un objeto ScalingReason. |
| scaling_reason_to_name(reason) | Convierte el objeto de razón de escalado a nombre. |
| name_to_scaling_mode(mode) | Convierte el nombre del modo de escalado en un objeto ScalingMode. |
| scaling_mode_to_name(mode) | Convierte el objeto del modo de escalado en nombre. |
