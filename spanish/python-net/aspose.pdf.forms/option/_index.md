## Option class

Clase que representa una opción del campo de elección.

El tipo Option expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| value | Obtiene o establece el valor de exportación de la opción. |
| name | Obtiene o establece el nombre de la opción. |
| selected | Obtiene o establece el estado seleccionado de la opción. Devuelve true si la opción está seleccionada. |
| index | Obtiene el índice de la opción. |
