## OptionCollection class

Clase que representa la colección de opciones del campo de elección.

El tipo OptionCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_synchronized | Devuelve true si el objeto está sincronizado. |
| sync_root | Objeto de sincronización de la colección. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene la opción por índice. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| get(index) | Obtiene la opción por índice. |
| get(name) | Obtiene la opción de la colección por nombre de opción. |
