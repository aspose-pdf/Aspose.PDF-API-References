## XFA class

Representa el formulario XML según la Arquitectura de Formularios XML (XFA).

El tipo XFA expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| field_names | Lista de nombres de campos en la plantilla del formulario. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| set_field_image(field_name, image) | Establece la imagen para el campo XFA. |
