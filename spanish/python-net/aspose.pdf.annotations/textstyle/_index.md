## TextStyle class

Clase que representa el estilo de texto en la anotación.

El tipo TextStyle expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| font_name | Nombre de la fuente. |
| font_size | Tamaño de la fuente. |
| alineación | Obtiene o establece la alineación horizontal del texto. |
| horizontal_alignment | Alineación del texto. Los valores válidos son: Izquierda, Centro, Derecha. |
| color | Color del texto. |
