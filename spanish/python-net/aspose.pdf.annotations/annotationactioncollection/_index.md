## AnnotationActionCollection class

Representa la colección de acciones de anotación.

El tipo AnnotationActionCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| on_enter | Obtiene o establece una acción que se ejecutará cuando el cursor entre en el área activa de la anotación. |
| on_exit | Obtiene o establece una acción que se ejecutará cuando el cursor salga del área activa de la anotación. |
| on_press_mouse_btn | Obtiene o establece una acción que se ejecutará cuando se presione el botón del ratón dentro del área activa de la anotación. |
| on_release_mouse_btn | Obtiene o establece una acción que se ejecutará cuando se suelte el botón del ratón dentro del área activa de la anotación. |
| on_receive_focus | Obtiene o establece una acción que se ejecutará cuando la anotación reciba el foco de entrada. |
| on_open_page | Obtiene o establece una acción que se ejecutará cuando se abra la página que contiene la anotación. |
| on_close_page | Obtiene o establece una acción que se ejecutará cuando se cierre la página que contiene la anotación. |
| on_show_page | Obtiene o establece una acción que se ejecutará cuando la página que contiene la anotación se vuelva visible en la interfaz de usuario de la aplicación visor. |
| on_hide_page | Obtiene o establece una acción que se ejecutará cuando la página que contiene la anotación ya no sea visible en la interfaz de usuario de la aplicación visor. |
| on_lost_focus | Obtiene o establece una acción que se ejecutará cuando la anotación pierda el foco de entrada. |
| on_modify_character | Obtiene o establece una acción que se ejecutará cuando el usuario modifique el carácter del campo. |
| on_validate | Obtiene o establece una acción que se ejecutará cuando el usuario cambie el contenido del campo. |
| on_format | Obtiene o establece una acción que se ejecutará para formatear el valor del campo. |
| on_calculate | Obtiene o establece una acción para calcular el valor del campo. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| remove_actions() | Elimina todas las acciones de la anotación. |
