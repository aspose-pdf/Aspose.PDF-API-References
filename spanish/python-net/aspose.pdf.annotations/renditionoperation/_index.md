## RenditionOperation enumeration

La operación a realizar cuando se activa la acción.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| PLAY_STOP | Si no hay ninguna representación asociada con la anotación, reproduzca la representación especificada, asociándola con la anotación. Si ya existe una representación asociada con la anotación, se detendrá, y la nueva representación se asociará con la anotación. |
| STOP | Detener cualquier reproducción que se esté reproduciendo en asociación con la anotación. |
| PAUSE | Pausar cualquier reproducción que se esté reproduciendo en asociación con la anotación. |
| RESUME | Reanudar cualquier reproducción que se esté reproduciendo en asociación con la anotación. |
| PLAY_RESUME | Reproducir la reproducción especificada, asociándola con la anotación. Si una reproducción ya está asociada con la anotación, reanudar la reproducción si está pausada. |
| UNDEFINED | Operación no definida. |
