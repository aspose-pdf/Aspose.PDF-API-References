## MediaRendition class

Clase que describe la representación de medios.

El tipo MediaRendition expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| name | Cadena de texto que especifica el nombre de la representación para su uso en una interfaz de usuario y para la búsqueda en el árbol de nombres mediante acciones de JavaScript. |
| rendition_type | Obtiene el tipo de representación. |
| media_clip | Obtiene o establece los objetos de clip de medios asociados con la representación. |
