## HighlightingMode enumeration

Enumera el modo de resaltado de la anotación, el efecto visual que se usará cuando se presione o mantenga pulsado el botón del ratón dentro de su área activa.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | Sin resaltado. |
| INVERT | Invierte el contenido del rectángulo de la anotación. |
| OUTLINE | Invierte el borde de la anotación. |
| PUSH | Muestra la apariencia inferior de la anotación, si existe. Si no se define una apariencia inferior, desplaza el contenido del rectángulo de la anotación para que parezca que se empuja bajo la superficie de la página. |
| TOGGLE | Lo mismo que Push (que es la opción preferida). |
