## Measure class

Clase que describe el sistema de coordenadas Measure.

El tipo Measure expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Measure(annotation) | Inicializa una nueva instancia de la clase Measure |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| scale_ratio | Una cadena de texto que expresa la relación de escala del dibujo. |
| x_format | Una matriz de formato numérico para la medición del cambio a lo largo del eje x y, si Y no está presente, también a lo largo del eje y |
| y_format | Una matriz de formato numérico para la medición del cambio a lo largo del eje y. |
| distance_format | Una matriz de formato numérico para la medición de distancia en cualquier dirección. |
| area_format | Una matriz de formato numérico para la medición de área. |
| angle_format | Una matriz de formato numérico para la medición de ángulos. |
| slope_format | Una matriz de formatos numéricos para la medición de la pendiente de una línea. |
| origin | Punto que especificará el origen del sistema de coordenadas de medición en coordenadas del espacio de usuario predeterminado. |
| xy_factor | Un factor que se utilizará para convertir las unidades más grandes a lo largo del eje y a las unidades más grandes a lo largo del eje x. |
