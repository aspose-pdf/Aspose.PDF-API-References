## DefaultAppearance class

Describe la apariencia predeterminada del campo (fuente, tamaño de texto y color).

El tipo DefaultAppearance expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| DefaultAppearance() | Constructor de DefaultAppearance. |
| DefaultAppearance(font_name, font_size, text_color) | Inicializa una nueva instancia de la clase DefaultAppearance |
| DefaultAppearance(font, font_size, text_color) | Inicializa una nueva instancia de la clase DefaultAppearance |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| font_size | Obtiene el tamaño de fuente en la apariencia predeterminada. |
| text_color | Obtiene o establece el color del texto en la apariencia predeterminada. |
| font_name | Obtiene el nombre de la fuente en la apariencia predeterminada. |
| font_resource_name | Obtiene el nombre de la fuente en la apariencia predeterminada. |
| font | Obtiene la fuente especificada como predeterminada para el texto. |
| text | Obtiene la lista de operadores pdf que representan la apariencia. |
