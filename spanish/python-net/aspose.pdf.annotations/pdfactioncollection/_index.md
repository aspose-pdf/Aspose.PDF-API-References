## PdfActionCollection class

Clase que describe una lista de acciones.

El tipo PdfActionCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| count | Obtiene el recuento de acciones. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene la acción por su índice. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| delete(index) | Elimina la acción por índice. |
| add(action) | Agregar acción a la lista de acciones. |
