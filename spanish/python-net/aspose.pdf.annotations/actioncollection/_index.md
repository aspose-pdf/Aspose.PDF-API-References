## ActionCollection class

Colección de acciones

El tipo ActionCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_synchronized | Devuelve true si el objeto está sincronizado. |
| sync_root | Obtiene el objeto de sincronización. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | Obtiene la acción por su índice. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| delete(index) | Elimina la acción de la colección por índice. |
| delete() | Elimina la acción de la colección por índice. |
