## AnnotationCollection class

Clase que representa una colección de anotaciones.

El tipo AnnotationCollection expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| is_synchronized | Obtiene un valor que indica si el acceso a Aspose.Pdf.Annotations.AnnotationCollection está sincronizado (seguro para subprocesos). |
| sync_root | Obtiene un objeto que puede usarse para sincronizar el acceso a Aspose.Pdf.Annotations.AnnotationCollection. |
## Indexer
| Nombre | Descripción |
| :- | :- |
| [index] | El índice del elemento a obtener. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| delete(index) | Elimina la anotación de la colección por índice. |
| delete() | Elimina la anotación de la colección por índice. |
| delete(annotation) | Elimina la anotación de la colección por índice. |
| add(annotation, consider_rotation) | Agrega la anotación a la colección. Si la página está rotada, entonces el rectángulo de la anotación se recalculará en consecuencia. |
| accept(visitor) | Acepta un visitante para procesar la anotación. |
| find_by_name(name) | Devuelve la anotación por su nombre. |
