## Border class

Clase que representa las características del borde de la anotación.

El tipo Border expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| Border(parent) | Inicializa una nueva instancia de la clase Border |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| h_corner_radius | Obtiene o establece el radio de esquina horizontal. |
| v_corner_radius | Obtiene o establece el radio de esquina vertical. |
| ancho | Obtiene o establece el ancho del borde. |
| effect_intensity | Obtiene o establece la intensidad del efecto. El rango válido del valor es [0..2]. |
| style | Obtiene o establece el estilo del borde. |
| effect | Obtiene o establece el efecto del borde. |
| dash | Obtiene o establece el patrón de guiones. |
