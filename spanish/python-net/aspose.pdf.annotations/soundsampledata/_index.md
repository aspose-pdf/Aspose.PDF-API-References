## SoundSampleData class

Representa entradas adicionales específicas de un objeto de sonido (Sección 9.2 PDF1-7).

El tipo SoundSampleData expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| SoundSampleData(sampling_rate) | Inicializa una nueva instancia de la clase SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels) | Inicializa una nueva instancia de la clase SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel) | Inicializa una nueva instancia de la clase SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel, sound_sample_data_encoding_format) | Inicializa una nueva instancia de la clase SoundSampleData |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| sampling_rate | Obtiene o establece la frecuencia de muestreo. |
| number_of_sound_channels | Obtiene o establece el número de canales de sonido. |
| bits_per_channel | Obtiene o establece el número de bits por valor de muestra por canal. |
| encoding_format | Obtiene o establece el formato de codificación. |
| DEFAULT_SAMPLING_RATE | Valor predeterminado para SamplingRate. |
| DEFAULT_OF_SOUND_CHANNELS | Valor predeterminado para el parámetro Channels. |
| DEFAULT_OF_BITS_PER_CHANNEL | Valor predeterminado para el parámetro BitsPerchannel. |
| DEFAULT_ENCODING_FORMAT | Valor predeterminado para el formato de codificación. |
