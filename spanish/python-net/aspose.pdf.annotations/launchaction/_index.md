## LaunchAction class

Representa una acción lanzar que inicia una aplicación o abre o imprime un documento.

El tipo LaunchAction expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| LaunchAction(file) | Inicializa una nueva instancia de la clase LaunchAction |
| LaunchAction(document, file) | Inicializa una nueva instancia de la clase LaunchAction |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| next | Acciones siguientes en la secuencia. |
| file | Obtiene o establece la aplicación que se lanzará o el documento que se abrirá o imprimirá. |
| new_window | Obtiene o establece una bandera que indica si se debe abrir el documento de destino en una nueva ventana (solo afecta a documentos PDF). |
