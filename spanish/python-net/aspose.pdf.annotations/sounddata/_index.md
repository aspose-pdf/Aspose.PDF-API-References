## SoundData class

Representa datos de sonido que definen el audio que se reproducirá cuando se active la anotación.

El tipo SoundData expone los siguientes miembros:
## Propiedades
| Nombre | Descripción |
| :- | :- |
| rate | Obtiene o establece la tasa de muestreo, en muestras por segundo. |
| canales | Obtiene o establece el número de canales de sonido. |
| bits | Obtiene o establece el número de bits por valor de muestra por canal. |
| contenidos | Obtiene la secuencia del sonido que se reproducirá cuando se active la anotación. |
| codificación | Obtiene o establece el formato de codificación de los datos de muestra. |
