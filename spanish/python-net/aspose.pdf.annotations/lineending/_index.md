## LineEnding enumeration

Enumera los estilos de extremo de línea que se usarán al dibujar la línea.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| NONE | Sin fin de línea. |
| SQUARE | Un cuadrado relleno con el color interior de la anotación, si lo hay. |
| CIRCLE | Un círculo relleno con el color interior de la anotación, si lo hay. |
| DIAMOND | Una forma de diamante rellena con el color interior de la anotación, si lo hay. |
| OPEN_ARROW | Dos líneas cortas que se encuentran en un ángulo agudo para formar una punta de flecha abierta. |
| CLOSED_ARROW | Dos líneas cortas que se encuentran en un ángulo agudo, como en el estilo OpenArrow, y conectadas por una tercera línea para formar una punta de flecha cerrada triangular rellena con el color interior de la anotación, si lo hay. |
| BUTT | Una línea corta en el extremo perpendicular a la propia línea. |
| R_OPEN_ARROW | Dos líneas cortas en la dirección inversa de OpenArrow. |
| R_CLOSED_ARROW | Una punta de flecha cerrada triangular en la dirección inversa de ClosedArrow. |
| SLASH | Una línea corta en el extremo aproximadamente a 30 grados en sentido horario respecto a la perpendicular a la propia línea. |
