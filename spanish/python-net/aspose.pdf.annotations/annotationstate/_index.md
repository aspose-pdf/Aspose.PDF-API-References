## AnnotationState enumeration

La enumeración de estados a los que se puede establecer la anotación original.

## Members
| Nombre del miembro | Descripción |
| :- | :- |
| UNDEFINED | Estado no definido. |
| MARKED | La anotación ha sido marcada por el usuario. |
| UNMARKED | La anotación no ha sido marcada por el usuario. |
| ACCEPTED | El usuario está de acuerdo con el cambio. |
| REJECTED | El usuario no está de acuerdo con el cambio. |
| CANCELLED | El cambio ha sido cancelado. |
| COMPLETADO | El cambio ha sido completado. |
| NONE | El usuario no ha indicado nada sobre el cambio. |
