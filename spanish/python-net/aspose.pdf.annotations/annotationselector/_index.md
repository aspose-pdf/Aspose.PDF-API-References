## AnnotationSelector class

Esta clase se usa para seleccionar anotaciones mediante la idea de plantilla Visitor.

El tipo AnnotationSelector expone los siguientes miembros:
## Constructores
| Nombre | Descripción |
| :- | :- |
| AnnotationSelector() | Inicializa una nueva instancia de la clase AnnotationSelector. |
| AnnotationSelector(annotation) | Inicializa una nueva instancia de la clase AnnotationSelector |
## Propiedades
| Nombre | Descripción |
| :- | :- |
| selected | La lista de objetos seleccionados. |
## Métodos
| Nombre | Descripción |
| :- | :- |
| visit(link) | Selecciona la anotación de enlace si AnnotationSelector se inicializó con el objeto LinkAnnotation. |
| visit(attachment) | Selecciona la anotación de adjunto si AnnotationSelector se inicializó con el objeto FileAttachmentAnnotation. |
| visit(text) | Selecciona la anotación de texto si AnnotationSelector se inicializó con el objeto TextAnnotation. |
| visitar(redact) | Selecciona la anotación de redactado si AnnotationSelector se inicializó con el objeto RedactAnnotation. |
| visit(freetext) | Selecciona la anotación de texto libre si AnnotationSelector se inicializó con el objeto FreeTextAnnotation. |
| visit(highlight) | Selecciona la anotación de adjunto si AnnotationSelector se inicializó con el objeto FreeTextAnnotation. |
| visit(underline) | Selecciona la anotación subrayada si AnnotationSelector se inicializó con el objeto UnderlineAnnotation. |
| visit(strike_out) | Selecciona la anotación tachada si AnnotationSelector se inicializó con el objeto StrikeOutAnnotation. |
