## Espacios de nombres

| Espacio de nombres | Descripción |
| :- | :- |
| [aspose.pdf](/pdf/python-net/aspose.pdf/) | El aspose.pdf es un espacio de nombres raíz para todas las clases de la biblioteca Aspose.Pdf que están ya sea directamente en él, como Document, o indirectamente a través de varios subespacios de nombres. |
| [aspose.pdf.annotations](/pdf/python-net/aspose.pdf.annotations/) | El espacio de nombres aspose.pdf.annotations proporciona clases para trabajar con varios tipos de acciones, destinos y otras características del documento que tradicionalmente se denominan interactivas, ofreciendo medios para que el usuario pueda interactuar con él. |
| [aspose.pdf.devices](/pdf/python-net/aspose.pdf.devices/) | El espacio de nombres aspose.pdf.devices proporciona clases que se utilizan para representar el documento como imagen(es) o texto plano. Así, el documento puede enviarse a dispositivos textuales o gráficos, lo que significa que queremos obtener su representación textual o gráfica. |
| [aspose.pdf.drawing](/pdf/python-net/aspose.pdf.drawing/) | El espacio de nombres aspose.pdf.drawing proporciona clases que describen primitivas gráficas como arco, línea, círculo, etc. Los objetos correspondientes pueden usarse para crear nuevos documentos. |
| [aspose.pdf.facades](/pdf/python-net/aspose.pdf.facades/) | El espacio de nombres aspose.pdf.facades proporciona clases que originalmente provienen de Aspose.Pdf.Kit. Estas clases se utilizan para manipular documentos realizando operaciones como concatenar, estampar, firmar, anotar, etc., pero a un nivel alto sin acceso a la estructura interna del documento. |
| [aspose.pdf.forms](/pdf/python-net/aspose.pdf.forms/) | El espacio de nombres aspose.pdf.forms contiene clases que describen formularios (estándar, estáticos, dinámicos) y varios tipos de campos como cuadro de texto, lista desplegable, botón de opción, etc. |
| [aspose.pdf.groupprocessor](/pdf/python-net/aspose.pdf.groupprocessor/) | El espacio de nombres aspose.pdf.groupprocessor proporciona clases usadas para trabajar con texto y fuentes. |
| [aspose.pdf.groupprocessor.creators](/pdf/python-net/aspose.pdf.groupprocessor.creators/) | El espacio de nombres aspose.pdf.groupprocessor.creators proporciona clases usadas para crear instancias de clases GroupProcessor. |
| [aspose.pdf.logicalstructure](/pdf/python-net/aspose.pdf.logicalstructure/) | El aspose.pdf.logicalstructure es un espacio de nombres para clases de Estructura Lógica PDF. |
| [aspose.pdf.operators](/pdf/python-net/aspose.pdf.operators/) | El espacio de nombres aspose.pdf.operators es un espacio de nombres para implementaciones de operadores. Estas clases describen los operadores usados en el contenido de páginas PDF. |
| [aspose.pdf.optimization](/pdf/python-net/aspose.pdf.optimization/) | El espacio de nombres aspose.pdf.optimization es un espacio de nombres para clases que gestionan el proceso de optimización del documento. |
| [aspose.pdf.pdfaoptionclasses](/pdf/python-net/aspose.pdf.pdfaoptionclasses/) | El espacio de nombres aspose.pdf.pdfaoptionclasses es un espacio de nombres para opciones de conversión PDF/A. |
| [aspose.pdf.sanitization](/pdf/python-net/aspose.pdf.sanitization/) | El espacio de nombres aspose.pdf.sanitization es un espacio de nombres para operaciones de sanitización. |
| [aspose.pdf.structure](/pdf/python-net/aspose.pdf.structure/) | El espacio de nombres aspose.pdf.structure proporciona clases que ayudan a trabajar con la estructura lógica de un documento, la cual presenta la organización del documento en capítulos y secciones o la identificación de elementos especiales como figuras, tablas y notas al pie. |
| [aspose.pdf.tagged](/pdf/python-net/aspose.pdf.tagged/) | El aspose.pdf.tagged es un espacio de nombres para clases que soportan documentos PDF etiquetados. |
