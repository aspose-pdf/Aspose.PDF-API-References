El paquete com.aspose.pdf.printing proporciona clases que se utilizan para configurar el proceso de impresión.

## Clases

| Clase | Descripción |
| --- | --- |
| [CustomPrintEventArgs](./customprinteventargs/) | Proporciona datos para el evento PdfViewer.getCustomPrintDelegate(). |
| [DuplexKind](./duplexkind/) | Especifica la configuración dúplex de la impresora. |
| [PdfPrinterResolution](./pdfprinterresolution/) | Representa la resolución compatible con una impresora. |
| [PdfPrinterResolutionKind](./pdfprinterresolutionkind/) | Especifica una resolución de impresora. |
| [PdfPrinterSettings](./pdfprintersettings/) | Especifica información sobre cómo se imprime un documento, incluida la impresora que lo imprime. |
| [PdfPrintRange](./pdfprintrange/) | Especifica la parte del documento a imprimir. |
| [PrinterMargins](./printermargins/) | Especifica las dimensiones de los márgenes de una página impresa. |
| [PrinterPaperKind](./printerpaperkind/) | Especifica los tamaños de papel estándar. |
| [PrintPageSettings](./printpagesettings/) | Especifica la configuración que se aplica a una sola página impresa. |
| [PrintPaperSize](./printpapersize/) | Especifica el tamaño de una hoja de papel. |
| [PrintPaperSizes](./printpapersizes/) | Representa los tamaños de papel estándar. |
| [PrintPaperSource](./printpapersource/) | Especifica la bandeja de papel de la que la impresora saca papel. |
| [PrintPaperSourceKind](./printpapersourcekind/) | Fuentes de papel estándar. |
| [PrintPaperSources](./printpapersources/) | Proporciona un conjunto de instancias {@link PrintPaperSource} predefinidas que representan fuentes de papel comunes. Esta clase no puede heredarse. |
