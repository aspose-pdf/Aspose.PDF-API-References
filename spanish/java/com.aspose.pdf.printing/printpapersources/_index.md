Proporciona un conjunto de instancias {@link PrintPaperSource} predefinidas que representan fuentes de papel comunes. Esta clase no puede heredarse.

## Campos

| Campo | Descripción |
| --- | --- |
| [AutomaticFeed](#AutomaticFeed) | Representa una fuente de papel de alimentación automática. |
| [Cassette](#Cassette) | Representa la casete de papel de la impresora. |
| [Envelope](#Envelope) | Representa una fuente de papel de alimentación automática de sobres. |
| [FormSource](#FormSource) | Representa la bandeja predeterminada de la impresora. |
| [LargeCapacity](#LargeCapacity) | Representa la bandeja de gran capacidad de la impresora. |
| [LargeFormat](#LargeFormat) | Representa la bandeja para papel de formato grande. |
| [Lower](#Lower) | Representa la bandeja inferior de la impresora. |
| [Manual](#Manual) | Representa una fuente de papel de alimentación manual. |
| [ManualFeedEnvelope](#ManualFeedEnvelope) | Representa una fuente de papel de alimentación manual de sobres. |
| [Middle](#Middle) | Representa la bandeja intermedia de la impresora. |
| [SmallFormat](#SmallFormat) | Representa la bandeja para papel de formato pequeño. |
| [TractorFeed](#TractorFeed) | Representa una fuente de papel continuo de alimentación por tractor. |
| [Upper](#Upper) | Representa la bandeja superior de la impresora, o la bandeja predeterminada si la impresora solo tiene una bandeja. |
