Representa el estado de validación de una validación de certificado. Esta enumeración define los posibles resultados de la validación de certificados: - Valid: Indica que el certificado ha sido validado con éxito. - Invalid: Indica que la validación del certificado falló. - Undefined: Indica que el proceso de validación fue inconcluso o no se realizó.
