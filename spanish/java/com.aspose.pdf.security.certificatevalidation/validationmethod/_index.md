Representa una enumeración que define el método utilizado para la validación de certificados.

## Campos

| Campo | Descripción |
| --- | --- |
| [All](#All) | Utiliza todos los métodos disponibles (OCSP y CRL) para la validación de certificados. |
| [Auto](#Auto) | Determina automáticamente el mejor método para la validación de certificados. |
| [Crl](#Crl) | Valida certificados usando el método de Lista de Revocación de Certificados (CRL). |
| [Ocsp](#Ocsp) | Utiliza el Protocolo de Estado de Certificado en Línea (OCSP) para la validación de certificados. OCSP es un protocolo que proporciona el estado de validación de un certificado mediante la consulta directa a la Autoridad de Certificación (CA) emisora. |
