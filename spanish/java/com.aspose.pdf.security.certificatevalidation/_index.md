## Clases

| Clase | Descripción |
| --- | --- |
| [ValidationMethod](./validationmethod/) | Representa una enumeración que define el método utilizado para la validación de certificados. |
| [ValidationMode](./validationmode/) | Especifica el modo de validación para los procesos de validación de firmas PDF. |
| [ValidationOptions](./validationoptions/) | Representa opciones para validar una firma digital en un documento PDF. |
| [ValidationResult](./validationresult/) | Representa el resultado de un proceso de validación de un certificado. La clase ValidationResult proporciona información sobre el resultado de validar un certificado, incluyendo su estado y un mensaje que describe cualquier problema encontrado durante la validación. |
| [ValidationStatus](./validationstatus/) | Representa el estado de validación de una validación de certificado. Esta enumeración define los posibles resultados de la validación de certificados: - Valid: Indica que el certificado ha sido validado con éxito. - Invalid: Indica que la validación del certificado falló. - Undefined: Indica que el proceso de validación fue inconcluso o no se realizó. |
