Enumera los modos que pueden usarse para guardar fuentes referenciadas en el PDF guardado.

## Campos

| Campo | Descripción |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | Todas las fuentes referenciadas se guardarán y referenciarán como fuentes EOT. |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | Todas las fuentes referenciadas se guardarán y referenciarán como fuentes TTF. |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | Todas las fuentes referenciadas se guardarán y referenciarán como fuentes WOFF. |
| [DontSave](#DontSave) | Todas las fuentes referenciadas no se guardarán. |
| [SaveInAllFormats](#SaveInAllFormats) | Todas las fuentes referenciadas se guardarán (y referenciarán en CSS) como 3 archivos independientes: EOT, TTH, WOFF. Incrementa el tamaño de los datos de salida pero hace que la salida sea adecuada para la gran mayoría de los navegadores web. |
