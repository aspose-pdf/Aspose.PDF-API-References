Enumera los estilos de terminación de línea que se usarán al dibujar la línea.

## Campos

| Campo | Descripción |
| --- | --- |
| [Butt](#Butt) | Una línea corta en el extremo perpendicular a la propia línea. |
| [Circle](#Circle) | Un círculo relleno con el color interior de la anotación, si lo hay. |
| [ClosedArrow](#ClosedArrow) | Dos líneas cortas que se encuentran en un ángulo agudo como en el estilo OpenArrow y conectadas por una tercera línea para formar una punta de flecha triangular cerrada rellena con el color interior de la anotación, si lo hay. |
| [Diamond](#Diamond) | Una forma de diamante rellena con el color interior de la anotación, si lo hay. |
| [None](#None) | Sin terminación de línea. |
| [OpenArrow](#OpenArrow) | Dos líneas cortas que se encuentran en un ángulo agudo para formar una punta de flecha abierta. |
| [RClosedArrow](#RClosedArrow) | Una punta de flecha triangular cerrada en la dirección inversa de ClosedArrow. |
| [ROpenArrow](#ROpenArrow) | Dos líneas cortas en la dirección inversa de OpenArrow. |
| [Slash](#Slash) | Una línea corta en el extremo aproximadamente a 30 grados en sentido horario desde la perpendicular a la propia línea. |
| [Square](#Square) | Un cuadrado relleno con el color interior de la anotación, si lo hay. |
