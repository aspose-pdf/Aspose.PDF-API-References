Enumera el modo de resaltado de la anotación, el efecto visual que se usará cuando se presione o mantenga pulsado el botón del ratón dentro de su área activa.

## Campos

| Campo | Descripción |
| --- | --- |
| [Invert](#Invert) | Invertir el contenido del rectángulo de la anotación. |
| [None](#None) | Sin resaltado. |
| [Outline](#Outline) | Invertir el borde de la anotación. |
| [Push](#Push) | Mostrar la apariencia inferior de la anotación, si existe. |
| [Toggle](#Toggle) | Igual que Push (que es la opción preferida). |
