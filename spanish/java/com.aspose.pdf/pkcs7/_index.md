Representa el objeto PKCS#7 que se ajusta a la especificación PKCS#7 en el RFC 2315 de Internet, PKCS #7: Cryptographic Message Syntax, Versión 1.5. El digest SHA1 del rango de bytes del documento está encapsulado en el campo SignedData de PKCS#7.
