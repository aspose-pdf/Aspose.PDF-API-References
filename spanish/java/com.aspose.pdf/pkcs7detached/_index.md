Representa el objeto PKCS#7 que se ajusta a la especificación PKCS#7 en el RFC 2315 de Internet, PKCS #7: Cryptographic Message Syntax, Versión 1.5. El digest original del mensaje firmado sobre el rango de bytes del documento se incorpora como el campo SignedData normal de PKCS#7. No se encapsulan datos en el campo SignedData de PKCS#7.
