```
public interface ITociElement
```

Representa un elemento que puede funcionar como una entrada de tabla de contenido (TOCI) en un documento PDF etiquetado. Esta interfaz abstrae tanto los elementos TOCI estándar como los elementos de ítem de lista (LI) utilizados en estructuras de tablas de contenido anidadas.

## Métodos

| Método | Descripción |
| --- | --- |
| [getGetElement](#getGetElement--) | Obtiene el elemento PDF subyacente que representa esta estructura TOCI. |

### getGetElement {#getGetElement--}
```
StructureElement getGetElement()
```

Obtiene el elemento PDF subyacente que representa esta estructura TOCI.

**Returns:**
El Elemento que forma la representación estructural de esta entrada de tabla de contenido.
