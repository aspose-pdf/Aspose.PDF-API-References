El espacio de nombres com.aspose.pdf.markdownoptions contiene clases de opciones específicas para una conversión markdown.

## Clases

| Clase | Descripción |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | Define los estilos de serialización disponibles para énfasis y énfasis fuerte. Para la especificación, consulte CommonMark - Emphasis and strong emphasis. |
| [HeadingLevels](./headinglevels/) | Representa una clase para trabajar con niveles de encabezado basados en el tamaño de fuente. |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | Representa tipos de estrategias de reconocimiento de encabezados. |
| [HeadingStyle](./headingstyle/) | Define los estilos de serialización disponibles para encabezados. Para la especificación, consulte CommonMark - ATX headings, respectivamente CommonMark - Setext headings. |
| [LineBreakStyle](./linebreakstyle/) | Representa los posibles estilos de salto de línea para un archivo. |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Representa la clase de opción de guardado de documento en formato markdown. |
