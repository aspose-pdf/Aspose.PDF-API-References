Define los estilos de serialización disponibles para encabezados. Para la especificación, consulte CommonMark - ATX headings, respectivamente CommonMark - Setext headings.

## Campos

| Campo | Descripción |
| --- | --- |
| [Atx](#Atx) | Prefija los encabezados con '#' |
| [Setext](#Setext) | Subraye los encabezados de nivel 1 y 2 con "======" respectivamente "------". Los encabezados Setext solo están disponibles para los niveles 1 y 2. Incluso con el estilo de encabezado configurado a Setext, se usará el estilo Atx para los encabezados de nivel 3 o superior. |

### Atx {#Atx}
```
public static final int Atx
```

Prefija los encabezados con '#'

### Setext {#Setext}
```
public static final int Setext
```

Subraye los encabezados de nivel 1 y 2 con "======" respectivamente "------". Los encabezados Setext solo están disponibles para los niveles 1 y 2. Incluso con el estilo de encabezado configurado a Setext, se usará el estilo Atx para los encabezados de nivel 3 o superior.
