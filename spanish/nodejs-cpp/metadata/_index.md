## Metadata PDF functions

| Nombre | Descripción |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | Establezca la información (metadatos) en un archivo PDF. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | Obtenga la información (metadatos) de un archivo PDF. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | Obtenga la lista de fuentes de un archivo PDF. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | Elimine los metadatos de un archivo PDF. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | Obtenga el recuento de palabras y caracteres en un archivo PDF. |
