## Security PDF functions

| Nombre | Descripción |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | Cifre un archivo PDF. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | Descifre un archivo PDF. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | Firme un archivo PDF con firmas digitales. |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | Firme un archivo PDF con firmas digitales separadas. |
| [AsposePdfChangePassword](./asposepdfchangepassword/) | Cambie las contraseñas del archivo PDF. |

## Detailed Description

Funciones para trabajar con archivos PDF con características de seguridad.

CommonJS

