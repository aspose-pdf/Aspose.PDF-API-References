Fornisce un insieme di istanze {@link PrintPaperSource} predefinite che rappresentano le fonti di carta comuni. Questa classe non può essere ereditata.

## Campi

| Campo | Descrizione |
| --- | --- |
| [AutomaticFeed](#AutomaticFeed) | Rappresenta una sorgente carta a caricamento automatico. |
| [Cassette](#Cassette) | Rappresenta la cassetta della carta della stampante. |
| [Envelope](#Envelope) | Rappresenta una sorgente carta per buste a caricamento automatico. |
| [FormSource](#FormSource) | Rappresenta il vassoio predefinito della stampante. |
| [LargeCapacity](#LargeCapacity) | Rappresenta il vassoio ad alta capacità della stampante. |
| [LargeFormat](#LargeFormat) | Rappresenta il vassoio per carta di formato più grande. |
| [Lower](#Lower) | Rappresenta il vassoio inferiore della stampante. |
| [Manual](#Manual) | Rappresenta una sorgente carta a caricamento manuale. |
| [ManualFeedEnvelope](#ManualFeedEnvelope) | Rappresenta una sorgente carta per buste a caricamento manuale. |
| [Middle](#Middle) | Rappresenta il vassoio centrale della stampante. |
| [SmallFormat](#SmallFormat) | Rappresenta il vassoio per carta di formato più piccolo. |
| [TractorFeed](#TractorFeed) | Rappresenta una sorgente carta continua a trascinamento. |
| [Upper](#Upper) | Rappresenta il vassoio più alto della stampante, o il vassoio predefinito se la stampante ha un solo vassoio. |
