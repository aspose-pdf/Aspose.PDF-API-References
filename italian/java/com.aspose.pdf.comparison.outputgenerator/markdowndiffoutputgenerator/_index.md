Rappresenta una classe per generare la rappresentazione Markdown delle differenze tra i testi. A causa della sintassi Markdown, non è possibile mostrare le modifiche ai caratteri di spazio. La selezione delle modifiche comporta l'aggiunta di caratteri di spazio intorno alla formattazione, altrimenti il visualizzatore Markdown non visualizzerà correttamente il testo. Le interruzioni di riga eliminate sono indicate dal segno - di paragrafo.
