Definisce la modalità di posizionamento. I valori possibili includono Legacy (compatibilità retroattiva) e Current (metodo aggiornato di calcolo della posizione del testo).

## Campi

| Campo | Descrizione |
| --- | --- |
| [Current](#Current) | L'interlinea aggiornata e il calcolo della posizione verticale vengono eseguiti in base all'angolo superiore sinistro anziché a quello inferiore sinistro. |
| [Legacy](#Legacy) | Posizionamento del testo legacy |
| [ModernLineSpacing](#ModernLineSpacing) | L'interlinea aggiornata, il calcolo della posizione verticale viene eseguito secondo le vecchie regole (cioè il testo è posizionato rispetto all'angolo inferiore sinistro del rettangolo specificato) |
