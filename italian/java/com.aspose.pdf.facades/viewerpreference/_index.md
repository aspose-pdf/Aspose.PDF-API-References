| [NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES](#NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES) | Struttura del documento visibile. |
| [NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS](#NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS) | Miniature visibili |
| [PAGE_LAYOUT_ONE_COLUMN](#PAGE_LAYOUT_ONE_COLUMN) | Visualizza le pagine in una colonna. |
| [PAGE_LAYOUT_SINGLE_PAGE](#PAGE_LAYOUT_SINGLE_PAGE) | Visualizza una pagina alla volta. |
| [PAGE_LAYOUT_TWO_COLUMN_LEFT](#PAGE_LAYOUT_TWO_COLUMN_LEFT) | Visualizza le pagine in due colonne, con le pagine dispari a destra |
| [PAGE_LAYOUT_TWO_COLUMN_RIGHT](#PAGE_LAYOUT_TWO_COLUMN_RIGHT) | Visualizza le pagine in due colonne, con le pagine dispari a destra. |
| [PAGE_MODE_FULL_SCREEN](#PAGE_MODE_FULL_SCREEN) | Modalità a schermo intero, senza barra dei menu, controlli della finestra o qualsiasi altra finestra visibile. |
| [PAGE_MODE_USE_ATTACHMENT](#PAGE_MODE_USE_ATTACHMENT) | Modalità pagina con allegati. |
| [PAGE_MODE_USE_NONE](#PAGE_MODE_USE_NONE) | Né la struttura del documento né le miniature sono visibili |
| [PAGE_MODE_USE_OC](#PAGE_MODE_USE_OC) | Pannello del gruppo di contenuti opzionali visibile. |
| [PAGE_MODE_USE_OUTLINES](#PAGE_MODE_USE_OUTLINES) | Struttura del documento visibile. |
| [PAGE_MODE_USE_THUMBS](#PAGE_MODE_USE_THUMBS) | Miniature visibili. |
| [PICK_TRAY_BY_PDF_SIZE](#PICK_TRAY_BY_PDF_SIZE) | Utilizza le dimensioni della pagina PDF per selezionare il vassoio di ingresso della carta. |
| [PRINT_SCALING_APP_DEFAULT](#PRINT_SCALING_APP_DEFAULT) | La scala di stampa predefinita del lettore conforme. |
| [PRINT_SCALING_NONE](#PRINT_SCALING_NONE) | Nessuna scala di pagina. |
| [SIMPLEX](#SIMPLEX) | Stampa su un lato. |
