## Classi

| Classe | Descrizione |
| --- | --- |
| [HiddenDataSanitizationOptions](./hiddendatasanitizationoptions/) | Rappresenta le opzioni di configurazione per la sanificazione dei dati nascosti all'interno di un documento. |
| [HiddenDataSanitizer](./hiddendatasanitizer/) | Rappresenta una classe per sanificare i dati nascosti. |
| [UnsignedContentAbsorber](./unsignedcontentabsorber/) | Rappresenta una classe per estrarre contenuti non firmati da un file PDF gestito da firme digitali. |
| [UnsignedContentAbsorber.Result](./unsignedcontentabsorber.result/) | Incapsula il risultato di un'operazione che tenta di estrarre contenuti non firmati da un documento PDF. Questa classe fornisce informazioni sul successo dell'operazione, dettagli del contenuto non firmato, un messaggio che descrive il risultato e lo stato di copertura delle firme del documento. |
| [UnsignedContentAbsorber.UnsignedContent](./unsignedcontentabsorber.unsignedcontent/) | Incapsula gli elementi di contenuto non firmato estratti da un documento PDF. Questa classe fornisce l'accesso a pagine, campi modulo, XForm e annotazioni che fanno parte del contenuto non firmato all'interno del documento. |
