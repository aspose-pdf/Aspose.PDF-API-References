Definisce gli stili di serializzazione disponibili per le intestazioni. Per la specifica vedere CommonMark - ATX headings, rispettivamente CommonMark - Setext headings.

## Campi

| Campo | Descrizione |
| --- | --- |
| [Atx](#Atx) | Prefissa le intestazioni con '#' |
| [Setext](#Setext) | Sottolinea le intestazioni di livello 1 e 2 con "======" rispettivamente "------". Le intestazioni Setext sono disponibili solo per i livelli 1 e 2. Anche se lo stile di intestazione è impostato su Setext, lo stile Atx verrà utilizzato per le intestazioni di livello 3 e superiori. |

### Atx {#Atx}
```
public static final int Atx
```

Prefissa le intestazioni con '#'

### Setext {#Setext}
```
public static final int Setext
```

Sottolinea le intestazioni di livello 1 e 2 con "======" rispettivamente "------". Le intestazioni Setext sono disponibili solo per i livelli 1 e 2. Anche se lo stile di intestazione è impostato su Setext, lo stile Atx verrà utilizzato per le intestazioni di livello 3 e superiori.
