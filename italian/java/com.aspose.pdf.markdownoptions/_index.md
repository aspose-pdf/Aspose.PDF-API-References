Lo spazio dei nomi com.aspose.pdf.markdownoptions contiene classi di opzioni specifiche per una conversione markdown.

## Classi

| Classe | Descrizione |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | Definisce gli stili di serializzazione disponibili per l'enfasi e l'enfasi forte. Per la specifica vedere CommonMark - Emphasis and strong emphasis. |
| [HeadingLevels](./headinglevels/) | Rappresenta una classe per lavorare con i livelli di intestazione basati sulla dimensione del carattere. |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | Rappresenta i tipi di strategie di riconoscimento delle intestazioni. |
| [HeadingStyle](./headingstyle/) | Definisce gli stili di serializzazione disponibili per le intestazioni. Per la specifica vedere CommonMark - ATX headings, rispettivamente CommonMark - Setext headings. |
| [LineBreakStyle](./linebreakstyle/) | Rappresenta gli stili di interruzione di riga possibili per un file. |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Rappresenta la classe di opzioni di salvataggio del documento nel formato markdown. |
