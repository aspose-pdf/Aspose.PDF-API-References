```
public interface ITociElement
```

Rappresenta un elemento che può funzionare come voce di indice (TOCI) in un documento PDF con tag. Questa interfaccia astrae sia gli elementi TOCI standard sia gli elementi List Item (LI) utilizzati in strutture di indice annidate.

## Metodi

| Metodo | Descrizione |
| --- | --- |
| [getGetElement](#getGetElement--) | Ottiene l'elemento PDF sottostante che rappresenta questa struttura TOCI. |

### getGetElement {#getGetElement--}
```
StructureElement getGetElement()
```

Ottiene l'elemento PDF sottostante che rappresenta questa struttura TOCI.

**Returns:**
L'Element che forma la rappresentazione strutturale di questa voce di indice.
