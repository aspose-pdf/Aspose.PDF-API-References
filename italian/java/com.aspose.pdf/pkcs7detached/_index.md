Rappresenta l'oggetto PKCS#7 conforme alla specifica PKCS#7 nella RFC 2315 di Internet, PKCS #7: Cryptographic Message Syntax, Versione 1.5. Il digest originale del messaggio firmato sull'intervallo di byte del documento è incorporato come campo SignedData normale di PKCS#7. Nessun dato è incapsulato nel campo SignedData di PKCS#7.
