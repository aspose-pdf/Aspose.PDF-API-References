Rappresenta l'oggetto PKCS#7 conforme alla specifica PKCS#7 nella RFC 2315 di Internet, PKCS #7: Cryptographic Message Syntax, Versione 1.5. Il digest SHA1 dell'intervallo di byte del documento è incapsulato nel campo SignedData di PKCS#7.
