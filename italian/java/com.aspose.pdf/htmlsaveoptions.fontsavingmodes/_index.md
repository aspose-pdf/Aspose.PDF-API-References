Enumera le modalità che possono essere usate per il salvataggio dei font referenziati nel PDF salvato.

## Campi

| Campo | Descrizione |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | Tutti i font referenziati verranno salvati e referenziati come EOT-fonts. |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | Tutti i font referenziati verranno salvati e referenziati come TTF-fonts. |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | Tutti i font referenziati saranno salvati e referenziati come font WOFF. |
| [DontSave](#DontSave) | Tutti i font referenziati non saranno salvati. |
| [SaveInAllFormats](#SaveInAllFormats) | Tutti i font referenziati saranno salvati (e referenziati nel CSS) come 3 file indipendenti: EOT, TTH, WOFF. Aumenta la dimensione dei dati di output ma rende l'output adatto alla stragrande maggioranza dei browser web. |
