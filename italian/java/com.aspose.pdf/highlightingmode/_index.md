Enumera la modalità di evidenziazione dell'annotazione, l'effetto visivo da utilizzare quando il pulsante del mouse è premuto o tenuto premuto all'interno della sua area attiva.

## Campi

| Campo | Descrizione |
| --- | --- |
| [Invert](#Invert) | Inverte il contenuto del rettangolo dell'annotazione. |
| [None](#None) | Nessuna evidenziazione. |
| [Outline](#Outline) | Inverte il bordo dell'annotazione. |
| [Push](#Push) | Mostra l'aspetto 'down' dell'annotazione, se presente. |
| [Toggle](#Toggle) | Uguale a Push (che è preferito). |
