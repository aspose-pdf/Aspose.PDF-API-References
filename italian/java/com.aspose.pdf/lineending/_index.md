Elenca gli stili di terminazione della linea da utilizzare nel disegno della linea.

## Campi

| Campo | Descrizione |
| --- | --- |
| [Butt](#Butt) | Una breve linea all'estremità perpendicolare alla linea stessa. |
| [Circle](#Circle) | Un cerchio riempito con il colore interno dell'annotazione, se presente. |
| [ClosedArrow](#ClosedArrow) | Due brevi linee che si incontrano formando un angolo acuto, come nello stile OpenArrow, e collegate da una terza linea per formare una punta di freccia triangolare chiusa riempita con il colore interno dell'annotazione, se presente. |
| [Diamond](#Diamond) | Una forma a diamante riempita con il colore interno dell'annotazione, se presente. |
| [None](#None) | Nessuna terminazione di linea. |
| [OpenArrow](#OpenArrow) | Due brevi linee che si incontrano formando un angolo acuto per formare una punta di freccia aperta. |
| [RClosedArrow](#RClosedArrow) | Una punta di freccia triangolare chiusa nella direzione opposta rispetto a ClosedArrow. |
| [ROpenArrow](#ROpenArrow) | Due brevi linee nella direzione opposta rispetto a OpenArrow. |
| [Slash](#Slash) | Una breve linea all'estremità circa 30 gradi in senso orario rispetto alla perpendicolare alla linea stessa. |
| [Square](#Square) | Un quadrato riempito con il colore interno dell'annotazione, se presente. |
