Specifica i tipi di segni della stampante da aggiungere a un documento. Questa enumerazione ha un attributo {@link FlagsAttribute} che consente una combinazione bitwise dei valori dei suoi membri.

## Campi

| Campo | Descrizione |
| --- | --- |
| [All](#All) | Specifica che tutti i tipi di segni della stampante devono essere aggiunti. |
| [BleedMarks](#BleedMarks) | Specifica che i segni di sbordo devono essere aggiunti. |
| [ColorBars](#ColorBars) | Specifica che le barre di colore devono essere aggiunte. |
| [None](#None) | Specifica che nessun segno della stampante deve essere aggiunto. |
| [PageInformation](#PageInformation) | Specifica che le informazioni di pagina devono essere aggiunte. |
| [RegistrationMarks](#RegistrationMarks) | Specifica che i segni di registrazione devono essere aggiunti. |
| [TrimMarks](#TrimMarks) | Specifica che i segni di ritaglio devono essere aggiunti. |
