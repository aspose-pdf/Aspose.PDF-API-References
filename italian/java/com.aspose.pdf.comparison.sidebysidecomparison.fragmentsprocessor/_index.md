## Classi

| Classe | Descrizione |
| --- | --- |
| [ExtractedFragmentsProcessorBase](./extractedfragmentsprocessorbase/) | Rappresenta una classe base per i processori di frammenti estratti. |
| [IgnoreSpacesFragmentsProcessor](./ignorespacesfragmentsprocessor/) | Rappresenta una classe per elaborare i frammenti di testo in modalità ignorare gli spazi. Questa classe ignora tutti gli spazi bianchi, evidenziando parole individuali come frammenti. |
| [NormalFragmentProcessor](./normalfragmentprocessor/) | Rappresenta una classe per elaborare i frammenti di testo in modalità normale. Questa classe considera solo gli spazi bianchi all'interno dei frammenti. |
| [ParseSpacesFragmentsProcessor](./parsespacesfragmentsprocessor/) | Rappresenta una classe per elaborare i frammenti di testo in modalità analisi spazi. Questa classe riconosce gli spazi tra i frammenti di testo in base alla distanza tra di essi. |
