## TextProperties class

Rappresenta le proprietà del testo come: dimensione del testo, colore, stile ecc.

Il tipo TextProperties espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextProperties(text_size) | Inizializza una nuova istanza della classe TextProperties |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| color | Ottiene o imposta il colore del testo. |
| is_color_specified | Ottiene o imposta un valore che indica se la proprietà [color](/pdf/python-net/aspose.pdf.facades/textproperties/) è specificata. |
| text_size | Ottiene o imposta la dimensione del testo. |
| is_text_size_specified | Ottiene o imposta un valore che indica se la proprietà [text_size](/pdf/python-net/aspose.pdf.facades/textproperties/) è specificata. |
