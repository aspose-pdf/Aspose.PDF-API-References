## PositioningMode enumeration

Definisce la modalità di posizionamento.<br/>            I valori possibili includono Legacy (compatibilità retroattiva) e <br/>            Current (metodo aggiornato di calcolo della posizione del testo)

## Members
| Nome membro | Descrizione |
| :- | :- |
| LEGACY | Posizionamento del testo legacy |
| MODERN_LINE_SPACING | Interlinea aggiornata, il calcolo della posizione verticale è effettuato secondo le vecchie regole <br/>            (cioè il testo è posizionato rispetto all'angolo inferiore sinistro del rettangolo specificato) |
| CURRENT | L'interlinea aggiornata e il calcolo della posizione verticale sono effettuati in base all'angolo superiore sinistro anziché a quello inferiore sinistro. |
