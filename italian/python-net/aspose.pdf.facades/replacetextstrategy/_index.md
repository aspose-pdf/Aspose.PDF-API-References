## ReplaceTextStrategy class

Questa classe contiene i parametri che definiscono il comportamento di PdfContentEditor quando viene eseguita l'operazione ReplaceText.

Il tipo ReplaceTextStrategy espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| ReplaceTextStrategy() | Inizializza una nuova istanza della classe ReplaceTextStrategy |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_regular_expression_used | Se false, la stringa da trovare è un semplice testo. Se true, la stringa da trovare è un'espressione regolare. |
| no_character_behavior | Azione eseguita quando non viene trovato alcun font appropriato per il testo modificato<br/>            (Lancia eccezione / Sostituisci con altro font / Sostituisci comunque). |
| replace_scope | Ambito dell'operazione di sostituzione (sostituisci la prima occorrenza o sostituisci tutte le occorrenze). |
