## FormFieldFacade class

Classe per rappresentare le proprietà del campo.

Il tipo FormFieldFacade espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| FormFieldFacade() | Inizializza una nuova istanza della classe FormFieldFacade |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| border_color | Il colore del bordo di un campo. |
| border_style | Lo stile di un bordo di campo. |
| border_width | La larghezza di un bordo di campo. |
| font | Il tipo di carattere di un testo di campo. |
| custom_font | Ottiene o imposta il nome del carattere quando questo non è standard (diverso dai 14 caratteri standard). |
| font_size | La dimensione di un testo di campo. |
| text_color | Il colore del testo di campo. |
| text_encoding | Il tipo di codifica del testo di campo. |
| alignment | L'allineamento di un testo di campo, il valore predefinito è allineamento a sinistra. |
| rotation | La rotazione di un testo di campo. |
| caption | La didascalia normale del campo modulo. |
| button_style | Lo stile del campo casella di controllo o pulsante radio, definito da FormFieldFacade.CheckBoxStyle*. |
| box | Un oggetto rettangolo che contiene la posizione del campo. |
| position | Un oggetto rettangolo che contiene la posizione del campo. |
| page_number | Un valore intero che contiene il numero della pagina su cui si trova il campo. |
| items | Un array di stringhe, ciascuna rappresentante un'opzione di un campo combo box/lista/pulsante radio. |
| export_items | Le opzioni per aggiungere una lista/combo/pulsante radio |
| background_color | Il colore di uno sfondo di campo, il valore predefinito è bianco. |
| backgroud_color | Proprietà obsoleta. Usa BackgroundColor. |
| BORDER_WIDTH_UNDIFIED | Larghezza del bordo non definita. |
| BORDER_WIDTH_UNDEFINED | Larghezza del bordo non definita. |
| BORDER_WIDTH_THIN | Definisce una larghezza del bordo sottile. |
| BORDER_WIDTH_MEDIUM | Definisce una larghezza del bordo media. |
| BORDER_WIDTH_THICK | Definisce una larghezza del bordo spessa. |
| BORDER_STYLE_SOLID | Definisce uno stile di bordo solido. |
| BORDER_STYLE_DASHED | Definisce uno stile di bordo tratteggiato. |
| BORDER_STYLE_BEVELED | Definisce uno stile di bordo smussato. |
| BORDER_STYLE_INSET | Definisce uno stile di bordo incassato. |
| BORDER_STYLE_UNDERLINE | Definisce uno stile di bordo sottolineato. |
| BORDER_STYLE_UNDEFINED | Stile di bordo non definito. |
| ALIGN_LEFT | Definisce l'allineamento allo stile sinistro. |
| ALIGN_CENTER | Definisce l'allineamento al centro. |
| ALIGN_RIGHT | Definisce l'allineamento a destra. |
| ALIGN_UNDEFINED | Stile di allineamento non definito. |
| ALIGN_JUSTIFIED | Definisce lo stile di allineamento di giustificazione del testo. |
| ALIGN_TOP | Definisce l'allineamento verticale in alto. |
| ALIGN_MIDDLE | Definisce l'allineamento verticale al centro. |
| ALIGN_BOTTOM | Definisce l'allineamento verticale in basso. |
| CHECK_BOX_STYLE_CIRCLE | Definisce uno stile di casella di controllo a cerchio. |
| CHECK_BOX_STYLE_CHECK | Definisce la forma di un campo di casella di controllo quando è selezionato. |
| CHECK_BOX_STYLE_CROSS | Definisce uno stile di casella di controllo a croce. |
| CHECK_BOX_STYLE_DIAMOND | Definisce uno stile di casella di controllo a diamante. |
| CHECK_BOX_STYLE_STAR | Definisce uno stile di casella di controllo a stella. |
| CHECK_BOX_STYLE_SQUARE | Definisce uno stile di casella di controllo quadrata. |
| CHECK_BOX_STYLE_UNDEFINED | Definisce uno stile di casella di controllo non definito. |
