## StampInfo class

Classe che rappresenta le informazioni del timbro.

Il tipo StampInfo espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| stamp_id | Ottiene l'identificatore del timbro. |
| index_on_page | Ottiene l'indice del timbro nella pagina. |
| stamp_type | Ottiene il tipo di timbro (immagine / modulo). |
| rectangle | Ottiene il rettangolo dove è posizionato il timbro. |
| image | Ottiene l'immagine del timbro. Può essere null se il timbro non contiene immagini (ad esempio per un timbro di testo). |
| modulo | Ottiene XForm del timbro. |
| text | Ottiene il testo nel timbro. |
| visibile | Ottiene la visibilità del timbro. Se false, il timbro è nascosto (con HideStampById). Il timbro nascosto può essere ripristinato con ShowStampById. |
