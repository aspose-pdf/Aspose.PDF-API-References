## LineInfo class

Rappresenta le informazioni della linea.

Il tipo LineInfo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| LineInfo() | Inizializza una nuova istanza della classe LineInfo |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| vertice_coordinate | Ottiene o imposta un array di numeri che rappresentano le coordinate orizzontali e verticali alternanti, rispettivamente, di ciascun vertice. |
| line_color | Ottiene o imposta il colore di una linea. |
| line_width | Ottiene o imposta la larghezza di una linea. |
| visibility | Ottiene o imposta la visibilità di una linea. |
| line_dash_pattern | Ottiene o imposta il modello di tratteggio di una linea. |
| border_style | Ottiene o imposta lo stile del bordo di una linea, 0 rappresenta solido, 1 rappresenta tratteggiato, 2 rappresenta smussato, 3 rappresenta inserito, 4 rappresenta sottolineato. |
