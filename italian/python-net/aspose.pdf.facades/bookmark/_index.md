## Bookmark class

Rappresenta un segnalibro.

Il tipo Bookmark espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Bookmark() | Inizializza una nuova istanza della classe Bookmark |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| azione | Ottiene o imposta l'azione associata al segnalibro.<br/>            Se è presente PageNumber l'azione non può essere specificata.<br/>            Il tipo di azione include: "GoTo", "GoToR", "Launch", "Named". |
| bold_flag | Ottiene o imposta il flag grassetto del titolo del segnalibro. |
| child_item | Ottiene o imposta i figli del segnalibro. |
| child_items | Ottiene o imposta i figli del segnalibro. |
| destination | Ottiene o imposta la pagina di destinazione del segnalibro. Necessario se l'azione è impostata su string.Empty. |
| italic_flag | Ottiene o imposta il flag corsivo del titolo del segnalibro. |
| level | Ottiene o imposta il livello gerarchico del segnalibro. |
| page_display | Ottiene o imposta il tipo di visualizzazione della pagina di destinazione del segnalibro. |
| page_display_bottom | Ottiene o imposta la coordinata inferiore della visualizzazione della pagina. |
| page_display_left | Ottiene o imposta la coordinata sinistra della visualizzazione della pagina. |
| page_display_right | Ottiene o imposta la coordinata destra della visualizzazione della pagina. |
| page_display_top | Ottiene o imposta la coordinata superiore della visualizzazione della pagina. |
| page_display_zoom | Ottiene o imposta il fattore di zoom della visualizzazione della pagina. |
| page_number | Ottiene o imposta il numero della pagina di destinazione del segnalibro. |
| remote_file | Ottiene o imposta il file (percorso) necessario per l'azione "GoToR" del segnalibro. |
| title | Ottiene o imposta il titolo del segnalibro. |
| title_color | Ottiene o imposta il colore del titolo del segnalibro. |
| open | Ottiene o imposta lo stato del segnalibro (aperto, chiuso). |
