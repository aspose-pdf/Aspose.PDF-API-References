## DocumentPrivilege class

Rappresenta i privilegi per accedere al file Pdf. Vedi [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             Ci sono 4 modalità di utilizzo di questa classe:<br/>             1. Utilizzare direttamente un privilegio predefinito.<br/>             2. Basarsi su un privilegio predefinito e modificare alcune autorizzazioni specifiche.<br/>             3. Basarsi su un privilegio predefinito e modificare una combinazione specifica di autorizzazioni di Adobe Professional.<br/>             4. Mescolare il modo 2 e il modo 3.

Il tipo DocumentPrivilege espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| allow_print | Imposta l'autorizzazione che consente la stampa o meno. <br/>            true consente e false è proibito. |
| allow_degraded_printing | Imposta l'autorizzazione che consente la stampa degradata o meno. <br/>            true consente e false è proibito. |
| allow_modify_contents | Imposta l'autorizzazione che consente la modifica del contenuto o meno. <br/>            true consente e false è proibito. |
| allow_copy | Imposta l'autorizzazione che consente la copia o meno. <br/>            true consente e false è proibito. |
| allow_modify_annotations | Imposta l'autorizzazione che consente la modifica delle annotazioni o meno. <br/>            true consente e false è proibito. |
| allow_fill_in | Imposta l'autorizzazione che consente la compilazione dei moduli o meno. <br/>            true consente e false è proibito. |
| allow_screen_readers | Imposta l'autorizzazione che consente i lettori di schermo o meno. <br/>            true consente e false è proibito. |
| allow_assembly | Imposta l'autorizzazione che consente l'assemblaggio o meno. <br/>            true consente e false è proibito. |
| degraded_printing | Consente la stampa degradata. |
| print | Consente la stampa del file. |
| modify_contents | Consente la modifica del file. |
| copy | Consente la copia del file. |
| modify_annotations | Consente la modifica delle annotazioni del file. |
| fill_in | Consente la compilazione dei moduli nel file. |
| screen_readers | Consente la lettura solo sullo schermo. |
| assembly | Consente l'assemblaggio del file. |
| allow_all | Tutto consentito. |
| forbid_all | Tutto vietato. |
