## ViewerPreference class

Descrive le preferenze del visualizzatore (modalità pagina, modalità pagina non a schermo intero, layout della pagina).

Il tipo ViewerPreference espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| ViewerPreference() | Inizializza una nuova istanza della classe ViewerPreference |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| PAGE_MODE_USE_OC | Pannello del gruppo di contenuti opzionali visibile. |
| DISPLAY_DOC_TITLE | Un flag che specifica se la barra del titolo della finestra deve visualizzare il titolo del documento |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | Pannello del gruppo di contenuti opzionali visibile. |
| PAGE_LAYOUT_SINGLE_PAGE | Visualizza una pagina alla volta. |
| PAGE_LAYOUT_ONE_COLUMN | Visualizza le pagine in una colonna. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | Visualizza le pagine in due colonne, con le pagine dispari a destra |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | Visualizza le pagine in due colonne, con le pagine dispari a destra. |
| PAGE_MODE_USE_NONE | Né la struttura del documento né le miniature sono visibili |
| PAGE_MODE_USE_OUTLINES | Struttura del documento visibile. |
| PAGE_MODE_USE_THUMBS | Miniature visibili. |
| PAGE_MODE_FULL_SCREEN | Modalità a schermo intero, senza barra dei menu, controlli della finestra o qualsiasi altra finestra visibile. |
| PAGE_MODE_USE_ATTACHMENT | Modalità pagina con allegati. |
| HIDE_TOOLBAR | Un flag che specifica se nascondere le barre degli strumenti del lettore conforme quando il documento è attivo. |
| HIDE_MENUBAR | Un flag che specifica se nascondere la barra dei menu del lettore conforme quando il documento è attivo. |
| HIDE_WINDOW_UI | Un flag che specifica se nascondere gli elementi dell'interfaccia utente nella finestra del documento (come le barre di scorrimento e i controlli di navigazione), lasciando visualizzato solo il contenuto del documento. |
| FIT_WINDOW | Un flag che specifica se ridimensionare la finestra del documento per adattarla alle dimensioni della prima pagina visualizzata. |
| CENTER_WINDOW | Un flag che specifica se posizionare la finestra del documento al centro dello schermo. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | Né la struttura del documento né le miniature sono visibili. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | Struttura del documento visibile. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | Miniature visibili |
| DIRECTION_L2R | Ordine di lettura del testo da sinistra a destra. |
| DIRECTION_R2L | Ordine di lettura del testo da destra a sinistra. |
| SIMPLEX | Stampa su un solo lato. |
| DUPLEX_FLIP_SHORT_EDGE | Stampa duplex e ribalta sul bordo corto del foglio. |
| DUPLEX_FLIP_LONG_EDGE | Stampa duplex e ribalta sul bordo corto del foglio. |
