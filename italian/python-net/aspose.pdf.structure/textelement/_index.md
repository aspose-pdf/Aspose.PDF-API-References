## TextElement class

Elemento di testo generale della struttura logica del documento.

Il tipo TextElement espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| children | Ottiene la collezione di elementi figli. |
| lang | (Optional; PDF 1.4) Una lingua che specifica la lingua naturale per tutto il testo<br/>            nell'elemento di struttura, tranne dove è sovrascritta da specifiche di lingua per elementi di struttura annidati<br/>            o contenuti marcati. |
| actual_text | (Optional; PDF 1.4) Testo che è una sostituzione esatta per l'elemento di struttura e i suoi figli.<br/>            Questo testo di sostituzione (che dovrebbe applicarsi alla più piccola porzione di contenuto possibile)<br/>            è utile quando si estraggono i contenuti del documento a supporto dell'accessibilità per gli utenti<br/>            con disabilità o per altri scopi. |
| alt | (Optional) Una descrizione alternativa dell'elemento di struttura e dei suoi figli in<br/>            forma leggibile dall'uomo, che è utile quando si estraggono i contenuti del documento a supporto<br/>            dell'accessibilità per gli utenti con disabilità o per altri scopi. |
| e | (Optional; PDF 1.5) La forma estesa di un'abbreviazione. |
| text | Ottiene il valore dell'elemento di struttura text. |
