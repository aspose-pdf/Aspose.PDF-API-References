## StructureTextState class

Rappresenta le impostazioni dello stato del testo per gli Elementi di Struttura Testo e TaggedContent (ITextElement, ITaggedContent)

Il tipo StructureTextState espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| font | Ottiene o imposta il font del testo. |
| font_size | Ottiene o imposta la dimensione del font del testo. |
| font_style | Ottiene o imposta lo stile del font del testo. |
| foreground_color | Ottiene o imposta il colore di primo piano del testo. |
| background_color | Ottiene o imposta il colore di sfondo del testo. |
| sottolinea | Ottiene o imposta la sottolineatura per il testo. |
| strike_out | Ottiene o imposta lo strikeout per il testo. |
| superscript | Ottiene o imposta il apice del testo. |
| subscript | Ottiene o imposta il pedice del testo. |
| horizontal_scaling | Ottiene o imposta la scala orizzontale del testo. |
| line_spacing | Ottiene o imposta l'interlinea del testo. |
| character_spacing | Ottiene o imposta la spaziatura dei caratteri del testo. |
| word_spacing | Ottiene o imposta la spaziatura delle parole del testo. |
| margin_info | Ottiene o imposta il margine per l'elemento di struttura a blocchi. |
