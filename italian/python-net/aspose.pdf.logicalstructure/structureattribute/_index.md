## StructureAttribute class

Rappresenta l'attributo dell'elemento di struttura.

Il tipo StructureAttribute espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| StructureAttribute(attribute_key) | Inizializza una nuova istanza della classe StructureAttribute |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| key | Ottiene la chiave dell'attributo. |
| is_initialized_value | Ottiene lo stato del valore dell'attributo di struttura. True se il valore è impostato. |
