## TableTRElement class

Rappresenta l'elemento di struttura TR nella struttura logica della tabella.

Il tipo TableTRElement espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| parent_element | Nessuno |
| child_elements | Nessuno |
| default_attribute_owner | Ottiene |
| attributes | Ottiene |
| structure_type | Ottiene il tipo dell'elemento di struttura. |
| id | Ottiene l'ID per l'elemento di struttura. |
| title | Ottiene o imposta il titolo per l'elemento di struttura. |
| language | Ottiene o imposta la lingua per l'elemento di struttura. |
| alternative_text | Ottiene o imposta il testo alternativo per l'elemento di struttura. |
| expansion_text | Ottiene o imposta il testo di espansione per l'elemento di struttura. |
| actual_text | Ottiene o imposta il testo reale per l'elemento di struttura. |
| background_color | Ottiene o imposta il colore di sfondo della riga. |
| border | Ottiene o imposta il bordo della riga. |
| default_cell_border | Ottiene il bordo predefinito della cella. |
| min_row_height | Ottiene l'altezza della riga. |
| fixed_row_height | Ottiene l'altezza fissa della riga - la riga può avere un'altezza fissa. |
| is_in_new_page | Ottiene se la riga fissa è su una nuova pagina - la pagina con questa proprietà dovrebbe essere stampata nella pagina successiva. Predefinito false. |
| is_row_broken | Ottiene se la riga può essere interrotta tra due pagine. |
| default_cell_text_state | Ottiene o imposta lo stato di testo predefinito per le celle della riga |
| default_cell_padding | Ottiene o imposta il margine predefinito per le celle della riga. |
| vertical_alignment | Ottiene o imposta l'allineamento verticale. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| append_child(element) | Nessuno |
| change_parent_element(new_parent_element) | Cambia l'elemento genitore per l'elemento di struttura corrente |
| generate_id() | Genera ID per l'elemento di struttura. |
| set_id(id) | Imposta ID per l'elemento di struttura. |
| clear_id() | Cancella ID per l'elemento di struttura. |
| set_tag(new_tag) | Imposta tag personalizzato per l'elemento di struttura. |
| create_th() | Crea [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/) e lo aggiunge alla tabella corrente. |
| create_td() | Crea [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/) e lo aggiunge alla tabella corrente. |
