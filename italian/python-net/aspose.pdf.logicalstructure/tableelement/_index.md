## TableElement class

Rappresenta l'elemento di struttura Table nella struttura logica.

Il tipo TableElement espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| parent_element | Nessuno |
| child_elements | Nessuno |
| default_attribute_owner | Ottiene |
| attributes | Ottiene |
| structure_type | Ottiene il tipo dell'elemento di struttura. |
| id | Ottiene l'ID per l'elemento di struttura. |
| title | Ottiene o imposta il titolo per l'elemento di struttura. |
| language | Ottiene o imposta la lingua per l'elemento di struttura. |
| alternative_text | Ottiene o imposta il testo alternativo per l'elemento di struttura. |
| expansion_text | Ottiene o imposta il testo di espansione per l'elemento di struttura. |
| actual_text | Ottiene o imposta il testo reale per l'elemento di struttura. |
| background_color | Ottiene o imposta il colore di sfondo della tabella. |
| border | Ottiene o imposta il bordo della tabella. |
| alignment | Ottiene o imposta l'allineamento della tabella. |
| corner_style | Ottiene o imposta gli stili degli angoli del bordo |
| broken | Ottiene o imposta la rottura verticale della tabella; |
| column_adjustment | Ottiene o imposta la regolazione delle colonne della tabella. |
| column_widths | Ottiene le larghezze delle colonne della tabella. |
| default_cell_border | Ottiene il bordo predefinito della cella. |
| default_cell_padding | Ottiene o imposta il padding predefinito della cella. |
| default_cell_text_state | Ottiene o imposta lo stato di testo predefinito della cella. |
| default_column_width | Ottiene o imposta la larghezza predefinita della colonna. |
| is_broken | Ottiene o imposta se la tabella è interrotta - verrà troncata per la pagina successiva. |
| is_borders_included | Ottiene o imposta il bordo incluso nelle larghezze delle colonne. |
| left | Ottiene o imposta la coordinata sinistra della tabella. |
| top | Ottiene o imposta la coordinata superiore della tabella. |
| repeating_columns_count | Ottiene o imposta il numero massimo di colonne per la tabella. |
| repeating_rows_count | Ottiene il conteggio delle prime righe ripetute per più pagine. |
| repeating_rows_style | Ottiene lo stile per le righe ripetute. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| append_child(element) | Nessuno |
| change_parent_element(new_parent_element) | Cambia l'elemento genitore per l'elemento di struttura corrente |
| generate_id() | Genera ID per l'elemento di struttura. |
| set_id(id) | Imposta ID per l'elemento di struttura. |
| clear_id() | Cancella ID per l'elemento di struttura. |
| set_tag(new_tag) | Imposta tag personalizzato per l'elemento di struttura. |

| create_t_foot() | Crea [TableTFootElement](/pdf/python-net/aspose.pdf.logicalstructure/tabletfootelement/) e lo aggiunge alla tabella corrente. |
