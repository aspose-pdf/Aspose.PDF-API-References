## MarkupSection class

Rappresenta una sezione di markup - la regione rettangolare di una pagina che contiene testo e può essere visualmente separata da altri blocchi di testo.

Il tipo MarkupSection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| rectangle | Rettangolo della sezione |
| fragments | Raccolta di oggetti [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) non vuoti che si trovano all'interno della sezione. |
| paragraphs | Raccolta di oggetti [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) che si trovano all'interno della sezione. |
