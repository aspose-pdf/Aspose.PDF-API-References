## TextParagraph class

Rappresenta i paragrafi di testo come oggetto di testo multilinea.

Il tipo TextParagraph espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextParagraph() | Inizializza una nuova istanza della classe TextParagraph |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| vertical_alignment | Ottiene o imposta l'allineamento verticale per il testo all'interno del [rettangolo](/pdf/python-net/aspose.pdf.text/textparagraph/) del paragrafo. |
| subsequent_lines_indent | Ottiene o imposta il valore di rientro delle righe successive.<br/> Se impostato a un valore diverso da zero, ha un vantaggio rispetto al valore FormattingOptions.SubsequentLinesIndent. |
| first_line_indent | Ottiene o imposta il valore di rientro delle righe successive.<br/> Se impostato a un valore diverso da zero, ha un vantaggio rispetto al valore FormattingOptions.SubsequentLinesIndent. |
| justify | Ottiene o imposta il valore che indica se il testo è giustificato. |
| horizontal_alignment | Ottiene o imposta l'allineamento orizzontale per il testo all'interno del [rettangolo](/pdf/python-net/aspose.pdf.text/textparagraph/) del paragrafo. |
| formatting_options | Ottiene o imposta le opzioni di formattazione. |
| position | Ottiene o imposta la posizione del paragrafo. |
| text_rectangle | Ottiene il rettangolo del testo posizionato nel paragrafo. |
| rectangle | Ottiene o imposta il rettangolo del paragrafo. |
| margine | Ottiene o imposta il padding. |
| rotation | Ottiene o imposta l'angolo di rotazione in gradi. |

| append_line(line, text_state, line_spacing) | Aggiunge una riga di testo con i parametri dello stato del testo |
