## TextExtractionErrorLocation class

Rappresenta la posizione nel documento PDF in cui è comparso l'errore di estrazione del testo.

Il tipo TextExtractionErrorLocation espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| path | Posizione del documento PDF in cui è comparso l'errore di estrazione del testo. |
| page_number | Numero della pagina del documento in cui è stato individuato l'errore di estrazione del testo. |
| object_type | Tipo dell'oggetto PDF (Page o xForm) in cui è stato individuato l'errore di estrazione del testo nel flusso dei contenuti. |
| form_key | Chiave (nome) del PDF Form XObject in cui è stato individuato l'errore di estrazione del testo nel flusso dei contenuti. Non vuoto se ObjectType == 'xForm'. |
| operator_index | Indice dell'operatore che mostra il testo nel flusso dei contenuti (collezione di operatori) che causa l'errore di estrazione del testo. |
| operator_string | Testo dell'operatore che causa l'errore di estrazione del testo. |
| font_used_key | Chiave (nome) dell'oggetto PDF Font utilizzato per la visualizzazione dell'operatore che causa l'errore di estrazione del testo. |
| text_start_point | Chiave (nome) dell'oggetto PDF Font utilizzato per la visualizzazione dell'operatore che causa l'errore di estrazione del testo. |
