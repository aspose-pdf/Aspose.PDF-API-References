## FontCollection class

Rappresenta la collezione di font.

Il tipo FontCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| sync_root | Ottiene un oggetto che può essere usato per sincronizzare l'accesso alla raccolta. |
| is_synchronized | Ottiene un valore che indica se l'accesso alla raccolta è sincronizzato (thread safe). |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Restituisce l'elemento font all'indice specificato. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| add(new_font, res_name) | Aggiunge un nuovo font alle risorse dei font e restituisce il nome assegnato automaticamente alla risorsa del font. |
