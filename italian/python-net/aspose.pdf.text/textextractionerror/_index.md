## TextExtractionError class

Descrive l'errore di estrazione del testo che è comparso nel documento PDF.

Il tipo TextExtractionError espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| summary | Breve descrizione dell'errore. |
| descrizione | Descrizione estesa dell'errore. |
| location | Posizione dell'errore. |
| font_key | Chiave (nome PDF) dell'oggetto Font utilizzato per mostrare il testo che causa l'errore di estrazione. |
| font_name | Nome leggibile (interno) dell'oggetto Font utilizzato per mostrare il testo che causa l'errore di estrazione. |
| extracted_text | Testo effettivamente estratto. |
