## TextRenderingMode enumeration

La modalità di rendering del testo, Tmode, determina se la visualizzazione del testo deve far sì che i contorni dei glifi vengano tracciati, riempiti, usati come limite di ritaglio, o una combinazione di questi tre.

## Members
| Nome membro | Descrizione |
| :- | :- |
| FILL_TEXT | Riempire il testo. |
| STROKE_TEXT | Tracciare il testo. |
| FILL_THEN_STROKE_TEXT | Riempire, quindi tracciare il testo. |
| INVISIBLE | Né riempire né tracciare il testo (invisibile). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Riempire il testo e aggiungere al percorso per il ritaglio (vedi 9.3.6, "Text Rendering Mode,"). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Tracciare il testo e aggiungere al percorso per il ritaglio. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Riempire, quindi tracciare il testo e aggiungere al percorso per il ritaglio. |
| ADD_PATH_TO_CLIPPING | Aggiungere il testo al percorso per il ritaglio. |
