## TextReplaceOptions class

Rappresenta le opzioni di sostituzione del testo.

Il tipo TextReplaceOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextReplaceOptions(scope) | Inizializza una nuova istanza della classe TextReplaceOptions |
| TextReplaceOptions(adjustment) | Inizializza una nuova istanza della classe TextReplaceOptions |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| replace_scope | Ottiene o imposta un ambito in cui viene applicata l'operazione di sostituzione del testo |
| replace_adjustment_action | Ottiene o imposta un'azione che verrà eseguita dopo la sostituzione del frammento di testo con una versione più breve. |
| adjustment_new_line_spacing | Ottiene o imposta il valore dell'interlinea utilizzata se la regolazione di sostituzione è forzata a creare una nuova riga di testo.<br/>            Il valore previsto è un moltiplicatore della dimensione del carattere del testo sostituito. Il valore predefinito è 1.2. |
