## TabStop class

Rappresenta una posizione personalizzata di tabulazione in un paragrafo.

Il tipo TabStop espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TabStop() | Inizializza una nuova istanza della classe [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/). |
| TabStop(position) | Inizializza una nuova istanza della classe TabStop |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| position | Ottiene o imposta un valore float che indica la posizione del tab stop. |
| leader_type | Ottiene o imposta un enum [TabLeaderType](/pdf/python-net/aspose.pdf.text/tableadertype/) che indica il tipo di tab leader. |
| alignment_type | Ottiene o imposta un enum [alignment_type](/pdf/python-net/aspose.pdf.text/tabstop/) che indica il tipo di allineamento del tab. |
| is_read_only | Ottiene il valore che indica che questa istanza di [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) è già collegata a [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) ed è diventata di sola lettura. |
