## TextEditOptions class

Descrive le opzioni delle operazioni di modifica del testo.

Il tipo TextEditOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextEditOptions(no_character_behavior) | Inizializza una nuova istanza della classe TextEditOptions |
| TextEditOptions(font_replace_behavior) | Inizializza una nuova istanza della classe TextEditOptions |
| TextEditOptions(allow_language_transformation) | Inizializza una nuova istanza della classe TextEditOptions |
| TextEditOptions(language_transformation_behavior) | Inizializza una nuova istanza della classe TextEditOptions |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| replacement_font | Ottiene o imposta il font utilizzato per la sostituzione se il font dell'utente non contiene il carattere richiesto |
| no_character_behavior | Ottiene o imposta la modalità che definisce il comportamento nel caso in cui i font non contengano i caratteri richiesti. |
| font_replace_behavior | Ottiene la modalità che definisce il comportamento per gli scenari di sostituzione dei font. |
| allow_language_transformation | Ottiene o imposta il valore che consente l'uso della trasformazione linguistica durante l'aggiunta o la modifica del testo.<br/>            true - la trasformazione linguistica verrà applicata se necessario (valore predefinito).<br/>            false - la trasformazione linguistica NON verrà applicata. |
| language_transformation_behavior | Ottiene la modalità che definisce il comportamento per gli scenari di trasformazione linguistica. |
| clipping_paths_processing | Ottiene la modalità per l'elaborazione del percorso di ritaglio del testo modificato. |
| to_attempt_get_underline_from_source | Ottiene o imposta il valore che consente la ricerca di sottolineature del testo nella pagina del documento sorgente.<br/>            (Obsoleto) Si prega di utilizzare TextSearchOptions.SearchForTextRelatedGraphics invece di questo. |
