## SystemFontsSubstitution class

Rappresenta una classe per la strategia di sostituzione dei font che sostituisce i font con i font di sistema.

Il tipo SystemFontsSubstitution espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| SystemFontsSubstitution(font_categories) | Inizializza una nuova istanza della classe SystemFontsSubstitution |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| font_categories | Ottiene o imposta le categorie di caratteri di sostituzione che devono essere sostituite con i caratteri di sistema. |
| default_font | Ottiene o imposta il carattere di sostituzione predefinito.<br/>            Il carattere viene utilizzato quando non è stata trovata alcun'altra sostituzione valida ma il carattere iniziale appartiene alla categoria di sostituzione target ([font_categories](/pdf/python-net/aspose.pdf.text/systemfontssubstitution/)). |
