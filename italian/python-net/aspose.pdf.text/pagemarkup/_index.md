## PageMarkup class

Il markup della pagina è rappresentato da collezioni di [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) e [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/).

Il tipo PageMarkup espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| numero | Ottiene il numero di pagina elaborato. |
| rectangle | Ottiene il rettangolo della pagina elaborata. |
| sections | Ottiene la collezione di [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) trovata nella pagina. |
| paragraphs | Ottiene la collezione di [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) trovata nella pagina. |
| text_fragments | Ottiene la collezione di [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) trovata nella pagina. |
| is_multicolumn_paragraphs_allowed | Ottiene o imposta il valore che indica se le righe di testo iniziali di una sezione successiva possono essere trattate come continuazione dell'ultimo paragrafo di una sezione precedente. |
