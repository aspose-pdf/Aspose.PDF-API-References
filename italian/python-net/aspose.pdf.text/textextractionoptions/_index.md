## TextExtractionOptions class

Rappresenta le opzioni di estrazione del testo.

Il tipo TextExtractionOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextExtractionOptions(formatting_mode) | Inizializza una nuova istanza della classe TextExtractionOptions |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| formatting_mode | Restituisce la modalità di formattazione. |
| scale_factor | Restituisce o imposta il fattore che verrà applicato per scalare la dimensione del carattere durante l'estrazione in modalità pura.<br/>            Un valore più piccolo porta a più spazi nel testo estratto.<br/>            Il valore predefinito è 1 - nessuna scalatura;<br/>            Impostare il valore a zero consente all'algoritmo di scegliere automaticamente la scalatura. |
