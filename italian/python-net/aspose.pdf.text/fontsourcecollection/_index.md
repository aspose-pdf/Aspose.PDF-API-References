## FontSourceCollection class

Rappresenta la collezione di sorgenti di font.

Il tipo FontSourceCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| sync_root | Ottiene un oggetto che può essere usato per sincronizzare l'accesso alla raccolta. |
| is_synchronized | Ottiene un valore che indica se l'accesso alla raccolta è sincronizzato (thread safe). |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Restituisce l'elemento font all'indice specificato. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| delete(font_source) | Elimina l'elemento della fonte del font. |
