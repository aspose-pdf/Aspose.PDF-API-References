## TextSegment class

Rappresenta un segmento di testo PDF.

Il tipo TextSegment espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextSegment() | Crea un oggetto TextSegment. |
| TextSegment(text) | Inizializza una nuova istanza della classe TextSegment |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| start_char_index | Ottiene l'indice del carattere iniziale del segmento corrente nell'operatore di visualizzazione del testo (Tj, TJ). |
| end_char_index | Ottiene l'indice del carattere finale del segmento corrente nell'operatore di visualizzazione del testo (Tj, TJ). |
| text | Ottiene o imposta l'oggetto stringa di testo che l'oggetto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) rappresenta. |
| text_state | Ottiene o imposta lo stato del testo per il testo che l'oggetto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) rappresenta. |
| position | Ottiene la posizione del testo per il testo, rappresentato con l'oggetto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| rectangle | Ottiene il rettangolo del TextSegment |
| baseline_position | Ottiene la posizione del testo per il testo, rappresentato con l'oggetto [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/).<br/>            L'YIndent della struttura Position rappresenta la coordinata della linea di base del segmento di testo. |
| text_edit_options | Ottiene o imposta le opzioni di modifica del testo. Le opzioni definiscono un comportamento speciale quando il simbolo richiesto non può essere scritto con il carattere. |
| caratteri | Ottiene la collezione di oggetti CharInfo che rappresentano le informazioni sui caratteri nel segmento di testo. |
| collegamento | Ottiene o imposta il collegamento ipertestuale del segmento (per il generatore PDF). |
## Metodi

| :- | :- |
