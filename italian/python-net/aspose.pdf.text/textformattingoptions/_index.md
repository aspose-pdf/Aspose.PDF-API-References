## TextFormattingOptions class

Rappresenta le opzioni di formattazione del testo.

Il tipo TextFormattingOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextFormattingOptions(wrap_mode) | Inizializza una nuova istanza della classe TextFormattingOptions |
| TextFormattingOptions() | Inizializza una nuova istanza dell'oggetto [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) con modalità di a capo parole non definita. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| wrap_mode | Ottiene o imposta la modalità di a capo parole.<br/>            Il valore predefinito è WordWrapMode.NoWrap |
| line_spacing | Ottiene o imposta la modalità di interlinea.<br/>            Il valore predefinito è LineSpacingMode.FontSize |
| hyphen_symbol | Ottiene o imposta il simbolo di trattino utilizzato nel processo di sillabazione. |
| subsequent_lines_indent | Ottiene o imposta il valore di rientro delle righe successive. |
| first_line_indent | Ottiene o imposta il valore di rientro della prima riga. |
