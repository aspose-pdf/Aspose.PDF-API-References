## TextFragmentState class

Rappresenta lo stato del testo di un frammento di testo.

Il tipo TextFragmentState espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| TextFragmentState(fragment) | Inizializza una nuova istanza della classe TextFragmentState |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| character_spacing | Ottiene o imposta la spaziatura dei caratteri del testo, rappresentata dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| line_spacing | Ottiene o imposta l'interlinea del testo. |
| horizontal_scaling | Ottiene o imposta la scala orizzontale del testo, rappresentata dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| subscript | Ottiene o imposta il pedice del testo, rappresentato dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| superscript | Ottiene o imposta l'apice del testo, rappresentato dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| word_spacing | Ottiene o imposta la spaziatura delle parole del testo. |
| invisibile | Ottiene o imposta l'invisibilità del testo. |
| rendering_mode | Ottiene o imposta la modalità di rendering del testo. |
| font_size | Ottiene o imposta la dimensione del carattere del testo, rappresentato dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font | Ottiene o imposta il font del testo, rappresentato dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| foreground_color | Ottiene o imposta il colore di primo piano del testo, rappresentato dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| stroking_color | Ottiene o imposta le operazioni di tracciatura del colore della resa di [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) (traccia del testo, bordo del rettangolo) |
| underline | Ottiene o imposta la sottolineatura per il testo, rappresentata dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| strike_out | Imposta il barrato per il testo, rappresentato dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| background_color | Imposta il colore di sfondo del testo, rappresentato dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font_style | Imposta lo stile del font del testo, rappresentato dall'oggetto [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| horizontal_alignment | Ottiene o imposta l'allineamento orizzontale del testo. |
| TAB_TAG | Puoi inserire questo tag nel testo per dichiarare la tabulazione. |
| TABSTOP_DEFAULT_VALUE | Valore predefinito della tabulazione nelle larghezze del carattere spazio del font predefinito. |
| tab_stops | Ottiene le tabulazioni per il testo. |
| formatting_options | Ottiene o imposta le opzioni di formattazione.<br/>            L'impostazione delle opzioni sarà efficace solo negli scenari di generatore. |
| rotation | Ottiene o imposta l'angolo di rotazione in gradi. |
| draw_text_rectangle_border | Ottiene o imposta il flag che indica se il bordo del rettangolo di testo è disegnato. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| apply_changes_from(text_state) | Applica le impostazioni da un altro textState. |
| measure_string(str) | Misura la stringa. |
