## ITaggedContent class

Rappresenta l'interfaccia per lavorare con il contenuto TaggedPdf del documento.

Il tipo ITaggedContent espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| structure_text_state | Ottieni le impostazioni di [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) per l'intero documento. |
| struct_tree_root_element | Restituisce il [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/) del documento PDF. |
| root_element | Restituisce l'elemento radice [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) della struttura logica del documento PDF. |
