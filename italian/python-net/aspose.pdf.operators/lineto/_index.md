## LineTo class

Classe che rappresenta l'operatore l (aggiunge una linea al percorso).

Il tipo LineTo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| LineTo(x, y) | Inizializza una nuova istanza della classe LineTo |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| index | Indice dell'operatore nell'elenco degli operatori della pagina. |
| x | Coordinata X del punto della linea. |
| y | Coordinata Y del punto della linea. |
