## BasicSetColorOperator class

Classe base per gli operatori set color.

Il tipo BasicSetColorOperator espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| index | Indice dell'operatore nell'elenco degli operatori della pagina. |
| r | Restituisce il componente rosso del colore |
| g | Restituisce il componente verde del colore |
| b | Restituisce il componente rosso del colore |
| c | Restituisce il componente ciano del colore CMYK. |
| m | Restituisce il componente magenta del colore CMYK. |
| y | Restituisce il componente giallo del colore CMYK. |
| k | Restituisce il componente nero del colore CMYK. |
| grey | Restituisce il componente nero del colore grigio. |
| color | Restituisce l'array dei componenti del colore. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| accept(visitor) | Accetta il visitatore IOperatorSelector che fornisce l'elaborazione degli operatori. |
| is_text_show_operator(op) | Determina se l'operatore è quello responsabile dell'output di testo (Tj, TJ, ecc.) |
| get_color() | Restituisce il colore specificato dall'operatore. |
