## SetColor class

Rappresenta la classe per l'operatore sc (imposta il colore per le operazioni di non tracciatura).

Il tipo SetColor espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| SetColor() | Inizializza l'operatore. |
| SetColor(g) | Inizializza una nuova istanza della classe SetColor |
| SetColor(r, g, b) | Inizializza una nuova istanza della classe SetColor |
| SetColor(c, m, y, k) | Inizializza una nuova istanza della classe SetColor |
| SetColor(color) | Inizializza una nuova istanza della classe SetColor |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| index | Nessuno |
| r | Restituisce il componente rosso del colore |
| g | Restituisce il componente verde del colore |
| b | Restituisce il componente rosso del colore |
| c | Restituisce il componente ciano del colore CMYK. |
| m | Restituisce il componente magenta del colore CMYK. |
| y | Restituisce il componente giallo del colore CMYK. |
| k | Restituisce il componente nero del colore CMYK. |
| grey | Restituisce il componente nero del colore grigio. |
| color | Restituisce l'array dei componenti del colore. |
