## GS class

Classe che rappresenta l'operatore gs (imposta i parametri dal dizionario dei parametri dello stato grafico).

Il tipo GS espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| GS(name) | Inizializza una nuova istanza della classe GS |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| index | Indice dell'operatore nell'elenco degli operatori della pagina. |
| name | Ottiene o imposta il nome della risorsa di stato grafico. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| accept(visitor) | Accetta l'oggetto visitor per elaborare l'operatore. |
