## SubmitFormAction class

Classe che descrive l'azione submit-form.

Il tipo SubmitFormAction espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| SubmitFormAction() | Inizializza l'oggetto SubmitFormAction. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| next | Azioni successive nella sequenza. |
| flags | Ottiene o imposta i flag dell'azione di invio. |
| url | URL di destinazione. |
| EXCLUDE | Se cancellato, l'array Fields specifica quali campi includere nella sottomissione. |
| INCLUDE_NO_VALUE_FIELDS | Se impostato, tutti i campi designati dall'array Fields e dal flag Include/Exclude verranno inviati. |
| EXPORT_FORMAT | Se impostato, i nomi dei campi e i valori verranno inviati nel formato HTML Form. |
| GET_METHOD | Se impostato, i nomi dei campi e i valori verranno inviati usando una richiesta HTTP GET. |
| SUBMIT_COORDINATES | Se impostato, le coordinate del clic del mouse che ha causato l'azione submit-form saranno trasmesse come parte dei dati del modulo. |
| XFDF | Se impostato, i nomi dei campi e i valori verranno inviati come XFDF. |
| INCLUDE_APPEND_SAVES | Se impostato, il file FDF inviato includerà il contenuto di tutti gli aggiornamenti incrementali. |
| INCLUDE_ANNOTATIONS | Se impostato, il file FDF inviato includerà tutte le annotazioni di markup nel documento PDF sottostante. |
| SUBMIT_PDF | Se impostato, il documento verrà inviato come PDF, usando il tipo MIME application/pdf. |
| CANONICAL_FORMAT | Se impostato, tutti i valori di campo inviati che rappresentano date saranno convertiti nel formato standard. |
| EXCL_NON_USER_ANNOTS | Se impostato, includerà solo le annotazioni di markup il cui campo T corrisponde al nome dell'utente corrente. |
| EXCL_F_KEY | Se impostato, il FDF inviato escluderà la voce F. |
| EMBED_FORM | Se impostato, la voce F del FDF inviato sarà una specifica di file contenente un <br/>            flusso di file incorporato che rappresenta il file PDF da cui il FDF viene inviato. |
