## Measure class

Classe che descrive il sistema di coordinate Measure.

Il tipo Measure espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Measure(annotation) | Inizializza una nuova istanza della classe Measure |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| scale_ratio | Una stringa di testo che esprime il rapporto di scala del disegno. |
| x_format | Un array di formati numerici per la misurazione del cambiamento lungo l'asse x e, se Y non è presente, anche lungo l'asse y. |
| y_format | Un array di formati numerici per la misurazione del cambiamento lungo l'asse y. |
| distance_format | Un array di formati numerici per la misurazione della distanza in qualsiasi direzione. |
| area_format | Un array di formati numerici per la misurazione dell'area. |
| angle_format | Un array di formati numerici per la misurazione degli angoli. |
| slope_format | Un array di formati numerici per la misurazione della pendenza di una linea. |
| origin | Punto che deve specificare l'origine del sistema di coordinate di misurazione nello spazio utente predefinito. |
| xy_factor | Un fattore che deve essere usato per convertire le unità più grandi lungo l'asse y in unità più grandi lungo l'asse x. |
