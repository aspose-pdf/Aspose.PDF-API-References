## LaunchAction class

Rappresenta un'azione di avvio che avvia un'applicazione o apre o stampa un documento.

Il tipo LaunchAction espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| LaunchAction(file) | Inizializza una nuova istanza della classe LaunchAction |
| LaunchAction(document, file) | Inizializza una nuova istanza della classe LaunchAction |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| next | Azioni successive nella sequenza. |
| file | Ottiene o imposta l'applicazione da avviare o il documento da aprire o stampare. |
| new_window | Ottiene o imposta un flag che specifica se aprire il documento di destinazione in una nuova finestra (influisce solo sui documenti PDF). |
