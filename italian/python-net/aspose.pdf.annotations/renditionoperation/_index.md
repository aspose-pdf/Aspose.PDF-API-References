## RenditionOperation enumeration

L'operazione da eseguire quando l'azione è attivata.

## Members
| Nome membro | Descrizione |
| :- | :- |
| PLAY_STOP | Se nessuna riproduzione è associata all'annotazione, riproduci la riproduzione specificata, associandola all'annotazione. Se una riproduzione è già associata all'annotazione, deve essere interrotta e la nuova riproduzione deve essere associata all'annotazione. |
| STOP | Interrompi qualsiasi riproduzione in corso associata all'annotazione. |
| PAUSE | Metti in pausa qualsiasi riproduzione in corso associata all'annotazione. |
| RESUME | Riprendi qualsiasi riproduzione in corso associata all'annotazione. |
| PLAY_RESUME | Riproduci la riproduzione specificata, associandola all'annotazione. Se una riproduzione è già associata all'annotazione, riprendi la riproduzione se è in pausa. |
| UNDEFINED | Operazione non definita. |
