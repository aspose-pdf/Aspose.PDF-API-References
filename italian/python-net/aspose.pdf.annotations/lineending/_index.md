## LineEnding enumeration

Enumera gli stili di terminazione della linea da utilizzare nel disegno della linea.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Nessuna fine riga. |
| SQUARE | Un quadrato riempito con il colore interno dell'annotazione, se presente. |
| CIRCLE | Un cerchio riempito con il colore interno dell'annotazione, se presente. |
| DIAMOND | Una forma a diamante riempita con il colore interno dell'annotazione, se presente. |
| OPEN_ARROW | Due linee corte che si incontrano formando un angolo acuto per creare una punta di freccia aperta. |
| CLOSED_ARROW | Due linee corte che si incontrano formando un angolo acuto come nello stile OpenArrow e collegate da una terza linea per creare una punta di freccia chiusa triangolare riempita con il colore interno dell'annotazione, se presente. |
| BUTT | Una linea corta all'estremità perpendicolare alla linea stessa. |
| R_OPEN_ARROW | Due linee corte nella direzione opposta rispetto a OpenArrow. |
| R_CLOSED_ARROW | Una punta di freccia chiusa triangolare nella direzione opposta rispetto a ClosedArrow. |
| SLASH | Una linea corta all'estremità circa 30 gradi in senso orario rispetto alla perpendicolare della linea stessa. |
