## DefaultAppearance class

Descrive l'aspetto predefinito del campo (carattere, dimensione del testo e colore).

Il tipo DefaultAppearance espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| DefaultAppearance() | Costruttore di DefaultAppearance. |
| DefaultAppearance(font_name, font_size, text_color) | Inizializza una nuova istanza della classe DefaultAppearance |

## Proprietà
| Nome | Descrizione |
| :- | :- |
| font_size | Ottiene la dimensione del carattere nell'aspetto predefinito. |
| text_color | Ottiene o imposta il colore del testo nell'aspetto predefinito. |
| font_name | Ottiene il nome del carattere nell'aspetto predefinito. |
| font_resource_name | Ottiene il nome del carattere nell'aspetto predefinito. |
| font | Ottiene il carattere specificato come predefinito per il testo. |
| text | Ottiene l'elenco degli operatori PDF che rappresentano l'aspetto. |
