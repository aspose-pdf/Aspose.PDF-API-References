## DocumentActionCollection class

La classe descrive le azioni eseguite su alcune azioni con il documento

Il tipo DocumentActionCollection espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| DocumentActionCollection(document) | Inizializza una nuova istanza della classe DocumentActionCollection |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| before_saving | Ottiene o imposta l'azione eseguita prima del salvataggio del documento. |
| before_closing | Ottiene o imposta l'azione che verrà eseguita prima della chiusura del documento. |
| after_saving | Ottiene o imposta l'azione che verrà eseguita dopo il salvataggio del documento. |
| before_printing | Azione che verrà eseguita prima della stampa del documento. |
| after_printing | Azione che verrà eseguita dopo la stampa del documento. |
