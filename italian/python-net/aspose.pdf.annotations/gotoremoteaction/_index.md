## GoToRemoteAction class

Rappresenta un'azione vai-a remota simile a un'azione vai-a ordinaria ma salta a una destinazione in un altro file PDF invece del file corrente.

Il tipo GoToRemoteAction espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| GoToRemoteAction(remote_pdf, remote_page_number) | Inizializza una nuova istanza della classe GoToRemoteAction |
| GoToRemoteAction(remote_pdf, destination) | Inizializza una nuova istanza della classe GoToRemoteAction |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| next | Azioni successive nella sequenza. |
| destination | Ottiene o imposta la destinazione a cui saltare. |
| file | Ottiene o imposta la specifica del file in cui si trova la destinazione. |
| new_window | Ottiene o imposta un flag che specifica se aprire il documento di destinazione in una nuova finestra. |
