## SoundSampleData class

Rappresenta voci aggiuntive specifiche per un oggetto audio (Sezione 9.2 PDF1-7).

Il tipo SoundSampleData espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| SoundSampleData(sampling_rate) | Inizializza una nuova istanza della classe SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels) | Inizializza una nuova istanza della classe SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel) | Inizializza una nuova istanza della classe SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel, sound_sample_data_encoding_format) | Inizializza una nuova istanza della classe SoundSampleData |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| sampling_rate | Ottiene o imposta la frequenza di campionamento. |
| number_of_sound_channels | Ottiene o imposta il numero di canali audio. |
| bits_per_channel | Ottiene o imposta il numero di bit per valore di campione per canale. |
| encoding_format | Ottiene o imposta il formato di codifica. |
| DEFAULT_SAMPLING_RATE | Valore predefinito per SamplingRate. |
| DEFAULT_OF_SOUND_CHANNELS | Valore predefinito per il parametro Channels. |
| DEFAULT_OF_BITS_PER_CHANNEL | Valore predefinito per il parametro BitsPerchannel. |
| DEFAULT_ENCODING_FORMAT | Valore predefinito per il formato di codifica. |
