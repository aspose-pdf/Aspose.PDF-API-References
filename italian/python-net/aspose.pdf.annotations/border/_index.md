## Border class

Classe che rappresenta le caratteristiche del bordo dell'annotazione.

Il tipo Border espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Border(parent) | Inizializza una nuova istanza della classe Border |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| h_corner_radius | Ottiene o imposta il raggio dell'angolo orizzontale. |
| v_corner_radius | Ottiene o imposta il raggio dell'angolo verticale. |
| width | Ottiene o imposta la larghezza del bordo. |
| effect_intensity | Ottiene o imposta l'intensità dell'effetto. L'intervallo valido del valore è [0..2]. |
| style | Ottiene o imposta lo stile del bordo. |
| effect | Ottiene o imposta l'effetto del bordo. |
| dash | Ottiene o imposta il modello di tratteggio. |
