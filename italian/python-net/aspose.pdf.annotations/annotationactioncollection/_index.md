## AnnotationActionCollection class

Rappresenta la raccolta di azioni di annotazione.

Il tipo AnnotationActionCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| on_enter | Ottiene o imposta un'azione da eseguire quando il cursore entra nell'area attiva dell'annotazione. |
| on_exit | Ottiene o imposta un'azione da eseguire quando il cursore esce dall'area attiva dell'annotazione. |
| on_press_mouse_btn | Ottiene o imposta un'azione da eseguire quando il pulsante del mouse viene premuto all'interno dell'area attiva dell'annotazione. |
| on_release_mouse_btn | Ottiene o imposta un'azione da eseguire quando il pulsante del mouse viene rilasciato all'interno dell'area attiva dell'annotazione. |
| on_receive_focus | Ottiene o imposta un'azione da eseguire quando l'annotazione riceve il focus di input. |
| on_open_page | Ottiene o imposta un'azione da eseguire quando la pagina contenente l'annotazione viene aperta. |
| on_close_page | Ottiene o imposta un'azione da eseguire quando la pagina contenente l'annotazione viene chiusa. |
| on_show_page | Ottiene o imposta un'azione da eseguire quando la pagina contenente l'annotazione diventa visibile nell'interfaccia utente dell'applicazione visualizzatore. |
| on_hide_page | Ottiene o imposta un'azione da eseguire quando la pagina contenente l'annotazione non è più visibile nell'interfaccia utente dell'applicazione visualizzatore. |
| on_lost_focus | Ottiene o imposta un'azione da eseguire quando l'annotazione perde il focus di input. |
| on_modify_character | Ottiene o imposta un'azione da eseguire quando l'utente modifica il carattere del campo. |
| on_validate | Ottiene o imposta un'azione da eseguire quando l'utente modifica il contenuto del campo. |
| on_format | Ottiene o imposta un'azione da eseguire per formattare il valore del campo. |
| on_calculate | Ottiene o imposta un'azione per calcolare il valore del campo. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| remove_actions() | Rimuove tutte le azioni dell'annotazione. |
