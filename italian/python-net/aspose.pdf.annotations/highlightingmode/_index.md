## HighlightingMode enumeration

Enumera la modalità di evidenziazione dell'annotazione, l'effetto visivo da utilizzare quando il pulsante del mouse è premuto o tenuto premuto all'interno della sua area attiva.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Nessuna evidenziazione. |
| INVERT | Inverte il contenuto del rettangolo dell'annotazione. |
| OUTLINE | Inverte il bordo dell'annotazione. |
| PUSH | Visualizza l'aspetto down dell'annotazione, se presente. Se non è definito alcun aspetto down, sposta il contenuto del rettangolo dell'annotazione in modo da apparire come se fosse spinto sotto la superficie della pagina. |
| TOGGLE | Stesso di Push (che è preferito). |
