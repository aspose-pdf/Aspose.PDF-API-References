## TextStyle class

Classe che rappresenta lo stile del testo nell'annotazione.

Il tipo TextStyle espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| font_name | Nome del carattere. |
| font_size | Dimensione del carattere. |
| alignment | Ottiene o imposta l'allineamento orizzontale del testo. |
| horizontal_alignment | Allineamento del testo. I valori validi sono: Sinistra, Centro, Destra. |
| color | Colore del testo. |
