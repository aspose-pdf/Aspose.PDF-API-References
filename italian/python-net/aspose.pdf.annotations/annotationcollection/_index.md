## AnnotationCollection class

Classe che rappresenta la raccolta di annotazioni.

Il tipo AnnotationCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_synchronized | Ottiene un valore che indica se l'accesso a Aspose.Pdf.Annotations.AnnotationCollection è sincronizzato (thread‑safe). |
| sync_root | Ottiene un oggetto che può essere utilizzato per sincronizzare l'accesso a Aspose.Pdf.Annotations.AnnotationCollection. |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | L'indice dell'elemento da ottenere. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| delete(index) | Elimina l'annotazione dalla collezione per indice. |
| delete() | Elimina l'annotazione dalla collezione per indice. |
| delete(annotation) | Elimina l'annotazione dalla collezione per indice. |
| add(annotation, consider_rotation) | Aggiunge l'annotazione alla collezione. Se la pagina è ruotata, il rettangolo dell'annotazione verrà ricalcolato di conseguenza. |
| accept(visitor) | Accetta un visitatore per elaborare l'annotazione. |
| find_by_name(name) | Restituisce l'annotazione per nome. |
