## SoundData class

Rappresenta i dati audio che definiscono il suono da riprodurre quando l'annotazione è attivata.

Il tipo SoundData espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| rate | Ottiene o imposta la frequenza di campionamento, in campioni al secondo. |
| canali | Ottiene o imposta il numero di canali audio. |
| bit | Ottiene o imposta il numero di bit per valore di campione per canale. |
| contents | Ottiene il flusso del suono da riprodurre quando l'annotazione è attivata. |
| encoding | Ottiene o imposta il formato di codifica per i dati del campione. |
