## AnnotationState enumeration

L'enumerazione degli stati a cui può essere impostata l'annotazione originale.

## Members
| Nome membro | Descrizione |
| :- | :- |
| UNDEFINED | Stato non definito. |
| MARKED | L'annotazione è stata contrassegnata dall'utente. |
| UNMARKED | L'annotazione non è stata contrassegnata dall'utente. |
| ACCEPTED | L'utente accetta la modifica. |
| REJECTED | L'utente rifiuta la modifica. |
| CANCELLED | La modifica è stata annullata. |
| COMPLETATO | La modifica è stata completata. |
| NONE | L'utente non ha indicato nulla sulla modifica. |
