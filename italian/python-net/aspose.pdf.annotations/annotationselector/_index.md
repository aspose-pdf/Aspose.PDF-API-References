## AnnotationSelector class

Questa classe è usata per selezionare le annotazioni utilizzando l'idea del modello Visitor.

Il tipo AnnotationSelector espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| AnnotationSelector() | Inizializza una nuova istanza della classe AnnotationSelector. |
| AnnotationSelector(annotation) | Inizializza una nuova istanza della classe AnnotationSelector |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| selected | L'elenco degli oggetti selezionati. |
