## XfaParserOptions class

classe per gestire l'incapsulamento dei dati correlati

Il tipo XfaParserOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| XfaParserOptions(page_size) | Inizializza una nuova istanza della classe XfaParserOptions |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| page_size | Ottiene o imposta la dimensione della pagina. |
| firmato | Se questa proprietà è vera, il documento verrà convertito utilizzando lo stream del modulo xfa (se esiste).<br/>            Se è falsa, lo stream del modulo xfa verrà ignorato.<br/>            Questa proprietà è stata introdotta perché non è chiaro come calcolare il checksum utilizzato per verificare la firma. |
| emulate_requierd_groups | Se questa proprietà è vera, verranno disegnati rettangoli rossi aggiuntivi per i "gruppi esclusi" Xfa richiesti<br/>            Questa proprietà è stata introdotta perché l'assenza di analoghi dei gruppi esclusi durante la conversione della rappresentazione Xfa dei moduli <br/>            allo standard.<br/>            È falsa per impostazione predefinita. |
| base_path | Ottiene o imposta il percorso base. |
