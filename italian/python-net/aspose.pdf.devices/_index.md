Lo spazio dei nomi aspose.pdf.devices fornisce classi utilizzate per rappresentare il documento come immagine(i) o testo semplice. In questo modo il documento può essere inviato a dispositivi testuali o grafici, il che significa che vogliamo ottenere una rappresentazione testuale o grafica.

## Classi
| Classe | Descrizione |
| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF in bmp. |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | Classe astratta per tutti i tipi di dispositivi. Il dispositivo è usato per rappresentare il documento PDF in qualche formato.<br/>            Ad esempio, la pagina del documento può essere rappresentata come immagine o testo. |
| [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF nel formato Dicom. |
| [DocumentDevice](/pdf/python-net/aspose.pdf.devices/documentdevice/) | Classe astratta per tutti i dispositivi utilizzati per elaborare l'intero documento PDF. |
| [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF in emf. |
| [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF in gif. |
| [ImageDevice](/pdf/python-net/aspose.pdf.devices/imagedevice/) | Una classe astratta per dispositivi immagine. |
| [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF in jpeg. |
| [Margins](/pdf/python-net/aspose.pdf.devices/margins/) | Questa classe rappresenta i margini di un'immagine. |
| [PageDevice](/pdf/python-net/aspose.pdf.devices/pagedevice/) | Classe astratta per tutti i dispositivi utilizzata per elaborare una determinata pagina del documento PDF. |
| [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) | Rappresenta un dispositivo immagine che aiuta a salvare le pagine del documento PDF in PNG. |
| [Resolution](/pdf/python-net/aspose.pdf.devices/resolution/) | Rappresenta una classe per contenere la risoluzione dell'immagine. |
| [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) | Rappresenta una classe per convertire le pagine del documento PDF in testo. |
| [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) | Rappresenta un dispositivo immagine che salva le pagine del documento PDF in un'immagine miniatura. |
| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | Questa classe aiuta a salvare le pagine del documento PDF, una per una, in un'unica immagine TIFF. |
| [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) | Questa classe rappresenta le impostazioni per l'importazione di PDF in TIFF. |
