## ThumbnailDevice class

Rappresenta un dispositivo immagine che salva le pagine del documento PDF in un'immagine miniatura.

Il tipo ThumbnailDevice espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| ThumbnailDevice() | Inizializza una nuova istanza della classe [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) <br/>            con dimensione predefinita dell'immagine thumbnail (200x200 pixel). |
| ThumbnailDevice(width, height) | Inizializza una nuova istanza della classe ThumbnailDevice |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| coordinate_type | Ottiene o imposta il tipo di coordinate della pagina (scatole Media/Crop). Il valore CropBox è usato per impostazione predefinita. |
| rendering_options | Ottiene o imposta le opzioni di rendering. |
| form_presentation_mode | Ottiene o imposta la modalità di presentazione del modulo. |
| resolution | Ottiene la risoluzione dell'immagine. |
| width | Ottiene la larghezza di output dell'immagine. |
| height | Ottiene l'altezza di output dell'immagine. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| process(page, output) | Converte la pagina in immagine thumbnail png e la salva nello stream di output. |
| process(page, output_file_name) | Converte la pagina in immagine thumbnail png e la salva nello stream di output. |
