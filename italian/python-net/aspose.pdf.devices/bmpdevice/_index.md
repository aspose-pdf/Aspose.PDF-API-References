## BmpDevice class

Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF in bmp.

Il tipo BmpDevice espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| BmpDevice() | Inizializza una nuova istanza della classe [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) con risoluzione predefinita. |
| BmpDevice(resolution) | Inizializza una nuova istanza della classe BmpDevice |
| BmpDevice(width, height, resolution) | Inizializza una nuova istanza della classe BmpDevice |
| BmpDevice(page_size, resolution) | Inizializza una nuova istanza della classe BmpDevice |
| BmpDevice(width, height) | Inizializza una nuova istanza della classe BmpDevice |
| BmpDevice(page_size) | Inizializza una nuova istanza della classe BmpDevice |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| coordinate_type | Ottiene o imposta il tipo di coordinate della pagina (scatole Media/Crop). Il valore CropBox è usato per impostazione predefinita. |
| rendering_options | Ottiene o imposta le opzioni di rendering. |
| form_presentation_mode | Ottiene o imposta la modalità di presentazione del modulo. |
| resolution | Ottiene la risoluzione dell'immagine. |
| width | Ottiene la larghezza di output dell'immagine. |
| height | Ottiene l'altezza di output dell'immagine. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| process(page, output) | Converte la pagina in bmp e la salva nello stream di output. |
| process(page, output_file_name) | Converte la pagina in bmp e la salva nello stream di output. |
