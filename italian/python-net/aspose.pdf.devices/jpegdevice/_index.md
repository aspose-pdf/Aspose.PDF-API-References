## JpegDevice class

Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF in jpeg.

Il tipo JpegDevice espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| JpegDevice() | Inizializza una nuova istanza della classe [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) con risoluzione predefinita e qualità massima. |
| JpegDevice(resolution) | Inizializza una nuova istanza della classe JpegDevice |
| JpegDevice(quality) | Inizializza una nuova istanza della classe JpegDevice |
| JpegDevice(resolution, quality) | Inizializza una nuova istanza della classe JpegDevice |
| JpegDevice(width, height) | Inizializza una nuova istanza della classe JpegDevice |
| JpegDevice(page_size) | Inizializza una nuova istanza della classe JpegDevice |
| JpegDevice(width, height, resolution) | Inizializza una nuova istanza della classe JpegDevice |
| JpegDevice(page_size, resolution) | Inizializza una nuova istanza della classe JpegDevice |
| JpegDevice(width, height, resolution, quality) | Inizializza una nuova istanza della classe JpegDevice |
| JpegDevice(page_size, resolution, quality) | Inizializza una nuova istanza della classe JpegDevice |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| coordinate_type | Ottiene o imposta il tipo di coordinate della pagina (scatole Media/Crop). Il valore CropBox è usato per impostazione predefinita. |
| rendering_options | Ottiene o imposta le opzioni di rendering. |
| form_presentation_mode | Ottiene o imposta la modalità di presentazione del modulo. |
| resolution | Ottiene la risoluzione dell'immagine. |
| width | Ottiene la larghezza di output dell'immagine. |
| height | Ottiene l'altezza di output dell'immagine. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| process(page, output) | Converte la pagina in jpeg e la salva nel flusso di output. |
| process(page, output_file_name) | Converte la pagina in jpeg e la salva nel flusso di output. |
