## DicomDevice class

Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF nel formato Dicom.

Il tipo DicomDevice espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| DicomDevice() | Inizializza una nuova istanza della classe [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) con risoluzione predefinita. |
| DicomDevice(resolution) | Inizializza una nuova istanza della classe DicomDevice |
| DicomDevice(page_size) | Inizializza una nuova istanza della classe DicomDevice |
| DicomDevice(width, height) | Inizializza una nuova istanza della classe DicomDevice |
| DicomDevice(page_size, resolution) | Inizializza una nuova istanza della classe DicomDevice |
| DicomDevice(width, height, resolution) | Inizializza una nuova istanza della classe DicomDevice |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| coordinate_type | Ottiene o imposta il tipo di coordinate della pagina (scatole Media/Crop). Il valore CropBox è usato per impostazione predefinita. |
| rendering_options | Ottiene o imposta le opzioni di rendering. |
| form_presentation_mode | Ottiene o imposta la modalità di presentazione del modulo. |
| resolution | Ottiene la risoluzione dell'immagine. |
| width | Ottiene la larghezza di output dell'immagine. |
| height | Ottiene l'altezza di output dell'immagine. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| process(page, output) | Converte la pagina in Dicom e la salva nello stream di output. |
| process(page, output_file_name) | Converte la pagina in Dicom e la salva nello stream di output. |
