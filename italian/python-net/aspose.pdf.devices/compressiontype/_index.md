## CompressionType enumeration

Utilizzato per specificare il valore del parametro passato a un dispositivo immagine TIFF.

## Members
| Nome membro | Descrizione |
| :- | :- |
| LZW | Specifica lo schema di compressione LZW. Può essere passato al codificatore Tiff come parametro appartenente alla categoria Compression. |
| CCITT4 | Specifica lo schema di compressione CCITT4. Può essere passato al codificatore CCITT4 come parametro appartenente alla categoria Compression. |
| CCITT3 | Specifica lo schema di compressione CCITT3. Può essere passato al codificatore CCITT3 come parametro appartenente alla categoria Compression. |
| RLE | Specifica lo schema di compressione RLE. Può essere passato al codificatore RLE come parametro appartenente alla categoria Compression. |
| NONE | Specifica nessuna compressione. Può essere passato al codificatore Tiff come parametro appartenente alla categoria compression. |
