## EmfDevice class

Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF in emf.

Il tipo EmfDevice espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| EmfDevice() | Inizializza una nuova istanza della classe [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) con la risoluzione predefinita dell'immagine raster scritta in emf. |
| EmfDevice(resolution) | Inizializza una nuova istanza della classe EmfDevice |
| EmfDevice(width, height) | Inizializza una nuova istanza della classe EmfDevice |
| EmfDevice(page_size) | Inizializza una nuova istanza della classe EmfDevice |
| EmfDevice(width, height, resolution) | Inizializza una nuova istanza della classe EmfDevice |
| EmfDevice(page_size, resolution) | Inizializza una nuova istanza della classe EmfDevice |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| coordinate_type | Ottiene o imposta il tipo di coordinate della pagina (scatole Media/Crop). Il valore CropBox è usato per impostazione predefinita. |
| rendering_options | Ottiene o imposta le opzioni di rendering. |
| form_presentation_mode | Ottiene o imposta la modalità di presentazione del modulo. |
| resolution | Ottiene la risoluzione dell'immagine. |
| width | Ottiene la larghezza di output dell'immagine. |
| height | Ottiene l'altezza di output dell'immagine. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| process(page, output) | Converte la pagina in emf e la salva nello stream di output. |
| process(page, output_file_name) | Converte la pagina in emf e la salva nello stream di output. |
