## GifDevice class

Rappresenta un dispositivo immagine che consente di salvare le pagine del documento PDF in gif.

Il tipo GifDevice espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| GifDevice() | Inizializza una nuova istanza della classe [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) con risoluzione predefinita. |
| GifDevice(resolution) | Inizializza una nuova istanza della classe GifDevice |
| GifDevice(width, height, resolution) | Inizializza una nuova istanza della classe GifDevice |
| GifDevice(page_size, resolution) | Inizializza una nuova istanza della classe GifDevice |
| GifDevice(width, height) | Inizializza una nuova istanza della classe GifDevice |
| GifDevice(page_size) | Inizializza una nuova istanza della classe GifDevice |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| coordinate_type | Ottiene o imposta il tipo di coordinate della pagina (scatole Media/Crop). Il valore CropBox è usato per impostazione predefinita. |
| rendering_options | Ottiene o imposta le opzioni di rendering. |
| form_presentation_mode | Ottiene o imposta la modalità di presentazione del modulo. |
| resolution | Ottiene la risoluzione dell'immagine. |
| width | Ottiene la larghezza di output dell'immagine. |
| height | Ottiene l'altezza di output dell'immagine. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| process(page, output) | Converte la pagina in gif e la salva nello stream di output. |
| process(page, output_file_name) | Converte la pagina in gif e la salva nello stream di output. |
