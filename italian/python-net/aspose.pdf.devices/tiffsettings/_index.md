## Proprietà
| Nome | Descrizione |
| :- | :- |
| margini | Ottiene i margini. |
| skip_blank_pages | Ottiene o imposta un valore che indica se saltare le pagine vuote. |
| compressione | Ottiene o imposta il tipo di compressione. |
| profondità | Ottiene o imposta la profondità colore. |
| forma | Ottiene o imposta il tipo di forma. |
| luminosità | Ottiene o imposta un valore limite della trasformazione dei colori in bianco e nero.<br/>            Questo parametro può essere applicato con EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle o ColorDepth.Format1bpp == 1 |
| coordinate_type | Ottiene o imposta il tipo di coordinate della pagina (Media/Crop boxes). Il valore CropBox è usato per impostazione predefinita. |
