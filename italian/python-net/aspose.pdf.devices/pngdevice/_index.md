## PngDevice class

Rappresenta un dispositivo immagine che aiuta a salvare le pagine del documento PDF in PNG.

Il tipo PngDevice espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PngDevice() | Inizializza una nuova istanza della classe [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) con risoluzione predefinita. |
| PngDevice(resolution) | Inizializza una nuova istanza della classe PngDevice |
| PngDevice(width, height, resolution) | Inizializza una nuova istanza della classe PngDevice |
| PngDevice(page_size, resolution) | Inizializza una nuova istanza della classe PngDevice |
| PngDevice(width, height) | Inizializza una nuova istanza della classe PngDevice |
| PngDevice(page_size) | Inizializza una nuova istanza della classe PngDevice |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| coordinate_type | Ottiene o imposta il tipo di coordinate della pagina (scatole Media/Crop). Il valore CropBox è usato per impostazione predefinita. |
| rendering_options | Ottiene o imposta le opzioni di rendering. |
| form_presentation_mode | Ottiene o imposta la modalità di presentazione del modulo. |
| resolution | Ottiene la risoluzione dell'immagine. |
| width | Ottiene la larghezza di output dell'immagine. |
| height | Ottiene l'altezza di output dell'immagine. |
| transparent_background | Ottiene o imposta se l'immagine ha uno sfondo trasparente. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| process(page, output) | Converte la pagina in png e la salva nello stream di output. |
| process(page, output_file_name) | Converte la pagina in png e la salva nello stream di output. |
