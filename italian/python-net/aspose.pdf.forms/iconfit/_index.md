## IconFit class

Descrive come l'icona dell'annotazione widget deve essere visualizzata all'interno del suo rettangolo di annotazione.

Il tipo IconFit espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| scaling_reason | Ottiene o imposta il motivo di scaling. |
| scaling_mode | Il tipo di scaling da utilizzare.        /// |
| leftover_left | Ottiene o imposta lo spazio da assegnare a sinistra dell'icona. |
| leftover_bottom | Ottiene o imposta lo spazio da assegnare in basso dell'icona. |
| spread_on_border | Se true, indica che l'aspetto del pulsante deve essere scalato per adattarsi completamente entro i limiti dell'annotazione senza considerare lo spessore della linea del bordo. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| name_to_scaling_reason(reason) | Converte il nome del motivo di scaling in un oggetto ScalingReason. |
| scaling_reason_to_name(reason) | Converte l'oggetto di motivo di scaling in nome. |
| name_to_scaling_mode(mode) | Converte il nome della modalità di scaling in oggetto ScalingMode. |
| scaling_mode_to_name(mode) | Converte l'oggetto della modalità di scaling in nome. |
