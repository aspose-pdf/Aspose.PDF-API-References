## Symbology enumeration

Una simbologia (Barcode) definisce i dettagli tecnici di un particolare tipo di codice a barre:<br/>            la larghezza delle barre, il set di caratteri, il metodo di codifica, le specifiche del checksum, ecc.

## Members
| Nome membro | Descrizione |
| :- | :- |
| PDF417 | Una simbologia 2D a più righe e lunghezza variabile con alta capacità di dati e capacità di correzione degli errori. |
| QR_CODE | Il codice QR (abbreviazione di Quick Response) è un codice a barre matriciale specifico (codice 2D), <br/>            leggibile da lettori di codici QR dedicati e telefoni con fotocamera. |
| DATA_MATRIX | Una simbologia matriciale 2D composta da moduli quadrati neri e bianchi disposti in un modello quadrato o <br/>            rettangolare. |
