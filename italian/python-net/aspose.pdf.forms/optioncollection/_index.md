## OptionCollection class

Classe che rappresenta la raccolta di opzioni del campo di scelta.

Il tipo OptionCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_synchronized | Restituisce true se l'oggetto è sincronizzato. |
| sync_root | Oggetto di sincronizzazione della collezione. |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Ottiene l'opzione per indice. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| get(index) | Ottiene l'opzione per indice. |
| get(name) | Ottiene l'opzione dalla collezione per nome dell'opzione. |
