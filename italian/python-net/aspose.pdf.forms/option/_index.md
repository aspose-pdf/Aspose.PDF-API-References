## Option class

Classe che rappresenta l'opzione del campo di scelta.

Il tipo Option espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| value | Ottiene o imposta il valore di esportazione dell'opzione. |
| name | Ottiene o imposta il nome dell'opzione. |
| selected | Ottiene o imposta lo stato di selezione dell'opzione. Restituisce true se l'opzione è selezionata. |
| index | Ottiene l'indice dell'opzione. |
