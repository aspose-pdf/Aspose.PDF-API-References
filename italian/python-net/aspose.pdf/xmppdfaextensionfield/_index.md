## XmpPdfAExtensionField class

Questo schema descrive un campo in un tipo strutturato. È molto simile allo schema PDF/A Property Value Type <br/>            , ma definisce un campo in una struttura invece di una proprietà.<br/>            URI dello spazio dei nomi dello schema: http://www.aiim.org/pdfa/ns/field#<br/>            Prefisso richiesto per lo spazio dei nomi dello schema: pdfaField.
