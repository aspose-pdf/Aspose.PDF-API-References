## RenderingOptions class

Rappresenta le opzioni di rendering.

Il tipo RenderingOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| RenderingOptions() | Inizializza una nuova istanza della classe RenderingOptions |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| barcode_optimization | Ottiene o imposta la modalità di ottimizzazione del codice a barre. |
| optimize_dimensions | Ottiene o imposta la modalità di ottimizzazione delle dimensioni. |
| system_fonts_native_rendering | Ottiene o imposta una modalità in cui i font di sistema vengono renderizzati nativamente. |
| use_new_imaging_engine | Ottiene o imposta un flag che determina se il nuovo motore di imaging è utilizzato o meno. |
| width_extra_units | Ottiene o imposta un valore usato per aumentare o diminuire la larghezza del rettangolo per l'operatore AppendRectangle. |
| height_extra_units | Ottiene o imposta un valore usato per aumentare o diminuire la larghezza del rettangolo per l'operatore AppendRectangle. |
| convert_fonts_to_unicode_ttf | Indica che tutti i font saranno convertiti in versioni TTF Unicode. Ciò è utile per motivi di compatibilità <br/>             e per ottimizzare l'uso dei font, poiché ogni nuovo font TTF non conterrà tutti i simboli <br/>             del font originale, ma solo i simboli utilizzati nel testo. |
| use_font_hinting | L'uso di questo flag attiva il meccanismo di hinting dei font. Il hinting dei font è l'uso di istruzioni matematiche per regolare la visualizzazione <br/>            di un font vettoriale. In alcuni casi, attivare questo flag può risolvere problemi di leggibilità del testo. <br/>            Al momento, l'uso di questo flag può avere effetto solo sui font TTF, se questi font sono usati nel documento di origine. |
| scale_images_to_fit_page_width | Ottiene o imposta un valore usato per scalare tutte le immagini nella pagina in modo da adattarle alla larghezza della pagina. |
| interpolation_high_quality | Ottiene o imposta la modalità ad alta qualità per l'interpolazione. |
| max_fonts_cache_size | Numero massimo di caratteri nella cache dei caratteri. Il valore predefinito è 10. |
| max_symbols_cache_size | Numero massimo di simboli nella cache dei simboli. Il valore predefinito è 100. |
| default_font_name | Ottiene/Imposta il nome predefinito del carattere usato per sostituire i caratteri mancanti. |
| ignore_resource_font_errors | Ottiene o imposta l'indicazione che gli errori relativi all'assenza del carattere saranno ignorati.<br/>            true - indica che gli errori di assenza del carattere saranno ignorati. I segmenti di testo che fanno riferimento a risorse errate saranno saltati durante l'elaborazione.<br/>            false per impostazione predefinita |
