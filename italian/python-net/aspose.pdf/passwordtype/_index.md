## PasswordType enumeration

Questa enumerazione rappresenta i tipi di password noti utilizzati per i documenti PDF protetti da password.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Il documento PDF non è protetto da password. |
| USER | Il documento PDF è stato aperto usando la password di apertura del documento (accesso limitato). |
| OWNER | Il documento PDF è stato aperto usando la password di modifica dei permessi (accesso completo). |
| INACCESSIBILE | Il documento PDF è protetto da password ma sia la password utente sia quella del proprietario non sono vuote e <br/>            nessuna delle password è stata definita o la password fornita era errata. Quindi è impossibile dedurre il tipo di password. |
