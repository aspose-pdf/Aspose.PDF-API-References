## ExtractImageMode enumeration

Definisce diversi modalità che possono essere usate durante l'estrazione di immagini dai documenti.

## Members
| Nome membro | Descrizione |
| :- | :- |
| DEFINED_IN_RESOURCES | Definisce la modalità di estrazione delle immagini in cui tutte le immagini definite nelle risorse per una pagina specifica vengono estratte. |
| ACTUALLY_USED | Definisce la modalità di estrazione delle immagini in cui vengono estratte solo le immagini effettivamente visualizzate su una pagina. |
