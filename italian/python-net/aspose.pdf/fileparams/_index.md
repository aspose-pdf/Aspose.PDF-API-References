## FileParams class

Definisce un dizionario dei parametri del file incorporato che deve contenere informazioni aggiuntive specifiche del file.

Il tipo FileParams espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| FileParams(spec) | Inizializza una nuova istanza della classe FileParams |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| size | La dimensione del file incorporato non compresso, in byte. |
| creation_date | La data e l'ora in cui il file incorporato è stato creato. |
| mod_date | La data e l'ora in cui il file incorporato è stato modificato l'ultima volta. |
| check_sum | Una stringa di 16 byte che è il checksum dei byte del file incorporato non compresso. <br/>            Il checksum è calcolato applicando l'algoritmo standard di digest MD5 <br/>            ai byte del flusso del file incorporato. |
