## PdfASymbolicFontEncodingStrategy class

Questa classe descrive le regole che possono essere utilizzate per ottimizzare il processo di copia dei dati di codifica per i casi<br/>            quando un font simbolico TrueType ha più di una codifica.<br/>            Alcuni documenti PDF dopo la conversione in formato PDF/A potrebbero presentare l'errore <br/>            "More than one encoding in symbolic TrueType font's cmap". <br/>            Qual è la causa di questo errore? Tutti i font simbolici TrueType hanno una tabella speciale "cmap"<br/>            nei loro dati interni. Questa tabella mappa i codici dei caratteri agli indici dei glifi. <br/>            E questa tabella può contenere diverse sotto‑tabelle di codifica che<br/>            descrivono le codifiche utilizzate. Vedi informazioni avanzate sulle tabelle cmap su<br/>            https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6cmap.html.<br/>            Di solito la tabella cmap contiene diverse sotto‑tabelle di codifica, ma lo standard PDF/A richiede<br/>            che solo una sotto‑tabella di codifica (3,0) debba essere lasciata per questo font nel documento PDF/A. <br/>            E la domanda chiave qui – quali dati devono essere presi da altre sotto‑tabelle per copiarli in<br/>            la tabella di codifica di destinazione (3,0)? La maggior parte dei font ha tabelle cmap 'ben formate' dove<br/>            ogni sotto‑tabella di codifica è completamente coerente con un'altra sotto‑tabella. Ma alcuni font<br/>            hanno tabelle cmap con collisioni – dove, per esempio, una sotto‑tabella ha l'indice del glifo <br/>            100 per Unicode 100, ma un'altra sotto‑tabella ha l'indice del glifo 200 per lo stesso Unicode 100.<br/>            Per risolvere questi problemi è necessaria una strategia speciale. <br/>            Per impostazione predefinita viene utilizzata la seguente strategia: <br/>            si cerca la sotto‑tabella mac(1,0). Se questa tabella viene trovata, solo questi dati vengono usati per riempire la<br/>            tabella di destinazione (3,0). Se la sotto‑tabella mac non viene trovata, allora tutte le sotto‑tabelle eccetto (3,0) vengono iterate <br/>            e usate per copiare i dati nella sotto‑tabella di destinazione (3,0). Inoltre la mappatura per ogni unicode(unicode, indice del glifo)<br/>            viene copiata nella tabella di destinazione solo se la tabella di destinazione non contiene ancora questo unicode al momento. <br/>            Quindi, per esempio, se la prima sotto‑tabella ha l'indice del glifo 100 per Unicode 100, e la successiva sotto‑tabella ha il glifo<br/>            indice 200 per lo stesso Unicode 100, solo i dati della prima sotto‑tabella (unicode=100, indice del glifo = 100) verranno copiati. <br/>            Quindi ogni sotto‑tabella precedente ha precedenza su quella successiva. <br/>            Le proprietà di questa classe [PdfASymbolicFontEncodingStrategy](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) aiutano a regolare il comportamento predefinito. <br/>            Se la proprietà [preferred_cmap_encoding_table](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) di tipo [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            è impostata, allora la sotto‑tabella pertinente verrà usata con precedenza rispetto alla sotto‑tabella mac(1,0). Il valore 'MacTable' della<br/>            enumerazione [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/) non ha senso in questo caso, poiché <br/>            fa riferimento alla stessa sotto‑tabella mac (1,0) che verrà usata per impostazione predefinita. <br/>            La proprietà [None](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) scarta tutte le priorità per qualsiasi sotto‑tabella.<br/>            Se questa proprietà è impostata, allora solo le sotto‑tabelle dalla coda dichiarata verranno usate nell'ordine specificato.<br/>            Se le sotto‑tabelle specificate non vengono trovate, allora verrà usata l'iterazione predefinita di tutte le sotto‑tabelle e la strategia di copia descritta sopra<br/>            verrà utilizzata.<br/>            L'oggetto [QueueItem](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy/queueitem/) specifica la sotto‑tabella di codifica utilizzata. Questa sotto‑tabella può essere impostata<br/>            tramite combinazione dei membri(PlatformID, PlatformSpecificId) o tramite [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            enumerazione.
