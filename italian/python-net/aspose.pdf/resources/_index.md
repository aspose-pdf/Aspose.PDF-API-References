## Resources class

Classe che rappresenta le risorse della pagina.

Il tipo Resources espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| forms | Ottiene la collezione di [forms](/pdf/python-net/aspose.pdf/resources/) forms |
| images | Ottiene la collezione di [images](/pdf/python-net/aspose.pdf/resources/) images |
| fonts | Ottiene la collezione di [fonts](/pdf/python-net/aspose.pdf/resources/) resources |
## Metodi
| Nome | Descrizione |
| :- | :- |
| get_fonts(create_if_absent) | Restituisce la collezione di fonts. Se le risorse non contengono una voce di fonts, verrà creata in base al flag CreateIfAbsent. |
