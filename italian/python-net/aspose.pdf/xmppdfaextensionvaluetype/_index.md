## XmpPdfAExtensionValueType class

Lo schema PDF/A ValueType è richiesto per tutti i tipi di valore di proprietà che non sono definiti nella specifica XMP 2004, cioè per i tipi di valore al di fuori dell'elenco seguente:<br/>            - Tipi di array (sono tipi contenitori che possono contenere uno o più campi): Alt, Bag, Seq<br/>            - Tipi di valore di base: Boolean, (aperta e chiusa) Choice, Date, Dimensions, Integer, Lang Alt, Locale, MIMEType, ProperName, Real, Text, Thumbnail, URI, URL, XPath<br/>            - Tipi di valore per la gestione dei media: AgentName, RenditionClass, ResourceEvent, ResourceRef, Version<br/>            - Tipo di valore base per Job/Workflow: Job<br/>            - Tipi di valore dello schema EXIF: Flash, CFAPattern, DeviceSettings, GPSCoordinate, OECF/SFR, Rational<br/>            URI dello spazio dei nomi dello schema: http://www.aiim.org/pdfa/ns/type#<br/>            Prefisso richiesto per lo spazio dei nomi dello schema: pdfaType
