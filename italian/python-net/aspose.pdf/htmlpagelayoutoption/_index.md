## HtmlPageLayoutOption enumeration

Specifica i flag che, insieme ad altre opzioni, determinano le dimensioni e i layout delle pagine.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Valore predefinito che indica che l'HtmlPageLayoutOption non influenzerà le dimensioni e i layout delle pagine. |
| FIT_TO_WIDEST_CONTENT_WIDTH | Indica che la larghezza della pagina è determinata dalla dimensione del contenuto stesso, non dalla larghezza di pagina specificata. |
| SCALE_TO_PAGE_WIDTH | Indica che il contenuto del documento sarà scalato per adattarsi alla pagina. |
