## Metadata class

Fornisce l'accesso al flusso di metadati XMP.

Il tipo Metadata espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_fixed_size | Verifica se la collezione ha dimensione fissa. |
| chiavi | Ottiene la collezione delle chiavi dei metadati. |
| valori | Ottiene i valori nei metadati. |
| is_synchronized | Verifica se la collezione è sincronizzata. |
| sync_root | Ottiene l'oggetto di sincronizzazione della collezione. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| register_namespace_uri(prefix, namespace_uri) | Registra l'URI dello spazio dei nomi. |
| register_namespace_uri(prefix, namespace_uri, schema_description) | Registra l'URI dello spazio dei nomi. |
| add(key, value) | Aggiunge un valore ai metadati. |
| add(key, value) | Aggiunge un valore ai metadati. |
| add(prefix, value) | Aggiunge l'estensione pdf ai metadati. |
| get_namespace_uri_by_prefix(prefix) | Restituisce l'URI dello spazio dei nomi per prefisso. |
| get_prefix_by_namespace_uri(namespace_uri) | Restituisce il prefisso per l'URI dello spazio dei nomi. |
| contains(key) | Verifica se la chiave è contenuta nei metadati. |
| remove(key) | Rimuove la voce dai metadati. |
| contains_key(key) | Determina se questo dizionario contiene la chiave specificata. |
| try_get_value(key, value) | Prova a trovare la chiave nel dizionario e recupera il valore se trovata. |
