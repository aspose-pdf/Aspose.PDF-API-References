## OutlineCollection class

Rappresenta la gerarchia del sommario del documento.

Il tipo OutlineCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| visible_count | Count è la somma del numero di elementi di contorno discendenti visibili a tutti i livelli. Nota: per favore non confondere con Count che è il numero di elementi nella collezione. |
| first | Ottiene un elemento di contorno che rappresenta il primo elemento di livello superiore nel contorno. |
| ultimo | Ottiene un elemento di outline che rappresenta l'ultimo elemento di livello superiore nell'outline. |
| is_synchronized | Ottiene un valore che indica se l'accesso a questa collezione è sincronizzato (thread safe). |
| sync_root | Ottiene un oggetto che può essere usato per sincronizzare l'accesso a questa collezione. |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Ottiene l'elemento di outline dalla collezione per indice. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| delete() | Elimina tutti gli elementi di outline dall'outline del documento. |
| delete(name) | Elimina l'elemento di outline con il titolo specificato dall'outline del documento. |
