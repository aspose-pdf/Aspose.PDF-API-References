## PageActionCollection class

Questa classe descrive le azioni della pagina

Il tipo PageActionCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| on_open | Un'azione che deve essere eseguita quando la pagina viene aperta. |
| on_close | Un'azione che deve essere eseguita quando la pagina viene chiusa. |
## Metodi
| Nome | Descrizione |
| :- | :- |
