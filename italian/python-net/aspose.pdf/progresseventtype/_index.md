## ProgressEventType enumeration

Questa enumerazione descrive i possibili tipi di eventi di avanzamento<br/>            che possono verificarsi durante la conversione

## Members
| Nome membro | Descrizione |
| :- | :- |
| TOTAL_PROGRESS | significa che l'evento verificatosi informa sul progresso totale della conversione |
| SOURCE_PAGE_ANALYSED | significa che l'evento verificatosi informa sulla fine dell'analisi di una delle pagine prima della conversione |
| RESULT_PAGE_CREATED | significa che l'evento verificatosi informa sulla creazione di una pagina risultato prima dell'esportazione fisica |
| RESULT_PAGE_SAVED | significa che l'evento verificatosi informa sul completamento del salvataggio di una pagina risultato |
