## PdfANonSpecificationFlags class

Questa classe contiene flag per controllare la conversione PDF/A nei casi in cui il documento PDF di origine non <br/>            corrisponda alla specifica PDF. Se i flag di questa classe sono usati, diminuiscono le prestazioni <br/>            ma è necessario quando il documento PDF di origine non può essere convertito nel formato PDF/A con il metodo usuale. <br/>            Per impostazione predefinita tutti i flag sono impostati su false.

Il tipo PdfANonSpecificationFlags espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PdfANonSpecificationFlags() | Inizializza una nuova istanza della classe PdfANonSpecificationFlags |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| check_different_names_in_font_dictionaries | Alcuni documenti PDF contengono font che hanno nomi diversi nei dati interni. <br/>            L'uso di questo flag impone una logica di elaborazione speciale per i casi in cui i campi <br/>            BaseFont e FontDescriptor.FontName sono diversi. |
