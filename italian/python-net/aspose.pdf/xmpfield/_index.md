## XmpField class

Rappresenta il campo XMP.

Il tipo XmpField espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| empty | Ottiene un campo xmp vuoto. |
| lang | Ottiene il qualificatore xml:lang. |
| prefix | Ottiene il prefisso. |
| namespace_uri | Ottiene l'URI dello spazio dei nomi. |
| local_name | Ottiene o imposta il nome del locale. |
| name | Ottiene il nome. |
| value | Ottiene il valore. |
| field_type | Ottiene il tipo del campo. |
| is_empty | Ottiene un valore che indica se questa istanza è vuota. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| to_structure() | Ottiene il valore come una struttura. |
| to_array() | Ottiene il valore come un array. |
