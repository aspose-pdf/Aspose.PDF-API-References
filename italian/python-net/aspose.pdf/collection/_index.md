## Collection class

Rappresenta la classe per Collection(12.3.5 Collections).

Il tipo Collection espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Collection() | Inizializza un nuovo oggetto Collection. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_synchronized | Ottiene un valore che indica se l'accesso a questa collezione è sincronizzato (thread safe). |
| sync_root | Ottiene un oggetto che può essere usato per sincronizzare l'accesso a questa collezione. |
| chiavi | Restituisce l'elenco delle chiavi degli allegati file. |
| default_entry | Nome predefinito del file incorporato. |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Ottiene il file incorporato per indice. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| delete(name) | Elimina il file dalla raccolta mediante la sua chiave nella raccolta. |
| delete() | Elimina il file dalla raccolta mediante la sua chiave nella raccolta. |
| add(key, file) | Aggiunge il file ai file incorporati con la chiave specificata. |
| delete_by_key(key) | Elimina il file dalla raccolta mediante la sua chiave nella raccolta. |
| find_by_name(name) | Restituisce il file incorporato per nome. |
