## XForm class

La classe rappresenta XForm

Il tipo XForm espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| b_box | Ottiene o imposta il riquadro di delimitazione del modulo. |
| name | Ottiene o imposta il nome del modulo. Il nome del modulo è il nome utilizzato per fare riferimento al modulo nel dizionario XObject nelle risorse della pagina. |
| contents | Ottiene gli operatori del modulo. |
| opi | Ottiene l'Open Prepress Interface (OPI). |
| matrix | Ottiene o imposta la matrice del modulo. |
| resources | Ottiene le risorse Form XObject. |
| rectangle | Ottiene o imposta il rettangolo del modulo. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| get_resources(allow_create) | Restituisce le risorse di Form X-Object |
| get_resources() | Restituisce le risorse di Form X-Object |
| create_new_form(source, document) | Crea XForm che duplica il contenuto della pagina. |
| free_memory() | Cancella i dati memorizzati nella cache |
