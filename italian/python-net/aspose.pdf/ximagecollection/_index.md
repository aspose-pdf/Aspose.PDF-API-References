## XImageCollection class

Classe che rappresenta la raccolta XImage.

Il tipo XImageCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_synchronized | Restituisce true se l'oggetto è sincronizzato. |
| sync_root | Restituisce l'oggetto di sincronizzazione. |
| names | Ottiene l'array dei nomi delle immagini. |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Ottiene l'immagine dalla collezione tramite il suo indice. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| add(image) | Aggiunge una nuova immagine all'elenco delle Immagini. Questo metodo aggiunge l'immagine come riferimento allo stesso PdfObject (che consente di ridurre le dimensioni del file) |
| add(image) | Aggiunge l'entità alla fine della collezione, così l'entità può essere accessibile tramite l'ultimo indice. |
| add(image, filter_type) | Aggiunge l'entità alla fine della collezione, così l'entità può essere accessibile tramite l'ultimo indice. |
| add(image, quality) | Aggiunge l'entità alla fine della collezione, così l'entità può essere accessibile tramite l'ultimo indice. |
| delete(index) | Rimuove l'indice dalla collezione per indice. |
| delete(index, action) | Rimuove l'immagine dalla collezione per indice eseguendo l'azione specificata dal parametro action. |
| delete(name) | Rimuove l'elemento dalla collezione per nome. |
| delete(name, action) | Rimuove l'elemento dalla collezione per nome. |
| delete() | Rimuove l'indice dalla collezione per indice. |
| replace(index, stream) | Sostituisci l'immagine nella collezione con un'altra immagine. |
| replace(index, stream, quality, is_black_and_white) | Sostituisci l'immagine nella collezione con un'altra immagine. |
| replace(index, stream, quality) | Sostituisci l'immagine nella collezione con un'altra immagine. |
| get_image_name(image) | Restituisce il nome nella lista delle immagini che è la chiave dell'immagine fornita. |
