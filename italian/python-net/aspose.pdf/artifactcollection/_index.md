## ArtifactCollection class

La classe rappresenta la collezione di artifact.

Il tipo ArtifactCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_synchronized | Questo oggetto è sincronizzato. |
| sync_root | Ottiene l'oggetto di sincronizzazione della collezione. |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Ottiene l'artifact per indice. L'indice parte da 1. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| delete(artifact) | Elimina l'artifact specificato. |
| delete(index) | Elimina l'artifact tramite il suo indice. |
| find_by_value(name, expected_value) | Trova gli artifact per valore personalizzato. |
| update(artifact) | Aggiorna l'artifact nella collezione. |
