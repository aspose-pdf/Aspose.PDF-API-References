## INamedDestinationCollection class

Raccolta di destinazioni nominate.

Il tipo INamedDestinationCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| count | Restituisce il conteggio delle destinazioni. |
| names | Ottiene l'array dei nomi delle destinazioni. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| remove(name) | Rimuove la destinazione per nome. |
| add(name, appointment) | Aggiunge una nuova destinazione nominata. |
