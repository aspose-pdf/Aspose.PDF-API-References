## ImagePlacement class

Rappresenta le caratteristiche di un'immagine posizionata nella pagina di un documento PDF.

Il tipo ImagePlacement espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| matrix | Matrice di trasformazione corrente per questa immagine. |
| rectangle | Ottiene il rettangolo dell'Image. |
| operatore | Operatore usato per visualizzare l'immagine. |
| rotation | Ottiene l'angolo di rotazione dell'Image. |
| resolution | Ottiene la risoluzione dell'Image. |
| image | Ottiene l'oggetto risorsa XImage correlato. |
| pagina | Ottiene la pagina che contiene l'immagine. |
| compositing_parameters | Ottiene i parametri di compositing dello stato grafico attivo per l'immagine posizionata nella pagina. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| save(stream) | Salva l'immagine con le trasformazioni corrispondenti: ridimensionamento, rotazione e risoluzione. |
| save(stream, format) | Salva l'immagine con le trasformazioni corrispondenti: ridimensionamento, rotazione e risoluzione. |
| hide() | Elimina l'immagine dalla pagina. |
| replace(image) | Sostituisci l'immagine nella collezione con un'altra immagine. |
