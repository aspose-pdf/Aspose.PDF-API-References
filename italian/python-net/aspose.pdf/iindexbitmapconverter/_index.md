## IIndexBitmapConverter class

Questa interfaccia è dichiarata per la personalizzazione degli algoritmi di quantizzazione. <br/>            Gli utenti possono implementare la propria realizzazione di questi algoritmi (ad esempio algoritmi basati su codice non gestito).

Il tipo IIndexBitmapConverter espone i seguenti membri:
## Metodi
| Nome | Descrizione |
| :- | :- |
| get_1_bpp_image(src) | Restituisce la rappresentazione bitmap a 1Bpp |
| get_4_bpp_image(src) | Restituisce la rappresentazione bitmap a 4Bpp |
| get_8_bpp_image(src) | Restituisce la rappresentazione bitmap a 8Bpp |
