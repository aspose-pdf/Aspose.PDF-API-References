## Row class

Rappresenta una riga della tabella.

Il tipo Row espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Row() | Inizializza una nuova istanza della classe Row |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| background_color | Ottiene o imposta il colore di sfondo. |
| border | Ottiene o imposta il bordo. |
| cells | Restituisce le celle della riga. |
| default_cell_border | Ottiene il bordo predefinito della cella; |
| min_row_height | Restituisce l'altezza per la riga; |
| fixed_row_height | Restituisce l'altezza fissa della riga - la riga può avere un'altezza fissa; |
| is_in_new_page | Restituisce se la riga fissa è in una nuova pagina - la pagina con questa proprietà dovrebbe essere stampata nella pagina successiva. Predefinito false; |
| is_row_broken | Restituisce se la riga può essere interrotta tra due pagine |
| default_cell_text_state | Ottiene o imposta lo stato di testo predefinito per le celle della riga |
| default_cell_padding | Restituisce o imposta il margine predefinito per le celle della riga |
| vertical_alignment | Ottiene o imposta l'allineamento verticale. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| clone() | Clona la riga. |
