## GraphInfo class

Rappresenta le informazioni grafiche.

Il tipo GraphInfo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| GraphInfo() | Inizializza una nuova istanza della classe GraphInfo |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| line_width | Ottiene o imposta un valore float che indica lo spessore della linea del grafico. |
| color | Ottiene o imposta un oggetto [color](/pdf/python-net/aspose.pdf/graphinfo/) che indica il colore del grafico. |
| dash_array | Ottiene o imposta un array di tratti. |
| dash_phase | Ottiene o imposta una fase di tratto. |
| fill_color | Ottiene o imposta un oggetto [color](/pdf/python-net/aspose.pdf/graphinfo/) che indica il colore di riempimento del grafico. |
| is_doubled | Ottiene o imposta se il bordo è raddoppiato. |
| skew_angle_x | Ottiene o imposta un valore float che indica l'angolo di inclinazione della coordinata x durante la trasformazione di un sistema di coordinate. |
| skew_angle_y | Ottiene o imposta un valore float che indica l'angolo di inclinazione della coordinata y durante la trasformazione di un sistema di coordinate. |
| scaling_rate_x | Ottiene o imposta un valore float che indica il fattore di scala della coordinata x durante la trasformazione di un sistema di coordinate. |
| scaling_rate_y | Ottiene o imposta un valore float che indica il fattore di scala della coordinata y durante la trasformazione di un sistema di coordinate. |
| rotation_angle | Ottiene o imposta un valore float che indica l'angolo di rotazione del sistema di coordinate <br/>            durante la trasformazione di un sistema di coordinate. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| clone() | Clona le informazioni grafiche. |
