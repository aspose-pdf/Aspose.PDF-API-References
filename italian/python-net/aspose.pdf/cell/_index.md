## Cell class

Rappresenta una cella della riga della tabella.

Il tipo Cell espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Cell(rect) | Inizializza una nuova istanza della classe Cell |
| Cell() | Inizializza una nuova istanza della classe Cell. |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_no_border | Ottiene o imposta se la cella ha bordo. |
| margine | Ottiene o imposta il padding. |
| border | Ottiene o imposta il bordo. |
| background_color | Ottiene o imposta il colore di sfondo. |
| background_image_file | Ottiene o imposta il file dell'immagine di sfondo. |
| background_image | Ottiene o imposta l'immagine di sfondo |
| alignment | Ottiene o imposta l'allineamento. |
| default_cell_text_state | Ottiene o imposta lo stato di testo predefinito della cella. |
| is_override_by_fragment | Imposta la proprietà TextState della cella sovrascritta dalla proprietà TextState di TextFragment. |
| paragraphs | Ottiene o imposta il testo formattato della cella. |
| is_word_wrapped | Ottiene o imposta l'avvolgimento delle parole del testo della cella. |
| vertical_alignment | Ottiene o imposta l'allineamento verticale. |
| col_span | Ottiene o imposta l'estensione della colonna. |
| row_span | Ottiene o imposta l'estensione della riga. |
| width | Ottiene o imposta la larghezza della colonna. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| clone() | Clona la cella. |
