## OutlineItemCollection class

Rappresenta una voce di sommario nella gerarchia del sommario di un documento PDF.

Il tipo OutlineItemCollection espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| OutlineItemCollection(outlines) | Inizializza una nuova istanza della classe OutlineItemCollection |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| visible_count | Restituisce il numero totale di elementi di outline a tutti i livelli nella gerarchia del contorno del documento. |
| title | Restituisce o imposta il titolo per questo elemento di outline. |
| destination | Restituisce o imposta la destinazione per questo elemento di outline. |
| azione | Restituisce o imposta l'azione per questo elemento di outline. |
| color | Restituisce o imposta il colore del testo del titolo di questo elemento di outline. |
| corsivo | Restituisce o imposta il flag corsivo per il testo del titolo di questo elemento di outline |
| grassetto | Restituisce o imposta il flag grassetto per il testo del titolo di questo elemento di outline |
| first | Restituisce l'elemento di outline che rappresenta il primo elemento di livello superiore nella gerarchia del outline. |
| ultimo | Restituisce l'elemento di outline che rappresenta l'ultimo elemento di livello superiore nella gerarchia del outline. |
| prev | Restituisce l'elemento di outline che rappresenta l'elemento precedente rispetto a questo nella gerarchia del outline. |
| next | Restituisce l'elemento di outline che rappresenta l'elemento successivo rispetto a questo nella gerarchia del outline. |
| has_next | Verifica se l'elemento di outline rappresenta l'elemento successivo rispetto a questo nella gerarchia del outline. |
| genitore | Restituisce l'oggetto genitore di questo elemento di outline nella gerarchia del outline. |
| is_synchronized | Restituisce il valore che indica se l'accesso a questa collezione è sincronizzato (thread safe). |
| sync_root | Restituisce l'oggetto che può essere usato per sincronizzare l'accesso a questa collezione. |
| open | Restituisce o imposta lo stato di apertura (true/false) per l'elemento di outline. |
| level | Restituisce il livello gerarchico dell'elemento di outline. |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Restituisce l'elemento di outline dalla collezione usando l'indice. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| delete() | Elimina questo elemento dell'indice dalla gerarchia dell'indice del documento. |
| delete(name) | Elimina la voce dell'indice con il nome specificato dalla gerarchia dell'indice del documento. |
| insert(index, outline) | Inserisce l'elemento dell'indice nella collezione nella posizione specificata. |
