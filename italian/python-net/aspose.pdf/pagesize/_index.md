## PageSize class

Classe che rappresenta le dimensioni della pagina in un documento PDF.

Il tipo PageSize espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PageSize(x, y) | Inizializza una nuova istanza della classe PageSize |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| width | Ottiene o imposta la larghezza della pagina. |
| height | Ottiene o imposta l'altezza della pagina. |
| is_landscape | Ottiene l'orientamento della pagina. Restituisce true se è orientamento orizzontale e false se è verticale. |
| a0 | Dimensione A0 (1189x840 mm). |
| a1 | Dimensione A1 (840x594 mm). |
| a2 | Dimensione A2 (594x420 mm). |
| a3 | Dimensione A3 (420x297 mm). |
| a4 | Formato A4 (297x210 mm). |
| a5 | Formato A5 (210x148 mm). |
| a6 | Formato A6 (148x105 mm). |
| b5 | Formato B5 (250x176 mm). |
| page_letter | Formato Letter (279x216 mm). |
| page_legal | Formato Legal (356x216 mm). |
| page_ledger | Formato Ledger (432x279 mm). |
| p11x17 | Formato 11x17 pollici. |
