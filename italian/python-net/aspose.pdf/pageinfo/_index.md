## PageInfo class

Rappresenta le informazioni della pagina.

Il tipo PageInfo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| PageInfo() | Inizializza una nuova istanza della classe PageInfo |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| any_margin | Ottiene o imposta il margine della pagina per qualsiasi pagina tranne la prima. |
| default_text_state | Ottiene o imposta il carattere predefinito. |
| height | Ottiene o imposta l'altezza della pagina. |
| pure_height | Ottiene o imposta l'altezza pura della pagina senza margini. |
| is_landscape | Ottiene o imposta se la pagina è in modalità landscape. |
