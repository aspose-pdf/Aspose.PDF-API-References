## HtmlSaveOptions class

Opzioni di salvataggio per l'esportazione in formato HTML

Il tipo HtmlSaveOptions espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| HtmlSaveOptions() | Inizializza una nuova istanza della classe [HtmlSaveOptions](/pdf/python-net/aspose.pdf/htmlsaveoptions/). |
| HtmlSaveOptions(document_type) | Inizializza una nuova istanza della classe HtmlSaveOptions |
| HtmlSaveOptions(fixed_layout) | Inizializza una nuova istanza della classe HtmlSaveOptions |
| HtmlSaveOptions(document_type, fixed_layout) | Inizializza una nuova istanza della classe HtmlSaveOptions |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| warning_handler | Callback per gestire eventuali avvisi generati. <br/>            Il WarningHandler restituisce l'elemento enum ReturnAction che specifica Continuare o Interrompere. <br/>            Continuare è l'azione predefinita e l'operazione di Salvataggio continua, tuttavia l'utente può anche restituire Interrompere, nel qual caso l'operazione di Salvataggio dovrebbe cessare. |
| save_format | Formato di salvataggio dei dati. |
| close_response | Ottiene o imposta il valore booleano che indica se l'oggetto Response sarà chiuso dopo che il documento è stato salvato nella risposta. |
| extract_ocr_sublayer_only | Nessuno |
| try_merge_adjacent_same_background_images | Nessuno |
| document_type | Ottiene o imposta il [HtmlDocumentType](/pdf/python-net/aspose.pdf/htmldocumenttype/). |
| compress_svg_graphics_if_any | Ottiene o imposta il flag che indica se<br/>            i grafici SVG trovati (se presenti) verranno compressi (zippati) <br/>            nel formato SVGZ durante il salvataggio |
| split_css_into_pages | Quando è selezionata la modalità multipagina (cioè 'SplitIntoPages' è 'true'), <br/>            questo attributo definisce se deve essere creato un file CSS separato<br/>            per ogni pagina HTML risultante.<br/>            Per impostazione predefinita questo attributo è false, quindi verrà creato<br/>            un unico grande CSS comune per tutte le pagine create. La dimensione totale di tutti<br/>            i CSS generati in questa modalità (un CSS per pagina) è solitamente<br/>            molto più grande della dimensione di un unico grande file CSS, perché nel caso precedente <br/>            le classi CSS sono duplicate in diversi file CSS per ciascuna pagina.<br/>            Pertanto, questa impostazione è consigliabile usarla solo quando sei interessato<br/>            all'elaborazione futura di ogni pagina HTML in modo indipendente, e quindi la dimensione<br/>            del CSS di ciascuna pagina presa singolarmente è la questione più critica. |
| split_into_pages | Ottiene o imposta il flag che indica se ogni pagina del documento sorgente <br/>            verrà convertita nel proprio documento HTML di destinazione, <br/>            cioè se l'HTML risultante sarà suddiviso in più pagine HTML. |
| explicit_list_of_saved_pages | Con questa proprietà è possibile definire esplicitamente <br/>            quali pagine del documento devono essere convertite.<br/>            Le pagine in questo elenco devono avere numeri a base 1. Cioè <br/>            i numeri validi delle pagine devono essere presi dall'intervallo (1...[NumberOfPagesInConvertedDocument])<br/>            L'ordine di comparsa delle pagine in questo elenco non influisce sul loro<br/>            ordine nelle pagine HTML risultanti - le pagine risultanti saranno sempre nell'ordine in cui sono <br/>            presenti nel PDF sorgente.<br/>            Se questo elenco è null (come è predefinito), tutte le pagine saranno convertite.<br/>            Se qualche numero di pagina in questo elenco supera l'intervallo delle pagine presenti (1-[amountOfPagesInDocument])<br/>            verrà generata un'eccezione. |
| fixed_layout | Ottiene o imposta un valore che indica se l'HTML è creato con layout fisso. |
| image_resolution | Ottiene o imposta la risoluzione per il rendering delle immagini. |
| default_font_name | Specifica il nome di un font installato che viene utilizzato per sostituire<br/>            qualsiasi font del documento che non è incorporato e non è installato nel sistema. <br/>            Se è null, verrà utilizzato il font di sostituzione predefinito. |
| batch_size | Definisce la dimensione del batch se la conversione batch è applicabile<br/>            alla coppia di formati di origine e destinazione. |
| font_sources | Origini dei font dei caratteri pre‑salvati. |
| additional_margin_width_in_points | Se l'attributo 'SplitOnPages=false', allora l'intero HTML che rappresenta tutte le pagine PDF di input non verrà<br/>            suddiviso in pagine HTML separate, ma sarà inserito in un unico grande file HTML di risultato.<br/>            Tuttavia ogni pagina PDF di origine sarà rappresentata con la propria <br/>            area rettangolare in HTML (se necessario tali aree possono essere bordate per mostrare i bordi della carta della pagina<br/>            con l'attributo speciale 'PageBorderIfAny'.<br/>            Questo parametro definisce la larghezza del margine che sarà forzatamente lasciata intorno a quelle aree HTML di output<br/>            che rappresentano le pagine del documento PDF di origine. In sostanza definisce l'intervallo garantito tra<br/>            le rappresentazioni HTML delle pagine \"carta\" del PDF in questa modalità di conversione. |
| use_z_order | Se l'attributo UseZORder è impostato su true, le grafiche e il testo vengono aggiunti al documento HTML risultante<br/>            secondo l'ordine Z nel documento PDF originale. Se questo attributo è false tutte le grafiche vengono inserite<br/>            come unico livello, il che può causare effetti indesiderati per gli oggetti sovrapposti. |
| convert_marked_content_to_layers | Se l'attributo ConvertMarkedContentToLayers è impostato su true, tutti gli elementi all'interno di un contenuto PDF marcato<br/>            (layer) verranno inseriti in un div HTML con l'attributo "data-pdflayer" che specifica il nome del layer.<br/>            Questo nome del layer sarà estratto dalle proprietà opzionali del contenuto PDF marcato.<br/>            Se questo attributo è false (per impostazione predefinita) non verrà creato alcun layer dal contenuto PDF marcato. |
| minimal_line_width | Questo attributo imposta la larghezza minima della linea del percorso grafico.<br/>            Se lo spessore della linea è inferiore a 1px, Adobe Acrobat lo arrotonda a questo valore. Pertanto questo attributo può<br/>            essere usato per emulare questo comportamento nei browser HTML. |
| prevent_glyphs_grouping | Questo attributo attiva la modalità in cui i glifi di testo non vengono raggruppati in parole e stringhe<br/>            Questa modalità consente di mantenere la massima precisione durante il posizionamento dei glifi sulla pagina e può essere<br/>            usata per la conversione di documenti con note musicali o glifi che devono essere posizionati separatamente l'uno dall'altro.<br/>            Questo parametro sarà applicato al documento solo quando il valore dell'attributo FixedLayout è true. |
| simple_textbox_mode_grouping | Questo attributo specifica un raggruppamento sequenziale di glifi e parole in stringhe<br/>            Ad esempio i tag e le parole hanno ordine diverso nell'HTML convertito e si desidera che corrispondano.<br/>            Questo parametro sarà applicato al documento solo quando il valore dell'attributo FixedLayout è true. |
| flow_layout_paragraph_full_width | Questo attributo specifica il testo del paragrafo a larghezza piena per la modalità Flow, FixedLayout = false |
| render_text_as_image | Se l'attributo RenderTextAsImage è impostato su true, il testo della sorgente diventa un'immagine in HTML.<br/>            Può essere utile per rendere il testo non selezionabile<br/>            o se il testo HTML non viene renderizzato correttamente. |
| save_full_font | Indica che il font completo verrà salvato, supporta solo i font True Type.<br/>            Per impostazione predefinita SaveFullFont = false e il convertitore salva il sottoinsieme del font iniziale<br/>            necessario per visualizzare il testo del documento. |
| antialiasing_processing | Questo parametro definisce le misure di antialiasing richieste durante la conversione di immagini di sfondo composte da PDF a HTML |
| save_transparent_texts | Il PDF può contenere testi trasparenti che possono essere copiati negli appunti (di solito accade quando il documento contiene immagini e testi OCR estratti da esse).<br/>            Questa impostazione indica al convertitore se è necessario salvare tali testi come testi trasparenti<br/>            selezionabili nel risultato HTML |
| save_shadowed_texts_as_transparent_texts | Pdf può contenere testi che sono oscurati da altri elementi (ad es. da immagini) ma <br/>            possono essere selezionati negli appunti in Acrobat Reader (di solito succede quando il documento contiene immagini e testi OCR estratti da esse).<br/>            Questa impostazione indica al convertitore se dobbiamo salvare tali testi come testi trasparenti<br/>            selezionabili nel risultato HTML per imitare il comportamento di Acrobat Reader (altrimenti tali testi sono solitamente salvati come nascosti, non disponibili per la copia negli appunti) |
| font_saving_mode | Definisce la modalità di salvataggio dei font che verrà utilizzata durante il salvataggio del PDF nel formato desiderato |
| page_border_if_any | Questo attributo rappresenta un insieme di impostazioni utilizzate per disegnare il bordo (se presente)<br/>            nel documento HTML risultante attorno all'area che rappresenta la pagina PDF di origine.<br/>            In sostanza riguarda la visualizzazione dei margini della carta della pagina,<br/>            non il bordo della pagina riferito nel PDF stesso. |
| page_margin_if_any | Questo attributo rappresenta un insieme di margini di pagina aggiuntivi (se presenti)<br/>            nel documento HTML risultante attorno all'area che rappresenta la pagina PDF di origine. |
| letters_positioning_method | Imposta la modalità di posizionamento delle lettere nelle parole nel risultato HTML |
| exclude_font_name_list | Elenco dei nomi dei font incorporati nel PDF che non devono essere incorporati nell'HTML. |
| special_folder_for_svg_images | Ottiene o imposta il percorso della directory in cui devono essere salvate solo le immagini SVG se vengono <br/>            incontrate durante il salvataggio del documento come HTML. Se il parametro è vuoto o nullo<br/>            le file SVG (se presenti) saranno salvate insieme alle altre immagini (vicino al file di output)<br/>            o in una cartella speciale per le immagini (se specificata nell'opzione SpecialImagesFolderIfAny).<br/>            Non influisce su nulla se la proprietà CustomImageSavingStrategy<br/>            è stata utilizzata con successo per elaborare il file immagine pertinente. |
| special_folder_for_all_images | Ottiene o imposta il percorso della directory in cui devono essere salvate tutte le immagini se vengono <br/>            incontrate durante il salvataggio del documento come HTML. Se il parametro è vuoto o nullo<br/>            i file immagine (se presenti) saranno salvati insieme agli altri file collegati all'HTML<br/>            Non influisce su nulla se la proprietà CustomImageSavingStrategy<br/>            è stata utilizzata con successo per elaborare il file immagine pertinente. |
| css_class_names_prefix | Quando il convertitore PDFtoHTML genera i CSS risultanti, i nomi delle classi CSS<br/>            (qualcosa come ".stl_01 {}" ... ".stl_NN {}") vengono generati<br/>            e usati nel CSS risultante. Questa proprietà consente di impostare forzatamente il prefisso del nome della classe<br/>            Ad esempio, se vuoi che tutti i nomi delle classi inizino con 'my_prefix_'<br/>            (cioè qualcosa come 'my_prefix_1' ... 'my_prefix_NNN'), <br/>            allora assegna semplicemente 'my_prefix_' a questa proprietà prima della conversione.<br/>            Se questa proprietà rimane invariata (cioè il valore null viene lasciato), allora<br/>            il convertitore genererà i nomi delle classi da solo <br/>            (sarà qualcosa come ".stl_01 {}" ... ".stl_NN {}") |
| parts_embedding_mode | Definisce se i file di riferimento (HTML, Font, Immagini, CSS)<br/>            saranno incorporati nel file HTML principale o saranno generati come entità binarie separate |
| html_markup_generation_mode | A volte sono presenti requisiti specifici per la generazione del markup HTML.<br/>            Questo parametro definisce le modalità di preparazione dell'HTML che possono essere utilizzate<br/>            durante la conversione da PDF a HTML per soddisfare tali requisiti specifici. |
| raster_images_saving_mode | Il PDF convertito può contenere immagini raster<br/>            Questo parametro definisce come devono essere gestite<br/>            durante la conversione da PDF a HTML |
| remove_empty_areas_on_top_and_bottom | Definisce se nell'HTML creato verranno rimosse le aree vuote superiore e inferiore senza alcun contenuto (se presenti). |
| font_encoding_strategy | Definisce una regola speciale di codifica per ottimizzare la decodifica PDF per il documento corrente. |
| pages_flow_type_depends_on_viewers_screen_size | Se l'attributo 'SplitOnPages=false', allora l'intero HTML che rappresenta tutte le pagine PDF di input verrà <br/>            inserito in un unico grande file HTML di risultato. <br/>            Questa opzione definisce se l'HTML di risultato sarà generato in modo tale<br/>            che il flusso delle aree che rappresentano le pagine PDF nell'HTML di risultato dipenda<br/>            dalla risoluzione dello schermo del visualizzatore. <br/>            Supponiamo che la larghezza dello schermo sul lato visualizzatore sia sufficientemente grande da posizionare 2 o più pagine una accanto<br/>            all'altra in direzione orizzontale. Se questa opzione è impostata su true, allora questa opportunità<br/>            verrà utilizzata (tante pagine saranno mostrate in direzione orizzontale una accanto all'altra<br/>            per quanto possibile, quindi il prossimo gruppo orizzontale di pagine sarà mostrato sotto il primo).<br/>            Altrimenti le pagine fluiranno in questo modo: la pagina successiva verrà sempre posta sotto la precedente. |
| try_save_text_underlining_and_strikeouting_in_css | Il PDF stesso non contiene marcatori di sottolineatura per i testi. È emulato con una linea situata sotto il testo.<br/>            Questa opzione consente al convertitore di provare a indovinare se questa o quella linea è una sottolineatura del testo<br/>            e inserire queste informazioni nel CSS invece di disegnare la sottolineatura graficamente |
