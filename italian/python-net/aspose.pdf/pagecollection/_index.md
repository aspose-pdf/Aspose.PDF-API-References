## PageCollection class

Raccolta di pagine di documenti PDF.

Il tipo PageCollection espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| is_synchronized | Restituisce true se l'oggetto è sincronizzato. |
| sync_root | Ottiene l'oggetto di sincronizzazione della collezione. |
## Indexer
| Nome | Descrizione |
| :- | :- |
| [index] | Ottiene la pagina per indice. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| add(entity) | Aggiunge la pagina alla collezione. |
| add() | Aggiunge la pagina alla collezione. |
| add(pages) | Aggiunge alla raccolta tutte le pagine dall'elenco. |
| add(pages) | Aggiunge alla raccolta tutte le pagine dall'array. |
| delete(index) | Elimina la pagina specificata. |
| delete() | Elimina la pagina specificata. |
| delete(pages) | Elimina le pagine specificate i cui numeri sono indicati nell'array. |
| accept(visitor) | Accetta l'oggetto visitor [AnnotationSelector](/pdf/python-net/aspose.pdf.annotations/annotationselector/) che fornisce funzionalità per lavorare con le annotazioni. |
| accept(visitor) | Accetta l'oggetto visitor [ImagePlacementAbsorber](/pdf/python-net/aspose.pdf/imageplacementabsorber/) che fornisce funzionalità per lavorare con gli oggetti di posizionamento delle immagini. |
| accept(visitor) | Accetta l'oggetto visitor [TextFragmentAbsorber](/pdf/python-net/aspose.pdf.text/textfragmentabsorber/) che fornisce funzionalità per lavorare con gli oggetti di testo. |
| accept(visitor) | Accetta l'oggetto visitor [TextAbsorber](/pdf/python-net/aspose.pdf.text/textabsorber/) che fornisce funzionalità per lavorare con gli oggetti di testo. |
| insert(page_number) | Inserisce una pagina vuota nella raccolta nella posizione specificata. |
| insert(page_number, entity) | Inserisce una pagina vuota nella raccolta nella posizione specificata. |
| insert(page_number, pages) | Inserisce pagine dalla raccolta nel documento. |
| insert(page_number, pages) | Inserisce pagine dall'array nel documento. |
| index_of(entity) | Restituisce l'indice della pagina specificata. |
| flatten() | Rimuove tutti i campi presenti nelle pagine e ne colloca i valori al loro posto. |
| free_memory() | Cancella i dati memorizzati nella cache |
