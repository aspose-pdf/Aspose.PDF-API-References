## HorizontalAlignment enumeration

Descrive l'allineamento orizzontale.

## Members
| Nome membro | Descrizione |
| :- | :- |
| NONE | Nessun allineamento. |
| SINISTRA | Allinea a sinistra. |
| CENTER | Allineamento centrale. |
| DESTRA | Allinea a destra. |
| JUSTIFY | Allineamento giustificato. Il testo sarà allineato sia al margine sinistro che a quello destro. |
| FULL_JUSTIFY | Simile all'allineamento 'Justify', tranne il fatto che l'ultima riga sarà solo <br/> allineata a sinistra in modalità 'Justify', mentre in modalità 'FullJustify' tutte le righe saranno<br/> allineate a sinistra e a destra. |
