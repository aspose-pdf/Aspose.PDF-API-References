## PageMode enumeration

La classe descrive i componenti utilizzati della pagina del documento.

## Members
| Nome membro | Descrizione |
| :- | :- |
| USE_NONE | Non utilizzare alcun componente. |
| USE_OUTLINES | Struttura del documento visibile. |
| USE_THUMBS | Miniature visibili. |
| FULL_SCREEN | FullScreenFull-screen mode, senza barra dei menu, controlli della finestra o qualsiasi altra finestra visibile. |
| USE_OC | Pannello del gruppo di contenuti opzionali visibile. |
| USE_ATTACHMENTS | Pannello degli allegati visibile. |
