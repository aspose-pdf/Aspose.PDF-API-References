## Opi class

Rappresenta The Open Prepress Interface (OPI) è un meccanismo per creare segnaposti a bassa risoluzione, o proxy,<br/>            per tali immagini ad alta risoluzione.

Il tipo Opi espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Opi(xform) | Inizializza una nuova istanza della classe Opi |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| version | Ottiene la versione di OPI a cui si riferisce questo dizionario. |
| file_specification | Ottiene il file esterno contenente l'immagine proxy a bassa risoluzione. |
| position | Ottiene un array di otto numeri della forma che specifica la posizione sulla pagina dell'immagine ritagliata. |
