## DocumentInfo class

Rappresenta le meta informazioni del documento PDF.

Il tipo DocumentInfo espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| DocumentInfo(document) | Inizializza una nuova istanza della classe DocumentInfo |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| title | Ottiene o imposta il titolo del documento. |
| creator | Ottiene o imposta il creatore del documento. |
| author | Ottiene o imposta l'autore del documento. |
| subject | Ottiene o imposta l'oggetto del documento. |
| keywords | Ottiene o imposta le parole chiave del documento. |
| producer | Ottiene o imposta il produttore del documento. |
| creation_date | Ottiene o imposta la data di creazione del documento. |
| creation_time_zone | Fuso orario della data di creazione. |
| mod_time_zone | Fuso orario della data di modifica. |
| mod_date | Ottiene o imposta la data di modifica del documento. |
| trapped | Ottiene o imposta il flag trapped. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| add(key, value) | Aggiunge un elemento con la chiave e il valore specificati nella collezione. |
| remove(key) | Rimuove l'elemento con la chiave specificata dalla collezione. |
| clear_custom_data() | Cancella solo i dati personalizzati, lasciando tutti gli altri valori predefiniti (Titolo, Autore, ecc.). |
| is_predefined_key(key) | Determina se la chiave è predefinita (Title, Author, ecc.), non personalizzata. |
