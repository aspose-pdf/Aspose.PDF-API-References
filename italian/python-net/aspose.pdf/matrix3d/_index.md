## Matrix3D class

La classe rappresenta una matrice di trasformazione.

Il tipo Matrix3D espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Matrix3D() | Costruttore<br/>            crea una matrice standard 1 a 1:<br/>            [ A B C D E F G H I Tx Ty Tz] = [ 1, 0, 0, 0, 1, 0, 0, 0, 1, 0, 0 , 0] |
| Matrix3D(matrix_3d_array) | Inizializza una nuova istanza della classe Matrix3D |
| Matrix3D(matrix) | Inizializza una nuova istanza della classe Matrix3D |
| Matrix3D(a, b, c, d, e, f, g, h, i, tx, ty, tz) | Inizializza una nuova istanza della classe Matrix3D |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| a | Un membro della matrice di trasformazione. |
| b | Membro B della matrice di trasformazione. |
| c | Membro C della matrice di trasformazione. |
| d | Membro D della matrice di trasformazione. |
| e | Membro E della matrice di trasformazione. |
| f | Membro F della matrice di trasformazione. |
| g | Membro G della matrice di trasformazione. |
| h | Membro H della matrice di trasformazione. |
| i | Membro I della matrice di trasformazione. |
| tx | Membro Tx della matrice di trasformazione. |
| ty | Membro Ty della matrice di trasformazione. |
| tz | Membro Tz della matrice di trasformazione. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| get_angle(rotation) | Traduce la rotazione in angolo (gradi) |
| add(other) | Aggiunge la matrice a un'altra matrice. |
