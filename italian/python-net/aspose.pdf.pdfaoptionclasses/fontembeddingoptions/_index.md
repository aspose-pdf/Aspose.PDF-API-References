## FontEmbeddingOptions class

Lo standard PDF/A richiede che tutti i caratteri siano incorporati nel documento.<br/>            Questa classe include flag per i casi in cui non è possibile incorporare alcuni caratteri perché tali caratteri sono assenti <br/>            sul PC di destinazione.

## Proprietà

| :- | :- |
| use_default_substitution | Dichiara di sostituire i font non incorporati usando la strategia di sostituzione dei font predefinita. Per impostazione predefinita false; |
