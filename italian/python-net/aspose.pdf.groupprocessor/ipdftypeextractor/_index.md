## IPdfTypeExtractor class

Rappresenta un'interfaccia per interagire con l'estrattore.

Il tipo IPdfTypeExtractor espone i seguenti membri:
## Proprietà
| Nome | Descrizione |
| :- | :- |
| page_count | Restituisce il conteggio delle pagine. |
| version | Restituisce la versione. |
| is_fast_extraction_used | Restituisce se è stato utilizzato il meccanismo di estrazione veloce. |
## Metodi
| Nome | Descrizione |
| :- | :- |
| extract_all_text() | Restituisce una collezione di valori di testo estratti. |
| extract_page_text(page_number) | Restituisce il testo della pagina. |
| dispose() | Rilascia. |
