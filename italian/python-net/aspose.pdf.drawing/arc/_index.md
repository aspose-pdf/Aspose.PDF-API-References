## Arc class

Rappresenta un arco.

Il tipo Arc espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Inizializza una nuova istanza della classe Arc |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| graph_info | Ottiene o imposta un oggetto [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) che indica le informazioni del grafico, come colore,<br/>            larghezza della linea, ecc. |
| text | Ottiene o imposta un testo per la forma |
| pos_x | Ottiene o imposta un valore float che indica la coordinata x del centro dell'arco. |
| pos_y | Ottiene o imposta un valore float che indica la coordinata y del centro dell'arco. |
| radius | Ottiene o imposta un valore float che indica il raggio dell'arco. |
| alpha | Ottiene o imposta un valore float che indica il grado dell'angolo iniziale dell'arco. |
| beta | Ottiene o imposta un valore float che indica il grado dell'angolo finale dell'arco. |
