## Rectangle class

Rappresenta un rettangolo.

Il tipo Rectangle espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Rectangle(left, bottom, width, height) | Inizializza una nuova istanza della classe Rectangle |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| graph_info | Ottiene o imposta un oggetto [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) che indica le informazioni del grafico, come colore,<br/>            larghezza della linea, ecc. |
| text | Ottiene o imposta un testo per la forma |
| rounded_corner_radius | Ottiene o imposta un valore float che indica il raggio degli angoli del rettangolo. |
| left | Ottiene o imposta un valore float che indica la posizione sinistra del rettangolo. |
| bottom | Ottiene o imposta un valore float che indica la posizione inferiore del rettangolo. |
| width | Ottiene o imposta un valore float che indica la larghezza del rettangolo. |
| height | Ottiene o imposta un valore float che indica l'altezza del rettangolo. |
