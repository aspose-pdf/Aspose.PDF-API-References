## Line class

Rappresenta una linea.

Il tipo Line espone i seguenti membri:
## Costruttori
| Nome | Descrizione |
| :- | :- |
| Line(position_array) | Inizializza una nuova istanza della classe Line |
## Proprietà
| Nome | Descrizione |
| :- | :- |
| graph_info | Ottiene o imposta un oggetto [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) che indica le informazioni del grafico, come colore,<br/>            larghezza della linea, ecc. |
| text | Ottiene o imposta un testo per la forma |
| position_array | Ottiene o imposta un oggetto [position_array](/pdf/python-net/aspose.pdf.drawing/line/) che indica l'array di posizioni. L'array è <br/>            composto dalle coordinate di ciascun punto di controllo della linea. <br/>            direttamente. |
