## Security PDF functions

| Nome | Descrizione |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | Cifra un file PDF. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | Decifra un file PDF. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | Firma un file PDF con firme digitali. |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | Firma un file PDF con firme digitali separate. |
| [AsposePdfChangePassword](./asposepdfchangepassword/) | Cambia le password del file PDF. |

## Detailed Description

Funzioni per gestire le funzionalità di sicurezza dei file PDF.

