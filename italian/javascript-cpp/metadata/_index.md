## Metadata PDF functions

| Nome | Descrizione |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | Imposta le informazioni (metadati) in un file PDF. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | Ottieni le informazioni (metadati) da un file PDF. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | Ottieni l'elenco dei font da un file PDF. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | Rimuovi i metadati da un file PDF. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | Ottieni il conteggio di parole e caratteri in un file PDF. |
| [AsposePdfGetPagesLayers](./asposepdfgetpageslayers/) | Ottieni l'elenco dei livelli da un file PDF. |

Funzioni per lavorare con file PDF di metadati.
