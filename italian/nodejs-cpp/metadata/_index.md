## Metadata PDF functions

| Nome | Descrizione |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | Imposta le informazioni (metadata) in un file PDF. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | Ottieni le informazioni (metadata) da un file PDF. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | Ottieni l'elenco dei font da un file PDF. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | Rimuovi i metadata da un file PDF. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | Ottieni il conteggio di parole e caratteri in un file PDF. |
| [AsposePdfGetPagesLayers](./asposepdfgetpageslayers/) | Ottieni l'elenco dei layer da un file PDF. |
