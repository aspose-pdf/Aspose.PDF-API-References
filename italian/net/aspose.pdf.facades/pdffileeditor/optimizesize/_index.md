## PdfFileEditor.OptimizeSize property

Ottiene o imposta il flag di ottimizzazione. I flussi di risorse uguali nel file risultante vengono uniti in un unico oggetto PDF se questo flag è impostato. Ciò consente di ridurre la dimensione del file risultante ma può causare un'esecuzione più lenta e requisiti di memoria maggiori. Valore predefinito: false.

```csharp
public bool OptimizeSize { get; set; }
```
