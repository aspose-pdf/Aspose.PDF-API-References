## FormDataConverter.Table property

Ottiene o imposta il contenitore dati intermedio, un DataTable. Deve essere definito prima di convertire i dati da un formato all'altro. Le Columns e il TableName del DataTable devono essere definiti. Il TableName è il nome della Table nel database. Il ColumnName di ogni colonna è il nome del campo qualificato del pdf. La Caption di ogni colonna è il nome della colonna della table nel database. Se il nome del campo è lo stesso del nome della colonna della table, la Caption non è necessaria.

```csharp
public DataTable Table { get; set; }
```
