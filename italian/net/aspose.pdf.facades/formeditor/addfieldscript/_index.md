## FormEditor.AddFieldScript method

Aggiungi JavaScript per un campo PushButton. Se esiste un evento precedente, il nuovo evento viene aggiunto dopo di esso.

```csharp
public bool AddFieldScript(string fieldName, string script)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| fieldName | String | Il nome completo del campo. |
| script | String | Lo script Java da aggiungere/posizionare in un campo pulsante. |

### Valore di ritorno

True nel caso lo script sia stato aggiunto con successo.
