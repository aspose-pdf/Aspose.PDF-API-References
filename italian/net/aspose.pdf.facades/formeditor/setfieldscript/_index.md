## FormEditor.SetFieldScript method


| Parametro | Tipo | Descrizione |

| fieldName | String | Il nome completo del campo. |
| script | String | Lo script Java da aggiungere/posizionare in un campo pulsante. |

vero se lo script del campo è stato impostato correttamente.
