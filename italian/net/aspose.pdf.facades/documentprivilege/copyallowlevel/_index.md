## DocumentPrivilege.CopyAllowLevel property

Ottiene e imposta il livello di copia del privilegio del documento. Come le impostazioni di autorizzazione di Adobe Professional. 0: Nessuno. 1: Abilita l'accesso al testo per dispositivi di lettura schermo per ipovedenti. 2: Abilita la copia di testo, immagini e altri contenuti.

```csharp
public int CopyAllowLevel { get; set; }
```

## Osservazioni

Se la proprietà ha un valore di -1, il livello è indefinito.
