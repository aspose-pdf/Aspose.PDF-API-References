## PdfExtractor.Resolution property

Imposta o ottiene la risoluzione per le immagini estratte. Il valore predefinito è 150. Le immagini con una risoluzione maggiore sono più nitide. Tuttavia aumentare la risoluzione comporta un aumento del tempo e della memoria necessari per estrarre le immagini. Di solito, per ottenere un'immagine nitida è sufficiente impostare la risoluzione a 150 o 300.

public int Resolution { get; set; }
