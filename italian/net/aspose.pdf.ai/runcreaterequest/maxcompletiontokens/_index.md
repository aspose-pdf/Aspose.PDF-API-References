## RunCreateRequest.MaxCompletionTokens property

Ottiene o imposta il numero massimo di token di completamento che possono essere utilizzati durante l'esecuzione. L'esecuzione cercherà di utilizzare solo il numero di token di completamento specificato, attraverso più turni dell'esecuzione. Se l'esecuzione supera il numero di token di completamento specificato, terminerà con stato incompleto. Vedi incomplete_details per ulteriori informazioni.

public int? MaxCompletionTokens { get; set; }
