## CreateChatCompletionChunkResponse.Usage property

Ottiene o imposta un campo opzionale che sarà presente solo quando imposti stream_options: {\"include_usage\": true} nella tua richiesta. Quando presente, contiene un valore null tranne l'ultimo blocco che contiene le statistiche di utilizzo dei token per l'intera richiesta.
