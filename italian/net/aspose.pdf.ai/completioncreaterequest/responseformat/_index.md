## CompletionCreateRequest.ResponseFormat property

Ottiene o imposta un oggetto che specifica il formato che il modello deve restituire. Compatibile con GPT-4 Turbo e tutti i modelli GPT-3.5 Turbo più recenti di gpt-3.5-turbo-1106. Impostare a { "type": "json_object" } abilita la modalità JSON, che garantisce che il messaggio generato dal modello sia JSON valido.

public ResponseFormat ResponseFormat { get; set; }
