Lo spazio dei nomi **Aspose.Pdf.Printing** fornisce classi e funzionalità per gestire le operazioni di stampa PDF, inclusi le impostazioni della stampante, le impostazioni di pagina e le estensioni per la gestione delle configurazioni correlate alla stampa.

## Classi

| Classe | Descrizione |
| --- | --- |
| [CustomPrintEventArgs](./customprinteventargs/) | Fornisce i dati per l'evento [`CustomPrint`](../aspose.pdf.facades/pdfviewer/customprint/). |
| [PageSettings](./pagesettings/) | Specifica le impostazioni che si applicano a una singola pagina stampata. |
| [PageSettingsExtensions](./pagesettingsextensions/) | Rappresenta i metodi di estensione per [`PageSettings`](../aspose.pdf.printing/pagesettings/). |
| [PaperSize](./papersize/) | Specifica le dimensioni di un foglio di carta. |
| [PaperSizeExtensions](./papersizeextensions/) | Rappresenta i metodi di estensione per [`PaperSize`](../aspose.pdf.printing/papersize/). |
| [PaperSizes](./papersizes/) | Rappresenta le dimensioni standard della carta. |
| [PaperSource](./papersource/) | Specifica il vassoio di carta da cui la stampante preleva la carta. |
| [PaperSourceExtensions](./papersourceextensions/) | Rappresenta i metodi di estensione per [`PaperSource`](../aspose.pdf.printing/papersource/). |
| [PaperSources](./papersources/) | Fornisce un insieme di istanze predefinite di [`PaperSource`](../aspose.pdf.printing/papersource/) che rappresentano le fonti di carta comuni. |
| [PdfQueryPageSettingsEventArgs](./pdfquerypagesettingseventargs/) | Fornisce i dati per l'evento [`PdfQueryPageSettings`](../aspose.pdf.facades/pdfviewer/pdfquerypagesettings/). |
| [PrinterResolution](./printerresolution/) | Rappresenta la risoluzione supportata da una stampante. |
| [PrinterResolutionExtensions](./printerresolutionextensions/) | Rappresenta i metodi di estensione per [`PrinterResolution`](../aspose.pdf.printing/printerresolution/). |
| [PrinterSettings](./printersettings/) | Specifica le informazioni su come viene stampato un documento, inclusa la stampante che lo stampa. |
| [PrinterSettingsExtensions](./printersettingsextensions/) | Rappresenta i metodi di estensione per [`PrinterSettings`](../aspose.pdf.printing/printersettings/). |
| [StartEndPageEventArgs](./startendpageeventargs/) | Fornisce i dati per gli eventi [`StartPage`](../aspose.pdf.facades/pdfviewer/startpage/) e [`EndPage`](../aspose.pdf.facades/pdfviewer/endpage/) della classe [`PdfViewer`](../aspose.pdf.facades/pdfviewer/). |
