## Spazi dei nomi

| Spazio dei nomi | Descrizione |
| --- | --- |
| [Aspose.Pdf](./aspose.pdf/) | Il **Aspose.Pdf** è uno spazio dei nomi radice per tutte le classi della libreria Aspose.Pdf che sono sia direttamente al suo interno, come **Document**, sia indirettamente tramite diversi sotto-spazi dei nomi. |
| [Aspose.Pdf.AI](./aspose.pdf.ai/) | Lo spazio dei nomi **Aspose.Pdf.AI** fornisce classi per le funzionalità di IA, inclusi client API e assistenti intelligenti. |
| [Aspose.Pdf.Annotations](./aspose.pdf.annotations/) | Lo spazio dei nomi **Aspose.Pdf.Annotations** fornisce classi per lavorare con vari tipi di azioni, destinazioni e altre funzionalità del documento tradizionalmente chiamate interattive, offrendo mezzi con cui l'utente può interagire con esso. |
| [Aspose.Pdf.Comparison](./aspose.pdf.comparison/) | Lo spazio dei nomi **Aspose.Pdf.Comparison** fornisce classi utilizzate per il confronto dei documenti. |
| [Aspose.Pdf.DataEditor](./aspose.pdf.dataeditor/) | Il **Aspose.Pdf.DataEditor** contiene strumenti per modificare i dati all'interno di un documento. |
| [Aspose.Pdf.Devices](./aspose.pdf.devices/) | Lo spazio dei nomi **Aspose.Pdf.Devices** fornisce classi utilizzate per rappresentare un documento come immagine(i) o testo semplice. In questo modo il documento può essere inviato a dispositivi testuali o grafici, consentendo di ottenere una rappresentazione testuale o grafica. |
| [Aspose.Pdf.Drawing](./aspose.pdf.drawing/) | Lo spazio dei nomi **Aspose.Pdf.Drawing** fornisce classi che descrivono primitive grafiche come arco, linea, cerchio, ecc. Gli oggetti corrispondenti possono essere usati per creare nuovi documenti. |
| [Aspose.Pdf.Facades](./aspose.pdf.facades/) | Lo spazio dei nomi **Aspose.Pdf.Facades** fornisce classi originariamente provenienti da Aspose.Pdf.Kit. Queste classi sono usate per manipolare i documenti eseguendo operazioni come concatenazione, aggiunta di filigrane, firma, annotazione, ecc., ma a livello alto senza accesso alla struttura interna del documento. |
| [Aspose.Pdf.Forms](./aspose.pdf.forms/) | Lo spazio dei nomi **Aspose.Pdf.Forms** contiene classi che descrivono i moduli (standard, statici, dinamici) e vari tipi di campi come casella di testo, casella di riepilogo, pulsante radio, ecc. |
| [Aspose.Pdf.LogicalStructure](./aspose.pdf.logicalstructure/) | Il **Aspose.Pdf.Tagged.LogicalStructure** è uno spazio dei nomi per le classi di Struttura Logica PDF. |
| [Aspose.Pdf.Multithreading](./aspose.pdf.multithreading/) | Lo spazio dei nomi **Aspose.Pdf.Multithreading** fornisce classi pensate per essere utilizzate in scenari multithread. |
| [Aspose.Pdf.Operators](./aspose.pdf.operators/) | Il **Aspose.Pdf.Operators** è uno spazio dei nomi per le implementazioni di operatori. Queste classi descrivono gli operatori usati nei contenuti delle pagine PDF. |
| [Aspose.Pdf.Optimization](./aspose.pdf.optimization/) | Il **Aspose.Pdf.Optimization** è uno spazio dei nomi per le classi che gestiscono il processo di ottimizzazione del documento. |
| [Aspose.Pdf.Plugins](./aspose.pdf.plugins/) | Il **Aspose.Pdf.Plugins** è uno spazio dei nomi radice per tutte le classi di Aspose.Pdf.Plugins che sono sia direttamente al suo interno, come **PdfOrganizer**, sia indirettamente tramite diversi sotto-spazi dei nomi. |
| [Aspose.Pdf.Printing](./aspose.pdf.printing/) | Lo spazio dei nomi **Aspose.Pdf.Printing** fornisce classi e funzionalità per gestire le operazioni di stampa PDF, inclusi le impostazioni della stampante, le impostazioni di pagina e le estensioni per la gestione delle configurazioni correlate alla stampa. |
| [Aspose.Pdf.Sanitization](./aspose.pdf.sanitization/) | Il **Aspose.Pdf.Sanitization** è uno spazio dei nomi per le operazioni di sanificazione. |
| [Aspose.Pdf.Security](./aspose.pdf.security/) | Lo spazio dei nomi **Aspose.Pdf.Security** contiene classi utilizzate per la crittografia e la firma digitale. |
| [Aspose.Pdf.Signatures](./aspose.pdf.signatures/) | Lo spazio dei nomi **Aspose.Pdf.Signatures** contiene classi utilizzate per rilevare firme compromesse. |
| [Aspose.Pdf.Structure](./aspose.pdf.structure/) | Lo spazio dei nomi **Aspose.Pdf.Structure** fornisce classi che aiutano a lavorare con la struttura logica di un documento, che presenta l'organizzazione del documento in capitoli e sezioni o l'identificazione di elementi speciali come figure, tabelle e note a piè di pagina. |
| [Aspose.Pdf.Tagged](./aspose.pdf.tagged/) | Il **Aspose.Pdf.Tagged** è uno spazio dei nomi per le classi a supporto dei documenti PDF Tagged. |
| [Aspose.Pdf.Text](./aspose.pdf.text/) | Il namespace **Aspose.Pdf.Text** fornisce classi che consentono di estrarre testo, aggiungere testo, manipolare il testo esistente di un document. Contiene anche classi che permettono di estrarre, sostituire, rimpiazzare i fonts di un document. |
| [Aspose.Pdf.Vector](./aspose.pdf.vector/) | Il **Aspose.Pdf.Vector** è un namespace radice per operazioni grafiche. |
| [Aspose.Pdf.XfaConverter](./aspose.pdf.xfaconverter/) | Il namespace **Aspose.Pdf.XfaConverter** fornisce classi che consentono di convertire XFA. |
