Lo spazio dei nomi **Aspose.Pdf.Devices** fornisce classi utilizzate per rappresentare un documento come immagine(i) o testo semplice. In questo modo il documento può essere inviato a dispositivi testuali o grafici, consentendo di ottenere una rappresentazione testuale o grafica.

## Classi

| Classe | Descrizione |
| --- | --- |
| [BmpDevice](./bmpdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento pdf in bmp. |
| [Device](./device/) | Classe astratta per tutti i tipi di dispositivi. Il dispositivo è usato per rappresentare il documento pdf in qualche formato. Ad esempio, la pagina del documento può essere rappresentata come immagine o testo. |
| [DicomDevice](./dicomdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento pdf in formato Dicom. |
| [DocumentDevice](./documentdevice/) | Classe astratta per tutti i dispositivi utilizzata per elaborare l'intero documento pdf. |
| [EmfDevice](./emfdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento pdf in emf. |
| [GifDevice](./gifdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento pdf in gif. |
| [ImageDevice](./imagedevice/) | Una classe astratta per dispositivi immagine. |
| [JpegDevice](./jpegdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento pdf in jpeg. |
| [Margins](./margins/) | Questa classe rappresenta i margini di un'immagine. |
| [PageDevice](./pagedevice/) | Classe astratta per tutti i dispositivi utilizzata per elaborare una determinata pagina del documento pdf. |
| [PngDevice](./pngdevice/) | Rappresenta un dispositivo immagine che consente di salvare le pagine del documento pdf in png. |
| [Resolution](./resolution/) | Rappresenta una classe per contenere la risoluzione dell'immagine. |
| [TextDevice](./textdevice/) | Rappresenta una classe per convertire le pagine del documento pdf in testo. |
| [ThumbnailDevice](./thumbnaildevice/) | Rappresenta un dispositivo immagine che salva le pagine del documento pdf in un'immagine Thumbnail. |
| [TiffDevice](./tiffdevice/) | Questa classe aiuta a salvare le pagine del documento pdf, una per una, in un'unica immagine tiff. |
| [TiffSettings](./tiffsettings/) | Questa classe rappresenta le impostazioni per l'importazione di pdf in Tiff. |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [ColorDepth](./colordepth/) | Usato per specificare il valore del parametro passato a un dispositivo immagine Tiff. |
| [CompressionType](./compressiontype/) | Usato per specificare il valore del parametro passato a un dispositivo immagine Tiff. |
| [FormPresentationMode](./formpresentationmode/) | Utilizzato per specificare la modalità di presentazione del modulo durante la stampa o la conversione in documenti pdf immagine. |
| [ShapeType](./shapetype/) | Questo enum rappresenta il tipo di forma per le immagini estratte. |
