## ICustomSecurityHandler.IsUserPassword method

Verifica se la password appartiene all'utente (password per aprire il documento). Il metodo viene chiamato dopo Initialize. La chiamata al metodo è utilizzata nell'API PDF.

```csharp
public bool IsUserPassword(string password)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| password | String | La password. |

### Valore di ritorno

True, se è una password per aprire il documento.
