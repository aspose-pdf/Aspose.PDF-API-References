## ValidationResult.Status property

Ottiene lo stato del processo di convalida per un certificato.

```csharp
public ValidationStatus Status { get; }
```

## Osservazioni

La proprietà Status indica il risultato della convalida del certificato. I valori possibili sono definiti nell'enumerazione [`ValidationStatus`](../../validationstatus/), come Valid, Invalid o Undefined. Fornisce un'indicazione su se il certificato ha superato i controlli di convalida o meno.
