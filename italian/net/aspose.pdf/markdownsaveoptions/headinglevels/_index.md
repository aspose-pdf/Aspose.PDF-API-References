## MarkdownSaveOptions.HeadingLevels property

Definisce i livelli di intestazione attesi da utilizzare nella strategia di riconoscimento delle intestazioni FontSize. Se il valore di questa proprietà è impostato, allora la strategia di riconoscimento delle intestazioni Heuristic verrà selezionata quando è impostato !:PdfToMarkdown.HeadingRecognitionStrategy.Auto, anche se il documento contiene segnalibri.

public HeadingLevels HeadingLevels { get; set; }
