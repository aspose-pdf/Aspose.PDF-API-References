## TextStamp.AutoAdjustFontSizeToFitStampRectangle property

Se abilitato, la dimensione del carattere verrà regolata automaticamente per adattarsi al rettangolo del timbro di dimensioni: [`Width`](../width/) e [`Height`](../height/). Default width and height sono derivati dal rettangolo della page.

```csharp
public bool AutoAdjustFontSizeToFitStampRectangle { get; set; }
```
