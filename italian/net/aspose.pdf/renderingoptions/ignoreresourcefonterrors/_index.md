## RenderingOptions.IgnoreResourceFontErrors property

Ottiene o imposta l'indicazione che gli errori relativi all'assenza del font saranno ignorati. true - indica che gli errori di assenza del font saranno ignorati. I segmenti di testo che si riferiscono a risorse errate verranno saltati durante l'elaborazione. false per impostazione predefinita

```csharp
public bool IgnoreResourceFontErrors { get; set; }
```
