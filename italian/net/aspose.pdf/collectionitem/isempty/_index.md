## CollectionItem.IsEmpty property

Ottiene un valore che indica se l'elemento di raccolta è vuoto.

```csharp
public bool IsEmpty { get; }
```

### Valore di ritorno

true se l'elemento della collezione è vuoto; altrimenti, false.

## Osservazioni

Questa proprietà restituisce true se l'elemento della collezione non contiene alcun valore, inclusi valori stringa, valori double, valori integer e valori date. Se uno di questi tipi di valore è presente nell'elemento della collezione, questa proprietà restituisce false.
