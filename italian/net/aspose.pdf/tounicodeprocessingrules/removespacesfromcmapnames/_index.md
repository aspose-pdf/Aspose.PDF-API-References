## ToUnicodeProcessingRules.RemoveSpacesFromCMapNames property

Alcuni font hanno mappe di codici carattere ToUnicode con spazi nei nomi. Questi spazi potrebbero generare errori nella mappatura del testo Unicode. Questo flag indica di rimuovere gli spazi dai nomi delle mappe di codici carattere ToUnicode. Per impostazione predefinita false.

```csharp
public bool RemoveSpacesFromCMapNames { get; set; }
```
