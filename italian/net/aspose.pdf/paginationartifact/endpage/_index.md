## PaginationArtifact.EndPage property

Ottiene o imposta il numero di page finale per l'artefatto. Il valore deve essere maggiore o uguale a 0. Se viene impostato un valore inferiore a 0, verrà regolato a 0. Il valore predefinito 0 indica che non ci sono limiti di page finale.

public int EndPage { get; set; }
