## HtmlSaveOptions.CssUrlRequestInfo.CustomProcessingCancelled field

Dovrebbe essere impostato dal codice personalizzato se non può o non deve definire l'URL che verrà usato nell'HTML generato per fare riferimento a quel CSS. Se è 'true', il file CSS verrà salvato in modo standard nella posizione standard.

public bool CustomProcessingCancelled;
