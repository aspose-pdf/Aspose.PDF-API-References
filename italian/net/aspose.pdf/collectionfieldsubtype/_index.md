## CollectionFieldSubtype enumeration

Rappresenta il parametro di sottotipo di un campo in una raccolta di schemi.

```csharp
public enum CollectionFieldSubtype
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| None | `0` | Il sottotipo non è definito. |
| S | `1` | Un tipo testo. I dati del campo devono essere memorizzati come stringa di testo PDF. |
| D | `2` | Un tipo data. I dati del campo devono essere memorizzati come stringa di data PDF. |
| N | `3` | Un tipo numero. I dati del campo devono essere memorizzati come numero PDF. |
| F | `4` | I dati del campo devono essere il nome file del flusso di file incorporato, identificato dalla voce UF della specifica del file, se presente; altrimenti dalla voce F della specifica del file. |
| Desc | `5` | I dati del campo devono essere il nome file del flusso di file incorporato, identificato dalla voce UF della specifica del file, se presente; altrimenti dalla voce F della specifica del file. |
| ModDate | `6` | I dati del campo devono essere la data di modifica del flusso di file incorporato, identificata dalla voce ModDate nel dizionario dei parametri del file incorporato. |
| CreationDate | `7` | I dati del campo devono essere la data di creazione del flusso di file incorporato, identificata dalla voce CreationDate nel file incorporato. |
| Size | `8` | I dati del campo devono essere la dimensione del file incorporato, identificata dalla voce Size nel dizionario dei parametri del file incorporato. |
| CompressedSize | `9` | (PDF 2.0) I dati del campo sono la lunghezza del flusso di file incorporato, identificata dalla voce Length nel dizionario del flusso di file incorporato, e i due valori devono essere identici. |
