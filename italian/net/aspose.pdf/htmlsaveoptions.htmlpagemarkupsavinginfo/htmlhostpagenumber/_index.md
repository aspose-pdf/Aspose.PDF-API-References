## HtmlSaveOptions.HtmlPageMarkupSavingInfo.HtmlHostPageNumber field

Impostato dal convertitore. Se la proprietà SplitToPages è impostata, vengono creati diversi file HTML (un file HTML per pagina convertita) durante la conversione. Questa proprietà contiene l'ordine del file HTML salvato. La proprietà può essere usata nella logica del codice personalizzato per decidere come elaborare o dove salvare la pagina HTML e, se la divisione in pagine è disattivata, questo valore contiene sempre '1' poiché in tal caso viene generata una sola grande pagina HTML per l'intero documento di origine.

```csharp
public int HtmlHostPageNumber;
```
