## HeadingRecognitionStrategy enumeration

Rappresenta i tipi di strategie di riconoscimento dell'intestazione.

```csharp
public enum HeadingRecognitionStrategy
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| Outlines | `0` | Rappresenta la strategia di riconoscimento delle intestazioni tramite contorni. |
| Heuristic | `1` | Rappresenta la strategia di riconoscimento delle intestazioni tramite regole euristiche e statistiche delle dimensioni dei caratteri. |
| Auto | `2` | Fornisce una selezione automatica della strategia di riconoscimento delle intestazioni. Questa è l'opzione predefinita. Se il documento contiene segnalibri, verrà selezionata la strategia Outlines, altrimenti Heuristic |
| None | `3` | Non riconoscere le intestazioni. Questa opzione può essere utile in documenti formattati in modo complesso. |
