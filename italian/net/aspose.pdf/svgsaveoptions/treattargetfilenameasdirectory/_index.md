## SvgSaveOptions.TreatTargetFileNameAsDirectory field

Questa opzione definisce se creare una directory di destinazione (se ancora assente) con lo stesso nome del file di output richiesto invece del file di output stesso. In tal caso, la directory conterrà tutte le immagini SVG di output delle pagine (come descritto di seguito). Se no, i file di output delle pagine diverse dalla prima verranno creati esattamente nella directory richiesta come file di output principale, ma con un suffisso nel nome file _[2...n], definito dal numero di pagina, ad es. se si definisce il file di output "C:\AsposeTests\output.svg" e l'output conterrà diversi file svg delle pagine, allora i file delle pagine saranno creati anche nella directory "C:\AsposeTests\" e avranno i nomi 'output.svg', 'output_2.svg', 'output_3.svg' ecc.

public bool TreatTargetFileNameAsDirectory;
