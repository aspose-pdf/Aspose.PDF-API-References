## OptimizedMemoryStream.Write method

Quando sovrascritto in una classe derivata, scrive una sequenza di byte nello stream corrente e avanza la posizione corrente all'interno di questo stream del numero di byte scritti.

```csharp
public override void Write(byte[] buffer, int offset, int count)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| buffer | Byte[] | Un array di byte. Questo metodo copia *count* byte da *buffer* allo stream corrente. |
| offset | Int32 | L'offset di byte basato su zero in *buffer* a cui iniziare a copiare i byte nello stream corrente. |
| conteggio | Int32 | Il numero di byte da scrivere nello stream corrente. |
