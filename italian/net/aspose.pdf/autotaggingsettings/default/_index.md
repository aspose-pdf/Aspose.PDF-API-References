## AutoTaggingSettings.Default property

Restituisce le impostazioni predefinite per la funzionalità di auto-tagging nei documenti PDF.

```csharp
public static AutoTaggingSettings Default { get; }
```

## Osservazioni

Le impostazioni predefinite abilitano l'auto-tagging e utilizzano la strategia automatica per il riconoscimento delle intestazioni. Queste impostazioni possono essere usate come configurazione di base per la conversione del formato PDF o altre operazioni che richiedono il tagging automatico del contenuto PDF.
