## AutoTaggingSettings.EnableAutoTagging property

Ottiene o imposta un valore che indica se la funzionalità di auto-tagging è abilitata.

```csharp
public bool EnableAutoTagging { get; set; }
```

## Osservazioni

Quando abilitata, la funzionalità di auto-tagging genera automaticamente contenuti taggati per il documento PDF, il che può migliorare l'accessibilità e la struttura.
