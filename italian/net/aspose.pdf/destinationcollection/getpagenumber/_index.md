## DestinationCollection.GetPageNumber method

Restituisce il numero di pagina della destinazione per nome.

```csharp
public int GetPageNumber(string destinameName, bool useCache)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| destinameName | String | Il nome della destinazione. |
| useCache | Boolean | Determina se la versione memorizzata nella cache della raccolta è utilizzata o meno. |

### Valore di ritorno

Il numero di pagina se la destinazione è stata trovata; altrimenti, -1.
