## HtmlSaveOptions.FontSavingModes enumeration

Enumera le modalità che possono essere usate per il salvataggio dei font referenziati nel PDF salvato.

```csharp
public enum FontSavingModes
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| AlwaysSaveAsWOFF | `0` | Tutti i font referenziati saranno salvati e referenziati come font WOFF. |
| AlwaysSaveAsTTF | `1` | Tutti i font referenziati saranno salvati e referenziati come font TTF. |
| AlwaysSaveAsEOT | `2` | Tutti i font referenziati saranno salvati e referenziati come font EOT. |
| SaveInAllFormats | `3` | Tutti i font referenziati saranno salvati (e referenziati nel CSS) come 3 file indipendenti: EOT, TTH, WOFF. Questo aumenta la dimensione dei dati di output ma rende l'output adatto alla stragrande maggioranza dei browser web. |
| DontSave | `4` | I font referenziati non saranno salvati. |
