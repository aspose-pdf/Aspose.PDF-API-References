## Stamp.Zoom property

Fattore di zoom del timbro. Consente di ridimensionare il timbro. Si noti che la coppia di proprietà ZoomX e ZoomY consente di impostare il fattore di zoom per ogni asse separatamente. L'impostazione di questa proprietà modifica entrambe le proprietà ZoomX e ZoomY. Se ZoomX e ZoomY sono diversi, la proprietà Zoom restituisce il valore di ZoomX.

```csharp
public double Zoom { get; set; }
```
