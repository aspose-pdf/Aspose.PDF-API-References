## HtmlSaveOptions.HtmlImageSavingInfo.HtmlHostPageNumber field

Indica al codice personalizzato a quale pagina del set generato di file HTML appartiene l'immagine salvata. Se la suddivisione in pagine è disattivata, questo valore contiene sempre '1' poiché in tal caso viene generata una sola pagina HTML.

public int HtmlHostPageNumber;
