## FloatingBox.IsNeedRepeating property

Ottiene o imposta un valore bool che indica se il paragrafo deve essere ripetuto nella pagina successiva. Il valore predefinito è false. L'attributo è valido solo quando sia il paragrafo stesso sia l'oggetto a cui si riferisce ReferenceParagraphID sono inclusi in RepeatingRows.

```csharp
public bool IsNeedRepeating { get; set; }
```
