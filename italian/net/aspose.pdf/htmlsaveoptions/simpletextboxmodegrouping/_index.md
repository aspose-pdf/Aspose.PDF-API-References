## HtmlSaveOptions.SimpleTextboxModeGrouping property

Questo attributo specifica un raggruppamento sequenziale di glifi e parole in stringhe. Ad esempio, i tag e le parole hanno ordine diverso nell'HTML convertito e si desidera che corrispondano. Questo parametro verrà applicato al documento solo quando il valore dell'attributo FixedLayout è true.

```csharp
public bool SimpleTextboxModeGrouping { get; set; }
```
