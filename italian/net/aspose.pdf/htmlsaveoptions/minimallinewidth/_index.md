## HtmlSaveOptions.MinimalLineWidth property

Questo attributo imposta la larghezza minima della linea del percorso grafico. Se lo spessore della linea è inferiore a 1 px, Adobe Acrobat lo arrotonda a questo valore. Pertanto questo attributo può essere usato per emulare questo comportamento nei browser HTML.

```csharp
public float MinimalLineWidth { get; set; }
```
