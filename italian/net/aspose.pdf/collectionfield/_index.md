## CollectionField class

Rappresenta una classe di campo schema della raccolta di documenti.

```csharp
public class CollectionField
```

## Proprietà

| Nome | Descrizione |
| --- | --- |
| [E](../../aspose.pdf/collectionfield/e/) { get; } | Restituisce un flag che indica se il processore PDF interattivo deve fornire supporto per la modifica del valore del campo. Valore predefinito: false |
| [FiledType](../../aspose.pdf/collectionfield/filedtype/) { get; } | Restituisce il tipo di valore di un campo in una raccolta di schema. Questo campo descrive il tipo di valore corrispondente a [`Subtype`](./subtype/). |
| [N](../../aspose.pdf/collectionfield/n/) { get; } | Restituisce il nome testuale del campo che deve essere presentato all'utente dal processore PDF interattivo |
| [O](../../aspose.pdf/collectionfield/o/) { get; } | Restituisce l'ordine relativo del nome del campo nell'interfaccia utente. I campi devono essere ordinati dal processore PDF interattivo in ordine crescente. |
| [Subtype](../../aspose.pdf/collectionfield/subtype/) { get; } | Restituisce il sottotipo di un valore di campo in una raccolta di schema. Il sottotipo del campo di raccolta o del campo relativo a file che questo dizionario descrive. Questa voce identifica il tipo di dati che deve essere memorizzato nel campo. |
| [V](../../aspose.pdf/collectionfield/v/) { get; } | Restituisce la visibilità iniziale del campo nell'interfaccia utente. Valore predefinito: true. |
