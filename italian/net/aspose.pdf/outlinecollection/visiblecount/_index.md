## OutlineCollection.VisibleCount property

Il conteggio è la somma del numero di elementi discendenti della struttura visibili a tutti i livelli. Nota: per favore non confondere con Count, che è il numero di elementi nella raccolta.

public override int VisibleCount { get; }
