## XImage.ImageMask property

Ottiene un flag che indica se l'immagine deve essere trattata come una maschera immagine (vedi 8.9.6, "Masked Images"). Se questo flag è true, il valore di BitsPerComponent deve essere 1 e Mask e ColorSpace non devono essere specificati; le aree non mascherate devono essere dipinte usando il colore corrente non di riempimento. Valore predefinito: false.

```csharp
public bool ImageMask { get; }
```

### Property Value

True se l'immagine è una maschera di immagine.
