## XImage.Name property

Ottiene o imposta il nome dell'immagine. Si prega di notare che se si cambia il nome dell'immagine che ha riferimenti nei contenuti della pagina, il documento potrebbe diventare non corretto. Si prega di usare il metodo **XImage.Rename** in questo caso.

```csharp
public string Name { get; set; }
```
