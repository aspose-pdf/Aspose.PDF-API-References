## ColumnInfo.ColumnSpacing property

Ottiene o imposta una stringa che contiene la spaziatura tra le colonne. Il valore di ciascuna spaziatura deve essere separato da uno spazio. L'unità predefinita è il punto, ma sono supportati anche cm e pollici. Per esempio, "120 2.5cm 1.5inch".

```csharp
public string ColumnSpacing { get; set; }
```

## Osservazioni

Se questa proprietà non è impostata, verrà utilizzato il valore predefinito 0 per ogni spaziatura.
