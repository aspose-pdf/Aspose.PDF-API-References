## PsLoadOptions.ConvertFontsToTTF property

Specifica se salvare i font non TrueType in TTF. Riduce in modo significativo il volume del documento risultante nella conversione da PS a PDF e aumenta la velocità di conversione dei file PS con una grande quantità di testo in font non TrueType in qualsiasi formato di output. Tuttavia, si verifica un piccolo spostamento verticale del testo durante la conversione del file PostSctipt in immagine.

public bool ConvertFontsToTTF { get; set; }
