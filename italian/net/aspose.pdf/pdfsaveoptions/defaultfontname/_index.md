## PdfSaveOptions.DefaultFontName property

Nome del carattere usato per impostazione predefinita per i caratteri assenti sul computer. Quando il documento PDF salvato contiene caratteri che non sono disponibili né nel documento stesso né sul dispositivo, l'API sostituisce questi caratteri con il carattere predefinito (se il carattere con `DefaultFontName` è presente sul dispositivo).

```csharp
public string DefaultFontName { get; set; }
```
