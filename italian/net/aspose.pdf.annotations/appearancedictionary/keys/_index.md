## AppearanceDictionary.Keys property

Ottiene le chiavi del dizionario. Se il dizionario di aspetto contiene sottodizionari, allora `Keys` contiene valori (N&#x7C;R&#x7C;D).state, dove N - aspetto normale, R - aspetto rollover, D - aspetto premuto e state - il nome dello stato (ad es. On, Off per le caselle di controllo).

public ICollection<string> Keys { get; }
