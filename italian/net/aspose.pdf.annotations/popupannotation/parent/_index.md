## PopupAnnotation.Parent property

Ottiene o imposta l'annotazione padre con cui questa annotazione popup deve essere associata. Se questa voce è presente, le voci Contents, M, C e T dell'annotazione padre sovrascriveranno quelle dell'annotazione popup stessa.

public Annotation Parent { get; set; }
