## LineEnding enumeration

Elenca gli stili di terminazione della linea da utilizzare nel disegno della linea.

```csharp
public enum LineEnding
```

### Valori

| Nome | Valore | Descrizione |
| --- | --- | --- |
| None | `0` | Nessuna terminazione della linea. |
| Square | `1` | Un quadrato riempito con il colore interno dell'annotazione, se presente. |
| Circle | `2` | Un cerchio riempito con il colore interno dell'annotazione, se presente. |
| Diamond | `3` | Una forma a diamante riempita con il colore interno dell'annotazione, se presente. |
| OpenArrow | `4` | Due linee corte che si incontrano formando un angolo acuto per creare una freccia aperta. |
| ClosedArrow | `5` | Due linee corte che si incontrano formando un angolo acuto come nello stile OpenArrow e collegate da una terza linea per formare una freccia chiusa triangolare riempita con il colore interno dell'annotazione, se presente. |
| Butt | `6` | Una linea corta all'estremità perpendicolare alla linea stessa. |
| ROpenArrow | `7` | Due linee corte nella direzione opposta rispetto a OpenArrow. |
| RClosedArrow | `8` | Una freccia chiusa triangolare nella direzione opposta rispetto a ClosedArrow. |
| Slash | `9` | Una linea corta all'estremità circa 30 gradi in senso orario rispetto alla perpendicolare della linea stessa. |
