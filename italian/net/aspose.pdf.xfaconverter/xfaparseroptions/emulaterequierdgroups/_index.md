## XfaParserOptions.EmulateRequierdGroups property

Se questa proprietà è true allora verranno disegnati rettangoli rossi aggiuntivi per i "excluded groups" Xfa richiesti. Questa proprietà è stata introdotta perché l'assenza di analoghi dei gruppi esclusi durante la conversione della rappresentazione Xfa dei moduli allo standard. È false per impostazione predefinita.

```csharp
public bool EmulateRequierdGroups { get; set; }
```
