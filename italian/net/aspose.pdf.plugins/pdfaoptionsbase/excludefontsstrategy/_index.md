## PdfAOptionsBase.ExcludeFontsStrategy property

Ottiene o imposta la strategia per rimuovere i font al fine di ridurre al minimo la dimensione del file di output durante il processo di conversione PDF/A.

```csharp
public RemoveFontsStrategy ExcludeFontsStrategy { get; set; }
```

### Property Value

La strategia per rimuovere i font. Può essere uno dei valori dell'enumerazione [`RemoveFontsStrategy`](../../../aspose.pdf/pdfformatconversionoptions.removefontsstrategy/). L'impostazione predefinita è la combinazione di SubsetFonts e RemoveDuplicatedFonts.

## Osservazioni

Questa proprietà consente di controllare come i font vengono gestiti durante il processo di conversione. È possibile scegliere di rimuovere i font duplicati, rimuovere i font simili con larghezze diverse o creare sottoinsiemi di font.
