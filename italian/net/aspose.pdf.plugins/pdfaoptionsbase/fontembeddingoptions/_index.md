## PdfAOptionsBase.FontEmbeddingOptions property

Ottiene le opzioni per elaborare i font che non possono essere incorporati nel Document.

```csharp
public FontEmbeddingOptions FontEmbeddingOptions { get; }
```

### Property Value

Le opzioni di incorporamento dei caratteri.

## Osservazioni

Lo standard PDF/A richiede che tutti i caratteri siano incorporati nel documento. Questa proprietà fornisce opzioni per gestire i casi in cui non è possibile incorporare alcuni caratteri perché assenti sul PC di destinazione.
