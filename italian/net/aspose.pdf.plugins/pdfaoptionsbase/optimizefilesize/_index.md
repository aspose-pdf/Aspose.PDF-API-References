## PdfAOptionsBase.OptimizeFileSize property

Ottiene o imposta un valore che indica se provare a ridurre la dimensione del file durante il processo di conversione PDF/A.

```csharp
public bool OptimizeFileSize { get; set; }
```

### Property Value

`true` se la dimensione del file deve essere ridotta il più possibile; altrimenti, `false`.

## Osservazioni

Quando impostato su `true`, il processo di conversione cercherà di minimizzare la dimensione del file risultante. Questo potrebbe influire sulle prestazioni del processo di conversione.
