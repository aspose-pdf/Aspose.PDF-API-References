## TextSearchOptions.IgnoreShadowText property

Ottiene o imposta l'indicazione che i frammenti di testo che rappresentano l'ombra del testo normale saranno ignorati durante la ricerca. true - indica che il testo in ombra non verrà trovato (prova questa opzione se la ricerca di testo restituisce frammenti duplicati in posizioni vicine). false - indica che il testo in ombra verrà trovato insieme al testo normale (valore predefinito).

```csharp
public bool IgnoreShadowText { get; set; }
```
