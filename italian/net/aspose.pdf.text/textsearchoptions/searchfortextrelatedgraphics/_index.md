## TextSearchOptions.SearchForTextRelatedGraphics property

Ottiene o imposta il valore che consente la ricerca di grafica correlata al testo (sottolineatura, sfondo ecc.) durante la ricerca del testo. true - la ricerca di grafica correlata al testo verrà eseguita (valore predefinito). false - gli elementi grafici presenti nel documento sorgente saranno ignorati. Impostare questa opzione in caso di problemi di prestazioni o se non è necessario gestire sottolineature, sfondi o ritagli.

```csharp
public bool SearchForTextRelatedGraphics { get; set; }
```
