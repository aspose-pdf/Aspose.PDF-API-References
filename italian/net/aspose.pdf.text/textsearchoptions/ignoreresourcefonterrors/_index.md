## TextSearchOptions.IgnoreResourceFontErrors property

Ottiene o imposta l'indicazione che gli errori relativi all'assenza del carattere saranno ignorati dall'assorbitore di testo (frammento). true - indica che gli errori di assenza del carattere saranno ignorati. I segmenti di testo che fanno riferimento a risorse errate saranno saltati durante l'elaborazione. false (predefinito) - l'errore di assenza del carattere interromperà l'elaborazione generando un'eccezione.

```csharp
public bool IgnoreResourceFontErrors { get; set; }
```
