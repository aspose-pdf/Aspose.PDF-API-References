## TextSearchOptions.StoredGraphicElementsMaxCount property

Ottiene o imposta il valore che limita la ricerca di grafica correlata al testo (sottolineatura, sfondo ecc.) su una pagina per il numero specificato di elementi. Il valore predefinito è 250. Impostare un valore inferiore in caso di problemi di prestazioni, provare un valore maggiore se alcuni elementi grafici non sono stati trovati.

```csharp
public int StoredGraphicElementsMaxCount { get; set; }
```
