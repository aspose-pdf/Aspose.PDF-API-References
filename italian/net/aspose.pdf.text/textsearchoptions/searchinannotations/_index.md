## TextSearchOptions.SearchInAnnotations property

Ottiene o imposta il valore che consente la ricerca di testo nelle Annotations. true - il testo sarà ricercato nelle Annotations. false - il testo nelle Annotations non sarà analizzato da TextFragmentAbsorber.

```csharp
public bool SearchInAnnotations { get; set; }
```
