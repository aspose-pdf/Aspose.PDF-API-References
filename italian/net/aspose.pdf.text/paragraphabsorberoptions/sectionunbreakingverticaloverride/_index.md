## ParagraphAbsorberOptions.SectionUnbreakingVerticalOverride property

Ottiene o imposta la lunghezza massima della zona con 'livello di riempimento zero' che non sarà considerata come interruzione di sezione verticale reale (come frazione della larghezza/altezza di una pagina). Il valore predefinito è 0.005.

```csharp
public double SectionUnbreakingVerticalOverride { get; set; }
```
