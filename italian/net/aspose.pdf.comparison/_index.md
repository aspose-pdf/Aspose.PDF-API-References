## Classi

| Classe | Descrizione |
| --- | --- |
| [ComparisonOptions](./comparisonoptions/) | Rappresenta una classe di opzioni per il confronto di documenti PDF. |
| [DiffOperation](./diffoperation/) | Rappresenta una classe di operazione di differenza. |
| [DocumentComparisonStatistics](./documentcomparisonstatistics/) | Rappresenta una classe di statistiche per il confronto di documenti. |
| [GraphicalPdfComparer](./graphicalpdfcomparer/) | Rappresenta una classe per confrontare graficamente i documenti PDF. Deve essere utilizzata per cercare piccole modifiche, principalmente di natura grafica. Per confrontare le modifiche al contenuto del testo, utilizzare altre classi di confronto PDF. |
| [HtmlDiffOutputGenerator](./htmldiffoutputgenerator/) | Rappresenta una classe per generare la rappresentazione HTML delle differenze di testo. Le interruzioni di riga eliminate sono indicate dal segno di paragrafo. |
| [ImagesDifference](./imagesdifference/) | Rappresenta la classe risultato del confronto di due pagine PDF. |
| [JsonDiffOutputGenerator](./jsondiffoutputgenerator/) | Rappresenta una classe per visualizzare i risultati del confronto di documenti o pagine PDF in formato JSON. |
| [MarkdownDiffOutputGenerator](./markdowndiffoutputgenerator/) | Rappresenta una classe per generare la rappresentazione markdown delle differenze di testo. A causa della sintassi markdown, non è possibile mostrare le modifiche ai caratteri di spazio. La selezione delle modifiche comporta l'aggiunta di caratteri di spazio intorno alla formattazione, altrimenti il visualizzatore markdown non visualizzerà correttamente il testo. Le interruzioni di riga eliminate sono indicate dal segno di paragrafo -. |
| [OutputTextStyle](./outputtextstyle/) | Rappresenta una classe di set di stili per evidenziare le modifiche al testo. |
| [PdfOutputGenerator](./pdfoutputgenerator/) | Rappresenta una classe per generare la rappresentazione PDF delle differenze di testo. |
| [SideBySideComparisonOptions](./sidebysidecomparisonoptions/) | Rappresenta una classe di opzioni per confrontare documenti con output affiancato. |
| [SideBySidePdfComparer](./sidebysidepdfcomparer/) |  |
| [TextItemComparisonStatistics](./textitemcomparisonstatistics/) | Rappresenta una classe di statistiche per il confronto del testo. |
| [TextPdfComparer](./textpdfcomparer/) | Rappresenta una classe per il confronto di due pagine PDF o documenti PDF. |
| [TextStyle](./textstyle/) | Rappresenta una classe di stile del testo. |
