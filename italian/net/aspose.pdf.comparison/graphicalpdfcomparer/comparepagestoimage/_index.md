## GraphicalPdfComparer.ComparePagesToImage method

Confronta le pagine graficamente. Il risultato del confronto è inserito in un'immagine.

```csharp
public void ComparePagesToImage(Page page1, Page page2, string resultImagePath)
```

| Parametro | Tipo | Descrizione |
| --- | --- | --- |
| page1 | Page | La prima pagina da confrontare. |
| page2 | Page | La seconda pagina da confrontare. |
| resultImagePath | String | Il percorso del file immagine di destinazione. |

### Eccezioni

| eccezione | condizione |
| --- | --- |
| ArgumentException | Se le pagine confrontate hanno dimensioni diverse. Se resultImagePath è nullo o una stringa vuota. Il formato di salvataggio dell'immagine è sconosciuto. |
