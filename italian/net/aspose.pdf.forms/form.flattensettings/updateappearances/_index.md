## Form.FlattenSettings.UpdateAppearances property

Se impostato, tutte le apparenze dei campi verranno rigenerate prima dell'appiattimento. Questa opzione può aiutare se il campo è stato appiattito in modo errato. Questa opzione può ridurre le prestazioni. Per impostazione predefinita è impostata su false.

public bool UpdateAppearances { get; set; }
