## Form.EmulateRequierdGroups property

Se questa proprietà è true, verranno disegnati rettangoli rossi aggiuntivi per i contenitori degli elementi Xfa exclGroup richiesti. Questa proprietà è stata introdotta a causa dell'assenza di analoghi per l'exclGroup durante la conversione della rappresentazione Xfa dei moduli allo standard. È false per impostazione predefinita.

```csharp
public bool EmulateRequierdGroups { get; set; }
```
