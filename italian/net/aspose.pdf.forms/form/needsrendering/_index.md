## Form.NeedsRendering property

Restituisce un valore che indica se il documento richiede la rimozione del modulo XFA dinamico. Questa proprietà è stata introdotta per determinare se [`IgnoreNeedsRendering`](../ignoreneedsrendering/) deve essere usato per rimuovere il modulo XFA nei casi in cui il modulo XFA è presente e `NeedsRendering` è false.

```csharp
public bool NeedsRendering { get; }
```
