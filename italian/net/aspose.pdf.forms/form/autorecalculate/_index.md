## Form.AutoRecalculate property

Se impostato, tutti i campi del modulo verranno ricalcolati quando qualsiasi campo viene modificato. Il valore predefinito è true. Impostare su false per aumentare le prestazioni durante la compilazione del modulo con un gran numero di campi calcolati.

```csharp
public bool AutoRecalculate { get; set; }
```
