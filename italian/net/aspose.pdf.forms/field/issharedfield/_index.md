## Field.IsSharedField property

Proprietà per il supporto del generatore. Utilizzata quando il campo è aggiunto all'intestazione o al piè di pagina. Se true, questo campo verrà creato una sola volta e il suo aspetto sarà visibile su tutte le pagine del Document. Se false, verrà creato un campo separato per ogni pagina del Document.

public bool IsSharedField { get; set; }
