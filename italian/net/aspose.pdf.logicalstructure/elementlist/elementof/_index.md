## ElementList indexer

Restituisce un elemento all'indice specificato.

```csharp
public virtual Element ElementOf[int index] { get; }
```

| Parametro | Descrizione |
| --- | --- |
| index | L'indice nella lista degli elementi. |

### Valore di ritorno

L'Elemento con l'indice specificato nella collezione. Se l'indice è maggiore o uguale al numero di elementi nella lista, questo restituisce null.
