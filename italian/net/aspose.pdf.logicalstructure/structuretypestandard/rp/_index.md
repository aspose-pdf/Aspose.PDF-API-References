## StructureTypeStandard.RP field

(Ruby punctuation) Punteggiatura che circonda il testo dell'annotazione ruby. Viene usata solo quando un'annotazione ruby non può essere formattata correttamente in stile ruby e invece è formattata come commento normale, o quando è formattata come warichu. Contiene testo (di solito una singola parentesi SINISTRA o DESTRA o un carattere di parentesi simile).

```csharp
public static readonly StructureTypeStandard RP;
```
