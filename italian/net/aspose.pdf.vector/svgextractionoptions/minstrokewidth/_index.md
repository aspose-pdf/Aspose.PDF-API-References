## SvgExtractionOptions.MinStrokeWidth property

Ottiene o imposta la larghezza minima del tratto che verrà utilizzata nello SVG risultante. Se il PDF utilizza una larghezza del tratto più sottile, verrà sostituita con questa larghezza. Il valore predefinito è 0.5.

```csharp
public double MinStrokeWidth { get; set; }
```

## Osservazioni

Il valore è espresso in unità di spazio utente trasformato della pagina PDF convertita. Per impostazione predefinita 1 unità di spazio utente corrisponde a 1/72 di pollice (0,35 mm), ma può essere sovrascritto dal documento PDF. Le trasformazioni possono influire sulla larghezza minima effettiva nello SVG generato.
