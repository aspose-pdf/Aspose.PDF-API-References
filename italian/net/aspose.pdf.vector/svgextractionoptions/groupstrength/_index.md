## SvgExtractionOptions.GroupStrength property

Ottiene e imposta un'opzione La forza del raggruppamento dei sottopercorsi in immagini. Consente di configurare il grado di raggruppamento dei sottopercorsi. L'intervallo di valori è da 0 a 1. Un valore 0 corrisponde all'opzione [`ExtractEverySubPathToSvg`](../extracteverysubpathtosvg/) abilitata. Un valore 1 creerà un'unica immagine per tutti i percorsi vettoriali nella pagina. L'opzione ha effetto quando [`AutoGrouping`](../autogrouping/) è false. Il valore predefinito è `0.8`.

```csharp
public double GroupStrength { get; set; }
```
