## ImageCompressionOptions.Version property

Versione dell'algoritmo di compressione. I valori possibili sono: 1. compressione standard, 2. veloce (compressione migliorata che è più veloce della standard ma potrebbe non essere applicabile a tutte le immagini), 3. mista (la compressione standard viene applicata alle immagini che non possono essere compresse dall'algoritmo più veloce; questo può fornire la migliore compressione ma è più lenta rispetto all'algoritmo \"fast\". La versione \"Fast\" non è applicabile al ridimensionamento delle immagini (verrà utilizzato il metodo standard). Il valore predefinito è \"Standard\").

```csharp
public ImageCompressionVersion Version { get; set; }
```
