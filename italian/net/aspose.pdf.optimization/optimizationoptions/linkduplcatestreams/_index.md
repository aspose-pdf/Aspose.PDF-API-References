## OptimizationOptions.LinkDuplcateStreams property

Se questo flag è impostato su true, Resource streams verranno analizzati. Se vengono trovati flussi duplicati (cioè se il contenuto del flusso è uguale), allora questi flussi verranno memorizzati come un unico oggetto. Questo consente di ridurre la dimensione del documento in alcuni casi (ad esempio, quando lo stesso documento è stato concatenato più volte).

```csharp
public bool LinkDuplcateStreams { get; set; }
```
