Il **Aspose.Pdf.Optimization** è uno spazio dei nomi per le classi che gestiscono il processo di ottimizzazione del documento.

## Classi

| Classe | Descrizione |
| --- | --- |
| [ImageCompressionOptions](./imagecompressionoptions/) | La classe contiene un insieme di opzioni per la compressione delle immagini. |
| [OptimizationOptions](./optimizationoptions/) | Classe che descrive l'algoritmo di ottimizzazione del documento. Un'istanza di questa classe può essere usata come parametro del metodo OptimizeResources(). |
## Enumerazione

| Enumerazione | Descrizione |
| --- | --- |
| [ImageCompressionVersion](./imagecompressionversion/) | Descrive le versioni dell'algoritmo di compressione delle immagini. |
| [ImageEncoding](./imageencoding/) | Tipi di codifica delle immagini. |
