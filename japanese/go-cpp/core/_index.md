## Core PDF functions

| 名前 | 説明 |
| -------------- | -------------- |
| [New](./new/) | 新しい PDF ドキュメントを作成します。 |
| [Open](./open/) | ファイル名で PDF ドキュメントを開きます。 |
| [Save](./save/) | 以前に開いた PDF ドキュメントを保存します。 |
| [SaveAs](./saveas/) | 以前に開いた PDF ドキュメントを新しいファイル名で保存します。 |
| [Close](./close/) | PDF ドキュメントの割り当てられたリソースを解放します。 |
| [SetLicense](./setlicense/) | ファイル名でライセンスを設定します。 |
| [ExtractText](./extracttext/) | PDF ドキュメントの内容をプレーンテキストとして返します。 |
| [WordCount](./wordcount/) | PDF ドキュメントの単語数を返します。 |
| [CharacterCount](./charactercount/) | PDF ドキュメントの文字数を返します。 |
| [Append](./append/) | 別の PDF ドキュメントからページを追加します。 |
| [AppendPages](./appendpages/) | 別の PDF ドキュメントから選択したページを追加します。 |
| [MergeDocuments](./mergedocuments/) | 提供された PDF ドキュメントを結合して新しい PDF ドキュメントを作成します。 |
| [SplitDocument](./splitdocument/) | ソース PDF ドキュメントからページを抽出して複数の新しい PDF ドキュメントを作成します。 |
| [Split](./split/) | 現在の PDF ドキュメントからページを抽出して複数の新しい PDF ドキュメントを作成します。 |
| [SplitAtPage](./splitatpage/) | PDF ドキュメントを 2 つの新しい PDF ドキュメントに分割します。 |
| [SplitAt](./splitat/) | 現在の PDF ドキュメントを 2 つの新しい PDF ドキュメントに分割します。 |
| [Bytes](./bytes/) | PDF ドキュメントの内容をバイトスライスとして返します。 |
| [GetMetaInfo](./getmetainfo/) | PDF ドキュメントのメタ情報の値を取得します。 |
| [SetMetaInfo](./setmetainfo/) | PDFドキュメントのメタ情報の値を設定します.. |
| [ClearMetaInfo](./clearmetainfo/) | PDFドキュメントのすべてのメタ情報の値をクリアします.. |
| [IsLinearized](./islinearized/) | ドキュメントがリニアライズされているかどうかを示す値を取得します。 |
| [PageAdd](./pageadd/) | PDFドキュメントに新しいページを追加します。 |
| [PageInsert](./pageinsert/) | PDFドキュメントの指定された位置に新しいページを挿入します。 |
| [PageDelete](./pagedelete/) | PDFドキュメントの指定されたページを削除します。 |
| [PageCount](./pagecount/) | PDFドキュメントのページ数を返します。 |
| [PageWordCount](./pagewordcount/) | PDFドキュメントの指定ページの単語数を返します。 |
| [PageCharacterCount](./pagecharactercount/) | PDFドキュメントの指定ページの文字数を返します。 |
| [PageIsBlank](./pageisblank/) | PDFドキュメントのページが空白かどうかを返します。 |


## Detailed Description

PDF ファイルを扱うためのコア機能。
