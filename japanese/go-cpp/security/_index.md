## Security

| 関数 | 説明 |
| -------- | ----------- |
| [OpenWithPassword](./openwithpassword/) | パスワードで保護されたPDFドキュメントを開きます。 |
| [Encrypt](./encrypt/) | PDFドキュメントを暗号化します。 |
| [Decrypt](./decrypt/) | PDFドキュメントの暗号化を解除します。 |
| [SetPermissions](./setpermissions/) | PDFドキュメントの権限を設定します。 |
| [GetPermissions](./getpermissions/) | PDFドキュメントの現在の権限を取得します。 |
| [IsEncrypted](./isencrypted/) | PDFドキュメントの暗号化状態を取得します。 |
| [SignPKCS7](./signpkcs7/) | PKCS#7 デジタル署名を使用して PDFドキュメントに署名します。 |
| [SignPKCS7Detached](./signpkcs7detached/) | PKCS#7 デタッチド デジタル署名を使用して PDFドキュメントに署名します。 |
| [IsSigned](./issigned/) | PDFドキュメントの署名状態を取得します。 |
| [RemoveSigns](./removesigns/) | PDFドキュメントから署名を削除します。 |
