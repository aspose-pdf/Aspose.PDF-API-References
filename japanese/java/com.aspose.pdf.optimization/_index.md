com.aspose.pdf.optimization は、ドキュメント最適化プロセスの管理のためのクラスを提供するパッケージです。

## クラス

| クラス | 説明 |
| --- | --- |
| [ImageCompressionOptions](./imagecompressionoptions/) | クラスは画像圧縮の設定オプションを含みます。 |
| [ImageCompressionVersion](./imagecompressionversion/) | 画像圧縮アルゴリズムのバージョンを説明します。 |
| [ImageEncoding](./imageencoding/) | 画像エンコーディングの種類。 |
| [OptimizationOptions](./optimizationoptions/) | ドキュメント最適化アルゴリズムを記述するクラス。このクラスのインスタンスは OptimizeResources() メソッドのパラメータとして使用できます。 |
