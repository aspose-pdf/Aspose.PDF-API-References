## クラス

| クラス | 説明 |
| --- | --- |
| [ExtractedFragmentsProcessorBase](./extractedfragmentsprocessorbase/) | 抽出されたフラグメントプロセッサの基底クラスを表します。 |
| [IgnoreSpacesFragmentsProcessor](./ignorespacesfragmentsprocessor/) | 空白無視モードでテキストフラグメントを処理するクラスを表します。このクラスはすべての空白を無視し、個々の単語をフラグメントとしてハイライトします。 |
| [NormalFragmentProcessor](./normalfragmentprocessor/) | 通常モードでテキストフラグメントを処理するクラスを表します。このクラスはフラグメント内の空白のみを考慮します。 |
| [ParseSpacesFragmentsProcessor](./parsespacesfragmentsprocessor/) | スペース解析モードでテキストフラグメントを処理するクラスを表します。このクラスはフラグメント間の距離に基づいてスペースを認識します。 |
