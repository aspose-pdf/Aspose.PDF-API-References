Binary Flag は、他のオプションと組み合わせてページのサイズとレイアウトを決定するフラグを指定します。

## フィールド

| フィールド | 説明 |
| --- | --- |
| [FitToWidestContentWidth](#FitToWidestContentWidth) | ページ幅が指定されたページ幅ではなく、コンテンツサイズ自体から決定されることを示します。 |
| [None](#None) | HtmlPageLayoutOption がページのサイズやレイアウトに影響しないことを示すデフォルト値です。 |
| [ScaleToPageWidth](#ScaleToPageWidth) | 文書の内容がページに合わせて拡大縮小されることを示します。 |
