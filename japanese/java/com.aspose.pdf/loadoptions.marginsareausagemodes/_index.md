変換時（HTML、EPUB など）の余白領域の使用モードを表し、インポートされたフォーマットの余白使用に関する指示の処理方法を定義します。

## フィールド

| フィールド | 説明 |
| --- | --- |
| [NeverPutContentOnMarginArea](#NeverPutContentOnMarginArea) | このモードは余白領域の使用を厳格に禁止するため、CSSやソース文書の形式が許可または要求していても、コンバータはレンダリング時に余白領域を決して使用しません。 |
| [PutContentOnMarginAreaIfNecessary](#PutContentOnMarginAreaIfNecessary) | このモードでは、コンバータはインポートされた文書（例：インポートされたHTMLのCSS）の形式に従って余白領域の使用を行います。したがって、インポートされた文書の形式がレンダリング時に余白領域の使用を要求する場合、コンバータはそれを許可します。 |

### NeverPutContentOnMarginArea {#NeverPutContentOnMarginArea}
```
public static final int NeverPutContentOnMarginArea
```

このモードは余白領域の使用を厳格に禁止するため、CSSやソース文書の形式が許可または要求していても、コンバータはレンダリング時に余白領域を決して使用しません。

### PutContentOnMarginAreaIfNecessary {#PutContentOnMarginAreaIfNecessary}
```
public static final int PutContentOnMarginAreaIfNecessary
```

このモードでは、コンバータはインポートされた文書（例：インポートされたHTMLのCSS）の形式に従って余白領域の使用を行います。したがって、インポートされた文書の形式がレンダリング時に余白領域の使用を要求する場合、コンバータはそれを許可します。
