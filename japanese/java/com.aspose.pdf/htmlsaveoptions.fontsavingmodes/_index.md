保存されたPDFで参照されるフォントの保存に使用できるモードを列挙します

## フィールド

| フィールド | 説明 |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | 参照されているすべてのフォントは EOT フォントとして保存および参照されます。 |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | 参照されているすべてのフォントは TTF フォントとして保存および参照されます。 |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | 参照されているすべてのフォントは WOFF フォントとして保存および参照されます。 |
| [DontSave](#DontSave) | 参照されているフォントは保存されません。 |
| [SaveInAllFormats](#SaveInAllFormats) | 参照されているすべてのフォントは、CSS で参照される形で、EOT、TTH、WOFF の 3 つの独立したファイルとして保存されます。これにより出力データのサイズは増加しますが、圧倒的多数のウェブブラウザでの使用に適した出力になります。 |

### SaveInAllFormats {#SaveInAllFormats}
```

```

参照されているすべてのフォントは、CSS で参照される形で、EOT、TTH、WOFF の 3 つの独立したファイルとして保存されます。これにより出力データのサイズは増加しますが、圧倒的多数のウェブブラウザでの使用に適した出力になります。
