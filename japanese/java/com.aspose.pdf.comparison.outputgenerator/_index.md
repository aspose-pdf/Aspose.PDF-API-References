## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [IFileOutputGenerator](./ifileoutputgenerator/) | テキスト間の差分をファイルに出力するためのインターフェイスを表します。 |
| [IStringOutputGenerator](./istringoutputgenerator/) | テキスト間の差分を文字列に出力するためのインターフェイスを表します。 |

| クラス | 説明 |

| [InternalHelper](./internalhelper/) |  |
| [IVentureLicenseTarget](./iventurelicensetarget/) |  |
| [MarkdownDiffOutputGenerator](./markdowndiffoutputgenerator/) | テキスト差分のMarkdown表現を生成するクラスを表します。Markdown構文のため、空白文字の変更を表示することはできません。変更を選択すると、フォーマットの前後に空白文字が追加されます。そうしないと、Markdownビューアがテキストを正しく表示できません。削除された改行は - 段落記号で示されます。 |
| [OutputTextStyle](./outputtextstyle/) | テキスト変更をマークするためのスタイルセットクラスを表します。 |
