証明書検証の検証ステータスを表します。この列挙は証明書検証の可能な結果を定義します: - Valid: 証明書が正常に検証されたことを示します。 - Invalid: 証明書検証が失敗したことを示します。 - Undefined: 検証プロセスが結論に至らなかったか、実行されなかったことを示します。

## フィールド

| [Valid](#Valid) | 証明書が正常に検証されたことを示します。 |
