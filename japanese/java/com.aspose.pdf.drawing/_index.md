com.aspose.pdf.drawing パッケージは、弧、線、円などのグラフィックプリミティブを記述するクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [Arc](./arc/) | 弧を表します。 |
| [Circle](./circle/) | 円を表します。 |
| [Curve](./curve/) | ベジエ曲線を表します。 |
| [Ellipse](./ellipse/) | 楕円を表します。 |
| [GradientAxialShading](./gradientaxialshading/) | グラデーション軸シェーディングクラスを表します。 |
| [GradientRadialShading](./gradientradialshading/) | グラデーション放射シェーディングタイプを表します。 |
| [Graph](./graph/) | グラフ - グラフィックジェネレータ段落を表します。 |
| [InternalHelper](./internalhelper/) | 内部クラス |
| [Line](./line/) | 線を表します。 |
| [Path](./path/) | 弧を表します。 |
| [PatternColorSpace](./patterncolorspace/) | 基本パターンクラスを表します。 |
| [Rectangle](./rectangle/) | 矩形を表します。 |
| [Shape](./shape/) | 形状 - 基本グラフィックオブジェクトを表します。 |
