com.aspose.pdf.markdownoptions 名前空間は、Markdown 変換のための特定のオプションクラスを含みます。

## クラス

| クラス | 説明 |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | 強調と太字強調の利用可能なシリアライズスタイルを定義します。仕様については CommonMark - Emphasis and strong emphasis を参照してください。 |
| [HeadingLevels](./headinglevels/) | フォントサイズに基づくヘッダーレベルを操作するクラスを表します。 |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | ヘッダー認識戦略のタイプを表します。 |
| [HeadingStyle](./headingstyle/) | 見出しの利用可能なシリアライズスタイルを定義します。仕様については、CommonMark - ATX headings および CommonMark - Setext headings を参照してください。 |
| [LineBreakStyle](./linebreakstyle/) | ファイルの改行スタイルの可能性を表します。 |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Markdown 形式でのドキュメント保存オプションクラスを表します。 |
