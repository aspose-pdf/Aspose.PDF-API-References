見出しの利用可能なシリアライズスタイルを定義します。仕様については、CommonMark - ATX headings および CommonMark - Setext headings を参照してください。

## フィールド

| フィールド | 説明 |
| --- | --- |
| [Atx](#Atx) | 見出しの前に '#' を付けます |
| [Setext](#Setext) | アンダースコアレベル1および2の見出しはそれぞれ "======" と "------" で表され、Setext 見出しはレベル1と2の見出しでのみ使用可能です。見出しスタイルが Setext に設定されていても、レベル3以上の見出しには Atx スタイルが使用されます。 |

### Atx {#Atx}
```
public static final int Atx
```

### Setext {#Setext}
```
public static final int Setext
```

アンダースコアレベル1および2の見出しはそれぞれ "======" と "------" で表され、Setext 見出しはレベル1と2の見出しでのみ使用可能です。見出しスタイルが Setext に設定されていても、レベル3以上の見出しには Atx スタイルが使用されます。
