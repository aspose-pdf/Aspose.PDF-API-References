com.aspose.pdf.printing パッケージは、印刷プロセスの設定に使用されるクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [CustomPrintEventArgs](./customprinteventargs/) | PdfViewer.getCustomPrintDelegate() イベントに対するデータを提供します。 |
| [DuplexKind](./duplexkind/) | プリンターの両面印刷設定を指定します。 |
| [PdfPrinterResolution](./pdfprinterresolution/) | プリンターがサポートする解像度を表します。 |
| [PdfPrinterResolutionKind](./pdfprinterresolutionkind/) | プリンターの解像度を指定します。 |
| [PdfPrinterSettings](./pdfprintersettings/) | ドキュメントがどのように印刷されるかに関する情報を指定します。これには印刷するプリンターも含まれます。 |
| [PdfPrintRange](./pdfprintrange/) | 印刷するドキュメントの部分を指定します。 |
| [PrinterMargins](./printermargins/) | 印刷されたページの余白の寸法を指定します。 |
| [PrinterPaperKind](./printerpaperkind/) | 標準用紙サイズを指定します。 |
| [PrintPageSettings](./printpagesettings/) | 単一の印刷ページに適用される設定を指定します。 |
| [PrintPaperSize](./printpapersize/) | 用紙のサイズを指定します。 |
| [PrintPaperSizes](./printpapersizes/) | 標準用紙サイズを表します。 |
| [PrintPaperSource](./printpapersource/) | プリンターが用紙を取得する用紙トレイを指定します。 |
| [PrintPaperSourceKind](./printpapersourcekind/) | 標準用紙ソースです。 |
| [PrintPaperSources](./printpapersources/) | 一般的な用紙ソースを表す事前定義された {@link PrintPaperSource} インスタンスのセットを提供します。このクラスは継承できません。 |
