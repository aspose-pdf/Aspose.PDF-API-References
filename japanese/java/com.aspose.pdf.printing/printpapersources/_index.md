一般的な用紙ソースを表す事前定義された {@link PrintPaperSource} インスタンスのセットを提供します。このクラスは継承できません。

## フィールド

| フィールド | 説明 |
| --- | --- |
| [AutomaticFeed](#AutomaticFeed) | 自動給紙の紙ソースを表します。 |
| [Cassette](#Cassette) | プリンターの用紙カセットを表します。 |
| [Envelope](#Envelope) | 自動封筒給紙ソースを表します。 |
| [FormSource](#FormSource) | プリンターのデフォルトトレイを表します。 |
| [LargeCapacity](#LargeCapacity) | プリンターの大容量トレイを表します。 |
| [LargeFormat](#LargeFormat) | 大判用紙用トレイを表します。 |
| [Lower](#Lower) | プリンターの下部トレイを表します。 |
| [Manual](#Manual) | 手動給紙ソースを表します。 |
| [ManualFeedEnvelope](#ManualFeedEnvelope) | 手動封筒給紙ソースを表します。 |
| [Middle](#Middle) | プリンターの中間トレイを表します。 |
| [SmallFormat](#SmallFormat) | 小型用紙用トレイを表します。 |
| [TractorFeed](#TractorFeed) | トラクタ給紙連続紙ソースを表します。 |
| [Upper](#Upper) | プリンターの最上部トレイ、またはプリンターにトレイが1つしかない場合はデフォルトトレイを表します。 |
