com.aspose.pdf.signatures パッケージは、署名機能のためのクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [CompromiseCheckResult](./compromisecheckresult/) | 文書のデジタル署名が改ざんされていないかチェックするクラスを表します。 |
| [InternalHelper](./internalhelper/) |  |
| [SignaturesCompromiseDetector](./signaturescompromisedetector/) | 文書の改ざん署名をチェックするクラスを表します。検出器は既知の署名改ざん手法のみをチェックします。検証は署名が改ざんされていないことを 100% 保証できず、テスト対象外の新しい未知の改ざん手法に対しては偽陰性結果になる可能性があります。 |
| [SignaturesCoverage](./signaturescoverage/) | 文書におけるデジタル署名が提供するカバレッジレベルを表す列挙型です。 |
