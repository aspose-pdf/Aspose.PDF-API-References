線のキャップスタイルは、ストローク時に開いたサブパスの端部（およびダッシュがある場合はそれ）で使用される形状を指定するものとします。

## フィールド

| フィールド | 説明 |
| --- | --- |
| [ButtCap](#ButtCap) | バットキャップ。ストロークはパスの終点で直角にカットされます。パスの終点を超える投影はありません。 |
| [RoundCap](#RoundCap) | ラウンドキャップ。線幅と同じ直径の半円弧が終点の周りに描かれ、塗りつぶされます。 |
| [SquareCap](#SquareCap) | プロジェクティングスクエアキャップ。ストロークはパスの終点を超えて、線幅の半分の距離だけ続き、直角にカットされます。 |

### RoundCap {#RoundCap}

### SquareCap {#SquareCap}
```
public static final int SquareCap
```

プロジェクティングスクエアキャップ。ストロークはパスの終点を超えて、線幅の半分の距離だけ続き、直角にカットされます。
