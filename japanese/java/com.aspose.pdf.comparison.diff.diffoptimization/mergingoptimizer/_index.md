編集セクションを再配置およびマージするクラスを表す。等価性をマージし、隣接する同一変更を結合する。Equals 操作間の変更をソートおよびマージする。順序やマージを変更しても結果は変わらず、より読みやすい出力になる。この処理は隣接する Equal 操作を結合する。
