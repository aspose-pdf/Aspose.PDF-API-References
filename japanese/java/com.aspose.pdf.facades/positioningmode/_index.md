配置モードを定義します。可能な値は Legacy（下位互換性）と Current（更新されたテキスト位置計算方法）です。

## フィールド

| フィールド | 説明 |
| --- | --- |
| [Current](#Current) | 行間と垂直位置の計算が左上隅に基づいて行われ、左下ではなくなりました。 |
| [Legacy](#Legacy) | レガシーテキスト配置 |
| [ModernLineSpacing](#ModernLineSpacing) | 行間が更新され、垂直位置の計算は従来のルールに従って行われます（つまり、テキストは指定された矩形の左下隅を基準に配置されます）。 |
