### compare {#compare-com.aspose.pdf.Document-com.aspose.pdf.Document-java.lang.String-com.aspose.pdf.comparison.sidebysidecomparison.SideBySideComparisonOptions-}
2つのドキュメントを比較します。ページは1つずつ比較されます。比較対象のドキュメントのページは、結果のドキュメントに順番にコピーされます。最初に最初のドキュメントの1ページ目、次に2番目のドキュメントの1ページ目がコピーされます。その後、最初のドキュメントの2ページ目、続いて2番目のドキュメントの2ページ目がコピーされる、という順序です。Adobe Acrobat の2ページ表示で開くと、変更点を並べて確認できます。削除は左側のページに、挿入は右側のページに示されます。

### compare {#compare-com.aspose.pdf.Page-com.aspose.pdf.Page-java.lang.String-com.aspose.pdf.comparison.sidebysidecomparison.SideBySideComparisonOptions-}
2ページを比較します。結果はPDFドキュメントに保存され、最初に1ページ目が書き込まれ、続いて2ページ目が書き込まれます。Adobe Acrobat の2ページ表示で開くと、変更点を並べて確認できます。削除は左側のページに、挿入は右側のページに示されます。
