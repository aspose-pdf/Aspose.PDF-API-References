### HiddenDataSanitizer {#HiddenDataSanitizer-com.aspose.pdf.security.HiddenDataSanitizationOptions-}
PDF ドキュメントから隠しデータをサニタイズする機能を提供し、メタデータ、注釈、JavaScript、またはプライベートコンテンツなどの機密情報や不要な情報が削除または変換されることを保証します。

### sanitize {#sanitize-com.aspose.pdf.Document-}
指定された PDF ドキュメントの隠しデータを削除または変換することでサニタイズします。

### sanitizeAllToImages {#sanitizeAllToImages-com.aspose.pdf.Document-}
ページの内容を画像に置き換え、他の隠しデータを削除します。背景色で隠しテキストを削除したり、画像の下に隠されたテキストを削除したりできます。また、すべてのインタラクティブ要素を完全に削除します。ドキュメントはそのまま画像に変換され、その後残りの隠しデータがクリアされます。まずクリアしてから変換する必要がある場合は、メインクラスのメソッドを使用してください。

### sanitizeAllToImages {#sanitizeAllToImages-com.aspose.pdf.Document-int-}
ページの内容を画像に置き換え、他の隠しデータを削除します。背景色で隠しテキストを削除したり、画像の下に隠されたテキストを削除したりできます。また、すべてのインタラクティブ要素を完全に削除します。ドキュメントはそのまま画像に変換され、その後残りの隠しデータがクリアされます。まずクリアしてから変換する必要がある場合は、メインクラスのメソッドを使用してください。
