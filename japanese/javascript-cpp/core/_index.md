## Core Functions

| 名前 | 説明 |
| -------------- | -------------- |
| [AsposePdfPrepare](./asposepdfprepare/) | 処理のためにMemory FSにBLOBを保存します。 |
| [AsposePdfPrepareBase64](./asposepdfpreparebase64/) | 処理のためにMemory FSに文字列表現のBLOBを保存します。 |

## Detailed Description

PDFファイルを操作するためのコア機能です。

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
または
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
