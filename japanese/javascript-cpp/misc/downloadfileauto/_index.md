_HTML でファイルをダウンロードするリンクを作成し、2 秒後にダウンロードを開始します。_

```js
function DownloadFileAuto(
    filename,
    mime 
)
```

**Parameters**:

* **fileName** file name
* **mime** string "mime/type"

**Doesn't work in Web Worker.**
