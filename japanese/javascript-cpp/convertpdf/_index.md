## Convert to PDF functions

| 名前 | 説明 |
| -------------- | -------------- |
| [AsposePdfFromTxt](./asposepdffromtxt/) | TXT ファイルを PDF に変換します。 |
| [AsposePdfFromImage](./asposepdffromimage/) | Image-file を PDF に変換します。 |

## Detailed Description

PDFファイルへ変換するための関数です。

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
または
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
