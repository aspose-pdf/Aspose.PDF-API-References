## PdfAOptionsBase.SymbolicFontEncodingStrategy property

PDF/A 形式に変換する際のシンボリック フォントのエンコード戦略を取得または設定します。

```csharp
public PdfASymbolicFontEncodingStrategy SymbolicFontEncodingStrategy { get; set; }
```

### Property Value

シンボリックフォントのエンコード戦略です。

## 備考

このプロパティを使用すると、元の TrueType シンボリックフォントが複数の CMap サブテーブルを含む場合に、結果ドキュメントにコピーされる CMap サブテーブルを制御できます。
