## PdfAOptionsBase.PdfAVersion property

検証または変換に使用する PDF/A 標準のバージョンを取得または設定します。

```csharp
public PdfAStandardVersion PdfAVersion { get; set; }
```

### Property Value

PDF/A 標準のバージョンです。これは [`PdfAStandardVersion`](../../pdfastandardversion/) 列挙体の値のいずれかです。

## 備考

PDF/A 標準のバージョンは、PDF/A の検証および変換における準拠レベルを決定するために使用されます。バージョンが Auto に設定されている場合、システムはドキュメント メタデータに基づいて検証に適切な PDF/A 標準バージョンを自動的に判断します。PDF/A 変換プロセスにおいて、Auto はデフォルトで PDF/A-1b 標準バージョンになります。
