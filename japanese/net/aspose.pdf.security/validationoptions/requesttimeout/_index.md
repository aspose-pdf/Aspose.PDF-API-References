## ValidationOptions.RequestTimeout property

検証プロセス中のネットワーク関連操作のタイムアウト期間（ミリ秒）を取得または設定します。RequestTimeout プロパティは、失効ステータスや OCSP サーバーなどのオンラインリソースにアクセスする際にシステムが待機すべき最大時間を定義します。

```csharp
public int RequestTimeout { get; set; }
```
