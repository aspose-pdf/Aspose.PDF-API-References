## TextSearchOptions.SearchForTextRelatedGraphics property

テキスト検索時にテキスト関連のグラフィック（下線、背景など）を検索するかどうかの値を取得または設定します。true - テキスト関連のグラフィック検索が実行されます（既定値）。false - ソースドキュメントに存在する可能性のあるグラフィック要素は無視されます。パフォーマンス上の問題がある場合や、下線・背景・クリッピングを処理する必要がない場合に設定してください。

```csharp
public bool SearchForTextRelatedGraphics { get; set; }
```
