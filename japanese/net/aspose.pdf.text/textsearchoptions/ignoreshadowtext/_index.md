## TextSearchOptions.IgnoreShadowText property

検索時に通常テキストの影を表すテキストフラグメントを無視するかどうかを取得または設定します。true - 影のテキストは見つかりません（検索結果に近接位置で重複フラグメントが返る場合に試してください）。false - 影のテキストも通常テキストと同様に見つかります（既定値）。

```csharp
public bool IgnoreShadowText { get; set; }
```
