## TextReplaceOptions.FontSizeAdjustment enumeration

テキストのフォントサイズを、包含領域に合わせて調整する方法に関するポリシーを指定します。

```csharp
public enum FontSizeAdjustment
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | フォントサイズは変更されません。 |
| ShrinkToFit | `1` | テキストが境界に収まらないほど大きい場合はフォントサイズが縮小されます。テキストが境界より小さい場合、フォントサイズは決して拡大されません。 |
| ScaleToFill | `2` | フォントサイズは（縮小と拡大の両方）調整され、テキストが矩形の境界内にできるだけ収まるようにします。 |
