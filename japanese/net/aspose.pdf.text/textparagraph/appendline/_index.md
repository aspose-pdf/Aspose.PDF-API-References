## AppendLine(string, float) {#appendline_6}

テキスト行を追加します。

```csharp
public void AppendLine(string line, float lineSpacing)
```

| パラメーター | タイプ | 説明 |
| --- | --- | --- |
| 行 | String | 新しい行のテキストです。 |
| lineSpacing | Single | 追加の間隔 (0.0 がデフォルトで、デフォルトのテキスト行の高さに相当します)。この間隔の値は特定の行のデフォルト行間に加算されるため、12pt フォントで描画されたテキスト行の後に空白行を取得したい場合は 12.0 を指定できます。 |
