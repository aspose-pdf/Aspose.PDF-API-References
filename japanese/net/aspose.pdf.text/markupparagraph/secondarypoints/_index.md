## MarkupParagraph.SecondaryPoints property

段落の継続を表す二次ポリゴンの点。次の列またはページで段落が継続している場合は null にはなりません。開始点は段落の左下隅です。次の点は反時計回りの順序です。

public List<Point[]> SecondaryPoints { get; }
