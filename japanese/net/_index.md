## 名前空間

| 名前空間 | 説明 |
| --- | --- |
| [Aspose.Pdf](./aspose.pdf/) | **Aspose.Pdf** は、Aspose.Pdf ライブラリのすべてのクラスに対するルート名前空間であり、**Document** のように直接含まれるものや、いくつかのサブ名前空間を通じて間接的に含まれるものがあります。 |
| [Aspose.Pdf.AI](./aspose.pdf.ai/) | **Aspose.Pdf.AI** 名前空間は、API クライアントやインテリジェントアシスタントなど、AI 機能向けのクラスを提供します。 |
| [Aspose.Pdf.Annotations](./aspose.pdf.annotations/) | **Aspose.Pdf.Annotations** 名前空間は、さまざまな種類のアクション、宛先、その他のドキュメント機能（従来はインタラクティブと呼ばれ、ユーザーが相互作用できる手段）を扱うためのクラスを提供します。 |
| [Aspose.Pdf.Comparison](./aspose.pdf.comparison/) | **Aspose.Pdf.Comparison** 名前空間は、ドキュメント比較に使用されるクラスを提供します。 |
| [Aspose.Pdf.DataEditor](./aspose.pdf.dataeditor/) | **Aspose.Pdf.DataEditor** には、ドキュメント内のデータを編集するためのツールが含まれています。 |
| [Aspose.Pdf.Devices](./aspose.pdf.devices/) | **Aspose.Pdf.Devices** 名前空間は、ドキュメントを画像やプレーンテキストとして表現するために使用されるクラスを提供します。そのため、ドキュメントはテキストデバイスやさまざまなグラフィックデバイスに送信でき、テキスト表現またはグラフィック表現を取得できます。 |
| [Aspose.Pdf.Drawing](./aspose.pdf.drawing/) | **Aspose.Pdf.Drawing** 名前空間は、弧、線、円などのグラフィックプリミティブを記述するクラスを提供します。対応するオブジェクトは新しいドキュメントの作成に使用できます。 |
| [Aspose.Pdf.Facades](./aspose.pdf.facades/) | **Aspose.Pdf.Facades** 名前空間は、もともと Aspose.Pdf.Kit から来たクラスを提供します。これらのクラスは、ドキュメントを結合、スタンプ付与、署名、注釈付与などの操作で操作するために使用されますが、ドキュメントの内部構造にアクセスせずに高レベルで行えます。 |
| [Aspose.Pdf.Forms](./aspose.pdf.forms/) | **Aspose.Pdf.Forms** 名前空間には、標準、静的、動的フォームや、テキストボックス、リストボックス、ラジオボタンなどのさまざまなフィールドを記述するクラスがあります。 |
| [Aspose.Pdf.LogicalStructure](./aspose.pdf.logicalstructure/) | **Aspose.Pdf.Tagged.LogicalStructure** は、PDF 論理構造クラスのための名前空間です。 |
| [Aspose.Pdf.Multithreading](./aspose.pdf.multithreading/) | **Aspose.Pdf.Multithreading** 名前空間は、マルチスレッドシナリオで使用されることを意図したクラスを提供します。 |
| [Aspose.Pdf.Operators](./aspose.pdf.operators/) | **Aspose.Pdf.Operators** は、Operator 実装のための名前空間です。これらのクラスは PDF **Page** コンテンツで使用されるオペレーターを記述します。 |
| [Aspose.Pdf.Optimization](./aspose.pdf.optimization/) | **Aspose.Pdf.Optimization** は、ドキュメント最適化プロセスの管理のためのクラスの名前空間です。 |
| [Aspose.Pdf.Plugins](./aspose.pdf.plugins/) | **Aspose.Pdf.Plugins** は、**PdfOrganizer** のように直接含まれるクラスや、いくつかのサブ名前空間を介して間接的に含まれるクラスのすべてに対するルート名前空間です。 |
| [Aspose.Pdf.Printing](./aspose.pdf.printing/) | **Aspose.Pdf.Printing** 名前空間は、プリンター設定、**Page** 設定、印刷関連設定の管理用拡張機能など、PDF 印刷操作を処理するためのクラスと機能を提供します。 |
| [Aspose.Pdf.Sanitization](./aspose.pdf.sanitization/) | **Aspose.Pdf.Sanitization** は、サニタイズ操作のための名前空間です。 |
| [Aspose.Pdf.Security](./aspose.pdf.security/) | **Aspose.Pdf.Security** 名前空間には、暗号化とデジタル署名に使用されるクラスが含まれています。 |
| [Aspose.Pdf.Signatures](./aspose.pdf.signatures/) | **Aspose.Pdf.Signatures** 名前空間には、改ざんされた署名を検出するためのクラスが含まれています。 |
| [Aspose.Pdf.Structure](./aspose.pdf.structure/) | **Aspose.Pdf.Structure** 名前空間は、ドキュメントの論理構造（章やセクションへの編成、図表や脚注などの特別な要素の識別）を扱うのに役立つクラスを提供します。 |
| [Aspose.Pdf.Tagged](./aspose.pdf.tagged/) | **Aspose.Pdf.Tagged** は、Tagged PDF ドキュメントのサポートのためのクラスの名前空間です。 |
| [Aspose.Pdf.Text](./aspose.pdf.text/) | この **Aspose.Pdf.Text** 名前空間は、テキストを抽出し、テキストを追加し、document の既存テキストを操作できるクラスを提供します。また、フォントを抽出、置換、代替できるクラスも含まれています。 |
| [Aspose.Pdf.Vector](./aspose.pdf.vector/) | この **Aspose.Pdf.Vector** は、グラフィック操作のルート名前空間です。 |
| [Aspose.Pdf.XfaConverter](./aspose.pdf.xfaconverter/) | この **Aspose.Pdf.XfaConverter** 名前空間は、XFA を変換できるクラスを提供します。 |
