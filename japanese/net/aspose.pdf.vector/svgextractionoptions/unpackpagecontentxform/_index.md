## SvgExtractionOptions.UnpackPageContentXForm property

ページ上で見つかった XFrom を展開するかどうかを決定するフラグを取得または設定します。XFrom 要素は別々の SVG ファイルに分割される可能性があります。ページコンテンツの Do ステートメントでレンダリングされた XForm のみが展開され、ネストされた XForm は展開されません。

```csharp
public bool UnpackPageContentXForm { get; set; }
```
