## SetDash.Phase property

破線位相。パスのストロークを開始する前に、破線配列を循環させて破線と間隔の長さを合計します。累積長さが破線位相で指定された値に等しくなると、パスのストロークが開始され、以降は破線配列が循環的に使用されます。

```csharp
public int Phase { get; set; }
```
