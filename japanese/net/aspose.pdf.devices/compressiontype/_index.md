## CompressionType enumeration

Tiff 画像デバイスに渡されるパラメータ値を指定するために使用されます。

```csharp
public enum CompressionType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| LZW | `0` | LZW 圧縮方式を指定します。Compression カテゴリに属するパラメータとして Tiff エンコーダに渡すことができます。 |
| CCITT4 | `1` | CCITT4 圧縮方式を指定します。Compression カテゴリに属するパラメータとして CCITT4 エンコーダに渡すことができます。 |
| CCITT3 | `2` | CCITT3 圧縮方式を指定します。Compression カテゴリに属するパラメータとして CCITT3 エンコーダに渡すことができます。 |
| RLE | `3` | RLE 圧縮方式を指定します。Compression カテゴリに属するパラメータとして RLE エンコーダに渡すことができます。 |
| None | `4` | 圧縮なしを指定します。Compression カテゴリに属するパラメータとして Tiff エンコーダに渡すことができます。 |
