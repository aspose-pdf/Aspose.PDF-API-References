**Aspose.Pdf.DataEditor** には、ドキュメント内のデータを編集するためのツールが含まれています。

## クラス

| クラス | 説明 |
| --- | --- |
| [CosPdfBoolean](./cospdfboolean/) | このクラスはブール型を表します。 |
| [CosPdfDictionary](./cospdfdictionary/) | オブジェクトの辞書にアクセスするためのクラスです。 |
| [CosPdfName](./cospdfname/) | このクラスは PDF の Name オブジェクトを表します。 |
| [CosPdfNumber](./cospdfnumber/) | このクラスは PDF の Number 型を表します。 |
| [CosPdfPrimitive](./cospdfprimitive/) | このクラスは基本公開型 [`CosPdfPrimitive`](../aspose.pdf.dataeditor/cospdfprimitive/) を表します。 |
| [CosPdfString](./cospdfstring/) | このクラスは PDF の String オブジェクトを表します。 |
| [DictionaryEditor](./dictionaryeditor/) | ドキュメントのツリーディクトリ（document dictionary、page dictionary、resources dictionary）にアクセスするためのクラスです。 |
## インターフェイス

| インターフェイス | 説明 |
| --- | --- |
| [ICosPdfPrimitive](./icospdfprimitive/) | PDF データエンティティを操作するためのインターフェイスです。 |
