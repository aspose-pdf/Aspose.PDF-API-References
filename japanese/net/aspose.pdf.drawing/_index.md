**Aspose.Pdf.Drawing** 名前空間は、弧、線、円などのグラフィックプリミティブを記述するクラスを提供します。対応するオブジェクトは新しいドキュメントの作成に使用できます。

## クラス

| クラス | 説明 |
| --- | --- |
| [Arc](./arc/) | 弧を表します。 |
| [Circle](./circle/) | 円を表します。 |
| [Curve](./curve/) | ベジェ曲線を表します。 |
| [Ellipse](./ellipse/) | 楕円を表します。 |
| [GradientAxialShading](./gradientaxialshading/) | グラデーション軸シェーディング クラスを表します。 |
| [GradientRadialShading](./gradientradialshading/) | グラデーション放射状シェーディング タイプを表します。 |
| [Graph](./graph/) | グラフ - グラフィックジェネレータ段落を表します。 |
| [Line](./line/) | 線を表します。 |
| [Path](./path/) | 弧を表します。 |
| [PatternColorSpace](./patterncolorspace/) | 基本パターン クラスを表します。 |
| [Rectangle](./rectangle/) | 矩形を表します。 |
| [Shape](./shape/) | 形状 - 基本グラフィックオブジェクトを表します。 |
