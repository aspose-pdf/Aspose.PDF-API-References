## XfaParserOptions.Signed property

このプロパティが true の場合、文書は Xfa フォームストリーム（存在する場合）を使用して変換されます。false の場合、Xfa フォームストリームは無視されます。このプロパティは、署名検証に使用されるチェックサムの計算方法が不明確であるために導入されました。

```csharp
public bool Signed { get; set; }
```
