## ITaggedContent.Save method

タグ付けされたコンテンツの現在の状態を関連付けられた PDF ドキュメントに保存します。

```csharp
public void Save()
```

## 備考

このメソッドは、PDF ドキュメント内ですべてのタグ付けコンテンツ要素が適切に更新され、保存されることを保証します。MCR 要素の MCID を更新したり、BDC 演算子を設定したり、PDF/UA 標準への準拠を確保したりといった必要な操作を実行します。
