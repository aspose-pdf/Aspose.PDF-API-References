## PositioningMode enumeration

配置モードを定義します。可能な値には Legacy（下位互換性）と Current（更新されたテキスト位置計算方法）が含まれます。

```csharp
public enum PositioningMode
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Legacy | `0` | レガシーテキスト配置 |
| ModernLineSpacing | `1` | 行間が更新され、垂直位置の計算は古い規則に従って行われます（つまり、テキストは指定された矩形の左下隅を基準に配置されます）。 |
| Current | `2` | 行間が更新され、垂直位置の計算は左下ではなく左上隅を基準に行われます。 |
