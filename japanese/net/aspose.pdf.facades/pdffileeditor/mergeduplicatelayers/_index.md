## PdfFileEditor.MergeDuplicateLayers property

このプロパティが true の場合、同名の結合されたドキュメントのオプションコンテンツは結果ドキュメントの 1 つのレイヤーにマージされます。false の場合、同名のレイヤーは別々のレイヤーとして結果ドキュメントに保存されます。

```csharp
public bool MergeDuplicateLayers { get; set; }
```
