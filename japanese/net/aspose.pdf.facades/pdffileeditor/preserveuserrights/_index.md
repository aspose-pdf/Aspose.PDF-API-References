## PdfFileEditor.PreserveUserRights property

true の場合、最初のドキュメントのユーザー権限が結合されたドキュメントに適用されます。他のすべてのドキュメントのユーザー権限は無視されます。

```csharp
public bool PreserveUserRights { get; set; }
```
