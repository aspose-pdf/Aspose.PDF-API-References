## PdfFileEditor.KeepFieldsUnique property

true の場合、フォームが結合されるとフィールド名が一意にされます。フィールド名にサフィックスが追加され、サフィックスのテンプレートは UniqueSuffix プロパティで指定できます。

```csharp
public bool KeepFieldsUnique { get; set; }
```
