## FormEditor.SetFieldScript method

PushButton フィールドの JavaScript を設定します。既存の JavaScript がある場合は新しいものに置き換えられます。

```csharp
public bool SetFieldScript(string fieldName, string script)
```

| パラメーター | タイプ | 説明 |
| --- | --- | --- |
| fieldName | String | 完全修飾フィールド名。 |
| script | String | プッシュボタン フィールドに追加/配置する JavaScript。 |

### 戻り値

フィールドスクリプトが正常に設定された場合は true。
