## DocumentPrivilege.AllowDegradedPrinting property

低品質印刷を許可するかどうかの権限を設定します。true は許可、false は禁止です。

```csharp
public bool AllowDegradedPrinting { get; set; }
```

## 備考

設定すると、印刷は外観の低レベル表現に制限され、品質が劣化する可能性があります。
