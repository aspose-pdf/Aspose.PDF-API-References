## PdfExtractor.Resolution property

抽出された画像の解像度を設定または取得します。デフォルト値は150です。解像度の値が大きい画像はより鮮明になります。ただし、解像度の値を上げると画像抽出に必要な時間とメモリが増加します。通常、鮮明な画像を得るには解像度を150または300に設定すれば十分です。

```csharp
public int Resolution { get; set; }
```
