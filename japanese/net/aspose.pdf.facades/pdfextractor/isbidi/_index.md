## PdfExtractor.IsBidi property

テキストにヘブライ語またはアラビア語の記号が含まれる場合に true になります。このケースは、文字列関数の動作が変わり、テキストの処理が右から左へ（数字やその他の非テキスト文字は除く）開始されるため、特別に考慮する必要があります。

```csharp
public bool IsBidi { get; }
```
