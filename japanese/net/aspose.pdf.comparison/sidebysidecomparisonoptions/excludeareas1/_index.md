## SideBySideComparisonOptions.ExcludeAreas1 property

除外領域を取得および設定します。比較メソッドで最初のページまたはドキュメントに使用されます。このオプションは [`ExcludeTables`](../excludetables/) と一緒に設定できます。このオプションは [`ComparisonArea1`](../comparisonarea1/) オプションと一緒に設定できません。

public Rectangle[] ExcludeAreas1 { get; set; }
