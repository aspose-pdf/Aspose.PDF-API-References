## Stamp.Rotate property

[`Rotation`](../../rotation/) の値に従ってスタンプコンテンツの回転を取得または設定します。注意: このプロパティは 0、90、180、270 度のように 90 度の倍数の角度を設定するためのものです。任意の角度を設定するには RotateAngle プロパティを使用してください。ArbitraryAngle で設定された角度が 90 の倍数でない場合、Rotate プロパティは Rotation.None を返します。

```csharp
public Rotation Rotate { get; set; }
```
