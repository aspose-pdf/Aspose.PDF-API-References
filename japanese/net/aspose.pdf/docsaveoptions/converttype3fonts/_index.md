## DocSaveOptions.ConvertType3Fonts property

Type3 フォントの変換を取得または設定します。Type 3 フォントでは、グリフはグラフィック演算子のストリームで定義されます。これにより、DOC/DOCX 出力ではテキストの代わりに画像が表示されます。このフラグを true に設定すると、Type3 フォントを TTF に変換し、結果ファイルでテキストを取得できます。

```csharp
public bool ConvertType3Fonts { get; set; }
```
