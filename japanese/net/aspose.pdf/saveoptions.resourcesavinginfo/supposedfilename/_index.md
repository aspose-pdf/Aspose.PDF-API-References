## SaveOptions.ResourceSavingInfo.SupposedFileName field

コンバータによって設定されます。コンバータからカスタムメソッドのコードへ渡される想定のファイル名です。カスタムコードでこのファイルをどのように処理するか、またはどこに保存するかを決定するために使用できます。

```csharp
public string SupposedFileName;
```
