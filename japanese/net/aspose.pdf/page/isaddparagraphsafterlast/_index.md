## Page.IsAddParagraphsAfterLast property

ページの最後の段落の後に段落を追加する機能を取得または設定します。

```csharp
public bool IsAddParagraphsAfterLast { get; set; }
```

### Property Value

この値は、ページの最後の段落の後に段落が追加されるかどうかを示します。値が true の場合、ページの最後の段落の後に段落が追加されます。
