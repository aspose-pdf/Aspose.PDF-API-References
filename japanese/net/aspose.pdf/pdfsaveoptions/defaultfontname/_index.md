## PdfSaveOptions.DefaultFontName property

コンピュータに存在しないフォントに対してデフォルトで使用されるフォント名です。PDF に保存される文書に、文書自体やデバイスに存在しないフォントが含まれている場合、API はそのフォントを（デバイス上に `DefaultFontName` のフォントが見つかった場合の）デフォルトフォントに置き換えます。

```csharp
public string DefaultFontName { get; set; }
```
