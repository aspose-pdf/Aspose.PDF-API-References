## HtmlSaveOptions.HtmlImageSavingInfo.PdfHostPageNumber field

カスタムコードに、保存された画像が元の PDF ドキュメントのどの page に対応しているかを伝えます。元のドキュメントのすべての page が保存されるわけではない可能性があるため、この値は元の PDF 内のホスト page 番号を示します。何らかの理由で元の page 番号が不明な場合は、常に「1」を返します。

```csharp
public int PdfHostPageNumber;
```
