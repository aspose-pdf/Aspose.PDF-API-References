## LoadOptions.ResourceLoadingResult.EncodingIfKnown field

リソースのエンコーディングが読み込み後または読み込み中に判明することがあります。その場合、カスタムコードはこのパラメーターを通じてコンバータにその情報を提供できます。エンコーディングが不明または重要でない場合は、このパラメーターに null を設定したままにできます。

```csharp
public Encoding EncodingIfKnown;
```
