## LoadOptions.ResourceLoadingResult.MIMETypeIfKnown field

読み込まれたリソースの MIME タイプに関する情報はコンバータにとって有用なことがあります。このパラメーターで MIME タイプ（読み込み後に判明した場合）を指定できます。MIME タイプが不明、または提供する必要がない場合は、パラメーターを null のままにしてください。

```csharp
public string MIMETypeIfKnown;
```
