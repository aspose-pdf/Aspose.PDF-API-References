## Document.CryptoAlgorithm property

Document が暗号化されている場合にセキュリティ設定を取得します。Document が暗号化されていない場合、.NET 1.1 では対応する例外がスローされ、他の .NET バージョンでは CryptoAlgorithm が null になります。

```csharp
public CryptoAlgorithm? CryptoAlgorithm { get; }
```
