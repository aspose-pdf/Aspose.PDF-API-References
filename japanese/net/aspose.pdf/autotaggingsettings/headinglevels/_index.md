## AutoTaggingSettings.HeadingLevels property

PDF ドキュメントの見出し構造を決定するために使用される見出しレベルを取得または設定します。

public HeadingLevels HeadingLevels { get; set; }

## 備考

`HeadingLevels` プロパティは、フォントサイズと見出しレベルのマッピングを設定できるようにします。これは自動タグ付けプロセス中に、ドキュメント内のテキスト要素のフォントサイズに基づいて適切な見出しレベルを識別し割り当てるために使用されます。
