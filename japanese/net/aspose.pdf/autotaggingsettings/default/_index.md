## AutoTaggingSettings.Default property

PDF ドキュメントの自動タグ付け機能のデフォルト設定を取得します。

```csharp
public static AutoTaggingSettings Default { get; }
```

## 備考

デフォルト設定は自動タグ付けを有効にし、見出し認識の自動戦略を使用します。これらの設定は、PDF 形式の変換や PDF コンテンツの自動タグ付けを必要とするその他の操作のベースライン構成として使用できます。
