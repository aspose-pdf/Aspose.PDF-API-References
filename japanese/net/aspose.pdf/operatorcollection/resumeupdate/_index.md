## ResumeUpdate(bool) {#resumeupdate_1}

ドキュメントの更新を再開します。保留中の変更がある場合、コンテンツストリームを更新します。invalidate パラメータが true の場合、すべての演算子を "changed" とマークします。

```csharp
public void ResumeUpdate(bool updateAll)
```

| パラメーター | タイプ | 説明 |
| --- | --- | --- |
| updateAll | Boolean | true の場合、コレクション内のすべての演算子が更新済みとしてマークされます。 |
