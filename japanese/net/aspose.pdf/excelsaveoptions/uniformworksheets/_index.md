## ExcelSaveOptions.UniformWorksheets property

ドキュメント全体で均一な列分割を使用する場合は true に設定します。デフォルト値は false です。これは、列の分割が各ページごとに独立することを意味します。

```csharp
public bool UniformWorksheets { get; set; }
```
