## ExcelSaveOptions.MinimizeTheNumberOfWorksheets property

結果のブックでワークシートの数を最小限に抑える必要がある場合は true を設定します。デフォルト値は false で、各 PDF ページが個別のワークシートとして保存されます。

```csharp
public bool MinimizeTheNumberOfWorksheets { get; set; }
```
