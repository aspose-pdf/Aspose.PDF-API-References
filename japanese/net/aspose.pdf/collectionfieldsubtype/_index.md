## CollectionFieldSubtype enumeration

```csharp
public enum CollectionFieldSubtype
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| None | `0` | サブタイプが定義されていません。 |
| S | `1` | テキスト型です。フィールド データは PDF テキスト文字列として保存されます。 |
| D | `2` | 日付型です。フィールド データは PDF 日付文字列として保存されます。 |
| N | `3` | 数値型です。フィールド データは PDF 数値として保存されます。 |
| F | `4` | フィールド データは、埋め込みファイルストリームのファイル名とします。ファイル仕様の UF エントリで識別できる場合はそれを使用し、存在しない場合はファイル仕様の F エントリを使用します。 |
| Desc | `5` | フィールド データは、埋め込みファイルストリームのファイル名とします。ファイル仕様の UF エントリで識別できる場合はそれを使用し、存在しない場合はファイル仕様の F エントリを使用します。 |
| ModDate | `6` | フィールド データは、埋め込みファイルパラメータ辞書の ModDate エントリで識別される埋め込みファイルストリームの更新日付とします。 |
| CreationDate | `7` | フィールド データは、埋め込みファイルの CreationDate エントリで識別される埋め込みファイルストリームの作成日付とします。 |
| Size | `8` | フィールド データは、埋め込みファイルパラメータ辞書の Size エントリで識別される埋め込みファイルのサイズとします。 |
| CompressedSize | `9` | (PDF 2.0) フィールド データは、埋め込みファイルストリーム辞書の Length エントリで識別される埋め込みファイルストリームの長さとし、両方の値は同一でなければなりません。 |
