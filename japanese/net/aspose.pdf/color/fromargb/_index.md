## FromArgb(int, int, int) {#fromargb}


| パラメーター | タイプ | 説明 |
| --- | --- | --- |
| r | Int32 | 赤色コンポーネント (値 0 - 255)。 |
| g | Int32 | 緑色コンポーネント (値 0 - 255)。 |
| b | Int32 | 青色コンポーネント (値 0 - 255)。 |

### 戻り値
