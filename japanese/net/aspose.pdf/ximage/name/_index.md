## XImage.Name property

画像名を取得または設定します。ページコンテンツで参照されている画像の名前を変更すると、ドキュメントが正しくなくなる可能性があることに注意してください。その場合は XImage.Rename メソッドを使用してください。

```csharp
public string Name { get; set; }
```
