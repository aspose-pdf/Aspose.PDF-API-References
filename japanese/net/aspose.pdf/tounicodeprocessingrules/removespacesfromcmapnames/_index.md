## ToUnicodeProcessingRules.RemoveSpacesFromCMapNames property

一部のフォントは名前にスペースが含まれる ToUnicode 文字コードマップを持っています。これらのスペースが Unicode テキストマッピングでエラーを引き起こす可能性があります。このフラグは ToUnicode 文字コードマップの名前からスペースを削除するよう指示します。デフォルトは false です。

```csharp
public bool RemoveSpacesFromCMapNames { get; set; }
```
