## ToUnicodeProcessingRules.MapNonLinkedSymbolsOnSpace property

一部のフォントは特定のテキストシンボルの Unicode 情報を提供しません。この情報不足によりエラー「Text cannot be mapped to Unicode」が発生します。このフラグを使用して、リンクされていないシンボルを Unicode の「スペース」(コード 32) にマップします。

```csharp
public bool MapNonLinkedSymbolsOnSpace { get; set; }
```
