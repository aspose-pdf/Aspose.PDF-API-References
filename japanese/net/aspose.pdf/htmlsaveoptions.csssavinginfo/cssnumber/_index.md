## HtmlSaveOptions.CssSavingInfo.CssNumber field

コンバータによって設定されます。変換中に複数の CSS ファイルが作成されます。このプロパティは、変換中に保存された CSS ファイルの順序を示します。カスタムコードのロジックで、CSS コンテンツの処理方法や保存場所を決定する際に使用できます。

public int CssNumber;
