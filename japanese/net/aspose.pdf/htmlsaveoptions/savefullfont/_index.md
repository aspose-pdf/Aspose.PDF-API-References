## HtmlSaveOptions.SaveFullFont property

完全なフォントを保存することを示します。True Type フォントのみサポートします。デフォルトでは SaveFullFont = false で、変換ツールは文書のテキスト表示に必要なフォントのサブセットを保存します。

```csharp
public bool SaveFullFont { get; set; }
```
