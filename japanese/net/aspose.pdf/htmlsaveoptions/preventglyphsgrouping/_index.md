## HtmlSaveOptions.PreventGlyphsGrouping property

この属性は、テキストのグリフが単語や文字列にまとめられないモードを有効にします。このモードにより、ページ上でのグリフの配置精度を最大限に保つことができ、楽譜や個別に配置すべきグリフを含む文書の変換に使用できます。このパラメータは、FixedLayout 属性の値が true の場合にのみ文書に適用されます。

```csharp
public bool PreventGlyphsGrouping { get; set; }
```
