## HtmlSaveOptions.ConvertMarkedContentToLayers property

属性 ConvertMarkedContentToLayers が true に設定されている場合、PDF のマークドコンテンツ（レイヤー）内のすべての要素が、レイヤー名を指定する "data-pdflayer" 属性を持つ HTML の div に配置されます。このレイヤー名は PDF のマークドコンテンツのオプションプロパティから抽出されます。この属性が false（デフォルト）の場合、PDF のマークドコンテンツからレイヤーは作成されません。

```csharp
public bool ConvertMarkedContentToLayers { get; set; }
```
