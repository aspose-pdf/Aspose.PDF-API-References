## HtmlSaveOptions.TrySaveTextUnderliningAndStrikeoutingInCss field

PDF 自体にはテキストの下線マーカーが含まれていません。テキストの下に線を配置してエミュレートされています。このオプションは、コンバータがその線がテキストの下線であるかどうかを推測し、グラフィカルに下線を描画する代わりに CSS に情報を入れることを可能にします。

```csharp
public bool TrySaveTextUnderliningAndStrikeoutingInCss;
```
