## HtmlSaveOptions.SimpleTextboxModeGrouping property

この属性は、グリフと単語を文字列に順次グループ化することを指定します。たとえば、変換された HTML でタグと単語の順序が異なり、合わせたい場合に使用します。このパラメータは FixedLayout 属性の値が true の場合にのみ文書に適用されます。

```csharp
public bool SimpleTextboxModeGrouping { get; set; }
```
