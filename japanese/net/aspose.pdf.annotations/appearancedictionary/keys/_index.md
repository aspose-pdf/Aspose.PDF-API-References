## AppearanceDictionary.Keys property

辞書のキーを取得します。もし外観辞書にサブ辞書がある場合、`Keys` には (N&#x7C;R&#x7C;D).state の値が含まれます。ここで N は通常の外観、R はロールオーバー外観、D はダウン外観を表し、state は状態名（例：チェックボックスの On、Off）です。

```csharp
public ICollection<string> Keys { get; }
```
