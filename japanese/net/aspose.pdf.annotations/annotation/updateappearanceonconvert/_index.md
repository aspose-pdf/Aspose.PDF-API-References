## Annotation.UpdateAppearanceOnConvert property

true の場合、PF ドキュメントを画像に変換する前にアノテーションの外観が更新されます。これによりフィールドが正しく変換されますが、時間がかかる可能性があります。

```csharp
public static bool UpdateAppearanceOnConvert { get; set; }
```
