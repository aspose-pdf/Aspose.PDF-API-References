## ReplyType enumeration

アノテーションと InReplyTo で指定されたものとの間の関係（「返信タイプ」）の種類を列挙します。

```csharp
public enum ReplyType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| Undefined | `0` | 未定義の関係です。 |
| Reply | `1` | この注釈は InReplyTo で指定された注釈への返信とみなされます。ビューアアプリケーションは、個別の返信を表示せず、スレッド化されたコメントとしてまとめて表示すべきです。 |
| Group | `2` | この注釈は InReplyTo で指定された注釈とグループ化されています。 |
