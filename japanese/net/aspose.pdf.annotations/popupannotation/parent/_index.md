## PopupAnnotation.Parent property

このポップアップ注釈が関連付けられる親注釈を取得または設定します。このエントリが存在する場合、親注釈の Contents、M、C、T エントリがポップアップ注釈自体のそれらを上書きします。

```csharp
public Annotation Parent { get; set; }
```
