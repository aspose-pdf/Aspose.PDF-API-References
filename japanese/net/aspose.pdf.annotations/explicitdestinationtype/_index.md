## ExplicitDestinationType enumeration

```csharp
public enum ExplicitDestinationType
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| XYZ | `0` | ウィンドウの左上隅に座標 (left, top) を配置し、ページの内容をズーム倍率で拡大してページを表示します。left、top、または zoom のいずれかのパラメーターに null 値を指定すると、そのパラメーターの現在の値は変更されずに保持されます。ズーム値が 0 の場合も null 値と同じ意味です。 |
| Fit | `1` | ページの内容をウィンドウ内に横方向および縦方向にページ全体が収まるように最小限拡大して表示します。必要な横方向と縦方向の拡大率が異なる場合は、両者のうち小さい方を使用し、もう一方の方向ではページをウィンドウの中央に配置します。 |
| FitH | `2` | ウィンドウの上端に垂直座標 top を配置し、ページの内容をウィンドウ内にページ全体の幅が収まる程度に拡大して表示します。top に null 値を指定すると、そのパラメーターの現在の値は変更されずに保持されます。 |
| FitV | `3` | ウィンドウの左端に水平座標 left を配置し、ページの内容をウィンドウ内にページ全体の高さが収まる程度に拡大して表示します。left に null 値を指定すると、そのパラメーターの現在の値は変更されずに保持されます。 |
| FitR | `4` | ページを表示し、その内容を左、下、右、topentirely の座標で指定された矩形がウィンドウ内に水平・垂直の両方で完全に収まるように拡大表示します。必要な水平および垂直の拡大率が異なる場合は、両方のうち小さい方を使用し、もう一方の次元で矩形をウィンドウの中央に配置します。任意のパラメータが null の場合、予測できない動作が発生する可能性があります。 |
| FitB | `5` | ページを表示し、その内容をバウンディングボックスがウィンドウ内に水平・垂直の両方で完全に収まるように拡大表示します。必要な水平および垂直の拡大率が異なる場合は、両方のうち小さい方を使用し、もう一方の次元でバウンディングボックスをウィンドウの中央に配置します。 |
| FitBH | `6` | ページを表示し、垂直座標 top をウィンドウの上端に配置し、ページの内容をバウンディングボックスの幅全体がウィンドウ内に収まるように拡大表示します。top が null の場合、そのパラメータの現在の値を変更せずに保持することを意味します。 |
| FitBV | `7` | ページを表示し、水平座標 left をウィンドウの左端に配置し、ページの内容をバウンディングボックスの高さ全体がウィンドウ内に収まるように拡大表示します。left が null の場合、そのパラメータの現在の値を変更せずに保持することを意味します。 |
