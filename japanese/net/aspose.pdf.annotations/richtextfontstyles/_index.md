## RichTextFontStyles enumeration

RichText のテキスト フラグメントのスタイル設定オプションです。

```csharp
[Flags]
public enum RichTextFontStyles
```

### 値

| 名前 | 値 | 説明 |
| --- | --- | --- |
| ClearExisting | `1` | 設定されている場合、追加のスタイルを適用する前に既存のすべてのスタイルをクリアします。他のスタイルフラグ（例: Bold）と組み合わせると、まずスタイルがリセットされ、指定されたスタイルが適用されます。このフラグがない場合、新しいスタイルは既存のスタイルに追加されます。 |
| Bold | `2` | 太字を指定するオプションです。 |
| Italic | `4` | 斜体を指定するオプションです。 |
| Underline | `8` | 下線を指定するオプションです。 |
