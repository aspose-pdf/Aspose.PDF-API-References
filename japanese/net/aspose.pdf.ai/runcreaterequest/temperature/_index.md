## RunCreateRequest.Temperature property

使用するサンプリング温度（0 から 2 の範囲）を取得または設定します。0.8 のような高い値は出力をよりランダムにし、0.2 のような低い値はより焦点が合い決定的になります。

public double? Temperature { get; set; }
