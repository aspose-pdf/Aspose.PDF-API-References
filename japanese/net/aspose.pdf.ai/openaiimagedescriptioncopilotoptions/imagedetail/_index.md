## OpenAIImageDescriptionCopilotOptions.ImageDetail property

ユーザーが指定した場合、画像の詳細レベルを取得または設定します。\"low\" はトークンを少なく使用し、\"high\" を使用すると高解像度を選択できます。設定しない場合はデフォルトで \"auto\" になります。

```csharp
public string ImageDetail { get; set; }
```
