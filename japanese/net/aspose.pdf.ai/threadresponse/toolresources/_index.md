## ThreadResponse.ToolResources property

このスレッドでアシスタントのツールに利用可能になるリソースのセットを取得または設定します。リソースはツールの種類に固有です。たとえば、code_interpreter ツールはファイル ID のリストが必要で、file_search ツールはベクトルストア ID のリストが必要です。

```csharp
public ToolResources ToolResources { get; set; }
```
