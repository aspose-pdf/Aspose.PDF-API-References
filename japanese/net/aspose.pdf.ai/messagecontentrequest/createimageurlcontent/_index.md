## MessageContentRequest.CreateImageUrlContent method

```csharp
public static MessageContentRequest CreateImageUrlContent(string imageUrl, string detail = "auto")
```

| パラメーター | タイプ | 説明 |
| --- | --- | --- |
| imageUrl | String | 画像の URL です。 |
| detail | String | 画像 URL の詳細です。ユーザーが指定した場合の画像の詳細レベルを指定します。"low" はトークン数が少なく、"high" を使用して高解像度を選択できます。デフォルトは "auto" です。 |
