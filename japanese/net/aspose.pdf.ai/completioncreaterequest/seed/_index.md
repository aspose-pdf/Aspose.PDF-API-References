## CompletionCreateRequest.Seed property

シード値を取得または設定します。この機能はベータ版です。指定した場合、システムは決定的にサンプリングしようと最善を尽くし、同じシードとパラメータでの繰り返しリクエストが同じ結果を返すようにします。ただし、決定性は保証されず、バックエンドの変更を監視するには system_fingerprint 応答パラメータを参照してください。

```csharp
public int? Seed { get; set; }
```
