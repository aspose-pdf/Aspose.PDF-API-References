## CompletionCreateRequest.FrequencyPenalty property

-2.0 から 2.0 の間の数値を取得または設定します。正の値は、これまでのテキスト中での既存頻度に基づいて新しいトークンにペナルティを課し、モデルが同じ行をそのまま繰り返す可能性を低減させます。

```csharp
public double? FrequencyPenalty { get; set; }
```
