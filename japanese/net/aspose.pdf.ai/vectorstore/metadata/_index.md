## VectorStore.Metadata property

ベクトルストアに添付できる 16 個のキーと値のペアのセットを取得または設定します。これはベクトルストアに関する追加情報を構造化された形式で保存するのに役立ちます。キーは最大 64 文字、値は最大 512 文字までです。

public Dictionary<string, string> Metadata { get; set; }
