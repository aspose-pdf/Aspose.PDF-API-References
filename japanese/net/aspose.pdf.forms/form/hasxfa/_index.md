## Form.HasXfa property

ドキュメントに XFA フォームが含まれるかどうかを示す値を取得します。このプロパティは、XFA フォームが存在し、[`IgnoreNeedsRendering`](../ignoreneedsrendering/) を使用すべきか判断するために導入されました。[`NeedsRendering`](../needsrendering/) が false の場合に XFA フォームを削除します。

```csharp
public bool HasXfa { get; }
```
