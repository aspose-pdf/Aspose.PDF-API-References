## Form.NeedsRendering property

ドキュメントが動的 XFA フォームの削除を必要とするかどうかを示す値を取得します。このプロパティは、XFA フォームが存在し、`NeedsRendering` が false の場合に [`IgnoreNeedsRendering`](../ignoreneedsrendering/) を使用して XFA フォームを削除すべきかを判断するために導入されました。

```csharp
public bool NeedsRendering { get; }
```
