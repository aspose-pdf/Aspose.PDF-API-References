## Form.SignaturesAppendOnly property

設定されている場合、ファイルがインクリメンタル更新ではなく、以前の内容を変更する形で保存（書き込み）されると無効になる可能性のある署名がDocumentに含まれます。

```csharp
public bool SignaturesAppendOnly { get; set; }
```
