## Form.IgnoreNeedsRendering property

このプロパティが true の場合、XFA フォームを標準フォームに変換する際に NeedsRendering キーの値が無視されます。デフォルトは false です。

```csharp
public bool IgnoreNeedsRendering { get; set; }
```
