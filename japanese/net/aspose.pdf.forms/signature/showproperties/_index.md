## Signature.ShowProperties property

署名プロパティの表示/非表示を強制します。ShowProperties が true の場合、署名フィールドは外観の事前定義フォーマット（文字列で表現）を持ちます： ------------------------------------------- Digitally signed by {certificate subject} Date: {signature.Date} Reason: {signature.Reason} Location: {signature.Location} ------------------------------------------- ここで {X} は X の値のプレースホルダーです。また、署名に画像がある場合、これらの文字列は画像上に配置されます。ShowProperties はデフォルトで true です。

```csharp
public bool ShowProperties { get; set; }
```
