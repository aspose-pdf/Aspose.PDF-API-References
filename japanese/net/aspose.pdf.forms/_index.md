**Aspose.Pdf.Forms** 名前空間には、標準、静的、動的フォームや、テキストボックス、リストボックス、ラジオボタンなどのさまざまなフィールドを記述するクラスがあります。

## クラス

| クラス | 説明 |
| --- | --- |
| [BarcodeField](./barcodefield/) | クラスはバーコードフィールドを表します。 |
| [ButtonField](./buttonfield/) | クラスはプッシュボタンフィールドを表します。 |
| [CheckboxField](./checkboxfield/) | クラスはチェックボックスフィールドを表します。 |
| [ChoiceField](./choicefield/) | 選択フィールドの基底クラスを表します。 |
| [ComboBoxField](./comboboxfield/) | クラスはフォームのコンボボックスフィールドを表します。 |
| [DateField](./datefield/) | カレンダー表示付きの日付フィールド。 |
| [DocMDPSignature](./docmdpsignature/) | document MDP（変更検出および防止）署名タイプのクラスを表します。 |
| [ExternalSignature](./externalsignature/) | X509Certificate2 を使用して分離型 PKCS#7 署名を作成します。エクスポート可能なプライベートキーを持たない USB スマートカードやトークンをサポートします。 |
| [Field](./field/) | Acro フォームフィールドの基底クラスです。 |
| [FileSelectBoxField](./fileselectboxfield/) | ファイル選択ボックス要素のフィールドです。 |
| [Form](./form/) | クラスはフォームオブジェクトを表します。 |
| [IconFit](./iconfit/) | ウィジェットアノテーションのアイコンがアノテーション矩形内にどのように表示されるかを記述します。 |
| [ListBoxField](./listboxfield/) | クラスはリストボックスフィールドを表します。 |
| [NumberField](./numberfield/) | 指定された有効文字を持つテキストフィールド |
| [Option](./option/) | クラスは選択フィールドのオプションを表します。 |
| [OptionCollection](./optioncollection/) | クラスは選択フィールドのオプションコレクションを表します。 |
| [PasswordBoxField](./passwordboxfield/) | クラスはパスワード入力用テキストフィールドを記述します。 |
| [PKCS1](./pkcs1/) | PKCS#1 標準に関する署名オブジェクトを表します。署名には RSA 暗号化アルゴリズムと SHA-1 ダイジェスト方式が使用されます。 |
| [PKCS7](./pkcs7/) | Internet RFC 2315、PKCS #7: Cryptographic Message Syntax、Version 1.5 の PKCS#7 仕様に準拠した PKCS#7 オブジェクトを表します。ドキュメントのバイト範囲の `SHA1 digest` が PKCS#7 SignedData フィールドにカプセル化されます。 |
| [PKCS7Detached](./pkcs7detached/) | Internet RFC 2315、PKCS #7: Cryptographic Message Syntax、Version 1.5 の PKCS#7 仕様に準拠した PKCS#7 オブジェクトを表します。ドキュメントのバイト範囲に対する元の署名メッセージダイジェストが通常の PKCS#7 SignedData フィールドとして組み込まれます。PKCS#7 SignedData フィールドにはデータがカプセル化されません。 |
| [RadioButtonField](./radiobuttonfield/) | ラジオボタン フィールドを表すクラスです。 |
| [RadioButtonOptionField](./radiobuttonoptionfield/) | RadioButton フィールドの項目を表すクラスです。 |
| [RichTextBoxField](./richtextboxfield/) | リッチテキストエディタ コンポーネントを記述するクラスです。 |
| [Signature](./signature/) | PDF ドキュメント内の署名オブジェクトを表す抽象クラスです。署名は署名オブジェクトの値を持つフィールドであり、これらはドキュメントの有効性を検証するために使用されるデータを含みます。 |
| [SignatureCustomAppearance](./signaturecustomappearance/) | 署名カスタム外観オブジェクトを表す抽象クラスです。 |
| [SignatureField](./signaturefield/) | 署名フォーム フィールドを表します。 |
| [SignHash](./signhash/) | ドキュメントハッシュに対してカスタム署名を行うデリゲートです。 |
| [TextBoxField](./textboxfield/) | テキストボックス フィールドを表すクラスです。 |
| [XFA](./xfa/) | XML Forms Architecture (XFA) に関する XML フォームを表します。 |
## 列挙体

| 列挙体 | 説明 |
| --- | --- |
| [BoxStyle](./boxstyle/) | チェックボックス内のチェック描画用スタイルを表します。 |
| [DocMDPAccessPermissions](./docmdpaccesspermissions/) | このドキュメントに付与されたアクセス許可です。有効な値は次のとおりです：1 - ドキュメントへの変更は許可されません。変更すると署名が無効になります。2 - 許可される変更はフォームへの入力、ページテンプレートのインスタンス化、署名です。その他の変更は署名を無効にします。3 - 2 と同じ許可に加えて、注釈の作成、削除、変更が許可されます。その他の変更は署名を無効にします。 |
| [FormType](./formtype/) | Acro Form の可能なタイプの列挙です。 |
| [IconCaptionPosition](./iconcaptionposition/) | アイコンの位置を記述します。 |
| [ScalingMode](./scalingmode/) | 使用すべき拡大縮小のタイプです。 |
| [ScalingReason](./scalingreason/) | アイコンが注釈矩形内で拡大縮小される条件です。 |
| [SubjectNameElements](./subjectnameelements/) | 署名サブジェクト文字列の要素を記述する列挙です。 |
| [Symbology](./symbology/) | (バーコード) シンボロジーは特定のバーコードタイプの技術的詳細、例えばバーの幅、文字セット、エンコード方法、チェックサムの仕様などを定義します。 |
