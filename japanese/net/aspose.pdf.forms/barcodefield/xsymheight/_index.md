## BarcodeField.XSymHeight property

2 つのバーコードモジュール間の垂直距離（ピクセル単位）を取得します。比率 XSymHeight/XSymWidth は整数でなければなりません。PDF417 の場合、許容される比率範囲は 1 から 4 です。QRCode および DataMatrix の場合、この比率は常に 1 です。

```csharp
public int XSymHeight { get; }
```
