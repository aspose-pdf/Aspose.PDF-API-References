**Aspose.Pdf.Structure** 名前空間は、ドキュメントの論理構造（章やセクションへの編成、図表や脚注などの特別な要素の識別）を扱うのに役立つクラスを提供します。

## クラス

| クラス | 説明 |
| --- | --- |
| [Element](./element/) | 論理構造の基本要素を表すクラスです。 |
| [ElementCollection](./elementcollection/) | 基本的な論理構造要素のコレクションです。 |
| [FigureElement](./figureelement/) | 論理構造の図を表すクラスです。 |
| [RootElement](./rootelement/) | ルート構造要素。 |
| [StructElement](./structelement/) | 一般的な構造要素。 |
| [TextElement](./textelement/) | 文書論理構造の一般テキスト要素。 |
