## FontEmbeddingOptions class

PDF/A 標準では、すべてのフォントを文書に埋め込むことが要求されます。<br/>            このクラスは、フォントが存在せず埋め込むことができない場合のフラグを含みます。<br/>            目的の PC 上にフォントがない場合です。

FontEmbeddingOptions 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| FontEmbeddingOptions() | FontEmbeddingOptions クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| use_default_substitution | 埋め込みされていないフォントをデフォルトのフォント置換戦略で置き換えることを宣言します。デフォルトは falseです； |
