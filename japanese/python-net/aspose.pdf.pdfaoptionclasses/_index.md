aspose.pdf.pdfaoptionclasses は、PDF/A 変換オプションのための名前空間です。

## クラス
| クラス | 説明 |
| :- | :- |
| [FontEmbeddingOptions](/pdf/python-net/aspose.pdf.pdfaoptionclasses/fontembeddingoptions/) | PDF/A 標準では、すべてのフォントを文書に埋め込むことが要求されます。<br/>            このクラスは、フォントが存在せず埋め込むことができない場合のフラグを含みます。<br/>            目的の PC 上にフォントがない場合です。 |
