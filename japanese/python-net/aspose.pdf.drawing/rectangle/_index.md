## Rectangle class

矩形を表します。

Rectangle 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Rectangle(left, bottom, width, height) | Rectangle クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| graph_info | グラフ情報（色、<br/>            線幅など）を示す [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) オブジェクトを取得または設定します |
| text | シェイプのテキストを取得または設定します |
| rounded_corner_radius | 矩形の角の半径を示す float 値を取得または設定します。 |
| left | 矩形の左位置を示す float 値を取得または設定します。 |
| bottom | 矩形の下位置を示す float 値を取得または設定します。 |
| width | 矩形の幅を示す float 値を取得または設定します。 |
| height | 矩形の高さを示す float 値を取得または設定します。 |
