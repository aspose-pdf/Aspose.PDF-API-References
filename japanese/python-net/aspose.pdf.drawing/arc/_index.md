## Arc class

円弧を表します。

Arc 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Arc クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| graph_info | グラフ情報（色、<br/>            線幅など）を示す [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) オブジェクトを取得または設定します |
| text | シェイプのテキストを取得または設定します |
| pos_x | 円弧の中心の x 座標を示す float 値を取得または設定します。 |
| pos_y | 円弧の中心の y 座標を示す float 値を取得または設定します。 |
| radius | 円弧の半径を示す float 値を取得または設定します。 |
| alpha | 円弧の開始角度（度）を示す float 値を取得または設定します。 |
| beta | 円弧の終了角度（度）を示す float 値を取得または設定します。 |
