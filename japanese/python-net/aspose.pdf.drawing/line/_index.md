## Line class

直線を表します。

Line 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Line(position_array) | Line クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| graph_info | グラフ情報（色、<br/>            線幅など）を示す [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) オブジェクトを取得または設定します |
| text | シェイプのテキストを取得または設定します |
| position_array | 位置配列を示す [position_array](/pdf/python-net/aspose.pdf.drawing/line/) オブジェクトを取得または設定します。配列は <br/>            ラインの各制御点の座標で構成されています。 <br/>            直接。 |
