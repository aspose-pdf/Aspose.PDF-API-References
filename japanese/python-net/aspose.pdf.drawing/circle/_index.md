## Circle class

円を表します。

Circle 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Circle(pos_x, pos_y, radius) | Circle クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| graph_info | グラフ情報（色、<br/>            線幅など）を示す [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) オブジェクトを取得または設定します |
| text | シェイプのテキストを取得または設定します |
| pos_x | 円の中心の x 座標を示す float 値を取得または設定します。 |
| pos_y | 円の中心の y 座標を示す float 値を取得または設定します。 |
| radius | 円の半径を示す float 値を取得または設定します。 |
