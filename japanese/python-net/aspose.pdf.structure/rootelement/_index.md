## RootElement class

ルート構造要素。

RootElement 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| children | 子要素コレクションを取得します。 |
| lang | (Optional; PDF 1.4) すべてのテキストの自然言語を指定する言語です<br/>            構造要素内のテキストは、入れ子になった構造要素やマーク付きコンテンツの言語指定で上書きされない限り適用されます。 |
| actual_text | (Optional; PDF 1.4) 構造要素とその子要素の正確な置換となるテキストです。<br/>            この置換テキストは（可能な限り小さなコンテンツ単位に適用すべきです）<br/>            障害を持つユーザーへのアクセシビリティ支援やその他の目的で文書内容を抽出する際に有用です。 |
| alt | （オプション）構造要素とその子要素の代替説明<br/>            人間が読みやすい形式で、文書の内容を抽出する際に、障害を持つユーザーへのアクセシビリティ支援やその他の目的で役立ちます。 |
| e | （オプション; PDF 1.5）省略形の展開形です。 |
