## PageCoordinateType enumeration

ページ座標タイプを記述します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| MEDIA_BOX | MediaBox はページの幅と高さを指定するために使用されます。 <br/>            一般的なユーザーにとって、これは実際のページサイズと同等である可能性があります。 <br/>            MediaBox は PDF の中で最大のページボックスです。他のページボックスは MediaBox と同じサイズにすることはできますが、より大きくすることはできません。 |
