## XForm class

クラスは XForm を表します。

XForm 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| b_box | フォームのバウンディングボックスを取得または設定します。 |
| name | フォーム名を取得または設定します。フォーム名はページリソースの XObejct 辞書でフォームを参照するために使用される名前です。 |
| contents | フォームの演算子を取得します。 |
| opi | Open Prepress Interface (OPI) を取得します。 |
| matrix | フォームの行列を取得または設定します。 |
| resources | Form XObject のリソースを取得します。 |
| rectangle | フォームの rectangel を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_resources(allow_create) | Form X-Object のリソースを返します |
| get_resources() | Form X-Object のリソースを返します |
| create_new_form(source, document) | ページの内容を複製する XForm を作成します。 |
| free_memory() | キャッシュされたデータをクリアします |
