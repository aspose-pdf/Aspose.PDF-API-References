## Point class

小数座標を持つ点を表します。

Point 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Point(x, y) | Point クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| x | X 座標の値。 |
| y | Y 座標の値。 |
| 自明 | 座標がすべて0の点を取得します。 |
