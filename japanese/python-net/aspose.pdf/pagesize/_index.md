## PageSize class

PDF 文書内のページサイズを表すクラスです。

PageSize 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| PageSize(x, y) | PageSize クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| width | ページ幅を取得または設定します。 |
| height | ページの高さを取得または設定します。 |
| is_landscape | ページの向きを取得します。横向きの場合は true、縦向きの場合は false を返します。 |
| a0 | A0 サイズ（1189×840 mm）。 |
| a1 | A1 サイズ（840×594 mm）。 |
| a2 | A2 サイズ（594×420 mm）。 |
| a3 | A3 サイズ (420x297 mm). |
| a4 | A4 サイズ (297x210 mm). |
| a5 | A5 サイズ (210x148 mm). |
| a6 | A6 サイズ (148x105 mm). |
| b5 | B5 サイズ (250x176 mm). |
| page_letter | レター サイズ (279x216 mm). |
| page_legal | リーガル サイズ (356x216 mm). |
| page_ledger | レッジャー サイズ (432x279 mm). |
| p11x17 | 11x17 インチ フォーマット. |
