## PageLabelCollection class

ページラベルコレクションを表すクラスです。

PageLabelCollection 型は次のメンバーを公開します:
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_label(page_index) | ページインデックス (0 から開始) によってページラベルを取得します。 |
| update_label(page_index, page_label) | 指定されたページインデックスのラベルを更新します（ページインデックスは0から開始します）。 |
| remove_label(page_index) | ページインデックスでラベルを削除します（ページインデックスは0から開始します）。 |
| get_pages() | コレクション内のページインデックスを取得します。 |
