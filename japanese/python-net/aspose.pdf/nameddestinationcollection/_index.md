## NamedDestinationCollection class

クラスは PDF ドキュメント内のすべてのデスティネーション（名前文字列をデスティネーションにマッピングする名前ツリー（12.3.2.3「Named Destinations」参照）および（7.7.4「Name Dictionary」参照））のコレクションを表します。

NamedDestinationCollection 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| count | 名前付きデスティネーションの数。 |
| names | デスティネーション名のリスト。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| remove(name) | 名前付きデスティネーションを削除します。 |
| add(name, appointment) | 新しい名前付きデスティネーションを追加します。 |
