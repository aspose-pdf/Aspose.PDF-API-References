## PageActionCollection class

このクラスはページアクションを記述します。

PageActionCollection 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| on_open | ページが開かれたときに実行されるアクションです。 |
| on_close | ページが閉じられたときに実行されるアクションです。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| remove_actions() | 注釈のすべてのアクションを削除します。 |
