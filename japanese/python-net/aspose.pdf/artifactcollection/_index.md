## ArtifactCollection class

Classはアーティファクト コレクションを表します。

ArtifactCollection 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_synchronized | このオブジェクトは同期されていますか。 |
| sync_root | コレクションの同期オブジェクトを取得します。 |
## Indexer
| 名前 | 説明 |
| :- | :- |
| [index] | インデックスでアーティファクトを取得します。インデックスは 1 から開始します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| delete(artifact) | 指定されたアーティファクトを削除します。 |
| delete(index) | インデックスでアーティファクトを削除します。 |
| find_by_value(name, expected_value) | カスタム値でアーティファクトを検索します。 |
| update(artifact) | コレクション内のアーティファクトを更新します。 |
