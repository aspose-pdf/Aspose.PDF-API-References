## OutlineCollection class

文書のアウトライン階層を表します。

OutlineCollection 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| visible_count | Count は、すべてのレベルにおける表示可能な子アウトライン項目の数の合計です。注意: コレクション内の項目数を示す Count と混同しないでください。 |
| first | アウトラインの最上位項目の最初の項目を表すアウトライン アイテムを取得します。 |
| last | アウトラインの最上位項目の最後の項目を表すアウトライン アイテムを取得します。 |
| is_synchronized | このコレクションへのアクセスが同期化されているか（スレッドセーフ）を示す値を取得します。 |
| sync_root | このコレクションへのアクセスを同期化するために使用できるオブジェクトを取得します。 |
## Indexer
| 名前 | 説明 |
| :- | :- |
| [index] | インデックスでコレクションからアウトライン アイテムを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| delete() | ドキュメントのアウトラインからすべてのアウトライン アイテムを削除します。 |
| delete(name) | 指定されたタイトルを持つアウトライン アイテムをドキュメントのアウトラインから削除します。 |
