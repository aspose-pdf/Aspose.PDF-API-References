## PageMode enumeration

クラスはドキュメントページで使用されるコンポーネントを記述します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| USE_NONE | コンポーネントを使用しません。 |
| USE_OUTLINES | 文書アウトラインが表示されます。 |
| USE_THUMBS | サムネイル画像が表示されます。 |
| FULL_SCREEN | FullScreen フルスクリーンモードです。メニューバーやウィンドウコントロール、その他のウィンドウは表示されません。 |
| USE_OC | オプションコンテンツグループパネルが表示されます。 |
| USE_ATTACHMENTS | 添付ファイルパネルが表示されます。 |
