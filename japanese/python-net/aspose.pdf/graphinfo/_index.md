## GraphInfo class

グラフィックス情報を表します。

GraphInfo 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| GraphInfo() | GraphInfo クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| line_width | グラフの線幅を示す float 値を取得または設定します。 |
| color | グラフの色を示す [color](/pdf/python-net/aspose.pdf/graphinfo/) オブジェクトを取得または設定します。 |
| dash_array | ダッシュ配列を取得または設定します。 |
| dash_phase | ダッシュフェーズを取得または設定します。 |
| fill_color | グラフの塗りつぶし色を示す [color](/pdf/python-net/aspose.pdf/graphinfo/) オブジェクトを取得または設定します。 |
| is_doubled | 境界が二重かどうかを取得または設定します。 |
| skew_angle_x | 座標系を変換するときの x 座標のせん断角度を示す float 値を取得または設定します。 |
| skew_angle_y | 座標系を変換するときの y 座標のせん断角度を示す float 値を取得または設定します。 |
| scaling_rate_x | 座標系を変換するときの x 座標のスケーリング率を示す float 値を取得または設定します。 |
| scaling_rate_y | 座標系を変換するときの y 座標のスケーリング率を示す float 値を取得または設定します。 |
| rotation_angle | 座標系の回転角度を示す float 値を取得または設定します <br/>            座標系を変換する際に。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| clone() | グラフィック情報をクローンします。 |
