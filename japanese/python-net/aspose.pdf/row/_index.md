## Row class

テーブルの行を表します。

Row 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Row() | Row クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| background_color | 背景色を取得または設定します。 |
| border | 境界線を取得または設定します。 |
| セル | 行のセルを取得します。 |
| default_cell_border | デフォルトのセル境界線を取得します; |
| min_row_height | 行の高さを取得します; |
| fixed_row_height | 固定行の高さを取得します - 行は固定高さになる場合があります; |
| is_in_new_page | 固定行が新しいページにあるか取得します - このプロパティが設定されたページは次のページに印刷されるべきです デフォルトは false; |
| is_row_broken | 行が2ページ間で分割できるか取得します |
| default_cell_text_state | 行セルのデフォルトテキスト状態を取得または設定します |
| default_cell_padding | 行セルのデフォルト余白を取得または設定します |
| vertical_alignment | 垂直方向の配置を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| clone() | 行をクローンします。 |
