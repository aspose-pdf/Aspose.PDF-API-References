## HtmlPageLayoutOption enumeration

ページのサイズとレイアウトを決定する他のオプションと組み合わせるフラグを指定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | HtmlPageLayoutOption がページのサイズやレイアウトに影響しないことを示すデフォルト値です。 |
| FIT_TO_WIDEST_CONTENT_WIDTH | ページ幅が指定されたページ幅ではなく、コンテンツサイズ自体から決定されることを示します。 |
| SCALE_TO_PAGE_WIDTH | ドキュメントの内容がページに合わせて拡大縮小されることを示します。 |
