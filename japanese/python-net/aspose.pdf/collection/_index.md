## Collection class

コレクション (12.3.5 Collections) 用のクラスを表します。

Collection 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Collection() | 新しい Collection オブジェクトを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_synchronized | このコレクションへのアクセスが同期化されているか（スレッドセーフ）を示す値を取得します。 |
| sync_root | このコレクションへのアクセスを同期化するために使用できるオブジェクトを取得します。 |
| keys | ファイル添付キーのリストを返します。 |
| default_entry | デフォルトの埋め込みファイル名です。 |
## Indexer
| 名前 | 説明 |
| :- | :- |
| [index] | インデックスで埋め込みファイルを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| delete(name) | コレクション内のキーでコレクションからファイルを削除します。 |
| delete() | コレクション内のキーでコレクションからファイルを削除します。 |
| add(key, file) | 指定されたキーで埋め込みファイルにファイルを追加します。 |
| delete_by_key(key) | コレクション内のキーでコレクションからファイルを削除します。 |
| find_by_name(name) | 名前で埋め込みファイルを返します。 |
