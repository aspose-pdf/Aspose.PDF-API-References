## SaveFormat enumeration

形式を指定します

## Members
| メンバー名 | 説明 |
| :- | :- |
| PDF | 形式を変更せずに保存することを意味します。すなわち PDF として<br/>             代わりに 'SaveFormat.None' を使用してください。これは廃止されたものです |
| NONE | 形式を変更せずに保存することを意味します。すなわち PDF として<br/>             これは廃止されたもので、最終的に削除されます。<br/>             代わりに 'SaveFormat.Pdf' を使用してください |
| DOC | DOC 形式で保存することを意味します |
| XPS | XPS 形式で保存することを意味します |
| HTML | HTML 形式で保存することを意味します |
| XML | XML 形式で保存することを意味します |
| TE_X | LaTeX テキストエディタに適した形式、すなわち TEX 形式で保存することを意味します |
| DOC_X | DOCX 形式で保存することを意味します |
| SVG | SVG 形式で保存することを意味します |
| MOBI_XML | MobiXML 形式（電子書籍の特殊形式）で保存することを意味します |
| EXCEL | MsExcel 形式で保存することを意味します |
| EPUB | EPUB 形式（電子書籍の特殊形式）で保存することを意味します |
| PPTX | PPTX 形式で保存することを意味します |
| APS | APS XML ファイルとして保存しています。 |
| PDF_XML | XML 形式の内部 PDF ドキュメント構造 |
