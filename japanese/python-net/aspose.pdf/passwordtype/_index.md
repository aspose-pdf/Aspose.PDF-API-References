## PasswordType enumeration

この列挙型はパスワード保護されたPDFドキュメントで使用される既知のパスワードタイプを表します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | PDF ドキュメントはパスワードで保護されていません。 |
| USER | Pdf ドキュメントはドキュメントオープンパスワードを使用して開かれました（制限付きアクセス）。 |
| 所有者 | Pdf ドキュメントは権限変更パスワードを使用して開かれました（フルアクセス）。 |
| アクセス不可 | Pdf ドキュメントはパスワードで保護されていますが、ユーザーと所有者のパスワードはどちらも空ではなく、<br/>            パスワードが定義されていないか、提供されたパスワードが正しくありません。そのため、パスワードの種類を推測することはできません。 |
