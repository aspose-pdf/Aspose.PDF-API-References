## Opi class

Open Prepress Interface (OPI) は、低解像度のプレースホルダーまたはプロキシを作成する仕組みであり、<br/>            そのような高解像度画像のためのものです。

Opi 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Opi(xform) | Opi クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| version | この辞書が参照する OPI のバージョンを取得します。 |
| file_specification | 低解像度プロキシ画像を含む外部ファイルを取得します。 |
| position | 切り抜かれた画像のページ上の位置を指定する形式の 8 つの数値の配列を取得します。 |
