## ImagePlacement class

PDF ドキュメントページに配置された画像の特性を表します。

ImagePlacement 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| matrix | この画像の現在の変換行列。 |
| rectangle | 画像の矩形を取得します。 |
| 演算子 | 画像を表示するために使用される演算子。 |
| rotation | 画像の回転角度を取得します。 |
| resolution | 画像の解像度を取得します。 |
| image | 関連する XImage リソースオブジェクトを取得します。 |
| page | 画像を含むページを取得します。 |
| compositing_parameters | ページに配置された画像に対してアクティブなグラフィックス状態の合成パラメータを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| save(stream) | 画像を対応する変換（スケーリング、回転、解像度）で保存します。 |
| save(stream, format) | 画像を対応する変換（スケーリング、回転、解像度）で保存します。 |
| hide() | ページから画像を削除します。 |
| replace(image) | コレクション内の画像を別の画像に置き換えます。 |
