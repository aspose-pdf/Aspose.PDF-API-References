## XmpField class

XMP フィールドを表します。

XmpField 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| 空 | 空の xmp フィールドを取得します。 |
| lang | xml:lang 修飾子を取得します。 |
| prefix | prefix を取得します。 |
| namespace_uri | namespace URI を取得します。 |
| local_name | local の名前を取得または設定します。 |
| name | 名前を取得します。 |
| value | 値を取得します。 |
| field_type | フィールドの型を取得します。 |
| is_empty | このインスタンスが空かどうかを示す値を取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| to_structure() | 構造体として値を取得します。 |
| to_array() | 配列として値を取得します。 |
