## ComHelper class

COM クライアントが Aspose.Pdf にドキュメントをロードするためのメソッドを提供します。

ComHelper 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| ComHelper() | ComHelper クラスの新しいインスタンスを初期化します |
## メソッド
| 名前 | 説明 |
| :- | :- |
| open_stream(input) | 新しい Document インスタンスを初期化して返します |
| open_stream(input, password) | 新しい Document インスタンスを初期化して返します |
| open_stream(input, is_managed_stream) | 新しい Document インスタンスを初期化して返します |
| open_stream(input, password, is_managed_stream) | 新しい Document インスタンスを初期化して返します |
| open_stream(input, options) | ストリームから既存のドキュメントを開き、PDF ドキュメントを取得するために必要な変換を行って返します。 |
| open_file(filename) | Document を使用して作成し、返します。 |
| open_file(filename, password) | Document を使用して作成し、返します。 |
| open_file(filename, password, is_managed_stream) | 暗号化されたドキュメントを操作するために、[Document](/pdf/python-net/aspose.pdf/document/) クラスの新しいインスタンスを初期化します。 |
| open_file(filename, options) | ファイルから既存のドキュメントを開き、PDF ドキュメントを取得するために必要な変換オプションを提供します。 |
