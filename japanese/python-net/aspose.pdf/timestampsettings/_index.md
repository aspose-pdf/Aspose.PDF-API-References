## TimestampSettings class

署名プロセス中に使用される OCSP 設定を表します。

TimestampSettings 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TimestampSettings(server_url, basic_auth_credentials, digest_hash_algorithm) | TimestampSettings クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| server_url | タイムスタンプサーバーの URL を取得または設定します。 |
| basic_auth_credentials | 基本認証のクレデンシャルを取得または設定します。ユーザー名とパスワードは文字列 "username:password" に結合されます。 |
| digest_hash_algorithm | 内部ハッシュ関数用のダイジェストアルゴリズムを取得または設定します。 |
