## PageInfo class

ページ情報を表します。

PageInfo 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| PageInfo() | PageInfo クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| any_margin | 最初のページを除く任意のページの余白を取得または設定します。 |
| default_text_state | デフォルトフォントを取得または設定します。 |
| height | ページの高さを取得または設定します。 |
| pure_height | ページの余白なしの純高さを取得または設定します。 |
| is_landscape | ページが横向きかどうかを取得または設定します。 |
| margin | ページ余白を取得または設定します。 |
| width | ページ幅を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| clone() | ページ情報をクローンします。 |
