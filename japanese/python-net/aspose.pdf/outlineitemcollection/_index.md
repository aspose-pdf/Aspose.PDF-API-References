## OutlineItemCollection class

PDF 文書のアウトライン階層内のエントリを表します。

OutlineItemCollection 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| OutlineItemCollection(outlines) | OutlineItemCollection クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| visible_count | ドキュメントのアウトライン階層のすべてのレベルにおけるアウトライン項目の総数を取得します。 |
| タイトル | このアウトライン項目のタイトルを取得または設定します。 |
| destination | このアウトライン項目の宛先を取得または設定します。 |
| action | このアウトライン項目のアクションを取得または設定します。 |
| color | このアウトライン項目のタイトルテキストの色を取得または設定します。 |
| 斜体 | このアウトライン項目のタイトルテキストの斜体フラグを取得または設定します |
| 太字 | このアウトライン項目のタイトルテキストの太字フラグを取得または設定します |
| first | アウトライン階層で最上位の最初の項目を表すアウトライン項目を取得します。 |
| last | アウトライン階層で最上位の最後の項目を表すアウトライン項目を取得します。 |
| 前 | この項目に対して相対的に前の項目を表すアウトライン項目を取得します。 |
| 次 | この項目に対して相対的に次の項目を表すアウトライン項目を取得します。 |
| has_next | この項目に対して相対的に次の項目を表すアウトライン項目があるかどうかを確認します。 |
| parent | アウトライン階層でこのアウトライン項目の親オブジェクトを取得します。 |
| is_synchronized | このコレクションへのアクセスが同期化（スレッドセーフ）されているかどうかを示す値を取得します。 |
| sync_root | このコレクションへのアクセスを同期化するために使用できるオブジェクトを取得します。 |
| open | アウトライン項目の開閉状態（true/false）を取得または設定します。 |
| level | アウトライン項目の階層レベルを取得します。 |
## Indexer
| 名前 | 説明 |
| :- | :- |
| [index] | インデックスを使用してコレクションからアウトライン項目を取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| delete() | このアウトライン項目を文書のアウトライン階層から削除します。 |
| delete(name) | 指定された名前のアウトラインエントリを文書のアウトライン階層から削除します。 |
| insert(index, outline) | 指定された位置にコレクションへアウトライン項目を挿入します。 |
