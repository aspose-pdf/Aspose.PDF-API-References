## Resources class

ページリソースを表すクラスです。

Resources 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| forms | [forms](/pdf/python-net/aspose.pdf/resources/) フォームコレクションを取得します |
| images | [images](/pdf/python-net/aspose.pdf/resources/) 画像コレクションを取得します |
| fonts | [fonts](/pdf/python-net/aspose.pdf/resources/) リソースコレクションを取得します |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_fonts(create_if_absent) | フォントコレクションを返します。リソースにフォントエントリが含まれていない場合、CreateIfAbsent フラグに応じて作成されます。 |
