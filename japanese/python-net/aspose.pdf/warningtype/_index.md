## WarningType enumeration

この列挙型は警告タイプを表します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| SOURCE_FILE_CORRUPTION | ファイルが破損しています。 |
| DATA_LOSS | テキスト/チャート/画像またはその他のデータが、ロード後のドキュメントツリー、または保存後に作成されたドキュメントのいずれかから完全に欠落しています。 |
| MAJOR_FORMATTING_LOSS | 元のドキュメントと比較して大幅な書式設定の損失があります。これは、書式設定の損失が大きいがデータはまだ存在する場合に該当します。 |
| MINOR_FORMATTING_LOSS | 元のドキュメントと比較した軽微な書式の損失です。これは忠実度の軽微な損失に関するものです。 |
| COMPATIBILITY_ISSUE | 特定のユーザーエージェントまたは以前のバージョンのユーザーエージェントによってドキュメントが開けなくなる既知の問題です。 |
| INVALID_INPUT_STREAM_TYPE | 無効な入力ストリームタイプ |
| UNEXPECTED_CONTENT | ファイルに予期しないコンテンツが含まれています。 |
