## Cell class

テーブル行のセルを表します。

Cell 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Cell(rect) | Cell クラスの新しいインスタンスを初期化します |
| Cell() | Cell クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_no_border | セルの枠線の有無を取得または設定します。 |
| margin | 余白を取得または設定します。 |
| border | 境界線を取得または設定します。 |
| background_color | 背景色を取得または設定します。 |
| background_image_file | 背景画像ファイルを取得または設定します。 |
| background_image | 背景画像を取得または設定します |
| alignment | 配置を取得または設定します。 |
| default_cell_text_state | デフォルトのセルテキスト状態を取得または設定します。 |
| is_override_by_fragment | セルの TextState プロパティが TextFragment の TextState プロパティによって上書きされるように設定します。 |
| paragraphs | セルの書式設定されたテキストを取得または設定します。 |
| is_word_wrapped | セルのテキストの折り返しを取得または設定します。 |
| vertical_alignment | 垂直方向の配置を取得または設定します。 |
| col_span | 列のスパンを取得または設定します。 |
| row_span | 行のスパンを取得または設定します。 |
| width | 列幅を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| clone() | セルをクローンします。 |
