## DocumentInfo class

PDF ドキュメントのメタ情報を表します。

DocumentInfo 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| DocumentInfo(document) | DocumentInfo クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| タイトル | ドキュメントのタイトルを取得または設定します。 |
| creator | ドキュメントの作成者を取得または設定します。 |
| author | ドキュメントの著者を取得または設定します。 |
| subject | ドキュメントの件名を取得または設定します。 |
| keywords | ドキュメントのキーワードを取得または設定します。 |
| producer | ドキュメントのプロデューサーを取得または設定します。 |
| creation_date | ドキュメント作成日を取得または設定します。 |
| creation_time_zone | 作成日のタイムゾーン。 |
| mod_time_zone | 更新日のタイムゾーン。 |
| mod_date | ドキュメントの更新日を取得または設定します。 |
| trapped | trapped フラグを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| add(key, value) | 指定されたキーと値を持つ要素をコレクションに追加します。 |
| remove(key) | 指定されたキーを持つ要素をコレクションから削除します。 |
| clear_custom_data() | カスタムデータのみをクリアし、他のすべての事前定義された値（Title、Author など）を残します。 |
| is_predefined_key(key) | キーが事前定義されているか（Title、Author など）を判定し、カスタムではありません。 |
