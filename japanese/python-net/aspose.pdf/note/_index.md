## Note class

このクラスはジェネレータ段落ノートを表します。

Note 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Note() | 新しい [Note](/pdf/python-net/aspose.pdf/note/) クラスのインスタンスを初期化します。 |
| Note(content) | Note クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| paragraphs | 脚注内のすべての段落を示すコレクションを取得または設定します |
| text | ノートテキストを取得または設定します |
| text_state | ノートテキストの状態を取得または設定します |
