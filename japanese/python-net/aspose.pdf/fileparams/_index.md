## FileParams class

追加のファイル固有情報を含む埋め込みファイルパラメータ辞書を定義します。

FileParams 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| FileParams(spec) | FileParams クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| サイズ | 埋め込みファイルの非圧縮サイズ（バイト単位）。 |
| creation_date | 埋め込みファイルが作成された日時。 |
| mod_date | 埋め込みファイルが最後に変更された日時。 |
| check_sum | 非圧縮埋め込みファイルのバイトのチェックサムである 16 バイトの文字列です。 <br/>            チェックサムは標準的な MD5 メッセージダイジェストアルゴリズムを適用して、埋め込みファイルストリームのバイトから計算されます。 |
