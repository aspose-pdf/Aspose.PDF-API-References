## PdfANonSpecificationFlags class

このクラスは、ソース PDF 文書が PDF 仕様に準拠していない場合の PDF/A 変換を制御するフラグを保持します。<br/>            これらのフラグを使用するとパフォーマンスが低下しますが、通常の方法でソース PDF 文書を PDF/A 形式に変換できない場合に必要です。<br/>            デフォルトでは、すべてのフラグが false に設定されています。

PdfANonSpecificationFlags 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| PdfANonSpecificationFlags() | PdfANonSpecificationFlags クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| check_different_names_in_font_dictionaries | 一部の PDF ドキュメントには、内部データで名前が異なるフォントが含まれています。 <br/>            このフラグを使用すると、BaseFont と FontDescriptor.FontName フィールドが異なる場合の特別な処理ロジックが適用されます。 |
