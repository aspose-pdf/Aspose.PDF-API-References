## XmpPdfAExtensionField class

このスキーマは構造化型のフィールドを記述します。PDF/A プロパティ値タイプ <br/>            スキーマに非常に似ていますが、プロパティの代わりに構造内のフィールドを定義します。<br/>            スキーマ名前空間 URI: http://www.aiim.org/pdfa/ns/field#<br/>            必要なスキーマ名前空間プレフィックス: pdfaField。

XmpPdfAExtensionField 型は次のメンバーを公開します：

| 名前 | 説明 |
| :- | :- |
| XmpPdfAExtensionField(name, value, value_type, description) | XmpPdfAExtensionField クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| description | 説明を取得します。 |
| value | 値を取得または設定します。 |
| name | フィールド名。フィールド名は有効な XML 要素名でなければなりません。 |
| value_type | フィールド値タイプは XMP Specification 2004 から取得するか、埋め込み PDF/A 値タイプ拡張<br/>            スキーマから取得します。事前定義された XMP タイプ名またはカスタムタイプ名です。 |
