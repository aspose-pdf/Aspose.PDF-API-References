## Rows class

テーブルの行コレクションを表します。

Rows 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Rows() | Rows クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| count | 項目の数。 |
## Indexer
| 名前 | 説明 |
| :- | :- |
| [index] | 行を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| add() | コレクションに行を追加します。 |
| add(row) | コレクションに行を追加します。 |
| index_of(row) | コレクション内の行のインデックスを返します。 |
| remove(row) | コレクションから行を削除します。 |
| remove_at(index) | コレクションの位置から行を削除します。 |
| remove_range(index, count) | コレクションから行セットを削除します。 |
| dispose() | 破棄します。 |
