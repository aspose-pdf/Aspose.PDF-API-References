## ProgressEventType enumeration

この列挙型は、変換中に発生し得る可能な進行イベントタイプを説明します<br/>            

## Members
| メンバー名 | 説明 |
| :- | :- |
| TOTAL_PROGRESS | 発生したイベントが変換の総進捗を通知することを意味します。 |
| SOURCE_PAGE_ANALYSED | 発生したイベントが変換前にページの1つの解析完了を通知することを意味します。 |
| RESULT_PAGE_CREATED | 発生したイベントが物理的エクスポート前に結果ページが1つ作成されたことを通知することを意味します。 |
| RESULT_PAGE_SAVED | 発生したイベントが結果ページ1つの保存完了を通知することを意味します。 |
