## Operator class

演算子を表す抽象クラスです。

Operator 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| index | ページの演算子リストにおける演算子インデックス。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| accept(visitor) | IOperatorSelector ビジターを受け入れ、演算子の処理を提供します。 |
| is_text_show_operator(op) | 演算子がテキスト出力（Tj、TJ など）を担当するかどうかを判定します。 |
