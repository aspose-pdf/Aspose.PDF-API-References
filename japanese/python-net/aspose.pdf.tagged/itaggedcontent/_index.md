## ITaggedContent class

ドキュメントの TaggedPdf コンテンツを操作するインターフェイスを表します。

ITaggedContent 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| structure_text_state | 全体のドキュメント用の [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) 設定を取得します。 |
| struct_tree_root_element | PDF ドキュメントの [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/) を取得します。 |
| root_element | PDF ドキュメントの論理構造のルート [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) を取得します。 |
