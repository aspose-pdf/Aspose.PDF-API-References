## クラス
| クラス | 説明 |
| :- | :- |
| [ITaggedContent](/pdf/python-net/aspose.pdf.tagged/itaggedcontent/) | ドキュメントの TaggedPdf コンテンツを操作するインターフェイスを表します。 |
| [TaggedException](/pdf/python-net/aspose.pdf.tagged/taggedexception/) | ドキュメントの TaggedPDF コンテンツに対する例外を表します。 |
