aspose.pdf.optimization は、ドキュメント最適化プロセスの管理のためのクラスを提供する名前空間です。

| クラス | 説明 |
| :- | :- |
| [ImageCompressionOptions](/pdf/python-net/aspose.pdf.optimization/imagecompressionoptions/) | クラスは画像圧縮のオプションセットを含みます。 |
| [OptimizationOptions](/pdf/python-net/aspose.pdf.optimization/optimizationoptions/) | ドキュメント最適化アルゴリズムを記述するクラスです。<br/>            このクラスのインスタンスは OptimizeResources() メソッドのパラメータとして使用できます。 |

| :- | :- |
