## ImageCompressionVersion enumeration

画像圧縮アルゴリズムのバージョンを記述します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| STANDARD | 標準アルゴリズム。デフォルト値。 |
| FAST | 標準よりも高速な改良アルゴリズムですが、すべてのケースに適用できるわけではありません。 |
| MIXED | 可能な場合は高速アルゴリズムを使用し、その他の場合は標準アルゴリズムを使用します。\"Fast\" より遅くなる可能性がありますが、圧縮率が向上することがあります。 |
