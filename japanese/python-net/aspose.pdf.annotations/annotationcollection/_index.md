## AnnotationCollection class

アノテーションコレクションを表すクラスです。

AnnotationCollection 型は以下のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_synchronized | Aspose.Pdf.Annotations.AnnotationCollection へのアクセスが同期化（スレッドセーフ）されているかどうかを示す値を取得します。 |
| sync_root | Aspose.Pdf.Annotations.AnnotationCollection へのアクセスを同期化するために使用できるオブジェクトを取得します。 |
## Indexer
| 名前 | 説明 |
| :- | :- |
| [index] | 取得する要素のインデックスです。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| delete(index) | インデックスでコレクションからアノテーションを削除します。 |
| delete() | インデックスでコレクションからアノテーションを削除します。 |
| delete(annotation) | インデックスでコレクションからアノテーションを削除します。 |
| add(annotation, consider_rotation) | アノテーションをコレクションに追加します。ページが回転している場合、アノテーションの矩形はそれに応じて再計算されます。 |
| accept(visitor) | アノテーションを処理するビジターを受け入れます。 |
| find_by_name(name) | 名前でアノテーションを返します。 |
