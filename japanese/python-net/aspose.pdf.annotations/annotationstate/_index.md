## AnnotationState enumeration

元のアノテーションが設定可能な状態の列挙です。

## Members
| メンバー名 | 説明 |
| :- | :- |
| UNDEFINED | 未定義の状態です。 |
| MARKED | 注釈はユーザーによってマークされました。 |
| UNMARKED | 注釈はユーザーによってマークされていません。 |
| ACCEPTED | ユーザーは変更に同意しています。 |
| REJECTED | ユーザーは変更に同意していません。 |
| CANCELLED | 変更はキャンセルされました。 |
| COMPLETED | 変更が完了しました。 |
| NONE | ユーザーは変更について何も示していません。 |
