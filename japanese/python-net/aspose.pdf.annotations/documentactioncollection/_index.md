## DocumentActionCollection class

クラスはドキュメントに対して実行されるいくつかのアクションに対する操作を記述します。

DocumentActionCollection 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| DocumentActionCollection(document) | DocumentActionCollection クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| before_saving | ドキュメントの保存前に実行されるアクションを取得または設定します。 |
| before_closing | ドキュメントのクローズ前に実行されるアクションを取得または設定します。 |
| after_saving | ドキュメントの保存後に実行されるアクションを取得または設定します。 |
| before_printing | ドキュメントの印刷前に実行されるアクションです。 |
| after_printing | ドキュメントの印刷後に実行されるアクションです。 |
