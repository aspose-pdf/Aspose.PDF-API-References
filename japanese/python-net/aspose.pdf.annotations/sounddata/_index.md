## SoundData class

アノテーションがアクティブになったときに再生される音声を定義するサウンドデータを表します。

SoundData 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| rate | サンプリングレート（1秒あたりのサンプル数）を取得または設定します。 |
| channels | サウンドチャンネル数を取得または設定します。 |
| bits | チャンネルごとのサンプル値あたりのビット数を取得または設定します。 |
| contents | アノテーションが有効化されたときに再生されるサウンドのストリームを取得します。 |
| エンコーディング | サンプルデータのエンコーディング形式を取得または設定します。 |
