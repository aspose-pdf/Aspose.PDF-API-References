## SoundSampleData class

サウンドオブジェクト固有の追加エントリを表します（Section 9.2 PDF1-7）。

SoundSampleData 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| SoundSampleData(sampling_rate) | SoundSampleData クラスの新しいインスタンスを初期化します |
| SoundSampleData(sampling_rate, number_of_sound_channels) | SoundSampleData クラスの新しいインスタンスを初期化します |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel) | SoundSampleData クラスの新しいインスタンスを初期化します |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel, sound_sample_data_encoding_format) | SoundSampleData クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| sampling_rate | サンプリングレートを取得または設定します。 |
| number_of_sound_channels | サウンドチャンネル数を取得または設定します。 |
| bits_per_channel | チャンネルごとのサンプル値あたりのビット数を取得または設定します。 |
| encoding_format | エンコーディング形式を取得または設定します。 |
| DEFAULT_SAMPLING_RATE | SamplingRate の既定値です。 |
| DEFAULT_OF_SOUND_CHANNELS | Channels パラメーターの既定値です。 |
| DEFAULT_OF_BITS_PER_CHANNEL | BitsPerchannel パラメーターの既定値です。 |
| DEFAULT_ENCODING_FORMAT | エンコーディング形式の既定値です。 |
