## LineEnding enumeration

線を描画する際に使用される線端スタイルを列挙します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | 改行なし。 |
| SQUARE | アノテーションの内部色で塗りつぶされた正方形（存在する場合）。 |
| CIRCLE | 注釈の内部色で塗りつぶされた円（該当する場合）。 |
| DIAMOND | 注釈の内部色で塗りつぶされたダイヤモンド形（該当する場合）。 |
| OPEN_ARROW | 鋭角で交わる2本の短い線で、開いた矢じりを形成します。 |
| CLOSED_ARROW | OpenArrowスタイルと同様に鋭角で交わる2本の短い線に、3本目の線で接続し、注釈の内部色で塗りつぶされた三角形の閉じた矢じりを形成します（該当する場合）。 |
| BUTT | 線自体に対して垂直な端点に短い線があります。 |
| R_OPEN_ARROW | OpenArrowとは逆方向の2本の短い線です。 |
| R_CLOSED_ARROW | ClosedArrowとは逆方向の三角形の閉じた矢じりです。 |
| SLASH | 線自体に対して垂直から約30度時計回りの端点に短い線があります。 |
