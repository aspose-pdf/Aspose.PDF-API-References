## RenditionOperation enumeration

アクションがトリガーされたときに実行する操作です。

## Members
| メンバー名 | 説明 |
| :- | :- |
| PLAY_STOP | 注釈にレンダリングが関連付けられていない場合、指定されたレンダリングを再生し、注釈に関連付けます。 注釈に既にレンダリングが関連付けられている場合、それを停止し、新しいレンダリングを注釈に関連付けます。 |
| STOP | 注釈に関連付けられて再生中のすべてのレンダリングを停止します。 |
| PAUSE | 注釈に関連付けられて再生中のすべてのレンダリングを一時停止します。 |
| RESUME | 注釈に関連付けられて再生中のすべてのレンダリングを再開します。 |
| PLAY_RESUME | 指定されたレンダリングを再生し、注釈に関連付けます。 注釈に既にレンダリングが関連付けられている場合、レンダリングが一時停止していれば再開します。 |
| UNDEFINED | 操作が定義されていません。 |
