## AnnotationActionCollection class

アノテーションアクションのコレクションを表します。

AnnotationActionCollection 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| on_enter | カーソルがアノテーションのアクティブ領域に入ったときに実行されるアクションを取得または設定します。 |
| on_exit | カーソルがアノテーションのアクティブ領域から離れたときに実行されるアクションを取得または設定します。 |
| on_press_mouse_btn | マウスボタンがアノテーションのアクティブ領域内で押されたときに実行されるアクションを取得または設定します。 |
| on_release_mouse_btn | マウスボタンがアノテーションのアクティブ領域内で離されたときに実行されるアクションを取得または設定します。 |
| on_receive_focus | アノテーションが入力フォーカスを受け取ったときに実行されるアクションを取得または設定します。 |
| on_open_page | アノテーションを含むページが開かれたときに実行されるアクションを取得または設定します。 |
| on_close_page | アノテーションを含むページが閉じられたときに実行されるアクションを取得または設定します。 |
| on_show_page | ビューアアプリケーションのユーザーインターフェイスで、アノテーションを含むページが表示されたときに実行されるアクションを取得または設定します。 |
| on_hide_page | ビューアアプリケーションのユーザーインターフェイスで、アノテーションを含むページが非表示になったときに実行されるアクションを取得または設定します。 |
| on_lost_focus | アノテーションが入力フォーカスを失ったときに実行されるアクションを取得または設定します。 |
| on_modify_character | ユーザーがフィールドの文字を変更したときに実行されるアクションを取得または設定します。 |
| on_validate | ユーザーがフィールドの内容を変更したときに実行されるアクションを取得または設定します。 |
| on_format | フィールド値をフォーマットするために実行されるアクションを取得または設定します。 |
| on_calculate | フィールド値を計算するアクションを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| remove_actions() | 注釈のすべてのアクションを削除します。 |
