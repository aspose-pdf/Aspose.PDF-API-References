## GoToRemoteAction class

通常の移動アクションに似ていますが、現在のファイルではなく別の PDF ファイル内のデスティネーションへジャンプするリモート移動アクションを表します。

GoToRemoteAction 型は次のメンバーを公開します。
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| GoToRemoteAction(remote_pdf, remote_page_number) | GoToRemoteAction クラスの新しいインスタンスを初期化します。 |
| GoToRemoteAction(remote_pdf, destination) | GoToRemoteAction クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| 次 | シーケンス内の次のアクション。 |
| destination | ジャンプ先の宛先を取得または設定します。 |
| file | 目的地が存在するファイルの仕様を取得または設定します。 |
| new_window | 目的地ドキュメントを新しいウィンドウで開くかどうかを指定するフラグを取得または設定します。 |
