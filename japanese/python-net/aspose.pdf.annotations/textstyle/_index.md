## TextStyle class

アノテーション内のテキストスタイルを表すクラスです。

TextStyle 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| font_name | フォント名。 |
| font_size | フォントサイズ。 |
| alignment | テキストの水平配置を取得または設定します。 |
| horizontal_alignment | テキストの配置。 有効な値は: Left, Center, Rigth。 |
| color | テキストの色。 |
