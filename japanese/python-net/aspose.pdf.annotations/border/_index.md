## Border class

アノテーション境界線の特性を表すクラスです。

Border 型は次のメンバーを公開します。
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Border(parent) | Border クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| h_corner_radius | 水平コーナー半径を取得または設定します。 |
| v_corner_radius | 垂直コーナー半径を取得または設定します。 |
| width | ボーダー幅を取得または設定します。 |
| effect_intensity | エフェクトの強度を取得または設定します。値の有効範囲は [0..2] です。 |
| style | ボーダースタイルを取得または設定します。 |
| effect | ボーダーエフェクトを取得または設定します。 |
| dash | ダッシュパターンを取得または設定します。 |
