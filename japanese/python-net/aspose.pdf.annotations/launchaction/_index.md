## LaunchAction class

アプリケーションを起動するか、ドキュメントを開くまたは印刷するランチアクションを表します。

LaunchAction 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| LaunchAction(file) | LaunchAction クラスの新しいインスタンスを初期化します |
| LaunchAction(document, file) | LaunchAction クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| 次 | シーケンス内の次のアクション。 |
| file | 起動するアプリケーションまたは開く・印刷するドキュメントを取得または設定します。 |
| new_window | 新しいウィンドウで対象ドキュメントを開くかどうかを指定するフラグを取得または設定します（PDF ドキュメントにのみ適用）。 |
