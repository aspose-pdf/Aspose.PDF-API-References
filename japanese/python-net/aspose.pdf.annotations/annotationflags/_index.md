## AnnotationFlags enumeration

アノテーションのさまざまな特性を指定するフラグのセットです。

## Members
| メンバー名 | 説明 |
| :- | :- |
| DEFAULT | デフォルト値。 |
| INVISIBLE | 設定されている場合、標準のアノテーションタイプのいずれにも属さず、アノテーションハンドラが利用できない場合はアノテーションを表示しません。<br/>            クリアされている場合、そのような不明なアノテーションを、存在すれば外観辞書で指定された外観ストリームを使用して表示します。 |
| HIDDEN | 設定されている場合、アノテーションのタイプやアノテーションハンドラの有無に関係なく、アノテーションを表示または印刷せず、ユーザーとの相互作用も許可しません。<br/>            画面スペースが限られている場合、アノテーションを選択的に非表示・表示する機能を、外観ストリームと組み合わせて、オンラインヘルプシステムと同様の機能を持つ補助的なポップアップ情報を表示するために利用できます。 |
| PRINT | 設定されている場合、ページが印刷されるときにアノテーションを印刷します。クリアされている場合、画面に表示されているかどうかに関係なく、アノテーションを印刷しません。<br/>            例えば、インタラクティブなプッシュボタンを表すアノテーションなど、印刷されたページでは意味のある目的を果たさないものに便利です。 |
| NO_ZOOM | 設定されている場合、ページの拡大率に合わせてアノテーションの外観を拡大縮小しません。<br/>            アノテーションのページ上の位置（アノテーション矩形の左上隅で定義されます）は、ページの拡大率に関係なく固定されたままです。 |
| NO_ROTATE | 設定されている場合、ページの回転に合わせてアノテーションの外観を回転させません。<br/>            アノテーション矩形の左上隅はページ上の固定位置に留まり、ページの回転に関係なく維持されます。 |
| NO_VIEW | 設定されている場合、画面上にアノテーションを表示せず、ユーザーとの相互作用も許可しません。<br/>            アノテーションは印刷される可能性があります（Print フラグの設定に依存）。<br/>            ただし、画面表示およびユーザー操作の目的では非表示と見なすべきです。 |
| READ_ONLY | 設定されている場合、アノテーションがユーザーと相互作用することを許可しません。アノテーションは表示<br/>            または印刷される可能性があります（NoView と Print フラグの設定に依存） が、マウスクリックに応答したり、マウスの動きに応じて外観を変えたりすべきではありません。このフラグはウィジェットアノテーションでは無視されます；<br/>            その機能は関連するフォームフィールドの ReadOnly フラグに吸収されます。 |
| LOCKED | 設定されている場合、ユーザーがアノテーションを削除したり、そのプロパティ（位置やサイズを含む）を変更したりできなくなります。<br/>            ただし、このフラグはアノテーションの内容、例えばフォームフィールドの値の変更は制限しません。<br/> |
| TOGGLE_NO_VIEW | 設定されている場合、特定のイベントに対して NoView フラグの解釈を反転させます。<br/>            一般的な使用例は、マウスカーソルが上に乗っている間だけ表示されるアノテーションです。 |
| LOCKED_CONTENTS | 設定されている場合、ユーザーがアノテーションの内容を変更できなくなります。<br/>            このフラグはアノテーションの削除や、位置やサイズなど他のプロパティの変更を制限しません。 |
