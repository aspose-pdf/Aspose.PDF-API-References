## HighlightingMode enumeration

注釈のハイライトモードを列挙します。これは、マウスボタンがアクティブ領域内で押されたり保持されたりしたときに使用される視覚効果です。

## Members
| メンバー名 | 説明 |
| :- | :- |
| NONE | ハイライトなし。 |
| INVERT | 注釈矩形の内容を反転させます。 |
| OUTLINE | 注釈の境界線を反転させます。 |
| PUSH | 注釈のダウン外観がある場合はそれを表示します。ダウン外観が定義されていない場合は、注釈矩形の内容をオフセットして、ページの表面下に押し込まれたかのように見せます。 |
| TOGGLE | Push と同じです（こちらが推奨されます）。 |
