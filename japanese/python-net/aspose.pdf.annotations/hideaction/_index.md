## HideAction class

Hidden フラグを設定またはクリアすることで、画面上の1つ以上のアノテーションを非表示または表示する隠しアクションを表します。

HideAction 型は次のメンバーを公開します:

| 名前 | 説明 |
| :- | :- |
| HideAction(annotation) | HideAction クラスの新しいインスタンスを初期化します。 |
| HideAction(annotation, is_hidden) | HideAction クラスの新しいインスタンスを初期化します。 |
| HideAction(field_name) | HideAction クラスの新しいインスタンスを初期化します。 |
| HideAction(field_name, is_hidden) | HideAction クラスの新しいインスタンスを初期化します。 |
| HideAction(annotations) | HideAction クラスの新しいインスタンスを初期化します。 |
| HideAction(annotations, is_hidden) | HideAction クラスの新しいインスタンスを初期化します。 |
| HideAction(names) | HideAction クラスの新しいインスタンスを初期化します。 |
| HideAction(names, is_hidden) | HideAction クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| 次 | シーケンス内の次のアクション。 |
| is_hidden | 注釈の非表示/表示ステータスを取得または設定します。 |
