## SubmitFormAction class

submit-form アクションを記述するクラスです。

SubmitFormAction 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| SubmitFormAction() | SubmitFormAction オブジェクトを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| 次 | シーケンス内の次のアクション。 |
| flags | 送信アクションのフラグを取得または設定します。 |
| url | 送信先 URL。 |
| EXCLUDE | クリアの場合、Fields 配列は送信に含めるフィールドを指定します。 |
| INCLUDE_NO_VALUE_FIELDS | 設定されている場合、Fields 配列と Include/Exclude フラグで指定されたすべてのフィールドが送信されます。 |
| EXPORT_FORMAT | 設定されている場合、フィールド名と値は HTML フォーム形式で送信されます。 |
| GET_METHOD | 設定されている場合、フィールド名と値は HTTP GET リクエストで送信されます。 |
| SUBMIT_COORDINATES | 設定されている場合、送信フォームアクションを引き起こしたマウスクリックの座標がフォームデータの一部として送信されます。 |
| XFDF | 設定されている場合、フィールド名と値は XFDF として送信されます。 |
| INCLUDE_APPEND_SAVES | 設定されている場合、送信された FDF ファイルにはすべての増分更新の内容が含まれます。 |
| INCLUDE_ANNOTATIONS | 設定されている場合、送信された FDF ファイルには基礎となる PDF ドキュメント内のすべてのマークアップ注釈が含まれます。 |
| SUBMIT_PDF | 設定されている場合、ドキュメントは MIME コンテンツタイプ application/pdf を使用して PDF として送信されます。 |
| CANONICAL_FORMAT | 設定されている場合、日付を表す送信されたフィールド値は標準形式に変換されます。 |
| EXCL_NON_USER_ANNOTS | 設定されている場合、T エントリが現在のユーザー名と一致するマークアップ注釈のみが含まれます。 |
| EXCL_F_KEY | 設定されている場合、送信された FDF から F エントリが除外されます。 |
| EMBED_FORM | 設定されている場合、送信された FDF の F エントリは、<br/>            PDF ファイルを表す埋め込みファイルストリームを含むファイル指定子となります。 |
