## DefaultAppearance class

フィールドのデフォルト外観（フォント、テキストサイズ、カラー）を記述します。

DefaultAppearance 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| DefaultAppearance() | DefaultAppearance のコンストラクタ。 |
| DefaultAppearance(font_name, font_size, text_color) | DefaultAppearance クラスの新しいインスタンスを初期化します |
| DefaultAppearance(font, font_size, text_color) | DefaultAppearance クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| font_size | デフォルトの外観でフォントサイズを取得します。 |
| text_color | デフォルトの外観でテキストの色を取得または設定します。 |
| font_name | デフォルトの外観でフォント名を取得します。 |
| font_resource_name | デフォルトの外観でフォント名を取得します。 |
| font | テキストのデフォルトとして指定されたフォントを取得します。 |
| text | 外観を表す PDF 演算子のリストを取得します。 |
