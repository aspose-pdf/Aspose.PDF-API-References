## FitBHExplicitDestination class

ページを表示し、垂直座標 top をウィンドウの上端に配置し、ページの内容をバウンディングボックスの幅全体がウィンドウ内に収まるように拡大する明示的なデスティネーションを表します。top に null 値を指定すると、そのパラメータの現在の値が変更されずに保持されます。
