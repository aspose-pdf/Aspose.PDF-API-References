## Measure class

測定座標系を記述するクラスです。

Measure 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Measure(annotation) | Measure クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| scale_ratio | 図面のスケール比率を表すテキスト文字列です。 |
| x_format | x 軸に沿った変化の測定、および Y が存在しない場合は y 軸に沿った変化の測定のための数値書式配列です。 |
| y_format | y 軸に沿った変化の測定のための数値書式配列です。 |
| distance_format | 任意の方向の距離測定のための数値書式配列です。 |
| area_format | 面積測定のための数値書式配列です。 |
| angle_format | 角度測定のための数値書式配列です。 |
| slope_format | 直線の勾配測定のための数値書式配列です。 |
| origin | デフォルトのユーザー空間座標系における測定座標系の原点を指定するポイントです。 |
| xy_factor | y 軸の最大単位を x 軸の最大単位に変換するために使用される係数です。 |
