## ReplyType enumeration

注釈とInReplyToで指定されたものとの間の関係（“返信タイプ”）の種類を列挙します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| UNDEFINED | 未定義の関係です。 |
| REPLY | この注釈は InReplyTo で指定された注釈への返信とみなされます。ビューアアプリケーションは、個別の返信としてではなく、スレッド化されたコメントとしてまとめて表示すべきです。 |
| GROUP | この注釈は InReplyTo で指定された注釈とグループ化されています。 |
