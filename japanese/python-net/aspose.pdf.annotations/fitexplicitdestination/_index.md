## FitExplicitDestination class

ページ全体がウィンドウ内に水平・垂直の両方向で収まるように内容を拡大して表示する明示的なデスティネーションを表します。必要な水平拡大率と垂直拡大率が異なる場合、両者のうち小さい方を使用し、もう一方の次元ではページをウィンドウ内で中央に配置します。
