## IPdfTypeExtractor class

抽出器とのやり取りのインターフェイスを表します。

IPdfTypeExtractor 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| page_count | ページ数を返します。 |
| version | バージョンを返します。 |
| is_fast_extraction_used | 高速抽出メカニズムが使用されたかどうかを返します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| extract_all_text() | 抽出されたテキスト値のコレクションを返します。 |
| extract_page_text(page_number) | ページテキストを返します。 |
| dispose() | 破棄します。 |
