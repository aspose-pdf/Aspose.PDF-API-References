## TextFormattingOptions class

テキスト書式設定オプションを表します

TextFormattingOptions 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TextFormattingOptions(wrap_mode) | TextFormattingOptions クラスの新しいインスタンスを初期化します |
| TextFormattingOptions() | 未定義の word wrap モードで [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) オブジェクトの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| wrap_mode | word wrap モードを取得または設定します。<br/>            デフォルト値は WordWrapMode.NoWrap です |
| line_spacing | 行間モードを取得または設定します。<br/>            デフォルト値は LineSpacingMode.FontSize です |
| hyphen_symbol | ハイフン化プロセスで使用されるハイフン記号を取得または設定します。 |
| subsequent_lines_indent | 次の行のインデント値を取得または設定します。 |
| first_line_indent | 最初の行のインデント値を取得または設定します。 |
