## MarkupParagraph class

段落を表します。

MarkupParagraph 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| points | 段落を表す多角形のポイントです。<br/>            開始点は段落の左下隅です。次のポイントは反時計回りの順序です。 |
| secondary_points | 段落の続き部分を表す二次多角形のポイントです。段落が次の列またはページに続く場合は null にはなりません。<br/>            開始点は段落の左下隅です。次のポイントは反時計回りの順序です。 |
| continuation_page_numbers | 段落が続くページ番号のリストです。段落が同じページの次の列に続く場合、開始したページと一致します。 |
| fragments | 段落の空でない [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) オブジェクトのコレクションです。 |
| lines | 段落の行です。各行はテキストフラグメントのリストで表されます。 |
| text | [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) オブジェクトが表す文字列テキストオブジェクトを取得します。 |
