## SystemFontsSubstitution class

フォントをシステムフォントに置き換えるフォント置換戦略のクラスを表します。

SystemFontsSubstitution 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| SystemFontsSubstitution(font_categories) | SystemFontsSubstitution クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| font_categories | システムフォントに置き換えるべき置換フォントカテゴリを取得または設定します。 |
| default_font | デフォルトの置換フォントを取得または設定します。<br/>            他に有効な置換が見つからず、かつ元のフォントが対象の置換カテゴリに属している場合にこのフォントが使用されます ([font_categories](/pdf/python-net/aspose.pdf.text/systemfontssubstitution/))。 |
