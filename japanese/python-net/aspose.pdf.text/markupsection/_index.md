## MarkupSection class

マークアップ セクションを表します - テキストを含み、別のテキストブロックから視覚的に分割できるページの矩形領域です。

MarkupSection 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| rectangle | セクション矩形 |
| fragments | セクション内にある空でない [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) オブジェクトのコレクションです。 |
| paragraphs | セクション内にある [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) オブジェクトのコレクションです。 |
