## TextExtractionError class

PDF ドキュメントに発生したテキスト抽出エラーを説明します。

TextExtractionError 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| summary | エラーの簡潔な説明。 |
| description | エラーの詳細な説明。 |
| location | Location of the error. |
| font_key | 抽出エラーを引き起こすテキストの表示に使用される Font オブジェクトのキー（PDF 名）。 |
| font_name | 抽出エラーを引き起こすテキストの表示に使用される Font オブジェクトの読み取り可能（内部）名。 |
| extracted_text | 実際に抽出されたテキスト。 |
