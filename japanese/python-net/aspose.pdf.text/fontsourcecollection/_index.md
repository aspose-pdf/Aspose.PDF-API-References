## FontSourceCollection class

フォントソースのコレクションを表します。

FontSourceCollection 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| sync_root | コレクションへのアクセスを同期するために使用できるオブジェクトを取得します。 |
| is_synchronized | コレクションへのアクセスが同期されているか（スレッドセーフか）を示す値を取得します。 |
## Indexer
| 名前 | 説明 |
| :- | :- |
| [index] | 指定されたインデックスのフォント要素を取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| delete(font_source) | フォントソース要素を削除します。 |
