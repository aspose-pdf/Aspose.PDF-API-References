## TextExtractionErrorLocation class

テキスト抽出エラーが発生した PDF ドキュメント内の場所を表します。

TextExtractionErrorLocation 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| path | テキスト抽出エラーが発生した PDF ドキュメントの場所。 |
| page_number | テキスト抽出エラーが発生したドキュメントページの番号。 |
| object_type | テキスト抽出エラーが発生したコンテンツストリーム内の PDF オブジェクト（ページまたは xForm）のタイプ。 |
| form_key | テキスト抽出エラーが発生したコンテンツストリーム内の PDF Form XObject のキー（名前）。ObjectType が 'xForm' の場合は空ではありません。 |
| operator_index | テキスト抽出エラーを引き起こす、コンテンツストリーム（オペレータコレクション）内のテキスト表示オペレータのインデックス。 |
| operator_string | テキスト抽出エラーを引き起こすテキスト表示オペレータ。 |
| font_used_key | テキスト抽出エラーを引き起こすオペレータの表示に使用される PDF フォントオブジェクトのキー（名前）。 |
| text_start_point | テキスト抽出エラーを引き起こすオペレータの表示に使用される PDF フォントオブジェクトのキー（名前）。 |
