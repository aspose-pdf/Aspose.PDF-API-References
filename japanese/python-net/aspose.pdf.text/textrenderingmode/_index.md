## TextRenderingMode enumeration

テキストレンダリングモード（Tmode）は、テキストを表示する際にグリフのアウトラインをストロークするか、塗りつぶすか、クリッピング境界として使用するか、またはこれら三つの組み合わせにするかを決定します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| FILL_TEXT | テキストを塗りつぶします。 |
| STROKE_TEXT | テキストの輪郭を描画します。 |
| FILL_THEN_STROKE_TEXT | テキストを塗りつぶし、次にストロークします。 |
| INVISIBLE | テキストを塗りつぶさず、ストロークもしません（不可視）。 |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | テキストを塗りつぶし、クリッピング用のパスに追加します（9.3.6、\"Text Rendering Mode,\" を参照）。 |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | テキストにストロークを適用し、クリッピング用のパスに追加します。 |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | テキストを塗りつぶし、次にストロークし、クリッピング用のパスに追加します。 |
| ADD_PATH_TO_CLIPPING | テキストをクリッピング用のパスに追加します。 |
