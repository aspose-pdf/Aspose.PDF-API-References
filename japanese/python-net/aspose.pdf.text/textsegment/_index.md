## TextSegment class

Pdf テキストのセグメントを表します。

TextSegment 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TextSegment() | TextSegment オブジェクトを作成します。 |
| TextSegment(text) | TextSegment クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| start_char_index | 表示テキスト演算子 (Tj, TJ) セグメント内の現在のセグメントの開始文字インデックスを取得します。 |
| end_char_index | 表示テキスト演算子 (Tj, TJ) セグメント内の現在のセグメントの終了文字インデックスを取得します。 |
| text | [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) オブジェクトが表す文字列テキストオブジェクトを取得または設定します。 |
| text_state | [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) オブジェクトが表すテキストのテキスト状態を取得または設定します。 |
| position | [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) オブジェクトで表されるテキストの位置を取得します。 |
| rectangle | TextSegment の矩形を取得します |
| baseline_position | [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) オブジェクトで表されるテキストの位置を取得します。<br/>            Position 構造体の YIndent はテキストセグメントのベースライン座標を表します。 |
| text_edit_options | テキスト編集オプションを取得または設定します。オプションは、要求されたシンボルがフォントで表現できない場合の特別な動作を定義します。 |
| 文字 | テキストセグメント内の文字に関する情報を表す CharInfo オブジェクトのコレクションを取得します。 |
| hyperlink | セグメントのハイパーリンク（PDF ジェネレータ用）を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| my_html_encode(value) | 文字列を HTML としてエンコードします。 |
