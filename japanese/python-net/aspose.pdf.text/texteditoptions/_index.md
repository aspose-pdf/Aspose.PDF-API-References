## TextEditOptions class

テキスト編集操作のオプションを説明します。

TextEditOptions 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TextEditOptions(no_character_behavior) | TextEditOptions クラスの新しいインスタンスを初期化します |
| TextEditOptions(font_replace_behavior) | TextEditOptions クラスの新しいインスタンスを初期化します |
| TextEditOptions(allow_language_transformation) | TextEditOptions クラスの新しいインスタンスを初期化します |
| TextEditOptions(language_transformation_behavior) | TextEditOptions クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| replacement_font | 必要な文字がユーザーフォントに含まれていない場合に置換に使用されるフォントを取得または設定します |
| no_character_behavior | フォントに要求された文字が含まれていない場合の動作を定義するモードを取得または設定します |
| font_replace_behavior | フォント置換シナリオの動作を定義するモードを取得します |
| allow_language_transformation | テキストの追加または編集時に言語変換の使用を許可する値を取得または設定します。<br/>            true - 必要に応じて言語変換が適用されます（既定値）。<br/>            false - 言語変換は適用されません。 |
| language_transformation_behavior | 言語変換シナリオの動作を定義するモードを取得します |
| clipping_paths_processing | 編集されたテキストのクリッピングパスを処理するモードを取得します |
| to_attempt_get_underline_from_source | ソースドキュメントのページ上でテキストの下線を検索することを許可する値を取得または設定します。<br/>            （非推奨）この代わりに TextSearchOptions.SearchForTextRelatedGraphics を使用してください。 |
