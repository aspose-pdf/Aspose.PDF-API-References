## TextParagraph class

テキスト段落をマルチラインテキストオブジェクトとして表します。

TextParagraph 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TextParagraph() | TextParagraph クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| vertical_alignment | 段落の [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) 内のテキストの垂直方向の配置を取得または設定します。 |
| subsequent_lines_indent | 次の行のインデント値を取得または設定します。<br/>            0 以外の値に設定すると、FormattingOptions.SubsequentLinesIndent の値よりも優位性があります。 |
| first_line_indent | 次の行のインデント値を取得または設定します。<br/>            0 以外の値に設定すると、FormattingOptions.SubsequentLinesIndent の値よりも優位性があります。 |
| justify | テキストが両端揃えかどうかの値を取得または設定します。 |
| horizontal_alignment | 段落の [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) 内のテキストの水平方向の配置を取得または設定します。 |
| formatting_options | 書式設定オプションを取得または設定します。 |
| position | 段落の位置を取得または設定します。 |
| text_rectangle | 段落に配置されたテキストの矩形を取得します。 |
| rectangle | 段落の矩形を取得または設定します。 |
| margin | 余白を取得または設定します。 |
| rotation | 回転角度（度単位）を取得または設定します。 |
