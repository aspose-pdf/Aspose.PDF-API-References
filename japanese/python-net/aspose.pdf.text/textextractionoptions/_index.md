## TextExtractionOptions class

テキスト抽出オプションを表します

TextExtractionOptions 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TextExtractionOptions(formatting_mode) | TextExtractionOptions クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| formatting_mode | 書式設定モードを取得します。 |
| scale_factor | 純粋モードで抽出中にフォントサイズを拡大するために適用される係数を取得または設定します。<br/>            値を小さく設定すると、抽出されたテキストにより多くのスペースが入ります。<br/>            デフォルト値は 1 で、拡大は行われません。<br/>            値を 0 に設定すると、アルゴリズムが自動的に拡大率を選択します。 |
