## TabStop class

段落内のカスタムタブストップ位置を表します。

TabStop 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TabStop() | [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) クラスの新しいインスタンスを初期化します。 |
| TabStop(position) | TabStop クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| position | タブストップ位置を示す float 値を取得または設定します。 |
| leader_type | [TabLeaderType](/pdf/python-net/aspose.pdf.text/tableadertype/) 列挙体で、タブリーダーのタイプを示すものを取得または設定します。 |
| alignment_type | [alignment_type](/pdf/python-net/aspose.pdf.text/tabstop/) 列挙体で、タブの配置タイプを示すものを取得または設定します。 |
| is_read_only | [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) インスタンスが既に [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) に添付され、読み取り専用になっていることを示す値を取得します。 |
