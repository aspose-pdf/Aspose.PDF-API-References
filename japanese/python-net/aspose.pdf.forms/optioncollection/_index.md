## OptionCollection class

選択フィールドのオプションコレクションを表すクラスです。

OptionCollection 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_synchronized | オブジェクトが同期されている場合に true を返します。 |
| sync_root | コレクションの同期オブジェクトです。 |
## Indexer
| 名前 | 説明 |
| :- | :- |
| [index] | インデックスでオプションを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get(index) | インデックスでオプションを取得します。 |
| get(name) | オプション名でコレクションからオプションを取得します。 |
