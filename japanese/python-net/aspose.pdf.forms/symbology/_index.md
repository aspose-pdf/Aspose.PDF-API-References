## Symbology enumeration

A (Barcode) Symbology は特定のバーコードタイプの技術的詳細を定義します：<br/>            バーの幅、文字セット、エンコード方法、チェックサムの仕様など。

## Members
| メンバー名 | 説明 |
| :- | :- |
| PDF417 | 高いデータ容量と誤り訂正機能を備えた、複数行・可変長の 2D シンボロジーです。 |
| QR_CODE | QR コード（Quick Response の略）は特定のマトリックスバーコード（2D コード）で、<br/>            専用の QR バーコードリーダーやカメラ付き電話で読み取れます。 |
| DATA_MATRIX | 黒と白の正方形モジュールが正方形または<br/>            長方形のパターンで配置された 2D マトリックスシンボロジーです。 |
