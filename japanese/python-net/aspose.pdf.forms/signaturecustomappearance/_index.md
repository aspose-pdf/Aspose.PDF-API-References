## SignatureCustomAppearance class

署名のカスタム外観オブジェクトを表す抽象クラスです。

SignatureCustomAppearance 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| SignatureCustomAppearance() | SignatureCustomAppearance クラスの新しいインスタンスを初期化します。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| font_family_name | フォントファミリ名を取得/設定します。ドキュメントに存在する必要があります。デフォルト値: Arial。 |
| font_size | フォントサイズを取得/設定します。デフォルト値: 10。 |
| foreground_color | 前景色（テキストの色）を取得/設定します。デフォルト値: Blue. |
| background_color | 背景色を取得/設定します。デフォルト値: Transparent. |
| show_contact_info | 連絡先情報の表示を取得/設定します。デフォルト値: true. |
| show_reason | 理由の表示を取得/設定します。デフォルト値: true. |
| show_location | 位置情報の表示を取得/設定します。デフォルト値: true. |
| contact_info_label | 連絡先情報ラベルを取得/設定します。デフォルト値: "Contact". |
| reason_label | 理由ラベルを取得/設定します。デフォルト値: "Reason". |
| location_label | 位置ラベルを取得/設定します。デフォルト値: "Location". |
| digital_signed_label | デジタル署名ラベルを取得/設定します。デフォルト値: "Digitally signed by". |
| use_digital_subject_format | [digital_subject_format](/pdf/python-net/aspose.pdf.forms/signaturecustomappearance/) の使用状態を取得/設定します。 |
| digital_subject_format | Subject文字列内の要素順序のフォーマットを取得/設定します。<br/>            結果例:<br/>            C=UK, CN=Org, O=Organization<br/>            または<br/>            CN=Org, C=UK, O=Organization<br/>            または<br/>            O=Organization |
| date_signed_at_label | 署名日ラベルを取得/設定します。デフォルト値: "Date". |
| date_time_local_format | ローカル日時フォーマットを取得/設定します。デフォルト値: "yyyy.MM.dd HH:mm:ss zzz". |
| date_time_format | datetime の書式を取得/設定します。既定値: "yyyy.MM.dd HH:mm:ss"。 |
| rotation | 署名の回転を取得または設定します。 |
