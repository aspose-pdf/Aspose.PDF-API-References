## IconFit class

ウィジェット注釈のアイコンが注釈矩形内にどのように表示されるかを説明します。

IconFit 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| scaling_reason | スケーリング理由を取得または設定します。 |
| scaling_mode | 使用するスケーリングのタイプです。        /// |
| leftover_left | アイコンの左側に割り当てるスペースを取得または設定します。 |
| leftover_bottom | アイコンの下側に割り当てるスペースを取得または設定します。 |
| spread_on_border | true の場合、ボタンの外観が注釈の境界内に完全に収まるようにスケーリングされ、境界線の幅は考慮されません。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| name_to_scaling_reason(reason) | スケーリング理由の名前を ScalingReason オブジェクトに変換します。 |
| scaling_reason_to_name(reason) | スケーリング理由オブジェクトを名前に変換します。 |
| name_to_scaling_mode(mode) | スケーリングモード名を ScalingMode オブジェクトに変換します。 |
| scaling_mode_to_name(mode) | スケーリングモードオブジェクトを名前に変換します。 |
