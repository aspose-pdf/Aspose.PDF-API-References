## Option class

選択フィールドのオプションを表すクラスです。

Option 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| value | オプションのエクスポート値を取得または設定します。 |
| name | オプションの名前を取得または設定します。 |
| selected | オプションの選択状態を取得または設定します。オプションが選択されている場合は true を返します。 |
| index | オプションのインデックスを取得します。 |
