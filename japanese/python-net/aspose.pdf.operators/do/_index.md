## Do class

Do 演算子（Invoke XObject）を表すクラス。

Do 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Do(name) | Do クラスの新しいインスタンスを初期化します |
| Do() | 新しい Do 演算子を構築します。<br/>            引数名を確認せずにすべての Do 演算子を取得するために使用されます。 |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| index | ページの演算子リストにおける演算子インデックス。 |
| name | 演算子の XObject 引数の名前。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| accept(visitor) | 演算子を処理するためにビジターオブジェクトを受け入れます。 |
| is_text_show_operator(op) | 演算子がテキスト出力（Tj、TJ など）を担当するかどうかを判定します。 |
