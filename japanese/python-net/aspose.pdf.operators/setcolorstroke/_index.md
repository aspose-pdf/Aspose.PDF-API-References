## SetColorStroke class

ストロークカラー演算子の色を設定する SC 演算子を表すクラス。

SetColorStroke 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| SetColorStroke() | 演算子を初期化します。 |
| SetColorStroke(g) | SetColorStroke クラスの新しいインスタンスを初期化します |
| SetColorStroke(r, g, b) | SetColorStroke クラスの新しいインスタンスを初期化します |
| SetColorStroke(color) | SetColorStroke クラスの新しいインスタンスを初期化します |
| SetColorStroke(c, m, y, k) | SetColorStroke クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| index | None |
| r | 色の赤成分を取得します |
| g | 色の緑成分を取得します |
| b | 色の赤成分を取得します |
| c | CMYKカラーのシアン成分を取得します。 |
| m | CMYKカラーのマゼンタ成分を取得します。 |
| y | CMYKカラーのイエロー成分を取得します。 |
| k | CMYKカラーのブラック成分を取得します。 |
| grey | グレーカラーのブラック成分を取得します。 |
| color | カラー成分の配列を取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| accept(visitor) | 演算子を処理するためにビジターオブジェクトを受け入れます。 |
| is_text_show_operator(op) | None |
| get_color() | 演算子で指定された色を返します。 |
