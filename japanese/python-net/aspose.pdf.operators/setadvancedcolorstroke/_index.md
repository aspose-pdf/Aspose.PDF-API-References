| 名前 | 説明 |
| :- | :- |
| SetAdvancedColorStroke() | 演算子を初期化します。 |
| SetAdvancedColorStroke(g) | SetAdvancedColorStroke クラスの新しいインスタンスを初期化します |
| SetAdvancedColorStroke(g, pattern_name) | SetAdvancedColorStroke クラスの新しいインスタンスを初期化します |
| SetAdvancedColorStroke(r, g, b, pattern_name) | SetAdvancedColorStroke クラスの新しいインスタンスを初期化します |
| SetAdvancedColorStroke(c, m, y, k, pattern_name) | SetAdvancedColorStroke クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| index | None |

| m | CMYKカラーのマゼンタ成分を取得します。 |
