## GS class

gs 演算子を表すクラス（グラフィック状態パラメータ辞書からパラメータを設定）。

GS 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| GS(name) | GS クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| index | ページの演算子リストにおける演算子インデックス。 |
| name | グラフィック状態リソースの名前を取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| accept(visitor) | 演算子を処理するためにビジターオブジェクトを受け入れます。 |
| is_text_show_operator(op) | 演算子がテキスト出力（Tj、TJ など）を担当するかどうかを判定します。 |
