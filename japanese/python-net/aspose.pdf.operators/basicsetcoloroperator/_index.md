## BasicSetColorOperator class

Set Color 演算子の基底クラス。

BasicSetColorOperator 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| index | ページの演算子リストにおける演算子インデックス。 |
| r | 色の赤成分を取得します |
| g | 色の緑成分を取得します |
| b | 色の赤成分を取得します |
| c | CMYKカラーのシアン成分を取得します。 |
| m | CMYKカラーのマゼンタ成分を取得します。 |
| y | CMYKカラーのイエロー成分を取得します。 |
| k | CMYKカラーのブラック成分を取得します。 |
| grey | グレーカラーのブラック成分を取得します。 |
| color | カラー成分の配列を取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| accept(visitor) | IOperatorSelector ビジターを受け入れ、演算子の処理を提供します。 |
| is_text_show_operator(op) | 演算子がテキスト出力（Tj、TJ など）を担当するかどうかを判定します。 |
| get_color() | 演算子で指定された色を返します。 |
