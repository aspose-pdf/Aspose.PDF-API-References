## BasicSetColorAndPatternOperator class

すべての Set Color 演算子の基底演算子。

BasicSetColorAndPatternOperator 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| index | None |
| r | 色の赤成分を取得します |
| g | 色の緑成分を取得します |
| b | 色の赤成分を取得します |
| c | CMYKカラーのシアン成分を取得します。 |
| m | CMYKカラーのマゼンタ成分を取得します。 |
| y | CMYKカラーのイエロー成分を取得します。 |
| k | CMYKカラーのブラック成分を取得します。 |
| grey | グレーカラーのブラック成分を取得します。 |
| color | カラー成分の配列を取得します。 |
| pattern_name | パターン名を取得します。 |

| :- | :- |
| accept(visitor) | None |
| is_text_show_operator(op) | None |
| get_color() | 演算子で指定された色を返します。 |
