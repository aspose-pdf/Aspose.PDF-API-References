## SetAdvancedColor class

非ストローク操作の色を設定する scn 演算子を表すクラス。

SetAdvancedColor 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| SetAdvancedColor() | 演算子を初期化します。 |
| SetAdvancedColor(g, pattern_name) | SetAdvancedColor クラスの新しいインスタンスを初期化します |
| SetAdvancedColor(g) | SetAdvancedColor クラスの新しいインスタンスを初期化します |
| SetAdvancedColor(r, g, b, pattern_name) | SetAdvancedColor クラスの新しいインスタンスを初期化します |
| SetAdvancedColor(c, m, y, k, pattern_name) | SetAdvancedColor クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| index | None |
| r | 色の赤成分を取得します |
| g | 色の緑成分を取得します |
| b | 色の赤成分を取得します |
| c | CMYKカラーのシアン成分を取得します。 |
| m | CMYKカラーのマゼンタ成分を取得します。 |
| y | CMYKカラーのイエロー成分を取得します。 |
| k | CMYKカラーのブラック成分を取得します。 |
| grey | グレーカラーのブラック成分を取得します。 |
| color | カラー成分の配列を取得します。 |
| pattern_name | パターン名を取得します。 |
