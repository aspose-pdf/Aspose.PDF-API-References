## ThumbnailDevice class

PDFドキュメントのページをサムネイル画像に保存するイメージデバイスを表します。

ThumbnailDevice 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| ThumbnailDevice() | デフォルトのサムネイル画像サイズ (200x200 ピクセル) で [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) クラスの新しいインスタンスを初期化します<br/>             |
| ThumbnailDevice(width, height) | ThumbnailDevice クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| coordinate_type | ページ座標タイプ（Media/Crop ボックス）を取得または設定します。デフォルトでは CropBox の値が使用されます。 |
| rendering_options | レンダリングオプションを取得または設定します。 |
| form_presentation_mode | フォーム表示モードを取得または設定します。 |
| resolution | 画像の解像度を取得します。 |
| width | 画像の出力幅を取得します。 |
| height | 画像の出力高さを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| process(page, output) | ページをサムネイル画像 PNG に変換し、出力ストリームに保存します。 |
| process(page, output_file_name) | ページをサムネイル画像 PNG に変換し、出力ストリームに保存します。 |
