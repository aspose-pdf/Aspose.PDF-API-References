## TiffDevice class

このクラスは、PDFドキュメントのページを1つのTIFF画像にページごとに保存するのに役立ちます。

TiffDevice 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TiffDevice(resolution) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(resolution, settings) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(resolution, settings, converter) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(settings) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(settings, converter) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice() | デフォルト設定で [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) クラスの新しいインスタンスを初期化します。 |
| TiffDevice(width, height, resolution, settings) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(width, height, resolution, settings, converter) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(page_size, resolution, settings) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(page_size, resolution, settings, converter) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(width, height, resolution) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(page_size, resolution) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(width, height, settings) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(width, height, settings, converter) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(page_size, settings, converter) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(page_size, settings) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(width, height) | TiffDevice クラスの新しいインスタンスを初期化します |
| TiffDevice(page_size) | TiffDevice クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| rendering_options | レンダリングオプションを取得または設定します。 |
| form_presentation_mode | フォーム表示モードを取得または設定します。 |
| 設定 | PDF を TIFF 画像にマッピングする設定を取得します。 |
| resolution | 画像の解像度を取得します。 |
| width | 画像の出力幅を取得します。 |
| height | 画像の出力高さを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| process(document, from_page, to_page, output) | 特定のドキュメントページを TIFF に変換し、出力ストリームに保存します。 |
| process(document, output) | 特定のドキュメントページを TIFF に変換し、出力ストリームに保存します。 |
| process(document, output_file_name) | 特定のドキュメントページを TIFF に変換し、出力ストリームに保存します。 |
| process(document, from_page, to_page, output_file_name) | 特定のドキュメントページを TIFF に変換し、出力ストリームに保存します。 |
| binarize_bradley(input_image_stream, output_image_stream, threshold) | 入力ストリームに対して Bradley 二値化を実行します。 |
