## TextDevice class

PDFドキュメントのページをテキストに変換するクラスを表します。

TextDevice 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TextDevice(extraction_options) | TextDevice クラスの新しいインスタンスを初期化します |
| TextDevice() | Raw テキストフォーマットモードと Unicode テキストエンコーディングを使用して、[TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) の新しいインスタンスを初期化します。 |
| TextDevice(encoding) | TextDevice クラスの新しいインスタンスを初期化します |
| TextDevice(extraction_options, encoding) | TextDevice クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| extraction_options | テキスト抽出オプションを取得または設定します。 |
| エンコーディング | 抽出されたテキストのエンコーディングを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| process(page, output) | ページを変換し、テキストストリームとして保存します。 |
| process(page, output_file_name) | ページを変換し、テキストストリームとして保存します。 |
