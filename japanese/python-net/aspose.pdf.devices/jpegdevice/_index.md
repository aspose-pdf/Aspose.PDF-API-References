## JpegDevice class

PDF ドキュメントのページを JPEG 形式で保存するのに役立つ画像デバイスを表します。

JpegDevice 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| JpegDevice() | デフォルトの解像度と最高品質で [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) クラスの新しいインスタンスを初期化します。 |
| JpegDevice(resolution) | JpegDevice クラスの新しいインスタンスを初期化します |
| JpegDevice(quality) | JpegDevice クラスの新しいインスタンスを初期化します |
| JpegDevice(resolution, quality) | JpegDevice クラスの新しいインスタンスを初期化します |
| JpegDevice(width, height) | JpegDevice クラスの新しいインスタンスを初期化します |
| JpegDevice(page_size) | JpegDevice クラスの新しいインスタンスを初期化します |
| JpegDevice(width, height, resolution) | JpegDevice クラスの新しいインスタンスを初期化します |
| JpegDevice(page_size, resolution) | JpegDevice クラスの新しいインスタンスを初期化します |
| JpegDevice(width, height, resolution, quality) | JpegDevice クラスの新しいインスタンスを初期化します |
| JpegDevice(page_size, resolution, quality) | JpegDevice クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| coordinate_type | ページ座標タイプ（Media/Crop ボックス）を取得または設定します。デフォルトでは CropBox の値が使用されます。 |
| rendering_options | レンダリングオプションを取得または設定します。 |
| form_presentation_mode | フォーム表示モードを取得または設定します。 |
| resolution | 画像の解像度を取得します。 |
| width | 画像の出力幅を取得します。 |
| height | 画像の出力高さを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| process(page, output) | ページを jpeg に変換し、出力ストリームに保存します。 |
| process(page, output_file_name) | ページを jpeg に変換し、出力ストリームに保存します。 |
