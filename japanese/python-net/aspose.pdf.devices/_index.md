aspose.pdf.devices 名前空間は、ドキュメントを画像またはプレーンテキストとして表現するために使用されるクラスを提供します。そのため、ドキュメントはテキストデバイスやさまざまなグラフィックデバイスに送信でき、テキストまたはグラフィック表現を取得できます。

## クラス
| クラス | 説明 |
| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | PDF ドキュメントのページを BMP 形式で保存するのに役立つ画像デバイスを表します。 |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | すべてのデバイスタイプの抽象クラス。デバイスは PDF ドキュメントをある形式で表現するために使用されます。<br/>            例えば、ドキュメントページは画像またはテキストとして表現できます。 |
| [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) | PDF ドキュメントのページを DICOM 形式で保存するのに役立つ画像デバイスを表します。 |
| [DocumentDevice](/pdf/python-net/aspose.pdf.devices/documentdevice/) | PDF ドキュメント全体を処理するために使用されるすべてのデバイスの抽象クラス。 |
| [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) | PDF ドキュメントのページを EMF 形式で保存するのに役立つ画像デバイスを表します。 |
| [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) | PDF ドキュメントのページを GIF 形式で保存するのに役立つ画像デバイスを表します。 |
| [ImageDevice](/pdf/python-net/aspose.pdf.devices/imagedevice/) | 画像デバイス用の抽象クラス。 |
| [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) | PDF ドキュメントのページを JPEG 形式で保存するのに役立つ画像デバイスを表します。 |
| [Margins](/pdf/python-net/aspose.pdf.devices/margins/) | このクラスは画像の余白を表します。 |
| [PageDevice](/pdf/python-net/aspose.pdf.devices/pagedevice/) | PDF ドキュメントの特定ページを処理するために使用されるすべてのデバイスの抽象クラス。 |
| [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) | PDF ドキュメントのページを PNG 形式で保存するのに役立つ画像デバイスを表します。 |
| [Resolution](/pdf/python-net/aspose.pdf.devices/resolution/) | 画像解像度を保持するクラスを表します。 |
| [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) | PDFドキュメントのページをテキストに変換するクラスを表します。 |
| [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) | PDFドキュメントのページをサムネイル画像に保存するイメージデバイスを表します。 |
| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | このクラスは、PDFドキュメントのページを1つのTIFF画像にページごとに保存するのに役立ちます。 |
| [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) | このクラスは、PDFをTIFFにインポートするための設定を表します。 |
