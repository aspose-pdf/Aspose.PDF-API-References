## ImageDevice class

画像デバイス用の抽象クラス。

ImageDevice 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| coordinate_type | ページ座標タイプ（Media/Crop ボックス）を取得または設定します。デフォルトでは CropBox の値が使用されます。 |
| rendering_options | レンダリングオプションを取得または設定します。 |
| form_presentation_mode | フォーム表示モードを取得または設定します。 |
| resolution | 画像の解像度を取得します。 |
| width | 画像の出力幅を取得します。 |
| height | 画像の出力高さを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| process(page, output) | 指定されたページに対して何らかの操作を実行します。例: ページをグラフィック画像に変換します。 |
| process(page, output_file_name) | 指定されたページに対して何らかの操作を実行し、結果をファイルに保存します。 |
