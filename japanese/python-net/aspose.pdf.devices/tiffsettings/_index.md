## TiffSettings class

このクラスは、PDFをTIFFにインポートするための設定を表します。

TiffSettings 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| TiffSettings() | [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) クラスの新しいインスタンスを初期化します。 |
| TiffSettings(shape_type) | TiffSettings クラスの新しいインスタンスを初期化します |
| TiffSettings(compression_type) | TiffSettings クラスの新しいインスタンスを初期化します |
| TiffSettings(color_depth) | TiffSettings クラスの新しいインスタンスを初期化します |
| TiffSettings(margins) | TiffSettings クラスの新しいインスタンスを初期化します |
| TiffSettings(compression_type, color_depth, margins) | TiffSettings クラスの新しいインスタンスを初期化します |
| TiffSettings(compression_type, color_depth, margins, skip_blank_pages) | TiffSettings クラスの新しいインスタンスを初期化します |
| TiffSettings(compression_type, color_depth, margins, skip_blank_pages, shape_type) | TiffSettings クラスの新しいインスタンスを初期化します |
| TiffSettings(skip_blank_pages) | TiffSettings クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| margins | 余白を取得します。 |
| skip_blank_pages | 空白ページをスキップするかどうかを示す値を取得または設定します。 |
| compression | 圧縮のタイプを取得または設定します。 |
| depth | カラー深度を取得または設定します。 |
| 形状 | 形状のタイプを取得または設定します。 |
| 明るさ | 白と黒の色変換の値境界を取得または設定します。<br/>            このパラメーターは EncoderValue.CompressionCCITT4、EncoderValue.CompressionCCITT3、EncoderValue.CompressionRle、または ColorDepth.Format1bpp == 1 と共に使用できます。 |
| coordinate_type | ページ座標タイプ（Media/Crop ボックス）を取得または設定します。デフォルトでは CropBox の値が使用されます。 |
