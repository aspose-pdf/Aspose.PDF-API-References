## DocumentDevice class

PDF ドキュメント全体を処理するために使用されるすべてのデバイスの抽象クラス。

DocumentDevice 型は次のメンバーを公開します:
## メソッド
| 名前 | 説明 |
| :- | :- |
| process(document, from_page, to_page, output) | 各デバイスはドキュメントに対する何らかの操作を表します。例: PDF ドキュメントを別の形式に変換できます。 |
| process(document, output) | 各デバイスはドキュメントに対する何らかの操作を表します。例: PDF ドキュメントを別の形式に変換できます。 |
| process(document, output_file_name) | ドキュメント全体を処理し、結果をファイルに保存します。 |
| process(document, from_page, to_page, output_file_name) | ドキュメントの特定のページを処理し、結果をファイルに保存します。 |
| binarize_bradley(input_image_stream, output_image_stream, threshold) | 入力ストリームに対して Bradley 二値化を実行します。 |
