## DicomDevice class

PDF ドキュメントのページを DICOM 形式で保存するのに役立つ画像デバイスを表します。

DicomDevice 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| DicomDevice() | デフォルトの解像度で [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) クラスの新しいインスタンスを初期化します。 |
| DicomDevice(resolution) | DicomDevice クラスの新しいインスタンスを初期化します |
| DicomDevice(page_size) | DicomDevice クラスの新しいインスタンスを初期化します |
| DicomDevice(width, height) | DicomDevice クラスの新しいインスタンスを初期化します |
| DicomDevice(page_size, resolution) | DicomDevice クラスの新しいインスタンスを初期化します |
| DicomDevice(width, height, resolution) | DicomDevice クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| coordinate_type | ページ座標タイプ（Media/Crop ボックス）を取得または設定します。デフォルトでは CropBox の値が使用されます。 |
| rendering_options | レンダリングオプションを取得または設定します。 |
| form_presentation_mode | フォーム表示モードを取得または設定します。 |
| resolution | 画像の解像度を取得します。 |
| width | 画像の出力幅を取得します。 |
| height | 画像の出力高さを取得します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| process(page, output) | ページを Dicom に変換し、出力ストリームに保存します。 |
| process(page, output_file_name) | ページを Dicom に変換し、出力ストリームに保存します。 |
