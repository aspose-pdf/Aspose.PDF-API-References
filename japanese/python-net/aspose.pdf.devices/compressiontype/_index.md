## CompressionType enumeration

TIFFイメージデバイスに渡されるパラメータ値を指定するために使用されます。

## Members
| メンバー名 | 説明 |
| :- | :- |
| LZW | LZW 圧縮方式を指定します。Compression カテゴリに属するパラメータとして Tiff エンコーダに渡すことができます。 |
| CCITT4 | CCITT4 圧縮方式を指定します。Compression カテゴリに属するパラメータとして CCITT4 エンコーダに渡すことができます。 |
| CCITT3 | CCITT3 圧縮方式を指定します。Compression カテゴリに属するパラメータとして CCITT3 エンコーダに渡すことができます。 |
| RLE | RLE 圧縮方式を指定します。Compression カテゴリに属するパラメータとして RLE エンコーダに渡すことができます。 |
| NONE | 圧縮なしを指定します。compression カテゴリに属するパラメータとして Tiff エンコーダに渡すことができます。 |
