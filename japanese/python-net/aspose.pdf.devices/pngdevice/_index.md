## PngDevice class

PDF ドキュメントのページを PNG 形式で保存するのに役立つ画像デバイスを表します。

PngDevice 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| PngDevice() | デフォルトの解像度で [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) クラスの新しいインスタンスを初期化します。 |
| PngDevice(resolution) | PngDevice クラスの新しいインスタンスを初期化します |
| PngDevice(width, height, resolution) | PngDevice クラスの新しいインスタンスを初期化します |
| PngDevice(page_size, resolution) | PngDevice クラスの新しいインスタンスを初期化します |
| PngDevice(width, height) | PngDevice クラスの新しいインスタンスを初期化します |
| PngDevice(page_size) | PngDevice クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| coordinate_type | ページ座標タイプ（Media/Crop ボックス）を取得または設定します。デフォルトでは CropBox の値が使用されます。 |
| rendering_options | レンダリングオプションを取得または設定します。 |
| form_presentation_mode | フォーム表示モードを取得または設定します。 |
| resolution | 画像の解像度を取得します。 |
| width | 画像の出力幅を取得します。 |
| height | 画像の出力高さを取得します。 |
| transparent_background | 画像が透明な背景を持つかどうかを取得または設定します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| process(page, output) | ページを PNG に変換し、出力ストリームに保存します。 |
| process(page, output_file_name) | ページを PNG に変換し、出力ストリームに保存します。 |
