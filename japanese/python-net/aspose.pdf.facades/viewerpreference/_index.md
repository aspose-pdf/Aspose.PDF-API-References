## ViewerPreference class

ビューアの設定（ページモード、全画面以外のページモード、ページレイアウト）を記述します。

ViewerPreference 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| ViewerPreference() | ViewerPreference クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| PAGE_MODE_USE_OC | オプションコンテンツグループパネルが表示されます。 |
| DISPLAY_DOC_TITLE | ウィンドウのタイトルバーに文書タイトルを表示するかどうかを指定するフラグ |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | オプションコンテンツグループパネルが表示されます。 |
| PAGE_LAYOUT_SINGLE_PAGE | 1ページずつ表示します。 |
| PAGE_LAYOUT_ONE_COLUMN | ページを1列で表示します。 |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | ページを2列で表示し、奇数ページを右側に配置します。 |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | ページを2列で表示し、奇数ページを右側に配置します。 |
| PAGE_MODE_USE_NONE | 文書アウトラインもサムネイル画像も表示されません |
| PAGE_MODE_USE_OUTLINES | 文書アウトラインが表示されます。 |
| PAGE_MODE_USE_THUMBS | サムネイル画像が表示されます。 |
| PAGE_MODE_FULL_SCREEN | 全画面モードで、メニューバー、ウィンドウコントロール、その他のウィンドウは表示されません。 |
| PAGE_MODE_USE_ATTACHMENT | 添付ファイル付きのページモードです。 |
| HIDE_TOOLBAR | ドキュメントがアクティブなときに、準拠リーダーのツールバーを非表示にするかどうかを指定するフラグです。 |
| HIDE_MENUBAR | ドキュメントがアクティブなときに、準拠リーダーのメニューバーを非表示にするかどうかを指定するフラグです。 |
| HIDE_WINDOW_UI | ドキュメントのウィンドウ内のユーザーインターフェイス要素（スクロールバーやナビゲーションコントロールなど）を非表示にし、ドキュメントの内容のみを表示するかどうかを指定するフラグです。 |
| FIT_WINDOW | 最初に表示されるページのサイズに合わせてドキュメントのウィンドウサイズを変更するかどうかを指定するフラグです。 |
| CENTER_WINDOW | 画面の中央にドキュメントのウィンドウを配置するかどうかを指定するフラグです。 |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | ドキュメントのアウトラインもサムネイル画像も表示されません。 |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | 文書アウトラインが表示されます。 |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | サムネイル画像が表示されます |
| DIRECTION_L2R | テキストの読み順は左から右です。 |
| DIRECTION_R2L | テキストの読み順は右から左です。 |
| SIMPLEX | 片面印刷。 |
| DUPLEX_FLIP_SHORT_EDGE | 短辺で両面印刷し、裏返しします。 |
| DUPLEX_FLIP_LONG_EDGE | 短辺で両面印刷し、裏返しします。 |
