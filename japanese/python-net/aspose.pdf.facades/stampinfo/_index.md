## StampInfo class

スタンプ情報を表すクラスです。

StampInfo 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| stamp_id | スタンプの識別子を取得します。 |
| index_on_page | ページ上のスタンプインデックスを取得します。 |
| stamp_type | スタンプのタイプ（画像 / フォーム）を取得します。 |
| rectangle | スタンプが配置されている矩形を取得します。 |
| image | スタンプの画像を取得します。スタンプに画像が含まれていない場合（例：テキストスタンプ）は null になることがあります。 |
| form | スタンプの XForm を取得します。 |
| text | スタンプ内のテキストを取得します。 |
| visible | スタンプの可視性を取得します。false の場合、スタンプは HideStampById によって非表示になります。非表示のスタンプは ShowStampById で復元できます。 |
