## KeySize enumeration

PDF文書の暗号化に使用できるさまざまなキーサイズを定義します。

## Members
| メンバー名 | 説明 |
| :- | :- |
| X40 | 40 ビットキーです。このキーサイズは RC4 アルゴリズムで使用され、低いセキュリティレベルを提供します。 <br/>            それでも、PDF 文書の古いバージョンはこのようなキー（v. 1.3 以下）のみで暗号化できます； |
| X128 | 128ビットキー。RC4 と AES の両アルゴリズムでこのキーサイズを使用できます。 |
| X256 | 256ビットキー。このキーサイズは AES のみで使用でき、最新の Adobe Reader バージョン（v.9 以降）で認識されます。 |
