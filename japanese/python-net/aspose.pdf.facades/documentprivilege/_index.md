## DocumentPrivilege class

PDF ファイルへのアクセス権限を表します。[PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/) を参照してください。<br/>             このクラスの使用方法は4つあります：<br/>             1. 事前定義された権限を直接使用する。<br/>             2. 事前定義された権限に基づき、特定の権限を変更する。<br/>             3. 事前定義された権限に基づき、特定の Adobe Professional 権限の組み合わせを変更する。<br/>             4. 方法2と方法3を組み合わせる。

DocumentPrivilege 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| allow_print | 印刷を許可するかどうかの権限を設定します。<br/>            true は許可、false は禁止です。 |
| allow_degraded_printing | 低解像度印刷を許可するかどうかの権限を設定します。<br/>            true は許可、false は禁止です。 |
| allow_modify_contents | 内容の変更を許可するかどうかの権限を設定します。<br/>            true は許可、false は禁止です。 |
| allow_copy | コピーを許可するかどうかの権限を設定します。 <br/>            true は許可、false は禁止です。 |
| allow_modify_annotations | 注釈の変更を許可するかどうかの権限を設定します。 <br/>            true は許可、false は禁止です。 |
| allow_fill_in | フォームへの入力を許可するかどうかの権限を設定します。 <br/>            true は許可、false は禁止です。 |
| allow_screen_readers | スクリーンリーダーを許可するかどうかの権限を設定します。 <br/>            true は許可、false は禁止です。 |
| allow_assembly | アセンブリを許可するかどうかの権限を設定します。 <br/>            true は許可、false は禁止です。 |
| degraded_printing | 低品質印刷を許可します。 |
| print | ファイルの印刷を許可します。 |
| modify_contents | ファイルの変更を許可します。 |
| copy | ファイルのコピーを許可します。 |
| modify_annotations | ファイルの注釈の変更を許可します。 |
| fill_in | ファイル内のフォームへの入力を許可します。 |
| screen_readers | 画面上でのみ読むことを許可します。 |
| assembly | ファイルのアセンブリを許可します。 |
| allow_all | すべて許可されました。 |
| forbid_all | すべてが禁止されました。 |
