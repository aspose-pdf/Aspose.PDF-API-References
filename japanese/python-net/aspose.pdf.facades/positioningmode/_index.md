## PositioningMode enumeration

配置モードを定義します。<br/>            可能な値には、レガシー（下位互換性）と<br/>            カレント（更新されたテキスト位置計算方法）が含まれます。

## Members
| メンバー名 | 説明 |
| :- | :- |
| LEGACY | レガシー テキスト配置 |
| MODERN_LINE_SPACING | 行間が更新され、垂直位置の計算は古い規則で行われます <br/>            （つまり、テキストは指定された矩形の左下隅を基準に配置されます） |
| CURRENT | 行間が更新され、垂直位置の計算は左下ではなく左上隅を基準に行われます。 |
