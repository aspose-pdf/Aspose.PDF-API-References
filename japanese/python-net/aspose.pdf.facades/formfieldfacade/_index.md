## FormFieldFacade class

フィールドプロパティを表すクラスです。

FormFieldFacade 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| FormFieldFacade() | FormFieldFacade クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| border_color | フィールド境界線の色です。 |
| border_style | フィールド境界線のスタイルです。 |
| border_width | フィールド境界線の幅です。 |
| font | フィールドテキストのフォントタイプです。 |
| custom_font | 標準でないフォント（14 の標準フォント以外）の場合、フォント名を取得または設定します。 |
| font_size | フィールドテキストのサイズです。 |
| text_color | フィールドテキストの色です。 |
| text_encoding | フィールドテキストの文字エンコーディングタイプです。 |
| alignment | フィールドテキストの配置で、デフォルトは左揃えです。 |
| rotation | フィールドテキストの回転です。 |
| caption | フォームフィールドの通常のキャプションです。 |
| button_style | チェックボックスまたはラジオボックスフィールドのスタイルで、FormFieldFacade.CheckBoxStyle* によって定義されます。 |
| box | フィールドの位置を保持する矩形オブジェクトです。 |
| position | フィールドの位置を保持する矩形オブジェクトです。 |
| page_number | フィールドが配置されているページ番号を保持する整数値です。 |
| items | 文字列の配列で、各要素はコンボボックス/リスト/ラジオボックスフィールドのオプションを表します。 |
| export_items | リスト/コンボ/ラジオボックスを追加するためのオプションです。 |
| background_color | フィールド背景の色で、デフォルトは白です。 |
| backgroud_color | 廃止されたプロパティです。BackgroundColor を使用してください。 |
| BORDER_WIDTH_UNDIFIED | 未定義のボーダー幅です。 |
| BORDER_WIDTH_UNDEFINED | 未定義のボーダー幅です。 |
| BORDER_WIDTH_THIN | 細いボーダー幅を定義します。 |
| BORDER_WIDTH_MEDIUM | 中程度のボーダー幅を定義します。 |
| BORDER_WIDTH_THICK | 太いボーダー幅を定義します。 |
| BORDER_STYLE_SOLID | 実線のボーダースタイルを定義します。 |
| BORDER_STYLE_DASHED | 破線のボーダースタイルを定義します。 |
| BORDER_STYLE_BEVELED | ベベル加工されたボーダースタイルを定義します。 |
| BORDER_STYLE_INSET | インセットされたボーダースタイルを定義します。 |
| BORDER_STYLE_UNDERLINE | 下線付きのボーダースタイルを定義します。 |
| BORDER_STYLE_UNDEFINED | 未定義のボーダースタイルです。 |
| ALIGN_LEFT | 左揃えの配置を定義します。 |
| ALIGN_CENTER | 中央揃えの配置を定義します。 |
| ALIGN_RIGHT | 右揃えの配置を定義します。 |
| ALIGN_UNDEFINED | 未定義の配置スタイルです。 |
| ALIGN_JUSTIFIED | テキストの両端揃え配置スタイルを定義します。 |
| ALIGN_TOP | 上部スタイルとして垂直配置を定義します。 |
| ALIGN_MIDDLE | 中部スタイルとして垂直配置を定義します。 |
| ALIGN_BOTTOM | 下部スタイルとして垂直配置を定義します。 |
| CHECK_BOX_STYLE_CIRCLE | 円形チェックボックススタイルを定義します。 |
| CHECK_BOX_STYLE_CHECK | チェックボックスがチェックされたときの形状を定義します。 |
| CHECK_BOX_STYLE_CROSS | 十字チェックボックススタイルを定義します。 |
| CHECK_BOX_STYLE_DIAMOND | ダイヤモンドチェックボックススタイルを定義します。 |
| CHECK_BOX_STYLE_STAR | 星形チェックボックススタイルを定義します。 |
| CHECK_BOX_STYLE_SQUARE | 四角形チェックボックススタイルを定義します。 |
| CHECK_BOX_STYLE_UNDEFINED | 未定義のチェックボックススタイルを定義します。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| reset() | すべての視覚属性を空の値にリセットします。 |
