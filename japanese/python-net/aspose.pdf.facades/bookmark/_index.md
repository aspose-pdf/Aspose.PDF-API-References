## Bookmark class

ブックマークを表します。

Bookmark 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| Bookmark() | Bookmark クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| action | ブックマークにバインドされたアクションを取得または設定します。<br/>            PageNumber が指定されている場合、アクションを指定できません。<br/>            アクションのタイプには、\"GoTo\", \"GoToR\", \"Launch\", \"Named\" が含まれます。 |
| bold_flag | ブックマークのタイトルの太字フラグを取得または設定します。 |
| child_item | ブックマークの子要素を取得または設定します。 |
| child_items | ブックマークの子要素を取得または設定します。 |
| destination | ブックマークの目的ページを取得または設定します。action が string.Empty に設定されている場合は必須です。 |
| italic_flag | ブックマークのタイトルの斜体フラグを取得または設定します。 |
| level | ブックマークの階層レベルを取得または設定します。 |
| page_display | ブックマークの目的ページの表示タイプを取得または設定します。 |
| page_display_bottom | ページ表示の下側座標を取得または設定します。 |
| page_display_left | ページ表示の左側座標を取得または設定します。 |
| page_display_right | ページ表示の右側座標を取得または設定します。 |
| page_display_top | ページ表示の上側座標を取得または設定します。 |
| page_display_zoom | ページ表示のズーム倍率を取得または設定します。 |
| page_number | ブックマークの目的ページ番号を取得または設定します。 |
| remote_file | ブックマークの "GoToR" アクションに必要なファイル（パス）を取得または設定します。 |
| タイトル | ブックマークのタイトルを取得または設定します。 |
| title_color | ブックマークのタイトルの色を取得または設定します。 |
| open | ブックマークの状態（開く、閉じる）を取得または設定します。 |
