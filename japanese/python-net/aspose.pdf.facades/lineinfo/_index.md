## LineInfo class

線の情報を表します。

LineInfo 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| LineInfo() | LineInfo クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| vertice_coordinate | 各頂点の水平座標と垂直座標を交互に表す数値の配列を取得または設定します。 |
| line_color | 線の色を取得または設定します。 |
| line_width | 線の幅を取得または設定します。 |
| visibility | 線の表示状態を取得または設定します。 |
| line_dash_pattern | 線の破線パターンを取得または設定します。 |
| border_style | 線の枠線スタイルを取得または設定します。0 は実線、1 は破線、2 は beleved、3 は insert、4 は下線を表します。 |
