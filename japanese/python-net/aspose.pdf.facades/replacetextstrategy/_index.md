## ReplaceTextStrategy class

このクラスは、ReplaceText操作が実行される際のPdfContentEditorの動作を定義するパラメータを含みます。

ReplaceTextStrategy 型は次のメンバーを公開します：
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| ReplaceTextStrategy() | ReplaceTextStrategy クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| is_regular_expression_used | false の場合、検索文字列は単純なテキストです。true の場合、検索文字列は正規表現です。 |
| no_character_behavior | 変更されたテキストに適切なフォントが見つからない場合に実行されるアクション<br/>            (例外をスロー / 他のフォントに置き換える / とにかく置き換える)。 |
| replace_scope | 置換操作の範囲 (最初の出現のみ置換またはすべての出現を置換)。 |
