## LinkElement class

論理構造内の Link 構造要素を表します。

LinkElement 型は以下のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| parent_element | None |
| child_elements | None |
| default_attribute_owner | None |
| attributes | None |
| structure_type | None |
| id | None |
| タイトル | None |
| language | None |
| alternative_text | None |
| expansion_text | None |
| actual_text | None |
| alternate_descriptions | 注釈の代替説明を取得または設定します。<br/>                注釈に表示されるテキスト、またはこの種の注釈がテキストを表示しない場合は、注釈の内容を人間が読める形での代替説明です。 |
| hyperlink | リンク要素のハイパーリンクを取得または設定します。 |
| structure_text_state | 取得 |
