## StructureTypeStandard class

標準構造タイプを表します。

StructureTypeStandard 型は次のメンバーを公開します:
## プロパティ
| 名前 | 説明 |
| :- | :- |
| tag | [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) のタグ名を取得します。 |
| カテゴリ | Standard Structure Type のカテゴリを取得します。 |
| ドキュメント | (Document) 完全なドキュメントです。これは、複数のパートまたは複数の記事を含む任意の構造ツリーのルート要素です。 |
| パート | (Part) ドキュメントの大規模な区分です。このタイプの要素は、記事やセクションをグループ化するのに適しています。 |
| 記事 | (Article) 単一の物語または説明を構成する、比較的自己完結型のテキスト本文です。記事は互いに重複しないようにすべきで、他の記事を構成要素として含んではいけません。 |
| セクション | (Section) 関連するコンテンツ要素をグループ化するためのコンテナです。 |
| DIV | (Division) 汎用的なブロックレベル要素または要素のグループです。 |
| BLOCK_QUOTE | (Block quotation) 周囲のテキストの作者とは別の人物に帰属する、1つ以上の段落からなるテキストの一部。 |
| CAPTION | (Caption) 表や図を説明する短いテキスト。 |
| TOC | (Table of contents) 目次項目エントリ（構造タイプ TOCI）や他の入れ子になった目次エントリ（TOC）で構成されたリスト。 |
| TOCI | (Table of contents item) 目次の個々のメンバー。このエントリの子要素は以下の構造タイプのいずれかになる可能性があります： |
| INDEX | (Index) 識別テキストと、文書本体でそのテキストの出現箇所を示す参照要素を伴うエントリのシーケンス。 |
| NON_STRUCT | (Nonstructural element) 本質的な構造的意味を持たないグルーピング要素で、単にグループ化の目的で使用されます。この要素は、division（構造タイプ Div）とは異なり、他の文書形式へ解釈またはエクスポートされませんが、子要素は通常通り処理されます。 |
| PRIVATE | (Private element) それを生成したアプリケーションに属するプライベートコンテンツを含むグルーピング要素。この種の要素の構造的意味は未定義で、完全に準拠ライターによって決定されます。Private element およびその子要素は、他の文書形式へ解釈またはエクスポートされません。 |
| P | (Paragraph) テキストの低レベルな区分。 |
| H | (Heading) 文書コンテンツのサブディビジョンのラベルです。見出しが付くディビジョンの最初の子要素である必要があります。 |
| H1 | レベル 1 見出し。セクションを階層的に入れ子にできず、入れ子レベルから見出しのレベルを判定できない準拠ライターで使用します。 |
| H2 | レベル 2 見出し。セクションを階層的に入れ子にできず、入れ子レベルから見出しのレベルを判定できない準拠ライターで使用します。 |
| H3 | レベル 3 見出し。セクションを階層的に入れ子にできず、入れ子レベルから見出しのレベルを判定できない準拠ライターで使用します。 |
| H4 | レベル4の見出しは、セクションを階層的に入れ子にできず、入れ子のレベルから見出しのレベルを判断できない準拠ライターでの使用を目的としています。 |
| H5 | レベル5の見出しは、セクションを階層的に入れ子にできず、入れ子のレベルから見出しのレベルを判断できない準拠ライターでの使用を目的としています。 |
| H6 | レベル6の見出しは、セクションを階層的に入れ子にできず、入れ子のレベルから見出しのレベルを判断できない準拠ライターでの使用を目的としています。 |
| L | (List) 同様の意味と重要性を持つ項目のシーケンスです。その直下の子要素は、オプションのキャプション (structure type Caption) の後に、1つ以上のリスト項目 (structure type LI) が続くべきです。 |
| LI | (List item) リストの個々のメンバーです。その子要素は、1つ以上のラベル、リスト本体、またはその両方 (structure types Lbl or LBody) で構成される場合があります。 |
| LBL | (Label) 同じリストまたは同種の項目グループ内で、特定の項目を他と区別する名前または番号です。 |
| L_BODY | (List body) リスト項目の記述内容です。例えば辞書リストでは、用語の定義が含まれます。コンテンツを直接含む場合もあれば、他の BLSE（ネストされたリストを含む可能性があります）を子要素として持つ場合もあります。 |
| TABLE | (Table) 長方形のデータセルからなる二次元レイアウトで、複雑なサブ構造を持つことがあります。子要素として1つ以上のテーブル行 (structure type TR) を含むか、オプションのテーブルヘッド (structure type THead) の後に1つ以上のテーブル本体要素 (structure type TBody) とオプションのテーブルフッター (structure type TFoot) が続く構成です。さらに、テーブルは最初または最後の子要素としてキャプション (structure type Caption) を持つことがあります。 |
| T_HEAD | (Table header row group; PDF 1.5) テーブルのヘッダーを構成する行のグループです。テーブルが複数ページに分割される場合、これらの行は各テーブルフラグメントの上部に再描画されることがあります（ただし THead 要素は1つだけです）。 |
| T_BODY | (Table body row group; PDF 1.5) テーブルの本体部分を構成する行のグループです。テーブルが複数ページに分割される場合、本体領域は行の境界で分割されることがあります。テーブルは、特定の行セットに対して枠線や背景を描画できるように、複数の TBody 要素を持つことができます。 |
| T_FOOT | (Table footer row group; PDF 1.5) テーブルのフッターを構成する行のグループです。テーブルが複数ページに分割される場合、これらの行は各テーブルフラグメントの下部に再描画されることがあります（ただし TFoot 要素は1つだけです）。 |
| TR | (Table row) テーブル内の見出しまたはデータの行です。テーブルヘッダーセルとテーブルデータセル (structure types TH and TD) を含むことがあります。 |
| TH | (Table header cell) テーブルの1つ以上の行または列を説明するヘッダー文字列を含むセルです。 |
| TD | (Table data cell) テーブルのコンテンツの一部であるデータを含むセルです。 |
| SPAN | (Span) 特定の固有特性を持たない汎用的なインラインテキスト部分です。例えば、特定のスタイリング属性のセットでテキストの範囲を区切るために使用できます。 |
| QUOTE | (Quotation) 周囲のテキストの作者とは異なる人物に帰属するインラインテキスト部分です。 |
| 注 | (Note) 文書本文中から参照される脚注や文末脚注などの説明テキスト項目です。子要素としてラベル（構造タイプ Lbl）を持つことがあります。ノートはそれを参照する本文テキストの構造要素の子として含めることも、別の場所（例えば文末脚注セクション）に含めて参照（構造タイプ Reference）によってアクセスすることもできます。 |
| REFERENCE | (Reference) 文書内の他の場所にあるコンテンツへの引用です。 |
| BIB_ENTRY | (Bibliography entry) 引用されたコンテンツの外部ソースを特定する参照です。子要素としてラベル（構造タイプ Lbl）を持つことがあります。 |
| CODE | (Code) コンピュータプログラムテキストの断片です。 |
| LINK | (Link) ILSE のコンテンツの一部と対応するリンクアノテーションまたは複数のリンクアノテーションとの関連付けです。その子要素は、1つ以上のコンテンツ項目または子 ILSE と、関連付けられたリンクアノテーションを識別する1つ以上のオブジェクト参照である必要があります。 |
| ANNOT | (Annotation; PDF 1.5) ILSE のコンテンツの一部と対応する PDF アノテーションとの関連付けです。Annot はリンクアノテーションとウィジェットアノテーションを除くすべての PDF アノテーションに使用されます。 |
| RUBY | (Ruby; PDF 1.5) 基本文に隣接して配置され、より小さい文字サイズで記述されたサイドノート（アノテーション）です。Ruby 要素は RB、RT、RP 要素を含むこともあります。 |
| RB | (Ruby base text) ルビアノテーションが適用される全サイズのテキストです。RB はテキスト、他のインライン要素、またはその両方の混合を含むことができます。RubyAlign 属性を持つことがあります。 |
| RT | (Ruby annotation text) ルビ基本文に隣接して配置される小さいサイズのテキストです。テキスト、他のインライン要素、またはその混合を含むことができます。RubyAlign および RubyPosition 属性を持つことがあります。 |
| RP | (Ruby punctuation) ルビアノテーションテキストを囲む句読点です。ルビアノテーションをルビスタイルで正しくフォーマットできない場合や、通常のコメントとして、または割注（warichu）としてフォーマットされる場合にのみ使用されます。テキスト（通常は単一の左括弧または右括弧などの括弧文字）を含みます。 |
| WARICHU | (Warichu; PDF 1.5) 基本文に続いて（インラインで）配置され、含むテキスト行の高さ内で2行の小さいテキストサイズにフォーマットされたコメントまたはアノテーションです。Warichu 要素は WT と WP 要素を含むこともあります。 |
| WT | (Warichu text) ワリチュコメントの小さいサイズのテキストで、2行にフォーマットされ、周囲のWP要素の間に配置されます。 |
| WP | (Warichu punctuation) WTテキストを囲む句読点です。テキストを含みます（通常は単一の左括弧または右括弧などの括弧文字）。JIS X 4051-1995によれば、ワリチュを囲む括弧は、書式設定者の裁量でスペース（幅は名目上1/4 EM）に変換できる場合があります。 |
| FIGURE | (Figure) グラフィックコンテンツの項目です。その配置はPlacementレイアウト属性で指定できる場合があります。 |
| FORMULA | (Formula) 数学的な式です。 |
| FORM | (Form) インタラクティブなフォームフィールドを表すウィジェット注釈です。 |
