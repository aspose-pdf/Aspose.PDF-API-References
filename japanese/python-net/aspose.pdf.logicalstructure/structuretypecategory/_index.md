## StructureTypeCategory class

標準構造タイプのカテゴリを表します。

StructureTypeCategory 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| GROUPING_ELEMENTS | グルーピング要素は他の要素をシーケンスや階層にまとめますが、直接コンテンツを保持せず、レイアウトに直接影響を与えません。 |
| BLS_ES | ブロックレベル構造要素（BLSE） は、ページ上のコンテンツ全体のレイアウトを、ブロック進行方向に沿って記述します。 |
| ILS_ES | インラインレベル構造要素（ILSE） は、BLSE 内のコンテンツのレイアウトを、インライン進行方向に沿って記述します。 |
| ILLUSTRATION_ELEMENTS | イラスト要素は、ページコンテンツの順序で配置されたコンパクトなコンテンツシーケンスで、ページレイアウトに対して単一のオブジェクトとみなされます。イラストは BLSE または ILSE のいずれかとして扱うことができます。 |
