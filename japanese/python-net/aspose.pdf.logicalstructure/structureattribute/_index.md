## StructureAttribute class

構造要素の属性を表します。

StructureAttribute 型は次のメンバーを公開します:
## コンストラクター
| 名前 | 説明 |
| :- | :- |
| StructureAttribute(attribute_key) | StructureAttribute クラスの新しいインスタンスを初期化します |
## プロパティ
| 名前 | 説明 |
| :- | :- |
| key | 属性キーを取得します。 |
| is_initialized_value | 構造属性値のステータスを取得します。値が設定されている場合は true です。 |
## メソッド
| 名前 | 説明 |
| :- | :- |
| get_name_value() | 値の名前を取得します。 |
| get_string_value() | 値の文字列を取得します。 |
| get_number_value() | 値の数値を取得します。 |
| get_array_value() | 値の名前配列を取得します。 |
| get_array_number_value() | 値の数配列を取得します。 |
| set_name_value(name) | 値の名前を設定します。 |
| set_string_value(value) | 値の文字列を設定します。 |
| set_number_value(number) | 値の数値を設定します。 |
| set_array_value(array) | 値の名前配列を設定します。 |
| set_array_number_value(array_number) | 値の数配列を設定します。 |
| set_color_value(color) | 値の色を設定します。 |
| set_rectangle_value(rectangle) | 値の矩形を設定します。 |
