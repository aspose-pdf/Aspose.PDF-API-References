## AttributeKey class

標準属性キーを表します。

AttributeKey 型は次のメンバーを公開します：
## プロパティ
| 名前 | 説明 |
| :- | :- |
| key | 属性キーを取得します。 |
| owner | 属性所有者を取得します。 |
| PLACEMENT | 配置属性（レイアウト属性の所有者）。 |
| WRITING_MODE | WritingMode 属性 (Layout 属性所有者). |
| BACKGROUND_COLOR | BackgroundColor 属性 (Layout 属性所有者). |
| BORDER_COLOR | BorderColor 属性 (Layout 属性所有者). |
| BORDER_STYLE | BorderStyle 属性 (Layout 属性所有者). |
| BORDER_THICKNESS | BorderThickness 属性 (Layout 属性所有者). |
| PADDING | Padding 属性 (Layout 属性所有者). |
| COLOR | Color 属性 (Layout 属性所有者). |
| SPACE_BEFORE | SpaceBefore 属性 (Layout 属性所有者). |
| SPACE_AFTER | SpaceAfter 属性 (Layout 属性所有者). |
| START_INDENT | StartIndent 属性 (Layout 属性所有者). |
| END_INDENT | EndIndent 属性 (Layout 属性所有者). |
| TEXT_INDENT | TextIndent 属性 (Layout 属性所有者). |
| TEXT_ALIGN | TextAlign 属性 (Layout 属性所有者). |
| B_BOX | BBox 属性 (Layout attribute owner)。 |
| WIDTH | Width 属性 (Layout attribute owner)。 |
| HEIGHT | Height 属性 (Layout attribute owner)。 |
| BLOCK_ALIGN | BlockAlign 属性 (Layout attribute owner)。 |
| INLINE_ALIGN | InlineAlign 属性 (Layout attribute owner)。 |
| T_BORDER_STYLE | TBorderStyle 属性 (Layout attribute owner)。 |

| TEXT_DECORATION_COLOR | TextDecorationColor 属性 (Layout attribute owner)。 |
| TEXT_DECORATION_THICKNESS | TextDecorationThickness 属性 (Layout attribute owner)。 |

| RUBY_ALIGN | RubyAlign 属性 (レイアウト属性所有者)。 |

| CHECKED | Checked 属性 (PrintField属性所有者)。 |
| DESC | Desc 属性 (PrintField属性所有者)。 |
| ROW_SPAN | RowSpan 属性 (テーブル属性所有者)。 |
| COL_SPAN | ColSpan 属性 (テーブル属性所有者)。 |
| HEADERS | Headers 属性 (テーブル属性所有者)。 |
