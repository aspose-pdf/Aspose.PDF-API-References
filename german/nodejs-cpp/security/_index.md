## Security PDF functions

| Name | Beschreibung |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | Verschlüsseln Sie eine PDF-Datei. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | Entschlüsseln Sie eine PDF-Datei. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | Signieren Sie eine PDF-Datei mit digitalen Signaturen. |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | Signieren Sie eine PDF-Datei mit losgelösten digitalen Signaturen. |
