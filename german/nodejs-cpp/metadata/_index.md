## Metadata PDF functions

| Name | Beschreibung |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | Legen Sie Informationen (Metadaten) in einer PDF-Datei fest. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | Rufen Sie Informationen (Metadaten) aus einer PDF-Datei ab. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | Ermitteln Sie die Schriftartenliste aus einer PDF-Datei. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | Entfernen Sie Metadaten aus einer PDF-Datei. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | Ermitteln Sie die Wort- und Zeichenanzahl in einer PDF-Datei. |
| [AsposePdfGetPagesLayers](./asposepdfgetpageslayers/) | Ermitteln Sie die Ebenenliste aus einer PDF-Datei. |
