## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ExtractedFragmentsProcessorBase](./extractedfragmentsprocessorbase/) | Stellt eine Basisklasse für extrahierte Fragmentprozessoren dar. |
| [IgnoreSpacesFragmentsProcessor](./ignorespacesfragmentsprocessor/) | Stellt eine Klasse zum Verarbeiten von Textfragmenten im Modus 'Leerzeichen ignorieren' dar. Diese Klasse ignoriert alle Leerzeichen und hebt einzelne Wörter als Fragmente hervor. |
| [NormalFragmentProcessor](./normalfragmentprocessor/) | Stellt eine Klasse zum Verarbeiten von Textfragmenten im Normalmodus dar. Diese Klasse berücksichtigt nur Leerzeichen innerhalb von Fragmenten. |
| [ParseSpacesFragmentsProcessor](./parsespacesfragmentsprocessor/) | Stellt eine Klasse zum Verarbeiten von Textfragmenten im Modus 'Leerzeichen parsen' dar. Diese Klasse erkennt Leerzeichen zwischen Textfragmenten basierend auf dem Abstand zwischen ihnen. |
