Stellt ein Aufzählungselement für das Deckungsniveau bereit, das digitale Signaturen in einem Dokument bieten.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [EntirelySigned](#EntirelySigned) | Gibt an, dass das Dokument vollständig durch digitale Signaturen abgedeckt ist. Dieser Wert bedeutet, dass alle erforderlichen Teile des Dokuments signiert wurden und keine Signaturen kompromittiert sind. |
| [PartiallySigned](#PartiallySigned) | Gibt an, dass das Dokument teilweise signiert ist, d. h. dass ein Teil, aber nicht der gesamte Inhalt, durch digitale Signaturen abgedeckt ist. Dieser Wert wird verwendet, wenn bestimmte Teile des Dokuments unsigniert bleiben oder von der Signaturabdeckung ausgeschlossen sind. |
| [Undefined](#Undefined) | Gibt an, dass der Zustand der Abdeckung digitaler Signaturen im Dokument undefiniert ist. Dieser Wert wird typischerweise verwendet, wenn eine oder mehrere Signaturen im Dokument kompromittiert sind oder nicht verifiziert werden können, wodurch eine eindeutige Bewertung der Signaturabdeckung des Dokuments verhindert wird. |
