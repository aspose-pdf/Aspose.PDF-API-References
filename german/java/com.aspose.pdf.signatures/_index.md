## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CompromiseCheckResult](./compromisecheckresult/) | Stellt eine Klasse zum Überprüfen digitaler Signaturen eines Dokuments auf Kompromittierung bereit. |
| [InternalHelper](./internalhelper/) |  |
| [SignaturesCompromiseDetector](./signaturescompromisedetector/) | Stellt eine Klasse zum Überprüfen kompromittierter Signaturen des Dokuments bereit. Der Detektor prüft nur bekannte Methoden zur Kompromittierung von Signaturen.
