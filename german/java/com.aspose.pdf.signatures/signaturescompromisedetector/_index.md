Stellt eine Klasse zum Überprüfen kompromittierter Signaturen des Dokuments bereit. Der Detektor prüft nur bekannte Methoden zur Kompromittierung von Signaturen. Die Verifizierung kann keine 100 %ige Garantie für das Fehlen einer Signaturkompromittierung geben und kann bei neuen, unbekannten Kompromittierungsmethoden, die von den getesteten abweichen, ein falsches Negativresultat liefern.
