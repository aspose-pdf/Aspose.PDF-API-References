Der com.aspose.pdf.markdownoptions‑Namensraum enthält spezifische Optionsklassen für eine Markdown-Konvertierung.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | Definiert die verfügbaren Serialisierungsstile für Hervorhebung und starke Hervorhebung. Für die Spezifikation siehe CommonMark – Emphasis and strong emphasis. |
| [HeadingLevels](./headinglevels/) | Stellt eine Klasse dar, die mit Überschriftenebenen basierend auf der Schriftgröße arbeitet. |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | Stellt Typen von Header-Erkennungsstrategien dar. |
| [HeadingStyle](./headingstyle/) | Definiert die verfügbaren Serialisierungsstile für Überschriften. Für die Spezifikation siehe CommonMark – ATX headings bzw. CommonMark – Setext headings. |
| [LineBreakStyle](./linebreakstyle/) | Stellt die möglichen Zeilenumbruchstile für eine Datei dar. |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Stellt die Dokument‑Speicheroption‑Klasse im Markdown-Format dar. |
