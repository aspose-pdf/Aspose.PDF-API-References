Definiert die verfügbaren Serialisierungsstile für Überschriften. Für die Spezifikation siehe CommonMark – ATX headings bzw. CommonMark – Setext headings.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Atx](#Atx) | Überschriften mit '#' voranstellen |
| [Setext](#Setext) | Unterstreiche Überschriften der Ebene 1 und 2 mit "======" bzw. "------". Setext-Überschriften sind nur für Ebenen 1 und 2 verfügbar. Selbst wenn der Überschriftsstil auf Setext gesetzt ist, wird für Ebenen 3 und höher der Atx-Stil verwendet. |

### Atx {#Atx}
```
public static final int Atx
```

Überschriften mit '#' voranstellen

### Setext {#Setext}
```
public static final int Setext
```

Unterstreiche Überschriften der Ebene 1 und 2 mit "======" bzw. "------". Setext-Überschriften sind nur für Ebenen 1 und 2 verfügbar. Selbst wenn der Überschriftsstil auf Setext gesetzt ist, wird für Ebenen 3 und höher der Atx-Stil verwendet.
