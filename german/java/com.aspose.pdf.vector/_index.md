Der Aspose.Pdf.Vector ist ein Root-Namespace für Grafikoperationen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [GraphicElement](./graphicelement/) | Stellt die Basisklasse für ein Grafikobjekt auf der Seite bereit. |
| [GraphicElementCollection](./graphicelementcollection/) | Stellt die {@link GraphicElement}-Sammlung bereit. |
| [GraphicsAbsorber](./graphicsabsorber/) | Stellt ein Absorber‑Objekt für Grafikelemente bereit. Führt eine Grafiksuche durch und bietet Zugriff auf die Suchergebnisse über die {@code GraphicsAbsorber.Elements}({@link GraphicsAbsorber#getElements})‑Sammlung. |
| [GraphicState](./graphicstate/) | Stellt den Grafikzustand des aktuellen {@link GraphicElement} bereit. |
| [InternalHelper](./internalhelper/) |  |
| [SubPath](./subpath/) | Stellt ein Vektorgrafik‑Objekt auf der Seite dar. Grundsätzlich werden Vektorgrafik‑Objekte durch zwei Gruppen von SubPaths repräsentiert. Eine davon wird durch eine Menge von Linien und Kurven dargestellt. Die anderen werden als Rechtecke präsentiert und können manchmal verwechselt werden. In der Regel ist es ein rechteckiger Bereich, der eine Farbe hat, aber sehr häufig wird dieses Rechteck am Anfang der Seite platziert und definiert den gesamten Seitenbereich in Weiß. So erhalten Sie den SubPath, aber visuell sehen Sie nur den Text auf der Seite. |
| [XFormPlacement](./xformplacement/) | Stellt die Platzierung von XForm dar. Wenn das XForm mehr als einmal auf der Seite angezeigt wird, haben alle mit diesem XForm verbundenen XformPlacements gemeinsame grafische Elemente, jedoch unterschiedliche grafische Zustände. |
