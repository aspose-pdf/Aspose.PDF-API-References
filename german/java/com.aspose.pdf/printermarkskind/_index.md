Gibt die Typen der Druckerzeichen an, die zu einem Dokument hinzugefügt werden sollen. Diese Aufzählung hat ein {@link FlagsAttribute} Attribut, das eine bitweise Kombination ihrer Memberwerte ermöglicht.
