Gibt eine Richtlinie dafür an, wie die Schriftgröße von Text angepasst werden soll, um in einen umgebenden Bereich zu passen.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [None](#None) | Die Schriftgröße wird nicht geändert. |
| [ScaleToFill](#ScaleToFill) | Die Schriftgröße wird angepasst (sowohl verkleinert als auch vergrößert), um den Text so weit wie möglich die Grenzen des Rechtecks ausfüllen zu lassen. |
| [ShrinkToFit](#ShrinkToFit) | Die Schriftgröße wird reduziert, wenn der Text zu groß ist, um in die Begrenzungen zu passen. |
