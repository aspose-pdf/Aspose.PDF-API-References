Stellt das PKCS#7‑Objekt dar, das der PKCS#7‑Spezifikation im Internet‑RFC 2315, PKCS #7: Cryptographic Message Syntax, Version 1.5, entspricht. Der ursprünglich signierte Nachrichten‑Digest über den Byte‑Bereich des Dokuments wird als normales PKCS#7‑SignedData‑Feld eingebunden. Es dürfen keine Daten im PKCS#7‑SignedData‑Feld gekapselt werden.
