### getEmulateRequierdGroups {#getEmulateRequierdGroups--}
```
public boolean getEmulateRequierdGroups()
```

Wenn diese Eigenschaft true ist, werden zusätzliche rote Rechtecke für erforderliche Xfa "excluded groups" gezeichnet. Diese Eigenschaft wurde eingeführt, weil bei der Konvertierung der Xfa‑Darstellung von Formularen zum Standard Analoga für ausgeschlossene Gruppen fehlen. Sie ist standardmäßig false.

### getSigned {#getSigned--}
```
public boolean getSigned()
```

Wenn diese Eigenschaft true ist, wird das Dokument unter Verwendung des xfa‑Formularstreams (falls vorhanden) konvertiert. Wenn sie false ist, wird der xfa‑Formularstream ignoriert. Diese Eigenschaft wurde eingeführt, weil nicht klar ist, wie die Prüfsumme berechnet werden soll, die zur Signaturprüfung verwendet wird.
