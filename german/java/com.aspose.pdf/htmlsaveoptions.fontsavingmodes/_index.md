Enumeriert Modi, die zum Speichern von im PDF referenzierten Schriftarten verwendet werden können.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | Alle referenzierten Schriftarten werden gespeichert und als EOT-fonts referenziert. |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | Alle referenzierten Schriftarten werden gespeichert und als TTF-fonts referenziert. |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | Alle referenzierten Schriftarten werden gespeichert und als WOFF-fonts referenziert. |
| [DontSave](#DontSave) | Alle referenzierten Schriftarten werden nicht gespeichert. |
| [SaveInAllFormats](#SaveInAllFormats) | Alle referenzierten Schriftarten werden (und in CSS referenziert) als 3 unabhängige Dateien gespeichert: EOT, TTH, WOFF. Es erhöht die Größe der Ausgabedaten, macht die Ausgabe jedoch für die überwiegende Mehrheit der Webbrowser geeignet. |
