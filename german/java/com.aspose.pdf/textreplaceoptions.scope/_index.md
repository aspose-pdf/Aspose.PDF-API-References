Geltungsbereich, in dem die Ersetzungs-Text-Operation angewendet wird; standardmäßig REPLACE_FIRST. Diese veraltete Option wurde aus Kompatibilitätsgründen beibehalten. Sie wirkt sich auf PdfContentEditor aus und hat keine Wirkung auf TextFragmentAbsorber.
