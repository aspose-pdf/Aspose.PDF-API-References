Binary Flag Gibt Flags an, die zusammen mit anderen Optionen die Größe und das Layout von Seiten bestimmen.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [FitToWidestContentWidth](#FitToWidestContentWidth) | Gibt an, dass die Breite der Seite aus der Größe des Inhalts selbst bestimmt wird, nicht aus der angegebenen Seitenbreite. |
| [None](#None) | Standardwert, der angibt, dass die HtmlPageLayoutOption die Größen und Layouts der Seiten nicht beeinflusst. |
| [ScaleToPageWidth](#ScaleToPageWidth) | Gibt an, dass der Inhalt des Dokuments skaliert wird, um auf die Seite zu passen. |
