Die Legacy-Konvertierungs-Engine ist die Konvertierungs-Engine, die eine Zeit lang verwendet wurde und standardmäßig verwendet wird.

### NewEngine {#NewEngine}
```
public static final int NewEngine
```

Die neue Konvertierungs-Engine befindet sich derzeit im A-Testing-Zustand. Wir stellen sie in der öffentlichen API zur Verfügung, um Feedback zu erhalten. Es wird derzeit empfohlen, sie nur zu verwenden, wenn die alte Konvertierungs-Engine ein Dokument aus bestimmten Gründen nicht konvertieren kann.
