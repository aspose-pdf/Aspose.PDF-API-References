Enumeriert die Arten von Beziehungen (den "Antworttyp") zwischen der Anmerkung und einer, die durch InReplyTo angegeben ist.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Group](#Group) | Die Anmerkung ist mit der durch InReplyTo angegebenen Anmerkung gruppiert. |
| [Reply](#Reply) | Die Anmerkung wird als Antwort auf die durch InReplyTo angegebene Anmerkung betrachtet. |
| [Undefined](#Undefined) | Undefinierte Beziehung. |
