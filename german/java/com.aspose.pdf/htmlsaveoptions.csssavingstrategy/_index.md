Sie können dieser Eigenschaft eine benutzerdefinierte Strategie zuweisen, die die Verarbeitung und/oder das Speichern eines CSS-Teils implementiert, das während der Konvertierung von PDF zu HTML erstellt wurde. In einem solchen Fall muss die Verarbeitung (wie das Speichern in einen Stream oder auf die Festplatte) in diesem benutzerdefinierten Code erfolgen.
