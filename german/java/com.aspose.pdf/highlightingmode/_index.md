Enumeriert den Hervorhebungsmodus der Anmerkung, den visuellen Effekt, der verwendet wird, wenn die Maustaste im aktiven Bereich gedrückt oder gehalten wird.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Invert](#Invert) | Invertiere den Inhalt des Anmerkungsrechtecks. |
| [None](#None) | Keine Hervorhebung. |
| [Outline](#Outline) | Invertiere den Rand der Anmerkung. |
| [Push](#Push) | Zeige das down-Erscheinungsbild der Anmerkung an, falls vorhanden. |
| [Toggle](#Toggle) | Wie Push (bevorzugt). |
