Manchmal gibt es spezifische Anforderungen an das erstellte HTML. Diese Aufzählung definiert HTML-Vorbereitungsmodi, die während der Konvertierung von PDF zu HTML verwendet werden können, um diesen spezifischen Anforderungen gerecht zu werden.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [WriteAllHtml](#WriteAllHtml) | Standardmodus, wenn keine spezifischen Anforderungen vorhanden sind. Es wird ein Ausgabeinhalt erzeugt, der alle Teile des HTML enthält, ohne besondere zusätzliche Verarbeitung. |
| [WriteOnlyBodyContent](#WriteOnlyBodyContent) | Alle HTML-Inhalte, die sich außerhalb des HTML‑Body befinden, werden entfernt, d. h. es bleibt nur der Inhalt, der sich innerhalb von {@code }‑Tags befindet. |

### WriteAllHtml {#WriteAllHtml}
```
public static final int WriteAllHtml
```

Standardmodus, wenn keine spezifischen Anforderungen vorhanden sind. Es wird ein Ausgabeinhalt erzeugt, der alle Teile des HTML enthält, ohne besondere zusätzliche Verarbeitung.

### WriteOnlyBodyContent {#WriteOnlyBodyContent}
```
public static final int WriteOnlyBodyContent
```

Alle HTML-Inhalte, die sich außerhalb des HTML‑Body befinden, werden entfernt, d. h. es bleibt nur der Inhalt, der sich innerhalb von {@code }‑Tags befindet.
