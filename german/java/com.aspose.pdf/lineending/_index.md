Enumeriert die Endstilarten für Linien, die beim Zeichnen der Linie verwendet werden.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Butt](#Butt) | Eine kurze Linie am Endpunkt, senkrecht zur Linie selbst. |
| [Circle](#Circle) | Ein Kreis, gefüllt mit der Innenfarbe der Anmerkung, falls vorhanden. |
| [ClosedArrow](#ClosedArrow) | Zwei kurze Linien, die in einem spitzen Winkel wie beim OpenArrow-Stil zusammentreffen und durch eine dritte Linie verbunden sind, um einen dreieckigen geschlossenen Pfeilkopf zu bilden, gefüllt mit der Innenfarbe der Anmerkung, falls vorhanden. |
| [Diamond](#Diamond) | Eine rautenförmige Form, gefüllt mit der Innenfarbe der Anmerkung, falls vorhanden. |
| [None](#None) | Kein Linienende. |
| [OpenArrow](#OpenArrow) | Zwei kurze Linien, die in einem spitzen Winkel zusammentreffen, um einen offenen Pfeilkopf zu bilden. |
| [RClosedArrow](#RClosedArrow) | Ein dreieckiger geschlossener Pfeilkopf in umgekehrter Richtung zu ClosedArrow. |
| [ROpenArrow](#ROpenArrow) | Zwei kurze Linien in umgekehrter Richtung zu OpenArrow. |
| [Slash](#Slash) | Eine kurze Linie am Endpunkt, etwa 30 Grad im Uhrzeigersinn von der Senkrechten zur Linie selbst. |
| [Square](#Square) | Ein Quadrat, gefüllt mit der Innenfarbe der Anmerkung, falls vorhanden. |
