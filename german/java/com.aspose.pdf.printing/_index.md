Das com.aspose.pdf.printing‑Paket stellt Klassen bereit, die zur Konfiguration des Druckvorgangs verwendet werden.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CustomPrintEventArgs](./customprinteventargs/) | Stellt Daten für das Ereignis PdfViewer.getCustomPrintDelegate() bereit. |
| [DuplexKind](./duplexkind/) | Gibt die Duplex-Einstellung des Druckers an. |
| [PdfPrinterResolution](./pdfprinterresolution/) | Stellt die vom Drucker unterstützte Auflösung dar. |
| [PdfPrinterResolutionKind](./pdfprinterresolutionkind/) | Gibt eine Druckerauflösung an. |
| [PdfPrinterSettings](./pdfprintersettings/) | Gibt Informationen darüber an, wie ein Dokument gedruckt wird, einschließlich des Druckers, der es druckt. |
| [PdfPrintRange](./pdfprintrange/) | Gibt den zu druckenden Teil des Dokuments an. |
| [PrinterMargins](./printermargins/) | Gibt die Abmessungen der Ränder einer gedruckten Seite an. |
| [PrinterPaperKind](./printerpaperkind/) | Gibt die Standardpapiergrößen an. |
| [PrintPageSettings](./printpagesettings/) | Gibt Einstellungen an, die für eine einzelne gedruckte Seite gelten. |
| [PrintPaperSize](./printpapersize/) | Gibt die Größe eines Blatt Papiers an. |
| [PrintPaperSizes](./printpapersizes/) | Stellt die Standardpapiergrößen dar. |
| [PrintPaperSource](./printpapersource/) | Gibt das Papierfach an, aus dem der Drucker das Papier bezieht. |
| [PrintPaperSourceKind](./printpapersourcekind/) | Standard-Papierquellen. |
| [PrintPaperSources](./printpapersources/) | Stellt eine Menge vordefinierter {@link PrintPaperSource}-Instanzen bereit, die gängige Papierquellen darstellen. Diese Klasse kann nicht abgeleitet werden. |
