Stellt eine Menge vordefinierter {@link PrintPaperSource}-Instanzen bereit, die gängige Papierquellen darstellen. Diese Klasse kann nicht abgeleitet werden.

## Felder

| Feld | Beschreibung |
| --- | --- |
| [AutomaticFeed](#AutomaticFeed) | Stellt eine automatische Zuführungspapierquelle dar. |
| [Cassette](#Cassette) | Stellt die Papierschacht des Druckers dar. |
| [Envelope](#Envelope) | Stellt eine automatische Umschlagzuführungspapierquelle dar. |
| [FormSource](#FormSource) | Stellt das Standardfach des Druckers dar. |
| [LargeCapacity](#LargeCapacity) | Stellt das Fach mit großer Kapazität des Druckers dar. |
| [LargeFormat](#LargeFormat) | Stellt das Fach für Papier im größeren Format dar. |
| [Lower](#Lower) | Stellt das untere Fach des Druckers dar. |
| [Manual](#Manual) | Stellt eine manuelle Papiereinzugsquelle dar. |
| [ManualFeedEnvelope](#ManualFeedEnvelope) | Stellt eine manuelle Umschlagzuführungspapierquelle dar. |
| [Middle](#Middle) | Stellt das mittlere Fach des Druckers dar. |
| [SmallFormat](#SmallFormat) | Stellt das Fach für Papier im kleineren Format dar. |
| [TractorFeed](#TractorFeed) | Stellt eine Traktorzuführung für kontinuierliches Papier dar. |
| [Upper](#Upper) | Stellt das oberste Fach des Druckers dar, oder das Standardfach, wenn der Drucker nur ein Fach hat. |
