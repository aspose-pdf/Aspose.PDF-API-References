```
public interface ITociElement
```

Stellt ein Element dar, das in einem getaggten PDF‑Dokument als Inhaltsverzeichniseintrag (TOCI) fungieren kann. Dieses Interface abstrahiert sowohl Standard‑TOCI‑Elemente als auch List‑Item‑Elemente (LI), die in verschachtelten Inhaltsverzeichnisstrukturen verwendet werden.

## Methoden

| Methode | Beschreibung |
| --- | --- |
| [getGetElement](#getGetElement--) | Liefert das zugrunde liegende PDF-Element, das diese TOCI-Struktur darstellt. |

### getGetElement {#getGetElement--}
```
StructureElement getGetElement()
```

Liefert das zugrunde liegende PDF-Element, das diese TOCI-Struktur darstellt.

**Returns:**
Das Element, das die strukturelle Darstellung dieses Inhaltsverzeichniseintrags bildet.
