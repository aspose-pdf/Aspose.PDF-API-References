## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [ValidationMethod](./validationmethod/) | Stellt ein Enum dar, das die für die Zertifikatsvalidierung verwendete Methode definiert. |
| [ValidationMode](./validationmode/) | Gibt den Validierungsmodus für PDF‑Signaturvalidierungsprozesse an. |
| [ValidationOptions](./validationoptions/) | Stellt Optionen für die Validierung einer digitalen Signatur in einem PDF‑Dokument dar. |
| [ValidationResult](./validationresult/) | Stellt das Ergebnis eines Validierungsprozesses für ein Zertifikat dar. Die Klasse ValidationResult liefert Informationen über das Ergebnis der Zertifikatsvalidierung, einschließlich ihres Status und einer Nachricht, die etwaige während der Validierung aufgetretene Probleme beschreibt. |
| [ValidationStatus](./validationstatus/) | Stellt den Validierungsstatus einer Zertifikatsvalidierung dar. Diese Aufzählung definiert die möglichen Ergebnisse der Zertifikatsvalidierung: - Valid: Gibt an, dass das Zertifikat erfolgreich validiert wurde. - Invalid: Gibt an, dass die Zertifikatsvalidierung fehlgeschlagen ist. - Undefined: Gibt an, dass der Validierungsprozess nicht eindeutig war oder nicht durchgeführt wurde. |
