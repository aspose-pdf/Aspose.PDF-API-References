Stellt den Validierungsstatus einer Zertifikatsvalidierung dar. Diese Aufzählung definiert die möglichen Ergebnisse der Zertifikatsvalidierung: - Valid: Gibt an, dass das Zertifikat erfolgreich validiert wurde. - Invalid: Gibt an, dass die Zertifikatsvalidierung fehlgeschlagen ist. - Undefined: Gibt an, dass der Validierungsprozess nicht eindeutig war oder nicht durchgeführt wurde.
