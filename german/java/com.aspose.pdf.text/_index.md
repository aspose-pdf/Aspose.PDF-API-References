Das com.aspose.pdf.text-Paket stellt Klassen bereit, die das Extrahieren von Text, das Hinzufügen von Text und das Manipulieren von vorhandenem Text in einem Dokument ermöglichen.

## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [CustomFontSubstitutionBase](./customfontsubstitutionbase/) | Stellt eine Basisklasse für benutzerdefinierte Schriftart-Ersetzungsstrategie dar. |
| [CustomFontSubstitutionBase.OriginalFontSpecification](./customfontsubstitutionbase.originalfontspecification/) | <p> Stellt die ursprüngliche Schriftartenspezifikation dar. </p> <hr> <p> Stellt Informationen zur ursprünglichen Schriftart bereit, wie z. B. ein Flag. Außerdem wird ein Flag bereitgestellt, das hilft zu prüfen, ob die Ersetzung ohnehin mit der Schriftart stattfinden wird, und der Benutzer kann die Standard‑Ersetzungslogik überschreiben. </p> |
| [ExtractedTextPostProcessor](./extractedtextpostprocessor/) | Führt die Nachbearbeitung von extrahiertem Text durch. |
| [FontSourceCollection](./fontsourcecollection/) | Stellt eine Sammlung von Schriftquellen dar. |
| [FontSubstitution](./fontsubstitution/) | Nur für den internen Gebrauch: Stellt eine Basisklasse für Schriftart‑Ersetzungsstrategien dar. |
| [FontSubstitutionCollection](./fontsubstitutioncollection/) | Stellt eine Sammlung von Schriftart‑Ersetzungsstrategien dar. |
| [FontTypes](./fonttypes/) | Aufzählung unterstützter Schriftarttypen. |
| [InternalHelper](./internalhelper/) | Interne Klasse |
| [SimpleFontSubstitution](./simplefontsubstitution/) | Stellt eine Klasse für eine einfache Schriftart‑Ersetzungsstrategie dar. |
| [SubstitutionFontCategories](./substitutionfontcategories/) | Stellt Schriftartkategorien dar, die ersetzt werden können. |
| [SystemFontsSubstitution](./systemfontssubstitution/) | Stellt eine Klasse für eine Schriftart‑Ersetzungsstrategie dar, die Schriftarten durch Systemschriftarten ersetzt. |
| [TextProcessingContext](./textprocessingcontext/) | Stellt den Kontext der Textverarbeitung dar |
