Definiert den Positionierungsmodus. Mögliche Werte sind Legacy (Rückwärtskompatibilität) und Current (aktualisierte Berechnung der Textposition).

## Felder

| Feld | Beschreibung |
| --- | --- |
| [Current](#Current) | Aktualisierte Zeilenabstände und vertikale Positionsberechnung basieren auf der linken oberen Ecke statt der linken unteren. |
| [Legacy](#Legacy) | Veraltete Textpositionierung |
| [ModernLineSpacing](#ModernLineSpacing) | Aktualisierte Zeilenabstände, vertikale Positionsberechnung erfolgt nach den alten Regeln (d. h. Text wird relativ zur linken unteren Ecke des angegebenen Rechtecks positioniert). |
