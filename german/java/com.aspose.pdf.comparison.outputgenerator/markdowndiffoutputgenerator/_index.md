Stellt eine Klasse zur Erzeugung einer Markdown-Darstellung von Textunterschieden dar. Aufgrund der Markdown-Syntax ist es nicht möglich, Änderungen an Leerzeichen darzustellen. Die Auswahl von Änderungen erfordert das Hinzufügen von Leerzeichen um die Formatierung herum, sonst wird der Text im Markdown-Viewer nicht korrekt angezeigt. Gelöschte Zeilenumbrüche werden durch das Absatzzeichen - angezeigt.
