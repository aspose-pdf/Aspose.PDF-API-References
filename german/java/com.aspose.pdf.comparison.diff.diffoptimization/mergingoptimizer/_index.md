Stellt eine Klasse dar, die Bearbeitungsabschnitte neu anordnet und zusammenführt. Sie führt Gleichheiten zusammen und kombiniert benachbarte identische Änderungen. Sie sortiert und führt Änderungen zwischen Equals-Operationen zusammen, weil das Ändern ihrer Reihenfolge und das Zusammenführen das Ergebnis nicht ändert, aber eine besser lesbare Ausgabe erzeugt. Dies kombiniert benachbarte Equal-Operationen.
