| [IDiffOptimizationOperation](./idiffoptimizationoperation/) | Stellt die Schnittstelle der Optimierer für Differenzoperationen dar. |
## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [MergingOptimizer](./mergingoptimizer/) | Stellt eine Klasse dar, die Bearbeitungsabschnitte neu anordnet und zusammenführt. Sie führt Gleichheiten zusammen und kombiniert benachbarte identische Änderungen. Sie sortiert und führt Änderungen zwischen Equals-Operationen zusammen, weil das Ändern ihrer Reihenfolge und das Zusammenführen das Ergebnis nicht ändert, aber eine besser lesbare Ausgabe erzeugt. Dies kombiniert benachbarte Equal-Operationen. |
| [OperationsMerger](./operationsmerger/) | Stellt eine Klasse dar, die Gleichheiten zusammenführt und benachbarte identische Änderungen kombiniert. Sie sortiert und führt Änderungen zwischen Equals-Operationen zusammen, weil das Ändern ihrer Reihenfolge und das Zusammenführen das Ergebnis nicht ändert, aber eine besser lesbare Ausgabe erzeugt. Dies kombiniert benachbarte Equal-Operationen. |
| [OperationsSlideMerger](./operationsslidemerger/) | Stellt eine Klasse dar, die einzelne Änderungen identifiziert, die von Gleichheiten umgeben sind, und sie mit der linken oder rechten Gleichheitsoperation zusammenführt. |
