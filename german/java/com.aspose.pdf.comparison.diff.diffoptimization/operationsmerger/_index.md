Stellt eine Klasse dar, die Gleichheiten zusammenführt und benachbarte identische Änderungen kombiniert. Sie sortiert und führt Änderungen zwischen Equals-Operationen zusammen, weil das Ändern ihrer Reihenfolge und das Zusammenführen das Ergebnis nicht ändert, aber eine besser lesbare Ausgabe erzeugt. Dies kombiniert benachbarte Equal-Operationen.
