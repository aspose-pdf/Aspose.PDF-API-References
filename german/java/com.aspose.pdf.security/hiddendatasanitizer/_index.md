### HiddenDataSanitizer {#HiddenDataSanitizer-com.aspose.pdf.security.HiddenDataSanitizationOptions-}
Bietet Funktionalität zum Bereinigen versteckter Daten aus einem PDF-Dokument und stellt sicher, dass sensible oder unnötige Informationen wie Metadaten, Anmerkungen, JavaScripts oder private Inhalte entfernt oder umgewandelt werden.

### sanitize {#sanitize-com.aspose.pdf.Document-}
Bereinigt ein gegebenes PDF-Dokument, indem versteckte Daten entfernt oder umgewandelt werden.

### sanitizeAllToImages {#sanitizeAllToImages-com.aspose.pdf.Document-}
Ersetzt den Seiteninhalt durch Bilder und entfernt andere versteckte Daten. Ermöglicht das Entfernen von verstecktem Text mit einer Hintergrundfarbe sowie von Text, der unter Bildern verborgen ist. Entfernt außerdem vollständig alle interaktiven Elemente. Das Dokument wird unverändert in Bilder konvertiert und anschließend von verbleibenden versteckten Daten bereinigt. Wenn Sie zuerst bereinigen und dann konvertieren müssen, verwenden Sie die Methode der Hauptklasse.
