## Klassen

| Klasse | Beschreibung |
| --- | --- |
| [HiddenDataSanitizationOptions](./hiddendatasanitizationoptions/) | Stellt die Konfigurationsoptionen zum Bereinigen versteckter Daten in einem Dokument bereit. |
| [HiddenDataSanitizer](./hiddendatasanitizer/) | Stellt eine Klasse zum Bereinigen versteckter Daten bereit. |

| [UnsignedContentAbsorber.Result](./unsignedcontentabsorber.result/) | Kapselt das Ergebnis einer Operation, die versucht, unsignierten Inhalt aus einem PDF-Dokument zu extrahieren. Diese Klasse liefert Informationen über den Erfolg der Operation, Details des unsignierten Inhalts, eine Nachricht, die das Ergebnis beschreibt, sowie den Deckungsstatus der Signaturen des Dokuments. |
| [UnsignedContentAbsorber.UnsignedContent](./unsignedcontentabsorber.unsignedcontent/) | Kapselt unsignierte Inhaltselemente, die aus einem PDF-Dokument extrahiert wurden. Diese Klasse bietet Zugriff auf Seiten, Formularfelder, XForms und Anmerkungen, die Teil des unsignierten Inhalts im Dokument sind. |
