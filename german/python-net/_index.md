## Namensräume

| Namensraum | Beschreibung |
| :- | :- |
| [aspose.pdf](/pdf/python-net/aspose.pdf/) | Der aspose.pdf ist ein Root‑Namensraum für alle Klassen der Aspose.Pdf‑Bibliothek, die entweder direkt darin wie Document oder indirekt über mehrere Unternamensräume liegen. |
| [aspose.pdf.annotations](/pdf/python-net/aspose.pdf.annotations/) | Der aspose.pdf.annotations‑Namensraum stellt Klassen zur Arbeit mit verschiedenen Arten von Aktionen, Zielen und anderen Dokumentfunktionen bereit, die traditionell als interaktiv bezeichnet werden und dem Benutzer ermöglichen, mit dem Dokument zu interagieren. |
| [aspose.pdf.devices](/pdf/python-net/aspose.pdf.devices/) | Der aspose.pdf.devices‑Namensraum stellt Klassen bereit, die zur Darstellung des Dokuments als Bild(er) oder Klartext verwendet werden. So kann das Dokument an textuelle oder verschiedene grafische Geräte gesendet werden, um eine textuelle bzw. grafische Darstellung zu erhalten. |
| [aspose.pdf.drawing](/pdf/python-net/aspose.pdf.drawing/) | Der aspose.pdf.drawing‑Namensraum bietet Klassen, die grafische Primitive wie Bogen, Linie, Kreis usw. beschreiben. Entsprechende Objekte können zur Erstellung neuer Dokumente verwendet werden. |
| [aspose.pdf.facades](/pdf/python-net/aspose.pdf.facades/) | Der aspose.pdf.facades‑Namensraum stellt Klassen bereit, die ursprünglich aus Aspose.Pdf.Kit stammen. Diese Klassen werden zur Manipulation von Dokumenten verwendet und führen Vorgänge wie Zusammenführen, Stempeln, Signieren, Kommentieren usw. auf hoher Ebene aus, ohne Zugriff auf die innere Struktur eines Dokuments. |
| [aspose.pdf.forms](/pdf/python-net/aspose.pdf.forms/) | Der aspose.pdf.forms‑Namensraum enthält Klassen, die Formulare (standard, statisch, dynamisch) und verschiedene Feldtypen wie Textfeld, Listfeld, Optionsfeld usw. beschreiben. |
| [aspose.pdf.groupprocessor](/pdf/python-net/aspose.pdf.groupprocessor/) | Der aspose.pdf.groupprocessor‑Namensraum stellt Klassen bereit, die zur Verarbeitung von Text und Schriftarten verwendet werden. |
| [aspose.pdf.groupprocessor.creators](/pdf/python-net/aspose.pdf.groupprocessor.creators/) | Der aspose.pdf.groupprocessor.creators‑Namensraum bietet Klassen, die zur Erstellung von Instanzen der GroupProcessor‑Klassen verwendet werden. |
| [aspose.pdf.logicalstructure](/pdf/python-net/aspose.pdf.logicalstructure/) | Der aspose.pdf.logicalstructure ist ein Namensraum für Klassen der PDF‑Logischen Struktur. |
| [aspose.pdf.operators](/pdf/python-net/aspose.pdf.operators/) | Der aspose.pdf.operators ist ein Namensraum für Operator‑Implementierungen. Diese Klassen beschreiben Operatoren, die im Inhalt von PDF‑Seiten verwendet werden. |
| [aspose.pdf.optimization](/pdf/python-net/aspose.pdf.optimization/) | Der aspose.pdf.optimization ist ein Namensraum für Klassen zur Verwaltung des Dokumentoptimierungsprozesses. |
| [aspose.pdf.pdfaoptionclasses](/pdf/python-net/aspose.pdf.pdfaoptionclasses/) | Der aspose.pdf.pdfaoptionclasses ist ein Namensraum für Optionen zur PDF/A‑Konvertierung. |
| [aspose.pdf.sanitization](/pdf/python-net/aspose.pdf.sanitization/) | Der aspose.pdf.sanitization ist ein Namensraum für Bereinigungs‑Operationen. |
| [aspose.pdf.structure](/pdf/python-net/aspose.pdf.structure/) | Der aspose.pdf.structure‑Namensraum stellt Klassen bereit, die bei der Arbeit mit der logischen Struktur eines Dokuments helfen, welche die Gliederung des Dokuments in Kapitel und Abschnitte sowie die Identifizierung spezieller Elemente wie Abbildungen, Tabellen und Fußnoten darstellt. |
| [aspose.pdf.tagged](/pdf/python-net/aspose.pdf.tagged/) | Der aspose.pdf.tagged ist ein Namensraum für Klassen zur Unterstützung von Tagged‑PDF‑Dokumenten. |
| [aspose.pdf.text](/pdf/python-net/aspose.pdf.text/) | Der aspose.pdf.text‑Namensraum bietet Klassen, die das Extrahieren von Text, das Hinzufügen von Text und die Manipulation bestehenden Textes eines Dokuments ermöglichen. Er enthält außerdem Klassen, die das Extrahieren, Ersetzen und Austauschen von Schriftarten eines Dokuments erlauben. |
| [aspose.pdf.xfaconverter](/pdf/python-net/aspose.pdf.xfaconverter/) | Der aspose.pdf.xfaconverter‑Namensraum stellt Klassen bereit, die die Konvertierung von XFA ermöglichen. |
