## PositioningMode enumeration

Definiert den Positionierungsmodus.<br/>            Mögliche Werte sind Legacy (Rückwärtskompatibilität) und <br/>            Current (aktualisierte Methode zur Berechnung der Textposition).

## Members
| Member-Name | Beschreibung |
| :- | :- |
| LEGACY | Legacy-Textpositionierung |
| MODERN_LINE_SPACING | Aktualisierter Zeilenabstand, die vertikale Positionsberechnung erfolgt nach den alten Regeln <br/>            (d. h. der Text wird relativ zur unteren linken Ecke des angegebenen Rechtecks positioniert) |
| CURRENT | Aktualisierter Zeilenabstand und die vertikale Positionsberechnung erfolgt basierend auf der linken oberen Ecke statt der linken unteren. |
