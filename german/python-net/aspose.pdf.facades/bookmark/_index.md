## Bookmark class

Stellt ein Lesezeichen dar.

Der Typ Bookmark stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Bookmark() | Initialisiert eine neue Instanz der Klasse Bookmark |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| action | Liest oder setzt die mit dem Lesezeichen verknüpfte Aktion.<br/>            Wenn PageNumber angegeben ist, kann die Aktion nicht festgelegt werden.<br/>            Der Aktionstyp umfasst: "GoTo", "GoToR", "Launch", "Named". |
| bold_flag | Liest oder setzt das Fettdruck-Flag des Titels des Lesezeichens. |
| child_item | Liest oder setzt die Kinder des Lesezeichens. |
| child_items | Liest oder setzt die Kinder des Lesezeichens. |
| destination | Liest oder setzt die Zielseite des Lesezeichens. Erforderlich, wenn die Aktion als string.Empty festgelegt ist. |
| italic_flag | Liest oder setzt das Kursiv-Flag des Titels des Lesezeichens. |
| level | Liest oder setzt die Hierarchieebene des Lesezeichens. |
| page_display | Liest oder setzt den Anzeigetyp der Zielseite des Lesezeichens. |
| page_display_bottom | Liest oder setzt die untere Koordinate der Seitenanzeige. |
| page_display_left | Liest oder setzt die linke Koordinate der Seitenanzeige. |
| page_display_right | Liest oder setzt die rechte Koordinate der Seitenanzeige. |
| page_display_top | Liest oder setzt die obere Koordinate der Seitenanzeige. |
| page_display_zoom | Liest oder setzt den Zoomfaktor der Seitenanzeige. |
| page_number | Liest oder setzt die Nummer der Zielseite des Lesezeichens. |
| remote_file | Liest oder setzt die Datei (Pfad), die für die \"GoToR\"-Aktion des Lesezeichens erforderlich ist. |
| title | Liest oder setzt den Titel des Lesezeichens. |
| title_color | Liest oder setzt die Farbe des Lesezeichentitels. |
| öffnen | Liest oder setzt den Zustand des Lesezeichens (offen, geschlossen). |
