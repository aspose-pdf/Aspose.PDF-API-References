## ViewerPreference class

Beschreibt Viewer-Einstellungen (Seitenmodus, Nicht-Vollbild-Seitenmodus, Seitenlayout).

Der Typ ViewerPreference stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ViewerPreference() | Initialisiert eine neue Instanz der Klasse ViewerPreference |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| PAGE_MODE_USE_OC | Optionales Inhaltsgruppen-Panel sichtbar. |
| DISPLAY_DOC_TITLE | Ein Flag, das angibt, ob die Titelleiste des Fensters den Dokumenttitel anzeigen soll |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | Optionales Inhaltsgruppen-Panel sichtbar. |
| PAGE_LAYOUT_SINGLE_PAGE | Zeigt jeweils eine Seite an. |
| PAGE_LAYOUT_ONE_COLUMN | Zeigt die Seiten in einer Spalte an. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | Anzeige der Seiten in zwei Spalten, wobei ungerade Seiten rechts angezeigt werden |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | Anzeige der Seiten in zwei Spalten, wobei ungerade Seiten rechts angezeigt werden. |
| PAGE_MODE_USE_NONE | Weder Dokumentenübersicht noch Miniaturbilder sichtbar |
| PAGE_MODE_USE_OUTLINES | Dokumentenübersicht sichtbar. |
| PAGE_MODE_USE_THUMBS | Miniaturbilder sichtbar. |
| PAGE_MODE_FULL_SCREEN | Vollbildmodus, ohne Menüleiste, Fenstersteuerungen oder sonstige Fenster sichtbar. |
| PAGE_MODE_USE_ATTACHMENT | Seitenmodus mit Anhängen. |
| HIDE_TOOLBAR | Ein Flag, das angibt, ob die Werkzeugleisten des konformen Readers ausgeblendet werden sollen, wenn das Dokument aktiv ist. |
| HIDE_MENUBAR | Ein Flag, das angibt, ob die Menüleiste des konformen Readers ausgeblendet werden soll, wenn das Dokument aktiv ist. |
| HIDE_WINDOW_UI | Ein Flag, das angibt, ob Benutzeroberflächenelemente im Dokumentenfenster (wie Bildlaufleisten und Navigationssteuerelemente) ausgeblendet werden sollen, sodass nur der Dokumentinhalt angezeigt wird. |
| FIT_WINDOW | Ein Flag, das angibt, ob das Dokumentenfenster an die Größe der zuerst angezeigten Seite angepasst werden soll. |
| CENTER_WINDOW | Ein Flag, das angibt, ob das Dokumentenfenster in der Bildschirmmitte positioniert werden soll. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | Weder Dokumentenübersicht noch Miniaturbilder sichtbar. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | Dokumentenübersicht sichtbar. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | Miniaturbilder sichtbar |
| DIRECTION_L2R | Lesereihenfolge des Textes von links nach rechts. |
| DIRECTION_R2L | Lesereihenfolge des Textes von rechts nach links. |
| SIMPLEX | Einseitig drucken. |
| DUPLEX_FLIP_SHORT_EDGE | Duplex und um die kurze Kante des Blattes wenden. |
| DUPLEX_FLIP_LONG_EDGE | Duplex und um die kurze Kante des Blattes wenden. |
