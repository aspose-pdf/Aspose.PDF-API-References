## KeySize enumeration

Definiert verschiedene Schlüssellängen, die zum Verschlüsseln von PDF-Dokumenten verwendet werden können.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| X40 | 40‑Bit‑Schlüssel. Eine solche Schlüssellänge wird mit dem RC4‑Algorithmus verwendet und bietet ein geringes Sicherheitsniveau. <br/>            Dennoch können alte Versionen von PDF‑Dokumenten nur mit solchen Schlüsseln verschlüsselt werden (v. 1.3 und niedriger); |
| X128 | 128‑Bit‑Schlüssel. Sowohl RC4‑ als auch AES‑Algorithmen können diese Schlüssellänge verwenden. |
| X256 | 256‑Bit‑Schlüssel. Eine solche Schlüssellänge kann nur mit AES verwendet werden und wird von den neuesten Adobe‑Reader‑Versionen erkannt (ab Version 9). |
