## LineInfo class

Der Typ LineInfo stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |

## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| vertice_coordinate | Liefert oder setzt ein Array von Zahlen, das die abwechselnd horizontalen und vertikalen Koordinaten jedes Scheitelpunkts darstellt. |
