## TextProperties class

Stellt Texteigenschaften wie Textgröße, Farbe, Stil usw. dar.

Der Typ TextProperties stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextProperties(text_size) | Initialisiert eine neue Instanz der Klasse TextProperties |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| farbe | Liest oder setzt die Textfarbe. |
| is_color_specified | Liest oder setzt einen Wert, der angibt, ob die [color](/pdf/python-net/aspose.pdf.facades/textproperties/) Eigenschaft angegeben ist. |
| text_size | Liest oder setzt die Textgröße. |
| is_text_size_specified | Liest oder setzt einen Wert, der angibt, ob die [text_size](/pdf/python-net/aspose.pdf.facades/textproperties/) Eigenschaft angegeben ist. |
