## ReplaceTextStrategy class

Diese Klasse enthält Parameter, die das Verhalten von PdfContentEditor definieren, wenn die ReplaceText-Operation ausgeführt wird.

Der Typ ReplaceTextStrategy stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ReplaceTextStrategy() | Initialisiert eine neue Instanz der Klasse ReplaceTextStrategy |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_regular_expression_used | Falls false, ist die zu findende Zeichenkette ein einfacher Text. Falls true, ist die zu findende Zeichenkette ein regulärer Ausdruck. |
| no_character_behavior | Aktion, die ausgeführt wird, wenn für den geänderten Text keine geeignete Schriftart gefunden wird<br/>            (Ausnahme werfen / Andere Schriftart substituieren / Trotzdem ersetzen). |
| replace_scope | Umfang der Ersetzungsoperation (erstes Vorkommen ersetzen oder alle Vorkommen ersetzen). |
