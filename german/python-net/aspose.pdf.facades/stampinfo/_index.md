## StampInfo class

Klasse, die Stempelinformationen darstellt.

Der Typ StampInfo stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| stamp_id | Liefert die Kennung des Stempels. |
| index_on_page | Liefert den Stempelindex auf der Seite. |
| stamp_type | Liefert den Stempeltyp (Bild / Formular). |
| Rechteck | Liefert das Rechteck, in dem der Stempel platziert ist. |
| image | Liefert das Bild des Stempels. Kann null sein, wenn der Stempel keine Bilder enthält (z. B. bei einem Textstempel). |
| Formular | Liefert das XForm des Stempels. |
| text | Liefert den Text im Stempel. |
| sichtbar | Liefert die Sichtbarkeit des Stempels. Wenn false, ist der Stempel ausgeblendet (mit HideStampById). Ein ausgeblendeter Stempel kann mit ShowStampById wiederhergestellt werden. |
