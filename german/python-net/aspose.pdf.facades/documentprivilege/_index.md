## DocumentPrivilege class

Stellt die Berechtigungen für den Zugriff auf PDF‑Dateien dar. Siehe [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             Es gibt 4 Möglichkeiten, diese Klasse zu verwenden:<br/>             1. Eine vordefinierte Berechtigung direkt verwenden.<br/>             2. Auf einer vordefinierten Berechtigung basieren und einige spezifische Berechtigungen ändern.<br/>             3. Auf einer vordefinierten Berechtigung basieren und eine spezifische Kombination von Adobe‑Professional‑Berechtigungen ändern.<br/>             4. Kombination von Möglichkeit 2 und 3.

Der DocumentPrivilege‑Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| allow_print | Legt die Berechtigung fest, die das Drucken erlaubt oder nicht. <br/>            true bedeutet erlaubt und false bedeutet verboten. |
| allow_degraded_printing | Legt die Berechtigung fest, die das degradierte Drucken erlaubt oder nicht. <br/>            true bedeutet erlaubt und false bedeutet verboten. |
| allow_modify_contents | Legt die Berechtigung fest, die das Ändern von Inhalten erlaubt oder nicht. <br/>            true bedeutet erlaubt und false bedeutet verboten. |
| allow_copy | Legt die Berechtigung fest, die das Kopieren erlaubt oder nicht. <br/>            true bedeutet erlaubt und false bedeutet verboten. |
| allow_modify_annotations | Legt die Berechtigung fest, die das Ändern von Anmerkungen erlaubt oder nicht. <br/>            true bedeutet erlaubt und false bedeutet verboten. |
| allow_fill_in | Legt die Berechtigung fest, die das Ausfüllen von Formularen erlaubt oder nicht. <br/>            true bedeutet erlaubt und false bedeutet verboten. |
| allow_screen_readers | Legt die Berechtigung fest, die Bildschirmleser erlaubt oder nicht. <br/>            true bedeutet erlaubt und false bedeutet verboten. |
| allow_assembly | Legt die Berechtigung fest, die das Zusammenführen erlaubt oder nicht. <br/>            true bedeutet erlaubt und false bedeutet verboten. |
| degraded_printing | Erlaubt das Drucken in niedriger Qualität. |
| print | Erlaubt das Drucken der Datei. |
| modify_contents | Erlaubt das Ändern der Datei. |
| copy | Erlaubt das Kopieren der Datei. |
| modify_annotations | Erlaubt das Ändern von Anmerkungen der Datei. |
| fill_in | Erlaubt das Ausfüllen von Formularen in der Datei. |
| screen_readers | Erlaubt das Lesen nur auf dem Bildschirm. |
| assembly | Ermöglicht das Assemblieren von Dateien. |
| allow_all | Alle erlaubt. |
| forbid_all | Alle verboten. |
