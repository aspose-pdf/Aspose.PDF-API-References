## EmfDevice class

Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im EMF-Format zu speichern.

Der Typ EmfDevice stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| EmfDevice() | Initialisiert eine neue Instanz der [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) Klasse mit der Standardauflösung des Rasterbildes, das in EMF geschrieben wird. |
| EmfDevice(resolution) | Initialisiert eine neue Instanz der EmfDevice-Klasse |
| EmfDevice(width, height) | Initialisiert eine neue Instanz der EmfDevice-Klasse |
| EmfDevice(page_size) | Initialisiert eine neue Instanz der EmfDevice-Klasse |
| EmfDevice(width, height, resolution) | Initialisiert eine neue Instanz der EmfDevice-Klasse |
| EmfDevice(page_size, resolution) | Initialisiert eine neue Instanz der EmfDevice-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| coordinate_type | Liest oder setzt den Seitenkoordinatentyp (Media-/Crop-Boxen). Der CropBox-Wert wird standardmäßig verwendet. |
| rendering_options | Liest oder setzt die Rendering-Optionen. |
| form_presentation_mode | Liest oder setzt den Präsentationsmodus des Formulars. |
| resolution | Ermittelt Bildauflösung. |
| breite | Ermittelt Bildausgabe-Breite. |
| höhe | Ermittelt Bildausgabe-Höhe. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| process(page, output) | Konvertiert die Seite in emf und speichert sie im Ausgabestream. |
| process(page, output_file_name) | Konvertiert die Seite in emf und speichert sie im Ausgabestream. |
