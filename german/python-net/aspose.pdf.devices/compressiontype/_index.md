## CompressionType enumeration

Wird verwendet, um den Parameterwert an ein TIFF-Bildgerät zu übergeben.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| LZW | Gibt das LZW-Komprimierungsschema an. Kann dem Tiff‑Encoder als Parameter übergeben werden, der zur Kategorie Compression gehört. |
| CCITT4 | Gibt das CCITT4-Komprimierungsschema an. Kann dem CCITT4‑Encoder als Parameter übergeben werden, der zur Kategorie Compression gehört. |
| CCITT3 | Gibt das CCITT3-Komprimierungsschema an. Kann dem CCITT3‑Encoder als Parameter übergeben werden, der zur Kategorie Compression gehört. |
| RLE | Gibt das RLE-Komprimierungsschema an. Kann dem RLE‑Encoder als Parameter übergeben werden, der zur Kategorie Compression gehört. |
| NONE | Gibt keine Kompression an. Kann dem Tiff‑Encoder als Parameter übergeben werden, der zur Kompressionskategorie gehört. |
