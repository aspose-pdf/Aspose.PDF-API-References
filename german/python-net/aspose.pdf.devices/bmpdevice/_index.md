## BmpDevice class

Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im BMP-Format zu speichern.

Der BmpDevice-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| BmpDevice() | Initialisiert eine neue Instanz der [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) Klasse mit Standardauflösung. |
| BmpDevice(resolution) | Initialisiert eine neue Instanz der BmpDevice-Klasse |
| BmpDevice(width, height, resolution) | Initialisiert eine neue Instanz der BmpDevice-Klasse |
| BmpDevice(page_size, resolution) | Initialisiert eine neue Instanz der BmpDevice-Klasse |
| BmpDevice(width, height) | Initialisiert eine neue Instanz der BmpDevice-Klasse |
| BmpDevice(page_size) | Initialisiert eine neue Instanz der BmpDevice-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| coordinate_type | Liest oder setzt den Seitenkoordinatentyp (Media-/Crop-Boxen). Der CropBox-Wert wird standardmäßig verwendet. |
| rendering_options | Liest oder setzt die Rendering-Optionen. |
| form_presentation_mode | Liest oder setzt den Präsentationsmodus des Formulars. |
| resolution | Ermittelt Bildauflösung. |
| breite | Ermittelt Bildausgabe-Breite. |
| höhe | Ermittelt Bildausgabe-Höhe. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| process(page, output) | Konvertiert die Seite in bmp und speichert sie im Ausgabestream. |
| process(page, output_file_name) | Konvertiert die Seite in bmp und speichert sie im Ausgabestream. |
