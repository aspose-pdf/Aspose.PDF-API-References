## ImageDevice class

Eine abstrakte Klasse für Bildgeräte.

Der Typ ImageDevice stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| coordinate_type | Liest oder setzt den Seitenkoordinatentyp (Media-/Crop-Boxen). Der CropBox-Wert wird standardmäßig verwendet. |
| rendering_options | Liest oder setzt die Rendering-Optionen. |
| form_presentation_mode | Liest oder setzt den Präsentationsmodus des Formulars. |
| resolution | Ermittelt Bildauflösung. |
| breite | Ermittelt Bildausgabe-Breite. |
| höhe | Ermittelt Bildausgabe-Höhe. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| process(page, output) | Führt eine Operation auf der angegebenen Seite aus, z. B. konvertiert die Seite in ein Grafikbild. |
| process(page, output_file_name) | Führt eine Operation auf der angegebenen Seite aus und speichert die Ergebnisse in die Datei. |
