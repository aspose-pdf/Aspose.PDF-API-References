## JpegDevice class

Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im JPEG-Format zu speichern.

Der Typ JpegDevice stellt die folgenden Mitglieder bereit:

| JpegDevice(resolution) | Initialisiert eine neue Instanz der Klasse JpegDevice |
| JpegDevice(quality) | Initialisiert eine neue Instanz der Klasse JpegDevice |
| JpegDevice(resolution, quality) | Initialisiert eine neue Instanz der Klasse JpegDevice |
