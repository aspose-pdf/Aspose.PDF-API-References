## DicomDevice class

Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im DICOM-Format zu speichern.

Der DicomDevice-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| DicomDevice() | Initialisiert eine neue Instanz der [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) Klasse mit Standardauflösung. |
| DicomDevice(resolution) | Initialisiert eine neue Instanz der DicomDevice-Klasse |
| DicomDevice(page_size) | Initialisiert eine neue Instanz der DicomDevice-Klasse |
| DicomDevice(width, height) | Initialisiert eine neue Instanz der DicomDevice-Klasse |
| DicomDevice(page_size, resolution) | Initialisiert eine neue Instanz der DicomDevice-Klasse |
| DicomDevice(width, height, resolution) | Initialisiert eine neue Instanz der DicomDevice-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| coordinate_type | Liest oder setzt den Seitenkoordinatentyp (Media-/Crop-Boxen). Der CropBox-Wert wird standardmäßig verwendet. |
| rendering_options | Liest oder setzt die Rendering-Optionen. |
| form_presentation_mode | Liest oder setzt den Präsentationsmodus des Formulars. |
| resolution | Ermittelt Bildauflösung. |
| breite | Ermittelt Bildausgabe-Breite. |
| höhe | Ermittelt Bildausgabe-Höhe. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| process(page, output) | Konvertiert die Seite in Dicom und speichert sie im Ausgabestream. |
| process(page, output_file_name) | Konvertiert die Seite in Dicom und speichert sie im Ausgabestream. |
