## PngDevice class

Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im PNG-Format zu speichern.

Der Typ PngDevice stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PngDevice() | Initialisiert eine neue Instanz der Klasse [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) mit Standardauflösung. |
| PngDevice(resolution) | Initialisiert eine neue Instanz der Klasse PngDevice |
| PngDevice(width, height, resolution) | Initialisiert eine neue Instanz der Klasse PngDevice |
| PngDevice(page_size, resolution) | Initialisiert eine neue Instanz der Klasse PngDevice |
| PngDevice(width, height) | Initialisiert eine neue Instanz der Klasse PngDevice |
| PngDevice(page_size) | Initialisiert eine neue Instanz der Klasse PngDevice |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| coordinate_type | Liest oder setzt den Seitenkoordinatentyp (Media-/Crop-Boxen). Der CropBox-Wert wird standardmäßig verwendet. |
| rendering_options | Liest oder setzt die Rendering-Optionen. |
| form_presentation_mode | Liest oder setzt den Präsentationsmodus des Formulars. |
| resolution | Ermittelt Bildauflösung. |
| breite | Ermittelt Bildausgabe-Breite. |
| höhe | Ermittelt Bildausgabe-Höhe. |
| transparent_background | Liest oder setzt, ob das Bild einen transparenten Hintergrund hat. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| process(page, output) | Konvertiert die Seite in ein PNG und speichert es im Ausgabestream. |
| process(page, output_file_name) | Konvertiert die Seite in ein PNG und speichert es im Ausgabestream. |
