## ThumbnailDevice class

Stellt ein Bildgerät dar, das PDF-Dokumentseiten als Miniaturbild speichert.

Der ThumbnailDevice-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ThumbnailDevice() | Initialisiert eine neue Instanz der [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) Klasse<br/>            mit Standardgröße des Vorschaubildes (200x200 Pixel). |
| ThumbnailDevice(width, height) | Initialisiert eine neue Instanz der ThumbnailDevice-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| coordinate_type | Liest oder setzt den Seitenkoordinatentyp (Media-/Crop-Boxen). Der CropBox-Wert wird standardmäßig verwendet. |
| rendering_options | Liest oder setzt die Rendering-Optionen. |
| form_presentation_mode | Liest oder setzt den Präsentationsmodus des Formulars. |
| resolution | Ermittelt Bildauflösung. |
| breite | Ermittelt Bildausgabe-Breite. |
| höhe | Ermittelt Bildausgabe-Höhe. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| process(page, output) | Konvertiert die Seite in ein PNG-Miniaturbild und speichert es im Ausgabestream. |
| process(page, output_file_name) | Konvertiert die Seite in ein PNG-Miniaturbild und speichert es im Ausgabestream. |
