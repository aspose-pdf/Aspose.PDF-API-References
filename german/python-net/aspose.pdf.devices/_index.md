Der aspose.pdf.devices‑Namensraum stellt Klassen bereit, die zur Darstellung des Dokuments als Bild(er) oder Klartext verwendet werden. So kann das Dokument an textuelle oder verschiedene grafische Geräte gesendet werden, um eine textuelle bzw. grafische Darstellung zu erhalten.

## Klassen
| Klasse | Beschreibung |
| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im BMP-Format zu speichern. |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | Abstrakte Klasse für alle Gerätetypen. Das Gerät wird verwendet, um ein PDF-Dokument in einem bestimmten Format darzustellen.<br/>            Zum Beispiel kann eine Dokumentseite als Bild oder Text dargestellt werden. |
| [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) | Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im DICOM-Format zu speichern. |
| [DocumentDevice](/pdf/python-net/aspose.pdf.devices/documentdevice/) | Abstrakte Klasse für alle Geräte, die verwendet werden, um das gesamte PDF-Dokument zu verarbeiten. |
| [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) | Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im EMF-Format zu speichern. |
| [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) | Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im GIF-Format zu speichern. |
| [ImageDevice](/pdf/python-net/aspose.pdf.devices/imagedevice/) | Eine abstrakte Klasse für Bildgeräte. |
| [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) | Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im JPEG-Format zu speichern. |
| [Margins](/pdf/python-net/aspose.pdf.devices/margins/) | Diese Klasse stellt die Ränder eines Bildes dar. |
| [PageDevice](/pdf/python-net/aspose.pdf.devices/pagedevice/) | Abstrakte Klasse für alle Geräte, die verwendet werden, um eine bestimmte Seite des PDF-Dokuments zu verarbeiten. |
| [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) | Stellt ein Bildgerät dar, das dabei hilft, PDF-Dokumentseiten im PNG-Format zu speichern. |
| [Resolution](/pdf/python-net/aspose.pdf.devices/resolution/) | Stellt eine Klasse dar, die die Bildauflösung hält. |
| [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) | Stellt eine Klasse dar, die PDF-Dokumentseiten in Text konvertiert. |
| [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) | Stellt ein Bildgerät dar, das PDF-Dokumentseiten als Miniaturbild speichert. |
| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | Diese Klasse hilft, PDF-Dokumentseiten einzeln in ein einziges TIFF-Bild zu speichern. |
| [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) | Diese Klasse stellt Einstellungen für den Import von PDF nach TIFF dar. |
