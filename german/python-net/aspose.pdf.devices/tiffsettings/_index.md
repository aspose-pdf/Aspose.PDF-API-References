## TiffSettings class

Diese Klasse stellt Einstellungen für den Import von PDF nach TIFF dar.

Der TiffSettings-Typ stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TiffSettings() | Initialisiert eine neue Instanz der [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) Klasse. |
| TiffSettings(shape_type) | Initialisiert eine neue Instanz der TiffSettings-Klasse |
| TiffSettings(compression_type) | Initialisiert eine neue Instanz der TiffSettings-Klasse |
| TiffSettings(color_depth) | Initialisiert eine neue Instanz der TiffSettings-Klasse |
| TiffSettings(margins) | Initialisiert eine neue Instanz der TiffSettings-Klasse |

| TiffSettings(skip_blank_pages) | Initialisiert eine neue Instanz der TiffSettings-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Ränder | Gibt die Ränder zurück. |
| skip_blank_pages | Gibt einen Wert zurück oder legt ihn fest, der angibt, ob leere Seiten übersprungen werden sollen. |
| Kompression | Gibt den Typ der Kompression zurück oder legt ihn fest. |
| Tiefe | Gibt die Farbtiefe zurück oder legt sie fest. |
| Form | Gibt den Typ der Form zurück oder legt ihn fest. |
| Helligkeit | Gibt einen Grenzwert für die Umwandlung von Farben in Weiß und Schwarz zurück oder legt ihn fest.<br/>            This parameter can be applied with EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle or ColorDepth.Format1bpp == 1 |
| coordinate_type | Gibt den Seitencoordinate‑Typ (Media‑/Crop‑Boxen) zurück oder legt ihn fest. Der CropBox‑Wert wird standardmäßig verwendet. |
