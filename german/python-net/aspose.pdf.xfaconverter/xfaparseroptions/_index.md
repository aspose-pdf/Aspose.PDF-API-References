## XfaParserOptions class

Klasse zur Handhabung der zugehörigen Datenkapselung.

Der Typ XfaParserOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| XfaParserOptions(page_size) | Initialisiert eine neue Instanz der Klasse XfaParserOptions |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| page_size | Liest oder setzt die Größe der Seite. |
| signiert | Wenn diese Eigenschaft true ist, wird das Dokument unter Verwendung des XFA-Formular-Streams konvertiert (falls vorhanden).<br/>            Wenn sie false ist, wird der XFA-Formular-Stream ignoriert.<br/>            Diese Eigenschaft wurde eingeführt, weil nicht klar ist, wie die Prüfsumme zu berechnen ist, die zur Signaturprüfung verwendet wird. |
| emulate_requierd_groups | Wenn diese Eigenschaft true ist, werden zusätzliche rote Rechtecke für erforderliche XFA‑„ausgeschlossene Gruppen“ gezeichnet.<br/>            Diese Eigenschaft wurde eingeführt, weil bei der Konvertierung der XFA-Darstellung von Formularen in den Standard Analoga zu ausgeschlossenen Gruppen fehlen.<br/>            Sie ist standardmäßig false. |
| base_path | Liest oder setzt den Basis‑Pfad. |
