## TabStop class

Der Typ TabStop stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TabStop() | Initialisiert eine neue Instanz der [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) Klasse. |
| TabStop(position) | Initialisiert eine neue Instanz der TabStop‑Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| position | Ruft einen Float‑Wert ab oder legt ihn fest, der die Tab‑Stopp‑Position angibt. |
| leader_type | Ruft einen [TabLeaderType](/pdf/python-net/aspose.pdf.text/tableadertype/)‑Enum ab oder legt ihn fest, der den Tab‑Leader‑Typ angibt. |
