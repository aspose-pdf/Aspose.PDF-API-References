## TextFragmentState class

Stellt den Textzustand eines Textfragments dar.

Der TextFragmentState-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextFragmentState(fragment) | Initialisiert eine neue Instanz der TextFragmentState-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| character_spacing | Liest oder setzt den Zeichenabstand des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt. |
| line_spacing | Liest oder setzt den Zeilenabstand des Textes. |
| horizontal_scaling | Liest oder setzt die horizontale Skalierung des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt. |
| subscript | Liest oder setzt den Tiefstellung des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt. |
| superscript | Liest oder setzt die Hochstellung des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt. |
| word_spacing | Liest oder setzt den Wortabstand des Textes. |
| unsichtbar | Liest oder setzt die Unsichtbarkeit des Textes. |
| rendering_mode | Liest oder setzt den Rendering-Modus des Textes. |
| font_size | Liest oder setzt die Schriftgröße des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt |
| font | Liest oder setzt die Schriftart des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt |
| foreground_color | Liest oder setzt die Vordergrundfarbe des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt |
| stroking_color | Liest oder setzt Farbstreichoperationen des [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Renderings (Textstrich, Rechteckrand) |
| underline | Liest oder setzt die Unterstreichung für den Text, dargestellt durch das Objekt [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| strike_out | Setzt die Durchstreichung für den Text, dargestellt durch das Objekt [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| background_color | Setzt die Hintergrundfarbe des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt |
| font_style | Setzt den Schriftstil des Textes, dargestellt durch das [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekt |
| horizontal_alignment | Liest oder setzt die horizontale Ausrichtung für den Text. |
| TAB_TAG | Sie können dieses Tag im Text platzieren, um eine Tabulation zu deklarieren. |
| TABSTOP_DEFAULT_VALUE | Standardwert der Tabulation in den Breiten des Leerzeichens der Standardschriftart. |
| tab_stops | Liest Tabstopps für den Text. |
| formatting_options | Liest oder setzt Formatierungsoptionen.<br/>            Das Festlegen der Optionen ist nur in Generatorszenarien wirksam. |
| rotation | Liest oder legt den Rotationswinkel in Grad fest. |
| draw_text_rectangle_border | Liest oder setzt, ob das Flag für das Zeichnen des Textrechteckrahmens gesetzt ist. |
## Methoden

| :- | :- |
| apply_changes_from(text_state) | Wendet Einstellungen von einem anderen textState an. |
| measure_string(str) | Misst die Zeichenkette. |
