## SimpleFontSubstitution class

Stellt eine Klasse für eine einfache Schriftart‑Ersetzungsstrategie dar.

Der SimpleFontSubstitution-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| SimpleFontSubstitution(original_font_name, substitution_font_name, is_forced_by_save_option) | Initialisiert eine neue Instanz der SimpleFontSubstitution-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| original_font_name | Gibt den ursprünglichen Schriftartnamen zurück, der durch [substitution_font_name](/pdf/python-net/aspose.pdf.text/simplefontsubstitution/) ersetzt werden soll |
| substitution_font_name | Gibt den Schriftartnamen zurück, der den [original_font_name](/pdf/python-net/aspose.pdf.text/simplefontsubstitution/) ersetzen soll |
