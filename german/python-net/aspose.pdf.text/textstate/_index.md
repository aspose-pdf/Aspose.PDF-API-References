## TextState class

Stellt einen Textzustand dar

Der TextState-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextState() | Erstellt ein TextState-Objekt. |
| TextState(font_size) | Initialisiert eine neue Instanz der TextState-Klasse |
| TextState(foreground_color) | Initialisiert eine neue Instanz der TextState-Klasse |
| TextState(foreground_color, font_size) | Initialisiert eine neue Instanz der TextState-Klasse |
| TextState(font_family) | Initialisiert eine neue Instanz der TextState-Klasse |
| TextState(font_family, bold, italic) | Initialisiert eine neue Instanz der TextState-Klasse |
| TextState(font_family, font_size) | Initialisiert eine neue Instanz der TextState-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| character_spacing | Liest oder setzt den Zeichenabstand des Textes. |
| line_spacing | Liest oder setzt den Zeilenabstand des Textes. |
| horizontal_scaling | Liest oder setzt die horizontale Skalierung des Textes. |
| subscript | Liest oder setzt die Tiefstellung des Textes. |
| superscript | Liest oder setzt die Hochstellung des Textes. |
| word_spacing | Liest oder setzt den Wortabstand des Textes. |
| invisible | Liest oder setzt die Unsichtbarkeit des Textes. Dies spiegelt im Wesentlichen den Zustand von [rendering_mode](/pdf/python-net/aspose.pdf.text/textstate/) wider, außer in einigen Sonderfällen (wie Beschneidung). |
| rendering_mode | Liest oder setzt den Rendering-Modus des Textes. |
| font_size | Liest oder setzt die Schriftgröße des Textes. |
| font | Liest oder setzt die Schriftart des Textes. |
| foreground_color | Liest oder setzt die Vordergrundfarbe des Textes. |
| stroking_color | Liest oder setzt die Vordergrundfarbe des Textes. |
| underline | Liest oder setzt die Unterstreichung für den Text, dargestellt durch das Objekt [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| strike_out | Setzt die Durchstreichung für den Text, dargestellt durch das Objekt [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| background_color | Setzt die Hintergrundfarbe des Textes. |
| font_style | Setzt den Schriftstil des Textes. |
| horizontal_alignment | Liest oder setzt die horizontale Ausrichtung für den Text. |
| TAB_TAG | Sie können dieses Tag im Text platzieren, um eine Tabulation zu deklarieren. |
| TABSTOP_DEFAULT_VALUE | Standardwert der Tabulation in den Breiten des Leerzeichens der Standardschriftart. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| apply_changes_from(text_state) | Wendet Einstellungen von einem anderen textState an. |
| measure_string(str) | Misst die Zeichenkette. |
