## TextExtractionError class

Beschreibt den Text­extraktionsfehler, der im PDF‑Dokument aufgetreten ist.

Der Typ TextExtractionError stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| summary | Kurze Beschreibung des Fehlers. |
| description | Erweiterte Beschreibung des Fehlers. |
| location | Ort des Fehlers. |
| font_key | Schlüssel (PDF-Name) des Font-Objekts, das zum Anzeigen von Text verwendet wird, der den Extraktionsfehler verursacht. |
| font_name | Lesbarer (interner) Name des Font-Objekts, das zum Anzeigen von Text verwendet wird, der den Extraktionsfehler verursacht. |
| extracted_text | Text, der tatsächlich extrahiert wurde. |
