## TextSegment class

Stellt ein Segment von PDF-Text dar.

Der Typ TextSegment stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextSegment() | Erstellt ein TextSegment-Objekt. |
| TextSegment(text) | Initialisiert eine neue Instanz der Klasse TextSegment |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| start_char_index | Liest den Startzeichenindex des aktuellen Segments im Show-Text-Operator (Tj, TJ)-Segment. |
| end_char_index | Liest den Endzeichenindex des aktuellen Segments im Show-Text-Operator (Tj, TJ)-Segment. |
| text | Liest oder setzt das Zeichenketten-Textobjekt, das das [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) Objekt repräsentiert. |
| text_state | Liest oder setzt den Textzustand für den Text, den das [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) Objekt repräsentiert. |
| position | Liest die Textposition für den Text, dargestellt mit dem [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) Objekt. |
| Rechteck | Liest das Rechteck des TextSegment |
| baseline_position | Liest die Textposition für den Text, dargestellt mit dem [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) Objekt.<br/>            Der YIndent der Position-Struktur stellt die Grundlinienkoordinate des Textsegments dar. |
| text_edit_options | Liest oder setzt Textbearbeitungsoptionen. Die Optionen definieren ein spezielles Verhalten, wenn das gewünschte Symbol nicht mit der Schriftart dargestellt werden kann. |
| characters | Liest die Sammlung von CharInfo-Objekten, die Informationen über Zeichen im Textsegment darstellen. |
| Hyperlink | Liest oder setzt den Segment-Hyperlink (für PDF-Generator). |
