## TextRenderingMode enumeration

Der Textdarstellungsmodus, Tmode, bestimmt, ob das Anzeigen von Text dazu führt, dass Glyphenumrisse gestrichelt, gefüllt, als Beschneidungsgrenze verwendet werden oder eine Kombination dieser drei Optionen.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| FILL_TEXT | Füllt Text. |
| STROKE_TEXT | Text umranden. |
| FILL_THEN_STROKE_TEXT | Füllen, dann Text umranden. |
| INVISIBLE | Weder füllen noch Text umranden (unsichtbar). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Text füllen und zum Pfad für das Clipping hinzufügen (siehe 9.3.6, "Text Rendering Mode,"). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Text umranden und zum Pfad für das Clipping hinzufügen. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Füllen, dann Text umranden und zum Pfad für das Clipping hinzufügen. |
| ADD_PATH_TO_CLIPPING | Text zum Pfad für das Clipping hinzufügen. |
