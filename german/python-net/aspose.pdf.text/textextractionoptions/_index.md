## TextExtractionOptions class

Stellt Optionen für die Textextraktion dar

Der Typ TextExtractionOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextExtractionOptions(formatting_mode) | Initialisiert eine neue Instanz der Klasse TextExtractionOptions |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| formatting_mode | Liest den Formatierungsmodus. |
| scale_factor | Liest oder setzt den Faktor, der zur Skalierung der Schriftgröße während der Extraktion im reinen Modus angewendet wird.<br/>            Das Setzen eines kleineren Wertes führt zu mehr Leerzeichen im extrahierten Text.<br/>            Der Standardwert ist 1 – keine Skalierung;<br/>            Das Setzen des Wertes auf Null lässt den Algorithmus die Skalierung automatisch wählen. |
