## SystemFontsSubstitution class

Stellt eine Klasse für eine Schriftart‑Ersetzungsstrategie dar, die Schriftarten durch Systemschriftarten ersetzt.

Der SystemFontsSubstitution-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| SystemFontsSubstitution(font_categories) | Initialisiert eine neue Instanz der SystemFontsSubstitution-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| font_categories | Liest oder setzt Schriftartkategorien für die Substitution, die durch Systemschriftarten ersetzt werden sollen. |
| default_font | Liest oder setzt die Standardsubstitutionsschriftart.<br/>            Die Schriftart wird verwendet, wenn keine andere gültige Substitution gefunden wurde, aber die ursprüngliche Schriftart zur Zielsubstitutionskategorie gehört ([font_categories](/pdf/python-net/aspose.pdf.text/systemfontssubstitution/)). |
