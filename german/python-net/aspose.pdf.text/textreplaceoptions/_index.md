## TextReplaceOptions class

Stellt Optionen für den Textaustausch dar

Der Typ TextReplaceOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextReplaceOptions(scope) | Initialisiert eine neue Instanz der Klasse TextReplaceOptions |
| TextReplaceOptions(adjustment) | Initialisiert eine neue Instanz der Klasse TextReplaceOptions |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| replace_scope | Liest oder setzt einen Geltungsbereich, in dem die Ersetzung von Text angewendet wird |
| replace_adjustment_action | Liest oder setzt eine Aktion, die nach dem Ersetzen eines Textfragmentes zu einer kürzeren Version ausgeführt wird. |
| adjustment_new_line_spacing | Liest oder setzt den Wert des Zeilenabstands, der verwendet wird, wenn die Ersetzungsanpassung erzwungen wird, eine neue Textzeile zu erzeugen.<br/>            Der erwartete Wert ist ein Multiplikator der Schriftgröße des ersetzten Textes. Standard ist 1,2. |
