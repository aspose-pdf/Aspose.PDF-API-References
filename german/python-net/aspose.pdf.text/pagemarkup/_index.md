## PageMarkup class

Seiten‑Markup wird durch Sammlungen von [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) und [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) dargestellt.

Der PageMarkup-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| number | Liefert die verarbeitete Seitennummer. |
| Rechteck | Liefert das verarbeitete Seitenrechteck. |
| sections | Liefert die Sammlung von [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) die auf der Seite gefunden wurde. |
| paragraphs | Liefert die Sammlung von [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) die auf der Seite gefunden wurde. |
| text_fragments | Liefert die Sammlung von [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) die auf der Seite gefunden wurde. |
| is_multicolumn_paragraphs_allowed | Liefert oder setzt den Wert, der angibt, ob die Anfangszeilen eines nächsten Abschnitts als Fortsetzung des letzten Absatzes eines vorherigen Abschnitts behandelt werden dürfen. |
