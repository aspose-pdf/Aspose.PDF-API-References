## TextEditOptions class

Beschreibt Optionen für Textbearbeitungs‑Operationen.

Der Typ TextEditOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextEditOptions(no_character_behavior) | Initialisiert eine neue Instanz der Klasse TextEditOptions |
| TextEditOptions(font_replace_behavior) | Initialisiert eine neue Instanz der Klasse TextEditOptions |
| TextEditOptions(allow_language_transformation) | Initialisiert eine neue Instanz der Klasse TextEditOptions |
| TextEditOptions(language_transformation_behavior) | Initialisiert eine neue Instanz der Klasse TextEditOptions |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| replacement_font | Ruft die Schriftart ab oder legt sie fest, die zum Ersetzen verwendet wird, wenn die Benutzerschriftart das erforderliche Zeichen nicht enthält |
| no_character_behavior | Ruft den Modus ab oder legt ihn fest, der das Verhalten definiert, falls Schriftarten die angeforderten Zeichen nicht enthalten. |
| font_replace_behavior | Ruft den Modus ab, der das Verhalten für Schriftart‑Ersetzungsszenarien definiert. |
| allow_language_transformation | Ruft den Wert ab oder legt ihn fest, der die Verwendung von Sprachtransformation beim Hinzufügen oder Bearbeiten von Text erlaubt.<br/>            true - Sprachtransformation wird bei Bedarf angewendet (Standardwert).<br/>            false - Sprachtransformation wird NICHT angewendet. |
| language_transformation_behavior | Ruft den Modus ab, der das Verhalten für Sprachtransformationsszenarien definiert. |
| clipping_paths_processing | Ruft den Modus für die Verarbeitung des Clipping-Pfads des bearbeiteten Textes ab. |
| to_attempt_get_underline_from_source | Ruft den Wert ab oder legt ihn fest, der die Suche nach Textunterstreichungen auf der Seite des Quelldokuments erlaubt.<br/>            (Veraltet) Bitte verwenden Sie stattdessen TextSearchOptions.SearchForTextRelatedGraphics. |
