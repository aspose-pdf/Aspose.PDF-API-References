## MarkupParagraph class

Stellt einen Absatz dar.

Der MarkupParagraph-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| points | Punkte des Polygons, das den Absatz beschreibt.<br/>            Der Startpunkt ist die linke untere Ecke des Absatzes. Und die nächsten Punkte folgen in gegen den Uhrzeigersinn. |
| secondary_points | Punkte des sekundären Polygons, das die Fortsetzung des Absatzes beschreibt. Es wird nicht null sein, wenn der Absatz in der nächsten Spalte oder Seite fortgesetzt wird.<br/>            Der Startpunkt ist die linke untere Ecke des Absatzes. Und die nächsten Punkte folgen in gegen den Uhrzeigersinn. |
| continuation_page_numbers | Liste der Seitenzahlen, auf denen der Absatz fortgesetzt wird. Sie stimmt mit der Seite überein, auf der der Absatz begann, wenn er in der nächsten Spalte auf derselben Seite fortgesetzt wird. |
| fragments | Sammlung nicht leerer [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) Objekte des Absatzes. |
| lines | Absatzzeilen. Jede Zeile wird durch eine Liste von Textfragmenten dargestellt. |
| text | Ruft das Zeichenketten‑Textobjekt ab, das das [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) Objekt darstellt. |
