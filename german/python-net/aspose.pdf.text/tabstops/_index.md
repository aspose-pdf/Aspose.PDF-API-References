## TabStops class

Stellt eine Sammlung von [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/)‑Objekten dar.

Der TabStops-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TabStops() | Initialisiert eine neue Instanz der TabStops-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_read_only | Liefert den Wert, der anzeigt, dass diese [TabStops](/pdf/python-net/aspose.pdf.text/tabstops/) Instanz bereits an [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) angehängt ist und schreibgeschützt wurde. |
| count | Initialisiert eine neue Instanz der [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) Klasse mit der angegebenen Position und <br/>            fügt sie der TabStops-Sammlung hinzu. |
## Indexer
| Name | Beschreibung |
| :- | :- |
| [index] | Liefert oder setzt ein [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) Objekt aus der Sammlung gemäß TabStop-Index. |
## Methoden

| :- | :- |

| add(tab_stop) | Initialisiert eine neue Instanz der [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) Klasse und fügt sie der <br/>            TabStops-Sammlung hinzu. |
