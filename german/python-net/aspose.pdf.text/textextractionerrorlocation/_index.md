## TextExtractionErrorLocation class

Stellt den Ort im PDF‑Dokument dar, an dem der Text­extraktionsfehler aufgetreten ist.

Der Typ TextExtractionErrorLocation stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| path | Ort des PDF-Dokuments, an dem der Text-Extraktionsfehler aufgetreten ist. |
| page_number | Seitenzahl des Dokuments, auf der der Text-Extraktionsfehler aufgetreten ist. |
| object_type | Typ des PDF-Objekts (Seite oder xForm), in dem der Text-Extraktionsfehler im Inhaltsstrom aufgetreten ist. |
| form_key | Schlüssel (Name) des PDF-Formular-XObject, in dem der Text-Extraktionsfehler im Inhaltsstrom aufgetreten ist. Nicht leer, wenn ObjectType == 'xForm'. |
| operator_index | Index des Textanzeigeoperators im Inhaltsstrom (Operatorensammlung), der den Text-Extraktionsfehler verursacht. |
| operator_string | Textanzeigeoperator, der den Text-Extraktionsfehler verursacht. |
| font_used_key | Schlüssel (Name) des PDF-Schriftobjekts, das für die Anzeige des Operators verwendet wird, der den Text-Extraktionsfehler verursacht. |
| text_start_point | Schlüssel (Name) des PDF-Schriftobjekts, das für die Anzeige des Operators verwendet wird, der den Text-Extraktionsfehler verursacht. |
