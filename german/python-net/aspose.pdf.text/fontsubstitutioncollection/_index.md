## FontSubstitutionCollection class

Stellt eine Sammlung von Schriftart-Ersetzungsstrategien dar.

Der FontSubstitutionCollection-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| sync_root | Liefert ein Objekt, das zur Synchronisation des Zugriffs auf die Sammlung verwendet werden kann. |
| is_synchronized | Liefert einen Wert, der angibt, ob der Zugriff auf die Sammlung synchronisiert ist (Thread‑sicher). |
## Indexer
| Name | Beschreibung |
| :- | :- |
| [index] | Gibt das Schriftart-Element am angegebenen Index zurück. |
