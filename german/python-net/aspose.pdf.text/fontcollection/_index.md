## FontCollection class

Stellt eine Schriftart-Sammlung dar.

Der Typ FontCollection stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| sync_root | Liefert ein Objekt, das zur Synchronisation des Zugriffs auf die Sammlung verwendet werden kann. |
| is_synchronized | Liefert einen Wert, der angibt, ob der Zugriff auf die Sammlung synchronisiert ist (Thread‑sicher). |
## Indexer
| Name | Beschreibung |
| :- | :- |
| [index] | Gibt das Schriftart-Element am angegebenen Index zurück. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| add(new_font, res_name) | Fügt eine neue Schriftart zu den Schriftressourcen hinzu und gibt den automatisch zugewiesenen Namen der Schriftressource zurück. |
