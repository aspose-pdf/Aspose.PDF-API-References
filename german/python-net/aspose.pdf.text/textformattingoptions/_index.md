## TextFormattingOptions class

Stellt Optionen für die Textformatierung dar

Der Typ TextFormattingOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TextFormattingOptions(wrap_mode) | Initialisiert eine neue Instanz der Klasse TextFormattingOptions |
| TextFormattingOptions() | Initialisiert eine neue Instanz des [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) Objekts mit undefiniertem Wortumbruchmodus. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| wrap_mode | Liest oder setzt den Wortumbruchmodus.<br/>            Standardwert ist WordWrapMode.NoWrap |
| line_spacing | Liest oder setzt den Zeilenabstandmodus.<br/>            Standardwert ist LineSpacingMode.FontSize |
| hyphen_symbol | Liest oder setzt das Trennzeichen, das im Silbentrennungsprozess verwendet wird. |
| subsequent_lines_indent | Liest oder setzt den Einzugwert für nachfolgende Zeilen. |
| first_line_indent | Liest oder setzt den Einzugwert für die erste Zeile. |
