## WarningType enumeration

Enum repräsentierte Warnungstyp.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Die Datei ist beschädigt. |
| DATA_LOSS | Text/Diagramm/Bild oder andere Daten fehlen vollständig entweder im Dokumentbaum nach dem Laden oder im erstellten Dokument nach dem Speichern. |
| MAJOR_FORMATTING_LOSS | Große Formatierungsverluste im Vergleich zum Originaldokument. Dies gilt für Fälle, in denen der Formatierungsverlust erheblich ist, die Daten jedoch noch vorhanden sind. |
| MINOR_FORMATTING_LOSS | Geringe Formatierungsverluste im Vergleich zum Originaldokument. Dies gilt für kleinere Genauigkeitsverluste. |
| COMPATIBILITY_ISSUE | Bekanntes Problem, das verhindert, dass das Dokument von bestimmten Benutzeragenten oder älteren Versionen von Benutzeragenten geöffnet wird. |

| UNEXPECTED_CONTENT | Die Datei enthält unerwarteten Inhalt. |
