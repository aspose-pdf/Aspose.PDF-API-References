## PageSize class

Klasse, die die Größe einer Seite im PDF-Dokument darstellt.

Der PageSize-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| PageSize(x, y) | Initialisiert eine neue Instanz der PageSize-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| breite | Liest oder setzt die Seitenbreite. |
| höhe | Liest oder setzt die Seitenhöhe. |
| is_landscape | Ermittelt die Seitenorientierung. Gibt true zurück, wenn dies eine Querformat-Orientierung ist, und false, wenn es Hochformat ist. |
| a0 | A0-Größe (1189×840 mm). |
| a1 | A1-Größe (840×594 mm). |
| a2 | A2-Größe (594×420 mm). |
| a3 | A3-Größe (420×297 mm). |
| a4 | A4-Größe (297×210 mm). |
| a5 | A5-Größe (210×148 mm). |
| a6 | A6-Größe (148×105 mm). |
| b5 | B5-Größe (250×176 mm). |
| page_letter | Letter-Größe (279×216 mm). |
| page_legal | Legal-Größe (356×216 mm). |
| page_ledger | Ledger-Größe (432×279 mm). |
| p11x17 | 11×17-Zoll-Format. |
