## ExtractImageMode enumeration

Definiert verschiedene Modi, die beim Extrahieren von Bildern aus Dokumenten verwendet werden können.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| DEFINED_IN_RESOURCES | Definiert den Bildextraktionsmodus, bei dem alle in den Ressourcen für die jeweilige Seite definierten Bilder extrahiert werden. |
| ACTUALLY_USED | Definiert den Bildextraktionsmodus, bei dem nur die Bilder extrahiert werden, die tatsächlich auf einer Seite angezeigt werden. |
