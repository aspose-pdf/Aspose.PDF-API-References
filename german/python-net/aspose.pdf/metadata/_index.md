## Metadata class

Stellt Zugriff auf den XMP-Metadaten-Stream bereit.

Der Metadata-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_fixed_size | Überprüft, ob die Sammlung eine feste Größe hat. |
| Schlüssel | Liefert die Sammlung von Metadaten‑Schlüsseln. |
| Werte | Liefert die Werte in den Metadaten. |
| is_synchronized | Überprüft, ob die Sammlung synchronisiert ist. |
| sync_root | Liefert das Synchronisationsobjekt der Sammlung. |
