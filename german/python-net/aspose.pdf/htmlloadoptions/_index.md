## HtmlLoadOptions class

Stellt Optionen zum Laden/Importieren einer HTML-Datei in ein PDF-Dokument dar.

Der Typ HtmlLoadOptions stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| HtmlLoadOptions() | Erstellt Ladeoptionen zum Konvertieren von HTML in ein PDF-Dokument mit leerem Basispfad. |
| HtmlLoadOptions(base_path) | Initialisiert eine neue Instanz der Klasse HtmlLoadOptions |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| warning_handler | Rückruf, um alle erzeugten Warnungen zu behandeln. <br/>            Der WarningHandler gibt ein ReturnAction-Enum-Element zurück, das entweder Continue oder Abort angibt. <br/>            Continue ist die Standardaktion und der Ladevorgang wird fortgesetzt, jedoch kann der Benutzer auch Abort zurückgeben, in welchem Fall der Ladevorgang beendet werden sollte. |
| load_format | Stellt das Dateiformat dar, das von [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) beschrieben wird. |
| is_render_to_single_page | Liest oder setzt die Darstellung des gesamten Dokuments auf einer einzigen Seite |
| is_embed_fonts | Liest oder setzt das Einbetten von Schriftarten in das Ergebnisdokument |
| page_layout_option | Liest oder setzt die Layout-Option. |
| html_media_type | Liest oder setzt mögliche Medientypen, die beim Rendern verwendet werden. |
| input_encoding | Liest oder setzt das Attribut, das die beim Parsen für dieses Dokument verwendete Kodierung angibt. Wenn dieses Attribut null ist, wird die Kodierung aus dem Zeichensatz-Attribut des Dokuments ermittelt. |
| base_path | Der Basis-Pfad/URL für die HTML-Datei. |
| page_info | Liest oder setzt Dokumentseiteninformationen |
