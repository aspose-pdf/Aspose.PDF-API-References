## TimestampSettings class

Stellt die OCSP-Einstellungen dar, die während des Signaturvorgangs verwendet werden.

Der Typ TimestampSettings stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| TimestampSettings(server_url, basic_auth_credentials, digest_hash_algorithm) | Initialisiert eine neue Instanz der Klasse TimestampSettings |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| server_url | Liest/setzt die URL des Zeitstempel-Servers. |
| basic_auth_credentials | Liest/setzt die Basis-Authentifizierungsdaten, Benutzername und Passwort werden zu einer Zeichenkette "username:password" kombiniert. |
| digest_hash_algorithm | Liest/setzt den Digest-Algorithmus für interne Hash‑Funktionen. |
