## EmbeddedFileCollection class

Klasse, die die Sammlung eingebetteter Dateien darstellt.

Der Typ EmbeddedFileCollection stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_synchronized | Gibt einen Wert zurück, der angibt, ob der Zugriff auf diese Sammlung synchronisiert ist (Thread-sicher). |
| sync_root | Gibt ein Objekt zurück, das verwendet werden kann, um den Zugriff auf diese Sammlung zu synchronisieren. |
| Schlüssel | Gibt eine Liste von Dateianhang‑Schlüsseln zurück. |
## Indexer
| Name | Beschreibung |
| :- | :- |
| [index] | Ruft die eingebettete Datei anhand ihres Index ab. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| delete(name) | Löscht die Datei aus der Sammlung anhand ihres Schlüssels in der Sammlung. |
| delete() | Löscht die Datei aus der Sammlung anhand ihres Schlüssels in der Sammlung. |
| add(key, file) | Fügt die Datei zu den eingebetteten Dateien mit dem angegebenen Schlüssel hinzu. |
| delete_by_key(key) | Löscht die Datei aus der Sammlung anhand ihres Schlüssels in der Sammlung. |
| find_by_name(name) | Gibt die eingebettete Datei anhand ihres Namens zurück. |
