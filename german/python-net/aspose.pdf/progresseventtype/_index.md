## ProgressEventType enumeration

Dieses Enum beschreibt mögliche Fortschritt-Ereignistypen<br/>            die während der Konvertierung auftreten können.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| TOTAL_PROGRESS | bedeutet, dass das aufgetretene Ereignis über den Gesamtfortschritt der Konvertierung informiert |
| SOURCE_PAGE_ANALYSED | bedeutet, dass das aufgetretene Ereignis das Ende der Analyse einer Seite vor der Konvertierung anzeigt |
| RESULT_PAGE_CREATED | bedeutet, dass das aufgetretene Ereignis die Erstellung einer Ergebnisseite vor dem physischen Export anzeigt |
| RESULT_PAGE_SAVED | bedeutet, dass das aufgetretene Ereignis das abgeschlossene Speichern einer Ergebnisseite anzeigt |
