## ImagePlacement class

Stellt die Eigenschaften eines in eine Pdf-Dokumentseite platzierten Bildes dar.

Der Typ ImagePlacement stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| matrix | Aktuelle Transformationsmatrix für dieses Bild. |
| Rechteck | Liefert das Rechteck des Bildes. |
| operator | Operator, der zum Anzeigen des Bildes verwendet wird. |
| rotation | Liefert den Rotationswinkel des Bildes. |
| resolution | Liefert die Auflösung des Bildes. |
| image | Liefert das zugehörige XImage-Ressourcenobjekt. |
| page | Liefert die Seite, die das Bild enthält. |
| compositing_parameters | Liefert die Kompositierungsparameter des Grafikzustands, die für das auf die Seite platzierte Bild aktiv sind. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| save(stream) | Speichert das Bild mit den entsprechenden Transformationen: Skalierung, Rotation und Auflösung. |
| save(stream, format) | Speichert das Bild mit den entsprechenden Transformationen: Skalierung, Rotation und Auflösung. |
| hide() | Löscht das Bild von der Seite. |
| replace(image) | Ersetzt das Bild in der Sammlung durch ein anderes Bild. |
