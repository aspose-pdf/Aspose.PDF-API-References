## DocumentInfo class

Stellt Metainformationen eines PDF‑Dokuments dar.

Der DocumentInfo-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| DocumentInfo(document) | Initialisiert eine neue Instanz der DocumentInfo-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| title | Liest oder setzt den Dokumenttitel. |
| creator | Liest oder setzt den Dokumentersteller. |
| author | Liest oder setzt den Dokumentautor. |
| subject | Liest oder setzt das Betreff des Dokuments. |
| keywords | Liest oder setzt die Schlüsselwörter des Dokuments. |
| producer | Liest oder setzt den Dokumenthersteller. |
| creation_date | Liest oder setzt das Erstellungsdatum des Dokuments. |
| creation_time_zone | Zeitzone des Erstellungsdatums. |
| mod_time_zone | Zeitzone des Änderungsdatums. |
| mod_date | Liest oder setzt das Änderungsdatum des Dokuments. |
| trapped | Liest oder setzt das Trapped-Flag. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| add(key, value) | Fügt ein Element mit dem angegebenen Schlüssel und Wert zur Sammlung hinzu. |
| remove(key) | Entfernt das Element mit dem angegebenen Schlüssel aus der Sammlung. |
| clear_custom_data() | Löscht nur benutzerdefinierte Daten und lässt alle anderen vordefinierten Werte (Titel, Autor usw.) unverändert. |
| is_predefined_key(key) | Bestimmt, ob der Schlüssel vordefiniert ist (Titel, Autor usw.), nicht benutzerdefiniert. |
