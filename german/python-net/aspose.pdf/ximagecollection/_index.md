## XImageCollection class

Klasse, die eine XImage-Sammlung darstellt.

Der Typ XImageCollection stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_synchronized | Gibt true zurück, wenn das Objekt synchronisiert ist. |
| sync_root | Gibt das Synchronisationsobjekt zurück. |
| names | Liefert ein Array von Bildnamen. |
## Indexer
| Name | Beschreibung |
| :- | :- |
| [index] | Liefert ein Bild aus der Sammlung anhand seines Index. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| add(image) | Fügt ein neues Bild zur Bildliste hinzu. Diese Methode fügt das Bild als Referenz zum selben PdfObject hinzu (was eine Verringerung der Dateigröße ermöglicht). |
| add(image) | Fügt ein Element am Ende der Sammlung hinzu, sodass das Element über den letzten Index zugänglich ist. |
| add(image, filter_type) | Fügt ein Element am Ende der Sammlung hinzu, sodass das Element über den letzten Index zugänglich ist. |
| add(image, quality) | Fügt ein Element am Ende der Sammlung hinzu, sodass das Element über den letzten Index zugänglich ist. |
| delete(index) | Entfernt ein Element aus der Sammlung anhand des Index. |
| delete(index, action) | Entfernt ein Bild aus der Sammlung anhand des Index und führt die im Parameter action angegebene Aktion aus. |
| delete(name) | Entfernt ein Element aus der Sammlung anhand des Namens. |
| delete(name, action) | Entfernt ein Element aus der Sammlung anhand des Namens. |
| delete() | Entfernt ein Element aus der Sammlung anhand des Index. |
| replace(index, stream) | Ersetzt das Bild in der Sammlung durch ein anderes Bild. |
| replace(index, stream, quality, is_black_and_white) | Ersetzt das Bild in der Sammlung durch ein anderes Bild. |
| replace(index, stream, quality) | Ersetzt das Bild in der Sammlung durch ein anderes Bild. |
| get_image_name(image) | Gibt den Namen in der Bildliste zurück, der Schlüssel des angegebenen Bildes ist. |
