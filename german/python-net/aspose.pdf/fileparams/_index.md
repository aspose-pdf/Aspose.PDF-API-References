## FileParams class

Definiert ein eingebettetes Dateiparameter‑Wörterbuch, das zusätzliche dateispezifische Informationen enthalten soll.

Der FileParams-Typ stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| FileParams(spec) | Initialisiert eine neue Instanz der FileParams-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Größe | Die Größe der unkomprimierten eingebetteten Datei in Bytes. |
| creation_date | Das Datum und die Uhrzeit, zu der die eingebettete Datei erstellt wurde. |
| mod_date | Das Datum und die Uhrzeit, zu der die eingebettete Datei zuletzt geändert wurde. |
| check_sum | Eine 16‑Byte‑Zeichenkette, die die Prüfsumme der Bytes der unkomprimierten eingebetteten Datei ist. <br/>            Die Prüfsumme wird berechnet, indem der Standard‑MD5‑Message‑Digest‑Algorithmus <br/>            auf die Bytes des eingebetteten Dateistreams angewendet wird. |
