## PageMode enumeration

Die Klasse beschreibt die verwendeten Komponenten der Dokumentseite.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| USE_NONE | Keine Komponenten verwenden. |
| USE_OUTLINES | Dokumentenübersicht sichtbar. |
| USE_THUMBS | Miniaturbilder sichtbar. |
| FULL_SCREEN | Vollbildmodus, ohne Menüleiste, Fenstersteuerungen oder andere Fenster sichtbar. |
| USE_OC | Optionales Inhaltsgruppen-Panel sichtbar. |
| USE_ATTACHMENTS | Anhangs‑Panel sichtbar. |
