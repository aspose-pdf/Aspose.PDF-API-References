## Resources class

Klasse, die Seitenressourcen darstellt.

Der Typ Resources stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| forms | Liest die [forms](/pdf/python-net/aspose.pdf/resources/) Formsammlung |
| images | Liest die [images](/pdf/python-net/aspose.pdf/resources/) Bildersammlung |
| fonts | Liest die [fonts](/pdf/python-net/aspose.pdf/resources/) Schriftarten-Sammlung |
## Methoden
| Name | Beschreibung |
| :- | :- |
| get_fonts(create_if_absent) | Gibt die Schriftarten-Sammlung zurück. Wenn Ressourcen keinen Schriftarten-Eintrag enthalten, wird er abhängig vom CreateIfAbsent-Flag erstellt. |
