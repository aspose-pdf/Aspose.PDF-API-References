## PdfANonSpecificationFlags class

Diese Klasse enthält Flags zur Steuerung der PDF/A-Konvertierung für Fälle, in denen das Quell‑PDF‑Dokument nicht <br/>            der PDF‑Spezifikation entspricht. Wenn die Flags dieser Klasse verwendet werden, verringert sich die Leistung <br/>           , aber sie ist notwendig, wenn das Quell‑PDF‑Dokument nicht auf herkömmliche Weise in das PDF/A‑Format konvertiert werden kann. <br/>            Standardmäßig sind alle Flags auf false gesetzt.

Der Typ PdfANonSpecificationFlags stellt die folgenden Mitglieder bereit:
