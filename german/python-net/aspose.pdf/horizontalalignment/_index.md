## HorizontalAlignment enumeration

Beschreibt die horizontale Ausrichtung.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| NONE | Keine Ausrichtung. |
| LEFT | Linksbündig ausrichten. |
| CENTER | Zentrierte Ausrichtung. |
| RIGHT | Rechtsbündig ausrichten. |
| BLOCKSATZ | Blocksatz-Ausrichtung. Der Text wird an beiden, linken und rechten Rändern ausgerichtet. |
| VOLL_BLOCKSATZ | Ähnlich zur 'Justify'-Ausrichtung, außer dass die allerletzte Zeile nur <br/>            linksbündig im 'Justify'-Modus ist, während im 'FullJustify'-Modus alle Zeilen <br/>            links- und rechtsbündig sind. |
