## ColumnInfo class

Diese Klasse repräsentiert Spalteninformationen.

Der Typ ColumnInfo stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| ColumnInfo() | Initialisiert eine neue Instanz der Klasse ColumnInfo |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| column_widths | Liest oder schreibt eine Zeichenkette, die die Breite der Spalten enthält. <br/>            Der Wert jeder Spalte sollte durch ein Leerzeichen getrennt werden. Die Standardmaßeinheit ist Punkt,<br/>            aber cm, Zoll und Prozentsatz der verfügbaren Breite werden ebenfalls unterstützt.<br/>            Zum Beispiel,\"120 2.5cm 1.5inch\" |
| column_spacing | Liest oder schreibt eine Zeichenkette, die den Abstand zwischen den Spalten enthält. <br/>            Der Wert jedes Abstands sollte durch ein Leerzeichen getrennt werden. Die Standardmaßeinheit ist Punkt,<br/>            aber cm und Zoll werden ebenfalls unterstützt. Zum Beispiel,\"120 2.5cm 1.5inch\". |
| column_count | Liest oder schreibt einen int-Wert, der die Anzahl der Spalten angibt. |
