## OutlineCollection class

Stellt die Dokumenten-Gliederungshierarchie dar.

Der Typ OutlineCollection stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| visible_count | Count ist die Summe der Anzahl sichtbarer untergeordneter Gliederungselemente auf allen Ebenen. Hinweis: Bitte nicht verwechseln mit Count, das die Anzahl der Elemente in der Sammlung angibt. |
| first | Gibt ein Gliederungselement zurück, das das erste Element der obersten Ebene in der Gliederung darstellt. |
| last | Gibt ein Gliederungselement zurück, das das letzte Element der obersten Ebene in der Gliederung darstellt. |
| is_synchronized | Gibt einen Wert zurück, der angibt, ob der Zugriff auf diese Sammlung synchronisiert ist (Thread-sicher). |
| sync_root | Gibt ein Objekt zurück, das verwendet werden kann, um den Zugriff auf diese Sammlung zu synchronisieren. |
## Indexer
| Name | Beschreibung |
| :- | :- |
| [index] | Gibt ein Gliederungselement aus der Sammlung anhand des Index zurück. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| delete() | Löscht alle Gliederungselemente aus der Dokumenten-Gliederung. |
| delete(name) | Löscht das Gliederungselement mit dem angegebenen Titel aus der Dokumenten-Gliederung. |
