## Row class

Stellt eine Zeile der Tabelle dar.

Der Row-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Row() | Initialisiert eine neue Instanz der Row-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| background_color | Liest oder setzt die Hintergrundfarbe. |
| rahmen | Liest oder setzt den Rand. |
| cells | Liest die Zellen der Zeile. |
| default_cell_border | Liest den Standardzellenrahmen; |
| min_row_height | Liest die Höhe für die Zeile; |
| fixed_row_height | Liest die feste Zeilenhöhe – die Zeile kann eine feste Höhe haben; |
| is_in_new_page | Liest, ob die Zeile auf einer neuen Seite ist – Seite mit dieser Eigenschaft sollte auf die nächste Seite gedruckt werden. Standard: false; |
| is_row_broken | Liest, ob die Zeile zwischen zwei Seiten umgebrochen werden kann |
| default_cell_text_state | Liest oder setzt den Standard‑Textzustand für Zeilenzellen. |
| default_cell_padding | Liest oder setzt den Standardabstand für Zeilenzellen. |
| vertical_alignment | Liest oder legt die vertikale Ausrichtung fest. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| clone() | Klont die Zeile. |
