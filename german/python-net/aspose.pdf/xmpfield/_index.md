## XmpField class

Stellt ein XMP-Feld dar.

Der XmpField-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| leer | Gibt ein leeres XMP-Feld zurück. |
| lang | Gibt den xml:lang-Qualifikator zurück. |
| prefix | Gibt das prefix zurück. |
| namespace_uri | Gibt die Namespace-URI zurück. |
| local_name | Liest oder setzt den Namen des lokalen Elements. |
| Name | Gibt den Namen zurück. |
| Wert | Gibt den Wert zurück. |
| field_type | Gibt den Typ des Feldes zurück. |
| is_empty | Gibt einen Wert zurück, der angibt, ob diese Instanz leer ist. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| to_structure() | Gibt den Wert als Struktur zurück. |
| to_array() | Gibt den Wert als Array zurück. |
