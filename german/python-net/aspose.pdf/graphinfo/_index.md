## GraphInfo class

Stellt Grafikinformationen dar.

Der GraphInfo-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| GraphInfo() | Initialisiert eine neue Instanz der GraphInfo-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| line_width | Liest oder setzt einen Float-Wert, der die Linienbreite des Diagramms angibt. |
| color | Liest oder setzt ein [color](/pdf/python-net/aspose.pdf/graphinfo/) Objekt, das die Farbe des Diagramms angibt. |
| dash_array | Liest oder setzt ein Strichmuster-Array. |
| dash_phase | Liest oder setzt eine Strichphase. |
| fill_color | Liest oder setzt ein [color](/pdf/python-net/aspose.pdf/graphinfo/) Objekt, das die Füllfarbe des Diagramms angibt. |
| is_doubled | Liest oder setzt, ob die Grenze verdoppelt ist. |
| skew_angle_x | Liest oder setzt einen Float-Wert, der den Schrägwinkel der x-Koordinate beim Transformieren eines Koordinatensystems angibt. |
| skew_angle_y | Liest oder setzt einen Float-Wert, der den Schrägwinkel der y-Koordinate beim Transformieren eines Koordinatensystems angibt. |
| scaling_rate_x | Liest oder setzt einen Float-Wert, der die Skalierungsrate der x-Koordinate beim Transformieren eines Koordinatensystems angibt. |
| scaling_rate_y | Liest oder setzt einen Fließkommawert, der die Skalierungsrate der y‑Koordinate beim Transformieren eines Koordinatensystems angibt. |
| rotation_angle | Liest oder setzt einen Fließkommawert, der den Rotationswinkel des Koordinatensystems <br/>            beim Transformieren eines Koordinatensystems angibt. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| clone() | Klone die Grafik‑Informationen. |
