## Cell class

Stellt eine Zelle der Tabellenzeile dar.

Der Cell-Typ stellt die folgenden Member bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Cell(rect) | Initialisiert eine neue Instanz der Cell-Klasse |
| Cell() | Initialisiert eine neue Instanz der Cell-Klasse. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_no_border | Liest oder legt fest, ob die Zelle einen Rand hat. |
| Rand | Liest oder legt den Abstand fest. |
| rahmen | Liest oder setzt den Rand. |
| background_color | Liest oder setzt die Hintergrundfarbe. |
| background_image_file | Liest oder setzt die Hintergrundbilddatei. |
| background_image | Liest oder setzt das Hintergrundbild |
| ausrichtung | Liest oder setzt die Ausrichtung. |
| default_cell_text_state | Liest oder legt den Standard-Textzustand der Zelle fest. |
| is_override_by_fragment | Legt fest, dass die TextState-Eigenschaft der Zelle von der TextState-Eigenschaft des TextFragment überschrieben wird. |
| paragraphs | Liest oder setzt den formatierten Text der Zelle. |
| is_word_wrapped | Liest oder legt den Wortumbruch des Zellentextes fest. |
| vertical_alignment | Liest oder legt die vertikale Ausrichtung fest. |
| col_span | Liest oder legt die Spaltenüberlappung fest. |
| row_span | Liest oder legt die Zeilenüberlappung fest. |
| breite | Liest oder setzt die Spaltenbreite. |
