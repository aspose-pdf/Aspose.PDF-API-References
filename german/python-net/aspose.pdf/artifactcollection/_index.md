## ArtifactCollection class

Klasse repräsentiert die Artefaktsammlung.

Der ArtifactCollection-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| is_synchronized | Ist dieses Objekt synchronisiert. |
| sync_root | Liefert das Synchronisationsobjekt der Sammlung. |
## Indexer
| Name | Beschreibung |
| :- | :- |
| [index] | Liefert das Artefakt nach Index. Der Index beginnt bei 1. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| delete(artifact) | Löscht das angegebene Artefakt. |
| delete(index) | Löscht das Artefakt nach seinem Index. |
| find_by_value(name, expected_value) | Findet Artefakte nach benutzerdefiniertem Wert. |
| update(artifact) | Aktualisiert das Artefakt in der Sammlung. |
