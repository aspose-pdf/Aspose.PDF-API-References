## Opi class

Stellt das Open Prepress Interface (OPI) dar, ein Mechanismus zur Erstellung von Low-Resolution-Platzhaltern oder Proxy‑Objekten,<br/>            für solche hochauflösenden Bilder.

Der Opi-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Opi(xform) | Initialisiert eine neue Instanz der Opi-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| version | Ermittelt die Version von OPI, auf die dieses Wörterbuch verweist. |
| file_specification | Ermittelt die externe Datei, die das Low-Resolution-Proxy-Bild enthält. |
| position | Ermittelt ein Array von acht Zahlen, das die Position des beschnittenen Bildes auf der Seite angibt. |
