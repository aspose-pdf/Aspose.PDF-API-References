## TeXMemoryOutputDirectory class

Implementiert das Abrufen eines Ausgabestreams aus dem Speicher. Sie können ihn zum Beispiel,<br/>            verwenden, wenn Sie die begleitende Ausgabe (wie eine Protokolldatei) nicht auf<br/>            die Festplatte schreiben möchten, sie aber anschließend aus dem Speicher lesen wollen.
