## PasswordType enumeration

Dieses Enum repräsentiert bekannte Passworttypen, die für passwortgeschützte PDF-Dokumente verwendet werden.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| NONE | Pdf-Dokument ist nicht passwortgeschützt. |
| USER | Pdf-Dokument wurde mit dem Öffnungskennwort (eingeschränkter Zugriff) geöffnet. |
| OWNER | Pdf-Dokument wurde mit dem Kennwort zum Ändern der Berechtigungen (voller Zugriff) geöffnet. |
| INACCESSIBLE | Pdf-Dokument ist passwortgeschützt, aber sowohl Benutzer- als auch Eigentümerkennwörter sind nicht leer und <br/>            keines der Kennwörter wurde definiert oder das bereitgestellte Kennwort war falsch. Daher ist es unmöglich, den Typ des Kennworts zu bestimmen. |
