## HtmlPageLayoutOption enumeration

Gibt Flags an, die zusammen mit anderen Optionen die Größen und Layouts von Seiten bestimmen.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| NONE | Standardwert, der angibt, dass die HtmlPageLayoutOption die Größen und Layouts der Seiten nicht beeinflusst. |
| FIT_TO_WIDEST_CONTENT_WIDTH | Gibt an, dass die Breite der Seite aus der Größe des Inhalts selbst bestimmt wird, nicht aus der angegebenen Seitenbreite. |
| SCALE_TO_PAGE_WIDTH | Gibt an, dass der Inhalt des Dokuments skaliert wird, um auf die Seite zu passen. |
