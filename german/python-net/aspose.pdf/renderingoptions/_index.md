## RenderingOptions class

Stellt Rendering-Optionen dar.

Der Typ RenderingOptions stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| RenderingOptions() | Initialisiert eine neue Instanz der RenderingOptions-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| barcode_optimization | Liest oder setzt den Barcode-Optimierungsmodus. |
| optimize_dimensions | Liest oder setzt den Modus zur Optimierung der Abmessungen. |
| system_fonts_native_rendering | Liest oder setzt einen Modus, in dem Systemschriftarten nativ gerendert werden. |
| use_new_imaging_engine | Liest oder setzt ein Flag, das bestimmt, ob die neue Bildverarbeitungs-Engine verwendet wird oder nicht. |
| width_extra_units | Liest oder setzt einen Wert, der verwendet wird, um die Breite des Rechtecks für den AppendRectangle-Operator zu vergrößern oder zu verkleinern. |
| height_extra_units | Liest oder setzt einen Wert, der verwendet wird, um die Breite des Rechtecks für den AppendRectangle-Operator zu vergrößern oder zu verkleinern. |
| convert_fonts_to_unicode_ttf | Gibt an, dass alle Schriftarten in TTF-Unicode-Versionen konvertiert werden. Das ist nützlich aus Kompatibilitäts‑Gründen <br/>             und um die Schriftartnutzung zu optimieren, da jede neue TTF‑Schrift nicht alle Symbole <br/>             der Quellschrift enthält, sondern nur die im Text verwendeten Symbole. |
| use_font_hinting | Die Verwendung dieses Flags aktiviert den Font‑Hinting‑Mechanismus. Font‑Hinting ist die Verwendung mathematischer Anweisungen, um die Anzeige <br/>            einer Kontur‑Schriftart anzupassen. In einigen Fällen kann das Aktivieren dieses Flags Probleme mit der Lesbarkeit von Text lösen. <br/>            Zum aktuellen Zeitpunkt wirkt sich die Verwendung dieses Flags nur auf TTF‑Schriftarten aus, wenn diese Schriftarten im Quelldokument verwendet werden. |
| scale_images_to_fit_page_width | Liest oder setzt einen Wert, der verwendet wird, um alle Bilder auf der Seite zu skalieren, sodass sie in die Seitenbreite passen. |
| interpolation_high_quality | Liest oder setzt den Hochqualitätsmodus für die Interpolation. |
| max_fonts_cache_size | Maximale Anzahl von Schriftarten im Schriftarten‑Cache. Standardwert ist 10. |
| max_symbols_cache_size | Maximale Anzahl von Symbolen im Symbol‑Cache. Standardwert ist 100. |
| default_font_name | Liest/Setzt den Standardnamen der Schriftart, die als Ersatz für fehlende Schriftarten verwendet wird. |
| ignore_resource_font_errors | Liest oder setzt die Angabe, dass Fehler im Zusammenhang mit fehlenden Schriftarten ignoriert werden.<br/>            true - bedeutet, dass Fehler wegen fehlender Schriftarten ignoriert werden. Textsegmente, die sich auf falsche Ressourcen beziehen, werden während der Verarbeitung übersprungen.<br/>            false ist standardmäßig. |
