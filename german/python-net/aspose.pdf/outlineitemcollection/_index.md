## OutlineItemCollection class

Stellt einen Gliederungseintrag in der Gliederungshierarchie eines PDF-Dokuments dar.

Der Typ OutlineItemCollection stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| OutlineItemCollection(outlines) | Initialisiert eine neue Instanz der Klasse OutlineItemCollection |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| visible_count | Ermittelt die Gesamtzahl der Outline-Elemente auf allen Ebenen in der Dokument-Outline-Hierarchie. |
| title | Liest oder setzt den Titel für dieses Outline-Element. |
| destination | Liest oder setzt das Ziel für dieses Outline-Element. |
| action | Ermittelt oder legt die Aktion für dieses Gliederungselement fest. |
| farbe | Ermittelt oder legt die Farbe für den Titeltext dieses Gliederungselements fest. |
| kursiv | Ermittelt oder legt das Kursiv-Flag für den Titeltext dieses Gliederungselements fest. |
| fett | Ermittelt oder legt das Fett-Flag für den Titeltext dieses Gliederungselements fest. |
| first | Ermittelt das Gliederungselement, das das erste Element der obersten Ebene in der Gliederungshierarchie darstellt. |
| last | Ermittelt das Gliederungselement, das das letzte Element der obersten Ebene in der Gliederungshierarchie darstellt. |
| prev | Ermittelt das Gliederungselement, das das vorherige Element relativ zu diesem Element in der Gliederungshierarchie darstellt. |
| Weiter | Ermittelt das Gliederungselement, das das nächste Element relativ zu diesem Element in der Gliederungshierarchie darstellt. |
| has_next | Überprüft, ob ein Gliederungselement das nächste Element relativ zu diesem Element in der Gliederungshierarchie darstellt. |
| Eltern | Ermittelt das übergeordnete Objekt dieses Gliederungselements in der Gliederungshierarchie. |
| is_synchronized | Ermittelt den Wert, der angibt, ob der Zugriff auf diese Sammlung synchronisiert (thread‑sicher) ist. |
| sync_root | Ermittelt das Objekt, das verwendet werden kann, um den Zugriff auf diese Sammlung zu synchronisieren. |
| öffnen | Ermittelt oder legt den Öffnungsstatus (true/false) für das Gliederungselement fest. |
| level | Ermittelt die Hierarchieebene des Gliederungselements. |
## Indexer
| Name | Beschreibung |
| :- | :- |
| [index] | Ermittelt das Gliederungselement aus der Sammlung anhand des Index. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| delete() | Löscht dieses Gliederungselement aus der Dokumenten‑Gliederungshierarchie. |
| delete(name) | Löscht den Gliederungseintrag mit dem angegebenen Namen aus der Dokumenten‑Gliederungshierarchie. |
| insert(index, outline) | Fügt das Gliederungselement in die Sammlung an der angegebenen Stelle ein. |
