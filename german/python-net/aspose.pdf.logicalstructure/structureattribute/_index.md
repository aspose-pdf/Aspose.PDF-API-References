## StructureAttribute class

Stellt ein Attribut des Strukturelements dar.

Der StructureAttribute-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| StructureAttribute(attribute_key) | Initialisiert eine neue Instanz der StructureAttribute-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| key | Gibt den Attributschlüssel zurück. |
| is_initialized_value | Ermittelt den Status des Struktur-Attributwertes. Wahr, wenn der Wert gesetzt ist. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| get_name_value() | Ermittelt den Wertnamen. |
| get_string_value() | Ermittelt den Wert-String. |
| get_number_value() | Ermittelt die Wertzahl. |
| get_array_value() | Ermittelt das Array der Wertnamen. |
| get_array_number_value() | Ermittelt das Array der Wertzahlen. |
| set_name_value(name) | Setzt den Wertnamen. |
| set_string_value(value) | Setzt den Wert-String. |
| set_number_value(number) | Setzt die Wertzahl. |
| set_array_value(array) | Setzt das Array der Wertnamen. |
| set_array_number_value(array_number) | Setzt das Array der Wertzahlen. |
| set_color_value(color) | Setzt die Wertfarbe. |
| set_rectangle_value(rectangle) | Setzt das Wertrechteck. |
