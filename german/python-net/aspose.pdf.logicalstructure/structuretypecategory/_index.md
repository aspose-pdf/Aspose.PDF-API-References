## StructureTypeCategory class

Stellt Kategorien von Standardstrukturtypen dar.

Der Typ StructureTypeCategory stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| GROUPING_ELEMENTS | Gruppierungselemente gruppieren andere Elemente zu Sequenzen oder Hierarchien, enthalten jedoch keinen Inhalt direkt und haben keinen direkten Einfluss auf das Layout. |
| BLS_ES | Block‑Level‑Strukturelemente (BLSEs) beschreiben das Gesamtlayout des Inhalts auf der Seite und verlaufen in Block‑Fortschritts‑Richtung. |
| ILS_ES | Inline‑Level‑Strukturelemente (ILSEs) beschreiben das Layout des Inhalts innerhalb eines BLSE und verlaufen in Inline‑Fortschritts‑Richtung. |
| ILLUSTRATION_ELEMENTS | Illustrationselemente sind kompakte Sequenzen von Inhalt, in Seiteninhaltsreihenfolge, die als einheitliche Objekte im Hinblick auf das Seitenlayout betrachtet werden. Eine Illustration kann entweder als BLSE oder als ILSE behandelt werden. |
