## ILSTextElement class

Stellt eine Basisklasse für Inline‑Ebene‑Textstrukturelemente in der logischen Struktur dar.

Der ILSTextElement-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| parent_element | Keine |
| child_elements | Keine |
| default_attribute_owner | Liest |
| Attribute | Liest |
| structure_type | Liest den Typ des Strukturelements. |
| id | Liest die ID des Strukturelements. |
| title | Liest oder setzt den Titel des Strukturelements. |
| Sprache | Liest oder setzt die Sprache für das Strukturelement. |
| alternative_text | Liest oder setzt den Alternativtext für das Strukturelement. |
| expansion_text | Liest oder setzt den Erweiterungstext für das Strukturelement. |
| actual_text | Liest oder setzt den tatsächlichen Text für das Strukturelement. |
| structure_text_state | Liest |
## Methoden
| Name | Beschreibung |
| :- | :- |
| append_child(element) | Keine |
| change_parent_element(new_parent_element) | Elternelement für das aktuelle Strukturelement ändern |
| generate_id() | Generiere ID für das Strukturelement. |
| set_id(id) | Setzt die ID für das Strukturelement. |
| clear_id() | Löscht die ID für das Strukturelement. |
| set_tag(new_tag) | Setzt ein benutzerdefiniertes Tag für das Strukturelement. |
| set_text(text) | Fügt Textinhalt zum aktuellen Textelement hinzu. |
