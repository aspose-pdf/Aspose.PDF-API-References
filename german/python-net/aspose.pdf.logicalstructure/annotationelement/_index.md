## AnnotationElement class

Stellt eine Basisklasse für Annotations-Strukturelemente in der logischen Struktur dar.

Der Typ AnnotationElement stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| parent_element | Keine |
| child_elements | Keine |
| default_attribute_owner | Liest |
| Attribute | Liest |
| structure_type | Liest den Typ des Strukturelements. |
| id | Liest die ID des Strukturelements. |
| title | Liest oder setzt den Titel des Strukturelements. |
| Sprache | Liest oder setzt die Sprache für das Strukturelement. |
| alternative_text | Liest oder setzt den Alternativtext für das Strukturelement. |
| expansion_text | Liest oder setzt den Erweiterungstext für das Strukturelement. |
| actual_text | Liest oder setzt den tatsächlichen Text für das Strukturelement. |
| alternate_descriptions | Liest oder setzt die alternativen Beschreibungen für die Anmerkung.<br/>                Text, der für die Anmerkung angezeigt werden soll oder, falls dieser Anmerkungstyp keinen Text anzeigt, eine alternative Beschreibung des Inhalts der Anmerkung in menschenlesbarer Form. |
