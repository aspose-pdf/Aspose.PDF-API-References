## TableElement class

Stellt das Tabellenelement in der logischen Struktur dar.

Der TableElement-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| parent_element | Keine |
| child_elements | Keine |
| default_attribute_owner | Liest |
| Attribute | Liest |
| structure_type | Liest den Typ des Strukturelements. |
| id | Liest die ID des Strukturelements. |
| title | Liest oder setzt den Titel des Strukturelements. |
| Sprache | Liest oder setzt die Sprache für das Strukturelement. |
| alternative_text | Liest oder setzt den Alternativtext für das Strukturelement. |
| expansion_text | Liest oder setzt den Erweiterungstext für das Strukturelement. |
| actual_text | Liest oder setzt den tatsächlichen Text für das Strukturelement. |
| background_color | Liest oder setzt die Hintergrundfarbe der Tabelle. |
| rahmen | Liest oder setzt den Tabellenrahmen. |
| ausrichtung | Liest oder setzt die Tabellenausrichtung. |
| corner_style | Liest oder setzt die Stile der Rahmen-Ecken |
| broken | Liest oder setzt die vertikale Unterbrechung der Tabelle; |
| column_adjustment | Liest oder setzt die Spaltenanpassung der Tabelle. |

| default_cell_border | Ruft den Standardzellenrand ab. |
| default_cell_padding | Liest oder legt den Standardzellenabstand fest. |

| left | Liest oder setzt die linke Koordinate der Tabelle. |

| repeating_columns_count | Liest oder legt die maximale Spaltenanzahl für die Tabelle fest. |
| repeating_rows_count | Liest die Anzahl der ersten Zeilen, die für mehrere Seiten wiederholt werden. |
| repeating_rows_style | Liest den Stil für wiederholende Zeilen. |
