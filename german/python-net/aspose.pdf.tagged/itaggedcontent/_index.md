## ITaggedContent class

Stellt eine Schnittstelle für die Arbeit mit TaggedPdf‑Inhalt des Dokuments dar.

Der ITaggedContent-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| structure_text_state | Rufen Sie die [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) Einstellungen für das gesamte Dokument ab. |
| struct_tree_root_element | Liefert das [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/) des PDF-Dokuments. |
| root_element | Liefert das Wurzel-[StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) der logischen Struktur des PDF-Dokuments. |
