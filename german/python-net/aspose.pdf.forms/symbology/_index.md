## Symbology enumeration

Eine (Barcode) Symbologie definiert die technischen Details eines bestimmten Barcode-Typs:<br/>            die Breite der Balken, Zeichensatz, Kodierungsmethode, Prüfspezifikationen usw.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| PDF417 | Eine mehrzeilige, variabel lange 2D-Symbologie mit hoher Datenkapazität und Fehlerkorrekturfähigkeit. |
| QR_CODE | QR-Code (Kurzform für Quick Response) ist ein spezifischer Matrix-Barcode (2D-Code), <br/>            lesbar von speziellen QR-Barcode-Lesegeräten und Handykameras. |
| DATA_MATRIX | Eine 2D-Matrix-Symbologie, die aus schwarzen und weißen quadratischen Modulen besteht, die entweder in einem quadratischen oder <br/>            rechteckigen Muster angeordnet sind. |
