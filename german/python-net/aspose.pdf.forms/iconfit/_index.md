## IconFit class

Beschreibt, wie das Symbol der Widget‑Annotation innerhalb ihres Annotationsrechtecks angezeigt werden soll.

Der IconFit‑Typ stellt die folgenden Member bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| scaling_reason | Liest oder setzt den Skalierungsgrund. |
| scaling_mode | Der Typ der zu verwendenden Skalierung.        /// |
| leftover_left | Liest oder setzt den Raum, der links vom Symbol zugewiesen wird. |
| leftover_bottom | Liest oder setzt den Raum, der unten am Symbol zugewiesen wird. |
| spread_on_border | Wenn true, zeigt dies an, dass das Erscheinungsbild des Buttons vollständig innerhalb der Grenzen der Anmerkung skaliert werden soll, ohne die Linienbreite des Rahmens zu berücksichtigen. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| name_to_scaling_reason(reason) | Konvertiert den Namen des Skalierungsgrundes in ein ScalingReason‑Objekt. |
| scaling_reason_to_name(reason) | Konvertiert das Skalierungsgrund-Objekt in einen Namen. |
| name_to_scaling_mode(mode) | Konvertiert den Skalierungsmodusnamen in ein ScalingMode-Objekt. |
| scaling_mode_to_name(mode) | Konvertiert das Skalierungsmodus-Objekt in einen Namen. |
