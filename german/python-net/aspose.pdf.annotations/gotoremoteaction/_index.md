## GoToRemoteAction class

Stellt eine Remote‑Go-to‑Aktion dar, die einer normalen Go-to‑Aktion ähnelt, jedoch zu einem Ziel in einer anderen PDF‑Datei springt anstatt in der aktuellen Datei.

Der Typ GoToRemoteAction stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| GoToRemoteAction(remote_pdf, remote_page_number) | Initialisiert eine neue Instanz der Klasse GoToRemoteAction |
| GoToRemoteAction(remote_pdf, destination) | Initialisiert eine neue Instanz der Klasse GoToRemoteAction |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Weiter | Nächste Aktionen in der Reihenfolge. |
| destination | Liest oder setzt das Ziel, zu dem gesprungen werden soll. |
| file | Liest oder setzt die Angabe der Datei, in der das Ziel gespeichert ist. |
| new_window | Liest oder setzt ein Flag, das angibt, ob das Zieldokument in einem neuen Fenster geöffnet werden soll. |
