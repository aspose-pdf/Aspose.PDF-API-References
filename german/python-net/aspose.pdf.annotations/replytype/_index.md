## ReplyType enumeration

Enumeriert die Arten von Beziehungen (den „Antworttyp“) zwischen der Annotation und einer, die durch InReplyTo angegeben ist.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| UNDEFINIERT | Undefinierte Beziehung. |
| ANTWORT | Die Anmerkung wird als Antwort auf die durch InReplyTo angegebene Anmerkung betrachtet. Anzeigeanwendungen sollten Antworten auf eine Anmerkung nicht einzeln, sondern zusammen in Form von verschachtelten Kommentaren anzeigen. |
| GRUPPE | Die Anmerkung ist mit der durch InReplyTo angegebenen Anmerkung gruppiert. |
