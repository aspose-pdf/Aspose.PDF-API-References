## FitBExplicitDestination class

Stellt ein explizites Ziel dar, das die Seite mit ihrem Inhalt so vergrößert anzeigt, dass ihr Begrenzungsrahmen vollständig sowohl horizontal als auch vertikal in das Fenster passt. Wenn die erforderlichen horizontalen und vertikalen Vergrößerungsfaktoren unterschiedlich sind, wird der kleinere der beiden verwendet, wobei der Begrenzungsrahmen in der anderen Dimension im Fenster zentriert wird.
