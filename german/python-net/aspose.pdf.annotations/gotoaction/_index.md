## GoToAction class

Stellt eine Go-to-Aktion dar, die die Ansicht zu einem angegebenen Ziel (Seite, Position und Vergrößerungsfaktor) ändert.

Der GoToAction-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| GoToAction(page) | Initialisiert eine neue Instanz der GoToAction-Klasse |
| GoToAction(page) | Initialisiert eine neue Instanz der GoToAction-Klasse |
| GoToAction(page, type, values) | Initialisiert eine neue Instanz der GoToAction-Klasse |
| GoToAction(destination) | Initialisiert eine neue Instanz der GoToAction-Klasse |
| GoToAction() | Konstruktor. |
| GoToAction(doc, name) | Initialisiert eine neue Instanz der GoToAction-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Weiter | Nächste Aktionen in der Reihenfolge. |
| destination | Liest oder setzt das Ziel, zu dem gesprungen werden soll. |
