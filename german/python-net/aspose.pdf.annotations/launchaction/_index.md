## LaunchAction class

Stellt eine Start‑Aktion dar, die eine Anwendung startet oder ein Dokument öffnet bzw. druckt.

Der Typ LaunchAction stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| LaunchAction(file) | Initialisiert eine neue Instanz der Klasse LaunchAction |
| LaunchAction(document, file) | Initialisiert eine neue Instanz der Klasse LaunchAction |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Weiter | Nächste Aktionen in der Reihenfolge. |
| file | Liest oder setzt die Anwendung, die gestartet werden soll, oder das Dokument, das geöffnet oder gedruckt werden soll. |
| new_window | Liest oder setzt ein Flag, das angibt, ob das Ziel-Dokument in einem neuen Fenster geöffnet werden soll (betrifft nur PDF-Dokumente). |
