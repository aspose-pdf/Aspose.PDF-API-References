## SubmitFormAction class

Klasse, die die Aktion eines Submit-Formulars beschreibt.

Der SubmitFormAction‑Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| SubmitFormAction() | Initialisiert ein SubmitFormAction‑Objekt. |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Weiter | Nächste Aktionen in der Reihenfolge. |
| flaggen | Liest oder setzt Flags der Submit‑Aktion |
| url | Ziel‑URL. |
| EXCLUDE | Wenn nicht gesetzt, gibt das Fields‑Array an, welche Felder in die Übermittlung einbezogen werden sollen. |
| INCLUDE_NO_VALUE_FIELDS | Wenn gesetzt, werden alle durch das Fields‑Array und das Include/Exclude‑Flag bezeichneten Felder übermittelt. |
| EXPORT_FORMAT | Falls gesetzt, werden Feldnamen und Werte im HTML-Formularformat übermittelt. |
| GET_METHOD | Falls gesetzt, werden Feldnamen und Werte mittels einer HTTP-GET-Anfrage übermittelt. |
| SUBMIT_COORDINATES | Falls gesetzt, werden die Koordinaten des Mausklicks, der die Submit-Form-Aktion ausgelöst hat, als Teil der Formulardaten übertragen. |
| XFDF | Falls gesetzt, werden Feldnamen und Werte als XFDF übermittelt. |
| INCLUDE_APPEND_SAVES | Falls gesetzt, enthält die übermittelte FDF-Datei die Inhalte aller inkrementellen Updates. |
| INCLUDE_ANNOTATIONS | Falls gesetzt, enthält die übermittelte FDF-Datei alle Markup-Anmerkungen im zugrunde liegenden PDF-Dokument. |
| SUBMIT_PDF | Falls gesetzt, wird das Dokument als PDF übermittelt, wobei der MIME-Typ application/pdf verwendet wird. |
| CANONICAL_FORMAT | Falls gesetzt, werden übermittelte Feldwerte, die Daten darstellen, in das Standardformat konvertiert. |
| EXCL_NON_USER_ANNOTS | Falls gesetzt, werden nur jene Markup-Anmerkungen einbezogen, deren T-Eintrag mit dem Namen des aktuellen Benutzers übereinstimmt. |
| EXCL_F_KEY | Falls gesetzt, wird der F-Eintrag aus der übermittelten FDF ausgeschlossen. |
| EMBED_FORM | Falls gesetzt, ist der F-Eintrag der übermittelten FDF eine Dateispezifikation, die einen <br/>            eingebetteten Dateistream enthält, der die PDF-Datei repräsentiert, aus der die FDF übermittelt wird. |
