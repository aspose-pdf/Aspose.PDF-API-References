## TextStyle class

Klasse, die den Stil von Text in einer Annotation darstellt

Der TextStyle-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| font_name | Name der Schriftart. |
| font_size | Schriftgröße. |
| ausrichtung | Liest oder setzt die horizontale Ausrichtung des Textes. |
| horizontal_alignment | Textausrichtung. Gültige Werte sind: Links, Zentriert, Rechts. |
| farbe | Farbe des Textes. |
