## LineEnding enumeration

Enumeriert die Linienendungsstile, die beim Zeichnen der Linie verwendet werden.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| NONE | Kein Zeilenende. |
| SQUARE | Ein Quadrat, das mit der Innenfarbe der Annotation gefüllt ist, falls vorhanden. |
| CIRCLE | Ein Kreis, der mit der Innenfarbe der Annotation gefüllt ist, falls vorhanden. |
| DIAMOND | Eine Raute, die mit der Innenfarbe der Annotation gefüllt ist, falls vorhanden. |
| OPEN_ARROW | Zwei kurze Linien, die in einem spitzen Winkel zusammentreffen, um eine offene Pfeilspitze zu bilden. |
| CLOSED_ARROW | Zwei kurze Linien, die in einem spitzen Winkel wie beim OpenArrow-Stil zusammentreffen und durch eine dritte Linie verbunden sind, um eine dreieckige geschlossene Pfeilspitze zu bilden, die mit der Innenfarbe der Annotation gefüllt ist, falls vorhanden. |
| BUTT | Eine kurze Linie am Endpunkt, die senkrecht zur Linie selbst steht. |
| R_OPEN_ARROW | Zwei kurze Linien in die entgegengesetzte Richtung von OpenArrow. |
| R_CLOSED_ARROW | Eine dreieckige geschlossene Pfeilspitze in die entgegengesetzte Richtung von ClosedArrow. |
| SLASH | Eine kurze Linie am Endpunkt, etwa 30 Grad im Uhrzeigersinn von der Senkrechten zur Linie selbst. |
