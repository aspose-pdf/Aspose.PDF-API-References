## AnnotationActionCollection class

Stellt die Sammlung von Annotationsaktionen dar.

Der Typ AnnotationActionCollection stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| on_enter | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn der Cursor den aktiven Bereich der Anmerkung betritt. |
| on_exit | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn der Cursor den aktiven Bereich der Anmerkung verlässt. |
| on_press_mouse_btn | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn die Maustaste innerhalb des aktiven Bereichs der Anmerkung gedrückt wird. |
| on_release_mouse_btn | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn die Maustaste innerhalb des aktiven Bereichs der Anmerkung losgelassen wird. |
| on_receive_focus | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn die Anmerkung den Eingabefokus erhält. |
| on_open_page | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn die Seite, die die Anmerkung enthält, geöffnet wird. |
| on_close_page | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn die Seite, die die Anmerkung enthält, geschlossen wird. |
| on_show_page | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn die Seite, die die Anmerkung enthält, in der Benutzeroberfläche der Viewer-Anwendung sichtbar wird. |
| on_hide_page | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn die Seite, die die Anmerkung enthält, in der Benutzeroberfläche der Viewer-Anwendung nicht mehr sichtbar ist. |
| on_lost_focus | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn die Anmerkung den Eingabefokus verliert. |
| on_modify_character | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn der Benutzer ein Zeichen des Feldes ändert. |
| on_validate | Liest oder legt eine Aktion fest, die ausgeführt wird, wenn der Benutzer den Inhalt des Feldes ändert. |
| on_format | Liest oder setzt eine Aktion, die zur Formatierung des Feldwerts ausgeführt wird. |
| on_calculate | Liest oder setzt eine Aktion, die den Feldwert berechnet. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| remove_actions() | Entfernt alle Aktionen der Anmerkung. |
