## FitHExplicitDestination class

Stellt ein explizites Ziel dar, das die Seite mit der vertikalen Koordinate top am oberen Rand des Fensters positioniert und den Seiteninhalt so vergrößert, dass die gesamte Breite der Seite in das Fenster passt. Ein Nullwert für top gibt an, dass der aktuelle Wert dieses Parameters unverändert beibehalten wird.

Der FitHExplicitDestination-Typ stellt die folgenden Mitglieder bereit:

| :- | :- |

| FitHExplicitDestination(document, page_number, top) | Initialisiert eine neue Instanz der FitHExplicitDestination-Klasse |
| FitHExplicitDestination(page_number, top) | Initialisiert eine neue Instanz der FitHExplicitDestination-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |

| page_number | Liefert die Zielseitennummer |
| top | Gibt die vertikale Koordinate top zurück, die am oberen Rand des Fensters positioniert ist. |
