## AnnotationState enumeration

Die Aufzählung der Zustände, auf die die ursprüngliche Annotation gesetzt werden kann.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| UNDEFINIERT | Nicht definierter Zustand. |
| MARKED | Die Anmerkung wurde vom Benutzer markiert. |
| UNMARKED | Die Anmerkung wurde vom Benutzer nicht markiert. |
| ACCEPTED | Der Benutzer stimmt der Änderung zu. |
| REJECTED | Der Benutzer stimmt der Änderung nicht zu. |
| CANCELLED | Die Änderung wurde storniert. |
| COMPLETED | Die Änderung wurde abgeschlossen. |
| NONE | Der Benutzer hat nichts zur Änderung angegeben. |
