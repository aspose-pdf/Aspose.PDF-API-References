## Measure class

Klasse, die das Mess‑Koordinatensystem beschreibt.

Der Typ Measure stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Measure(annotation) | Initialisiert eine neue Instanz der Klasse Measure |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| scale_ratio | Eine Textzeichenfolge, die das Maßstabsverhältnis der Zeichnung ausdrückt. |
| x_format | Ein Zahlenformat-Array zur Messung von Änderungen entlang der x-Achse und, falls Y nicht vorhanden ist, ebenfalls entlang der y-Achse. |
| y_format | Ein Zahlenformat-Array zur Messung von Änderungen entlang der y-Achse. |
| distance_format | Ein Zahlenformat-Array zur Messung von Entfernungen in beliebiger Richtung. |
| area_format | Ein Zahlenformat-Array zur Messung von Flächen. |
| angle_format | Ein Zahlenformat-Array zur Messung von Winkeln. |
| slope_format | Ein Zahlenformat-Array zur Messung der Steigung einer Linie. |
| origin | Punkt, der den Ursprung des Messkoordinatensystems in den Standard‑Benutzer‑Raum‑Koordinaten festlegt. |
| xy_factor | Ein Faktor, der verwendet werden soll, um die größten Einheiten entlang der y-Achse in die größten Einheiten entlang der x-Achse umzuwandeln. |
