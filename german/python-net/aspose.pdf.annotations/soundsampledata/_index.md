## SoundSampleData class

Stellt zusätzliche Einträge dar, die spezifisch für ein Sound-Objekt sind (Abschnitt 9.2 PDF1-7).

Der Typ SoundSampleData stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| SoundSampleData(sampling_rate) | Initialisiert eine neue Instanz der Klasse SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels) | Initialisiert eine neue Instanz der Klasse SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel) | Initialisiert eine neue Instanz der Klasse SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel, sound_sample_data_encoding_format) | Initialisiert eine neue Instanz der Klasse SoundSampleData |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| sampling_rate | Liest oder setzt die Abtastrate. |
| number_of_sound_channels | Ruft die Anzahl der Soundkanäle ab oder legt sie fest. |
| bits_per_channel | Ruft die Anzahl der Bits pro Samplewert pro Kanal ab oder legt sie fest. |
| encoding_format | Liest oder setzt das Kodierungsformat. |
| DEFAULT_SAMPLING_RATE | Standardwert für SamplingRate. |
| DEFAULT_OF_SOUND_CHANNELS | Standardwert für den Parameter Channels. |
| DEFAULT_OF_BITS_PER_CHANNEL | Standardwert für den Parameter BitsPerchannel. |
| DEFAULT_ENCODING_FORMAT | Standardwert für das Kodierungsformat. |
