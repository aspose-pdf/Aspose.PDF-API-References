## SoundData class

Stellt Sound-Daten dar, die den abzuspielenden Klang definieren, wenn die Anmerkung aktiviert wird.

Der SoundData-Typ stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| rate | Ruft die Abtastrate ab oder legt sie fest, in Samples pro Sekunde. |
| channels | Ruft die Anzahl der Soundkanäle ab oder legt sie fest. |
| bits | Ruft die Anzahl der Bits pro Samplewert pro Kanal ab oder legt sie fest. |
| inhalt | Ruft den Stream des abzuspielenden Sounds ab, wenn die Anmerkung aktiviert wird. |
| encoding | Ruft das Kodierungsformat für die Sample-Daten ab oder legt es fest. |
