## HideAction class

Stellt eine Versteck‑Aktion dar, die eine oder mehrere Anmerkungen auf dem Bildschirm ausblendet oder einblendet, indem deren Hidden‑Flag gesetzt oder gelöscht wird.

Der HideAction-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| HideAction(annotation) | Initialisiert eine neue Instanz der HideAction-Klasse |
| HideAction(annotation, is_hidden) | Initialisiert eine neue Instanz der HideAction-Klasse |
| HideAction(field_name) | Initialisiert eine neue Instanz der HideAction-Klasse |
| HideAction(field_name, is_hidden) | Initialisiert eine neue Instanz der HideAction-Klasse |
| HideAction(annotations) | Initialisiert eine neue Instanz der HideAction-Klasse |
| HideAction(annotations, is_hidden) | Initialisiert eine neue Instanz der HideAction-Klasse |
| HideAction(names) | Initialisiert eine neue Instanz der HideAction-Klasse |
| HideAction(names, is_hidden) | Initialisiert eine neue Instanz der HideAction-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Weiter | Nächste Aktionen in der Reihenfolge. |
| is_hidden | Liest oder setzt den Status der Annotation(en), die ausgeblendet/angezeigt werden sollen. |
