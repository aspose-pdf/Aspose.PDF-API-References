## DocumentActionCollection class

Klasse beschreibt Aktionen, die an einigen Aktionen mit dem Dokument durchgeführt werden.

Der Typ DocumentActionCollection stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| DocumentActionCollection(document) | Initialisiert eine neue Instanz der Klasse DocumentActionCollection |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| before_saving | Liest oder legt die vor dem Speichern des Dokuments ausgeführte Aktion fest. |
| before_closing | Liest oder legt die Aktion fest, die vor dem Schließen des Dokuments ausgeführt wird. |
| after_saving | Liest oder legt die nach dem Speichern des Dokuments ausgeführte Aktion fest. |
| before_printing | Aktion, die vor dem Drucken des Dokuments ausgeführt wird. |
| after_printing | Aktion, die nach dem Drucken des Dokuments ausgeführt wird. |
