## HighlightingMode enumeration

Enumeriert den Hervorhebungsmodus der Annotation, den visuellen Effekt, der verwendet wird, wenn die Maustaste innerhalb ihres aktiven Bereichs gedrückt oder gehalten wird.

## Members
| Member-Name | Beschreibung |
| :- | :- |
| NONE | Keine Hervorhebung. |
| INVERT | Kehrt den Inhalt des Anmerkungsrechtecks um. |
| OUTLINE | Kehrt die Grenze der Anmerkung um. |
| PUSH | Zeigt das unten‑Aussehen der Anmerkung an, falls vorhanden. Wenn kein unten‑Aussehen definiert ist, wird der Inhalt des Anmerkungsrechtecks versetzt, sodass es aussieht, als würde es unter die Seitenoberfläche geschoben werden. |
| TOGGLE | Dasselbe wie Push (was bevorzugt wird). |
