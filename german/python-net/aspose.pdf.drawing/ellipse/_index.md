## Ellipse class

Stellt eine Ellipse dar.

Der Ellipse-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Ellipse(left, bottom, width, height) | Initialisiert eine neue Instanz der Ellipse-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| graph_info | Liest oder setzt ein [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) Objekt, das die Graph-Informationen angibt, wie Farbe,<br/>            Linienstärke usw. |
| text | Liest oder setzt einen Text für die Form |
| left | Liest oder setzt einen Float-Wert, der die linke Position der Ellipse angibt. |
| bottom | Liest oder setzt einen Float-Wert, der die untere Position der Ellipse angibt. |
| breite | Liest oder setzt einen Float-Wert, der die Breite der Ellipse angibt. |
| höhe | Liest oder setzt einen Float-Wert, der die Höhe der Ellipse angibt. |
