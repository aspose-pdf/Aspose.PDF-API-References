## Rectangle class

Stellt ein Rechteck dar.

Der Typ Rectangle stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Rectangle(left, bottom, width, height) | Initialisiert eine neue Instanz der Klasse Rectangle |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| graph_info | Liest oder setzt ein [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) Objekt, das die Graph-Informationen angibt, wie Farbe,<br/>            Linienstärke usw. |
| text | Liest oder setzt einen Text für die Form |
| rounded_corner_radius | Liest oder setzt einen Float-Wert, der den Radius der Rechteck-Ecken angibt. |
| left | Liest oder setzt einen Float-Wert, der die linke Position des Rechtecks angibt. |
| bottom | Liest oder setzt einen Float-Wert, der die untere Position des Rechtecks angibt. |
| breite | Liest oder setzt einen float-Wert, der die Breite des Rechtecks angibt. |
| höhe | Liest oder setzt einen float-Wert, der die Höhe des Rechtecks angibt. |
