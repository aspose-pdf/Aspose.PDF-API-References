## Arc class

Stellt einen Bogen dar.

Der Arc-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Initialisiert eine neue Instanz der Arc-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| graph_info | Liest oder setzt ein [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) Objekt, das die Graph-Informationen angibt, wie Farbe,<br/>            Linienstärke usw. |
| text | Liest oder setzt einen Text für die Form |
| pos_x | Liest oder setzt einen float-Wert, der die x-Koordinate des Mittelpunktes des Bogens angibt. |
| pos_y | Liest oder setzt einen float-Wert, der die y-Koordinate des Mittelpunktes des Bogens angibt. |
| radius | Liest oder setzt einen float-Wert, der den Radius des Bogens angibt. |
| alpha | Liest oder setzt einen float-Wert, der den Anfangswinkelgrad des Bogens angibt. |
| beta | Liest oder setzt einen float-Wert, der den Endwinkelgrad des Bogens angibt. |
