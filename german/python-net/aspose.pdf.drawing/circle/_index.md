## Circle class

Stellt einen Kreis dar.

Der Circle-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Circle(pos_x, pos_y, radius) | Initialisiert eine neue Instanz der Circle-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| graph_info | Liest oder setzt ein [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) Objekt, das die Graph-Informationen angibt, wie Farbe,<br/>            Linienstärke usw. |
| text | Liest oder setzt einen Text für die Form |
| pos_x | Liest oder setzt einen float-Wert, der die x-Koordinate des Kreismittelpunkts angibt. |
| pos_y | Liest oder setzt einen float-Wert, der die y-Koordinate des Kreismittelpunkts angibt. |
| radius | Liest oder setzt einen float-Wert, der den Radius des Kreises angibt. |
