## Do class

Klasse, die den Do-Operator repräsentiert (XObject aufrufen).

Der Typ Do stellt die folgenden Mitglieder bereit:

| Name | Beschreibung |
| :- | :- |
| Do(name) | Initialisiert eine neue Instanz der Klasse Do |
| Do() | Konstruiert einen neuen Do-Operator. <br/>            Wird verwendet, um alle Do-Operatoren abzurufen, d. h. ohne die Namen ihrer Argumente zu prüfen. |
