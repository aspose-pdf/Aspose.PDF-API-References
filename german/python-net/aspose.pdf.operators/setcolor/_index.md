## SetColor class

Stellt Klasse für den sc-Operator dar (Farbe für nicht-strichbasierte Operationen setzen).

Der SetColor-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| SetColor() | Initialisiert den Operator. |
| SetColor(g) | Initialisiert eine neue Instanz der SetColor-Klasse |
| SetColor(r, g, b) | Initialisiert eine neue Instanz der SetColor-Klasse |
| SetColor(c, m, y, k) | Initialisiert eine neue Instanz der SetColor-Klasse |
| SetColor(color) | Initialisiert eine neue Instanz der SetColor-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Index | Keine |
| r | Liest die rote Komponente der Farbe. |
| g | Liest die grüne Komponente der Farbe. |
| b | Liest die rote Komponente der Farbe. |
| c | Liest die Cyan‑Komponente der CMYK-Farbe. |
| m | Liest die Magenta‑Komponente der CMYK-Farbe. |
| y | Liest die Gelb‑Komponente der CMYK-Farbe. |
| k | Liest die Schwarz‑Komponente der CMYK-Farbe. |
| grey | Liest die Schwarz‑Komponente der Graufarbe. |
| farbe | Liest ein Array von Farbkomponenten. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| accept(visitor) | Akzeptiert ein Besucherobjekt, um den Operator zu verarbeiten. |
| is_text_show_operator(op) | Keine |
| get_color() | Gibt die vom Operator angegebene Farbe zurück. |
