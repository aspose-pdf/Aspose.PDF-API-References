## Re class

Klasse, die den re-Operator darstellt (Rechteck zum Pfad hinzufügen).

Der Re-Typ stellt die folgenden Mitglieder bereit:
## Konstruktoren
| Name | Beschreibung |
| :- | :- |
| Re() | Initialisiert den Operator. |
| Re(x, y, width, height) | Initialisiert eine neue Instanz der Re-Klasse |
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| Index | Operatorindex in der Liste der Seitenoperatoren. |
| x | X-Koordinate der linken Seite des Rechtecks. |
| y | Y-Koordinate der unteren Seite des Rechtecks. |
| breite | Breite des Rechtecks. |
| höhe | Höhe des Rechtecks. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| accept(visitor) | Akzeptiert ein Besucherobjekt, um den Operator zu verarbeiten. |
