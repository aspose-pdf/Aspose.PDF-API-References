## StructElement class

Allgemeines Strukturelement.

Der Typ StructElement stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| children | Ruft die Sammlung der Kindelemente ab. |
| lang | (Optional; PDF 1.4) Eine Sprache, die die natürliche Sprache für allen Text<br/> im Strukturelement angibt, außer dort, wo sie durch Sprachspezifikationen für verschachtelte Strukturelemente<br/> oder markierten Inhalt überschrieben wird. |
| actual_text | (Optional; PDF 1.4) Text, der eine exakte Ersetzung für das Strukturelement und seine Kinder darstellt.<br/> Dieser Ersetzungstext (der so klein wie möglich angewendet werden sollte)<br/> ist nützlich beim Extrahieren des Dokumentinhalts zur Unterstützung der Barrierefreiheit für Nutzer<br/> mit Behinderungen oder für andere Zwecke. |
| alt | (Optional) Eine alternative Beschreibung des Strukturelements und seiner Kinder in<br/> menschenlesbarer Form, die nützlich ist beim Extrahieren des Dokumentinhalts zur Unterstützung<br/> der Barrierefreiheit für Nutzer mit Behinderungen oder für andere Zwecke. |
| e | (Optional; PDF 1.5) Die ausgeschriebene Form einer Abkürzung. |
