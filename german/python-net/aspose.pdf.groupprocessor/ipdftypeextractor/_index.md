## IPdfTypeExtractor class

Stellt eine Schnittstelle zur Interaktion mit dem Extraktor dar.

Der Typ IPdfTypeExtractor stellt die folgenden Mitglieder bereit:
## Eigenschaften
| Name | Beschreibung |
| :- | :- |
| page_count | Gibt die Seitenanzahl zurück. |
| version | Gibt die Version zurück. |
| is_fast_extraction_used | Gibt zurück, ob der schnelle Extraktionsmechanismus verwendet wurde. |
## Methoden
| Name | Beschreibung |
| :- | :- |
| extract_all_text() | Gibt eine Sammlung der extrahierten Textwerte zurück. |
| extract_page_text(page_number) | Gibt den Text der Seite zurück. |
| dispose() | Freigeben. |
