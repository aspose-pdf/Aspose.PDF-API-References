## Security PDF functions

| Name | Beschreibung |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | Eine PDF-Datei verschlüsseln. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | Eine PDF-Datei entschlüsseln. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | Eine PDF-Datei mit digitalen Signaturen signieren. |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | Eine PDF-Datei mit losgelösten digitalen Signaturen signieren. |
| [AsposePdfChangePassword](./asposepdfchangepassword/) | Passwörter der PDF-Datei ändern. |

## Detailed Description

Funktionen zum Arbeiten mit Sicherheitsmerkmalen von PDF-Dateien.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
oder
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
