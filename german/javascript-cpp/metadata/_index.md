## Metadata PDF functions

| Name | Beschreibung |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | Informationen (Metadaten) in einer PDF-Datei festlegen. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | Informationen (Metadaten) aus einer PDF-Datei abrufen. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | Liste der Schriftarten aus einer PDF-Datei abrufen. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | Metadaten aus einer PDF-Datei entfernen. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | Wort- und Zeichenanzahl in einer PDF-Datei ermitteln. |
| [AsposePdfGetPagesLayers](./asposepdfgetpageslayers/) | Liste der Ebenen aus einer PDF-Datei abrufen. |


## Detailed Description

Funktionen zum Arbeiten mit Metadaten-PDF-Dateien.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
oder

<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
