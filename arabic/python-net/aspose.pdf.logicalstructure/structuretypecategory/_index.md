## StructureTypeCategory class

يمثل فئات أنواع البنية القياسية.

يعرض نوع StructureTypeCategory الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| GROUPING_ELEMENTS | تقوم عناصر التجميع بتجميع عناصر أخرى في تسلسلات أو هياكل شجرية لكنها لا تحتفظ بالمحتوى مباشرة ولا تؤثر مباشرة على التخطيط. |
| BLS_ES | العناصر الهيكلية على مستوى الكتلة (BLSEs) تصف التخطيط العام للمحتوى على الصفحة، مع التقدم في اتجاه تقدم الكتلة. |
| ILS_ES | العناصر الهيكلية على مستوى السطر (ILSEs) تصف تخطيط المحتوى داخل BLSE، مع التقدم في اتجاه تقدم السطر. |
| ILLUSTRATION_ELEMENTS | عناصر التوضيح هي تسلسلات مدمجة من المحتوى، وفق ترتيب محتوى الصفحة، وتُعتبر ككائنات موحدة بالنسبة لتخطيط الصفحة. يمكن التعامل مع التوضيح إما كـ BLSE أو كـ ILSE. |
