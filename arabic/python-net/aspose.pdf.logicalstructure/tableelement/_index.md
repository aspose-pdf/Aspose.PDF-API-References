| expansion_text | يحصل أو يعيّن نص التوسيع لعنصر البنية. |

| الحد | يحصل أو يضبط حدود الجدول. |

| default_cell_border | يحصل على حد الخلية الافتراضي. |
| default_cell_padding | يحصل أو يضبط حشو الخلية الافتراضي. |
| default_cell_text_state | يحصل أو يضبط حالة نص الخلية الافتراضية. |
| default_column_width | يحصل أو يضبط عرض العمود الافتراضي. |
| is_broken | يحصل أو يضبط ما إذا كان الجدول مكسورًا - سيتم تقصيره للصفحة التالية. |
| is_borders_included | يحصل أو يضبط تضمين الحدود في عرض الأعمدة. |
| left | يحصل أو يضبط إحداثي اليسار للجدول. |
| top | يحصل أو يضبط إحداثي أعلى الجدول. |
| repeating_columns_count | يحصل أو يضبط الحد الأقصى لعدد الأعمدة للجدول. |
| repeating_rows_count | يحصل على عدد الصفوف الأولى المتكررة لعدة صفحات. |
| repeating_rows_style | يحصل على النمط للصفوف المتكررة. |
