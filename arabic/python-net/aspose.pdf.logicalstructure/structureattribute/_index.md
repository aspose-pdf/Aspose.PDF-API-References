## StructureAttribute class

يمثل سمة عنصر البنية.

نوع StructureAttribute يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| StructureAttribute(attribute_key) | ينشئ مثلاً جديداً من الفئة StructureAttribute |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| key | يحصل على مفتاح السمة. |
| is_initialized_value | يحصل على حالة قيمة سمة البنية. صحيح إذا تم تعيين القيمة. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| get_name_value() | يحصل على اسم القيمة. |
| get_string_value() | يحصل على سلسلة القيمة. |
| get_number_value() | يحصل على رقم القيمة. |
| get_array_value() | يحصل على مصفوفة أسماء القيم. |
| get_array_number_value() | يحصل على مصفوفة أرقام القيم. |
| set_name_value(name) | يضبط اسم القيمة. |
| set_string_value(value) | يضبط سلسلة القيمة. |
| set_number_value(number) | يضبط رقم القيمة. |
| set_array_value(array) | يضبط مصفوفة أسماء القيم. |
| set_array_number_value(array_number) | يضبط مصفوفة أرقام القيم. |
| set_color_value(color) | يضبط لون القيمة. |
| set_rectangle_value(rectangle) | يضبط مستطيل القيمة. |
