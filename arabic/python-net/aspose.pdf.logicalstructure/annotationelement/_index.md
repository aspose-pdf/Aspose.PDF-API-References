## AnnotationElement class

يمثل فئة أساسية لعناصر بنية التعليقات التوضيحية في البنية المنطقية.

يعرض نوع AnnotationElement الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| parent_element | لا شيء |
| child_elements | لا شيء |
| default_attribute_owner | يحصل |
| attributes | يحصل |
| structure_type | يحصل على نوع عنصر البنية. |
| id | يحصل على المعرف لعنصر البنية. |
| title | يحصل أو يضبط العنوان لعنصر البنية. |
| language | يحصل أو يعيّن اللغة لعنصر البنية. |
| alternative_text | يحصل أو يعيّن النص البديل لعنصر البنية. |
| expansion_text | يحصل أو يعيّن نص التوسيع لعنصر البنية. |
| actual_text | يحصل أو يعيّن النص الفعلي لعنصر البنية. |
| alternate_descriptions | يحصل أو يعيّن أوصاف بديلة للتعليق.<br/>                النص الذي يجب عرضه للتعليق أو، إذا كان هذا النوع من التعليقات لا يعرض نصًا، وصف بديل لمحتويات التعليق بصيغة قابلة للقراءة البشرية. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| append_child(element) | لا شيء |
| change_parent_element(new_parent_element) | تغيير عنصر الأب للعنصر البنائي الحالي |
| generate_id() | إنشاء معرف لعنصر البنية. |
| set_id(id) | يعيّن المعرف لعنصر البنية. |
| clear_id() | مسح المعرف لعنصر البنية. |
| set_tag(new_tag) | يعيّن علامة مخصصة لعنصر البنية. |
