## StructureTextState class

يمثل إعدادات حالة النص لعناصر بنية النص والمحتوى الموسوم (ITextElement, ITaggedContent).

يعرض نوع StructureTextState الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| font | يحصل أو يضبط خط النص. |
| font_size | يحصل أو يضبط حجم الخط في النص. |
| font_style | يحصل أو يضبط نمط خط النص. |
| foreground_color | يحصل أو يضبط لون المقدمة للنص. |
| background_color | يحصل أو يضبط لون خلفية النص. |
| underline | يحصل أو يضبط underline للنص. |
| strike_out | يحصل أو يضبط strikeout للنص. |
| superscript | يحصل أو يضبط النص كحرف علوي. |
| subscript | يحصل أو يضبط النص كحرف سفلي. |
| horizontal_scaling | يحصل أو يضبط التحجيم الأفقي للنص. |
| line_spacing | يحصل أو يضبط تباعد الأسطر في النص. |
| character_spacing | يحصل أو يضبط تباعد الأحرف في النص. |
| word_spacing | يحصل أو يضبط تباعد الكلمات في النص. |
| margin_info | يحصل أو يضبط margin لعنصر بنية الكتلة. |
