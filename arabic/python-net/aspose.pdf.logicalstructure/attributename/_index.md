## AttributeName class

يمثل فئة لقيم أسماء السمات.

يعرض نوع AttributeName الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| name | يحصل على قيمة الاسم للخاصية. |
| attribute_key | يحصل على مفتاح السمة. |
| PLACEMENT_BLOCK | وضع الخاصية: كتلة - مكدسة في اتجاه تقدم الكتلة داخل مساحة مرجعية محيطة أو BLSE الأب. |
| PLACEMENT_INLINE | وضع الخاصية: ضمن السطر - محزمة في اتجاه تقدم السطر داخل BLSE محيط. |
| PLACEMENT_BEFORE | وضع الخاصية: قبل - موضوعة بحيث يتطابق الحافة الأمامية لمستطيل تخصيص العنصر مع تلك الخاصة بأقرب مساحة مرجعية محيطة. |
| PLACEMENT_START | وضع الخاصية: بداية - موضوعة بحيث يتطابق حافة البداية لمستطيل تخصيص العنصر مع تلك الخاصة بأقرب مساحة مرجعية محيطة. |
| PLACEMENT_END | وضع الخاصية: نهاية - موضوعة بحيث يتطابق حافة النهاية لمستطيل تخصيص العنصر مع تلك الخاصة بأقرب مساحة مرجعية محيطة. |
| WRITING_MODE_LR_TB | وضع الكتابة للخاصية: LrTb - تقدم داخل السطر من اليسار إلى اليمين؛ تقدم الكتلة من الأعلى إلى الأسفل. هذا هو وضع الكتابة النموذجي للأنظمة الكتابية الغربية. |
| WRITING_MODE_RL_TB | وضع الكتابة للخاصية: RlTb - تقدم داخل السطر من اليمين إلى اليسار؛ تقدم الكتلة من الأعلى إلى الأسفل. هذا هو وضع الكتابة النموذجي للأنظمة الكتابية العربية والعبرية. |
| WRITING_MODE_TB_RL | وضع الكتابة للخاصية: TbRl - تقدم داخل السطر من الأعلى إلى الأسفل؛ تقدم الكتلة من اليمين إلى اليسار. هذا هو وضع الكتابة النموذجي للأنظمة الكتابية الصينية واليابانية. |
| BORDER_STYLE_NONE | نمط حدود الخاصية: لا شيء - لا حدود. يجبر القيمة المحسوبة لـ BorderThicknessto أن تكون 0. |
| BORDER_STYLE_HIDDEN | نمط حدود الخاصية: مخفي - نفس لا شيء، باستثناء حل تعارض الحدود لعناصر الجدول. |
| BORDER_STYLE_DOTTED | نمط حدود الخاصية: منقط - الحد هو سلسلة من النقاط. |
| BORDER_STYLE_DASHED | Attribute BorderStyle: Dashed - الحد هو سلسلة من مقاطع الخط القصيرة. |
| BORDER_STYLE_SOLID | Attribute BorderStyle: Solid - الحد هو مقطع خط واحد. |
| BORDER_STYLE_DOUBLE | Attribute BorderStyle: Double - الحد هو خطان صلبان. مجموع الخطين والمسافة بينهما يساوي قيمة BorderThickness. |
| BORDER_STYLE_GROOVE | Attribute BorderStyle: Groove - يبدو الحد كما لو أنه محفور في القماش. |
| BORDER_STYLE_RIDGE | Attribute BorderStyle: Ridge - يبدو الحد كما لو أنه يخرج من القماش (العكس من Groove). |
| BORDER_STYLE_INSET | Attribute BorderStyle: Inset - يجعل الحد الصندوق بالكامل يبدو كما لو أنه مدمج في القماش. |
| BORDER_STYLE_OUTSET | Attribute BorderStyle: Outset - يجعل الحد الصندوق بالكامل يبدو كما لو أنه يخرج من القماش (العكس من Inset). |
| TEXT_ALIGN_START | Attribute TextAlign: Start - محاذاة مع الحافة البداية. |
| TEXT_ALIGN_CENTER | Attribute TextAlign: Center - تمركز بين حافتي البداية والنهاية. |
| TEXT_ALIGN_END | Attribute TextAlign: End - محاذاة مع الحافة النهاية. |
| TEXT_ALIGN_JUSTIFY | Attribute TextAlign: Justify - محاذاة مع كل من الحافتين البداية والنهاية، مع توسيع المسافات الداخلية داخل كل سطر إذا لزم الأمر لتحقيق هذه المحاذاة. السطر الأخير (أو الوحيد) يجب أن يكون محاذيًا مع الحافة البداية فقط. |
| WIDTH_AUTO | Attribute Width: Auto - سيتم تحديد عرض العنصر بناءً على العرض الداخلي لمحتواه. |
| HEIGHT_AUTO | Attribute Height: Auto - سيتم تحديد ارتفاع العنصر بناءً على الارتفاع الداخلي لمحتواه. |
| BLOCK_ALIGN_BEFORE | Attribute BlockAlign: Before - حافة البداية لمستطيل تخصيص الطفل الأول محاذاة مع مستطيل محتوى خلية الجدول. |
| BLOCK_ALIGN_MIDDLE | السمة BlockAlign: Middle- الأطفال متمركزون داخل خلية الجدول. يجب أن تكون المسافة بين الحافة السابقة لمستطيل تخصيص الطفل الأول وتلك الخاصة بمستطيل محتوى خلية الجدول هي نفسها المسافة بين الحافة اللاحقة لمستطيل تخصيص الطفل الأخير وتلك الخاصة بمستطيل محتوى خلية الجدول. |
| BLOCK_ALIGN_AFTER | السمة BlockAlign: After - الحافة اللاحقة لمستطيل تخصيص الطفل الأخير محاذاة مع تلك الخاصة بمستطيل محتوى خلية الجدول. |
| BLOCK_ALIGN_JUSTIFY | السمة BlockAlign: Justify - الأطفال محاذون مع كل من الحافتين السابقة واللاحقة لمستطيل محتوى خلية الجدول. يجب وضع الطفل الأول كما هو موضح للـ Before والطفل الأخير كما هو موضح للـ After، مع تساوي المسافات بين الأطفال. إذا كان هناك طفل واحد فقط، فسيتم محاذاته مع الحافة السابقة فقط، كما في Before. |
| INLINE_ALIGN_START | السمة InlineAlign: Start - الحافة البداية لمستطيل تخصيص كل طفل محاذاة مع تلك الخاصة بمستطيل محتوى خلية الجدول. |
| INLINE_ALIGN_CENTER | السمة InlineAlign: Center - كل طفل متمركز داخل خلية الجدول. يجب أن تكون المسافة بين حواف البداية لمستطيل تخصيص الطفل ومستطيل محتوى خلية الجدول هي نفسها المسافة بين حواف النهاية. |
| INLINE_ALIGN_END | السمة InlineAlign: End - الحافة النهائية لمستطيل تخصيص كل طفل محاذاة مع تلك الخاصة بمستطيل محتوى خلية الجدول. |
| LINE_HEIGHT_NORMAL | السمة LineHeight: Normal - ضبط ارتفاع السطر لتضمين أي قيمة غير صفرية محددة لـ BaselineShift. |
| LINE_HEIGHT_AUTO | السمة LineHeight: Auto - لا يتم تعديل قيمة BaselineShift. |
| TEXT_DECORATION_TYPE_NONE | السمة TextDecorationType: None - لا توجد زخرفة للنص. |
| TEXT_DECORATION_TYPE_UNDERLINE | السمة TextDecorationType: Underline - خط تحت النص. |
| TEXT_DECORATION_TYPE_OVERLINE | السمة TextDecorationType: Overline - خط فوق النص. |
| TEXT_DECORATION_TYPE_LINE_THROUGH | السمة TextDecorationType: LineThrough - خط يمر عبر وسط النص. |
| RUBY_ALIGN_START | السمة RubyAlign: البداية - يجب محاذاة المحتوى على الحافة البداية في اتجاه التقدم داخل السطر. |
| RUBY_ALIGN_CENTER | السمة RubyAlign: الوسط - يجب توسيط المحتوى في اتجاه التقدم داخل السطر. |
| RUBY_ALIGN_END | السمة RubyAlign: النهاية - يجب محاذاة المحتوى على الحافة النهاية في اتجاه التقدم داخل السطر. |
| RUBY_ALIGN_JUSTIFY | السمة RubyAlign: ضبط - يجب توسيع المحتوى لملء العرض المتاح في اتجاه التقدم داخل السطر. |
| RUBY_ALIGN_DISTRIBUTE | السمة RubyAlign: توزيع - يجب توسيع المحتوى لملء العرض المتاح في اتجاه التقدم داخل السطر. ومع ذلك، يجب إدراج مساحة أيضًا عند الحافة البداية والحافة النهاية للنص. يجب توزيع التباعد باستخدام نسبة 1:2:1 (بداية:وسط:نهاية). سيتغير إلى نسبة 0:1:1 إذا ظهر الروبي في بداية سطر النص أو إلى نسبة 1:1:0 إذا ظهر الروبي في نهاية سطر النص. |
| RUBY_POSITION_BEFORE | السمة RubyPosition: قبل - يجب محاذاة محتوى RT على طول الحافة قبل للعنصر. |
| RUBY_POSITION_AFTER | السمة RubyPosition: بعد - يجب محاذاة محتوى RT على طول الحافة بعد للعنصر. |
| RUBY_POSITION_WARICHU | السمة RubyPosition: Warichu - يجب تنسيق محتوى RT والعناصر RP المرتبطة كـ warichu، متبوعًا بعنصر RB. |
| RUBY_POSITION_INLINE | السمة RubyPosition: Inline - يجب تنسيق محتوى RT والعناصر RP المرتبطة كتعليق داخل أقواس، متبوعًا بعنصر RB. |
| GLYPH_ORIENTATION_VERTICAL_AUTO | السمة GlyphOrientationVertical: تلقائي - يحدد توجيهًا افتراضيًا للنص، اعتمادًا على ما إذا كان بعرض كامل (عرضه يساوي ارتفاعه). |
| LIST_NUMBERING_NONE | السمة ListNumbering: لا شيء - لا ترقيم تلقائي؛ عناصر Lbl (إن وجدت) تحتوي على نص عشوائي لا يخضع لأي مخطط ترقيم. |
| LIST_NUMBERING_DISC | السمة ListNumbering: قرص - نقطة دائرية صلبة. |
| LIST_NUMBERING_CIRCLE | السمة ListNumbering: دائرة - نقطة دائرية مفتوحة. |
| LIST_NUMBERING_SQUARE | السمة ListNumbering: مربع - نقطة مربعة صلبة. |
| LIST_NUMBERING_DECIMAL | السمة ListNumbering: عشري - أرقام عربية عشرية (1-9, 10-99, ...). |
| LIST_NUMBERING_UPPER_ROMAN | السمة ListNumbering: UpperRoman - أرقام رومانية بالحروف الكبيرة (I, II, III, IV, ...). |
| LIST_NUMBERING_LOWER_ROMAN | السمة ListNumbering: LowerRoman - أرقام رومانية بالحروف الصغيرة (i, ii, iii, iv, ...). |
| LIST_NUMBERING_UPPER_ALPHA | السمة ListNumbering: UpperAlpha - أحرف بالحروف الكبيرة (A, B, C, ...). |
| LIST_NUMBERING_LOWER_ALPHA | السمة ListNumbering: LowerAlpha - أحرف بالحروف الصغيرة (a, b, c, ...). |
| ROLE_RB | السمة Role: rb - زر راديو. |
| ROLE_CB | السمة Role: cb - مربع اختيار. |
| ROLE_PB | السمة Role: pb - زر ضغط. |
| ROLE_TV | السمة Role: tv - حقل نص-قيمة. |
| CHECKED_ON | السمة checked: On - حالة زر راديو أو مربع اختيار. |
| CHECKED_OFF | السمة checked: Off - حالة زر راديو أو مربع اختيار. |
| CHECKED_NEUTRAL | السمة المحددة: محايدة - حالة زر الراديو أو حقل خانة الاختيار. |
| SCOPE_ROW | نطاق السمة: صف. |
| SCOPE_COLUMN | نطاق السمة: عمود. |
| SCOPE_BOTH | نطاق السمة: كلاهما. |
