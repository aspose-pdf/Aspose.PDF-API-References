## TableTRElement class

يمثل عنصر بنية TR في الهيكل المنطقي للجدول.

يعرض نوع TableTRElement الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| parent_element | لا شيء |
| child_elements | لا شيء |
| default_attribute_owner | يحصل |
| attributes | يحصل |
| structure_type | يحصل على نوع عنصر البنية. |
| id | يحصل على المعرف لعنصر البنية. |
| title | يحصل أو يضبط العنوان لعنصر البنية. |
| language | يحصل أو يعيّن اللغة لعنصر البنية. |
| alternative_text | يحصل أو يعيّن النص البديل لعنصر البنية. |
| expansion_text | يحصل أو يعيّن نص التوسيع لعنصر البنية. |
| actual_text | يحصل أو يعيّن النص الفعلي لعنصر البنية. |
| background_color | يسترجع أو يعيّن لون خلفية الصف. |
| الحد | يسترجع أو يعيّن حد الصف. |
| default_cell_border | يحصل على حد الخلية الافتراضي. |
| min_row_height | يسترجع ارتفاع الصف. |
| fixed_row_height | يسترجع ارتفاع الصف الثابت - قد يكون للصف ارتفاع ثابت. |
| is_in_new_page | يسترجع ما إذا كان الصف الثابت في صفحة جديدة - يجب طباعة الصفحة التي تحتوي هذه الخاصية في الصفحة التالية. القيمة الافتراضية false. |
| is_row_broken | يسترجع ما إذا كان يمكن كسر الصف بين صفحتين. |
| default_cell_text_state | يسترجع أو يعيّن الحالة النصية الافتراضية لخلايا الصف. |
| default_cell_padding | يسترجع أو يعيّن الهامش الافتراضي لخلايا الصف. |
| vertical_alignment | يحصل أو يضبط المحاذاة العمودية. |
