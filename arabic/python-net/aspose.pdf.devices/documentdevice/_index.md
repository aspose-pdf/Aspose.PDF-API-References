## DocumentDevice class

فئة مجردة لجميع الأجهزة التي تُستخدم لمعالجة المستند pdf بالكامل.

نوع DocumentDevice يعرض الأعضاء التالية:
## الطرق
| الاسم | الوصف |
| :- | :- |
| process(document, from_page, to_page, output) | كل جهاز يمثل عملية ما على المستند، على سبيل المثال يمكننا تحويل مستند pdf إلى تنسيق آخر. |
| process(document, output) | كل جهاز يمثل عملية ما على المستند، على سبيل المثال يمكننا تحويل مستند pdf إلى تنسيق آخر. |
| process(document, output_file_name) | يعالج المستند بالكامل ويحفظ النتائج في ملف. |
| process(document, from_page, to_page, output_file_name) | يعالج صفحات معينة من المستند ويحفظ النتائج في ملف. |
| binarize_bradley(input_image_stream, output_image_stream, threshold) | قم بعملية ثنائية برادلي لتدفق الإدخال. |
