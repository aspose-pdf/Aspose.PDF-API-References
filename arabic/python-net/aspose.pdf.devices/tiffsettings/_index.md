## الخصائص
| الاسم | الوصف |
| :- | :- |
| margins | يحصل على الهوامش. |
| skip_blank_pages | يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب تخطي الصفحات الفارغة. |
| compression | يحصل أو يعيّن نوع الضغط. |
| depth | يحصل أو يعيّن عمق اللون. |
| shape | يحصل أو يعيّن نوع الشكل. |
| brightness | يحصل أو يعيّن حد قيمة لتحويل الألوان بين الأبيض والأسود.<br/>            يمكن تطبيق هذا المعامل مع EncoderValue.CompressionCCITT4، EncoderValue.CompressionCCITT3، EncoderValue.CompressionRle أو ColorDepth.Format1bpp == 1 |
| coordinate_type | يحصل أو يعيّن نوع إحداثيات الصفحة (صناديق Media/Crop). يتم استخدام قيمة CropBox بشكل افتراضي. |
