## EmfDevice class

يمثّل جهاز صورة يساعد على حفظ صفحات مستند pdf بصيغة emf.

نوع EmfDevice يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| EmfDevice() | ينشئ مثيلاً جديداً من الفئة [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) بدقة افتراضية للصورة النقطية المكتوبة إلى emf. |
| EmfDevice(resolution) | يُهيئ نسخة جديدة من فئة EmfDevice |
| EmfDevice(width, height) | يُهيئ نسخة جديدة من فئة EmfDevice |
| EmfDevice(page_size) | يُهيئ نسخة جديدة من فئة EmfDevice |
| EmfDevice(width, height, resolution) | يُهيئ نسخة جديدة من فئة EmfDevice |
| EmfDevice(page_size, resolution) | يُهيئ نسخة جديدة من فئة EmfDevice |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| coordinate_type | يحصل أو يضبط نوع إحداثيات الصفحة (صناديق Media/Crop). يتم استخدام قيمة CropBox كإعداد افتراضي. |
| rendering_options | يحصل أو يضبط خيارات العرض. |
| form_presentation_mode | يحصل أو يضبط وضع عرض النموذج. |
| resolution | يحصل على دقة الصورة. |
| العرض | يحصل على عرض إخراج الصورة. |
| الارتفاع | يحصل على ارتفاع إخراج الصورة. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| process(page, output) | يقوم بتحويل الصفحة إلى صيغة emf ويحفظها في تدفق الإخراج. |
| process(page, output_file_name) | يقوم بتحويل الصفحة إلى صيغة emf ويحفظها في تدفق الإخراج. |
