## ImageDevice class

فئة مجردة لأجهزة الصورة.

نوع ImageDevice يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| coordinate_type | يحصل أو يضبط نوع إحداثيات الصفحة (صناديق Media/Crop). يتم استخدام قيمة CropBox كإعداد افتراضي. |
| rendering_options | يحصل أو يضبط خيارات العرض. |
| form_presentation_mode | يحصل أو يضبط وضع عرض النموذج. |
| resolution | يحصل على دقة الصورة. |
| العرض | يحصل على عرض إخراج الصورة. |
| الارتفاع | يحصل على ارتفاع إخراج الصورة. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| process(page, output) | يؤدي بعض العمليات على الصفحة المعطاة، على سبيل المثال يحول الصفحة إلى صورة رسومية. |
| process(page, output_file_name) | يؤدي بعض العمليات على الصفحة المعطاة ويحفظ النتائج في الملف. |
