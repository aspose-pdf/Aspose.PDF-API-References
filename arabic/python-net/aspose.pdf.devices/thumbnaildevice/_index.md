## ThumbnailDevice class

يمثل جهاز صورة يحفظ صفحات مستند PDF كصورة مصغرة.

يعرض نوع ThumbnailDevice الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ThumbnailDevice() | ينشئ مثيلاً جديدًا من الفئة [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) <br/>            بحجم الصورة المصغرة الافتراضي (200x200 بكسل). |
| ThumbnailDevice(width, height) | ينشئ مثيلاً جديدًا من فئة ThumbnailDevice |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| coordinate_type | يحصل أو يضبط نوع إحداثيات الصفحة (صناديق Media/Crop). يتم استخدام قيمة CropBox كإعداد افتراضي. |
| rendering_options | يحصل أو يضبط خيارات العرض. |
| form_presentation_mode | يحصل أو يضبط وضع عرض النموذج. |
| resolution | يحصل على دقة الصورة. |
| العرض | يحصل على عرض إخراج الصورة. |
| الارتفاع | يحصل على ارتفاع إخراج الصورة. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| process(page, output) | يحوّل الصفحة إلى صورة مصغرة بصيغة png ويحفظها في تدفق الإخراج. |
| process(page, output_file_name) | يحوّل الصفحة إلى صورة مصغرة بصيغة png ويحفظها في تدفق الإخراج. |
