## OptimizationOptions class

فئة تصف خوارزمية تحسين المستند.<br/>            يمكن استخدام نسخة من هذه الفئة كمعامل لطريقة OptimizeResources().

يعرض نوع OptimizationOptions الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| OptimizationOptions() | ينشئ مثيلًا جديدًا من فئة OptimizationOptions |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| link_duplcate_streams | إذا تم تعيين هذه العلامة إلى true، سيتم تحليل تدفقات الموارد. إذا تم العثور على تدفقات مكررة (أي إذا كان محتوى التدفق متساويًا)، فسيتم تخزين هذه التدفقات ككائن واحد. <br/>            يتيح ذلك تقليل حجم المستند في بعض الحالات (على سبيل المثال، عندما تم دمج نفس المستند عدة مرات). |
| allow_reuse_page_content | إذا كان true، سيتم إعادة استخدام محتويات الصفحة عندما يتم تحسين المستند للصفحات المتساوية. |
| remove_unused_streams | إذا تم تعيين هذه العلامة إلى true، يتم فحص كل مورد بناءً على استخدامه. إذا لم يُستخدم المورد أبدًا، يتم إزالة المورد.<br/>            قد يؤدي ذلك إلى تقليل حجم المستند، على سبيل المثال عندما تم استخراج الصفحات من المستند. |
| remove_unused_objects | إذا تم تعيين هذه العلامة إلى true، سيتم فحص جميع كائنات المستند وإزالة الكائنات غير المستخدمة (أي الكائنات التي لا تحتوي على أي مرجع) من المستند. |
| image_compression_options | مجموعة من الخيارات التي تصف ما إذا كانت الصور في المستند ستُضغط ومعلمات الضغط. |
| compress_images | إذا تم تعيين هذه العلامة إلى true، سيتم ضغط الصور في المستند. مستوى الضغط محدد بخصيصة ImageQuality. |
| resize_images | إذا تم تعيين هذه العلامة إلى true وكان CompressImages true، سيتم تغيير حجم الصور إذا كانت دقة الصورة أكبر من المعامل MaxResolution المحدد. |
| image_quality | يحدد مستوى ضغط الصورة عندما يتم استخدام العلامة CompressIamges. |
| max_resoultion | يحدد الحد الأقصى لدقة الصور. إذا كانت الصورة ذات دقة أعلى، سيتم تعديل حجمها. |
| unembed_fonts | اجعل الخطوط غير مضمنة إذا تم تعيينها إلى true. |
| subset_fonts | سيتم تحويل الخطوط إلى مجموعات فرعية إذا تم تعيينها إلى true. |
| remove_private_info | إزالة المعلومات الخاصة (معلومات جزء الصفحة). |
| image_encoding | ترميز الصورة الذي سيُستخدم. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| all() | ينشئ استراتيجية تحسين مع تفعيل جميع الخيارات.<br/>            يرجى ملاحظة أن الخيارات المفعلة هي فقط تلك التي لا تغير أي وظيفة في المستند.<br/>            أي أن ضغط الصور وإلغاء تضمين الخطوط لن يتم تمكينهما (ويمكن تضمينهما يدويًا). |
