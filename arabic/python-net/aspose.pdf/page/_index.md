## Page class

الفئة تمثل صفحة من وثيقة PDF.

يعرض نوع Page الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_add_paragraphs_after_last | يحصل أو يضبط إضافة الفقرات بعد الفقرة الأخيرة في الصفحة |
| background_image | يحصل أو يعيّن صورة الخلفية للصفحة (للمولد فقط، لا تُملأ عند قراءة المستند). |
| toc_info | يحصل أو يضبط معلومات جدول المحتويات. |
| رأس | يحصل أو يعيّن رأس الصفحة. |
| الطبقات | يحصل أو يعيّن مجموعة الطبقات. |
| التذييل | يحصل أو يعيّن تذييل الصفحة. |
| paragraphs | يحصل على الفقرات. |
| page_info | يحصل أو يعيّن معلومات الصفحة (للمولد فقط، لا يتم ملؤها عند قراءة المستند). |
| المستطيل | يحصل أو يعيّن مستطيل الصفحة.<br/>            عند الحصول: يتم إرجاع صندوق القص للصفحة إذا تم تحديده، وإلا يتم إرجاع صندوق الوسائط للصفحة.<br/>            عند التعيين: يتم دائمًا تعيين صندوق الوسائط للصفحة.<br/>            يرجى ملاحظة أن هذه الخاصية لا تأخذ دوران الصفحة في الاعتبار. للحصول على مستطيل الصفحة مع مراعاة الدوران يرجى استخدام ActualRect. |
| color_type | يعيّن نوع اللون للصفحات بناءً على المعلومات المستلمة من المشغلات SetColor،<br/>            الصور والنماذج. |
| note_line_style | يحصل أو يعيّن نمط الخط للملاحظات.(للمولد فقط، لا يتم ملؤه عند قراءة المستند) |
| tab_order | يحصل أو يعيّن ترتيب التبويب للصفحة. <br/>            القيم الممكنة: Row, Column. Default, Manual |
| duration | يحصل أو يعيّن مدة عرض الصفحة. هذه هي الوقت بالثواني التي يجب عرض الصفحة خلالها أثناء العرض.<br/>            يرجع -1 إذا لم يتم تعريف المدة. |
| contents | يحصل على مجموعة المشغلات في تدفق محتوى الصفحة.<br/>            [OperatorCollection](/pdf/python-net/aspose.pdf/operatorcollection/) |
| المجموعة | يحصل أو يعيّن فئة سمات المجموعة التي تحدد سمات مجموعة صفحة الصفحة للاستخدام في نموذج التصوير الشفاف. |
| annotations | يحصل على مجموعة تعليقات الصفحة.<br/>            [annotations](/pdf/python-net/aspose.pdf/page/) |
| resources | يحصل على موارد الصفحة. كائن الموارد يحتوي على مجموعات من الصور والنماذج والخطوط.<br/>            [resources](/pdf/python-net/aspose.pdf/page/) |
| تدوير | يحصل أو يعيّن دوران الصفحة. |
| trim_box | يحصل أو يعيّن صندوق القص للصفحة. |
| art_box | يحصل أو يعيّن صندوق الفن للصفحة. |
| bleed_box | يحصل أو يضبط صندوق النزيف للصفحة. |
| crop_box | يحصل أو يضبط صندوق القص للصفحة. |
| media_box | يحصل أو يضبط صندوق الوسائط للصفحة. |
| الرقم | احصل على رقم الصفحة. |
| rotation_matrix | يحصل على مصفوفة التحويل للصفحة. |
| background | يحصل أو يضبط لون الخلفية للصفحة. |
| watermark | يحصل أو يضبط العلامة المائية للصفحة. |
| artifacts | يحصل على مجموعة من القطع الأثرية في الصفحة. |
| الإجراءات | يحصل على مجموعة من خصائص الصفحة. |
| fields_in_tab_order | يحصل على قائمة كائنات الحقل بترتيب التبويب في هذه الصفحة. |
| user_unit | يحصل أو يضبط قيمة UserUnit. رقم موجب يحدد حجم وحدات مساحة المستخدم الافتراضية، بمضاعفات 1 ⁄ 72 بوصة.<br/>            القيمة الافتراضية هي 1. يرجى ضبط الصفر أو قيمة سالبة لمسح هذا الإدخال في الصفحة. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| send_to(device, output) | يرسل الصفحة للمعالجة باستخدام جهاز الصفحة المحدد. |
| send_to(device, output_file_name) | يرسل الصفحة للمعالجة باستخدام جهاز الصفحة المحدد. |
| accept(visitor) | يقبل كائن الزائر [AnnotationSelector](/pdf/python-net/aspose.pdf.annotations/annotationselector/) الذي يوفر وظائف للعمل مع التعليقات التوضيحية. |
| accept(visitor) | يقبل كائن الزائر [TextFragmentAbsorber](/pdf/python-net/aspose.pdf.text/textfragmentabsorber/) الذي يوفر وظائف للعمل مع كائنات النص. |
| accept(visitor) | يقبل كائن الزائر [ImagePlacementAbsorber](/pdf/python-net/aspose.pdf/imageplacementabsorber/) الذي يوفر وظائف للعمل مع كائنات وضع الصور. |
| accept(visitor) | يقبل كائن الزائر [TextAbsorber](/pdf/python-net/aspose.pdf.text/textabsorber/) الذي يوفر وظائف للعمل مع كائنات النص. |
| add_image(image_stream, image_rect) | يضيف الصورة إلى الصفحة ويضعها في وسط المستطيل المحدد مع الحفاظ على نسبة الصورة. |
| add_image(hocr, image_stream, image_rect) | يضيف صورة قابلة للبحث إلى الصفحة ويضعها في وسط المستطيل المحدد مع الحفاظ على نسبة الصورة. |
| add_image(image_stream, image_rect, image_width, image_height, save_image_proportions) | يضيف صورة إلى الصفحة ويضعها اعتمادًا على موضع مستطيل الصورة. |
| add_image(image_path, rectangle) | يضيف صورة قابلة للبحث إلى الصفحة ويضعها في وسط المستطيل المحدد مع الحفاظ على نسبة الصورة. |
| is_blank(fill_threshold_factor) | يحصل على العلامة التي تحدد ما إذا كانت الصفحة فارغة أم لا. |
| get_page_rect(consider_rotation) | يرجع مستطيل الصفحة وفقًا لـ CropBox الخاص بها (أو MediaBox إذا كان CropBox فارغًا). |
| calculate_content_b_box() | يحسب قيمة bbox - المستطيل الذي يحتوي على المحتوى دون الهوامش المرئية. |
| rotation_to_int(rotation) | يحول عضو تعداد الدوران إلى قيمة عددية. |
| int_to_rotation(rotation) | يحول القيمة العددية إلى عضو تعداد الدوران المقابل. |
| add_stamp(stamp) | ضع ختمًا في الصفحة. يمكن أن يكون الختم رقم الصفحة أو صورة أو نصًا بسيطًا، مثل شعار. |
| flatten() | يزيل جميع الحقول الموجودة على الصفحة ويضع قيمها بدلاً منها. |
| set_page_size(width, height) | يضبط حجم الصفحة. |
| make_grayscale() | يحول الصفحة إلى تدرج الرمادي. |
| free_memory() | يمسح البيانات المخزنة مؤقتًا. |
| get_notifications() | يرجع الإشعارات حول العمليات الداخلية مع محتوى الصفحة. (يتم دعم الإشعارات حول أحداث الفقرات في سيناريوهات إضافة النص فقط حاليًا.) |
| as_byte_array(resolution) | يحول الصفحة الحالية إلى صورة نقطية ثم يرجع مصفوفة من البايتات. |
| as_xml() | يحول الصفحة الحالية إلى XML بترميز UTF-8. |
