## Table class

يمثل جدولًا يمكن إضافته إلى الصفحة.

يعرض نوع Table الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Table() | ينشئ نسخة جديدة من الفئة Table |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| vertical_alignment | يحصل أو يضبط محاذاة عمودية للفقرة |
| horizontal_alignment | يحصل أو يضبط محاذاة أفقية للفقرة |
| margin | يحصل أو يضبط هامشًا خارجيًا للفقرة (لإنشاء PDF) |
| is_first_paragraph_in_column | يحصل أو يضبط قيمة منطقية تشير إلى ما إذا كانت هذه الفقرة ستظهر في العمود التالي.<br/>            القيمة الافتراضية هي false. (لإنشاء PDF) |
| is_kept_with_next | يحصل أو يضبط قيمة منطقية تشير إلى ما إذا كانت الفقرة الحالية ستبقى في نفس الصفحة مع الفقرة التالية.<br/>            القيمة الافتراضية هي false. (لإنشاء PDF) |
| is_in_new_page | يحصل أو يضبط قيمة منطقية تجبر هذه الفقرة على الإنشاء في صفحة جديدة.<br/>            القيمة الافتراضية هي false. (لإنشاء PDF) |
| is_in_line_paragraph | يحصل أو يضبط ما إذا كانت الفقرة مضمنة داخل السطر.<br/>            القيمة الافتراضية هي false. (لإنشاء PDF) |
| hyperlink | يحصل أو يضبط الارتباط التشعبي للجزء (لمولد PDF). |
| z_index | يحصل أو يضبط قيمة عددية تشير إلى ترتيب Z للرسمة. الرسمة ذات ZIndex أكبر <br/>            ستوضع فوق الرسمة ذات ZIndex أصغر. يمكن أن يكون ZIndex سالبًا. الرسمة ذات ZIndex سالب <br/>            ستوضع خلف النص في الصفحة. |
| background_color | يحصل أو يضبط لون خلفية الجدول |
| break_text | يحصل أو يضبط نص الفاصل للجدول |
| corner_style | يحصل أو يضبط أنماط زوايا الحدود |
| repeating_rows_style | يحصل على النمط للصفوف المتكررة |
| repeating_columns_count | يحصل أو يضبط الحد الأقصى لعدد الأعمدة للجدول |
| repeating_rows_count | يحصل على عدد الصفوف الأولى المتكررة لعدة صفحات |
| column_widths | يحصل على عرض أعمدة الجدول. |
| broken | يحصل أو يضبط كسر عمودي للجدول broken; |
| default_cell_border | يحصل على حد الخلية الافتراضي؛ |
| default_column_width | يحصل على حد الخلية الافتراضي؛ |
| صفوف | يحصل على صفوف الجدول. |
| الحد | يحصل أو يضبط الحد. |
| default_cell_padding | يحصل أو يضبط حشو الخلية الافتراضي. |
| default_cell_text_state | يحصل أو يضبط حالة نص الخلية الافتراضية. |
| المحاذاة | يحصل أو يضبط محاذاة الجدول. |
| left | يحصل أو يضبط إحداثي اليسار للجدول. |
| top | يحصل أو يضبط إحداثي أعلى الجدول. |
| is_broken | يحصل أو يضبط ما إذا كان الجدول مكسورًا - سيتم تقصيره للصفحة التالية. |
| is_borders_included | يحصل أو يضبط تضمين الحدود في عرض الأعمدة. |
| column_adjustment | يحصل أو يضبط تعديل عمود الجدول. |
