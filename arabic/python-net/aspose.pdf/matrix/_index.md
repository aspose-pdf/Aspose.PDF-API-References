## Matrix class

الفئة تمثل مصفوفة التحويل.

يظهر نوع Matrix الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Matrix() | المنشئ<br/>            ينشئ مصفوفة قياسية 1 إلى 1:<br/>            [ A B C D E F ] = [ 1, 0, 0, 1, 0, 0] |
| Matrix(matrix_array) | يُهيئ نسخة جديدة من فئة Matrix |
| Matrix(matrix_array) | يُهيئ نسخة جديدة من فئة Matrix |
| Matrix(matrix) | يُهيئ نسخة جديدة من فئة Matrix |
| Matrix(a, b, c, d, e, f) | يُهيئ نسخة جديدة من فئة Matrix |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| data | يحصل على بيانات Matrix كمصفوفة. |
| a | عضو في مصفوفة التحويل. |
| b | عضو B في مصفوفة التحويل. |
| c | عضو C في مصفوفة التحويل. |
| d | عضو D في مصفوفة التحويل. |
| e | عضو E في مصفوفة التحويل. |
| f | عضو F في مصفوفة التحويل. |
| العناصر | عناصر المصفوفة. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| rotation(alpha) | ينشئ مصفوفة لزاوية الدوران المعطاة. |
| rotation(rotation) | ينشئ مصفوفة لزاوية الدوران المعطاة. |
| transform(p) | يحوّل النقطة باستخدام هذه المصفوفة. |
| transform(rect) | يحوّل المستطيل.<br/>            إذا لم تكن الزاوية 90 * N درجةً، فسيتم إرجاع المستطيل المحيط. |
| skew(alpha, beta) | ينشئ مصفوفة لزاوية الدوران المعطاة. |
| get_angle(rotation) | يحوّل الدوران إلى زاوية (بالدرجات) |
| multiply(other) | يضرب المصفوفة بالمصفوفة الأخرى. |
| add(other) | يضيف المصفوفة إلى المصفوفة الأخرى. |
| reverse() | يحسب المصفوفة العكسية. |
