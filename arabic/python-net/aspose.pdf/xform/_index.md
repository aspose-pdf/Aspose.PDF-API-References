## XForm class

الفئة تمثل XForm

يعرض نوع XForm الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| b_box | يحصل أو يضبط صندوق حدود النموذج. |
| name | يحصل أو يضبط اسم النموذج. اسم النموذج هو الاسم الذي يُستخدم للإشارة إلى النموذج في قاموس XObejct في موارد الصفحة. |
| المحتويات | يحصل على المشغلات الخاصة بالنموذج. |
| opi | يحصل على واجهة ما قبل الطباعة المفتوحة (OPI). |
| matrix | يحصل أو يضبط مصفوفة النموذج. |
| resources | يحصل على موارد Form XObject. |
| rectangle | يحصل أو يضبط مستطيل النموذج. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| get_resources(allow_create) | يرجع موارد Form X-Object |
| get_resources() | يرجع موارد Form X-Object |
| create_new_form(source, document) | ينشئ XForm يكرر محتويات الصفحة. |
| free_memory() | يمسح البيانات المخزنة مؤقتًا. |
