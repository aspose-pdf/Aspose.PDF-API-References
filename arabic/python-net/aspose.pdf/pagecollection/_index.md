## PageCollection class

مجموعة من صفحات وثيقة PDF.

يعرض نوع PageCollection الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | يرجع true إذا كان الكائن متزامنًا. |
| sync_root | يحصل على كائن المزامنة للمجموعة. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على الصفحة حسب الفهرس. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| إضافة(entity) | يضيف الصفحة إلى المجموعة. |
| add() | يضيف الصفحة إلى المجموعة. |
| add(pages) | يضيف إلى المجموعة جميع الصفحات من القائمة. |
| add(pages) | يضيف إلى المجموعة جميع الصفحات من المصفوفة. |
| delete(index) | حذف الصفحة المحددة. |
| delete() | حذف الصفحة المحددة. |
| delete(pages) | حذف الصفحات المحددة التي أرقامها موجودة في المصفوفة. |
| accept(visitor) | يقبل كائن الزائر [AnnotationSelector](/pdf/python-net/aspose.pdf.annotations/annotationselector/) الذي يوفر وظائف للعمل مع التعليقات التوضيحية. |
| accept(visitor) | يقبل كائن الزائر [ImagePlacementAbsorber](/pdf/python-net/aspose.pdf/imageplacementabsorber/) الذي يوفر وظائف للعمل مع كائنات وضع الصور. |
| accept(visitor) | يقبل كائن الزائر [TextFragmentAbsorber](/pdf/python-net/aspose.pdf.text/textfragmentabsorber/) الذي يوفر وظائف للعمل مع كائنات النص. |
| accept(visitor) | يقبل كائن الزائر [TextAbsorber](/pdf/python-net/aspose.pdf.text/textabsorber/) الذي يوفر وظائف للعمل مع كائنات النص. |
| insert(page_number) | إدراج صفحة فارغة في المجموعة في الموضع المحدد. |
| insert(page_number, entity) | إدراج صفحة فارغة في المجموعة في الموضع المحدد. |
| insert(page_number, pages) | يدرج الصفحات من المجموعة في المستند. |
| insert(page_number, pages) | يدرج الصفحات من المصفوفة في المستند. |
| index_of(entity) | يعيد فهرس الصفحة المحددة. |
| flatten() | يزيل جميع الحقول الموجودة على الصفحات ويضع قيمها بدلاً منها. |
| free_memory() | يمسح البيانات المخزنة مؤقتًا. |
