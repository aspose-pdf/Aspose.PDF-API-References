## ImagePlacement class

يمثل خصائص صورة موضوعة في صفحة مستند PDF.

يعرض نوع ImagePlacement الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| matrix | مصفوفة التحويل الحالية لهذه الصورة. |
| rectangle | يحصل على مستطيل الصورة. |
| المعامل | المعامل المستخدم لعرض الصورة. |
| rotation | يحصل على زاوية دوران الصورة. |
| resolution | يحصل على دقة الصورة. |
| image | يحصل على كائن مورد XImage المرتبط. |
| صفحة | يحصل على الصفحة التي تحتوي على الصورة. |
| compositing_parameters | يحصل على معلمات التركيب لحالة الرسومات النشطة للصورة الموضوعة على الصفحة. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| save(stream) | يحفظ الصورة مع التحولات المقابلة: التحجيم، الدوران والدقة. |
| save(stream, format) | يحفظ الصورة مع التحولات المقابلة: التحجيم، الدوران والدقة. |
| hide() | احذف الصورة من الصفحة. |
| replace(image) | استبدل الصورة في المجموعة بصورة أخرى. |
