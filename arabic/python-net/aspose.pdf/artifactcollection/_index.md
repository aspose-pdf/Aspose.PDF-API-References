## ArtifactCollection class

الفئة تمثل مجموعة artifact.

يعرض نوع ArtifactCollection الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | هل هذا الكائن متزامن. |
| sync_root | يحصل على كائن المزامنة للمجموعة. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على العنصر حسب الفهرس. يبدأ الفهرس من 1. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| delete(artifact) | يحذف العنصر المحدد. |
| delete(index) | يحذف العنصر حسب فهرسه. |
| find_by_value(name, expected_value) | يبحث عن العناصر حسب قيمة مخصصة. |
| update(artifact) | تحديث العنصر داخل المجموعة. |
