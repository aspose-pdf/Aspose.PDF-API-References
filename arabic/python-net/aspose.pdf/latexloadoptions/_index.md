## LatexLoadOptions class

يمثل خيارات تحميل/استيراد ملف TeX إلى مستند PDF.

يعرض نوع LatexLoadOptions الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| LatexLoadOptions() | يقوم بإنشاء نسخة جديدة من فئة LatexLoadOptions |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| warning_handler | استدعاء رد نداء للتعامل مع أي تحذيرات تم إنشاؤها. <br/>            تُعيد WarningHandler عنصر تعداد ReturnAction يحدد إما Continue أو Abort. <br/>            Continue هو الإجراء الافتراضي وتستمر عملية التحميل، ومع ذلك قد يُعيد المستخدم أيضًا Abort وفي هذه الحالة يجب أن تتوقف عملية التحميل. |
| load_format | يمثل تنسيق الملف الذي تصفه [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/). |
| job_name | الحصول/تعيين اسم المهمة. |
| input_directory | الحصول/تعيين دليل إدخال TeX. |
| output_directory | الحصول/تعيين دليل إخراج TeX. |
| repeat | الحصول/تعيين العلامة التي تشير إلى ما إذا كان من الضروري تشغيل مهمة TeX مرتين في حالة،<br/>            على سبيل المثال، وجود مراجع في ملفات TeX المدخلة. بشكل عام، هذا السلوك مفيد عندما<br/>            يجمع المحرك بعض البيانات أثناء عملية التنضيد ويخزنها في ملف مساعد،<br/>            جميعها في التشغيل الأول. وفي التشغيل الثاني، يستخدم المحرك تلك البيانات بطريقة ما. |
| subset_fonts | الحصول/تعيين العلامة التي تشير إلى ما إذا كان يجب تقليل الخطوط في ملف الإخراج أم لا. |
| show_terminal_output | الحصول/تعيين العلامة التي تشير إلى ما إذا كان يجب عرض مخرجات الطرفية على وحدة التحكم. |
| date_time | الحصول/تعيين قيمة معينة للبدائيات الخاصة بالتاريخ/الوقت مثل \year، \month، \day و \time. |
| no_ligatures | الحصول/تعيين علامة تلغي الأحرف المتصلة في جميع الخطوط. |
| rasterize_formulas | الحصول/تعيين علامة تسمح بتحويل صيغ الرياضيات إلى صورة نقطية. |
