## Rectangle class

الفئة تمثل المستطيل.

يعرض نوع Rectangle الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Rectangle(llx, lly, urx, ury, normalize_coordinates) | ينشئ مثيلاً جديداً من الفئة Rectangle |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| العرض | عرض المستطيل. |
| الارتفاع | ارتفاع المستطيل. |
| llx | الإحداثي X للزاوية السفلية اليسرى. |
| lly | الإحداثي Y للزاوية السفلية اليسرى. |
| urx | الإحداثي X للزاوية العلوية اليمنى. |
| ury | الإحداثي Y للزاوية العلوية اليمنى. |
| بسيط | يُهيئ مستطيلًا تافهًا أي مستطيلًا بموقع وحجم صفر. |
| is_trivial | يتحقق مما إذا كان المستطيل تافهًا أي أنه يملك حجمًا وموقعًا صفر. |
| is_empty | يتحقق مما إذا كان المستطيل فارغًا. |
| is_point | يتحقق مما إذا كان المستطيل نقطة أي أن LLX يساوي URX وLLY يساوي URY. |
| empty | مستطيل فارغ |
## الطرق
| الاسم | الوصف |
| :- | :- |
| rotate(angle) | دوّر المستطيل بالزاوية المحددة. |
| rotate(angle) | دوّر المستطيل بالزاوية المحددة. |
| to_rect() | يحوّل المستطيل إلى كائن من System.Drawing.Rectangle. يتم تقصير المواقع والأحجام ذات الفاصلة العائمة. |
| from_rect(src) | يُهيئ مستطيلًا جديدًا من الكائن المعطى System.Drawing.Rectangle. |
| parse(value) | حاول تحليل السلسلة واستخراج مكوّنات المستطيل llx و lly و urx و ury منها. |
| equals(other) | تحقق مما إذا كانت المستطيلات متساوية أي أنها تملك نفس الموقع والأحجام. |
| near_equals(other, delta) | تحقق مما إذا كانت المستطيلات تقريبًا متساوية أي أنها تملك موقعًا وأحجامًا متقاربة (حتى دلتا). |
| intersect(other_rect) | يتقاطع مع المستطيلات. |
| join(other_rect) | ينضم إلى المستطيلات. |
| is_intersect(other_rect) | يحدد ما إذا كان هذا المستطيل يتقاطع مع المستطيل الآخر. |
| contains(point) | يحدد ما إذا كانت النقطة المعطاة داخل المستطيل. |
| center() | يرجع إحداثيات مركز المستطيل. |
| clone() | ينسخ كائن المستطيل. |
| to_points() | يحول المستطيل إلى مصفوفة من النقاط ("QuadPoints"). |
