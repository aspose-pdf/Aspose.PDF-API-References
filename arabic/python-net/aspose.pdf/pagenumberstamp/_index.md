## PageNumberStamp class

يمثل ختم رقم الصفحة ويُستخدم لترقيم الصفحات.

يعرض نوع PageNumberStamp الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| PageNumberStamp(format) | ينشئ مثيلاً جديدًا من الفئة PageNumberStamp |
| PageNumberStamp() | ينشئ مثيلاً جديدًا من الفئة [PageNumberStamp](/pdf/python-net/aspose.pdf/pagenumberstamp/). تم تعيين التنسيق إلى "#". |
| PageNumberStamp(formatted_text) | ينشئ مثيلاً جديدًا من الفئة PageNumberStamp |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| background | يضبط أو يحصل على قيمة منطقية تشير إلى أن المحتوى مختوم كخلفية.<br/>            إذا كانت القيمة true، يتم وضع محتوى الختم في الأسفل.<br/>            بشكل افتراضي، تكون القيمة false، يتم وضع محتوى الختم في الأعلى. |
| الشفافية | يحصل أو يضبط قيمة لتحديد شفافية الختم. القيمة تتراوح بين 0.0 إلى 1.0.<br/>            بشكل افتراضي القيمة هي 1.0. |
| outline_opacity | يحصل أو يضبط قيمة لتحديد شفافية حدود الختم. القيمة تتراوح بين 0.0 إلى 1.0.<br/>            بشكل افتراضي القيمة هي 1.0. |
| outline_width | يحصل أو يضبط قيمة عرض حدود الختم.<br/>            بشكل افتراضي القيمة هي 1.0. |
| rotate | يضبط أو يحصل على دوران محتوى الطابع وفق قيم [Rotation](/pdf/python-net/aspose.pdf/rotation/).<br/>            ملاحظة. هذه الخاصية مخصصة لضبط الزوايا التي هي مضاعفات 90 درجة (0، 90، 180، 270 درجة).<br/>            لضبط زاوية عشوائية استخدم الخاصية RotateAngle. <br/>            إذا كانت الزاوية التي تم ضبطها بواسطة ArbitraryAngle ليست مضاعفًا لـ 90 فإن خاصية Rotate تُرجع Rotation.None. |
| x_indent | إحداثي الطابع الأفقي، يبدأ من اليسار. |
| y_indent | إحداثي الطابع العمودي، يبدأ من الأسفل. |
| horizontal_alignment | يضبط أو يحصل على محاذاة الطابع الأفقي على الصفحة. |
| vertical_alignment | يضبط أو يحصل على محاذاة الطابع العمودي على الصفحة. |
| left_margin | يضبط أو يحصل على الهامش الأيسر للطابع. |
| right_margin | يضبط أو يحصل على الهامش الأيمن للطابع. |
| bottom_margin | يضبط أو يحصل على الهامش السفلي للطابع. |
| top_margin | يضبط أو يحصل على الهامش العلوي للطابع. |
| zoom_x | عامل التكبير الأفقي للطابع. يسمح بتكبير الطابع أفقيًا. |
| العرض | العرض المطلوب للطابع على الصفحة. |
| الارتفاع | الارتفاع المطلوب للطابع على الصفحة. |
| zoom_y | عامل التكبير العمودي للطابع. يسمح بتكبير الطابع عموديًا. |
| zoom | عامل التكبير للطابع. يسمح بتكبير الطابع.<br/>            يرجى ملاحظة أن زوج الخصائص ZoomX و ZoomY يسمح بتعيين عامل التكبير لكل محور على حدة. <br/>            ضبط هذه الخاصية يغيّر كل من خصائص ZoomX و ZoomY. <br/>            إذا كانت ZoomX و ZoomY مختلفة فإن خاصية Zoom تُرجع قيمة ZoomX. |
| rotate_angle | يضبط أو يحصل على زاوية دوران الطابع بالدرجات.<br/>            هذه الخاصية تسمح بتعيين زاوية دوران عشوائية. |
| draw | تحدد هذه الخاصية كيفية رسم الطابع على الصفحة. إذا كان Draw = true يتم رسم الطابع كعمليات رسومية، وإذا كان Draw = false يتم رسم الطابع كنص. |
| treat_y_indent_as_base_line | يحدد أصل الإحداثيات لوضع النص.<br/>            إذا كان TreatYIndentAsBaseLine = true (الإعداد الافتراضي عندما Draw = true) سيتم اعتبار قيمة YIndent كخط أساس للنص.<br/>            إذا كان TreatYIndentAsBaseLine = false (الإعداد الافتراضي عندما Draw = false) سيتم اعتبار قيمة YIndent كقاع (خط النزول) النص. |
| word_wrap | يحدد التفاف الكلمات. إذا تم تعيين هذه الخاصية إلى true وتم تحديد قيمة Width، سيتم كسر النص إلى عدة أسطر لتناسب العرض المحدد. القيمة الافتراضية: false. |
| justify | يحدد محاذاة النص. إذا تم تعيين هذه الخاصية إلى true، يتم محاذاة الحافتين اليسرى واليمنى للنص. القيمة الافتراضية: false. |
| scale | يحدد مقياس النص. إذا تم تعيين هذه الخاصية إلى true وتم تحديد قيمة Width، سيتم تحجيم النص ليتناسب مع العرض المحدد. |
| value | يحصل أو يعيّن قيمة النص المستخدمة كطابع على الصفحة. |
| text_state | يحصل على خصائص النص للعلامة. راجع [text_state](/pdf/python-net/aspose.pdf/textstamp/) للحصول على التفاصيل. |
| text_alignment | محاذاة النص داخل العلامة. |
| max_row_width | الحد الأقصى لارتفاع الصف لخيار WordWrap. |
| format | قيمة نصية لتوسيم أرقام الصفحات. <br/>            يجب أن تشمل القيمة الحرف '#' الذي يتم استبداله برقم الصفحة أثناء عملية التوسيم. |
| starting_number | يحصل أو يضبط قيمة رقم الصفحة الابتدائية. الصفحات الأخرى سيتم ترقيمها بدءًا من هذه القيمة. |
| numbering_style | نمط الترقيم المستخدم في هذه الطابع. |
