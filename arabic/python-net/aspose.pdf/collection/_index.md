## Collection class

## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Collection() | يُهيئ كائن Collection جديد. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | يحصل على قيمة تشير إلى ما إذا كان الوصول إلى هذه المجموعة متزامنًا (آمن للخيوط). |
| sync_root | يحصل على كائن يمكن استخدامه لمزامنة الوصول إلى هذه المجموعة. |
| المفاتيح | يرجع قائمة مفاتيح مرفقات الملفات. |
| default_entry | اسم الملف المضمّن الافتراضي. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على الملف المضمّن حسب فهرسه. |
## الطرق

| :- | :- |
