## PageSize class

الفئة تمثل حجم الصفحة في وثيقة PDF.

يعرض نوع PageSize الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| PageSize(x, y) | ينشئ مثيلاً جديداً من فئة PageSize |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| العرض | يحصل أو يضبط عرض الصفحة. |
| الارتفاع | يحصل أو يضبط ارتفاع الصفحة. |
| is_landscape | يحصل على اتجاه الصفحة. يُعيد true إذا كان الاتجاه أفقيًا و false إذا كان عموديًا. |
| a0 | حجم A0 (1189x840 مم). |
| a1 | حجم A1 (840x594 مم). |
| a2 | حجم A2 (594x420 مم). |
| a3 | حجم A3 (420x297 مم). |
| a4 | حجم A4 (297x210 مم). |
| a5 | حجم A5 (210x148 مم). |
| a6 | حجم A6 (148x105 مم). |
| b5 | حجم B5 (250x176 مم). |
| page_letter | حجم Letter (279x216 مم). |
| page_legal | حجم Legal (356x216 مم). |
| page_ledger | حجم Ledger (432x279 مم). |
| p11x17 | تنسيق 11x17 بوصة. |
