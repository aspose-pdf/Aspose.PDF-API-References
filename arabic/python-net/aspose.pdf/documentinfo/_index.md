## DocumentInfo class

يمثل معلومات التعريف لمستند PDF.

يعرض نوع DocumentInfo الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| DocumentInfo(document) | يُنشئ مثيلًا جديدًا من فئة DocumentInfo |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| title | يحصل أو يضبط عنوان المستند. |
| creator | يحصل أو يضبط منشئ المستند. |
| author | يحصل أو يضبط مؤلف المستند. |
| subject | يحصل أو يضبط موضوع المستند. |
| keywords | يحصل أو يضبط الكلمات المفتاحية للمستند. |
| producer | يحصل أو يضبط منتج المستند. |
| creation_date | يحصل أو يضبط تاريخ إنشاء المستند. |
| creation_time_zone | المنطقة الزمنية لتاريخ الإنشاء. |
| mod_time_zone | المنطقة الزمنية لتاريخ التعديل. |
| mod_date | يحصل أو يضبط تاريخ تعديل المستند. |
| trapped | يحصل أو يضبط علامة trapped. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| add(key, value) | يضيف عنصرًا بالمفتاح والقيمة المحددين إلى المجموعة. |
| remove(key) | يزيل العنصر بالمفتاح المحدد من المجموعة. |
| clear_custom_data() | يمسح البيانات المخصصة فقط، ويترك جميع القيم المحددة مسبقًا الأخرى (العنوان، المؤلف، إلخ). |
| is_predefined_key(key) | يحدد ما إذا كان المفتاح معرفًا مسبقًا (Title, Author, إلخ)، وليس مخصصًا. |
