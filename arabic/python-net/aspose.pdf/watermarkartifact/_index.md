## WatermarkArtifact class

الفئة تصف كائن العلامة المائية. قد يُستخدم هذا لـ

نوع WatermarkArtifact يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| WatermarkArtifact() | ينشئ مثلاً من Watermark artifact. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| custom_type | يحصل على اسم نوع القطعة. قد يُستخدم إذا كان نوع القطعة غير قياسي. |
| custom_subtype | يحصل على اسم النوع الفرعي للقطعة. قد يُستخدم إذا كان النوع الفرعي للقطعة ليس نوعًا فرعيًا قياسيًا. |
| type | يحصل على نوع القطعة. |
| subtype | يحصل على النوع الفرعي للقطعة. إذا كان للقطعة نوع فرعي غير قياسي، يمكن قراءة اسم النوع الفرعي عبر CustomSubtype. |
| المحتويات | يحصل على مجموعة من المشغلات الداخلية للقطعة. |
| نموذج | يحصل على XForm للقطعة (إذا تم استخدام XForm). |
| rectangle | يحصل على مستطيل القطعة. |
| position | يحصل أو يعيّن موضع القطعة.<br/>            إذا تم تحديد هذه الخاصية، فإن الهوامش والمحاذاة تُهمل. |
| right_margin | الهامش الأيمن للقطعة. <br/>            إذا تم تحديد الموضع صراحةً (في خاصية Position) يتم تجاهل هذه القيمة. |
| left_margin | الهامش الأيسر للقطعة. <br/>            إذا تم تحديد الموضع صراحةً (في خاصية Position) يتم تجاهل هذه القيمة. |
| top_margin | الهامش العلوي للقطعة. <br/>            إذا تم تحديد الموضع صراحةً (في خاصية Position) يتم تجاهل هذه القيمة. |
| bottom_margin | الهامش السفلي للقطعة. <br/>            إذا تم تحديد الموضع صراحةً (في خاصية Position) يتم تجاهل هذه القيمة. |
| artifact_horizontal_alignment | محاذاة القطعة أفقياً. <br/>            إذا تم تحديد الموضع صراحةً (في خاصية Position) يتم تجاهل هذه القيمة. |
| artifact_vertical_alignment | محاذاة عمودية للعنصر. <br/>            إذا تم تحديد الموضع صراحةً (في خاصية Position) يتم تجاهل هذه القيمة. |
| rotation | يحصل أو يضبط زاوية دوران العنصر. |
| text | يحصل على نص العنصر. |
| image | يحصل على صورة العنصر (إذا كانت موجودة). |
| الشفافية | يحصل أو يضبط شفافية العنصر. القيم الممكنة في النطاق 0..1. |
| سطور | سطور العنصر النصي متعدد الأسطر. |
| text_state | حالة النص لنص العنصر. |
| is_background | إذا كان صحيحًا يتم وضع العنصر خلف محتويات الصفحة. |
## الطرق

| set_lines_and_state(text, text_state) | يضبط النص وخصائص النص للعنصر. يسمح بتحديد عدة سطور. |

| remove_value(name) | يزيل القيمة المخصصة من العنصر. |
| begin_updates() | ابدأ التحديثات المتأخرة. استخدم هذه الميزة إذا كنت بحاجة إلى إجراء عدة تغييرات على نفس العنصر لتحسين الأداء. <br/> عادةً ما يتم تغيير مشغلي العنصر في أي وقت يتم فيه تغيير خاصية العنصر. هذا يؤدي إلى تغيير محتوى الصفحة<br/> في كل مرة يتم فيها تغيير العنصر. لتجنب هذا التأثير ضع جميع تحديثات العنصر بين استدعاءات StartUpdates/SaveUpdates.<br/> هذا يسمح بتغيير محتوى الصفحة مرة واحدة فقط. |
| save_updates() | يحفظ جميع التحديثات في العنصر التي تم إجراؤها بعد استدعاء BeginUpdates(). |
