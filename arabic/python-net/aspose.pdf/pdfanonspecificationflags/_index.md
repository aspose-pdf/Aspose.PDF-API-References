## PdfANonSpecificationFlags class

هذه الفئة تحتفظ بعلامات للتحكم في تحويل PDF/A للحالات التي لا يتطابق فيها مستند PDF المصدر <br/>            مع مواصفات PDF. إذا تم استخدام علامات هذه الفئة فإنها تقلل الأداء <br/>            لكنها ضرورية عندما لا يمكن تحويل مستند PDF المصدر إلى صيغة PDF/A بالطريقة المعتادة. <br/>            بشكل افتراضي يتم تعيين جميع العلامات إلى false.
