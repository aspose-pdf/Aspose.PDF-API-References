## ColumnInfo class

تمثل هذه الفئة معلومات الأعمدة.

يعرض نوع ColumnInfo الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| ColumnInfo() | ينشئ مثيلاً جديداً من الفئة ColumnInfo |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| column_widths | يحصل أو يضبط سلسلة تحتوي على عرض الأعمدة. <br/>            يجب أن تكون قيمة كل عمود مفصولة بمسافة. الوحدة الافتراضية هي النقطة،<br/>            ولكن السنتيمتر، البوصة والنسبة المئوية للعرض المتاح مدعومة أيضاً.<br/>            على سبيل المثال,"120 2.5cm 1.5inch" |
| column_spacing | يحصل أو يضبط سلسلة تحتوي على التباعد بين الأعمدة. <br/>            يجب أن تكون قيمة كل تباعد مفصولة بمسافة. الوحدة الافتراضية هي النقطة،<br/>            ولكن السنتيمتر والبوصة مدعومة أيضاً. على سبيل المثال,"120 2.5cm 1.5inch". |
| column_count | يحصل أو يضبط قيمة عددية صحيحة تشير إلى عدد الأعمدة. |
