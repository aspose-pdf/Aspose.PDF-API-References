## OutlineItemCollection class

يمثل مدخل المخطط في تسلسل هيكل المخطط لوثيقة PDF.

يعرض نوع OutlineItemCollection الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| OutlineItemCollection(outlines) | يُنشئ مثيلًا جديدًا من فئة OutlineItemCollection |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| visible_count | يحصل على العدد الإجمالي لعناصر المخطط في جميع المستويات في تسلسل هرمي لمخطط المستند. |
| title | يحصل أو يعيّن العنوان لهذا عنصر المخطط. |
| الوجهة | يحصل أو يعيّن الوجهة لهذا عنصر المخطط. |
| إجراء | يحصل أو يعيّن الإجراء لهذا عنصر المخطط. |
| اللون | يحصل أو يعيّن اللون لنص العنوان لهذا عنصر المخطط. |
| مائل | يحصل أو يعيّن علامة المائل لنص العنوان لهذا عنصر المخطط |
| عريض | يحصل أو يعيّن علامة العريض لنص العنوان لهذا عنصر المخطط |
| first | يحصل على عنصر المخطط الذي يمثل أول عنصر من المستوى الأعلى في التسلسل الهرمي للمخطط. |
| الأخير | يحصل على عنصر المخطط الذي يمثل آخر عنصر من المستوى الأعلى في التسلسل الهرمي للمخطط. |
| السابق | يحصل على عنصر المخطط الذي يمثل العنصر السابق بالنسبة لهذا العنصر في التسلسل الهرمي للمخطط. |
| التالي | يحصل على عنصر المخطط الذي يمثل العنصر التالي بالنسبة لهذا العنصر في التسلسل الهرمي للمخطط. |
| has_next | تحقق مما إذا كان عنصر المخطط يمثل العنصر التالي بالنسبة لهذا العنصر في التسلسل الهرمي للمخطط. |
| الأصل | يحصل على كائن الأب لهذا عنصر المخطط في التسلسل الهرمي للمخطط. |
| is_synchronized | يحصل على القيمة التي تشير إلى ما إذا كان الوصول إلى هذه المجموعة متزامنًا (آمن للخيوط). |
| sync_root | يحصل على الكائن الذي يمكن استخدامه لمزامنة الوصول إلى هذه المجموعة. |
| فتح | يحصل أو يعيّن حالة الفتح (صحيح/خطأ) لعنصر المخطط. |
| المستوى | يحصل على مستوى التسلسل الهرمي لعنصر المخطط. |
