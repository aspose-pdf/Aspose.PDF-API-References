## FileParams class

يحدد قاموس معلمات الملف المضمن الذي يجب أن يحتوي على معلومات إضافية خاصة بالملف.

يعرض نوع FileParams الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| FileParams(spec) | يُنشئ مثيلًا جديدًا من الفئة FileParams |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| size | حجم الملف المضمن غير المضغوط، بالبايت. |
| creation_date | التاريخ والوقت عندما تم إنشاء الملف المضمن. |
| mod_date | التاريخ والوقت عندما تم تعديل الملف المضمن آخر مرة. |
| check_sum | سلسلة بطول 16 بايت تمثل المجموع الاختباري للبايتات الخاصة بالملف المضمن غير المضغوط. <br/>            يتم حساب المجموع الاختباري بتطبيق خوارزمية MD5 القياسية لتلخيص الرسائل <br/>            على بايتات تدفق الملف المضمن. |
