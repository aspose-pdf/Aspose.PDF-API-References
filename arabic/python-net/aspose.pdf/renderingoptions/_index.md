| :- | :- |

## الخصائص
| الاسم | الوصف |
| :- | :- |
| barcode_optimization | يحصل أو يضبط وضع تحسين الباركود. |
| optimize_dimensions | يحصل أو يضبط وضع تحسين الأبعاد. |
| system_fonts_native_rendering | يحصل أو يضبط وضع يتم فيه عرض الخطوط النظامية أصلياً. |
| use_new_imaging_engine | يحصل أو يضبط علامة تحدد ما إذا كان محرك التصوير الجديد يُستخدم أم لا. |
| width_extra_units | يحصل أو يضبط قيمة تُستخدم لزيادة أو تقليل عرض المستطيل لمعامل AppendRectangle. |
| height_extra_units | يحصل أو يضبط قيمة تُستخدم لزيادة أو تقليل عرض المستطيل لمعامل AppendRectangle. |
| convert_fonts_to_unicode_ttf | يشير إلى أن جميع الخطوط سيتم تحويلها إلى إصدارات TTF يونيكود. هذا مفيد لأسباب التوافق <br/>             و لتحسين استخدام الخطوط، لأن كل خط TTF جديد لن يحتوي على جميع الرموز <br/>             من الخط الأصلي، بل فقط الرموز المستخدمة في النص. |
| use_font_hinting | استخدام هذه العلامة يُفعِّل آلية تحسين تلميحات الخط. تحسين تلميحات الخط هو استخدام تعليمات رياضية لضبط عرض <br/>            الخط الخارطي. في بعض الحالات قد يحل تشغيل هذه العلامة مشاكل وضوح النص. <br/>            في الوقت الحالي قد يؤثر استخدام هذه العلامة فقط على خطوط TTF، إذا تم استخدام هذه الخطوط في المستند الأصلي. |
| scale_images_to_fit_page_width | يحصل أو يضبط قيمة تُستخدم لتكبير جميع الصور على الصفحة لتناسب عرض الصفحة. |
| interpolation_high_quality | يحصل أو يعيّن وضع الجودة العالية للتقريب. |
| max_fonts_cache_size | العدد الأقصى للخطوط في ذاكرة التخزين المؤقت للخطوط. القيمة الافتراضية هي 10. |
| max_symbols_cache_size | العدد الأقصى للرموز في ذاكرة التخزين المؤقت للرموز. القيمة الافتراضية هي 100. |
| default_font_name | يحصل/يعيّن الاسم الافتراضي للخط المستخدم كبديل للخطوط المفقودة. |
| ignore_resource_font_errors | يحصل أو يعيّن إشارة إلى أن الأخطاء المتعلقة بغياب الخط سيتم تجاهلها.<br/>            true - يعني أن أخطاء غياب الخط سيتم تجاهلها. سيتم تخطي مقاطع النص التي تشير إلى موارد غير صحيحة أثناء المعالجة.<br/>            false بشكل افتراضي |
