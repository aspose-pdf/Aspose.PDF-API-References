## XImageCollection class

الفئة تمثل مجموعة XImage.

نوع XImageCollection يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | يرجع true إذا كان الكائن متزامنًا. |
| sync_root | يرجع كائن المزامنة. |
| names | يحصل على مصفوفة أسماء الصور. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على الصورة من المجموعة حسب فهرستها. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| add(image) | يضيف صورة جديدة إلى قائمة الصور. هذه الطريقة تضيف الصورة كمرجع إلى نفس PdfObject (ما يسمح بتقليل حجم الملف) |
| add(image) | يضيف الكيان إلى نهاية المجموعة، بحيث يمكن الوصول إلى الكيان عبر الفهرس الأخير. |
| add(image, filter_type) | يضيف الكيان إلى نهاية المجموعة، بحيث يمكن الوصول إلى الكيان عبر الفهرس الأخير. |
| add(image, quality) | يضيف الكيان إلى نهاية المجموعة، بحيث يمكن الوصول إلى الكيان عبر الفهرس الأخير. |
| delete(index) | يزيل المؤشر من المجموعة حسب المؤشر. |
| delete(index, action) | يزيل الصورة من المجموعة حسب الفهرس مع تنفيذ الإجراء المحدد بواسطة معامل الإجراء. |
| delete(name) | يزيل العنصر من المجموعة حسب الاسم. |
| delete(name, action) | يزيل العنصر من المجموعة حسب الاسم. |
| delete() | يزيل المؤشر من المجموعة حسب المؤشر. |
| replace(index, stream) | استبدل الصورة في المجموعة بصورة أخرى. |
| replace(index, stream, quality, is_black_and_white) | استبدل الصورة في المجموعة بصورة أخرى. |
| replace(index, stream, quality) | استبدل الصورة في المجموعة بصورة أخرى. |
| get_image_name(image) | يعيد الاسم في قائمة الصور الذي هو مفتاح الصورة المعطاة. |
