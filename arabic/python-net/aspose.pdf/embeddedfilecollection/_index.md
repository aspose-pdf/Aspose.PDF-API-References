## EmbeddedFileCollection class

فئة تمثل مجموعة الملفات المضمنة.

يعرض نوع EmbeddedFileCollection الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | يحصل على قيمة تشير إلى ما إذا كان الوصول إلى هذه المجموعة متزامنًا (آمن للخيوط). |
| sync_root | يحصل على كائن يمكن استخدامه لمزامنة الوصول إلى هذه المجموعة. |
| المفاتيح | يرجع قائمة مفاتيح مرفقات الملفات. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على الملف المضمّن حسب فهرسه. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| delete(name) | يحذف الملف من المجموعة باستخدام مفتاحه في المجموعة. |
| delete() | يحذف الملف من المجموعة باستخدام مفتاحه في المجموعة. |
| add(key, file) | يضيف الملف إلى الملفات المضمّنة بالمفتاح المحدد. |
| delete_by_key(key) | يحذف الملف من المجموعة باستخدام مفتاحه في المجموعة. |
| find_by_name(name) | يرجع الملف المضمّن حسب اسمه. |
