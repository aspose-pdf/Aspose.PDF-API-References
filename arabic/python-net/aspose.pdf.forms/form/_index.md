## Form class

فئة تمثل كائن النموذج.

نوع Form يكشف عن الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | يرجع true إذا كان الكائن آمنًا من حيث الخيوط. |
| sync_root | يرجع كائن المزامنة. |
| auto_recalculate | إذا تم ضبطه، سيتم إعادة حساب جميع حقول النموذج عند تغيير أي حقل. القيمة الافتراضية هي true. اضبطه على false لزيادة الأداء عند ملء النموذج بعدد كبير من الحقول المحسوبة. |
| auto_restore_form | إذا تم ضبطه، سيتم إنشاء حقول النموذج الغائبة تلقائيًا إذا كانت موجودة في التعليقات التوضيحية. |
| default_resources | يحصل على الموارد الافتراضية الموجودة في هذا النموذج. |
| default_appearance | يحصل أو يضبط المظهر الافتراضي للنموذج (كائن يصف الخط الافتراضي، حجم النص واللون للحقول في النموذج). |
| xfa | يحصل على بيانات XFA للنموذج (إذا كانت موجودة). |
| ignore_needs_rendering | إذا كانت هذه الخاصية true فإن قيمة المفتاح NeedsRendering سيتم تجاهلها أثناء تحويل <br/>            نموذج XFA إلى نموذج Standard. القيمة الافتراضية هي false. |
| remove_permission | إذا كانت هذه الخاصية true سيتم إزالة القاموس "Perms" من مستند pdf بعد التحويل <br/>            المستندات الديناميكية إلى معيارية. يمكن أن يحتوي القاموس "Perms" على قواعد تعيق عرض اختيار <br/>            الحقول الإلزامية في قارئ Adobe Acrobat.<br/>            القيمة الافتراضية هي false. |
| emulate_requierd_groups | إذا كانت هذه الخاصية true فسيتم رسم مستطيلات حدود حمراء إضافية لعناصر Xfa exclGroup المطلوبة<br/>            تم تقديم هذه الخاصية بسبب عدم وجود نظائر لـ exclGroup أثناء تحويل تمثيل نماذج Xfa <br/>            إلى معيارية.<br/>            القيمة الافتراضية هي false. |
| type | يحصل على نوع النموذج. القيم الممكنة هي: Standard, Static, Dynamic. |
| fields | يحصل على قائمة بجميع الحقول في أدنى مستوى من النموذج الهرمي. |
| signatures_exist | إذا تم التعيين، يحتوي المستند على حقل توقيع واحد على الأقل. |
| signatures_append_only | إذا تم التعيين، يحتوي المستند على توقيعات قد تُصبح غير صالحة إذا تم حفظ (كتابة) الملف بطريقة تغير محتوياته السابقة، <br/>            على عكس التحديث التراكمي. |
| sign_dependent_elements_rendering_mode_when_converted | يمكن للنماذج أن تحتوي على معلومات توقيع، أي يمكن أن تكون موقعة أو غير موقعة.<br/>              وأحيانًا يجب أن تعتمد طريقة عرض النموذج على ما إذا كان النموذج موقّعًا أم لا.<br/>              تخبر هذه الخاصية محول النموذج (مثلاً أثناء تحويل نموذج XFA إلى نموذج Standard)<br/>              ما إذا كان يجب عرض النموذج الناتج كـ موقّع أو كـ غير موقّع. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على حقل النموذج بواسطة فهرس الحقل. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| delete(field) | احذف الحقل من النموذج. |
| delete(field_name) | يحذف الحقل من النموذج بناءً على اسمه. |
| add(field, page_number) | يضيف حقلًا إلى النموذج. |
| add(field) | يضيف حقلًا إلى النموذج. |
| add(field, partial_name, page_number) | يضيف حقلًا جديدًا إلى النموذج؛ إذا تم وضع هذا الحقل بالفعل على نموذج آخر أو هذا النموذج، يتم إنشاء نسخة من الحقل. |
| has_field(field) | تحقق مما إذا كان النموذج يحتوي بالفعل على الحقل المحدد. |
| has_field(field_name) | يحدد ما إذا كان الحقل بالاسم المحدد قد أُضيف بالفعل إلى النموذج. |
| copy_to(array, index) | ينسخ الحقول الموضوعة على النموذج إلى مصفوفة. |
| flatten() | يزيل جميع حقول النموذج ويضع قيمها مباشرة على الصفحة. |
| add_field_appearance(field, page_number, rect) | يضيف مظهرًا إضافيًا للحقل إلى الصفحة المحددة من المستند في الموقع المحدد. |
| get_fields_in_rect(rect) | يعيد الحقول داخل المستطيل المحدد. |
