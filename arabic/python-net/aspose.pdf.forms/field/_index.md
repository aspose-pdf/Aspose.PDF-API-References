## Field class

الفئة الأساسية لحقول نموذج Acro.

نوع Field يكشف عن الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Field(doc) | يُهيئ نسخة جديدة من الفئة Field |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| vertical_alignment | لا شيء |
| horizontal_alignment | يحصل أو يعيّن محاذاة النص للتعليق التوضيحي. |
| margin | لا شيء |
| is_first_paragraph_in_column | لا شيء |
| is_kept_with_next | لا شيء |
| is_in_new_page | لا شيء |
| is_in_line_paragraph | لا شيء |
| hyperlink | لا شيء |
| z_index | لا شيء |
| تحديث_المظهر_عند_التحويل | إذا كان صحيحًا، سيتم تحديث مظهر التعليق التوضيحي قبل تحويل مستند PF إلى صورة. هذا يسمح بتحويل الحقول بشكل صحيح لكنه قد يتطلب وقتًا أكثر. |
| استخدام_مجموعة_خط_فرعية | إذا تم تعيين هذه الخاصية إلى true، ستُضاف الخطوط إلى المستند كجزء فرعي. القيمة الافتراضية هي true. |
| الأعلام | علامات التعليق التوضيحي. |
| نوع_التعليق_التوضيحي | يحصل على نوع التعليق التوضيحي. |
| العرض | يحصل أو يعيّن عرض التعليق التوضيحي. |
| الإجراءات | يحصل على إجراءات التعليق التوضيحي. |
| الارتفاع | يحصل أو يعيّن ارتفاع التعليق التوضيحي. |
| المستطيل | يحصل أو يضبط مستطيل الحقل. |
| المحتويات | يحصل أو يعيّن نص التعليق التوضيحي. |
| name | يحصل أو يعيّن اسم التعليق التوضيحي على الصفحة. |
| تم_التعديل | يحصل أو يعيّن التاريخ والوقت عندما تم تعديل التعليق التوضيحي مؤخرًا. |
| اللون | يحصل أو يعيّن لون التعليق التوضيحي. |
| border | يحصل أو يعيّن خصائص حدود التعليق التوضيحي. [border](/pdf/python-net/aspose.pdf.annotations/annotation/) |
| الحالة_النشطة | يحصل أو يضبط حالة مظهر التعليق التوضيحي الحالي. |
| الخصائص | يحصل على خصائص التعليق التوضيحي. |
| الحالات | يحصل على قاموس المظهر للتعليق التوضيحي. |
| المحاذاة | محاذاة التعليق التوضيحي. هذه الخاصية قديمة. استخدم HorizontalAligment بدلاً من ذلك. |
| محاذاة_النص_الأفقية | يحصل أو يعيّن محاذاة النص للتعليق التوضيحي. |
| الاسم_الكامل | يحصل على الاسم المؤهل بالكامل للتعليق التوضيحي. |
| المظهر | يحصل على قاموس المظهر للتعليق التوضيحي. |
| فهرس_الصفحة | يحصل على فهرس الصفحة التي تحتوي على هذا الحقل. |
| عند_التفعيل | إجراء يتم تنفيذه عندما يتم تنشيط التعليق التوضيحي. |
| تمييز | وضع تمييز التعليق التوضيحي. |
| الأصل | يحصل على أصل التعليق التوضيحي. |
| default_appearance | يحصل أو يضبط المظهر الافتراضي للحقل. |
| read_only | يحصل أو يضبط حالة القراءة فقط للحقل. |
| required | يحصل أو يضبط حالة required للحقل. |
| قابل للتصدير | يحصل أو يضبط علامة قابل للتصدير للحقل. |
| partial_name | يحصل أو يضبط الاسم الجزئي للحقل. |
| alternate_name | يحصل أو يضبط الاسم البديل للحقل (حقل بديل <br/>            الاسم الذي سيُستخدم بدلاً من الاسم الفعلي للحقل <br/>            حيثما يتم التعرف على الحقل في واجهة المستخدم).<br/>            يُستخدم الاسم البديل كأداة تلميح للحقل في Adobe Acrobat. |
| mapping_name | يحصل أو يضبط اسم التخطيط للحقل الذي سيُستخدم عند تصدير بيانات نماذج الحقول التفاعلية من المستند. |
| value | يحصل أو يضبط قيمة الحقل. |
| is_synchronized | يرجع true إذا كان القاموس متزامناً. |
| sync_root | كائن المزامنة. |
| is_group | يحصل أو يعيّن قيمة منطقية تشير إلى ما إذا كان هذا الحقل غير نهائي أي مجموعة من الحقول. |
| annotation_index | يحصل أو يعيّن فهرس هذا التعليق على الصفحة. |
| is_shared_field | خاصية لدعم المولد. تُستخدم عندما يُضاف الحقل إلى الرأس أو التذييل. إذا كان true، سيتم إنشاء هذا الحقل مرة واحدة وستكون مظهره مرئيًا في جميع صفحات المستند. إذا كان false، سيتم إنشاء حقل منفصل لكل صفحة من المستند. |
| fit_into_rectangle | إذا كان true فسيتم تقليل حجم الخط ليتناسب مع النص داخل المستطيل المحدد. |
| max_font_size | الحد الأقصى لحجم الخط الذي يمكن استخدامه لمحتويات الحقل. -1 لعدم فحص الحجم. |
| min_font_size | الحد الأدنى لحجم الخط الذي يمكن استخدامه لمحتويات الحقل. -1 لعدم فحص الحجم. |
| tab_order | يحصل أو يعيّن ترتيب التبويب للحقل. |
