## Option class

الفئة تمثل خيار حقل الاختيار.

نوع Option يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| value | يحصل أو يعيّن قيمة تصدير الخيار. |
| name | يحصل أو يعيّن اسم الخيار. |
| selected | يحصل أو يعيّن حالة الاختيار للخيار. تُعيد true إذا كان الخيار مختارًا. |
| index | يحصل على فهرس الخيار. |
