## OptionCollection class

الفئة تمثل مجموعة خيارات حقل الاختيار.

نوع OptionCollection يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | يعيد true إذا كان الكائن متزامنًا. |
| sync_root | كائن المزامنة للمجموعة. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على الخيار حسب الفهرس. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| get(index) | يحصل على الخيار حسب الفهرس. |
| get(name) | يحصل على الخيار من المجموعة حسب اسم الخيار. |
