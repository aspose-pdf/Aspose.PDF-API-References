## IconFit class

يصف كيفية عرض أيقونة التعليق التوضيحي للودجت داخل مستطيل التعليق الخاص به.

يعرض نوع IconFit الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| scaling_reason | يحصل على أو يعيّن سبب التحجيم. |
| scaling_mode | نوع التحجيم الذي سيُستخدم.        /// |
| leftover_left | يحصل على أو يعيّن المسافة المخصصة على يسار الأيقونة. |
| leftover_bottom | يحصل على أو يعيّن المسافة المخصصة أسفل الأيقونة. |
| spread_on_border | إذا كان true، يشير إلى أن مظهر الزر يجب أن يُحجم ليتناسب بالكامل داخل حدود التعليق التوضيحي دون أخذ عرض خط الحدود في الاعتبار. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| name_to_scaling_reason(reason) | يحوّل اسم سبب التحجيم إلى كائن ScalingReason. |
| scaling_reason_to_name(reason) | يقوم بتحويل كائن سبب التحجيم إلى اسم. |
| name_to_scaling_mode(mode) | يقوم بتحويل اسم وضع التحجيم إلى كائن ScalingMode. |
| scaling_mode_to_name(mode) | يقوم بتحويل كائن وضع التحجيم إلى اسم. |
