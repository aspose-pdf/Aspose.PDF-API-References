## GoToRemoteAction class

يمثّل إجراء الانتقال إلى عن بُعد (remote go-to) المشابه لإجراء الانتقال إلى العادي لكنه ينتقل إلى وجهة في ملف PDF آخر بدلاً من الملف الحالي.

نوع GoToRemoteAction يكشف عن الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| GoToRemoteAction(remote_pdf, remote_page_number) | ينشئ مثيلاً جديداً من فئة GoToRemoteAction |
| GoToRemoteAction(remote_pdf, destination) | ينشئ مثيلاً جديداً من فئة GoToRemoteAction |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| التالي | الإجراءات التالية في التسلسل. |
| الوجهة | يحصل أو يعيّن الوجهة للانتقال إليها. |
| file | يحصل أو يضبط مواصفات الملف الذي يقع فيه الوجهة. |
| new_window | يحصل أو يضبط علمًا يحدد ما إذا كان سيتم فتح المستند الهدف في نافذة جديدة. |
