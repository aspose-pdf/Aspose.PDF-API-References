## LinkAnnotation class

يمثل إما رابطًا تشعبيًا إلى وجهة في مكان آخر داخل المستند أو إجراءً يجب تنفيذه.

نوع LinkAnnotation يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| LinkAnnotation(page, rect) | ينشئ مثيلاً جديدًا من الفئة LinkAnnotation |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| vertical_alignment | يحصل أو يضبط محاذاة عمودية للفقرة |
| horizontal_alignment | يحصل أو يعيّن محاذاة النص للتعليق التوضيحي. |
| margin | يحصل أو يضبط هامشًا خارجيًا للفقرة (لإنشاء PDF) |
| is_first_paragraph_in_column | يحصل أو يضبط قيمة منطقية تشير إلى ما إذا كانت هذه الفقرة ستظهر في العمود التالي.<br/>            القيمة الافتراضية هي false. (لإنشاء PDF) |
| is_kept_with_next | يحصل أو يضبط قيمة منطقية تشير إلى ما إذا كانت الفقرة الحالية ستبقى في نفس الصفحة مع الفقرة التالية.<br/>            القيمة الافتراضية هي false. (لإنشاء PDF) |
| is_in_new_page | يحصل أو يضبط قيمة منطقية تجبر هذه الفقرة على الإنشاء في صفحة جديدة.<br/>            القيمة الافتراضية هي false. (لإنشاء PDF) |
| is_in_line_paragraph | يحصل أو يضبط ما إذا كانت الفقرة مضمنة داخل السطر.<br/>            القيمة الافتراضية هي false. (لإنشاء PDF) |
| hyperlink | يحصل أو يضبط الارتباط التشعبي للجزء (لمولد PDF). |
| z_index | يحصل أو يضبط قيمة عددية تشير إلى ترتيب Z للرسمة. الرسمة ذات ZIndex أكبر <br/>            ستوضع فوق الرسمة ذات ZIndex أصغر. يمكن أن يكون ZIndex سالبًا. الرسمة ذات ZIndex سالب <br/>            ستوضع خلف النص في الصفحة. |
| تحديث_المظهر_عند_التحويل | إذا كان صحيحًا، سيتم تحديث مظهر التعليق التوضيحي قبل تحويل مستند PF إلى صورة. هذا يسمح بتحويل الحقول بشكل صحيح لكنه قد يتطلب وقتًا أكثر. |
| استخدام_مجموعة_خط_فرعية | إذا تم تعيين هذه الخاصية إلى true، ستُضاف الخطوط إلى المستند كجزء فرعي. القيمة الافتراضية هي true. |
| الأعلام | علامات التعليق التوضيحي. |
| نوع_التعليق_التوضيحي | يحصل على نوع التعليق التوضيحي. |
| العرض | يحصل أو يعيّن عرض التعليق التوضيحي. |
| الإجراءات | يحصل على قائمة إجراءات التعليقات التوضيحية. |
| الارتفاع | يحصل أو يعيّن ارتفاع التعليق التوضيحي. |
| المستطيل | يحصل أو يضبط مستطيل التعليق التوضيحي. |
| المحتويات | يحصل أو يعيّن نص التعليق التوضيحي. |
| name | يحصل أو يعيّن اسم التعليق التوضيحي على الصفحة. |
| تم_التعديل | يحصل أو يعيّن التاريخ والوقت عندما تم تعديل التعليق التوضيحي مؤخرًا. |
| اللون | يحصل أو يعيّن لون التعليق التوضيحي. |
| border | يحصل أو يعيّن خصائص حدود التعليق التوضيحي. [border](/pdf/python-net/aspose.pdf.annotations/annotation/) |
| الحالة_النشطة | يحصل أو يضبط حالة مظهر التعليق التوضيحي الحالي. |
| الخصائص | يحصل على خصائص التعليق التوضيحي. |
| الحالات | يحصل على قاموس المظهر للتعليق التوضيحي. |
| المحاذاة | محاذاة التعليق التوضيحي. هذه الخاصية قديمة. استخدم HorizontalAligment بدلاً من ذلك. |
| محاذاة_النص_الأفقية | يحصل أو يعيّن محاذاة النص للتعليق التوضيحي. |
| الاسم_الكامل | يحصل على الاسم المؤهل بالكامل للتعليق التوضيحي. |
| المظهر | يحصل على قاموس المظهر للتعليق التوضيحي. |
| فهرس_الصفحة | يحصل على فهرس الصفحة التي تحتوي على التعليق التوضيحي. |
| إجراء | إجراء يتم تنفيذه عند تفعيل التعليق التوضيحي للرابط. |
| الوجهة | وجهة تُعرض عند تفعيل التعليق التوضيحي. |
| تمييز | التأثير البصري الذي يُستخدم عند ضغط زر الفأرة أو الاستمرار في الضغط داخل المنطقة النشطة. |
