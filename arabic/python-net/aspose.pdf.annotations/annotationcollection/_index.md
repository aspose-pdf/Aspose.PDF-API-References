## AnnotationCollection class

فئة تمثل مجموعة التعليقات.

نوع AnnotationCollection يكشف عن الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | يحصل على قيمة تشير إلى ما إذا كان الوصول إلى Aspose.Pdf.Annotations.AnnotationCollection متزامنًا (آمن للخيوط). |
| sync_root | يحصل على كائن يمكن استخدامه لمزامنة الوصول إلى Aspose.Pdf.Annotations.AnnotationCollection. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | فهرس العنصر المراد الحصول عليه. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| delete(index) | يحذف التعليق التوضيحي من المجموعة حسب الفهرس. |
| delete() | يحذف التعليق التوضيحي من المجموعة حسب الفهرس. |
| delete(annotation) | يحذف التعليق التوضيحي من المجموعة حسب الفهرس. |
| add(annotation, consider_rotation) | يضيف التعليق إلى المجموعة. إذا تم تدوير الصفحة فسيتم إعادة حساب مستطيل التعليق وفقًا لذلك. |
| accept(visitor) | يقبل الزائر لمعالجة التعليق. |
| find_by_name(name) | يعيد التعليق بناءً على اسمه. |
