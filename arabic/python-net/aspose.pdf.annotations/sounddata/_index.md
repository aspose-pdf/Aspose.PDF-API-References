## SoundData class

يمثل بيانات صوتية تحدد الصوت الذي يُشغل عند تفعيل التعليق.

يعرض نوع SoundData الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| rate | يحصل أو يضبط معدل العينة، بالعينات في الثانية. |
| قنوات | يحصل أو يضبط عدد قنوات الصوت. |
| بتات | يحصل أو يضبط عدد البتات لكل قيمة عينة لكل قناة. |
| المحتويات | يحصل على تدفق الصوت الذي سيتم تشغيله عند تنشيط التعليق. |
| الترميز | يحصل أو يضبط تنسيق الترميز لبيانات العينة. |
