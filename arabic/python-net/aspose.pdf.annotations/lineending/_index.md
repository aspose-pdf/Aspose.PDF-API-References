## LineEnding enumeration

| :- | :- |
| NONE | لا توجد نهاية سطر. |
| مربع | مربع مملوء بلون داخل التعليق، إذا كان موجودًا. |
| CIRCLE | دائرة مملوءة بلون داخل التعليق، إذا كان موجودًا. |

| CLOSED_ARROW | خطان قصيران يلتقيان بزاوية حادة كما في نمط السهم المفتوح ويتصلان بخط ثالث لتشكيل رأس سهم مغلق مثلثي مملوء بلون داخل التعليق، إذا كان موجودًا. |
