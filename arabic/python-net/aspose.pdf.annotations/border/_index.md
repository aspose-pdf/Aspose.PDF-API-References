## Border class

فئة تمثل خصائص حدود التعليق.

نوع Border يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Border(parent) | ينشئ مثيلًا جديدًا من فئة Border |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| h_corner_radius | يحصل أو يضبط نصف قطر الزاوية الأفقية. |
| v_corner_radius | يحصل أو يضبط نصف قطر الزاوية العمودية. |
| العرض | يحصل أو يضبط عرض الحدود. |
| effect_intensity | يحصل أو يضبط شدة التأثير. النطاق الصالح للقيمة هو [0..2]. |
| style | يحصل أو يضبط نمط الحدود. |
| effect | يحصل أو يضبط تأثير الحدود. |
| dash | يحصل أو يضبط نمط الشرط. |
