## PdfActionCollection class

فئة تصف قائمة الإجراءات.

نوع PdfActionCollection يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| count | يحصل على عدد الإجراءات. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على الإجراء حسب فهرسه. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| delete(index) | إزالة الإجراء حسب الفهرس. |
| add(action) | إضافة إجراء إلى قائمة الإجراءات. |
