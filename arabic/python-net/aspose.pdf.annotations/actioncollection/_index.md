## ActionCollection class

مجموعة من الإجراءات

نوع ActionCollection يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_synchronized | يرجع true إذا كان الكائن متزامنًا. |
| sync_root | يحصل على كائن المزامنة. |
## Indexer
| الاسم | الوصف |
| :- | :- |
| [index] | يحصل على الإجراء حسب فهرسه. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| delete(index) | يزيل الإجراء من المجموعة حسب الفهرس. |
| delete() | يزيل الإجراء من المجموعة حسب الفهرس. |
