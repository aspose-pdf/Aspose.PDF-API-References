## SoundSampleData class

يمثل مدخلات إضافية خاصة بكائن صوت (القسم 9.2 PDF1-7).

نوع SoundSampleData يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| SoundSampleData(sampling_rate) | يُنشئ مثيلاً جديدًا لفئة SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels) | يُنشئ مثيلاً جديدًا لفئة SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel) | يُنشئ مثيلاً جديدًا لفئة SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel, sound_sample_data_encoding_format) | يُنشئ مثيلاً جديدًا لفئة SoundSampleData |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| sampling_rate | يحصل أو يعيّن معدل العينة. |
| number_of_sound_channels | يحصل أو يضبط عدد قنوات الصوت. |
| bits_per_channel | يحصل أو يضبط عدد البتات لكل قيمة عينة لكل قناة. |
| encoding_format | يحصل أو يعيّن تنسيق الترميز. |
| DEFAULT_SAMPLING_RATE | القيمة الافتراضية لـ SamplingRate. |
| DEFAULT_OF_SOUND_CHANNELS | القيمة الافتراضية لمعلمة القنوات. |
| DEFAULT_OF_BITS_PER_CHANNEL | القيمة الافتراضية لمعلمة BitsPerchannel. |
| DEFAULT_ENCODING_FORMAT | القيمة الافتراضية لتنسيق الترميز. |
