## SubmitFormAction class

فئة تصف إجراء إرسال النموذج.

نوع SubmitFormAction يكشف عن الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| SubmitFormAction() | يُنشئ كائن SubmitFormAction. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| التالي | الإجراءات التالية في التسلسل. |
| الأعلام | يحصل أو يعيّن العلامات الخاصة بإجراء الإرسال. |
| url | عنوان URL الوجهة. |
| EXCLUDE | إذا كان غير محدد، تحدد مصفوفة Fields الحقول التي يجب تضمينها في الإرسال. |
| INCLUDE_NO_VALUE_FIELDS | إذا تم التعيين، يجب إرسال جميع الحقول المحددة بواسطة مصفوفة Fields وعلم Include/Exclude. |
| EXPORT_FORMAT | إذا تم التعيين، يجب إرسال أسماء الحقول والقيم بتنسيق HTML Form. |
| GET_METHOD | إذا تم التعيين، يجب إرسال أسماء الحقول والقيم باستخدام طلب HTTP GET. |
| SUBMIT_COORDINATES | إذا تم التعيين، يجب نقل إحداثيات نقرة الفأرة التي تسببت في إجراء submit-form كجزء من بيانات النموذج. |
| XFDF | إذا تم التعيين، يجب إرسال أسماء الحقول والقيم كـ XFDF. |
| INCLUDE_APPEND_SAVES | إذا تم التعيين، يجب أن يتضمن ملف FDF المرسل محتويات جميع التحديثات المتزايدة. |
| INCLUDE_ANNOTATIONS | إذا تم التعيين، يجب أن يتضمن ملف FDF المرسل جميع تعليقات التوسيم في مستند PDF الأساسي. |
| SUBMIT_PDF | إذا تم التعيين، يجب إرسال المستند كـ PDF، باستخدام نوع محتوى MIME application/pdf. |
| CANONICAL_FORMAT | إذا تم التعيين، يجب تحويل أي قيم حقول مُرسلة تمثل تواريخ إلى الصيغة القياسية. |
| EXCL_NON_USER_ANNOTS | إذا تم التعيين، يجب أن يتضمن فقط تلك تعليقات التوسيم التي يتطابق إدخال T الخاص بها مع اسم المستخدم الحالي. |
| EXCL_F_KEY | إذا تم التعيين، يجب أن يستثني ملف FDF المرسل إدخال F. |
| EMBED_FORM | إذا تم التعيين، يجب أن يكون إدخال F في ملف FDF المرسل مواصفة ملف تحتوي على <br/>            تدفق ملف مضمّن يمثل ملف PDF الذي يتم إرسال FDF منه. |
