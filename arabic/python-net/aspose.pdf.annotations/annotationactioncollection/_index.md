## AnnotationActionCollection class

يمثل مجموعة إجراءات التعليق.

نوع AnnotationActionCollection يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| on_enter | يحصل أو يعيّن إجراءً يُنفّذ عندما يدخل المؤشر منطقة التعليق النشطة. |
| on_exit | يحصل أو يعيّن إجراءً يُنفّذ عندما يخرج المؤشر من منطقة التعليق النشطة. |
| on_press_mouse_btn | يحصل أو يعيّن إجراءً يُنفّذ عندما يُضغط زر الفأرة داخل منطقة التعليق النشطة. |
| on_release_mouse_btn | يحصل أو يعيّن إجراءً يُنفّذ عندما يُطلق زر الفأرة داخل منطقة التعليق النشطة. |
| on_receive_focus | يحصل أو يعيّن إجراءً يُنفّذ عندما يتلقى التعليق تركيز الإدخال. |
| on_open_page | يحصل أو يعيّن إجراءً يُنفّذ عندما تُفتح الصفحة التي تحتوي على التعليق. |
| on_close_page | يحصل أو يعيّن إجراءً يُنفّذ عندما تُغلق الصفحة التي تحتوي على التعليق. |
| on_show_page | يحصل أو يعيّن إجراءً يُنفّذ عندما تصبح الصفحة التي تحتوي على التعليق مرئية في واجهة مستخدم تطبيق العارض. |
| on_hide_page | يحصل أو يعيّن إجراءً يتم تنفيذه عندما تصبح الصفحة التي تحتوي على التعليق غير مرئية بعد الآن في واجهة مستخدم تطبيق العارض. |
| on_lost_focus | يحصل أو يعيّن إجراءً يتم تنفيذه عندما يفقد التعليق تركيز الإدخال. |
| on_modify_character | يحصل أو يعيّن إجراءً يتم تنفيذه عندما يقوم المستخدم بتعديل حرف الحقل. |
| on_validate | يحصل أو يعيّن إجراءً يتم تنفيذه عندما يغيّر المستخدم محتويات الحقل. |
| on_format | يحصل أو يعيّن إجراءً يتم تنفيذه لتنسيق قيمة الحقل. |
| on_calculate | يحصل أو يعيّن إجراءً لحساب قيمة الحقل. |
