## Ellipse class

نوع القطع الناقص يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Ellipse(left, bottom, width, height) | يقوم بإنشاء نسخة جديدة من فئة Ellipse |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| graph_info | يحصل أو يضبط كائن [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) الذي يشير إلى معلومات الرسم، مثل اللون،<br/>            عرض الخط، إلخ. |
| text | يحصل أو يضبط نصاً للشكل |
| left | يحصل أو يضبط قيمة عائمة تشير إلى الموضع الأيسر للقطع الناقص. |
| bottom | يحصل أو يضبط قيمة عائمة تشير إلى الموضع السفلي للقطع الناقص. |
| العرض | يحصل أو يضبط قيمة عائمة تشير إلى عرض القطع الناقص. |
| الارتفاع | يحصل أو يضبط قيمة عائمة تشير إلى ارتفاع القطع الناقص. |
