## Arc class

يمثل قوسًا.

نوع القوس يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | ينشئ مثيلاً جديداً من فئة القوس |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| graph_info | يحصل أو يضبط كائن [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) الذي يشير إلى معلومات الرسم، مثل اللون،<br/>            عرض الخط، إلخ. |
| text | يحصل أو يضبط نصاً للشكل |
| pos_x | يسترجع أو يعيّن قيمة عائمة تشير إلى الإحداثي X لمركز القوس. |
| pos_y | يسترجع أو يعيّن قيمة عائمة تشير إلى الإحداثي Y لمركز القوس. |
| radius | يسترجع أو يعيّن قيمة عائمة تشير إلى نصف قطر القوس. |
| alpha | يسترجع أو يعيّن قيمة عائمة تشير إلى درجة الزاوية الابتدائية للقوس. |
| beta | يسترجع أو يعيّن قيمة عائمة تشير إلى درجة الزاوية النهائية للقوس. |
