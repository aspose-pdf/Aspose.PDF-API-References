## Circle class

يمثل دائرة.

نوع الدائرة يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Circle(pos_x, pos_y, radius) | ينشئ مثيلاً جديداً من فئة الدائرة |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| graph_info | يحصل أو يضبط كائن [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) الذي يشير إلى معلومات الرسم، مثل اللون،<br/>            عرض الخط، إلخ. |
| text | يحصل أو يضبط نصاً للشكل |
| pos_x | يسترجع أو يعيّن قيمة عائمة تشير إلى الإحداثي X لمركز الدائرة. |
| pos_y | يسترجع أو يعيّن قيمة عائمة تشير إلى الإحداثي Y لمركز الدائرة. |
| radius | يسترجع أو يعيّن قيمة عائمة تشير إلى نصف قطر الدائرة. |
