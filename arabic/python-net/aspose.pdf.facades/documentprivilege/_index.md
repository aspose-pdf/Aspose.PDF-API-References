## DocumentPrivilege class

يمثل الصلاحيات للوصول إلى ملف PDF. راجع [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             هناك 4 طرق لاستخدام هذه الفئة:<br/>             1.استخدام الصلاحية المحددة مسبقًا مباشرة.<br/>             2.استنادًا إلى صلاحية محددة مسبقًا وتغيير بعض الأذونات المحددة.<br/>             3.استنادًا إلى صلاحية محددة مسبقًا وتغيير بعض تركيبة أذونات Adobe Professional المحددة.<br/>             4.دمج الطريقة 2 والطريقة 3.

يعرض نوع DocumentPrivilege الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| allow_print | يضبط الإذن الذي يسمح بالطباعة أو لا. <br/>            true يعني مسموح و false يعني ممنوع. |
| allow_degraded_printing | يضبط الإذن الذي يسمح بالطباعة منخفضة الجودة أو لا. <br/>            true يعني مسموح و false يعني ممنوع. |
| allow_modify_contents | يضبط الإذن الذي يسمح بتعديل المحتوى أو لا. <br/>            true يعني مسموح و false يعني ممنوع. |
| allow_copy | يضبط الإذن الذي يسمح بالنسخ أو لا. <br/>            true يعني مسموح و false يعني ممنوع. |
| allow_modify_annotations | يضبط الإذن الذي يسمح بتعديل التعليقات التوضيحية أو لا. <br/>            true يعني مسموح و false يعني ممنوع. |
| allow_fill_in | يضبط الإذن الذي يسمح بملء النماذج أو لا. <br/>            true يعني مسموح و false يعني ممنوع. |
| allow_screen_readers | يضبط الإذن الذي يسمح بقراء الشاشة أو لا. <br/>            true يعني مسموح و false يعني ممنوع. |
| allow_assembly | يضبط الإذن الذي يسمح بالتجميع أو لا. <br/>            true يعني مسموح و false يعني ممنوع. |
| degraded_printing | يسمح بالطباعة منخفضة الجودة. |
| print | يسمح بطباعة الملف. |
| modify_contents | يسمح بتعديل الملف. |
| copy | يسمح بنسخ الملف. |
| modify_annotations | يسمح بتعديل التعليقات التوضيحية للملف. |
| fill_in | يسمح بملء النماذج في الملف. |
| screen_readers | يسمح بالقراءة على الشاشة فقط. |
| assembly | يسمح بتجميع الملف. |
| allow_all | كل شيء مسموح. |
| forbid_all | كل شيء ممنوع. |
