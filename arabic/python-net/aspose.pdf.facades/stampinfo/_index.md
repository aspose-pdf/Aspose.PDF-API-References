## StampInfo class

فئة تمثل معلومات الطابع.

نوع StampInfo يعرّف الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| stamp_id | يحصل على معرف الطابع. |
| index_on_page | يحصل على فهرس الطابع على الصفحة. |
| stamp_type | يحصل على نوع الطابع (صورة / نموذج). |
| rectangle | يحصل على المستطيل حيث تم وضع الطابع. |
| image | يحصل على صورة الطابع. قد تكون فارغة إذا لم يحتوي الطابع على صور (مثلاً للطابع النصي). |
| نموذج | يحصل على XForm للطابع. |
| text | يحصل على النص داخل الطابع. |
| مرئي | يحصل على رؤية الطابع. إذا كان false فإن الطابع يكون مخفيًا (باستخدام HideStampById). يمكن استعادة الطابع المخفي بواسطة ShowStampById. |
