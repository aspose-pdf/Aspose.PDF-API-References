## Bookmark class

يمثل إشارة مرجعية.

نوع Bookmark يكشف عن الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Bookmark() | ينشئ مثيلًا جديدًا من فئة Bookmark |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| إجراء | يحصل أو يضبط الإجراء المرتبط بالعلامة المرجعية.<br/>            إذا تم تقديم PageNumber لا يمكن تحديد الإجراء.<br/>            نوع الإجراء يشمل: "GoTo", "GoToR", "Launch", "Named". |
| bold_flag | يحصل أو يضبط علامة الخط العريض لعنوان العلامة المرجعية. |
| child_item | يحصل أو يضبط العناصر الفرعية للعلامة المرجعية. |
| child_items | يحصل أو يضبط العناصر الفرعية للعلامة المرجعية. |
| الوجهة | يحصل أو يضبط صفحة الوجهة للعلامة المرجعية. مطلوب إذا تم تعيين الإجراء كـ string.Empty. |
| italic_flag | يحصل أو يضبط علامة الخط المائل لعنوان العلامة المرجعية. |
| المستوى | يحصل أو يضبط مستوى التسلسل الهرمي للعلامة المرجعية. |
| page_display | يحصل أو يضبط نوع عرض صفحة الوجهة للعلامة المرجعية. |
| page_display_bottom | يحصل أو يضبط إحداثي القاع لعرض الصفحة. |
| page_display_left | يحصل أو يضبط إحداثي اليسار لعرض الصفحة. |
| page_display_right | يحصل أو يضبط إحداثي اليمين لعرض الصفحة. |
| page_display_top | يحصل أو يضبط إحداثي الأعلى لعرض الصفحة. |
| page_display_zoom | يحصل أو يضبط عامل التكبير لعرض الصفحة. |
| page_number | يحصل أو يضبط رقم صفحة الوجهة للعلامة المرجعية. |
| remote_file | يحصل أو يضبط الملف (المسار) المطلوب لإجراء "GoToR" للعلامة المرجعية. |
| title | يحصل أو يضبط عنوان العلامة المرجعية. |
| title_color | يحصل أو يضبط لون عنوان العلامة المرجعية. |
| فتح | يحصل أو يضبط حالة الإشارة المرجعية (فتح، إغلاق). |
