## LineInfo class

يمثل معلومات السطر.

نوع LineInfo يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| LineInfo() | يُنشئ مثيلًا جديدًا لفئة LineInfo |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| vertice_coordinate | يحصل أو يضبط مصفوفة من الأعداد التي تمثل الإحداثيات الأفقية والرأسية المتبادلة، على التوالي، لكل رأس. |
| line_color | يحصل أو يضبط لون الخط. |
| line_width | يحصل أو يضبط عرض الخط. |
| visibility | يحصل أو يضبط رؤية الخط. |
| line_dash_pattern | يحصل أو يضبط نمط المتقطع للخط. |
| border_style | يحصل أو يضبط نمط حدود الخط، 0 يمثل صلبًا، 1 يمثل متقطعًا، 2 يمثل مائلًا، 3 يمثل مدخلًا، 4 يمثل تسطيرًا. |
