## SaveableFacade class

الفئة الأساسية لجميع الواجهات القابلة للحفظ.

نوع SaveableFacade يعرض الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| مستند | يحصل على واجهة المستند التي يعمل عليها. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| bind_pdf(src_file) | يُهيئ الـ facade. |
| bind_pdf(src_stream) | يُهيئ الـ facade. |
| bind_pdf(src_doc) | يُهيئ الـ facade. |
| save(dest_file) | يحفظ مستند PDF إلى الملف المحدد. |
| save(dest_stream) | يحفظ مستند PDF إلى الدفق المحدد. |
| close() | يتخلص من Aspose.Pdf.Document المرتبط بواجهة. |
