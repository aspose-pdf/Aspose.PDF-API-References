## PdfFileSecurity class

يمثل تشفير أو فك تشفير ملف PDF باستخدام كلمة مرور المالك أو المستخدم، وتغيير إعداد الأمان وكلمة المرور.

نوع PdfFileSecurity يعرض الأعضاء التالية:

| PdfFileSecurity(input_file, output_file) | ينشئ مثيلاً جديدًا من الفئة PdfFileSecurity |
| PdfFileSecurity() | تهيئة كائن PdfFileSecurity. |

| PdfFileSecurity(document, output_stream) | ينشئ مثيلاً جديدًا من الفئة PdfFileSecurity |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| مستند | يحصل على واجهة المستند التي يعمل عليها. |
