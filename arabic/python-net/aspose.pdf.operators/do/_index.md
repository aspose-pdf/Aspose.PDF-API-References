## Do class

الفئة تمثل مشغل Do (استدعاء XObject).

يعرض نوع Do الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Do(name) | ينشئ مثيلاً جديداً من الفئة Do |
| Do() | ينشئ مشغل Do جديد. <br/>            يُستخدم لاسترجاع جميع مشغلات Do، أي دون التحقق من أسماء وسائطها. |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| index | فهرس المشغل في قائمة مشغلات الصفحة. |
| name | اسم وسيط XObject للمشغل. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| accept(visitor) | يقبل كائن الزائر لمعالجة المشغّل. |
| is_text_show_operator(op) | يحدد ما إذا كان المشغل هو المشغل المسؤول عن إخراج النص (Tj, TJ, إلخ) |
