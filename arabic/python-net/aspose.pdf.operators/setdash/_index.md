| :- | :- |

## الخصائص
| الاسم | الوصف |
| :- | :- |
| index | فهرس المشغل في قائمة مشغلات الصفحة. |
| pattern | نمط الشرط. يجب أن تكون عناصر المصفوفة أعداداً تحدد أطوال الشرط المتناوب والفجوات.<br/>            في حالة مصفوفة عنصر واحد تكون أطوال الشرط والفجوة متساوية. |
| phase | مرحلة الشرط. قبل بدء رسم مسار، يجب تمرير مصفوفة الشرط، مع جمع أطوال الشرط والفجوات. <br/>            عندما يساوي الطول المتراكم القيمة المحددة بواسطة مرحلة الشرط، يبدأ رسم المسار، <br/>            وتُستخدم مصفوفة الشرط بشكل دوري من تلك النقطة فصاعداً. |
