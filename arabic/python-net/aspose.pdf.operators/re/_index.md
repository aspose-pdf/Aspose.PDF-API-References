## Re class

فئة تمثل عامل re (إضافة مستطيل إلى المسار).

يعرض نوع Re الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| Re() | يقوم بتهيئة المشغل. |
| Re(x, y, width, height) | يقوم بتهيئة نسخة جديدة من الفئة Re |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| index | فهرس المشغل في قائمة مشغلات الصفحة. |
| x | الإحداثي X لأكثر جانب أيسر من المستطيل. |
| y | الإحداثي Y للجانب السفلي من المستطيل. |
| العرض | عرض المستطيل. |
| الارتفاع | ارتفاع المستطيل. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| accept(visitor) | يقبل كائن الزائر لمعالجة المشغّل. |
| is_text_show_operator(op) | يحدد ما إذا كان المشغل هو المشغل المسؤول عن إخراج النص (Tj, TJ, إلخ) |
