## BasicSetColorOperator class

الفئة الأساسية لعوامل ضبط اللون.

يعرض نوع BasicSetColorOperator الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| index | فهرس المشغل في قائمة مشغلات الصفحة. |
| r | يحصل على المكوّن الأحمر للون |
| g | يحصل على المكوّن الأخضر للون |
| b | يحصل على المكوّن الأحمر للون |
| c | يحصل على المكوّن السماوي للون CMYK. |
| m | يحصل على المكوّن الأرجواني للون CMYK. |
| y | يحصل على المكوّن الأصفر للون CMYK. |
| k | يحصل على المكوّن الأسود للون CMYK. |
| grey | يحصل على المكوّن الأسود للون الرمادي. |
| اللون | يحصل على مصفوفة مكوّنات اللون. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| accept(visitor) | يقبل الزائر IOperatorSelector الذي يوفر معالجة المشغلات. |
| is_text_show_operator(op) | يحدد ما إذا كان المشغل هو المشغل المسؤول عن إخراج النص (Tj, TJ, إلخ) |
| get_color() | يعيد اللون المحدد بواسطة المشغّل. |
