## LineTo class

الفئة تمثل مشغل l (إضافة خط إلى المسار).

نوع LineTo يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| LineTo(x, y) | ينشئ مثيلاً جديداً من فئة LineTo |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| index | فهرس المشغل في قائمة مشغلات الصفحة. |
| x | الإحداثي X لنقطة الخط. |
| y | الإحداثي Y لنقطة الخط. |
## الطرق
| الاسم | الوصف |
| :- | :- |
| accept(visitor) | يقبل كائن الزائر لمعالجة المشغّل. |
| is_text_show_operator(op) | يحدد ما إذا كان المشغل هو المشغل المسؤول عن إخراج النص (Tj, TJ, إلخ) |
