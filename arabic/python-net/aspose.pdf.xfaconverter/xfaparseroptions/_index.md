## XfaParserOptions class

فئة للتعامل مع تغليف البيانات المرتبطة.

نوع XfaParserOptions يكشف عن الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| XfaParserOptions(page_size) | يُنشئ مثيلًا جديدًا من فئة XfaParserOptions |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| page_size | يحصل على حجم الصفحة أو يعيّنه. |
| موقع | إذا كانت هذه الخاصية صحيحة فسيتم تحويل المستند باستخدام تدفق نموذج xfa (إذا كان موجودًا).<br/>            إذا كانت خاطئة فسيتم تجاهل تدفق نموذج xfa.<br/>            تم تقديم هذه الخاصية لأنه غير واضح كيفية حساب المجموع الاختباري المستخدم للتحقق من التوقيع. |
| emulate_requierd_groups | إذا كانت هذه الخاصية صحيحة فسيتم رسم مستطيلات حمراء إضافية للمجموعات "المستبعدة" المطلوبة في Xfa<br/>            تم تقديم هذه الخاصية بسبب غياب نظائر المجموعات المستبعدة أثناء تحويل تمثيل نماذج Xfa<br/>            إلى المعيار.<br/>            القيمة الافتراضية هي خاطئة. |
| base_path | يحصل أو يضبط مسار القاعدة. |
