## TextState class

يمثل حالة نصية للنص

نوع TextState يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| TextState() | ينشئ كائن حالة النص. |
| TextState(font_size) | يُهيئ نسخة جديدة من فئة TextState |
| TextState(foreground_color) | يُهيئ نسخة جديدة من فئة TextState |
| TextState(foreground_color, font_size) | يُهيئ نسخة جديدة من فئة TextState |
| TextState(font_family) | يُهيئ نسخة جديدة من فئة TextState |
| TextState(font_family, bold, italic) | يُهيئ نسخة جديدة من فئة TextState |
| TextState(font_family, font_size) | يُهيئ نسخة جديدة من فئة TextState |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| character_spacing | يحصل أو يضبط تباعد الأحرف في النص. |
| line_spacing | يحصل أو يضبط تباعد الأسطر في النص. |
| horizontal_scaling | يحصل أو يضبط التحجيم الأفقي للنص. |
| subscript | يحصل أو يضبط النص كحرف سفلي. |
| superscript | يحصل أو يضبط النص كحرف علوي. |
| word_spacing | يحصل أو يضبط تباعد الكلمات في النص. |
| invisible | يحصل أو يضبط عدم ظهور النص. هذا أساسًا يعكس حالة [rendering_mode](/pdf/python-net/aspose.pdf.text/textstate/) ، باستثناء بعض الحالات الخاصة (مثل القص). |
| rendering_mode | يحصل أو يضبط وضعية العرض للنص. |
| font_size | يحصل أو يضبط حجم الخط في النص. |
| font | يحصل أو يضبط خط النص. |
| foreground_color | يحصل أو يضبط لون المقدمة للنص. |
| stroking_color | يحصل أو يضبط لون المقدمة للنص. |
| underline | يحصل أو يضبط التسطير للنص، الممثل بواسطة كائن [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| strike_out | يضبط الشطب للنص، الممثل بواسطة كائن [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| background_color | يضبط لون الخلفية للنص. |
| font_style | يضبط نمط الخط للنص. |
| horizontal_alignment | يحصل أو يضبط المحاذاة الأفقية للنص. |
| TAB_TAG | يمكنك وضع هذه العلامة في النص لتحديد التبويب. |
| TABSTOP_DEFAULT_VALUE | القيمة الافتراضية للتبويب في عرض حرف المسافة للخط الافتراضي. |
