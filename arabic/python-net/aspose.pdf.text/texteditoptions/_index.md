## TextEditOptions class

يصف خيارات عمليات تحرير النص.

نوع TextEditOptions يكشف عن الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| TextEditOptions(no_character_behavior) | ينشئ مثيلاً جديداً من فئة TextEditOptions |
| TextEditOptions(font_replace_behavior) | ينشئ مثيلاً جديداً من فئة TextEditOptions |
| TextEditOptions(allow_language_transformation) | ينشئ مثيلاً جديداً من فئة TextEditOptions |
| TextEditOptions(language_transformation_behavior) | ينشئ مثيلاً جديداً من فئة TextEditOptions |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| replacement_font | يحصل أو يعيّن الخط المستخدم للاستبدال إذا لم يحتوي خط المستخدم على الحرف المطلوب |
| no_character_behavior | يحصل أو يعيّن الوضع الذي يحدد السلوك في حال عدم احتواء الخطوط على الأحرف المطلوبة. |
| font_replace_behavior | يحصل على الوضع الذي يحدد السلوك في سيناريوهات استبدال الخطوط. |
| allow_language_transformation | الحصول أو تعيين القيمة التي تسمح باستخدام تحويل اللغة أثناء إضافة أو تحرير النص.<br/>            true - سيتم تطبيق تحويل اللغة إذا لزم الأمر (القيمة الافتراضية).<br/>            false - لن يتم تطبيق تحويل اللغة. |
| language_transformation_behavior | الحصول على الوضع الذي يحدد السلوك لسيناريوهات تحويل اللغة. |
| clipping_paths_processing | الحصول على الوضع لمعالجة مسار القص للنص المُحرر. |
| to_attempt_get_underline_from_source | الحصول أو تعيين القيمة التي تسمح بالبحث عن تسطير النص في صفحة المستند المصدر.<br/>            (مهمل) يرجى استخدام TextSearchOptions.SearchForTextRelatedGraphics بدلاً من ذلك. |
