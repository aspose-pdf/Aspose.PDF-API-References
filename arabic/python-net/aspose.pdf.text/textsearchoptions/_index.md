## TextSearchOptions class

يمثل خيارات البحث النصي

نوع TextSearchOptions يعرض الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| TextSearchOptions(is_regular_expression_used) | يُنشئ مثيلاً جديداً لفئة TextSearchOptions |
| TextSearchOptions(rectangle) | يُنشئ مثيلاً جديداً لفئة TextSearchOptions |
| TextSearchOptions(rectangle, is_regular_expression_used) | يُنشئ مثيلاً جديداً لفئة TextSearchOptions |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| is_regular_expression_used | يحصل أو يضبط إشارة إلى أن التعبير النمطي مستخدم. |
| limit_to_page_bounds | يحصل أو يضبط إشارة إلى أن النص يُبحث ضمن حدود الصفحة. |
| rectangle | يحصل أو يضبط المستطيل الذي يحد النص المُبحث. |
| use_font_engine_encoding | يحصل أو يضبط إشارة إلى أن النص سيُبحث باستخدام ترميز محرك الخط.<br/>            true - يعني أن ترميز محرك الخط سيُستخدم (جرّب هذا إذا فشل البحث عن النص بسبب ترميز غير كامل في المستند)<br/>            false - يعني أن ترميز خط المستند سيُستخدم (القيمة الافتراضية) |
| ignore_shadow_text | يحصل أو يضبط إشارة إلى أن شظايا النص التي تمثل ظل النص العادي ستُتجاهل أثناء البحث.<br/>            true - يعني أن نص الظل لن يتم العثور عليه (جرّب هذا إذا أعاد البحث عن النص شظايا مكررة في المواقع القريبة)<br/>            false - يعني أن نص الظل سيُعثر عليه بالإضافة إلى النص العادي (القيمة الافتراضية) |
| log_text_extraction_errors | يحصل أو يضبط إشارة إلى أن أخطاء استخراج النص (فك الترميز) ستُسجل في ما يمتص النص (الشظايا).<br/>            true - يعني أن أخطاء استخراج النص (فك الترميز) ستُسجل. قد يقلل ذلك من الأداء.<br/>            false (default) - لا تسجيل للأخطاء. |
| ignore_resource_font_errors | يحصل أو يعيّن إشارة إلى أن الأخطاء المتعلقة بغياب الخط سيتم تجاهلها بواسطة ماص النص (الجزء).<br/>            true - يعني أن أخطاء غياب الخط سيتم تجاهلها. سيتم تخطي مقاطع النص التي تشير إلى موارد غير صحيحة أثناء المعالجة.<br/>            false (default) - سيؤدي خطأ غياب الخط إلى إنهاء المعالجة عن طريق رمي استثناء. |
| search_for_text_related_graphics | يحصل أو يعيّن القيمة التي تسمح بالبحث عن الرسومات المتعلقة بالنص (التسطير، الخلفية إلخ) أثناء بحث النص.<br/>            true - سيتم تنفيذ البحث عن الرسومات المتعلقة بالنص (القيمة الافتراضية).<br/>            false - سيتم تجاهل العناصر الرسومية التي قد تكون موجودة في المستند المصدر. اضبط هذا في حالة وجود مشكلات أداء أو عدم الحاجة لمعالجة التسطير أو الخلفية أو القص. |
| stored_graphic_elements_max_count | يحصل أو يعيّن القيمة التي تحدّ من البحث عن الرسومات المتعلقة بالنص (التسطير، الخلفية إلخ) في الصفحة لعدد محدد من العناصر.<br/>            القيمة الافتراضية هي 250. اضبط قيمة أقل في حالة وجود مشاكل في الأداء، جرب قيمة أكبر إذا لم يتم العثور على بعض العناصر الرسومية. |
| search_in_annotations | يحصل أو يعيّن القيمة التي تسمح بالبحث عن النص في التعليقات التوضيحية.<br/>            true - سيتم البحث عن النص في التعليقات التوضيحية.<br/>            false - لن يتم تحليل النص في التعليقات التوضيحية بواسطة TextFragmentAbsorber. |
