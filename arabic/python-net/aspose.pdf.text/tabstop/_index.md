## TabStop class

يمثل موضع توقف تبويب مخصص في الفقرة.

يُظهر نوع TabStop الأعضاء التالية:
## المُنشئات
| الاسم | الوصف |
| :- | :- |
| TabStop() | ينشئ مثيلاً جديداً من الفئة [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/). |
| TabStop(position) | ينشئ مثيلاً جديداً من فئة TabStop |
## الخصائص
| الاسم | الوصف |
| :- | :- |
| position | يحصل أو يعيّن قيمة عائمة تشير إلى موضع علامة التبويب. |
| leader_type | يحصل أو يعيّن تعداد [TabLeaderType](/pdf/python-net/aspose.pdf.text/tableadertype/) الذي يحدد نوع قائد التبويب. |
| alignment_type | يحصل أو يعيّن تعداد [alignment_type](/pdf/python-net/aspose.pdf.text/tabstop/) الذي يحدد نوع محاذاة علامة التبويب. |
| is_read_only | يحصل على قيمة تشير إلى أن مثيل [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) هذا مرتبط بالفعل بـ [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) وأصبح للقراءة فقط |
