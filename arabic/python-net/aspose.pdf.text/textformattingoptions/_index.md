## الخصائص
| الاسم | الوصف |
| :- | :- |
| wrap_mode | الحصول أو تعيين وضع التفاف الكلمات.<br/>            القيمة الافتراضية هي WordWrapMode.NoWrap |
| line_spacing | الحصول أو تعيين وضع تباعد الأسطر.<br/>            القيمة الافتراضية هي LineSpacingMode.FontSize |
| hyphen_symbol | الحصول أو تعيين رمز الواصلة الذي يُستخدم في عملية التجزئة. |
| subsequent_lines_indent | الحصول أو تعيين قيمة مسافة إزاحة الأسطر اللاحقة. |
| first_line_indent | الحصول أو تعيين قيمة مسافة إزاحة السطر الأول. |
