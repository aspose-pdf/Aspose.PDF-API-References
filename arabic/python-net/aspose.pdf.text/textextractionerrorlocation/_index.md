## TextExtractionErrorLocation class

يمثل الموقع في مستند PDF حيث ظهر خطأ استخراج النص.

يعرض نوع TextExtractionErrorLocation الأعضاء التالية:
## الخصائص
| الاسم | الوصف |
| :- | :- |
| path | موقع مستند PDF حيث ظهر خطأ استخراج النص. |
| page_number | رقم صفحة المستند التي وقع فيها خطأ استخراج النص. |
| object_type | نوع كائن PDF (صفحة أو xForm) الذي وقع فيه خطأ استخراج النص في تدفق المحتوى. |
| form_key | المفتاح (الاسم) لكائن PDF Form XObject الذي وقع فيه خطأ استخراج النص في تدفق المحتوى. غير فارغ إذا كان ObjectType == 'xForm'. |
| operator_index | فهرس المشغل الذي يظهر النص في تدفق المحتوى (مجموعة المشغلات) والذي يسبب خطأ استخراج النص. |
| operator_string | المشغل الذي يظهر النص والذي يسبب خطأ استخراج النص. |
| font_used_key | المفتاح (الاسم) لكائن خط PDF المستخدم لعرض المشغل الذي يسبب خطأ استخراج النص. |
| text_start_point | المفتاح (الاسم) لكائن خط PDF المستخدم لعرض المشغل الذي يسبب خطأ استخراج النص. |
