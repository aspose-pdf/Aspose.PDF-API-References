## TextSearchOptions.IgnoreResourceFontErrors property

الحصول أو الضبط إشارة إلى أن الأخطاء المتعلقة بغياب الخط سيتجاهلها ماص النص (الجزء). true - يعني أن أخطاء غياب الخط ستُتجاهل. سيتم تخطي مقاطع النص التي تشير إلى موارد غير صحيحة أثناء المعالجة. false (default) - سيؤدي خطأ غياب الخط إلى إنهاء المعالجة برمي استثناء.

```csharp
public bool IgnoreResourceFontErrors { get; set; }
```
