## TextRenderingMode enumeration

وضع عرض النص، Tmode، يحدد ما إذا كان إظهار النص سيتسبب في رسم حدود الحروف، تعبئتها، استخدامها كحد قص، أو مزيج من الثلاثة.

```csharp
public enum TextRenderingMode
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| FillText | `0` | تعبئة النص. |
| StrokeText | `1` | رسم النص. |
| FillThenStrokeText | `2` | تعبئة، ثم رسم النص. |
| Invisible | `3` | لا تعبئة ولا رسم للنص (غير مرئي). |
| FillTextAndAddPathToClipping | `4` | تعبئة النص وإضافته إلى المسار للقص (انظر 9.3.6، "Text Rendering Mode,"). |
| StrokeTextAndAddPathToClipping | `5` | رسم النص وإضافته إلى المسار للقص. |
| FillThenStrokeTextAndAddPathToClipping | `6` | تعبئة، ثم رسم النص وإضافته إلى المسار للقص. |
| AddPathToClipping | `7` | إضافة النص إلى المسار للقص. |
