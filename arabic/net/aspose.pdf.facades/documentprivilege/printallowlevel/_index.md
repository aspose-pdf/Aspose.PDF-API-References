## DocumentPrivilege.PrintAllowLevel property

يحصل على ويضبط مستوى الطباعة لامتياز المستند. تمامًا كما في إعدادات الطباعة المسموح بها في Adobe Professional. 0: لا شيء. 1: دقة منخفضة (150 نقطة في البوصة). 2: دقة عالية.

```csharp
public int PrintAllowLevel { get; set; }
```
