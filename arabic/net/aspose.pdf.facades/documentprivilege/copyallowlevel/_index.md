## DocumentPrivilege.CopyAllowLevel property

يحصل على ويضبط مستوى النسخ لامتياز المستند. تمامًا كما في إعدادات الأذونات في Adobe Professional. 0: لا شيء. 1: تمكين الوصول النصي لأجهزة قارئ الشاشة للمكفوفين. 2: تمكين نسخ النصوص، الصور وغيرها من المحتوى.

```csharp
public int CopyAllowLevel { get; set; }
```

## ملاحظات

إذا كانت الخاصية لها قيمة -1، فإن المستوى غير معرف.
