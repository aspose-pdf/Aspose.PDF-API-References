## SvgExtractionOptions.GroupStrength property

يحصل ويضبط خيار قوة تجميع المسارات الفرعية إلى صور. يتيح لك تكوين درجة تجميع المسارات الفرعية. النطاق القيمي من 0 إلى 1. القيمة 0 تمثل تمكين خيار [`ExtractEverySubPathToSvg`](../extracteverysubpathtosvg/). القيمة 1 ستنشئ صورة واحدة لجميع المسارات المتجهية على الصفحة. يؤثر هذا الخيار عندما يكون [`AutoGrouping`](../autogrouping/) غير مفعل. القيمة الافتراضية هي `0.8`.

```csharp
public double GroupStrength { get; set; }
```
