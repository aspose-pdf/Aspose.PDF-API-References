## SvgExtractionOptions.StrictExtractionAreaBoundCheck property

يحصل ويضبط خيار لتحديد ما إذا كانت المسارات الفرعية داخل المستطيل المحدد في [`ExtractionAreaBound`](../extractionareabound/) بشكل صارم. إذا تم تعيينه إلى false، فإن المسارات الفرعية التي ليست مشمولة بالكامل في [`ExtractionAreaBound`](../extractionareabound/) سيتم استخراجها. القيمة الافتراضية هي `True`.

```csharp
public bool StrictExtractionAreaBoundCheck { get; set; }
```
