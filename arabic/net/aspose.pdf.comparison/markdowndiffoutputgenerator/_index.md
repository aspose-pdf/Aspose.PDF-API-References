## MarkdownDiffOutputGenerator class

يمثّل فئة لإنشاء تمثيل markdown لاختلافات النصوص. بسبب صيغة markdown، لا يمكن إظهار التغييرات في أحرف المسافات. اختيار التغييرات يتطلب إضافة أحرف مسافة حول التنسيق، وإلا لن يعرض عارض markdown النص بشكل صحيح. يتم الإشارة إلى فواصل الأسطر المحذوفة بعلامة الفقرة -.

```csharp
public class MarkdownDiffOutputGenerator : IFileOutputGenerator, IStringOutputGenerator
```
