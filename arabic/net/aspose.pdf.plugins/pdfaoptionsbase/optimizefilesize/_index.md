## PdfAOptionsBase.OptimizeFileSize property

يحصل أو يعيّن قيمة تشير إلى ما إذا كان يجب محاولة تقليل حجم الملف أثناء عملية تحويل PDF/A.

```csharp
public bool OptimizeFileSize { get; set; }
```

### Property Value

`true` إذا كان يجب تقليل حجم الملف قدر الإمكان؛ وإلا `false`.

## ملاحظات

عند تعيينه إلى `true`، ستحاول عملية التحويل تقليل حجم الملف الناتج. قد يؤثر ذلك على أداء عملية التحويل.
