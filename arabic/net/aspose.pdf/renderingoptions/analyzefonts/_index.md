## RenderingOptions.AnalyzeFonts property

يستبدل الخطوط حسب الحاجة لضمان إمكانية عرض جميع الأحرف في النص. تتبع خوارزمية استبدال الخطوط الخطوات التالية: 1. إذا قام المستخدم بتعيين خاصية DefaultFontName صراحةً، تحقق مما إذا كان الخط المحدد يمكنه عرض الأحرف المطلوبة. 2. إذا لم يتم تعيين خط من قبل المستخدم، ابحث عبر الخطوط المضافة عبر !:FontRepository.Sources. 3. حلل النص لتحديد أبجديته أو خطه واقترح أسماء الخطوط وفقًا لذلك. حاول العثور على هذه الخطوط واستخدامها من النظام. 4. كإجراء احتياطي، ابحث في النظام عن أي خط قادر على عرض الأحرف المطلوبة.

```csharp
public bool AnalyzeFonts { get; set; }
```
