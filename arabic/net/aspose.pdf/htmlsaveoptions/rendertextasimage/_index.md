## HtmlSaveOptions.RenderTextAsImage property

إذا تم تعيين الخاصية **RenderTextAsImage** إلى true، يصبح النص من المصدر صورة في HTML. قد يكون ذلك مفيدًا لجعل النص غير قابل للتحديد أو عندما لا يتم عرض نص HTML بشكل صحيح.

public bool RenderTextAsImage { get; set; }
