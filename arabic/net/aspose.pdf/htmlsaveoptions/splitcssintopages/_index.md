## HtmlSaveOptions.SplitCssIntoPages property

عند اختيار وضع متعدد الصفحات (أي أن **SplitIntoPages** هو true)، تحدد هذه الخاصية ما إذا كان يجب إنشاء ملف CSS منفصل لكل صفحة HTML ناتجة. بشكل افتراضي هذه الخاصية false، لذا يتم إنشاء ملف CSS كبير مشترك لجميع الصفحات التي تم إنشاؤها. الحجم الإجمالي لجميع ملفات CSS التي تُولد في هذا الوضع (CSS واحد لكل صفحة) عادةً ما يكون أكبر بكثير من حجم ملف CSS واحد كبير، لأن في الحالة الأولى تتكرر فئات CSS في عدة ملفات لكل صفحة. لذلك، يُفضَّل عدم استخدام هذا الإعداد إلا عندما تكون مهتمًا بمعالجة كل صفحة HTML على حدة في المستقبل، وبالتالي يكون حجم CSS لكل صفحة منفصلة هو الأمر الأكثر حرجًا.

```csharp
public bool SplitCssIntoPages { get; set; }
```
