## HtmlSaveOptions.UseZOrder property

إذا تم تعيين الخاصية **UseZORder** إلى true، تُضاف الرسومات والنص إلى مستند HTML الناتج وفقًا لترتيب Z في مستند PDF الأصلي. إذا كانت هذه الخاصية false، تُوضع جميع الرسومات كطبقة واحدة مما قد يسبب بعض التأثيرات غير الضرورية للكائنات المتداخلة.

```csharp
public bool UseZOrder { get; set; }
```
