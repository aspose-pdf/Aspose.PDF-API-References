## EpubLoadOptions.PageSizeAdjustmentMode field

تنبيه! تم تنفيذ الميزة ولكن لم تُضف بعد إلى API العامة بسبب مشكلة عائق في طبقة OSHARED تم اكتشافها في المستند النموذجي. يمثل وضع استخدام حجم الصفحة أثناء التحويل. الصيغ (مثل HTML, EPUB إلخ) عادةً ما تكون ذات تصميم مرن، لذا يسمح بتلائم حجم الصفحة المطلوب. لكن أحيانًا يكون للمحتوى مواضع أفقية أو حجم محدد لا يسمح بوضع المحتوى داخل حجم الصفحة المطلوب. في هذه الحالة يمكننا تحديد ما يجب القيام به (أي عندما لا يتناسب حجم المحتوى مع حجم الصفحة الأولي المطلوب في مستند PDF الناتج).

```csharp
public PageSizeAdjustmentModes PageSizeAdjustmentMode;
```
