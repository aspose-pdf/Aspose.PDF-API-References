## Metered.SetMeteredKey method

يضبط المفتاح العام والخاص للترخيص المتعقب. إذا قمت بشراء ترخيص متعقب، عند بدء التطبيق يجب استدعاء هذه الـ API، عادةً يكون ذلك كافيًا. ومع ذلك، إذا فشل دائمًا تحميل بيانات الاستهلاك وتجاوزت 24 ساعة، سيتم تعيين الترخيص إلى حالة التقييم؛ لتجنب هذه الحالة، يجب عليك فحص حالة الترخيص بانتظام، إذا كانت في حالة التقييم، استدعِ هذه الـ API مرة أخرى.

```csharp
public void SetMeteredKey(string publicKey, string privateKey)
```

| --- | --- | --- |
| publicKey | String | المفتاح العام |
| privateKey | String | المفتاح الخاص |
