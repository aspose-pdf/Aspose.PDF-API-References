## HtmlSaveOptions.HtmlPageMarkupSavingInfo.HtmlHostPageNumber field

يتم تعيينه بواسطة المحول. إذا تم ضبط خاصية SplitToPages، فسيتم إنشاء عدة ملفات HTML (ملف HTML واحد لكل صفحة محوّلة) أثناء عملية التحويل. تحتوي هذه الخاصية على ترتيب ملف صفحة HTML المحفوظة. يمكن استخدام الخاصية في منطق الشيفرة المخصصة لتحديد كيفية معالجة أو مكان حفظ صفحة HTML، وإذا تم إيقاف تقسيم الصفحات فإن هذه القيمة تكون دائمًا "1" لأن الحالة تكون صفحة HTML واحدة كبيرة تُنشأ للمستند الأصلي بالكامل.

```csharp
public int HtmlHostPageNumber;
```
