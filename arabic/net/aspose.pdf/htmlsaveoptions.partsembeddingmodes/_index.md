## HtmlSaveOptions.PartsEmbeddingModes enumeration

هذا التعداد يعدد أوضاع تضمين الملفات المشار إليها في HTML. يتيح التحكم فيما إذا كانت الملفات المشار إليها (HTML، الخطوط، الصور، ملفات CSS) سيتم تضمينها في ملف HTML الرئيسي أو سيتم إنشاؤها ككيانات ثنائية منفصلة.

```csharp
public enum PartsEmbeddingModes
```

### القيم

| الاسم | القيمة | الوصف |
| --- | --- | --- |
| EmbedAllIntoHtml | `0` | يفرض تضمين جميع الملفات المشار إليها (CSS، الصور، الخطوط) في ترميز HTML المُولد (أي داخل HTML نفسه). ينتج هذا النهج ملف HTML واحد، لكن حجم الناتج يصبح أكبر (نظرًا لاستخدام ترميز Base64 للملفات الثنائية) ولا تدعم جميع المتصفحات (خاصة القديمة) معالجة الملفات الثنائية المضمّنة في HTML بنجاح. لكنه يسمح بالحصول على HTML يحتوي على النتيجة كاملةً دون أي ملفات إضافية. |
| EmbedCssOnly | `1` | يفرض فصل جميع الملفات المشار إليها باستثناء CSS (الصور والخطوط). أي أن CSS سيتم تضمينه في HTML الناتج، بينما سيتم معالجة باقي الملفات المشار إليها (الصور والخطوط) كأجزاء خارجية. ينتج هذا HTML مناسب لمجموعة واسعة من المتصفحات. |
| NoEmbedding | `2` | يفرض فصل الملفات المشار إليها (CSS، الصور، الخطوط). يولد هذا النهج مجموعة من الملفات، لكن حجم الناتج يصبح أصغر (نظرًا لعدم استخدام ترميز Base64 للملفات الثنائية). كما أن هذا النهج يولد HTML مناسب لمجموعة واسعة من المتصفحات. |
