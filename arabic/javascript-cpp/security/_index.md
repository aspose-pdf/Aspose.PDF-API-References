## Security PDF functions

| الاسم | الوصف |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | تشفير ملف PDF. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | فك تشفير ملف PDF. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | توقيع ملف PDF باستخدام التوقيعات الرقمية. |

## Detailed Description

وظائف للعمل مع ميزات الأمان في ملفات PDF.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
أو
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
