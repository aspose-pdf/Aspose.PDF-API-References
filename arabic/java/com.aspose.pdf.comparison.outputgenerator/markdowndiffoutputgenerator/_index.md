يمثل فئة لتوليد تمثيل Markdown لفروقات النصوص. بسبب بنية Markdown، لا يمكن إظهار التغييرات في أحرف الفراغ. اختيار التغييرات يتطلب إضافة أحرف فراغ حول التنسيق، وإلا لن يعرض عارض Markdown النص بشكل صحيح. يتم الإشارة إلى فواصل الأسطر المحذوفة بعلامة الفقرة -.
