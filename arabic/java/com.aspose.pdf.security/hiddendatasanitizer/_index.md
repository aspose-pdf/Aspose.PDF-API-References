### HiddenDataSanitizer {#HiddenDataSanitizer-com.aspose.pdf.security.HiddenDataSanitizationOptions-}
يوفر وظائف لتطهير البيانات المخفية من مستند PDF، مع ضمان إزالة أو تحويل المعلومات الحساسة أو غير الضرورية مثل البيانات الوصفية، التعليقات التوضيحية، JavaScripts، أو المحتوى الخاص.

### sanitize {#sanitize-com.aspose.pdf.Document-}

### sanitizeAllToImages {#sanitizeAllToImages-com.aspose.pdf.Document-}
يستبدل محتوى الصفحة بالصور ويزيل البيانات المخفية الأخرى. يتيح لك إزالة النص المخفي مع لون خلفية، وكذلك النص المخفي تحت الصور. كما يزيل تمامًا جميع العناصر التفاعلية. يتم تحويل المستند إلى صور كما هو، ثم يتم مسح أي بيانات مخفية متبقية. إذا كنت بحاجة إلى مسح البيانات أولاً ثم التحويل، استخدم طريقة الفئة الرئيسية.
