يعدّ الأنماط التي يمكن استخدامها لحفظ الخطوط المشار إليها في ملف PDF المحفوظ.

## الحقول

| حقل | الوصف |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | سيتم حفظ جميع الخطوط المشار إليها والإشارة إليها كخطوط EOT. |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | سيتم حفظ جميع الخطوط المشار إليها والإشارة إليها كخطوط TTF. |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | سيتم حفظ جميع الخطوط المشار إليها والإشارة إليها كخطوط WOFF. |
| [DontSave](#DontSave) | لن يتم حفظ جميع الخطوط المشار إليها. |
| [SaveInAllFormats](#SaveInAllFormats) | سيتم حفظ جميع الخطوط المشار إليها (والإشارة إليها في CSS) كـ 3 ملفات مستقلة: EOT، TTH، WOFF. يزيد ذلك من حجم بيانات الإخراج لكنه يجعل الإخراج مناسبًا للغالبية العظمى من متصفحات الويب. |
