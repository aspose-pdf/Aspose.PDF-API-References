يحدد أنماط التسلسل المتاحة للعناوين. للمواصفات راجع CommonMark - ATX headings، وCommonMark - Setext headings.

## الحقول

| حقل | الوصف |
| --- | --- |
| [Atx](#Atx) | أضف بادئة للعناوين باستخدام '#' |
| [Setext](#Setext) | ضع خطًا تحت عناوين المستوى 1 و2 باستخدام "======" و"------" على التوالي. عناوين Setext متاحة فقط للمستوى 1 و2. حتى إذا تم تعيين نمط العنوان إلى Setext، سيُستخدم نمط Atx للمستويات 3 وما فوق. |
