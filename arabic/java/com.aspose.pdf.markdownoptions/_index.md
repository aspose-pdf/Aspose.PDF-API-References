المساحة الاسمية com.aspose.pdf.markdownoptions تحتوي على فئات خيارات محددة لتحويل markdown.

## الفئات

| فئة | الوصف |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | يحدد أنماط التسلسل المتاحة للتأكيد والتأكيد القوي. للمواصفات راجع CommonMark - Emphasis and strong emphasis. |
| [HeadingLevels](./headinglevels/) | يمثل فئة للعمل مع مستويات العناوين بناءً على حجم الخط. |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | يمثل أنواع استراتيجيات التعرف على العناوين. |
| [HeadingStyle](./headingstyle/) | يحدد أنماط التسلسل المتاحة للعناوين. للمواصفات راجع CommonMark - ATX headings، وCommonMark - Setext headings. |
| [LineBreakStyle](./linebreakstyle/) | يمثل أنماط فواصل الأسطر الممكنة لملف. |
| [MarkdownSaveOptions](./markdownsaveoptions/) | يمثل فئة خيار حفظ المستند بتنسيق markdown. |
