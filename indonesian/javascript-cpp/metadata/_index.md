## Metadata PDF functions

| Nama | Deskripsi |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | Atur info (metadata) dalam file PDF. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | Dapatkan info (metadata) dari file PDF. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | Dapatkan daftar font dari file PDF. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | Hapus metadata dari file PDF. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | Dapatkan jumlah kata dan karakter dalam file PDF. |
| [AsposePdfGetPagesLayers](./asposepdfgetpageslayers/) | Dapatkan daftar lapisan dari file PDF. |


## Detailed Description

Fungsi untuk bekerja dengan file Metadata PDF.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
atau
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
