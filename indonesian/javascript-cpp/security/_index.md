## Security PDF functions

| Nama | Deskripsi |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | Enkripsi file PDF. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | Dekripsi file PDF. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | Tandatangani file PDF dengan tanda tangan digital. |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | Tandatangani file PDF dengan tanda tangan digital terpisah. |
| [AsposePdfChangePassword](./asposepdfchangepassword/) | Ubah kata sandi file PDF. |

## Detailed Description

Fungsi untuk bekerja dengan fitur keamanan file PDF.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
atau
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
