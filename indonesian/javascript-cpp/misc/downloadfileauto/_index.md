_Buat tautan di HTML untuk mengunduh file dan mulai mengunduh setelah 2 detik._

```js
function DownloadFileAuto(
    filename,
    mime 
)
```

**Parameters**:

* **fileName** file name
* **mime** string "mime/type"

**Doesn't work in Web Worker.**
