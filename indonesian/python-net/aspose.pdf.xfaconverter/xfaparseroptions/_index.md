## XfaParserOptions class

kelas untuk menangani enkapsulasi data terkait

Tipe XfaParserOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| XfaParserOptions(page_size) | Menginisialisasi instance baru dari kelas XfaParserOptions |
## Properti
| Nama | Deskripsi |
| :- | :- |
| page_size | Mendapatkan atau mengatur ukuran halaman. |
| tertanda | Jika properti ini bernilai true maka dokumen akan dikonversi dengan menggunakan aliran formulir xfa (jika ada).<br/>            Jika bernilai false maka aliran formulir xfa akan diabaikan.<br/>            Properti ini diperkenalkan karena tidak jelas bagaimana menghitung checksum yang digunakan untuk memeriksa tanda tangan. |
| emulate_requierd_groups | Jika properti ini bernilai true maka persegi panjang merah tambahan akan digambar untuk "excluded groups" Xfa yang diperlukan<br/>            Properti ini diperkenalkan karena tidak adanya analog grup yang dikecualikan selama konversi representasi Xfa formulir <br/>            ke standar.<br/>            Nilainya false secara default. |
| base_path | Mendapatkan atau mengatur jalur dasar. |
