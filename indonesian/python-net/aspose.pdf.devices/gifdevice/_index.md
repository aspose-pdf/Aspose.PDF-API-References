## GifDevice class

Mewakili perangkat gambar yang membantu menyimpan halaman dokumen pdf ke gif.

Tipe GifDevice menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| GifDevice() | Menginisialisasi instance baru dari kelas [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) dengan resolusi default. |
| GifDevice(resolution) | Menginisialisasi instance baru dari kelas GifDevice |
| GifDevice(width, height, resolution) | Menginisialisasi instance baru dari kelas GifDevice |
| GifDevice(page_size, resolution) | Menginisialisasi instance baru dari kelas GifDevice |
| GifDevice(width, height) | Menginisialisasi instance baru dari kelas GifDevice |
| GifDevice(page_size) | Menginisialisasi instance baru dari kelas GifDevice |
## Properti
| Nama | Deskripsi |
| :- | :- |
| coordinate_type | Mendapatkan atau mengatur tipe koordinat halaman (Media/Crop boxes). Nilai CropBox digunakan secara default. |
| rendering_options | Mendapatkan atau mengatur opsi rendering. |
| form_presentation_mode | Mendapatkan atau mengatur mode presentasi formulir. |
| resolution | Mendapatkan resolusi gambar. |
| lebar | Mendapatkan lebar output gambar. |
| tinggi | Mendapatkan tinggi output gambar. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| process(page, output) | Mengonversi halaman menjadi gif dan menyimpannya ke aliran output. |
| process(page, output_file_name) | Mengonversi halaman menjadi gif dan menyimpannya ke aliran output. |
