## Metode
| Nama | Deskripsi |
| :- | :- |
| process(document, from_page, to_page, output) | Setiap perangkat mewakili beberapa operasi pada dokumen, misalnya kami dapat mengonversi dokumen pdf ke format lain. |
| process(document, output) | Setiap perangkat mewakili beberapa operasi pada dokumen, misalnya kami dapat mengonversi dokumen pdf ke format lain. |
