## TextDevice class

Mewakili kelas untuk mengonversi halaman dokumen pdf menjadi teks.

Tipe TextDevice menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextDevice(extraction_options) | Menginisialisasi instance baru dari kelas TextDevice |
| TextDevice() | Menginisialisasi instance baru dari [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) dengan mode pemformatan teks Raw dan enkoding teks Unicode. |
| TextDevice(encoding) | Menginisialisasi instance baru dari kelas TextDevice |
| TextDevice(extraction_options, encoding) | Menginisialisasi instance baru dari kelas TextDevice |
## Properti
| Nama | Deskripsi |
| :- | :- |
| extraction_options | Mendapatkan atau mengatur opsi ekstraksi teks. |
| encoding | Mendapatkan atau mengatur enkoding teks yang diekstrak. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| process(page, output) | Mengonversi halaman dan menyimpannya sebagai aliran teks. |
| process(page, output_file_name) | Mengonversi halaman dan menyimpannya sebagai aliran teks. |
