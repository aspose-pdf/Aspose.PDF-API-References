## PngDevice class

Mewakili perangkat gambar yang membantu menyimpan halaman dokumen pdf ke dalam png.

Tipe PngDevice menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| PngDevice() | Menginisialisasi sebuah instance baru dari kelas [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) dengan resolusi default. |
| PngDevice(resolution) | Menginisialisasi sebuah instance baru dari kelas PngDevice |
| PngDevice(width, height, resolution) | Menginisialisasi sebuah instance baru dari kelas PngDevice |
| PngDevice(page_size, resolution) | Menginisialisasi sebuah instance baru dari kelas PngDevice |
| PngDevice(width, height) | Menginisialisasi sebuah instance baru dari kelas PngDevice |
| PngDevice(page_size) | Menginisialisasi sebuah instance baru dari kelas PngDevice |
## Properti
| Nama | Deskripsi |
| :- | :- |
| coordinate_type | Mendapatkan atau mengatur tipe koordinat halaman (Media/Crop boxes). Nilai CropBox digunakan secara default. |
| rendering_options | Mendapatkan atau mengatur opsi rendering. |
| form_presentation_mode | Mendapatkan atau mengatur mode presentasi formulir. |
| resolution | Mendapatkan resolusi gambar. |
| lebar | Mendapatkan lebar output gambar. |
| tinggi | Mendapatkan tinggi output gambar. |
| transparent_background | Mendapatkan atau mengatur apakah gambar memiliki latar belakang transparan. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| process(page, output) | Mengonversi halaman menjadi png dan menyimpannya ke dalam aliran output. |
| process(page, output_file_name) | Mengonversi halaman menjadi png dan menyimpannya ke dalam aliran output. |
