## EmfDevice class

Mewakili perangkat gambar yang membantu menyimpan halaman dokumen pdf ke emf.

Tipe EmfDevice menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| EmfDevice() | Menginisialisasi instance baru dari kelas [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) dengan resolusi default gambar raster yang ditulis ke emf. |
| EmfDevice(resolution) | Menginisialisasi instance baru dari kelas EmfDevice |
| EmfDevice(width, height) | Menginisialisasi instance baru dari kelas EmfDevice |
| EmfDevice(page_size) | Menginisialisasi instance baru dari kelas EmfDevice |
| EmfDevice(width, height, resolution) | Menginisialisasi instance baru dari kelas EmfDevice |
| EmfDevice(page_size, resolution) | Menginisialisasi instance baru dari kelas EmfDevice |
## Properti
| Nama | Deskripsi |
| :- | :- |
| coordinate_type | Mendapatkan atau mengatur tipe koordinat halaman (Media/Crop boxes). Nilai CropBox digunakan secara default. |
| rendering_options | Mendapatkan atau mengatur opsi rendering. |
| form_presentation_mode | Mendapatkan atau mengatur mode presentasi formulir. |
| resolution | Mendapatkan resolusi gambar. |
| lebar | Mendapatkan lebar output gambar. |
| tinggi | Mendapatkan tinggi output gambar. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| process(page, output) | Mengonversi halaman menjadi emf dan menyimpannya ke dalam aliran output. |
| process(page, output_file_name) | Mengonversi halaman menjadi emf dan menyimpannya ke dalam aliran output. |
