## CompressionType enumeration

Digunakan untuk menentukan nilai parameter yang diteruskan ke perangkat gambar Tiff.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| LZW | Menentukan skema kompresi LZW. Dapat diteruskan ke encoder Tiff sebagai parameter yang termasuk dalam kategori Compression. |
| CCITT4 | Menentukan skema kompresi CCITT4. Dapat diteruskan ke encoder CCITT4 sebagai parameter yang termasuk dalam kategori Compression. |
| CCITT3 | Menentukan skema kompresi CCITT3. Dapat diteruskan ke encoder CCITT3 sebagai parameter yang termasuk dalam kategori Compression. |
| RLE | Menentukan skema kompresi RLE. Dapat diteruskan ke encoder RLE sebagai parameter yang termasuk dalam kategori Compression. |
| NONE | Menentukan tidak ada kompresi. Dapat diteruskan ke encoder Tiff sebagai parameter yang termasuk dalam kategori compression. |
