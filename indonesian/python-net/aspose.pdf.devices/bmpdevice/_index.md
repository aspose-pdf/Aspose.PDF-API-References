## BmpDevice class

Mewakili perangkat gambar yang membantu menyimpan halaman dokumen pdf ke bmp.

Tipe BmpDevice menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| BmpDevice() | Menginisialisasi instance baru dari kelas [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) dengan resolusi default. |
| BmpDevice(resolution) | Menginisialisasi instance baru dari kelas BmpDevice |
| BmpDevice(width, height, resolution) | Menginisialisasi instance baru dari kelas BmpDevice |
| BmpDevice(page_size, resolution) | Menginisialisasi instance baru dari kelas BmpDevice |
| BmpDevice(width, height) | Menginisialisasi instance baru dari kelas BmpDevice |
| BmpDevice(page_size) | Menginisialisasi instance baru dari kelas BmpDevice |
## Properti
| Nama | Deskripsi |
| :- | :- |
| coordinate_type | Mendapatkan atau mengatur tipe koordinat halaman (Media/Crop boxes). Nilai CropBox digunakan secara default. |
| rendering_options | Mendapatkan atau mengatur opsi rendering. |
| form_presentation_mode | Mendapatkan atau mengatur mode presentasi formulir. |
| resolution | Mendapatkan resolusi gambar. |
| lebar | Mendapatkan lebar output gambar. |
| tinggi | Mendapatkan tinggi output gambar. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| process(page, output) | Mengonversi halaman menjadi bmp dan menyimpannya ke aliran output. |
| process(page, output_file_name) | Mengonversi halaman menjadi bmp dan menyimpannya ke aliran output. |
