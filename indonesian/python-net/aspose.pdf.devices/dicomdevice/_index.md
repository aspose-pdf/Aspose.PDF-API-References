## DicomDevice class

Mewakili perangkat gambar yang membantu menyimpan halaman dokumen pdf ke format Dicom.

Tipe DicomDevice menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| DicomDevice() | Menginisialisasi instance baru dari kelas [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) dengan resolusi default. |
| DicomDevice(resolution) | Menginisialisasi instance baru dari kelas DicomDevice |
| DicomDevice(page_size) | Menginisialisasi instance baru dari kelas DicomDevice |
| DicomDevice(width, height) | Menginisialisasi instance baru dari kelas DicomDevice |
| DicomDevice(page_size, resolution) | Menginisialisasi instance baru dari kelas DicomDevice |
| DicomDevice(width, height, resolution) | Menginisialisasi instance baru dari kelas DicomDevice |
## Properti
| Nama | Deskripsi |
| :- | :- |
| coordinate_type | Mendapatkan atau mengatur tipe koordinat halaman (Media/Crop boxes). Nilai CropBox digunakan secara default. |
| rendering_options | Mendapatkan atau mengatur opsi rendering. |
| form_presentation_mode | Mendapatkan atau mengatur mode presentasi formulir. |
| resolution | Mendapatkan resolusi gambar. |
| lebar | Mendapatkan lebar output gambar. |
| tinggi | Mendapatkan tinggi output gambar. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| process(page, output) | Mengonversi halaman menjadi Dicom dan menyimpannya ke aliran output. |
| process(page, output_file_name) | Mengonversi halaman menjadi Dicom dan menyimpannya ke aliran output. |
