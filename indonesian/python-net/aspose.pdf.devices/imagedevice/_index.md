## ImageDevice class

Kelas abstrak untuk perangkat gambar.

Tipe ImageDevice menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| coordinate_type | Mendapatkan atau mengatur tipe koordinat halaman (Media/Crop boxes). Nilai CropBox digunakan secara default. |
| rendering_options | Mendapatkan atau mengatur opsi rendering. |
| form_presentation_mode | Mendapatkan atau mengatur mode presentasi formulir. |
| resolution | Mendapatkan resolusi gambar. |
| lebar | Mendapatkan lebar output gambar. |
| tinggi | Mendapatkan tinggi output gambar. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| process(page, output) | Melakukan beberapa operasi pada halaman yang diberikan, misalnya mengonversi halaman menjadi gambar grafis. |
| process(page, output_file_name) | Melakukan beberapa operasi pada halaman yang diberikan dan menyimpan hasil ke dalam file. |
