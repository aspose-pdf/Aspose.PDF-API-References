## Properti
| Nama | Deskripsi |
| :- | :- |
| margin | Mendapatkan margin. |
| skip_blank_pages | Mendapatkan atau mengatur nilai yang menunjukkan apakah akan melewatkan halaman kosong. |
| kompresi | Mendapatkan atau mengatur tipe kompresi. |
| kedalaman | Mendapatkan atau mengatur kedalaman warna. |
| bentuk | Mendapatkan atau mengatur tipe bentuk. |
| kecerahan | Mendapatkan atau mengatur batas nilai transformasi warna antara putih dan hitam.<br/>            Parameter ini dapat diterapkan dengan EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle atau ColorDepth.Format1bpp == 1 |
| coordinate_type | Mendapatkan atau mengatur tipe koordinat halaman (Media/Crop boxes). Nilai CropBox digunakan secara default. |
