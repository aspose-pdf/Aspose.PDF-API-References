## JpegDevice class

Mewakili perangkat gambar yang membantu menyimpan halaman dokumen pdf ke jpeg.

Tipe JpegDevice menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| JpegDevice() | Menginisialisasi instance baru dari kelas [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) dengan resolusi default dan kualitas maksimum. |
| JpegDevice(resolution) | Menginisialisasi instance baru dari kelas JpegDevice |
| JpegDevice(quality) | Menginisialisasi instance baru dari kelas JpegDevice |
| JpegDevice(resolution, quality) | Menginisialisasi instance baru dari kelas JpegDevice |
| JpegDevice(width, height) | Menginisialisasi instance baru dari kelas JpegDevice |
| JpegDevice(page_size) | Menginisialisasi instance baru dari kelas JpegDevice |
| JpegDevice(width, height, resolution) | Menginisialisasi instance baru dari kelas JpegDevice |
| JpegDevice(page_size, resolution) | Menginisialisasi instance baru dari kelas JpegDevice |
| JpegDevice(width, height, resolution, quality) | Menginisialisasi instance baru dari kelas JpegDevice |
| JpegDevice(page_size, resolution, quality) | Menginisialisasi instance baru dari kelas JpegDevice |
## Properti
| Nama | Deskripsi |
| :- | :- |
| coordinate_type | Mendapatkan atau mengatur tipe koordinat halaman (Media/Crop boxes). Nilai CropBox digunakan secara default. |
| rendering_options | Mendapatkan atau mengatur opsi rendering. |
| form_presentation_mode | Mendapatkan atau mengatur mode presentasi formulir. |
| resolution | Mendapatkan resolusi gambar. |
| lebar | Mendapatkan lebar output gambar. |
| tinggi | Mendapatkan tinggi output gambar. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| process(page, output) | Mengonversi halaman menjadi jpeg dan menyimpannya ke aliran keluaran. |
| process(page, output_file_name) | Mengonversi halaman menjadi jpeg dan menyimpannya ke aliran keluaran. |
