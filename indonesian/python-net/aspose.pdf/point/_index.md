## Point class

Mewakili titik dengan koordinat pecahan.

Tipe Point menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Point(x, y) | Menginisialisasi sebuah instance baru dari kelas Point |
## Properti
| Nama | Deskripsi |
| :- | :- |
| x | Nilai koordinat X. |
| y | Nilai koordinat Y. |
| sepele | Mendapatkan titik dengan koordinat nol. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| to_point() | Mengonversi titik menjadi objek System.Drawing.PointF. |
