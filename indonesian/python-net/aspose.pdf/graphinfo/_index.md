## GraphInfo class

Mewakili informasi grafis.

Tipe GraphInfo menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| GraphInfo() | Menginisialisasi instance baru dari kelas GraphInfo |
## Properti
| Nama | Deskripsi |
| :- | :- |
| line_width | Mendapatkan atau mengatur nilai float yang menunjukkan lebar garis grafik. |
| color | Mendapatkan atau mengatur objek [color](/pdf/python-net/aspose.pdf/graphinfo/) yang menunjukkan warna grafik. |
| dash_array | Mendapatkan atau mengatur array dash. |
| dash_phase | Mendapatkan atau mengatur fase dash. |
| fill_color | Mendapatkan atau mengatur objek [color](/pdf/python-net/aspose.pdf/graphinfo/) yang menunjukkan warna isi grafik. |
| is_doubled | Mendapatkan atau mengatur apakah batas digandakan. |
| skew_angle_x | Mendapatkan atau mengatur nilai float yang menunjukkan sudut kemiringan koordinat x saat mentransformasi sistem koordinat. |
| skew_angle_y | Mendapatkan atau mengatur nilai float yang menunjukkan sudut kemiringan koordinat y saat mentransformasi sistem koordinat. |
| scaling_rate_x | Mendapatkan atau mengatur nilai float yang menunjukkan tingkat skala koordinat x saat mentransformasi sistem koordinat. |
| scaling_rate_y | Mendapatkan atau mengatur nilai float yang menunjukkan tingkat skala koordinat y saat mentransformasi sistem koordinat. |
| rotation_angle | Mendapatkan atau mengatur nilai float yang menunjukkan sudut rotasi sistem koordinat <br/>            saat mentransformasi sistem koordinat. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| clone() | Kloning informasi grafik. |
