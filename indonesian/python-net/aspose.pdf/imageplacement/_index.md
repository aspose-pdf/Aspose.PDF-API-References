## ImagePlacement class

Mewakili karakteristik gambar yang ditempatkan pada halaman dokumen Pdf.

Tipe ImagePlacement menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| matriks | Matriks transformasi saat ini untuk gambar ini. |
| rectangle | Mendapatkan persegi panjang Image. |
| operator | Operator yang digunakan untuk menampilkan gambar. |
| rotation | Mendapatkan sudut rotasi Image. |
| resolution | Mendapatkan resolusi Image. |
| image | Mendapatkan objek sumber daya XImage yang terkait. |
| halaman | Mendapatkan halaman yang berisi gambar. |
| compositing_parameters | Mendapatkan parameter kompositing dari keadaan grafik yang aktif untuk gambar yang ditempatkan pada halaman. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| save(stream) | Menyimpan gambar dengan transformasi yang sesuai: penskalaan, rotasi, dan resolusi. |
| save(stream, format) | Menyimpan gambar dengan transformasi yang sesuai: penskalaan, rotasi, dan resolusi. |
| hide() | Hapus gambar dari halaman. |
| replace(image) | Ganti gambar dalam koleksi dengan gambar lain. |
