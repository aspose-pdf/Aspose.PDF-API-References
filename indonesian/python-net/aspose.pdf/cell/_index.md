## Cell class

Mewakili sel dari baris tabel.

Tipe Cell mengekspos anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Cell(rect) | Menginisialisasi sebuah instance baru dari kelas Cell |
| Cell() | Menginisialisasi sebuah instance baru dari kelas Cell. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_no_border | Mendapatkan atau mengatur apakah sel memiliki batas. |
| margin | Mendapatkan atau mengatur padding. |
| batas | Mendapatkan atau mengatur batas. |
| background_color | Mendapatkan atau mengatur warna latar belakang. |
| background_image_file | Mendapatkan atau mengatur file gambar latar belakang. |
| background_image | Mendapatkan atau mengatur gambar latar belakang |
| perataan | Mendapatkan atau mengatur perataan. |
| default_cell_text_state | Mendapatkan atau mengatur status teks sel default. |
| is_override_by_fragment | Mengatur properti TextState sel ditimpa oleh properti TextState TextFragment. |
| paragraphs | Mendapatkan atau mengatur teks terformat sel. |
| is_word_wrapped | Mendapatkan atau mengatur pembungkus kata teks sel. |
| vertical_alignment | Mendapatkan atau mengatur perataan vertikal. |
| col_span | Mendapatkan atau mengatur rentang kolom. |
| row_span | Mendapatkan atau mengatur rentang baris. |
| lebar | Mendapatkan atau mengatur lebar kolom. |
