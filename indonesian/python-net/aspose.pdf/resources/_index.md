## Resources class

Kelas yang mewakili sumber daya halaman.

Tipe Resources menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| forms | Mendapatkan koleksi [forms](/pdf/python-net/aspose.pdf/resources/) |
| images | Mendapatkan koleksi [images](/pdf/python-net/aspose.pdf/resources/) |
| fonts | Mendapatkan koleksi [fonts](/pdf/python-net/aspose.pdf/resources/) sumber daya |
## Metode
| Nama | Deskripsi |
| :- | :- |
| get_fonts(create_if_absent) | Mengembalikan koleksi font. Jika sumber daya tidak memiliki entri font, entri tersebut akan dibuat tergantung pada flag CreateIfAbsent. |
