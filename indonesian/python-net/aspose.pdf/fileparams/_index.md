## FileParams class

Mendefinisikan kamus parameter file tersemat yang harus berisi informasi tambahan khusus file.

Tipe FileParams menyajikan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| FileParams(spec) | Menginisialisasi sebuah instance baru dari kelas FileParams |
## Properti
| Nama | Deskripsi |
| :- | :- |
| ukuran | Ukuran file tersemat yang tidak terkompresi, dalam byte. |
| creation_date | Tanggal dan waktu saat file tersemat dibuat. |
| mod_date | Tanggal dan waktu saat file tersemat terakhir kali dimodifikasi. |
| check_sum | String 16-byte yang merupakan checksum dari byte-byte file tersemat yang tidak terkompresi. <br/>            Checksum dihitung dengan menerapkan algoritma standar MD5 message-digest <br/>            pada byte-byte aliran file tersemat. |
