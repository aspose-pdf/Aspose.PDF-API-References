## Metadata class

Menyediakan akses ke aliran metadata XMP.

Tipe Metadata menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_fixed_size | Memeriksa apakah colleciton memiliki ukuran tetap. |
| kunci | Mendapatkan koleksi kunci metadata. |
| nilai | Mendapatkan nilai dalam metadata. |
| is_synchronized | Memeriksa apakah koleksi disinkronkan. |
| sync_root | Mendapatkan objek sinkronisasi koleksi. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| register_namespace_uri(prefix, namespace_uri) | Mendaftarkan URI namespace. |
| register_namespace_uri(prefix, namespace_uri, schema_description) | Mendaftarkan URI namespace. |
| add(key, value) | Menambahkan nilai ke metadata. |
| add(key, value) | Menambahkan nilai ke metadata. |
| add(prefix, value) | Menambahkan ekstensi pdf ke metadata. |
| get_namespace_uri_by_prefix(prefix) | Mengembalikan  URI namespace berdasarkan prefiks. |
| get_prefix_by_namespace_uri(namespace_uri) | Mengembalikan prefiks berdasarkan URI namespace. |
| contains(key) | Memeriksa apakah kunci terdapat dalam metadata. |
| remove(key) | Menghapus entri dari metadata. |
| contains_key(key) | Menentukan apakah kamus ini berisi kunci yang ditentukan. |
| try_get_value(key, value) | Mencoba menemukan kunci dalam kamus dan mengambil nilai jika ditemukan. |
