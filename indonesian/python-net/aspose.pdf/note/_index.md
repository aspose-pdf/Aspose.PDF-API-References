## Note class

Kelas ini mewakili catatan paragraf generator.

Tipe Catatan menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Note() | Menginisialisasi sebuah instance baru dari kelas [Note](/pdf/python-net/aspose.pdf/note/). |
| Note(content) | Menginisialisasi sebuah instance baru dari kelas Note |
## Properti
| Nama | Deskripsi |
| :- | :- |
| paragraphs | Mendapatkan atau mengatur koleksi yang menunjukkan semua paragraf dalam FootNote. |
| text | Mendapatkan atau mengatur teks catatan. |
| text_state | Mendapatkan atau mengatur status teks catatan. |
