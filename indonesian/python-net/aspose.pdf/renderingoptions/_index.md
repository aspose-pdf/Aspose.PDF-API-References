## RenderingOptions class

Mewakili opsi rendering.

Tipe RenderingOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| RenderingOptions() | Menginisialisasi instance baru dari kelas RenderingOptions |
## Properti
| Nama | Deskripsi |
| :- | :- |
| barcode_optimization | Mendapatkan atau mengatur mode optimasi barcode. |
| optimize_dimensions | Mendapatkan atau mengatur mode optimasi dimensi. |
| system_fonts_native_rendering | Mendapatkan atau mengatur mode dimana font sistem dirender secara native. |
| use_new_imaging_engine | Mendapatkan atau mengatur flag yang menentukan apakah mesin imaging baru digunakan atau tidak. |
| width_extra_units | Mendapatkan atau mengatur nilai yang digunakan untuk memperbesar atau memperkecil lebar persegi panjang untuk operator AppendRectangle. |
| height_extra_units | Mendapatkan atau mengatur nilai yang digunakan untuk memperbesar atau memperkecil lebar persegi panjang untuk operator AppendRectangle. |
| convert_fonts_to_unicode_ttf | Menunjukkan bahwa semua font akan dikonversi ke versi unicode TTF. Hal ini berguna untuk alasan kompatibilitas <br/>             dan untuk mengoptimalkan penggunaan font, karena setiap font TTF baru tidak akan memiliki semua simbol <br/>             dari font sumber, melainkan hanya simbol yang digunakan dalam teks. |
| use_font_hinting | Penggunaan flag ini mengaktifkan mekanisme font hinting. Font hinting adalah penggunaan instruksi matematis untuk menyesuaikan tampilan <br/>            font outline. Dalam beberapa kasus mengaktifkan flag ini dapat menyelesaikan masalah keterbacaan teks. <br/>            Saat ini penggunaan flag ini hanya berpengaruh pada font TTF, jika font tersebut digunakan dalam dokumen sumber. |
| scale_images_to_fit_page_width | Mendapatkan atau mengatur nilai yang digunakan untuk menskalakan semua gambar pada halaman agar sesuai dengan lebar halaman. |
| interpolation_high_quality | Mendapatkan atau mengatur mode kualitas tinggi untuk interpolasi. |
| max_fonts_cache_size | Jumlah maksimum font dalam cache font. Nilai default adalah 10. |
| max_symbols_cache_size | Jumlah maksimum simbol dalam cache simbol. Nilai default adalah 100. |
| default_font_name | Mendapatkan/mengatur nama default font yang digunakan untuk menggantikan font yang hilang. |
| ignore_resource_font_errors | Mendapatkan atau mengatur indikasi bahwa kesalahan terkait ketidakhadiran font akan diabaikan.<br/>            true - berarti bahwa kesalahan ketidakhadiran font akan diabaikan. Segmen teks yang merujuk pada sumber yang tidak tepat akan dilewati selama pemrosesan.<br/>            false secara default |
