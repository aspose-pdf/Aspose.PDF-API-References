## XImageCollection class

Kelas yang mewakili koleksi XImage.

Tipe XImageCollection mengekspos anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_synchronized | Mengembalikan true jika objek disinkronkan. |
| sync_root | Mengembalikan objek sinkronisasi. |
| nama | Mendapatkan array nama gambar. |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan gambar dari koleksi berdasarkan indeksnya. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| add(image) | Menambahkan gambar baru ke daftar Gambar. Metode ini menambahkan gambar sebagai referensi ke PdfObject yang sama (yang memungkinkan mengurangi ukuran file) |
| add(image) | Menambahkan entitas ke akhir koleksi, sehingga entitas dapat diakses melalui indeks terakhir. |
| add(image, filter_type) | Menambahkan entitas ke akhir koleksi, sehingga entitas dapat diakses melalui indeks terakhir. |
| add(image, quality) | Menambahkan entitas ke akhir koleksi, sehingga entitas dapat diakses melalui indeks terakhir. |
| delete(index) | Menghapus indeks dari koleksi berdasarkan indeks. |
| delete(index, action) | Menghapus gambar dari koleksi berdasarkan indeks dengan melakukan aksi yang ditentukan oleh parameter aksi. |
| delete(name) | Menghapus item dari koleksi berdasarkan nama. |
| delete(name, action) | Menghapus item dari koleksi berdasarkan nama. |
| delete() | Menghapus indeks dari koleksi berdasarkan indeks. |
| replace(index, stream) | Ganti gambar dalam koleksi dengan gambar lain. |
| replace(index, stream, quality, is_black_and_white) | Ganti gambar dalam koleksi dengan gambar lain. |
| replace(index, stream, quality) | Ganti gambar dalam koleksi dengan gambar lain. |
| get_image_name(image) | Mengembalikan nama dalam daftar gambar yang merupakan kunci dari gambar yang diberikan. |
