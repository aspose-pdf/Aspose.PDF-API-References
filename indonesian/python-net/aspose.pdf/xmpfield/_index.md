## XmpField class

Mewakili bidang XMP.

Tipe XmpField menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| empty | Mendapatkan bidang xmp kosong. |
| lang | Mendapatkan qualifier xml:lang. |
| prefix | Mendapatkan awalan. |
| namespace_uri | Mendapatkan URI namespace. |
| local_name | Mendapatkan atau mengatur nama lokal. |
| name | Mendapatkan nama. |
| value | Mendapatkan nilai. |
| field_type | Mendapatkan tipe bidang. |
| is_empty | Mendapatkan nilai yang menunjukkan apakah instance ini kosong. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| to_structure() | Mendapatkan nilai sebagai struktur. |
| to_array() | Mendapatkan nilai sebagai array. |
