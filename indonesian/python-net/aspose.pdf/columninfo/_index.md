## ColumnInfo class

Kelas ini mewakili informasi kolom.

Tipe ColumnInfo menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ColumnInfo() | Menginisialisasi sebuah instance baru dari kelas ColumnInfo |
## Properti
| Nama | Deskripsi |
| :- | :- |
| column_widths | Mendapatkan atau mengatur string yang berisi lebar kolom. <br/>            Nilai setiap kolom harus dipisahkan dengan spasi. Unit default adalah point,<br/>            tetapi cm, inch, dan persentase lebar yang tersedia juga didukung.<br/>            Misalnya,"120 2.5cm 1.5inch" |
| column_spacing | Mendapatkan atau mengatur string yang berisi jarak antar kolom. <br/>            Nilai setiap jarak harus dipisahkan dengan spasi. Unit default adalah point,<br/>            tetapi cm dan inch juga didukung. Misalnya,"120 2.5cm 1.5inch". |
| column_count | Mendapatkan atau mengatur nilai int yang menunjukkan jumlah kolom. |
