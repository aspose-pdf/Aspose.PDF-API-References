## Opi class

Mewakili Open Prepress Interface (OPI) adalah mekanisme untuk membuat placeholder beresolusi rendah, atau proxy,<br/>            untuk gambar beresolusi tinggi seperti itu.

Tipe Opi menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Opi(xform) | Menginisialisasi sebuah instance baru dari kelas Opi |
## Properti
| Nama | Deskripsi |
| :- | :- |
| version | Mendapatkan versi OPI yang dirujuk oleh kamus ini. |
| file_specification | Mendapatkan file eksternal yang berisi gambar proksi resolusi rendah. |
| position | Mendapatkan sebuah array berisi delapan angka yang menentukan lokasi pada halaman gambar yang dipotong. |
