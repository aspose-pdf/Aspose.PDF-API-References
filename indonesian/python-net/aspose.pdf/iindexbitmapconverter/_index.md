## IIndexBitmapConverter class

Tipe IIndexBitmapConverter menampilkan anggota-anggota berikut:
## Metode
| Nama | Deskripsi |

| get_4_bpp_image(src) | Mengembalikan representasi bitmap 4Bpp |
| get_8_bpp_image(src) | Mengembalikan representasi bitmap 8Bpp |
