## ArtifactCollection class

Kelas mewakili koleksi artefak.

Tipe ArtifactCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_synchronized | Apakah objek ini disinkronkan. |
| sync_root | Mendapatkan objek sinkronisasi dari koleksi. |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan artefak berdasarkan indeks. Indeks dimulai dari 1. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| delete(artifact) | Menghapus artefak yang ditentukan. |
| delete(index) | Menghapus artefak berdasarkan indeksnya. |
| find_by_value(name, expected_value) | Menemukan artefak berdasarkan nilai khusus. |
| update(artifact) | Perbarui artefak di dalam koleksi. |
