## DocumentInfo class

Mewakili informasi meta dari dokumen PDF.

Tipe DocumentInfo menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| DocumentInfo(document) | Menginisialisasi instance baru dari kelas DocumentInfo |
## Properti
| Nama | Deskripsi |
| :- | :- |
| title | Mendapatkan atau mengatur judul dokumen. |
| creator | Mendapatkan atau mengatur pembuat dokumen. |
| author | Mendapatkan atau mengatur penulis dokumen. |
| subject | Mendapatkan atau mengatur subjek dokumen. |
| keywords | Mendapatkan atau mengatur kata kunci dokumen. |
| producer | Mendapatkan atau mengatur produsen dokumen. |
| creation_date | Mendapatkan atau mengatur tanggal pembuatan dokumen. |
| creation_time_zone | Zona waktu tanggal pembuatan. |
| mod_time_zone | Zona waktu tanggal modifikasi. |
| mod_date | Mendapatkan atau mengatur tanggal modifikasi dokumen. |
| trapped | Mendapatkan atau mengatur flag trapped. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| add(key, value) | Menambahkan elemen dengan kunci dan nilai yang ditentukan ke dalam koleksi. |
| remove(key) | Menghapus elemen dengan kunci yang ditentukan dari koleksi. |
| clear_custom_data() | Membersihkan data khusus saja, meninggalkan semua nilai pra‑definisi lainnya (Title, Author, dll.). |
| is_predefined_key(key) | Menentukan apakah kunci sudah ditentukan sebelumnya (Title, Author, dll.), bukan kustom. |
