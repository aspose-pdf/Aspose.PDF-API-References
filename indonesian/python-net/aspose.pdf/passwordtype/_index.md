## PasswordType enumeration

Enum ini mewakili tipe kata sandi yang dikenal yang digunakan untuk dokumen PDF yang dilindungi kata sandi.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| NONE | Dokumen PDF tidak dilindungi kata sandi. |
| USER | Dokumen PDF dibuka menggunakan kata sandi pembukaan dokumen (akses terbatas). |
| OWNER | Dokumen PDF dibuka menggunakan kata sandi ubah izin (akses penuh). |
| TIDAK DAPAT DIAKSES | Dokumen PDF dilindungi kata sandi tetapi kata sandi pengguna dan pemilik tidak kosong dan <br/>            tidak ada kata sandi yang didefinisikan atau kata sandi yang diberikan salah. Jadi tidak mungkin menentukan jenis kata sandi tersebut. |
