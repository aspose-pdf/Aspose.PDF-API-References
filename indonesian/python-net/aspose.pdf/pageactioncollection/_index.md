## PageActionCollection class

Kelas ini menggambarkan aksi halaman

Tipe PageActionCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| on_open | Aksi yang akan dilakukan ketika halaman dibuka. |
| on_close | Aksi yang akan dilakukan ketika halaman ditutup. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| remove_actions() | Menghapus semua aksi dari anotasi. |
