## OutlineCollection class

Mewakili hierarki outline dokumen.

Tipe OutlineCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| visible_count | Count adalah jumlah dari jumlah item outline turunan yang terlihat pada semua tingkat. Catatan: jangan bingung dengan Count yang merupakan jumlah item dalam koleksi. |
| first | Mendapatkan item outline yang mewakili item tingkat atas pertama dalam outline. |
| terakhir | Mendapatkan item outline yang mewakili item tingkat atas terakhir dalam outline. |
| is_synchronized | Mendapatkan nilai yang menunjukkan apakah akses ke koleksi ini disinkronkan (aman terhadap thread). |
| sync_root | Mendapatkan objek yang dapat digunakan untuk menyinkronkan akses ke koleksi ini. |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan item outline dari koleksi berdasarkan indeks. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| delete() | Menghapus semua item outline dari outline dokumen. |
| delete(name) | Menghapus item outline dengan judul yang ditentukan dari outline dokumen. |
