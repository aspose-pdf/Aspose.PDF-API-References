## LatexLoadOptions class

Mewakili opsi untuk memuat/mengimpor file TeX ke dalam dokumen PDF.

Tipe LatexLoadOptions mengekspos anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| LatexLoadOptions() | Menginisialisasi sebuah instance baru dari kelas LatexLoadOptions |
## Properti
| Nama | Deskripsi |
| :- | :- |
| warning_handler | Callback untuk menangani peringatan apa pun yang dihasilkan. <br/>            WarningHandler mengembalikan item enum ReturnAction yang menentukan apakah Continue atau Abort. <br/>            Continue adalah aksi default dan operasi Load berlanjut, namun pengguna juga dapat mengembalikan Abort yang berarti operasi Load harus dihentikan. |
| load_format | Mewakili format file yang dijelaskan oleh [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/). |
| job_name | Mendapatkan/mengatur nama pekerjaan. |
| input_directory | Mendapatkan/mengatur direktori input TeX. |
| output_directory | Mendapatkan/mengatur direktori output TeX. |
| repeat | Mendapatkan/mengatur flag yang menunjukkan apakah perlu menjalankan pekerjaan TeX dua kali dalam kasus,<br/>            misalnya, ada referensi dalam file TeX input. Secara umum, perilaku ini berguna ketika<br/>            mesin mengumpulkan beberapa data selama proses penataan huruf dan menyimpannya dalam file tambahan,<br/>            semua pada run pertama. Dan pada run kedua, mesin entah bagaimana menggunakan data tersebut. |
| subset_fonts | Mendapatkan/mengatur flag yang menunjukkan apakah harus melakukan subset font dalam file output atau tidak. |
| show_terminal_output | Mendapatkan/mengatur flag yang menunjukkan apakah menampilkan output terminal di konsol. |
| date_time | Mendapatkan/mengatur nilai tertentu untuk primitif tanggal/waktu seperti \year, \month, \day, dan \time. |
| no_ligatures | Mendapatkan/mengatur flag yang membatalkan ligatur di semua font. |
| rasterize_formulas | Mendapatkan/mengatur flag yang memungkinkan merasterkan formula matematika. |
