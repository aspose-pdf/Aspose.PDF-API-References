## Row class

Mewakili baris tabel.

Tipe Row menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Row() | Menginisialisasi instance baru dari kelas Row |
## Properti
| Nama | Deskripsi |
| :- | :- |
| background_color | Mendapatkan atau mengatur warna latar belakang. |
| batas | Mendapatkan atau mengatur batas. |
| cells | Mendapatkan sel-sel baris. |
| default_cell_border | Mendapatkan batas sel default; |
| min_row_height | Mendapatkan tinggi untuk baris; |
| fixed_row_height | Mendapatkan tinggi baris tetap - baris mungkin memiliki tinggi tetap; |
| is_in_new_page | Mendapatkan apakah baris tetap berada di halaman baru - halaman dengan properti ini harus dicetak ke halaman berikutnya Default false; |
| is_row_broken | Mendapatkan apakah baris dapat dipisah antara dua halaman |
| default_cell_text_state | Mendapatkan atau mengatur keadaan teks default untuk sel baris |
| default_cell_padding | Mendapatkan atau mengatur margin default untuk sel baris |
| vertical_alignment | Mendapatkan atau mengatur perataan vertikal. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| clone() | Menggandakan baris. |
