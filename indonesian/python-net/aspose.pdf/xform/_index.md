## XForm class

Kelas yang mewakili XForm

Tipe XForm memperlihatkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| b_box | Mendapatkan atau mengatur kotak pembatas formulir. |
| name | Mendapatkan atau mengatur nama formulir. Nama formulir adalah nama yang digunakan untuk merujuk formulir dalam kamus XObejct pada sumber daya halaman. |
| konten | Mendapatkan operator formulir. |
| opi | Mendapatkan Open Prepress Interface (OPI). |
| matriks | Mendapatkan atau mengatur matriks formulir. |
| resources | Mendapatkan sumber daya Form XObject. |
| rectangle | Mendapatkan atau mengatur persegi panjang formulir. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| get_resources(allow_create) | Mengembalikan sumber daya Form X-Object |
| get_resources() | Mengembalikan sumber daya Form X-Object |
| create_new_form(source, document) | Membuat XForm yang menduplikasi konten halaman. |
| free_memory() | Menghapus data cache |
