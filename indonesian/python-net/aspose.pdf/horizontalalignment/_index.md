## HorizontalAlignment enumeration

Menjelaskan perataan horizontal.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| NONE | Tidak ada perataan. |
| LEFT | Rata kiri. |
| CENTER | Perataan tengah. |
| RIGHT | Rata kanan. |
| JUSTIFY | Perataan justify. Teks akan diratakan pada margin kiri dan kanan. |
| FULL_JUSTIFY | Mirip dengan perataan 'Justify', kecuali baris terakhir akan hanya <br/>            left-aligned dalam mode 'Justify', sementara dalam mode 'FullJustify' semua baris akan <br/>            left- and right-aligned. |
