## FloatingBox class



Tipe FloatingBox menyediakan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| FloatingBox(width, height) | Menginisialisasi instance baru dari kelas FloatingBox |
| FloatingBox() | Menginisialisasi instance baru dari kelas [FloatingBox](/pdf/python-net/aspose.pdf/floatingbox/). |
## Properti
| Nama | Deskripsi |
| :- | :- |
| vertical_alignment | Mendapatkan atau mengatur perataan vertikal paragraf |
| horizontal_alignment | Mendapatkan atau mengatur perataan horizontal paragraf |
| margin | Mendapatkan atau mengatur margin luar untuk paragraf (untuk pembuatan pdf) |
| is_first_paragraph_in_column | Mendapatkan atau mengatur nilai bool yang menunjukkan apakah paragraf ini akan berada di kolom berikutnya.<br/>            Defaultnya false. (untuk pembuatan pdf) |
| is_kept_with_next | Mendapatkan atau mengatur nilai bool yang menunjukkan apakah paragraf saat ini tetap berada di halaman yang sama bersama paragraf berikutnya.<br/>            Defaultnya false. (untuk pembuatan pdf) |
| is_in_new_page | Mendapatkan atau mengatur nilai bool yang memaksa paragraf ini dihasilkan pada halaman baru.<br/>            Defaultnya false. (untuk pembuatan pdf) |
| is_in_line_paragraph | Mendapatkan atau mengatur apakah paragraf bersifat inline.<br/>            Defaultnya false. (untuk pembuatan pdf) |
| hyperlink | Mendapatkan atau mengatur hyperlink fragmen (untuk generator pdf). |
| z_index | Mendapatkan atau mengatur nilai int yang menunjukkan urutan Z dari grafik. Grafik dengan ZIndex yang lebih besar <br/>            akan ditempatkan di atas grafik dengan ZIndex yang lebih kecil. ZIndex dapat bernilai negatif. Grafik dengan ZIndex negatif <br/>            akan ditempatkan di belakang teks pada halaman. |
| column_info | Mendapatkan atau mengatur informasi kolom |
| lebar | Mendapatkan atau mengatur nilai float yang menunjukkan lebar kotak mengambang. |
| tinggi | Mendapatkan atau mengatur nilai float yang menunjukkan tinggi kotak mengambang. |
| is_need_repeating | Mendapatkan atau mengatur nilai bool yang menunjukkan apakah paragraf perlu diulang pada halaman berikutnya.<br/>            Nilai default adalah false. Atribut ini hanya berlaku ketika paragraf itu sendiri dan objek yang dirujuk oleh ReferenceParagraphID keduanya termasuk dalam RepeatingRows. |
| paragraphs | Mendapatkan atau mengatur koleksi [paragraphs](/pdf/python-net/aspose.pdf/floatingbox/) yang menunjukkan semua paragraf dalam sel. |
| border | Mendapatkan atau mengatur objek [BorderInfo](/pdf/python-net/aspose.pdf/borderinfo/) yang menunjukkan informasi batas kotak mengambang. |
| background_color | Mendapatkan atau mengatur objek [Color](/pdf/python-net/aspose.pdf/color/) yang menunjukkan warna latar belakang kotak mengambang. |
| background_image | Mendapatkan atau mengatur gambar latar belakang untuk halaman (hanya untuk generator, tidak diisi saat membaca dokumen). |
| padding | Mendapatkan atau mengatur objek [MarginInfo](/pdf/python-net/aspose.pdf/margininfo/) yang menunjukkan padding kotak mengambang. |
| left | Mendapatkan atau mengatur koordinat kiri tabel. |
| top | Mendapatkan atau mengatur koordinat atas tabel. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| clone() | Mengkloning objek [FloatingBox](/pdf/python-net/aspose.pdf/floatingbox/) baru. Paragraf dalam kotak mengambang tidak diklon. |
