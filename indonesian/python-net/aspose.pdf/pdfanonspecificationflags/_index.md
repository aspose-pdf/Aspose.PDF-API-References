## PdfANonSpecificationFlags class

Kelas ini menyimpan flag untuk mengontrol konversi PDF/A pada kasus ketika dokumen PDF sumber tidak <br/>            sesuai dengan spesifikasi PDF. Jika flag dari kelas ini digunakan, kinerjanya menurun <br/>            tetapi diperlukan ketika dokumen PDF sumber tidak dapat dikonversi ke format PDF/A dengan cara biasa. <br/>            Secara default semua flag diatur ke false.

Tipe PdfANonSpecificationFlags menampilkan anggota-anggota berikut:

| :- | :- |
| PdfANonSpecificationFlags() | Menginisialisasi instance baru dari kelas PdfANonSpecificationFlags |
## Properti
| Nama | Deskripsi |
| :- | :- |
| check_different_names_in_font_dictionaries | Beberapa dokumen PDF berisi font yang memiliki nama berbeda dalam data internal. <br/>            Penggunaan flag ini memaksa logika pemrosesan khusus untuk kasus ketika bidang <br/>            BaseFont dan FontDescriptor.FontName berbeda. |
