## PageSize class

Kelas yang merepresentasikan ukuran halaman dalam dokumen PDF.

Tipe PageSize menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| PageSize(x, y) | Menginisialisasi instance baru dari kelas PageSize |
## Properti
| Nama | Deskripsi |
| :- | :- |
| lebar | Mendapatkan atau mengatur lebar halaman. |
| tinggi | Mendapatkan atau mengatur tinggi halaman. |
| is_landscape | Mendapatkan orientasi halaman. Mengembalikan true jika orientasi lanskap dan false jika orientasi potret. |
| a0 | Ukuran A0 (1189x840 mm). |
| a1 | Ukuran A1 (840x594 mm). |
| a2 | Ukuran A2 (594x420 mm). |
| a3 | Ukuran A3 (420x297 mm). |
| a4 | Ukuran A4 (297x210 mm). |
| a5 | Ukuran A5 (210x148 mm). |
| a6 | Ukuran A6 (148x105 mm). |
| b5 | Ukuran B5 (250x176 mm). |
| page_letter | Ukuran Letter (279x216 mm). |
| page_legal | Ukuran Legal (356x216 mm). |
| page_ledger | Ukuran Ledger (432x279 mm). |
| p11x17 | Format 11x17 inci. |
