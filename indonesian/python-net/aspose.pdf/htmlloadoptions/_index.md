## HtmlLoadOptions class

Mewakili opsi untuk memuat/mengimpor file html ke dalam dokumen pdf.

Tipe HtmlLoadOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| HtmlLoadOptions() | Membuat opsi pemuatan untuk mengonversi html menjadi dokumen pdf dengan jalur dasar kosong. |
| HtmlLoadOptions(base_path) | Menginisialisasi instance baru dari kelas HtmlLoadOptions |
## Properti
| Nama | Deskripsi |
| :- | :- |
| warning_handler | Callback untuk menangani peringatan apa pun yang dihasilkan. <br/>            WarningHandler mengembalikan item enum ReturnAction yang menentukan apakah Continue atau Abort. <br/>            Continue adalah aksi default dan operasi Load berlanjut, namun pengguna juga dapat mengembalikan Abort yang berarti operasi Load harus dihentikan. |
| load_format | Mewakili format file yang dijelaskan oleh [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/). |
| is_render_to_single_page | Mendapatkan atau mengatur render seluruh dokumen ke satu halaman |
| is_embed_fonts | Mendapatkan atau mengatur penyematan font ke dokumen hasil |
| page_layout_option | Mendapatkan atau mengatur opsi tata letak. |
| html_media_type | Mendapatkan atau mengatur tipe media yang mungkin digunakan selama render. |
| input_encoding | Mendapatkan atau mengatur atribut yang menentukan enkoding yang digunakan untuk dokumen ini pada saat parsing. Jika atribut ini null, enkoding akan ditentukan dari atribut set karakter dokumen. |
| base_path | Jalur dasar/url untuk file html. |
| page_info | Mendapatkan atau mengatur informasi halaman dokumen |
