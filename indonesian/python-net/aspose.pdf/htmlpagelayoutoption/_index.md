## HtmlPageLayoutOption enumeration

Menentukan flag yang bersama opsi lain menentukan ukuran dan tata letak halaman.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| NONE | Nilai default yang menunjukkan bahwa HtmlPageLayoutOption tidak akan memengaruhi ukuran dan tata letak halaman. |
| FIT_TO_WIDEST_CONTENT_WIDTH | Menunjukkan bahwa lebar halaman ditentukan dari ukuran konten itu sendiri, bukan dari lebar halaman yang ditentukan. |
| SCALE_TO_PAGE_WIDTH | Menunjukkan bahwa konten dokumen akan diskalakan agar sesuai dengan halaman. |
