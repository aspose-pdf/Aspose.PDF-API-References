## PageLabelCollection class

Kelas yang merepresentasikan koleksi label halaman.

Tipe PageLabelCollection menampilkan anggota-anggota berikut:
## Metode
| Nama | Deskripsi |
| :- | :- |
| get_label(page_index) | Mendapatkan label halaman berdasarkan indeks halaman (indeks halaman dimulai dari 0). |
| update_label(page_index, page_label) | Perbarui label untuk indeks halaman yang diberikan (indeks halaman dimulai dari 0). |
| remove_label(page_index) | Hapus label berdasarkan indeks halaman (indeks halaman dimulai dari 0). |
| get_pages() | Mendapatkan indeks halaman dalam koleksi. |
