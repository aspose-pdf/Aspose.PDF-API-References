## EmbeddedFileCollection class

Kelas yang mewakili koleksi file tersemat.

Tipe EmbeddedFileCollection mengekspos anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_synchronized | Mendapatkan nilai yang menunjukkan apakah akses ke koleksi ini disinkronkan (aman terhadap thread). |
| sync_root | Mendapatkan objek yang dapat digunakan untuk menyinkronkan akses ke koleksi ini. |
| kunci | Mengembalikan daftar kunci lampiran file. |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan file tersemat berdasarkan indeksnya. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| delete(name) | Menghapus file dari koleksi berdasarkan kuncinya dalam koleksi. |
| delete() | Menghapus file dari koleksi berdasarkan kuncinya dalam koleksi. |
| add(key, file) | Menambahkan file ke file tersemat dengan kunci yang ditentukan. |
| delete_by_key(key) | Menghapus file dari koleksi berdasarkan kuncinya dalam koleksi. |
| find_by_name(name) | Mengembalikan file tersemat berdasarkan namanya. |
