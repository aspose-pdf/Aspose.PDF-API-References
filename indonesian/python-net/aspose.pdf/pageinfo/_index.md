## PageInfo class

Mewakili informasi halaman.

Tipe PageInfo menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| PageInfo() | Menginisialisasi sebuah instance baru dari kelas PageInfo. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| any_margin | Mendapatkan atau mengatur margin halaman untuk semua halaman kecuali yang pertama. |
| default_text_state | Mendapatkan atau mengatur font default. |
| tinggi | Mendapatkan atau mengatur tinggi halaman. |
| pure_height | Mendapatkan atau mengatur tinggi murni halaman tanpa margin. |
| is_landscape | Mendapatkan atau mengatur apakah halaman dalam orientasi lanskap. |
| margin | Mendapatkan atau mengatur margin halaman. |
| lebar | Mendapatkan atau mengatur lebar halaman. |
