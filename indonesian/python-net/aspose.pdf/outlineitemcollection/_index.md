## OutlineItemCollection class

Mewakili entri outline dalam hierarki outline dokumen PDF.

Tipe OutlineItemCollection menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| OutlineItemCollection(outlines) | Menginisialisasi sebuah instance baru dari kelas OutlineItemCollection |
## Properti
| Nama | Deskripsi |
| :- | :- |
| visible_count | Mendapatkan total jumlah item outline pada semua level dalam hierarki outline dokumen. |
| title | Mendapatkan atau mengatur judul untuk item outline ini. |
| tujuan | Mendapatkan atau mengatur tujuan untuk item outline ini. |
| action | Mendapatkan atau mengatur aksi untuk item outline ini. |
| warna | Mendapatkan atau mengatur warna untuk teks judul item outline ini. |
| miring | Mendapatkan atau mengatur flag miring untuk teks judul item outline ini |
| tebal | Mendapatkan atau mengatur flag tebal untuk teks judul item outline ini |
| first | Mendapatkan item outline yang mewakili item tingkat atas pertama dalam hierarki outline. |
| terakhir | Mendapatkan item outline yang mewakili item tingkat atas terakhir dalam hierarki outline. |
| sebelumnya | Mendapatkan item outline yang mewakili item sebelumnya relatif terhadap item ini dalam hierarki outline. |
| berikutnya | Mendapatkan item outline yang mewakili item berikutnya relatif terhadap item ini dalam hierarki outline. |
| has_next | Memeriksa apakah ada item outline yang mewakili item berikutnya relatif terhadap item ini dalam hierarki outline. |
| parent | Mendapatkan objek induk dari item outline ini dalam hierarki outline. |
| is_synchronized | Mendapatkan nilai yang menunjukkan apakah akses ke koleksi ini disinkronkan (aman untuk thread). |
| sync_root | Mendapatkan objek yang dapat digunakan untuk menyinkronkan akses ke koleksi ini. |
| buka | Mendapatkan atau mengatur status terbuka (true/false) untuk item outline. |
| level | Mendapatkan level hierarki dari item outline. |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan item outline dari koleksi menggunakan indeks. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| delete() | Menghapus item outline ini dari hierarki outline dokumen. |
| delete(name) | Menghapus entri outline dengan nama yang ditentukan dari hierarki outline dokumen. |
| insert(index, outline) | Menyisipkan item outline ke dalam koleksi pada tempat yang ditentukan. |
