## TimestampSettings class

Mewakili pengaturan ocsp yang digunakan selama proses penandatanganan.

Tipe TimestampSettings menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TimestampSettings(server_url, basic_auth_credentials, digest_hash_algorithm) | Menginisialisasi instance baru dari kelas TimestampSettings |
## Properti
| Nama | Deskripsi |
| :- | :- |
| server_url | Mendapatkan/mengatur URL server timestamp. |
| basic_auth_credentials | Mendapatkan/mengatur kredensial otentikasi dasar, Username dan password digabungkan menjadi string "username:password". |
| digest_hash_algorithm | Mendapatkan/mengatur algoritma digest untuk fungsi hash internal. |
