## OperatorCollection class

Kelas mewakili kumpulan operator

Tipe OperatorCollection menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_fast_text_extraction_mode | Menunjukkan apakah koleksi dibatasi untuk ekstraksi teks cepat. |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan operator berdasarkan indeksnya. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| insert(index, op) | Menyisipkan operator ke dalam koleksi. |
| insert(at, ops) | Menyisipkan operator pada posisi yang diberikan. |
| insert(at, ops) | Menyisipkan operator ke dalam koleksi. |
| delete(index) | Menghapus operator dari koleksi. |
| delete(ops) | Menghapus operator dari koleksi. |
| delete(list) | None |
| add(ops) | Menambahkan operator di akhir operator konten. |
| add(ops) | Menambahkan operator baru ke dalam koleksi. |
| suppress_update() | Menekan pembaruan data konten.<br/>            Aliran konten tidak diperbarui sampai ResumeUpdate dipanggil. |
| resume_update() | Melanjutkan pembaruan dokumen.<br/>            Memperbarui aliran konten jika ada perubahan yang tertunda. |
| cancel_update() | Membatalkan pembaruan terakhir.<br/>            Metode ini dapat dipanggil ketika perubahan tidak boleh memicu pembaruan konten. |
| accept(visitor) | Menerima objek pengunjung IOperatorSelector untuk memproses operator. |
| replace(operators) | Ganti operator dalam koleksi dengan operator lain. |
