Mewakili informasi daftar isi.

## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TocInfo() | Menginisialisasi sebuah instance baru dari kelas [TocInfo](/pdf/python-net/aspose.pdf/tocinfo/). |
