## Option class

Kelas mewakili opsi bidang pilihan.

Tipe Option menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| value | Mendapatkan atau mengatur nilai ekspor opsi. |
| name | Mendapatkan atau mengatur nama opsi. |
| selected | Mendapatkan atau mengatur status terpilih opsi. Mengembalikan true jika opsi terpilih. |
| index | Mendapatkan indeks opsi. |
