## OptionCollection class

Tipe OptionCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_synchronized | Mengembalikan true jika objek disinkronkan. |
| sync_root | Objek sinkronisasi dari koleksi. |

| Nama | Deskripsi |
| :- | :- |

## Metode

| :- | :- |
