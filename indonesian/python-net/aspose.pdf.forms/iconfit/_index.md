## IconFit class

Menjelaskan bagaimana ikon anotasi widget harus ditampilkan di dalam persegi panjang anotasinya.

Tipe IconFit menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| scaling_reason | Mendapatkan atau mengatur alasan skala. |
| scaling_mode | Tipe skala yang akan digunakan.        /// |
| leftover_left | Mendapatkan atau mengatur ruang yang dialokasikan di sebelah kiri ikon. |
| leftover_bottom | Mendapatkan atau mengatur ruang yang dialokasikan di bagian bawah ikon. |
| spread_on_border | Jika true, menunjukkan bahwa tampilan tombol harus diskalakan agar sepenuhnya muat dalam batas anotasi tanpa memperhitungkan lebar garis border. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| name_to_scaling_reason(reason) | Mengonversi nama alasan skala menjadi objek ScalingReason. |
| scaling_reason_to_name(reason) | Mengonversi objek alasan skala menjadi nama. |
| name_to_scaling_mode(mode) | Mengonversi nama mode skala menjadi objek ScalingMode. |
| scaling_mode_to_name(mode) | Mengonversi objek mode skala menjadi nama. |
