## StructureTextState class

Mewakili pengaturan keadaan teks untuk Elemen Struktur Teks dan TaggedContent (ITextElement, ITaggedContent)

Tipe StructureTextState menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| font | Mendapatkan atau mengatur font teks. |
| font_size | Mendapatkan atau mengatur ukuran font teks. |
| font_style | Mendapatkan atau mengatur gaya font teks. |
| foreground_color | Mendapatkan atau mengatur warna latar depan teks. |
| background_color | Mendapatkan atau mengatur warna latar belakang teks. |
| garis bawah | Mendapatkan atau mengatur garis bawah untuk teks. |
| coret | Mendapatkan atau mengatur coret untuk teks. |
| superscript | Mendapatkan atau mengatur superskrip teks. |
| subscript | Mendapatkan atau mengatur subskrip teks. |
| horizontal_scaling | Mendapatkan atau mengatur skala horizontal teks. |
| line_spacing | Mendapatkan atau mengatur spasi baris teks. |
| character_spacing | Mendapatkan atau mengatur spasi karakter teks. |
| word_spacing | Mendapatkan atau mengatur spasi kata teks. |
| margin_info | Mendapatkan atau mengatur margin untuk elemen struktur blok. |
