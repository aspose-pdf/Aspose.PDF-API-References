## TableTRElement class

Mewakili elemen struktur TR dalam struktur logis tabel.

Tipe TableTRElement menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| parent_element | None |
| child_elements | None |
| default_attribute_owner | Mendapatkan |
| atribut | Mendapatkan |
| structure_type | Mendapatkan tipe elemen struktur. |
| id | Mendapatkan ID untuk elemen struktur. |
| title | Mendapatkan atau mengatur judul untuk elemen struktur. |
| bahasa | Mendapatkan atau mengatur bahasa untuk elemen struktur. |
| alternative_text | Mendapatkan atau mengatur teks alternatif untuk elemen struktur. |
| expansion_text | Mendapatkan atau mengatur teks ekspansi untuk elemen struktur. |
| actual_text | Mendapatkan atau mengatur teks aktual untuk elemen struktur. |
| background_color | Mendapatkan atau mengatur warna latar belakang baris. |
| batas | Mendapatkan atau mengatur batas baris. |
| default_cell_border | Mendapatkan batas sel default. |
| min_row_height | Mendapatkan tinggi untuk baris. |
| fixed_row_height | Mendapatkan tinggi baris tetap - baris dapat memiliki tinggi tetap. |
| is_in_new_page | Mendapatkan apakah baris tetap berada di halaman baru - halaman dengan properti ini harus dicetak ke halaman berikutnya. Default false. |
| is_row_broken | Mendapatkan apakah baris dapat dipotong antara dua halaman. |
| default_cell_text_state | Mendapatkan atau mengatur keadaan teks default untuk sel baris |
| default_cell_padding | Mendapatkan atau mengatur margin default untuk sel baris. |
| vertical_alignment | Mendapatkan atau mengatur perataan vertikal. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| append_child(element) | None |
| change_parent_element(new_parent_element) | Ubah elemen induk untuk elemen struktur saat ini |
| generate_id() | Hasilkan ID untuk elemen struktur. |
| set_id(id) | Mengatur ID untuk elemen struktur. |
| clear_id() | Bersihkan ID untuk elemen struktur. |
| set_tag(new_tag) | Mengatur tag khusus untuk elemen struktur. |
