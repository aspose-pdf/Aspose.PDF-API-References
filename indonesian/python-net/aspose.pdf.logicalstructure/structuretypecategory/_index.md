## StructureTypeCategory class

Mewakili Kategori Tipe Struktur Standar.

Tipe StructureTypeCategory menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| GROUPING_ELEMENTS | Elemen pengelompokan mengelompokkan elemen lain menjadi urutan atau hierarki tetapi tidak menyimpan konten secara langsung dan tidak memiliki efek langsung pada tata letak. |
| BLS_ES | Elemen struktur tingkat blok (BLSEs) menggambarkan tata letak keseluruhan konten pada halaman, bergerak dalam arah progresi blok. |
| ILS_ES | Elemen struktur tingkat inline (ILSEs) menggambarkan tata letak konten di dalam BLSE, bergerak dalam arah progresi inline. |
| ILLUSTRATION_ELEMENTS | Elemen ilustrasi adalah urutan konten yang padat, dalam urutan konten halaman, yang dianggap sebagai objek tunggal terhadap tata letak halaman. Sebuah ilustrasi dapat diperlakukan sebagai BLSE atau ILSE. |
