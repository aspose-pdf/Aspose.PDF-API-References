## StructureAttribute class

Mewakili atribut elemen struktur.

Tipe StructureAttribute menyajikan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| StructureAttribute(attribute_key) | Menginisialisasi sebuah instance baru dari kelas StructureAttribute |
## Properti
| Nama | Deskripsi |
| :- | :- |
| key | Mendapatkan kunci atribut. |
| is_initialized_value | Mendapatkan status nilai atribut struktur. True jika nilai telah diatur. |
