## ILSTextElement class

Mewakili kelas dasar untuk elemen struktur teks tingkat inline dalam struktur logis.

Tipe ILSTextElement menyajikan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| parent_element | None |
| child_elements | None |
| default_attribute_owner | Mendapatkan |
| atribut | Mendapatkan |
| structure_type | Mendapatkan tipe elemen struktur. |
| id | Mendapatkan ID untuk elemen struktur. |
| title | Mendapatkan atau mengatur judul untuk elemen struktur. |
| bahasa | Mendapatkan atau mengatur bahasa untuk elemen struktur. |
| alternative_text | Mendapatkan atau mengatur teks alternatif untuk elemen struktur. |
| expansion_text | Mendapatkan atau mengatur teks ekspansi untuk elemen struktur. |
| actual_text | Mendapatkan atau mengatur teks aktual untuk elemen struktur. |
| structure_text_state | Mendapatkan |
## Metode
| Nama | Deskripsi |
| :- | :- |
| append_child(element) | None |
| change_parent_element(new_parent_element) | Ubah elemen induk untuk elemen struktur saat ini |
| generate_id() | Hasilkan ID untuk elemen struktur. |
| set_id(id) | Mengatur ID untuk elemen struktur. |
| clear_id() | Bersihkan ID untuk elemen struktur. |
| set_tag(new_tag) | Mengatur tag khusus untuk elemen struktur. |
| set_text(text) | Menambahkan konten teks ke elemen teks saat ini. |
