## ToUnicodeProcessingRules class

Kelas ini menjelaskan aturan yang dapat digunakan untuk menyelesaikan kesalahan Adobe Preflight <br/>            "Teks tidak dapat dipetakan ke Unicode".

Tipe ToUnicodeProcessingRules menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ToUnicodeProcessingRules() | Konstruktor |
| ToUnicodeProcessingRules(remove_spaces) | Menginisialisasi sebuah instance baru dari kelas ToUnicodeProcessingRules |
| ToUnicodeProcessingRules(remove_spaces, map_non_linked_unicodes_on_space) | Menginisialisasi sebuah instance baru dari kelas ToUnicodeProcessingRules |
## Properti
| Nama | Deskripsi |
| :- | :- |
| remove_spaces_from_c_map_names | Beberapa font memiliki peta kode karakter ToUnicode dengan spasi di nama. Spasi ini dapat menyebabkan kesalahan<br/>            dengan pemetaan teks unicode. Flag ini menginstruksikan untuk menghapus spasi dari nama peta kode karakter ToUnicode.<br/>            Secara default false. |
| map_non_linked_symbols_on_space | Beberapa font tidak menyediakan informasi tentang unicode untuk beberapa simbol teks. <br/>            Kekurangan informasi ini menyebabkan kesalahan "Text cannot be mapped to Unicode".<br/>            Gunakan flag ini untuk memetakan simbol yang tidak terhubung ke unicode "space" (kode 32). |
