## FontEmbeddingOptions class

Standar PDF/A mengharuskan semua font harus disematkan ke dalam dokumen.<br/>            Kelas ini mencakup flag untuk kasus ketika tidak memungkinkan menyematkan beberapa font karena font tersebut tidak ada <br/>            pada PC tujuan.

Tipe FontEmbeddingOptions menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| FontEmbeddingOptions() | Menginisialisasi instance baru dari kelas FontEmbeddingOptions |
## Properti
| Nama | Deskripsi |
| :- | :- |
| use_default_substitution | Menyatakan untuk menggantikan font yang tidak ter-embed menggunakan strategi substitusi font default. Secara default false; |
