## IPdfTypeExtractor class

Mewakili antarmuka untuk berinteraksi dengan ekstraktor.

Tipe IPdfTypeExtractor menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| page_count | Mengembalikan jumlah halaman. |
| version | Mengembalikan versi. |
| is_fast_extraction_used | Mengembalikan apakah mekanisme ekstraksi cepat digunakan. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| extract_all_text() | Mengembalikan koleksi nilai teks yang diekstrak. |
| extract_page_text(page_number) | Mengembalikan teks halaman. |
| dispose() | Membuang. |
