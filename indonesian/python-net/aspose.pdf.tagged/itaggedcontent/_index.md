## ITaggedContent class

Mewakili antarmuka untuk bekerja dengan konten TaggedPdf dokumen.

Tipe ITaggedContent menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| structure_text_state | Dapatkan pengaturan [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) untuk seluruh dokumen. |
| struct_tree_root_element | Mendapatkan [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/) dari dokumen PDF. |
| root_element | Mendapatkan [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) akar dari struktur logis dokumen PDF. |
