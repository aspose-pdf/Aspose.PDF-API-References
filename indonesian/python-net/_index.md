## Namespace

| Namespace | Deskripsi |
| :- | :- |
| [aspose.pdf](/pdf/python-net/aspose.pdf/) | aspose.pdf adalah namespace akar untuk semua kelas dalam pustaka Aspose.Pdf yang berada langsung di dalamnya seperti Document atau tidak langsung melalui beberapa sub-namespace. |
| [aspose.pdf.annotations](/pdf/python-net/aspose.pdf.annotations/) | Namespace aspose.pdf.annotations menyediakan kelas untuk bekerja dengan berbagai jenis aksi, tujuan, dan fitur lain dari dokumen yang secara tradisional disebut interaktif, memberikan cara bagi pengguna berinteraksi dengan dokumen. |
| [aspose.pdf.devices](/pdf/python-net/aspose.pdf.devices/) | Namespace aspose.pdf.devices menyediakan kelas yang digunakan untuk merepresentasikan dokumen sebagai gambar atau teks biasa. Sehingga dokumen dapat dikirim ke perangkat teks atau grafis yang beragam, yang berarti kita dapat memperoleh representasi teks atau grafis. |
| [aspose.pdf.drawing](/pdf/python-net/aspose.pdf.drawing/) | Namespace aspose.pdf.drawing menyediakan kelas yang menggambarkan primitif grafis seperti busur, garis, lingkaran, dll. Objek terkait dapat digunakan untuk membuat dokumen baru. |
| [aspose.pdf.facades](/pdf/python-net/aspose.pdf.facades/) | Namespace aspose.pdf.facades menyediakan kelas yang awalnya berasal dari Aspose.Pdf.Kit. Kelas-kelas ini digunakan untuk memanipulasi dokumen dengan melakukan operasi seperti menggabungkan, menstempel, menandatangani, memberi anotasi, dll., tetapi pada tingkat tinggi tanpa mengakses struktur internal dokumen. |
| [aspose.pdf.forms](/pdf/python-net/aspose.pdf.forms/) | Namespace aspose.pdf.forms memiliki kelas yang menjelaskan formulir (standar, statis, dinamis) serta berbagai jenis bidang seperti kotak teks, kotak daftar, tombol radio, dll. |
| [aspose.pdf.groupprocessor](/pdf/python-net/aspose.pdf.groupprocessor/) | Namespace aspose.pdf.groupprocessor menyediakan kelas yang digunakan untuk mengelola teks dan font. |
| [aspose.pdf.groupprocessor.creators](/pdf/python-net/aspose.pdf.groupprocessor.creators/) | Namespace aspose.pdf.groupprocessor.creators menyediakan kelas yang digunakan untuk membuat instance kelas GroupProcessor. |
| [aspose.pdf.logicalstructure](/pdf/python-net/aspose.pdf.logicalstructure/) | aspose.pdf.logicalstructure adalah namespace untuk kelas PDF Logical Structure. |
| [aspose.pdf.operators](/pdf/python-net/aspose.pdf.operators/) | Namespace aspose.pdf.operators adalah namespace untuk implementasi Operator. Kelas-kelas ini menjelaskan operator yang digunakan dalam konten halaman PDF. |
| [aspose.pdf.optimization](/pdf/python-net/aspose.pdf.optimization/) | Namespace aspose.pdf.optimization adalah namespace untuk kelas yang mengelola proses optimasi dokumen. |
| [aspose.pdf.pdfaoptionclasses](/pdf/python-net/aspose.pdf.pdfaoptionclasses/) | Namespace aspose.pdf.pdfaoptionclasses adalah namespace untuk opsi konversi PDF/A. |
| [aspose.pdf.sanitization](/pdf/python-net/aspose.pdf.sanitization/) | Namespace aspose.pdf.sanitization adalah namespace untuk operasi sanitasi. |
| [aspose.pdf.structure](/pdf/python-net/aspose.pdf.structure/) | Namespace aspose.pdf.structure menyediakan kelas yang membantu bekerja dengan struktur logis sebuah dokumen yang menampilkan organisasi dokumen menjadi bab dan bagian atau mengidentifikasi elemen khusus seperti gambar, tabel, dan catatan kaki. |
| [aspose.pdf.tagged](/pdf/python-net/aspose.pdf.tagged/) | Namespace aspose.pdf.tagged adalah namespace untuk kelas yang mendukung dokumen Tagged PDF. |
| [aspose.pdf.text](/pdf/python-net/aspose.pdf.text/) | Namespace aspose.pdf.text menyediakan kelas yang memungkinkan mengekstrak teks, menambah teks, memanipulasi teks yang ada dalam dokumen. Ia juga berisi kelas yang memungkinkan mengekstrak, mengganti, atau menggantikan font dalam dokumen. |
| [aspose.pdf.xfaconverter](/pdf/python-net/aspose.pdf.xfaconverter/) | Namespace aspose.pdf.xfaconverter menyediakan kelas yang memungkinkan mengonversi XFA. |
