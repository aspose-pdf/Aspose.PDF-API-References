## Line class

Mewakili garis.

Tipe Line menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Line(position_array) | Menginisialisasi instance baru dari kelas Line |
## Properti
| Nama | Deskripsi |
| :- | :- |
| graph_info | Mendapatkan atau mengatur objek [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) yang menunjukkan informasi grafik, seperti warna,<br/>            lebar garis, dll. |
| text | Mendapatkan atau mengatur teks untuk bentuk |
| position_array | Mendapatkan atau mengatur objek [position_array](/pdf/python-net/aspose.pdf.drawing/line/) yang menunjukkan array posisi. Array tersebut <br/>            terdiri dari koordinat setiap titik kontrol dari garis. <br/>            secara langsung. |
