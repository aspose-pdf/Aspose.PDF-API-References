## Arc class

Mewakili busur.

Tipe Arc menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Menginisialisasi instance baru dari kelas Arc |
## Properti
| Nama | Deskripsi |
| :- | :- |
| graph_info | Mendapatkan atau mengatur objek [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) yang menunjukkan informasi grafik, seperti warna,<br/>            lebar garis, dll. |
| text | Mendapatkan atau mengatur teks untuk bentuk |
| pos_x | Mendapatkan atau mengatur nilai float yang menunjukkan koordinat x pusat busur. |
| pos_y | Mendapatkan atau mengatur nilai float yang menunjukkan koordinat y pusat busur. |
| radius | Mendapatkan atau mengatur nilai float yang menunjukkan jari-jari busur. |
| alpha | Mendapatkan atau mengatur nilai float yang menunjukkan derajat sudut awal busur. |
| beta | Mendapatkan atau mengatur nilai float yang menunjukkan derajat sudut akhir busur. |
