## Rectangle class

Mewakili persegi panjang.

Tipe Rectangle menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Rectangle(left, bottom, width, height) | Menginisialisasi instance baru dari kelas Rectangle |
## Properti
| Nama | Deskripsi |
| :- | :- |
| graph_info | Mendapatkan atau mengatur objek [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) yang menunjukkan informasi grafik, seperti warna,<br/>            lebar garis, dll. |
| text | Mendapatkan atau mengatur teks untuk bentuk |
| rounded_corner_radius | Mendapatkan atau mengatur nilai float yang menunjukkan radius sudut persegi panjang. |
| left | Mendapatkan atau mengatur nilai float yang menunjukkan posisi kiri persegi panjang. |
| bottom | Mendapatkan atau mengatur nilai float yang menunjukkan posisi bawah persegi panjang. |
| lebar | Mendapatkan atau mengatur nilai float yang menunjukkan lebar persegi panjang. |
| tinggi | Mendapatkan atau mengatur nilai float yang menunjukkan tinggi persegi panjang. |
