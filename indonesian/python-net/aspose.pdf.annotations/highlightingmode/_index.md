## HighlightingMode enumeration

Menumerasikan mode penyorotan anotasi, efek visual yang digunakan saat tombol mouse ditekan atau ditahan di dalam area aktifnya.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| NONE | Tidak ada penyorotan. |
| INVERT | Membalik isi persegi panjang anotasi. |
| OUTLINE | Membalik batas anotasi. |
| PUSH | Tampilkan tampilan turun anotasi, jika ada. Jika tidak ada tampilan turun yang didefinisikan, geser isi persegi panjang anotasi sehingga terlihat seolah-olah ditolak ke bawah permukaan halaman. |
| TOGGLE | Sama dengan Push (yang lebih disukai). |
