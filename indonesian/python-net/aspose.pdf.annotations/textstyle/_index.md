## TextStyle class

Kelas yang mewakili gaya teks dalam anotasi

Tipe TextStyle menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| font_name | Nama font. |
| font_size | Ukuran Fonst. |
| perataan | Mendapatkan atau mengatur perataan horizontal teks. |
| horizontal_alignment | Perataan teks. Nilai yang valid adalah: Left, Center, Rigth. |
| warna | Warna teks. |
