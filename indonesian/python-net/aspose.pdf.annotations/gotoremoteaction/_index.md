## GoToRemoteAction class

Mewakili aksi pergi-ke remote yang mirip dengan aksi pergi-ke biasa tetapi melompat ke tujuan dalam file PDF lain alih-alih file saat ini.

Tipe GoToRemoteAction mengungkapkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| GoToRemoteAction(remote_pdf, remote_page_number) | Menginisialisasi sebuah instance baru dari kelas GoToRemoteAction |
| GoToRemoteAction(remote_pdf, destination) | Menginisialisasi sebuah instance baru dari kelas GoToRemoteAction |
## Properti
| Nama | Deskripsi |
| :- | :- |
| berikutnya | Aksi berikutnya dalam urutan. |
| tujuan | Mendapatkan atau mengatur tujuan untuk melompat ke. |
| file | Mendapatkan atau mengatur spesifikasi file tempat tujuan berada. |
| new_window | Mendapatkan atau mengatur flag yang menentukan apakah membuka dokumen tujuan di jendela baru. |
