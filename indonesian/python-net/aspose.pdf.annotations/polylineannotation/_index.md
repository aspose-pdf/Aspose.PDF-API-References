## PolylineAnnotation class

Mewakili anotasi polyline yang mirip dengan poligon, kecuali bahwa simpul pertama dan terakhir tidak terhubung secara implisit.

Tipe PolylineAnnotation menampilkan anggota-anggota berikut:
