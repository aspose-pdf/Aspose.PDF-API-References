## AnnotationSelector class

Kelas ini digunakan untuk memilih anotasi menggunakan ide template Visitor.

Tipe AnnotationSelector menampilkan anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| AnnotationSelector() | Menginisialisasi instance baru dari kelas AnnotationSelector. |
| AnnotationSelector(annotation) | Menginisialisasi sebuah instance baru dari kelas AnnotationSelector |
## Properti
| Nama | Deskripsi |
| :- | :- |
| selected | Daftar objek yang dipilih. |
