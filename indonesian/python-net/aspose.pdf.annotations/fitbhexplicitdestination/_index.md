## FitBHExplicitDestination class

Mewakili tujuan eksplisit yang menampilkan halaman dengan koordinat vertikal atas ditempatkan pada tepi atas jendela dan isi halaman diperbesar cukup untuk menyesuaikan lebar penuh kotak pembatasnya dalam jendela. Nilai null untuk top menunjukkan bahwa nilai parameter tersebut saat ini harus dipertahankan tidak berubah.
