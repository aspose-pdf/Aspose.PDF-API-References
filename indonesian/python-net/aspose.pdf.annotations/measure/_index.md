## Measure class

Kelas yang menjelaskan sistem koordinat Measure.

Tipe Measure menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Measure(annotation) | Menginisialisasi instance baru dari kelas Measure |
## Properti
| Nama | Deskripsi |
| :- | :- |
| scale_ratio | String teks yang menyatakan rasio skala gambar. |
| x_format | Array format angka untuk pengukuran perubahan sepanjang sumbu x dan, jika Y tidak ada, sepanjang sumbu y juga |
| y_format | Array format angka untuk pengukuran perubahan sepanjang sumbu y. |
| distance_format | Array format angka untuk pengukuran jarak dalam arah apa pun. |
| area_format | Array format angka untuk pengukuran area. |
| angle_format | Array format angka untuk pengukuran sudut. |
| slope_format | Array format angka untuk pengukuran kemiringan sebuah garis. |
| origin | Titik yang akan menentukan asal sistem koordinat pengukuran dalam koordinat ruang pengguna default. |
| xy_factor | Faktor yang akan digunakan untuk mengonversi satuan terbesar pada sumbu y ke satuan terbesar pada sumbu x. |
