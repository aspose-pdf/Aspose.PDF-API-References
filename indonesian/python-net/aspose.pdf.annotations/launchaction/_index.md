## LaunchAction class

Mewakili aksi peluncuran yang meluncurkan aplikasi atau membuka atau mencetak dokumen.

Tipe LaunchAction menyediakan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| LaunchAction(file) | Menginisialisasi instance baru dari kelas LaunchAction |
| LaunchAction(document, file) | Menginisialisasi instance baru dari kelas LaunchAction |
## Properti
| Nama | Deskripsi |
| :- | :- |
| berikutnya | Aksi berikutnya dalam urutan. |
| file | Mendapatkan atau mengatur aplikasi yang akan diluncurkan atau dokumen yang akan dibuka atau dicetak. |
| new_window | Mendapatkan atau mengatur flag yang menentukan apakah dokumen tujuan dibuka di jendela baru (hanya memengaruhi dokumen PDF). |
