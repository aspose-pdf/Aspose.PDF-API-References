## HideAction class

Mewakili aksi sembunyikan yang menyembunyikan atau menampilkan satu atau lebih anotasi di layar dengan mengatur atau menghapus flag Hidden mereka.

Tipe HideAction memperlihatkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| HideAction(annotation) | Menginisialisasi sebuah instance baru dari kelas HideAction |
| HideAction(annotation, is_hidden) | Menginisialisasi sebuah instance baru dari kelas HideAction |
| HideAction(field_name) | Menginisialisasi sebuah instance baru dari kelas HideAction |
| HideAction(field_name, is_hidden) | Menginisialisasi sebuah instance baru dari kelas HideAction |
| HideAction(annotations) | Menginisialisasi sebuah instance baru dari kelas HideAction |
| HideAction(annotations, is_hidden) | Menginisialisasi sebuah instance baru dari kelas HideAction |
| HideAction(names) | Menginisialisasi sebuah instance baru dari kelas HideAction |
| HideAction(names, is_hidden) | Menginisialisasi sebuah instance baru dari kelas HideAction |
## Properti
| Nama | Deskripsi |
| :- | :- |
| berikutnya | Aksi berikutnya dalam urutan. |
| is_hidden | Mendapatkan atau mengatur status anotasi untuk disembunyikan/ditampilkan. |
