## AnnotationCollection class

Kelas yang mewakili koleksi anotasi.

Tipe AnnotationCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_synchronized | Mendapatkan nilai yang menunjukkan apakah akses ke Aspose.Pdf.Annotations.AnnotationCollection disinkronkan (aman terhadap thread). |
| sync_root | Mendapatkan objek yang dapat digunakan untuk menyinkronkan akses ke Aspose.Pdf.Annotations.AnnotationCollection. |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Indeks elemen yang akan diambil. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| delete(index) | Menghapus anotasi dari koleksi berdasarkan indeks. |
| delete() | Menghapus anotasi dari koleksi berdasarkan indeks. |
| delete(annotation) | Menghapus anotasi dari koleksi berdasarkan indeks. |
| add(annotation, consider_rotation) | Menambahkan anotasi ke koleksi. Jika halaman diputar maka persegi panjang anotasi akan dihitung ulang sesuai. |
| accept(visitor) | Menerima pengunjung untuk memproses anotasi. |
| find_by_name(name) | Mengembalikan anotasi berdasarkan namanya. |
