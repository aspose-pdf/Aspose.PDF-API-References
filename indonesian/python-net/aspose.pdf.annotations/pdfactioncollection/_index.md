## PdfActionCollection class

Tipe PdfActionCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| count | Mendapatkan jumlah aksi. |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan aksi berdasarkan indeksnya. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| delete(index) | Hapus aksi berdasarkan indeks. |
| add(action) | Tambahkan aksi ke daftar aksi. |
