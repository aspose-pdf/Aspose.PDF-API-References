## AppearanceDictionary class

Kamus tampilan anotasi yang menentukan bagaimana anotasi akan ditampilkan secara visual pada halaman.

Tipe AppearanceDictionary menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_fixed_size | Mendapatkan nilai yang menunjukkan apakah kamus memiliki ukuran tetap. |
| keys | Gets keys of the dictionary. If appearance dictionary has subditionaries, then [keys](/pdf/python-net/aspose.pdf.annotations/appearancedictionary/) contains (N | R | Nilai .state D),<br/>            dimana N - tampilan normal, R - tampilan rollover, D - tampilan down dan state - nama keadaan<br/>            (misalnya On, Off untuk kotak centang). |
| nilai | Mendapatkan daftar nilai kamus. <br/>            Koleksi hasil berisi daftar objek XForm. |
| is_synchronized | Mendapatkan nilai yang menunjukkan apakah akses ke kamus disinkronkan (aman untuk thread). |
| sync_root | Mendapatkan objek yang dapat digunakan untuk menyinkronkan akses ke kamus. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| add(key, value) | Menambahkan elemen dengan kunci dan nilai yang diberikan. |
| add(key, value) | Tambahkan X form untuk kunci yang ditentukan. |
| copy_to(array, index) | Menyalin elemen kamus ke Array, mulai dari indeks Array tertentu. |
| contains_key(key) | Menentukan apakah kamus ini berisi kunci yang ditentukan. |
| remove(key) | Menghapus kunci dari kamus. |
| try_get_value(key, value) | Mencoba menemukan kunci dalam kamus dan mengambil nilai jika ditemukan. |
