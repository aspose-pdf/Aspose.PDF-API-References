## SubmitFormAction class

Kelas yang menjelaskan aksi submit-form.

Tipe SubmitFormAction menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| SubmitFormAction() | Menginisialisasi objek SubmitFormAction. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| berikutnya | Aksi berikutnya dalam urutan. |
| bendera | Mendapatkan atau mengatur flagas aksi submit |
| url | URL tujuan. |
| EXCLUDE | Jika kosong, array Fields menentukan bidang mana yang akan disertakan dalam pengiriman. |
| INCLUDE_NO_VALUE_FIELDS | Jika diatur, semua bidang yang ditentukan oleh array Fields dan flag Include/Exclude akan dikirimkan. |
| EXPORT_FORMAT | Jika diatur, nama bidang dan nilai akan dikirimkan dalam format Formulir HTML. |
| GET_METHOD | Jika diatur, nama bidang dan nilai akan dikirimkan menggunakan permintaan HTTP GET. |
| SUBMIT_COORDINATES | Jika diatur, koordinat klik mouse yang menyebabkan aksi submit-form akan dikirimkan sebagai bagian dari data formulir. |
| XFDF | Jika diatur, nama bidang dan nilai akan dikirimkan sebagai XFDF. |
| INCLUDE_APPEND_SAVES | Jika diatur, file FDF yang dikirimkan akan mencakup isi semua pembaruan inkremental. |
| INCLUDE_ANNOTATIONS | Jika diatur, file FDF yang dikirimkan akan mencakup semua anotasi markup dalam dokumen PDF yang mendasarinya. |
| SUBMIT_PDF | Jika diatur, dokumen akan dikirimkan sebagai PDF, menggunakan tipe konten MIME application/pdf. |
| CANONICAL_FORMAT | Jika diatur, setiap nilai bidang yang dikirimkan yang mewakili tanggal akan dikonversi ke format standar. |
| EXCL_NON_USER_ANNOTS | Jika diatur, hanya anotasi markup yang entri T-nya cocok dengan nama pengguna saat ini yang akan disertakan. |
| EXCL_F_KEY | Jika diatur, FDF yang dikirimkan akan mengecualikan entri F. |
| EMBED_FORM | Jika diatur, entri F dari FDF yang dikirimkan akan menjadi spesifikasi file yang berisi <br/>            aliran file tersemat yang mewakili file PDF tempat FDF dikirimkan. |
