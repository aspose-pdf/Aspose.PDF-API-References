## DefaultAppearance class

Menjelaskan tampilan default bidang (font, ukuran teks, dan warna).

Tipe DefaultAppearance menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| DefaultAppearance() | Konstruktor DefaultAppearance. |
| DefaultAppearance(font_name, font_size, text_color) | Menginisialisasi instance baru dari kelas DefaultAppearance |
| DefaultAppearance(font, font_size, text_color) | Menginisialisasi instance baru dari kelas DefaultAppearance |
## Properti
| Nama | Deskripsi |
| :- | :- |
| font_size | Mendapatkan ukuran font dalam tampilan default. |
| text_color | Mendapatkan atau mengatur warna teks dalam tampilan default. |
| font_name | Mendapatkan nama font dalam tampilan default. |
| font_resource_name | Mendapatkan nama font dalam tampilan default. |
| font | Mendapatkan font yang ditentukan sebagai default untuk teks. |
| text | Mendapatkan daftar operator pdf yang mewakili tampilan. |
