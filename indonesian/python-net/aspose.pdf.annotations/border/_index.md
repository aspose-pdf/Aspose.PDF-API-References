## Border class

Kelas yang mewakili karakteristik batas anotasi.

Tipe Border menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Border(parent) | Menginisialisasi sebuah instance baru dari kelas Border |
## Properti
| Nama | Deskripsi |
| :- | :- |
| h_corner_radius | Mendapatkan atau mengatur radius sudut horizontal. |
| v_corner_radius | Mendapatkan atau mengatur radius sudut vertikal. |
| lebar | Mendapatkan atau mengatur lebar border. |
| effect_intensity | Mendapatkan atau mengatur intensitas efek. Rentang nilai yang valid adalah [0..2]. |
| style | Mendapatkan atau mengatur gaya border. |
| effect | Mendapatkan atau mengatur efek border. |
| dash | Mendapatkan atau mengatur pola dash. |
