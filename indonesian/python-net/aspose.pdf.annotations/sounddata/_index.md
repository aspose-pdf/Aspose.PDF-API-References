## SoundData class

Mewakili data suara yang mendefinisikan suara yang akan diputar ketika anotasi diaktifkan.

Tipe SoundData menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| rate | Mendapatkan atau mengatur laju sampling, dalam sampel per detik. |
| saluran | Mendapatkan atau mengatur jumlah saluran suara. |
| bit | Mendapatkan atau mengatur jumlah bit per nilai sampel per saluran. |
| konten | Mendapatkan aliran suara yang akan diputar ketika anotasi diaktifkan. |
| encoding | Mendapatkan atau mengatur format enkoding untuk data sampel. |
