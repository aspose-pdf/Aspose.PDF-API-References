## LineInfo class

Mewakili informasi baris.

Tipe LineInfo menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| LineInfo() | Menginisialisasi instance baru dari kelas LineInfo |
## Properti
| Nama | Deskripsi |
| :- | :- |
| vertice_coordinate | Mendapatkan atau mengatur array angka yang mewakili koordinat horizontal dan vertikal secara bergantian, masing-masing, dari setiap vertex. |
| line_color | Mendapatkan atau mengatur warna garis. |
| line_width | Mendapatkan atau mengatur lebar garis. |
| visibility | Mendapatkan atau mengatur visibilitas garis. |
| line_dash_pattern | Mendapatkan atau mengatur pola dash garis. |
| border_style | Mendapatkan atau mengatur gaya batas garis, 0 mewakili solid, 1 mewakili dashed, 2 mewakili beleved, 3 mewakili insert, 4 mewakili underline. |
