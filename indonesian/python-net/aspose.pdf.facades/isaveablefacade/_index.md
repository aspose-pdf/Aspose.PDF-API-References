## ISaveableFacade class

Antarmuka fasad yang mendefinisikan metode umum untuk semua fasad yang dapat disimpan.

Tipe ISaveableFacade mengekspos anggota-anggota berikut:
## Metode
| Nama | Deskripsi |
| :- | :- |
| save(dest_file) | Menyimpan dokumen PDF hasil ke file. |
| save(dest_stream) | Menyimpan dokumen PDF hasil ke aliran. |
| bind_pdf(src_file) | Mengikat dokumen PDF untuk diedit. |
| bind_pdf(src_stream) | Mengikat dokumen PDF untuk diedit. |
| bind_pdf(src_doc) | Mengikat dokumen PDF untuk diedit. |
| close() | Melepaskan semua sumber daya yang terkait dengan fasad saat ini. |
