## DocumentPrivilege class

Mewakili hak istimewa untuk mengakses file Pdf. Lihat [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             Ada 4 cara menggunakan kelas ini:<br/>             1. Menggunakan hak istimewa yang telah ditentukan secara langsung.<br/>             2. Berdasarkan hak istimewa yang telah ditentukan dan mengubah beberapa izin tertentu.<br/>             3. Berdasarkan hak istimewa yang telah ditentukan dan mengubah kombinasi izin Adobe Professional tertentu.<br/>             4. Menggabungkan cara 2 dan cara 3.

Tipe DocumentPrivilege menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| allow_print | Mengatur izin yang memperbolehkan pencetakan atau tidak. <br/>            true berarti diperbolehkan dan false berarti dilarang. |
| allow_degraded_printing | Mengatur izin yang memperbolehkan pencetakan terdegradasi atau tidak. <br/>            true berarti diperbolehkan dan false berarti dilarang. |
| allow_modify_contents | Mengatur izin yang memperbolehkan memodifikasi konten atau tidak. <br/>            true berarti diperbolehkan dan false berarti dilarang. |
| allow_copy | Mengatur izin yang memperbolehkan penyalinan atau tidak. <br/>            true berarti diperbolehkan dan false berarti dilarang. |
| allow_modify_annotations | Mengatur izin yang memperbolehkan memodifikasi anotasi atau tidak. <br/>            true berarti diperbolehkan dan false berarti dilarang. |
| allow_fill_in | Mengatur izin yang memperbolehkan mengisi formulir atau tidak. <br/>            true berarti diperbolehkan dan false berarti dilarang. |
| allow_screen_readers | Mengatur izin yang memperbolehkan pembaca layar atau tidak. <br/>            true berarti diperbolehkan dan false berarti dilarang. |
| allow_assembly | Mengatur izin yang memperbolehkan perakitan atau tidak. <br/>            true berarti diperbolehkan dan false berarti dilarang. |
| degraded_printing | Mengizinkan pencetakan terdegradasi. |
| print | Mengizinkan pencetakan berkas. |
| modify_contents | Mengizinkan modifikasi berkas. |
| copy | Mengizinkan penyalinan file. |
| modify_annotations | Mengizinkan memodifikasi anotasi file. |
| fill_in | Mengizinkan mengisi formulir dalam file. |
| screen_readers | Mengizinkan membaca hanya di layar. |
| assembly | Mengizinkan perakitan file. |
| allow_all | Semua diizinkan. |
| forbid_all | Semua dilarang. |
