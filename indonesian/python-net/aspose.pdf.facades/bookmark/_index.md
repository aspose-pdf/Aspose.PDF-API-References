## Bookmark class

Mewakili sebuah penanda buku.

Tipe Bookmark menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Bookmark() | Menginisialisasi instance baru dari kelas Bookmark |
## Properti
| Nama | Deskripsi |
| :- | :- |
| action | Mendapatkan atau mengatur aksi yang terikat dengan bookmark.<br/>            Jika PageNumber disajikan aksi tidak dapat ditentukan.<br/>            Jenis aksi mencakup: \"GoTo\", \"GoToR\", \"Launch\", \"Named\". |
| bold_flag | Mendapatkan atau mengatur flag tebal judul bookmark. |
| child_item | Mendapatkan atau mengatur anak-anak bookmark. |
| child_items | Mendapatkan atau mengatur anak-anak bookmark. |
| tujuan | Mendapatkan atau mengatur halaman tujuan bookmark. Diperlukan jika aksi diatur sebagai string.Empty. |
| italic_flag | Mendapatkan atau mengatur flag italic judul bookmark. |
| level | Mendapatkan atau mengatur level hierarki bookmark. |
| page_display | Mendapatkan atau mengatur tipe tampilan halaman tujuan bookmark. |
| page_display_bottom | Mendapatkan atau mengatur koordinat bawah tampilan halaman. |
| page_display_left | Mendapatkan atau mengatur koordinat kiri tampilan halaman. |
| page_display_right | Mendapatkan atau mengatur koordinat kanan tampilan halaman. |
| page_display_top | Mendapatkan atau mengatur koordinat atas tampilan halaman. |
| page_display_zoom | Mendapatkan atau mengatur faktor zoom tampilan halaman. |
| page_number | Mendapatkan atau mengatur nomor halaman tujuan bookmark. |
| remote_file | Mendapatkan atau mengatur file (path) yang diperlukan untuk aksi "GoToR" bookmark. |
| title | Mendapatkan atau mengatur judul bookmark. |
| title_color | Mendapatkan atau mengatur warna judul bookmark. |
| buka | Mendapatkan atau mengatur status bookmark (buka, tutup). |
