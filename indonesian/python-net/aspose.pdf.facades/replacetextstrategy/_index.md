## ReplaceTextStrategy class

Kelas ini berisi parameter yang menentukan perilaku PdfContentEditor saat operasi ReplaceText dilakukan.

Tipe ReplaceTextStrategy menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ReplaceTextStrategy() | Menginisialisasi instance baru dari kelas ReplaceTextStrategy |
## Properti
| Nama | Deskripsi |
| :- | :- |
| is_regular_expression_used | Jika false, string yang dicari adalah teks sederhana. Jika true, string yang dicari adalah ekspresi reguler. |
| no_character_behavior | Aksi yang dilakukan ketika tidak ada font yang sesuai ditemukan untuk teks yang diubah<br/>            (Melempar pengecualian / Mengganti dengan font lain / Mengganti tetap). |
| replace_scope | Ruang lingkup operasi penggantian (ganti kemunculan pertama atau ganti semua kemunculan). |
