## ViewerPreference class

Menggambarkan preferensi penampil (mode halaman, mode halaman non layar penuh, tata letak halaman).

Tipe ViewerPreference menyediakan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| ViewerPreference() | Menginisialisasi instance baru dari kelas ViewerPreference |
## Properti
| Nama | Deskripsi |
| :- | :- |
| PAGE_MODE_USE_OC | Panel grup konten opsional terlihat. |
| DISPLAY_DOC_TITLE | Flag yang menentukan apakah bilah judul jendela harus menampilkan judul dokumen. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | Panel grup konten opsional terlihat. |
| PAGE_LAYOUT_SINGLE_PAGE | Tampilkan satu halaman sekaligus. |
| PAGE_LAYOUT_ONE_COLUMN | Tampilkan halaman dalam satu kolom. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | Tampilkan halaman dalam dua kolom, dengan halaman bernomor ganjil di sebelah kanan |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | Tampilkan halaman dalam dua kolom, dengan halaman bernomor ganjil di sebelah kanan. |
| PAGE_MODE_USE_NONE | Baik outline dokumen maupun gambar thumbnail tidak terlihat |
| PAGE_MODE_USE_OUTLINES | Outline dokumen terlihat. |
| PAGE_MODE_USE_THUMBS | Gambar thumbnail terlihat. |
| PAGE_MODE_FULL_SCREEN | Mode layar penuh, tanpa bilah menu, kontrol jendela, atau jendela lain yang terlihat. |
| PAGE_MODE_USE_ATTACHMENT | Mode halaman dengan lampiran. |
| HIDE_TOOLBAR | Bendera yang menentukan apakah menyembunyikan bilah alat pembaca yang sesuai saat dokumen aktif. |
| HIDE_MENUBAR | Bendera yang menentukan apakah menyembunyikan bilah menu pembaca yang sesuai saat dokumen aktif. |
| HIDE_WINDOW_UI | Bendera yang menentukan apakah menyembunyikan elemen antarmuka pengguna di jendela dokumen (seperti bilah gulir dan kontrol navigasi), sehingga hanya isi dokumen yang ditampilkan. |
| FIT_WINDOW | Bendera yang menentukan apakah mengubah ukuran jendela dokumen agar sesuai dengan ukuran halaman pertama yang ditampilkan. |
| CENTER_WINDOW | Bendera yang menentukan apakah menempatkan jendela dokumen di tengah layar. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | Tidak ada outline dokumen maupun gambar thumbnail yang terlihat. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | Outline dokumen terlihat. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | Gambar thumbnail terlihat |
| DIRECTION_L2R | Urutan membaca teks dari kiri ke kanan. |
| DIRECTION_R2L | Urutan membaca teks dari kanan ke kiri. |
| SIMPLEX | Cetak satu sisi. |
| DUPLEX_FLIP_SHORT_EDGE | Duplex dan balik pada tepi pendek lembar. |
| DUPLEX_FLIP_LONG_EDGE | Duplex dan balik pada tepi pendek lembar. |
