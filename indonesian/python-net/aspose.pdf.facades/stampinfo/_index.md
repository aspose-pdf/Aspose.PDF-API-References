## StampInfo class

Kelas yang mewakili informasi stempel.

Tipe StampInfo menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| stamp_id | Mendapatkan pengidentifikasi stempel. |
| index_on_page | Mendapatkan indeks stempel pada halaman. |
| stamp_type | Mendapatkan tipe stempel (gambar / formulir). |
| rectangle | Mendapatkan persegi panjang tempat stempel ditempatkan. |
| image | Mendapatkan gambar stempel. Bisa bernilai null jika stempel tidak berisi gambar (misalnya untuk stempel teks). |
| formulir | Mendapatkan XForm dari stempel. |
| text | Mendapatkan teks dalam stempel. |
| terlihat | Mendapatkan visibilitas stempel. Jika false maka stempel disembunyikan (dengan HideStampById). Stempel yang disembunyikan dapat dipulihkan dengan ShowStampById. |
