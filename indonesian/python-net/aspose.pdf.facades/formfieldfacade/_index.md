## FormFieldFacade class

Kelas untuk merepresentasikan properti bidang.

Tipe FormFieldFacade menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| FormFieldFacade() | Menginisialisasi sebuah instance baru dari kelas FormFieldFacade |
## Properti
| Nama | Deskripsi |
| :- | :- |
| border_color | Warna batas bidang. |
| border_style | Gaya batas bidang. |
| border_width | Lebar batas bidang. |
| font | Jenis font teks bidang. |
| custom_font | Mendapatkan atau mengatur nama font ketika ini tidak standar (selain 14 font standar). |
| font_size | Ukuran teks bidang. |
| text_color | Warna teks bidang. |
| text_encoding | Tipe pengkodean teks dari teks bidang. |
| perataan | Perataan teks bidang, default adalah perataan kiri. |
| rotation | Rotasi teks bidang. |
| caption | Keterangan normal dari bidang formulir. |
| button_style | Gaya kotak centang atau kotak radio, didefinisikan oleh FormFieldFacade.CheckBoxStyle*. |
| kotak | Objek persegi panjang yang menyimpan lokasi bidang. |
| position | Objek persegi panjang yang menyimpan lokasi bidang. |
| page_number | Nilai integer yang menyimpan nomor halaman tempat bidang berada. |
| items | Array string, masing-masing mewakili opsi dari bidang kotak kombo/daftar/kotak radio. |
| export_items | Opsi untuk menambahkan daftar/kombinasi/kotak radio |
| background_color | Warna latar belakang bidang, default adalah putih. |
| backgroud_color | Properti usang. Gunakan BackgroundColor. |
| BORDER_WIDTH_UNDIFIED | Lebar batas tidak terdefinisi. |
| BORDER_WIDTH_UNDEFINED | Lebar batas tidak terdefinisi. |
| BORDER_WIDTH_THIN | Mendefinisikan lebar batas tipis. |
| BORDER_WIDTH_MEDIUM | Mendefinisikan lebar batas sedang. |
| BORDER_WIDTH_THICK | Mendefinisikan lebar batas tebal. |
| BORDER_STYLE_SOLID | Mendefinisikan gaya batas padat. |
| BORDER_STYLE_DASHED | Mendefinisikan gaya batas bergaris. |
| BORDER_STYLE_BEVELED | Mendefinisikan gaya batas bevel. |
| BORDER_STYLE_INSET | Mendefinisikan gaya batas terbenam. |
| BORDER_STYLE_UNDERLINE | Mendefinisikan gaya batas bergaris bawah. |
| BORDER_STYLE_UNDEFINED | Gaya batas tidak terdefinisi. |
| ALIGN_LEFT | Mendefinisikan perataan ke gaya kiri. |
| ALIGN_CENTER | Mendefinisikan penyelarasan ke gaya tengah. |
| ALIGN_RIGHT | Mendefinisikan penyelarasan ke gaya kanan. |
| ALIGN_UNDEFINED | Gaya penyelarasan tidak terdefinisi. |
| ALIGN_JUSTIFIED | Mendefinisikan gaya penyelarasan justifikasi teks. |
| ALIGN_TOP | Mendefinisikan penyelarasan vertikal sebagai gaya atas. |
| ALIGN_MIDDLE | Mendefinisikan penyelarasan vertikal sebagai gaya tengah. |
| ALIGN_BOTTOM | Mendefinisikan penyelarasan vertikal sebagai gaya bawah. |
| CHECK_BOX_STYLE_CIRCLE | Mendefinisikan gaya kotak centang lingkaran. |
| CHECK_BOX_STYLE_CHECK | Mendefinisikan bentuk bidang kotak centang ketika tercentang. |
| CHECK_BOX_STYLE_CROSS | Mendefinisikan gaya kotak centang silang. |
| CHECK_BOX_STYLE_DIAMOND | Mendefinisikan gaya kotak centang berlian. |
| CHECK_BOX_STYLE_STAR | Mendefinisikan gaya kotak centang bintang. |
| CHECK_BOX_STYLE_SQUARE | Mendefinisikan gaya kotak centang persegi. |
| CHECK_BOX_STYLE_UNDEFINED | Mendefinisikan gaya kotak centang yang tidak terdefinisi. |
## Metode
