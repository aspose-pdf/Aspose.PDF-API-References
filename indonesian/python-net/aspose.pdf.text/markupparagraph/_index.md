## MarkupParagraph class

Mewakili sebuah paragraf.

Tipe MarkupParagraph menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| titik | Titik-titik poligon yang menggambarkan paragraf.<br/>            Titik awal berada di sudut kiri bawah paragraf. Dan titik-titik berikutnya berada dalam urutan berlawanan arah jarum jam. |
| titik_sekunder | Titik-titik poligon sekunder yang menggambarkan kelanjutan paragraf. Tidak akan bernilai null jika paragraf dilanjutkan di kolom atau halaman berikutnya.<br/>            Titik awal berada di sudut kiri bawah paragraf. Dan titik-titik berikutnya berada dalam urutan berlawanan arah jarum jam. |
| nomor_halaman_lanjutan | Daftar nomor halaman tempat paragraf dilanjutkan. Akan cocok dengan halaman tempat paragraf dimulai jika dilanjutkan di kolom berikutnya pada halaman yang sama. |
| fragments | Koleksi objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) yang tidak kosong dari paragraf. |
| baris | Baris-baris paragraf. Setiap baris direpresentasikan oleh daftar fragmen teks. |
| text | Mendapatkan objek teks string yang direpresentasikan oleh objek [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/). |
