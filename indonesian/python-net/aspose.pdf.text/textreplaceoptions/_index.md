## TextReplaceOptions class

Mewakili opsi penggantian teks

Tipe TextReplaceOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextReplaceOptions(scope) | Menginisialisasi instance baru dari kelas TextReplaceOptions |
| TextReplaceOptions(adjustment) | Menginisialisasi instance baru dari kelas TextReplaceOptions |
## Properti
| Nama | Deskripsi |
| :- | :- |
| replace_scope | Mendapatkan atau mengatur ruang lingkup tempat operasi penggantian teks diterapkan |
| replace_adjustment_action | Mendapatkan atau mengatur aksi yang akan dilakukan setelah penggantian fragmen teks menjadi lebih pendek. |
| adjustment_new_line_spacing | Mendapatkan atau mengatur nilai spasi baris yang digunakan jika penyesuaian penggantian dipaksa untuk membuat baris teks baru.<br/>            Nilai yang diharapkan adalah pengganda ukuran font dari teks yang diganti. Default adalah 1.2. |
