## IFontOptions class

Properti berguna untuk menyesuaikan perilaku Font

Tipe IFontOptions menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| notify_about_font_embedding_error | Terkadang tidak memungkinkan untuk menyematkan font yang diinginkan ke dalam dokumen. Ada banyak alasan, misalnya<br/>            pembatasan lisensi atau ketika font yang diinginkan tidak ditemukan di komputer tujuan.<br/>            Ketika situasi ini terjadi tidak mudah dideteksi, karena font yang diinginkan disematkan melalui pengaturan <br/>            flag properti Font.IsEmbedded = true; Tentu saja properti ini dapat dibaca segera setelah diatur tetapi<br/>            pendekatannya tidak nyaman. Flag NotifyAboutFontEmbeddingError memberlakukan mekanisme pengecualian <br/>            untuk kasus ketika upaya menyematkan font gagal. Jika flag ini diatur, sebuah pengecualian bertipe<br/>            [FontEmbeddingException](/pdf/python-net/aspose.pdf/fontembeddingexception/) akan dilemparkan. Secara default false. |
