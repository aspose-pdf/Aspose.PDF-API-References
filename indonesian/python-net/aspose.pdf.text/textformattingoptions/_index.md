## TextFormattingOptions class

Mewakili opsi pemformatan teks

Tipe TextFormattingOptions menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextFormattingOptions(wrap_mode) | Menginisialisasi instance baru dari kelas TextFormattingOptions. |
| TextFormattingOptions() | Menginisialisasi instance baru dari objek [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) dengan mode pembungkus kata yang tidak terdefinisi. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| wrap_mode | Mendapatkan atau mengatur mode pembungkus kata.<br/>            Nilai default adalah WordWrapMode.NoWrap. |
| line_spacing | Mendapatkan atau mengatur mode spasi baris.<br/>            Nilai default adalah LineSpacingMode.FontSize. |
| hyphen_symbol | Mendapatkan atau mengatur simbol hyphen yang digunakan dalam proses hyphenation. |
| subsequent_lines_indent | Mendapatkan atau mengatur nilai indentasi baris berikutnya. |
| first_line_indent | Mendapatkan atau mengatur nilai indentasi baris pertama. |
