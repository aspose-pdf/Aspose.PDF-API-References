## TextState class

Mewakili status teks dari sebuah teks

Tipe TextState menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextState() | Membuat objek status teks. |
| TextState(font_size) | Menginisialisasi sebuah instance baru dari kelas TextState |
| TextState(foreground_color) | Menginisialisasi sebuah instance baru dari kelas TextState |
| TextState(foreground_color, font_size) | Menginisialisasi sebuah instance baru dari kelas TextState |
| TextState(font_family) | Menginisialisasi sebuah instance baru dari kelas TextState |
| TextState(font_family, bold, italic) | Menginisialisasi sebuah instance baru dari kelas TextState |
| TextState(font_family, font_size) | Menginisialisasi sebuah instance baru dari kelas TextState |
## Properti
| Nama | Deskripsi |
| :- | :- |
| character_spacing | Mendapatkan atau mengatur spasi karakter teks. |
| line_spacing | Mendapatkan atau mengatur spasi baris teks. |
| horizontal_scaling | Mendapatkan atau mengatur skala horizontal teks. |
| subscript | Mendapatkan atau mengatur subskrip teks. |
| superscript | Mendapatkan atau mengatur superskrip teks. |
| word_spacing | Mendapatkan atau mengatur spasi kata teks. |
| invisible | Mendapatkan atau mengatur keburaman teks. Ini pada dasarnya mencerminkan keadaan [rendering_mode](/pdf/python-net/aspose.pdf.text/textstate/), kecuali untuk beberapa kasus khusus (seperti pemotongan). |
| rendering_mode | Mendapatkan atau mengatur mode rendering teks. |
| font_size | Mendapatkan atau mengatur ukuran font teks. |
| font | Mendapatkan atau mengatur font teks. |
| foreground_color | Mendapatkan atau mengatur warna latar depan teks. |
| stroking_color | Mendapatkan atau mengatur warna latar depan teks. |
| underline | Mendapatkan atau mengatur garis bawah untuk teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| strike_out | Mengatur coret untuk teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| background_color | Mengatur warna latar belakang teks. |
| font_style | Mengatur gaya font teks. |
| horizontal_alignment | Mendapatkan atau mengatur perataan horizontal untuk teks. |
| TAB_TAG | Anda dapat menempatkan tag ini dalam teks untuk mendeklarasikan tabulasi. |
| TABSTOP_DEFAULT_VALUE | Nilai default tabulasi dalam lebar karakter spasi dari font default. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| apply_changes_from(text_state) | Menerapkan pengaturan dari textState lain. |
| measure_string(str) | Mengukur string. |
