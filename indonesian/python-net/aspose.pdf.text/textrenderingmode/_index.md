## TextRenderingMode enumeration

Mode rendering teks, Tmode, menentukan apakah menampilkan teks akan menyebabkan kontur glif digambar, diisi, digunakan sebagai batas pemotongan, atau kombinasi dari ketiganya.

## Members
| Nama anggota | Deskripsi |
| :- | :- |
| FILL_TEXT | Isi teks. |
| STROKE_TEXT | Garis teks. |
| FILL_THEN_STROKE_TEXT | Isi, lalu garis teks. |
| INVISIBLE | Tidak mengisi maupun menggaris teks (tidak terlihat). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Isi teks dan tambahkan ke jalur untuk pemotongan (lihat 9.3.6, "Text Rendering Mode,"). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Garis teks dan tambahkan ke jalur untuk pemotongan. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Isi, lalu garis teks dan tambahkan ke jalur untuk pemotongan. |
| ADD_PATH_TO_CLIPPING | Tambahkan teks ke jalur untuk pemotongan. |
