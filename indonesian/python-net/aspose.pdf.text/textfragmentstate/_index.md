## TextFragmentState class

Mewakili keadaan teks dari sebuah fragmen teks.

Tipe TextFragmentState menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextFragmentState(fragment) | Menginisialisasi instance baru dari kelas TextFragmentState |
## Properti
| Nama | Deskripsi |
| :- | :- |
| character_spacing | Mendapatkan atau mengatur jarak karakter teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| line_spacing | Mendapatkan atau mengatur spasi baris teks. |
| horizontal_scaling | Mendapatkan atau mengatur skala horizontal teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| subscript | Mendapatkan atau mengatur subskrip teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| superscript | Mendapatkan atau mengatur superskrip teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| word_spacing | Mendapatkan atau mengatur spasi kata teks. |
| tidak terlihat | Mendapatkan atau mengatur ketidakterlihatan teks. |
| rendering_mode | Mendapatkan atau mengatur mode render teks. |
| font_size | Mendapatkan atau mengatur ukuran font teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font | Mendapatkan atau mengatur font teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| foreground_color | Mendapatkan atau mengatur warna latar depan teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| stroking_color | Mendapatkan atau mengatur operasi gores warna pada rendering [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) (menyapu teks, batas persegi panjang) |
| underline | Mendapatkan atau mengatur garis bawah untuk teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| strike_out | Mengatur coret untuk teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| background_color | Mengatur warna latar belakang teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font_style | Mengatur gaya font teks, yang direpresentasikan oleh objek [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| horizontal_alignment | Mendapatkan atau mengatur perataan horizontal untuk teks. |
| TAB_TAG | Anda dapat menempatkan tag ini dalam teks untuk mendeklarasikan tabulasi. |
| TABSTOP_DEFAULT_VALUE | Nilai default tabulasi dalam lebar karakter spasi dari font default. |
| tab_stops | Mendapatkan tabstops untuk teks. |
| formatting_options | Mendapatkan atau mengatur opsi pemformatan.<br/>            Penetapan opsi akan efektif hanya dalam skenario generator. |
| rotation | Mendapatkan atau mengatur sudut rotasi dalam derajat. |
| draw_text_rectangle_border | Mendapatkan atau mengatur flag apakah batas persegi panjang teks digambar. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| apply_changes_from(text_state) | Menerapkan pengaturan dari textState lain. |
| measure_string(str) | Mengukur string. |
