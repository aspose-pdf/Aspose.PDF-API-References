## FontCollection class

Mewakili koleksi font.

Tipe FontCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| sync_root | Mendapatkan objek yang dapat digunakan untuk menyinkronkan akses ke koleksi. |
| is_synchronized | Mendapatkan nilai yang menunjukkan apakah akses ke koleksi disinkronkan (aman untuk thread). |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan elemen font pada indeks yang ditentukan. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| add(new_font, res_name) | Menambahkan font baru ke sumber daya font dan mengembalikan nama sumber daya font yang ditetapkan secara otomatis. |
