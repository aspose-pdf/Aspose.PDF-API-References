## FontSourceCollection class

Mewakili koleksi sumber font.

Tipe FontSourceCollection menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| sync_root | Mendapatkan objek yang dapat digunakan untuk menyinkronkan akses ke koleksi. |
| is_synchronized | Mendapatkan nilai yang menunjukkan apakah akses ke koleksi disinkronkan (aman untuk thread). |
## Indexer
| Nama | Deskripsi |
| :- | :- |
| [index] | Mendapatkan elemen font pada indeks yang ditentukan. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| delete(font_source) | Menghapus elemen sumber font. |
