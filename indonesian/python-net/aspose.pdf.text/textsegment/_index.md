## TextSegment class

Mewakili segmen teks Pdf.

Tipe TextSegment menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextSegment() | Membuat objek TextSegment. |
| TextSegment(text) | Menginisialisasi instance baru dari kelas TextSegment |
## Properti
| Nama | Deskripsi |
| :- | :- |
| start_char_index | Mendapatkan indeks karakter awal dari segmen saat ini dalam operator menampilkan teks (Tj, TJ) segmen. |
| end_char_index | Mendapatkan indeks karakter akhir dari segmen saat ini dalam operator menampilkan teks (Tj, TJ) segmen. |
| text | Mendapatkan atau mengatur objek teks string yang direpresentasikan oleh objek [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| text_state | Mendapatkan atau mengatur status teks untuk teks yang direpresentasikan oleh objek [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| position | Mendapatkan posisi teks untuk teks, yang direpresentasikan dengan objek [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| rectangle | Mendapatkan persegi panjang dari TextSegment |
| baseline_position | Mendapatkan posisi teks untuk teks, yang direpresentasikan dengan objek [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/).<br/>            YIndent dari struktur Position merepresentasikan koordinat baseline dari segmen teks. |
| text_edit_options | Mendapatkan atau mengatur opsi penyuntingan teks. Opsi tersebut mendefinisikan perilaku khusus ketika simbol yang diminta tidak dapat ditulis dengan font. |
| karakter | Mendapatkan koleksi objek CharInfo yang merepresentasikan informasi tentang karakter dalam segmen teks. |
| hyperlink | Mendapatkan atau mengatur hyperlink segmen (untuk pembuat pdf). |
