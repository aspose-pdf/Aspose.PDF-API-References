## TabStop class

Mewakili posisi tab stop khusus dalam sebuah paragraf.

Tipe TabStop memperlihatkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TabStop() | Menginisialisasi instance baru dari kelas [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/). |
| TabStop(position) | Menginisialisasi instance baru dari kelas TabStop |
## Properti
| Nama | Deskripsi |
| :- | :- |
| position | Mendapatkan atau mengatur nilai float yang menunjukkan posisi tab stop. |
| leader_type | Mendapatkan atau mengatur enum [TabLeaderType](/pdf/python-net/aspose.pdf.text/tableadertype/) yang menunjukkan tipe pemimpin tab. |
| alignment_type | Mendapatkan atau mengatur enum [alignment_type](/pdf/python-net/aspose.pdf.text/tabstop/) yang menunjukkan tipe perataan tab. |
| is_read_only | Mendapatkan nilai yang menunjukkan bahwa instance [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) ini sudah terhubung ke [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) dan menjadi hanya-baca |
