## TextExtractionErrorLocation class

Mewakili lokasi dalam dokumen PDF dimana kesalahan ekstraksi teks muncul.

Tipe TextExtractionErrorLocation menampilkan anggota-anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| path | Lokasi dokumen PDF tempat kesalahan ekstraksi teks muncul. |
| page_number | Nomor halaman dokumen tempat kesalahan ekstraksi teks berada. |
| object_type | Tipe objek PDF (Page atau xForm) di mana kesalahan ekstraksi teks pada aliran konten berada. |
| form_key | Kunci (nama) PDF Form XObject di mana kesalahan ekstraksi teks pada aliran konten berada. Tidak kosong jika ObjectType == 'xForm'. |
| operator_index | Indeks operator yang menampilkan teks dalam aliran konten (koleksi operator) yang menyebabkan kesalahan ekstraksi teks. |
| operator_string | Operator yang menampilkan teks yang menyebabkan kesalahan ekstraksi teks. |
| font_used_key | Kunci (nama) objek PDF Font yang digunakan untuk menampilkan operator yang menyebabkan kesalahan ekstraksi teks. |
| text_start_point | Kunci (nama) objek PDF Font yang digunakan untuk menampilkan operator yang menyebabkan kesalahan ekstraksi teks. |
