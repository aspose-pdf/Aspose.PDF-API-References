## TextEditOptions class

Menjelaskan opsi operasi penyuntingan teks.

Tipe TextEditOptions memperlihatkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextEditOptions(no_character_behavior) | Menginisialisasi instance baru dari kelas TextEditOptions |
| TextEditOptions(font_replace_behavior) | Menginisialisasi instance baru dari kelas TextEditOptions |
| TextEditOptions(allow_language_transformation) | Menginisialisasi instance baru dari kelas TextEditOptions |
| TextEditOptions(language_transformation_behavior) | Menginisialisasi instance baru dari kelas TextEditOptions |
## Properti
| Nama | Deskripsi |
| :- | :- |
| replacement_font | Mendapatkan atau mengatur font yang digunakan untuk penggantian jika font pengguna tidak mengandung karakter yang diperlukan |
| no_character_behavior | Mendapatkan atau mengatur mode yang menentukan perilaku bila font tidak mengandung karakter yang diminta. |
| font_replace_behavior | Mendapatkan mode yang menentukan perilaku untuk skenario penggantian font. |
| allow_language_transformation | Mendapatkan atau mengatur nilai yang memungkinkan penggunaan transformasi bahasa selama penambahan atau penyuntingan teks.<br/>            true - transformasi bahasa akan diterapkan jika diperlukan (nilai default).<br/>            false - transformasi bahasa TIDAK akan diterapkan. |
| language_transformation_behavior | Mendapatkan mode yang menentukan perilaku untuk skenario transformasi bahasa. |
| clipping_paths_processing | Mendapatkan mode untuk memproses clipping path teks yang disunting. |
| to_attempt_get_underline_from_source | Mendapatkan atau mengatur nilai yang memungkinkan pencarian garis bawah teks pada halaman dokumen sumber.<br/>            (Usang) Harap gunakan TextSearchOptions.SearchForTextRelatedGraphics sebagai gantinya. |
