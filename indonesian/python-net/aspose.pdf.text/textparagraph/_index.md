## TextParagraph class

Mewakili paragraf teks sebagai objek teks multiline.

Tipe TextParagraph menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| TextParagraph() | Menginisialisasi instance baru dari kelas TextParagraph |
## Properti
| Nama | Deskripsi |
| :- | :- |
| vertical_alignment | Mendapatkan atau mengatur perataan vertikal untuk teks di dalam [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) paragraf. |
| subsequent_lines_indent | Mendapatkan atau mengatur nilai indentasi baris berikutnya.<br/>            Jika diatur ke nilai non-zero, ini memiliki keunggulan dibandingkan nilai FormattingOptions.SubsequentLinesIndent. |
| first_line_indent | Mendapatkan atau mengatur nilai indentasi baris berikutnya.<br/>            Jika diatur ke nilai non-zero, ini memiliki keunggulan dibandingkan nilai FormattingOptions.SubsequentLinesIndent. |
| justify | Mendapatkan atau mengatur nilai apakah teks diratakan penuh. |
| horizontal_alignment | Mendapatkan atau mengatur perataan horizontal untuk teks di dalam [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) paragraf. |
| formatting_options | Mendapatkan atau mengatur opsi pemformatan. |
| position | Mendapatkan atau mengatur posisi paragraf. |
| text_rectangle | Mendapatkan persegi panjang teks yang ditempatkan pada paragraf. |
| rectangle | Mendapatkan atau mengatur persegi panjang paragraf. |
| margin | Mendapatkan atau mengatur padding. |
| rotation | Mendapatkan atau mengatur sudut rotasi dalam derajat. |
