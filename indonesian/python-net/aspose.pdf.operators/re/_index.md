## Re class

Kelas yang mewakili operator re (menambahkan persegi panjang ke jalur).

Tipe Re menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Re() | Menginisialisasi operator. |
| Re(x, y, width, height) | Menginisialisasi sebuah instance baru dari kelas Re |
## Properti
| Nama | Deskripsi |
| :- | :- |
| index | Indeks operator dalam daftar operator halaman. |
| x | Koordinat X dari sisi paling kiri persegi panjang. |
| y | Koordinat Y dari sisi bawah persegi panjang. |
| lebar | Lebar persegi panjang. |
| tinggi | Tinggi persegi panjang. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| accept(visitor) | Menerima objek visitor untuk memproses operator. |
| is_text_show_operator(op) | Menentukan apakah operator tersebut adalah operator yang bertanggung jawab untuk output teks (Tj, TJ, dll) |
