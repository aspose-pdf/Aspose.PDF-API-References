## SetColor class

Mewakili kelas untuk operator sc (mengatur warna untuk operasi non-stroking).

Tipe SetColor menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| SetColor() | Menginisialisasi operator. |
| SetColor(g) | Menginisialisasi sebuah instance baru dari kelas SetColor |
| SetColor(r, g, b) | Menginisialisasi sebuah instance baru dari kelas SetColor |
| SetColor(c, m, y, k) | Menginisialisasi sebuah instance baru dari kelas SetColor |
| SetColor(color) | Menginisialisasi sebuah instance baru dari kelas SetColor |
## Properti
| Nama | Deskripsi |
| :- | :- |
| index | None |
| r | Mendapatkan komponen merah dari warna |
| g | Mendapatkan komponen hijau dari warna |
| b | Mendapatkan komponen merah dari warna |
| c | Mendapatkan komponen cyan dari warna CMYK. |
| m | Mendapatkan komponen magenta dari warna CMYK. |
| y | Mendapatkan komponen kuning dari warna CMYK. |
| k | Mendapatkan komponen hitam dari warna CMYK. |
| abu-abu | Mendapatkan komponen hitam dari warna abu-abu. |
| warna | Mendapatkan array komponen warna. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| accept(visitor) | Menerima objek visitor untuk memproses operator. |
| is_text_show_operator(op) | None |
| get_color() | Mengembalikan warna yang ditentukan oleh operator. |
