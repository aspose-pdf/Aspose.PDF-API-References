## Do class

Kelas yang mewakili operator Do (memanggil XObject).

Tipe Do menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| Do(name) | Menginisialisasi instance baru dari kelas Do |
| Do() | Membuat operator Do baru. <br/>            Digunakan untuk mengambil semua operator Do, yaitu tanpa memeriksa nama argumen mereka. |
## Properti
| Nama | Deskripsi |
| :- | :- |
| index | Indeks operator dalam daftar operator halaman. |
| name | Nama argumen XObject dari operator. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| accept(visitor) | Menerima objek visitor untuk memproses operator. |
| is_text_show_operator(op) | Menentukan apakah operator tersebut adalah operator yang bertanggung jawab untuk output teks (Tj, TJ, dll) |
