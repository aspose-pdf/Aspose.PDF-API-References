## GS class

Kelas yang mewakili operator gs (menetapkan parameter dari kamus parameter keadaan grafis).

Tipe GS menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| GS(name) | Menginisialisasi instance baru dari kelas GS |
## Properti
| Nama | Deskripsi |
| :- | :- |
| index | Indeks operator dalam daftar operator halaman. |
| name | Mendapatkan atau mengatur nama sumber daya state grafis. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| accept(visitor) | Menerima objek visitor untuk memproses operator. |
| is_text_show_operator(op) | Menentukan apakah operator tersebut adalah operator yang bertanggung jawab untuk output teks (Tj, TJ, dll) |
