Tipe MP menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| MP(tag) | Menginisialisasi instance baru dari kelas MP |
## Properti
| Nama | Deskripsi |
| :- | :- |

| tag | Mendapatkan atau mengatur tag konten yang ditandai |

| Nama | Deskripsi |
| :- | :- |
