## SetColorStroke class

Kelas yang mewakili operator SC mengatur warna untuk operator warna stroking.

| Nama | Deskripsi |
| :- | :- |
| SetColorStroke() | Menginisialisasi operator. |
| SetColorStroke(g) | Menginisialisasi instance baru dari kelas SetColorStroke |
| SetColorStroke(r, g, b) | Menginisialisasi instance baru dari kelas SetColorStroke |
| SetColorStroke(color) | Menginisialisasi instance baru dari kelas SetColorStroke |
| SetColorStroke(c, m, y, k) | Menginisialisasi instance baru dari kelas SetColorStroke |
## Properti
| Nama | Deskripsi |
| :- | :- |
| index | None |
| r | Mendapatkan komponen merah dari warna |
| g | Mendapatkan komponen hijau dari warna |
| b | Mendapatkan komponen merah dari warna |
| c | Mendapatkan komponen cyan dari warna CMYK. |
| m | Mendapatkan komponen magenta dari warna CMYK. |
| y | Mendapatkan komponen kuning dari warna CMYK. |
| k | Mendapatkan komponen hitam dari warna CMYK. |
| abu-abu | Mendapatkan komponen hitam dari warna abu-abu. |
