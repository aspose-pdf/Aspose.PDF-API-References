## SetAdvancedColorStroke class

Kelas yang mewakili operator SCN (mengatur warna untuk operasi stroking).

| :- | :- |

| SetAdvancedColorStroke(c, m, y, k, pattern_name) | Menginisialisasi sebuah instance baru dari kelas SetAdvancedColorStroke |

| Nama | Deskripsi |
| :- | :- |
