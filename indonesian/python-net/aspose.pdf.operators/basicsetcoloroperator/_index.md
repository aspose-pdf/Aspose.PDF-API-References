## BasicSetColorOperator class

Kelas dasar untuk operator set color.

Tipe BasicSetColorOperator menampilkan anggota berikut:
## Properti
| Nama | Deskripsi |
| :- | :- |
| index | Indeks operator dalam daftar operator halaman. |
| r | Mendapatkan komponen merah dari warna |
| g | Mendapatkan komponen hijau dari warna |
| b | Mendapatkan komponen merah dari warna |
| c | Mendapatkan komponen cyan dari warna CMYK. |
| m | Mendapatkan komponen magenta dari warna CMYK. |
| y | Mendapatkan komponen kuning dari warna CMYK. |
| k | Mendapatkan komponen hitam dari warna CMYK. |
| abu-abu | Mendapatkan komponen hitam dari warna abu-abu. |
| warna | Mendapatkan array komponen warna. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| accept(visitor) | Menerima pengunjung IOperatorSelector yang menyediakan pemrosesan operator. |
| is_text_show_operator(op) | Menentukan apakah operator tersebut adalah operator yang bertanggung jawab untuk output teks (Tj, TJ, dll) |
| get_color() | Mengembalikan warna yang ditentukan oleh operator. |
