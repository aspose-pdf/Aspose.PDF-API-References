## SetAdvancedColor class

Kelas yang mewakili operator scn (mengatur warna untuk operasi non-stroking).

Tipe SetAdvancedColor menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| SetAdvancedColor() | Menginisialisasi operator. |
| SetAdvancedColor(g, pattern_name) | Menginisialisasi sebuah instance baru dari kelas SetAdvancedColor |
| SetAdvancedColor(g) | Menginisialisasi sebuah instance baru dari kelas SetAdvancedColor |
| SetAdvancedColor(r, g, b, pattern_name) | Menginisialisasi sebuah instance baru dari kelas SetAdvancedColor |
| SetAdvancedColor(c, m, y, k, pattern_name) | Menginisialisasi sebuah instance baru dari kelas SetAdvancedColor |
## Properti
| Nama | Deskripsi |
| :- | :- |
| index | None |
| r | Mendapatkan komponen merah dari warna |
| g | Mendapatkan komponen hijau dari warna |
| b | Mendapatkan komponen merah dari warna |
| c | Mendapatkan komponen cyan dari warna CMYK. |
| m | Mendapatkan komponen magenta dari warna CMYK. |
| y | Mendapatkan komponen kuning dari warna CMYK. |
| k | Mendapatkan komponen hitam dari warna CMYK. |
| abu-abu | Mendapatkan komponen hitam dari warna abu-abu. |
| warna | Mendapatkan array komponen warna. |
| pattern_name | Mendapatkan Nama Pola. |
