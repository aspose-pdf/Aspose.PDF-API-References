## SetDash class

Kelas yang mewakili operator d (mengatur pola dash garis).

Tipe SetDash menampilkan anggota-anggota berikut:
## Konstruktor
| Nama | Deskripsi |
| :- | :- |
| SetDash(pattern, phase) | Menginisialisasi sebuah instance baru dari kelas SetDash |
## Properti
| Nama | Deskripsi |
| :- | :- |
| index | Indeks operator dalam daftar operator halaman. |
| pattern | Pola dash. Elemen array harus berupa angka yang menentukan panjang dash dan celah yang bergantian.<br/>            Jika array memiliki satu elemen, panjang dash dan celah adalah sama. |
| phase | Fase dash. Sebelum memulai menggambar jalur, array dash harus diputar, menambahkan panjang dash dan celah. <br/>            Ketika panjang yang terakumulasi sama dengan nilai yang ditentukan oleh fase dash, menggambar jalur akan dimulai, <br/>            dan array dash akan digunakan secara siklik dari titik tersebut. |
## Metode
| Nama | Deskripsi |
| :- | :- |
| accept(visitor) | Menerima objek visitor untuk memproses operator. |
| is_text_show_operator(op) | Menentukan apakah operator tersebut adalah operator yang bertanggung jawab untuk output teks (Tj, TJ, dll) |
