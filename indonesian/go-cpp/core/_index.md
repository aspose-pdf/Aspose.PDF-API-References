## Core PDF functions

| Nama | Deskripsi |
| -------------- | -------------- |
| [New](./new/) | Buat dokumen PDF baru. |
| [Open](./open/) | Buka dokumen PDF dengan nama file. |
| [Save](./save/) | Simpan dokumen PDF yang sebelumnya dibuka. |
| [SaveAs](./saveas/) | Simpan dokumen PDF yang sebelumnya dibuka dengan nama file baru. |
| [Close](./close/) | Lepaskan sumber daya yang dialokasikan untuk dokumen PDF. |
| [SetLicense](./setlicense/) | Atur lisensi dengan nama file. |
| [ExtractText](./extracttext/) | Kembalikan isi dokumen PDF sebagai teks biasa. |
| [WordCount](./wordcount/) | Kembalikan jumlah kata dalam dokumen PDF. |
| [CharacterCount](./charactercount/) | Kembalikan jumlah karakter dalam dokumen PDF. |
| [Append](./append/) | Tambahkan halaman dari dokumen PDF lain. |
| [AppendPages](./appendpages/) | Tambahkan halaman terpilih dari dokumen PDF lain. |
| [MergeDocuments](./mergedocuments/) | Buat dokumen PDF baru dengan menggabungkan dokumen PDF yang disediakan. |
| [SplitDocument](./splitdocument/) | Buat beberapa dokumen PDF baru dengan mengekstrak halaman dari dokumen PDF sumber. |
| [Split](./split/) | Buat beberapa dokumen PDF baru dengan mengekstrak halaman dari dokumen PDF saat ini. |
| [SplitAtPage](./splitatpage/) | Bagi dokumen PDF menjadi dua dokumen PDF baru. |
| [SplitAt](./splitat/) | Bagi dokumen PDF saat ini menjadi dua dokumen PDF baru. |
| [Bytes](./bytes/) | Kembalikan isi dokumen PDF sebagai potongan byte. |
| [GetMetaInfo](./getmetainfo/) | Dapatkan nilai informasi meta dokumen PDF.. |
| [SetMetaInfo](./setmetainfo/) | Atur nilai informasi meta dari PDF-dokumen.. |
| [ClearMetaInfo](./clearmetainfo/) | Bersihkan semua nilai informasi meta dari PDF-dokumen.. |
| [IsLinearized](./islinearized/) | Dapatkan nilai yang menunjukkan apakah dokumen terlinier. |
| [PageAdd](./pageadd/) | Tambahkan halaman baru dalam PDF-dokumen. |
| [PageInsert](./pageinsert/) | Sisipkan halaman baru pada posisi yang ditentukan dalam PDF-dokumen. |
| [PageDelete](./pagedelete/) | Hapus halaman yang ditentukan dalam PDF-dokumen. |
| [PageCount](./pagecount/) | Kembalikan jumlah halaman dalam PDF-dokumen. |
| [PageWordCount](./pagewordcount/) | Kembalikan jumlah kata pada halaman yang ditentukan dalam PDF-dokumen. |
| [PageCharacterCount](./pagecharactercount/) | Kembalikan jumlah karakter pada halaman yang ditentukan dalam PDF-dokumen. |
| [PageIsBlank](./pageisblank/) | Kembalikan apakah halaman kosong dalam PDF-dokumen. |
