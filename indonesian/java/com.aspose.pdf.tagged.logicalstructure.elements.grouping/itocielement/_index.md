```
public interface ITociElement
```

Mewakili elemen yang dapat berfungsi sebagai entri daftar isi (TOCI) dalam dokumen PDF bertag. Antarmuka ini mengabstraksikan baik elemen TOCI standar maupun elemen Item Daftar (LI) yang digunakan dalam struktur daftar isi bersarang.

## Metode

| Metode | Deskripsi |
| --- | --- |
| [getGetElement](#getGetElement--) | Mendapatkan elemen PDF yang mendasari yang mewakili struktur TOCI ini. |

### getGetElement {#getGetElement--}
```
StructureElement getGetElement()
```

Mendapatkan elemen PDF yang mendasari yang mewakili struktur TOCI ini.

**Returns:**
Elemen yang membentuk representasi struktural dari entri daftar isi ini.
