## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ValidationMethod](./validationmethod/) | Mewakili enum yang mendefinisikan metode yang digunakan untuk validasi sertifikat. |
| [ValidationMode](./validationmode/) | Menentukan mode validasi untuk proses validasi tanda tangan PDF. |
| [ValidationOptions](./validationoptions/) | Mewakili opsi untuk memvalidasi tanda tangan digital dalam dokumen PDF. |
| [ValidationResult](./validationresult/) | Mewakili hasil proses validasi untuk sebuah sertifikat. Kelas ValidationResult menyediakan informasi tentang hasil validasi sertifikat, termasuk statusnya dan pesan yang menjelaskan masalah apa pun yang ditemui selama validasi. |
| [ValidationStatus](./validationstatus/) | Mewakili status validasi dari validasi sertifikat. Enumerasi ini mendefinisikan kemungkinan hasil validasi sertifikat: - Valid: Menunjukkan bahwa sertifikat telah berhasil divalidasi. - Invalid: Menunjukkan bahwa validasi sertifikat gagal. - Undefined: Menunjukkan bahwa proses validasi tidak konklusif atau tidak dilakukan. |
