Mewakili kelas untuk menghasilkan representasi markdown dari perbedaan teks. Karena sintaks markdown, tidak memungkinkan menampilkan perubahan pada karakter spasi. Pemilihan perubahan menambahkan karakter spasi di sekitar pemformatan, jika tidak penampil markdown tidak akan menampilkan teks dengan benar. Pemutusan baris yang dihapus ditandai dengan - tanda paragraf.
