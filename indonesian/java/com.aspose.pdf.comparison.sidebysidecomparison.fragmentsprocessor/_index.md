## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [ExtractedFragmentsProcessorBase](./extractedfragmentsprocessorbase/) | Mewakili kelas dasar untuk pemroses fragmen yang diekstrak. |
| [IgnoreSpacesFragmentsProcessor](./ignorespacesfragmentsprocessor/) | Mewakili kelas untuk memproses fragmen teks dengan mode mengabaikan spasi. Kelas ini mengabaikan semua spasi, menyorot kata individu sebagai fragmen. |
| [NormalFragmentProcessor](./normalfragmentprocessor/) | Mewakili kelas untuk memproses fragmen teks dengan mode normal. Kelas ini hanya mempertimbangkan spasi dalam fragmen. |
| [ParseSpacesFragmentsProcessor](./parsespacesfragmentsprocessor/) | Mewakili kelas untuk memproses fragmen teks dengan mode mengurai spasi. Kelas ini mengenali spasi antara fragmen teks berdasarkan jarak di antara mereka. |
