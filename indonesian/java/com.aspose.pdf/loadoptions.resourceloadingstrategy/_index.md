```
public static interface LoadOptions.ResourceLoadingStrategy
```

Kadang-kadang diperlukan untuk menghindari penggunaan pemuat internal sumber daya eksternal (seperti gambar atau CSS) dan menyediakan metode khusus, yang akan mengambil sumber daya yang diminta dari suatu tempat. Misalnya selama penggunaan Aspose.PDf di cloud akses langsung ke file yang direferensikan tidak memungkinkan, dan beberapa kode khusus yang dimasukkan ke dalam metode khusus harus digunakan. Delegasi ini mendefinisikan tanda tangan dari metode khusus tersebut.
