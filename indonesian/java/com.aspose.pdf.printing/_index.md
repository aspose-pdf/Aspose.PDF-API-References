Paket com.aspose.pdf.printing menyediakan kelas yang digunakan untuk mengkonfigurasi proses pencetakan.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [CustomPrintEventArgs](./customprinteventargs/) | Menyediakan data untuk peristiwa PdfViewer.getCustomPrintDelegate(). |
| [DuplexKind](./duplexkind/) | Menentukan pengaturan dupleks printer. |
| [PdfPrinterResolution](./pdfprinterresolution/) | Mewakili resolusi yang didukung oleh printer. |
| [PdfPrinterResolutionKind](./pdfprinterresolutionkind/) | Menentukan resolusi printer. |
| [PdfPrinterSettings](./pdfprintersettings/) | Menentukan informasi tentang cara dokumen dicetak, termasuk printer yang mencetaknya. |
| [PdfPrintRange](./pdfprintrange/) | Menentukan bagian dokumen yang akan dicetak. |
| [PrinterMargins](./printermargins/) | Menentukan dimensi margin halaman yang dicetak. |
| [PrinterPaperKind](./printerpaperkind/) | Menentukan ukuran kertas standar. |
| [PrintPageSettings](./printpagesettings/) | Menentukan pengaturan yang berlaku untuk satu halaman yang dicetak. |
| [PrintPaperSize](./printpapersize/) | Menentukan ukuran selembar kertas. |
| [PrintPaperSizes](./printpapersizes/) | Mewakili ukuran kertas standar. |
| [PrintPaperSource](./printpapersource/) | Menentukan baki kertas dari mana printer mengambil kertas. |
| [PrintPaperSourceKind](./printpapersourcekind/) | Sumber kertas standar. |
| [PrintPaperSources](./printpapersources/) | Menyediakan sekumpulan instance {@link PrintPaperSource} yang telah ditentukan sebelumnya yang mewakili sumber kertas umum. Kelas ini tidak dapat diwariskan. |
