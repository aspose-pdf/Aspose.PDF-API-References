## CompressionType enumeration

Digunakan untuk menentukan nilai parameter yang diteruskan ke perangkat gambar Tiff.

```csharp
public enum CompressionType
```

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| LZW | `0` | Menentukan skema kompresi LZW. Dapat diteruskan ke enkoder Tiff sebagai parameter yang termasuk dalam kategori Kompresi. |
| CCITT4 | `1` | Menentukan skema kompresi CCITT4. Dapat diteruskan ke encoder CCITT4 sebagai parameter yang termasuk dalam kategori Compression. |
| CCITT3 | `2` | Menentukan skema kompresi CCITT3. Dapat diteruskan ke encoder CCITT3 sebagai parameter yang termasuk dalam kategori Compression. |
| RLE | `3` | Menentukan skema kompresi RLE. Dapat diteruskan ke encoder RLE sebagai parameter yang termasuk dalam kategori Compression. |
| None | `4` | Menentukan tanpa kompresi. Dapat diteruskan ke encoder Tiff sebagai parameter yang termasuk dalam kategori compression. |
