## MarkdownSaveOptions.ResourcesDirectoryName property

Mendapatkan dan mengatur nama direktori untuk menyimpan sumber daya dokumen seperti gambar. Jika nilai tidak ditentukan, maka gambar akan ditulis ke direktori yang sama dengan file markdown itu sendiri. Ini bukan jalur, hanya nama! Direktori ini akan secara otomatis dibuat di dalam direktori dengan file markdown yang disimpan.

```csharp
public string ResourcesDirectoryName { get; set; }
```
