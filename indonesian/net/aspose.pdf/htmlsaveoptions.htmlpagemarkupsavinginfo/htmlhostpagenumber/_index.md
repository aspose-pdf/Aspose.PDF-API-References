## HtmlSaveOptions.HtmlPageMarkupSavingInfo.HtmlHostPageNumber field

Ditentukan oleh konverter. Jika properti SplitToPages diatur, maka beberapa file HTML (satu file HTML per halaman yang dikonversi) dibuat selama proses konversi. Properti ini berisi urutan file halaman HTML yang disimpan. Properti ini dapat digunakan dalam logika kode khusus untuk memutuskan bagaimana memproses atau dimana menyimpan halaman HTML, dan jika pemisahan halaman dimatikan nilai ini selalu berisi '1' karena dalam kasus tersebut hanya satu halaman HTML besar yang dihasilkan untuk seluruh dokumen sumber.

```csharp
public int HtmlHostPageNumber;
```
