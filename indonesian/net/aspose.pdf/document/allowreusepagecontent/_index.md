## Document.AllowReusePageContent property

Memungkinkan menggabungkan konten halaman untuk mengoptimalkan ukuran dokumen. Jika digunakan, maka halaman yang berbeda namun duplikat dapat merujuk ke objek konten yang sama. Harap perhatikan bahwa mode ini dapat menyebabkan efek samping seperti mengubah konten halaman ketika halaman lain diubah.

```csharp
public bool AllowReusePageContent { get; set; }
```
