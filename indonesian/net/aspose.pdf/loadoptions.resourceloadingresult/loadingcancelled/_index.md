## LoadOptions.ResourceLoadingResult.LoadingCancelled field

Kadang karena beberapa alasan pemuatan tidak boleh terjadi melalui kode khusus. Dalam kasus tersebut, harap setel flag ini ke True. Dalam kasus ini konverter akan mencoba menggunakan pemuat sumber daya default internal untuk mendapatkan hasil tersebut (seperti perilakunya ketika strategi khusus tidak disediakan).

```csharp
public bool LoadingCancelled;
```
