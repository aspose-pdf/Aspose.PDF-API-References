## LoadOptions.ResourceLoadingResult.EncodingIfKnown field

Kadang encoding sumber daya diketahui setelah atau selama pemuatan. Dalam kasus tersebut kode khusus dapat memberikan konverter pengetahuan tersebut melalui parameter ini. Anda dapat membiarkan null pada parameter ini jika encoding tidak diketahui atau tidak penting.

```csharp
public Encoding EncodingIfKnown;
```
