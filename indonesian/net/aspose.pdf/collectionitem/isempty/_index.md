## CollectionItem.IsEmpty property

Mendapatkan nilai yang menunjukkan apakah item koleksi kosong.

```csharp
public bool IsEmpty { get; }
```

### Nilai Kembalian

true jika item koleksi kosong; jika tidak, false.

## Catatan

Properti ini mengembalikan true jika item koleksi tidak berisi nilai apa pun, termasuk nilai string, nilai double, nilai integer, dan nilai tanggal. Jika salah satu tipe nilai ini ada dalam item koleksi, properti ini mengembalikan false.
