## HtmlSaveOptions.HtmlImageSavingInfo.PdfHostPageNumber field

Memberitahu kode khusus pada halaman mana dari dokumen PDF asli gambar yang disimpan terkait. Karena mungkin tidak semua halaman dokumen asli akan disimpan, nilai ini memberi tahu kita tentang nomor halaman host dalam PDF asli. Jika nomor halaman asli karena suatu alasan tidak diketahui, selalu mengembalikan '1'.

```csharp
public int PdfHostPageNumber;
```
