## SvgSaveOptions.TreatTargetFileNameAsDirectory field

Opsi ini menentukan apakah akan dibuat direktori target (jika belum ada) dengan nama yang sama dengan file output yang diminta, alih-alih file output itu sendiri. Dengan cara ini, direktori akan berisi semua gambar SVG output dari halaman (seperti dijelaskan di bawah). Jika tidak, file output halaman selain yang pertama akan dibuat tepat di direktori yang diminta sebagai file output utama, tetapi akan memiliki akhiran nama file _[2...n], yang ditentukan oleh nomor halaman, misalnya jika Anda menentukan file output \"C:\\AsposeTests\\output.svg\" dan output akan berisi beberapa file SVG halaman, maka file halaman juga akan dibuat di direktori \"C:\\AsposeTests\\\" dan memiliki nama 'output.svg', 'output_2.svg', 'output_3.svg', dll.

```csharp
public bool TreatTargetFileNameAsDirectory;
```
