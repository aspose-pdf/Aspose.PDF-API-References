## HtmlSaveOptions.CssUrlRequestInfo.CustomProcessingCancelled field

Harus diatur oleh kode khusus jika tidak dapat atau tidak seharusnya menentukan URL yang akan digunakan dalam HTML yang dihasilkan untuk merujuk CSS tersebut. Jika bernilai 'true', maka file CSS akan disimpan dengan cara standar di tempat standar.

public bool CustomProcessingCancelled;
