## AutoTaggingSettings.HeadingLevels property

Mendapatkan atau mengatur level heading yang digunakan untuk menentukan struktur heading dalam dokumen PDF.

```csharp
public HeadingLevels HeadingLevels { get; set; }
```

## Catatan

Properti `HeadingLevels` memungkinkan mengonfigurasi pemetaan ukuran font ke level heading. Ini digunakan selama proses auto-tagging untuk mengidentifikasi dan menetapkan level heading yang sesuai berdasarkan ukuran font elemen teks dalam dokumen.
