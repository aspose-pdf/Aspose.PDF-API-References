## Catatan

Pengaturan default mengaktifkan auto-tagging dan menggunakan strategi otomatis untuk pengenalan heading. Pengaturan ini dapat digunakan sebagai konfigurasi dasar untuk konversi format PDF atau operasi lain yang memerlukan penandaan otomatis konten PDF.
