## AutoTaggingSettings.HeadingRecognitionStrategy property

Mendapatkan atau mengatur strategi yang digunakan untuk mengenali heading dalam dokumen selama auto-tagging.

```csharp
public HeadingRecognitionStrategy HeadingRecognitionStrategy { get; set; }
```

## Catatan

Properti `HeadingRecognitionStrategy` menentukan bagaimana heading diidentifikasi dalam dokumen. Strategi yang tersedia mencakup pengenalan heading berdasarkan outline, analisis heuristik, atau deteksi otomatis. Menetapkan properti ini ke None menonaktifkan pengenalan heading.
