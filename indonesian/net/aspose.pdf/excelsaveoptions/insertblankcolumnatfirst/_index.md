## ExcelSaveOptions.InsertBlankColumnAtFirst property

Atur true jika Anda memerlukan penyisipan kolom kosong sebagai kolom pertama lembar kerja. Nilai default adalah false; artinya kolom kosong tidak akan disisipkan.
