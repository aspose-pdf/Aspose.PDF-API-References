## RenderingOptions.UseFontHinting property

Penggunaan flag ini mengaktifkan mekanisme font hinting. Font hinting adalah penggunaan instruksi matematis untuk menyesuaikan tampilan font outline. Dalam beberapa kasus mengaktifkan flag ini dapat menyelesaikan masalah keterbacaan teks. Saat ini penggunaan flag ini hanya berpengaruh pada font TTF, jika font tersebut digunakan dalam dokumen sumber.

```csharp
public bool UseFontHinting { get; set; }
```
