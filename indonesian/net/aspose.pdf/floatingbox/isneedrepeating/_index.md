## FloatingBox.IsNeedRepeating property

Mendapatkan atau mengatur nilai bool yang menunjukkan apakah paragraf perlu diulang pada halaman berikutnya. Nilai default adalah false. Atribut ini hanya valid ketika paragraf itu sendiri dan objek yang dirujuk oleh ReferenceParagraphID keduanya termasuk dalam RepeatingRows.

```csharp
public bool IsNeedRepeating { get; set; }
```
