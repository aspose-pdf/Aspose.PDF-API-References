## PdfANonSpecificationFlags class

Kelas ini menyimpan flag untuk mengontrol konversi PDF/A pada kasus ketika dokumen PDF sumber tidak sesuai dengan spesifikasi PDF. Jika flag dari kelas ini digunakan, kinerjanya menurun tetapi diperlukan ketika dokumen PDF sumber tidak dapat dikonversi ke format PDF/A dengan cara biasa. Secara default semua flag diatur ke false.
