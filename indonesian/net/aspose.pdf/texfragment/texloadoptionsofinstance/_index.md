## TeXFragment.TeXLoadOptionsOfInstance property

Mendapatkan atau mengatur TeXLoadOptions yang akan digunakan untuk memuat (dan merender) LaTeX ke dalam instance kelas ini. Silakan gunakan ketika diperlukan pengaturan khusus untuk mengimpor LaTeX bagi instance tertentu (misalnya ketika instance ini atau itu harus menggunakan BasePath khusus untuk LaTeX yang diimpor atau harus menggunakan pemuat khusus untuk sumber daya eksternal). Jika parameter bernilai default (null), maka opsi pemuatan LaTeX standar akan digunakan.

```csharp
public TeXLoadOptions TeXLoadOptionsOfInstance { get; set; }
```
