## HtmlSaveOptions.ConvertMarkedContentToLayers property

Jika atribut ConvertMarkedContentToLayers diatur ke true maka semua elemen di dalam konten PDF yang ditandai (lapisan) akan ditempatkan ke dalam div HTML dengan atribut "data-pdflayer" yang menentukan nama lapisan. Nama lapisan ini akan diambil dari properti opsional dari konten PDF yang ditandai. Jika atribut ini false (secara default) maka tidak ada lapisan yang akan dibuat dari konten PDF yang ditandai.

```csharp
public bool ConvertMarkedContentToLayers { get; set; }
```
