## HtmlSaveOptions.FontSources property

Sumber font dari font yang telah disimpan sebelumnya.

```csharp
public FontSourceCollection FontSources { get; }
```

## Catatan

Fonts dapat disimpan terlebih dahulu untuk tujuan cache dan kemudian diteruskan ke proses konversi Html. Misalnya ini dapat berguna dalam skenario pemisahan dokumen dan pemrosesan halaman dokumen dalam beberapa thread dengan satu set font.
