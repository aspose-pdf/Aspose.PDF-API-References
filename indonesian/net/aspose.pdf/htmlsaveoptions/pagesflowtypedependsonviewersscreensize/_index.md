## HtmlSaveOptions.PagesFlowTypeDependsOnViewersScreenSize field

Jika atribut 'SplitOnPages=false', maka seluruh HTML yang mewakili semua halaman PDF input akan dimasukkan ke dalam satu file HTML hasil yang besar. Flag ini menentukan apakah HTML hasil akan dihasilkan dengan cara aliran area yang mewakili halaman PDF dalam HTML hasil akan bergantung pada resolusi layar penampil. Misalkan lebar layar pada sisi penampil cukup besar untuk menempatkan 2 atau lebih halaman berdampingan secara horizontal. Jika flag ini diatur ke true, maka kesempatan ini akan digunakan (sebanyak mungkin halaman akan ditampilkan secara horizontal berdampingan, kemudian grup horizontal berikutnya akan ditampilkan di bawah grup pertama). Jika tidak, halaman akan mengalir dengan cara: halaman berikutnya selalu berada di bawah halaman sebelumnya.

```csharp
public bool PagesFlowTypeDependsOnViewersScreenSize;
```
