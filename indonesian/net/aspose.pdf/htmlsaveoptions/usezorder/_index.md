## HtmlSaveOptions.UseZOrder property

Jika atribut UseZORder diatur ke true, grafik dan teks ditambahkan ke dokumen HTML hasil sesuai urutan Z dalam dokumen PDF asli. Jika atribut ini false, semua grafik diletakkan sebagai lapisan tunggal yang dapat menyebabkan efek tidak perlu pada objek yang tumpang tindih.

```csharp
public bool UseZOrder { get; set; }
```
