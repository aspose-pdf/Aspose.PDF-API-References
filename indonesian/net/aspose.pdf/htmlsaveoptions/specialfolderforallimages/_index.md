## HtmlSaveOptions.SpecialFolderForAllImages field

Mendapatkan atau mengatur jalur ke direktori tempat semua gambar harus disimpan jika ditemukan selama penyimpanan dokumen sebagai HTML. Jika parameter kosong atau null, maka file gambar (jika ada) akan disimpan bersama file lain yang terhubung ke HTML. Hal ini tidak memengaruhi apa pun jika properti CustomImageSavingStrategy berhasil digunakan untuk memproses file gambar yang relevan.

```csharp
public string SpecialFolderForAllImages;
```
