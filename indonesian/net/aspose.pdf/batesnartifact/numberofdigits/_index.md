## BatesNArtifact.NumberOfDigits property

Mendapatkan atau mengatur jumlah digit untuk Bates numbering. Nilai harus antara 3 dan 15 termasuk. Jika nilai yang diatur kurang dari 3, akan disesuaikan menjadi 3. Jika nilai yang diatur lebih dari 15, akan disesuaikan menjadi 15. Nilai default adalah 6.

public int NumberOfDigits { get; set; }
