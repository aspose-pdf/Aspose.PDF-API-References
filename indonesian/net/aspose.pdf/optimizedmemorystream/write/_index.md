## OptimizedMemoryStream.Write method

Ketika dioverride dalam kelas turunan, menulis urutan byte ke aliran saat ini dan memajukan posisi saat ini dalam aliran ini sebanyak jumlah byte yang ditulis.

```csharp
public override void Write(byte[] buffer, int offset, int count)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| buffer | Byte[] | Array byte. Metode ini menyalin *count* byte dari *buffer* ke aliran saat ini. |
| offset | Int32 | Offset byte berbasis nol dalam *buffer* tempat memulai menyalin byte ke aliran saat ini. |
| jumlah | Int32 | Jumlah byte yang akan ditulis ke aliran saat ini. |
