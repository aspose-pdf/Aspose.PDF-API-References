## TeXLoadOptions.Repeat property

Mendapatkan/mengatur flag yang menunjukkan apakah perlu menjalankan pekerjaan TeX dua kali dalam kasus, misalnya, terdapat referensi dalam file TeX masukan. Secara umum, perilaku ini berguna ketika mesin mengumpulkan beberapa data selama proses penataan dan menyimpannya dalam file tambahan pada run pertama. Dan pada run kedua, mesin entah bagaimana menggunakan data tersebut.

```csharp
public bool Repeat { get; set; }
```
