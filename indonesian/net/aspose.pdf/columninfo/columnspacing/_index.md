## ColumnInfo.ColumnSpacing property

Mendapatkan atau mengatur string yang berisi jarak antar kolom. Nilai setiap jarak harus dipisahkan dengan spasi. Unit default adalah point, tetapi cm dan inch juga didukung. Misalnya, \"120 2.5cm 1.5inch\".

```csharp
public string ColumnSpacing { get; set; }
```

## Catatan

Jika properti ini tidak diatur, nilai default 0 akan digunakan untuk setiap jarak.
