## SvgExtractionOptions.GroupStrength property

Mendapatkan dan mengatur opsi Kekuatan pengelompokan subpath menjadi gambar. Memungkinkan Anda mengonfigurasi tingkat pengelompokan subpath. Rentang nilai adalah dari 0 hingga 1. Nilai 0 berarti opsi [`ExtractEverySubPathToSvg`](../extracteverysubpathtosvg/) diaktifkan. Nilai 1 akan membuat satu gambar tunggal untuk semua jalur vektor pada halaman. Opsi ini berpengaruh ketika [`AutoGrouping`](../autogrouping/) bernilai false. Nilai default adalah `0.8`.

```csharp
public double GroupStrength { get; set; }
```
