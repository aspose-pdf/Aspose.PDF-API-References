## SvgExtractionOptions.StrictExtractionAreaBoundCheck property

Mendapatkan dan mengatur opsi untuk secara ketat memeriksa apakah subpath berada dalam persegi panjang yang ditentukan di [`ExtractionAreaBound`](../extractionareabound/). Jika disetel ke false, maka subpath yang tidak sepenuhnya termasuk dalam [`ExtractionAreaBound`](../extractionareabound/) akan diekstrak. Nilai default adalah `True`.

public bool StrictExtractionAreaBoundCheck { get; set; }
