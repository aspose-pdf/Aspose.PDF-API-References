## Namespace

| Namespace | Deskripsi |
| --- | --- |
| [Aspose.Pdf](./aspose.pdf/) | **Aspose.Pdf** adalah namespace root untuk semua kelas dari pustaka Aspose.Pdf yang berada baik secara langsung di dalamnya seperti **Document** atau secara tidak langsung melalui beberapa sub-namespace. |
| [Aspose.Pdf.AI](./aspose.pdf.ai/) | **Aspose.Pdf.AI** namespace menyediakan kelas untuk fungsionalitas AI, termasuk klien API dan asisten cerdas. |
| [Aspose.Pdf.Annotations](./aspose.pdf.annotations/) | **Aspose.Pdf.Annotations** namespace menyediakan kelas untuk bekerja dengan berbagai jenis aksi, tujuan, dan fitur lain dari dokumen yang secara tradisional disebut interaktif, memberikan cara bagi pengguna untuk berinteraksi dengannya. |
| [Aspose.Pdf.Comparison](./aspose.pdf.comparison/) | **Aspose.Pdf.Comparison** namespace menyediakan kelas yang digunakan untuk perbandingan dokumen. |
| [Aspose.Pdf.DataEditor](./aspose.pdf.dataeditor/) | **Aspose.Pdf.DataEditor** berisi alat untuk mengedit data dalam sebuah dokumen. |
| [Aspose.Pdf.Devices](./aspose.pdf.devices/) | **Aspose.Pdf.Devices** namespace menyediakan kelas yang digunakan untuk merepresentasikan dokumen sebagai gambar atau teks biasa. Jadi dokumen dapat dikirim ke perangkat tekstual atau grafis yang berarti kita ingin mendapatkan representasi tekstual atau grafisnya. |
| [Aspose.Pdf.Drawing](./aspose.pdf.drawing/) | **Aspose.Pdf.Drawing** namespace menyediakan kelas yang menggambarkan primitif grafis seperti busur, garis, lingkaran, dll. Objek terkait dapat digunakan untuk membuat dokumen baru. |
| [Aspose.Pdf.Facades](./aspose.pdf.facades/) | **Aspose.Pdf.Facades** namespace menyediakan kelas yang awalnya berasal dari Aspose.Pdf.Kit. Kelas-kelas ini digunakan untuk memanipulasi dokumen dengan melakukan operasi seperti menggabungkan, menambahkan stempel, menandatangani, memberi anotasi, dll., tetapi pada tingkat tinggi tanpa mengakses struktur internal dokumen. |
| [Aspose.Pdf.Forms](./aspose.pdf.forms/) | **Aspose.Pdf.Forms** namespace memiliki kelas yang menggambarkan formulir (standar, statis, dinamis) dan berbagai jenis bidang seperti kotak teks, kotak daftar, tombol radio, dll. |
| [Aspose.Pdf.LogicalStructure](./aspose.pdf.logicalstructure/) | **Aspose.Pdf.Tagged.LogicalStructure** adalah namespace untuk kelas Struktur Logis PDF. |
| [Aspose.Pdf.Multithreading](./aspose.pdf.multithreading/) | **Aspose.Pdf.Multithreading** namespace menyediakan kelas yang dimaksudkan untuk digunakan dalam skenario multi-thread. |
| [Aspose.Pdf.Operators](./aspose.pdf.operators/) | **Aspose.Pdf.Operators** adalah namespace untuk implementasi Operator. Kelas-kelas ini menggambarkan operator yang digunakan dalam konten halaman PDF. |
| [Aspose.Pdf.Optimization](./aspose.pdf.optimization/) | **Aspose.Pdf.Optimization** adalah namespace untuk kelas yang mengelola proses optimisasi dokumen. |
| [Aspose.Pdf.Plugins](./aspose.pdf.plugins/) | **Aspose.Pdf.Plugins** adalah namespace root untuk semua kelas dari Aspose.Pdf.Plugins yang berada baik secara langsung di dalamnya seperti **PdfOrganizer** atau secara tidak langsung melalui beberapa sub-namespace. |
| [Aspose.Pdf.Printing](./aspose.pdf.printing/) | **Aspose.Pdf.Printing** namespace menyediakan kelas dan fungsionalitas untuk menangani operasi pencetakan PDF, termasuk pengaturan printer, pengaturan halaman, dan ekstensi untuk mengelola konfigurasi terkait pencetakan. |
| [Aspose.Pdf.Sanitization](./aspose.pdf.sanitization/) | **Aspose.Pdf.Sanitization** adalah namespace untuk operasi sanitasi. |
| [Aspose.Pdf.Security](./aspose.pdf.security/) | **Aspose.Pdf.Security** namespace berisi kelas yang digunakan untuk enkripsi dan penandatanganan digital. |
| [Aspose.Pdf.Signatures](./aspose.pdf.signatures/) | **Aspose.Pdf.Signatures** namespace berisi kelas yang digunakan untuk mendeteksi tanda tangan yang terkompromi. |
| [Aspose.Pdf.Structure](./aspose.pdf.structure/) | **Aspose.Pdf.Structure** namespace menyediakan kelas yang membantu bekerja dengan struktur logis sebuah dokumen yang menyajikan organisasi dokumen menjadi bab dan bagian atau identifikasi elemen khusus seperti gambar, tabel, dan catatan kaki. |
| [Aspose.Pdf.Tagged](./aspose.pdf.tagged/) | **Aspose.Pdf.Tagged** adalah namespace untuk kelas yang mendukung dokumen Tagged PDF. |
| [Aspose.Pdf.Text](./aspose.pdf.text/) | Namespace **Aspose.Pdf.Text** menyediakan kelas yang memungkinkan untuk mengekstrak teks, menambahkan teks, memanipulasi teks yang ada dalam dokumen. Itu juga berisi kelas yang memungkinkan untuk mengekstrak, mengganti, menggantikan font dalam dokumen. |
| [Aspose.Pdf.Vector](./aspose.pdf.vector/) | Namespace **Aspose.Pdf.Vector** adalah namespace akar untuk operasi grafik. |
| [Aspose.Pdf.XfaConverter](./aspose.pdf.xfaconverter/) | Namespace **Aspose.Pdf.XfaConverter** menyediakan kelas yang memungkinkan untuk mengonversi XFA. |
