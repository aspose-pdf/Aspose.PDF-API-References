## XfaParserOptions.Signed property

Jika properti ini bernilai true maka Document akan dikonversi dengan menggunakan aliran formulir xfa (jika ada). Jika bernilai false maka aliran formulir xfa akan diabaikan. Properti ini diperkenalkan karena tidak jelas bagaimana menghitung checksum yang digunakan untuk memeriksa tanda tangan.

```csharp
public bool Signed { get; set; }
```
