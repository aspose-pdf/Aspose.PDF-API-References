## SideBySideComparisonOptions.AdditionalChangeMarks property

Dapatkan dan atur properti yang menentukan apakah penanda perubahan tambahan ditampilkan. Jika diatur, menampilkan tanda perubahan yang tidak ada pada halaman saat ini tetapi ada pada halaman lain. Jika perubahan terletak di antara kata-kata, tanda tersebut mungkin tidak diposisikan secara tepat relatif terhadap karakter spasi. Nilai default adalah `false`.

```csharp
public bool AdditionalChangeMarks { get; set; }
```
