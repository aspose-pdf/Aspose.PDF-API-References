## TruncationStrategy.StrategyType property

Mendapatkan atau mengatur strategi pemotongan yang digunakan untuk thread. Defaultnya adalah auto. Jika diatur ke last_messages, thread akan dipotong menjadi n pesan terbaru dalam thread. Ketika diatur ke auto, pesan-pesan di tengah thread akan dihapus untuk menyesuaikan panjang konteks model, max_prompt_tokens.

public string StrategyType { get; set; }
