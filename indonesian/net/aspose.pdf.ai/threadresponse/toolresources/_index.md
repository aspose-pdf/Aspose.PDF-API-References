## ThreadResponse.ToolResources property

Mendapatkan atau mengatur sekumpulan sumber daya yang tersedia untuk alat asisten dalam thread ini. Sumber daya tersebut spesifik untuk jenis alat. Misalnya, alat code_interpreter memerlukan daftar ID file, sementara alat file_search memerlukan daftar ID vector store.
