## CreateEmbeddingRequest.Input property

Mendapatkan atau mengatur teks input untuk di-embed, dienkode sebagai string atau array token. Untuk meng-embed beberapa input dalam satu permintaan, berikan array string atau array array token. Input tidak boleh melebihi token maksimum untuk model (8192 token untuk text-embedding-ada-002), tidak boleh berupa string kosong, dan setiap array harus berukuran 2048 dimensi atau kurang.

public string Input { get; set; }
