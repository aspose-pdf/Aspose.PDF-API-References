## TextSearchOptions.UseFontEngineEncoding property

Mendapatkan atau mengatur indikasi bahwa teks akan dicari menggunakan enkoding mesin font. true - berarti enkoding mesin font akan digunakan (coba ini jika pencarian teks gagal karena enkoding yang tidak sempurna dalam dokumen) false - berarti enkoding font dokumen yang akan digunakan (nilai default)

```csharp
public bool UseFontEngineEncoding { get; set; }
```
