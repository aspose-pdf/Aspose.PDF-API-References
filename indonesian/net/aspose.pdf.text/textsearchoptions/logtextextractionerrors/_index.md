## TextSearchOptions.LogTextExtractionErrors property

Mendapatkan atau mengatur indikasi bahwa kesalahan ekstraksi teks (dekoding) akan dicatat dalam penyerap teks (fragmen). true - berarti kesalahan ekstraksi teks (dekoding) akan dicatat. Ini dapat menurunkan kinerja. false (default) - tidak ada pencatatan kesalahan.

public bool LogTextExtractionErrors { get; set; }
