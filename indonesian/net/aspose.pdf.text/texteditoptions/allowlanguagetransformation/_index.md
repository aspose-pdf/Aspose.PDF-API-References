## TextEditOptions.AllowLanguageTransformation property

Mendapatkan atau mengatur nilai yang mengizinkan penggunaan transformasi bahasa selama penambahan atau penyuntingan teks. true - transformasi bahasa akan diterapkan jika diperlukan (nilai default). false - transformasi bahasa TIDAK akan diterapkan.

public bool AllowLanguageTransformation { get; set; }
