## TextExtractionOptions.ScaleFactor property

Mendapatkan atau mengatur faktor yang akan diterapkan untuk mengubah ukuran font selama ekstraksi dalam mode murni. Menetapkan nilai yang lebih kecil menghasilkan lebih banyak spasi dalam teks yang diekstrak. Nilai default adalah 1 - tidak ada skala; Menetapkan nilai ke nol memungkinkan algoritma memilih skala secara otomatis.

```csharp
public double ScaleFactor { get; set; }
```
