## RadioButtonField.NoToggleToOff property

Mendapatkan atau mengatur flag yang memungkinkan tombol radio tidak memiliki nilai terpilih. Jika `true`, tepat satu tombol radio harus dipilih setiap saat; memilih tombol yang sudah dipilih tidak berpengaruh. Jika `false`, mengklik tombol yang dipilih akan membatalkannya, sehingga tidak ada tombol yang dipilih.

```csharp
public bool NoToggleToOff { get; set; }
```

## Catatan

Beberapa pembaca PDF (termasuk Adobe Acrobat) mungkin mengabaikan status `false` dari flag tersebut.
