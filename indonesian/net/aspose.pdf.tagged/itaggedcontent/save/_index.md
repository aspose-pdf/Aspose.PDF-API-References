## ITaggedContent.Save method

Menyimpan status saat ini dari konten bertag ke PDF Document yang terkait.

```csharp
public void Save()
```

## Catatan

Metode ini memastikan bahwa semua elemen konten ber-tag diperbarui dan disimpan dengan benar di dalam dokumen PDF. Metode ini melakukan operasi yang diperlukan seperti memperbarui MCID untuk elemen MCR, mengatur operator BDC, dan memastikan kepatuhan terhadap standar PDF/UA.
