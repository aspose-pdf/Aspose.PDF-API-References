## ITaggedContent.SetLanguage method

Mengatur bahasa alami untuk PDF Document.

Pengidentifikasi bahasa yang harus menentukan bahasa alami untuk semua teks dalam dokumen kecuali bila diganti oleh spesifikasi bahasa untuk elemen struktur atau konten yang ditandai.

```csharp
public void SetLanguage(string lang)
```

| Parameter | Tipe | Deskripsi |
| --- | --- | --- |
| lang | String | Pengidentifikasi bahasa harus berupa string teks kosong, untuk menunjukkan bahwa bahasa tidak diketahui, atau sebuah Language-Tag sebagaimana didefinisikan dalam RFC 3066, Tag untuk Identifikasi Bahasa. |
