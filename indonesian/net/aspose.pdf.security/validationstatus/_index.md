## ValidationStatus enumeration

### Nilai

| Nama | Nilai | Deskripsi |
| --- | --- | --- |
| Valid | `0` | Menunjukkan bahwa sertifikat telah berhasil divalidasi. |
| Invalid | `1` | Menunjukkan bahwa validasi sertifikat gagal. |
| Undefined | `2` | Menunjukkan bahwa proses validasi tidak konklusif atau tidak dilakukan. |

## Catatan
