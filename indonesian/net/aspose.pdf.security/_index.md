**Aspose.Pdf.Security** namespace berisi kelas yang digunakan untuk enkripsi dan penandatanganan digital.

## Kelas

| Kelas | Deskripsi |
| --- | --- |
| [CertificateEncryptionOptions](./certificateencryptionoptions/) | Mewakili kelas untuk opsi enkripsi dokumen PDF menggunakan metode enkripsi berbasis sertifikat. Digunakan untuk membuka dokumen PDF yang terenkripsi. |
| [DsaAlgorithmInfo](./dsaalgorithminfo/) | Mewakili kelas untuk informasi tentang algoritma tanda tangan DSA. |
| [EcdsaAlgorithmInfo](./ecdsaalgorithminfo/) | Mewakili kelas untuk informasi tentang algoritma tanda tangan ECDSA. |
| [EncryptionParameters](./encryptionparameters/) | Mewakili kelas parameter enkripsi. |
| [KeyedSignatureAlgorithmInfo](./keyedsignaturealgorithminfo/) | Mewakili kelas untuk informasi tentang algoritma tanda tangan berbasis kunci. |
| [RsaAlgorithmInfo](./rsaalgorithminfo/) | Mewakili kelas untuk informasi tentang algoritma tanda tangan RSA. |
| [SignatureAlgorithmInfo](./signaturealgorithminfo/) | Mewakili kelas untuk informasi tentang algoritma tanda tangan, termasuk tipe, standar kriptografi, dan algoritma hash digest. |
| [SignatureLengthMismatchException](./signaturelengthmismatchexception/) | Mewakili kesalahan yang terjadi selama penandatanganan PDF. Terjadi jika [`SignHash`](../aspose.pdf.forms/signhash/) digunakan untuk menandatangani dokumen dan panjang sebenarnya dari tanda tangan lebih besar daripada yang ditentukan dalam opsi [`DefaultSignatureLength`](../aspose.pdf.forms/signature/defaultsignaturelength/). |
| [TimestampAlgorithmInfo](./timestampalgorithminfo/) | Mewakili kelas untuk informasi tentang algoritma tanda tangan timestamp. |
| [UnknownSignatureAlgorithmInfo](./unknownsignaturealgorithminfo/) | Mewakili kelas untuk informasi tentang algoritma tanda tangan yang tidak diketahui. |
| [ValidationOptions](./validationoptions/) | Mewakili opsi untuk memvalidasi tanda tangan digital dalam dokumen PDF. |
| [ValidationResult](./validationresult/) | Mewakili hasil proses validasi untuk sebuah sertifikat. |
