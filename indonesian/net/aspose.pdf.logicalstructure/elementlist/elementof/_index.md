## ElementList indexer

Mendapatkan sebuah elemen pada indeks yang diberikan.

```csharp
public virtual Element ElementOf[int index] { get; }
```

| Parameter | Deskripsi |
| --- | --- |
| index | Indeks ke dalam daftar elemen. |

### Nilai Kembalian

Elemen dengan indeks yang ditentukan dalam koleksi. Jika indeks lebih besar atau sama dengan jumlah elemen dalam daftar, ini mengembalikan null.
