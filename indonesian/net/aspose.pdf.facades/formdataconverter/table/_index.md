## FormDataConverter.Table property

Mendapatkan atau mengatur kontainer data menengah, satu DataTable. Harus didefinisikan sebelum mengonversi data dari satu format ke format lain. Columns dan TableName dari DataTable harus didefinisikan. TableName adalah nama Table dalam basis data. Setiap ColumnName kolom adalah nama field yang memenuhi syarat dari pdf. Setiap Caption kolom adalah nama kolom tabel dalam basis data. Jika nama field sama dengan nama kolom tabel, Caption tidak perlu ditentukan.

```csharp
public DataTable Table { get; set; }
```
