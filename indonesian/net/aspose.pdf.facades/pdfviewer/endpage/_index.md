## PdfViewer.EndPage event

Terjadi ketika pencetakan sebuah halaman selesai di PdfViewer.

```csharp
public event EventHandler<StartEndPageEventArgs> EndPage;
```

## Catatan

Event ini dipicu setelah sebuah halaman diproses di PdfViewer. Ini dapat digunakan untuk melakukan aksi atau pembaruan setelah pencetakan halaman.
