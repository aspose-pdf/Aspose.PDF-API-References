## PdfAOptionsBase.FontEmbeddingOptions property

Mendapatkan opsi untuk memproses font yang tidak dapat disematkan ke dalam dokumen.

```csharp
public FontEmbeddingOptions FontEmbeddingOptions { get; }
```

### Property Value

Opsi penyematan font.

## Catatan

Standar PDF/A mengharuskan semua font harus disematkan ke dalam dokumen. Properti ini menyediakan opsi untuk menangani kasus ketika tidak memungkinkan menyematkan beberapa font karena tidak ada di PC tujuan.
