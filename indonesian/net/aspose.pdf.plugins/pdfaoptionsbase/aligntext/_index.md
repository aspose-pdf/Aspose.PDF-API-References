## PdfAOptionsBase.AlignText property

Mendapatkan atau mengatur nilai yang menunjukkan apakah cara tambahan diperlukan untuk mempertahankan perataan teks selama proses konversi PDF/A.

```csharp
public bool AlignText { get; set; }
```

### Property Value

`true` jika perataan teks berubah dan tindakan tambahan diperlukan untuk memulihkannya; selain itu, `false`.

## Catatan

Saat diatur ke `true`, proses konversi akan berusaha memulihkan batas segmen teks asli. Untuk sebagian besar dokumen tidak perlu mengubah properti ini dari nilai default `false`, karena perataan teks tidak berubah selama proses konversi default.
