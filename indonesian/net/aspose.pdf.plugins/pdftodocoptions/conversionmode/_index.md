## PdfToDocOptions.ConversionMode property

Memungkinkan mengontrol bagaimana dokumen PDF dikonversi menjadi dokumen pengolah kata.

```csharp
public ConversionMode ConversionMode { get; set; }
```

## Catatan

Gunakan mode TextBox ketika dokumen yang dihasilkan tidak akan banyak diedit lagi. Textbox mudah dimodifikasi ketika tidak banyak yang harus dilakukan.

Gunakan mode Flow ketika dokumen output memerlukan penyuntingan lebih lanjut. Paragraf dan baris teks dalam mode flow memungkinkan modifikasi teks yang mudah, namun objek pemformatan yang tidak didukung akan terlihat lebih buruk dibandingkan mode TextBox.
