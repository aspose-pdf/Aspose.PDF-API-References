## PdfToXlsOptions.MinimizeTheNumberOfWorksheets property

Atur true jika Anda perlu meminimalkan jumlah lembar kerja dalam buku kerja yang dihasilkan. Nilai default adalah false; artinya setiap halaman PDF disimpan sebagai lembar kerja terpisah.

public bool MinimizeTheNumberOfWorksheets { get; set; }
