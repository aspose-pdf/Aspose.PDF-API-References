## XfaParserOptions class

classe pour gérer l'encapsulation des données associées

Le type XfaParserOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| XfaParserOptions(page_size) | Initialise une nouvelle instance de la classe XfaParserOptions |
## Propriétés
| Nom | Description |
| :- | :- |
| page_size | Obtient ou définit la taille de la page. |
| signé | Si cette propriété est vraie, le document sera converti en utilisant le flux de formulaire xfa (s'il existe).<br/>            Si elle est fausse, le flux de formulaire xfa sera ignoré.<br/>            Cette propriété a été introduite parce qu'il n'est pas clair comment calculer la somme de contrôle utilisée pour vérifier la signature. |
| emulate_requierd_groups | Si cette propriété est vraie, des rectangles rouges supplémentaires seront dessinés pour les \"groupes exclus\" Xfa requis.<br/>            Cette propriété a été introduite en raison de l'absence d'analogues des groupes exclus lors de la conversion de la représentation Xfa des formulaires <br/>            vers le standard.<br/>            Elle est fausse par défaut. |
| base_path | Obtient ou définit le chemin de base. |
