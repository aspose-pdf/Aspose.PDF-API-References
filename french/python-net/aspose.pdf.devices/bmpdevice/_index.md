## BmpDevice class

Représente un dispositif d'image qui aide à enregistrer les pages du document PDF au format bmp.

Le type BmpDevice expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| BmpDevice() | Initialise une nouvelle instance de la classe [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) avec la résolution par défaut. |
| BmpDevice(resolution) | Initialise une nouvelle instance de la classe BmpDevice |
| BmpDevice(width, height, resolution) | Initialise une nouvelle instance de la classe BmpDevice |
| BmpDevice(page_size, resolution) | Initialise une nouvelle instance de la classe BmpDevice |
| BmpDevice(width, height) | Initialise une nouvelle instance de la classe BmpDevice |
| BmpDevice(page_size) | Initialise une nouvelle instance de la classe BmpDevice |
## Propriétés
| Nom | Description |
| :- | :- |
| coordinate_type | Obtient ou définit le type de coordonnées de la page (Media/Crop boxes). La valeur CropBox est utilisée par défaut. |
| rendering_options | Obtient ou définit les options de rendu. |
| form_presentation_mode | Obtient ou définit le mode de présentation du formulaire. |
| resolution | Obtient la résolution de l'image. |
| largeur | Obtient la largeur de sortie de l'image. |
| hauteur | Obtient la hauteur de sortie de l'image. |
