## ColorDepth enumeration

Utilisé pour spécifier la valeur du paramètre transmise à un dispositif d'image TIFF.

## Members
| Nom du membre | Description |
| :- | :- |
| DEFAULT | Profondeur de couleur par défaut.<br/>            Une profondeur de 32 bits est utilisée par défaut. |
| FORMAT_8BPP | 8 bits par pixel. Égal |
| FORMAT_4BPP | 4 bits par pixel. Égal |
| FORMAT_1BPP | 1 bit par pixel. Égal |
