## PngDevice class

Représente le dispositif d'image qui aide à enregistrer les pages du document PDF au format PNG.

Le type PngDevice expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| PngDevice() | Initialise une nouvelle instance de la classe [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) avec la résolution par défaut. |
| PngDevice(resolution) | Initialise une nouvelle instance de la classe PngDevice |
| PngDevice(width, height, resolution) | Initialise une nouvelle instance de la classe PngDevice |
| PngDevice(page_size, resolution) | Initialise une nouvelle instance de la classe PngDevice |
| PngDevice(width, height) | Initialise une nouvelle instance de la classe PngDevice |
| PngDevice(page_size) | Initialise une nouvelle instance de la classe PngDevice |
## Propriétés
| Nom | Description |
| :- | :- |
| coordinate_type | Obtient ou définit le type de coordonnées de la page (Media/Crop boxes). La valeur CropBox est utilisée par défaut. |
| rendering_options | Obtient ou définit les options de rendu. |
| form_presentation_mode | Obtient ou définit le mode de présentation du formulaire. |
| resolution | Obtient la résolution de l'image. |
| largeur | Obtient la largeur de sortie de l'image. |
| hauteur | Obtient la hauteur de sortie de l'image. |
| transparent_background | Obtient ou définit si l'image a un arrière-plan transparent. |
## Méthodes
| Nom | Description |
| :- | :- |
| process(page, output) | Convertit la page en png et l'enregistre dans le flux de sortie. |
| process(page, output_file_name) | Convertit la page en png et l'enregistre dans le flux de sortie. |
