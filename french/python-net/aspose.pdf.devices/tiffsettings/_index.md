## Propriétés
| Nom | Description |
| :- | :- |
| marges | Obtient les marges. |
| skip_blank_pages | Obtient ou définit une valeur indiquant s'il faut ignorer les pages blanches. |
| compression | Obtient ou définit le type de compression. |
| profondeur | Obtient ou définit la profondeur de couleur. |
| forme | Obtient ou définit le type de forme. |
| luminosité | Obtient ou définit une limite de valeur de la transformation des couleurs en blanc et noir.<br/>            Ce paramètre peut être appliqué avec EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle ou ColorDepth.Format1bpp == 1 |
| coordinate_type | Obtient ou définit le type de coordonnées de page (boîtes Media/Crop). La valeur CropBox est utilisée par défaut. |
