## ThumbnailDevice class

Représente le dispositif d'image qui enregistre les pages du document PDF en image miniature.

Le type ThumbnailDevice expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| ThumbnailDevice() | Initialise une nouvelle instance de la classe [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) <br/>            avec la taille par défaut de l’image miniature (200x200 pixels). |
| ThumbnailDevice(width, height) | Initialise une nouvelle instance de la classe ThumbnailDevice |
## Propriétés
| Nom | Description |
| :- | :- |
| coordinate_type | Obtient ou définit le type de coordonnées de la page (Media/Crop boxes). La valeur CropBox est utilisée par défaut. |
| rendering_options | Obtient ou définit les options de rendu. |
| form_presentation_mode | Obtient ou définit le mode de présentation du formulaire. |
| resolution | Obtient la résolution de l'image. |
| largeur | Obtient la largeur de sortie de l'image. |
| hauteur | Obtient la hauteur de sortie de l'image. |
## Méthodes
| Nom | Description |
| :- | :- |
| process(page, output) | Convertit la page en image miniature png et l’enregistre dans le flux de sortie. |
| process(page, output_file_name) | Convertit la page en image miniature png et l’enregistre dans le flux de sortie. |
