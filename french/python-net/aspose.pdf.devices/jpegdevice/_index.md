## JpegDevice class

Représente un dispositif d'image qui aide à enregistrer les pages du document PDF au format jpeg.

Le type JpegDevice expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| JpegDevice() | Initialise une nouvelle instance de la classe [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) avec la résolution par défaut et la qualité maximale. |
| JpegDevice(resolution) | Initialise une nouvelle instance de la classe JpegDevice |
| JpegDevice(quality) | Initialise une nouvelle instance de la classe JpegDevice |
| JpegDevice(resolution, quality) | Initialise une nouvelle instance de la classe JpegDevice |
| JpegDevice(width, height) | Initialise une nouvelle instance de la classe JpegDevice |
| JpegDevice(page_size) | Initialise une nouvelle instance de la classe JpegDevice |
| JpegDevice(width, height, resolution) | Initialise une nouvelle instance de la classe JpegDevice |
| JpegDevice(page_size, resolution) | Initialise une nouvelle instance de la classe JpegDevice |
| JpegDevice(width, height, resolution, quality) | Initialise une nouvelle instance de la classe JpegDevice |
| JpegDevice(page_size, resolution, quality) | Initialise une nouvelle instance de la classe JpegDevice |
## Propriétés
| Nom | Description |
| :- | :- |
| coordinate_type | Obtient ou définit le type de coordonnées de la page (Media/Crop boxes). La valeur CropBox est utilisée par défaut. |
| rendering_options | Obtient ou définit les options de rendu. |
| form_presentation_mode | Obtient ou définit le mode de présentation du formulaire. |
| resolution | Obtient la résolution de l'image. |
| largeur | Obtient la largeur de sortie de l'image. |
| hauteur | Obtient la hauteur de sortie de l'image. |
## Méthodes
| Nom | Description |
| :- | :- |
| process(page, output) | Convertit la page en jpeg et l'enregistre dans le flux de sortie. |
| process(page, output_file_name) | Convertit la page en jpeg et l'enregistre dans le flux de sortie. |
