## CompressionType enumeration

Utilisé pour spécifier la valeur du paramètre transmise à un dispositif d'image TIFF.

## Members
| Nom du membre | Description |
| :- | :- |
| LZW | Spécifie le schéma de compression LZW. Peut être transmis à l'encodeur Tiff en tant que paramètre appartenant à la catégorie Compression. |
| CCITT4 | Spécifie le schéma de compression CCITT4. Peut être transmis à l'encodeur CCITT4 en tant que paramètre appartenant à la catégorie Compression. |
| CCITT3 | Spécifie le schéma de compression CCITT3. Peut être transmis à l'encodeur CCITT3 en tant que paramètre appartenant à la catégorie Compression. |
| RLE | Spécifie le schéma de compression RLE. Peut être transmis à l'encodeur RLE en tant que paramètre appartenant à la catégorie Compression. |
| NONE | Spécifie aucune compression. Peut être transmis à l'encodeur Tiff en tant que paramètre appartenant à la catégorie compression. |
