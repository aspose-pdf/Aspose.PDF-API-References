L'espace de noms aspose.pdf.devices fournit des classes utilisées pour représenter le document sous forme d'image(s) ou de texte brut. Ainsi le document peut être envoyé vers des périphériques textuels ou graphiques, ce qui permet d'obtenir une représentation textuelle ou graphique.

## Classes
| Classe | Description |
| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | Représente un dispositif d'image qui aide à enregistrer les pages du document PDF au format bmp. |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | Classe abstraite pour tous les types de dispositifs. Le dispositif est utilisé pour représenter le document PDF dans un certain format.<br/>            Par exemple, la page du document peut être représentée comme une image ou du texte. |
| [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) | Représente un dispositif d'image qui aide à enregistrer les pages du document PDF au format Dicom. |
| [DocumentDevice](/pdf/python-net/aspose.pdf.devices/documentdevice/) | Classe abstraite pour tous les dispositifs qui sont utilisés pour traiter l'ensemble du document PDF. |
| [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) | Représente un dispositif d'image qui aide à enregistrer les pages du document PDF au format emf. |
| [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) | Représente un dispositif d'image qui aide à enregistrer les pages du document PDF au format gif. |
| [ImageDevice](/pdf/python-net/aspose.pdf.devices/imagedevice/) | Une classe abstraite pour les dispositifs d'image. |
| [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) | Représente un dispositif d'image qui aide à enregistrer les pages du document PDF au format jpeg. |
| [Margins](/pdf/python-net/aspose.pdf.devices/margins/) | Cette classe représente les marges d'une image. |
| [PageDevice](/pdf/python-net/aspose.pdf.devices/pagedevice/) | Classe abstraite pour tous les appareils qui est utilisée pour traiter certaines pages du document PDF. |
| [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) | Représente le dispositif d'image qui aide à enregistrer les pages du document PDF au format PNG. |
| [Resolution](/pdf/python-net/aspose.pdf.devices/resolution/) | Représente une classe permettant de conserver la résolution d'image. |
| [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) | Représente une classe pour convertir les pages du document PDF en texte. |
| [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) | Représente le dispositif d'image qui enregistre les pages du document PDF en image miniature. |
| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | Cette classe aide à enregistrer les pages du document PDF, page par page, dans une seule image TIFF. |
| [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) | Cette classe représente les paramètres d'importation du PDF vers TIFF. |
