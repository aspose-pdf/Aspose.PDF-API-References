## ImageCompressionVersion enumeration

Décrit les versions de l'algorithme de compression d'image.

## Members
| Nom du membre | Description |
| :- | :- |
| STANDARD | Algorithme standard. Valeur par défaut. |
| FAST | Algorithme amélioré, plus rapide que le standard mais non applicable à tous les cas. |
| MIXED | Utilisez l'algorithme rapide lorsque c'est possible et le standard pour les autres cas. Peut être plus lent que "Fast" mais peut produire une meilleure compression. |
