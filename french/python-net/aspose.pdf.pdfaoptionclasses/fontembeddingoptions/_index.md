## FontEmbeddingOptions class

La norme PDF/A exige que toutes les polices soient incorporées dans le document.<br/>            Cette classe inclut des indicateurs pour les cas où il n'est pas possible d'incorporer certaines polices parce que cette police est absente <br/>            sur le PC de destination.
