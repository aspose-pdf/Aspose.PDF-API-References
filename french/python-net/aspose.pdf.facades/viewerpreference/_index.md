## ViewerPreference class

Décrit les préférences du visualiseur (mode page, mode page non plein écran, mise en page).

Le type ViewerPreference expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| ViewerPreference() | Initialise une nouvelle instance de la classe ViewerPreference |
## Propriétés
| Nom | Description |
| :- | :- |
| PAGE_MODE_USE_OC | Panneau de groupe de contenu optionnel visible. |
| DISPLAY_DOC_TITLE | Un indicateur spécifiant si la barre de titre de la fenêtre doit afficher le titre du document. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | Panneau de groupe de contenu optionnel visible. |
| PAGE_LAYOUT_SINGLE_PAGE | Affiche une page à la fois. |
| PAGE_LAYOUT_ONE_COLUMN | Affiche les pages en une colonne. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | Afficher les pages en deux colonnes, avec les pages impaires à droite |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | Afficher les pages en deux colonnes, avec les pages impaires à droite. |
| PAGE_MODE_USE_NONE | Ni le plan du document ni les vignettes ne sont visibles |
| PAGE_MODE_USE_OUTLINES | Plan du document visible. |
| PAGE_MODE_USE_THUMBS | Vignettes visibles. |
| PAGE_MODE_FULL_SCREEN | Mode plein écran, sans barre de menus, contrôles de fenêtre, ni aucune autre fenêtre visible. |
| PAGE_MODE_USE_ATTACHMENT | Mode page avec pièces jointes. |
| HIDE_TOOLBAR | Un indicateur spécifiant s’il faut masquer les barres d’outils du lecteur conforme lorsque le document est actif. |
| HIDE_MENUBAR | Un indicateur spécifiant s’il faut masquer la barre de menus du lecteur conforme lorsque le document est actif. |
| HIDE_WINDOW_UI | Un indicateur spécifiant s’il faut masquer les éléments de l’interface utilisateur dans la fenêtre du document (comme les barres de défilement et les contrôles de navigation), ne laissant affiché que le contenu du document. |
| FIT_WINDOW | Un indicateur spécifiant s’il faut redimensionner la fenêtre du document pour correspondre à la taille de la première page affichée. |
| CENTER_WINDOW | Un indicateur spécifiant s’il faut positionner la fenêtre du document au centre de l’écran. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | Ni le contour du document ni les images miniatures visibles. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | Plan du document visible. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | Images miniatures visibles |
| DIRECTION_L2R | Ordre de lecture du texte de gauche à droite. |
| DIRECTION_R2L | Ordre de lecture du texte de droite à gauche. |
| SIMPLEX | Imprimer recto uniquement. |
| DUPLEX_FLIP_SHORT_EDGE | Recto verso avec retournement sur le bord court de la feuille. |
| DUPLEX_FLIP_LONG_EDGE | Recto verso avec retournement sur le bord court de la feuille. |
