## StampInfo class

Classe représentant les informations du tampon.

Le type StampInfo expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| stamp_id | Obtient l'identifiant du tampon. |
| index_on_page | Obtient l'index du tampon sur la page. |
| stamp_type | Obtient le type de tampon (image / formulaire). |
| rectangle | Obtient le rectangle où le tampon est placé. |
| image | Obtient l'image du tampon. Peut être nul si le tampon ne contient pas d'images (par exemple pour un tampon texte). |
| form | Obtient le XForm du tampon. |
| text | Obtient le texte du tampon. |
| visible | Obtient la visibilité du tampon. Si false alors le tampon est masqué (avec HideStampById). Le tampon masqué peut être restauré avec ShowStampById. |
