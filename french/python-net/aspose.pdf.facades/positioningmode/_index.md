## PositioningMode enumeration

Définit le mode de positionnement.<br/>            Les valeurs possibles incluent Legacy (compatibilité descendante) et <br/>            Current (méthode mise à jour de calcul de la position du texte)

## Members
| Nom du membre | Description |
| :- | :- |
| LEGACY | Positionnement du texte hérité |
| MODERN_LINE_SPACING | Espacement des lignes mis à jour, le calcul de la position verticale est effectué selon les anciennes règles <br/>            (c.-à-d. le texte est positionné par rapport au coin inférieur gauche du rectangle spécifié) |
| CURRENT | L'espacement des lignes mis à jour et le calcul de la position verticale sont effectués en fonction du coin supérieur gauche plutôt que du coin inférieur gauche. |
