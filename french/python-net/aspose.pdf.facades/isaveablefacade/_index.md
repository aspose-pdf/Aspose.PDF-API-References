## ISaveableFacade class

Interface de façade qui définit les méthodes communes à toutes les façades enregistrables.

Le type ISaveableFacade expose les membres suivants :
## Méthodes
| Nom | Description |
| :- | :- |
| save(dest_file) | Enregistre le document PDF résultant dans un fichier. |
| save(dest_stream) | Enregistre le document PDF résultant dans un flux. |
| bind_pdf(src_file) | Lie le document PDF pour l'édition. |
| bind_pdf(src_stream) | Lie le document PDF pour l'édition. |
| bind_pdf(src_doc) | Lie le document PDF pour l'édition. |
| close() | Libère toutes les ressources associées à la façade actuelle. |
