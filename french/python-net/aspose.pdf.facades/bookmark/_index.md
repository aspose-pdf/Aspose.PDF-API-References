## Bookmark class

Représente un signet.

Le type Bookmark expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Bookmark() | Initialise une nouvelle instance de la classe Bookmark |
## Propriétés
| Nom | Description |
| :- | :- |
| action | Obtient ou définit l'action liée au signet.<br/>            Si PageNumber est présent, l'action ne peut pas être spécifiée.<br/>            Le type d'action comprend : "GoTo", "GoToR", "Launch", "Named". |
| bold_flag | Obtient ou définit le drapeau gras du titre du signet. |
| child_item | Obtient ou définit les enfants du signet. |
| child_items | Obtient ou définit les enfants du signet. |
| destination | Obtient ou définit la page de destination du signet. Requis si l'action est définie sur string.Empty. |
| italic_flag | Obtient ou définit le drapeau italique du titre du signet. |
| niveau | Obtient ou définit le niveau hiérarchique du signet. |
| page_display | Obtient ou définit le type d'affichage de la page de destination du signet. |
| page_display_bottom | Obtient ou définit la coordonnée inférieure de l'affichage de la page. |
| page_display_left | Obtient ou définit la coordonnée gauche de l'affichage de la page. |
| page_display_right | Obtient ou définit la coordonnée droite de l'affichage de la page. |
| page_display_top | Obtient ou définit la coordonnée supérieure de l'affichage de la page. |
| page_display_zoom | Obtient ou définit le facteur de zoom de l'affichage de la page. |
| page_number | Obtient ou définit le numéro de la page de destination du signet. |
| remote_file | Obtient ou définit le fichier (chemin) requis pour l'action "GoToR" du signet. |
| title | Obtient ou définit le titre du signet. |
| title_color | Obtient ou définit la couleur du titre du signet. |
| ouvrir | Obtient ou définit l'état du signet (ouvert, fermé). |
