## KeySize enumeration

Définit différentes tailles de clé pouvant être utilisées pour chiffrer des documents pdf.

## Members
| Nom du membre | Description |
| :- | :- |
| X40 | Clé de 40 bits. Cette taille de clé est utilisée avec l'algorithme RC4 et offre un faible niveau de sécurité. <br/>            Néanmoins, les anciennes versions de documents PDF ne peuvent être chiffrées qu'avec de telles clés (v. 1.3 et antérieures); |
| X128 | Clé de 128 bits. Les algorithmes RC4 et AES peuvent tous deux utiliser cette taille de clé. |
| X256 | Clé de 256 bits. Cette taille de clé ne peut être utilisée qu'avec AES et est reconnue par les dernières versions d'Adobe Reader (à partir de la v.9). |
