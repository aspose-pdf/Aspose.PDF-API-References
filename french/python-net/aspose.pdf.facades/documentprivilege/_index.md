## DocumentPrivilege class

Représente les privilèges d'accès à un fichier Pdf. Voir [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             Il existe 4 manières d'utiliser cette classe :<br/>             1. Utiliser directement un privilège prédéfini.<br/>             2. Partir d'un privilège prédéfini et modifier certaines permissions spécifiques.<br/>             3. Partir d'un privilège prédéfini et modifier une combinaison spécifique de permissions Adobe Professional.<br/>             4. Mélange la way2 et la way3.

Le type DocumentPrivilege expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| allow_print | Définit la permission qui autorise l’impression ou non. <br/>            true autorise et false interdit. |
| allow_degraded_printing | Définit la permission qui autorise l’impression dégradée ou non. <br/>            true autorise et false interdit. |
| allow_modify_contents | Définit la permission qui autorise la modification du contenu ou non. <br/>            true autorise et false interdit. |
| allow_copy | Définit la permission qui autorise la copie ou non. <br/>            true autorise et false interdit. |
| allow_modify_annotations | Définit la permission qui autorise la modification des annotations ou non. <br/>            true autorise et false interdit. |
| allow_fill_in | Définit la permission qui autorise le remplissage des formulaires ou non. <br/>            true autorise et false interdit. |
| allow_screen_readers | Définit la permission qui autorise les lecteurs d’écran ou non. <br/>            true autorise et false interdit. |
| allow_assembly | Définit la permission qui autorise l’assemblage ou non. <br/>            true autorise et false interdit. |
| degraded_printing | Autorise l’impression dégradée. |
| print | Autorise l’impression du fichier. |
| modify_contents | Autorise la modification du fichier. |
| copy | Autorise la copie du fichier. |
| modify_annotations | Autorise la modification des annotations du fichier. |
| fill_in | Autorise le remplissage des formulaires dans le fichier. |
| screen_readers | Autorise la lecture uniquement à l'écran. |
| assembly | Autorise l'assemblage du fichier. |
| allow_all | Tout autorisé. |
| forbid_all | Tout interdit. |
