## LineInfo class

Représente les informations d'une ligne.

Le type LineInfo expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| LineInfo() | Initialise une nouvelle instance de la classe LineInfo |
## Propriétés
| Nom | Description |
| :- | :- |
| vertice_coordinate | Obtient ou définit un tableau de nombres représentant les coordonnées horizontales et verticales alternées, respectivement, de chaque sommet. |
| line_color | Obtient ou définit la couleur d'une ligne. |
| line_width | Obtient ou définit la largeur d'une ligne. |
| visibility | Obtient ou définit la visibilité d'une ligne. |
| line_dash_pattern | Obtient ou définit le motif de tirets d'une ligne. |
| border_style | Obtient ou définit le style de bordure d'une ligne, 0 représente plein, 1 représente en pointillé, 2 représente beleved, 3 représente insert, 4 représente souligné. |
