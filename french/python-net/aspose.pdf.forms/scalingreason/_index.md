## ScalingReason enumeration

Les circonstances dans lesquelles l'icône doit être mise à l'échelle à l'intérieur du rectangle d'annotation.

## Members
| Nom du membre | Description |
| :- | :- |
| ALWAYS | Toujours mettre à l'échelle. |
| ICON_IS_BIGGER | Mettez à l'échelle uniquement lorsque l'icône est plus grande que le rectangle d'annotation. |
| ICON_IS_SMALLER | Mettez à l'échelle uniquement lorsque l'icône est plus petite que le rectangle d'annotation. |
| NEVER | Ne jamais mettre à l'échelle. |
