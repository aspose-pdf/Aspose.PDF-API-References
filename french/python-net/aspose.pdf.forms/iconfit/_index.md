## IconFit class

Décrit comment l'icône de l'annotation widget doit être affichée à l'intérieur de son rectangle d'annotation.

Le type IconFit expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| scaling_reason | Obtient ou définit la raison de mise à l'échelle. |
| scaling_mode | Le type de mise à l'échelle qui doit être utilisé.        /// |
| leftover_left | Obtient ou définit l'espace à allouer à gauche de l'icône. |
| leftover_bottom | Obtient ou définit l'espace à allouer en bas de l'icône. |
| spread_on_border | Si vrai, indique que l'apparence du bouton doit être mise à l'échelle pour s'adapter entièrement aux limites de l'annotation sans tenir compte de la largeur du trait de la bordure. |
## Méthodes
| Nom | Description |
| :- | :- |
| name_to_scaling_reason(reason) | Convertit le nom de la raison de mise à l'échelle en objet ScalingReason. |
| scaling_reason_to_name(reason) | Convertit l'objet de raison de mise à l'échelle en nom. |
| name_to_scaling_mode(mode) | Convertit le nom du mode de mise à l'échelle en objet ScalingMode. |
| scaling_mode_to_name(mode) | Convertit l'objet du mode de mise à l'échelle en nom. |
