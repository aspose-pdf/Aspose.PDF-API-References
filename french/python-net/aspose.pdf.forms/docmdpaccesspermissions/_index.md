## DocMDPAccessPermissions enumeration

Les autorisations d'accès accordées pour ce document.<br/>            Valeurs valides :<br/>            1 - Aucun changement du document n'est autorisé ; toute modification du document invalide la signature.<br/>            2 - Les changements autorisés sont le remplissage des formulaires, l'instanciation de modèles de page et la signature ; d'autres modifications invalident la signature.<br/>            3 - Les changements autorisés sont les mêmes que pour 2, ainsi que la création, la suppression et la modification d'annotations ; d'autres modifications invalident la signature.

## Members
| Nom du membre | Description |
| :- | :- |
| NO_CHANGES | 1 - Aucun changement du document n'est autorisé ; toute modification du document invalide la signature. |
| FILLING_IN_FORMS | 2 - Les changements autorisés sont le remplissage des formulaires, l'instanciation de modèles de pages et la signature ; les autres modifications invalident la signature. |
| ANNOTATION_MODIFICATION | 3 - Les changements autorisés sont les mêmes que pour 2, ainsi que la création, la suppression et la modification d'annotations ; les autres modifications invalident la signature. |
