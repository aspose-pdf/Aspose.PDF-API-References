## Symbology enumeration

Une symbologie (code-barres) définit les détails techniques d'un type particulier de code-barres :<br/>            la largeur des barres, le jeu de caractères, la méthode d'encodage, les spécifications du checksum, etc.

## Members
| Nom du membre | Description |
| :- | :- |
| PDF417 | Une symbologie 2D à plusieurs rangées, de longueur variable, avec une grande capacité de données et une capacité de correction d'erreurs. |
| QR_CODE | Le code QR (abréviation de Quick Response) est un code-barres matriciel spécifique (code 2D), <br/>            lisible par les lecteurs de codes QR dédiés et les téléphones à caméra. |
| DATA_MATRIX | Une symbologie matricielle 2D composée de modules carrés noirs et blancs disposés en forme carrée ou <br/>            rectangulaire. |
