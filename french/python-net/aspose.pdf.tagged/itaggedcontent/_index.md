## ITaggedContent class

Représente l'interface pour travailler avec le contenu TaggedPdf du document.

Le type ITaggedContent expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| structure_text_state | Obtenir les paramètres [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) pour l'ensemble du document. |
| struct_tree_root_element | Obtient le [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/) du document PDF. |
| root_element | Obtient l'élément racine [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) de la structure logique du document PDF. |
