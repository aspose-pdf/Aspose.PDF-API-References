## BasicSetColorOperator class

Classe de base pour les opérateurs set color.

Le type BasicSetColorOperator expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| index | Indice de l'opérateur dans la liste des opérateurs de la page. |
| r | Obtient le composant rouge de la couleur |
| g | Obtient le composant vert de la couleur |
| b | Obtient le composant rouge de la couleur |
| c | Obtient le composant cyan de la couleur CMJN. |
| m | Obtient le composant magenta de la couleur CMJN. |
| y | Obtient le composant jaune de la couleur CMJN. |
| k | Obtient le composant noir de la couleur CMJN. |
| grey | Obtient le composant noir de la couleur grise. |
| couleur | Obtient le tableau des composants de couleur. |
## Méthodes
| Nom | Description |
| :- | :- |
| accept(visitor) | Accepte le visiteur IOperatorSelector qui fournit le traitement des opérateurs. |
| is_text_show_operator(op) | Détermine si l'opérateur est celui responsable de la sortie du texte (Tj, TJ, etc.) |
| get_color() | Renvoie la couleur spécifiée par l'opérateur. |
