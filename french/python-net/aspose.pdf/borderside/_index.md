## BorderSide enumeration

Énumère les côtés de la bordure.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Pas de bordure. |
| GAUCHE | Bordure gauche. |
| TOP | Bordure supérieure. |
| DROITE | Bordure droite. |
| BOTTOM | Bordure inférieure. |
| ALL | Toutes les bordures des côtés. Il a le même sens que "Box" et sera remplacé par "Box" dans un an. Donc, veuillez utiliser "Box" si possible. |
| BOX | Bordures des quatre côtés. |
