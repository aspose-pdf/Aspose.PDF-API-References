## Cell class

Représente une cellule de la ligne du tableau.

Le type Cell expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Cell(rect) | Initialise une nouvelle instance de la classe Cell |
| Cell() | Initialise une nouvelle instance de la classe Cell. |
## Propriétés
| Nom | Description |
| :- | :- |
| is_no_border | Obtient ou définit si la cellule possède une bordure. |
| marge | Obtient ou définit le remplissage. |
| bordure | Obtient ou définit la bordure. |
| background_color | Obtient ou définit la couleur d’arrière‑plan. |
| background_image_file | Obtient ou définit le fichier d'image d'arrière-plan. |
| background_image | Obtient ou définit l'image d'arrière-plan |
| alignement | Obtient ou définit l'alignement. |
| default_cell_text_state | Obtient ou définit l'état de texte par défaut de la cellule. |
| is_override_by_fragment | Définit que la propriété TextState de la cellule est remplacée par la propriété TextState de TextFragment. |
| paragraphs | Obtient ou définit le texte formaté de la cellule. |
| is_word_wrapped | Obtient ou définit le renvoi à la ligne du texte de la cellule. |
| vertical_alignment | Obtient ou définit l'alignement vertical. |
| col_span | Obtient ou définit l'étendue de colonne. |
| row_span | Obtient ou définit l'étendue de ligne. |
| largeur | Obtient ou définit la largeur de la colonne. |
