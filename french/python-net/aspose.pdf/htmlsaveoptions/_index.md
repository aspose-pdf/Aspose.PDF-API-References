## HtmlSaveOptions class

Options d'enregistrement pour l'exportation au format Html

Le type HtmlSaveOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| HtmlSaveOptions() | Initialise une nouvelle instance de la classe [HtmlSaveOptions](/pdf/python-net/aspose.pdf/htmlsaveoptions/). |
| HtmlSaveOptions(document_type) | Initialise une nouvelle instance de la classe HtmlSaveOptions |
| HtmlSaveOptions(fixed_layout) | Initialise une nouvelle instance de la classe HtmlSaveOptions |
| HtmlSaveOptions(document_type, fixed_layout) | Initialise une nouvelle instance de la classe HtmlSaveOptions |
## Propriétés
| Nom | Description |
| :- | :- |
| warning_handler | Rappel pour gérer les avertissements générés. <br/>            Le WarningHandler renvoie l'élément d'énumération ReturnAction spécifiant soit Continue, soit Abort. <br/>            Continue est l'action par défaut et l'opération d'enregistrement se poursuit, cependant l'utilisateur peut également renvoyer Abort, auquel cas l'opération d'enregistrement doit s'arrêter. |
| save_format | Format d'enregistrement des données. |
| close_response | Obtient ou définit la valeur booléenne indiquant si l'objet Response sera fermé après que le document ait été enregistré dans la réponse. |
| extract_ocr_sublayer_only | Aucun |
| try_merge_adjacent_same_background_images | Aucun |
| document_type | Obtient ou définit le [HtmlDocumentType](/pdf/python-net/aspose.pdf/htmldocumenttype/). |
| compress_svg_graphics_if_any | Obtient ou définit le drapeau qui indique si<br/>            les graphiques SVG trouvés (le cas échéant) seront compressés (zippés) <br/>            au format SVGZ lors de l'enregistrement |
| split_css_into_pages | Lorsque le mode multipage est sélectionné (c’est‑à‑dire que 'SplitIntoPages' est 'true'), <br/>            cet attribut définit s’il faut créer un fichier CSS séparé<br/>            pour chaque page HTML résultante.<br/>            Par défaut, cet attribut est false, donc un seul CSS commun volumineux sera créé pour toutes les pages générées. La taille totale de tous<br/>            les CSS générés dans ce mode (un CSS par page) est généralement<br/>            bien supérieure à la taille d’un seul gros fichier CSS, car dans le premier cas <br/>            les classes CSS sont dupliquées dans plusieurs fichiers CSS pour chaque page.<br/>            Ainsi, ce paramètre ne doit être utilisé que lorsque vous êtes intéressé<br/>            par le traitement futur de chaque page HTML de façon indépendante, et que la taille<br/>            du CSS de chaque page prise séparément est le problème le plus critique. |
| split_into_pages | Obtient ou définit le drapeau qui indique si chaque page du document source <br/>            sera convertie en son propre document HTML cible, <br/>            c’est‑à‑dire si le HTML résultant sera divisé en plusieurs pages HTML. |
| explicit_list_of_saved_pages | Avec cette propriété, vous pouvez définir explicitement <br/>            quelles pages du document doivent être converties.<br/>            Les pages de cette liste doivent être numérotées à partir de 1. C’est‑à‑dire <br/>            que les numéros valides doivent provenir de la plage (1...[NumberOfPagesInConvertedDocument])<br/>            L’ordre d’apparition des pages dans cette liste n’affecte pas leur<br/>            ordre dans les pages HTML résultantes – les pages résultantes seront toujours dans l’ordre dans lequel elles sont <br/>            présentes dans le PDF source.<br/>            Si cette liste est null (comme c’est le cas par défaut), toutes les pages seront converties.<br/>            Si un numéro de page de cette liste dépasse la plage des pages présentes (1-[amountOfPagesInDocument])<br/>            une exception sera levée. |
| fixed_layout | Obtient ou définit une valeur indiquant si le HTML est créé avec une mise en page fixe. |
| image_resolution | Obtient ou définit la résolution pour le rendu d’image. |
| default_font_name | Spécifie le nom d’une police installée qui est utilisée pour remplacer<br/>            toute police du document qui n’est pas incorporée et qui n’est pas installée dans le système. <br/>            Si null, la police de substitution par défaut est utilisée. |
| batch_size | Définit la taille du lot si la conversion par lots est applicable<br/>            à la paire de formats source et destination. |
| font_sources | Sources de polices des polices préenregistrées. |
| additional_margin_width_in_points | Si l'attribut 'SplitOnPages=false', alors l'ensemble du HTML représentant toutes les pages PDF d'entrée ne sera<br/>            pas découpé en différentes pages HTML, mais sera placé dans un seul grand fichier HTML résultat.<br/>            Cependant chaque page PDF source sera représentée par sa propre <br/>            zone rectangulaire en HTML (si nécessaire, ces zones peuvent être bordées pour montrer les bords du papier de la page<br/>            avec l'attribut spécial 'PageBorderIfAny'.<br/>            Ce paramètre définit la largeur de la marge qui sera forcée autour de ces zones HTML de sortie<br/>            qui représentent les pages du document PDF source. En essence, il définit l'intervalle garanti entre<br/>            les représentations HTML des pages "paper" du PDF dans ce mode de conversion. |
| use_z_order | Si l'attribut UseZORder est défini sur true, les graphiques et le texte sont ajoutés au document HTML résultant<br/>            selon l'ordre Z du document PDF original. Si cet attribut est false, tous les graphiques sont placés<br/>            en une seule couche, ce qui peut entraîner des effets indésirables pour les objets superposés. |
| convert_marked_content_to_layers | Si l'attribut ConvertMarkedContentToLayers est défini sur true, alors tous les éléments à l'intérieur d'un contenu PDF marqué<br/>            (couche) seront placés dans une div HTML avec l'attribut "data-pdflayer" spécifiant le nom de la couche.<br/>            Ce nom de couche sera extrait des propriétés optionnelles du contenu PDF marqué.<br/>            Si cet attribut est false (par défaut), aucune couche ne sera créée à partir du contenu PDF marqué. |
| minimal_line_width | Cet attribut définit la largeur minimale d'une ligne de chemin graphique.<br/>            Si l'épaisseur de la ligne est inférieure à 1 px, Adobe Acrobat l'arrondit à cette valeur. Ainsi, cet attribut peut<br/>            être utilisé pour émuler ce comportement dans les navigateurs HTML. |
| prevent_glyphs_grouping | Cet attribut active le mode où les glyphes de texte ne seront pas regroupés en mots et chaînes<br/>            Ce mode permet de conserver une précision maximale lors du positionnement des glyphes sur la page et peut être<br/>            utilisé pour la conversion de documents contenant des notes de musique ou des glyphes qui doivent être placés séparément les uns des autres.<br/>            Ce paramètre ne sera appliqué au document que lorsque la valeur de l'attribut FixedLayout est true. |
| simple_textbox_mode_grouping | Cet attribut spécifie un regroupement séquentiel des glyphes et des mots en chaînes<br/>            Par exemple, les balises et les mots ont un ordre différent dans le HTML converti et vous souhaitez qu'ils correspondent.<br/>            Ce paramètre ne sera appliqué au document que lorsque la valeur de l'attribut FixedLayout est true. |
| flow_layout_paragraph_full_width | Cet attribut spécifie le texte de paragraphe en pleine largeur pour le mode Flow, FixedLayout = false |
| render_text_as_image | Si l'attribut RenderTextAsImage est défini sur true, le texte de la source devient une image dans le HTML.<br/>            Peut être utile pour rendre le texte non sélectionnable<br/>            ou si le texte HTML n'est pas rendu correctement. |
| save_full_font | Indique que la police complète sera enregistrée, ne prend en charge que les polices True Type.<br/>            Par défaut, SaveFullFont = false et le convertisseur enregistre le sous-ensemble de la police initiale<br/>            nécessaire pour afficher le texte du document. |
| antialiasing_processing | Ce paramètre définit les mesures d'anticrénelage requises lors de la conversion d'images d'arrière-plan composées du PDF vers HTML |
| save_transparent_texts | Le PDF peut contenir des textes transparents qui peuvent être sélectionnés dans le presse-papiers (cela se produit généralement lorsque le document contient des images et des textes OCR extraits).<br/>            Ce paramètre indique au convertisseur si nous devons enregistrer ces textes comme des textes transparents<br/>            sélectionnables dans le HTML résultant. |
| save_shadowed_texts_as_transparent_texts | Le PDF peut contenir des textes masqués par d'autres éléments (p. ex. par des images) mais <br/>            peuvent être sélectionnés dans le presse‑papier dans Acrobat Reader (cela se produit généralement lorsque le document contient des images et des textes OCR extraits).<br/>            Ce paramètre indique au convertisseur si nous devons enregistrer ces textes comme des textes transparents<br/>            sélectionnables dans le HTML résultant afin d'imiter le comportement d'Acrobat Reader (sinon ces textes sont généralement enregistrés comme cachés, non disponibles pour la copie dans le presse‑papier). |
| font_saving_mode | Définit le mode d'enregistrement des polices qui sera utilisé lors de la sauvegarde du PDF dans le format souhaité. |
| page_border_if_any | Cet attribut représente un ensemble de paramètres utilisés pour dessiner la bordure (le cas échéant)<br/>            dans le document HTML résultant autour de la zone représentant la page PDF source.<br/>            En essence, il concerne l'affichage des bords du papier de la page,<br/>            et non la bordure de page référencée dans la page PDF elle‑même. |
| page_margin_if_any | Cet attribut représente un ensemble de marges de page supplémentaires (le cas échéant)<br/>            dans le document HTML résultant autour de la zone représentant la page PDF source. |
| letters_positioning_method | Définit le mode de positionnement des lettres dans les mots dans le HTML résultant. |
| exclude_font_name_list | Liste des noms de polices intégrées au PDF qui ne seront pas intégrées dans le HTML. |
| special_folder_for_svg_images | Obtient ou définit le chemin du répertoire dans lequel seuls les images SVG doivent être enregistrées si elles <br/>            sont rencontrées lors de la sauvegarde du document au format HTML. Si le paramètre est vide ou nul<br/>            alors les fichiers SVG (le cas échéant) seront enregistrés avec les autres fichiers image (à proximité du fichier de sortie)<br/>            ou dans un dossier spécial pour les images (si celui‑ci est spécifié dans l'option SpecialImagesFolderIfAny).<br/>            Cela n'affecte rien si la propriété CustomImageSavingStrategy<br/>            a été utilisée avec succès pour traiter le fichier image concerné. |
| special_folder_for_all_images | Obtient ou définit le chemin du répertoire dans lequel toutes les images doivent être enregistrées si elles <br/>            sont rencontrées lors de la sauvegarde du document au format HTML. Si le paramètre est vide ou nul<br/>            alors les fichiers image (le cas échéant) seront enregistrés avec les autres fichiers liés au HTML<br/>            Cela n'affecte rien si la propriété CustomImageSavingStrategy<br/>            a été utilisée avec succès pour traiter le fichier image concerné. |
| css_class_names_prefix | Lorsque le convertisseur PDFtoHTML génère les CSS résultants, les noms de classes CSS<br/>            (quelque chose comme ".stl_01 {}" ... ".stl_NN {}") sont générés<br/>            et utilisés dans le CSS résultat. Cette propriété permet de définir de force le préfixe des noms de classe<br/>            Par exemple, si vous souhaitez que tous les noms de classe commencent par 'my_prefix_'<br/>            (c’est‑à‑dire quelque chose comme 'my_prefix_1' ... 'my_prefix_NNN'), <br/>            alors attribuez simplement 'my_prefix_' à cette propriété avant la conversion.<br/>            Si cette propriété reste inchangée (c’est‑à‑dire que la valeur null est conservée), alors<br/>            le convertisseur générera lui‑même les noms de classe <br/>            (ce sera quelque chose comme ".stl_01 {}" ... ".stl_NN {}"). |
| parts_embedding_mode | Il définit si les fichiers référencés (HTML, polices, images, CSS) <br/>            seront incorporés dans le fichier HTML principal ou seront générés comme des entités binaires séparées. |
| html_markup_generation_mode | Parfois, des exigences spécifiques concernant la génération du balisage HTML sont présentes.<br/>            Ce paramètre définit les modes de préparation du HTML qui peuvent être utilisés<br/>            lors de la conversion du PDF en HTML afin de répondre à ces exigences spécifiques. |
| raster_images_saving_mode | Le PDF converti peut contenir des images raster<br/>            Ce paramètre définit comment elles doivent être traitées<br/>            lors de la conversion du PDF en HTML. |
| remove_empty_areas_on_top_and_bottom | Définit si dans le HTML créé les zones vides supérieures et inférieures seront supprimées lorsqu'elles ne contiennent aucun contenu (le cas échéant). |
| font_encoding_strategy | Définit une règle spéciale d'encodage pour ajuster le décodage PDF du document actuel. |
| pages_flow_type_depends_on_viewers_screen_size | Si l'attribut 'SplitOnPages=false', alors tout le HTML représentant toutes les pages PDF d'entrée sera <br/>            placé dans un seul grand fichier HTML de résultat. <br/>            Ce drapeau définit si le HTML de résultat sera généré de telle manière<br/>            que le flux des zones représentant les pages PDF dans le HTML de résultat dépendra<br/>            de la résolution d'écran du visualiseur. <br/>            Supposons que la largeur de l'écran du côté du visualiseur soit suffisante pour placer 2 ou plus pages côte à côte en direction horizontale. Si ce drapeau est défini sur true, alors cette opportunité<br/>            sera utilisée (autant de pages seront affichées en direction horizontale les unes à côté des autres<br/>            autant que possible, puis le groupe horizontal suivant de pages sera affiché sous le premier).<br/>            Sinon, les pages s'écouleront de la manière suivante : la page suivante se place toujours sous la précédente. |
| try_save_text_underlining_and_strikeouting_in_css | Le PDF lui‑-même ne contient pas de marqueurs de soulignement pour les textes. Il les émule avec une ligne placée sous le texte.<br/>            Cette option permet au convertisseur d'essayer de deviner qu'une ligne est le soulignement d'un texte<br/>            et d'insérer cette information dans le CSS au lieu de dessiner le soulignement graphiquement. |
