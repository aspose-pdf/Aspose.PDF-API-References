## ColumnInfo class

Cette classe représente les informations de colonnes.

Le type ColumnInfo expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| ColumnInfo() | Initialise une nouvelle instance de la classe ColumnInfo |
## Propriétés
| Nom | Description |
| :- | :- |
| column_widths | Obtient ou définit une chaîne qui contient la largeur des colonnes. <br/>            La valeur de chaque colonne doit être séparée par un espace. L'unité par défaut est le point,<br/>            mais le cm, le pouce et le pourcentage de la largeur disponible sont également pris en charge.<br/>            Par exemple,"120 2.5cm 1.5inch" |
| column_spacing | Obtient ou définit une chaîne qui contient l'espacement entre les colonnes. <br/>            La valeur de chaque espacement doit être séparée par un espace. L'unité par défaut est le point,<br/>            mais le cm et le pouce sont également pris en charge. Par exemple,"120 2.5cm 1.5inch". |
| column_count | Obtient ou définit une valeur int qui indique le nombre de colonnes. |
