## PdfASymbolicFontEncodingStrategy class

Cette classe décrit les règles qui peuvent être utilisées pour ajuster le processus de copie des données d’encodage dans les cas<br/> où la police TrueType symbolique possède plus d’un encodage.<br/> Certains documents PDF après conversion au format PDF/A peuvent générer l’erreur <br/> "More than one encoding in symbolic TrueType font's cmap". <br/> Quelle est la raison de cette erreur ? Toutes les polices TrueType symboliques possèdent une table spéciale "cmap"<br/> dans leurs données internes. Cette table associe les codes de caractères aux indices de glyphes. <br/> Et cette table peut contenir différentes sous‑tables d’encodage qui<br/> décrivent les encodages utilisés. Voir des informations avancées sur les tables cmap à<br/> https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6cmap.html.<br/> Habituellement la table cmap contient plusieurs sous‑tables d’encodage, mais la norme PDF/A exige<br/> qu’une seule sous‑table d’encodage (3,0) soit conservée pour cette police dans le document PDF/A. <br/> Et la question clé ici – quelles données doivent être prises des autres sous‑tables pour être copiées dans<br/> la table d’encodage de destination (3,0) ? La majorité des polices ont des tables cmap « well‑formed » où<br/> chaque sous‑table d’encodage est entièrement cohérente avec les autres sous‑tables. Mais certaines polices<br/> ont des tables cmap avec des collisions – par exemple, une sous‑table possède l’indice de glyphe <br/> 100 pour le caractère Unicode 100, tandis qu’une autre sous‑table possède l’indice de glyphe 200 pour le même Unicode 100.<br/> Pour résoudre ces problèmes, une stratégie spéciale est nécessaire. <br/> Par défaut, la stratégie suivante est utilisée : <br/> la sous‑table mac(1,0) est recherchée. Si cette table est trouvée, seules ces données sont utilisées pour remplir la table de destination<br/> (3,0). Si la sous‑table mac n’est pas trouvée, alors toutes les sous‑tables sauf (3,0) sont parcourues <br/> et utilisées pour copier les données dans la sous‑table de destination (3,0). De plus, le mappage pour chaque unicode (unicode, indice de glyphe)<br/> est copié dans la table de destination uniquement si la table de destination ne contient pas cet unicode à ce moment‑là. <br/> Ainsi, par exemple, si la première sous‑table possède l’indice de glyphe 100 pour l’unicode 100, et que la sous‑table suivante possède le<br/> indice de glyphe 200 pour le même unicode 100, seules les données de la première sous‑table (unicode=100, indice de glyphe = 100) seront copiées. <br/> Ainsi chaque sous‑table précédente a la priorité sur la suivante. <br/> Les propriétés de cette classe [PdfASymbolicFontEncodingStrategy](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) aident à ajuster le comportement par défaut. <br/> Si la propriété [preferred_cmap_encoding_table](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/) est définie, alors la sous‑table pertinente sera utilisée en priorité par rapport à la sous‑table mac(1,0). La valeur 'MacTable' de l’énumération [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/) n’a aucun sens dans ce cas, car elle <br/> pointe sur la même sous‑table mac (1,0) qui sera utilisée par défaut. <br/> La propriété [None](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) ignore toutes les priorités pour toute sous‑table.<br/> Si cette propriété est définie, alors seules les sous‑tables de la file d’attente déclarée seront utilisées dans l’ordre spécifié.<br/> Si les sous‑tables spécifiées ne sont pas trouvées, alors l’itération par défaut de toutes les sous‑tables et la stratégie de copie décrite ci‑dessus<br/> seront utilisées.<br/> L’objet [QueueItem](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy/queueitem/) spécifie la sous‑table d’encodage utilisée. Cette sous‑table peut être définie<br/> via une combinaison de membres (PlatformID, PlatformSpecificId) ou via l’énumération [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/).
