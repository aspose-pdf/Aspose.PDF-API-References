## ProgressEventType enumeration

Cette énumération décrit les types d'événements de progression possibles<br/>            qui peuvent survenir pendant la conversion

## Members
| Nom du membre | Description |
| :- | :- |
| TOTAL_PROGRESS | signifie que l'événement survenu informe du progrès total de la conversion |
| SOURCE_PAGE_ANALYSED | signifie que l'événement survenu informe de la fin de l'analyse d'une des pages avant la conversion |
| RESULT_PAGE_CREATED | signifie que l'événement survenu informe de la création d'une page de résultat avant l'exportation physique |
| RESULT_PAGE_SAVED | signifie que l'événement survenu informe de l'enregistrement terminé d'une page de résultat |
