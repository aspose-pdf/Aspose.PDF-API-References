## PasswordType enumeration

Cette énumération représente les types de mots de passe connus utilisés pour les documents PDF protégés par mot de passe.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Le document PDF n'est pas protégé par mot de passe. |
| USER | Le document PDF a été ouvert en utilisant le mot de passe d'ouverture du document (accès restreint). |
| OWNER | Le document PDF a été ouvert en utilisant le mot de passe de modification des autorisations (accès complet). |
| INACCESSIBLE | Le document PDF est protégé par mot de passe mais les mots de passe utilisateur et propriétaire ne sont pas vides et <br/>            aucun des mots de passe n'a été défini ou le mot de passe fourni était incorrect. Il est donc impossible de déduire le type du mot de passe. |
