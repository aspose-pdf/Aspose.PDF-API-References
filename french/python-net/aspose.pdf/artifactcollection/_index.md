## ArtifactCollection class

Classe représentant la collection d'artefacts.

Le type ArtifactCollection expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| is_synchronized | Cet objet est-il synchronisé ? |
| sync_root | Obtient l'objet de synchronisation de la collection. |
## Indexer
| Nom | Description |
| :- | :- |
| [index] | Obtient l'artifact par indice. L'indice commence à 1. |
## Méthodes
| Nom | Description |
| :- | :- |
| delete(artifact) | Supprime l'artifact spécifié. |
| delete(index) | Supprime l'artifact par son indice. |
| find_by_value(name, expected_value) | Recherche des artifacts par valeur personnalisée. |
| update(artifact) | Met à jour l'artifact dans la collection. |
