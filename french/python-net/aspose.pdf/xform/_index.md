## XForm class

Classe représentant XForm

Le type XForm expose les membres suivants:
## Propriétés
| Nom | Description |
| :- | :- |
| b_box | Obtient ou définit la boîte englobante du formulaire. |
| nom | Obtient ou définit le nom du formulaire. Le nom du formulaire est le nom utilisé pour référencer le formulaire dans le dictionnaire XObejct des ressources de page. |
| contenu | Obtient les opérateurs du formulaire. |
| opi | Obtient l'interface Open Prepress (OPI). |
| matrice | Obtient ou définit la matrice du formulaire. |
| resources | Obtient les ressources du Form XObject. |
| rectangle | Obtient ou définit le rectangle du formulaire. |
## Méthodes
| Nom | Description |
| :- | :- |
| get_resources(allow_create) | Renvoie les ressources du Form X-Object |
| get_resources() | Renvoie les ressources du Form X-Object |
| create_new_form(source, document) | Crée un XForm qui duplique le contenu de la page. |
| free_memory() | Efface les données en cache |
