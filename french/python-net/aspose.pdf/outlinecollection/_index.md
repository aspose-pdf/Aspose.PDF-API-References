## OutlineCollection class

Représente la hiérarchie du plan du document.

Le type OutlineCollection expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| visible_count | Count est la somme du nombre d'éléments d'outline descendants visibles à tous les niveaux. Remarque : veuillez ne pas confondre avec Count qui représente le nombre d'éléments dans la collection. |
| first | Obtient un élément d'outline représentant le premier élément de niveau supérieur dans l'outline. |
| dernier | Obtient un élément de plan représentant le dernier élément de niveau supérieur dans le plan. |
| is_synchronized | Obtient une valeur indiquant si l'accès à cette collection est synchronisé (thread-safe). |
| sync_root | Obtient un objet pouvant être utilisé pour synchroniser l'accès à cette collection. |
## Indexer
| Nom | Description |
| :- | :- |
| [index] | Obtient un élément de plan de la collection par indice. |
## Méthodes
| Nom | Description |
| :- | :- |
| delete() | Supprime tous les éléments de plan du plan du document. |
| delete(name) | Supprime l'élément de plan avec le titre spécifié du plan du document. |
