Le type Row expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Row() | Initialise une nouvelle instance de la classe Row |
## Propriétés
| Nom | Description |
| :- | :- |
| background_color | Obtient ou définit la couleur d’arrière‑plan. |
| bordure | Obtient ou définit la bordure. |
| cells | Obtient les cellules de la ligne. |
| default_cell_border | Obtient la bordure de cellule par défaut ; |
| min_row_height | Obtient la hauteur de la ligne; |
| fixed_row_height | Obtient la hauteur fixe de la ligne - la ligne peut avoir une hauteur fixe; |
| is_in_new_page | Obtient si la ligne fixe se trouve sur une nouvelle page - la page avec cette propriété doit être imprimée sur la page suivante Valeur par défaut false; |
| is_row_broken | Obtient si la ligne peut être interrompue entre deux pages |
| default_cell_text_state | Obtient ou définit l’état de texte par défaut pour les cellules de la ligne |
| default_cell_padding | Obtient ou définit la marge par défaut pour les cellules de la ligne |
| vertical_alignment | Obtient ou définit l'alignement vertical. |
