## EmbeddedFileCollection class

Classe représentant la collection de fichiers intégrés.

Le type EmbeddedFileCollection expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| is_synchronized | Obtient une valeur indiquant si l'accès à cette collection est synchronisé (thread-safe). |
| sync_root | Obtient un objet pouvant être utilisé pour synchroniser l'accès à cette collection. |
| keys | Renvoie la liste des clés de pièces jointes de fichier. |
## Indexer
| Nom | Description |
| :- | :- |
| [index] | Obtient le fichier intégré par son index. |
## Méthodes
| Nom | Description |
| :- | :- |
| delete(name) | Supprime le fichier de la collection par sa clé dans la collection. |
| delete() | Supprime le fichier de la collection par sa clé dans la collection. |
| add(key, file) | Ajoute le fichier aux fichiers intégrés avec la clé spécifiée. |
| delete_by_key(key) | Supprime le fichier de la collection par sa clé dans la collection. |
| find_by_name(name) | Renvoie le fichier intégré par son nom. |
