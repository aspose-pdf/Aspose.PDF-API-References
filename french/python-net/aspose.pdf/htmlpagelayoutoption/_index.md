## HtmlPageLayoutOption enumeration

Spécifie les indicateurs qui, avec d'autres options, déterminent les tailles et la disposition des pages.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Valeur par défaut indiquant que le HtmlPageLayoutOption n'affectera pas les tailles et la mise en page des pages. |
| FIT_TO_WIDEST_CONTENT_WIDTH | Indique que la largeur de la page est déterminée à partir de la taille du contenu elle-même, et non à partir de la largeur de page spécifiée. |
| SCALE_TO_PAGE_WIDTH | Indique que le contenu du document sera mis à l'échelle pour s'adapter à la page. |
