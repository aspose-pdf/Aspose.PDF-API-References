## ImagePlacement class

Représente les caractéristiques d'une image placée sur une page de document Pdf.

Le type ImagePlacement expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| matrice | Matrice de transformation actuelle pour cette image. |
| rectangle | Obtient le rectangle de l'Image. |
| opérateur | Opérateur utilisé pour afficher l'image. |
| rotation | Obtient l'angle de rotation de l'Image. |
| resolution | Obtient la résolution de l'Image. |
| image | Obtient l'objet de ressource XImage associé. |
| page | Obtient la page contenant l'image. |
| compositing_parameters | Obtient les paramètres de composition de l'état graphique actif pour l'image placée sur la page. |
## Méthodes
| Nom | Description |
| :- | :- |
| save(stream) | Enregistre l'image avec les transformations correspondantes : mise à l'échelle, rotation et résolution. |
| save(stream, format) | Enregistre l'image avec les transformations correspondantes : mise à l'échelle, rotation et résolution. |
| hide() | Supprime l'image de la page. |
| replace(image) | Remplace l'image dans la collection par une autre image. |
