## Opi class

Représente The Open Prepress Interface (OPI), un mécanisme de création d'espaces réservés à basse résolution, ou de proxys,<br/>            pour de telles images haute résolution.

Le type Opi expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Opi(xform) | Initialise une nouvelle instance de la classe Opi |
## Propriétés
| Nom | Description |
| :- | :- |
| version | Obtient la version d'OPI à laquelle ce dictionnaire fait référence. |
| file_specification | Obtient le fichier externe contenant l'image proxy à basse résolution. |
| position | Obtient un tableau de huit nombres sous forme spécifiant l'emplacement sur la page de l'image recadrée. |
