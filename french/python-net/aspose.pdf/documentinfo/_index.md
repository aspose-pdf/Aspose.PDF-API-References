Le type DocumentInfo expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| DocumentInfo(document) | Initialise une nouvelle instance de la classe DocumentInfo |

| Nom | Description |
| :- | :- |

| creator | Obtient ou définit le créateur du document. |
| author | Obtient ou définit l'auteur du document. |
| subject | Obtient ou définit le sujet du document. |
| keywords | Obtient ou définit les mots-clés du document. |
