## PageMode enumeration

La classe décrit les composants utilisés de la page du document.

## Members
| Nom du membre | Description |
| :- | :- |
| USE_NONE | N'utilisez aucun composant. |
| USE_OUTLINES | Plan du document visible. |
| USE_THUMBS | Vignettes visibles. |
| FULL_SCREEN | FullScreenmode plein écran, sans barre de menus, contrôles de fenêtre ou toute autre fenêtre visible. |
| USE_OC | Panneau de groupe de contenu optionnel visible. |
| USE_ATTACHMENTS | Panneau des pièces jointes visible. |
