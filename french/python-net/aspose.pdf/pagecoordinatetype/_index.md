## PageCoordinateType enumeration

Décrit le type de coordonnées de page.

## Members
| Nom du membre | Description |
| :- | :- |
| MEDIA_BOX | Le MediaBox est utilisé pour spécifier la largeur et la hauteur de la page. <br/>            Pour l'utilisateur moyen, cela correspond probablement à la taille réelle de la page. <br/>            Le MediaBox est la plus grande boîte de page dans un PDF. Les autres boîtes de page peuvent être égales à <br/>            la taille du MediaBox mais ne peuvent pas être plus grandes. |
| CROP_BOX | Le CropBox définit la région à laquelle le contenu de la page doit être découpé. <br/>            Acrobat utilise cette taille pour l'affichage à l'écran et l'impression. |
