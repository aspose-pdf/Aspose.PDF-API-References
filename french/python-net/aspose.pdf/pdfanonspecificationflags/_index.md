## PdfANonSpecificationFlags class

Cette classe contient des indicateurs pour contrôler la conversion PDF/A dans les cas où le document PDF source ne <br/>            correspond pas à la spécification PDF. Si les indicateurs de cette classe sont utilisés, cela diminue les performances <br/>            mais c'est nécessaire lorsque le document PDF source ne peut pas être converti au format PDF/A de la manière habituelle. <br/>            Par défaut, tous les indicateurs sont réglés sur false.
