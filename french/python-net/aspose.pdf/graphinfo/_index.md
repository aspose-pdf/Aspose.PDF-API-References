## GraphInfo class

Représente les informations graphiques.

Le type GraphInfo expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| GraphInfo() | Initialise une nouvelle instance de la classe GraphInfo |
## Propriétés
| Nom | Description |
| :- | :- |
| line_width | Obtient ou définit une valeur flottante qui indique la largeur de ligne du graphique. |
| color | Obtient ou définit un objet [color](/pdf/python-net/aspose.pdf/graphinfo/) qui indique la couleur du graphique. |
| dash_array | Obtient ou définit un tableau de tirets. |
| dash_phase | Obtient ou définit une phase de tiret. |
| fill_color | Obtient ou définit un objet [color](/pdf/python-net/aspose.pdf/graphinfo/) qui indique la couleur de remplissage du graphique. |
| is_doubled | Obtient ou définit si la bordure est doublée. |
| skew_angle_x | Obtient ou définit une valeur flottante qui indique l'angle d'inclinaison de la coordonnée x lors de la transformation d'un système de coordonnées. |
| skew_angle_y | Obtient ou définit une valeur flottante qui indique l'angle d'inclinaison de la coordonnée y lors de la transformation d'un système de coordonnées. |
| scaling_rate_x | Obtient ou définit une valeur flottante qui indique le taux d'échelle de la coordonnée x lors de la transformation d'un système de coordonnées. |
| scaling_rate_y | Obtient ou définit une valeur flottante qui indique le taux d'échelle de la coordonnée y lors de la transformation d'un système de coordonnées. |
| rotation_angle | Obtient ou définit une valeur flottante qui indique l'angle de rotation du système de coordonnées <br/>            lors de la transformation d'un système de coordonnées. |
