## ExtractImageMode enumeration

Définit différents modes pouvant être utilisés lors de l'extraction d'images à partir de documents.

## Members
| Nom du membre | Description |
| :- | :- |
| DEFINED_IN_RESOURCES | Définit le mode d'extraction d'images dans lequel toutes les images définies dans les ressources pour une page particulière sont extraites. |
| ACTUALLY_USED | Définit le mode d'extraction d'images dans lequel seules les images réellement affichées sur une page sont extraites. |
