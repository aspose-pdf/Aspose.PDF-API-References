## IIndexBitmapConverter class

Cette interface est déclarée pour la personnalisation des algorithmes de quantification. <br/>            Les utilisateurs peuvent implémenter leur propre réalisation de ces algorithmes (par exemple des algorithmes basés sur du code non géré).

Le type IIndexBitmapConverter expose les membres suivants :
## Méthodes
| Nom | Description |
| :- | :- |
| get_1_bpp_image(src) | Renvoie la représentation bitmap 1Bpp |
| get_4_bpp_image(src) | Renvoie la représentation bitmap 4Bpp |
| get_8_bpp_image(src) | Renvoie la représentation bitmap 8Bpp |
