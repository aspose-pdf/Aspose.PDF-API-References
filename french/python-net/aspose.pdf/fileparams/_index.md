## FileParams class

Définit un dictionnaire de paramètres de fichier intégré qui doit contenir des informations supplémentaires spécifiques au fichier.

Le type FileParams expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| FileParams(spec) | Initialise une nouvelle instance de la classe FileParams |
## Propriétés
| Nom | Description |
| :- | :- |
| taille | La taille du fichier intégré non compressé, en octets. |
| creation_date | La date et l'heure de création du fichier intégré. |
| mod_date | La date et l'heure de la dernière modification du fichier intégré. |
| check_sum | Une chaîne de 16 octets qui est la somme de contrôle des octets du fichier intégré non compressé. <br/>            La somme de contrôle est calculée en appliquant l'algorithme standard de hachage MD5 <br/>            aux octets du flux du fichier intégré. |
