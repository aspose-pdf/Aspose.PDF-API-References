## WarningType enumeration

L'énumération représente le type d'avertissement.

## Members
| Nom du membre | Description |
| :- | :- |
| SOURCE_FILE_CORRUPTION | Le fichier est corrompu. |
| DATA_LOSS | Le texte, le graphique, l'image ou d'autres données sont complètement manquants, que ce soit dans l'arbre du document après le chargement ou dans le document créé après l'enregistrement. |
| MAJOR_FORMATTING_LOSS | Pertes de mise en forme majeures par rapport au document original. Cela s'applique aux cas où la perte de mise en forme est importante mais que les données sont toujours présentes. |
| MINOR_FORMATTING_LOSS | Pertes de mise en forme mineures par rapport au document original. Cela concerne les pertes mineures de fidélité. |
| COMPATIBILITY_ISSUE | Problème connu qui empêchera le document d'être ouvert par certains agents utilisateurs, ou par des versions antérieures d'agents utilisateurs. |
| INVALID_INPUT_STREAM_TYPE | Type de flux d'entrée invalide |
| UNEXPECTED_CONTENT | Le fichier contient un contenu inattendu. |
