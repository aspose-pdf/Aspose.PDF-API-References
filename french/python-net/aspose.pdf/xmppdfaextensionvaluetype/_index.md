## XmpPdfAExtensionValueType class

Le schéma PDF/A ValueType est requis pour tous les types de valeur de propriété qui ne sont pas définis dans la spécification XMP 2004, c'est‑à‑dire pour les types de valeur en dehors de la liste suivante :<br/>            - Types de tableau (ce sont des types conteneurs pouvant contenir un ou plusieurs champs) : Alt, Bag, Seq<br/>            - Types de valeur de base : Boolean, (open and closed) Choice, Date, Dimensions, Integer, Lang Alt, Locale, MIMEType, ProperName, Real, Text, Thumbnail, URI, URL, XPath<br/>            - Types de valeur de gestion des médias : AgentName, RenditionClass, ResourceEvent, ResourceRef, Version<br/>            - Type de valeur de travail de base : Job<br/>            - Types de valeur du schéma EXIF : Flash, CFAPattern, DeviceSettings, GPSCoordinate, OECF/SFR, Rational<br/>            URI de l'espace de noms du schéma : http://www.aiim.org/pdfa/ns/type#<br/>            Préfixe d'espace de noms requis pour le schéma : pdfaType
