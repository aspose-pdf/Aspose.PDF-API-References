## OutlineItemCollection class

Représente une entrée du plan dans la hiérarchie du plan du document PDF.

Le type OutlineItemCollection expose les membres suivants:
## Constructeurs
| Nom | Description |
| :- | :- |
| OutlineItemCollection(outlines) | Initialise une nouvelle instance de la classe OutlineItemCollection |
## Propriétés
| Nom | Description |
| :- | :- |
| visible_count | Obtient le nombre total d'éléments de plan à tous les niveaux de la hiérarchie du plan du document. |
| title | Obtient ou définit le titre de cet élément de plan. |
| destination | Obtient ou définit la destination de cet élément de plan. |
| action | Obtient ou définit l'action de cet élément de plan. |
| couleur | Obtient ou définit la couleur du texte du titre de cet élément de plan. |
| italique | Obtient ou définit le drapeau italique pour le texte du titre de cet élément de plan |
| gras | Obtient ou définit le drapeau gras pour le texte du titre de cet élément de plan |
| first | Obtient l'élément de plan représentant le premier élément de niveau supérieur dans la hiérarchie du plan. |
| dernier | Obtient l'élément de plan représentant le dernier élément de niveau supérieur dans la hiérarchie du plan. |
| prev | Obtient l'élément de plan représentant l'élément précédent relativement à cet élément dans la hiérarchie du plan. |
| suivant | Obtient l'élément de plan représentant l'élément suivant relativement à cet élément dans la hiérarchie du plan. |
| has_next | Vérifie si l'élément de plan représentant l'élément suivant relativement à cet élément dans la hiérarchie du plan. |
| parent | Obtient l'objet parent de cet élément de plan dans la hiérarchie du plan. |
| is_synchronized | Obtient la valeur indiquant si l'accès à cette collection est synchronisé (thread‑safe). |
| sync_root | Obtient l'objet pouvant être utilisé pour synchroniser l'accès à cette collection. |
| ouvrir | Obtient ou définit l'état d'ouverture (true/false) de l'élément de plan. |
| niveau | Obtient le niveau hiérarchique de l'élément de plan. |
## Indexer
| Nom | Description |
| :- | :- |
| [index] | Obtient l'élément de plan de la collection en utilisant l'index. |
## Méthodes
| Nom | Description |
| :- | :- |
| delete() | Supprime cet élément d'outline de la hiérarchie des outlines du document. |
| delete(name) | Supprime l'entrée d'outline avec le nom spécifié de la hiérarchie des outlines du document. |
| insert(index, outline) | Insère l'élément d'outline dans la collection à l'endroit spécifié. |
