## HorizontalAlignment enumeration

Décrit l'alignement horizontal.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Aucun alignement. |
| GAUCHE | Aligner à gauche. |
| CENTER | Alignement centré. |
| DROITE | Aligner à droite. |
| JUSTIFY | Alignement justifié. Le texte sera aligné sur les marges gauche et droite. |
| FULL_JUSTIFY | Similaire à l'alignement 'Justify', sauf que la toute dernière ligne sera uniquement <br/>            alignée à gauche en mode 'Justify', tandis qu'en mode 'FullJustify' toutes les lignes seront<br/>            alignées à gauche et à droite. |
