## NumberingStyle enumeration

Énumération des styles de numérotation de page pris en charge pour la classe PageLabel.

## Members
| Nom du membre | Description |
| :- | :- |
| NUMERALS_ARABIC | Nombres décimaux arabes. |
| NUMERALS_ROMAN_UPPERCASE | Nombres romains en majuscules (I, II, III...). |
| NUMERALS_ROMAN_LOWERCASE | Nombres romains en minuscules (i, ii, iii...). |
| LETTERS_UPPERCASE | Lettres latines en majuscules (A, B, C...). |
| LETTERS_LOWERCASE | Lettres latines en minuscules (a, b, c...). |
| NONE | Pas de numérotation. |
