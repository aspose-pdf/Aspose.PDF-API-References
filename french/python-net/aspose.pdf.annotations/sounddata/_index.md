## SoundData class

Représente des données sonores définissant le son à lire lorsque l'annotation est activée.

Le type SoundData expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| rate | Obtient ou définit le taux d'échantillonnage, en échantillons par seconde. |
| canaux | Obtient ou définit le nombre de canaux audio. |
| bits | Obtient ou définit le nombre de bits par valeur d'échantillon par canal. |
| contenu | Obtient le flux du son à lire lorsque l'annotation est activée. |
| encodage | Obtient ou définit le format d'encodage des données d'échantillon. |
