## TextStyle class

Classe représentant le style du texte dans l'annotation

Le type TextStyle expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| font_name | Nom de la police. |
| font_size | Taille de la police. |
| alignement | Obtient ou définit l'alignement horizontal du texte. |
| horizontal_alignment | Alignement du texte. Les valeurs valides sont : Left, Center, Rigth. |
| couleur | Couleur du texte. |
