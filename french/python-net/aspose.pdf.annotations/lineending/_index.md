## LineEnding enumeration

Énumère les styles de terminaison de ligne à utiliser pour tracer la ligne.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Pas de fin de ligne. |
| CARRÉ | Un carré rempli avec la couleur intérieure de l'annotation, le cas échéant. |
| CIRCLE | Un cercle rempli avec la couleur intérieure de l'annotation, le cas échéant. |
| DIAMANT | Une forme de losange remplie avec la couleur intérieure de l'annotation, le cas échéant. |
| OPEN_ARROW | Deux courtes lignes se rejoignant en un angle aigu pour former une pointe de flèche ouverte. |
| CLOSED_ARROW | Deux courtes lignes se rejoignant en un angle aigu, comme dans le style OpenArrow, et reliées par une troisième ligne pour former une pointe de flèche fermée triangulaire remplie de la couleur intérieure de l'annotation, le cas échéant. |
| BUTT | Une courte ligne à l'extrémité perpendiculaire à la ligne elle-même. |
| R_OPEN_ARROW | Deux courtes lignes dans la direction opposée à OpenArrow. |
| R_CLOSED_ARROW | Une pointe de flèche fermée triangulaire dans la direction opposée à ClosedArrow. |
| SLASH | Une courte ligne à l'extrémité à environ 30 degrés dans le sens horaire par rapport à la perpendiculaire de la ligne elle-même. |
