## GoToRemoteAction class

Représente une action de navigation distante similaire à une action de navigation ordinaire mais qui saute vers une destination dans un autre fichier PDF au lieu du fichier actuel.

Le type GoToRemoteAction expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| GoToRemoteAction(remote_pdf, remote_page_number) | Initialise une nouvelle instance de la classe GoToRemoteAction |
| GoToRemoteAction(remote_pdf, destination) | Initialise une nouvelle instance de la classe GoToRemoteAction |
## Propriétés
| Nom | Description |
| :- | :- |
| suivant | Actions suivantes dans la séquence. |
| destination | Obtient ou définit la destination vers laquelle sauter. |
| file | Obtient ou définit la spécification du fichier dans lequel la destination est située. |
| new_window | Obtient ou définit un indicateur spécifiant s'il faut ouvrir le document de destination dans une nouvelle fenêtre. |
