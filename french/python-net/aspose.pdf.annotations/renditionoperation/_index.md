## RenditionOperation enumeration

L'opération à effectuer lorsque l'action est déclenchée.

## Members
| Nom du membre | Description |
| :- | :- |
| PLAY_STOP | Si aucune version n'est associée à l'annotation, lisez la version spécifiée en l'associant à l'annotation. Si une version est déjà associée à l'annotation, elle doit être arrêtée, et la nouvelle version doit être associée à l'annotation. |
| STOP | Arrêtez toute rendition en cours de lecture associée à l'annotation. |
| PAUSE | Mettez en pause toute rendition en cours de lecture associée à l'annotation. |
| RESUME | Reprenez toute rendition en cours de lecture associée à l'annotation. |
| PLAY_RESUME | Lisez la rendition spécifiée, en l'associant à l'annotation. Si une rendition est déjà associée à l'annotation, reprenez la rendition si elle est en pause. |
| UNDEFINED | Opération non définie. |
