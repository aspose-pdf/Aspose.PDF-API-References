## AnnotationState enumeration

L'énumération des états auxquels l'annotation d'origine peut être définie.

## Members
| Nom du membre | Description |
| :- | :- |
| UNDEFINED | État non défini. |
| MARKED | L'annotation a été marquée par l'utilisateur. |
| UNMARKED | L'annotation n'a pas été marquée par l'utilisateur. |
| ACCEPTED | L'utilisateur accepte le changement. |
| REJECTED | L'utilisateur rejette le changement. |
| CANCELLED | Le changement a été annulé. |
| COMPLÉTÉ | Le changement a été complété. |
| NONE | L'utilisateur n'a indiqué aucune information concernant le changement. |
