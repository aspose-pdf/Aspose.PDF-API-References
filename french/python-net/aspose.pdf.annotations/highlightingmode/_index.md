## HighlightingMode enumeration

Énumère le mode de surlignage de l'annotation, l'effet visuel à utiliser lorsque le bouton de la souris est pressé ou maintenu dans sa zone active.

## Members
| Nom du membre | Description |
| :- | :- |
| NONE | Pas de surlignage. |
| INVERT | Inverse le contenu du rectangle de l'annotation. |
| OUTLINE | Inverse la bordure de l'annotation. |
| PUSH | Affiche l'apparence « down » de l'annotation, le cas échéant. Si aucune apparence « down » n'est définie, décale le contenu du rectangle de l'annotation pour donner l'impression qu'il est poussé sous la surface de la page. |
| TOGGLE | Identique à Push (préféré). |
