## ReplyType enumeration

Énumère les types de relations (le « type de réponse ») entre l'annotation et celle spécifiée par InReplyTo.

## Members
| Nom du membre | Description |
| :- | :- |
| UNDEFINED | Relation indéfinie. |
| REPLY | L'annotation est considérée comme une réponse à l'annotation spécifiée par InReplyTo. Les applications de visualisation ne doivent pas afficher les réponses à une annotation individuellement, mais les regrouper sous forme de commentaires en fil. |
| GROUP | L'annotation est groupée avec l'annotation spécifiée par InReplyTo. |
