## Measure class

Classe qui décrit le système de coordonnées de mesure.

Le type Measure expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Measure(annotation) | Initialise une nouvelle instance de la classe Measure |
## Propriétés
| Nom | Description |
| :- | :- |
| scale_ratio | Une chaîne de texte exprimant le rapport d'échelle du dessin. |
| x_format | Un tableau de formats numériques pour la mesure du changement le long de l'axe x et, si Y n'est pas présent, également le long de l'axe y. |
| y_format | Un tableau de formats numériques pour la mesure du changement le long de l'axe y. |
| distance_format | Un tableau de formats numériques pour la mesure de la distance dans n'importe quelle direction. |
| area_format | Un tableau de formats numériques pour la mesure de la surface. |
| angle_format | Un tableau de formats numériques pour la mesure des angles. |
| slope_format | Un tableau de formats numériques pour la mesure de la pente d'une ligne. |
| origin | Point qui doit spécifier l'origine du système de coordonnées de mesure dans les coordonnées d'espace utilisateur par défaut. |
| xy_factor | Un facteur qui doit être utilisé pour convertir les plus grandes unités le long de l'axe y en les plus grandes unités le long de l'axe x. |
