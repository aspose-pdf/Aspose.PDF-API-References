## Arc class

Représente un arc.

Le type Arc expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Initialise une nouvelle instance de la classe Arc |
## Propriétés
| Nom | Description |
| :- | :- |
| graph_info | Obtient ou définit un objet [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/) qui indique les informations du graphique, telles que la couleur,<br/>            la largeur de ligne, etc. |
| text | Obtient ou définit un texte pour la forme |
| pos_x | Obtient ou définit une valeur flottante qui indique la coordonnée x du centre de l'arc. |
| pos_y | Obtient ou définit une valeur flottante qui indique la coordonnée y du centre de l'arc. |
| radius | Obtient ou définit une valeur flottante qui indique le rayon de l'arc. |
| alpha | Obtient ou définit une valeur flottante qui indique le degré d'angle de début de l'arc. |
| beta | Obtient ou définit une valeur flottante qui indique le degré d'angle de fin de l'arc. |
