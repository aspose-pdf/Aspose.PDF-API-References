## IPdfTypeExtractor class

Représente une interface pour interagir avec l'extracteur.

Le type IPdfTypeExtractor expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| page_count | Renvoie le nombre de pages. |
| version | Renvoie la version. |
| is_fast_extraction_used | Renvoie si le mécanisme d'extraction rapide est utilisé. |
## Méthodes
| Nom | Description |
| :- | :- |
| extract_all_text() | Renvoie une collection des valeurs de texte extraites. |
| extract_page_text(page_number) | Renvoie le texte de la page. |
| dispose() | Libérer. |
