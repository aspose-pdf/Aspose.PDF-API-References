## FigureElement class

Classe représentant la figure de la structure logique.

Le type FigureElement expose les membres suivants:
## Propriétés
| Nom | Description |
| :- | :- |
| children | Obtient la collection d'éléments enfants. |
| lang | (Optionnel; PDF 1.4) Une langue spécifiant la langue naturelle pour tout le texte<br/>            dans l'élément de structure, sauf lorsqu'elle est remplacée par des spécifications de langue pour les éléments de structure imbriqués<br/>            ou le contenu balisé. |
| actual_text | (Optionnel; PDF 1.4) Texte qui remplace exactement l'élément de structure et ses enfants.<br/>            Ce texte de remplacement (qui doit s'appliquer à la plus petite portion de contenu possible)<br/>            est utile lors de l'extraction du contenu du document afin de soutenir l'accessibilité pour les utilisateurs<br/>            en situation de handicap ou à d'autres fins. |
| alt | (Optionnel) Une description alternative de l'élément de structure et de ses enfants en<br/>            forme lisible par l'homme, ce qui est utile lors de l'extraction du contenu du document afin de soutenir<br/>            l'accessibilité pour les utilisateurs en situation de handicap ou à d'autres fins. |
| e | (Optionnel; PDF 1.5) La forme développée d'une abréviation. |
| image | Obtient la valeur de l'élément de structure figure. |
