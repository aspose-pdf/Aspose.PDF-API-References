## PageMarkup class

Le balisage de page est représenté par des collections de [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) et [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/).

Le type PageMarkup expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| nombre | Obtient le numéro de page traité. |
| rectangle | Obtient le rectangle de page traité. |
| sections | Obtient la collection de [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) qui a été trouvée sur la page. |
| paragraphs | Obtient la collection de [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) qui a été trouvée sur la page. |
| text_fragments | Obtient la collection de [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) qui a été trouvée sur la page. |
| is_multicolumn_paragraphs_allowed | Obtient ou définit la valeur qui indique si les lignes de texte de début d'une section suivante peuvent être traitées comme la continuation du dernier paragraphe d'une section précédente. |
