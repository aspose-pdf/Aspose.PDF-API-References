## TextFormattingOptions class

Représente les options de mise en forme du texte

Le type TextFormattingOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TextFormattingOptions(wrap_mode) | Initialise une nouvelle instance de la classe TextFormattingOptions |
| TextFormattingOptions() | Initialise une nouvelle instance de l'objet [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) avec un mode de retour à la ligne indéfini. |
## Propriétés
| Nom | Description |
| :- | :- |
| wrap_mode | Obtient ou définit le mode de retour à la ligne.<br/>            La valeur par défaut est WordWrapMode.NoWrap |
| line_spacing | Obtient ou définit le mode d'espacement des lignes.<br/>            La valeur par défaut est LineSpacingMode.FontSize |
| hyphen_symbol | Obtient ou définit le symbole de trait d'union utilisé dans le processus de césure. |
| subsequent_lines_indent | Obtient ou définit la valeur du retrait des lignes suivantes. |
| first_line_indent | Obtient ou définit la valeur du retrait de la première ligne. |
