## TextExtractionErrorLocation class

Représente l'emplacement dans le document PDF où l'erreur d'extraction de texte est survenue.

Le type TextExtractionErrorLocation expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| path | Emplacement du document PDF où l'erreur d'extraction de texte est survenue. |
| page_number | Numéro de la page du document où l'erreur d'extraction de texte s'est produite. |
| object_type | Type de l'objet PDF (Page ou xForm) dans lequel l'erreur d'extraction de texte du flux de contenu s'est produite. |
| form_key | Clé (nom) du XObject de formulaire PDF dans lequel l'erreur d'extraction de texte du flux de contenu s'est produite. Non vide si ObjectType == 'xForm'. |
| operator_index | Index de l'opérateur affichant le texte dans le flux de contenu (collection d'opérateurs) qui provoque l'erreur d'extraction de texte. |
| operator_string | Opérateur affichant le texte qui provoque l'erreur d'extraction de texte. |
| font_used_key | Clé (nom) de l'objet PDF Font qui est utilisé pour afficher l'opérateur qui provoque une erreur d'extraction de texte. |
| text_start_point | Clé (nom) de l'objet PDF Font qui est utilisé pour afficher l'opérateur qui provoque une erreur d'extraction de texte. |
