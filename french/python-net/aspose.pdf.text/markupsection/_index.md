## MarkupSection class

Représente une section de balisage - la région rectangulaire d'une page qui contient du texte et peut être visuellement séparée d'autres blocs de texte.

Le type MarkupSection expose les membres suivants :
## Propriétés
| Nom | Description |
| :- | :- |
| rectangle | Rectangle de section |
| fragments | Collection d'objets [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) non vides qui se trouvent dans la section. |
| paragraphs | Collection d'objets [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) qui se trouvent dans la section. |
