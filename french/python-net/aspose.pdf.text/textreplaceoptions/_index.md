## TextReplaceOptions class

Représente les options de remplacement de texte

Le type TextReplaceOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TextReplaceOptions(scope) | Initialise une nouvelle instance de la classe TextReplaceOptions |
| TextReplaceOptions(adjustment) | Initialise une nouvelle instance de la classe TextReplaceOptions |
## Propriétés
| Nom | Description |
| :- | :- |
| replace_scope | Obtient ou définit une portée où l'opération de remplacement de texte est appliquée |
| replace_adjustment_action | Obtient ou définit une action qui sera effectuée après le remplacement d'un fragment de texte par une version plus courte. |
| adjustment_new_line_spacing | Obtient ou définit la valeur de l'interligne utilisée si le réglage de remplacement force la création d'une nouvelle ligne de texte.<br/>            La valeur attendue est un multiplicateur de la taille de police du texte remplacé. La valeur par défaut est 1,2. |
