## TextEditOptions class

Décrit les options des opérations de modification de texte.

Le type TextEditOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TextEditOptions(no_character_behavior) | Initialise une nouvelle instance de la classe TextEditOptions |
| TextEditOptions(font_replace_behavior) | Initialise une nouvelle instance de la classe TextEditOptions |
| TextEditOptions(allow_language_transformation) | Initialise une nouvelle instance de la classe TextEditOptions |
| TextEditOptions(language_transformation_behavior) | Initialise une nouvelle instance de la classe TextEditOptions |
## Propriétés
| Nom | Description |
| :- | :- |
| replacement_font | Obtient ou définit la police utilisée pour le remplacement si la police de l'utilisateur ne contient pas le caractère requis |
| no_character_behavior | Obtient ou définit le mode qui définit le comportement dans le cas où les polices ne contiennent pas les caractères demandés. |
| font_replace_behavior | Obtient le mode qui définit le comportement pour les scénarios de remplacement de polices. |
| allow_language_transformation | Obtient ou définit la valeur qui autorise l'utilisation de la transformation linguistique lors de l'ajout ou de la modification du texte.<br/>            true - la transformation linguistique sera appliquée si nécessaire (valeur par défaut).<br/>            false - la transformation linguistique NE sera PAS appliquée. |
| language_transformation_behavior | Obtient le mode qui définit le comportement pour les scénarios de transformation linguistique. |
| clipping_paths_processing | Obtient le mode de traitement du chemin de découpe du texte modifié. |
| to_attempt_get_underline_from_source | Obtient ou définit la valeur qui autorise la recherche de soulignement de texte sur la page du document source.<br/>            (Obsolète) Veuillez utiliser TextSearchOptions.SearchForTextRelatedGraphics à la place. |
