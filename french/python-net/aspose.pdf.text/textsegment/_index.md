## TextSegment class

Représente un segment de texte PDF.

Le type TextSegment expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TextSegment() | Crée un objet TextSegment. |
| TextSegment(text) | Initialise une nouvelle instance de la classe TextSegment |
## Propriétés
| Nom | Description |
| :- | :- |
| start_char_index | Obtient l'index du caractère de départ du segment actuel dans le segment de l'opérateur d'affichage de texte (Tj, TJ). |
| end_char_index | Obtient l'index du caractère de fin du segment actuel dans le segment de l'opérateur d'affichage de texte (Tj, TJ). |
| text | Obtient ou définit l'objet texte de chaîne que représente l'objet [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| text_state | Obtient ou définit l'état du texte pour le texte que représente l'objet [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| position | Obtient la position du texte, représentée par l'objet [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| rectangle | Obtient le rectangle du TextSegment |
| baseline_position | Obtient la position du texte, représentée par l'objet [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/).<br/>            Le YIndent de la structure Position représente la coordonnée de la ligne de base du segment de texte. |
| text_edit_options | Obtient ou définit les options de modification de texte. Les options définissent un comportement spécial lorsque le symbole demandé ne peut pas être écrit avec la police. |
| caractères | Obtient la collection d'objets CharInfo qui représentent les informations sur les caractères du segment de texte. |
| hyperlien | Obtient ou définit le lien hypertexte du segment (pour le générateur de PDF). |
