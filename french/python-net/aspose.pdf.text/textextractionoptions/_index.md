## TextExtractionOptions class

Représente les options d'extraction de texte

Le type TextExtractionOptions expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TextExtractionOptions(formatting_mode) | Initialise une nouvelle instance de la classe TextExtractionOptions |
## Propriétés
| Nom | Description |
| :- | :- |
| formatting_mode | Obtient le mode de formatage. |
| scale_factor | Obtient ou définit le facteur qui sera appliqué pour mettre à l'échelle la taille de la police lors de l'extraction en mode pur.<br/>            Une valeur plus petite entraîne davantage d'espaces dans le texte extrait.<br/>            La valeur par défaut est 1 - aucune mise à l'échelle ;<br/>            Mettre la valeur à zéro permet à l'algorithme de choisir automatiquement la mise à l'échelle. |
