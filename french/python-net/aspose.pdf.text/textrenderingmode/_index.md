## TextRenderingMode enumeration

Le mode de rendu du texte, Tmode, détermine si l'affichage du texte doit entraîner le tracé, le remplissage, l'utilisation des contours de glyphes comme limite de découpe, ou une combinaison de ces trois options.

## Members
| Nom du membre | Description |
| :- | :- |
| FILL_TEXT | Remplir le texte. |
| STROKE_TEXT | Tracer le texte. |
| FILL_THEN_STROKE_TEXT | Remplir, puis tracer le texte. |
| INVISIBLE | Ni remplissage ni tracé du texte (invisible). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Remplir le texte et ajouter au chemin pour le rognage (voir 9.3.6, "Text Rendering Mode,"). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Tracer le texte et ajouter au chemin pour le rognage. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Remplir, puis tracer le texte et ajouter au chemin pour le rognage. |
| ADD_PATH_TO_CLIPPING | Ajouter le texte au chemin pour le rognage. |
