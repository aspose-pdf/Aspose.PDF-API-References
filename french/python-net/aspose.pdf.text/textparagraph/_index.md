## TextParagraph class

Représente les paragraphes de texte comme un objet texte multilignes.

Le type TextParagraph expose les membres suivants :
## Constructeurs
| Nom | Description |
| :- | :- |
| TextParagraph() | Initialise une nouvelle instance de la classe TextParagraph |
## Propriétés
| Nom | Description |
| :- | :- |
| vertical_alignment | Obtient ou définit l'alignement vertical du texte à l'intérieur du [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) du paragraphe. |
| subsequent_lines_indent | Obtient ou définit la valeur du retrait des lignes suivantes.<br/>            Si elle est définie sur une valeur non nulle, elle a un avantage sur la valeur FormattingOptions.SubsequentLinesIndent. |
| first_line_indent | Obtient ou définit la valeur du retrait des lignes suivantes.<br/>            Si elle est définie sur une valeur non nulle, elle a un avantage sur la valeur FormattingOptions.SubsequentLinesIndent. |
| justify | Obtient ou définit la valeur indiquant si le texte est justifié. |
| horizontal_alignment | Obtient ou définit l'alignement horizontal du texte à l'intérieur du [rectangle](/pdf/python-net/aspose.pdf.text/textparagraph/) du paragraphe. |
| formatting_options | Obtient ou définit les options de formatage. |
| position | Obtient ou définit la position du paragraphe. |
| text_rectangle | Obtient le rectangle du texte placé dans le paragraphe. |
| rectangle | Obtient ou définit le rectangle du paragraphe. |
| marge | Obtient ou définit le remplissage. |
| rotation | Obtient ou définit l'angle de rotation en degrés. |
