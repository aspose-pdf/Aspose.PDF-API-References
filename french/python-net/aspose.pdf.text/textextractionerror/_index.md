## TextExtractionError class

Décrit l'erreur d'extraction de texte survenue dans le document PDF.

Le type TextExtractionError expose les membres suivants:
## Propriétés
| Nom | Description |
| :- | :- |
| summary | Brève description de l'erreur. |
| description | Description détaillée de l'erreur. |
| location | Emplacement de l'erreur. |
| font_key | Clé (nom PDF) de l'objet Font utilisé pour afficher le texte qui provoque l'erreur d'extraction. |
| font_name | Nom lisible (interne) de l'objet Font utilisé pour afficher le texte qui provoque l'erreur d'extraction. |
| extracted_text | Texte réellement extrait. |
