## Security PDF functions

| Nom | Description |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | Chiffrer un fichier PDF. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | Déchiffrer un fichier PDF. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | Signer un fichier PDF avec des signatures numériques. |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | Signer un fichier PDF avec des signatures numériques détachées. |
| [AsposePdfChangePassword](./asposepdfchangepassword/) | Modifier les mots de passe du fichier PDF. |

## Detailed Description

Fonctions pour travailler avec les fonctionnalités de sécurité des fichiers PDF.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
ou
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
