## Core Functions

| Nom | Description |
| -------------- | -------------- |
| [AsposePdfPrepare](./asposepdfprepare/) | Enregistrer le BLOB dans le système de fichiers mémoire pour le traitement. |
| [AsposePdfPrepareBase64](./asposepdfpreparebase64/) | Enregistrer la représentation sous forme de chaîne du BLOB dans le système de fichiers mémoire pour le traitement. |

## Detailed Description

Fonctions de base pour travailler avec des fichiers PDF.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
ou
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
