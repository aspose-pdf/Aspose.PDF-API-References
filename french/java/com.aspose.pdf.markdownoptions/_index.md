L'espace de noms com.aspose.pdf.markdownoptions contient des classes d'options spécifiques pour une conversion markdown.

## Classes

| Classe | Description |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | Définit les styles de sérialisation disponibles pour l'emphase et l'emphase forte. Pour la spécification, voir CommonMark - Emphasis and strong emphasis. |
| [HeadingLevels](./headinglevels/) | Représente une classe permettant de travailler avec les niveaux d'en-tête basés sur la taille de la police. |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | Représente les types de stratégies de reconnaissance d'en-tête. |
| [HeadingStyle](./headingstyle/) | Définit les styles de sérialisation disponibles pour les titres. Pour la spécification, voir CommonMark - ATX headings, respectivement CommonMark - Setext headings. |
| [LineBreakStyle](./linebreakstyle/) | Représente les styles de saut de ligne possibles pour un fichier. |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Représente la classe d'option d'enregistrement du document au format markdown. |
