Définit les styles de sérialisation disponibles pour les titres. Pour la spécification, voir CommonMark - ATX headings, respectivement CommonMark - Setext headings.

## Champs

| Champ | Description |
| --- | --- |
| [Atx](#Atx) | Préfixer les titres avec '#' |
| [Setext](#Setext) | Souligner les titres de niveau 1 et 2 avec "======" respectivement "------". Les titres Setext ne sont disponibles que pour les niveaux 1 et 2. Même si le style de titre est défini sur Setext, le style Atx sera utilisé pour les titres de niveau 3 et supérieurs. |

```
public static final int Atx
```

### Setext {#Setext}
```
public static final int Setext
```

Souligner les titres de niveau 1 et 2 avec "======" respectivement "------". Les titres Setext ne sont disponibles que pour les niveaux 1 et 2. Même si le style de titre est défini sur Setext, le style Atx sera utilisé pour les titres de niveau 3 et supérieurs.
