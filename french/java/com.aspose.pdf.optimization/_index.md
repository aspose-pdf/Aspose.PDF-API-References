Le com.aspose.pdf.optimization est un package contenant des classes pour la gestion du processus d'optimisation du document.

## Classes

| Classe | Description |
| --- | --- |
| [ImageCompressionOptions](./imagecompressionoptions/) | La classe contient un ensemble d'options pour la compression d'image. |
| [ImageCompressionVersion](./imagecompressionversion/) | Décrit les versions de l'algorithme de compression d'image. |
| [ImageEncoding](./imageencoding/) | Types d'encodage d'image. |
| [OptimizationOptions](./optimizationoptions/) | Classe qui décrit l'algorithme d'optimisation de document. Une instance de cette classe peut être utilisée comme paramètre de la méthode OptimizeResources(). |
