Définit le mode de positionnement. Les valeurs possibles incluent Legacy (compatibilité descendante) et Current (méthode mise à jour de calcul de la position du texte).

## Champs

| Champ | Description |
| --- | --- |
| [Current](#Current) | L'espacement des lignes mis à jour et le calcul de la position verticale sont effectués à partir du coin supérieur gauche plutôt que du coin inférieur gauche. |
| [Legacy](#Legacy) | Positionnement du texte hérité |
| [ModernLineSpacing](#ModernLineSpacing) | L'espacement des lignes mis à jour, le calcul de la position verticale sont effectués selon les anciennes règles (c.-à-d. le texte est positionné par rapport au coin inférieur gauche du rectangle spécifié) |
