## Classes

| Classe | Description |
| --- | --- |
| [ExtractedFragmentsProcessorBase](./extractedfragmentsprocessorbase/) | Représente une classe de base pour les processeurs de fragments extraits. |
| [IgnoreSpacesFragmentsProcessor](./ignorespacesfragmentsprocessor/) | Représente une classe pour traiter les fragments de texte en mode d'ignorance des espaces. Cette classe ignore tous les espaces, mettant en évidence les mots individuels en tant que fragments. |
| [NormalFragmentProcessor](./normalfragmentprocessor/) | Représente une classe pour traiter les fragments de texte en mode normal. Cette classe ne considère les espaces que à l'intérieur des fragments. |
| [ParseSpacesFragmentsProcessor](./parsespacesfragmentsprocessor/) | Représente une classe pour traiter les fragments de texte en mode d'analyse des espaces. Cette classe reconnaît les espaces entre les fragments de texte en fonction de la distance qui les sépare. |
