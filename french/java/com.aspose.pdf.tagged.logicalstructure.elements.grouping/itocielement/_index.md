```
public interface ITociElement
```

Représente un élément pouvant fonctionner comme une entrée de table des matières (TOCI) dans un document PDF balisé. Cette interface abstrait à la fois les éléments TOCI standard et les éléments d'élément de liste (LI) utilisés dans les structures de tables des matières imbriquées.

## Méthodes

| Méthode | Description |
| --- | --- |
| [getGetElement](#getGetElement--) | Obtient l'élément PDF sous-jacent qui représente cette structure TOCI. |

### getGetElement {#getGetElement--}
```
StructureElement getGetElement()
```

Obtient l'élément PDF sous-jacent qui représente cette structure TOCI.

**Returns:**
L'élément qui forme la représentation structurelle de cette entrée de table des matières.
