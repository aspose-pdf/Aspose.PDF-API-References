## Classes

| Classe | Description |
| --- | --- |
| [HiddenDataSanitizationOptions](./hiddendatasanitizationoptions/) | Représente les options de configuration pour la désinfection des données cachées dans un document. |
| [HiddenDataSanitizer](./hiddendatasanitizer/) | Représente une classe pour désinfecter les données cachées. |
| [UnsignedContentAbsorber](./unsignedcontentabsorber/) | Représente une classe permettant d'extraire le contenu non signé d'un fichier PDF géré par des signatures numériques. |
| [UnsignedContentAbsorber.Result](./unsignedcontentabsorber.result/) | Encapsule le résultat d'une opération visant à extraire le contenu non signé d'un document PDF. Cette classe fournit des informations sur le succès de l'opération, les détails du contenu non signé, un message décrivant le résultat et le statut de couverture des signatures du document. |
| [UnsignedContentAbsorber.UnsignedContent](./unsignedcontentabsorber.unsignedcontent/) | Encapsule les éléments de contenu non signé extraits d'un document PDF. Cette classe donne accès aux pages, aux champs de formulaire, aux XForms et aux annotations qui font partie du contenu non signé du document. |
