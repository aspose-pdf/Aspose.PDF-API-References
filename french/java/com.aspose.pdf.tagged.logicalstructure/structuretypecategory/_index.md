### BLSEs {#BLSEs}
```
public static final StructureTypeCategory BLSEs
```

Les éléments de structure de niveau bloc (BLSEs) décrivent la mise en page globale du contenu sur la page, en suivant la direction de progression des blocs.

### GroupingElements {#GroupingElements}
```
public static final StructureTypeCategory GroupingElements
```

Les éléments de regroupement regroupent d'autres éléments en séquences ou hiérarchies mais ne contiennent aucun contenu directement et n'ont aucun effet direct sur la mise en page.

### IllustrationElements {#IllustrationElements}
```
public static final StructureTypeCategory IllustrationElements
```

Les éléments d'illustration sont des séquences compactes de contenu, dans l'ordre du contenu de la page, considérées comme des objets unitaires par rapport à la mise en page. Une illustration peut être traitée comme un BLSE ou un ILSE.

### ILSEs {#ILSEs}
```
public static final StructureTypeCategory ILSEs
```

Les éléments de structure de niveau en ligne (ILSEs) décrivent la mise en page du contenu à l'intérieur d'un BLSE, en suivant la direction de progression en ligne.
