Spécifie les types de marques d'imprimante à ajouter à un document. Cette énumération possède un attribut {@link FlagsAttribute} qui permet une combinaison bit à bit de ses valeurs membres.

## Champs

| Champ | Description |
| --- | --- |
| [All](#All) | Spécifie que tous les types de marques d'imprimante doivent être ajoutés. |
| [BleedMarks](#BleedMarks) | Spécifie que les marques de débord doivent être ajoutées. |
| [ColorBars](#ColorBars) | Spécifie que les barres de couleur doivent être ajoutées. |
| [None](#None) | Spécifie qu'aucune marque d'imprimante ne doit être ajoutée. |
| [PageInformation](#PageInformation) | Spécifie que les informations de page doivent être ajoutées. |
| [RegistrationMarks](#RegistrationMarks) | Spécifie que les marques d'enregistrement doivent être ajoutées. |
| [TrimMarks](#TrimMarks) | Spécifie que les marques de coupe doivent être ajoutées. |
