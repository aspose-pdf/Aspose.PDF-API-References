```
public interface IIndexBitmapConverter
```

Cette interface est déclarée pour la personnalisation des algorithmes de quantification. Les utilisateurs peuvent implémenter leur propre réalisation de ces algorithmes (par exemple des algorithmes basés sur du code non géré).
