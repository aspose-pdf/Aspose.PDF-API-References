Énumère les styles de terminaison de ligne à utiliser lors du dessin de la ligne.

## Champs

| Champ | Description |
| --- | --- |
| [Butt](#Butt) | Une courte ligne à l'extrémité perpendiculaire à la ligne elle-même. |
| [Circle](#Circle) | Un cercle rempli de la couleur intérieure de l'annotation, le cas échéant. |
| [ClosedArrow](#ClosedArrow) | Deux courtes lignes se rejoignant en un angle aigu comme dans le style OpenArrow et reliées par une troisième ligne pour former une pointe de flèche fermée triangulaire remplie de la couleur intérieure de l'annotation, le cas échéant. |
| [Diamond](#Diamond) | Une forme de losange remplie de la couleur intérieure de l'annotation, le cas échéant. |
| [None](#None) | Pas de terminaison de ligne. |
| [OpenArrow](#OpenArrow) | Deux courtes lignes se rejoignant en un angle aigu pour former une pointe de flèche ouverte. |
| [RClosedArrow](#RClosedArrow) | Une pointe de flèche fermée triangulaire dans la direction opposée à ClosedArrow. |
| [ROpenArrow](#ROpenArrow) | Deux courtes lignes dans la direction opposée à OpenArrow. |
| [Slash](#Slash) | Une courte ligne à l'extrémité à environ 30 degrés dans le sens horaire par rapport à la perpendiculaire à la ligne elle-même. |
| [Square](#Square) | Un carré rempli de la couleur intérieure de l'annotation, le cas échéant. |
