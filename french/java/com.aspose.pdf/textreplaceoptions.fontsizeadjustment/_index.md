Spécifie une politique concernant la façon dont la taille de police du texte doit être ajustée pour tenir dans une zone contenant.

## Champs

| Champ | Description |
| --- | --- |
| [None](#None) | La taille de la police n'est pas modifiée. |
| [ScaleToFill](#ScaleToFill) | La taille de la police est ajustée (réduction et agrandissement) pour que le texte remplisse les limites du rectangle autant que possible. |
| [ShrinkToFit](#ShrinkToFit) | La taille de la police est réduite si le texte est trop grand pour tenir dans les limites. |
