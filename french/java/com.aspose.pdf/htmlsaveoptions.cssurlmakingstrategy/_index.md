Vous pouvez affecter à cette propriété un délégué créé à partir d'une méthode personnalisée qui implémente la création de l'URL du CSS référencé dans le document HTML généré. Par ex., si vous souhaitez que le CSS soit référencé dans le HTML, par ex. comme "otherPage.ASPX?CssID=zjjkklj", alors cette stratégie personnalisée doit renvoyer "otherPage.ASPX?CssID=zjjkklj"
