Représente l'objet PKCS#7 conforme à la spécification PKCS#7 de la RFC 2315 d'Internet, PKCS #7 : Cryptographic Message Syntax, version 1.5. Le condensat SHA1 de la plage d'octets du document est encapsulé dans le champ SignedData de PKCS#7.
