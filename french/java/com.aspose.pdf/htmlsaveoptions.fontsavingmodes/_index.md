Énumère les modes pouvant être utilisés pour l'enregistrement des polices référencées dans le PDF enregistré.

## Champs

| Champ | Description |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | Toutes les polices référencées seront enregistrées et référencées en tant que polices EOT. |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | Toutes les polices référencées seront enregistrées et référencées en tant que polices TTF. |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | Toutes les polices référencées seront enregistrées et référencées en tant que polices WOFF. |
| [DontSave](#DontSave) | Toutes les polices référencées ne seront pas enregistrées. |
| [SaveInAllFormats](#SaveInAllFormats) | Toutes les polices référencées seront enregistrées (et référencées dans le CSS) en tant que 3 fichiers indépendants : EOT, TTH, WOFF. Cela augmente la taille des données de sortie mais rend la sortie adaptée à la grande majorité des navigateurs web. |

### SaveInAllFormats {#SaveInAllFormats}
```
public static final int SaveInAllFormats
```

Toutes les polices référencées seront enregistrées (et référencées dans le CSS) en tant que 3 fichiers indépendants : EOT, TTH, WOFF. Cela augmente la taille des données de sortie mais rend la sortie adaptée à la grande majorité des navigateurs web.
