Énumère le mode de surbrillance de l'annotation, l'effet visuel à utiliser lorsque le bouton de la souris est pressé ou maintenu dans sa zone active.

## Champs

| Champ | Description |
| --- | --- |
| [Invert](#Invert) | Inverser le contenu du rectangle d'annotation. |
| [None](#None) | Pas de surlignage. |
| [Outline](#Outline) | Inverser la bordure de l'annotation. |
| [Push](#Push) | Afficher l'apparence descendante de l'annotation, le cas échéant. |
| [Toggle](#Toggle) | Identique à Push (qui est préféré). |
