Fournit un ensemble d'instances {@link PrintPaperSource} prédéfinies représentant les sources de papier courantes. Cette classe ne peut pas être héritée.

## Champs

| Champ | Description |
| --- | --- |
| [AutomaticFeed](#AutomaticFeed) | Représente une source de papier à alimentation automatique. |
| [Cassette](#Cassette) | Représente la cassette à papier de l'imprimante. |
| [Envelope](#Envelope) | Représente une source de papier à alimentation d'enveloppe automatique. |
| [FormSource](#FormSource) | Représente le bac par défaut de l'imprimante. |
| [LargeCapacity](#LargeCapacity) | Représente le bac à grande capacité de l'imprimante. |
| [LargeFormat](#LargeFormat) | Représente le bac pour le papier au format plus grand. |
| [Lower](#Lower) | Représente le bac inférieur de l'imprimante. |
| [Manual](#Manual) | Représente une source de papier à alimentation manuelle. |
| [ManualFeedEnvelope](#ManualFeedEnvelope) | Représente une source de papier à alimentation d'enveloppe manuelle. |
| [Middle](#Middle) | Représente le bac du milieu de l'imprimante. |
| [SmallFormat](#SmallFormat) | Représente le bac pour le papier au format plus petit. |
| [TractorFeed](#TractorFeed) | Représente une source de papier continu à alimentation à tracteur. |
| [Upper](#Upper) | Représente le bac le plus haut de l'imprimante, ou le bac par défaut si l'imprimante n'a qu'un seul bac. |
