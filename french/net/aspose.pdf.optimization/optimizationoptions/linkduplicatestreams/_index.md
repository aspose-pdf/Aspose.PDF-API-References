## OptimizationOptions.LinkDuplicateStreams property

Si ce drapeau est réglé sur true, les flux de ressources seront analysés. Si des flux en double sont trouvés (c.-à-d. si le contenu du flux est identique), alors ces flux seront stockés comme un seul objet. Cela permet de diminuer la taille du document dans certains cas (par exemple, lorsque le même document a été concaténé plusieurs fois).

```csharp
public bool LinkDuplicateStreams { get; set; }
```
