## ImageCompressionVersion enumeration

Décrit les versions de l'algorithme de compression d'image.

```csharp
public enum ImageCompressionVersion
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Standard | `0` | Algorithme standard. Valeur par défaut. |
| Fast | `2` | Algorithme amélioré, plus rapide que le standard mais non applicable à tous les cas. |
| Mixed | `3` | Utilisez l'algorithme rapide lorsque possible et le standard pour les autres cas. Peut être plus lent que "Fast" mais peut produire une meilleure compression. |
