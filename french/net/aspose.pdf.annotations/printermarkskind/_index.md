## PrinterMarksKind enumeration

Spécifie les types de marques d'imprimante à ajouter à un document.

```csharp
[Flags]
public enum PrinterMarksKind
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Spécifie qu’aucune marque d’imprimante ne doit être ajoutée. |
| TrimMarks | `1` | Spécifie que les marques de coupe doivent être ajoutées. |
| BleedMarks | `2` | Spécifie que les marques de débordement doivent être ajoutées. |
| RegistrationMarks | `4` | Spécifie que les marques d’enregistrement doivent être ajoutées. |
| ColorBars | `8` | Spécifie que les barres de couleur doivent être ajoutées. |
| PageInformation | `10` | Spécifie que les informations de page doivent être ajoutées. |
| All | `1F` | Spécifie que tous les types de marques d’imprimante doivent être ajoutés. |

## Remarques

Cette énumération possède un attribut FlagsAttribute qui permet une combinaison binaire de ses valeurs membres.
