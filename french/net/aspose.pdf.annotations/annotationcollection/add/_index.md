## Add(Annotation, bool) {#add_1}

Ajoute une annotation à la collection. Si la page est pivotée, le rectangle de l'annotation sera recalculé en conséquence.

```csharp
public void Add(Annotation annotation, bool considerRotation)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| annotation | Annotation | Annotation qui doit être ajoutée. |
| considerRotation | Boolean | Si vrai et si la page est pivotée, la position de l'annotation sera recalculée en fonction de la rotation de la page. |
