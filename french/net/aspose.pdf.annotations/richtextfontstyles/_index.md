## RichTextFontStyles enumeration

Options pour le style des fragments de texte dans RichText.

```csharp
[Flags]
public enum RichTextFontStyles
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| ClearExisting | `1` | Si défini, supprime tous les styles existants avant d’appliquer des styles supplémentaires. Lorsqu’il est combiné avec d’autres indicateurs de style (par ex., Bold), il réinitialise d’abord les styles, puis applique ceux spécifiés. Sans cet indicateur, les nouveaux styles sont ajoutés aux styles existants. |
| Bold | `2` | Option qui spécifie Bold. |
| Italic | `4` | Option qui spécifie Italic. |
| Underline | `8` | Option qui spécifie Underline. |
