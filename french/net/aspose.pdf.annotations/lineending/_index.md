## LineEnding enumeration

Énumère les styles de terminaison de ligne à utiliser lors du tracé de la ligne.

```csharp
public enum LineEnding
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Pas de terminaison de ligne. |
| Square | `1` | Un carré rempli avec la couleur intérieure de l'annotation, le cas échéant. |
| Circle | `2` | Un cercle rempli avec la couleur intérieure de l'annotation, le cas échéant. |
| Diamond | `3` | Une forme de losange remplie avec la couleur intérieure de l'annotation, le cas échéant. |
| OpenArrow | `4` | Deux courtes lignes se rejoignant en un angle aigu pour former une pointe de flèche ouverte. |
| ClosedArrow | `5` | Deux courtes lignes se rejoignant en un angle aigu comme dans le style OpenArrow et reliées par une troisième ligne pour former une pointe de flèche fermée triangulaire remplie avec la couleur intérieure de l'annotation, le cas échéant. |
| Butt | `6` | Une courte ligne à l'extrémité perpendiculaire à la ligne elle-même. |
| ROpenArrow | `7` | Deux courtes lignes dans la direction opposée à OpenArrow. |
| RClosedArrow | `8` | Une pointe de flèche fermée triangulaire dans la direction opposée à ClosedArrow. |
| Slash | `9` | Une courte ligne à l'extrémité approximativement à 30 degrés dans le sens horaire par rapport à la perpendiculaire à la ligne elle-même. |
