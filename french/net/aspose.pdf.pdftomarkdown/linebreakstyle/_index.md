## LineBreakStyle enumeration

Représente les styles de saut de ligne possibles pour un fichier.

```csharp
public enum LineBreakStyle
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Windows | `0` | Sélectionne le style d'enveloppe de chaîne Windows (CRLF). |
| Unix | `1` | Sélectionne le style d'enveloppe de chaîne Unix (LF). Utilisé également pour OSX. |
| Auto | `2` | Sélectionne automatiquement le type d'enveloppe de chaîne en fonction du système d'exploitation. |
