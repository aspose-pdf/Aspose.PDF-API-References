## ComparisonOptions.ExcludeTables property

Obtient et définit l'option qui détermine si les tables sont exclues de la comparaison. Cette option ne peut pas être définie en même temps que l'option [`ExtractionArea`](../extractionarea/). La valeur par défaut est `false`.

```csharp
public bool ExcludeTables { get; set; }
```
