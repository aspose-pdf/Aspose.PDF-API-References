## ComparisonOptions.ExcludeAreas2 property

Obtient et définit les zones à exclure. Utilisé pour la deuxième page ou le document dans la méthode de comparaison. Cette option peut être définie avec [`ExcludeTables`](../excludetables/). Cette option ne peut pas être définie avec l'option [`ExtractionArea`](../extractionarea/).

public Rectangle[] ExcludeAreas2 { get; set; }
