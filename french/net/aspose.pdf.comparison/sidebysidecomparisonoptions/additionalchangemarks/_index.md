## SideBySideComparisonOptions.AdditionalChangeMarks property

Obtenir et définir la propriété qui détermine si des marqueurs de changement supplémentaires sont affichés. Si elle est définie, elle affiche les marques de changement qui ne sont pas sur la page actuelle mais présentes sur une autre page. Si le changement se situe entre des mots, la marque peut ne pas être positionnée exactement par rapport au caractère d'espace. La valeur par défaut est `false`.

```csharp
public bool AdditionalChangeMarks { get; set; }
```
