## TextExtractionOptions.ScaleFactor property

Obtient ou définit le facteur qui sera appliqué pour mettre à l'échelle la taille de la police lors de l'extraction en mode pur. Une valeur plus faible entraîne davantage d'espaces dans le texte extrait. La valeur par défaut est 1 - aucune mise à l'échelle ; définir la valeur à zéro permet à l'algorithme de choisir automatiquement l'échelle.

public double ScaleFactor { get; set; }
