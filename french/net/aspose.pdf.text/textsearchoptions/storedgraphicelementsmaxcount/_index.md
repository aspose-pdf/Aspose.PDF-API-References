## TextSearchOptions.StoredGraphicElementsMaxCount property

Obtient ou définit la valeur qui limite la recherche de graphiques liés au texte (soulignement, arrière-plan, etc.) sur une page au nombre spécifié d'éléments. La valeur par défaut est 250. Réduisez la valeur en cas de problèmes de performances, augmentez-la si certains éléments graphiques n'ont pas été trouvés.

```csharp
public int StoredGraphicElementsMaxCount { get; set; }
```
