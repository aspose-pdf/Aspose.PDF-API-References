## TextSearchOptions.IgnoreResourceFontErrors property

Obtient ou définit l'indication selon laquelle les erreurs liées à l'absence de police seront ignorées par l'absorbeur de texte (fragment). true - signifie que les erreurs d'absence de police seront ignorées. Les segments de texte faisant référence à des ressources incorrectes seront sautés lors du traitement. false (par défaut) - l'erreur d'absence de police interrompra le traitement en lançant une exception.

public bool IgnoreResourceFontErrors { get; set; }
