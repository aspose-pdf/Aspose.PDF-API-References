## TextState.BackgroundColor property

Définit la couleur d'arrière-plan du texte.

```csharp
public virtual Color BackgroundColor { get; set; }
```

## Remarques

Notez que la valeur n'est pas conservée en tant que caractéristique de texte dans le document. Le getter de la propriété BackgroundColor fonctionne pour un objet dans le cas où il a été explicitement défini auparavant avec le setter BackgroundColor pour ces objets. La propriété est utilisée par le runtime dans le contexte du processus actuel de génération/modification.
