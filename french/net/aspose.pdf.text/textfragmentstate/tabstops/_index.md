## TextFragmentState.TabStops property

Obtient les tabulations du texte.

```csharp
public TabStops TabStops { get; }
```

## Remarques

Notez que la propriété Tabstops ne fonctionne que dans les scénarios de génération de nouveaux documents. Les tabulations peuvent être ajoutées lors de l'initialisation du [`TextFragment`](../../textfragment/). Les tabulations doivent être construites avant le texte.
