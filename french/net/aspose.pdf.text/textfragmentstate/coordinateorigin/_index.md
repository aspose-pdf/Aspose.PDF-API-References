## TextFragmentState.CoordinateOrigin property

Obtient ou définit le CoordinateOrigin du texte. Si le CoordinateOrigin est Descender, la coordonnée Y du texte correspond au point le plus bas de la police. Si le CoordinateOrigin est BaseLine, la coordonnée Y du texte correspond à la ligne de base de la police. La valeur par défaut est Descender. Si la valeur Descent de la police est trop grande, le texte peut être rendu plus haut que d'autres polices. Dans ce cas, le CoordinateOrigin BaseLine peut être sélectionné pour un meilleur rendu du texte.

public override CoordinateOrigin CoordinateOrigin { get; set; }
