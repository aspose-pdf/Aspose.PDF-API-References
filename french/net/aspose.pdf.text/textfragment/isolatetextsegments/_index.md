```csharp
public TextSegmentCollection IsolateTextSegments(int startIndex, int length)
```

| Paramètre | Type | Description |

| startIndex | Int32 | Position dans le texte à partir de laquelle le(s) nouveau(x) [`TextSegment`](../../textsegment/)(s) commencera. |
