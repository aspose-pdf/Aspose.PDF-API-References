## TextReplaceOptions.FontSizeAdjustment enumeration

Spécifie une politique sur la façon dont la taille de police du texte doit être ajustée pour tenir dans une zone contenant.

```csharp
public enum FontSizeAdjustment
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | La taille de police n'est pas modifiée. |
| ShrinkToFit | `1` | La taille de police est réduite si le texte est trop grand pour tenir dans les limites. La taille de police n'est jamais augmentée si le texte est plus petit que les limites. |
| ScaleToFill | `2` | La taille de police est ajustée (réduction et agrandissement) pour que le texte remplisse les limites du rectangle autant que possible. |
