## HtmlSaveOptions.SaveTransparentTexts field

Le PDF peut contenir des textes transparents pouvant être sélectionnés dans le presse‑papier (cela se produit généralement lorsque le document contient des images et des textes OCRisés extraits). Ce paramètre indique au convertisseur s'il faut enregistrer ces textes comme des textes transparents sélectionnables dans le HTML résultant.

```csharp
public bool SaveTransparentTexts;
```
