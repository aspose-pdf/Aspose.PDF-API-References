## HtmlSaveOptions.PagesFlowTypeDependsOnViewersScreenSize field

Si l’attribut 'SplitOnPages=false', alors l’ensemble du HTML représentant toutes les pages PDF d’entrée sera placé dans un seul grand fichier HTML résultant. Ce drapeau définit si le HTML résultant sera généré de manière à ce que le flux des zones représentant les pages PDF dans le HTML dépendre de la résolution d’écran du visualiseur. Supposons que la largeur de l’écran du visualiseur soit suffisante pour placer deux pages ou plus côte à côte en direction horizontale. Si ce drapeau est défini sur true, alors cette possibilité sera utilisée (autant de pages seront affichées horizontalement côte à côte que possible, puis le groupe horizontal suivant sera affiché sous le premier). Sinon, les pages s’écouleront de la façon suivante : la page suivante se place toujours sous la précédente.

```csharp
public bool PagesFlowTypeDependsOnViewersScreenSize;
```
