## HtmlSaveOptions.DefaultFontName property

Spécifie le nom d'une police installée qui est utilisée pour remplacer toute police de document qui n'est pas incorporée et n'est pas installée dans le système. Si null, la police de substitution par défaut est utilisée.

```csharp
public string DefaultFontName { get; set; }
```

### Property Value

Nom de police
