## HtmlSaveOptions.IgnoreResourceFontErrors property

Obtient ou définit l’indication selon laquelle les erreurs liées à l’absence de police seront ignorées. true - signifie que les erreurs d’absence de police seront ignorées. Les segments de texte qui font référence à des ressources incorrectes seront ignorés pendant le traitement. false par défaut

public bool IgnoreResourceFontErrors { get; set; }
