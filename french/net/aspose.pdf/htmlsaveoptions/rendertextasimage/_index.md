## HtmlSaveOptions.RenderTextAsImage property

Si l’attribut RenderTextAsImage est défini sur true, le texte de la source devient une image dans le HTML. Cela peut être utile pour rendre le texte non sélectionnable ou si le texte HTML n’est pas rendu correctement.

public bool RenderTextAsImage { get; set; }
