## HtmlSaveOptions.MinimalLineWidth property

Cet attribut définit la largeur minimale de la ligne du chemin graphique. Si l’épaisseur de la ligne est inférieure à 1 px, Adobe Acrobat l’arrondit à cette valeur. Ainsi, cet attribut peut être utilisé pour émuler ce comportement dans les navigateurs HTML.

```csharp
public float MinimalLineWidth { get; set; }
```
