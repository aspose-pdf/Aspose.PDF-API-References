## HorizontalAlignment enumeration

Décrit l'alignement horizontal.

```csharp
public enum HorizontalAlignment
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Aucun alignement. |
| Left | `1` | Aligner à gauche. |
| Center | `2` | Alignement centré. |
| Right | `3` | Aligner à droite. |
| Justify | `4` | Alignement justifié. Le texte sera aligné sur les marges gauche et droite. |
| FullJustify | `5` | Similaire à l'alignement 'Justify', sauf que la toute dernière ligne sera uniquement alignée à gauche en mode 'Justify', tandis qu'en mode 'FullJustify' toutes les lignes seront alignées à gauche et à droite. |
