## HtmlFragment.HtmlLoadOptions property

Obtient ou définit HtmlLoadOptions qui seront utilisés pour le chargement (et le rendu) du HTML dans cette instance de classe. Veuillez l'utiliser lorsqu'il est nécessaire d'utiliser un paramètre spécifique pour l'importation du HTML pour telle ou telle instance (par ex. lorsque cette instance ou cette autre doit utiliser un BasePath spécifique pour le HTML importé ou doit utiliser un chargeur spécifique de ressources externes). Si le paramètre est par défaut (null), alors les options de chargement HTML standard seront utilisées.

```csharp
public HtmlLoadOptions HtmlLoadOptions { get; set; }
```
