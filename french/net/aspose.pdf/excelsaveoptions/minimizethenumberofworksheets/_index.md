## ExcelSaveOptions.MinimizeTheNumberOfWorksheets property

Définissez true si vous devez réduire le nombre de feuilles de calcul dans le classeur résultant. La valeur par défaut est false ; cela signifie que chaque page PDF sera enregistrée comme une feuille séparée.

```csharp
public bool MinimizeTheNumberOfWorksheets { get; set; }
```
