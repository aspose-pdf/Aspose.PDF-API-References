## HtmlSaveOptions.HtmlImageSavingInfo.ParentType field

L’image enregistrée peut concerner le HTML lui‑même ou être extraite d’un SVG intégré au HTML. Cette propriété peut indiquer au code personnalisé le type de parent de l’image traitée. Elle est définie par le convertisseur et peut être utilisée dans le code personnalisé pour décider de ce qui doit être fait avec cette image (par ex. le code personnalisé peut décider où enregistrer l’image ou comment elle doit être référencée dans le contenu du parent).

```csharp
public ImageParentTypes ParentType;
```
