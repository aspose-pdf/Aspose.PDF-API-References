## XImage.Name property

Obtient ou définit le nom de l'image. Veuillez noter que si vous modifiez le nom de l'image qui possède des références dans le contenu des pages, le document peut devenir incorrect. Veuillez utiliser la méthode XImage.Rename dans ce cas.
