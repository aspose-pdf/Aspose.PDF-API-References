## XImage.ImageMask property

Obtient un indicateur indiquant si l'image doit être traitée comme un masque d'image (voir 8.9.6, "Masked Images"). Si cet indicateur est true, la valeur de BitsPerComponent doit être 1 et Mask et ColorSpace ne doivent pas être spécifiés ; les zones non masquées doivent être peintes en utilisant la couleur de tracé actuelle. Valeur par défaut : false.

```csharp
public bool ImageMask { get; }
```

### Property Value

True si l'image est un masque d'image.
