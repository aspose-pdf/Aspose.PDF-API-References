## ToUnicodeProcessingRules.MapNonLinkedSymbolsOnSpace property

Certaines polices ne fournissent pas d'informations sur les unicodes pour certains symboles de texte. Cette absence d'information déclenche une erreur "Text cannot be mapped to Unicode". Utilisez ce drapeau pour mapper les symboles non liés sur le caractère unicode "espace" (code 32).

```csharp
public bool MapNonLinkedSymbolsOnSpace { get; set; }
```
