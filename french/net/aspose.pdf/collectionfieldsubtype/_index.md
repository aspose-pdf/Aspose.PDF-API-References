## CollectionFieldSubtype enumeration

Représente le paramètre de sous-type d’un champ dans une collection sceme.

```csharp
public enum CollectionFieldSubtype
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Le sous‑type n'est pas défini. |
| S | `1` | Un type texte. Les données du champ doivent être stockées sous forme de chaîne texte PDF. |
| D | `2` | Un type date. Les données du champ doivent être stockées sous forme de chaîne date PDF. |
| N | `3` | Un type nombre. Les données du champ doivent être stockées sous forme de nombre PDF. |
| F | `4` | Les données du champ doivent être le nom de fichier du flux de fichier intégré, tel qu'identifié par l'entrée UF de la spécification du fichier, si elle est présente ; sinon par l'entrée F de la spécification du fichier. |
| Desc | `5` | Les données du champ doivent être le nom de fichier du flux de fichier intégré, tel qu'identifié par l'entrée UF de la spécification du fichier, si elle est présente ; sinon par l'entrée F de la spécification du fichier. |
| ModDate | `6` | Les données du champ doivent être la date de modification du flux de fichier intégré, telle qu'identifiée par l'entrée ModDate du dictionnaire des paramètres du fichier intégré. |
| CreationDate | `7` | Les données du champ doivent être la date de création du flux de fichier intégré, telle qu'identifiée par l'entrée CreationDate du fichier intégré. |
| Size | `8` | Les données du champ doivent être la taille du fichier intégré, telle qu'identifiée par l'entrée Size du dictionnaire des paramètres du fichier intégré. |
| CompressedSize | `9` | (PDF 2.0) Les données du champ sont la longueur du flux de fichier intégré, telle qu'identifiée par l'entrée Length du dictionnaire du flux de fichier intégré, et les deux valeurs doivent être identiques. |
