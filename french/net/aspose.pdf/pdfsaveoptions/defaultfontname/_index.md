## PdfSaveOptions.DefaultFontName property

Nom de police utilisé par défaut pour les polices absentes sur l'ordinateur. Lorsque le document PDF enregistré contient des polices qui ne sont pas disponibles dans le document lui‑même et sur l'appareil, l'API remplace ces polices par la police par défaut (si une police avec `DefaultFontName` est trouvée sur l'appareil).

```csharp
public string DefaultFontName { get; set; }
```
