## HtmlSaveOptions.HtmlMarkupGenerationModes enumeration

Parfois, des exigences spécifiques pour le HTML créé sont présentes. Cette énumération définit les modes de préparation du HTML qui peuvent être utilisés lors de la conversion de PDF en HTML afin de répondre à ces exigences spécifiques.

```csharp
public enum HtmlMarkupGenerationModes
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| WriteAllHtml | `0` | Mode par défaut : aucune exigence spécifique n'est présente. Le résultat généré contiendra toutes les parties du HTML sans aucun traitement supplémentaire spécial. |
| WriteOnlyBodyContent | `1` | tout le contenu HTML qui se trouve en dehors du corps du HTML sera supprimé, c’est‑à‑dire qu’il ne restera que le contenu qui se trouve à l’intérieur des balises \c \ \c \ |
