## AutoTaggingSettings.Default property

Obtient les paramètres par défaut pour la fonctionnalité d’autotagging dans les documents PDF.

```csharp
public static AutoTaggingSettings Default { get; }
```

## Remarques

Les paramètres par défaut activent l'auto-étiquetage et utilisent la stratégie automatique pour la reconnaissance des titres. Ces paramètres peuvent être utilisés comme configuration de base pour la conversion de format PDF ou d'autres opérations nécessitant l'étiquetage automatique du contenu PDF.
