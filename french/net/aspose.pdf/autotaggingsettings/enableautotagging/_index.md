## AutoTaggingSettings.EnableAutoTagging property

Obtient ou définit une valeur indiquant si la fonctionnalité d’autotagging est activée.

```csharp
public bool EnableAutoTagging { get; set; }
```

## Remarques

Lorsqu'elle est activée, la fonctionnalité d'auto-étiquetage génère automatiquement du contenu étiqueté pour le document PDF, ce qui peut améliorer l'accessibilité et la structure.
