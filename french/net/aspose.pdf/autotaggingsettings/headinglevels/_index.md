## AutoTaggingSettings.HeadingLevels property

Obtient ou définit les niveaux de titres utilisés pour déterminer la structure des titres dans un document PDF.

```csharp
public HeadingLevels HeadingLevels { get; set; }
```

## Remarques

La propriété `HeadingLevels` permet de configurer le mappage des tailles de police aux niveaux de titres. Elle est utilisée pendant le processus d'auto-étiquetage pour identifier et attribuer les niveaux de titres appropriés en fonction de la taille de police des éléments texte du document.
