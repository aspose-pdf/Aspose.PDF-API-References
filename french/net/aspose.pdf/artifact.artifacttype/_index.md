## Artifact.ArtifactType enumeration

Énumération des types d'artefacts possibles.

```csharp
public enum ArtifactType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Pagination | `0` | Artefacts de pagination. Fonctionnalités de page auxiliaires telles que les en-têtes courants et les folios (numéros de page). |
| Layout | `1` | Artefacts de mise en page. Éléments purement esthétiques typographiques ou de conception tels que les lignes de notes de bas de page ou les écrans d'arrière-plan. |
| Page | `2` | Artefacts de page. Aides à la production extérieures au document lui‑même, telles que les marques de coupe et les barres de couleur. |
| Background | `3` | Artefacts d'arrière-plan. Images, motifs ou blocs colorés. |
| Undefined | `4` | Le type d'artefact n'est pas défini ou est inconnu. |
