## HtmlSaveOptions.CssUrlRequestInfo.CustomProcessingCancelled field

Doit être défini par le code personnalisé s'il ne peut pas ou ne doit pas définir l'URL qui sera utilisée dans le HTML généré pour référencer ce CSS. Si c'est 'true', le fichier CSS sera enregistré de manière standard à l'emplacement standard.

```csharp
public bool CustomProcessingCancelled;
```
