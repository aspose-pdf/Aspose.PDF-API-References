## Stamp.Background property

Définit ou récupère une valeur booléenne indiquant que le contenu est tamponné en arrière-plan. Si la valeur est vraie, le contenu du tampon est placé en bas. Par défaut, la valeur est fausse, le contenu du tampon est placé en haut.

public bool Background { get; set; }
