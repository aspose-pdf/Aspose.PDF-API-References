## HtmlLoadOptions.InputEncoding property

Obtient ou définit l’attribut spécifiant l’encodage utilisé pour ce document lors de l’analyse. Si cet attribut est nul, l’encodage sera déterminé à partir de l’attribut de jeu de caractères du document.

public string InputEncoding { get; set; }
