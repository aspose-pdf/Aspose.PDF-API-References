## DocSaveOptions.MaxDistanceBetweenTextLines property

Ce paramètre est utilisé pour regrouper les lignes de texte en paragraphes. Il détermine à quelle distance peuvent se trouver deux lignes de texte relatives. Spécifié en centaines de pour cent de la hauteur des lignes de texte.

```csharp
public float MaxDistanceBetweenTextLines { get; set; }
```
