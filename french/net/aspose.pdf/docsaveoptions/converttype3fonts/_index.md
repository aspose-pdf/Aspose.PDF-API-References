## DocSaveOptions.ConvertType3Fonts property

Obtient ou définit la conversion pour les polices Type3. Dans les polices Type3, les glyphes doivent être définis par des flux d'opérateurs graphiques. Cela signifie que dans la sortie DOC/DOCX nous voyons des images au lieu du texte. Définissez ce drapeau sur true pour convertir les polices Type3 en TTF et obtenir du texte dans le fichier résultant.

```csharp
public bool ConvertType3Fonts { get; set; }
```
