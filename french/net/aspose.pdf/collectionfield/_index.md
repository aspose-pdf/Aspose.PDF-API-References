## Propriétés

| Nom | Description |
| --- | --- |
| [E](../../aspose.pdf/collectionfield/e/) { get; } | Obtient un indicateur indiquant si le processeur PDF interactif doit fournir une prise en charge de la modification de la valeur du champ. Valeur par défaut : false |
| [FiledType](../../aspose.pdf/collectionfield/filedtype/) { get; } | Obtient le type d’une valeur de champ dans une collection de schéma. Ce champ décrit le type de valeur correspondant à [`Subtype`](./subtype/). |
| [N](../../aspose.pdf/collectionfield/n/) { get; } | Obtient le nom de champ textuel qui doit être présenté à l’utilisateur par le processeur PDF interactif |

| [Subtype](../../aspose.pdf/collectionfield/subtype/) { get; } | Obtient le sous‑type d’une valeur de champ dans une collection de schéma. Le sous‑type du champ de collection ou du champ lié à un fichier que ce dictionnaire décrit. Cette entrée identifie le type de données qui doit être stocké dans le champ. |
| [V](../../aspose.pdf/collectionfield/v/) { get; } | Obtient la visibilité initiale du champ dans l’interface utilisateur. Valeur par défaut : true. |
