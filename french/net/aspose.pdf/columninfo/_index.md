## Propriétés

| Nom | Description |
| --- | --- |
| [ColumnCount](../../aspose.pdf/columninfo/columncount/) { get; set; } | Obtient ou définit une valeur entière indiquant le nombre de colonnes. |
| [ColumnSpacing](../../aspose.pdf/columninfo/columnspacing/) { get; set; } | Obtient ou définit une chaîne contenant l'espacement entre les colonnes. La valeur de chaque colonne doit être séparée par un espace. L'unité par défaut est le point, mais le cm, le pouce et le pourcentage de la largeur disponible sont également pris en charge. Par exemple, "120 2.5cm 1.5inch" |
