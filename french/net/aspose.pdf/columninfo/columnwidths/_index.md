## ColumnInfo.ColumnWidths property

Obtient ou définit une chaîne contenant la largeur des colonnes. La valeur de chaque colonne doit être séparée par un espace. L'unité par défaut est le point, mais le cm, le pouce et le pourcentage de la largeur disponible sont également pris en charge. Par exemple, "120 2.5cm 1.5inch"

public string ColumnWidths { get; set; }
