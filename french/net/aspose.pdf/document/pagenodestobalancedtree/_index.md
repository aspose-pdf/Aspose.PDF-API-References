## Document.PageNodesToBalancedTree method

Organise les nœuds de l'arbre des pages d'un document en un arbre équilibré. Seulement si le document possède plus de nodesNumInSubtrees objets de page, sinon cela ne fait rien. N'appelez pas cette méthode pendant l'itération sur les éléments Pages, cela peut donner des résultats imprévisibles.

```csharp
public void PageNodesToBalancedTree(byte nodesNumInSubtrees = 10)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| nodesNumInSubtrees | Byte | Nombre souhaité de sous-nœuds. La valeur par défaut est dix. |
