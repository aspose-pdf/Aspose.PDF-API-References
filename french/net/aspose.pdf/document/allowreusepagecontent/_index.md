## Document.AllowReusePageContent property

Permet de fusionner le contenu des pages pour optimiser la taille du document. Si utilisé, alors des pages différentes mais dupliquées peuvent référencer le même objet de contenu. Veuillez noter que ce mode peut entraîner des effets secondaires tels que la modification du contenu d'une page lorsque une autre page est modifiée.

```csharp
public bool AllowReusePageContent { get; set; }
```
