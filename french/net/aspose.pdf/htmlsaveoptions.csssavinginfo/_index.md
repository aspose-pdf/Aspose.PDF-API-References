## HtmlSaveOptions.CssSavingInfo class

Cette classe représente un ensemble de données liées à l'enregistrement personnalisé du CSS lors de la conversion de PDF au format HTML.

```csharp
public class CssSavingInfo
```

## Champs

| Nom | Description |
| --- | --- |
| [ContentStream](../../aspose.pdf/htmlsaveoptions.csssavinginfo/contentstream) | Défini par le convertisseur. Représente le contenu binaire du CSS enregistré. |
| [CssNumber](../../aspose.pdf/htmlsaveoptions.csssavinginfo/cssnumber) | Défini par le convertisseur. Lors de la conversion, plusieurs fichiers CSS sont créés. Cette propriété indique l'ordre du fichier CSS enregistré pendant la conversion. Elle peut être utilisée dans la logique du code personnalisé pour décider comment traiter ou où enregistrer le contenu CSS. |
| [SupposedURL](../../aspose.pdf/htmlsaveoptions.csssavinginfo/supposedurl) | Défini par le convertisseur. Nom de fichier supposé qui provient du convertisseur vers le code de la méthode personnalisée. Peut être utilisé dans le code personnalisé pour décider comment traiter ou où enregistrer le contenu. |
