## OutlineCollection.VisibleCount property

Count est la somme du nombre d'éléments de plan descendants visibles à tous les niveaux. Remarque : veuillez ne pas confondre avec Count qui représente le nombre d'éléments dans la collection.

public override int VisibleCount { get; }
