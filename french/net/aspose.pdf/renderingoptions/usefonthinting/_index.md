## RenderingOptions.UseFontHinting property

L'utilisation de ce drapeau active le mécanisme d'optimisation des polices (font hinting). Le hinting des polices consiste à utiliser des instructions mathématiques pour ajuster l'affichage d'une police vectorielle. Dans certains cas, activer ce drapeau peut résoudre des problèmes de lisibilité du texte. À l'heure actuelle, l'utilisation de ce drapeau ne produit d'effet que pour les polices TTF, si ces polices sont utilisées dans le document source.

```csharp
public bool UseFontHinting { get; set; }
```
