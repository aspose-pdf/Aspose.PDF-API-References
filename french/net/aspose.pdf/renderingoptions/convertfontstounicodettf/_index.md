## RenderingOptions.ConvertFontsToUnicodeTTF property

Indique que toutes les polices seront converties en versions Unicode TTF. Cela est utile pour des raisons de compatibilité et pour optimiser l'utilisation des polices, car chaque nouvelle police TTF ne contiendra pas tous les symboles de la police source, mais uniquement les symboles utilisés dans le texte.

```csharp
public bool ConvertFontsToUnicodeTTF { get; set; }
```
