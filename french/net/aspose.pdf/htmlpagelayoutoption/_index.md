## HtmlPageLayoutOption enumeration

Spécifie les indicateurs qui, avec d'autres options, déterminent les tailles et les mises en page des pages.

```csharp
public enum HtmlPageLayoutOption
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| None | `0` | Valeur par défaut indiquant que HtmlPageLayoutOption n’affectera pas les tailles et les mises en page des pages. |
| FitToWidestContentWidth | `3` | Indique que la largeur de la page est déterminée à partir de la taille du contenu lui‑même, et non à partir de la largeur de page spécifiée. |
| ScaleToPageWidth | `256` | Indique que le contenu du document sera mis à l’échelle pour s’adapter à la page. |
