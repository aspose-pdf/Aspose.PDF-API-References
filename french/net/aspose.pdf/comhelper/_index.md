## Remarques

Utilisez la classe ComHelper pour charger un document à partir d'un fichier ou d'un flux dans un objet Document dans une application COM. La classe Document fournit un constructeur par défaut pour créer un nouveau document et propose également des constructeurs surchargés pour charger un document à partir d'un fichier ou d'un flux. Si vous utilisez Aspose.Words depuis une application .NET, vous pouvez utiliser directement tous les constructeurs de Document, mais si vous utilisez Aspose.Pdf depuis une application COM, seul le constructeur par défaut de Document est disponible.
