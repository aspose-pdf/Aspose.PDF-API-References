## Add(XImage) {#add_2}

Ajoute une nouvelle image à la liste Image. Cette méthode ajoute l'image en tant que référence au même PdfObject (ce qui permet de réduire la taille du fichier)

```csharp
public string Add(XImage image)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| image | XImage | XImage à ajouter. |

### Valeur de retour

Nom de l'image ajoutée.
