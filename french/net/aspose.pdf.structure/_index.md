L’espace de noms **Aspose.Pdf.Structure** fournit des classes qui aident à travailler avec la structure logique d’un document, présentant l’organisation du document en chapitres et sections ou l’identification d’éléments spéciaux tels que les figures, les tableaux et les notes de bas de page.

| Classe | Description |
| --- | --- |

| [ElementCollection](./elementcollection/) | Collection d'éléments de base de la structure logique. |
| [FigureElement](./figureelement/) | Classe représentant la figure de la structure logique. |
| [RootElement](./rootelement/) | Élément racine de la structure. |
| [StructElement](./structelement/) | Élément de structure général. |
| [TextElement](./textelement/) | Élément de texte général de la structure logique du document. |
