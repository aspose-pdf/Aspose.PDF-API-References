## PdfAOptionsBase.OptimizeFileSize property

Obtient ou définit une valeur indiquant s'il faut tenter de réduire la taille du fichier pendant le processus de conversion PDF/A.

```csharp
public bool OptimizeFileSize { get; set; }
```

### Property Value

`true` si la taille du fichier doit être réduite au maximum ; sinon, `false`.

## Remarques

Lorsque la valeur est `true`, le processus de conversion tentera de minimiser la taille du fichier résultant. Cela peut affecter les performances du processus de conversion.
