## DefaultMetadataProperties enumeration

Énumération des propriétés XMP standard.

```csharp
public enum DefaultMetadataProperties
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Advisory | `0` | xmp:Advisory property. Un tableau non ordonné spécifiant les propriétés qui ont été modifiées en dehors de l'application d'édition. Chaque élément doit contenir un seul /// espace de noms et XPath séparés par un espace ASCII. |
| BaseURL | `1` | xmp:BaseURL property. L'URL de base pour les URL relatives dans le contenu du document. Si ce document contient des liens Internet, et que ces liens sont relatifs, /// ils sont relatifs à cette URL de base. Cette propriété fournit une méthode standard pour que les URL relatives intégrées soient interprétées par les outils. /// Les outils d'édition Web doivent définir la valeur en fonction de leur notion de l'endroit où les URL seront interprétées. |
| CreateDate | `2` | xmp:CreateDate property. La date et l'heure auxquelles la ressource a été créée à l'origine. |
| CreatorTool | `3` | xmp:CreatorTool property. Le nom du premier outil connu utilisé pour créer la ressource. |
| Identifier | `4` | xmp:Identifier property. Un tableau non ordonné de chaînes de texte qui identifient de manière unique la ressource dans un contexte donné. |
| MetadataDate | `5` | xmp:MetadataDate property. La date et l'heure auxquelles les métadonnées de cette ressource ont été modifiées pour la dernière fois. |
| ModifyDate | `6` | xmp:ModifyDate property. La date et l'heure auxquelles la ressource a été modifiée pour la dernière fois. |
| Nickname | `7` | xmp:Nickname property. Un nom informel court pour la ressource. |
| Thumbnails | `8` | xmp:Thumbnails property. Un tableau alternatif d'images miniatures pour un fichier, pouvant différer par des caractéristiques telles que la taille ou le codage de l'image. |
