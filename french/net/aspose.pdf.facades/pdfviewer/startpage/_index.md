## PdfViewer.StartPage event

Se produit avant qu'une page commence à imprimer.

```csharp
public event EventHandler<StartEndPageEventArgs> StartPage;
```

## Remarques

Cet événement est déclenché pour chaque page sur le point d'être imprimée. Il peut être utilisé pour exécuter des actions personnalisées avant le démarrage de l'impression de la page.
