## PdfViewer.PrintAsImage property

Définit ou obtient un mode pour PdfViewer afin d'imprimer en tant qu'image.

```csharp
public bool PrintAsImage { get; set; }
```

## Remarques

Si true, imprime toujours en tant qu'image (génère l'image qui est imprimée). Si false, imprime directement sur le dispositif si toutes les fonctionnalités sont prises en charge. Dans le cas où le document contient des fonctionnalités non prises en charge, le système peut automatiquement décider d'imprimer en tant qu'image. La valeur par défaut est false.
