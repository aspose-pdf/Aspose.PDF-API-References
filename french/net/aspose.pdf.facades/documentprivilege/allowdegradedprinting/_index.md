## DocumentPrivilege.AllowDegradedPrinting property

Définit la permission qui autorise l'impression de qualité réduite ou non. true signifie autorisé et false signifie interdit.

```csharp
public bool AllowDegradedPrinting { get; set; }
```

## Remarques

Lorsqu'elle est définie, l'impression sera limitée à une représentation de bas niveau de l'apparence, éventuellement de qualité dégradée.
