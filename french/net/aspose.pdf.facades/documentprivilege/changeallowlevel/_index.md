## DocumentPrivilege.ChangeAllowLevel property

Obtient et définit le niveau de modification du privilège du document. Identique aux paramètres Changes Allowed d'Adobe Professional. 0 : Aucun. 1 : Insertion, suppression et rotation des pages. 2 : Remplissage des champs de formulaire et signature des champs de signature existants. 3 : Commentaire, remplissage des champs de formulaire et signature des champs de signature existants. 4 : Tout sauf l'extraction des pages.

```csharp
public int ChangeAllowLevel { get; set; }
```

## Remarques

Si la propriété a une valeur de -1, le niveau est indéfini.
