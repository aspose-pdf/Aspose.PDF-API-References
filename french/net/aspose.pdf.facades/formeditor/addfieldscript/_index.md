## FormEditor.AddFieldScript method

Ajoute du JavaScript pour un champ PushButton. Si un ancien événement existe, le nouvel événement est ajouté après celui-ci.

```csharp
public bool AddFieldScript(string fieldName, string script)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| fieldName | String | Le nom complet du champ. |
| script | String | Le script Java à ajouter/placer dans un champ de bouton poussoir. |

### Valeur de retour

Vrai si le script a été ajouté avec succès.
