## FormDataConverter.Table property

Obtient ou définit le conteneur de données intermédiaire, un DataTable. Il doit être défini avant de convertir des données d'un format à un autre format. Les Columns et le TableName du DataTable doivent être définis. Le TableName est le nom de la Table dans la base de données. Le ColumnName de chaque colonne est le nom de champ qualifié du pdf. La Caption de chaque colonne est le nom de la colonne de la table dans la base de données. Si le nom du champ est identique au nom de la colonne de la table, la Caption n'a pas besoin d'être spécifiée.

public DataTable Table { get; set; }
