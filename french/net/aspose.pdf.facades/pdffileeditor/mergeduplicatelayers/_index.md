## PdfFileEditor.MergeDuplicateLayers property

Le contenu optionnel des documents concaténés portant le même nom sera fusionné en une seule couche dans le document résultant si cette propriété est vraie. Sinon, les couches portant le même nom seront enregistrées comme des couches distinctes dans le document résultant.

```csharp
public bool MergeDuplicateLayers { get; set; }
```
