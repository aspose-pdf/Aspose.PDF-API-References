## ITaggedContent.Save method

Enregistre l'état actuel du contenu balisé dans le document PDF associé.

```csharp
public void Save()
```

## Remarques

Cette méthode garantit que tous les éléments de contenu balisé sont correctement mis à jour et enregistrés dans le Document PDF. Elle effectue les opérations nécessaires telles que la mise à jour du MCID pour les éléments MCR, la définition des opérateurs BDC, et assure la conformité aux normes PDF/UA.
