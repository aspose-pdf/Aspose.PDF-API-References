## VectorStore class

Un assistant pour créer un magasin vectoriel avec file_ids et l'attacher à ce fil. Un maximum de 1 magasin vectoriel peut être attaché au fil.

```csharp
public class VectorStore
```

## Propriétés

| Nom | Description |
| --- | --- |
| [FileIds](../../aspose.pdf.ai/vectorstore/fileids/) { get; set; } | Obtient ou définit une liste d'ID de fichiers à ajouter au magasin de vecteurs. Un magasin de vecteurs peut contenir au maximum 10 000 fichiers. |
| [Metadata](../../aspose.pdf.ai/vectorstore/metadata/) { get; set; } | Obtient ou définit un ensemble de 16 paires clé-valeur pouvant être attachées à un magasin de vecteurs. Cela peut être utile pour stocker des informations supplémentaires sur le magasin de vecteurs dans un format structuré. Les clés peuvent contenir jusqu'à 64 caractères et les valeurs jusqu'à 512 caractères. |
