## VectorStore.Metadata property

Obtient ou définit un ensemble de 16 paires clé-valeur pouvant être attachées à un magasin de vecteurs. Cela peut être utile pour stocker des informations supplémentaires sur le magasin de vecteurs dans un format structuré. Les clés peuvent contenir jusqu'à 64 caractères et les valeurs jusqu'à 512 caractères.

```csharp
public Dictionary<string, string> Metadata { get; set; }
```
