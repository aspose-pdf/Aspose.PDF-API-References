## MessageContentRequest.CreateImageUrlContent method

Crée un contenu d'URL d'image pour un message.

```csharp
public static MessageContentRequest CreateImageUrlContent(string imageUrl, string detail = "auto")
```

| Paramètre | Type | Description |
| --- | --- | --- |
| imageUrl | String | L'URL de l'image. |
| détail | String | Le détail de l'URL de l'image. Spécifie le niveau de détail de l'image si indiqué par l'utilisateur. "low" utilise moins de jetons, vous pouvez choisir une haute résolution en utilisant "high". La valeur par défaut est "auto". |

### Valeur de retour

Une nouvelle instance de MessageContentRequest avec le contenu ImageUrl.
