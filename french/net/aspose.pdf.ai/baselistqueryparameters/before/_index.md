## BaseListQueryParameters.Before property

Obtient ou définit un curseur à utiliser pour la pagination. before est un ID d'objet qui définit votre position dans la liste. Par exemple, si vous effectuez une requête de liste et recevez 100 objets, se terminant par obj_foo, votre appel suivant peut inclure before=obj_foo afin de récupérer la page précédente de la liste.

public string Before { get; set; }
