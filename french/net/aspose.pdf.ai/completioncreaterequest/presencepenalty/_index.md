## CompletionCreateRequest.PresencePenalty property

Obtient ou définit un nombre compris entre -2.0 et 2.0. Les valeurs positives pénalisent les nouveaux jetons en fonction de leur apparition dans le texte actuel, augmentant la probabilité que le modèle parle de nouveaux sujets.

public double? PresencePenalty { get; set; }
