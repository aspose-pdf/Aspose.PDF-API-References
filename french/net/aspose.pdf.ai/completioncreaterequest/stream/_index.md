## CompletionCreateRequest.Stream property

Obtient ou définit si le streaming doit être utilisé. Si défini, les deltas de messages partiels seront envoyés, comme dans ChatGPT. Les jetons seront envoyés sous forme d'événements serveur uniquement contenant des données dès qu'ils seront disponibles, le flux étant terminé par un message data: [DONE].

public bool? Stream { get; set; }
