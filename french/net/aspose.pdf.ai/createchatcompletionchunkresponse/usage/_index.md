## CreateChatCompletionChunkResponse.Usage property

Obtient ou définit un champ optionnel qui ne sera présent que lorsque vous définissez stream_options : {\"include_usage\": true} dans votre requête. Lorsqu'il est présent, il contient une valeur null sauf pour le dernier segment qui contient les statistiques d'utilisation des jetons pour l'ensemble de la requête.

public Usage Usage { get; set; }
