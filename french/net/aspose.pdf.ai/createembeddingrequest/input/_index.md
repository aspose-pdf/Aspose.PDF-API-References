## CreateEmbeddingRequest.Input property

Obtient ou définit le texte d'entrée à intégrer, encodé sous forme de chaîne ou de tableau de jetons. Pour intégrer plusieurs entrées dans une seule requête, transmettez un tableau de chaînes ou un tableau de tableaux de jetons. L'entrée ne doit pas dépasser le nombre maximal de jetons d'entrée pour le modèle (8192 jetons pour text-embedding-ada-002), ne peut pas être une chaîne vide, et tout tableau doit comporter 2048 dimensions ou moins.

public string Input { get; set; }
