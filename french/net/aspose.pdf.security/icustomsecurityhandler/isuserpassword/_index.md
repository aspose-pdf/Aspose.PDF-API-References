## ICustomSecurityHandler.IsUserPassword method

Vérifiez si le mot de passe appartient à l'utilisateur (mot de passe pour ouvrir le Document). La méthode est appelée après Initialize. L'appel de la méthode est utilisé dans l'API PDF.

```csharp
public bool IsUserPassword(string password)
```

| Paramètre | Type | Description |
| --- | --- | --- |
| password | String | Le mot de passe. |

### Valeur de retour

Vrai, si c'est un mot de passe pour ouvrir le document.
