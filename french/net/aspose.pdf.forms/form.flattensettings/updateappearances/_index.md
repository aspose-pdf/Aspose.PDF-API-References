## Form.FlattenSettings.UpdateAppearances property

Si défini, toutes les apparences de champ seront régénérées avant l'aplatissement. Cette option peut aider si le champ est mal aplati. Cette option peut réduire les performances. Par défaut, elle est définie sur false.

public bool UpdateAppearances { get; set; }
