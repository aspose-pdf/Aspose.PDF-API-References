## Form.AutoRecalculate property

Si défini, tous les champs du formulaire seront recalculés lorsqu'un champ est modifié. La valeur par défaut est true. Définissez sur false afin d'augmenter les performances lors du remplissage du formulaire avec un grand nombre de champs calculés.

```csharp
public bool AutoRecalculate { get; set; }
```
