## Form.RemovePermission property

Si cette propriété est vraie, le dictionnaire "Perms" sera supprimé du document pdf après la conversion des documents dynamiques en standard. Le dictionnaire "Perms" peut contenir des règles qui perturbent l'affichage de la sélection des champs obligatoires dans le lecteur Adobe Acrobat. Elle est false par défaut.

```csharp
public bool RemovePermission { get; set; }
```
