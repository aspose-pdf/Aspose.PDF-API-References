## Form.NeedsRendering property

Obtient une valeur indiquant si le document nécessite la suppression du formulaire XFA dynamique. Cette propriété a été introduite pour déterminer si [`IgnoreNeedsRendering`](../ignoreneedsrendering/) doit être utilisé pour supprimer le formulaire XFA dans les cas où le formulaire XFA est présent et que `NeedsRendering` est faux.

```csharp
public bool NeedsRendering { get; }
```
