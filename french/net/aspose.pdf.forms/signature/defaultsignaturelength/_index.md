## Signature.DefaultSignatureLength property

Obtient ou définit la longueur par défaut des données de signature en octets.

```csharp
public int DefaultSignatureLength { get; set; }
```

## Remarques

Il s'agit d'une estimation de la longueur de la signature en octets. Utilisée pour la signature via [`CustomSignHash`](../customsignhash/) si le paramètre [`AvoidEstimatingSignatureLength`](../avoidestimatingsignaturelength/) est défini. La valeur par défaut est 3000.
