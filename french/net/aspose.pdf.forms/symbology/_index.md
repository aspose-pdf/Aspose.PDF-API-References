## Symbology enumeration

Une symbologie (code-barres) définit les détails techniques d'un type particulier de code-barres : la largeur des barres, le jeu de caractères, la méthode d'encodage, les spécifications de la somme de contrôle, etc.

```csharp
public enum Symbology
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| PDF417 | `0` | Une symbologie 2D à plusieurs rangées et longueur variable avec une grande capacité de données et une capacité de correction d'erreurs. |
| QRCode | `1` | Le code QR (abréviation de Quick Response) est un code matriciel spécifique (code 2D), lisible par les lecteurs de codes QR dédiés et les téléphones à appareil photo. |
| DataMatrix | `2` | Une symbologie matricielle 2D composée de modules carrés noirs et blancs disposés en motif carré ou rectangulaire. |
