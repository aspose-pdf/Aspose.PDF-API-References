## SvgExtractionOptions.GroupStrength property

Obtient et définit une option La force du regroupement des sous‑chemins en images. Vous permet de configurer le degré de regroupement des sous‑chemins. La valeur varie de 0 à 1. Une valeur de 0 correspond à l'option [`ExtractEverySubPathToSvg`](../extracteverysubpathtosvg/) activée. Une valeur de 1 crée une image unique pour tous les chemins vectoriels de la page. L'option a un effet lorsque [`AutoGrouping`](../autogrouping/) est false. La valeur par défaut est `0.8`.

public double GroupStrength { get; set; }
