## SvgExtractionOptions.StrictExtractionAreaBoundCheck property

Obtient et définit une option qui vérifie strictement si les sous‑chemins sont à l'intérieur du rectangle spécifié dans [`ExtractionAreaBound`](../extractionareabound/). Si elle est définie sur false, les sous‑chemins qui ne sont pas complètement inclus dans [`ExtractionAreaBound`](../extractionareabound/) seront extraits. La valeur par défaut est `True`.

public bool StrictExtractionAreaBoundCheck { get; set; }
