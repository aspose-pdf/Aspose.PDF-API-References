## CompressionType enumeration

Utilisé pour spécifier la valeur du paramètre transmis à un dispositif d'image TIFF.

```csharp
public enum CompressionType
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| LZW | `0` | Spécifie le schéma de compression LZW. Peut être transmis à l'encodeur Tiff comme paramètre appartenant à la catégorie Compression. |
| CCITT4 | `1` | Spécifie le schéma de compression CCITT4. Peut être transmis à l'encodeur CCITT4 en tant que paramètre appartenant à la catégorie Compression. |
| CCITT3 | `2` | Spécifie le schéma de compression CCITT3. Peut être transmis à l'encodeur CCITT3 en tant que paramètre appartenant à la catégorie Compression. |
| RLE | `3` | Spécifie le schéma de compression RLE. Peut être transmis à l'encodeur RLE en tant que paramètre appartenant à la catégorie Compression. |
| None | `4` | Spécifie aucune compression. Peut être transmis à l'encodeur Tiff en tant que paramètre appartenant à la catégorie compression. |
