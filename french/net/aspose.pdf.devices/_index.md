L’espace de noms **Aspose.Pdf.Devices** fournit des classes utilisées pour représenter un document sous forme d’image(s) ou de texte brut. Ainsi le document peut être envoyé vers des périphériques textuels ou graphiques, ce qui permet d’obtenir une représentation textuelle ou graphique.

## Classes

| Classe | Description |
| --- | --- |
| [BmpDevice](./bmpdevice/) | Représente un dispositif d'image qui permet d'enregistrer les pages du document PDF au format BMP. |
| [Device](./device/) | Classe abstraite pour tous les types de dispositifs. Le dispositif est utilisé pour représenter le document PDF dans un certain format. Par exemple, une page de document peut être représentée comme une image ou du texte. |
| [DicomDevice](./dicomdevice/) | Représente un dispositif d'image qui permet d'enregistrer les pages du document PDF au format DICOM. |
| [DocumentDevice](./documentdevice/) | Classe abstraite pour tous les dispositifs qui est utilisée pour traiter l'ensemble du document PDF. |
| [EmfDevice](./emfdevice/) | Représente un dispositif d'image qui permet d'enregistrer les pages du document PDF au format EMF. |
| [GifDevice](./gifdevice/) | Représente un dispositif d'image qui permet d'enregistrer les pages du document PDF au format GIF. |
| [ImageDevice](./imagedevice/) | Une classe abstraite pour les dispositifs d'image. |
| [JpegDevice](./jpegdevice/) | Représente un dispositif d'image qui permet d'enregistrer les pages du document PDF au format JPEG. |
| [Margins](./margins/) | Cette classe représente les marges d'une image. |
| [PageDevice](./pagedevice/) | Classe abstraite pour tous les dispositifs qui est utilisée pour traiter une page spécifique du document PDF. |
| [PngDevice](./pngdevice/) | Représente un dispositif d'image qui permet d'enregistrer les pages du document PDF au format PNG. |
| [Resolution](./resolution/) | Représente une classe permettant de stocker la résolution d'image. |
| [TextDevice](./textdevice/) | Représente une classe permettant de convertir les pages du document PDF en texte. |
| [ThumbnailDevice](./thumbnaildevice/) | Représente un dispositif d'image qui enregistre les pages du document PDF en image miniature. |
| [TiffDevice](./tiffdevice/) | Cette classe aide à enregistrer les pages du document PDF, page par page, dans une seule image TIFF. |
| [TiffSettings](./tiffsettings/) | Cette classe représente les paramètres d'importation du PDF vers TIFF. |
## Énumération

| [CompressionType](./compressiontype/) | Utilisé pour spécifier la valeur du paramètre transmis à un dispositif d'image TIFF. |
| [FormPresentationMode](./formpresentationmode/) | Utilisé pour spécifier le mode de présentation du formulaire lors de l'impression ou de la conversion en documents pdf image. |
| [ShapeType](./shapetype/) | Cette énumération représente le type de forme pour les images extraites. |
