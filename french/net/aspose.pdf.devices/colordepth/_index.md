## ColorDepth enumeration

Utilisé pour spécifier la valeur du paramètre transmis à un dispositif d'image TIFF.

```csharp
public enum ColorDepth
```

### Valeurs

| Nom | Valeur | Description |
| --- | --- | --- |
| Default | `0` | Profondeur de couleur par défaut. Une profondeur de 32 bits est utilisée par défaut. |
| Format24bpp | `1` | Rgb profondeur de 24 bits. |
| Format8bpp | `2` | 8 bits par pixel. Égal à !:PixelFormat.Format8bppIndexed |
| Format4bpp | `3` | 4 bits par pixel. Égal à !:PixelFormat.Format4bppIndexed |
| Format1bpp | `4` | 1 bit par pixel. Égal à !:PixelFormat.Format32bppRgb |
