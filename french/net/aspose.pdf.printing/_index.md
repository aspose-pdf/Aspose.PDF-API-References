L’espace de noms **Aspose.Pdf.Printing** fournit des classes et des fonctionnalités pour gérer les opérations d’impression PDF, y compris les paramètres d’imprimante, les paramètres de page et les extensions pour la gestion des configurations liées à l’impression.

## Classes

| Classe | Description |
| --- | --- |
| [CustomPrintEventArgs](./customprinteventargs/) | Fournit des données pour l'événement [`CustomPrint`](../aspose.pdf.facades/pdfviewer/customprint/). |
| [PageSettings](./pagesettings/) | Spécifie les paramètres qui s'appliquent à une page imprimée unique. |
| [PageSettingsExtensions](./pagesettingsextensions/) | Représente les méthodes d'extension pour [`PageSettings`](../aspose.pdf.printing/pagesettings/). |
| [PaperSize](./papersize/) | Spécifie la taille d'une feuille de papier. |
| [PaperSizeExtensions](./papersizeextensions/) | Représente les méthodes d'extension pour [`PaperSize`](../aspose.pdf.printing/papersize/). |
| [PaperSizes](./papersizes/) | Représente les formats de papier standard. |
| [PaperSource](./papersource/) | Spécifie le bac à papier dont l'imprimante prend le papier. |
| [PaperSourceExtensions](./papersourceextensions/) | Représente les méthodes d'extension pour [`PaperSource`](../aspose.pdf.printing/papersource/). |
| [PaperSources](./papersources/) | Fournit un ensemble d'instances prédéfinies de [`PaperSource`](../aspose.pdf.printing/papersource/) représentant des sources de papier courantes. |
| [PdfQueryPageSettingsEventArgs](./pdfquerypagesettingseventargs/) | Fournit des données pour l'événement [`PdfQueryPageSettings`](../aspose.pdf.facades/pdfviewer/pdfquerypagesettings/). |
| [PrinterResolution](./printerresolution/) | Représente la résolution prise en charge par une imprimante. |
| [PrinterResolutionExtensions](./printerresolutionextensions/) | Représente les méthodes d'extension pour [`PrinterResolution`](../aspose.pdf.printing/printerresolution/). |
| [PrinterSettings](./printersettings/) | Spécifie les informations sur la façon dont un document est imprimé, y compris l'imprimante qui l'imprime. |
| [PrinterSettingsExtensions](./printersettingsextensions/) | Représente les méthodes d'extension pour [`PrinterSettings`](../aspose.pdf.printing/printersettings/). |
| [StartEndPageEventArgs](./startendpageeventargs/) | Fournit des données pour les événements [`StartPage`](../aspose.pdf.facades/pdfviewer/startpage/) et [`EndPage`](../aspose.pdf.facades/pdfviewer/endpage/) de la classe [`PdfViewer`](../aspose.pdf.facades/pdfviewer/). |
