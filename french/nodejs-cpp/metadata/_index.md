## Metadata PDF functions

| Nom | Description |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | Définir les informations (métadonnées) dans un fichier PDF. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | Obtenir les informations (métadonnées) d'un fichier PDF. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | Obtenir la liste des polices d'un fichier PDF. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | Supprimer les métadonnées d'un fichier PDF. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | Obtenir le nombre de mots et de caractères dans un fichier PDF. |
| [AsposePdfGetPagesLayers](./asposepdfgetpageslayers/) | Obtenir la liste des calques d'un fichier PDF. |


## Detailed Description

Fonctions pour travailler avec des fichiers PDF de métadonnées.

CommonJS

```js
const AsposePdf = require('asposepdfnodejs');
```

ECMAScript/ES6
