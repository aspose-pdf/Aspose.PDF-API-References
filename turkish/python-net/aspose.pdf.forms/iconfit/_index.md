## IconFit class

Widget açıklamasının simgesinin açıklama dikdörtgeni içinde nasıl görüntüleneceğini açıklar.

IconFit türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| scaling_reason | Ölçeklendirme nedenini alır veya ayarlar. |
| scaling_mode | Kullanılacak ölçeklendirme türü.        /// |
| leftover_left | Simgenin solunda tahsis edilecek boşluğu alır veya ayarlar. |
| leftover_bottom | Simgenin altında tahsis edilecek boşluğu alır veya ayarlar. |
| spread_on_border | Doğru ise, düğme görünümünün kenarlığın çizgi kalınlığı dikkate alınmadan, ek açıklamanın sınırları içinde tamamen sığacak şekilde ölçeklendirileceğini gösterir. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| name_to_scaling_reason(reason) | Ölçeklendirme nedeninin adını ScalingReason nesnesine dönüştürür. |
| scaling_reason_to_name(reason) | Ölçekleme nedeni obejct'i ada dönüştürür. |
| name_to_scaling_mode(mode) | Ölçekleme modu adını ScalingMode nesnesine dönüştürür. |
| scaling_mode_to_name(mode) | Ölçekleme modu nesnesini ada dönüştürür. |
