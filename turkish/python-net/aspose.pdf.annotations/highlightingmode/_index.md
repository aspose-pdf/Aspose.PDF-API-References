## HighlightingMode enumeration

Ek açıklamanın vurgulama modunu, fare düğmesi aktif alan içinde basıldığında veya tutulduğunda kullanılacak görsel efekti numaralandırır.

## Members
| Üye adı | Açıklama |
| :- | :- |
| NONE | Vurgulama yok. |
| INVERT | Ek açıklama dikdörtgeninin içeriğini tersine çevir. |
| OUTLINE | Ek açıklamanın kenarlığını tersine çevir. |
| PUSH | Ek açıklamanın aşağı görünümünü, varsa gösterir. Eğer aşağı görünüm tanımlı değilse, ek açıklama dikdörtgeninin içeriğini kaydırarak sayfanın yüzeyinin altında itiliyormuş gibi görünmesini sağlar. |
| TOGGLE | Push ile aynı (tercih edilen). |
