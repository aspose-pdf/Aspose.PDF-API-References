## DefaultAppearance class

Alanının (yazı tipi, metin boyutu ve renk) varsayılan görünümünü açıklar.

DefaultAppearance türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| DefaultAppearance() | DefaultAppearance yapıcısı. |
| DefaultAppearance(font_name, font_size, text_color) | DefaultAppearance sınıfının yeni bir örneğini başlatır |
| DefaultAppearance(font, font_size, text_color) | DefaultAppearance sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| font_size | Varsayılan görünümdeki yazı tipi boyutunu alır. |
| text_color | Varsayılan görünümdeki metin rengini alır veya ayarlar. |
| font_name | Varsayılan görünümdeki yazı tipi adını alır. |
| font_resource_name | Varsayılan görünümdeki yazı tipi adını alır. |
| font | Metin için varsayılan olarak belirtilen yazı tipini alır. |
| text | Görünümü temsil eden pdf operatörlerinin listesini alır. |
