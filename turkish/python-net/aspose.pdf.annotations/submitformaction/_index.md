## SubmitFormAction class

Submit-form eylemini tanımlayan sınıf.

SubmitFormAction türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| SubmitFormAction() | SubmitFormAction nesnesini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| next | Sıralamadaki sonraki eylemler. |
| bayraklar | Gönderme eyleminin bayraklarını alır veya ayarlar |
| url | Hedef URL. |
| EXCLUDE | Temizse, Fields dizisi gönderimde hangi alanların dahil edileceğini belirtir. |
| INCLUDE_NO_VALUE_FIELDS | Ayarlanırsa, Fields dizisi ve Include/Exclude bayrağı tarafından belirlenen tüm alanlar gönderilecektir. |
| EXPORT_FORMAT | Ayarlanırsa, alan adları ve değerleri HTML Form formatında gönderilecektir. |
| GET_METHOD | Ayarlanırsa, alan adları ve değerleri bir HTTP GET isteği kullanılarak gönderilecektir. |
| SUBMIT_COORDINATES | Ayarlanırsa, submit-form eylemine neden olan fare tıklamasının koordinatları form verilerinin bir parçası olarak iletilecektir. |
| XFDF | Ayarlanırsa, alan adları ve değerleri XFDF olarak gönderilecektir. |
| INCLUDE_APPEND_SAVES | Ayarlanırsa, gönderilen FDF dosyası tüm artımlı güncellemelerin içeriğini içerecektir. |
| INCLUDE_ANNOTATIONS | Ayarlanırsa, gönderilen FDF dosyası temel PDF belgesindeki tüm işaretleme açıklamalarını içerecektir. |
| SUBMIT_PDF | Ayarlanırsa, belge PDF olarak, MIME içerik türü application/pdf kullanılarak gönderilecektir. |
| CANONICAL_FORMAT | Ayarlanırsa, tarih temsil eden gönderilen alan değerleri standart formata dönüştürülecektir. |
| EXCL_NON_USER_ANNOTS | Ayarlanırsa, yalnızca T girdisi mevcut kullanıcının adıyla eşleşen işaretleme açıklamaları dahil edilecektir. |
| EXCL_F_KEY | Ayarlanırsa, gönderilen FDF F girdisini dışarıda bırakacaktır. |
| EMBED_FORM | Ayarlanırsa, gönderilen FDF'nin F girdisi, <br/>            gömülü dosya akışı içeren bir dosya tanımı olacaktır; bu akış, FDF'nin gönderildiği PDF dosyasını temsil eder. |
