## SoundSampleData class

Bir ses nesnesine özgü ek girişleri temsil eder (Bölüm 9.2 PDF1-7).

SoundSampleData türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| SoundSampleData(sampling_rate) | SoundSampleData sınıfının yeni bir örneğini başlatır. |
| SoundSampleData(sampling_rate, number_of_sound_channels) | SoundSampleData sınıfının yeni bir örneğini başlatır. |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel) | SoundSampleData sınıfının yeni bir örneğini başlatır. |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel, sound_sample_data_encoding_format) | SoundSampleData sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| sampling_rate | Örnekleme oranını alır veya ayarlar. |
| number_of_sound_channels | Ses kanallarının sayısını alır veya ayarlar. |
| bits_per_channel | Kanal başına örnek değeri için bit sayısını alır veya ayarlar. |
| encoding_format | Kodlama biçimini alır veya ayarlar. |
| DEFAULT_SAMPLING_RATE | SamplingRate için varsayılan değer. |
| DEFAULT_OF_SOUND_CHANNELS | Channels parametresi için varsayılan değer. |
| DEFAULT_OF_BITS_PER_CHANNEL | BitsPerchannel parametresi için varsayılan değer. |
| DEFAULT_ENCODING_FORMAT | Kodlama biçimi için varsayılan değer. |
