## TableTRElement class

Tablonun mantıksal yapısında TR yapı öğesini temsil eder.

TableTRElement türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| parent_element | Yok |
| child_elements | Yok |
| default_attribute_owner | Alır |
| öznitelikler | Alır |
| structure_type | Yapı öğesinin tipini alır. |
| id | Yapı öğesi için kimliği alır. |
| title | Yapı öğesi için başlığı alır veya ayarlar. |
| language | Yapı öğesi için dili alır veya ayarlar. |
| alternative_text | Yapı öğesi için alternatif metni alır veya ayarlar. |
| expansion_text | Yapı öğesi için genişletme metnini alır veya ayarlar. |
| actual_text | Yapı öğesi için gerçek metni alır veya ayarlar. |
| background_color | Satır arka plan rengini alır veya ayarlar. |
| kenar | Satır kenarlığını alır veya ayarlar. |
| default_cell_border | Varsayılan hücre kenarlığını alır. |
| min_row_height | Satır yüksekliğini alır. |
| fixed_row_height | Sabit satır yüksekliğini alır - satır sabit yüksekliğe sahip olabilir. |
| is_in_new_page | Sabit satırın yeni sayfada olup olmadığını alır - bu özelliğe sahip sayfa bir sonraki sayfaya basılmalıdır. Varsayılan false. |
| is_row_broken | Satırın iki sayfa arasında kırılıp kırılmayacağını alır. |
| default_cell_text_state | Satır hücreleri için varsayılan metin durumunu alır veya ayarlar. |
| default_cell_padding | Satır hücreleri için varsayılan kenar boşluğunu alır veya ayarlar. |
| vertical_alignment | Dikey hizalamayı alır veya ayarlar. |
