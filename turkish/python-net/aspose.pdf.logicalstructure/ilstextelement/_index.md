## ILSTextElement class

Mantıksal yapı içinde satır içi düzey metin yapı öğeleri için temel sınıfı temsil eder.

ILSTextElement türü aşağıdaki üyeleri gösterir:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| parent_element | Yok |
| child_elements | Yok |
| default_attribute_owner | Alır |
| öznitelikler | Alır |
| structure_type | Yapı öğesinin tipini alır. |
| id | Yapı öğesi için kimliği alır. |
| title | Yapı öğesi için başlığı alır veya ayarlar. |
| language | Yapı öğesi için dili alır veya ayarlar. |
| alternative_text | Yapı öğesi için alternatif metni alır veya ayarlar. |
| expansion_text | Yapı öğesi için genişletme metnini alır veya ayarlar. |
| actual_text | Yapı öğesi için gerçek metni alır veya ayarlar. |
| structure_text_state | Alır |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| append_child(element) | Yok |
| change_parent_element(new_parent_element) | Mevcut yapı öğesi için üst öğeyi değiştir. |
| generate_id() | Yapı öğesi için kimlik oluştur. |
| set_id(id) | Yapı öğesi için kimliği ayarlar. |
| clear_id() | Yapı öğesi için kimliği temizler. |
| set_tag(new_tag) | Yapı öğesi için özel etiketi ayarlar. |
| set_text(text) | Mevcut metin öğesine metin içeriği ekler. |
