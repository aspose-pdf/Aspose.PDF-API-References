## Bookmark class

Bir yer imini temsil eder.

Bookmark türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Bookmark() | Bookmark sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| action | Yer imiyle bağlanan eylemi alır veya ayarlar.<br/>            SayfaNumarası (PageNumber) sunulmuşsa eylem belirtilemez.<br/>            Eylem türleri şunları içerir: "GoTo", "GoToR", "Launch", "Named". |
| bold_flag | Yer imi başlığının kalınlık bayrağını alır veya ayarlar. |
| child_item | Yer iminin alt öğelerini alır veya ayarlar. |
| child_items | Yer iminin alt öğelerini alır veya ayarlar. |
| hedef | Yer işaretinin hedef sayfasını alır veya ayarlar. Eylem string.Empty olarak ayarlandıysa gereklidir. |
| italic_flag | Yer işareti başlığının italik bayrağını alır veya ayarlar. |
| seviye | Yer işareti hiyerarşi seviyesini alır veya ayarlar. |
| page_display | Yer işareti hedef sayfasının görüntüleme türünü alır veya ayarlar. |
| page_display_bottom | Sayfa görüntülemenin alt koordinatını alır veya ayarlar. |
| page_display_left | Sayfa görüntülemenin sol koordinatını alır veya ayarlar. |
| page_display_right | Sayfa görüntülemenin sağ koordinatını alır veya ayarlar. |
| page_display_top | Sayfa görüntülemenin üst koordinatını alır veya ayarlar. |
| page_display_zoom | Sayfa görüntülemenin yakınlaştırma faktörünü alır veya ayarlar. |
| page_number | Yer işareti hedef sayfasının numarasını alır veya ayarlar. |
| remote_file | Yer işareti için "GoToR" eylemi gerektiren dosyayı (yolu) alır veya ayarlar. |
| title | Yer işareti başlığını alır veya ayarlar. |
| title_color | Yer işareti başlığının rengini alır veya ayarlar. |
| aç | Yer işareti durumunu (açık, kapalı) alır veya ayarlar. |
