## StampInfo class

Damga bilgilerini temsil eden sınıf.

StampInfo türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| stamp_id | Damganın tanımlayıcısını alır. |
| index_on_page | Sayfadaki damga indeksini alır. |
| stamp_type | Damga tipini alır (görüntü / form). |
| rectangle | Damganın yerleştirildiği dikdörtgeni alır. |
| image | Damganın görüntüsünü alır. Damga görüntü içermiyorsa (örneğin metin damgası) null olabilir. |
| form | Damganın XForm'unu alır. |
| text | Damgadaki metni alır. |
| görünür | Damganın görünürlüğünü alır. False ise damga gizlenir (HideStampById ile). Gizli damga, ShowStampById ile geri getirilebilir. |
