## ISaveableFacade class

Tüm kaydedilebilir facade'ler için ortak yöntemleri tanımlayan facade arayüzü.

ISaveableFacade türü aşağıdaki üyeleri ortaya çıkar:
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| save(dest_file) | Sonuç PDF belgesini dosyaya kaydeder. |
| save(dest_stream) | Sonuç PDF belgesini akışa kaydeder. |
| bind_pdf(src_file) | PDF belgesini düzenleme için bağlar. |
| bind_pdf(src_stream) | PDF belgesini düzenleme için bağlar. |
| bind_pdf(src_doc) | PDF belgesini düzenleme için bağlar. |
| close() | Mevcut facade ile ilişkili tüm kaynakları serbest bırakır. |
