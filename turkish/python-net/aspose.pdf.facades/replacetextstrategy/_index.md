## ReplaceTextStrategy class

Bu sınıf, ReplaceText işlemi gerçekleştirildiğinde PdfContentEditor davranışını tanımlayan parametreleri içerir.

ReplaceTextStrategy türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| ReplaceTextStrategy() | ReplaceTextStrategy sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| is_regular_expression_used | Yanlış ise, bulunacak dize basit bir metindir. Doğru ise, bulunacak dize düzenli ifadedir. |
| no_character_behavior | Değiştirilen metin için uygun bir yazı tipi bulunamadığında gerçekleştirilen eylem<br/>            (İstisna fırlat / Başka bir yazı tipi ile değiştir / Yine de değiştir). |
| replace_scope | Değiştirme işleminin kapsamı (ilk oluşumu değiştir veya tüm oluşumları değiştir). |
