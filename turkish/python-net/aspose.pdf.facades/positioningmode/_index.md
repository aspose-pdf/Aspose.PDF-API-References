## PositioningMode enumeration

Konumlandırma modunu tanımlar.<br/>            Olası değerler arasında Legacy (geriye dönük uyumluluk) ve <br/>            Current (güncellenmiş metin konum hesaplama yöntemi) bulunur.

## Members
| Üye adı | Açıklama |
| :- | :- |
| LEGACY | Eski metin konumlandırması |
| MODERN_LINE_SPACING | Güncellenmiş satır aralığı, dikey konum hesaplaması eski kurallara göre yapılır <br/>            (yani metin belirtilen dikdörtgenin sol-alt köşesine göre konumlandırılır) |
| CURRENT | Güncellenmiş satır aralığı ve dikey konum hesaplaması sol-alt köşe yerine sol-üst köşeye göre yapılır. |
