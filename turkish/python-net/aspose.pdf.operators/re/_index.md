## Re class

re operatörünü temsil eden sınıf (yola dikdörtgen ekle).

Re türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Re() | Operatörü başlatır. |
| Re(x, y, width, height) | Re sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| index | Sayfa operatörleri listesinde operatör indeksi. |
| x | Dikdörtgenin en sol tarafının X koordinatı. |
| y | Dikdörtgenin alt tarafının Y koordinatı. |
| genişlik | Dikdörtgenin genişliği. |
| yükseklik | Dikdörtgenin yüksekliği. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| accept(visitor) | Operatörü işlemek için ziyaretçi nesnesini kabul eder. |
| is_text_show_operator(op) | Operatörün metin çıktısından sorumlu operatör (Tj, TJ vb.) olup olmadığını belirler |
