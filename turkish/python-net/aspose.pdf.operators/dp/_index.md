## DP class

DP operatörünü temsil eden sınıf (belirlenmiş işaretli içerik noktası).

DP türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| DP(tag) | DP sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| index | Sayfa operatörleri listesinde operatör indeksi. |
| tag | İşaretlenmiş içerik etiketini alır veya ayarlar |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| accept(visitor) | Operatörü işlemek için ziyaretçi nesnesini kabul eder. |
| is_text_show_operator(op) | Operatörün metin çıktısından sorumlu operatör (Tj, TJ vb.) olup olmadığını belirler |
