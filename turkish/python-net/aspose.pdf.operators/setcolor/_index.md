## SetColor class

SetColor türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| SetColor() | Operatörü başlatır. |
| SetColor(g) | SetColor sınıfının yeni bir örneğini başlatır |
| SetColor(r, g, b) | SetColor sınıfının yeni bir örneğini başlatır |
| SetColor(c, m, y, k) | SetColor sınıfının yeni bir örneğini başlatır |
| SetColor(color) | SetColor sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| index | Yok |
| r | Renk bileşeninin kırmızı kısmını alır. |
| g | Renk bileşeninin yeşil kısmını alır. |
| b | Renk bileşeninin kırmızı kısmını alır. |
| c | CMYK renginin camgöbeği (cyan) bileşenini alır. |
| m | CMYK renginin macenta bileşenini alır. |
| y | CMYK renginin sarı bileşenini alır. |
| k | CMYK renginin siyah bileşenini alır. |
| grey | Gri renginin siyah bileşenini alır. |
| renk | Renk bileşenlerinin dizisini alır. |
