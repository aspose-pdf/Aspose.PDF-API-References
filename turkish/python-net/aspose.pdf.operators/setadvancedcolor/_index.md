## SetAdvancedColor class

scn operatörünü temsil eden sınıf (çizim dışı işlemler için rengi ayarla).

SetAdvancedColor türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| SetAdvancedColor() | Operatörü başlatır. |
| SetAdvancedColor(g, pattern_name) | SetAdvancedColor sınıfının yeni bir örneğini başlatır |
| SetAdvancedColor(g) | SetAdvancedColor sınıfının yeni bir örneğini başlatır |
| SetAdvancedColor(r, g, b, pattern_name) | SetAdvancedColor sınıfının yeni bir örneğini başlatır |
| SetAdvancedColor(c, m, y, k, pattern_name) | SetAdvancedColor sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| index | Yok |
| r | Renk bileşeninin kırmızı kısmını alır. |
| g | Renk bileşeninin yeşil kısmını alır. |
| b | Renk bileşeninin kırmızı kısmını alır. |
| c | CMYK renginin camgöbeği (cyan) bileşenini alır. |
| m | CMYK renginin macenta bileşenini alır. |
| y | CMYK renginin sarı bileşenini alır. |
| k | CMYK renginin siyah bileşenini alır. |
| grey | Gri renginin siyah bileşenini alır. |
| renk | Renk bileşenlerinin dizisini alır. |
| pattern_name | Desen adını alır. |
