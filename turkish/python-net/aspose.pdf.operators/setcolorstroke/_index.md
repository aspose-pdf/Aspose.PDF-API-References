## SetColorStroke class

SC operatörünü temsil eden sınıf (çizim renk operatörleri için rengi ayarla).

SetColorStroke türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| SetColorStroke() | Operatörü başlatır. |
| SetColorStroke(g) | SetColorStroke sınıfının yeni bir örneğini başlatır |
| SetColorStroke(r, g, b) | SetColorStroke sınıfının yeni bir örneğini başlatır |
| SetColorStroke(color) | SetColorStroke sınıfının yeni bir örneğini başlatır |
| SetColorStroke(c, m, y, k) | SetColorStroke sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| index | Yok |
| r | Renk bileşeninin kırmızı kısmını alır. |
| g | Renk bileşeninin yeşil kısmını alır. |
| b | Renk bileşeninin kırmızı kısmını alır. |
| c | CMYK renginin camgöbeği (cyan) bileşenini alır. |
| m | CMYK renginin macenta bileşenini alır. |
| y | CMYK renginin sarı bileşenini alır. |
| k | CMYK renginin siyah bileşenini alır. |
| grey | Gri renginin siyah bileşenini alır. |
| renk | Renk bileşenlerinin dizisini alır. |
