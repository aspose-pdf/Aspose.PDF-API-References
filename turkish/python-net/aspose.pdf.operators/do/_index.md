## Do class

Do operatörünü temsil eden sınıf (XObject'i çağır).

Do türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Do(name) | Do sınıfının yeni bir örneğini başlatır |
| Do() | Yeni Do operatörü oluşturur. <br/>            Tüm Do operatörlerini, yani argüman adlarını kontrol etmeden, almak için kullanılır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| index | Sayfa operatörleri listesinde operatör indeksi. |
| name | Operatörün XObject argümanının adı. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| accept(visitor) | Operatörü işlemek için ziyaretçi nesnesini kabul eder. |
| is_text_show_operator(op) | Operatörün metin çıktısından sorumlu operatör (Tj, TJ vb.) olup olmadığını belirler |
