## GS class

gs operatörünü temsil eden sınıf (grafik durum parametre sözlüğünden parametreleri ayarla).

GS türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| GS(name) | GS sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| index | Sayfa operatörleri listesinde operatör indeksi. |
| name | Grafik durum kaynağının adını alır veya ayarlar. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| accept(visitor) | Operatörü işlemek için ziyaretçi nesnesini kabul eder. |
| is_text_show_operator(op) | Operatörün metin çıktısından sorumlu operatör (Tj, TJ vb.) olup olmadığını belirler |
