## BasicSetColorOperator class

Renk ayarlama operatörleri için temel sınıf.

BasicSetColorOperator türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| index | Sayfa operatörleri listesinde operatör indeksi. |
| r | Renk bileşeninin kırmızı kısmını alır. |
| g | Renk bileşeninin yeşil kısmını alır. |
| b | Renk bileşeninin kırmızı kısmını alır. |
| c | CMYK renginin camgöbeği (cyan) bileşenini alır. |
| m | CMYK renginin macenta bileşenini alır. |
| y | CMYK renginin sarı bileşenini alır. |
| k | CMYK renginin siyah bileşenini alır. |
| grey | Gri renginin siyah bileşenini alır. |
| renk | Renk bileşenlerinin dizisini alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| accept(visitor) | IOperatorSelector ziyaretçisini kabul eder, bu da operatör işleme sağlar. |
| is_text_show_operator(op) | Operatörün metin çıktısından sorumlu operatör (Tj, TJ vb.) olup olmadığını belirler |
| get_color() | Operatör tarafından belirtilen rengi döndürür. |
