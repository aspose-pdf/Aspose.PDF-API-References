## ThumbnailDevice class

PDF belge sayfalarını küçük resim (Thumbnail) olarak kaydeden görüntü aygıtını temsil eder.

ThumbnailDevice türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| ThumbnailDevice() | Varsayılan küçük resim boyutu (200x200 piksel) ile [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) sınıfının yeni bir örneğini başlatır<br/>             |
| ThumbnailDevice(width, height) | ThumbnailDevice sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| coordinate_type | Sayfa koordinat tipini (Media/Crop kutuları) alır veya ayarlar. Varsayılan olarak CropBox değeri kullanılır. |
| rendering_options | Renderleme seçeneklerini alır veya ayarlar. |
| form_presentation_mode | Form sunum modunu alır veya ayarlar. |
| resolution | Görüntü çözünürlüğünü alır. |
| genişlik | Görüntü çıkış genişliğini alır. |
| yükseklik | Görüntü çıkış yüksekliğini alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| process(page, output) | Sayfayı küçük resim png formatına dönüştürür ve çıktı akışına kaydeder. |
| process(page, output_file_name) | Sayfayı küçük resim png formatına dönüştürür ve çıktı akışına kaydeder. |
