## EmfDevice class

PDF belge sayfalarını emf formatına kaydetmeye yardımcı olan görüntü cihazını temsil eder.

EmfDevice türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| EmfDevice() | Raster görüntünün emf'ye yazıldığı varsayılan çözünürlükle yeni bir [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) sınıfı örneği başlatır. |
| EmfDevice(resolution) | EmfDevice sınıfının yeni bir örneğini başlatır. |
| EmfDevice(width, height) | EmfDevice sınıfının yeni bir örneğini başlatır. |
| EmfDevice(page_size) | EmfDevice sınıfının yeni bir örneğini başlatır. |
| EmfDevice(width, height, resolution) | EmfDevice sınıfının yeni bir örneğini başlatır. |
| EmfDevice(page_size, resolution) | EmfDevice sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| coordinate_type | Sayfa koordinat tipini (Media/Crop kutuları) alır veya ayarlar. Varsayılan olarak CropBox değeri kullanılır. |
| rendering_options | Renderleme seçeneklerini alır veya ayarlar. |
| form_presentation_mode | Form sunum modunu alır veya ayarlar. |
| resolution | Görüntü çözünürlüğünü alır. |
| genişlik | Görüntü çıkış genişliğini alır. |
| yükseklik | Görüntü çıkış yüksekliğini alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| process(page, output) | Sayfayı emf formatına dönüştürür ve çıktı akışına kaydeder. |
| process(page, output_file_name) | Sayfayı emf formatına dönüştürür ve çıktı akışına kaydeder. |
