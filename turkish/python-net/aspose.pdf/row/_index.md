## Row class

Tablonun bir satırını temsil eder.

Row türü aşağıdaki üyeleri ortaya çıkarır:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Row() | Row sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| background_color | Arka plan rengini alır veya ayarlar. |
| kenar | Kenarı alır veya ayarlar. |
| cells | Satırın hücrelerini alır. |
| default_cell_border | Varsayılan hücre kenarlığını alır; |
| min_row_height | Satırın yüksekliğini alır; |
| fixed_row_height | Sabit satır yüksekliğini alır - satır sabit yüksekliğe sahip olabilir; |
| is_in_new_page | Sabit satırın yeni sayfada olup olduğunu alır - bu özelliğe sahip sayfa bir sonraki sayfaya basılmalıdır. Varsayılan false; |
| is_row_broken | Satırın iki sayfa arasında bölünebilir olup olmadığını alır |
| default_cell_text_state | Satır hücreleri için varsayılan metin durumunu alır veya ayarlar. |
| default_cell_padding | Satır hücreleri için varsayılan kenar boşluğunu alır veya ayarlar |
| vertical_alignment | Dikey hizalamayı alır veya ayarlar. |
