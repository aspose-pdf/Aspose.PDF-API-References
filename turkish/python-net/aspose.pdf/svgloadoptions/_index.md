## SvgLoadOptions class

SVG dosyasını pdf belgesine yükleme/içe aktarma seçeneklerini temsil eder.

Bu SvgLoadOptions türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| SvgLoadOptions() | SvgLoadOptions sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| warning_handler | Üretilen herhangi bir uyarıyı işlemek için geri çağırma. <br/>            WarningHandler, Continue veya Abort belirten ReturnAction enum öğesini döndürür. <br/>            Continue varsayılan eylemdir ve Load işlemi devam eder, ancak kullanıcı Abort döndürürse Load işlemi durmalıdır. |
| load_format | Dosya formatını temsil eder ki [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) bunu tanımlar. |
| page_info | Belge yüklenirken uygulanması gereken sayfa bilgilerini alır veya ayarlar.<br/>            NOT: bu parametre yalnızca ConversionEngine == ConversionEngines.NewEngine olduğunda çalışır. |
| adjust_page_size | PDF sayfa boyutunu SVG boyutuna ayarlar. |
| conversion_engine | Dönüştürme sırasında kullanılacak dönüşüm motorunun seçilmesine izin verir.<br/>            Şu anda yeni motor B-test aşamasındadır, bu yüzden bu değer varsayılan olarak <br/>            ConversionEngines.LegacyEngine olarak ayarlanır. |
