## Cell class

Tablonun satırının bir hücresini temsil eder.

Cell türü aşağıdaki üyeleri ortaya çıkarır:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Cell(rect) | Cell sınıfının yeni bir örneğini başlatır |
| Cell() | Cell sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| is_no_border | Hücrenin kenarlığını alır veya ayarlar. |
| kenar boşluğu | Dolgu değerini alır veya ayarlar. |
| kenar | Kenarı alır veya ayarlar. |
| background_color | Arka plan rengini alır veya ayarlar. |
| background_image_file | Arka plan görüntü dosyasını alır veya ayarlar. |
| background_image | Arka plan görüntüsünü alır veya ayarlar |
| hizalama | Hizalamayı alır veya ayarlar. |
| default_cell_text_state | Varsayılan hücre metin durumunu alır veya ayarlar. |
| is_override_by_fragment | Hücrenin TextState özelliğinin, TextFragment TextState özelliği tarafından geçersiz kılındığını ayarlar. |
| paragraphs | Hücrenin biçimlendirilmiş metnini alır veya ayarlar. |
| is_word_wrapped | Hücrenin metninin kelime kaydırmasını alır veya ayarlar. |
| vertical_alignment | Dikey hizalamayı alır veya ayarlar. |
| col_span | Sütun kapsamını alır veya ayarlar. |
| row_span | Satır kapsamını alır veya ayarlar. |
| genişlik | Sütun genişliğini alır veya ayarlar. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
