## Opi class

## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| Opi(xform) | Opi sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| version | Bu sözlüğün referans verdiği OPI sürümünü alır. |
| file_specification | Düşük çözünürlüklü proxy görüntüsünü içeren harici dosyayı alır. |
