## HtmlLoadOptions class

HTML dosyasını PDF belgesine yükleme/içe aktarma seçeneklerini temsil eder.

HtmlLoadOptions türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| HtmlLoadOptions() | Boş temel yol ile html'yi pdf belgesine dönüştürmek için yükleme seçenekleri oluşturur. |
| HtmlLoadOptions(base_path) | HtmlLoadOptions sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| warning_handler | Üretilen herhangi bir uyarıyı işlemek için geri çağırma. <br/>            WarningHandler, Continue veya Abort belirten ReturnAction enum öğesini döndürür. <br/>            Continue varsayılan eylemdir ve Load işlemi devam eder, ancak kullanıcı Abort döndürürse Load işlemi durmalıdır. |
| load_format | Dosya formatını temsil eder ki [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) bunu tanımlar. |
| is_render_to_single_page | Tüm belgeyi tek sayfaya render etmeyi alır veya ayarlar |
| is_embed_fonts | Sonuç belgesine font gömmeyi alır veya ayarlar |
| page_layout_option | Düzen seçeneğini alır veya ayarlar. |
| html_media_type | Renderleme sırasında kullanılan olası medya türlerini alır veya ayarlar. |
| input_encoding | Bu belgenin ayrıştırma sırasında kullanılan kodlamasını belirten özelliği alır veya ayarlar. Bu özellik null ise kodlama, belgenin karakter kümesi özelliğinden belirlenecektir. |
| base_path | Html dosyası için temel yol/url. |
| page_info | Belge sayfa bilgilerini alır veya ayarlar |
