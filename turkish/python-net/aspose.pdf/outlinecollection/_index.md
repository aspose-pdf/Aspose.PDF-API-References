## OutlineCollection class

Belge taslak hiyerarşisini temsil eder.

OutlineCollection türü aşağıdaki üyeleri ortaya çıkarır:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| visible_count | Count, tüm seviyelerdeki görünür alt başlık öğelerinin sayısının toplamıdır. Not: Lütfen koleksiyondaki öğe sayısı olan Count ile karıştırmayın. |
| first | Ana başlıktaki ilk üst düzey öğeyi temsil eden bir outline öğesini alır. |
| son | Taslakta son üst düzey öğeyi temsil eden bir taslak öğesini alır. |
| is_synchronized | Bu koleksiyona erişimin senkronize (iş parçacığı güvenli) olup olmadığını gösteren bir değeri alır. |
| sync_root | Bu koleksiyona erişimi senkronize etmek için kullanılabilecek bir nesneyi alır. |
## Indexer
| Ad | Açıklama |
| :- | :- |
| [index] | Koleksiyondan indeksle bir taslak öğesini alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| delete() | Belge taslağından tüm taslak öğelerini siler. |
| delete(name) | Belge taslağından belirtilen başlığa sahip taslak öğesini siler. |
