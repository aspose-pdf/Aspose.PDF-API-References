## ImageDeleteAction enumeration

Koleksiyondan görüntü kaldırıldığında görüntü nesnesiyle gerçekleştirilen eylem. Görüntü nesnesi kaldırılırsa

## Members
| Üye adı | Açıklama |
| :- | :- |
| KEEP_CONTENTS | Görüntü koleksiyondan kaldırılacaktır. Sayfa içeriği görüntüye referanslar içeriyorsa bunlar kaldırılmayacaktır. Belge geçersiz hale gelebilir. |
| NONE | Görüntü koleksiyondan ve sayfa içeriğinden kaldırılacak, ancak görüntü nesnesi silinmeyecektir. Dosya boyutu azalmayacaktır. |

| CHECK | Görüntü koleksiyondan kaldırılacak ve yalnızca diğer sayfalardan görüntüye başka referans yoksa görüntü nesnesi kaldırılacaktır. Bu, ForceDelete seçeneğine göre daha fazla zaman alabilir. |
