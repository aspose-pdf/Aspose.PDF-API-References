## TocInfo class

İçindekiler tablosu bilgisini temsil eder.

TocInfo türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| TocInfo() | Yeni bir [TocInfo](/pdf/python-net/aspose.pdf/tocinfo/) sınıfı örneği başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| column_info | Sütun bilgisini alır veya ayarlar. |
| format_array | İçindekiler tablosu için format dizisini alır veya ayarlar. |
| format_array_length | Format dizisi uzunluğunu alır veya ayarlar. |
| title | İçindekiler tablosu başlığını alır veya ayarlar. |
| is_count_toc_pages | İçindekiler sayfalarının sayılıp sayılmadığını alır veya ayarlar. |
| page_numbers_prefix | Sayfa numarasından önceki önek'i alır veya ayarlar. |
| is_show_page_numbers | İçindekilerde sayfa numaralarının gösterilip gösterilmeyeceğini alır veya ayarlar. |
| line_dash | İçindekiler satır çizgi stilini alır veya ayarlar. |
