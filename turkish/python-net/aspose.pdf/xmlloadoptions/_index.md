## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| XmlLoadOptions() | xsl verisi olmadan [XmlLoadOptions](/pdf/python-net/aspose.pdf/xmlloadoptions/) nesnesi oluşturur. |

| XmlLoadOptions(xsl_stream) | XmlLoadOptions sınıfının yeni bir örneğini başlatır. |

| Ad | Açıklama |
