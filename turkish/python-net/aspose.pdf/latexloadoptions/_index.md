## LatexLoadOptions class

PDF belgesine TeX dosyası yükleme/ithal etme seçeneklerini temsil eder.

LatexLoadOptions türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| LatexLoadOptions() | LatexLoadOptions sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| warning_handler | Üretilen herhangi bir uyarıyı işlemek için geri çağırma. <br/>            WarningHandler, Continue veya Abort belirten ReturnAction enum öğesini döndürür. <br/>            Continue varsayılan eylemdir ve Load işlemi devam eder, ancak kullanıcı Abort döndürürse Load işlemi durmalıdır. |
| load_format | Dosya formatını temsil eder ki [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) bunu tanımlar. |
| job_name | İşin adını alır/ayarlar. |
| input_directory | TeX giriş dizinini alır/ayarlar. |
| output_directory | TeX çıktı dizinini alır/ayarlar. |
| repeat | TeX işinin iki kez çalıştırılması gerekip gerekmediğini gösteren bayrağı alır/ayarlar, örneğin giriş TeX dosyasında referanslar olduğunda.<br/>            Genel olarak, bu davranış, motorun dizgi süreci boyunca bazı verileri toplaması ve bunları bir yardımcı dosyada,<br/>            ilk çalıştırmada saklaması durumunda faydalıdır. Ve ikinci çalıştırmada motor bu verileri bir şekilde kullanır. |
| subset_fonts | Çıktı dosyasında yazı tiplerini alt kümeleyip alt kümelemeyeceğini gösteren bayrağı alır/ayarlar. |
| show_terminal_output | Konsolda terminal çıktısını gösterip göstermeyeceğini belirten bayrağı alır/ayarlar. |
| date_time |  \year, \month, \day ve \time gibi tarih/saat ilkel değerleri için belirli bir değeri alır/ayarlar. |
| no_ligatures | Tüm yazı tiplerindeki ligatürleri iptal eden bir bayrağı alır/ayarlar. |
| rasterize_formulas | Matematik formüllerini rasterleştirmeye izin veren bir bayrağı alır/ayarlar. |
