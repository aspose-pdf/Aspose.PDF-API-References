## PdfSaveOptions class

Pdf formatına dışa aktarma için kaydetme seçenekleri

PdfSaveOptions türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| PdfSaveOptions() | PdfSaveOptions sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| warning_handler | Üretilen herhangi bir uyarıyı işlemek için geri çağırma. <br/>            WarningHandler, Continue veya Abort belirten ReturnAction enum öğesini döndürür. <br/>            Continue varsayılan eylemdir ve Kaydetme işlemi devam eder, ancak kullanıcı Abort döndürürse Kaydetme işlemi durmalıdır. |
| save_format | Veri kaydetme biçimi. |
| close_response | Belge yanıt içine kaydedildikten sonra Response nesnesinin kapatılıp kapatılmayacağını gösteren boolean değeri alır veya ayarlar. |
| temp_path | Geçici dosyalar için yol. |
| default_font_name | Bilgisayarda bulunmayan yazı tipleri için varsayılan olarak kullanılan yazı tipi adı.<br/>            PDF olarak kaydedilen belge, belgede ve cihazda bulunmayan yazı tipleri içerdiğinde, API bu yazı tiplerini <br/>            varsayılan yazı tipiyle (cihazda [default_font_name](/pdf/python-net/aspose.pdf/pdfsaveoptions/) adlı yazı tipi bulunursa) değiştirir. |
