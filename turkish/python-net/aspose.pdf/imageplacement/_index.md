## ImagePlacement class

PDF belge sayfasına yerleştirilen bir görüntünün özelliklerini temsil eder.

ImagePlacement türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| matris | Bu görüntü için geçerli dönüşüm matrisi. |
| rectangle | Görüntünün dikdörtgenini alır. |
| operator | Görüntüyü görüntülemek için kullanılan operatör. |
| rotation | Görüntünün döndürme açısını alır. |
| resolution | Görüntünün çözünürlüğünü alır. |
| image | İlgili XImage kaynak nesnesini alır. |
| sayfa | Görüntüyü içeren sayfayı alır. |
| compositing_parameters | Sayfaya yerleştirilen görüntü için etkin grafik durumunun birleşim parametrelerini alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| save(stream) | Görüntüyü ilgili dönüşümlerle kaydeder: ölçekleme, döndürme ve çözünürlük. |
| save(stream, format) | Görüntüyü ilgili dönüşümlerle kaydeder: ölçekleme, döndürme ve çözünürlük. |
| hide() | Görüntüyü sayfadan sil. |
| replace(image) | Koleksiyondaki görüntüyü başka bir görüntüyle değiştir. |
