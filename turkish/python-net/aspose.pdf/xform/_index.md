## XForm class

Sınıf XForm'u temsil eder.

XForm türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| b_box | Formun sınırlama kutusunu alır veya ayarlar. |
| name | Form adını alır veya ayarlar. Form adı, sayfa kaynaklarındaki XObejct sözlüğünde formu referanslamak için kullanılan isimdir. |
| içerik | Formun operatörlerini alır. |
| opi | Açık Ön Baskı Arayüzü (OPI)'yi alır. |
| matris | Formun matrisini alır veya ayarlar. |
| resources | Form XObject kaynaklarını alır. |
| rectangle | Formun dikdörtgenini alır veya ayarlar. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| get_resources(allow_create) | Form X-Object'in kaynaklarını döndürür |
| get_resources() | Form X-Object'in kaynaklarını döndürür |
| create_new_form(source, document) | Sayfanın içeriğini kopyalayan XForm oluşturur. |
| free_memory() | Önbelleğe alınmış verileri temizler |
