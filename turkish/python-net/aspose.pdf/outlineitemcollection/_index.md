## OutlineItemCollection class

PDF belgesinin taslak hiyerarşisindeki taslak girişini temsil eder.

OutlineItemCollection türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| OutlineItemCollection(outlines) | OutlineItemCollection sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| visible_count | Belge taslak hiyerarşisindeki tüm seviyelerdeki taslak öğelerinin toplam sayısını alır. |
| title | Bu taslak öğesi için başlığı alır veya ayarlar. |
| hedef | Bu taslak öğesi için hedefi alır veya ayarlar. |
| action | Bu taslak öğesi için eylemi alır veya ayarlar. |
| renk | Bu taslak öğesinin başlık metni için rengi alır veya ayarlar. |
| italik | Bu taslak öğesinin başlık metni için italik bayrağını alır veya ayarlar |
| kalın | Bu taslak öğesinin başlık metni için kalın bayrağını alır veya ayarlar |
| first | Taslak hiyerarşisindeki ilk üst düzey öğeyi temsil eden taslak öğesini alır. |
| son | Taslak hiyerarşisindeki son üst düzey öğeyi temsil eden taslak öğesini alır. |
| prev | Taslak hiyerarşisinde bu öğeye göre önceki öğeyi temsil eden taslak öğesini alır. |
| next | Taslak hiyerarşisinde bu öğeye göre sonraki öğeyi temsil eden taslak öğesini alır. |
| has_next | Taslak hiyerarşisinde bu öğeye göre sonraki öğeyi temsil eden taslak öğesinin olup olmadığını kontrol eder. |
| üst | Taslak hiyerarşisindeki bu taslak öğesinin üst nesnesini alır. |
| is_synchronized | Bu koleksiyona erişimin senkronize (iş parçacığı güvenli) olup olduğunu gösteren değeri alır. |
| sync_root | Bu koleksiyona erişimi senkronize etmek için kullanılabilecek nesneyi alır. |
| aç | Taslak öğesi için açık durumunu (true/false) alır veya ayarlar. |
| seviye | Taslak öğesinin hiyerarşi seviyesini alır. |
## Indexer
| Ad | Açıklama |
| :- | :- |
| [index] | Koleksiyondan indeks kullanarak taslak öğesini alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| delete() | Bu taslak öğesini belge taslak hiyerarşisinden siler. |
| delete(name) | Belirtilen adla taslak girişini belge taslak hiyerarşisinden siler. |
| insert(index, outline) | Taslak öğesini belirtilen konuma koleksiyona ekler. |
