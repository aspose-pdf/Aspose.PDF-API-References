## FileParams class

FileParams türü aşağıdaki üyeleri içerir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| FileParams(spec) | FileParams sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| boyut | Sıkıştırılmamış gömülü dosyanın boyutu, bayt cinsinden. |
| creation_date | Gömülü dosyanın oluşturulduğu tarih ve saat. |
| mod_date | Gömülü dosyanın son değiştirildiği tarih ve saat. |
