## XImageCollection class

XImage koleksiyonunu temsil eden sınıf.

XImageCollection türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| is_synchronized | Nesne eşzamanlıysa true döndürür. |
| sync_root | Eşzamanlama nesnesini döndürür. |
| names | Görüntü adlarının dizisini alır. |
## Indexer
| Ad | Açıklama |
| :- | :- |
| [index] | Görüntüyü koleksiyondan indeksine göre alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| add(image) | Yeni görüntüyü Image listesine ekler. Bu yöntem, görüntüyü aynı PdfObject'e referans olarak ekler (bu, dosya boyutunun azalmasını sağlar). |
| add(image) | Varlığı koleksiyonun sonuna ekler, böylece varlık son indeksle erişilebilir. |
| add(image, filter_type) | Varlığı koleksiyonun sonuna ekler, böylece varlık son indeksle erişilebilir. |
| add(image, quality) | Varlığı koleksiyonun sonuna ekler, böylece varlık son indeksle erişilebilir. |
| delete(index) | Koleksiyondan indekse göre indeksi kaldırır. |
| delete(index, action) | İndeks aracılığıyla koleksiyondan resmi kaldırır ve action parametresiyle belirtilen eylemi gerçekleştirir. |
| delete(name) | Koleksiyondan adıyla öğeyi kaldırır. |
| delete(name, action) | Koleksiyondan adıyla öğeyi kaldırır. |
| delete() | Koleksiyondan indekse göre indeksi kaldırır. |
| replace(index, stream) | Koleksiyondaki görüntüyü başka bir görüntüyle değiştir. |
| replace(index, stream, quality, is_black_and_white) | Koleksiyondaki görüntüyü başka bir görüntüyle değiştir. |
| replace(index, stream, quality) | Koleksiyondaki görüntüyü başka bir görüntüyle değiştir. |
| get_image_name(image) | Verilen resmin anahtarı olan görüntüler listesinde ismi döndürür. |
