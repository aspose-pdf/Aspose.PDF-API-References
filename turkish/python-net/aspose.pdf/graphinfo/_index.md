## GraphInfo class

Grafik bilgisini temsil eder.

GraphInfo türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| GraphInfo() | GraphInfo sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| line_width | Grafiğin çizgi kalınlığını belirten bir float değerini alır veya ayarlar. |
| color | Grafiğin rengini belirten bir [color](/pdf/python-net/aspose.pdf/graphinfo/) nesnesini alır veya ayarlar. |
| dash_array | Bir dash dizisini alır veya ayarlar. |
| dash_phase | Bir dash fazını alır veya ayarlar. |
| fill_color | Grafiğin dolgu rengini belirten bir [color](/pdf/python-net/aspose.pdf/graphinfo/) nesnesini alır veya ayarlar. |
| is_doubled | Kenarlığın çift olup olmadığını alır veya ayarlar. |
| skew_angle_x | Koordinat sistemi dönüştürülürken x koordinatının eğim açısını belirten bir float değerini alır veya ayarlar. |
| skew_angle_y | Koordinat sistemi dönüştürülürken y koordinatının eğim açısını belirten bir float değerini alır veya ayarlar. |
| scaling_rate_x | Koordinat sistemi dönüştürülürken x koordinatının ölçekleme oranını belirten bir float değerini alır veya ayarlar. |
| scaling_rate_y | Koordinat sistemi dönüştürülürken y koordinatının ölçekleme oranını belirten bir float değerini alır veya ayarlar. |
| rotation_angle | Koordinat sisteminin dönüş açısını belirten bir float değerini alır veya ayarlar <br/>            koordinat sistemi dönüştürülürken. |
