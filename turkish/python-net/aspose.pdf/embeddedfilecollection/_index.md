## EmbeddedFileCollection class

Gömülü dosyalar koleksiyonunu temsil eden sınıf.

EmbeddedFileCollection türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| is_synchronized | Bu koleksiyona erişimin senkronize (iş parçacığı güvenli) olup olmadığını gösteren bir değeri alır. |
| sync_root | Bu koleksiyona erişimi senkronize etmek için kullanılabilecek bir nesneyi alır. |
| anahtarlar | Dosya ekleme anahtarlarının listesini döndürür. |
## Indexer
| Ad | Açıklama |
| :- | :- |
| [index] | Gömülü dosyayı indeksine göre alır. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| delete(name) | Dosyayı koleksiyondaki anahtarına göre koleksiyondan siler. |
| delete() | Dosyayı koleksiyondaki anahtarına göre koleksiyondan siler. |
| add(key, file) | Belirtilen anahtarla dosyayı gömülü dosyalara ekler. |
| delete_by_key(key) | Dosyayı koleksiyondaki anahtarına göre koleksiyondan siler. |
| find_by_name(name) | Gömülü dosyayı adıyla döndürür. |
