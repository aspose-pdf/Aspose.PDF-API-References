## PageSize class

PDF belgesindeki sayfanın boyutunu temsil eden sınıf.

PageSize türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| PageSize(x, y) | PageSize sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| genişlik | Sayfa genişliğini alır veya ayarlar. |
| yükseklik | Sayfa yüksekliğini alır veya ayarlar. |
| is_landscape | Sayfa yönlendirmesini alır. Yatay yönlendirme ise true, dikey yönlendirme ise false döndürür. |
| a0 | A0 boyutu (1189x840 mm). |
| a1 | A1 boyutu (840x594 mm). |
| a2 | A2 boyutu (594x420 mm). |
| a3 | A3 boyutu (420x297 mm). |
| a4 | A4 boyutu (297x210 mm). |
| a5 | A5 boyutu (210x148 mm). |
| a6 | A6 boyutu (148x105 mm). |
| b5 | B5 boyutu (250x176 mm). |
| page_letter | Letter boyutu (279x216 mm). |
| page_legal | Legal boyutu (356x216 mm). |
| page_ledger | Ledger boyutu (432x279 mm). |
| p11x17 | 11x17 inç formatı. |
