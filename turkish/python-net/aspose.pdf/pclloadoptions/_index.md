## PclLoadOptions class

PCL dosyasını pdf belgesine yükleme (import) seçeneklerini temsil eder.

PclLoadOptions türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| PclLoadOptions() | PclLoadOptions sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| warning_handler | Üretilen herhangi bir uyarıyı işlemek için geri çağırma. <br/>            WarningHandler, Continue veya Abort belirten ReturnAction enum öğesini döndürür. <br/>            Continue varsayılan eylemdir ve Load işlemi devam eder, ancak kullanıcı Abort döndürürse Load işlemi durmalıdır. |
| load_format | Dosya formatını temsil eder ki [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) bunu tanımlar. |
| batch_size | Toplu dönüşüm uygulanabilir olduğunda toplu boyutunu tanımlar<br/>            kaynak ve hedef format çiftine. |
| conversion_engine | Dönüşüm için kullanılacak conversion_engine'i tanımlar. |
| supress_errors | supress_errors, PCL dönüşüm hatalarının bastırılıp bastırılmayacağını gösteren boolean değeri alır veya ayarlar. |
