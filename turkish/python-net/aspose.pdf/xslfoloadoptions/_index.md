## XslFoLoadOptions class

XSL-FO dosyasını PDF belgesine yükleme/içe aktarma seçeneklerini temsil eder.

XslFoLoadOptions türü aşağıdaki üyeleri ortaya çıkarır:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| XslFoLoadOptions() | XSL verisi olmadan [XslFoLoadOptions](/pdf/python-net/aspose.pdf/xslfoloadoptions/) nesnesi oluşturur. |
| XslFoLoadOptions(xsl_file) | XslFoLoadOptions sınıfının yeni bir örneğini başlatır |
| XslFoLoadOptions(xsl_stream) | XslFoLoadOptions sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| warning_handler | Üretilen herhangi bir uyarıyı işlemek için geri çağırma. <br/>            WarningHandler, Continue veya Abort belirten ReturnAction enum öğesini döndürür. <br/>            Continue varsayılan eylemdir ve Load işlemi devam eder, ancak kullanıcı Abort döndürürse Load işlemi durmalıdır. |
| load_format | Dosya formatını temsil eder ki [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/) bunu tanımlar. |
| xsl_stream | xml'i pdf belgesine dönüştürmek için xsl verisini alır. |
| base_path | Yüklenen SVG dosyasında başvurulan harici kaynaklara (varsa) göreceli yolların aranacağı temel yol/URL. |
| parsing_errors_handling_type | Kaynak XSLFO belgesi biçimlendirme hataları içerebilir. Bu enum, bu hataların ele alınması için olası stratejileri listeler. |
