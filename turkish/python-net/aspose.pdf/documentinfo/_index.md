## DocumentInfo class

PDF belgesinin meta bilgisini temsil eder.

DocumentInfo türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| DocumentInfo(document) | DocumentInfo sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| title | Belge başlığını alır veya ayarlar. |
| creator | Belge oluşturucusunu alır veya ayarlar. |
| author | Belge yazarını alır veya ayarlar. |
| subject | Belgenin konusunu alır veya ayarlar. |
| keywords | Belgenin anahtar kelimelerini alır veya ayarlar. |
| producer | Belge üreticisini alır veya ayarlar. |
| creation_date | Belge oluşturma tarihini alır veya ayarlar. |
| creation_time_zone | Oluşturma tarihinin saat dilimi. |
| mod_time_zone | Değiştirme tarihinin saat dilimi. |
| mod_date | Belge değiştirme tarihini alır veya ayarlar. |
| trapped | Trapped bayrağını alır veya ayarlar. |
## Yöntemler
| Ad | Açıklama |
| :- | :- |
| add(key, value) | Belirtilen anahtar ve değerle bir öğe koleksiyona ekler. |
| remove(key) | Belirtilen anahtara sahip öğeyi koleksiyondan kaldırır. |
| clear_custom_data() | Yalnızca özel verileri temizler, diğer tüm önceden tanımlı değerleri (Başlık, Yazar, vb.) bırakır. |
| is_predefined_key(key) | Anahtarın önceden tanımlı (Title, Author, etc.) olup olmadığını, özel olmadığını belirler. |
