## ToUnicodeProcessingRules class

Bu sınıf, Adobe Preflight hatasını çözmek için kullanılabilecek kuralları tanımlar<br/>            "Metin Unicode'a eşlenemiyor".

ToUnicodeProcessingRules türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| ToUnicodeProcessingRules() | Yapıcı |
| ToUnicodeProcessingRules(remove_spaces) | ToUnicodeProcessingRules sınıfının yeni bir örneğini başlatır |
| ToUnicodeProcessingRules(remove_spaces, map_non_linked_unicodes_on_space) | ToUnicodeProcessingRules sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| remove_spaces_from_c_map_names | Bazı yazı tiplerinde ToUnicode karakter kod haritalarında adlarda boşluklar bulunur. Bu boşluklar unicode metin eşlemesinde hatalara neden olabilir.<br/>            Bu bayrak, ToUnicode karakter kod haritalarının adlarından boşlukları kaldırmak için kullanılır.<br/>            Varsayılan olarak false. |
| map_non_linked_symbols_on_space | Bazı yazı tipleri bazı metin sembolleri için unicode bilgisi sağlamaz. <br/>            Bu bilgi eksikliği \"Text cannot be mapped to Unicode\" hatasına yol açar.<br/>            Bu bayrağı, bağlanmamış sembolleri unicode \"space\" (kod 32) üzerine eşlemek için kullanın. |
