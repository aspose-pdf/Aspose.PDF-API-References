## XfaParserOptions class

ilgili veri kapsüllemeyi işlemek için sınıf

XfaParserOptions türü aşağıdaki üyeleri ortaya çıkarır:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| XfaParserOptions(page_size) | XfaParserOptions sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| page_size | Sayfanın boyutunu alır veya ayarlar. |
| imzalı | Bu özellik true ise belge, xfa form akışı (varsa) kullanılarak dönüştürülecektir.<br/>            Eğer false ise xfa form akışı göz ardı edilecektir.<br/>            Bu özellik, imzayı kontrol etmek için kullanılan kontrol toplamının nasıl hesaplanacağı net olmadığı için tanıtıldı. |
| emulate_requierd_groups | Bu özellik true ise gerekli Xfa "excluded groups" için ek kırmızı dikdörtgenler çizilecektir.<br/>            Bu özellik, formların Xfa temsili standarda dönüştürülürken excluded groups benzerlerinin bulunmaması nedeniyle tanıtıldı.<br/>            Varsayılan olarak false'tur. |
| base_path | Temel yolu alır veya ayarlar. |
