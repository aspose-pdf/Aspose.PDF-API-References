## TextFormattingOptions class

Metin biçimlendirme seçeneklerini temsil eder

TextFormattingOptions türü aşağıdaki üyeleri gösterir:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| TextFormattingOptions(wrap_mode) | TextFormattingOptions sınıfının yeni bir örneğini başlatır |
| TextFormattingOptions() | Tanımsız kelime kaydırma modu ile [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) nesnesinin yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| wrap_mode | Kelime kaydırma modunu alır veya ayarlar.<br/>            Varsayılan değer WordWrapMode.NoWrap'tir |
| line_spacing | Satır aralığı modunu alır veya ayarlar.<br/>            Varsayılan değer LineSpacingMode.FontSize'dır |
| hyphen_symbol | Tireleme işleminde kullanılan tire simgesini alır veya ayarlar. |
| subsequent_lines_indent | Sonraki satırların girinti değerini alır veya ayarlar. |
| first_line_indent | İlk satır girinti değerini alır veya ayarlar. |
