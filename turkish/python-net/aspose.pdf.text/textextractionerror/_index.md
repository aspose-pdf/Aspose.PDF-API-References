## TextExtractionError class

PDF belgesinde ortaya çıkan metin çıkarma hatasını açıklar.

TextExtractionError türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| summary | Hatanın kısa açıklaması. |
| açıklama | Hatanın genişletilmiş açıklaması. |
| location | Hatanın konumu. |
| font_key | Çıkarma hatasına neden olan metni göstermek için kullanılan Font nesnesinin (PDF adı) anahtarı. |
| font_name | Çıkarma hatasına neden olan metni göstermek için kullanılan Font nesnesinin okunabilir (dahili) adı. |
| extracted_text | Gerçekten çıkarılan metin. |
