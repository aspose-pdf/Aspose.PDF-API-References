## TextState class

Bir metnin metin durumunu temsil eder

TextState türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| TextState() | Metin durumu nesnesi oluşturur. |
| TextState(font_size) | TextState sınıfının yeni bir örneğini başlatır |
| TextState(foreground_color) | TextState sınıfının yeni bir örneğini başlatır |
| TextState(foreground_color, font_size) | TextState sınıfının yeni bir örneğini başlatır |
| TextState(font_family) | TextState sınıfının yeni bir örneğini başlatır |
| TextState(font_family, bold, italic) | TextState sınıfının yeni bir örneğini başlatır |
| TextState(font_family, font_size) | TextState sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| character_spacing | Metnin karakter aralığını alır veya ayarlar. |
| line_spacing | Metnin satır aralığını alır veya ayarlar. |
| horizontal_scaling | Metnin yatay ölçeklendirmesini alır veya ayarlar. |
| subscript | Metnin alt simgesini alır veya ayarlar. |
| superscript | Metnin üst simgesini alır veya ayarlar. |
| word_spacing | Metnin kelime aralığını alır veya ayarlar. |
| invisible | Metnin görünmezliğini alır veya ayarlar. Bu temelde [rendering_mode](/pdf/python-net/aspose.pdf.text/textstate/) durumunu yansıtır, bazı özel durumlar (örneğin kırpma) hariç. |
| rendering_mode | Metnin renderleme modunu alır veya ayarlar. |
| font_size | Metnin yazı tipi boyutunu alır veya ayarlar. |
| font | Metnin yazı tipini alır veya ayarlar. |
| foreground_color | Metnin ön plan rengini alır veya ayarlar. |
| stroking_color | Metnin ön plan rengini alır veya ayarlar. |
| underline | Metin için alt çizgiyi alır veya ayarlar, [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) nesnesiyle temsil edilir. |
| strike_out | Metin için üstü çiziliyi ayarlar, [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) nesnesiyle temsil edilir. |
| background_color | Metnin arka plan rengini ayarlar. |
| font_style | Metnin yazı tipi stilini ayarlar. |
| horizontal_alignment | Metnin yatay hizalamasını alır veya ayarlar. |
| TAB_TAG | Bu etiketi metinde sekme bildirmek için yerleştirebilirsiniz. |
| TABSTOP_DEFAULT_VALUE | Varsayılan yazı tipinin boşluk karakteri genişliğindeki sekme varsayılan değeri. |
