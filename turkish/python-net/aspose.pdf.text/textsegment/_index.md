## TextSegment class

Pdf metninin bir segmentini temsil eder.

TextSegment türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| TextSegment() | TextSegment nesnesi oluşturur. |
| TextSegment(text) | TextSegment sınıfının yeni bir örneğini başlatır |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| start_char_index | Gösterim metni operatöründeki (Tj, TJ) segmentte mevcut segmentin başlangıç karakter indeksini alır. |
| end_char_index | Gösterim metni operatöründeki (Tj, TJ) segmentte mevcut segmentin bitiş karakter indeksini alır. |
| text | Metin nesnesini temsil eden [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) nesnesi için dize metin nesnesini alır veya ayarlar. |
| text_state | [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) nesnesi tarafından temsil edilen metin için metin durumunu alır veya ayarlar. |
| position | [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) nesnesiyle temsil edilen metin için metin konumunu alır. |
| rectangle | TextSegment'in dikdörtgenini alır. |
| baseline_position | [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) nesnesiyle temsil edilen metin için metin konumunu alır.<br/>            Position yapısının YIndent özelliği, metin segmentinin temel çizgi koordinatını temsil eder. |
| text_edit_options | Metin düzenleme seçeneklerini alır veya ayarlar. Seçenekler, istenen sembolün yazı tipiyle yazılamadığı durumlarda özel davranışı tanımlar. |
| karakterler | Metin segmentindeki karakterler hakkında bilgi temsil eden CharInfo nesnelerinin koleksiyonunu alır. |
| köprü | Segment hiperlinkini (pdf oluşturucu için) alır veya ayarlar. |
