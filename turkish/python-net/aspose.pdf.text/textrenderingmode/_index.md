## TextRenderingMode enumeration

Metin işleme modu, Tmode, metnin gösterilmesinin glif konturlarının çizilmesi, doldurulması, kırpma sınırı olarak kullanılması ya da bu üçünün bir kombinasyonu olup olmayacağını belirler.

| :- | :- |
| FILL_TEXT | Metni doldur. |
| STROKE_TEXT | Metni çiz. |
| FILL_THEN_STROKE_TEXT | Metni doldur, ardından çiz. |
| INVISIBLE | Ne metni doldurur ne de çizer (görünmez). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Metni doldur ve kırpma için yola ekle (bkz. 9.3.6, "Text Rendering Mode,"). |

| ADD_PATH_TO_CLIPPING | Metni kırpma için yola ekle. |
