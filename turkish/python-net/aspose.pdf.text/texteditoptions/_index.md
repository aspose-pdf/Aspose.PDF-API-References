## TextEditOptions class

Metin düzenleme işlemlerinin seçeneklerini açıklar.

TextEditOptions türü aşağıdaki üyeleri sunar:
## Yapıcılar
| Ad | Açıklama |
| :- | :- |
| TextEditOptions(no_character_behavior) | TextEditOptions sınıfının yeni bir örneğini başlatır. |
| TextEditOptions(font_replace_behavior) | TextEditOptions sınıfının yeni bir örneğini başlatır. |
| TextEditOptions(allow_language_transformation) | TextEditOptions sınıfının yeni bir örneğini başlatır. |
| TextEditOptions(language_transformation_behavior) | TextEditOptions sınıfının yeni bir örneğini başlatır. |
## Özellikler
| Ad | Açıklama |
| :- | :- |
| replacement_font | Gerekli karakteri içermeyen kullanıcı yazı tipinde yerine kullanılacak yazı tipini alır veya ayarlar. |
| no_character_behavior | Yazı tipleri istenen karakterleri içermediğinde davranışı tanımlayan modu alır veya ayarlar. |
| font_replace_behavior | Yazı tipi değiştirme senaryoları için davranışı tanımlayan modu alır. |
| allow_language_transformation | Metin ekleme veya düzenleme sırasında dil dönüşümünün kullanılmasına izin veren değeri alır veya ayarlar.<br/>            true - dil dönüşümü gerektiğinde uygulanacaktır (varsayılan değer).<br/>            false - dil dönüşümü uygulanmayacaktır. |
| language_transformation_behavior | Dil dönüşüm senaryoları için davranışı tanımlayan modu alır. |
| clipping_paths_processing | Düzenlenen metnin kırpma yolunu işlemek için modu alır. |
| to_attempt_get_underline_from_source | Kaynak belgenin sayfasında metin altı çizgisi aramaya izin veren değeri alır veya ayarlar.<br/>            (Eski) Lütfen bunun yerine TextSearchOptions.SearchForTextRelatedGraphics kullanın. |
