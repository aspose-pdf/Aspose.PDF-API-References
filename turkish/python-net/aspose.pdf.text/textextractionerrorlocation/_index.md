## TextExtractionErrorLocation class

PDF belgesinde metin çıkarma hatasının ortaya çıktığı konumu temsil eder.

TextExtractionErrorLocation türü aşağıdaki üyeleri sunar:
## Özellikler
| Ad | Açıklama |
| :- | :- |
| path | Metin çıkarma hatasının ortaya çıktığı PDF belgesinin konumu. |
| page_number | Metin çıkarma hatasının bulunduğu belge sayfasının numarası. |
| object_type | İçerik akışı metin çıkarma hatasının bulunduğu PDF nesnesinin (Sayfa veya xForm) türü. |
| form_key | İçerik akışı metin çıkarma hatasının bulunduğu PDF Form XObject'in anahtarı (adı). ObjectType == 'xForm' ise boş değildir. |
| operator_index | Metin çıkarma hatasına neden olan içerik akışındaki (operatör koleksiyonu) metni gösteren operatörün indeksi. |
| operator_string | Metin çıkarma hatasına neden olan metni gösteren operatör. |
| font_used_key | Metin çıkarma hatasına neden olan operatörü gösterirken kullanılan PDF Font nesnesinin anahtarı (adı). |
| text_start_point | Metin çıkarma hatasına neden olan operatörü gösterirken kullanılan PDF Font nesnesinin anahtarı (adı). |
