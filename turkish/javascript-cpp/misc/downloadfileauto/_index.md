_Dosyayı indirmek için HTML'de bir bağlantı oluştur ve 2 saniye sonra indirmeyi başlat._

```js
function DownloadFileAuto(
    filename,
    mime 
)
```

**Parameters**:

* **fileName** file name
* **mime** string "mime/type"

**Doesn't work in Web Worker.**
