_Dosyayı indirmek için HTML'de bir bağlantı oluştur._

```js
function DownloadFile(
    filename,
    mime 
)
```

**Parameters**:

* **fileName** file name
* **mime** string "mime/type"

**Doesn't work in Web Worker.**
