### ParseSpaces {#ParseSpaces}
```
public static final int ParseSpaces
```

Mod, normal moda benzer, ancak metin parçacıkları arasındaki görsel boşlukları mesafeye dayalı olarak hesaba katmaya çalışır. Parçacıklar arasındaki boşluk sayısının tanımlanması, belgelerin nasıl oluşturulduğuna büyük ölçüde bağlı olduğundan doğru olmayabilir. Belgeler farklı oluşturucular tarafından oluşturulmuşsa, metin parçacıkları arasındaki boşlukların karşılaştırılmasında hatalar oluşabilir. Bu seçenek, mantıklı olsa da, karmaşık yapıdaki belgelere uygulandığında beklenen karşılaştırma sonuçlarından farklı sonuçlar üretebilir.
