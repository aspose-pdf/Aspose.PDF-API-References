### compare {#compare-com.aspose.pdf.Document-com.aspose.pdf.Document-java.lang.String-com.aspose.pdf.comparison.sidebysidecomparison.SideBySideComparisonOptions-}

### compare {#compare-com.aspose.pdf.Page-com.aspose.pdf.Page-java.lang.String-com.aspose.pdf.comparison.sidebysidecomparison.SideBySideComparisonOptions-}
