### BevelJoin {#BevelJoin}
```
public static final int BevelJoin
```

Bisel birleşim. İki segment, butt kapaklarıyla (bkz. 8.4.3.3, "Line Cap Style") tamamlanacak ve segmentlerin uçlarının ötesindeki ortaya çıkan çentik bir üçgenle doldurulacaktır.

### MiterJoin {#MiterJoin}
```
public static final int MiterJoin
```

Köşe birleşimi. İki segmentin darbelerinin dış kenarları bir açıda buluşana kadar uzatılacak, bir çerçeve gibi. Segmentler, miter limit parametresiyle tanımlanan kadar keskin bir açıyla buluşurlarsa (bkz. 8.4.3.5, "Miter Limit"), bunun yerine bir bisel birleşim kullanılacaktır.

### RoundJoin {#RoundJoin}
```
public static final int RoundJoin
```

Yuvarlak birleşim. İki segmentin buluştuğu noktada, çizgi genişliğine eşit çapta bir daire yayı çizilecek ve iki segmentin darbelerinin dış kenarları birleştirilecektir. Bu dilim şeklindeki şekil doldurularak yuvarlak bir köşe oluşturulacaktır.
