```
public static interface LoadOptions.ResourceLoadingStrategy
```

Bazen dış kaynakların (görüntüler veya CSS gibi) dahili yükleyicisinin kullanılmasından kaçınmak ve istenen kaynakları bir yerden alacak özel bir yöntem sağlamak gerekir. Örneğin, bulutta Aspose.PDf kullanılırken başvurulan dosyalara doğrudan erişim mümkün değildir ve özel bir kodun özel bir yönteme yerleştirilmesi gerekir. Bu temsilci, böyle bir özel yöntemin imzasını tanımlar.
