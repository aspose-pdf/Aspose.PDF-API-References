### Flatten {#Flatten}
```
public static final int Flatten
```

PDF içeriğini konumlandırılmış metin parçacıklarıyla koordinatlarına göre temsil eder. Temelde "Raw" moduna benzer. Ancak "Raw" bir belgedeki metin parçacıklarının (operatörlerin) yapısını korumaya odaklanırken, "Flatten" metni okuma sırasına göre tutmaya odaklanır.
