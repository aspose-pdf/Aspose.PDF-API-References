Bu com.aspose.pdf.markdownoptions ad alanı, markdown dönüşümü için özel seçenek sınıfları içerir.

## Sınıflar

| Sınıf | Açıklama |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | Vurgu ve güçlü vurgu için mevcut serileştirme stillerini tanımlar. Belirtilen standart için CommonMark - Emphasis and strong emphasis bölümüne bakın. |
| [HeadingLevels](./headinglevels/) | Yazı tipi boyutuna göre başlık seviyeleriyle çalışmak için bir sınıfı temsil eder. |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | Başlık tanıma stratejileri türlerini temsil eder. |
| [HeadingStyle](./headingstyle/) | Başlıklar için mevcut serileştirme stillerini tanımlar. Belirtilen standart için CommonMark - ATX headings ve CommonMark - Setext headings bölümlerine bakın. |
| [LineBreakStyle](./linebreakstyle/) | Bir dosya için olası satır sonu stillerini temsil eder. |
| [MarkdownSaveOptions](./markdownsaveoptions/) | Markdown formatında belge kaydetme seçeneği sınıfını temsil eder. |
