Bir sertifika doğrulamasının doğrulama durumunu temsil eder. Bu enum, sertifika doğrulamasının olası sonuçlarını tanımlar: - Valid: Sertifikanın başarıyla doğrulandığını gösterir. - Invalid: Sertifika doğrulamasının başarısız olduğunu gösterir. - Undefined: Doğrulama sürecinin sonuçsuz kaldığını veya yürütülmediğini gösterir.
