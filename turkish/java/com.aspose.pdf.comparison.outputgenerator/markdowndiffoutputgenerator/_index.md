Metin farklarının markdown temsilini üretmek için bir sınıfı temsil eder. Markdown sözdizimi nedeniyle boşluk karakterlerindeki değişiklikler gösterilemez. Değişikliklerin seçilmesi, biçimlendirme etrafına boşluk karakterleri eklemeyi gerektirir, aksi takdirde markdown görüntüleyici metni doğru şekilde göstermez.
