```
public interface ITociElement
```

Etiketli bir PDF belgesinde içindekiler tablosu girişi (TOCI) olarak işlev görebilen bir öğeyi temsil eder. Bu arayüz, hem standart TOCI öğelerini hem de iç içe geçmiş içindekiler yapılarında kullanılan Liste Öğesi (LI) öğelerini soyutlar.

StructureElement getGetElement()
