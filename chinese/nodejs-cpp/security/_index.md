## Security PDF functions

| 名称 | 描述 |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | 加密 PDF 文件。 |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | 解密 PDF 文件。 |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | 使用数字签名对 PDF 文件进行签名。 |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | 使用分离式数字签名对 PDF 文件进行签名。 |
| [AsposePdfChangePassword](./asposepdfchangepassword/) | 更改 PDF 文件的密码。 |

## Detailed Description

用于处理带安全特性的 PDF 文件的功能。

CommonJS

```js
const AsposePdf = require('asposepdfnodejs');
```

ECMAScript/ES6

```js
import AsposePdf from 'asposepdfnodejs';
```
