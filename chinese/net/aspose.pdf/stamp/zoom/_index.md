## Stamp.Zoom property

印章的缩放因子。用于缩放印章。请注意，ZoomX 和 ZoomY 两个属性可以分别为每个轴设置缩放因子。设置此属性会同时更改 ZoomX 和 ZoomY 属性。如果 ZoomX 和 ZoomY 不同，则 Zoom 属性返回 ZoomX 的值。

```csharp
public double Zoom { get; set; }
```
