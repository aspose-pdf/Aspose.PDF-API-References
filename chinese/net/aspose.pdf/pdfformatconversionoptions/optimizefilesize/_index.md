## PdfFormatConversionOptions.OptimizeFileSize property

获取或设置一个标志，用于启用/禁用特殊转换模式以获得文件大小更小的 PDF/A 文档。当前此标志影响 PDF 文档中使用的字体优化，未来可能还会用于开启对其他数据结构（如图形）的优化。该标志与模式的组合可以显著减小文件大小，但同时也可能显著降低转换性能。

```csharp
public bool OptimizeFileSize { get; set; }
```
