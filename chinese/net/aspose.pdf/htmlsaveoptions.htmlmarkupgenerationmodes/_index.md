## HtmlSaveOptions.HtmlMarkupGenerationModes enumeration

有时会出现对生成的 HTML 的特定需求。此枚举定义了在 PDF 转换为 HTML 过程中可用于满足此类特定需求的 HTML 准备模式。

```csharp
public enum HtmlMarkupGenerationModes
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| WriteAllHtml | `0` | 默认模式下不存在任何特定需求。生成的输出将包含 HTML 的所有部分，且不进行任何特殊的额外处理。 |
| WriteOnlyBodyContent | `1` | 将去除所有位于 HTML body 之外的 HTML 内容，即仅保留位于 \c \ \c \ 标签内部的内容。 |
