## HtmlPageLayoutOption enumeration

指定标志，这些标志与其他选项共同决定页面的尺寸和布局。

```csharp
public enum HtmlPageLayoutOption
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 默认值，表示 HtmlPageLayoutOption 不会影响页面的大小和布局。 |
| FitToWidestContentWidth | `3` | 指示页面宽度由内容大小本身决定，而不是由指定的页面宽度决定。 |
| ScaleToPageWidth | `256` | 指示文档内容将被缩放以适应页面。 |
