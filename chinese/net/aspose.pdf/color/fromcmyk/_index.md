## Color.FromCmyk method

从 CMYK 颜色分量获取有效的 pdf Color 对象。

```csharp
public static Color FromCmyk(double c, double m, double y, double k)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| c | Double | 青色分量（值 0 - 1）。 |
| m | Double | 品红色分量（值 0 - 1）。 |
| y | Double | 黄色分量（值 0 - 1）。 |
| k | Double | 键色分量（值 0 - 1）。 |

### 返回值

Color 对象的每个分量值在 [0..1] 范围内.
