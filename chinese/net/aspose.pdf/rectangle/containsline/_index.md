## Rectangle.ContainsLine method

确定矩形是否包含由两点表示的线段。

```csharp
public bool ContainsLine(double x1, double y1, double x2, double y2)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| x1 | Double | 线段起点的 X 坐标。 |
| y1 | Double | 线段起点的 Y 坐标。 |
| x2 | Double | 线段终点的 X 坐标。 |
| y2 | Double | 线段终点的 Y 坐标。 |

### 返回值

`true` 如果矩形包含该线段；否则为 `false`。
