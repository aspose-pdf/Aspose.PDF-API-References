## HtmlSaveOptions.SaveFullFont property

指示将保存完整字体，仅支持 True Type 字体。默认情况下 SaveFullFont = false，转换器仅保存文档文本显示所需的初始字体子集。

```csharp
public bool SaveFullFont { get; set; }
```
