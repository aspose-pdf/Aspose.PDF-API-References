## HtmlSaveOptions.UseZOrder property

如果将属性 UseZORder 设置为 true，图形和文本将按照原始 PDF 文档中的 Z 顺序添加到生成的 HTML 文档中。如果此属性为 false，所有图形将放置在单一层上，可能会导致重叠对象出现不必要的效果。

```csharp
public bool UseZOrder { get; set; }
```
