## HtmlSaveOptions.CssClassNamesPrefix field

当 PDFtoHTML 转换器生成结果 CSS 时，CSS 类名（例如 ".stl_01 {}" … ".stl_NN {}"）会被生成并用于结果 CSS。此属性允许强制设置类名前缀。例如，如果您希望所有类名以 'my_prefix_' 开头（即类似 'my_prefix_1' … 'my_prefix_NNN'），只需在转换前将 'my_prefix_' 赋给此属性。如果此属性保持未设置（即值为 null），转换器将自行生成类名（如 ".stl_01 {}" … ".stl_NN {}"）。

```csharp
public string CssClassNamesPrefix;
```
