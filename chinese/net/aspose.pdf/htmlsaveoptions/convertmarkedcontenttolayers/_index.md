## HtmlSaveOptions.ConvertMarkedContentToLayers property

如果属性 ConvertMarkedContentToLayers 设置为 true，则 PDF 标记内容（图层）中的所有元素将放入具有 \"data-pdflayer\" 属性并指定图层名称的 HTML div 中。该图层名称将从 PDF 标记内容的可选属性中提取。如果此属性为 false（默认），则不会从 PDF 标记内容创建任何图层。

```csharp
public bool ConvertMarkedContentToLayers { get; set; }
```
