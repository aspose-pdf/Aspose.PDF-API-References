## HtmlSaveOptions.RenderTextAsImage property

如果将属性 RenderTextAsImage 设置为 true，来源文本将在 HTML 中变为图像。这在需要使文本不可选中或 HTML 文本渲染不正确时可能有用。

```csharp
public bool RenderTextAsImage { get; set; }
```
