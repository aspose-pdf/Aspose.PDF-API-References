## HtmlSaveOptions.SpecialFolderForAllImages field

获取或设置在将文档保存为 HTML 时必须保存任何遇到的图像的目录路径。如果参数为空或 null，则图像文件（如果有）将与链接到 HTML 的其他文件一起保存。如果已成功使用 CustomImageSavingStrategy 属性处理相关图像文件，则此设置不产生任何影响。

```csharp
public string SpecialFolderForAllImages;
```
