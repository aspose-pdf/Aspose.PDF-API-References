## HtmlSaveOptions.SpecialFolderForSvgImages field

获取或设置在将文档保存为 HTML 时必须保存仅 SVG 图像的目录路径。如果参数为空或 null，则 SVG 文件（如果有）将与其他图像文件（位于输出文件附近）一起保存，或保存到特殊图像文件夹（如果在 SpecialImagesFolderIfAny 选项中指定）。如果已成功使用 CustomImageSavingStrategy 属性处理相关图像文件，则此设置不产生任何影响。

```csharp
public string SpecialFolderForSvgImages;
```
