## HtmlSaveOptions.MinimalLineWidth property

此属性设置图形路径线的最小宽度。如果线的粗细小于 1px，Adobe Acrobat 会将其四舍五入为此值。因此可以使用此属性在 HTML 浏览器中模拟此行为。

```csharp
public float MinimalLineWidth { get; set; }
```
