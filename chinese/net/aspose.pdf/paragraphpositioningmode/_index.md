## ParagraphPositioningMode enumeration

指定用于确定元素在页面上位置的变体。

```csharp
public enum ParagraphPositioningMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Default | `0` | 位置由先前放置的元素决定。在确定后续元素的位置时会考虑添加的元素。 |
| Absolute | `1` | 位置由 Left 和 Top 值指定，不依赖于先前的元素，也不影响后续元素的位置。 |
