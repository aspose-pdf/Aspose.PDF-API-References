## PdfSaveOptions.DefaultFontName property

默认用于缺失字体的字体名称。当保存为 PDF 的文档中包含在文档本身和设备上都不可用的字体时，API 会将这些字体替换为默认字体（如果在设备上找到 `DefaultFontName` 字体）。

```csharp
public string DefaultFontName { get; set; }
```
