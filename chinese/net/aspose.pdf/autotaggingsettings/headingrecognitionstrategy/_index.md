## AutoTaggingSettings.HeadingRecognitionStrategy property

获取或设置在自动标记期间用于识别文档中标题的策略。

```csharp
public HeadingRecognitionStrategy HeadingRecognitionStrategy { get; set; }
```

## 备注

`HeadingRecognitionStrategy` 属性决定了如何在 Document 中识别标题。可用的策略包括基于大纲、启发式分析或自动检测的标题识别。将此属性设置为 None 将禁用标题识别。
