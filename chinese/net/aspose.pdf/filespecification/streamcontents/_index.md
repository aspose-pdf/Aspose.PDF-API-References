## FileSpecification.StreamContents property

以流的形式获取文件内容。内容不会加载到内存中，从而降低内存使用。但此流不支持定位和 Length 属性。如果需要这些功能，请改用 Contents 属性。

```csharp
public Stream StreamContents { get; }
```
