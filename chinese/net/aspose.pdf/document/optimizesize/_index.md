## Document.OptimizeSize property

获取或设置优化标志。如果设置此标志，当向文档添加页面时，结果文件中相同的资源流将合并为一个 PDF 对象。这可以减小生成文件的大小，但可能导致执行速度变慢和内存需求增大。默认值：false。

```csharp
public bool OptimizeSize { get; set; }
```
