## Document.DisableFontLicenseVerifications property

如果字体许可证禁止某些操作，则许多与字体相关的操作无法执行。例如，如果许可证规则禁用嵌入，则某些字体无法嵌入到 PDF 文档中。此标志用于在当前 PDF 文档中禁用所有字体的任何许可证限制。使用此标志时请谨慎。设置后表示设置此标志的人自行承担可能的许可证/法律违规责任，即自行承担风险。强烈建议仅在完全确信不会侵犯版权法时才使用此标志。默认值为 false。

```csharp
public bool DisableFontLicenseVerifications { get; set; }
```
