## MarkdownSaveOptions.HeadingLevels property

定义在 FontSize 识别标题策略中使用的预期标题级别。如果设置了此属性值，则即使文档包含书签，也会在设置 !:PdfToMarkdown.HeadingRecognitionStrategy.Auto 策略时选择标题识别启发式策略。

```csharp
public HeadingLevels HeadingLevels { get; set; }
```
