## MarkdownSaveOptions.UseImageHtmlTag property

获取和设置是否允许使用 img 标签在文本左侧或右侧插入图像。在这种情况下，markdown 查看器中，文本将环绕图像换行。

```csharp
public bool UseImageHtmlTag { get; set; }
```
