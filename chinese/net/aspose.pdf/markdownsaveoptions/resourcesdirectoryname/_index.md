## MarkdownSaveOptions.ResourcesDirectoryName property

获取和设置用于保存文档资源（如图像）的目录名称。如果未指定该值，则图像将写入与 markdown 文件本身相同的目录。这不是路径，仅是名称！该目录将在保存 markdown 文件的目录中自动创建。

```csharp
public string ResourcesDirectoryName { get; set; }
```
