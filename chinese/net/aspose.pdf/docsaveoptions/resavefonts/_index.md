## DocSaveOptions.ReSaveFonts property

获取或设置重新保存字体的过程。如果设为 true，我们将在每页重新加载字体，以避免先前字体属性的影响，并从头加载新创建的字体。如果想提升性能，请将此选项设为 false。默认值为 true；

```csharp
public bool ReSaveFonts { get; set; }
```
