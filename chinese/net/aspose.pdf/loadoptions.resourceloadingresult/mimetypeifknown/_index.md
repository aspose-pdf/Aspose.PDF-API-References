## LoadOptions.ResourceLoadingResult.MIMETypeIfKnown field

有时已加载资源的 MIME 类型信息对转换器很有用。您可以在此参数中提供 MIME 类型（如果在加载后已知）。当 MIME 类型未知或无需提供时，请将参数设为 null。

```csharp
public string MIMETypeIfKnown;
```
