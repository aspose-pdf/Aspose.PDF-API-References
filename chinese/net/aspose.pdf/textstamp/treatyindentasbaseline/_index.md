## TextStamp.TreatYIndentAsBaseLine property

定义放置文本的坐标原点。如果 TreatYIndentAsBaseLine = true（Draw = true 时的默认值），YIndent 值将被视为文本基线。如果 TreatYIndentAsBaseLine = false（Draw = false 时的默认值），YIndent 值将被视为文本的底部（下降线）。

```csharp
public bool TreatYIndentAsBaseLine { get; set; }
```
