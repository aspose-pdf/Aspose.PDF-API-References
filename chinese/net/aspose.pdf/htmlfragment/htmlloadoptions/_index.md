## HtmlFragment.HtmlLoadOptions property

获取或设置用于将 HTML 加载（和呈现）到此类实例中的 HtmlLoadOptions。请在需要为此实例或该实例的 HTML 导入使用特定设置时使用它（例如，当此实例或该实例应使用特定的 BasePath 来导入 HTML，或应使用特定的外部资源加载器时）。如果参数为默认值（null），则使用标准的 HTML 加载选项。

```csharp
public HtmlLoadOptions HtmlLoadOptions { get; set; }
```
