## Page.UserUnit property

获取或设置 UserUnit 值。一个正数，表示默认用户空间单位的大小，以 1/72 英寸的倍数计。默认值为 1。请设置为零或负数以清除页面中的此条目。

```csharp
public double UserUnit { get; set; }
```
