## RenderingOptions.UseFontHinting property

使用此标志可开启字体微调机制。字体微调是使用数学指令来调整轮廓字体的显示方式。在某些情况下，打开此标志可能会解决文本可读性问题。目前，此标志的使用仅对 TTF 字体生效，如果这些字体在源文档中使用的话。

```csharp
public bool UseFontHinting { get; set; }
```
