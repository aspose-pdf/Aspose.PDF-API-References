## RenderingOptions.IgnoreResourceFontErrors property

获取或设置指示是否忽略与缺少字体相关错误的标志。true - 表示将忽略缺少字体的错误。处理期间将跳过引用不正确资源的文本段。默认值为 false。

```csharp
public bool IgnoreResourceFontErrors { get; set; }
```
