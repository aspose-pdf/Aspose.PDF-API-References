## HtmlSaveOptions.CssSavingInfo.CssNumber field

由转换器设置。在转换过程中会创建多个 CSS 文件。此属性显示在转换期间已保存 CSS 文件的序号。可在自定义代码逻辑中使用，以决定如何处理或将 CSS 内容保存到何处。

```csharp
public int CssNumber;
```
