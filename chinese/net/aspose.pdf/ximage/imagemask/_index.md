## XImage.ImageMask property

获取一个标志，指示图像是否应被视为图像遮罩（参见 8.9.6，“Masked Images”）。如果此标志为 true，则 BitsPerComponent 的值应为 1，且不应指定 Mask 和 ColorSpace；未遮罩的区域应使用当前非描边颜色进行绘制。默认值：false。

```csharp
public bool ImageMask { get; }
```

### Property Value

True 表示该图像是图像掩码。
