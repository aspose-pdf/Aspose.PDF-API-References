| 名称 | 值 | 描述 |
| --- | --- | --- |
| Pdf | `0` | 表示在不更改格式的情况下保存，即保存为 PDF，请使用它而不是 'SaveFormat.None'，后者已过时。 |
| None | `0` | 表示在不更改格式的情况下保存，即保存为 PDF。此方式已过时且将被删除，请改用 'SaveFormat.Pdf'。 |

| Svg | `7` | 表示以 SVG 格式保存 |
