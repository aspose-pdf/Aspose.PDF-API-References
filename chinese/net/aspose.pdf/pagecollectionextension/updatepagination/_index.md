## PageCollectionExtension.UpdatePagination method

更新所有页面的页眉和页脚页码及日期。如果文档至少包含一个具有特殊设置数据的分页工件，则此操作有效。集合中的所有页面将根据其设置使用源工件进行更新。

```csharp
public static void UpdatePagination(this PageCollection pageCollection)
```
