## PsLoadOptions.ConvertFontsToTTF property

指定是否将非 TrueType 字体保存为 TTF。它显著降低 PS 转 PDF 转换后文档的体积，并提高在非 TrueType 字体文本量大的 PS 文件转换为任何输出格式的速度。然而，在将 PostSctipt 文件转换为图像时会出现轻微的垂直文字位移。

```csharp
public bool ConvertFontsToTTF { get; set; }
```
