## PasswordType enumeration

此枚举表示用于受密码保护的 PDF 文档的已知密码类型。

```csharp
public enum PasswordType
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | Pdf 文档未受密码保护。 |
| User | `1` | Pdf 文档已使用打开密码打开（受限访问）。 |
| Owner | `2` | Pdf 文档已使用更改权限密码打开（完全访问）。 |
| Inaccessible | `3` | Pdf 文档受密码保护，但用户密码和所有者密码均不为空，且未定义任何密码或提供的密码不正确。因此无法推断密码的类型。 |
