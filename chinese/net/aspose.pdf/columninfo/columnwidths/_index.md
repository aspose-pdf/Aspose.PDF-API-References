## ColumnInfo.ColumnWidths property

获取或设置一个字符串，包含列的宽度。每列的数值应以空格分隔。默认单位是点（point），但也支持厘米（cm）、英寸（inch）以及可用宽度的百分比。例如，\"120 2.5cm 1.5inch\"。

```csharp
public string ColumnWidths { get; set; }
```
