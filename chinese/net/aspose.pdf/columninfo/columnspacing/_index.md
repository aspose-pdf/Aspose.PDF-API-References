## ColumnInfo.ColumnSpacing property

获取或设置一个字符串，包含列之间的间距。每个间距的数值应以空格分隔。默认单位是点（point），但也支持厘米（cm）和英寸（inch）。例如，\"120 2.5cm 1.5inch\"。

```csharp
public string ColumnSpacing { get; set; }
```

## 备注

如果未设置此属性，将对每个间距使用默认值 0。
