## SetDash.Phase property

虚线相位。在开始描边路径之前，虚线数组应循环遍历，累计虚线和间隙的长度。当累计长度等于虚线相位指定的值时，路径的描边将开始，并且从该点起虚线数组将循环使用。

```csharp
public int Phase { get; set; }
```
