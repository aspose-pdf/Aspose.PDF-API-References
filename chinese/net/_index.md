## 命名空间

| 命名空间 | 描述 |
| --- | --- |
| [Aspose.Pdf](./aspose.pdf/) | **Aspose.Pdf** 是 Aspose.Pdf 库中所有类的根命名空间，这些类可以直接位于其中，如 **Document**，也可以通过多个子命名空间间接访问。 |
| [Aspose.Pdf.AI](./aspose.pdf.ai/) | **Aspose.Pdf.AI** 命名空间提供用于 AI 功能的类，包括 API 客户端和智能助理。 |
| [Aspose.Pdf.Annotations](./aspose.pdf.annotations/) | **Aspose.Pdf.Annotations** 命名空间提供用于处理文档中各种操作、目标及其他传统称为交互式功能的类，使用户能够与文档进行交互。 |
| [Aspose.Pdf.Comparison](./aspose.pdf.comparison/) | **Aspose.Pdf.Comparison** 命名空间提供用于文档比较的类。 |
| [Aspose.Pdf.DataEditor](./aspose.pdf.dataeditor/) | **Aspose.Pdf.DataEditor** 包含用于编辑文档内部数据的工具。 |
| [Aspose.Pdf.Devices](./aspose.pdf.devices/) | **Aspose.Pdf.Devices** 命名空间提供用于将文档表示为图像或纯文本的类。因此文档可以发送到文本或各种图形设备，以获取其文本或图形表示。 |
| [Aspose.Pdf.Drawing](./aspose.pdf.drawing/) | **Aspose.Pdf.Drawing** 命名空间提供描述图形原语（如弧线、直线、圆等）的类。相应的对象可用于创建新文档。 |
| [Aspose.Pdf.Facades](./aspose.pdf.facades/) | **Aspose.Pdf.Facades** 命名空间提供最初来自 Aspose.Pdf.Kit 的类。这些类用于在不访问文档内部结构的情况下，对文档执行合并、加盖印章、签名、注释等高级操作。 |
| [Aspose.Pdf.Forms](./aspose.pdf.forms/) | **Aspose.Pdf.Forms** 命名空间拥有描述表单（标准、静态、动态）以及各种字段类型（如文本框、列表框、单选按钮等）的类。 |
| [Aspose.Pdf.LogicalStructure](./aspose.pdf.logicalstructure/) | **Aspose.Pdf.Tagged.LogicalStructure** 是用于 PDF 逻辑结构类的命名空间。 |
| [Aspose.Pdf.Multithreading](./aspose.pdf.multithreading/) | **Aspose.Pdf.Multithreading** 命名空间提供旨在多线程场景中使用的类。 |
| [Aspose.Pdf.Operators](./aspose.pdf.operators/) | **Aspose.Pdf.Operators** 是用于运算符实现的命名空间。这些类描述了在 PDF 页面内容中使用的运算符。 |
| [Aspose.Pdf.Optimization](./aspose.pdf.optimization/) | **Aspose.Pdf.Optimization** 是用于管理文档优化过程的类的命名空间。 |
| [Aspose.Pdf.Plugins](./aspose.pdf.plugins/) | **Aspose.Pdf.Plugins** 是 Aspose.Pdf.Plugins 所有类的根命名空间，这些类可以直接位于其中，如 **PdfOrganizer**，也可以通过多个子命名空间间接访问。 |
| [Aspose.Pdf.Printing](./aspose.pdf.printing/) | **Aspose.Pdf.Printing** 命名空间提供用于处理 PDF 打印操作的类和功能，包括打印机设置、页面设置以及用于管理打印相关配置的扩展。 |
| [Aspose.Pdf.Sanitization](./aspose.pdf.sanitization/) | **Aspose.Pdf.Sanitization** 是用于清理操作的命名空间。 |
| [Aspose.Pdf.Security](./aspose.pdf.security/) | **Aspose.Pdf.Security** 命名空间包含用于加密和数字签名的类。 |
| [Aspose.Pdf.Signatures](./aspose.pdf.signatures/) | **Aspose.Pdf.Signatures** 命名空间包含用于检测受损签名的类。 |
| [Aspose.Pdf.Structure](./aspose.pdf.structure/) | **Aspose.Pdf.Structure** 命名空间提供帮助处理文档逻辑结构的类，该结构展示了文档在章节和节中的组织方式，以及对图形、表格和脚注等特殊元素的识别。 |
| [Aspose.Pdf.Tagged](./aspose.pdf.tagged/) | **Aspose.Pdf.Tagged** 是用于支持 Tagged PDF 文档的类的命名空间。 |
| [Aspose.Pdf.Text](./aspose.pdf.text/) | 该 **Aspose.Pdf.Text** 命名空间提供类，允许提取文本、添加文本、操作现有的文本的 Document。它还包含允许提取、替换、替代字体的 Document。 |
| [Aspose.Pdf.Vector](./aspose.pdf.vector/) | 该 **Aspose.Pdf.Vector** 是用于图形操作的根命名空间。 |
| [Aspose.Pdf.XfaConverter](./aspose.pdf.xfaconverter/) | 该 **Aspose.Pdf.XfaConverter** 命名空间提供类，允许转换 XFA。 |
