## TextExtractorOptions.TextFormattingMode enumeration

定义在将 PDF Document 转换为文本时可使用的不同模式。参见 [`TextExtractorOptions`](../textextractoroptions/) 类。

```csharp
public enum TextFormattingMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| Pure | `0` | 表示带有少量格式化例程的 PDF 文本内容。这包括考虑相对位置并添加额外空格以将文本对齐到页面宽度。 |
| Raw | `1` | 按原样表示 PDF 内容，即不进行格式化。 |
| Plain | `2` | 表示 PDF 文本内容，考虑文本片段的相对位置，但不添加额外空格。 |
