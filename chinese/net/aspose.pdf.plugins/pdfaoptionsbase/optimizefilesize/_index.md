## PdfAOptionsBase.OptimizeFileSize property

获取或设置一个值，指示是否尝试在 PDF/A 转换过程中减小文件大小。

```csharp
public bool OptimizeFileSize { get; set; }
```

### Property Value

`true` 表示应尽可能减小文件大小；否则为 `false`。

## 备注

设置为 `true` 时，转换过程将尝试最小化生成的文件大小。这可能会影响转换过程的性能。
