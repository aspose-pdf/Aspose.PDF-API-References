## PdfAOptionsBase.PuaSymbolsProcessingStrategy property

获取或设置在 PDF 文档中处理私有使用区（PUA）符号的策略。

```csharp
public PuaProcessingStrategy PuaSymbolsProcessingStrategy { get; set; }
```

### Property Value

处理 PUA 符号的策略。对于符合 Level B 标准的文档默认是 None，对于符合 Level A 标准的文档默认是 SurroundPuaTextWithEmptyActualText。
