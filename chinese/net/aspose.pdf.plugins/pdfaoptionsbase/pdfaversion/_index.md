## PdfAOptionsBase.PdfAVersion property

获取或设置用于验证或转换的 PDF/A 标准版本。

```csharp
public PdfAStandardVersion PdfAVersion { get; set; }
```

### Property Value

PDF/A 标准的版本。它可以是来自 [`PdfAStandardVersion`](../../pdfastandardversion/) 枚举的值之一。

## 备注

PDF/A 标准版本用于确定 PDF/A 验证和转换的合规级别。如果将版本设置为 Auto，系统将根据文档元数据自动确定用于验证的适当 PDF/A 标准版本。对于 PDF/A 转换过程，Auto 默认使用 PDF/A-1b 标准版本。
