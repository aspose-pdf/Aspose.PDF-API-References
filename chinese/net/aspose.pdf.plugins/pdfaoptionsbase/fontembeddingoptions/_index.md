## PdfAOptionsBase.FontEmbeddingOptions property

获取处理无法嵌入 Document 的字体的选项。

```csharp
public FontEmbeddingOptions FontEmbeddingOptions { get; }
```

### Property Value

字体嵌入选项。

## 备注

PDF/A 标准要求所有字体必须嵌入文档中。此属性提供在目标电脑缺少某些字体而无法嵌入时的处理选项。
