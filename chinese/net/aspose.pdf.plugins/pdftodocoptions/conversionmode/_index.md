## PdfToDocOptions.ConversionMode property

允许控制 PDF 文档如何转换为文字处理文档。

```csharp
public ConversionMode ConversionMode { get; set; }
```

## 备注

当生成的文档不需要大量后续编辑时，请使用 TextBox 模式。文本框在工作量不大时易于修改。

当输出文档需要进一步编辑时，请使用 Flow 模式。Flow 模式下的段落和文本行便于文本的修改，但不受支持的格式对象的显示效果会比 TextBox 模式更差。
