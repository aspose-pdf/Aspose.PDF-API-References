## DocumentPrivilege.AllowDegradedPrinting property

设置是否允许低质量打印的权限。true 表示允许，false 表示禁止。

```csharp
public bool AllowDegradedPrinting { get; set; }
```

## 备注

当设置时，打印将被限制为外观的低级表示，可能会降低质量。
