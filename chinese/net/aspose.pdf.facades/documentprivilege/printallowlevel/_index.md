## DocumentPrivilege.PrintAllowLevel property

获取和设置 Document 权限的打印级别。就像 Adobe Professional 的 Printing Allowed 设置。0：无。1：低分辨率（150 dpi）。2：高分辨率。

```csharp
public int PrintAllowLevel { get; set; }
```

## 备注

如果属性的值为 -1，则该级别未定义。
