## DocumentPrivilege.ChangeAllowLevel property

获取和设置 Document 权限的更改级别。就像 Adobe Professional 的 Changes Allowed 设置。0：无。1：插入、删除和旋转页面。2：填写表单字段并签署现有签名字段。3：添加批注、填写表单字段并签署现有签名字段。4：除提取页面之外的所有操作。

```csharp
public int ChangeAllowLevel { get; set; }
```

## 备注

如果属性的值为 -1，则该级别未定义。
