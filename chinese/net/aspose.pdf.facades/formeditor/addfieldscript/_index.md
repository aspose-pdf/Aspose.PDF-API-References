## FormEditor.AddFieldScript method

为 PushButton 字段添加 JavaScript。如果已有旧事件，新事件将添加在其后。

```csharp
public bool AddFieldScript(string fieldName, string script)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| fieldName | String | 完全限定的字段名称。 |
| script | String | 要添加/放入 PushButton 字段的 Java 脚本。 |

### 返回值

如果脚本成功添加则为 True。
