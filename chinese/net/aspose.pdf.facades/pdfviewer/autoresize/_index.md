## PdfViewer.AutoResize property

获取或设置一个 bool 值，指示文件是否以优化大小打印。如果为 false，则在不进行页面缩放的情况下打印页面；如果为 true，则在缩放以适应可打印区域的情况下打印页面。

```csharp
public bool AutoResize { get; set; }
```
