## PdfViewer.PrintAsImage property

设置或获取 PdfViewer 的图像打印模式。

```csharp
public bool PrintAsImage { get; set; }
```

## 备注

如果为 true，则始终以图像方式打印（生成要打印的图像）；如果为 false，则在所有功能受支持时直接打印到设备。如果文档包含不受支持的功能，系统可能会自动决定以图像方式打印。默认值为 false。
