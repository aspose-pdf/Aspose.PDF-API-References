## PdfExtractor.Resolution property

设置或获取提取图像的分辨率。默认值为 150。分辨率更高的图像会更清晰。然而，提高分辨率会导致提取图像所需的时间和内存增加。通常，要获得清晰的图像，只需将分辨率设置为 150 或 300。

```csharp
public int Resolution { get; set; }
```
