## TiffSettings.Brightness property

获取或设置白色和黑色颜色转换的阈值。此参数可与 EncoderValue.CompressionCCITT4、EncoderValue.CompressionCCITT3、EncoderValue.CompressionRle 或 ColorDepth.Format1bpp == 1 一起使用。

```csharp
public float Brightness { get; set; }
```

### Property Value

亮度值应在 0 到 1 的范围内。默认值为 0.33f。
