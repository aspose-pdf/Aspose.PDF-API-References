## ValidationOptions.RequestTimeout property

获取或设置验证过程中的网络相关操作的超时时间（毫秒）。RequestTimeout 属性定义在访问在线资源（如撤销状态或 OCSP 服务器）时系统应等待网络响应的最长时间。

```csharp
public int RequestTimeout { get; set; }
```
