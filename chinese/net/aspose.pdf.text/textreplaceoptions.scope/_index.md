## TextReplaceOptions.Scope enumeration

文本替换操作的范围默认应用 REPLACE_FIRST。此已废弃选项保留用于兼容性。它影响 PdfContentEditor，但对 TextFragmentAbsorber 没有影响。

```csharp
public enum Scope
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| REPLACE_FIRST | `0` | 仅在每个受影响的页面上替换文本的首次出现 |
| REPLACE_ALL | `1` | 在所有受影响的页面上替换所有文本出现 |
