## TextSearchOptions.IgnoreShadowText property

获取或设置指示在搜索期间是否忽略表示普通文本阴影的文本片段。true - 表示不会找到阴影文本（如果文本搜索在相近位置返回重复片段，可尝试此设置）。false - 表示阴影文本将与普通文本一起被找到（默认值）。

```csharp
public bool IgnoreShadowText { get; set; }
```
