## TextSearchOptions.UseFontEngineEncoding property

获取或设置指示是否使用字体引擎编码进行文本搜索。true - 表示将使用字体引擎编码（如果文本搜索因文档中编码不完整而失败，可尝试此设置）。false - 表示将使用文档字体编码（默认值）。

```csharp
public bool UseFontEngineEncoding { get; set; }
```
