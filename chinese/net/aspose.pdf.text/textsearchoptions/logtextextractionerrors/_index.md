## TextSearchOptions.LogTextExtractionErrors property

获取或设置指示是否将在文本（片段）吸收器中记录文本提取（解码）错误。true - 表示将记录文本提取（解码）错误，这可能会降低性能。false（默认） - 不记录错误。

```csharp
public bool LogTextExtractionErrors { get; set; }
```
