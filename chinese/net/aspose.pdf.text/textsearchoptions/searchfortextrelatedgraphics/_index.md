## TextSearchOptions.SearchForTextRelatedGraphics property

获取或设置允许在文本搜索期间搜索与文本相关的图形（下划线、背景等）的值。true - 将执行文本相关图形的搜索（默认值）。false - 将忽略源文档中可能出现的图形元素。若出现性能问题或不需要处理下划线、背景或裁剪，可将其设为 false。

```csharp
public bool SearchForTextRelatedGraphics { get; set; }
```
