```csharp
public enum WordWrapMode
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| NoWrap | `0` | 不执行换行 |
| DiscretionaryHyphenation | `1` | 执行可选连字符处理。允许在单词中间断开。 |
| ByWords | `2` | 换行仅对完整单词进行换行。如果完整单词无法换行，则尝试使用可选连字符处理。 |
| Undefined | `3` | 未设置 WordWrapMode。将使用上层结构（表格单元格、段落等）的换行策略。 |
