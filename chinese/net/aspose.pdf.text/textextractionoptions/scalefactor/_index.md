## TextExtractionOptions.ScaleFactor property

获取或设置在纯模式下提取时用于缩放字体大小的因子。较小的值会导致提取的文本中出现更多空格。默认值为 1 - 不缩放；将值设为零则允许算法自动选择缩放。

```csharp
public double ScaleFactor { get; set; }
```
