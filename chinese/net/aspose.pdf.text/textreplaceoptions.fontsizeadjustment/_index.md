## TextReplaceOptions.FontSizeAdjustment enumeration

指定文本字体大小应如何调整以适应包含区域的策略。

```csharp
public enum FontSizeAdjustment
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| None | `0` | 字体大小不变。 |
| ShrinkToFit | `1` | 如果文本过大而无法适应边界，则会减小字体大小。如果文本小于边界，则字体大小永不增大。 |
| ScaleToFill | `2` | 字体大小会被调整（包括缩小和放大），以使文本尽可能填满矩形的边界。 |
