## SideBySideComparisonOptions.ExcludeAreas2 property

获取和设置排除区域。用于比较方法中的第二页或文档。此选项可以与 [`ExcludeTables`](../excludetables/) 一起设置。此选项不能与 [`ComparisonArea2`](../comparisonarea2/) 选项一起设置。

public Rectangle[] ExcludeAreas2 { get; set; }
