## BaseListQueryParameters.Before property

获取或设置用于分页的游标。before 是定义您在列表中位置的对象 ID。例如，如果您发出列表请求并收到 100 个对象，最后一个为 obj_foo，则后续调用可以包含 before=obj_foo 以获取列表的上一页。

public string Before { get; set; }
