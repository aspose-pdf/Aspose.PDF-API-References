## CreateEmbeddingRequest.Input property

获取或设置要嵌入的输入文本，编码为字符串或标记数组。要在单个请求中嵌入多个输入，请传递字符串数组或标记数组的数组。输入不得超过模型的最大输入标记数（text-embedding-ada-002 为 8192 标记），不能为空字符串，且任何数组的维度必须不超过 2048。

public string Input { get; set; }
