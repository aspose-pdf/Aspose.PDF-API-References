## AssistantCreateRequest.TopP property

获取或设置温度采样的替代方案，称为 nucleus 采样，即模型根据 top_p 概率质量考虑 token 的结果。因此 0.1 表示仅考虑占前 10% 概率质量的 token。我们通常建议只调整其中之一，而不是同时修改两者。

public double? TopP { get; set; }
