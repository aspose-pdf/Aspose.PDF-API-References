## TruncationStrategy.StrategyType property

获取或设置线程使用的截断策略。默认是 auto。如果设置为 last_messages，线程将截断为最近的 n 条消息。当设置为 auto 时，线程中间的消息将被删除，以适应模型的上下文长度 max_prompt_tokens。

```csharp
public string StrategyType { get; set; }
```
