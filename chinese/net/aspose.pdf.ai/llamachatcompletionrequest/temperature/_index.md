## LlamaChatCompletionRequest.Temperature property

设置或获取使用的采样温度，范围在 0 到 2 之间。像 0.8 这样的较高值会使输出更随机，而像 0.2 这样的较低值会使输出更集中且确定。默认值为 1。

```csharp
public double? Temperature { get; set; }
```
