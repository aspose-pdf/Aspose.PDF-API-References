## PopupAnnotation.Parent property

获取或设置此 pop-up 注释应关联的父注释。如果存在此条目，父注释的 Contents、M、C 和 T 条目将覆盖该 pop-up 注释本身的对应条目。

```csharp
public Annotation Parent { get; set; }
```
