## AppearanceDictionary.Keys property

获取字典的键。如果外观字典具有子字典，则 `Keys` 包含 (N&#x7C;R&#x7C;D).state 值，其中 N - 普通外观，R - 悬停外观，D - 按下外观，state - 状态的名称（例如复选框的 On、Off）。

public ICollection<string> Keys { get; }
