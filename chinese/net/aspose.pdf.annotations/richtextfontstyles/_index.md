## RichTextFontStyles enumeration

RichText 中文本片段样式的选项。

```csharp
[Flags]
public enum RichTextFontStyles
```

### 值

| 名称 | 值 | 描述 |
| --- | --- | --- |
| ClearExisting | `1` | 如果设置，则在应用其他样式之前清除所有现有样式。当与其他样式标志（例如 Bold）组合使用时，它首先重置样式，然后应用指定的样式。如果未设置此标志，则新样式会添加到现有样式中。 |
| Bold | `2` | 指定粗体的选项。 |
| Italic | `4` | 指定斜体的选项。 |
| Underline | `8` | 指定下划线的选项。 |
