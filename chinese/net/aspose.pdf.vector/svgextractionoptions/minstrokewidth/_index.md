## SvgExtractionOptions.MinStrokeWidth property

获取或设置生成的 SVG 中使用的最小笔画宽度。如果 PDF 使用更细的笔画宽度，将被此宽度替代。默认值为 0.5。

```csharp
public double MinStrokeWidth { get; set; }
```

## 备注

该值以转换后的 PDF 页面用户空间单位表示。默认情况下，1 个用户空间单位等于 1/72 英寸（0.35 毫米），但可以被 PDF 文档覆盖。变换可能会影响生成的 SVG 中的实际最小宽度。
