## Field.IsSharedField property

用于 Generator 支持的属性。字段添加到页眉或页脚时使用。如果为 true，则此字段只创建一次，其外观将在 Document 的所有 Page 上可见。如果为 false，则为每个 Document Page 创建单独的字段。

```csharp
public bool IsSharedField { get; set; }
```
