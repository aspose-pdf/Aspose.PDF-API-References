## Signature.ShowProperties property

强制显示/隐藏签名属性。如果 ShowProperties 为 true，签名字段将具有预定义的外观格式（字符串表示）： ------------------------------------------- Digitally signed by {certificate subject} Date: {signature.Date} Reason: {signature.Reason} Location: {signature.Location} ------------------------------------------- 其中 {X} 为 X 值的占位符。签名也可以包含图像，在此情况下上述字符串会放置在图像上。ShowProperties 默认为 true。

```csharp
public bool ShowProperties { get; set; }
```
