## Form.NeedsRendering property

获取一个值，指示文档是否需要删除动态 XFA 表单。引入此属性是为了确定在 XFA 表单存在且 `NeedsRendering` 为 false 的情况下，是否应使用 [`IgnoreNeedsRendering`](../ignoreneedsrendering/) 来删除 XFA 表单。

```csharp
public bool NeedsRendering { get; }
```
