## Form.HasXfa property

获取一个值，指示文档是否包含 XFA 表单。引入此属性是为了在 XFA 表单存在且 [`NeedsRendering`](../needsrendering/) 为 false 的情况下，确定是否应使用 [`IgnoreNeedsRendering`](../ignoreneedsrendering/) 来移除 XFA 表单。

```csharp
public bool HasXfa { get; }
```
