## Form.AutoRecalculate property

如果设置为 true，则在任意字段更改时会重新计算所有表单字段。默认值为 true。为提高在填充包含大量计算字段的表单时的性能，可将其设为 false。

```csharp
public bool AutoRecalculate { get; set; }
```
