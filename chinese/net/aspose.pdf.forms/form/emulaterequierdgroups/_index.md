## Form.EmulateRequierdGroups property

如果此属性为 true，则会为必需的 Xfa exclGroup 元素容器绘制额外的红色边界矩形。之所以引入此属性，是因为在将 Xfa 表单表示转换为标准时缺少 exclGroup 的对应项。默认值为 false。

```csharp
public bool EmulateRequierdGroups { get; set; }
```
