## BarcodeField.XSymHeight property

获取两个条形码模块之间的垂直距离，单位为像素。比例 XSymHeight/XSymWidth 应为整数值。对于 PDF417，可接受的比例范围为 1 到 4。对于 QRCode 和 DataMatrix，此比例始终为 1。

```csharp
public int XSymHeight { get; }
```
