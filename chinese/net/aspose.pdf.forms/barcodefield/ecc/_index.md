## BarcodeField.ECC property

获取表示错误纠正系数的整数值。对于 PDF417，应在 0 到 8 之间。对于 QRCode，应在 0 到 3 之间（0 表示 'L'，1 表示 'M'，2 表示 'Q'，3 表示 'H'）。

public int ECC { get; }
