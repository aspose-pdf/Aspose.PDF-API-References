## XfaParserOptions.Signed property

如果此属性为 true，则文档将在使用 xfa 表单流（如果存在）的情况下进行转换；如果为 false，则 xfa 表单流将被忽略。引入此属性是因为尚不清楚如何计算用于校验签名的校验和。

```csharp
public bool Signed { get; set; }
```
