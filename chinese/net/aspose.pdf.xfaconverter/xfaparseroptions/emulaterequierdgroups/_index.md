## XfaParserOptions.EmulateRequierdGroups property

如果此属性为 true，则会为必需的 Xfa "排除组"绘制额外的红色矩形。引入此属性是因为在将 Xfa 表单表示转换为标准时缺少排除组的对应项。默认值为 false。

```csharp
public bool EmulateRequierdGroups { get; set; }
```
