## AttributeName.RubyAlign_Distribute field

属性 RubyAlign：Distribute - 内容应在行内进展方向展开以填满可用宽度。然而，还应在文本的起始边缘和结束边缘插入空白。间距应使用 1:2:1（起始:中间:结束）比例分配。如果 ruby 出现在文本行的起始位置，则改为 0:1:1 比例；如果出现在文本行的结束位置，则改为 1:1:0 比例.

```csharp
public static readonly AttributeName RubyAlign_Distribute;
```
