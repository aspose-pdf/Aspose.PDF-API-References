## StructureElement.RemoveAndMoveItsChildObjectsToItsParent method

从结构中移除元素、父对象对它的引用、子对象对它的引用以及相应的 Document 对象。将被移除对象的子对象插入到其原父对象的子集合中，起始索引为被移除对象的索引。

```csharp
public void RemoveAndMoveItsChildObjectsToItsParent(
    bool checkIfChildObjectsCanBeMovedToParent = true)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| checkIfChildObjectsCanBeMovedToParent | Boolean | 检查是否可以将已删除对象的子对象插入到其父对象的子对象集合中。 |
