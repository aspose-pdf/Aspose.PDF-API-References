## StructureTypeStandard.TOC field

(目录) 由目录项条目（结构类型 TOCI）和/或其他嵌套目录条目（TOC）组成的列表。

仅包含 TOCI 条目的目录条目表示平面层次结构。包含其他嵌套目录条目（以及可能的 TOCI 条目）的目录条目表示更复杂的层次结构。理想情况下，顶层目录条目的层次结构应反映文档主体的结构。

```csharp
public static readonly StructureTypeStandard TOC;
```
