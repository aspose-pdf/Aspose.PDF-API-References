## StructureTypeStandard.WP field

(Warichu punctuation) 环绕 WT 文本的标点符号。它包含文本（通常是单个左括号或右括号或类似的括号字符）。根据 JIS X 4051-1995，围绕 warichu 的括号可由格式化程序自行决定转换为一个空格（宽度约为 1/4 EM）。

```csharp
public static readonly StructureTypeStandard WP;
```
