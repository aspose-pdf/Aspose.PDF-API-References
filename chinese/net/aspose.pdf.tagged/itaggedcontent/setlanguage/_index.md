## ITaggedContent.SetLanguage method

设置 PDF 文档的自然语言。

语言标识符用于指定文档中所有文本的自然语言，除非结构元素或标记内容的语言规范覆盖了它。

```csharp
public void SetLanguage(string lang)
```

| 参数 | 类型 | 描述 |
| --- | --- | --- |
| lang | String | 语言标识符应为一个空文本字符串，以表示语言未知，或为 RFC 3066 中定义的语言标签（Language-Tag），即语言标识标签。 |
