## Metadata PDF functions

| 名称 | 描述 |
| -------------- | -------------- |
| [AsposePdfSetInfo](./asposepdfsetinfo/) | 在 PDF 文件中设置信息（元数据）. |
| [AsposePdfGetInfo](./asposepdfgetinfo/) | 从 PDF 文件获取信息（元数据）. |
| [AsposePdfGetAllFonts](./asposepdfgetallfonts/) | 获取 PDF 文件的字体列表. |
| [AsposePdfRemoveMetadata](./asposepdfremovemetadata/) | 从 PDF 文件中移除元数据. |
| [AsposePdfGetWordsCharactersCount](./asposepdfgetwordscharacterscount/) | 获取 PDF 文件中的单词和字符计数. |
| [AsposePdfGetPagesLayers](./asposepdfgetpageslayers/) | 获取 PDF 文件的图层列表. |


## Detailed Description

用于处理元数据 PDF 文件的函数.

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
或
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
