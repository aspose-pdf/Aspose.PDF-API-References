## Security PDF functions

| 名称 | 描述 |
| -------------- | -------------- |
| [AsposePdfEncrypt](./asposepdfencrypt/) | 加密 PDF 文件. |
| [AsposePdfDecrypt](./asposepdfdecrypt/) | 解密 PDF 文件. |
| [AsposePdfSignPKCS7](./asposepdfsignpkcs7/) | 使用数字签名对 PDF 文件进行签名. |
| [AsposePdfSignPKCS7Detached](./asposepdfsignpkcs7detached/) | 使用分离数字签名对 PDF 文件进行签名. |
| [AsposePdfChangePassword](./asposepdfchangepassword/) | 更改 PDF 文件的密码. |

## Detailed Description

用于处理 PDF 文件安全功能的函数。

```js
/* Web Worker*/
const AsposePDFWebWorker = new Worker("AsposePDFforJS.js");
```
或
```html
<!-- Load and initiate Aspose.PDF for JavaScript via C++ -->
<script type="text/javascript" async src="AsposePDFforJS.js"></script>
```
