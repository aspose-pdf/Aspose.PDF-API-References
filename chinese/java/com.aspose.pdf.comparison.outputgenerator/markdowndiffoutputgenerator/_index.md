表示用于生成文本差异 Markdown 表示的类。由于 Markdown 语法，无法显示空白字符的更改。选择更改时需要在格式周围添加空白字符，否则 Markdown 查看器将无法正确显示文本。已删除的换行通过 - 段落标记表示。
