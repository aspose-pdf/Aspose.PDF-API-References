枚举可用于保存已保存 PDF 中引用的字体的模式。

## 字段

| 字段 | 描述 |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | 所有引用的字体将被保存并以 EOT-fonts 形式引用。 |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | 所有引用的字体将被保存并以 TTF-fonts 形式引用。 |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | 所有引用的字体将被保存并以 WOFF-fonts 形式引用。 |
| [DontSave](#DontSave) | 所有引用的字体将不会被保存。 |
| [SaveInAllFormats](#SaveInAllFormats) | 所有引用的字体将被保存（并在 CSS 中引用）为 3 个独立文件：EOT、TTH、WOFF。它会增加输出数据的大小，但使输出适用于绝大多数网页浏览器。 |
