表示符合互联网 RFC 2315 中 PKCS#7 规范（PKCS #7：加密消息语法，版本 1.5）的 PKCS#7 对象。文档字节范围的原始签名消息摘要被作为普通的 PKCS#7 SignedData 字段加入。PKCS#7 SignedData 字段中不应封装任何数据。
