定义定位模式。可能的取值包括 Legacy（向后兼容）和 Current（更新的文本位置计算方法）。

## 字段

| 字段 | 描述 |
| --- | --- |
| [Current](#Current) | 已更新行间距，垂直位置计算基于左上角而非左下角。 |
| [Legacy](#Legacy) | 传统文本定位 |
| [ModernLineSpacing](#ModernLineSpacing) | 已更新行间距，垂直位置计算遵循旧规则（即文本相对于指定矩形的左下角定位） |
