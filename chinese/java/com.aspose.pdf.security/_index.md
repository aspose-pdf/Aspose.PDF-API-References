## 类

| 类 | 描述 |
| --- | --- |
| [HiddenDataSanitizationOptions](./hiddendatasanitizationoptions/) | 表示文档中清理隐藏数据的配置选项。 |
| [HiddenDataSanitizer](./hiddendatasanitizer/) | 表示用于清理隐藏数据的类。 |
| [UnsignedContentAbsorber](./unsignedcontentabsorber/) | 表示用于从受数字签名管理的 PDF 文件中提取未签名内容的类。 |

| [UnsignedContentAbsorber.UnsignedContent](./unsignedcontentabsorber.unsignedcontent/) | 封装从 PDF 文档中提取的未签名内容元素。此类提供对页面、表单字段、XForm 和文档中未签名内容所包含的注释的访问。 |
