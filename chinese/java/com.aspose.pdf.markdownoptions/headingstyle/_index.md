定义可用的标题序列化样式。规格请参见 CommonMark - ATX headings，以及 CommonMark - Setext headings。

## 字段

| 字段 | 描述 |
| --- | --- |
| [Atx](#Atx) | 在标题前加上 '#' |
| [Setext](#Setext) | 使用 "======" 和 "------" 的下划线第1级和第2级标题（Setext 标题）仅适用于第1级和第2级标题。即使标题样式设置为 Setext，级别3及以上的标题仍会使用 Atx 样式。 |

### Atx {#Atx}
```
public static final int Atx
```

### Setext {#Setext}
```
public static final int Setext
```

使用 "======" 和 "------" 的下划线第1级和第2级标题（Setext 标题）仅适用于第1级和第2级标题。即使标题样式设置为 Setext，级别3及以上的标题仍会使用 Atx 样式。
