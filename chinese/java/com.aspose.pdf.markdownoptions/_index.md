com.aspose.pdf.markdownoptions 命名空间包含用于 Markdown 转换的特定选项类。

## 类

| 类 | 描述 |
| --- | --- |
| [EmphasisStyle](./emphasisstyle/) | 定义可用的强调和强强调的序列化样式。规格请参见 CommonMark - Emphasis and strong emphasis。 |
| [HeadingLevels](./headinglevels/) | 表示一个基于字体大小处理标题级别的类。 |
| [HeadingRecognitionStrategy](./headingrecognitionstrategy/) | 表示标题识别策略的类型。 |
| [HeadingStyle](./headingstyle/) | 定义可用的标题序列化样式。规格请参见 CommonMark - ATX headings，以及 CommonMark - Setext headings。 |
| [LineBreakStyle](./linebreakstyle/) | 表示文件可能的换行样式。 |
| [MarkdownSaveOptions](./markdownsaveoptions/) | 表示 Markdown 格式的文档保存选项类。 |
