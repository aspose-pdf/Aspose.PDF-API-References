线帽样式应指定在描边时用于开放子路径（以及虚线（如果有））端点的形状。

## 字段

| 字段 | 描述 |
| --- | --- |
| [ButtCap](#ButtCap) | 平帽。笔画在路径端点处方正结束。路径端点之外不应有投射。 |
| [RoundCap](#RoundCap) | 圆帽。将在端点周围绘制直径等于线宽的半圆弧，并填充。 |
| [SquareCap](#SquareCap) | 投射方形帽。笔画应在路径端点之外继续，距离等于线宽的一半，并方正结束。 |
