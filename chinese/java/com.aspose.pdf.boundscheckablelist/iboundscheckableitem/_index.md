### checkBounds {#checkBounds-double-double-}

**Parameters:**
| 参数 | 类型 | 描述 |
| --- | --- | --- |
| containerWidth |  | 容器的宽度。 |
| containerHeight |  | 容器的高度。 |

**Returns:**
如果匹配则为 true；否则为 false。
