## GoToRemoteAction class

表示远程跳转操作，类似于普通跳转操作，但跳转到另一个 PDF 文件中的目标，而不是当前文件。

| 名称 | 描述 |

| GoToRemoteAction(remote_pdf, destination) | 初始化 GoToRemoteAction 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| 下一步 | 顺序中的下一个操作。 |
| destination | 获取或设置要跳转的目标。 |
| file | 获取或设置目标所在文件的规范。 |
| new_window | 获取或设置一个标志，指定是否在新窗口中打开目标文档。 |
