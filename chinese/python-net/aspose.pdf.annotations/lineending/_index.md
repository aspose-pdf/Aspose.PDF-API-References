## LineEnding enumeration

绘制线条时使用的线端样式的枚举。

## Members
| Member name | 描述 |
| :- | :- |
| NONE | 无换行符。 |
| SQUARE | 一个填充了注释内部颜色的方形（如果有）。 |
| CIRCLE | 如果有的话，一个填充了注释内部颜色的圆形。 |
| DIAMOND | 如果有的话，一个填充了注释内部颜色的菱形。 |
| OPEN_ARROW | 两条短线在锐角相交，形成一个开放的箭头。 |
| CLOSED_ARROW | 两条短线以锐角相交，类似 OpenArrow 样式，并通过第三条线连接，形成一个填充了注释内部颜色的三角形闭合箭头（如果有）。 |
| BUTT | 在端点处与线本身垂直的一条短线。 |
| R_OPEN_ARROW | 两条短线方向与 OpenArrow 相反。 |
| R_CLOSED_ARROW | 一个方向与 ClosedArrow 相反的三角形闭合箭头。 |
| SLASH | 在端点处，一条大约与线本身垂直顺时针30度的短线。 |
