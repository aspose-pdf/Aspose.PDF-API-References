## AnnotationState enumeration

原始注释可以设置的状态枚举。

## Members
| Member name | 描述 |
| :- | :- |
| UNDEFINED | 未定义的状态。 |
| MARKED | 该注释已被用户标记。 |
| UNMARKED | 该注释未被用户标记。 |
| ACCEPTED | 用户同意此更改。 |
| REJECTED | 用户不同意此更改。 |
| CANCELLED | 此更改已被取消。 |
| COMPLETED | 此更改已完成。 |
| NONE | 用户未对更改作出任何指示。 |
