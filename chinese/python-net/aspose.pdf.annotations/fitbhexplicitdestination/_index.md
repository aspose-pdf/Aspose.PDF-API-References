## FitBHExplicitDestination class

表示显式目标，该目标将页面的垂直坐标 top 定位在窗口的上边缘，并将页面内容放大到恰好使其边界框的整个宽度适合窗口。top 为 null 值表示保留该参数的当前值不变。
