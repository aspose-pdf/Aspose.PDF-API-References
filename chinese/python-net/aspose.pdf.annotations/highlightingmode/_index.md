## HighlightingMode enumeration

注释高亮模式的枚举，即在其活动区域内按下或保持鼠标按钮时使用的视觉效果。

## Members
| Member name | 描述 |
| :- | :- |
| NONE | 无高亮。 |
| INVERT | 反转注释矩形的内容。 |
| OUTLINE | 反转注释的边框。 |
| PUSH | 显示注释的下沉外观（如果有）。如果未定义下沉外观，则偏移注释矩形的内容，使其看起来像被推到页面表面以下。 |
| TOGGLE | 与 Push 相同（推荐使用）。 |
