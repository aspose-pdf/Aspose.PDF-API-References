## RenditionOperation enumeration

触发操作时要执行的操作。

## Members
| Member name | 描述 |
| :- | :- |
| PLAY_STOP | 如果没有与注释关联的呈现，则播放指定的呈现，并将其与注释关联。如果已有呈现与注释关联，则应停止该呈现，并将新的呈现与注释关联。 |
| STOP | 停止与注释关联的任何正在播放的呈现。 |
| PAUSE | 暂停与注释关联的任何正在播放的呈现。 |
| RESUME | 恢复与注释关联的任何正在播放的呈现。 |
| PLAY_RESUME | 播放指定的呈现，并将其与注释关联。如果已有呈现与注释关联且已暂停，则恢复该呈现。 |
| UNDEFINED | 未定义操作。 |
