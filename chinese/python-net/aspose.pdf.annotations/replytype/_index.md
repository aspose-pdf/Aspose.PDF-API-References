## ReplyType enumeration

枚举注释与 InReplyTo 指定的注释之间关系（“回复类型”）的种类。

## Members
| Member name | 描述 |
| :- | :- |
| UNDEFINED | 未定义的关系。 |
| REPLY | 该注释被视为对 InReplyTo 指定的注释的回复。查看器应用程序不应单独显示对注释的回复，而应以线程评论的形式一起显示。 |
| GROUP | 该注释与 InReplyTo 指定的注释分组在一起。 |
