| :- | :- |

## 属性
| 名称 | 描述 |
| :- | :- |
| scale_ratio | 一个表示图纸比例的文本字符串。 |
| x_format | 用于测量沿 xaxis 变化的数字格式数组，如果 Y 未出现，则也用于沿 y 轴的测量。 |

| slope_format | 用于测量直线斜率的数字格式数组。 |
| origin | 用于在默认用户空间坐标中指定测量坐标系原点的点。 |
| xy_factor | 用于将 y 轴上最大的单位转换为 x 轴上最大的单位的因子。 |
