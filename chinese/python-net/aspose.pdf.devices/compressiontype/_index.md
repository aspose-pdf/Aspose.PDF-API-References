## CompressionType enumeration

用于指定传递给 TIFF 图像设备的参数值。

## Members
| Member name | 描述 |
| :- | :- |
| LZW | 指定 LZW 压缩方案。可以作为属于 Compression 类别的参数传递给 Tiff 编码器。 |
| CCITT4 | 指定 CCITT4 压缩方案。可以作为属于 Compression 类别的参数传递给 CCITT4 编码器。 |
| CCITT3 | 指定 CCITT3 压缩方案。可以作为属于 Compression 类别的参数传递给 CCITT3 编码器。 |
| RLE | 指定 RLE 压缩方案。可以作为属于 Compression 类别的参数传递给 RLE 编码器。 |
| NONE | 指定无压缩。可以作为属于 compression 类别的参数传递给 Tiff 编码器。 |
