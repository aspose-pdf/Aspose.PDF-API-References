## ImageDevice class

图像设备的抽象类。

ImageDevice 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| coordinate_type | 获取或设置页面坐标类型（Media/Crop 框）。默认使用 CropBox 值。 |
| rendering_options | 获取或设置渲染选项。 |
| form_presentation_mode | 获取或设置表单呈现模式。 |
| resolution | 获取图像分辨率。 |
| width | 获取图像输出宽度。 |
| 高度 | 获取图像输出高度。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| process(page, output) | 对给定页面执行某些操作，例如将页面转换为图形图像。 |
| process(page, output_file_name) | 对给定页面执行某些操作并将结果保存到文件中。 |
