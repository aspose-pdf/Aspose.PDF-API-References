## ThumbnailDevice class

表示将 PDF 文档页面保存为缩略图图像的图像设备。

ThumbnailDevice 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ThumbnailDevice() | 初始化 [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) 类的实例<br/>            默认缩略图大小为 (200x200 像素)。 |
| ThumbnailDevice(width, height) | 初始化 ThumbnailDevice 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| coordinate_type | 获取或设置页面坐标类型（Media/Crop 框）。默认使用 CropBox 值。 |
| rendering_options | 获取或设置渲染选项。 |
| form_presentation_mode | 获取或设置表单呈现模式。 |
| resolution | 获取图像分辨率。 |
| width | 获取图像输出宽度。 |
| 高度 | 获取图像输出高度。 |
## 方法
| 名称 | 描述 |
| :- | :- |
