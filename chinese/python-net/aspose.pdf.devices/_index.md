aspose.pdf.devices 命名空间提供用于将文档表示为图像或纯文本的类。因此文档可以输出到文本或各种图形设备，以获得文本或图形表示。

## 类
| 类 | 描述 |
| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | 表示图像设备，可帮助将 PDF 文档页面保存为 bmp。 |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | 所有设备类型的抽象类。设备用于以某种格式表示 PDF 文档。<br/>            例如，文档页面可以表示为图像或文本。 |
| [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) | 表示图像设备，可帮助将 PDF 文档页面保存为 Dicom 格式。 |
| [DocumentDevice](/pdf/python-net/aspose.pdf.devices/documentdevice/) | 用于处理整个 PDF 文档的所有设备的抽象类。 |
| [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) | 表示图像设备，可帮助将 PDF 文档页面保存为 emf。 |
| [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) | 表示图像设备，可帮助将 PDF 文档页面保存为 gif。 |
| [ImageDevice](/pdf/python-net/aspose.pdf.devices/imagedevice/) | 图像设备的抽象类。 |
| [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) | 表示图像设备，可帮助将 PDF 文档页面保存为 jpeg。 |
| [Margins](/pdf/python-net/aspose.pdf.devices/margins/) | 此类表示图像的边距。 |
| [PageDevice](/pdf/python-net/aspose.pdf.devices/pagedevice/) | 用于处理 PDF 文档特定页面的所有设备的抽象类。 |
| [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) | 表示图像设备，可帮助将 PDF 文档页面保存为 png。 |
| [Resolution](/pdf/python-net/aspose.pdf.devices/resolution/) | 表示用于保存图像分辨率的类。 |
| [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) | 表示用于将 PDF 文档页面转换为文本的类。 |
| [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) | 表示将 PDF 文档页面保存为缩略图图像的图像设备。 |
| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | 此类帮助将 PDF 文档逐页保存为单个 TIFF 图像。 |
| [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) | 此类表示将 PDF 导入为 TIFF 的设置。 |
## 枚举
