## ColorDepth enumeration

用于指定传递给 TIFF 图像设备的参数值。

## Members
| Member name | 描述 |
| :- | :- |
| DEFAULT | 默认颜色深度。<br/>            默认使用 32 位深度。 |
| FORMAT_8BPP | 每像素 8 位。相等 |
| FORMAT_4BPP | 每像素 4 位。相等 |
| FORMAT_1BPP | 每像素 1 位。相等 |
