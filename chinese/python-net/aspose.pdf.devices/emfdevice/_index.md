## EmfDevice class

表示图像设备，可帮助将 PDF 文档页面保存为 emf。

EmfDevice 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| EmfDevice() | 使用默认分辨率初始化一个新的 [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) 类实例，该分辨率用于写入 emf 的光栅图像。 |
| EmfDevice(resolution) | 初始化 EmfDevice 类的新实例 |
| EmfDevice(width, height) | 初始化 EmfDevice 类的新实例 |
| EmfDevice(page_size) | 初始化 EmfDevice 类的新实例 |

## 属性
| 名称 | 描述 |
| :- | :- |
| coordinate_type | 获取或设置页面坐标类型（Media/Crop 框）。默认使用 CropBox 值。 |

| form_presentation_mode | 获取或设置表单呈现模式。 |
| resolution | 获取图像分辨率。 |
| width | 获取图像输出宽度。 |
| 高度 | 获取图像输出高度。 |
