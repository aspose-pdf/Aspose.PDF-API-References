## TextExtractionError class

描述在 PDF 文档中出现的文本提取错误。

TextExtractionError 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| summary | 错误的简要描述。 |
| description | 错误的详细描述。 |
| location | 错误的位置。 |
| font_key | 用于显示导致提取错误的文本的 Font 对象的键（PDF 名称）。 |
| font_name | 用于显示导致提取错误的文本的 Font 对象的可读（内部）名称。 |
| extracted_text | 实际提取的文本。 |
