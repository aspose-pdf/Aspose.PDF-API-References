## TextEditOptions class

描述文本编辑操作的选项。

TextEditOptions 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| TextEditOptions(no_character_behavior) | 初始化 TextEditOptions 类的新实例 |
| TextEditOptions(font_replace_behavior) | 初始化 TextEditOptions 类的新实例 |
| TextEditOptions(allow_language_transformation) | 初始化 TextEditOptions 类的新实例 |
| TextEditOptions(language_transformation_behavior) | 初始化 TextEditOptions 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| replacement_font | 获取或设置用于替换的字体，如果用户字体不包含所需字符 |
| no_character_behavior | 获取或设置在字体不包含请求字符时定义行为的模式。 |
| font_replace_behavior | 获取定义字体替换场景行为的模式。 |
| allow_language_transformation | 获取或设置在添加或编辑文本时允许使用语言转换的值。<br/>            true - 如有必要，将应用语言转换（默认值）。<br/>            false - 将不应用语言转换。 |
| language_transformation_behavior | 获取定义语言转换场景行为的模式。 |
| clipping_paths_processing | 获取编辑文本的剪裁路径处理模式。 |
| to_attempt_get_underline_from_source | 获取或设置允许在源文档页面上搜索文本下划线的值。<br/>            （已弃用）请使用 TextSearchOptions.SearchForTextRelatedGraphics 代替此项。 |
