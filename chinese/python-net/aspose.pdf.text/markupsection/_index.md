## MarkupSection class

表示一个标记章节——页面上包含文本的矩形区域，可在视觉上与其他文本块区分。

MarkupSection 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| rectangle | 节矩形 |
| fragments | 集合中非空的 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 对象，这些对象位于该节内部。 |
| paragraphs | 集合中位于该节内部的 [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) 对象。 |
