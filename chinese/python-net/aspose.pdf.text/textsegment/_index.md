| 名称 | 描述 |
| :- | :- |

## 属性
| 名称 | 描述 |
| :- | :- |
| start_char_index | 获取当前段在显示文本操作符 (Tj, TJ) 段中的起始字符索引。 |
| end_char_index | 获取当前段在显示文本操作符 (Tj, TJ) 段中的结束字符索引。 |
| text | 获取或设置 [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) 对象所表示的字符串文本对象。 |
| text_state | 获取或设置 [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) 对象所表示的文本的文本状态。 |
| position | 获取由 [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) 对象表示的文本的位置。 |
| rectangle | 获取 TextSegment 的矩形 |
| baseline_position | 获取由 [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/) 对象表示的文本的位置。<br/>            Position 结构的 YIndent 表示文本段的基线坐标。 |
| text_edit_options | 获取或设置文本编辑选项。该选项定义当请求的符号无法使用字体写入时的特殊行为。 |
| characters | 获取表示文本段中字符信息的 CharInfo 对象集合。 |
| hyperlink | 获取或设置段的超链接（用于 PDF 生成器）。 |
