## PageMarkup class

页面标记由 [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) 和 [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) 的集合表示。

PageMarkup 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| number | 获取已处理的页面编号。 |
| rectangle | 获取已处理的页面矩形。 |
| sections | 获取在页面上找到的 [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) 集合。 |
| paragraphs | 获取在页面上找到的 [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) 集合。 |
| text_fragments | 获取在页面上找到的 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 集合。 |
| is_multicolumn_paragraphs_allowed | 获取或设置指示是否可以将下一节的起始文本行视为前一节最后一个段落的延续的值。 |
