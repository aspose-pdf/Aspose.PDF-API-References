## TextRenderingMode enumeration

文本渲染模式（Tmode）决定显示文本时是否会对字形轮廓进行描边、填充、用作裁剪边界，或上述三者的组合。

## Members
| Member name | 描述 |
| :- | :- |
| FILL_TEXT | 填充文本。 |
| STROKE_TEXT | 描边文本。 |
| FILL_THEN_STROKE_TEXT | 填充，然后描边文本。 |
| INVISIBLE | 既不填充也不描边文本（不可见）。 |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | 填充文本并将其添加到用于裁剪的路径中（参见 9.3.6，“文本渲染模式，”）。 |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | 描边文本并将其添加到用于裁剪的路径中。 |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | 填充，然后描边文本并将其添加到用于裁剪的路径中。 |
| ADD_PATH_TO_CLIPPING | 将文本添加到用于裁剪的路径中。 |
