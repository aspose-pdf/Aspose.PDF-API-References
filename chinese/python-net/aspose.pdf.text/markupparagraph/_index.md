## MarkupParagraph class

表示一个段落。

MarkupParagraph 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| points | 描述段落的多边形的点。<br/>            起始点是段落的左下角。后续点按逆时针顺序排列。 |
| secondary_points | 描述段落续写的次要多边形的点。如果段落在下一列或页面继续，则该值不为 null。<br/>            起始点是段落的左下角。后续点按逆时针顺序排列。 |
| continuation_page_numbers | 段落续写所在的页码列表。如果段落在同一页的下一列继续，则该列表与段落起始页相同。 |
| fragments | 段落中非空的 [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) 对象集合。 |
| lines | 段落的行。每行由文本片段列表表示。 |
| text | 获取由 [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/) 对象表示的字符串文本对象。 |
