## TextExtractionErrorLocation class

表示在 PDF 文档中出现文本提取错误的位置。

TextExtractionErrorLocation 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| path | 出现文本提取错误的 PDF 文档位置。 |
| page_number | 出现文本提取错误的文档页码。 |
| object_type | 出现内容流文本提取错误的 PDF 对象类型（页面或 xForm）。 |
| form_key | 出现内容流文本提取错误的 PDF 表单 XObject 的键（名称）。如果 ObjectType == 'xForm'，则此键不为空。 |
| operator_index | 导致文本提取错误的内容流（操作符集合）中显示文本的操作符索引。 |
| operator_string | 导致文本提取错误的显示文本的操作符。 |
| font_used_key | 用于显示导致文本提取错误的操作符的 PDF 字体对象的键（名称）。 |
| text_start_point | 用于显示导致文本提取错误的操作符的 PDF 字体对象的键（名称）。 |
