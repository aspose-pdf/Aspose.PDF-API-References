## ImageCompressionVersion enumeration

描述图像压缩算法的版本。

## Members
| Member name | 描述 |
| :- | :- |
| STANDARD | 标准算法。默认值。 |
| FAST | 改进的算法比标准更快，但并非适用于所有情况。 |
| MIXED | 在可能的情况下使用快速算法，在其他情况下使用标准算法。可能比 "Fast" 更慢，但可能产生更好的压缩效果。 |
