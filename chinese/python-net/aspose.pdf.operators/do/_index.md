## Do class

表示 Do 操作符的类（调用 XObject）。

Do 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Do(name) | 初始化 Do 类的新实例 |
| Do() | 构造新的 Do 运算符。<br/>            用于检索所有 Do 运算符，即不检查其参数名称。 |
## 属性
| 名称 | 描述 |
| :- | :- |
| index | 页面操作符列表中的操作符索引。 |
| 名称 | 运算符的 XObject 参数名称。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| accept(visitor) | 接受访问者对象以处理运算符。 |
| is_text_show_operator(op) | 确定该操作符是否负责文本输出的操作符 (Tj, TJ, 等) |
