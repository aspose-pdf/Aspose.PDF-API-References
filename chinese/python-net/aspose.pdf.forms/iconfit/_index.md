## IconFit class

描述小部件注释的图标应如何在其注释矩形内显示。

IconFit 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| scaling_reason | 获取或设置缩放原因。 |
| scaling_mode | 应使用的缩放类型。        /// |
| leftover_left | 获取或设置在图标左侧分配的空间。 |
| leftover_bottom | 获取或设置在图标底部分配的空间。 |
| spread_on_border | 如果为 true，则表示按钮外观应缩放以完全适应注释的边界，而不考虑边框的线宽。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| name_to_scaling_reason(reason) | 将缩放原因的名称转换为 ScalingReason 对象。 |
| scaling_reason_to_name(reason) | 将缩放原因对象转换为名称。 |
| name_to_scaling_mode(mode) | 将缩放模式名称转换为 ScalingMode 对象。 |
| scaling_mode_to_name(mode) | 将缩放模式对象转换为名称。 |
