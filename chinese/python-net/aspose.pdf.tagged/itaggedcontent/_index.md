## ITaggedContent class

表示用于处理文档中 TaggedPdf 内容的接口。

ITaggedContent 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| structure_text_state | 获取整个文档的 [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) 设置。 |
| struct_tree_root_element | 获取 PDF 文档的 [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/)。 |
| root_element | 获取 PDF 文档逻辑结构的根 [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/)。 |
