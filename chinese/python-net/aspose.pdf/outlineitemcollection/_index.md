## OutlineItemCollection class

表示 PDF 文档大纲层次结构中的大纲条目。

OutlineItemCollection 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| OutlineItemCollection(outlines) | 初始化 OutlineItemCollection 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| visible_count | 获取文档大纲层次结构中所有级别的大纲项总数。 |
| 标题 | 获取或设置此大纲项的标题。 |
| destination | 获取或设置此大纲项的目标。 |
| action | 获取或设置此大纲项的操作。 |
| 颜色 | 获取或设置此大纲项标题文本的颜色。 |
| 斜体 | 获取或设置此大纲项标题文本的斜体标志 |
| 粗体 | 获取或设置此大纲项标题文本的粗体标志 |
| first | 获取表示大纲层次结构中第一个顶级项的大纲项。 |
| last | 获取表示大纲层次结构中最后一个顶级项的大纲项。 |
| 上一个 | 获取在大纲层次结构中相对于此项的前一个项所对应的大纲项。 |
| 下一步 | 获取在大纲层次结构中相对于此项的下一个项所对应的大纲项。 |
| has_next | 检查在大纲层次结构中相对于此项的下一个项所对应的大纲项是否存在。 |
| 父级 | 获取此大纲项在大纲层次结构中的父对象。 |
| is_synchronized | 获取指示对该集合的访问是否同步（线程安全）的值。 |
| sync_root | 获取可用于同步对该集合访问的对象。 |
| open | 获取或设置大纲项的打开状态（true/false）。 |
| level | 获取大纲项的层级级别。 |
## Indexer
| 名称 | 描述 |
| :- | :- |
| [index] | 使用索引从集合中获取大纲项。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| delete() | 从文档大纲层次结构中删除此大纲项。 |
| delete(name) | 从文档大纲层次结构中删除具有指定名称的大纲条目。 |
| insert(index, outline) | 在指定位置将大纲项插入集合中。 |
