## WarningType enumeration

枚举表示警告类型。

## Members
| Member name | 描述 |
| :- | :- |
| SOURCE_FILE_CORRUPTION | 文件已损坏。 |
| DATA_LOSS | 文本/图表/图像或其他数据在加载后文档树中，或在保存后创建的文档中完全缺失。 |
| MAJOR_FORMATTING_LOSS | 与原始文档相比，出现了重大格式丢失。这适用于格式丢失虽大但数据仍然存在的情况。 |
| MINOR_FORMATTING_LOSS | 与原始文档相比，出现了轻微的格式损失。这是针对轻微的保真度损失。 |
| COMPATIBILITY_ISSUE | 已知问题会导致某些用户代理或旧版本的用户代理无法打开文档。 |
| INVALID_INPUT_STREAM_TYPE | 无效的输入流类型 |
| UNEXPECTED_CONTENT | 文件包含意外内容。 |
