## PasswordType enumeration

此枚举表示用于受密码保护的 PDF 文档的已知密码类型。

## Members
| Member name | 描述 |
| :- | :- |
| NONE | Pdf 文档未受密码保护。 |
| USER | Pdf 文档使用打开密码打开（受限访问）。 |
| 所有者 | Pdf 文档使用更改权限密码打开（完全访问）。 |
| 不可访问 | Pdf 文档受密码保护，但用户密码和所有者密码均不为空，且 <br/>            未定义任何密码或提供的密码不正确。因此无法推断密码的类型。 |
