## EmbeddedFileCollection class

表示嵌入文件集合的类。

EmbeddedFileCollection 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| is_synchronized | 获取一个值，指示对该集合的访问是否已同步（线程安全）。 |
| sync_root | 获取一个可用于同步对该集合访问的对象。 |
| keys | 返回文件附件键的列表。 |
## Indexer
| 名称 | 描述 |
| :- | :- |
| [index] | 根据索引获取嵌入文件。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| delete(name) | 通过集合中的键删除集合中的文件。 |
| delete() | 通过集合中的键删除集合中的文件。 |
| add(key, file) | 使用指定的键将文件添加到嵌入文件中。 |
| delete_by_key(key) | 通过集合中的键删除集合中的文件。 |
| find_by_name(name) | 按名称返回嵌入的文件。 |
