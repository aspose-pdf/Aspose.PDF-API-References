## HtmlPageLayoutOption enumeration

指定与其他选项一起决定页面尺寸和布局的标志。

## Members
| Member name | 描述 |
| :- | :- |
| NONE | 默认值，表示 HtmlPageLayoutOption 不会影响页面的大小和布局。 |
| FIT_TO_WIDEST_CONTENT_WIDTH | 指示页面宽度是根据内容大小本身确定的，而不是根据指定的页面宽度。 |
| SCALE_TO_PAGE_WIDTH | 指示文档的内容将被缩放以适应页面。 |
