## 属性
| 名称 | 描述 |
| :- | :- |
| vertical_alignment | 获取或设置段落的垂直对齐方式 |
| horizontal_alignment | 获取或设置段落的水平对齐方式 |
| margin | 获取或设置段落的外边距（用于 PDF 生成） |
| is_first_paragraph_in_column | 获取或设置一个布尔值，指示此段落是否将在下一列。<br/>            默认值为 false。（用于 PDF 生成） |
| is_kept_with_next | 获取或设置一个布尔值，指示当前段落是否与下一段落保持在同一页。<br/>            默认值为 false。（用于 PDF 生成） |
| is_in_new_page | 获取或设置一个布尔值，强制此段落在新页面生成。<br/>            默认值为 false。（用于 PDF 生成） |
| is_in_line_paragraph | 获取或设置段落是否为内联。<br/>            默认值为 false。（用于 PDF 生成） |
| hyperlink | 获取或设置片段超链接（用于 PDF 生成器）。 |
| z_index | 获取或设置一个整数值，指示 graph 的 Z 顺序。ZIndex 较大的 graph <br/>            将放置在 ZIndex 较小的 graph 之上。ZIndex 可以为负数。ZIndex 为负的 graph <br/>            将放置在页面文本的后面。 |
| column_info | 获取或设置列信息 |
| width | 获取或设置一个浮点值，表示浮动框的宽度。 |
| 高度 | 获取或设置一个浮点值，表示浮动框的高度。 |
| is_need_repeating | 获取或设置一个布尔值，指示段落是否需要在下一页重复。<br/>            默认值为 false。该属性仅在段落本身以及其 ReferenceParagraphID 所引用的对象都包含在 RepeatingRows 中时有效。 |
| paragraphs | 获取或设置一个 [paragraphs](/pdf/python-net/aspose.pdf/floatingbox/) 集合，表示单元格中的所有段落。 |
| border | 获取或设置一个 [BorderInfo](/pdf/python-net/aspose.pdf/borderinfo/) 对象，表示浮动框的边框信息。 |
| background_color | 获取或设置一个 [Color](/pdf/python-net/aspose.pdf/color/) 对象，表示浮动框的背景颜色。 |
| background_image | 获取或设置页面的背景图像（仅用于生成器，在读取文档时不填充）。 |
| padding | 获取或设置一个 [MarginInfo](/pdf/python-net/aspose.pdf/margininfo/) 对象，用于指示浮动框的内边距。 |
| left | 获取或设置表格左坐标。 |
| top | 获取或设置表格顶部坐标。 |
