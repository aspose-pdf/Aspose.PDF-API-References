## OutlineCollection class

表示文档大纲层次结构。

OutlineCollection 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| visible_count | Count 是所有层级中可见子大纲项数量的总和。注意：请不要将其与 Count（集合中项目的数量）混淆。 |
| first | 获取表示大纲中第一个顶层项目的轮廓项。 |
| last | 获取表示大纲中最后一个顶层项目的轮廓项。 |
| is_synchronized | 获取一个值，指示对该集合的访问是否已同步（线程安全）。 |
| sync_root | 获取一个可用于同步对该集合访问的对象。 |
## Indexer
| 名称 | 描述 |
| :- | :- |
| [index] | 按索引从集合中获取轮廓项。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| delete() | 删除文档大纲中的所有轮廓项。 |
| delete(name) | 删除文档大纲中具有指定标题的轮廓项。 |
