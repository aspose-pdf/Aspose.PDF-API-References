## PdfANonSpecificationFlags class

此类保存用于控制 PDF/A 转换的标志，以应对源 PDF 文档不符合 PDF 规范的情况。<br/>            如果使用此类的标志会降低性能，<br/>            但当源 PDF 文档无法通过常规方式转换为 PDF/A 格式时这是必要的。<br/>            默认情况下所有标志均设置为 false。
