## ExtractImageMode enumeration

定义在从文档中提取图像时可使用的不同模式。

## Members
| Member name | 描述 |
| :- | :- |
| DEFINED_IN_RESOURCES | 定义图像提取模式，在此模式下会提取特定页面资源中定义的所有图像。 |
| ACTUALLY_USED | 定义图像提取模式，仅提取实际在页面上显示的图像。 |
