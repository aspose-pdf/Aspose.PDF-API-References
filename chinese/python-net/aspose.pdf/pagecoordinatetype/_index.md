## PageCoordinateType enumeration

描述页面坐标类型。

## Members
| Member name | 描述 |
| :- | :- |
| MEDIA_BOX | MediaBox 用于指定页面的宽度和高度。 <br/>            对于普通用户，这可能等同于实际的页面尺寸。 <br/>            MediaBox 是 PDF 中最大的页面框。其他页面框可以等于 <br/>            MediaBox 的尺寸，但不能更大。 |
| CROP_BOX | CropBox 定义页面内容将被裁剪的区域。 <br/>            Acrobat 使用此尺寸进行屏幕显示和打印。 |
