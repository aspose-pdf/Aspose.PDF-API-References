## ImagePlacement class

表示放置在 PDF 文档页面上的图像特性。

ImagePlacement 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| matrix | 此图像的当前变换矩阵。 |
| rectangle | 获取图像的矩形。 |
| 运算符 | 用于显示图像的运算符。 |
| rotation | 获取图像的旋转角度。 |
| resolution | 获取图像的分辨率。 |
| image | 获取相关的 XImage 资源对象。 |
| 获取包含 TextFragment 的页面。 | 获取包含该图像的页面。 |
| compositing_parameters | 获取用于放置到页面的图像的活动图形状态的合成参数。 |
## 方法
| 名称 | 描述 |
| :- | :- |
| save(stream) | 保存图像及其相应的变换：缩放、旋转和分辨率。 |
| save(stream, format) | 保存图像及其相应的变换：缩放、旋转和分辨率。 |
| hide() | 从页面中删除图像。 |
| replace(image) | 将集合中的图像替换为另一图像。 |
