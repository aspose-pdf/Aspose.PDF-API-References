## RootElement class

根结构元素。

RootElement 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| children | 获取子元素集合。 |
| lang | (可选；PDF 1.4) 指定结构元素中所有文本的自然语言<br/>            除非被嵌套结构元素或标记内容的语言规范覆盖。 |
| actual_text | (可选；PDF 1.4) 文本是结构元素及其子元素的精确替代。<br/>            此替代文本（应尽可能适用于最小的内容块）<br/>            在提取文档内容以支持残障用户的可访问性时或出于其他目的时非常有用。 |
| alt | （可选）结构元素及其子元素的替代描述，以人类可读的形式呈现，<br/>            在提取文档内容以支持残障用户的可访问性或用于其他目的时非常有用。 |
| e | （可选；PDF 1.5）缩写的完整形式。 |
