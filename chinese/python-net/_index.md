## 命名空间

| 命名空间 | 描述 |
| :- | :- |
| [aspose.pdf](/pdf/python-net/aspose.pdf/) | aspose.pdf 是 Aspose.Pdf 库中所有类的根命名空间，类可以直接位于其中，如 Document，或通过多个子命名空间间接访问。 |
| [aspose.pdf.annotations](/pdf/python-net/aspose.pdf.annotations/) | aspose.pdf.annotations 命名空间提供用于处理文档中各种操作、目标及其他传统称为交互式功能的类，使用户能够与文档进行交互。 |
| [aspose.pdf.devices](/pdf/python-net/aspose.pdf.devices/) | aspose.pdf.devices 命名空间提供用于将文档表示为图像或纯文本的类。因此文档可以输出到文本或各种图形设备，以获得文本或图形表示。 |
| [aspose.pdf.drawing](/pdf/python-net/aspose.pdf.drawing/) | aspose.pdf.drawing 命名空间提供描述弧线、直线、圆形等图形原语的类。相应的对象可用于创建新文档。 |
| [aspose.pdf.facades](/pdf/python-net/aspose.pdf.facades/) | aspose.pdf.facades 命名空间提供最初来自 Aspose.Pdf.Kit 的类。这些类用于在不访问文档内部结构的情况下，以高级方式对文档进行合并、加盖印章、签名、注释等操作。 |
| [aspose.pdf.forms](/pdf/python-net/aspose.pdf.forms/) | aspose.pdf.forms 命名空间包含描述表单（标准、静态、动态）以及文本框、列表框、单选按钮等各种字段类型的类。 |
| [aspose.pdf.groupprocessor](/pdf/python-net/aspose.pdf.groupprocessor/) | aspose.pdf.groupprocessor 命名空间提供用于处理文本和字体的类。 |
| [aspose.pdf.groupprocessor.creators](/pdf/python-net/aspose.pdf.groupprocessor.creators/) | aspose.pdf.groupprocessor.creators 命名空间提供用于创建 GroupProcessor 类实例的类。 |
| [aspose.pdf.logicalstructure](/pdf/python-net/aspose.pdf.logicalstructure/) | aspose.pdf.logicalstructure 是用于 PDF 逻辑结构类的命名空间。 |
| [aspose.pdf.operators](/pdf/python-net/aspose.pdf.operators/) | aspose.pdf.operators 是用于运算符实现的命名空间。这些类描述了在 PDF 页面内容中使用的运算符。 |
| [aspose.pdf.optimization](/pdf/python-net/aspose.pdf.optimization/) | aspose.pdf.optimization 是用于管理文档优化过程的类的命名空间。 |
| [aspose.pdf.pdfaoptionclasses](/pdf/python-net/aspose.pdf.pdfaoptionclasses/) | aspose.pdf.pdfaoptionclasses 是用于 PDF/A 转换选项的命名空间。 |
| [aspose.pdf.sanitization](/pdf/python-net/aspose.pdf.sanitization/) | aspose.pdf.sanitization 是用于清理操作的命名空间。 |
| [aspose.pdf.structure](/pdf/python-net/aspose.pdf.structure/) | aspose.pdf.structure 命名空间提供帮助处理文档逻辑结构的类，该结构将文档组织为章节和节，或识别图形、表格、脚注等特殊元素。 |
| [aspose.pdf.tagged](/pdf/python-net/aspose.pdf.tagged/) | aspose.pdf.tagged 是用于支持标签化 PDF 文档的类的命名空间。 |
| [aspose.pdf.text](/pdf/python-net/aspose.pdf.text/) | aspose.pdf.text 命名空间提供用于提取文本、添加文本、操作文档中现有文本的类。它还包含用于提取、替换、替换文档字体的类。 |
| [aspose.pdf.xfaconverter](/pdf/python-net/aspose.pdf.xfaconverter/) | aspose.pdf.xfaconverter 命名空间提供用于转换 XFA 的类。 |
