## PositioningMode enumeration

定义定位模式。<br/>            可选值包括 Legacy（向后兼容）和 <br/>            Current（更新的文本位置计算方法）

## Members
| Member name | 描述 |
| :- | :- |
| LEGACY | 传统文本定位 |
| MODERN_LINE_SPACING | 更新的行间距，垂直位置计算遵循旧规则 <br/>            （即文本相对于指定矩形的左下角定位） |
| CURRENT | 更新的行间距和垂直位置计算基于左上角而非左下角进行。 |
