## ViewerPreference class

描述查看器首选项（页面模式、非全屏页面模式、页面布局）。

ViewerPreference 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ViewerPreference() | 初始化 ViewerPreference 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| PAGE_MODE_USE_OC | 可选内容组面板可见。 |
| DISPLAY_DOC_TITLE | 一个标志，指定窗口的标题栏是否应显示文档标题 |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | 可选内容组面板可见。 |
| PAGE_LAYOUT_SINGLE_PAGE | 一次显示一页。 |
| PAGE_LAYOUT_ONE_COLUMN | 以单列显示页面。 |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | 以两列显示页面，奇数页在右侧 |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | 以两列显示页面，奇数页在右侧。 |
| PAGE_MODE_USE_NONE | 文档大纲和缩略图均不可见 |
| PAGE_MODE_USE_OUTLINES | 文档大纲可见。 |
| PAGE_MODE_USE_THUMBS | 缩略图可见。 |
| PAGE_MODE_FULL_SCREEN | 全屏模式，未显示菜单栏、窗口控制或任何其他窗口。 |
| PAGE_MODE_USE_ATTACHMENT | 带附件的页面模式。 |
| HIDE_TOOLBAR | 一个标志，指定在文档处于活动状态时是否隐藏符合规范的阅读器工具栏。 |
| HIDE_MENUBAR | 一个标志，指定在文档处于活动状态时是否隐藏符合规范的阅读器菜单栏。 |
| HIDE_WINDOW_UI | 一个标志，指定是否隐藏文档窗口中的用户界面元素（如滚动条和导航控件），仅显示文档内容。 |
| FIT_WINDOW | 一个标志，指定是否调整文档窗口大小以适应首次显示页面的尺寸。 |
| CENTER_WINDOW | 一个标志，指定是否将文档窗口置于屏幕中心。 |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | 文档大纲和缩略图均不可见。 |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | 文档大纲可见。 |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | 缩略图可见 |
| DIRECTION_L2R | 文本阅读顺序从左到右。 |
| DIRECTION_R2L | 文本阅读顺序从右到左。 |
| SIMPLEX | 打印单面。 |
| DUPLEX_FLIP_SHORT_EDGE | 双面打印并在纸张的短边翻转。 |
| DUPLEX_FLIP_LONG_EDGE | 双面打印并在纸张的短边翻转。 |
