## Bookmark class

表示一个书签。

Bookmark 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| Bookmark() | 初始化 Bookmark 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| action | 获取或设置与书签绑定的操作。<br/>            如果提供了 PageNumber，则无法指定操作。<br/>            操作类型包括：\"GoTo\", \"GoToR\", \"Launch\", \"Named\". |
| bold_flag | 获取或设置书签标题的粗体标志。 |
| child_item | 获取或设置书签的子项。 |
| child_items | 获取或设置书签的子项。 |
| destination | 获取或设置书签的目标页面。如果操作设置为 string.Empty，则此项为必需。 |
| italic_flag | 获取或设置书签标题的斜体标志。 |
| level | 获取或设置书签的层级级别。 |
| page_display | 获取或设置显示书签目标页面的类型。 |
| page_display_bottom | 获取或设置页面显示的底部坐标。 |
| page_display_left | 获取或设置页面显示的左侧坐标。 |
| page_display_right | 获取或设置页面显示的右侧坐标。 |
| page_display_top | 获取或设置页面显示的顶部坐标。 |
| page_display_zoom | 获取或设置页面显示的缩放因子。 |
| page_number | 获取或设置书签目标页的页码。 |
| remote_file | 获取或设置书签的 "GoToR" 操作所需的文件（路径）。 |
| 标题 | 获取或设置书签的标题。 |
| title_color | 获取或设置书签标题的颜色。 |
| open | 获取或设置书签状态（打开，关闭）。 |
