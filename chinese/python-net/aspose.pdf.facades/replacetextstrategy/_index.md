## ReplaceTextStrategy class

此类包含在执行 ReplaceText 操作时定义 PdfContentEditor 行为的参数。

ReplaceTextStrategy 类型公开以下成员：
## 构造函数
| 名称 | 描述 |
| :- | :- |
| ReplaceTextStrategy() | 初始化 ReplaceTextStrategy 类的新实例 |
## 属性
| 名称 | 描述 |
| :- | :- |
| is_regular_expression_used | 如果为 false，待查找的字符串是普通文本。如果为 true，待查找的字符串是正则表达式。 |
| no_character_behavior | 当未找到适用于更改文本的合适字体时执行的操作<br/>            （抛出异常 / 替换为其他字体 / 仍然替换）。 |
| replace_scope | 替换操作的范围（替换第一次出现或替换全部出现）。 |
