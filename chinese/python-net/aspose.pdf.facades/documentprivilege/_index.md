## DocumentPrivilege class

表示访问 PDF 文件的权限。参见[PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/)。<br/>             使用此类有 4 种方式：<br/>             1.直接使用预定义的权限。<br/>             2.基于预定义的权限并更改某些特定权限。<br/>             3.基于预定义的权限并更改某些特定的 Adobe Professional 权限组合。<br/>             4.混合方式 2 和方式 3。

DocumentPrivilege 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| allow_print | 设置是否允许打印的权限。<br/>            true 表示允许，false 表示禁止。 |
| allow_degraded_printing | 设置是否允许降级打印的权限。<br/>            true 表示允许，false 表示禁止。 |
| allow_modify_contents | 设置是否允许修改内容的权限。<br/>            true 表示允许，false 表示禁止。 |
| allow_copy | 设置是否允许复制的权限。<br/>            true 表示允许，false 表示禁止。 |
| allow_modify_annotations | 设置是否允许修改注释的权限。<br/>            true 表示允许，false 表示禁止。 |
| allow_fill_in | 设置是否允许填写表单的权限。<br/>            true 表示允许，false 表示禁止。 |
| allow_screen_readers | 设置是否允许屏幕阅读器的权限。<br/>            true 表示允许，false 表示禁止。 |
| allow_assembly | 设置是否允许组装的权限。<br/>            true 表示允许，false 表示禁止。 |
| degraded_printing | 允许降级打印。 |
| print | 允许打印文件。 |
| modify_contents | 允许修改文件。 |
| copy | 允许复制文件。 |
| modify_annotations | 允许修改文件的注释。 |
| fill_in | 允许在文件中填写表单。 |
| screen_readers | 仅允许在屏幕上阅读。 |
| assembly | 允许组装文件。 |
| allow_all | 全部允许。 |
| forbid_all | 全部禁止。 |
