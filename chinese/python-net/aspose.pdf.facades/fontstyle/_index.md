## FontStyle enumeration

枚举 14 种字体类型。

## Members
| Member name | 描述 |
| :- | :- |
| COURIER | Courier 字体。 |
| COURIER_BOLD | 粗体 Courier 字体。 |
| COURIER_OBLIQUE | 倾斜 Curier 字体。 |
| COURIER_BOLD_OBLIQUE | 粗体倾斜 Courier 字体。 |
| HELVETICA | Helvetica 字体。 |
| HELVETICA_BOLD | 粗体 Helvetica 字体。 |
| HELVETICA_OBLIQUE | 倾斜 Helvetica 字体。 |
| HELVETICA_BOLD_OBLIQUE | 粗体倾斜 Helvetica 字体。 |
| SYMBOL | Symbol 字体。 |
| TIMES_ROMAN | Times-Roman 字体。 |
| TIMES_BOLD | 粗体 Times 字体。 |
| TIMES_ITALIC | 斜体 Times 字体。 |
| TIMES_BOLD_ITALIC | 粗体斜体 Times 字体。 |
| ZAPF_DINGBATS | ZapfDingbats 字体。 |
| UNKNOWN | 未知字体。将使用标准字体。 |
| CJK_FONT | 支持 CJK 的 True Type 字体，默认是 MS PGothic 字体。 |
