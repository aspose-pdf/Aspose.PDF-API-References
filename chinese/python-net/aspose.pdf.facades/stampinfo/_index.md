## StampInfo class

表示印章信息的类。

StampInfo 类型公开以下成员：
## 属性
| 名称 | 描述 |
| :- | :- |
| stamp_id | 获取印章的标识符。 |
| index_on_page | 获取印章在页面上的索引。 |
| stamp_type | 获取印章类型（图像 / 表单）。 |
| rectangle | 获取印章放置的矩形区域。 |
| image | 获取印章的图像。如果印章不包含图像（例如文本印章），则可能为 null。 |
| form | 获取印章的 XForm。 |
| text | 获取印章中的文本。 |
| visible | 获取印章的可见性。如果为 false，则印章被隐藏（使用 HideStampById）。隐藏的印章可以通过 ShowStampById 恢复。 |
