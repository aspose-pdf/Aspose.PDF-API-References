## PptxSaveOptions::set_RecognizeUnderlineAndStrikeout method


Sets whether underline and strikeout lines are recognized as text formatting. The default value is true.

```cpp
void Aspose::Pdf::PptxSaveOptions::set_RecognizeUnderlineAndStrikeout(bool value)
```

## Remarks


When false, underline and strikeout lines are preserved as graphics and rendered as images instead of being converted to text formatting. [Text](../../../aspose.pdf.text/) remains editable unless [SlidesAsImages](../) is true.
