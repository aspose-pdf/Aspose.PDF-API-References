## CreateImageFileContent(string, string) {#createimagefilecontent}

Creates an image file content for a message.

```csharp
public MessageContentRequest CreateImageFileContent(string fileId, string detail)
```

| Parameter | Type | Description |
| --- | --- | --- |
| fileId | string | The ID of the image file. |
| detail | string | The detail of the image file.
 Specifies the detail level of the image if specified by the user.
 "low" uses fewer tokens, you can opt in to high resolution using "high".
 Default is "auto". |

### Return Value

[MessageContentRequest](../../../aspose.pdf.ai/messagecontentrequest/)

A new instance of MessageContentRequest with ImageFile content.
