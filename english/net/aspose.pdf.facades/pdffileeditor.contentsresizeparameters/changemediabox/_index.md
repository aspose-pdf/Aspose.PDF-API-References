## PdfFileEditor.ContentsResizeParameters.ChangeMediaBox property

Gets and sets whether to adjust the MediaBox of a PDF page during the resizing operation.
 The default value is `false`

Setting this parameter enables fitting the MediaBox to the CropBox value during resizing.

public bool ChangeMediaBox { get; set; }
