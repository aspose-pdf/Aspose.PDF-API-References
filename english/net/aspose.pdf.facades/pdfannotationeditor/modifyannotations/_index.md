## ModifyAnnotations(int, int, Enum, [Annotation](../../../aspose.pdf.annotations/annotation/)) {#modifyannotations}

> **Deprecated.** Use ModifyAnnotations(int start, int end, Annotation annotation) instead.

Modifies the annotations of the specifed type on the specified page range.
 It supports to modify next annotation properties: Modified, Title, Contents, Color, Subject and Open.

```csharp
public void ModifyAnnotations(int start, int end, Enum annotType, Annotation annotation)
```

| Parameter | Type | Description |
| --- | --- | --- |
| start | int | The start page number. |
| end | int | The end page number. |
| annotType | Enum | The annotation type. |
| annotation | Annotation | The annotation object contains new properties. |
