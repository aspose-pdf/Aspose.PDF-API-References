## OcrSearchablePdfOptions.FlattenImages property

Gets or sets a value indicating whether images are flattened during conversion. Text in PDF images can be painted using the mechanics of masks, in which case the images must be flattened.

```csharp
public bool FlattenImages { get; set; }
```

### Property Value

`true` to flatten images; otherwise, `false`. The default is `false`.
