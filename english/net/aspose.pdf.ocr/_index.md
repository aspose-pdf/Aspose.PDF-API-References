## Overview

The **Aspose.Pdf.Ocr** namespace provides classes for extracting plain text from PDF pages using OCR.

Part of the [Aspose.PDF for .NET](../) API reference.

## Classes

| Class | Description |
| --- | --- |
| [OcrTextAbsorber](./ocrtextabsorber/) | Extracts plain text from PDF pages using OCR over the rendered page bitmap. |
| [OcrTextRecognitionOptions](./ocrtextrecognitionoptions/) | Options for [`OcrTextAbsorber`](../aspose.pdf.ocr/ocrtextabsorber/). |

## Enumeration

| Enumeration | Description |
| --- | --- |
| [OcrLanguage](./ocrlanguage/) | Language used by [`OcrTextAbsorber`](../aspose.pdf.ocr/ocrtextabsorber/) for recognition. |
