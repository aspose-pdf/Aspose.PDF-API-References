## UnsignedContentAbsorber.UnsignedContent class

Encapsulates unsigned content elements extracted from a PDF document.
 This class provides access to pages, form fields, XForms, and annotations
 that are part of the unsigned content within the document.

```csharp
public sealed class UnsignedContent
```
