## SideBySideDocsComparisonResult.FullChanges property

Get a complete list of changes to the pages of the document.
 Each index in the list represents the two pages of the document that are being compared, and the list of change operations represents the list of changes to those pages.

The list does not contain information about the position of changes on the pages but shows the full cross-pages changes.

```csharp
public List<List<DiffOperation>> FullChanges { get; }
```
