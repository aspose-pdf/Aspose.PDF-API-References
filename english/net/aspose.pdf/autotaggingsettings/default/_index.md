## AutoTaggingSettings.Default property

Gets the default settings for auto-tagging functionality in PDF documents.

The default settings enable auto-tagging and use the automatic strategy for heading recognition.
 These settings can be used as a baseline configuration for PDF format conversion or other operations
 requiring automatic tagging of PDF content.

public AutoTaggingSettings Default { get; }
