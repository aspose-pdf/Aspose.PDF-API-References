## GetFileName(string, bool) {#getfilename}

Gets the file name using the available file specification names, the specified fallback name,
 or a generated name if no other name is available.

```csharp
public string GetFileName(string fallbackName, bool allowEmptyName)
```

| Parameter | Type | Description |
| --- | --- | --- |
| fallbackName | string | The fallback file name to use if no file specification name is available. |
| allowEmptyName | bool | Specifies whether an empty file name is allowed. |

### Return Value

string

The resolved file name.
