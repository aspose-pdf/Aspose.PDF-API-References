## PaginationArtifact.EndPage property

Gets or sets the ending page number for the artifact.
 The value must be greater than or equal to 0. If a value less than 0 is set, it will be adjusted to 0.
 The default value of 0 means there are no end page boundaries.

```csharp
public int EndPage { get; set; }
```
