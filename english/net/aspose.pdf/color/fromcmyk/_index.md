## FromCmyk(double, double, double, double) {#fromcmyk}

Gets valid pdf Color object from CMYK color components.

```csharp
public Color FromCmyk(double c, double m, double y, double k)
```

| Parameter | Type | Description |
| --- | --- | --- |
| c | double | The Cyan color component (value 0 - 1). |
| m | double | The Magenta color component (value 0 - 1). |
| y | double | The Yellow color component (value 0 - 1). |
| k | double | The Key color component (value 0 - 1). |

### Return Value

[Color](../../../aspose.pdf/color/)

Color object with each component value in [0..1] range.
