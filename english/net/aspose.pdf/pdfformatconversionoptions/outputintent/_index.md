## PdfFormatConversionOptions.OutputIntent property

Gets or sets the [`OutputIntent`](../../../aspose.pdf/outputintent/) for the PDF format conversion.

The `OutputIntent` specifies the intended output device or condition
 for which the PDF document is being prepared. It is used to ensure that the colors
 in the document are rendered correctly on the target device.

public OutputIntent OutputIntent { get; set; }
