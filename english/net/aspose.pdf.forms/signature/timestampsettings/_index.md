## Signature.TimestampSettings property

Gets/sets timestamp settings.

If the property is set and a certificate is provided to the constructor of the [`Signature`](../../../aspose.pdf.lowcode/signature/) class,
 the digital signature will be timestamped with an embedded timestamp.
 If the property is set but no certificate is provided to the constructor of the [`Signature`](../../../aspose.pdf.lowcode/signature/) class,
 the timestamp will be added as a separate signature.

```csharp
public TimestampSettings TimestampSettings { get; set; }
```
