## BarcodeField.ECC property

Gets an integer value representing the error correction coefficient. 
 For PDF417, shall be from 0 to 8. For QRCode, shall be from 0 to 3 
 (0 for 'L', 1 for 'M', 2 for 'Q', and 3 for 'H').

public int ECC { get; }
