## Overview

The **Aspose.Pdf.Structure** namespace provides classes which help to work with a logical structure of a document which presents 
 the organization of the document into chapters and sections or the identification of special elements such as figures, tables, and footnotes.

Part of the [Aspose.PDF for .NET](../) API reference.
