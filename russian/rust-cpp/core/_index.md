## Core PDF functions

| Имя | Описание |
| -------------- | -------------- |
| [new](./new/) | Создать новый PDF-документ. |
| [open](./open/) | Открыть PDF-документ с именем файла. |
| [save](./save/) | Сохранить ранее открытый PDF-документ. |
| [save_as](./save_as/) | Сохранить ранее открытый PDF-документ с новым именем файла. |
| [set_license](./set_license/) | Установить лицензию с именем файла. |
| [extract_text](./extract_text/) | Вернуть содержимое PDF-документа в виде простого текста. |
| [word_count](./word_count/) | Вернуть количество слов в PDF-документе. |
| [character_count](./character_count/) | Вернуть количество символов в PDF-документе. |
| [append](./append/) | Добавить страницы из другого PDF-документа. |
| [append_pages](./append_pages/) | Добавить выбранные страницы из другого PDF-документа. |
| [merge_documents](./merge_documents/) | Создать новый PDF-документ, объединив предоставленные PDF-документы. |
| [split_document](./split_document/) | Создать несколько новых PDF-документов, извлекая страницы из исходного PDF-документа. |
| [split](./split/) | Создать несколько новых PDF-документов, извлекая страницы из текущего PDF-документа. |
| [split_at_page](./split_at_page/) | Разделить PDF-документ на два новых PDF-документа. |
| [split_at](./split_at/) | Разделить текущий PDF-документ на два новых PDF-документа. |
| [bytes](./bytes/) | Вернуть содержимое PDF-документа в виде вектора байтов. |
| [get_meta_info](./get_meta_info/) | Получить значение мета-информации PDF-документа. |
| [set_meta_info](./set_meta_info/) | Установить значение метаинформации PDF-документа. |
| [clear_meta_info](./clear_meta_info/) | Очистить все значения метаинформации PDF-документа. |
| [is_linearized](./is_linearized/) | Получить значение, указывающее, линейризирован ли документ. |
| [page_add](./page_add/) | Добавить новую страницу в PDF-документ. |
| [page_insert](./page_insert/) | Вставить новую страницу в указанную позицию в PDF-документе. |
| [page_delete](./page_delete/) | Удалить указанную страницу в PDF-документе. |
| [page_count](./page_count/) | Вернуть количество страниц в PDF-документе. |
| [page_word_count](./page_word_count/) | Вернуть количество слов на указанной странице в PDF-документе. |
| [page_character_count](./page_character_count/) | Вернуть количество символов на указанной странице в PDF-документе. |
| [page_is_blank](./page_is_blank/) | Вернуть, является ли страница пустой в PDF-документе. |
