## Core PDF functions

| Имя | Описание |
| -------------- | -------------- |
| [New](./new/) | Создать новый PDF-document. |
| [Open](./open/) | Открыть PDF-document с именем файла. |
| [Save](./save/) | Сохранить ранее открытый PDF-document. |
| [SaveAs](./saveas/) | Сохранить ранее открытый PDF-document с новым именем файла. |
| [Close](./close/) | Освободить выделенные ресурсы для PDF-document. |
| [SetLicense](./setlicense/) | Установить лицензию с помощью имени файла. |
| [ExtractText](./extracttext/) | Вернуть содержимое PDF-document в виде простого текста. |
| [WordCount](./wordcount/) | Вернуть количество слов в PDF-document. |
| [CharacterCount](./charactercount/) | Вернуть количество символов в PDF-document. |
| [Append](./append/) | Добавить страницы из другого PDF-document. |
| [AppendPages](./appendpages/) | Добавить выбранные страницы из другого PDF-document. |
| [MergeDocuments](./mergedocuments/) | Создать новый PDF-document, объединив предоставленные PDF-documents. |
| [SplitDocument](./splitdocument/) | Создать несколько новых PDF-documents, извлекая страницы из исходного PDF-document. |
| [Split](./split/) | Создать несколько новых PDF-documents, извлекая страницы из текущего PDF-document. |
| [SplitAtPage](./splitatpage/) | Разделить PDF-document на два новых PDF-documents. |
| [SplitAt](./splitat/) | Разделить текущий PDF-document на два новых PDF-documents. |
| [Bytes](./bytes/) | Вернуть содержимое PDF-document в виде среза байтов. |
| [GetMetaInfo](./getmetainfo/) | Получить значение мета‑информации PDF-document.. |
| [SetMetaInfo](./setmetainfo/) | Установить значение метаинформации PDF-документа.. |
| [ClearMetaInfo](./clearmetainfo/) | Очистить все значения метаинформации PDF-документа.. |
| [IsLinearized](./islinearized/) | Получить значение, указывающее, линейзирован ли документ. |
| [PageAdd](./pageadd/) | Добавить новую страницу в PDF-документ. |
| [PageInsert](./pageinsert/) | Вставить новую страницу в указанной позиции PDF-документа. |
| [PageDelete](./pagedelete/) | Удалить указанную страницу из PDF-документа. |
| [PageCount](./pagecount/) | Вернуть количество страниц в PDF-документе. |
| [PageWordCount](./pagewordcount/) | Вернуть количество слов на указанной странице PDF-документа. |
| [PageCharacterCount](./pagecharactercount/) | Вернуть количество символов на указанной странице PDF-документа. |
| [PageIsBlank](./pageisblank/) | Вернуть, является ли страница пустой в PDF-документе. |
