## SetColorStroke class

Класс, представляющий оператор SC, устанавливающий цвет для операций с обводкой.

Тип SetColorStroke раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SetColorStroke() | Инициализирует оператор. |
| SetColorStroke(g) | Инициализирует новый экземпляр класса SetColorStroke |
| SetColorStroke(r, g, b) | Инициализирует новый экземпляр класса SetColorStroke |
| SetColorStroke(color) | Инициализирует новый экземпляр класса SetColorStroke |
| SetColorStroke(c, m, y, k) | Инициализирует новый экземпляр класса SetColorStroke |
## Свойства
| Имя | Описание |
| :- | :- |
| index | None |
| r | Получает красный компонент цвета |
| g | Получает зелёный компонент цвета |
| b | Получает красный компонент цвета |
| c | Получает циановый компонент цвета CMYK. |
| m | Получает пурпурный компонент цвета CMYK. |
| y | Получает жёлтый компонент цвета CMYK. |
| k | Получает чёрный компонент цвета CMYK. |
| grey | Получает чёрный компонент серого цвета. |
| цвет | Получает массив компонентов цвета. |
## Методы
| Имя | Описание |
| :- | :- |
| accept(visitor) | Принимает объект посетителя для обработки оператора. |
| is_text_show_operator(op) | None |
| get_color() | Возвращает цвет, указанный оператором. |
