## BasicSetColorOperator class

Базовый класс для операторов set color.

## Свойства
| Имя | Описание |
| :- | :- |
| index | Индекс оператора в списке операторов страницы. |
| r | Получает красный компонент цвета |
| g | Получает зелёный компонент цвета |
| b | Получает красный компонент цвета |
| c | Получает циановый компонент цвета CMYK. |
| m | Получает пурпурный компонент цвета CMYK. |
| y | Получает жёлтый компонент цвета CMYK. |
| k | Получает чёрный компонент цвета CMYK. |
| grey | Получает чёрный компонент серого цвета. |
| цвет | Получает массив компонентов цвета. |
