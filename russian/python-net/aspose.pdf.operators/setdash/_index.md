## SetDash class

Класс, представляющий оператор d (установка шаблона пунктирной линии).

Тип SetDash раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SetDash(pattern, phase) | Инициализирует новый экземпляр класса SetDash |
## Свойства
| Имя | Описание |
| :- | :- |
| index | Индекс оператора в списке операторов страницы. |
| pattern | Шаблон штриха. Элементы массива должны быть числами, указывающими длины чередующихся штрихов и промежутков.<br/>            Если массив содержит один элемент, длины штриха и промежутка равны. |
| phase | Фаза штриха. Перед началом обводки пути массив штрихов должен быть пройден, суммируя длины штрихов и промежутков. <br/>            Когда накопленная длина достигает значения, указанного фазой штриха, обводка пути начинается, <br/>            и массив штрихов используется циклически с этого момента. |
## Методы
| Имя | Описание |
| :- | :- |
| accept(visitor) | Принимает объект посетителя для обработки оператора. |
| is_text_show_operator(op) | Определяет, является ли оператор оператором, отвечающим за вывод текста (Tj, TJ и т.д.) |
