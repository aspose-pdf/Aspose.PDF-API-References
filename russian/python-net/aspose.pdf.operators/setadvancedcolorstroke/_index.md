## SetAdvancedColorStroke class

| Имя | Описание |
| :- | :- |
| SetAdvancedColorStroke() | Инициализирует оператор. |
| SetAdvancedColorStroke(g) | Инициализирует новый экземпляр класса SetAdvancedColorStroke |
| SetAdvancedColorStroke(g, pattern_name) | Инициализирует новый экземпляр класса SetAdvancedColorStroke |
