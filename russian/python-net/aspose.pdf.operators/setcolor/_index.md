## SetColor class

Представляет класс для оператора sc (установка цвета для операций без обводки).

Тип SetColor раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SetColor() | Инициализирует оператор. |
| SetColor(g) | Инициализирует новый экземпляр класса SetColor |
| SetColor(r, g, b) | Инициализирует новый экземпляр класса SetColor |
| SetColor(c, m, y, k) | Инициализирует новый экземпляр класса SetColor |
| SetColor(color) | Инициализирует новый экземпляр класса SetColor |
## Свойства
| Имя | Описание |
| :- | :- |
| index | None |
| r | Получает красный компонент цвета |
| g | Получает зелёный компонент цвета |
| b | Получает красный компонент цвета |
| c | Получает циановый компонент цвета CMYK. |
| m | Получает пурпурный компонент цвета CMYK. |
| y | Получает жёлтый компонент цвета CMYK. |
| k | Получает чёрный компонент цвета CMYK. |
| grey | Получает чёрный компонент серого цвета. |
| цвет | Получает массив компонентов цвета. |
## Методы
| Имя | Описание |
| :- | :- |
| accept(visitor) | Принимает объект посетителя для обработки оператора. |
| is_text_show_operator(op) | None |
| get_color() | Возвращает цвет, указанный оператором. |
