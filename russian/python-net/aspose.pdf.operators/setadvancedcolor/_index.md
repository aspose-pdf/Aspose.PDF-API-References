## SetAdvancedColor class

Класс, представляющий оператор scn (установка цвета для операций без обводки).

Тип SetAdvancedColor раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SetAdvancedColor() | Инициализирует оператор. |
| SetAdvancedColor(g, pattern_name) | Инициализирует новый экземпляр класса SetAdvancedColor |
| SetAdvancedColor(g) | Инициализирует новый экземпляр класса SetAdvancedColor |
| SetAdvancedColor(r, g, b, pattern_name) | Инициализирует новый экземпляр класса SetAdvancedColor |
| SetAdvancedColor(c, m, y, k, pattern_name) | Инициализирует новый экземпляр класса SetAdvancedColor |
## Свойства
| Имя | Описание |
| :- | :- |
| index | None |
| r | Получает красный компонент цвета |
| g | Получает зелёный компонент цвета |
| b | Получает красный компонент цвета |
| c | Получает циановый компонент цвета CMYK. |
| m | Получает пурпурный компонент цвета CMYK. |
| y | Получает жёлтый компонент цвета CMYK. |
| k | Получает чёрный компонент цвета CMYK. |
| grey | Получает чёрный компонент серого цвета. |
| цвет | Получает массив компонентов цвета. |
| pattern_name | Получает имя шаблона. |
## Методы

| :- | :- |
| accept(visitor) | Принимает объект посетителя для обработки оператора. |
| is_text_show_operator(op) | None |
