## MP class

Класс, представляющий оператор MP (определение отмеченной точки содержимого).

Тип MP раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| MP(tag) | Инициализирует новый экземпляр класса MP |
## Свойства
| Имя | Описание |
| :- | :- |
| index | Индекс оператора в списке операторов страницы. |
| tag | Получает или задает тег помеченного содержимого |
## Методы
| Имя | Описание |
| :- | :- |
| accept(visitor) | Принимает объект посетителя для обработки оператора. |
| is_text_show_operator(op) | Определяет, является ли оператор оператором, отвечающим за вывод текста (Tj, TJ и т.д.) |
