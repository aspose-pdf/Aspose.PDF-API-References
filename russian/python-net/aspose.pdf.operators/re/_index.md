## Re class

Класс, представляющий оператор re (добавление прямоугольника к пути).

Тип Re раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Re() | Инициализирует оператор. |
| Re(x, y, width, height) | Инициализирует новый экземпляр класса Re |
## Свойства
| Имя | Описание |
| :- | :- |
| index | Индекс оператора в списке операторов страницы. |
| x | X‑координата самой левой стороны прямоугольника. |
| y | Y‑координата нижней стороны прямоугольника. |
| ширина | Ширина прямоугольника. |
| высота | Высота прямоугольника. |
## Методы
| Имя | Описание |
| :- | :- |
| accept(visitor) | Принимает объект посетителя для обработки оператора. |
| is_text_show_operator(op) | Определяет, является ли оператор оператором, отвечающим за вывод текста (Tj, TJ и т.д.) |
