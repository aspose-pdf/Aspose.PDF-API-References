## Do class

Класс, представляющий оператор Do (вызов XObject).

Тип Do раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Do(name) | Инициализирует новый экземпляр класса Do |
| Do() | Создаёт новый оператор Do. <br/>            Используется для получения всех операторов Do, т. е. без проверки их имён аргументов. |
## Свойства
| Имя | Описание |
| :- | :- |
| index | Индекс оператора в списке операторов страницы. |
| name | Имя аргумента XObject оператора. |
## Методы
| Имя | Описание |
| :- | :- |
| accept(visitor) | Принимает объект посетителя для обработки оператора. |
| is_text_show_operator(op) | Определяет, является ли оператор оператором, отвечающим за вывод текста (Tj, TJ и т.д.) |
