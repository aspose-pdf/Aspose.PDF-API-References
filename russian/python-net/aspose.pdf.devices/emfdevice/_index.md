## EmfDevice class

Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат EMF.

Тип EmfDevice раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| EmfDevice() | Инициализирует новый экземпляр класса [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) с разрешением растрового изображения по умолчанию, записываемого в emf. |
| EmfDevice(resolution) | Инициализирует новый экземпляр класса EmfDevice |
| EmfDevice(width, height) | Инициализирует новый экземпляр класса EmfDevice |
| EmfDevice(page_size) | Инициализирует новый экземпляр класса EmfDevice |
| EmfDevice(width, height, resolution) | Инициализирует новый экземпляр класса EmfDevice |
| EmfDevice(page_size, resolution) | Инициализирует новый экземпляр класса EmfDevice |
## Свойства
| Имя | Описание |
| :- | :- |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| rendering_options | Получает или задает параметры рендеринга. |
| form_presentation_mode | Получает или задает режим представления формы. |
| resolution | Получает разрешение изображения. |
| ширина | Получает ширину выходного изображения. |
| высота | Получает высоту выходного изображения. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Преобразует страницу в emf и сохраняет её в выходном потоке. |
| process(page, output_file_name) | Преобразует страницу в emf и сохраняет её в выходном потоке. |
