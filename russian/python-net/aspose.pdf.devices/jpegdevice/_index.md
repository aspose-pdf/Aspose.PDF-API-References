## JpegDevice class

Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат JPEG.

Тип JpegDevice раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| JpegDevice() | Инициализирует новый экземпляр класса [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) с разрешением по умолчанию и максимальным качеством. |
| JpegDevice(resolution) | Инициализирует новый экземпляр класса JpegDevice |
| JpegDevice(quality) | Инициализирует новый экземпляр класса JpegDevice |
| JpegDevice(resolution, quality) | Инициализирует новый экземпляр класса JpegDevice |
| JpegDevice(width, height) | Инициализирует новый экземпляр класса JpegDevice |
| JpegDevice(page_size) | Инициализирует новый экземпляр класса JpegDevice |
| JpegDevice(width, height, resolution) | Инициализирует новый экземпляр класса JpegDevice |
| JpegDevice(page_size, resolution) | Инициализирует новый экземпляр класса JpegDevice |
| JpegDevice(width, height, resolution, quality) | Инициализирует новый экземпляр класса JpegDevice |
| JpegDevice(page_size, resolution, quality) | Инициализирует новый экземпляр класса JpegDevice |
## Свойства
| Имя | Описание |
| :- | :- |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| rendering_options | Получает или задает параметры рендеринга. |
| form_presentation_mode | Получает или задает режим представления формы. |
| resolution | Получает разрешение изображения. |
| ширина | Получает ширину выходного изображения. |
| высота | Получает высоту выходного изображения. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Преобразует страницу в jpeg и сохраняет её в выходном потоке. |
| process(page, output_file_name) | Преобразует страницу в jpeg и сохраняет её в выходном потоке. |
