## TextDevice class

Представляет класс для преобразования страниц PDF‑документа в текст.

Тип TextDevice раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextDevice(extraction_options) | Инициализирует новый экземпляр класса TextDevice |
| TextDevice() | Инициализирует новый экземпляр [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) в режиме необработанного форматирования текста и с кодировкой Unicode. |
| TextDevice(encoding) | Инициализирует новый экземпляр класса TextDevice |
| TextDevice(extraction_options, encoding) | Инициализирует новый экземпляр класса TextDevice |
## Свойства
| Имя | Описание |
| :- | :- |
| extraction_options | Получает или задает параметры извлечения текста. |
| кодировка | Получает или задает кодировку извлечённого текста. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Преобразует страницу и сохраняет её как текстовый поток. |
| process(page, output_file_name) | Преобразует страницу и сохраняет её как текстовый поток. |
