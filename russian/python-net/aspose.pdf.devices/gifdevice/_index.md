## GifDevice class

Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат GIF.

Тип GifDevice раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| GifDevice() | Инициализирует новый экземпляр класса [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) с разрешением по умолчанию. |
| GifDevice(resolution) | Инициализирует новый экземпляр класса GifDevice |
| GifDevice(width, height, resolution) | Инициализирует новый экземпляр класса GifDevice |
| GifDevice(page_size, resolution) | Инициализирует новый экземпляр класса GifDevice |
| GifDevice(width, height) | Инициализирует новый экземпляр класса GifDevice |
| GifDevice(page_size) | Инициализирует новый экземпляр класса GifDevice |
## Свойства
| Имя | Описание |
| :- | :- |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| rendering_options | Получает или задает параметры рендеринга. |
| form_presentation_mode | Получает или задает режим представления формы. |
| resolution | Получает разрешение изображения. |
| ширина | Получает ширину выходного изображения. |
| высота | Получает высоту выходного изображения. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Преобразует страницу в gif и сохраняет её в выходном потоке. |
| process(page, output_file_name) | Преобразует страницу в gif и сохраняет её в выходном потоке. |
