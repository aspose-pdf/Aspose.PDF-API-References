## ImageDevice class

Абстрактный класс для устройств изображения.

Тип ImageDevice раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| rendering_options | Получает или задает параметры рендеринга. |
| form_presentation_mode | Получает или задает режим представления формы. |
| resolution | Получает разрешение изображения. |
| ширина | Получает ширину выходного изображения. |
| высота | Получает высоту выходного изображения. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Выполняет некоторую операцию над указанной страницей, например, преобразует страницу в графическое изображение. |
| process(page, output_file_name) | Выполняет некоторую операцию над указанной страницей и сохраняет результаты в файл. |
