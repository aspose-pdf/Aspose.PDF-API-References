## CompressionType enumeration

Используется для указания значения параметра, передаваемого устройству TIFF‑изображения.

## Members
| Имя члена | Описание |
| :- | :- |
| LZW | Указывает схему сжатия LZW. Может быть передан кодировщику Tiff в качестве параметра, относящегося к категории Compression. |
| CCITT4 | Указывает схему сжатия CCITT4. Может быть передан кодировщику CCITT4 в качестве параметра, относящегося к категории Compression. |
| CCITT3 | Указывает схему сжатия CCITT3. Может быть передан кодировщику CCITT3 в качестве параметра, относящегося к категории Compression. |
| RLE | Указывает схему сжатия RLE. Может быть передан кодировщику RLE в качестве параметра, относящегося к категории Compression. |
| NONE | Указывает отсутствие сжатия. Может быть передан кодировщику Tiff в качестве параметра, относящегося к категории compression. |
