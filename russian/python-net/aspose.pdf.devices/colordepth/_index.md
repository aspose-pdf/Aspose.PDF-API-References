## ColorDepth enumeration

Используется для указания значения параметра, передаваемого устройству TIFF‑изображения.

## Members
| Имя члена | Описание |
| :- | :- |
| DEFAULT | Глубина цвета по умолчанию.<br/>            По умолчанию используется глубина 32 бита. |
| FORMAT_8BPP | 8 бит на пиксель. Эквивалентно |
| FORMAT_4BPP | 4 бита на пиксель. Эквивалентно |
| FORMAT_1BPP | 1 бит на пиксель. Эквивалентно |
