## DicomDevice class

Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат DICOM.

Тип DicomDevice раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| DicomDevice() | Создаёт новый экземпляр класса [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) с разрешением по умолчанию. |
| DicomDevice(resolution) | Создаёт новый экземпляр класса DicomDevice |
| DicomDevice(page_size) | Создаёт новый экземпляр класса DicomDevice |
| DicomDevice(width, height) | Создаёт новый экземпляр класса DicomDevice |
| DicomDevice(page_size, resolution) | Создаёт новый экземпляр класса DicomDevice |
| DicomDevice(width, height, resolution) | Создаёт новый экземпляр класса DicomDevice |
## Свойства
| Имя | Описание |
| :- | :- |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| rendering_options | Получает или задает параметры рендеринга. |
| form_presentation_mode | Получает или задает режим представления формы. |
| resolution | Получает разрешение изображения. |
| ширина | Получает ширину выходного изображения. |
| высота | Получает высоту выходного изображения. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Преобразует страницу в Dicom и сохраняет её в выходном потоке. |
| process(page, output_file_name) | Преобразует страницу в Dicom и сохраняет её в выходном потоке. |
