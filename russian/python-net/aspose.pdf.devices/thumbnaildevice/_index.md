## ThumbnailDevice class

Представляет устройство изображения, которое сохраняет страницы PDF‑документа в виде миниатюры.

Тип ThumbnailDevice раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ThumbnailDevice() | Создаёт новый экземпляр класса [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) <br/>            с размером изображения миниатюры по умолчанию (200x200 пикселей). |
| ThumbnailDevice(width, height) | Создаёт новый экземпляр класса ThumbnailDevice |
## Свойства
| Имя | Описание |
| :- | :- |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| rendering_options | Получает или задает параметры рендеринга. |
| form_presentation_mode | Получает или задает режим представления формы. |
| resolution | Получает разрешение изображения. |
| ширина | Получает ширину выходного изображения. |
| высота | Получает высоту выходного изображения. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Преобразует страницу в изображение миниатюры png и сохраняет её в выходном потоке. |
| process(page, output_file_name) | Преобразует страницу в изображение миниатюры png и сохраняет её в выходном потоке. |
