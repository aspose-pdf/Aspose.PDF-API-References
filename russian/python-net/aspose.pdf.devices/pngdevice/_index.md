## PngDevice class

Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в PNG.

Тип PngDevice раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PngDevice() | Инициализирует новый экземпляр класса [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) с разрешением по умолчанию. |
| PngDevice(resolution) | Инициализирует новый экземпляр класса PngDevice |
| PngDevice(width, height, resolution) | Инициализирует новый экземпляр класса PngDevice |
| PngDevice(page_size, resolution) | Инициализирует новый экземпляр класса PngDevice |
| PngDevice(width, height) | Инициализирует новый экземпляр класса PngDevice |
| PngDevice(page_size) | Инициализирует новый экземпляр класса PngDevice |
## Свойства
| Имя | Описание |
| :- | :- |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| rendering_options | Получает или задает параметры рендеринга. |
| form_presentation_mode | Получает или задает режим представления формы. |
| resolution | Получает разрешение изображения. |
| ширина | Получает ширину выходного изображения. |
| высота | Получает высоту выходного изображения. |
| transparent_background | Получает или задает, имеет ли изображение прозрачный фон. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Преобразует страницу в PNG и сохраняет её в выходном потоке. |
| process(page, output_file_name) | Преобразует страницу в PNG и сохраняет её в выходном потоке. |
