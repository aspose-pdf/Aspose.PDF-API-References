## TiffSettings class

Этот класс представляет настройки импорта PDF в TIFF.

Тип TiffSettings раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TiffSettings() | Инициализирует новый экземпляр класса [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/). |
| TiffSettings(shape_type) | Инициализирует новый экземпляр класса TiffSettings |
| TiffSettings(compression_type) | Инициализирует новый экземпляр класса TiffSettings |
| TiffSettings(color_depth) | Инициализирует новый экземпляр класса TiffSettings |
| TiffSettings(margins) | Инициализирует новый экземпляр класса TiffSettings |
| TiffSettings(compression_type, color_depth, margins) | Инициализирует новый экземпляр класса TiffSettings |
| TiffSettings(compression_type, color_depth, margins, skip_blank_pages) | Инициализирует новый экземпляр класса TiffSettings |
| TiffSettings(compression_type, color_depth, margins, skip_blank_pages, shape_type) | Инициализирует новый экземпляр класса TiffSettings |
| TiffSettings(skip_blank_pages) | Инициализирует новый экземпляр класса TiffSettings |
## Свойства
| Имя | Описание |
| :- | :- |
| margins | Получает отступы. |
| skip_blank_pages | Получает или задает значение, указывающее, следует ли пропускать пустые страницы. |
| compression | Получает или задает тип сжатия. |
| depth | Получает или задает глубину цвета. |
| shape | Получает или задает тип формы. |
| brightness | Получает или задает граничное значение преобразования цветов в белый и черный.<br/>            Этот параметр может быть применён с EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle или ColorDepth.Format1bpp == 1 |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
