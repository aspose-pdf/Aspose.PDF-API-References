## BmpDevice class

Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат BMP.

Тип BmpDevice раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| BmpDevice() | Создаёт новый экземпляр класса [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) с разрешением по умолчанию. |
| BmpDevice(resolution) | Создаёт новый экземпляр класса BmpDevice |
| BmpDevice(width, height, resolution) | Создаёт новый экземпляр класса BmpDevice |
| BmpDevice(page_size, resolution) | Создаёт новый экземпляр класса BmpDevice |
| BmpDevice(width, height) | Создаёт новый экземпляр класса BmpDevice |
| BmpDevice(page_size) | Создаёт новый экземпляр класса BmpDevice |
## Свойства
| Имя | Описание |
| :- | :- |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| rendering_options | Получает или задает параметры рендеринга. |
| form_presentation_mode | Получает или задает режим представления формы. |
| resolution | Получает разрешение изображения. |
| ширина | Получает ширину выходного изображения. |
| высота | Получает высоту выходного изображения. |
## Методы
| Имя | Описание |
| :- | :- |
| process(page, output) | Преобразует страницу в bmp и сохраняет её в выходном потоке. |
| process(page, output_file_name) | Преобразует страницу в bmp и сохраняет её в выходном потоке. |
