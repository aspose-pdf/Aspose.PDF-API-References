Пространство имён aspose.pdf.devices предоставляет классы, используемые для представления документа в виде изображений или простого текста. Таким образом, документ может быть передан на текстовые или различные графические устройства, что позволяет получить его текстовое или графическое представление.

## Классы
| Класс | Описание |
| :- | :- |
| [BmpDevice](/pdf/python-net/aspose.pdf.devices/bmpdevice/) | Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат BMP. |
| [Device](/pdf/python-net/aspose.pdf.devices/device/) | Абстрактный класс для всех типов устройств. Устройство используется для представления PDF‑документа в некотором формате.<br/>            Например, страницу документа можно представить как изображение или как текст. |
| [DicomDevice](/pdf/python-net/aspose.pdf.devices/dicomdevice/) | Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат DICOM. |
| [DocumentDevice](/pdf/python-net/aspose.pdf.devices/documentdevice/) | Абстрактный класс для всех устройств, используемых для обработки всего PDF‑документа. |
| [EmfDevice](/pdf/python-net/aspose.pdf.devices/emfdevice/) | Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат EMF. |
| [GifDevice](/pdf/python-net/aspose.pdf.devices/gifdevice/) | Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат GIF. |
| [ImageDevice](/pdf/python-net/aspose.pdf.devices/imagedevice/) | Абстрактный класс для устройств изображения. |
| [JpegDevice](/pdf/python-net/aspose.pdf.devices/jpegdevice/) | Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в формат JPEG. |
| [Margins](/pdf/python-net/aspose.pdf.devices/margins/) | Этот класс представляет поля изображения. |
| [PageDevice](/pdf/python-net/aspose.pdf.devices/pagedevice/) | Абстрактный класс для всех устройств, используемый для обработки определённой страницы PDF‑документа. |
| [PngDevice](/pdf/python-net/aspose.pdf.devices/pngdevice/) | Представляет устройство изображения, которое помогает сохранять страницы PDF‑документа в PNG. |
| [Resolution](/pdf/python-net/aspose.pdf.devices/resolution/) | Представляет класс для хранения разрешения изображения. |
| [TextDevice](/pdf/python-net/aspose.pdf.devices/textdevice/) | Представляет класс для преобразования страниц PDF‑документа в текст. |
| [ThumbnailDevice](/pdf/python-net/aspose.pdf.devices/thumbnaildevice/) | Представляет устройство изображения, которое сохраняет страницы PDF‑документа в виде миниатюры. |
| [TiffDevice](/pdf/python-net/aspose.pdf.devices/tiffdevice/) | Этот класс помогает сохранять страницы PDF‑документа по одной в одно TIFF‑изображение. |
| [TiffSettings](/pdf/python-net/aspose.pdf.devices/tiffsettings/) | Этот класс представляет настройки импорта PDF в TIFF. |
