## Line class

Представляет линию.

Тип Line раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Line(position_array) | Инициализирует новый экземпляр класса Line |
## Свойства
| Имя | Описание |
| :- | :- |
| graph_info | Получает или задает объект [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/), который указывает информацию о графе, такую как цвет,<br/>            ширина линии и т.д. |
| text | Получает или задает текст для фигуры |
| position_array | Получает или задает объект [position_array](/pdf/python-net/aspose.pdf.drawing/line/), указывающий массив позиций. Массив <br/> состоит из координат каждой контрольной точки линии. <br/> напрямую. |
