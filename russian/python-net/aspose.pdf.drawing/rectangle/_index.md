## Rectangle class

Представляет прямоугольник.

Тип Rectangle раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Rectangle(left, bottom, width, height) | Инициализирует новый экземпляр класса Rectangle |
## Свойства
| Имя | Описание |
| :- | :- |
| graph_info | Получает или задает объект [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/), который указывает информацию о графе, такую как цвет,<br/>            ширина линии и т.д. |
| text | Получает или задает текст для фигуры |
| rounded_corner_radius | Получает или задает значение типа float, указывающее радиус углов прямоугольника. |
| left | Получает или задает значение типа float, указывающее левую позицию прямоугольника. |
| bottom | Получает или задает значение типа float, указывающее нижнюю позицию прямоугольника. |
| ширина | Получает или задает значение типа float, указывающее ширину прямоугольника. |
| высота | Получает или задает значение типа float, указывающее высоту прямоугольника. |
