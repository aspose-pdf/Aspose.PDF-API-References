## Arc class

Представляет дугу.

Тип Arc раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Arc(pos_x, pos_y, radius, alpha, beta) | Инициализирует новый экземпляр класса Arc |
## Свойства
| Имя | Описание |
| :- | :- |
| graph_info | Получает или задает объект [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/), который указывает информацию о графе, такую как цвет,<br/>            ширина линии и т.д. |
| text | Получает или задает текст для фигуры |
| pos_x | Получает или задает значение типа float, указывающее координату x центра дуги. |
| pos_y | Получает или задает значение типа float, указывающее координату y центра дуги. |
| radius | Получает или задает значение типа float, указывающее радиус дуги. |
| alpha | Получает или задает значение типа float, указывающее начальный угол дуги в градусах. |
| beta | Получает или задает значение типа float, указывающее конечный угол дуги в градусах. |
