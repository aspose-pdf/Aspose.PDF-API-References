## Ellipse class

Представляет эллипс.

Тип Ellipse раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Ellipse(left, bottom, width, height) | Инициализирует новый экземпляр класса Ellipse |
## Свойства
| Имя | Описание |
| :- | :- |
| graph_info | Получает или задает объект [graph_info](/pdf/python-net/aspose.pdf.drawing/shape/), который указывает информацию о графе, такую как цвет,<br/>            ширина линии и т.д. |
| text | Получает или задает текст для фигуры |
| left | Получает или задает значение типа float, указывающее левую позицию эллипса. |
| bottom | Получает или задает значение типа float, указывающее нижнюю позицию эллипса. |
| ширина | Получает или задает значение типа float, указывающее ширину эллипса. |
| высота | Получает или задает значение типа float, указывающее высоту эллипса. |
