## RootElement class

Элемент корневой структуры.

Тип RootElement раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| children | Получает коллекцию дочерних элементов. |
| lang | (Optional; PDF 1.4) Язык, указывающий естественный язык для всего текста<br/> в структурном элементе, за исключением случаев, когда он переопределяется спецификациями языка для вложенных структурных<br/> элементов или помеченного контента. |
| actual_text | (Optional; PDF 1.4) Текст, являющийся точной заменой структурного элемента и его дочерних элементов.<br/> Этот заменяющий текст (который должен применяться к максимально небольшому фрагменту контента)<br/> полезен при извлечении содержимого документа в целях обеспечения доступности для пользователей<br/> с ограниченными возможностями или для других целей. |
| alt | (Optional) Альтернативное описание структурного элемента и его дочерних элементов в<br/> человекочитаемой форме, которое полезно при извлечении содержимого документа в целях обеспечения<br/> доступности для пользователей с ограниченными возможностями или для других целей. |
| e | (Optional; PDF 1.5) Расширенная форма аббревиатуры. |
