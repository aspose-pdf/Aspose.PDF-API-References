## Form class

Класс, представляющий объект формы.

Тип Form раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| is_synchronized | Возвращает true, если объект потокобезопасен. |
| sync_root | Возвращает объект синхронизации. |
| auto_recalculate | Если установлено, все поля формы будут пересчитываться при изменении любого поля. Значение по умолчанию — true. Установите false для повышения производительности при заполнении формы большим количеством вычисляемых полей. |
| auto_restore_form | Если установлено, отсутствующие поля формы будут автоматически созданы, если они присутствуют в аннотациях. |
| default_resources | Получает ресурсы по умолчанию, размещённые в этой форме. |
| default_appearance | Получает или устанавливает внешний вид формы по умолчанию (объект, описывающий шрифт, размер текста и цвет по умолчанию для полей формы). |
| xfa | Получает XFA‑данные формы (если присутствуют). |
| ignore_needs_rendering | Если это свойство истинно, значение ключа NeedsRendering будет игнорироваться при конвертации <br/>            XFA‑формы в стандартную форму. По умолчанию значение ложно. |
| remove_permission | Если это свойство истинно, словарь "Perms" будет удалён из PDF‑документа после конвертации <br/>            динамических документов в стандартные. Словарь "Perms" может содержать правила, которые нарушают отображение выбора <br/>            обязательных полей в Adobe Acrobat Reader.<br/>            По умолчанию значение ложно. |
| emulate_requierd_groups | Если это свойство истинно, для контейнеров обязательных элементов Xfa exclGroup будут нарисованы дополнительные красные границы‑прямоугольники<br/>            Это свойство было введено из‑за отсутствия аналогов exclGroup при конвертации представления форм Xfa <br/>            в стандартный формат.<br/>            По умолчанию значение ложно. |
| type | Получает тип формы. Возможные значения: Standard, Static, Dynamic. |
| fields | Получает список всех полей на самом нижнем уровне иерархической формы. |
| signatures_exist | Если установлено, документ содержит как минимум одно поле подписи. |
| signatures_append_only | Если установлено, документ содержит подписи, которые могут быть аннулированы, если файл сохраняется (записывается) способом, изменяющим его прежнее содержимое, <br/>            в отличие от инкрементного обновления. |
| sign_dependent_elements_rendering_mode_when_converted | Формы могут содержать информацию о подписи, т.е. могут быть подписаны или не подписаны.<br/>              И представление формы иногда должно зависеть от того, подписана форма или нет.<br/>              Это свойство указывает конвертеру формы (например, при конвертации XFA‑формы в стандартную форму)<br/>              должна ли результирующая форма отображаться как подписанная или как неподписанная. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает поле формы по индексу поля. |
## Методы
| Имя | Описание |
| :- | :- |
| delete(field) | Удалить поле из формы. |
| delete(field_name) | Удаляет поле из формы по его имени. |
| add(field, page_number) | Добавляет поле в форму. |
| add(field) | Добавляет поле в форму. |
| add(field, partial_name, page_number) | Добавляет новое поле в форму; если это поле уже размещено в другой или этой форме, создаётся копия поля. |
| has_field(field) | Проверьте, есть ли в форме указанное поле. |
| has_field(field_name) | Определяет, было ли поле с указанным именем уже добавлено в форму. |
| copy_to(array, index) | Копирует поля, размещённые в форме, в массив. |
| flatten() | Удаляет все поля формы и размещает их значения непосредственно на странице. |
| add_field_appearance(field, page_number, rect) | Добавляет дополнительное отображение поля на указанную страницу документа в заданном месте. |
| get_fields_in_rect(rect) | Возвращает поля внутри указанного прямоугольника. |
