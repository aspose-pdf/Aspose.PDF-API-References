## Field class

Базовый класс для полей AcroForm.

Тип Field раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Field(doc) | Инициализирует новый экземпляр класса Field |
## Свойства
| Имя | Описание |
| :- | :- |
| vertical_alignment | None |
| horizontal_alignment | Получает или задает выравнивание текста для аннотации. |
| margin | None |
| is_first_paragraph_in_column | None |
| is_kept_with_next | None |
| is_in_new_page | None |
| is_in_line_paragraph | None |
| hyperlink | None |
| z_index | None |
| update_appearance_on_convert | Если true, внешний вид аннотации будет обновлён перед преобразованием PF‑документа в изображение. Это позволяет корректно преобразовать поля, но, вероятно, требует больше времени. |
| use_font_subset | Если это свойство установлено в true, шрифты будут добавлены в документ как подмножества. Значение по умолчанию — true. |
| флаги | Флаги аннотации. |
| тип_аннотации | Получает тип аннотации. |
| ширина | Получает или задает ширину аннотации. |
| действия | Получает действия аннотации. |
| высота | Получает или задает высоту аннотации. |
| прямоугольник | Получает или задает прямоугольник поля. |
| содержимое | Получает или задает текст аннотации. |
| name | Получает или задает имя аннотации на странице. |
| изменено | Получает или задает дату и время последнего изменения аннотации. |
| цвет | Получает или задает цвет аннотации. |
| border | Получает или задает характеристики границы аннотации. [border](/pdf/python-net/aspose.pdf.annotations/annotation/) |
| активное_состояние | Получает или задает текущее состояние внешнего вида аннотации. |
| характеристики | Получает характеристики аннотации. |
| состояния | Получает словарь внешнего вида аннотации. |
| выравнивание | Выравнивание аннотации. Это свойство устарело. Используйте HorizontalAligment вместо него. |
| горизонтальное_выравнивание_текста | Получает или задает выравнивание текста для аннотации. |
| полное_имя | Получает полностью квалифицированное имя аннотации. |
| вид | Получает словарь внешнего вида аннотации. |
| индекс_страницы | Получает индекс страницы, содержащей это поле. |
| при_активации | Действие, которое будет выполнено при активации аннотации. |
| выделение | Режим выделения аннотации. |
| родитель | Получает родителя аннотации. |
| default_appearance | Получает или задает внешний вид по умолчанию поля. |
| read_only | Получает или задает статус только для чтения поля. |
| required | Получает или задает обязательный статус поля. |
| exportable | Получает или задает флаг экспортируемости поля. |
| partial_name | Получает или задает частичное имя поля. |
| alternate_name | Получает или задает альтернативное имя поля (Альтернативное поле <br/>            имя, которое должно использоваться вместо фактического имени поля <br/>            везде, где поле должно быть идентифицировано в пользовательском интерфейсе).<br/>            Альтернативное имя используется как всплывающая подсказка поля в Adobe Acrobat. |
| mapping_name | Получает или задает имя сопоставления поля, которое будет использоваться при экспорте данных интерактивных полей формы из документа. |
| value | Получает или задает значение поля. |
| is_synchronized | Возвращает true, если словарь синхронизирован. |
| sync_root | Объект синхронизации. |
| is_group | Получает или задает логическое значение, указывающее, является ли это поле нетерминальным, т.д. группой полей. |
| annotation_index | Получает или задает индекс этой аннотации на странице. |
| is_shared_field | Свойство для поддержки Generator. Используется, когда поле добавляется в верхний или нижний колонтитул. Если true, это поле будет создано один раз, и его отображение будет видно на всех страницах документа. Если false, отдельное поле будет создано для каждой страницы документа. |
| fit_into_rectangle | Если true, размер шрифта будет уменьшен, чтобы поместить текст в указанный прямоугольник. |
| max_font_size | Максимальный размер шрифта, который может использоваться для содержимого поля. -1 — не проверять размер. |
| min_font_size | Минимальный размер шрифта, который может использоваться для содержимого поля. -1 — не проверять размер. |
| tab_order | Получает или задает порядок табуляции поля. |
