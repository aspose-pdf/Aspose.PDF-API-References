## IconFit class

Описывает, как значок аннотации виджета должен отображаться внутри её прямоугольника аннотации.

Тип IconFit раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| scaling_reason | Получает или задает причину масштабирования. |
| scaling_mode | Тип масштабирования, который будет использоваться.        /// |
| leftover_left | Получает или задает пространство, выделяемое слева от значка. |
| leftover_bottom | Получает или задает пространство, выделяемое снизу от значка. |
| spread_on_border | Если true, указывает, что внешний вид кнопки должен быть масштабирован так, чтобы полностью помещаться в границы аннотации, не учитывая толщину линии границы. |
## Методы
| Имя | Описание |
| :- | :- |
| name_to_scaling_reason(reason) | Преобразует имя причины масштабирования в объект ScalingReason. |
| scaling_reason_to_name(reason) | Преобразует объект причины масштабирования в имя. |
| name_to_scaling_mode(mode) | Преобразует имя режима масштабирования в объект ScalingMode. |
| scaling_mode_to_name(mode) | Преобразует объект режима масштабирования в имя. |
