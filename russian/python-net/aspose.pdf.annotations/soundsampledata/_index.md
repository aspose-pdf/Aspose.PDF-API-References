## SoundSampleData class

Представляет дополнительные записи, специфичные для звукового объекта (Раздел 9.2 PDF1‑7).

Тип SoundSampleData раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SoundSampleData(sampling_rate) | Инициализирует новый экземпляр класса SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels) | Инициализирует новый экземпляр класса SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel) | Инициализирует новый экземпляр класса SoundSampleData |
| SoundSampleData(sampling_rate, number_of_sound_channels, bits_per_channel, sound_sample_data_encoding_format) | Инициализирует новый экземпляр класса SoundSampleData |
## Свойства
| Имя | Описание |
| :- | :- |
| sampling_rate | Получает или задает частоту дискретизации. |
| number_of_sound_channels | Получает или задает количество звуковых каналов. |
| bits_per_channel | Получает или задает количество битов на значение образца для каждого канала. |
| encoding_format | Получает или задает формат кодирования. |
| DEFAULT_SAMPLING_RATE | Значение по умолчанию для SamplingRate. |
| DEFAULT_OF_SOUND_CHANNELS | Значение по умолчанию для параметра Channels. |
| DEFAULT_OF_BITS_PER_CHANNEL | Значение по умолчанию для параметра BitsPerchannel. |
| DEFAULT_ENCODING_FORMAT | Значение по умолчанию для формата кодирования. |
