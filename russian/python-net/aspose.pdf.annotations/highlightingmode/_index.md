## HighlightingMode enumeration

Перечисляет режим подсветки аннотации, визуальный эффект, используемый при нажатии или удержании кнопки мыши внутри её активной области.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Без подсветки. |
| INVERT | Инвертировать содержимое прямоугольника аннотации. |
| OUTLINE | Инвертировать границу аннотации. |
| PUSH | Отобразить нижнее отображение аннотации, если оно присутствует. Если нижнее отображение не определено, сместить содержимое прямоугольника аннотации так, будто оно нажимается вниз под поверхность страницы. |
| TOGGLE | То же, что Push (предпочтительно). |
