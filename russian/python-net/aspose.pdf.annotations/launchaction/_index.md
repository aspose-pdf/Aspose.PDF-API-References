## LaunchAction class

Представляет действие запуска, которое запускает приложение или открывает, либо печатает документ.

Тип LaunchAction раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LaunchAction(file) | Инициализирует новый экземпляр класса LaunchAction |
| LaunchAction(document, file) | Инициализирует новый экземпляр класса LaunchAction |
## Свойства
| Имя | Описание |
| :- | :- |
| следующий | Следующие действия в последовательности. |
| файл | Получает или задает приложение, которое будет запущено, или документ, который будет открыт или распечатан. |
| new_window | Получает или задает флаг, указывающий, открывать ли целевой документ в новом окне (только для PDF‑документов). |
