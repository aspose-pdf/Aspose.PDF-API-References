## DefaultAppearance class

Описывает внешний вид поля по умолчанию (шрифт, размер текста и цвет).

Тип DefaultAppearance раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| DefaultAppearance() | Конструктор DefaultAppearance. |
| DefaultAppearance(font_name, font_size, text_color) | Инициализирует новый экземпляр класса DefaultAppearance |
| DefaultAppearance(font, font_size, text_color) | Инициализирует новый экземпляр класса DefaultAppearance |
## Свойства
| Имя | Описание |
| :- | :- |
| font_size | Получает размер шрифта в настройках по умолчанию. |
| text_color | Получает или задает цвет текста в настройках по умолчанию. |
| font_name | Получает имя шрифта в отображении по умолчанию. |
| font_resource_name | Получает имя шрифта в отображении по умолчанию. |
| font | Получает шрифт, указанный как шрифт по умолчанию для текста. |
| text | Получает список операторов PDF, которые представляют отображение. |
