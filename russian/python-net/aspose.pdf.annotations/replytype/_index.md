## ReplyType enumeration

Перечисляет виды отношений («тип ответа») между аннотацией и той, которая указана в InReplyTo.

## Members
| Имя члена | Описание |
| :- | :- |
| UNDEFINED | Неопределённая связь. |
| REPLY | Аннотация считается ответом на аннотацию, указанную в InReplyTo. Приложения‑просмотрщики не должны отображать ответы на аннотацию по отдельности, а объединять их в виде ветвящихся комментариев. |
| GROUP | Аннотация сгруппирована с аннотацией, указанной в InReplyTo. |
