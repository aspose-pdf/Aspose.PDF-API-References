## Measure class

Класс, описывающий систему координат измерения.

Тип Measure раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Measure(annotation) | Инициализирует новый экземпляр класса Measure |
## Свойства
| Имя | Описание |
| :- | :- |
| scale_ratio | Текстовая строка, выражающая масштабное соотношение чертежа. |
| x_format | Массив форматов чисел для измерения изменения вдоль оси X и, если ось Y не указана, также вдоль оси Y. |
| y_format | Массив форматов чисел для измерения изменения вдоль оси Y. |
| distance_format | Массив форматов чисел для измерения расстояния в любом направлении. |
| area_format | Массив форматов чисел для измерения площади. |
| angle_format | Массив форматов чисел для измерения углов. |
| slope_format | Массив форматов чисел для измерения наклона линии. |
| origin | Точка, определяющая начало системы координат измерения в координатах пространства пользователя по умолчанию. |
| xy_factor | Коэффициент, используемый для преобразования крупнейших единиц вдоль оси y в крупнейшие единицы вдоль оси x. |
