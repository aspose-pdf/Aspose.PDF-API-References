## SoundData class

Представляет звуковые данные, определяющие звук, который будет воспроизводиться при активации аннотации.

## Свойства
| Имя | Описание |
| :- | :- |
| rate | Получает или задает частоту дискретизации в образцах в секунду. |
| каналы | Получает или задает количество звуковых каналов. |
| биты | Получает или задает количество битов на значение образца для каждого канала. |
| содержимое | Получает поток звука, который будет воспроизводиться при активации аннотации. |
