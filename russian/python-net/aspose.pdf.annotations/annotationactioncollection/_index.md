## AnnotationActionCollection class

Представляет коллекцию действий аннотации.

Тип AnnotationActionCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| on_enter | Получает или задает действие, которое будет выполнено, когда курсор входит в активную область аннотации. |
| on_exit | Получает или задает действие, которое будет выполнено, когда курсор выходит из активной области аннотации. |
| on_press_mouse_btn | Получает или задает действие, которое будет выполнено, когда кнопка мыши нажата внутри активной области аннотации. |
| on_release_mouse_btn | Получает или задает действие, которое будет выполнено, когда кнопка мыши отпущена внутри активной области аннотации. |
| on_receive_focus | Получает или задает действие, которое будет выполнено, когда аннотация получает фокус ввода. |
| on_open_page | Получает или задает действие, которое будет выполнено, когда открывается страница, содержащая аннотацию. |
| on_close_page | Получает или задает действие, которое будет выполнено, когда закрывается страница, содержащая аннотацию. |
| on_show_page | Получает или задает действие, которое будет выполнено, когда страница, содержащая аннотацию, становится видимой в пользовательском интерфейсе приложения‑просмотрщика. |
| on_hide_page | Получает или задает действие, которое будет выполнено, когда страница, содержащая аннотацию, больше не видна в пользовательском интерфейсе приложения‑просмотрщика. |
| on_lost_focus | Получает или задает действие, которое будет выполнено, когда аннотация теряет фокус ввода. |
| on_modify_character | Получает или задает действие, которое будет выполнено, когда пользователь изменяет символ поля. |
| on_validate | Получает или задает действие, которое будет выполнено, когда пользователь изменяет содержимое поля. |
| on_format | Получает или задает действие, которое будет выполнено для форматирования значения поля. |
| on_calculate | Получает или задает действие для вычисления значения поля. |
## Методы
| Имя | Описание |
| :- | :- |
| remove_actions() | Удаляет все действия аннотации. |
