## PdfActionCollection class

Класс описывает список действий.

Тип PdfActionCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| count | Получает количество действий. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает действие по его индексу. |
## Методы
| Имя | Описание |
| :- | :- |
| delete(index) | Удалить действие по индексу. |
| add(action) | Добавить действие в список действий. |
