## FitBVExplicitDestination class

Представляет явное назначение, которое отображает страницу, при этом горизонтальная координата left размещается у левого края окна, а содержимое страницы увеличивается ровно настолько, чтобы полностью поместить высоту её ограничивающего прямоугольника в окно. Значение null для left указывает, что текущие значения этого параметра должны оставаться без изменений.
