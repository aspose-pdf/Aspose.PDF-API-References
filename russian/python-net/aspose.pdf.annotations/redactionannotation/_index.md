## RedactionAnnotation class

Представляет аннотацию Redact.

Тип RedactionAnnotation раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| RedactionAnnotation(document) | Инициализирует новый экземпляр класса RedactionAnnotation |
| RedactionAnnotation(page, rect) | Инициализирует новый экземпляр класса RedactionAnnotation |
