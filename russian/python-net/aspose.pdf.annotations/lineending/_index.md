## LineEnding enumeration

Перечисляет стили окончаний линий, используемые при рисовании линии.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Нет завершения строки. |
| SQUARE | Квадрат, заполненный внутренним цветом аннотации, если он задан. |
| CIRCLE | Круг, заполненный внутренним цветом аннотации, если он задан. |
| DIAMOND | Алмазная форма, заполненная внутренним цветом аннотации, если он задан. |
| OPEN_ARROW | Две короткие линии, образующие острый угол, формируют открытую стрелку. |
| CLOSED_ARROW | Две короткие линии, образующие острый угол, как в стиле OpenArrow, и соединённые третьей линией, образуют треугольную закрытую стрелку, заполненную внутренним цветом аннотации, если он задан. |
| BUTT | Короткая линия в конце, перпендикулярная самой линии. |
| R_OPEN_ARROW | Две короткие линии в обратном направлении от OpenArrow. |
| R_CLOSED_ARROW | Треугольная закрытая стрелка в обратном направлении от ClosedArrow. |
| SLASH | Короткая линия в конце, примерно под 30 градусов по часовой стрелке от перпендикуляра к самой линии. |
