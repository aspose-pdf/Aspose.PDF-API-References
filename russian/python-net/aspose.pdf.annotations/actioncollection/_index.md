## ActionCollection class

Коллекция действий

Тип ActionCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| is_synchronized | Возвращает true, если объект синхронизирован. |
| sync_root | Получает объект синхронизации. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает действие по его индексу. |
## Методы
| Имя | Описание |
| :- | :- |
| delete(index) | Удаляет действие из коллекции по индексу. |
| delete() | Удаляет действие из коллекции по индексу. |
