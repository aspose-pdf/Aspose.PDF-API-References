## TextAnnotation class

Представляет текстовую аннотацию, представляющую собой «липкую заметку», прикреплённую к точке в PDF‑документе.

Тип TextAnnotation раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextAnnotation(document) | Инициализирует новый экземпляр класса TextAnnotation |
| TextAnnotation(page, rect) | Инициализирует новый экземпляр класса TextAnnotation |
## Свойства
| Имя | Описание |
| :- | :- |
| vertical_alignment | None |
| horizontal_alignment | Получает или задает выравнивание текста для аннотации. |
| margin | None |
| is_first_paragraph_in_column | None |
| is_kept_with_next | None |
| is_in_new_page | None |
| is_in_line_paragraph | None |
| hyperlink | None |
| z_index | None |
| update_appearance_on_convert | Если true, внешний вид аннотации будет обновлён перед преобразованием PF‑документа в изображение. Это позволяет корректно преобразовать поля, но, вероятно, требует больше времени. |
| use_font_subset | Если это свойство установлено в true, шрифты будут добавлены в документ как подмножества. Значение по умолчанию — true. |
| флаги | Флаги аннотации. |
| тип_аннотации | Получает тип аннотации. |
| ширина | Получает или задает ширину аннотации. |
| действия | Получает список действий аннотации. |
| высота | Получает или задает высоту аннотации. |
| прямоугольник | Получает или задает прямоугольник аннотации. |
| содержимое | Получает или задает текст аннотации. |
| name | Получает или задает имя аннотации на странице. |
| изменено | Получает или задает дату и время последнего изменения аннотации. |
| цвет | Получает или задает цвет аннотации. |
| border | Получает или задает характеристики границы аннотации. [border](/pdf/python-net/aspose.pdf.annotations/annotation/) |
| активное_состояние | Получает или задает текущее состояние внешнего вида аннотации. |
| характеристики | Получает характеристики аннотации. |
| состояния | Получает словарь внешнего вида аннотации. |
| выравнивание | Выравнивание аннотации. Это свойство устарело. Используйте HorizontalAligment вместо него. |
| горизонтальное_выравнивание_текста | Получает или задает выравнивание текста для аннотации. |
| полное_имя | Получает полностью квалифицированное имя аннотации. |
| вид | Получает словарь внешнего вида аннотации. |
| индекс_страницы | Получает индекс страницы, содержащей аннотацию. |
| title | Получает или задаёт текст, который будет отображаться в заголовке аннотации. |
| rich_text | Получает или задает строку с форматированным текстом, отображаемую во всплывающем окне при открытии аннотации. |
| creation_date | Получает дату и время создания аннотации. |
| subject | Получает текст, представляющий описание объекта. |
| popup | Всплывающая аннотация для ввода или редактирования текста, связанного с этой аннотацией. |
| непрозрачность | Получает или задает постоянное значение непрозрачности, используемое при отрисовке аннотации. |
| in_reply_to | Ссылка на аннотацию, к которой данная аннотация является "ответом".<br/>            Обе аннотации должны находиться на одной странице документа. |
| reply_type | Строка, указывающая отношение ("тип ответа") между этой аннотацией<br/>            и аннотацией, указанной в InReplyTo. |
| открыть | Получает или задает флаг, указывающий, должна ли аннотация изначально отображаться открытой. |
| icon | Получает или задает значок, используемый при отображении аннотации. |
| state | Получает или задает состояние, в которое должна быть установлена оригинальная аннотация. |
## Методы
| Имя | Описание |
| :- | :- |
| clone() | None |
| get_rectangle(consider_rotation) | Возвращает прямоугольник аннотации с учётом поворота страницы. |
| accept(visitor) | Принимает объект посетителя для обработки аннотации. |
| flatten() | Размещает содержимое аннотации непосредственно на странице,<br/>            объект аннотации будет удалён. |
| change_after_resize(transform) | Обновляет начальные и конечные точки в соответствии с матричным преобразованием. |
