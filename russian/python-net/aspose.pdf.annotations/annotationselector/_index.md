## AnnotationSelector class

Этот класс используется для выбора аннотаций с помощью идеи шаблона Visitor.

Тип AnnotationSelector раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| AnnotationSelector() | Инициализирует новый экземпляр класса AnnotationSelector |
| AnnotationSelector(annotation) | Инициализирует новый экземпляр класса AnnotationSelector |
## Свойства
| Имя | Описание |
| :- | :- |
| selected | Список выбранных объектов. |
