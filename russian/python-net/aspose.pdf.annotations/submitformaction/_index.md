## Свойства
| Имя | Описание |
| :- | :- |
| следующий | Следующие действия в последовательности. |
| флаги | Получает или задает флаги действия отправки. |
| url | URL назначения. |
| EXCLUDE | Если не установлен, массив Fields указывает, какие поля включать в отправку. |
| INCLUDE_NO_VALUE_FIELDS | Если установлен, все поля, указанные массивом Fields и флагом Include/Exclude, будут отправлены. |
| EXPORT_FORMAT | Если установлен, имена полей и их значения будут отправлены в формате HTML‑формы. |
| GET_METHOD | Если установлен, имена полей и их значения будут отправлены с использованием HTTP‑GET запроса. |
| SUBMIT_COORDINATES | Если установлен, координаты щелчка мыши, вызвавшего действие submit‑form, будут переданы в составе данных формы. |
| XFDF | Если установлен, имена полей и их значения будут отправлены в виде XFDF. |
| INCLUDE_APPEND_SAVES | Если установлен, отправляемый файл FDF будет включать содержимое всех инкрементных обновлений. |
| INCLUDE_ANNOTATIONS | Если установлен, отправляемый файл FDF будет включать все разметочные аннотации в базовом PDF‑документе. |
| SUBMIT_PDF | Если установлен, документ будет отправлен в формате PDF, используя MIME‑тип содержимого application/pdf. |
| CANONICAL_FORMAT | Если установлен, любые отправленные значения полей, представляющие даты, будут преобразованы в стандартный формат. |
| EXCL_NON_USER_ANNOTS | Если установлен, будут включены только те разметочные аннотации, у которых запись T совпадает с именем текущего пользователя. |
| EXCL_F_KEY | Если установлен, отправляемый FDF будет исключать запись F. |
| EMBED_FORM | Если установлен, запись F отправляемого FDF будет файловой спецификацией, содержащей <br/>            встроенный поток файла, представляющий PDF‑файл, из которого отправляется FDF. |
