## DocumentActionCollection class

Класс описывает действия, выполняемые над некоторыми действиями с документом

Тип DocumentActionCollection раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| DocumentActionCollection(document) | Инициализирует новый экземпляр класса DocumentActionCollection |
## Свойства
| Имя | Описание |
| :- | :- |
| before_saving | Получает или задаёт действие, выполняемое перед сохранением документа. |
| before_closing | Получает или задаёт действие, которое будет выполнено перед закрытием документа. |
| after_saving | Получает или задаёт действие, которое будет выполнено после сохранения документа. |
| before_printing | Действие, которое будет выполнено перед печатью документа. |
| after_printing | Действие, которое будет выполнено после печати документа. |
