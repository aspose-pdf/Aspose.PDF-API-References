## AnnotationState enumeration

Перечисление состояний, в которые может быть установлена оригинальная аннотация.

## Members
| Имя члена | Описание |
| :- | :- |
| UNDEFINED | Неопределённое состояние. |
| MARKED | Аннотация была отмечена пользователем. |
| UNMARKED | Аннотация не была отмечена пользователем. |
| ACCEPTED | Пользователь согласен с изменением. |
| REJECTED | Пользователь не согласен с изменением. |
| CANCELLED | Изменение было отменено. |
| ЗАВЕРШЕНО | Изменение было завершено. |
| NONE | Пользователь не указал ничего о изменении. |
