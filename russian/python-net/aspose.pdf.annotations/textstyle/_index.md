## TextStyle class

Класс, представляющий стиль текста в аннотации.

Тип TextStyle раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| font_name | Имя шрифта. |
| font_size | Размер шрифта. |
| выравнивание | Получает или задает горизонтальное выравнивание текста. |
| horizontal_alignment | Выравнивание текста. Допустимые значения: Left, Center, Rigth. |
| цвет | Цвет текста. |
