## RenditionOperation enumeration

Операция, выполняемая при срабатывании действия.

## Members
| Имя члена | Описание |
| :- | :- |
| PLAY_STOP | Если с аннотацией не связан рендер, воспроизведите указанный рендер, связав его с аннотацией. Если рендер уже связан с аннотацией, он будет остановлен, и новый рендер будет связан с аннотацией. |
| СТОП | Остановите любое воспроизведение, связанное с аннотацией. |
| ПАУЗА | Приостановите любое воспроизведение, связанное с аннотацией. |
| ПРОДОЛЖИТЬ | Возобновите любое воспроизведение, связанное с аннотацией. |
| PLAY_RESUME | Воспроизведите указанное воспроизведение, связав его с аннотацией. Если воспроизведение уже связано с аннотацией, возобновите его, если оно приостановлено. |
| UNDEFINED | Операция не определена. |
