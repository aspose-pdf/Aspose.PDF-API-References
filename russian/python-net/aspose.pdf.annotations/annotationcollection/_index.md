## AnnotationCollection class

Класс, представляющий коллекцию аннотаций.

Тип AnnotationCollection предоставляет следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| is_synchronized | Получает значение, указывающее, синхронизирован ли доступ к Aspose.Pdf.Annotations.AnnotationCollection (потокобезопасный). |
| sync_root | Получает объект, который можно использовать для синхронизации доступа к Aspose.Pdf.Annotations.AnnotationCollection. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Индекс элемента для получения. |
## Методы
| Имя | Описание |
| :- | :- |
| delete(index) | Удаляет аннотацию из коллекции по индексу. |
| delete() | Удаляет аннотацию из коллекции по индексу. |
| delete(annotation) | Удаляет аннотацию из коллекции по индексу. |
| add(annotation, consider_rotation) | Добавляет аннотацию в коллекцию. Если страница повернута, то прямоугольник аннотации будет пересчитан соответствующим образом. |
| accept(visitor) | Принимает посетителя для обработки аннотации. |
| find_by_name(name) | Возвращает аннотацию по её имени. |
