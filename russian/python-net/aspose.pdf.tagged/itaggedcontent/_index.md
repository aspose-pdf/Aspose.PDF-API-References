## ITaggedContent class

Представляет интерфейс для работы с содержимым TaggedPdf документа.

Тип ITaggedContent раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| structure_text_state | Получить настройки [StructureTextState](/pdf/python-net/aspose.pdf.logicalstructure/structuretextstate/) для всего документа. |
| struct_tree_root_element | Получает [StructTreeRootElement](/pdf/python-net/aspose.pdf.logicalstructure/structtreerootelement/) PDF‑документа. |
| root_element | Получает корневой [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/) логической структуры PDF‑документа. |
