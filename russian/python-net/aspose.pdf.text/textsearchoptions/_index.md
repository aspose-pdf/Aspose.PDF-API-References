## TextSearchOptions class

Представляет параметры поиска текста

Тип TextSearchOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextSearchOptions(is_regular_expression_used) | Инициализирует новый экземпляр класса TextSearchOptions |
| TextSearchOptions(rectangle) | Инициализирует новый экземпляр класса TextSearchOptions |
| TextSearchOptions(rectangle, is_regular_expression_used) | Инициализирует новый экземпляр класса TextSearchOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| is_regular_expression_used | Получает или задает признак использования регулярного выражения. |
| limit_to_page_bounds | Получает или задает признак поиска текста в пределах границ страницы. |
| rectangle | Получает или задает прямоугольник, ограничивающий искомый текст. |
| use_font_engine_encoding | Получает или задает признак того, что поиск текста будет выполняться с использованием кодировки шрифтового движка.<br/>            true - означает, что будет использована кодировка шрифтового движка (попробуйте это, если поиск текста не удаётся из‑за несовершенной кодировки в документе)<br/>            false - означает, что будет использована кодировка шрифта документа (значение по умолчанию) |
| ignore_shadow_text | Получает или задает признак того, что фрагменты текста, представляющие тень обычного текста, будут игнорироваться при поиске.<br/>            true - означает, что теневой текст не будет найден (попробуйте это, если поиск текста возвращает дублирующиеся фрагменты в близких позициях)<br/>            false - означает, что теневой текст будет найден вместе с обычным текстом (значение по умолчанию) |
| log_text_extraction_errors | Получает или задает признак того, что ошибки извлечения текста (декодирования) будут записываться в поглотитель текста (фрагмента).<br/>            true - означает, что ошибки извлечения текста (декодирования) будут записываться. Это может снизить производительность.<br/>            false (default) - запись ошибок отключена. |
| ignore_resource_font_errors | Получает или задает указание, что ошибки, связанные с отсутствием шрифта, будут игнорироваться поглотителем текста (фрагмента).<br/>            true - означает, что ошибки отсутствия шрифта будут игнорироваться. Сегменты текста, ссылающиеся на некорректные ресурсы, будут пропущены при обработке.<br/>            false (по умолчанию) - ошибка отсутствия шрифта завершит обработку, выбросив исключение. |
| search_for_text_related_graphics | Получает или задает значение, позволяющее выполнять поиск графических элементов, связанных с текстом (подчеркивание, фон и т.д.) во время поиска текста.<br/>            true - поиск графических элементов, связанных с текстом, будет выполнен (значение по умолчанию).<br/>            false - графические элементы, которые могут присутствовать в исходном документе, будут игнорироваться. Установите это в случае проблем с производительностью или отсутствия необходимости обрабатывать подчеркивание, фон или обрезку. |
| stored_graphic_elements_max_count | Получает или задает значение, ограничивающее поиск графических элементов, связанных с текстом (подчеркивание, фон и т.д.) на странице до указанного количества элементов.<br/>            Значение по умолчанию — 250. Установите меньшее значение в случае проблем с производительностью, попробуйте большее значение, если некоторые графические элементы не были найдены. |
| search_in_annotations | Получает или задает значение, позволяющее выполнять поиск текста в Аннотациях.<br/>            true - текст будет искаться в Аннотациях.<br/>            false - текст в Аннотациях не будет обрабатываться TextFragmentAbsorber. |
