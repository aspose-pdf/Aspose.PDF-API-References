## SystemFontsSubstitution class

Представляет класс стратегии замены шрифтов, заменяющий шрифты системными шрифтами.

Тип SystemFontsSubstitution раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| SystemFontsSubstitution(font_categories) | Инициализирует новый экземпляр класса SystemFontsSubstitution |
## Свойства
| Имя | Описание |
| :- | :- |
| font_categories | Получает или задаёт категории шрифтов замены, которые должны быть заменены системными шрифтами. |
| default_font | Получает или задаёт шрифт замены по умолчанию.<br/>            Шрифт используется, когда не найдено других действительных замен, но исходный шрифт принадлежит целевой категории замены ([font_categories](/pdf/python-net/aspose.pdf.text/systemfontssubstitution/)). |
