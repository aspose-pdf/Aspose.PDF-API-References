## TextReplaceOptions class

Представляет параметры замены текста

Тип TextReplaceOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextReplaceOptions(scope) | Инициализирует новый экземпляр класса TextReplaceOptions |
| TextReplaceOptions(adjustment) | Инициализирует новый экземпляр класса TextReplaceOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| replace_scope | Получает или задает область, в которой применяется операция замены текста |
| replace_adjustment_action | Получает или задает действие, которое будет выполнено после замены фрагмента текста на более короткий. |
| adjustment_new_line_spacing | Получает или задает значение межстрочного интервала, используемого, если принудительно создаётся новая строка текста при замене.<br/>            Ожидаемое значение — множитель размера шрифта заменяемого текста. По умолчанию 1.2. |
