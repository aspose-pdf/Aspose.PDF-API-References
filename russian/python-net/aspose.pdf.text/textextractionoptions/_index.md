## TextExtractionOptions class

Представляет параметры извлечения текста

Тип TextExtractionOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextExtractionOptions(formatting_mode) | Инициализирует новый экземпляр класса TextExtractionOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| formatting_mode | Получает режим форматирования. |
| scale_factor | Получает или задает коэффициент, который будет применяться для масштабирования размера шрифта при извлечении в чистом режиме.<br/>            Установка меньшего значения приводит к большему количеству пробелов в извлечённом тексте.<br/>            Значение по умолчанию — 1, без масштабирования;<br/>            Установка значения в ноль позволяет алгоритму автоматически выбирать масштаб. |
