## PageMarkup class

Разметка страницы представлена коллекциями [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/) и [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/).

Тип PageMarkup раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| номер | Получает обработанный номер страницы. |
| rectangle | Получает обработанный прямоугольник страницы. |
| sections | Получает коллекцию [MarkupSection](/pdf/python-net/aspose.pdf.text/markupsection/), найденную на странице. |
| paragraphs | Получает коллекцию [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/), найденную на странице. |
| text_fragments | Получает коллекцию [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/), найденную на странице. |
| is_multicolumn_paragraphs_allowed | Получает или задает значение, указывающее, могут ли начальные строки текста следующего раздела рассматриваться как продолжение последнего абзаца предыдущего раздела. |
