## TabStops class

Представляет коллекцию объектов [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/).

Тип TabStops раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TabStops() | Инициализирует новый экземпляр класса TabStops |
## Свойства
| Имя | Описание |
| :- | :- |
| is_read_only | Получает значение, указывающее, что данный экземпляр [TabStops](/pdf/python-net/aspose.pdf.text/tabstops/) уже прикреплен к [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) и стал только для чтения. |
| count | Инициализирует новый экземпляр класса [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) с указанной позицией и <br/>            добавляет его в коллекцию TabStops. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает или задает объект [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) из коллекции по индексу TabStop. |
