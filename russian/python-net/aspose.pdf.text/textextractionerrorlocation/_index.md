## TextExtractionErrorLocation class

Представляет место в документе PDF, где возникла ошибка извлечения текста.

Тип TextExtractionErrorLocation раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| path | Местоположение PDF‑документа, где возникла ошибка извлечения текста. |
| page_number | Номер страницы документа, где обнаружена ошибка извлечения текста. |
| object_type | Тип PDF‑объекта (Page или xForm), в котором обнаружена ошибка извлечения текста из потока содержимого. |
| form_key | Ключ (имя) PDF Form XObject, в котором обнаружена ошибка извлечения текста из потока содержимого. Не пустой, если ObjectType == 'xForm'. |
| operator_index | Индекс оператора отображения текста в потоке содержимого (коллекция операторов), вызывающего ошибку извлечения текста. |
| operator_string | Оператор отображения текста, вызывающий ошибку извлечения текста. |
| font_used_key | Ключ (имя) объекта PDF Font, который используется для отображения оператора, вызывающего ошибку извлечения текста. |
| text_start_point | Ключ (имя) объекта PDF Font, который используется для отображения оператора, вызывающего ошибку извлечения текста. |
