## FontSourceCollection class

Представляет коллекцию источников шрифтов.

Тип FontSourceCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| sync_root | Получает объект, который может использоваться для синхронизации доступа к коллекции. |
| is_synchronized | Получает значение, указывающее, синхронизирован ли доступ к коллекции (потокобезопасный). |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Возвращает элемент шрифта по указанному индексу. |
## Методы
| Имя | Описание |
| :- | :- |
| delete(font_source) | Удаляет элемент источника шрифта. |
