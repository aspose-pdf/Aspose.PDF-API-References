## FontCollection class

Представляет коллекцию шрифтов.

Тип FontCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| sync_root | Получает объект, который может использоваться для синхронизации доступа к коллекции. |
| is_synchronized | Получает значение, указывающее, синхронизирован ли доступ к коллекции (потокобезопасный). |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Возвращает элемент шрифта по указанному индексу. |
## Методы
| Имя | Описание |
| :- | :- |
| add(new_font, res_name) | Добавляет новый шрифт в ресурсы шрифтов и возвращает автоматически присвоенное имя ресурса шрифта. |
