## TextParagraph class

Представляет текстовые абзацы как многострочный объект текста.

Тип TextParagraph раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextParagraph() | Инициализирует новый экземпляр класса TextParagraph |
## Свойства
| Имя | Описание |
| :- | :- |
| vertical_alignment | Получает или задает вертикальное выравнивание текста внутри [прямоугольника](/pdf/python-net/aspose.pdf.text/textparagraph/) абзаца. |
| subsequent_lines_indent | Получает или задает значение отступа последующих строк.<br/>            Если установить ненулевое значение, оно имеет преимущество перед значением FormattingOptions.SubsequentLinesIndent. |
| first_line_indent | Получает или задает значение отступа последующих строк.<br/>            Если установить ненулевое значение, оно имеет преимущество перед значением FormattingOptions.SubsequentLinesIndent. |
| justify | Получает или задает значение, указывающее, выровнен ли текст по ширине. |
| horizontal_alignment | Получает или задает горизонтальное выравнивание текста внутри [прямоугольника](/pdf/python-net/aspose.pdf.text/textparagraph/) абзаца. |
| formatting_options | Получает или задает параметры форматирования. |
| position | Получает или задает позицию абзаца. |
| text_rectangle | Получает прямоугольник текста, размещённого в абзаце. |
| rectangle | Получает или задает прямоугольник абзаца. |
| margin | Получает или задает отступ. |
| rotation | Получает или задает угол вращения в градусах. |
