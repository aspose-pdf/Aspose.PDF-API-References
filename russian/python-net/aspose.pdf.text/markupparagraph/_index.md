## MarkupParagraph class

Представляет абзац.

Тип MarkupParagraph раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| точки | Точки многоугольника, описывающего абзац.<br/>            Начальная точка — нижний левый угол абзаца. Последующие точки идут в порядке против часовой стрелки. |
| вторичные_точки | Точки вторичного многоугольника, описывающего продолжение абзаца. Не будет null, если абзац продолжается в следующей колонке или на странице.<br/>            Начальная точка — нижний левый угол абзаца. Последующие точки идут в порядке против часовой стрелки. |
| номера_страниц_продолжения | Список номеров страниц, на которых продолжается абзац. Он будет совпадать со страницей, где абзац начался, если он продолжается в следующей колонке на той же странице. |
| fragments | Коллекция непустых объектов [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) абзаца. |
| строки | Строки абзаца. Каждая строка представлена списком текстовых фрагментов. |
| text | Получает объект строкового текста, который представляет объект [MarkupParagraph](/pdf/python-net/aspose.pdf.text/markupparagraph/). |
