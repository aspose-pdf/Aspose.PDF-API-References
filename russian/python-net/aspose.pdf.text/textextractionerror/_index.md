## TextExtractionError class

Описывает ошибку извлечения текста, возникшую в документе PDF.

Тип TextExtractionError раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| summary | Краткое описание ошибки. |
| описание | Расширенное описание ошибки. |
| location | Местоположение ошибки. |
| font_key | Ключ (имя PDF) объекта Font, используемого для отображения текста, вызывающего ошибку извлечения. |
| font_name | Читаемое (внутреннее) имя объекта Font, используемого для отображения текста, вызывающего ошибку извлечения. |
| extracted_text | Текст, который был фактически извлечён. |
