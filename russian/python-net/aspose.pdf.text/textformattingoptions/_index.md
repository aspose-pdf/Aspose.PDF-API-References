## TextFormattingOptions class

Представляет параметры форматирования текста

Тип TextFormattingOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextFormattingOptions(wrap_mode) | Инициализирует новый экземпляр класса TextFormattingOptions |
| TextFormattingOptions() | Инициализирует новый экземпляр объекта [TextFormattingOptions](/pdf/python-net/aspose.pdf.text/textformattingoptions/) с неопределенным режимом переноса слов. |
## Свойства
| Имя | Описание |
| :- | :- |
| wrap_mode | Получает или задает режим переноса слов.<br/>            Значение по умолчанию — WordWrapMode.NoWrap |
| line_spacing | Получает или задает режим межстрочного интервала.<br/>            Значение по умолчанию — LineSpacingMode.FontSize |
| hyphen_symbol | Получает или задает символ дефиса, используемый в процессе переноса слов. |
| subsequent_lines_indent | Получает или задает значение отступа последующих строк. |
| first_line_indent | Получает или задает значение отступа первой строки. |
