## Font class

Представляет объект шрифта.

Тип Font раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| font_name | Получает имя шрифта объекта [Font](/pdf/python-net/aspose.pdf.text/font/). |
| decoded_font_name | Иногда шрифты PDF (обычно китайские/японские/корейские) могут иметь специфическое имя шрифта.<br/>            Это имя является значением свойства PDF‑шрифта "BaseFont", и иногда это свойство<br/>            может быть представлено в шестнадцатеричной форме. При прямом чтении этого имени оно может отображаться<br/>            в нечитаемом виде. Чтобы получить читаемую форму, необходимо декодировать имя шрифта по<br/>            правилам, специфичным для данного шрифта. <br/>            Это свойство возвращает декодированное имя шрифта, поэтому используйте его в случаях, когда вы сталкиваетесь <br/>            с нечитаемым [font_name](/pdf/python-net/aspose.pdf.text/font/).<br/>            Если свойство [font_name](/pdf/python-net/aspose.pdf.text/font/) имеет читаемую форму, это свойство будет таким же, как <br/>            [font_name](/pdf/python-net/aspose.pdf.text/font/), так что вы можете использовать его в любых случаях, когда необходимо<br/>            получить имя шрифта в читаемой форме. |
| base_font | Получает значение BaseFont объекта шрифта PDF. Также известен как имя PostScript шрифта. |
| is_embedded | Получает или задает значение, указывающее, встроен ли шрифт.<br/>            Шрифт, основанный на IFont, будет автоматически подмножен и встроен |
| is_subset | Получает или задает значение, указывающее, является ли шрифт подмножеством.<br/>             Шрифт, основанный на IFont, будет автоматически подмножен и встроен |
| is_accessible | Получает информацию о том, присутствует ли шрифт (установлен) в системе. |
| font_options | Полезные свойства для настройки поведения шрифта |
## Методы
| Имя | Описание |
| :- | :- |
| get_last_font_embedding_error() | Цель этого метода — вернуть описание ошибки, если попытка<br/>            встроить шрифт завершилась неудачей. Если ошибок нет, метод возвращает пустую строку. |
| save(stream) | Сохраняет шрифт в поток.<br/>            Обратите внимание, что шрифт сохраняется во промежуточный формат TTF, предназначенный только для использования в преобразованной копии оригинального документа.<br/>            Файл шрифта не предназначен для использования вне контекста оригинального документа. |
| measure_string(str, font_size) | Измеряет строку. |
