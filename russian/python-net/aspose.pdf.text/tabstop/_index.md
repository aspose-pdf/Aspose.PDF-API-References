## TabStop class

Представляет пользовательскую позицию табуляции в абзаце.

Тип TabStop раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TabStop() | Инициализирует новый экземпляр класса [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/). |
| TabStop(position) | Инициализирует новый экземпляр класса TabStop |
## Свойства
| Имя | Описание |
| :- | :- |
| position | Получает или задает значение типа float, указывающее позицию табуляции. |
| leader_type | Получает или задает перечисление [TabLeaderType](/pdf/python-net/aspose.pdf.text/tableadertype/), указывающее тип лидера табуляции. |
| alignment_type | Получает или задает перечисление [alignment_type](/pdf/python-net/aspose.pdf.text/tabstop/), указывающее тип выравнивания табуляции. |
| is_read_only | Получает значение, указывающее, что данный экземпляр [TabStop](/pdf/python-net/aspose.pdf.text/tabstop/) уже прикреплён к [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) и стал только для чтения |
