## FontRepository class

Выполняет поиск шрифтов. Ищет среди системно установленных шрифтов и стандартных PDF‑шрифтов.<br/>             Также предоставляет возможность открывать пользовательские шрифты.

Тип FontRepository раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| FontRepository() | Инициализирует новый экземпляр класса FontRepository. |
## Свойства
| Имя | Описание |
| :- | :- |
| substitutions | Получает коллекцию стратегий замены шрифтов. |
| sources | Получает коллекцию источников шрифтов. |
## Методы
| Имя | Описание |
| :- | :- |
| find_font(font_name) | Ищет и возвращает шрифт с указанным именем. |
| find_font(font_name, ignore_case) | Ищет и возвращает шрифт с указанным именем, игнорируя или учитывая регистр. |
| find_font(font_family_name, stl) | Ищет и возвращает шрифт с указанным именем шрифта и стилем шрифта. |
| find_font(font_family_name, stl, ignore_case) | Ищет и возвращает шрифт с указанным именем шрифта и стилем шрифта <br/>             игнорируя или учитывая чувствительность к регистру. |
| open_font(font_stream, font_type) | Открывает шрифт с указанным потоком шрифта. |
| open_font(font_file_path) | Открывает шрифт с указанным путем к файлу шрифта. |
| open_font(font_file_path, metrics_file_path) | Открывает шрифт с указанным путем к файлу шрифта. |
| load_fonts() | Загружает системные установленные шрифты и стандартные шрифты Pdf. Этот метод был разработан для ускорения процесса загрузки шрифтов.<br/>            По умолчанию шрифты загружаются при первом запросе любого шрифта. Использование этого метода загружает системные и стандартные шрифты Pdf<br/>            сразу перед открытием любого документа Pdf. |
| reload_fonts() | Перезагружает все шрифты, указанные свойством [sources](/pdf/python-net/aspose.pdf.text/fontrepository/) |
