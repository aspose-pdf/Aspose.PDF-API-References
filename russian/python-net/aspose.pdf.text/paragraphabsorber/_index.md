## ParagraphAbsorber class

Представляет объект‑поглотитель структурных объектов страницы, таких как секции и абзацы.<br/>            Выполняет поиск секций и абзацев текста и предоставляет доступ к прямоугольникам и полигонам, описывающим их в координатном пространстве текста. <br/>            Также выполняет поиск текстовых сегментов и предоставляет доступ к результатам поиска через коллекции TextFragments, сгруппированные по структурным элементам.

Тип ParagraphAbsorber раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ParagraphAbsorber() | Инициализирует новый экземпляр [ParagraphAbsorber](/pdf/python-net/aspose.pdf.text/paragraphabsorber/), который выполняет поиск разделов/абзацев документа или страницы. |
| ParagraphAbsorber(sections_search_depth) | Инициализирует новый экземпляр класса ParagraphAbsorber |
## Свойства
| Имя | Описание |
| :- | :- |
| page_markups | Получает коллекцию [PageMarkup](/pdf/python-net/aspose.pdf.text/pagemarkup/), которые были поглощены. |
| sections_search_depth | Получает или задаёт значение, указывающее, сколько раз будут выполнены последовательные поиски более мелких элементов структуры.<br/>            Глубина поиска по умолчанию — 3.<br/>            Это означает три поиска горизонтально разделённых разделов (заголовки, абзацы и т.д.) и три поиска вертикально разделённых (колонки). |
| is_multicolumn_paragraphs_allowed | Получает или задает значение, указывающее, могут ли начальные строки текста следующего раздела рассматриваться как продолжение последнего абзаца предыдущего раздела. |
## Методы

| :- | :- |
