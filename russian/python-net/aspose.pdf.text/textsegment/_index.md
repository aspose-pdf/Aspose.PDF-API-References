## TextSegment class

Представляет сегмент текста PDF.

Тип TextSegment раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextSegment() | Создаёт объект TextSegment. |
| TextSegment(text) | Инициализирует новый экземпляр класса TextSegment |
## Свойства
| Имя | Описание |
| :- | :- |
| start_char_index | Получает начальный индекс символа текущего сегмента в операторе вывода текста (Tj, TJ). |
| end_char_index | Получает конечный индекс символа текущего сегмента в операторе вывода текста (Tj, TJ). |
| text | Получает или задает объект строкового текста, который представляет объект [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| text_state | Получает или задает состояние текста для текста, который представляет объект [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| position | Получает позицию текста, представленного объектом [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/). |
| rectangle | Получает прямоугольник TextSegment |
| baseline_position | Получает позицию текста, представленного объектом [TextSegment](/pdf/python-net/aspose.pdf.text/textsegment/).<br/>            YIndent структуры Position представляет координату базовой линии текстового сегмента. |
| text_edit_options | Получает или задает параметры редактирования текста. Параметры определяют особое поведение, когда запрашиваемый символ нельзя отобразить выбранным шрифтом. |
| символы | Получает коллекцию объектов CharInfo, представляющих информацию о символах в текстовом сегменте. |
| hyperlink | Получает или задает гиперссылку сегмента (для генератора PDF). |
## Методы
| Имя | Описание |
| :- | :- |
| my_html_encode(value) | Кодирует строку как HTML. |
