## TextFragmentState class

Представляет состояние текста текстового фрагмента.

Тип TextFragmentState раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextFragmentState(fragment) | Инициализирует новый экземпляр класса TextFragmentState |
## Свойства
| Имя | Описание |
| :- | :- |
| character_spacing | Получает или задает межсимвольный интервал текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| line_spacing | Получает или задает межстрочный интервал текста. |
| horizontal_scaling | Получает или задает горизонтальное масштабирование текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| subscript | Получает или задает подстрочный стиль текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| superscript | Получает или задает надстрочный стиль текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| word_spacing | Получает или задает интервал между словами текста. |
| невидимый | Получает или задает невидимость текста. |
| rendering_mode | Получает или задает режим отрисовки текста. |
| font_size | Получает или задает размер шрифта текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font | Получает или задает шрифт текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| foreground_color | Получает или задает цвет переднего плана текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| stroking_color | Получает или задает цвет операций штриховки при рендеринге [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) (обводка текста, граница прямоугольника) |
| underline | Получает или задает подчеркивание текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| strike_out | Устанавливает зачеркивание текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/). |
| background_color | Задает цвет фона текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| font_style | Задает стиль шрифта текста, представленного объектом [TextFragment](/pdf/python-net/aspose.pdf.text/textfragment/) |
| horizontal_alignment | Получает или задает горизонтальное выравнивание текста. |
| TAB_TAG | Вы можете разместить этот тег в тексте, чтобы объявить табуляцию. |
| TABSTOP_DEFAULT_VALUE | Значение табуляции по умолчанию в ширине символа пробела шрифта по умолчанию. |
| tab_stops | Получает табуляционные позиции текста. |
| formatting_options | Получает или задает параметры форматирования.<br/>            Установка параметров будет действовать только в сценариях генератора. |
| rotation | Получает или задает угол вращения в градусах. |
| draw_text_rectangle_border | Получает или задает флаг отрисовки границы прямоугольника текста. |
