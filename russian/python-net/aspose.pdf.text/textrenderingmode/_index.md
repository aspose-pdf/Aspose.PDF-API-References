## TextRenderingMode enumeration

Режим рендеринга текста, Tmode, определяет, будет ли отображение текста вызывать обводку контуров глифов, их заполнение, использование в качестве границы обрезки или комбинацию этих трех действий.

## Members
| Имя члена | Описание |
| :- | :- |
| FILL_TEXT | Заполняет текст. |
| STROKE_TEXT | Обводит текст. |
| FILL_THEN_STROKE_TEXT | Заполняет, затем обводит текст. |
| INVISIBLE | Текст не заполняется и не обводится (невидимый). |
| FILL_TEXT_AND_ADD_PATH_TO_CLIPPING | Заполняет текст и добавляет его в путь для обрезки (см. 9.3.6, "Text Rendering Mode,"). |
| STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Обводит текст и добавляет его в путь для обрезки. |
| FILL_THEN_STROKE_TEXT_AND_ADD_PATH_TO_CLIPPING | Заполняет, затем обводит текст и добавляет его в путь для обрезки. |
| ADD_PATH_TO_CLIPPING | Добавляет текст в путь для обрезки. |
