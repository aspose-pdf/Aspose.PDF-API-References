## TextEditOptions class

Описывает параметры операций редактирования текста.

Тип TextEditOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextEditOptions(no_character_behavior) | Инициализирует новый экземпляр класса TextEditOptions |
| TextEditOptions(font_replace_behavior) | Инициализирует новый экземпляр класса TextEditOptions |
| TextEditOptions(allow_language_transformation) | Инициализирует новый экземпляр класса TextEditOptions |
| TextEditOptions(language_transformation_behavior) | Инициализирует новый экземпляр класса TextEditOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| replacement_font | Получает или задает шрифт, используемый для замены, если пользовательский шрифт не содержит требуемый символ |
| no_character_behavior | Получает или задает режим, определяющий поведение в случае, если шрифты не содержат запрошенные символы. |
| font_replace_behavior | Получает режим, определяющий поведение в сценариях замены шрифтов. |
| allow_language_transformation | Получает или задает значение, позволяющее использовать трансформацию языка при добавлении или редактировании текста.<br/>            true - трансформация языка будет применена при необходимости (значение по умолчанию).<br/>            false - трансформация языка НЕ будет применена. |
| language_transformation_behavior | Получает режим, определяющий поведение для сценариев трансформации языка. |
| clipping_paths_processing | Получает режим обработки обрезающего пути отредактированного текста. |
| to_attempt_get_underline_from_source | Получает или задает значение, позволяющее искать подчеркивание текста на странице исходного документа.<br/>            (Устарело) Пожалуйста, используйте TextSearchOptions.SearchForTextRelatedGraphics вместо этого. |
