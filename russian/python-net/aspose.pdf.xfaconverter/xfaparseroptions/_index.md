## XfaParserOptions class

класс для обработки инкапсуляции связанных данных

Тип XfaParserOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| XfaParserOptions(page_size) | Инициализирует новый экземпляр класса XfaParserOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| page_size | Получает или задаёт размер страницы. |
| подписан | Если это свойство истинно, документ будет конвертирован с использованием потока формы xfa (если он существует).<br/>            Если оно ложно, поток формы xfa будет игнорироваться.<br/>            Это свойство было введено, потому что не ясно, как вычислить контрольную сумму, используемую для проверки подписи. |
| emulate_requierd_groups | Если это свойство истинно, будут нарисованы дополнительные красные прямоугольники для требуемых Xfa "исключённых групп"<br/>            Это свойство было введено из‑за отсутствия аналогов исключённых групп при конвертации представления форм Xfa <br/>            в стандарт.<br/>            По умолчанию оно ложно. |
| base_path | Получает или задаёт базовый путь. |
