## IPdfTypeExtractor class

Представляет интерфейс для взаимодействия с извлекательом.

Тип IPdfTypeExtractor раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| page_count | Возвращает количество страниц. |
| version | Возвращает версию. |
| is_fast_extraction_used | Возвращает, использовался ли быстрый механизм извлечения. |
## Методы
| Имя | Описание |
| :- | :- |
| extract_all_text() | Возвращает коллекцию извлечённых текстовых значений. |
| extract_page_text(page_number) | Возвращает текст страницы. |
| dispose() | Освободить. |
