## ViewerPreference class

Описывает настройки просмотрщика (режим страницы, режим не во весь экран, компоновка страниц).

Тип ViewerPreference предоставляет следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ViewerPreference() | Инициализирует новый экземпляр класса ViewerPreference |
## Свойства
| Имя | Описание |
| :- | :- |
| PAGE_MODE_USE_OC | Панель группы необязательного содержимого видима. |
| DISPLAY_DOC_TITLE | Флаг, указывающий, должно ли заголовок окна отображать название документа. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OC | Панель группы необязательного содержимого видима. |
| PAGE_LAYOUT_SINGLE_PAGE | Отображать одну страницу за раз. |
| PAGE_LAYOUT_ONE_COLUMN | Отображать страницы в один столбец. |
| PAGE_LAYOUT_TWO_COLUMN_LEFT | Отображать страницы в двух колонках, при этом нечётные страницы находятся справа |
| PAGE_LAYOUT_TWO_COLUMN_RIGHT | Отображать страницы в двух колонках, при этом нечётные страницы находятся справа. |
| PAGE_MODE_USE_NONE | Ни оглавление документа, ни миниатюры не видны |
| PAGE_MODE_USE_OUTLINES | Оглавление документа видно. |
| PAGE_MODE_USE_THUMBS | Миниатюры видны. |
| PAGE_MODE_FULL_SCREEN | Полноэкранный режим без панели меню, элементов управления окном или любого другого видимого окна. |
| PAGE_MODE_USE_ATTACHMENT | Режим страницы с вложениями. |
| HIDE_TOOLBAR | Флаг, указывающий, следует ли скрывать панели инструментов совместимого просмотрщика, когда документ активен. |
| HIDE_MENUBAR | Флаг, указывающий, следует ли скрывать строку меню совместимого просмотрщика, когда документ активен. |
| HIDE_WINDOW_UI | Флаг, указывающий, следует ли скрывать элементы пользовательского интерфейса в окне документа (например, полосы прокрутки и элементы навигации), оставляя отображённым только содержимое документа. |
| FIT_WINDOW | Флаг, указывающий, следует ли изменить размер окна документа, чтобы он соответствовал размеру первой отображаемой страницы. |
| CENTER_WINDOW | Флаг, указывающий, следует ли разместить окно документа в центре экрана. |
| NON_FULL_SCREEN_PAGE_MODE_USE_NONE | Ни контур документа, ни миниатюры не видны. |
| NON_FULL_SCREEN_PAGE_MODE_USE_OUTLINES | Оглавление документа видно. |
| NON_FULL_SCREEN_PAGE_MODE_USE_THUMBS | Миниатюры видны |
| DIRECTION_L2R | Порядок чтения текста слева направо. |
| DIRECTION_R2L | Порядок чтения текста справа налево. |
| SIMPLEX | Печать односторонняя. |
| DUPLEX_FLIP_SHORT_EDGE | Дуплекс с переворотом по короткому краю листа. |
| DUPLEX_FLIP_LONG_EDGE | Дуплекс с переворотом по короткому краю листа. |
