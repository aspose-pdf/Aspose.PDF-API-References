## PositioningMode enumeration

Определяет режим позиционирования.<br/>            Возможные значения включают Legacy (обратная совместимость) и <br/>            Current (обновлённый метод расчёта позиции текста)

## Members
| Имя члена | Описание |
| :- | :- |
| LEGACY | Устаревшее позиционирование текста |
| MODERN_LINE_SPACING | Обновленное межстрочное расстояние, вычисление вертикального положения выполняется по старым правилам <br/>            (т.е. текст позиционируется относительно нижнего левого угла указанного прямоугольника) |
| CURRENT | Обновленное межстрочное расстояние и вычисление вертикального положения выполняются относительно верхнего левого угла, а не нижнего левого. |
