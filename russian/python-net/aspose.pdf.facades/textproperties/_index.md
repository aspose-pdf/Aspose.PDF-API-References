## TextProperties class

Представляет свойства текста, такие как размер, цвет, стиль и т.д.

Тип TextProperties раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextProperties(text_size) | Инициализирует новый экземпляр класса TextProperties |
## Свойства
| Имя | Описание |
| :- | :- |
| цвет | Получает или задает цвет текста. |
| is_color_specified | Получает или задает значение, указывающее, указано ли свойство [color](/pdf/python-net/aspose.pdf.facades/textproperties/). |
| text_size | Получает или задает размер текста. |
| is_text_size_specified | Получает или задает значение, указывающее, указано ли свойство [text_size](/pdf/python-net/aspose.pdf.facades/textproperties/). |
