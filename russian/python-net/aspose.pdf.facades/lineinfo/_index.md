## LineInfo class

Представляет информацию о линии.

Тип LineInfo раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| LineInfo() | Инициализирует новый экземпляр класса LineInfo |
## Свойства
| Имя | Описание |
| :- | :- |
| vertice_coordinate | Получает или задает массив чисел, представляющих попеременно горизонтальные и вертикальные координаты, соответственно, каждой вершины. |
| line_color | Получает или задает цвет линии. |
| line_width | Получает или задает ширину линии. |
| visibility | Получает или задает видимость линии. |
| line_dash_pattern | Получает или задает шаблон штриховки линии. |
| border_style | Получает или задает стиль границы линии, 0 обозначает сплошную, 1 — пунктирную, 2 — beleved, 3 — insert, 4 — underline. |
