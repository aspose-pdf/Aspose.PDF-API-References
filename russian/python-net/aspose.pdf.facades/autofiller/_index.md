## AutoFiller class

Представляет класс для получения данных из базы данных или другого источника данных, заполняет их в разработанные поля шаблонного pdf и в конце генерирует новый pdf‑файл или поток.<br/>             Имеет два режима ввода шаблонного файла: ввод как поток или pdf‑файл.<br/>             Имеет четыре типа режимов вывода: один объединённый поток, один объединённый файл, множество небольших потоков, множество небольших файлов.<br/>             Может принимать буквальные данные, содержащиеся в System.Data.DataTable.
