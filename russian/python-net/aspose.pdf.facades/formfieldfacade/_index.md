## FormFieldFacade class

Класс для представления свойств поля.

Тип FormFieldFacade раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| FormFieldFacade() | Инициализирует новый экземпляр класса FormFieldFacade |
## Свойства
| Имя | Описание |
| :- | :- |
| border_color | Цвет границы поля. |
| border_style | Стиль границы поля. |
| border_width | Ширина границы поля. |
| font | Тип шрифта текста поля. |
| custom_font | Получает или задает имя шрифта, когда он нестандартный (отличный от 14 стандартных шрифтов). |
| font_size | Размер текста поля. |
| text_color | Цвет текста поля. |
| text_encoding | Тип кодировки текста поля. |
| выравнивание | Выравнивание текста поля, по умолчанию — выравнивание по левому краю. |
| rotation | Поворот текста поля. |
| caption | Обычная подпись поля формы. |
| button_style | Стиль поля флажка или переключателя, определенный в FormFieldFacade.CheckBoxStyle*. |
| box | Объект прямоугольника, содержащий расположение поля. |
| position | Объект прямоугольника, содержащий расположение поля. |
| page_number | Целочисленное значение, содержащее номер страницы, на которой находится поле. |
| items | Массив строк, каждая из которых представляет вариант поля выпадающего списка/списка/переключателя. |
| export_items | Опции для добавления списка/выпадающего списка/переключателя |
| background_color | Цвет фона поля, по умолчанию — белый. |
| backgroud_color | Устаревшее свойство. Используйте BackgroundColor. |
| BORDER_WIDTH_UNDIFIED | Неопределённая ширина границы. |
| BORDER_WIDTH_UNDEFINED | Неопределённая ширина границы. |
| BORDER_WIDTH_THIN | Определяет тонкую ширину границы. |
| BORDER_WIDTH_MEDIUM | Определяет среднюю ширину границы. |
| BORDER_WIDTH_THICK | Определяет большую ширину границы. |
| BORDER_STYLE_SOLID | Определяет сплошной стиль границы. |
| BORDER_STYLE_DASHED | Определяет пунктирный стиль границы. |
| BORDER_STYLE_BEVELED | Определяет фасетный стиль границы. |
| BORDER_STYLE_INSET | Определяет вложенный стиль границы. |
| BORDER_STYLE_UNDERLINE | Определяет подчеркивающий стиль границы. |
| BORDER_STYLE_UNDEFINED | Неопределённый стиль границы. |
| ALIGN_LEFT | Определяет выравнивание по левому стилю. |
| ALIGN_CENTER | Определяет выравнивание по центру. |
| ALIGN_RIGHT | Определяет выравнивание по правому краю. |
| ALIGN_UNDEFINED | Неопределённый стиль выравнивания. |
| ALIGN_JUSTIFIED | Определяет стиль выравнивания текста по ширине. |
| ALIGN_TOP | Определяет вертикальное выравнивание по верхнему краю. |
| ALIGN_MIDDLE | Определяет вертикальное выравнивание по центру. |
| ALIGN_BOTTOM | Определяет вертикальное выравнивание по нижнему краю. |
| CHECK_BOX_STYLE_CIRCLE | Определяет стиль флажка в виде круга. |
| CHECK_BOX_STYLE_CHECK | Определяет форму поля флажка, когда он отмечен. |
| CHECK_BOX_STYLE_CROSS | Определяет стиль флажка в виде крестика. |
| CHECK_BOX_STYLE_DIAMOND | Определяет стиль флажка в виде ромба. |
| CHECK_BOX_STYLE_STAR | Определяет стиль флажка в виде звезды. |
| CHECK_BOX_STYLE_SQUARE | Определяет стиль квадратного флажка. |
| CHECK_BOX_STYLE_UNDEFINED | Определяет неопределённый стиль флажка. |
