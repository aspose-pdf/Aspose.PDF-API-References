## ISaveableFacade class

Фасадный интерфейс, определяющий методы, общие для всех сохраняемых фасадов.

Тип ISaveableFacade раскрывает следующие члены:
## Методы
| Имя | Описание |
| :- | :- |
| save(dest_file) | Сохраняет полученный документ PDF в файл. |
| save(dest_stream) | Сохраняет полученный документ PDF в поток. |
| bind_pdf(src_file) | Привязывает PDF-документ для редактирования. |
| bind_pdf(src_stream) | Привязывает PDF-документ для редактирования. |
| bind_pdf(src_doc) | Привязывает PDF-документ для редактирования. |
| close() | Освобождает любые ресурсы, связанные с текущим фасадом. |
