## StampInfo class

Класс, представляющий информацию о штампе.

Тип StampInfo раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| stamp_id | Получает идентификатор штампа. |
| index_on_page | Получает индекс штампа на странице. |
| stamp_type | Получает тип штампа (изображение / форма). |
| rectangle | Получает прямоугольник, в котором размещен штамп. |
| image | Получает изображение штампа. Может быть null, если штамп не содержит изображений (например, для текстового штампа). |
| форма | Получает XForm штампа. |
| text | Получает текст в штампе. |
| видимый | Получает видимость штампа. Если false, то штамп скрыт (с помощью HideStampById). Скрытый штамп может быть восстановлен с помощью ShowStampById. |
