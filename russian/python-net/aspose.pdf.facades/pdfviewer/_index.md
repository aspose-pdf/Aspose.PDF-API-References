## PdfViewer class

Представляет класс для просмотра или печати pdf.

Тип PdfViewer раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PdfViewer() | Инициализирует новый объект [PdfViewer](/pdf/python-net/aspose.pdf.facades/pdfviewer/). |
| PdfViewer(document) | Инициализирует новый экземпляр класса PdfViewer |
## Свойства
| Имя | Описание |
| :- | :- |
| show_hidden_areas | Получает или задает флаг, контролирующий видимость скрытых областей на странице. |
| print_status | Получает результат задания печати. Если успешно, то null; иначе объект исключения. |
| use_intermidiate_image | Получает/задает использование конвертации страницы pdf в промежуточный png‑файл во время печати в файловом режиме. Используйте это, когда важен размер выходного файла. |
| coordinate_type | Получает или задает тип координат страницы (Media/Crop коробки). Значение CropBox используется по умолчанию. |
| print_as_image | Устанавливает или получает режим печати PdfViewer в виде изображения. |
| page_count | Получает количество страниц текущего PDF‑файла. |
| password | Получает или задает пароль входного документа. |
| print_page_dialog | Получает или задает логическое значение, указывающее, выводить ли диалог номера страницы при печати. |
| print_as_grayscale | Получает или задает логическое значение, указывающее, печатается ли страница в градациях серого. По умолчанию false. |
| printer_job_name | Получает или задает имя документа в очереди принтера при печати документа. Значение по умолчанию — имя файла. |
| form_presentation_mode | Получает или задает режим представления формы. |
| rendering_options | Получает или задает параметры рендеринга. |
| vertical_alignment | Получает или задает значение, указывающее вертикальное выравнивание |
| horizontal_alignment | Получает или задает значение, указывающее горизонтальное выравнивание |
| auto_resize | Получает или задает логическое значение, указывающее, будет ли файл печататься с оптимизированным размером. |
| auto_rotate | Получает или задает логическое значение, указывающее, будет ли файл печататься с автоматическим вращением. |
| auto_rotate_mode | Получает или задает значение AutoRotateMode, указывающее направление вращения |
| resolution | Получает или задает разрешение при просмотре и печати. Чем выше разрешение, тем ниже скорость. Значение по умолчанию — 150. |
| scale_factor | Получает или задает значение с плавающей точкой, указывающее коэффициент масштабирования. Значение по умолчанию — 1.0. |
