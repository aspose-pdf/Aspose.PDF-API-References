## PdfFileSecurity class

Представляет шифрование или дешифрование Pdf‑файла с паролем владельца или пользователя, изменение параметров безопасности и пароля.

Тип PdfFileSecurity раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PdfFileSecurity(input_stream, output_stream) | Инициализирует новый экземпляр класса PdfFileSecurity |
| PdfFileSecurity(input_file, output_file) | Инициализирует новый экземпляр класса PdfFileSecurity |
| PdfFileSecurity() | Инициализировать объект PdfFileSecurity. |
| PdfFileSecurity(document) | Инициализирует новый экземпляр класса PdfFileSecurity |
| PdfFileSecurity(document, output_file) | Инициализирует новый экземпляр класса PdfFileSecurity |
| PdfFileSecurity(document, output_stream) | Инициализирует новый экземпляр класса PdfFileSecurity |
## Свойства
| Имя | Описание |
| :- | :- |
| document | Получает фасад документа, над которым работает. |
| allow_exceptions | Если это значение установлено в true, при сбое операции будет выброшено исключение. В противном случае метод возвращает false при ошибке, и последнее исключение можно проверить с помощью свойства LastException. |
