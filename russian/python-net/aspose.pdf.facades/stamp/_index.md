## Stamp class

Класс, представляющий штамп.

Тип Stamp раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Stamp() | Инициализирует новый экземпляр класса Stamp |
## Свойства
| Имя | Описание |
| :- | :- |
| stamp_id | Получает или задает идентификатор штампа. |
| качество | Получает или задает качество изображения штампа в процентах. Допустимые значения 0..100%. |
| непрозрачность | Получает или задает непрозрачность штампа. |
| page_number | Получает или задает номер страницы. |
| страницы | Получает или задает массив номеров страниц, которые будут затронуты штампом. <br/>            Если Pages = null, все страницы документа будут затронуты. |
| rotation | Получает или задает вращение штампа в градусах. |
| is_background | Получает или задает статус фона. Если true, штамп будет размещён как фон спаммированной страницы.<br/>            По умолчанию установлено значение false. |
| blending_space | Получает или задает значение BlendingColorSpace, определяющее цветовое пространство <br/>            которое используется для выполнения операций прозрачности и смешивания на странице. |
## Методы
| Имя | Описание |
| :- | :- |
| bind_pdf(pdf_file, page_number) | Устанавливает PDF‑файл и номер страницы, которые будут использоваться в качестве штампа. |
| bind_pdf(pdf_stream, page_number) | Устанавливает PDF‑файл и номер страницы, которые будут использоваться в качестве штампа. |
| bind_image(image_file) | Устанавливает изображение в качестве штампа. |
| bind_image(image) | Устанавливает изображение, которое будет использоваться в качестве штампа. |
| bind_logo(formatted_text) | Устанавливает текст в качестве штампа. |
| bind_text_state(text_state) | Устанавливает состояние текста штампа. |
| set_origin(origin_x, origin_y) | Устанавливает позицию на странице, где будет размещена печать. |
| set_image_size(width, height) | Устанавливает размер штампа изображения. Изображение будет масштабировано в соответствии с указанными значениями. |
