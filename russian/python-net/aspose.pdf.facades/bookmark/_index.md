## Bookmark class

Представляет закладку.

Тип Bookmark раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Bookmark() | Инициализирует новый экземпляр класса Bookmark |
## Свойства
| Имя | Описание |
| :- | :- |
| action | Получает или задает действие, связанное с закладкой.<br/>            Если указано PageNumber, действие не может быть задано.<br/>            Типы действий включают: "GoTo", "GoToR", "Launch", "Named". |
| bold_flag | Получает или задает флаг жирного начертания заголовка закладки. |
| child_item | Получает или задает дочерние элементы закладки. |
| child_items | Получает или задает дочерние элементы закладки. |
| назначение | Получает или задает страницу назначения закладки. Требуется, если действие установлено как string.Empty. |
| italic_flag | Получает или задает флаг наклона заголовка закладки. |
| level | Получает или задает уровень иерархии закладки. |
| page_display | Получает или задает тип отображения страницы назначения закладки. |
| page_display_bottom | Получает или задает нижнюю координату отображения страницы. |
| page_display_left | Получает или задает левую координату отображения страницы. |
| page_display_right | Получает или задает правую координату отображения страницы. |
| page_display_top | Получает или задает верхнюю координату отображения страницы. |
| page_display_zoom | Получает или задает коэффициент масштабирования отображения страницы. |
| page_number | Получает или задает номер страницы назначения закладки. |
| remote_file | Получает или задает файл (путь), который требуется для действия "GoToR" закладки. |
| title | Получает или задает заголовок закладки. |
| title_color | Получает или задает цвет заголовка закладки. |
| открыть | Получает или задает состояние закладки (открыта, закрыта). |
