## PdfPageEditor class

Представляет класс для редактирования страниц PDF‑файла, включая вращение страницы, масштабирование, перемещение положения и изменение размера страницы.

Тип PdfPageEditor предоставляет следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PdfPageEditor() | Конструктор для класса PdfPageEditor. |
| PdfPageEditor(document) | Инициализирует новый экземпляр класса PdfPageEditor |
## Свойства
| Имя | Описание |
| :- | :- |
| document | Получает фасад документа, над которым работает. |
| transition_duration | Получает или задает длительность эффекта перехода. |
| transition_type | Получает или задает стиль перехода, используемый при переходе к этой странице с другой во время презентации. |
| display_duration | Получает или задает длительность отображения страниц. |
| process_pages | Получает или задает номера страниц для редактирования. По умолчанию будет редактироваться каждая страница. |
| rotation | Получает или задает вращение страниц, вращение должно быть 0, 90, 180 или 270.<br/>            Значение по умолчанию — 0. |
| zoom | Получает или задает коэффициент масштабирования. Значение 1.0 соответствует 100%.<br/>            Значение по умолчанию — 1.0. |
| page_size | Получает или задает размер страницы выходного файла. |
| выравнивание | Получает или задает горизонтальное выравнивание оригинального содержимого PDF на результирующей странице, значение по умолчанию — AlignmentType.Left. |
| horizontal_alignment | Получает или задает горизонтальное выравнивание оригинального содержимого PDF на результирующей странице, значение по умолчанию — AlignmentType.Left. |
| vertical_alignment | Получает или задает вертикальное выравнивание оригинального содержимого PDF на результирующей странице, значение по умолчанию — VerticalAlignmentType.Bottom. |
| vertical_alignment_type | Получает или задает вертикальное выравнивание оригинального содержимого PDF на результирующей странице, значение по умолчанию — VerticalAlignmentType.Bottom. |
| SPLITVOUT | Вертикальное разделение наружу |
| SPLITHOUT | Горизонтальное разделение наружу |
| SPLITVIN | Вертикальное разделение внутрь |
| SPLITHIN | Горизонтальное разделение внутрь |
| BLINDV | Вертикальные жалюзи |
| BLINDH | Вертикальные жалюзи |
| INBOX | Внутренний ящик |
| OUTBOX | Внешний ящик |
| LRWIPE | Смахивание слева направо |
| RLWIPE | Смахивание справа налево |
| BTWIPE | Стирание снизу‑вверх |
| TBWIPE | Стирание сверху‑вниз |
| РАСТАВРЕНИЕ | Старая страница растворяется |
| LRGLITTER | Блестки слева‑направо |
| TBGLITTER | Блестки сверху‑вниз |
| DGLITTER | Диагональные блестки |
## Методы
| Имя | Описание |
| :- | :- |
| bind_pdf(src_file) | Привязывает PDF-документ для редактирования. |
| bind_pdf(src_stream) | Привязывает PDF-документ для редактирования. |
| bind_pdf(src_doc) | Привязывает PDF-документ для редактирования. |
| save(output_file) | Сохраняет изменённый документ в файл. |
| save(output_stream) | Сохраняет изменённый документ в поток. |

| get_page_rotation(page) | Возвращает поворот указанной страницы. |
| get_page_box_size(page, page_box_name) | Возвращает размер указанного блока в документе. |
| apply_changes() | Применяет изменения, внесённые в страницы документа. |
