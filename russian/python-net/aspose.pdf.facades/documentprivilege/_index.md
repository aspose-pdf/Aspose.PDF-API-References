## DocumentPrivilege class

Представляет привилегии для доступа к файлу Pdf. См. [PdfFileSecurity](/pdf/python-net/aspose.pdf.facades/pdffilesecurity/).<br/>             Существует 4 способа использования этого класса:<br/>             1. Использовать предопределённую привилегию напрямую.<br/>             2. На основе предопределённой привилегии изменить некоторые специфические разрешения.<br/>             3. На основе предопределённой привилегии изменить комбинацию специфических разрешений Adobe Professional.<br/>             4. Сочетает способ 2 и способ 3.

Тип DocumentPrivilege раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| allow_print | Устанавливает разрешение, позволяющее печать или нет. <br/>            true — разрешено, false — запрещено. |
| allow_degraded_printing | Устанавливает разрешение, позволяющее ухудшённую печать или нет. <br/>            true — разрешено, false — запрещено. |
| allow_modify_contents | Устанавливает разрешение, позволяющее изменять содержимое или нет. <br/>            true — разрешено, false — запрещено. |
| allow_copy | Устанавливает разрешение, позволяющее копировать или нет. <br/>            true — разрешено, false — запрещено. |
| allow_modify_annotations | Устанавливает разрешение, позволяющее изменять аннотации или нет. <br/>            true — разрешено, false — запрещено. |
| allow_fill_in | Устанавливает разрешение, позволяющее заполнять формы или нет. <br/>            true — разрешено, false — запрещено. |
| allow_screen_readers | Устанавливает разрешение, позволяющее использовать программы чтения с экрана или нет. <br/>            true — разрешено, false — запрещено. |
| allow_assembly | Устанавливает разрешение, позволяющее сборку или нет. <br/>            true — разрешено, false — запрещено. |
| degraded_printing | Разрешает ухудшённую печать. |
| print | Разрешает печать файла. |
| modify_contents | Разрешает изменение файла. |
| copy | Разрешает копировать файл. |
| modify_annotations | Разрешает изменять аннотации файла. |
| fill_in | Разрешает заполнять формы в файле. |
| screen_readers | Разрешает только чтение на экране. |
| assembly | Разрешает сборку файла. |
| allow_all | Все разрешено. |
| forbid_all | Все запрещено. |
