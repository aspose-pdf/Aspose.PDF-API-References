## Свойства
| Имя | Описание |
| :- | :- |
| document | Получает фасад документа, над которым работает. |
| import_result | Результат последней операции импорта. Массив объектов, описывающих результат импорта для каждого поля. |
| src_file_name | Получает или задает имя исходного файла. |
| dest_file_name | Получает или задает имя целевого файла. |
| src_stream | Получает или задает исходный поток. |
| dest_stream | Получает или задает поток назначения. |
| field_names | Получает список имен полей в форме. |
| form_submit_button_names | Получает все имена кнопок отправки формы. |
