## SaveableFacade class

Базовый класс для всех сохраняемых фасадов.

Тип SaveableFacade раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| document | Получает фасад документа, над которым работает. |
## Методы
| Имя | Описание |
| :- | :- |
| bind_pdf(src_file) | Инициализирует фасад. |
| bind_pdf(src_stream) | Инициализирует фасад. |
| bind_pdf(src_doc) | Инициализирует фасад. |
| save(dest_file) | Сохраняет документ PDF в указанный файл. |
| save(dest_stream) | Сохраняет документ PDF в указанный поток. |
