## OptimizationOptions class

Класс, описывающий алгоритм оптимизации документа.<br/>            Экземпляр этого класса может использоваться в качестве параметра метода OptimizeResources().

Тип OptimizationOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| OptimizationOptions() | Инициализирует новый экземпляр класса OptimizationOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| link_duplcate_streams | Если этот флаг установлен в true, потоки ресурсов будут проанализированы. Если найдены дублирующие потоки (т.е. содержимое потоков одинаково), эти потоки будут сохранены как один объект. <br/>            Это позволяет уменьшить размер документа в некоторых случаях (например, когда один и тот же документ был объединён несколько раз). |
| allow_reuse_page_content | Если true, содержимое страниц будет переиспользовано при оптимизации документа для одинаковых страниц. |
| remove_unused_streams | Если этот флаг установлен в true, каждый ресурс проверяется на использование. Если ресурс никогда не используется, он удаляется.<br/>            Это может уменьшить размер документа, например, когда страницы были извлечены из документа. |
| remove_unused_objects | Если этот флаг установлен в true, все объекты документа будут проверены, и неиспользуемые объекты (т.е. объекты, не имеющие ссылок) удаляются из документа. |
| image_compression_options | Набор параметров, описывающих, будут ли изображения в документе сжаты, и параметры сжатия. |
| compress_images | Если этот флаг установлен в true, изображения будут сжаты в документе. Уровень сжатия указывается свойством ImageQuality. |
| resize_images | Если этот флаг установлен в true и CompressImages также true, изображения будут изменены в размере, если их разрешение превышает указанный параметр MaxResolution. |
| image_quality | Указывает уровень сжатия изображения, когда используется флаг CompressIamges. |
| max_resoultion | Указывает максимальное разрешение изображений. Если изображение имеет более высокое разрешение, оно будет масштабировано. |
| unembed_fonts | Сделать шрифты не встраиваемыми, если установлен в true. |
| subset_fonts | Шрифты будут преобразованы в подмножества, если установлен в true. |
| remove_private_info | Удалить личную информацию (информация о частях страниц). |
| image_encoding | Кодировка изображения, которая будет использована. |
## Методы
| Имя | Описание |
| :- | :- |
| all() | Создаёт стратегию оптимизации со всеми активированными параметрами.<br/>            Обратите внимание, что активируются только те параметры, которые не изменяют функциональность документа.<br/>            Т.е. сжатие изображений и отключение встраивания шрифтов не будет включено (и их можно включить вручную). |
