## ImageCompressionOptions class

Класс содержит набор параметров для сжатия изображений.

Тип ImageCompressionOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ImageCompressionOptions() | Инициализирует новый экземпляр класса ImageCompressionOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| compress_images | Если этот флаг установлен в true, изображения будут сжаты в документе. Уровень сжатия указывается свойством ImageQuality. |
| resize_images | Если этот флаг установлен в true и CompressImages также true, изображения будут изменены в размере, если их разрешение превышает указанный параметр MaxResolution. |
| image_quality | Указывает уровень сжатия изображения, когда используется флаг CompressIamges. |
| max_resolution | Указывает максимальное разрешение изображений. Если изображение имеет более высокое разрешение, оно будет масштабировано. |
| version | Версия алгоритма сжатия. Возможные значения: 1. стандартное сжатие, 2. быстрое (улучшенное сжатие, которое быстрее, чем стандартное, но может быть неприменимо не ко всем изображениям), 3. смешанное (стандартное сжатие применяется к изображениям, которые нельзя сжать более быстрым алгоритмом; это может дать лучшее сжатие, но работает медленнее, чем алгоритм "fast". Версия "Fast" не применима для изменения размеров изображений (будет использован стандартный метод). По умолчанию — "Standard".) |
| кодировка | Получает или задает кодировку, используемую для хранения изображений. |
