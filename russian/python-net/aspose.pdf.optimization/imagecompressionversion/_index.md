## ImageCompressionVersion enumeration

Описывает версии алгоритма сжатия изображений.

## Members
| Имя члена | Описание |
| :- | :- |
| STANDARD | Стандартный алгоритм. Значение по умолчанию. |
| FAST | Улучшенный алгоритм, быстрее стандартного, но применим не во всех случаях. |
| MIXED | Использовать быстрый алгоритм, когда это возможно, и стандартный в остальных случаях. Может быть медленнее, чем "Fast", но может обеспечить лучшую компрессию. |
