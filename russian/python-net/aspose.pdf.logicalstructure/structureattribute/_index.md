## StructureAttribute class

Представляет атрибут элемента структуры.

Тип StructureAttribute раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| StructureAttribute(attribute_key) | Инициализирует новый экземпляр класса StructureAttribute |
## Свойства
| Имя | Описание |
| :- | :- |
| key | Получает ключ атрибута. |
| is_initialized_value | Получает статус значения атрибута структуры. Истина, если значение установлено. |
## Методы
| Имя | Описание |
| :- | :- |
| get_name_value() | Получает значение имени. |
| get_string_value() | Получает значение строки. |
| get_number_value() | Получает числовое значение. |
| get_array_value() | Получает массив имён. |
| get_array_number_value() | Получает массив чисел. |
| set_name_value(name) | Устанавливает значение имени. |
| set_string_value(value) | Устанавливает значение строки. |
| set_number_value(number) | Устанавливает числовое значение. |
| set_array_value(array) | Устанавливает массив имён. |
| set_array_number_value(array_number) | Устанавливает массив чисел. |
| set_color_value(color) | Устанавливает значение цвета. |
| set_rectangle_value(rectangle) | Устанавливает значение прямоугольника. |
