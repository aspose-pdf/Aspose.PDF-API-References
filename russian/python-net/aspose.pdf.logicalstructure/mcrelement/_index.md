## MCRElement class

Представляет объект ссылки на отмеченный контент в логической структуре.

Тип MCRElement раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| parent_element | Получить родительский элемент. |
| child_elements | Получает коллекцию дочерних элементов |
| image_src | None |
| content | None |
| mcid | Получает MCID объекта ссылки на помеченный контент. |
