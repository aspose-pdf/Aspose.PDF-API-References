## TableTRElement class

Представляет элемент структуры TR в логической структуре таблицы.

Тип TableTRElement раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| parent_element | None |
| child_elements | None |
| default_attribute_owner | Получает |
| атрибуты | Получает |
| structure_type | Получает тип структурного элемента. |
| id | Получает идентификатор структурного элемента. |
| title | Получает или задает заголовок структурного элемента. |
| language | Получает или задает язык для структурного элемента. |
| alternative_text | Получает или задает альтернативный текст для структурного элемента. |
| expansion_text | Получает или задает расширенный текст для структурного элемента. |
| actual_text | Получает или задает фактический текст для структурного элемента. |
| background_color | Получает или задает цвет фона строки. |
| граница | Получает или задает границу строки. |
| default_cell_border | Получает границу ячейки по умолчанию. |
| min_row_height | Получает высоту строки. |
| fixed_row_height | Получает фиксированную высоту строки — строка может иметь фиксированную высоту. |
| is_in_new_page | Получает, находится ли фиксированная строка на новой странице — страница с этим свойством должна быть напечатана на следующей странице. По умолчанию false. |
| is_row_broken | Получает, может ли строка быть разорвана между двумя страницами. |
| default_cell_text_state | Получает или задает состояние текста по умолчанию для ячеек строки. |
| default_cell_padding | Получает или задает отступ по умолчанию для ячеек строки. |
| vertical_alignment | Получает или задает вертикальное выравнивание. |
## Методы
| Имя | Описание |
| :- | :- |
| append_child(element) | None |
| change_parent_element(new_parent_element) | Изменить родительский элемент для текущего структурного элемента |
| generate_id() | Сгенерировать идентификатор для структурного элемента. |
| set_id(id) | Задает идентификатор для структурного элемента. |
| clear_id() | Очищает идентификатор для структурного элемента. |
| set_tag(new_tag) | Задает пользовательский тег для структурного элемента. |
| create_th() | Создаёт [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/) и добавляет его в текущую таблицу. |
| create_td() | Создаёт [TableTHElement](/pdf/python-net/aspose.pdf.logicalstructure/tablethelement/) и добавляет его в текущую таблицу. |
