## StructureTypeCategory class

Представляет категории стандартных типов структуры.

Тип StructureTypeCategory раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| GROUPING_ELEMENTS | Элементы группировки объединяют другие элементы в последовательности или иерархии, но не содержат контент напрямую и не влияют напрямую на макет. |
| BLS_ES | Элементы структуры уровня блока (BLSEs) описывают общую компоновку контента на странице, продвигаясь в направлении блоковой прогрессии. |
| ILS_ES | Элементы структуры уровня строки (ILSEs) описывают расположение контента внутри BLSE, продвигаясь в направлении строковой прогрессии. |
| ILLUSTRATION_ELEMENTS | Элементы иллюстрации представляют собой компактные последовательности контента в порядке следования на странице и рассматриваются как единые объекты относительно макета страницы. Иллюстрацию можно рассматривать как BLSE или ILSE. |
