## TableCellElement class

Представляет базовый класс для элементов ячеек таблицы (TH и TD) в логической структуре.

Тип TableCellElement раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| parent_element | None |
| child_elements | None |
| default_attribute_owner | Получает |
| атрибуты | Получает |
| structure_type | Получает тип структурного элемента. |
| id | Получает идентификатор структурного элемента. |
| title | Получает или задает заголовок структурного элемента. |
| language | Получает или задает язык для структурного элемента. |
| alternative_text | Получает или задает альтернативный текст для структурного элемента. |
| expansion_text | Получает или задает расширенный текст для структурного элемента. |
| actual_text | Получает или задает фактический текст для структурного элемента. |
| background_color | Получает или задает цвет фона ячейки. |
| граница | Получает или задает границу ячейки. |
| is_no_border | Получает или задает наличие границы у ячейки. |
| margin | Получает или задает отступ. |
| выравнивание | Получает или задает выравнивание ячейки. |
| default_cell_text_state | Получает или задает состояние текста ячейки по умолчанию. |
| is_word_wrapped | Получает или задает перенос слов текста ячейки. |
| vertical_alignment | Получает или задает вертикальное выравнивание. |
| col_span | Получает или задает охват столбцов. |
| row_span | Получает или задает охват строк. |
| structure_text_state | Получает |
