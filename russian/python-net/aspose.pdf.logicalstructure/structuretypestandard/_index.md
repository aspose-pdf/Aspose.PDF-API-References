## StructureTypeStandard class

Представляет стандартные типы структуры.

Тип StructureTypeStandard раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| tag | Получает имя тега [StructureElement](/pdf/python-net/aspose.pdf.logicalstructure/structureelement/). |
| категория | Получает категорию Standard Structure Type. |
| DOCUMENT | (Document) Полный документ. Это корневой элемент любого структурного дерева, содержащего несколько частей или несколько статей. |
| PART | (Part) Крупномасштабное деление документа. Этот тип элемента подходит для группировки статей или разделов. |
| ART | (Article) Относительно автономный блок текста, представляющий собой единый рассказ или изложение. Статьи должны быть раздельными; то есть они не должны содержать другие статьи в качестве составных элементов. |
| SECT | (Section) Контейнер для группировки связанных элементов контента. |
| DIV | (Division) Универсальный блочный элемент или группа элементов. |
| BLOCK_QUOTE | (Block quotation) Фрагмент текста, состоящий из одного или нескольких абзацев, приписываемый лицу, отличному от автора окружающего текста. |
| CAPTION | (Caption) Краткий фрагмент текста, описывающий таблицу или рисунок. |
| TOC | (Table of contents) Список, состоящий из записей элементов оглавления (тип структуры TOCI) и/или других вложенных записей оглавления (TOC). |
| TOCI | (Table of contents item) Отдельный элемент оглавления. Дочерние элементы этой записи могут принадлежать к любому из следующих типов структур: |
| INDEX | (Index) Последовательность записей, содержащих идентифицирующий текст вместе с элементами ссылок, указывающих на вхождения указанного текста в основном тексте документа. |
| NON_STRUCT | (Nonstructural element) Группирующий элемент без внутреннего структурного значения; он служит исключительно для группировки. Этот тип элемента отличается от деления (тип структуры Div) тем, что не должен интерпретироваться или экспортироваться в другие форматы документов; однако его потомки должны обрабатываться нормально. |
| PRIVATE | (Private element) Группирующий элемент, содержащий приватный контент, принадлежащий приложению, его создавшему. Структурное значение этого типа элемента не определено и должно полностью определяться соответствующим автором. Ни элемент Private, ни его потомки не должны интерпретироваться или экспортироваться в другие форматы документов. |
| P | (Paragraph) Низкоуровневое деление текста. |
| H | (Heading) Метка для подраздела содержимого документа. Она должна быть первым дочерним элементом раздела, которым она озаглавлена. |
| H1 | Заголовок уровня 1, для использования в совместимых писателях, которые не могут иерархически вложить свои разделы и поэтому не могут определить уровень заголовка по уровню вложенности. |
| H2 | Заголовок уровня 2, для использования в совместимых писателях, которые не могут иерархически вложить свои разделы и поэтому не могут определить уровень заголовка по уровню вложенности. |
| H3 | Заголовок уровня 3, для использования в совместимых писателях, которые не могут иерархически вложить свои разделы и поэтому не могут определить уровень заголовка по уровню вложенности. |
| H4 | Заголовок уровня 4, для использования в совместимых писателях, которые не могут иерархически вложить свои разделы и поэтому не могут определить уровень заголовка по уровню вложенности. |
| H5 | Заголовок уровня 5, для использования в совместимых писателях, которые не могут иерархически вложить свои разделы и поэтому не могут определить уровень заголовка по уровню вложенности. |
| H6 | Заголовок уровня 6, для использования в совместимых писателях, которые не могут иерархически вложить свои разделы и поэтому не могут определить уровень заголовка по уровню вложенности. |
| L | (List) Последовательность элементов одинакового значения и важности. Его непосредственные дочерние элементы должны быть необязательной подписью (тип структуры Caption), за которой следуют один или несколько элементов списка (тип структуры LI). |
| LI | (List item) Отдельный элемент списка. Его дочерними элементами могут быть один или несколько ярлыков, тела списка или оба варианта (типы структур Lbl или LBody). |
| LBL | (Label) Имя или номер, отличающий данный элемент от других в том же списке или в другой группе аналогичных элементов. |
| L_BODY | (List body) Описательное содержание элемента списка. Например, в словарном списке оно содержит определение термина. Оно может содержать контент напрямую или иметь другие BLSE, возможно включая вложенные списки, в качестве дочерних элементов. |
| TABLE | (Table) Двумерное расположение прямоугольных ячеек данных, возможно с сложной подструктурой. Оно содержит либо одну или несколько строк таблицы (тип структуры TR) в качестве дочерних элементов; либо необязательный заголовок таблицы (тип структуры THead), за которым следуют один или несколько элементов тела таблицы (тип структуры TBody) и необязательный нижний колонтитул (тип структуры TFoot). Кроме того, таблица может иметь подпись (тип структуры Caption) в качестве первого или последнего дочернего элемента. |
| T_HEAD | (Table header row group; PDF 1.5) Группа строк, составляющих заголовок таблицы. Если таблица разбивается на несколько страниц, эти строки могут быть перерисованы в верхней части каждого фрагмента таблицы (хотя элемент THead присутствует только один). |
| T_BODY | (Table body row group; PDF 1.5) Группа строк, составляющих основную часть тела таблицы. Если таблица разбивается на несколько страниц, область тела может быть разрезана по границе строки. Таблица может иметь несколько элементов TBody, чтобы позволить рисовать границу или фон для набора строк. |
| T_FOOT | (Table footer row group; PDF 1.5) Группа строк, составляющих нижний колонтитул таблицы. Если таблица разбивается на несколько страниц, эти строки могут быть перерисованы внизу каждого фрагмента таблицы (хотя существует только один элемент TFoot.) |
| TR | (Table row) Строка заголовков или данных в таблице. Она может содержать ячейки заголовков таблицы и ячейки данных таблицы (типы структуры TH и TD). |
| TH | (Table header cell) Ячейка таблицы, содержащая текст заголовка, описывающий одну или несколько строк или столбцов таблицы. |
| TD | (Table data cell) Ячейка таблицы, содержащая данные, являющиеся частью содержимого таблицы. |
| SPAN | (Span) Универсальная встроенная часть текста без каких‑либо особых характеристик. Она может использоваться, например, для ограничения диапазона текста заданным набором атрибутов стиля. |
| QUOTE | (Quotation) Встроенная часть текста, приписываемая кому‑то, кроме автора окружающего текста. |
| ПРИМЕЧАНИЕ | (Note) Элемент пояснительного текста, такой как сноска или концевика, на который ссылаются из основного текста документа. Он может иметь метку (тип структуры Lbl) как дочерний элемент. Примечание может быть включено как дочерний элемент структурного элемента в основном тексте, который на него ссылается, либо может быть размещено в другом месте (например, в разделе концевых сносок) и доступно посредством ссылки (тип структуры Reference). |
| REFERENCE | (Reference) Ссылка на содержимое, расположенное в другом месте документа. |
| BIB_ENTRY | (Bibliography entry) Ссылка, идентифицирующая внешний источник некоторого цитируемого содержимого. Может содержать метку (тип структуры Lbl) как дочерний элемент. |
| CODE | (Code) Фрагмент текста компьютерной программы. |
| LINK | (Link) Связь между частью содержимого ILSE и соответствующей аннотацией ссылки или аннотациями ссылок. Его дочерними элементами должны быть один или несколько элементов содержимого или дочерних ILSE, а также один или несколько ссылок на объекты, идентифицирующие связанные аннотации ссылок. |
| ANNOT | (Annotation; PDF 1.5) Связь между частью содержимого ILSE и соответствующей аннотацией PDF. Annot следует использовать для всех аннотаций PDF, кроме аннотаций ссылок и виджетов. |
| RUBY | (Ruby; PDF 1.5) Пояснительная записка (аннотация), написанная меньшим размером шрифта и размещённая рядом с базовым текстом, к которому она относится. Элемент Ruby также может содержать элементы RB, RT и RP. |
| RB | (Ruby base text) Полный текст, к которому применяется ruby‑аннотация. RB может содержать текст, другие встроенные элементы или их сочетание. Может иметь атрибут RubyAlignattribute. |
| RT | (Ruby annotation text) Текст меньшего размера, который должен располагаться рядом с базовым ruby‑текстом. Он может содержать текст, другие встроенные элементы или их сочетание. Может иметь атрибуты RubyAlign и RubyPosition. |
| RP | (Ruby punctuation) Знаки препинания, окружающие текст ruby‑аннотации. Используется только когда ruby‑аннотация не может быть правильно оформлена в стиле ruby и вместо этого форматируется как обычный комментарий, либо когда она оформлена как warichu. Содержит текст (обычно одну левую или правую скобку или аналогичный ограничительный символ). |
| WARICHU | (Warichu; PDF 1.5) Комментарий или аннотация меньшего размера, оформленная в две более короткие строки в пределах высоты содержащей строки текста и размещённая после (внутри строки) базового текста, к которому относится. Элемент Warichu также может содержать элементы WT и WP. |
| WT | (Warichu text) Текст меньшего размера в комментарии warichu, оформленный в две строки и размещённый между окружающими элементами WP. |
| WP | (Warichu punctuation) Знаки препинания, окружающие текст WT. Содержит текст (обычно одну левую или правую скобку или аналогичный ограничительный символ). Согласно JIS X 4051-1995, скобки, окружающие warichu, могут быть заменены ПРОБЕЛОМ (примерно 1/4 EM по ширине) по усмотрению форматировщика. |
| FIGURE | (Figure) Элемент графического содержимого. Его размещение может быть указано с помощью атрибута макета Placement. |
| FORMULA | (Formula) Математическая формула. |
| FORM | (Form) Виджет‑аннотация, представляющая интерактивное поле формы. |
