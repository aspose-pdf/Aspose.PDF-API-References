## PageInfo class

Представляет информацию о странице.

Тип PageInfo раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PageInfo() | Инициализирует новый экземпляр класса PageInfo. |
## Свойства
| Имя | Описание |
| :- | :- |
| any_margin | Получает или задает отступ страницы для любой страницы, кроме первой. |
| default_text_state | Получает или задает шрифт по умолчанию. |
| высота | Получает или задает высоту страницы. |
| pure_height | Получает или задает чистую высоту страницы без отступов. |
| is_landscape | Получает или задает, является ли страница ландшафтной. |
| margin | Получает или задает отступ страницы. |
| ширина | Получает или задает ширину страницы. |
