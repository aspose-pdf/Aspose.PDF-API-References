## RenderingOptions class

Представляет параметры рендеринга.

Тип RenderingOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| RenderingOptions() | Инициализирует новый экземпляр класса RenderingOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| barcode_optimization | Получает или задает режим оптимизации штрих‑кода. |
| optimize_dimensions | Получает или задает режим оптимизации размеров. |
| system_fonts_native_rendering | Получает или задает режим, при котором системные шрифты отображаются нативно. |
| use_new_imaging_engine | Получает или задает флаг, определяющий, используется ли новый движок визуализации. |
| width_extra_units | Получает или задает значение, используемое для увеличения или уменьшения ширины прямоугольника для оператора AppendRectangle. |
| height_extra_units | Получает или задает значение, используемое для увеличения или уменьшения ширины прямоугольника для оператора AppendRectangle. |
| convert_fonts_to_unicode_ttf | Указывает, что все шрифты будут преобразованы в версии TTF Unicode. Это полезно для совместимости <br/>             причин и оптимизации использования шрифтов, поскольку каждый новый шрифт TTF будет содержать не все символы <br/>             исходного шрифта, а только те символы, которые используются в тексте. |
| use_font_hinting | Использование этого флага включает механизм хинтинга шрифтов. Хинтинг шрифтов — это применение математических инструкций для корректировки отображения <br/>            контурного шрифта. В некоторых случаях включение этого флага может решить проблемы с разборчивостью текста. <br/>            В текущий момент использование этого флага может влиять только на шрифты TTF, если эти шрифты используются в исходном документе. |
| scale_images_to_fit_page_width | Получает или задает значение, используемое для масштабирования всех изображений на странице, чтобы они соответствовали ширине страницы. |
| interpolation_high_quality | Получает или задает режим высокого качества для интерполяции. |
| max_fonts_cache_size | Максимальное количество шрифтов в кэше шрифтов. Значение по умолчанию — 10. |
| max_symbols_cache_size | Максимальное количество символов в кэше символов. Значение по умолчанию — 100. |
| default_font_name | Получает/устанавливает имя шрифта по умолчанию, используемого для замены отсутствующих шрифтов. |
| ignore_resource_font_errors | Получает или задает индикатор того, что ошибки, связанные с отсутствием шрифта, будут игнорироваться.<br/>            true — означает, что ошибки отсутствия шрифта будут игнорироваться. Сегменты текста, ссылающиеся на некорректные ресурсы, будут пропущены во время обработки.<br/>            false по умолчанию |
