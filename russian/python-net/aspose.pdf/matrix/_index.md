## Matrix class

Класс представляет матрицу преобразования.

Тип Matrix раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Matrix() | Конструктор<br/>            создает стандартную матрицу 1 к 1:<br/>            [ A B C D E F ] = [ 1, 0, 0, 1, 0, 0] |
| Matrix(matrix_array) | Инициализирует новый экземпляр класса Matrix |
| Matrix(matrix_array) | Инициализирует новый экземпляр класса Matrix |
| Matrix(matrix) | Инициализирует новый экземпляр класса Matrix |
| Matrix(a, b, c, d, e, f) | Инициализирует новый экземпляр класса Matrix |
## Свойства
| Имя | Описание |
| :- | :- |
| data | Получает данные Matrix в виде массива. |
| a | Элемент A матрицы преобразования. |
| b | Элемент B матрицы преобразования. |
| c | Элемент C матрицы преобразования. |
| d | Элемент D матрицы преобразования. |
| e | Элемент E матрицы преобразования. |
| f | Элемент F матрицы преобразования. |
| элементы | Элементы матрицы. |
## Методы
| Имя | Описание |
| :- | :- |
| rotation(alpha) | Создает матрицу для заданного угла вращения. |
| rotation(rotation) | Создает матрицу для заданного угла вращения. |
| transform(p) | Преобразует точку, используя эту матрицу. |
| transform(rect) | Преобразует прямоугольник.<br/>            Если угол не равен 90·N градусов, возвращается ограничивающий прямоугольник. |
| skew(alpha, beta) | Создает матрицу для заданного угла вращения. |
| get_angle(rotation) | Переводит вращение в угол (градусы) |
| multiply(other) | Умножает матрицу на другую матрицу. |
| add(other) | Добавляет матрицу к другой матрице. |
| reverse() | Вычисляет обратную матрицу. |
