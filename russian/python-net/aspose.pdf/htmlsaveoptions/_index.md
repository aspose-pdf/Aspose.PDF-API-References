## HtmlSaveOptions class

Параметры сохранения для экспорта в формат HTML

Тип HtmlSaveOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| HtmlSaveOptions() | Инициализирует новый экземпляр класса [HtmlSaveOptions](/pdf/python-net/aspose.pdf/htmlsaveoptions/). |
| HtmlSaveOptions(document_type) | Инициализирует новый экземпляр класса HtmlSaveOptions |
| HtmlSaveOptions(fixed_layout) | Инициализирует новый экземпляр класса HtmlSaveOptions |
| HtmlSaveOptions(document_type, fixed_layout) | Инициализирует новый экземпляр класса HtmlSaveOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| warning_handler | Обратный вызов для обработки любых сгенерированных предупреждений. <br/>            WarningHandler возвращает элемент перечисления ReturnAction, указывающий либо Continue, либо Abort. <br/>            Continue является действием по умолчанию, и операция сохранения продолжается, однако пользователь также может вернуть Abort, в этом случае операция сохранения должна быть прекращена. |
| save_format | Формат сохранения данных. |
| close_response | Получает или задает логическое значение, указывающее, будет ли объект Response закрыт после сохранения документа в ответ. |
| extract_ocr_sublayer_only | None |
| try_merge_adjacent_same_background_images | None |
| document_type | Получает или задает [HtmlDocumentType](/pdf/python-net/aspose.pdf/htmldocumenttype/). |
| compress_svg_graphics_if_any | Получает или задает флаг, указывающий, будет ли <br/>            найденная графика SVG (если есть) сжата (упакована) <br/>            в формат SVGZ при сохранении |
| split_css_into_pages | Когда выбран режим мультистраничности (т.е. 'SplitIntoPages' равно 'true'), <br/>            этот атрибут определяет, следует ли создавать отдельный CSS‑файл<br/>            для каждой результирующей HTML‑страницы.<br/>            По умолчанию этот атрибут имеет значение false, поэтому будет создан<br/>            один большой общий CSS для всех созданных страниц. | split_into_pages | Получает или задает флаг, указывающий, будет ли каждая страница исходного <br/>            документа преобразована в собственный целевой HTML‑документ, <br/>            т.е. будет ли результирующий HTML разбит на несколько HTML‑страниц. |
| explicit_list_of_saved_pages | С помощью этого свойства вы можете явно определить <br/>            какие страницы документа должны быть преобразованы.<br/>            Страницы в этом списке должны иметь нумерацию, начинающуюся с 1. Т.е. <br/>            допустимые номера страниц должны быть взяты из диапазона (1...[NumberOfPagesInConvertedDocument])<br/>            Порядок появления страниц в этом списке не влияет на их<br/>            порядок в результирующих HTML‑страницах — в результирующих страницах они всегда будут расположены в том порядке, в котором они <br/>            присутствуют в исходном PDF.<br/>            Если этот список равен null (как по умолчанию), будут преобразованы все страницы.<br/>            Если любой номер страницы из этого списка выходит за пределы существующих страниц (1-[amountOfPagesInDocument])<br/>            будет выброшено исключение. |
| fixed_layout | Получает или задает значение, указывающее, создаётся ли HTML в виде фиксированного макета. |
| image_resolution | Получает или задает разрешение для рендеринга изображений. |
| default_font_name | Указывает имя установленного шрифта, который используется для замены<br/>            любого шрифта документа, не встроенного и не установленного в системе. <br/>            Если значение null, используется шрифт замены по умолчанию. |

| font_sources | Источники шрифтов предварительно сохранённых. |
| additional_margin_width_in_points | Если атрибут 'SplitOnPages=false', тогда весь HTML, представляющий все входные страницы PDF, не будет<br/>            разбит на отдельные HTML‑страницы, а будет помещён в один большой результирующий HTML‑файл.<br/>            Однако каждая исходная страница PDF будет представлена своей <br/>            прямоугольной областью в HTML (при необходимости эти области могут быть обведены, чтобы показать края листа бумаги<br/>            с помощью специального атрибута 'PageBorderIfAny'.<br/>            Этот параметр определяет ширину отступа, который будет принудительно оставлен вокруг этих выходных HTML‑областей,<br/>            представляющих страницы исходного PDF‑документа. По сути он задаёт гарантированный интервал между<br/>            HTML‑представлениями PDF "paper" страниц в таком режиме преобразования. |
| use_z_order | Если атрибут UseZORder установлен в true, графика и текст добавляются в результирующий HTML‑документ<br/>            в соответствии с Z‑порядком в оригинальном PDF‑документе. Если этот атрибут false, вся графика помещается<br/>            в один слой, что может вызвать нежелательные эффекты для перекрывающихся объектов. |
| convert_marked_content_to_layers | Если атрибут ConvertMarkedContentToLayers установлен в true, все элементы внутри помеченного PDF‑контента<br/>            (слой) будут помещены в HTML‑div с атрибутом "data-pdflayer", указывающим имя слоя.<br/>            Это имя слоя будет извлечено из дополнительных свойств помеченного PDF‑контента.<br/>            Если этот атрибут false (по умолчанию), то из помеченного PDF‑контента не будет создано ни одного слоя. |
| minimal_line_width | Этот атрибут задаёт минимальную ширину линии графического пути.<br/>            Если толщина линии меньше 1 px, Adobe Acrobat округляет её до этого значения. Поэтому данный атрибут может<br/>            использоваться для эмуляции этого поведения в HTML‑браузерах. |
| prevent_glyphs_grouping | Этот атрибут включает режим, при котором глифы текста не группируются в слова и строки.<br/>            Этот режим позволяет сохранять максимальную точность позиционирования глифов на странице и может быть<br/>            использован при конвертации документов с нотными знаками или глифами, которые должны располагаться отдельно друг от друга.<br/>            Этот параметр применяется к документу только тогда, когда значение атрибута FixedLayout равно true. |
| simple_textbox_mode_grouping | Этот атрибут задаёт последовательную группировку глифов и слов в строки.<br/>            Например, теги и слова имеют разный порядок в преобразованном HTML, и вы хотите, чтобы они совпадали.<br/>            Этот параметр применяется к документу только тогда, когда значение атрибута FixedLayout равно true. |
| flow_layout_paragraph_full_width | Этот атрибут задаёт текст абзаца полной ширины для режима Flow, FixedLayout = false |
| render_text_as_image | Если атрибут RenderTextAsImage установлен в true, текст из источника превращается в изображение в HTML.<br/>            Может быть полезно, чтобы сделать текст нечувствительным к выделению<br/>            или когда HTML‑текст отображается некорректно. |
| save_full_font | Указывает, что будет сохранён полный шрифт, поддерживает только True Type шрифты.<br/>            По умолчанию SaveFullFont = false, и конвертер сохраняет подмножество исходного шрифта,<br/>            необходимое для отображения текста документа. |
| antialiasing_processing | Этот параметр определяет необходимые меры по сглаживанию при конвертации сложных фоновых изображений из PDF в HTML |
| save_transparent_texts | PDF может содержать прозрачный текст, который можно скопировать в буфер обмена (обычно это происходит, когда документ содержит изображения и из него извлечён OCR‑текст).<br/>            Эта настройка указывает конвертеру, нужно ли сохранять такой текст как прозрачный<br/>            выделяемый текст в результирующем HTML. |
| save_shadowed_texts_as_transparent_texts | Pdf может содержать тексты, которые скрыты другими элементами (например, изображениями), но <br/> могут быть выделены в буфер обмена в Acrobat Reader (обычно это происходит, когда документ содержит изображения и извлечённые из него OCR‑тексты).<br/> Эта настройка указывает конвертеру, нужно ли сохранять такие тексты как прозрачные<br/> выделяемые тексты в результирующем HTML, имитируя поведение Acrobat Reader (в противном случае такие тексты обычно сохраняются как скрытые, недоступные для копирования в буфер обмена) |
| font_saving_mode | Определяет режим сохранения шрифтов, который будет использоваться при сохранении PDF в желаемый формат |
| page_border_if_any | Этот атрибут представляет набор настроек, используемых для рисования рамки (если есть)<br/> в результирующем HTML‑документе вокруг области, представляющей исходную страницу PDF.<br/> По сути он касается отображения краёв листа бумаги,<br/> а не границы страницы, указанной в самой странице PDF. |
| page_margin_if_any | Этот атрибут представляет набор дополнительных полей страницы (если есть)<br/> в результирующем HTML‑документе вокруг области, представляющей исходную страницу PDF. |
| letters_positioning_method | Устанавливает режим позиционирования букв в словах в результирующем HTML |
| exclude_font_name_list | Список встроенных в PDF названий шрифтов, которые не будут встраиваться в HTML. |
| special_folder_for_svg_images | Получает или задает путь к каталогу, в который должны сохраняться только SVG‑изображения, если они <br/> встречаются при сохранении документа в формате HTML. Если параметр пустой или null,<br/> то SVG‑файлы (если есть) будут сохранены вместе с другими изображениями (рядом с выходным файлом)<br/> или в специальный каталог для изображений (если он указан в параметре SpecialImagesFolderIfAny).<br/> Это не влияет ни на что, если свойство CustomImageSavingStrategy<br/> было успешно использовано для обработки соответствующего файла изображения. |

Если параметр пустой или null,<br/> то файлы изображений (если есть) будут сохранены вместе с другими файлами, связанными с HTML<br/> Это не влияет ни на что, если свойство CustomImageSavingStrategy<br/> было успешно использовано для обработки соответствующего файла изображения. |
