## FileParams class

Определяет словарь параметров вложенного файла, который должен содержать дополнительную информацию, специфичную для файла.

Тип FileParams раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| FileParams(spec) | Инициализирует новый экземпляр класса FileParams |
## Свойства
| Имя | Описание |
| :- | :- |
| size | Размер несжатого встроенного файла в байтах. |
| creation_date | Дата и время создания встроенного файла. |
| mod_date | Дата и время последнего изменения встроенного файла. |
| check_sum | Строка из 16 байтов, являющаяся контрольной суммой байтов несжатого встроенного файла. <br/>            Контрольная сумма вычисляется с помощью стандартного алгоритма MD5 message-digest <br/>            над байтами потока встроенного файла. |
