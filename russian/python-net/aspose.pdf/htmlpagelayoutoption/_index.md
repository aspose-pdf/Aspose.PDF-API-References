## HtmlPageLayoutOption enumeration

Указывает флаги, которые вместе с другими параметрами определяют размеры и макеты страниц.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Значение по умолчанию, указывающее, что HtmlPageLayoutOption не будет влиять на размеры и макеты страниц. |
| FIT_TO_WIDEST_CONTENT_WIDTH | Указывает, что ширина страницы определяется размером содержимого, а не указанной шириной страницы. |
| SCALE_TO_PAGE_WIDTH | Указывает, что содержимое документа будет масштабировано до размеров страницы. |
