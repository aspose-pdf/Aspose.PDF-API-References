## XmpPdfAExtensionField class

Эта схема описывает поле в структурированном типе. Она очень похожа на PDF/A Property Value Type <br/>            схему, но определяет поле в структуре вместо свойства.<br/>            URI пространства имён схемы: http://www.aiim.org/pdfa/ns/field#<br/>            Требуемый префикс пространства имён схемы: pdfaField.
