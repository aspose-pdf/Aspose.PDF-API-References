## ExtractImageMode enumeration

Определяет различные режимы, которые могут использоваться при извлечении изображений из документов.

## Members
| Имя члена | Описание |
| :- | :- |
| DEFINED_IN_RESOURCES | Определяет режим извлечения изображений, при котором все изображения, определённые в ресурсах для конкретной страницы, извлекаются. |
| ACTUALLY_USED | Определяет режим извлечения изображений, при котором извлекаются только те изображения, которые действительно отображаются на странице. |
