## CompositingParameters class

Представляет объект, содержащий параметры композитинга графики текущего графического состояния.

Тип CompositingParameters раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| CompositingParameters(blend_mode) | Инициализирует новый экземпляр класса CompositingParameters |
| CompositingParameters(blend_mode, filter_type) | Инициализирует новый экземпляр класса CompositingParameters |
| CompositingParameters(blend_mode, filter_type, is_masked) | Инициализирует новый экземпляр класса CompositingParameters |
## Свойства
| Имя | Описание |
| :- | :- |
| blend_mode | Получает режим смешивания текущего графического состояния. |
| filter_type | Получает тип фильтра изображения. |
| is_masked | Получает флаг маски. |
