## OutlineCollection class

Представляет иерархию оглавления документа.

Тип OutlineCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| visible_count | Count — это сумма количества видимых дочерних элементов оглавления на всех уровнях. Примечание: пожалуйста, не путайте с Count, который является числом элементов в коллекции. |
| first | Получает элемент оглавления, представляющий первый элемент верхнего уровня в оглавлении. |
| последний | Получает элемент оглавления, представляющий последний элемент верхнего уровня в оглавлении. |
| is_synchronized | Получает значение, указывающее, синхронизирован ли доступ к этой коллекции (потокобезопасен). |
| sync_root | Получает объект, который может использоваться для синхронизации доступа к этой коллекции. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает элемент оглавления из коллекции по индексу. |
## Методы
| Имя | Описание |
| :- | :- |
| delete() | Удаляет все элементы оглавления из оглавления документа. |
| delete(name) | Удаляет элемент оглавления с указанным заголовком из оглавления документа. |
