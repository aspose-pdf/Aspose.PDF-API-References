## Metadata class

Предоставляет доступ к потоку метаданных XMP.

Тип Metadata раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| is_fixed_size | Проверяет, имеет ли коллекция фиксированный размер. |
| ключи | Получает коллекцию ключей метаданных. |
| значения | Получает значения в метаданных. |
| is_synchronized | Проверяет, синхронизирована ли коллекция. |
| sync_root | Получает объект синхронизации коллекции. |
## Методы
| Имя | Описание |
| :- | :- |
| register_namespace_uri(prefix, namespace_uri) | Регистрирует URI пространства имён. |
| register_namespace_uri(prefix, namespace_uri, schema_description) | Регистрирует URI пространства имён. |
| add(key, value) | Добавляет значение в метаданные. |
| add(key, value) | Добавляет значение в метаданные. |
| add(prefix, value) | Добавляет расширение pdf в метаданные. |
| get_namespace_uri_by_prefix(prefix) | Возвращает URI пространства имён по префиксу. |
| get_prefix_by_namespace_uri(namespace_uri) | Возвращает префикс по URI пространства имён. |
| contains(key) | Проверяет, содержится ли ключ в метаданных. |
| remove(key) | Удаляет запись из метаданных. |
| contains_key(key) | Определяет, содержит ли этот словарь указанный ключ. |
| try_get_value(key, value) | Пытается найти ключ в словаре и получить значение, если найдено. |
