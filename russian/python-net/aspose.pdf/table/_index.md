## Table class

Представляет таблицу, которую можно добавить на страницу.

Тип Table раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Table() | Инициализирует новый экземпляр класса Table |
## Свойства
| Имя | Описание |
| :- | :- |
| vertical_alignment | Получает или задает вертикальное выравнивание абзаца |
| horizontal_alignment | Получает или задает горизонтальное выравнивание абзаца |
| margin | Получает или задает внешний отступ для абзаца (для генерации PDF) |
| is_first_paragraph_in_column | Получает или задает значение типа bool, указывающее, будет ли этот абзац в следующей колонке.<br/>            По умолчанию false. (для генерации PDF) |
| is_kept_with_next | Получает или задает значение типа bool, указывающее, останется ли текущий абзац на той же странице вместе со следующим абзацем.<br/>            По умолчанию false. (для генерации PDF) |
| is_in_new_page | Получает или задает значение типа bool, принуждающее этот абзац генерироваться на новой странице.<br/>            По умолчанию false. (для генерации PDF) |
| is_in_line_paragraph | Получает или задает, является ли абзац встроенным.<br/>            По умолчанию false. (для генерации PDF) |
| hyperlink | Получает или задает гиперссылку фрагмента (для генератора PDF). |
| z_index | Получает или задает целочисленное значение, указывающее порядок Z графа. Граф с большим ZIndex <br/> будет размещён над графом с меньшим ZIndex. ZIndex может быть отрицательным. Граф с отрицательным <br/> ZIndex будет размещён позади текста на странице. |
| background_color | Получает или задает цвет фона таблицы |
| break_text | Получает или задает разрыв текста для таблицы |
| corner_style | Получает или задает стили углов границы |
| repeating_rows_style | Получает стиль повторяющихся строк |
| repeating_columns_count | Получает или задает максимальное количество столбцов для таблицы |
| repeating_rows_count | Получает количество первых строк, повторяемых на нескольких страницах |
| column_widths | Получает ширины столбцов таблицы. |
| broken | Получает или задает вертикальное разбиение таблицы; |
| default_cell_border | Получает границу ячейки по умолчанию; |
| default_column_width | Получает границу ячейки по умолчанию; |
| строки | Получает строки таблицы. |
| граница | Получает или задает границу. |
| default_cell_padding | Получает или задает отступ ячейки по умолчанию. |
| default_cell_text_state | Получает или задает состояние текста ячейки по умолчанию. |
| выравнивание | Получает или задает выравнивание таблицы. |
| left | Получает или задает левую координату таблицы. |
| top | Получает или задает верхнюю координату таблицы. |
| is_broken | Получает или задает, что таблица повреждена — будет обрезана для следующей страницы. |
| is_borders_included | Получает или задает включение границы в ширины столбцов. |
| column_adjustment | Получает или задает настройку столбцов таблицы. |
## Методы
| Имя | Описание |
| :- | :- |
| clone() | Клонировать таблицу. |
| get_width() | Получить ширину. |
| get_height(parent_page) | Получить высоту. |
| set_column_text_state(col_number, text_state) | Установить высоту. |
| import_array(imported_array, first_filled_row, first_filled_column, is_left_columns_filled) | Импортирует одномерный массив данных в таблицу. Импорт размещает по одной ячейке для каждого элемента массива и<br/>              начинается с строки и столбца, указанных в параметрах. Во время импорта, если обнаружено, что необходимые строки<br/>              отсутствуют (т.е. целевая таблица слишком мала, чтобы вместить все данные), необходимые строки будут созданы |
