## ArtifactCollection class

Класс представляет коллекцию артефактов.

Тип ArtifactCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| is_synchronized | Синхронизирован ли этот объект. |
| sync_root | Получает объект синхронизации коллекции. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает артефакт по индексу. Индекс начинается с 1. |
## Методы
| Имя | Описание |
| :- | :- |
| delete(artifact) | Удаляет указанный артефакт. |
| delete(index) | Удаляет артефакт по его индексу. |
| find_by_value(name, expected_value) | Находит артефакты по пользовательскому значению. |
| update(artifact) | Обновляет артефакт в коллекции. |
