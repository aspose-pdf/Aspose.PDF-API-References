## Opi class

Представляет Open Prepress Interface (OPI) — механизм создания низкоразрешённых заполнителей или прокси,<br/>            для таких высокоразрешённых изображений.

Тип Opi раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Opi(xform) | Инициализирует новый экземпляр класса Opi |
## Свойства
| Имя | Описание |
| :- | :- |
| version | Получает версию OPI, к которой относится этот словарь. |
| file_specification | Получает внешний файл, содержащий прокси‑изображение низкого разрешения. |
| position | Получает массив из восьми чисел, задающих расположение обрезанного изображения на странице. |
