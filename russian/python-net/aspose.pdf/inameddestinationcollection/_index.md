## INamedDestinationCollection class

Коллекция именованных назначений.

Тип INamedDestinationCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| count | Возвращает количество назначений. |
| names | Возвращает массив имён назначений. |
## Методы
| Имя | Описание |
| :- | :- |
| remove(name) | Удаляет назначение по его имени. |
| add(name, appointment) | Добавляет новое именованное назначение. |
