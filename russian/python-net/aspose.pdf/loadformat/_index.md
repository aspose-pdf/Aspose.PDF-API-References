## LoadFormat enumeration

Указывает формат загрузки.

## Members
| Имя члена | Описание |
| :- | :- |
| CGM | означает загрузку документа в формате CGM |
| HTML | означает загрузку документа в формате HTML |
| EPUB | означает загрузку документа в формате EPUB (специальный формат электронных книг) |
| XML | означает загрузку документа в формате XML (специальный XML, представляющий логическую структуру PDF-документа) |
| XSLFO | означает загрузку документа в формате XSLFO |
| PCL | означает загрузку документа в формате PCL |
| XPS | означает загрузку документа в формате XPS |
| TEX | означает загрузку документа в формате TEX - формат редактора LaTeX |
| SVG | означает загрузку документа в формате SVG - формат редактора LaTeX |
| MHT | означает загрузку документа в формате MHT (это упакованный формат HTML) |
| PS | означает загрузку документа в формате PS (формат документа PostScript) |
| MD | означает, что документ загружен в формате MD (markdown). |
| TXT | означает, что документ загружен в формате TXT. |

| PDFXML | Внутренняя структура PDF‑документа в формате XML. |
