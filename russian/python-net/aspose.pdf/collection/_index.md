## Collection class

Представляет класс для Collection (12.3.5 Collections).

Тип Collection раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Collection() | Инициализирует новый объект Collection. |
## Свойства
| Имя | Описание |
| :- | :- |
| is_synchronized | Получает значение, указывающее, синхронизирован ли доступ к этой коллекции (потокобезопасен). |
| sync_root | Получает объект, который может использоваться для синхронизации доступа к этой коллекции. |
| ключи | Возвращает список ключей вложений файлов. |
| default_entry | Имя встроенного файла по умолчанию. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает встроенный файл по его индексу. |
## Методы
| Имя | Описание |
| :- | :- |
| delete(name) | Удаляет файл из коллекции по его ключу в коллекции. |
| delete() | Удаляет файл из коллекции по его ключу в коллекции. |
| add(key, file) | Добавляет файл во встроенные файлы с указанным ключом. |
| delete_by_key(key) | Удаляет файл из коллекции по его ключу в коллекции. |
| find_by_name(name) | Возвращает встроенный файл по его имени. |
