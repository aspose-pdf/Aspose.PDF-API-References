## NamedDestinationCollection class

Класс представляет коллекцию всех назначений (дерево имён, сопоставляющее строки имён с назначениями (см. 12.3.2.3, "Named Destinations") и (см. 7.7.4, "Name Dictionary")) в PDF‑документе.

Тип NamedDestinationCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| count | Количество именованных пунктов назначения. |
| names | Список имён пунктов назначения. |
## Методы
| Имя | Описание |
| :- | :- |
| remove(name) | Удалить именованный пункт назначения. |
| add(name, appointment) | Добавить новый именованный пункт назначения. |
