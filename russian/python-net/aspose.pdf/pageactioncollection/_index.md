## PageActionCollection class

Этот класс описывает действия страницы

Тип PageActionCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| on_open | Действие, которое будет выполнено при открытии страницы. |
| on_close | Действие, которое будет выполнено при закрытии страницы. |
## Методы
| Имя | Описание |
| :- | :- |
| remove_actions() | Удаляет все действия аннотации. |
