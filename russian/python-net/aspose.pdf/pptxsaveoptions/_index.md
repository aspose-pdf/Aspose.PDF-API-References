## PptxSaveOptions class

Параметры сохранения для экспорта в формат SVG

Тип PptxSaveOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PptxSaveOptions() | Инициализирует новый экземпляр класса PptxSaveOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| warning_handler | Обратный вызов для обработки любых сгенерированных предупреждений. <br/>            WarningHandler возвращает элемент перечисления ReturnAction, указывающий либо Continue, либо Abort. <br/>            Continue является действием по умолчанию, и операция сохранения продолжается, однако пользователь также может вернуть Abort, в этом случае операция сохранения должна быть прекращена. |
| save_format | Формат сохранения данных. |
| close_response | Получает или задает логическое значение, указывающее, будет ли объект Response закрыт после сохранения документа в ответ. |
| extract_ocr_sublayer_only | Этот атрибут включает функциональность извлечения изображения или текста <br/>            для PDF‑документов с OCR‑подслоем. |
| try_merge_adjacent_same_background_images | Иногда PDF‑файлы содержат фоновые изображения (страниц или ячеек таблиц)<br/>              сформированные из нескольких одинаковых плиточных фоновых изображений, расположенных рядом друг с другом.<br/>              В таком случае рендереры целевых форматов (например MsWord для формата DOCS) иногда генерируют<br/>              видимые границы между частями фоновых изображений,<br/>              поскольку их методы сглаживания краёв изображения (анти‑алиасинг) отличаются от используемых в Acrobat Reader.<br/>               Если кажется, что экспортированный документ содержит такие видимые границы между <br/>              частями одинаковых фоновых изображений, пожалуйста, попробуйте использовать эту настройку, чтобы избавиться <br/>              от нежелательного эффекта. <br/>                ВНИМАНИЕ! Эта оптимизация качества обычно существенно замедляет конвертацию,<br/>              поэтому, пожалуйста, используйте эту опцию только тогда, когда это действительно необходимо. |
| slides_as_images | Если установлено в true, то всё содержимое распознаётся как изображения (по одному на страницу) |
| image_resolution | Получает или задает разрешение изображения (dpi). По умолчанию 192 dpi. |
| separate_images | Если установлено в true, то изображения отделяются от всех остальных графических элементов |
| optimize_text_boxes | Переключает распознавание текстовых колонок |
