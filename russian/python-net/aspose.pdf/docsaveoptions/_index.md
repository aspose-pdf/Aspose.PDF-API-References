## DocSaveOptions class

Параметры сохранения для экспорта в формат Doc

Тип DocSaveOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| DocSaveOptions() | Инициализирует новый экземпляр класса DocSaveOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| warning_handler | Обратный вызов для обработки любых сгенерированных предупреждений. <br/>            WarningHandler возвращает элемент перечисления ReturnAction, указывающий либо Continue, либо Abort. <br/>            Continue является действием по умолчанию, и операция сохранения продолжается, однако пользователь также может вернуть Abort, в этом случае операция сохранения должна быть прекращена. |
| save_format | Формат сохранения данных. |
| close_response | Получает или задает логическое значение, указывающее, будет ли объект Response закрыт после сохранения документа в ответ. |
| extract_ocr_sublayer_only | Этот атрибут включает функциональность извлечения изображения или текста <br/>            для PDF‑документов с OCR‑подслоем. |
| try_merge_adjacent_same_background_images | Иногда PDF‑файлы содержат фоновые изображения (страниц или ячеек таблиц)<br/>              сформированные из нескольких одинаковых плиточных фоновых изображений, расположенных рядом друг с другом.<br/>              В таком случае рендереры целевых форматов (например MsWord для формата DOCS) иногда генерируют<br/>              видимые границы между частями фоновых изображений,<br/>              поскольку их методы сглаживания краёв изображения (анти‑алиасинг) отличаются от используемых в Acrobat Reader.<br/>               Если кажется, что экспортированный документ содержит такие видимые границы между <br/>              частями одинаковых фоновых изображений, пожалуйста, попробуйте использовать эту настройку, чтобы избавиться <br/>              от нежелательного эффекта. <br/>                ВНИМАНИЕ! Эта оптимизация качества обычно существенно замедляет конвертацию,<br/>              поэтому, пожалуйста, используйте эту опцию только тогда, когда это действительно необходимо. |
| режим | Режим распознавания. |
| relative_horizontal_proximity | В PDF слова могут быть внутренне представлены операторами, которые печатают слова<br/>              путем независимого печатания их букв или слогов. Поэтому для обнаружения слов иногда необходимо обнаруживать группы<br/>              независимых символов, которые на самом деле являются словами.<br/>                Эта настройка определяет ширину пробела между текстовыми элементами (буквами, слогами) <br/>              который должен рассматриваться как расстояние между словами при распознавании слов в исходном PDF.<br/>              (наличие пустого пространства как минимум этой ширины между буквами означает, что <br/>               текстовые элементы относятся к разным словам).<br/>              Нормировано по размеру шрифта — 1.0 означает 100 % предполагаемого размера шрифта слова.<br/>             ВНИМАНИЕ! Используется только в случаях, когда исходный PDF содержит специфические редкo используемые шрифты<br/>             , для которых оптимальное значение нельзя вычислить из шрифта. <br/>               Таким образом, в подавляющем большинстве случаев этот параметр не меняет результат документа. |
| max_distance_between_text_lines | Этот параметр используется для группировки строк текста в абзацы.<br/>            Определяет, насколько далеко могут находиться две относительные строки текста. Указывается в сотнях процентов от высоты строк текста. |
| recognize_bullets | Включить распознавание маркеров |
| add_return_to_line_end | Использовать разрывы абзацев или строк |
| image_resolution_x | Разрешение X преобразованных изображений. |
| image_resolution_y | Разрешение Y преобразованных изображений. |
| формат | Формат вывода |
| batch_size | Определяет размер пакета, если применяется пакетное преобразование<br/>            для пары исходного и целевого форматов. |
| memory_save_mode_path | Определяет путь (имя файла или директории) для хранения<br/>            временных данных при конвертации в режиме сохранения в памяти. |
