## XImageCollection class

Класс, представляющий коллекцию XImage.

Тип XImageCollection раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| is_synchronized | Возвращает true, если объект синхронизирован. |
| sync_root | Возвращает объект синхронизации. |
| names | Получает массив имен изображений. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает изображение из коллекции по его индексу. |
## Методы
| Имя | Описание |
| :- | :- |
| add(image) | Добавляет новое изображение в список Image. Этот метод добавляет изображение как ссылку на тот же PdfObject (что позволяет уменьшить размер файла) |
| add(image) | Добавляет объект в конец коллекции, чтобы объект можно было получить по последнему индексу. |
| add(image, filter_type) | Добавляет объект в конец коллекции, чтобы объект можно было получить по последнему индексу. |
| add(image, quality) | Добавляет объект в конец коллекции, чтобы объект можно было получить по последнему индексу. |
| delete(index) | Удаляет элемент из коллекции по индексу. |
| delete(index, action) | Удаляет изображение из коллекции по индексу, выполняя действие, указанное параметром action. |
| delete(name) | Удаляет элемент из коллекции по имени. |
| delete(name, action) | Удаляет элемент из коллекции по имени. |
| delete() | Удаляет элемент из коллекции по индексу. |
| replace(index, stream) | Заменить изображение в коллекции другим изображением. |
| replace(index, stream, quality, is_black_and_white) | Заменить изображение в коллекции другим изображением. |
| replace(index, stream, quality) | Заменить изображение в коллекции другим изображением. |
| get_image_name(image) | Возвращает имя из списка изображений, которое является ключом данного изображения. |
