## FloatingBox class



Тип FloatingBox раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| FloatingBox(width, height) | Инициализирует новый экземпляр класса FloatingBox |
| FloatingBox() | Инициализирует новый экземпляр класса [FloatingBox](/pdf/python-net/aspose.pdf/floatingbox/). |
## Свойства
| Имя | Описание |
| :- | :- |
| vertical_alignment | Получает или задает вертикальное выравнивание абзаца |
| horizontal_alignment | Получает или задает горизонтальное выравнивание абзаца |
| margin | Получает или задает внешний отступ для абзаца (для генерации PDF) |
| is_first_paragraph_in_column | Получает или задает значение типа bool, указывающее, будет ли этот абзац в следующей колонке.<br/>            По умолчанию false. (для генерации PDF) |
| is_kept_with_next | Получает или задает значение типа bool, указывающее, останется ли текущий абзац на той же странице вместе со следующим абзацем.<br/>            По умолчанию false. (для генерации PDF) |
| is_in_new_page | Получает или задает значение типа bool, принуждающее этот абзац генерироваться на новой странице.<br/>            По умолчанию false. (для генерации PDF) |
| is_in_line_paragraph | Получает или задает, является ли абзац встроенным.<br/>            По умолчанию false. (для генерации PDF) |
| hyperlink | Получает или задает гиперссылку фрагмента (для генератора PDF). |
| z_index | Получает или задает целочисленное значение, указывающее порядок Z графа. Граф с большим ZIndex <br/> будет размещён над графом с меньшим ZIndex. ZIndex может быть отрицательным. Граф с отрицательным <br/> ZIndex будет размещён позади текста на странице. |
| column_info | Получает или задает информацию о столбце |
| ширина | Получает или задает значение типа float, указывающее ширину плавающего блока. |
| высота | Получает или задает значение типа float, указывающее высоту плавающего блока. |
| is_need_repeating | Получает или задает логическое значение, указывающее, нужно ли повторять абзац на следующей странице.<br/>            Значение по умолчанию — false. Атрибут действителен только когда сам абзац и объект, на который ссылается ReferenceParagraphID, оба включены в RepeatingRows. |
| paragraphs | Получает или задает коллекцию [paragraphs](/pdf/python-net/aspose.pdf/floatingbox/), указывающую все абзацы в ячейке. |
| border | Получает или задает объект [BorderInfo](/pdf/python-net/aspose.pdf/borderinfo/), содержащий информацию о границе плавающего блока. |
| background_color | Получает или задает объект [Color](/pdf/python-net/aspose.pdf/color/), указывающий цвет фона плавающего блока. |
| background_image | Получает или задает фонового изображения для страницы (только для генератора, не заполняется при чтении документа). |
| padding | Получает или задает объект [MarginInfo](/pdf/python-net/aspose.pdf/margininfo/), указывающий отступы плавающего блока. |
| left | Получает или задает левую координату таблицы. |
| top | Получает или задает верхнюю координату таблицы. |
## Методы
| Имя | Описание |
| :- | :- |
| clone() | Создаёт клон нового объекта [FloatingBox](/pdf/python-net/aspose.pdf/floatingbox/). Абзацы в плавающем блоке не копируются. |
