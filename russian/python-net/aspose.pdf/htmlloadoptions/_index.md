## HtmlLoadOptions class

Представляет параметры загрузки/импорта HTML‑файла в PDF‑документ.

Тип HtmlLoadOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| HtmlLoadOptions() | Создаёт параметры загрузки для преобразования html в pdf‑документ с пустым базовым путём. |
| HtmlLoadOptions(base_path) | Инициализирует новый экземпляр класса HtmlLoadOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| warning_handler | Обратный вызов для обработки любых сгенерированных предупреждений. <br/>            WarningHandler возвращает элемент перечисления ReturnAction, указывающий либо Continue, либо Abort. <br/>            Continue является действием по умолчанию, и операция Load продолжается, однако пользователь также может вернуть Abort, в этом случае операция Load должна быть прекращена. |
| load_format | Представляет файловый формат, который описывается в [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/). |
| is_render_to_single_page | Получает или задаёт рендеринг всего документа в одну страницу |
| is_embed_fonts | Получает или задаёт встраивание шрифтов в результирующий документ |
| page_layout_option | Получает или задаёт параметр компоновки. |
| html_media_type | Получает или задаёт возможные типы медиа, используемые при рендеринге. |
| input_encoding | Получает или задаёт атрибут, указывающий кодировку, используемую для этого документа во время разбора. Если этот атрибут равен null, кодировка будет определена из атрибута набора символов документа. |
| base_path | Базовый путь/URL для html‑файла. |
| page_info | Получает или задает информацию о странице документа |
