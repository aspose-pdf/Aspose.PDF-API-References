## Page class

Класс, представляющий страницу PDF‑документа.

Тип Page раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| is_add_paragraphs_after_last | Получает или задает добавление абзацев после последнего абзаца страницы |
| background_image | Получает или задает фонового изображения для страницы (только для генератора, не заполняется при чтении документа). |
| toc_info | Получает или задает информацию о содержании. |
| header | Получает или задает заголовок страницы. |
| слои | Получает или задает коллекцию слоёв. |
| нижний колонтитул | Получает или задает нижний колонтитул страницы. |
| paragraphs | Получает абзацы. |
| page_info | Получает или задает информацию о странице (только для генератора, не заполняется при чтении документа). |
| прямоугольник | Получает или задает прямоугольник страницы.<br/>            При получении: возвращается crop‑box страницы, если он указан, иначе возвращается media‑box страницы.<br/>            При установке: всегда задаётся media‑box страницы.<br/>            Обратите внимание, что это свойство не учитывает поворот страницы. Чтобы получить прямоугольник страницы с учётом поворота, используйте ActualRect. |
| color_type | Устанавливает тип цвета страниц на основе информации, полученной от операторов SetColor,<br/>            изображений и форм. |
| note_line_style | Получает или задает стиль линии для заметок (только для генератора, не заполняется при чтении документа). |
| tab_order | Получает или задает порядок табуляции страницы. <br/>            Возможные значения: Row, Column. По умолчанию, Manual. |
| duration | Получает или задает длительность отображения страницы. Это время в секундах, в течение которого страница должна отображаться во время презентации.<br/>            Возвращает -1, если длительность не определена. |
| contents | Получает коллекцию операторов в потоке содержимого страницы.<br/>            [OperatorCollection](/pdf/python-net/aspose.pdf/operatorcollection/) |
| group | Получает или задает класс атрибутов группы, определяющий атрибуты группы страницы для использования в модели прозрачного изображения. |
| annotations | Получает коллекцию аннотаций страницы.<br/>            [annotations](/pdf/python-net/aspose.pdf/page/) |
| resources | Получает ресурсы страницы. Объект Resources содержит коллекции изображений, форм и шрифтов.<br/>            [resources](/pdf/python-net/aspose.pdf/page/) |
| повернуть | Получает или задает поворот страницы. |
| trim_box | Получает или задает trim‑box страницы. |
| art_box | Получает или задает art‑box страницы. |
| bleed_box | Получает или задает bleed box страницы. |
| crop_box | Получает или задает crop box страницы. |
| media_box | Получает или задает media box страницы. |
| номер | Получить номер страницы. |
| rotation_matrix | Получает матрицу преобразования для страницы. |
| background | Получает или задает цвет фона страницы. |
| watermark | Получает или задает водяной знак страницы. |
| artifacts | Получает коллекцию артефактов на странице. |
| действия | Получает коллекцию свойств страницы. |
| fields_in_tab_order | Получает список объектов Field в порядке Tab на этой странице. |
| user_unit | Получает или задает значение UserUnit. Положительное число, задающее размер единиц пользовательского пространства по умолчанию, в кратных 1 ⁄ 72 дюйма.<br/>            Значение по умолчанию равно 1. Пожалуйста, установите ноль или отрицательное значение, чтобы очистить эту запись на странице. |
## Методы
| Имя | Описание |
| :- | :- |
| send_to(device, output) | Отправляет страницу на обработку с указанным устройством страницы. |
| send_to(device, output_file_name) | Отправляет страницу на обработку с указанным устройством страницы. |
| accept(visitor) | Принимает объект‑посетитель [AnnotationSelector](/pdf/python-net/aspose.pdf.annotations/annotationselector/), который предоставляет функциональность для работы с аннотациями. |
| accept(visitor) | Принимает объект‑посетитель [TextFragmentAbsorber](/pdf/python-net/aspose.pdf.text/textfragmentabsorber/), который предоставляет функциональность для работы с текстовыми объектами. |
| accept(visitor) | Принимает объект‑посетитель [ImagePlacementAbsorber](/pdf/python-net/aspose.pdf/imageplacementabsorber/), который предоставляет функциональность для работы с объектами размещения изображений. |
| accept(visitor) | Принимает объект‑посетитель [TextAbsorber](/pdf/python-net/aspose.pdf.text/textabsorber/), который предоставляет функциональность для работы с текстовыми объектами. |
| add_image(image_stream, image_rect) | Добавляет изображение на страницу и размещает его в центре указанного прямоугольника, сохраняя пропорции изображения. |
| add_image(hocr, image_stream, image_rect) | Добавляет поисковое изображение на страницу и размещает его в центре указанного прямоугольника, сохраняя пропорции изображения. |
| add_image(image_stream, image_rect, image_width, image_height, save_image_proportions) | Добавляет изображение на страницу и размещает его в зависимости от положения прямоугольника изображения. |
| add_image(image_path, rectangle) | Добавляет поисковое изображение на страницу и размещает его в центре указанного прямоугольника, сохраняя пропорции изображения. |
| is_blank(fill_threshold_factor) | Получает флаг, указывающий, является ли страница пустой. |
| get_page_rect(consider_rotation) | Возвращает прямоугольник страницы в соответствии с её CropBox (или MediaBox, если CropBox равен null). |
| calculate_content_b_box() | Вычисляет значение bbox — прямоугольник, содержащий содержимое без видимых полей. |
| rotation_to_int(rotation) | Преобразует элемент перечисления rotation в целочисленное значение. |
| int_to_rotation(rotation) | Преобразует целочисленное значение в соответствующий элемент перечисления rotation. |
| add_stamp(stamp) | Помещает штамп на страницу. Штамп может быть номером страницы, изображением или простым текстом, например, логотипом. |
| flatten() | Удаляет все поля, расположенные на странице, и вместо них размещает их значения. |
| set_page_size(width, height) | Устанавливает размер страницы. |
| make_grayscale() | Преобразует страницу в градации серого. |
| free_memory() | Очищает кэшированные данные |
| get_notifications() | Возвращает уведомления о внутренних операциях с содержимым страницы. (В настоящее время поддерживаются только уведомления о событиях абзацев в сценариях добавления текста.) |
| as_byte_array(resolution) | Преобразует текущую страницу в bitmap и затем возвращает массив байтов. |
| as_xml() | Преобразует текущую страницу в XML с кодировкой UTF-8. |
