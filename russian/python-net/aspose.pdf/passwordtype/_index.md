## PasswordType enumeration

Это перечисление представляет известные типы паролей, используемых для защищённых паролем PDF‑документов.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | PDF‑документ не защищён паролем. |
| USER | PDF‑документ был открыт с использованием пароля открытия документа (ограниченный доступ). |
| OWNER | PDF‑документ был открыт с использованием пароля изменения прав (полный доступ). |
| НЕДОСТУПНО | PDF‑документ защищён паролем, но оба пароля пользователя и владельца не пусты, и <br/>            ни один из паролей не был определён, либо введённый пароль неверен. Поэтому невозможно определить тип пароля. |
