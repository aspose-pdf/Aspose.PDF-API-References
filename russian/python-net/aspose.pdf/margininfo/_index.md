## MarginInfo class

Этот класс представляет отступ для различных объектов.

Тип MarginInfo раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| MarginInfo() | Инициализирует новый экземпляр класса [MarginInfo](/pdf/python-net/aspose.pdf/margininfo/). |
| MarginInfo(left, bottom, right, top) | Инициализирует новый экземпляр класса MarginInfo |
## Свойства
| Имя | Описание |
| :- | :- |
| left | Получает или задает значение типа float, указывающее левый отступ. |
| право | Получает или задает значение типа float, указывающее правый отступ. |
| top | Получает или задает значение типа float, указывающее верхний отступ. |
| bottom | Получает или задает значение типа float, указывающее нижний отступ. |
