## PageSize class

Класс, представляющий размер страницы в PDF‑документе.

Тип PageSize раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PageSize(x, y) | Инициализирует новый экземпляр класса PageSize |
## Свойства
| Имя | Описание |
| :- | :- |
| ширина | Получает или задает ширину страницы. |
| высота | Получает или задает высоту страницы. |
| is_landscape | Получает ориентацию страницы. Возвращает true, если ориентация альбомная, и false, если портретная. |
| a0 | Размер A0 (1189×840 мм). |
| a1 | Размер A1 (840×594 мм). |
| a2 | Размер A2 (594×420 мм). |
| a3 | Размер A3 (420×297 мм). |
| a4 | Размер A4 (297x210 мм). |
| a5 | Размер A5 (210x148 мм). |
| a6 | Размер A6 (148x105 мм). |
| b5 | Размер B5 (250x176 мм). |
| page_letter | Размер Letter (279x216 мм). |
| page_legal | Размер Legal (356x216 мм). |
| page_ledger | Размер Ledger (432x279 мм). |
| p11x17 | Формат 11x17 дюймов. |
