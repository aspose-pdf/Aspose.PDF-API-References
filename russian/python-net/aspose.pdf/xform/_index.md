## XForm class

Класс представляет XForm

Тип XForm раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| b_box | Получает или задает ограничивающий прямоугольник формы. |
| name | Получает или задает имя формы. Имя формы — это имя, используемое для ссылки на форму в словаре XObject в ресурсах страницы. |
| содержимое | Получает операторы формы. |
| opi | Получает Open Prepress Interface (OPI). |
| matrix | Получает или задает матрицу формы. |
| resources | Получает ресурсы Form XObject. |
| rectangle | Получает или задает прямоугольник формы. |
## Методы
| Имя | Описание |
| :- | :- |
| get_resources(allow_create) | Возвращает ресурсы Form X-Object |
| get_resources() | Возвращает ресурсы Form X-Object |
| create_new_form(source, document) | Создает XForm, который дублирует содержимое страницы. |
| free_memory() | Очищает кэшированные данные |
