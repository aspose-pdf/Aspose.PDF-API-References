## Cell class

Представляет ячейку строки таблицы.

Тип Cell раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Cell(rect) | Инициализирует новый экземпляр класса Cell |
| Cell() | Инициализирует новый экземпляр класса Cell. |
## Свойства
| Имя | Описание |
| :- | :- |
| is_no_border | Получает или задает наличие границы у ячейки. |
| margin | Получает или задает отступ. |
| граница | Получает или задает границу. |
| background_color | Получает или задает цвет фона. |
| background_image_file | Получает или задает файл фонового изображения. |
| background_image | Получает или задает фоновое изображение |
| выравнивание | Получает или задает выравнивание. |
| default_cell_text_state | Получает или задает состояние текста ячейки по умолчанию. |
| is_override_by_fragment | Устанавливает, что свойство TextState ячейки переопределяется свойством TextState TextFragment. |
| paragraphs | Получает или задает отформатированный текст ячейки. |
| is_word_wrapped | Получает или задает перенос слов текста ячейки. |
| vertical_alignment | Получает или задает вертикальное выравнивание. |
| col_span | Получает или задает охват столбцов. |
| row_span | Получает или задает охват строк. |
| ширина | Получает или задает ширину столбца. |
## Методы
| Имя | Описание |
| :- | :- |
| clone() | Клонировать ячейку. |
