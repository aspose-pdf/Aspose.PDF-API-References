Все шрифты PDF могут быть встроены <br/>            в документ простым установлением флага IsEmbedded в true, но стандартные шрифты PDF Type1 являются исключением из этого правила.<br/>            Встраивание стандартных шрифтов Type1 требует много времени, поэтому для встраивания этих шрифтов необходимо не только установить флаг IsEmbedded в true для указанного шрифта, но и установить <br/>            дополнительный флаг на уровне документа — EmbedStandardFonts = true;<br/>            Это свойство может быть установлено только один раз для всех шрифтов.<br/>            По умолчанию false. |
| disable_font_license_verifications | Многие операции со шрифтом не могут быть выполнены, если эти операции запрещены лицензией данного шрифта. <br/>            Например, некоторый шрифт нельзя встроить в PDF‑документ, если правила лицензии запрещают встраивание этого шрифта. <br/>            Этот флаг используется для отключения любых ограничений лицензии для всех шрифтов в текущем PDF‑документе.<br/>            Будьте осторожны при использовании этого флага. Когда он установлен, это означает, что человек, устанавливающий флаг, <br/>            берёт на себя всю ответственность за возможные нарушения лицензий/законов. <br/>            Таким образом, он действует на свой собственный риск. <br/>            Настоятельно рекомендуется использовать этот флаг только тогда, когда вы полностью уверены, что не нарушаете <br/>            закон об авторском праве. <br/>            По умолчанию false. |
