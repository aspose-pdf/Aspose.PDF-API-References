## EpubLoadOptions class

Содержит параметры для загрузки/импорта EPUB‑файла в PDF‑документ.

Тип EpubLoadOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| EpubLoadOptions() | Создаёт параметры загрузки по умолчанию для преобразования EPUB‑файла в PDF‑документ. <br/>            Размер страницы PDF по умолчанию — A4 300 dpi 2480 × 3508. |
| EpubLoadOptions(page_size) | Инициализирует новый экземпляр класса EpubLoadOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| warning_handler | Обратный вызов для обработки любых сгенерированных предупреждений. <br/>            WarningHandler возвращает элемент перечисления ReturnAction, указывающий либо Continue, либо Abort. <br/>            Continue является действием по умолчанию, и операция Load продолжается, однако пользователь также может вернуть Abort, в этом случае операция Load должна быть прекращена. |
| load_format | Представляет файловый формат, который описывается в [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/). |
| page_size | Получает или задаёт размер выходной страницы при импорте. |
| margin | Получает ссылку на объект, представляющий информацию о полях. |
| margins_area_usage_mode | Представляет режим использования области полей — определяет обработку <br/>              инструкций (если есть) CSS импортируемого документа<br/>              связанных с использованием полей. |
| page_size_adjustment_mode | ВНИМАНИЕ! Функция реализована, но ещё не добавлена в публичный API из‑за блокирующей проблемы в <br/>              слое OSHARED, обнаруженной для образца документа.<br/>              <br/>             <br/>              Представляет режим использования размера страницы во время конвертации.<br/>             Форматы (например HTML, EPUB и др.) обычно имеют плавающий дизайн, поэтому позволяют подогнать требуемый<br/>             размер страницы. Но иногда содержимое имеет заданные горизонтальные позиции или размер, которые<br/>             не позволяют разместить содержимое в требуемом размере страницы.<br/>               В таком случае мы можем определить, что следует сделать (т.е. когда размер содержимого не вписывается в<br/>             требуемый начальный размер страницы результирующего PDF‑документа). |
