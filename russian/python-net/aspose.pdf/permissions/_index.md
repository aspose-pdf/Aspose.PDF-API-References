## Permissions enumeration

Это перечисление представляет разрешения пользователя для PDF.

## Members
| Имя члена | Описание |
| :- | :- |
| PRINT_DOCUMENT | (Обработчики безопасности версии 2) Печать документа.<br/>            (Обработчики безопасности версии 3 и выше) Печать документа <br/>            (возможно не в наивысшем качестве, <br/>            в зависимости от того, установлен ли также [PRINTING_QUALITY](/pdf/python-net/aspose.pdf/permissions/)). |
| MODIFY_CONTENT | Изменять содержимое документа операциями, отличными <br/>            от тех, которые контролируются [MODIFY_TEXT_ANNOTATIONS](/pdf/python-net/aspose.pdf/permissions/), <br/>            [FILL_FORM](/pdf/python-net/aspose.pdf/permissions/), и 11. |
| EXTRACT_CONTENT | (Обработчики безопасности версии 2) Копировать или иным способом извлекать <br/>            текст и графику из документа, включая извлечение <br/>            текста и графики (в поддержку доступности для пользователей <br/>            с ограниченными возможностями или для других целей).<br/>            (Обработчики безопасности версии 3 и выше) Копировать или иным способом <br/>            извлекать текст и графику из документа операциями <br/>            , отличными от контролируемых [EXTRACT_CONTENT_WITH_DISABILITIES](/pdf/python-net/aspose.pdf/permissions/). |
| MODIFY_TEXT_ANNOTATIONS | Добавлять или изменять текстовые аннотации, заполнять интерактивные поля форм, <br/>            и, если [MODIFY_CONTENT](/pdf/python-net/aspose.pdf/permissions/) также установлен, создавать или изменять интерактивные поля форм <br/>            (включая поля подписи). |
| FILL_FORM | (Обработчики безопасности версии 3 и выше) Заполнять существующие <br/>            интерактивные поля форм (включая поля подписи), даже если <br/>            [MODIFY_TEXT_ANNOTATIONS](/pdf/python-net/aspose.pdf/permissions/) отключён. |
| EXTRACT_CONTENT_WITH_DISABILITIES | (Обработчики безопасности версии 3 и выше) Извлекать текст и <br/>            графику (в поддержку доступности для пользователей с ограниченными возможностями <br/>            или для других целей). |
| ASSEMBLE_DOCUMENT | (Обработчики безопасности версии 3 и выше) Собирать документ <br/>            (вставлять, вращать или удалять страницы и создавать закладки или миниатюры <br/>            изображений), даже если [MODIFY_CONTENT](/pdf/python-net/aspose.pdf/permissions/) отключён. |
| PRINTING_QUALITY | (Обработчики безопасности версии 3 и выше) Печатать документ в <br/>            представление, из которого может быть создана точная цифровая копия содержимого PDF. Когда этот бит сброшен (и бит 3 установлен), <br/>            печать ограничивается низкоуровневым представлением внешнего вида, <br/>            возможно с пониженным качеством. |
