## Rectangle class

Класс представляет прямоугольник.

Тип Rectangle раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Rectangle(llx, lly, urx, ury, normalize_coordinates) | Инициализирует новый экземпляр класса Rectangle |
## Свойства
| Имя | Описание |
| :- | :- |
| ширина | Ширина прямоугольника. |
| высота | Высота прямоугольника. |
| llx | X‑координата нижнего‑левого угла. |
| lly | Y‑координата нижнего‑левого угла. |
| urx | X‑координата верхнего‑правого угла. |
| ury | Y‑координата верхнего‑правого угла. |
| тривиальный | Инициализирует тривиальный прямоугольник, т.е. прямоугольник с нулевым положением и размером. |
| is_trivial | Проверяет, является ли прямоугольник тривиальным, т.е. имеет нулевой размер и положение. |
| is_empty | Проверяет, пустой ли прямоугольник. |
| is_point | Проверяет, является ли прямоугольник точкой, т.е. LLX равен URX и LLY равен URY. |
| empty | Пустой прямоугольник |
## Методы
| Имя | Описание |
| :- | :- |
| rotate(angle) | Поворачивает прямоугольник на указанный угол. |
| rotate(angle) | Поворачивает прямоугольник на указанный угол. |
| to_rect() | Преобразует прямоугольник в экземпляр System.Drawing.Rectangle. Позиции и размеры с плавающей точкой усекаются. |
| from_rect(src) | Инициализирует новый прямоугольник из заданного экземпляра System.Drawing.Rectangle. |
| parse(value) | Пытается разобрать строку и извлечь из неё компоненты прямоугольника llx, lly, urx, ury. |
| equals(other) | Проверяет, равны ли прямоугольники, т.е. имеют одинаковое положение и размеры. |
| near_equals(other, delta) | Проверяет, почти ли равны прямоугольники, т.е. имеют почти одинаковое (в пределах delta) положение и размеры. |
| intersect(other_rect) | Пересекает прямоугольники. |
| join(other_rect) | Объединяет прямоугольники. |

| contains(point) | Определяет, находится ли заданная точка внутри прямоугольника. |
| center() | Возвращает координаты центра прямоугольника. |
| clone() | Создаёт копию объекта Rectangle. |
| to_points() | Преобразует прямоугольник в массив точек (\"QuadPoints\"). |
