## PclLoadOptions class

Представляет параметры загрузки (импорта) файла PCL в PDF‑документ.

Тип PclLoadOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PclLoadOptions() | Инициализирует новый экземпляр класса PclLoadOptions |
## Свойства
| Имя | Описание |
| :- | :- |
| warning_handler | Обратный вызов для обработки любых сгенерированных предупреждений. <br/>            WarningHandler возвращает элемент перечисления ReturnAction, указывающий либо Continue, либо Abort. <br/>            Continue является действием по умолчанию, и операция Load продолжается, однако пользователь также может вернуть Abort, в этом случае операция Load должна быть прекращена. |
| load_format | Представляет файловый формат, который описывается в [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/). |
| batch_size | Определяет размер пакета, если применяется пакетное преобразование<br/>            для пары исходного и целевого форматов. |
| conversion_engine | Определяет движок конвертации, который будет использоваться для преобразования |
| supress_errors | Получает или задает логическое значение, указывающее, должны ли ошибки конвертации PCL быть подавлены. |
