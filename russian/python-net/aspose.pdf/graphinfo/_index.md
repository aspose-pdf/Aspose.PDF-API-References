## GraphInfo class

Представляет информацию о графике.

Тип GraphInfo раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| GraphInfo() | Инициализирует новый экземпляр класса GraphInfo |
## Свойства
| Имя | Описание |
| :- | :- |
| line_width | Получает или задает значение типа float, указывающее ширину линии графика. |
| color | Получает или задает объект [color](/pdf/python-net/aspose.pdf/graphinfo/), указывающий цвет графика. |
| dash_array | Получает или задает массив пунктиров. |
| dash_phase | Получает или задает фазу пунктиров. |
| fill_color | Получает или задает объект [color](/pdf/python-net/aspose.pdf/graphinfo/), указывающий цвет заливки графика. |
| is_doubled | Получает или задает, удвоена ли граница. |
| skew_angle_x | Получает или задает значение типа float, указывающее угол наклона координаты x при преобразовании системы координат. |
| skew_angle_y | Получает или задает значение типа float, указывающее угол наклона координаты y при преобразовании системы координат. |
| scaling_rate_x | Получает или задает значение типа float, указывающее коэффициент масштабирования координаты x при преобразовании системы координат. |
| scaling_rate_y | Получает или задает значение типа float, указывающее коэффициент масштабирования координаты y при преобразовании системы координат. |
| rotation_angle | Получает или задает значение типа float, указывающее угол поворота системы координат <br/>            при преобразовании системы координат. |
## Методы
| Имя | Описание |
| :- | :- |
| clone() | Создать копию информации о графике. |
