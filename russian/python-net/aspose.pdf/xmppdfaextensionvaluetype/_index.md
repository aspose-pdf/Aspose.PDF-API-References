## XmpPdfAExtensionValueType class

Схема PDF/A ValueType требуется для всех типов значений свойств, которые не определены в спецификации XMP 2004, т.е. для типов значений, не входящих в следующий список:<br/>            - Типы массивов (это типы контейнеров, которые могут содержать одно или несколько полей): Alt, Bag, Seq<br/>            - Базовые типы значений: Boolean, (открытый и закрытый) Choice, Date, Dimensions, Integer, Lang Alt, Locale, MIMEType, ProperName, Real, Text, Thumbnail, URI, URL, XPath<br/>            - Типы значений управления медиа: AgentName, RenditionClass, ResourceEvent, ResourceRef, Version<br/>            - Базовый тип значения Job/Workflow: Job<br/>            - Типы значений схемы EXIF: Flash, CFAPattern, DeviceSettings, GPSCoordinate, OECF/SFR, Rational<br/>            URI пространства имён схемы: http://www.aiim.org/pdfa/ns/type#<br/>            Требуемый префикс пространства имён схемы: pdfaType
