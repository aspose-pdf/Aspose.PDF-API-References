## PdfASymbolicFontEncodingStrategy class

Этот класс описывает правила, которые могут использоваться для настройки процесса копирования данных кодирования в случаях<br/>            когда символический шрифт TrueType имеет более одной кодировки.<br/>            Некоторые PDF‑документы после преобразования в формат PDF/A могут содержать ошибку <br/>            "More than one encoding in symbolic TrueType font's cmap". <br/>            В чем причина этой ошибки? Все символические шрифты TrueType имеют специальную таблицу "cmap"<br/>            во внутренних данных. Эта таблица сопоставляет коды символов с индексами глифов. <br/>            И эта таблица может содержать различные подтаблицы кодировок, которые<br/>            описывают используемые кодировки. См. подробную информацию о таблицах cmap по адресу<br/>            https://developer.apple.com/fonts/TrueType-Reference-Manual/RM06/Chap6cmap.html.<br/>            Обычно таблица cmap содержит несколько подтаблиц кодировок, но стандарт PDF/A требует<br/>            чтобы только одна подтаблица кодировки (3,0) оставалась для этого шрифта в документе PDF/A. <br/>            И ключевой вопрос здесь — какие данные необходимо взять из других подтаблиц для копирования в<br/>            целевую таблицу кодировки (3,0)? Большинство шрифтов имеют «правильно сформированные» таблицы cmap, где<br/>            каждая подтаблица кодировки полностью согласована с другой подтаблицей. Но некоторые шрифты<br/>            имеют таблицы cmap с конфликтами — где, например, одна подтаблица имеет индекс глифа <br/>            100 для Unicode 100, но другая подтаблица имеет индекс глифа 200 для того же Unicode 100.<br/>            Для решения этой проблемы требуется специальная стратегия. <br/>            По умолчанию используется следующая стратегия: <br/>            ищется подтаблица mac(1,0). Если эта таблица найдена, только эти данные используются для заполнения целевой<br/>            таблицы (3,0). Если подтаблица mac не найдена, тогда все подтаблицы, кроме (3,0), перебираются <br/>            и используются для копирования данных в целевую подтаблицу (3,0). Также отображение для каждого unicode(unicode, glyph index)<br/>            копируется в целевую таблицу только если в текущий момент в целевой таблице нет этого unicode. <br/>            Таким образом, например, если первая подтаблица имеет индекс глифа 100 для Unicode 100, а следующая подтаблица имеет глиф<br/>            индекс 200 для того же Unicode 100, только данные из первой подтаблицы (unicode=100, glyph index = 100) будут скопированы. <br/>            Таким образом, каждая предыдущая подтаблица имеет приоритет перед следующей. <br/>            Свойства этого класса [PdfASymbolicFontEncodingStrategy](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) помогают настроить поведение по умолчанию. <br/>            Если свойство [preferred_cmap_encoding_table](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) типа [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            установлено, то соответствующая подтаблица будет использоваться с приоритетом перед подтаблицей mac(1,0). Значение 'MacTable' из<br/>            перечисления [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/) не имеет смысла в данном случае, так как оно <br/>            указывает на ту же подтаблицу mac (1,0), которая будет использоваться по умолчанию. <br/>            Свойство [None](/pdf/python-net/aspose.pdf/pdfasymbolicfontencodingstrategy/) отбрасывает все приоритеты для любой подтаблицы.<br/>            Если это свойство установлено, то будут использоваться только подтаблицы из объявленной очереди в указанном порядке.<br/>            Если указанные подтаблицы не найдены, тогда будет использована итерация всех подтаблиц и стратегия копирования, описанная выше<br/>            будет использована.<br/>            Объект [QueueItem](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy/queueitem/) указывает используемую подтаблицу кодировки. Эта подтаблица может быть установлена<br/>            через комбинацию членов (PlatformID, PlatformSpecificId) или через [CMapEncodingTableType](/pdf/python-net/aspose.pdf.pdfasymbolicfontencodingstrategy.queueitem/cmapencodingtabletype/)<br/>            перечисление.
