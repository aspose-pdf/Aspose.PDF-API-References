## HorizontalAlignment enumeration

Описывает горизонтальное выравнивание.

## Members
| Имя члена | Описание |
| :- | :- |
| NONE | Нет выравнивания. |
| LEFT | Выравнивание по левому краю. |
| CENTER | Выравнивание по центру. |
| RIGHT | Выравнивание по правому краю. |
| JUSTIFY | Выравнивание по ширине. Текст будет выровнен по левому и правому краям. |
| FULL_JUSTIFY | Похоже на выравнивание 'Justify', за исключением того, что последняя строка будет только <br/>            выровнена по левому краю в режиме 'Justify', тогда как в режиме 'FullJustify' все строки будут<br/>            выровнены по левому и правому краю. |
