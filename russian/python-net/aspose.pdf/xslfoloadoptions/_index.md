## XslFoLoadOptions class

Представляет параметры загрузки/импорта XSL-FO‑файла в PDF‑документ.

Тип XslFoLoadOptions раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| XslFoLoadOptions() | Создаёт объект [XslFoLoadOptions](/pdf/python-net/aspose.pdf/xslfoloadoptions/) без данных xsl. |
| XslFoLoadOptions(xsl_file) | Инициализирует новый экземпляр класса XslFoLoadOptions. |
| XslFoLoadOptions(xsl_stream) | Инициализирует новый экземпляр класса XslFoLoadOptions. |
## Свойства
| Имя | Описание |
| :- | :- |
| warning_handler | Обратный вызов для обработки любых сгенерированных предупреждений. <br/>            WarningHandler возвращает элемент перечисления ReturnAction, указывающий либо Continue, либо Abort. <br/>            Continue является действием по умолчанию, и операция Load продолжается, однако пользователь также может вернуть Abort, в этом случае операция Load должна быть прекращена. |
| load_format | Представляет файловый формат, который описывается в [LoadOptions](/pdf/python-net/aspose.pdf/loadoptions/). |
| xsl_stream | Получает данные xsl для преобразования xml в pdf‑документ. |
| base_path | Базовый путь/URL, из которого ищутся относительные пути к внешним ресурсам (если есть), указанные в загруженном файле SVG. |
| parsing_errors_handling_type | Исходный документ XSLFO может содержать ошибки форматирования. Этот enum перечисляет возможные стратегии обработки этих ошибок. |
