## XImage class

Класс, представляющий графический X-Object.

Тип XImage раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| contains_transparency | Если изображение содержит прозрачность, возвращает true; иначе — false. |
| grayscaled | Получает серую версию изображения. |
| filter_type | Получает тип фильтра изображения. |
| ширина | Получает ширину изображения. |
| высота | Получает высоту изображения. |
| name | Получает или задает имя изображения. Обратите внимание, что если вы измените имя изображения, которое имеет ссылки в содержимом страницы, документ может стать некорректным. В этом случае используйте метод XImage.Rename. |
| metadata | Метаданные изображения. |
## Методы
| Имя | Описание |
| :- | :- |
| save(stream) | Сохраняет данные изображения в поток в виде JPEG‑изображения. |
| save(stream, format) | Сохраняет изображение в поток в запрошенном формате. |
| save(stream, resolution) | Сохраняет данные изображения в поток в виде JPEG‑изображения с указанным разрешением. |
| save(stream, format, resolution) | Сохраняет изображение в поток в запрошенном формате с указанным разрешением. |
| rename(name) | Переименовывает изображение и заменяет все ссылки на изображение новым именем. |
| get_color_type() | Возвращает тип цвета изображения. |
| detect_color_type(bmp) | Возвращает тип цвета изображения. |
| is_the_same_object(image) | Возвращает true, если оба изображения ссылаются на один и тот же объект. |
| get_name_in_collection() | Возвращает имя изображения в коллекции ints. |
| to_stream() | Возвращает оригинальный поток изображения. |
