## ColumnInfo class

Этот класс представляет информацию о столбцах.

Тип ColumnInfo раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| ColumnInfo() | Инициализирует новый экземпляр класса ColumnInfo |
## Свойства
| Имя | Описание |
| :- | :- |
| column_widths | Получает или задает строку, содержащую ширину столбцов. <br/>            Значение каждого столбца должно быть разделено пробелом. Значение по умолчанию — пункт,<br/>            но также поддерживаются см, дюйм и процент от доступной ширины.<br/>            Например,"120 2.5cm 1.5inch" |
| column_spacing | Получает или задает строку, содержащую интервал между столбцами. <br/>            Значение каждого интервала должно быть разделено пробелом. Значение по умолчанию — пункт,<br/>            но также поддерживаются см и дюйм. Например,"120 2.5cm 1.5inch". |
| column_count | Получает или задает целочисленное значение, указывающее количество столбцов. |
