## DocumentInfo class

Представляет метаинформацию PDF‑документа.

Тип DocumentInfo раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| DocumentInfo(document) | Инициализирует новый экземпляр класса DocumentInfo |
## Свойства
| Имя | Описание |
| :- | :- |
| title | Получает или задаёт заголовок документа. |
| creator | Получает или задаёт создателя документа. |
| author | Получает или задаёт автора документа. |
| subject | Получает или задаёт тему документа. |
| keywords | Получает или задаёт ключевые слова документа. |
| producer | Получает или задаёт программу‑создатель документа. |
| creation_date | Получает или задаёт дату создания документа. |
| creation_time_zone | Часовой пояс даты создания. |
| mod_time_zone | Часовой пояс даты изменения. |
| mod_date | Получает или задаёт дату изменения документа. |
| trapped | Получает или задаёт флаг trapped. |
## Методы
| Имя | Описание |
| :- | :- |
| add(key, value) | Добавляет элемент с указанным ключом и значением в коллекцию. |
| remove(key) | Удаляет элемент с указанным ключом из коллекции. |
| clear_custom_data() | Очищает только пользовательские данные, оставляя все остальные предопределённые значения (Title, Author и т.д.). |
| is_predefined_key(key) | Определяет, является ли ключ предопределённым (Title, Author и т.д.), а не пользовательским. |
