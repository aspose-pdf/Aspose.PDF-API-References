## ImageDeleteAction enumeration

Действие, которое выполняется с объектом изображения, когда изображение удаляется из коллекции. Если объект изображения удалён

## Members
| Имя члена | Описание |
| :- | :- |
| KEEP_CONTENTS | Изображение будет удалено из коллекции. Если содержимое страницы содержит ссылки на изображение, они не будут удалены. Документ может стать недействительным. |
| NONE | Изображение будет удалено из коллекции и из содержимого страниц, но объект изображения не будет удалён. Размер файла не уменьшится. |
| FORCE_DELETE | Изображение будет удалено из коллекции, а объект изображения будет удалён из документа. Если существуют другие ссылки на тот же объект, документ может быть повреждён. |
| CHECK | Изображение будет удалено из коллекции, а объект изображения будет удалён только при отсутствии других ссылок на изображение с других страниц. Это может потребовать больше времени по сравнению с опцией ForceDelete. |
