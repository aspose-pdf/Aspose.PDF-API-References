## Point class

Представляет точку с дробными координатами.

Тип Point раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Point(x, y) | Инициализирует новый экземпляр класса Point |
## Свойства
| Имя | Описание |
| :- | :- |
| x | Значение координаты X. |
| y | Значение координаты Y. |
| тривиальный | Получает точку с нулевыми координатами. |
## Методы
| Имя | Описание |
| :- | :- |
| to_point() | Преобразует точку в объект System.Drawing.PointF. |
