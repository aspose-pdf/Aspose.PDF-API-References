## TextStamp class

Представляет текстовый штамп.

Тип TextStamp предоставляет следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| TextStamp(value) | Инициализирует новый экземпляр класса TextStamp |
| TextStamp(value, text_state) | Инициализирует новый экземпляр класса TextStamp |
| TextStamp(formatted_text) | Инициализирует новый экземпляр класса TextStamp |
## Свойства
| Имя | Описание |
| :- | :- |
| background | Устанавливает или получает логическое значение, указывающее, что содержимое наносится как фон.<br/>            Если значение истинно, содержимое штампа размещается внизу.<br/>            По умолчанию значение ложно, содержимое штампа размещается вверху. |
| непрозрачность | Получает или задает значение, указывающее непрозрачность штампа. Значение от 0.0 до 1.0.<br/>            По умолчанию значение равно 1.0. |
| outline_opacity | Получает или задает значение, указывающее непрозрачность контура штампа. Значение от 0.0 до 1.0.<br/>            По умолчанию значение равно 1.0. |
| outline_width | Получает или задает значение ширины контура штампа.<br/>            По умолчанию значение равно 1.0. |
| rotate | Устанавливает или получает вращение содержимого штампа в соответствии со значениями [Rotation](/pdf/python-net/aspose.pdf/rotation/).<br/>            Примечание. Это свойство предназначено для установки углов, кратных 90 градусам (0, 90, 180, 270 градусов).<br/>            Чтобы установить произвольный угол, используйте свойство RotateAngle. <br/>            Если угол, установленный через ArbitraryAngle, не кратен 90, то свойство Rotate возвращает Rotation.None. |
| x_indent | Горизонтальная координата штампа, начиная с левого края. |
| y_indent | Вертикальная координата штампа, начиная снизу. |
| horizontal_alignment | Получает или задает горизонтальное выравнивание штампа на странице. |
| vertical_alignment | Получает или задает вертикальное выравнивание штампа на странице. |
| left_margin | Получает или задает левый отступ штампа. |
| right_margin | Получает или задает правый отступ штампа. |
| bottom_margin | Получает или задает нижний отступ штампа. |
| top_margin | Получает или задает верхний отступ штампа. |
| zoom_x | Горизонтальный коэффициент масштабирования штампа. Позволяет масштабировать штамп по горизонтали. |
| ширина | Желаемая ширина штампа на странице. |
| высота | Желаемая высота штампа на странице. |
| zoom_y | Вертикальный коэффициент масштабирования штампа. Позволяет масштабировать штамп по вертикали. |
| zoom | Коэффициент масштабирования штампа. Позволяет масштабировать штамп.<br/>            Обратите внимание, что пара свойств ZoomX и ZoomY позволяет задавать коэффициент масштабирования для каждой оси отдельно. <br/>            Установка этого свойства изменяет оба свойства ZoomX и ZoomY. <br/>            Если ZoomX и ZoomY различаются, то свойство Zoom возвращает значение ZoomX. |
| rotate_angle | Получает или задает угол вращения штампа в градусах.<br/>            Это свойство позволяет задавать произвольный угол вращения. |
| draw | Это свойство определяет, как штамп отображается на странице. Если Draw = true, штамп отображается как графические операторы, а если draw = false, то штамп отображается как текст. |
| treat_y_indent_as_base_line | Определяет начало координат для размещения текста.<br/>            Если TreatYIndentAsBaseLine = true (значение по умолчанию, когда Draw = true), значение YIndent будет рассматриваться как базовая линия текста.<br/>            Если TreatYIndentAsBaseLine = false (значение по умолчанию, когда Draw = false), значение YIndent будет рассматриваться как нижняя (линия спуска) текста. |
| word_wrap | Определяет перенос слов. Если это свойство установлено в true и указано значение Width, текст будет разбит на несколько строк, чтобы поместиться в указанную ширину. Значение по умолчанию: false. |
| justify | Определяет выравнивание текста. Если это свойство установлено в true, обе границы текста — слева и справа — выравниваются. Значение по умолчанию: false. |
| scale | Определяет масштабирование текста. Если это свойство установлено в true и указано значение Width, текст будет масштабирован, чтобы соответствовать указанной ширине. |
| value | Получает или задает строковое значение, используемое в качестве штампа на странице. |
| text_state | Получает текстовые свойства штампа. См. [text_state](/pdf/python-net/aspose.pdf/textstamp/) для подробностей. |
| text_alignment | Выравнивание текста внутри штампа. |
| max_row_width | Максимальная высота строки для опции WordWrap. |
## Методы
| Имя | Описание |
| :- | :- |
| put(page) | Добавляет текстовый штамп на страницу. |
| set_stamp_id(value) | Задает идентификатор штампа. |
| get_stamp_id() | Возвращает идентификатор штампа. |
