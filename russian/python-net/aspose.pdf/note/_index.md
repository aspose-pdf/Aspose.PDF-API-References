## Note class

Этот класс представляет заметку абзаца генератора.

Тип Note раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Note() | Инициализирует новый экземпляр класса [Note](/pdf/python-net/aspose.pdf/note/). |
| Note(content) | Инициализирует новый экземпляр класса Note |
## Свойства
| Имя | Описание |
| :- | :- |
| paragraphs | Получает или задает коллекцию, указывающую все абзацы в сноске. |
| text | Получает или задает текст примечания. |
| text_state | Получает или задает состояние текста примечания. |
