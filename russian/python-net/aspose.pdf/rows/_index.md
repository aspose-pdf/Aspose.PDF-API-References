## Rows class

Представляет коллекцию строк таблицы.

Тип Rows раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| Rows() | Инициализирует новый экземпляр класса Rows |
## Свойства
| Имя | Описание |
| :- | :- |
| count | Количество элементов. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Получает или задает строку. |
## Методы
| Имя | Описание |
| :- | :- |
| add() | Добавить строку в коллекцию. |
| add(row) | Добавить строку в коллекцию. |
| index_of(row) | Возвращает индекс строки в коллекции. |
| remove(row) | Удалить строку из коллекции. |
| remove_at(index) | Удалить строку из коллекции по позиции. |
| remove_range(index, count) | Удалить набор строк из коллекции. |
| dispose() | Освободить. |
