## Resources class

Класс, представляющий ресурсы страницы.

Тип Resources раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| forms | Получает коллекцию [forms](/pdf/python-net/aspose.pdf/resources/) форм |
| images | Получает коллекцию [images](/pdf/python-net/aspose.pdf/resources/) изображений |
| fonts | Получает коллекцию [fonts](/pdf/python-net/aspose.pdf/resources/) ресурсов |
## Методы
| Имя | Описание |
| :- | :- |
| get_fonts(create_if_absent) | Возвращает коллекцию шрифтов. Если в ресурсах отсутствует запись шрифтов, она будет создана в зависимости от флага CreateIfAbsent. |
