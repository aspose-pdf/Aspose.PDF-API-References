## PdfANonSpecificationFlags class

Этот класс содержит флаги для управления конвертацией PDF/A в случаях, когда исходный PDF‑документ не <br/>            соответствует спецификации PDF. Если флаги этого класса используются, производительность снижается <br/>            но это необходимо, когда исходный PDF‑документ нельзя преобразовать в формат PDF/A обычным способом. <br/>            По умолчанию все флаги установлены в false.

Тип PdfANonSpecificationFlags раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| PdfANonSpecificationFlags() | Инициализирует новый экземпляр класса PdfANonSpecificationFlags |
## Свойства
| Имя | Описание |
| :- | :- |
| check_different_names_in_font_dictionaries | Некоторые PDF‑документы содержат шрифты, у которых разные имена во внутренних данных. <br/>            Использование этого флага заставляет применять специальную логику обработки для случаев, когда поля <br/>            BaseFont и FontDescriptor.FontName различаются. |
