## BorderSide enumeration

Перечисляет стороны границы.

## Members

| :- | :- |
| NONE | Нет границы. |
| LEFT | Левая граница. |
| TOP | Верхняя граница. |
| RIGHT | Правая граница. |
| BOTTOM | Нижняя граница. |
| ALL | Границы всех сторон. Имеет то же значение, что и "Box" и будет заменён на "Box" через год. Поэтому, пожалуйста, используйте "Box", если возможно. |
