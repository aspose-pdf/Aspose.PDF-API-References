## ProgressEventType enumeration

Это перечисление описывает возможные типы событий прогресса<br/>            которые могут возникать во время конвертации

## Members
| Имя члена | Описание |
| :- | :- |
| TOTAL_PROGRESS | означает, что произошедшее событие информирует о полном прогрессе конвертации |
| SOURCE_PAGE_ANALYSED | означает, что произошедшее событие информирует о завершении анализа одной из страниц перед конвертацией |
| RESULT_PAGE_CREATED | означает, что произошедшее событие информирует о создании одной результирующей страницы перед физическим экспортом |
| RESULT_PAGE_SAVED | означает, что произошедшее событие информирует о завершении сохранения одной результирующей страницы |
