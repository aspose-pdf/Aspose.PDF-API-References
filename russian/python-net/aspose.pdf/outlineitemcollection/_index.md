## OutlineItemCollection class

Представляет запись оглавления в иерархии оглавления PDF‑документа.

Тип OutlineItemCollection раскрывает следующие члены:
## Конструкторы
| Имя | Описание |
| :- | :- |
| OutlineItemCollection(outlines) | Инициализирует новый экземпляр класса OutlineItemCollection |
## Свойства
| Имя | Описание |
| :- | :- |
| visible_count | Возвращает общее количество элементов оглавления на всех уровнях иерархии оглавления документа. |
| title | Возвращает или задает заголовок для этого элемента оглавления. |
| назначение | Возвращает или задает назначение для этого элемента оглавления. |
| action | Возвращает или задает действие для этого элемента оглавления. |
| цвет | Возвращает или задает цвет текста заголовка этого элемента оглавления. |
| курсив | Возвращает или задает флаг курсив для текста заголовка этого элемента оглавления |
| жирный | Возвращает или задает флаг жирный для текста заголовка этого элемента оглавления |
| first | Возвращает элемент оглавления, представляющий первый элемент верхнего уровня в иерархии оглавления. |
| последний | Возвращает элемент оглавления, представляющий последний элемент верхнего уровня в иерархии оглавления. |
| prev | Возвращает элемент оглавления, представляющий предыдущий элемент относительно данного элемента в иерархии оглавления. |
| следующий | Возвращает элемент оглавления, представляющий следующий элемент относительно данного элемента в иерархии оглавления. |
| has_next | Проверяет, существует ли элемент оглавления, представляющий следующий элемент относительно данного элемента в иерархии оглавления. |
| родитель | Возвращает родительский объект этого элемента оглавления в иерархии оглавления. |
| is_synchronized | Возвращает значение, указывающее, синхронизирован ли доступ к этой коллекции (потокобезопасен). |
| sync_root | Возвращает объект, который может использоваться для синхронизации доступа к этой коллекции. |
| открыть | Возвращает или задает статус открытости (true/false) для элемента оглавления. |
| level | Возвращает уровень иерархии элемента оглавления. |
## Indexer
| Имя | Описание |
| :- | :- |
| [index] | Возвращает элемент оглавления из коллекции по индексу. |
## Методы
| Имя | Описание |
| :- | :- |
| delete() | Удаляет этот элемент оглавления из иерархии оглавления документа. |
| delete(name) | Удаляет запись оглавления с указанным именем из иерархии оглавления документа. |
| insert(index, outline) | Вставляет элемент оглавления в коллекцию в указанное место. |
