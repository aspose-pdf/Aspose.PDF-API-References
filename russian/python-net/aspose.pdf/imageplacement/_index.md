## ImagePlacement class

Представляет характеристики изображения, размещённого на странице PDF‑документа.

The ImagePlacement type раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| matrix | Текущая матрица преобразования для этого изображения. |
| rectangle | Получает прямоугольник изображения. |
| оператор | Оператор, используемый для отображения изображения. |
| rotation | Получает угол поворота изображения. |
| resolution | Получает разрешение изображения. |
| image | Получает связанный объект ресурса XImage. |
| страница | Получает страницу, содержащую изображение. |
| compositing_parameters | Получает параметры композитинга графического состояния, активные для изображения, размещённого на странице. |
## Методы
| Имя | Описание |
| :- | :- |
| save(stream) | Сохраняет изображение с соответствующими преобразованиями: масштабирование, вращение и разрешение. |
| save(stream, format) | Сохраняет изображение с соответствующими преобразованиями: масштабирование, вращение и разрешение. |
| hide() | Удалить изображение со страницы. |
| replace(image) | Заменить изображение в коллекции другим изображением. |
