## XmpField class

Представляет поле XMP.

Тип XmpField раскрывает следующие члены:
## Свойства
| Имя | Описание |
| :- | :- |
| empty | Получает пустое поле xmp. |
| lang | Получает квалификатор xml:lang. |
| prefix | Получает префикс. |
| namespace_uri | Получает URI пространства имён. |
| local_name | Получает или задаёт имя локального. |
| name | Получает имя. |
| value | Получает значение. |
| field_type | Получает тип поля. |
| is_empty | Получает значение, указывающее, пустой ли этот экземпляр. |
## Методы
| Имя | Описание |
| :- | :- |
| to_structure() | Получает значение в виде структуры. |
| to_array() | Получает значение в виде массива. |
