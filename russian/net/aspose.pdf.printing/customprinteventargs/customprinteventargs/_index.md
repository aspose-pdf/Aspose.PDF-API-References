Инициализирует [`CustomPrintEventArgs`](../) с указанным принтером и настройками страницы.

    PageSettings pageSettings)

| Параметр | Тип | Описание |
| --- | --- | --- |
| fileName | String | Имя файла, который печатается. |
| printerSettings | PrinterSettings | Информация о принтере, на котором должен быть распечатан документ. |
| pageSettings | PageSettings | Настройки, которые должны применяться к каждой странице документа. |
