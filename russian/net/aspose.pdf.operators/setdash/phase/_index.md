## SetDash.Phase property

Фаза пунктиров. Перед началом обводки пути массив пунктиров должен быть пройден, суммируя длины тире и пробелов. Когда накопленная длина достигает значения, указанного фазой пунктиров, обводка пути начинается, и массив пунктиров используется циклически с этого момента.

public int Phase { get; set; }
