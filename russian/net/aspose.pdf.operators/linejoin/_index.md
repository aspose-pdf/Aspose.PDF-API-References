## LineJoin enumeration

Стиль соединения линий должен определять форму, которая будет использоваться в углах контуров, которые обводятся.

```csharp
public enum LineJoin
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| MiterJoin | `0` | Стык под углом. Внешние края линий двух сегментов должны быть продлены до их встречи под углом, как в рамке картины. Если сегменты встречаются под слишком острым углом, определяемым параметром предела среза (см. 8.4.3.5, «Miter Limit»), вместо этого используется фасковое соединение. |
| RoundJoin | `1` | Скруглённое соединение. Дуга круга с диаметром, равным толщине линии, должна быть нарисована вокруг точки, где встречаются два сегмента, соединяя внешние края штрихов обоих сегментов. Эта фигурка в виде куска пирога должна быть заполнена, создавая скруглённый угол. |
| BevelJoin | `2` | Скошенное соединение. Оба сегмента должны завершаться заглушками (см. 8.4.3.3, "Line Cap Style"), а полученный вырез за пределами концов сегментов должен быть заполнен треугольником. |
