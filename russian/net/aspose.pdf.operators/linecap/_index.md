## LineCap enumeration

Стиль окончания линии должен определять форму, которая будет использоваться на концах открытых подпутей (и штрихов, если они есть) при их обводке.

```csharp
public enum LineCap
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| ButtCap | `0` | Butt cap. Обводка должна заканчиваться квадратом в конечной точке пути. Не должно быть проекции за пределы конца пути. |
| RoundCap | `1` | Round cap. Полукруглая дуга диаметром, равным ширине линии, должна быть нарисована вокруг конечной точки и заполнена. |
| SquareCap | `2` | Projecting square cap. Обводка должна продолжаться за конечную точку пути на расстояние, равное половине ширины линии, и заканчиваться квадратом. |
