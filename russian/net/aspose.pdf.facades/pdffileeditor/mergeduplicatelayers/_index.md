## PdfFileEditor.MergeDuplicateLayers property

Если это свойство true, необязательное содержимое конкатенированных документов с одинаковыми именами будет объединено в один слой в результирующем документе. В противном случае слои с одинаковыми именами будут сохранены как отдельные слои в результирующем документе.

```csharp
public bool MergeDuplicateLayers { get; set; }
```
