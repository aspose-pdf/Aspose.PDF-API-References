## PdfExtractor.Resolution property

Устанавливает или получает разрешение для извлечённых изображений. Значение по умолчанию — 150. Изображения с более высоким разрешением более чёткие. Однако увеличение разрешения приводит к росту времени и памяти, необходимых для извлечения изображений. Обычно, чтобы получить чёткое изображение, достаточно установить разрешение 150 или 300.

```csharp
public int Resolution { get; set; }
```
