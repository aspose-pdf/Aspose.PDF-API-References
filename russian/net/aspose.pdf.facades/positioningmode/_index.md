## PositioningMode enumeration

Определяет режим позиционирования. Возможные значения включают Legacy (обратная совместимость) и Current (обновлённый метод расчёта позиции текста).

```csharp
public enum PositioningMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Legacy | `0` | Устаревшее позиционирование текста |
| ModernLineSpacing | `1` | Обновленное межстрочное расстояние, вычисление вертикального положения выполняется по старым правилам (т.е. текст позиционируется относительно нижнего левого угла указанного прямоугольника) |
| Current | `2` | Обновленное межстрочное расстояние и вычисление вертикального положения выполняются на основе левого верхнего угла, а не левого нижнего. |
