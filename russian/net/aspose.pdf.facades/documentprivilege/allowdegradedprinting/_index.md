## DocumentPrivilege.AllowDegradedPrinting property

Устанавливает разрешение, позволяющее печать с пониженным качеством или нет. true — разрешено, false — запрещено.

```csharp
public bool AllowDegradedPrinting { get; set; }
```

## Примечания

При установке печать будет ограничена низкоуровневым представлением внешнего вида, возможно, с ухудшенным качеством.
