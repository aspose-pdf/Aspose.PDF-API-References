## AutoFiller.BasicFileName property

Получает или задает базовое имя файла, если будет генерировано много небольших файлов. Сгенерированный файл будет иметь вид "BasicFileName0","BasicFileName1",... Это работает с другим свойством [`GeneratingPath`](../generatingpath/)GeneratingPath.

public string BasicFileName { get; set; }
