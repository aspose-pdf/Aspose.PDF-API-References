## BaseParagraph.ZIndex property

Получает или задает целочисленное значение, указывающее порядок Z графика. График с большим ZIndex будет размещён над графиком с меньшим ZIndex. ZIndex может быть отрицательным. График с отрицательным ZIndex будет размещён позади текста на странице.

```csharp
public int ZIndex { get; set; }
```
