## Document.DisableFontLicenseVerifications property

Многие операции со шрифтом не могут быть выполнены, если эти операции запрещены лицензией данного шрифта. Например, некоторый шрифт нельзя встроить в PDF документ, если правила лицензии отключают встраивание для этого шрифта. Этот флаг используется для отключения любых лицензионных ограничений для всех шрифтов в текущем PDF документе. Будьте осторожны при использовании этого флага. Когда он установлен, это означает, что человек, устанавливающий этот флаг, берёт на себя всю ответственность за возможные нарушения лицензий/законов. Таким образом, он делает это на свой собственный риск. Настоятельно рекомендуется использовать этот флаг только тогда, когда вы полностью уверены, что не нарушаете закон об авторском праве. По умолчанию false.

```csharp
public bool DisableFontLicenseVerifications { get; set; }
```
