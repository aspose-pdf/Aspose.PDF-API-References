## Document.OptimizeSize property

Получает или задает флаг оптимизации. Когда страницы добавляются в document, одинаковые потоки ресурсов в результирующем файле объединяются в один объект PDF, если этот флаг установлен. Это позволяет уменьшить размер результирующего файла, но может вызвать более медленное выполнение и большие требования к памяти. Значение по умолчанию: false.

```csharp
public bool OptimizeSize { get; set; }
```
