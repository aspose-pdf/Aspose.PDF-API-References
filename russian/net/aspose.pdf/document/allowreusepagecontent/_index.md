## Document.AllowReusePageContent property

Позволяет объединять содержимое страниц для оптимизации размера документа. При использовании разные, но дублированные страницы могут ссылаться на один и тот же объект содержимого. Обратите внимание, что этот режим может вызвать побочные эффекты, такие как изменение содержимого страницы при изменении другой страницы.

```csharp
public bool AllowReusePageContent { get; set; }
```
