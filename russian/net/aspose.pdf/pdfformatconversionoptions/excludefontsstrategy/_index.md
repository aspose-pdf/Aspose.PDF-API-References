## PdfFormatConversionOptions.ExcludeFontsStrategy property

Стратегии исключения избыточных шрифтов и уменьшения размера файла документа. Этот параметр имеет смысл только когда флаг [`OptimizeFileSize`](../optimizefilesize/) установлен в true. По умолчанию используется комбинация стратегий SubsetFonts и RemoveDuplicatedFonts.

```csharp
public RemoveFontsStrategy ExcludeFontsStrategy { get; set; }
```
