## HtmlSaveOptions.CssSavingInfo class

Этот класс представляет набор данных, связанных с пользовательским сохранением CSS во время преобразования PDF в формат HTML

```csharp
public class CssSavingInfo
```

## Поля

| Имя | Описание |
| --- | --- |
| [ContentStream](../../aspose.pdf/htmlsaveoptions.csssavinginfo/contentstream) | Устанавливается конвертером. Представляет двоичное содержимое сохранённого CSS |
| [CssNumber](../../aspose.pdf/htmlsaveoptions.csssavinginfo/cssnumber) | Устанавливается конвертером. Во время конвертации создаётся несколько CSS‑файлов. Это свойство показывает порядковый номер сохранённого CSS‑файла во время конвертации. Его можно использовать в логике пользовательского кода, чтобы решить, как обрабатывать или куда сохранять содержимое CSS. |
| [SupposedURL](../../aspose.pdf/htmlsaveoptions.csssavinginfo/supposedurl) | Устанавливается конвертером. Предполагаемое имя файла, которое передаётся от конвертера в код пользовательского метода. Может использоваться в пользовательском коде для решения, как обрабатывать или куда сохранять содержимое. |
