## HtmlSaveOptions.HtmlImageSavingInfo.ParentType field

Сохранённое изображение может относиться к самому HTML или быть извлечено из SVG, встроенного в HTML. Это свойство может сообщить пользовательскому коду тип родительского элемента обработанного изображения. Устанавливается конвертером и может использоваться пользовательским кодом для решения, что делать с этим изображением (например, пользовательский код может решить, где сохранить изображение или как его следует ссылаться в содержимом родителя).

```csharp
public ImageParentTypes ParentType;
```
