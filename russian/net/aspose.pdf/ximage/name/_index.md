## XImage.Name property

Получает или задает имя изображения. Обратите внимание, что если вы измените имя изображения, которое имеет ссылки в содержимом страниц, документ может стать некорректным. В этом случае используйте метод XImage.Rename.

```csharp
public string Name { get; set; }
```
