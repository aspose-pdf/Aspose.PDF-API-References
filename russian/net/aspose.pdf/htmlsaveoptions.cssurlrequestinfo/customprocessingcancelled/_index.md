## HtmlSaveOptions.CssUrlRequestInfo.CustomProcessingCancelled field

Должно устанавливаться пользовательским кодом, если он не может или не должен определять URL, который будет использоваться в сгенерированном HTML для ссылки на этот CSS. Если значение 'true', то CSS‑файл будет сохранён стандартным способом в стандартном месте.

```csharp
public bool CustomProcessingCancelled;
```
