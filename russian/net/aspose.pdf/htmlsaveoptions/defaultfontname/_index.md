## HtmlSaveOptions.DefaultFontName property

Указывает имя установленного шрифта, который используется для замены любого шрифта документа, не встроенного и не установленного в системе. Если значение null, используется шрифт замены по умолчанию.

```csharp
public string DefaultFontName { get; set; }
```

### Property Value

Имя шрифта
