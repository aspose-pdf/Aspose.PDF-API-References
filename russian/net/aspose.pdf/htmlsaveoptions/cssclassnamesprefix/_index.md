## HtmlSaveOptions.CssClassNamesPrefix field

Когда конвертер PDFtoHTML генерирует результирующие CSS‑файлы, имена классов CSS (например, \".stl_01 {}\" … \".stl_NN {}\") создаются и используются в итоговом CSS. Это свойство позволяет принудительно задать префикс имени класса. Например, если вы хотите, чтобы все имена классов начинались с 'my_prefix_' (т.е. выглядели как 'my_prefix_1' … 'my_prefix_NNN'), просто присвойте 'my_prefix_' этому свойству перед конвертацией. Если это свойство оставлено без изменения (т.е. значение null), конвертер сгенерирует имена классов самостоятельно (это будет что‑то вроде \".stl_01 {}\" … \".stl_NN {}\").

```csharp
public string CssClassNamesPrefix;
```
