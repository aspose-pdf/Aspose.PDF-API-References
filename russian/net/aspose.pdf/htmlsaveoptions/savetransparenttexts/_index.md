## HtmlSaveOptions.SaveTransparentTexts field

Pdf может содержать прозрачные тексты, которые можно скопировать в буфер обмена (обычно это происходит, когда документ содержит изображения и извлечённый с помощью OCR текст). Эта настройка указывает конвертеру, нужно ли сохранять такие тексты как прозрачные выбираемые тексты в результирующем HTML.

```csharp
public bool SaveTransparentTexts;
```
