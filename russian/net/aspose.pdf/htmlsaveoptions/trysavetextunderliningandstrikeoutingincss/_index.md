## HtmlSaveOptions.TrySaveTextUnderliningAndStrikeoutingInCss field

Сам PDF не содержит маркеров подчеркивания для текста. Оно имитируется линией, расположенной под текстом. Эта опция позволяет конвертеру попытаться определить, является ли та или иная линия подчеркиванием текста, и поместить эту информацию в CSS вместо графического рисования подчеркивания.

```csharp
public bool TrySaveTextUnderliningAndStrikeoutingInCss;
```
