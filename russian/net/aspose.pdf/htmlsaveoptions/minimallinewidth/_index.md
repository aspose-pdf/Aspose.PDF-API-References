## HtmlSaveOptions.MinimalLineWidth property

Этот атрибут задает минимальную ширину линии графического пути. Если толщина линии меньше 1 px, Adobe Acrobat округляет её до этого значения. Таким образом, этот атрибут можно использовать для эмуляции данного поведения в браузерах HTML.

```csharp
public float MinimalLineWidth { get; set; }
```
