## HtmlSaveOptions.RenderTextAsImage property

Если атрибут RenderTextAsImage установлен в true, текст из источника становится изображением в HTML. Это может быть полезно, чтобы сделать текст нечитаемым для выделения или если HTML‑текст отображается некорректно.

```csharp
public bool RenderTextAsImage { get; set; }
```
