## CollectionFieldSubtype enumeration

Представляет параметр подтипа поля в коллекции схем.

```csharp
public enum CollectionFieldSubtype
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Подтип не определён. |
| S | `1` | Тип текста. Данные поля должны храниться как текстовая строка PDF. |
| D | `2` | Тип даты. Данные поля должны храниться как строка даты PDF. |
| N | `3` | Тип числа. Данные поля должны храниться как число PDF. |
| F | `4` | Данные поля должны быть именем файла встроенного потока, определяемым записью UF в спецификации файла, если она присутствует; в противном случае — записью F в спецификации файла. |
| Desc | `5` | Данные поля должны быть именем файла встроенного потока, определяемым записью UF в спецификации файла, если она присутствует; в противном случае — записью F в спецификации файла. |
| ModDate | `6` | Данные поля должны быть датой модификации встроенного потока файла, определяемой записью ModDate в словаре параметров встроенного файла. |
| CreationDate | `7` | Данные поля должны быть датой создания встроенного потока файла, определяемой записью CreationDate во встроенном файле. |
| Size | `8` | Данные поля должны быть размером встроенного файла, определяемым записью Size в словаре параметров встроенного файла. |
| CompressedSize | `9` | (PDF 2.0) Данные поля — это длина встроенного потока файла, определяемая записью Length в словаре встроенного потока файла, и оба значения должны быть одинаковыми. |
