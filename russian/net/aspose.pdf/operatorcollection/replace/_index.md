## OperatorCollection.Replace method

Заменяет операторы в коллекции другими операторами.

```csharp
public void Replace(IList<Operator> operators)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| операторы | IList`1 | Список операторов, который заменит текущие операторы, содержащиеся в коллекции. Каждый оператор из списка должен иметь корректный индекс в диапазоне [1..N], где N — количество операторов в коллекции. |
