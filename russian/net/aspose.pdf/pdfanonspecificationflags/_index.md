## PdfANonSpecificationFlags class

Этот класс содержит флаги для управления конвертацией в PDF/A в случаях, когда исходный PDF‑документ не соответствует спецификации PDF. Если флаги этого класса используются, производительность снижается, но это необходимо, когда исходный PDF‑документ нельзя преобразовать в формат PDF/A обычным способом. По умолчанию все флаги установлены в значение false.

```csharp
public class PdfANonSpecificationFlags
```
