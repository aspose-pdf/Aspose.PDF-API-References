## ToUnicodeProcessingRules.MapNonLinkedSymbolsOnSpace property

Некоторые шрифты не предоставляют информацию о юникодах для некоторых символов текста. Этот недостаток информации вызывает ошибку \"Text cannot be mapped to Unicode\". Используйте этот флаг, чтобы сопоставлять несвязанные символы с юникодом \"пробел\"(code 32).

```csharp
public bool MapNonLinkedSymbolsOnSpace { get; set; }
```
