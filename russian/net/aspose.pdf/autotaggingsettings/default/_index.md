## AutoTaggingSettings.Default property

Возвращает настройки по умолчанию для функции автотегирования в PDF‑документах.

```csharp
public static AutoTaggingSettings Default { get; }
```

## Примечания

Настройки по умолчанию включают автотегирование и используют автоматическую стратегию распознавания заголовков. Эти настройки могут использоваться в качестве базовой конфигурации для конвертации PDF формата или других операций, требующих автоматического тегирования PDF содержимого.
