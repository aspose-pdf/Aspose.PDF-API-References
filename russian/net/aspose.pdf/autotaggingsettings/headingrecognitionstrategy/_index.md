## AutoTaggingSettings.HeadingRecognitionStrategy property

Возвращает или задаёт стратегию, используемую для распознавания заголовков в Document во время автотегирования.

```csharp
public HeadingRecognitionStrategy HeadingRecognitionStrategy { get; set; }
```

## Примечания

Свойство `HeadingRecognitionStrategy` определяет, как заголовки идентифицируются в Document. Доступные стратегии включают распознавание заголовков на основе контуров, эвристического анализа или автоматического обнаружения. Установка этого свойства в значение None отключает распознавание заголовков.
