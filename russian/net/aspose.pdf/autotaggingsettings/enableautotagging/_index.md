## AutoTaggingSettings.EnableAutoTagging property

Возвращает или задаёт значение, указывающее, включена ли функция автотегирования.

```csharp
public bool EnableAutoTagging { get; set; }
```

## Примечания

Когда включено, функция автотегирования автоматически генерирует тегированное содержимое для PDF Document, что может улучшить доступность и структуру.
