## DocSaveOptions.ConvertType3Fonts property

Получает или задает преобразование для шрифтов Type3. В шрифтах Type 3 глифы определяются потоками графических операторов. Это означает, что в выводе DOC/DOCX мы видим изображения вместо текста. Установите этот флаг в true, чтобы преобразовать шрифты Type3 в TTF и получить текст в результирующем файле.

```csharp
public bool ConvertType3Fonts { get; set; }
```
