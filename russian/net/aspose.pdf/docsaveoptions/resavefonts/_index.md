## DocSaveOptions.ReSaveFonts property

Получает или задает процедуру повторного сохранения шрифтов. Если установить в true, шрифты будут перезагружаться на каждой странице, чтобы избежать влияния предыдущих свойств шрифта, и новый созданный шрифт будет загружаться с нуля. Установите эту опцию в false, если хотите повысить производительность. Значение по умолчанию — true;

```csharp
public bool ReSaveFonts { get; set; }
```
