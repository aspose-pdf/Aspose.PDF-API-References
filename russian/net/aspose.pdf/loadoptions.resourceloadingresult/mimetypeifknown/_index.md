## LoadOptions.ResourceLoadingResult.MIMETypeIfKnown field

Иногда информация о MIME‑типе загруженного ресурса полезна конвертеру. Вы можете указать MIME‑тип (если он известен после загрузки) в этом параметре. Пожалуйста, оставьте параметр равным null, когда MIME‑тип неизвестен или его не требуется указывать.

```csharp
public string MIMETypeIfKnown;
```
