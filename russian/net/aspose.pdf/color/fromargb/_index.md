## FromArgb(int, int, int) {#fromargb}

Получает действительный объект pdf Color из компонентов цвета RGB.

```csharp
public static Color FromArgb(int r, int g, int b)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| r | Int32 | Красный компонент цвета (значение 0 - 255). |
| g | Int32 | Зелёный компонент цвета (значение 0 - 255). |
| b | Int32 | Синий компонент цвета (значение 0 - 255). |

### Возвращаемое значение

Объект Color, где значение каждого компонента находится в диапазоне [0..255].
