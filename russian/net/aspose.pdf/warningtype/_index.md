### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| SourceFileCorruption | `0` | Файл повреждён. |
| DataLoss | `1` | Текст/диаграмма/изображение или другие данные полностью отсутствуют либо в дереве документа после загрузки, либо в созданном документе после сохранения. |
| MajorFormattingLoss | `2` | Существенные потери форматирования по сравнению с оригинальным документом. Это используется в случаях, когда потеря форматирования значительна, но данные всё ещё присутствуют. |
| MinorFormattingLoss | `3` | Незначительные потери форматирования по сравнению с оригинальным документом. Это используется для небольших потерь точности. |
| CompatibilityIssue | `4` | Известная проблема, которая может помешать открытию документа некоторыми пользовательскими агентами или их более старыми версиями. |
| InvalidInputStreamType | `5` | Недопустимый тип входного потока |
