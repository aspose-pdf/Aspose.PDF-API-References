## ImageDeleteAction enumeration

Действие, которое выполняется с объектом изображения, когда изображение удаляется из коллекции. Если объект изображения удалён

```csharp
public enum ImageDeleteAction
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| KeepContents | `0` | Изображение будет удалено из коллекции. Если содержимое Page содержит ссылки на изображение, они не будут удалены. Document may became invalid. |
| None | `1` | Изображение будет удалено из коллекции и из содержимого страницы, но объект изображения не будет удалён. Размер файла не уменьшится. |
| ForceDelete | `2` | Изображение будет удалено из коллекции, а объект изображения будет удалён из документа. Если существуют другие ссылки на тот же объект, документ может быть повреждён. |
| Check | `3` | Изображение будет удалено из коллекции, а объект изображения будет удалён только при отсутствии других ссылок на изображение с других страниц. Это может потребовать больше времени по сравнению с опцией ForceDelete. |
