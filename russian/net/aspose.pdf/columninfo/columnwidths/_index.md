## ColumnInfo.ColumnWidths property

Получает или задает строку, содержащую ширину столбцов. Значения каждой колонки должны разделяться пробелом. Единицей измерения по умолчанию является пункт, но также поддерживаются см, дюймы и процент от доступной ширины. Например, "120 2.5cm 1.5inch"

```csharp
public string ColumnWidths { get; set; }
```
