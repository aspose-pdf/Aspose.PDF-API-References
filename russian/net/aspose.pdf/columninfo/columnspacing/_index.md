## ColumnInfo.ColumnSpacing property

Получает или задает строку, содержащую расстояние между столбцами. Значения каждого расстояния должны разделяться пробелом. Единицей измерения по умолчанию является пункт, но также поддерживаются см и дюймы. Например, "120 2.5cm 1.5inch".

```csharp
public string ColumnSpacing { get; set; }
```

## Примечания

Если это свойство не задано, для каждого расстояния будет использовано значение по умолчанию 0.
