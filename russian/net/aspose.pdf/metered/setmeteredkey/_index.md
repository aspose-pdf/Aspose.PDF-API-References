## Metered.SetMeteredKey method

Устанавливает публичный и приватный ключ учёта. Если вы приобретаете лицензию с учётом, при запуске приложения этот API должен быть вызван, обычно этого достаточно. Однако если постоянно не удаётся загрузить данные о потреблении и проходит более 24 часов, лицензия будет переключена в режим оценки; чтобы избежать этого, следует регулярно проверять статус лицензии, и если он находится в режиме оценки, вызвать этот API снова.

```csharp
public void SetMeteredKey(string publicKey, string privateKey)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| publicKey | String | публичный ключ |
| privateKey | String | приватный ключ |
