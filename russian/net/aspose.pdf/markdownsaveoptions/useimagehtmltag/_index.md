## MarkdownSaveOptions.UseImageHtmlTag property

Получает и задает разрешение на использование тега img для вставки изображений слева и справа от текста. В этом случае в просмотрщике markdown текст будет обтекать изображение.

```csharp
public bool UseImageHtmlTag { get; set; }
```
