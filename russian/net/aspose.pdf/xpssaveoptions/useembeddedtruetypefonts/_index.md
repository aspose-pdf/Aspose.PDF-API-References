## XpsSaveOptions.UseEmbeddedTrueTypeFonts property

Получает/устанавливает флаг использования встроенных TrueType шрифтов. Отказ от использования встроенных TrueType шрифтов может сократить время конвертации.

public bool UseEmbeddedTrueTypeFonts { get; set; }
