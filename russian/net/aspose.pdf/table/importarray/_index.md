## Table.ImportArray method

Импортирует одномерный массив данных в таблицу. Импорт размещает одну ячейку на каждый элемент массива, начиная с строки и столбца, указанных в параметрах. Во время импорта, если обнаруживается, что необходимые строки отсутствуют (т.е. целевая таблица слишком мала, чтобы вместить все данные), необходимые строки будут созданы.

```csharp
public void ImportArray(object[] importedArray, int firstFilledRow, int firstFilledColumn, 
    bool isLeftColumnsFilled)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| importedArray | Object[] | импортированные данные, null будут импортированы как пустые строки |
| firstFilledRow | Int32 | Определите номер первой целевой строки в целевой таблице, с которой начнётся импорт. Если количество строк в целевой таблице меньше требуемого, недостающие строки будут созданы сначала. |
| firstFilledColumn | Int32 | указывает номер первого целевого столбца в целевой таблице, столбец должен присутствовать в целевой таблице до начала импорта |
| isLeftColumnsFilled | Boolean | Если 'isLeftColumnsFilled'=false, то во второй и всех последующих заполненных строках ячейки, находящиеся слева от firstFilledColumn, будут пропущены |
