## Stamp.Rotate property

Получает или задает вращение содержимого штампа согласно значениям [`Rotation`](../../rotation/) . Примечание. Это свойство предназначено для установки углов, кратных 90 градусам (0, 90, 180, 270 градусов). Для установки произвольного угла используйте свойство RotateAngle. Если угол, установленный через ArbitraryAngle, не кратен 90, то свойство Rotate возвращает Rotation.None.

```csharp
public Rotation Rotate { get; set; }
```
