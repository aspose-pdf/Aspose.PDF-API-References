## HtmlSaveOptions.PartsEmbeddingModes enumeration

Это перечисление определяет возможные режимы встраивания файлов, на которые ссылается HTML. Позволяет контролировать, будут ли связанные файлы (HTML, шрифты, изображения, CSS) встроены в основной HTML‑файл или созданы как отдельные бинарные сущности.

```csharp
public enum PartsEmbeddingModes
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| EmbedAllIntoHtml | `0` | Принудительно встраивает все связанные файлы (CSS, изображения, шрифты) в генерируемую разметку HTML (т.е. непосредственно в HTML). Такой подход создаёт один HTML‑файл, но общий размер вывода увеличивается (из‑за использования Base64‑кодирования бинарных данных), и не все браузеры (особенно старые) корректно обрабатывают встроенные в HTML бинарные данные. Однако он позволяет получить HTML, содержащий весь результат без дополнительных файлов. |
| EmbedCssOnly | `1` | Принудительно отделяет все связанные файлы, кроме CSS (изображения и шрифты). То есть CSS будет встроен в результирующий HTML, а все остальные связанные файлы (изображения и шрифты) будут обработаны как внешние части. Это генерирует HTML, подходящий для широкого спектра браузеров. |
| NoEmbedding | `2` | Принудительно отделяет связанные файлы (CSS, изображения, шрифты). Такой подход создаёт набор файлов, но общий размер вывода становится меньше (поскольку не используется Base64‑кодирование бинарных данных). Кроме того, такой подход генерирует HTML, подходящий для широкого спектра браузеров. |
