## PdfSaveOptions.DefaultFontName property

Имя шрифта, используемое по умолчанию для шрифтов, отсутствующих на компьютере. Когда PDF‑документ, сохраняемый в PDF, содержит шрифты, которые недоступны в самом документе и на устройстве, API заменяет эти шрифты шрифтом по умолчанию (если шрифт с `DefaultFontName` найден на устройстве)

```csharp
public string DefaultFontName { get; set; }
```
