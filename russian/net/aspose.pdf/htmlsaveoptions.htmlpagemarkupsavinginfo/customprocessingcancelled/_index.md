## HtmlSaveOptions.HtmlPageMarkupSavingInfo.CustomProcessingCancelled field

Должно устанавливаться в пользовательском коде при необходимости. Этот флаг должен быть установлен в значение "true" в пользовательском коде, если по каким‑то причинам предоставленная html‑разметка должна обрабатываться не пользовательским кодом, а самим кодом конвертера стандартным способом для конвертера. Таким образом, установка этого флага в пользовательском коде означает, что пользовательский код не обработал указанный файл, и конвертер должен обработать его самостоятельно.

```csharp
public bool CustomProcessingCancelled;
```
