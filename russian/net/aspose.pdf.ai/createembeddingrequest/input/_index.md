## CreateEmbeddingRequest.Input property

Получает или задает входной текст для встраивания, закодированный как строка или массив токенов. Чтобы встроить несколько входов в одном запросе, передайте массив строк или массив массивов токенов. Ввод не должен превышать максимальное количество токенов для модели (8192 токена для text-embedding-ada-002), не может быть пустой строкой, и любой массив должен иметь 2048 измерений или меньше.

```csharp
public string Input { get; set; }
```
