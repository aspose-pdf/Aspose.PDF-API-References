## RunThreadCreateRequest.TopP property

Получает или задает значение, альтернативное выборке с температурой, называемую ядерной выборкой, при которой модель учитывает результаты токенов с вероятностной массой top_p. То есть 0.1 означает, что учитываются только токены, составляющие верхние 10 % вероятностной массы. Обычно рекомендуется изменять либо это значение, либо температуру, но не оба одновременно.

```csharp
public double? TopP { get; set; }
```
