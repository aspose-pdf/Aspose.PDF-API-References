## RunThreadCreateRequest.MaxPromptTokens property

Получает или задает максимальное количество токенов подсказки, которые могут быть использованы в течение выполнения запуска. Запуск будет прилагать все усилия использовать только указанное количество токенов подсказки, в течение нескольких ходов запуска. Если запуск превысит указанное количество токенов подсказки, он завершится со статусом incomplete. См. incomplete_details для получения дополнительной информации.

```csharp
public int? MaxPromptTokens { get; set; }
```
