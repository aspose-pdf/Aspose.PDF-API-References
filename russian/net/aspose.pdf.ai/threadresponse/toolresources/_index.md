## ThreadResponse.ToolResources property

Получает или задает набор ресурсов, доступных инструментам ассистента в этой ветке. Ресурсы специфичны для типа инструмента. Например, инструмент code_interpreter требует список ID файлов, тогда как инструмент file_search требует список ID векторных хранилищ.

```csharp
public ToolResources ToolResources { get; set; }
```
