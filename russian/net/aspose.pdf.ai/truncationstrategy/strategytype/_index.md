## TruncationStrategy.StrategyType property

Получает или задаёт стратегию усечения, используемую для потока. По умолчанию — auto. Если установить значение last_messages, поток будет усечён до n самых последних сообщений. При установке auto сообщения в середине потока будут удаляться, чтобы соответствовать длине контекста модели, max_prompt_tokens.

```csharp
public string StrategyType { get; set; }
```
