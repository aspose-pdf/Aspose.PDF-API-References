## CompletionCreateRequest.NumberOfChoices property

Получает или задает количество вариантов завершения чата, генерируемых для каждого входного сообщения. Обратите внимание, что плата взимается на основе количества сгенерированных токенов во всех вариантах. Оставьте n равным 1, чтобы минимизировать расходы.

```csharp
public int? NumberOfChoices { get; set; }
```
