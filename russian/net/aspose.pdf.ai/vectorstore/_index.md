## VectorStore class

Помощник для создания векторного хранилища с file_ids и привязки его к этой ветке. Может быть привязано максимум 1 векторное хранилище.

```csharp
public class VectorStore
```

## Свойства

| Имя | Описание |
| --- | --- |
| [FileIds](../../aspose.pdf.ai/vectorstore/fileids/) { get; set; } | Получает или задает список идентификаторов файлов для добавления в векторное хранилище. Максимальное количество файлов в векторном хранилище — 10000. |
| [Metadata](../../aspose.pdf.ai/vectorstore/metadata/) { get; set; } | Получает или задает набор из 16 пар «ключ‑значение», которые можно прикрепить к векторному хранилищу. Это может быть полезно для хранения дополнительной информации о векторном хранилище в структурированном виде. Ключи могут быть длиной не более 64 символов, а значения — не более 512 символов. |
