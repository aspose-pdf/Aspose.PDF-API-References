## VectorStore.Metadata property

Получает или задает набор из 16 пар «ключ‑значение», которые можно прикрепить к векторному хранилищу. Это может быть полезно для хранения дополнительной информации о векторном хранилище в структурированном виде. Ключи могут быть длиной не более 64 символов, а значения — не более 512 символов.

```csharp
public Dictionary<string, string> Metadata { get; set; }
```
