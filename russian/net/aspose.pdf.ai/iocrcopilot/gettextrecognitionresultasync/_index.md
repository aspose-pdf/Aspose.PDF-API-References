## IOcrCopilot.GetTextRecognitionResultAsync method

Асинхронно получает результаты распознавания текста для PDF‑документов и файлов изображений. Поддерживаемые типы изображений: PNG (.png), JPEG (.jpeg и .jpg), WEBP (.webp), неанимированный GIF (.gif).

```csharp
public Task<List<TextRecognitionResult>> GetTextRecognitionResultAsync(
    CancellationToken? cancellationToken = default)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| cancellationToken | Nullable`1 | Необязательный токен отмены для прекращения операции. |

### Возвращаемое значение

Задача, представляющая асинхронную операцию. Результат задачи содержит список [`TextRecognitionResult`](../../textrecognitionresult/).
