## AssistantCreateRequest.ToolResources property

Получает или задает ресурсы, используемые инструментами помощника. Ресурсы специфичны для типа инструмента. Например, инструмент code_interpreter требует список идентификаторов файлов, тогда как инструмент file_search требует список идентификаторов хранилищ векторов.

public ToolResources ToolResources { get; set; }
