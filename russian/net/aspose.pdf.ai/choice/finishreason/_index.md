## Choice.FinishReason property

Получает или задает причину, по которой модель прекратила генерировать токены. Это будет stop, если модель достигла естественной точки остановки или предоставленной последовательности остановки, length, если было достигнуто максимальное количество токенов, указанное в запросе.

```csharp
public string FinishReason { get; set; }
```
