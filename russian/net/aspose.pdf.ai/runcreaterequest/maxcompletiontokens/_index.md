## RunCreateRequest.MaxCompletionTokens property

Получает или задает максимальное количество токенов завершения, которые могут быть использованы в течение выполнения запуска. Запуск будет прилагать все усилия использовать только указанное количество токенов завершения, в течение нескольких ходов запуска. Если запуск превысит указанное количество токенов завершения, он завершится со статусом incomplete. См. incomplete_details для получения дополнительной информации.

```csharp
public int? MaxCompletionTokens { get; set; }
```
