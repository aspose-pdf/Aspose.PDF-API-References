## BaseListQueryParameters.Before property

Получает или задает курсор для использования в пагинации. before — это идентификатор объекта, определяющий ваше положение в списке. Например, если вы делаете запрос списка и получаете 100 объектов, заканчивая obj_foo, ваш последующий вызов может включать before=obj_foo, чтобы получить предыдущую страницу списка.

```csharp
public string Before { get; set; }
```
