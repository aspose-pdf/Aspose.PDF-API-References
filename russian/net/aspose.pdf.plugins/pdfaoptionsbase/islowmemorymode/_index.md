## PdfAOptionsBase.IsLowMemoryMode property

Получает или задает значение, указывающее, включён ли режим низкого потребления памяти во время процесса конвертации PDF/A.

```csharp
public bool IsLowMemoryMode { get; set; }
```

### Property Value

`true`, если режим низкого потребления памяти включён; иначе `false`.
