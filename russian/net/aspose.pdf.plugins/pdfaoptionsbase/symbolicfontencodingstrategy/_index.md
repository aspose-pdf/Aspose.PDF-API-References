## PdfAOptionsBase.SymbolicFontEncodingStrategy property

Получает или задает стратегию кодирования символических шрифтов при конвертации в формат PDF/A.

```csharp
public PdfASymbolicFontEncodingStrategy SymbolicFontEncodingStrategy { get; set; }
```

### Property Value

Стратегия кодирования символьных шрифтов.

## Примечания

Это свойство позволяет управлять тем, какая подтаблица CMap будет скопирована в результирующий документ в случаях, когда исходный TrueType символьный шрифт в документе содержит несколько подтаблиц CMap.
