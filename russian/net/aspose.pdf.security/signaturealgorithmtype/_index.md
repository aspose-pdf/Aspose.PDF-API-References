## SignatureAlgorithmType enumeration

Перечисляет типы алгоритмов подписи, используемых для цифровых подписей.

```csharp
public enum SignatureAlgorithmType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Ecdsa | `0` | Алгоритм цифровой подписи на эллиптической кривой (ECDSA), используемый для цифровых подписей. |
| Rsa | `1` | Алгоритм Rivest–Shamir–Adleman (RSA), используемый для цифровых подписей. |
| Dsa | `2` | Алгоритм цифровой подписи (DSA), используемый для цифровых подписей. |
| Timestamp | `3` | Отметка времени, используемая как алгоритм подписи для обеспечения цифровых подписей. |
| Unknown | `4` | Указывает, что тип алгоритма подписи неизвестен. |
