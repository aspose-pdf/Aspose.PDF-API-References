## ValidationMode enumeration

Указывает режим проверки для процессов проверки подписи PDF.

```csharp
public enum ValidationMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Представляет режим, при котором проверка не выполняется. |
| OnlyCheck | `1` | Представляет режим, при котором проверка выполняется, но её результат не влияет на проверку цифровой подписи. Вы можете самостоятельно проверить результат проверки. |
| Strict | `2` | Представляет режим, при котором проверка выполняется, и её результат влияет на проверку цифровой подписи. Если сертификат не может быть проверен, цифровая подпись считается недействительной. Вы можете самостоятельно проверить результат проверки. |
