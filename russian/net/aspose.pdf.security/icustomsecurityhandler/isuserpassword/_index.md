## ICustomSecurityHandler.IsUserPassword method

Проверьте, принадлежит ли пароль пользователю (пароль для открытия документа). Метод вызывается после Initialize. Вызов метода используется в PDF API.

```csharp
public bool IsUserPassword(string password)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| password | String | Пароль. |

### Возвращаемое значение

True, если это пароль для открытия Document.
