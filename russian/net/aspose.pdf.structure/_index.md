Пространство имён **Aspose.Pdf.Structure** предоставляет классы, помогающие работать с логической структурой документа, представляющей организацию документа на главы и разделы, а также идентификацию специальных элементов, таких как рисунки, таблицы и сноски.

| [ElementCollection](./elementcollection/) | Коллекция базовых элементов логической структуры. |
| [FigureElement](./figureelement/) | Класс, представляющий рисунок логической структуры. |
| [RootElement](./rootelement/) | Элемент корневой структуры. |
| [StructElement](./structelement/) | Элемент общей структуры. |
| [TextElement](./textelement/) | Общий текстовый элемент логической структуры документа. |
