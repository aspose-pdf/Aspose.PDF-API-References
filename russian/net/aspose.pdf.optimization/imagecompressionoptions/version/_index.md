## ImageCompressionOptions.Version property

Версия алгоритма сжатия. Возможные значения: 1. стандартное сжатие, 2. быстрое (улучшенное сжатие, которое быстрее стандартного, но может быть неприменимо ко всем изображениям), 3. смешанное (стандартное сжатие применяется к изображениям, которые нельзя сжать более быстрым алгоритмом; это может дать лучшее сжатие, но работает медленнее, чем алгоритм \"fast\"). Версия \"Fast\" не применяется для изменения размера изображений (будет использован стандартный метод). По умолчанию — \"Standard\".

```csharp
public ImageCompressionVersion Version { get; set; }
```
