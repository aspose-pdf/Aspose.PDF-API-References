Пространство имён **Aspose.Pdf.Optimization** — это пространство имён для классов, управляющих процессом оптимизации документа.

## Классы

| Класс | Описание |
| --- | --- |
| [ImageCompressionOptions](./imagecompressionoptions/) | Класс содержит набор параметров для сжатия изображений. |
| [OptimizationOptions](./optimizationoptions/) | Класс, описывающий алгоритм оптимизации документа. Экземпляр этого класса может использоваться в качестве параметра метода OptimizeResources(). |
## Перечисление

| Перечисление | Описание |
