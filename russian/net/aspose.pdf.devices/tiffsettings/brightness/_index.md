## TiffSettings.Brightness property

Получает или задает границу значения преобразования цветов в белый и черный. Этот параметр может быть применён с EncoderValue.CompressionCCITT4, EncoderValue.CompressionCCITT3, EncoderValue.CompressionRle или ColorDepth.Format1bpp == 1

```csharp
public float Brightness { get; set; }
```

### Property Value

Значение яркости должно находиться в диапазоне от 0 до 1. По умолчанию значение равно 0.33f
