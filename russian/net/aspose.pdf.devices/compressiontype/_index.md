## CompressionType enumeration

Используется для указания значения параметра, передаваемого устройству изображения Tiff.

```csharp
public enum CompressionType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| LZW | `0` | Определяет схему сжатия LZW. Может быть передан кодировщику Tiff в качестве параметра, относящегося к категории Compression. |
| CCITT4 | `1` | Указывает схему сжатия CCITT4. Может быть передан в кодировщик CCITT4 в качестве параметра, принадлежащего категории Compression. |
| CCITT3 | `2` | Указывает схему сжатия CCITT3. Может быть передан в кодировщик CCITT3 в качестве параметра, принадлежащего категории Compression. |
| RLE | `3` | Указывает схему сжатия RLE. Может быть передан в кодировщик RLE в качестве параметра, принадлежащего категории Compression. |
| None | `4` | Указывает отсутствие сжатия. Может быть передан в кодировщик Tiff в качестве параметра, принадлежащего категории compression. |
