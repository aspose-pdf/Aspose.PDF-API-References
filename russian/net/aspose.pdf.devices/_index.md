Пространство имён **Aspose.Pdf.Devices** предоставляет классы, используемые для представления документа в виде изображений или простого текста. Таким образом, документ может быть передан на текстовые или различные графические устройства, что позволяет получить его текстовое или графическое представление.

## Классы

| Класс | Описание |
| --- | --- |
| [BmpDevice](./bmpdevice/) | Представляет устройство изображения, которое помогает сохранять страницы pdf‑документа в bmp. |
| [Device](./device/) | Абстрактный класс для всех типов устройств. Устройство используется для представления pdf‑документа в определённом формате. Например, страницу документа можно представить как изображение или текст. |
| [DicomDevice](./dicomdevice/) | Представляет устройство изображения, которое помогает сохранять страницы pdf‑документа в формате Dicom. |
| [DocumentDevice](./documentdevice/) | Абстрактный класс для всех устройств, который используется для обработки всего pdf‑документа. |
| [EmfDevice](./emfdevice/) | Представляет устройство изображения, которое помогает сохранять страницы pdf‑документа в emf. |
| [GifDevice](./gifdevice/) | Представляет устройство изображения, которое помогает сохранять страницы pdf‑документа в gif. |
| [ImageDevice](./imagedevice/) | Абстрактный класс для устройств изображения. |
| [JpegDevice](./jpegdevice/) | Представляет устройство изображения, которое помогает сохранять страницы pdf‑документа в jpeg. |
| [Margins](./margins/) | Этот класс представляет поля изображения. |
| [PageDevice](./pagedevice/) | Абстрактный класс для всех устройств, который используется для обработки определённой страницы pdf‑документа. |
| [PngDevice](./pngdevice/) | Представляет устройство изображения, которое помогает сохранять страницы pdf‑документа в png. |
| [Resolution](./resolution/) | Представляет класс для хранения разрешения изображения. |
| [TextDevice](./textdevice/) | Представляет класс для преобразования страниц pdf‑документа в текст. |
| [ThumbnailDevice](./thumbnaildevice/) | Представляет устройство изображения, которое сохраняет страницы pdf‑документа в миниатюрное изображение. |
| [TiffDevice](./tiffdevice/) | Этот класс помогает сохранять страницы pdf‑документа по одной в одно tiff‑изображение. |
| [TiffSettings](./tiffsettings/) | Этот класс представляет настройки импорта pdf в Tiff. |
