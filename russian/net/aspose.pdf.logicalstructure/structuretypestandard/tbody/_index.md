## StructureTypeStandard.TBody field

(Table body row group; PDF 1.5) Группа строк, составляющих основную часть тела таблицы. Если таблица разбивается на несколько страниц, область тела может быть разделена по границе строки. Таблица может иметь несколько элементов TBody для отрисовки границы или фона набора строк.

public static readonly StructureTypeStandard TBody;
