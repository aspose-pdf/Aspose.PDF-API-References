## StructureElement.RemoveAndMoveItsChildObjectsToItsParent method

Удаляет элемент из структуры, ссылку на него из родительского объекта, ссылки на него из дочерних объектов и соответствующий объект из документа. Вставляет дочерние объекты удалённого объекта в прежнюю коллекцию дочерних объектов родителя, начиная с индекса удалённого объекта.

```csharp
public void RemoveAndMoveItsChildObjectsToItsParent(
    bool checkIfChildObjectsCanBeMovedToParent = true)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| checkIfChildObjectsCanBeMovedToParent | Boolean | Проверьте, можно ли вставить дочерние объекты удалённого элемента в коллекцию дочерних объектов его родителя. |
