## TextReplaceOptions.Scope enumeration

Область, в которой применяется операция замены текста, REPLACE_FIRST по умолчанию. Этот устаревший параметр сохранён для совместимости. Он влияет на PdfContentEditor и не оказывает влияния на TextFragmentAbsorber.

```csharp
public enum Scope
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| REPLACE_FIRST | `0` | Заменять только первое вхождение текста на каждой из затронутых страниц |
| REPLACE_ALL | `1` | Заменять все вхождения текста на всех затронутых страницах |
