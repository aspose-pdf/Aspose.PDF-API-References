## TextSearchOptions.IgnoreResourceFontErrors property

Получает или задает индикатор, указывающий, что ошибки, связанные с отсутствием шрифта, будут игнорироваться поглотителем текста (фрагмента). true — означает, что ошибки отсутствия шрифта будут игнорироваться. Сегменты текста, ссылающиеся на некорректные ресурсы, будут пропущены при обработке. false (по умолчанию) — ошибка отсутствия шрифта завершит обработку, выбросив исключение.

```csharp
public bool IgnoreResourceFontErrors { get; set; }
```
