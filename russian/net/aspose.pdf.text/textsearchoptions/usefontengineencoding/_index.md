## TextSearchOptions.UseFontEngineEncoding property

Получает или задает индикатор, указывающий, что поиск текста будет выполнен с использованием кодировки шрифтового движка. true — означает, что будет использована кодировка шрифтового движка (используйте, если поиск текста не удаётся из‑за несовершенной кодировки в документе). false — означает, что будет использована кодировка шрифтов документа (значение по умолчанию).

```csharp
public bool UseFontEngineEncoding { get; set; }
```
