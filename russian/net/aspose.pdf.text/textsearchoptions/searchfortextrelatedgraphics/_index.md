## TextSearchOptions.SearchForTextRelatedGraphics property

Получает или задает значение, позволяющее выполнять поиск графических элементов, связанных с текстом (подчеркивание, фон и т.д.), во время поиска текста. true — поиск графики, связанной с текстом, будет выполнен (значение по умолчанию). false — графические элементы, присутствующие в исходном документе, будут игнорироваться. Установите это при проблемах с производительностью или если нет необходимости обрабатывать подчеркивание, фон или обрезку.

```csharp
public bool SearchForTextRelatedGraphics { get; set; }
```
