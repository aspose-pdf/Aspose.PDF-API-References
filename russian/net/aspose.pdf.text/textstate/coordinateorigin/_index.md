## TextState.CoordinateOrigin property

Получает или задаёт CoordinateOrigin текста. Если CoordinateOrigin имеет значение Descender, координата Y текста соответствует самой нижней точке шрифта. Если CoordinateOrigin имеет значение BaseLine, координата Y текста соответствует базовой линии шрифта. Значение по умолчанию — Descender. Если значение Descent шрифта слишком велико, текст может отображаться выше, чем у других шрифтов. В этом случае можно выбрать CoordinateOrigin BaseLine для лучшего отображения текста.

```csharp
public virtual CoordinateOrigin CoordinateOrigin { get; set; }
```
