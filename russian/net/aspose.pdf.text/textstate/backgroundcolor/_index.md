## TextState.BackgroundColor property

Устанавливает цвет фона текста.

```csharp
public virtual Color BackgroundColor { get; set; }
```

## Примечания

Обратите внимание, что значение не сохраняется как характеристика текста в документе. Геттер свойства BackgroundColor работает для объекта, если он был явно установлен ранее с помощью сеттера BackgroundColor для этого объекта. Свойство используется средой выполнения в контексте текущего процесса генерации/модификации.
