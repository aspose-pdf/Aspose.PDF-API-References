## MarkupParagraph.ContinuationPageNumbers property

Список номеров страниц, на которых продолжается абзац. Он будет совпадать со страницей, где абзац начался, если он продолжается в следующей колонке на той же странице.

```csharp
public List<int> ContinuationPageNumbers { get; }
```
