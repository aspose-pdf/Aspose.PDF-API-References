## TextExtractionOptions.ScaleFactor property

Получает или задает коэффициент, который будет применяться для масштабирования размера шрифта при извлечении в чистом режиме. Уменьшение значения приводит к большему количеству пробелов в извлечённом тексте. Значение по умолчанию — 1, без масштабирования; Установка значения в ноль позволяет алгоритму выбирать масштабирование автоматически.

```csharp
public double ScaleFactor { get; set; }
```
