## ParagraphAbsorberOptions.SectionUnbreakingHorizontalOverride property

Получает или задает максимальную длину зоны с «уровнем нулевого заполнения», которая не будет рассматриваться как реальный горизонтальный разрыв секции (в виде доли от ширины/высоты страницы). Значение по умолчанию — 0.005.

```csharp
public double SectionUnbreakingHorizontalOverride { get; set; }
```
