## SvgExtractionOptions.MinStrokeWidth property

Получает или задает минимальную ширину штриха, которая будет использоваться в результирующем SVG. Если PDF использует более тонкую ширину штриха, она будет заменена этой шириной. Значение по умолчанию — 0.5.

```csharp
public double MinStrokeWidth { get; set; }
```

## Примечания

Значение выражается в преобразованных единицах пользовательского пространства конвертированной PDF‑страницы. По умолчанию 1 единица пользовательского пространства равна 1/72 дюйма (0,35 мм), но это может быть переопределено документом PDF. Преобразования могут влиять на фактическую минимальную ширину в генерируемом SVG.
