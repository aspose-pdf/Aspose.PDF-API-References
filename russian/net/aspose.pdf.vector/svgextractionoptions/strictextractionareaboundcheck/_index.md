## SvgExtractionOptions.StrictExtractionAreaBoundCheck property

Получает и задает параметр, строго проверяющий, находятся ли подпути внутри указанного прямоугольника в [`ExtractionAreaBound`](../extractionareabound/). Если установить значение false, то подпути, которые не полностью включены в [`ExtractionAreaBound`](../extractionareabound/), будут извлечены. Значение по умолчанию — `True`.

```csharp
public bool StrictExtractionAreaBoundCheck { get; set; }
```
