### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Windows | `0` | Выбирает стиль переноса строк Windows (CRLF). |
| Unix | `1` | Выбирает стиль переноса строк Unix (LF). Также используется для OSX. |
