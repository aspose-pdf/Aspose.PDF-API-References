## HeadingRecognitionStrategy enumeration

Представляет типы стратегий распознавания заголовков.

```csharp
public enum HeadingRecognitionStrategy
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Outlines | `0` | Представляет стратегию распознавания заголовков с помощью outlines. |
| Heuristic | `1` | Представляет стратегию распознавания заголовков с помощью правил эвристики и статистики размеров шрифтов. |
| Auto | `2` | Обеспечивает автоматический выбор стратегии распознавания заголовков. Это вариант по умолчанию. Если документ содержит закладки, будет выбрана стратегия Outlines, иначе Heuristic. |
| None | `3` | Не распознавать заголовки. Этот вариант может быть полезен в сложных по форматированию документах. |
