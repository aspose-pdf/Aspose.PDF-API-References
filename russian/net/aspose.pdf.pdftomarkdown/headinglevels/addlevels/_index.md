## HeadingLevels.AddLevels method

Добавляет уровни заголовков. Коллекция размеров шрифтов должна быть отсортирована по убыванию.

```csharp
public void AddLevels(ICollection<double> fontSizes)
```

| Параметр | Тип | Описание |
| --- | --- | --- |
| fontSizes | ICollection`1 | Значения должны быть отсортированы по убыванию. |

### Исключения

| исключение | условие |
| --- | --- |
| ArgumentException | Если значение не отсортировано или значение меньше единицы. |
