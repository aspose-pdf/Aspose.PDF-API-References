## Пространства имён

| Пространство имён | Описание |
| --- | --- |
| [Aspose.Pdf](./aspose.pdf/) | Это **Aspose.Pdf** — корневое пространство имён для всех классов библиотеки Aspose.Pdf, которые находятся либо непосредственно в нём, как **Document**, либо косвенно через несколько подпроcтранств имён. |
| [Aspose.Pdf.AI](./aspose.pdf.ai/) | Пространство имён **Aspose.Pdf.AI** предоставляет классы для функций ИИ, включая клиентские API и интеллектуальных помощников. |
| [Aspose.Pdf.Annotations](./aspose.pdf.annotations/) | Пространство имён **Aspose.Pdf.Annotations** предоставляет классы для работы с различными типами действий, назначений и другими функциями документа, которые традиционно называют интерактивными, предоставляя пользователю возможность взаимодействовать с ним. |
| [Aspose.Pdf.Comparison](./aspose.pdf.comparison/) | Пространство имён **Aspose.Pdf.Comparison** предоставляет классы, используемые для сравнения документов. |
| [Aspose.Pdf.DataEditor](./aspose.pdf.dataeditor/) | Пространство имён **Aspose.Pdf.DataEditor** содержит инструменты для редактирования данных внутри документа. |
| [Aspose.Pdf.Devices](./aspose.pdf.devices/) | Пространство имён **Aspose.Pdf.Devices** предоставляет классы, используемые для представления документа в виде изображений или простого текста. Таким образом, документ может быть передан на текстовые или различные графические устройства, что позволяет получить его текстовое или графическое представление. |
| [Aspose.Pdf.Drawing](./aspose.pdf.drawing/) | Пространство имён **Aspose.Pdf.Drawing** предоставляет классы, описывающие графические примитивы, такие как дуга, линия, круг и т.д. Соответствующие объекты могут использоваться для создания новых документов. |
| [Aspose.Pdf.Facades](./aspose.pdf.facades/) | Пространство имён **Aspose.Pdf.Facades** предоставляет классы, изначально пришедшие из Aspose.Pdf.Kit. Эти классы используются для манипулирования документами, выполняя операции такие как объединение, наложение штампов, подпись, аннотирование и т.п., но на высоком уровне без доступа к внутренней структуре документа. |
| [Aspose.Pdf.Forms](./aspose.pdf.forms/) | Пространство имён **Aspose.Pdf.Forms** содержит классы, описывающие формы (стандартные, статические, динамические) и различные типы полей, такие как текстовое поле, список, переключатель и т.д. |
| [Aspose.Pdf.LogicalStructure](./aspose.pdf.logicalstructure/) | Пространство имён **Aspose.Pdf.Tagged.LogicalStructure** — это пространство имён для классов логической структуры PDF. |
| [Aspose.Pdf.Multithreading](./aspose.pdf.multithreading/) | Пространство имён **Aspose.Pdf.Multithreading** предоставляет классы, предназначенные для использования в многопоточных сценариях. |
| [Aspose.Pdf.Operators](./aspose.pdf.operators/) | Пространство имён **Aspose.Pdf.Operators** — это пространство имён для реализаций операторов. Эти классы описывают операторы, используемые в содержимом страниц PDF. |
| [Aspose.Pdf.Optimization](./aspose.pdf.optimization/) | Пространство имён **Aspose.Pdf.Optimization** — это пространство имён для классов, управляющих процессом оптимизации документа. |
| [Aspose.Pdf.Plugins](./aspose.pdf.plugins/) | Пространство имён **Aspose.Pdf.Plugins** — это корневое пространство имён для всех классов Aspose.Pdf.Plugins, которые находятся либо непосредственно в нём, как **PdfOrganizer**, либо косвенно через несколько подпроcтранств имён. |
| [Aspose.Pdf.Printing](./aspose.pdf.printing/) | Пространство имён **Aspose.Pdf.Printing** предоставляет классы и функции для работы с операциями печати PDF, включая настройки принтера, параметры страниц и расширения для управления конфигурациями, связанными с печатью. |
| [Aspose.Pdf.Sanitization](./aspose.pdf.sanitization/) | Пространство имён **Aspose.Pdf.Sanitization** — это пространство имён для операций санитизации. |
| [Aspose.Pdf.Security](./aspose.pdf.security/) | Пространство имён **Aspose.Pdf.Security** содержит классы, используемые для шифрования и цифровой подписи. |
| [Aspose.Pdf.Signatures](./aspose.pdf.signatures/) | Пространство имён **Aspose.Pdf.Signatures** содержит классы, используемые для обнаружения скомпрометированных подписей. |
| [Aspose.Pdf.Structure](./aspose.pdf.structure/) | Пространство имён **Aspose.Pdf.Structure** предоставляет классы, помогающие работать с логической структурой документа, представляющей организацию документа на главы и разделы, а также идентификацию специальных элементов, таких как рисунки, таблицы и сноски. |
| [Aspose.Pdf.Tagged](./aspose.pdf.tagged/) | Пространство имён **Aspose.Pdf.Tagged** — это пространство имён для классов, поддерживающих Tagged PDF документы. |
| [Aspose.Pdf.Text](./aspose.pdf.text/) | Пространство имен **Aspose.Pdf.Text** предоставляет классы, позволяющие извлекать текст, добавлять текст, изменять существующий текст Document. Оно также содержит классы, позволяющие извлекать, заменять, подменять шрифты Document. |
| [Aspose.Pdf.Vector](./aspose.pdf.vector/) | Пространство имен **Aspose.Pdf.Vector** является корневым пространством имен для графических операций. |
| [Aspose.Pdf.XfaConverter](./aspose.pdf.xfaconverter/) | Пространство имен **Aspose.Pdf.XfaConverter** предоставляет классы, позволяющие конвертировать XFA. |
