| [CosPdfName](./cospdfname/) | Этот класс представляет объект Pdf Name. |
| [CosPdfNumber](./cospdfnumber/) | Этот класс представляет тип Pdf Number. |
| [CosPdfPrimitive](./cospdfprimitive/) | Этот класс представляет базовый публичный тип [`CosPdfPrimitive`](../aspose.pdf.dataeditor/cospdfprimitive/). |
| [CosPdfString](./cospdfstring/) | Этот класс представляет объект Pdf String. |
| [DictionaryEditor](./dictionaryeditor/) | Класс для доступа к дереву словарей Document (document dictionary, page dictionary, resources dictionary). |
