## ComparisonOptions.ExtractionArea property

Получить и установить прямоугольную область, в которой будет сравниваться текст страниц. Этот параметр нельзя задать вместе с параметрами [`ExcludeTables`](../excludetables/), [`ExcludeAreas1`](../excludeareas1/) и [`ExcludeAreas2`](../excludeareas2/).

public Rectangle ExtractionArea { get; set; }
