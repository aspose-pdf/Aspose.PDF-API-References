## ComparisonOptions.ExcludeAreas1 property

Получайте и задавайте области исключения. Используется для первой Page или Document в методе сравнения. Эта опция может быть установлена вместе с [`ExcludeTables`](../excludetables/). Эта опция не может быть установлена вместе с опцией [`ExtractionArea`](../extractionarea/).

public Rectangle[] ExcludeAreas1 { get; set; }
