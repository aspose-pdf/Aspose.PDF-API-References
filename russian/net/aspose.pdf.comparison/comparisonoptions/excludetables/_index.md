## ComparisonOptions.ExcludeTables property

Получить и установить параметр, определяющий, исключаются ли таблицы из сравнения. Этот параметр нельзя задавать одновременно с параметром [`ExtractionArea`](../extractionarea/). Значение по умолчанию — `false`.

```csharp
public bool ExcludeTables { get; set; }
```
