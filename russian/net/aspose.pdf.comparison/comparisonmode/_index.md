## ComparisonMode enumeration

Перечисление режимов сравнения.

```csharp
public enum ComparisonMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Normal | `0` | Нормальный режим. Учитываются только пробелы внутри текстовых фрагментов (в зависимости от способа генерации документа). |
| IgnoreSpaces | `1` | Все пробелы игнорируются. Изменения ищутся только в словах. |
| ParseSpaces | `2` | Режим похож на нормальный, но пытается учитывать визуальное расстояние между текстовыми фрагментами на основе расстояния. Определение количества пробелов между фрагментами может быть неточным, поскольку это сильно зависит от способа генерации документов. Если документы созданы разными генераторами, могут возникнуть неточности при сравнении пробелов между текстовыми фрагментами. |
