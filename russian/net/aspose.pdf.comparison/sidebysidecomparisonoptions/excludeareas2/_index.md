## SideBySideComparisonOptions.ExcludeAreas2 property

Получайте и задавайте области исключения. Используется для второй Page или Document в методе сравнения. Эта опция может быть установлена вместе с [`ExcludeTables`](../excludetables/). Эта опция не может быть установлена вместе с опцией [`ComparisonArea2`](../comparisonarea2/).

```csharp
public Rectangle[] ExcludeAreas2 { get; set; }
```
