## SideBySideComparisonOptions.ExcludeTables property

Получайте и задавайте опцию, определяющую, исключаются ли таблицы из сравнения. Эта опция не может быть установлена одновременно с [`ComparisonArea1`](../comparisonarea1/) и [`ComparisonArea2`](../comparisonarea2/). Значение по умолчанию — `false`.

```csharp
public bool ExcludeTables { get; set; }
```
