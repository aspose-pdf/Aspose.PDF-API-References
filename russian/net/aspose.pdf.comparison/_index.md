Выбор изменений приводит к добавлению пробельных символов вокруг форматирования, иначе markdown‑просмотрщик некорректно отобразит текст. Удалённые разрывы строк обозначаются знаком абзаца «-». |
| [OutputTextStyle](./outputtextstyle/) | Представляет класс набора стилей для пометки изменений текста. |

| [SideBySideComparisonOptions](./sidebysidecomparisonoptions/) | Представляет класс параметров для сравнения документов с выводом бок о бок. |
| [SideBySidePdfComparer](./sidebysidepdfcomparer/) |  |
