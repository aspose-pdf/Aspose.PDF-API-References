## ITaggedContent.Save method

Сохраняет текущее состояние размеченного содержимого в связанный PDF‑документ.

```csharp
public void Save()
```

## Примечания

Этот метод гарантирует, что все элементы помеченного содержимого правильно обновляются и сохраняются в PDF документе. Он выполняет необходимые операции, такие как обновление MCID для элементов MCR, установка операторов BDC и обеспечение соответствия стандартам PDF/UA.
