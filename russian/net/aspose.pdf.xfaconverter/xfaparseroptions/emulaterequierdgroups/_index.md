## XfaParserOptions.EmulateRequierdGroups property

Если это свойство истинно, то будут нарисованы дополнительные красные прямоугольники для требуемых Xfa "исключённых групп". Это свойство было введено из‑за отсутствия аналогов исключённых групп при преобразовании представления Xfa форм в стандарт. По умолчанию значение ложно.

```csharp
public bool EmulateRequierdGroups { get; set; }
```
