## ExplicitDestinationType enumeration

Перечисляет типы явных пунктов назначения.

```csharp
public enum ExplicitDestinationType
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| XYZ | `0` | Отображает страницу так, чтобы координаты (left, top) располагались в левом верхнем углу окна, а содержимое страницы увеличивалось в соответствии с коэффициентом zoom. Значение null для любого из параметров left, top или zoom указывает, что текущие значения этих параметров должны оставаться без изменений. Значение zoom, равное 0, имеет то же значение, что и null. |
| Fit | `1` | Отображает страницу так, чтобы её содержимое было увеличено ровно настолько, чтобы вся страница полностью помещалась в окне как по горизонтали, так и по вертикали. Если требуемые коэффициенты масштабирования по горизонтали и вертикали различаются, используется меньший из них, при этом страница центрируется в окне по другой оси. |
| FitH | `2` | Отображает страницу так, чтобы вертикальная координата top располагалась у верхнего края окна, а содержимое страницы увеличивалось ровно настолько, чтобы вся ширина страницы полностью помещалась в окне. Значение null для top указывает, что текущий параметр должен оставаться без изменений. |
| FitV | `3` | Отображает страницу так, чтобы горизонтальная координата left располагалась у левого края окна, а содержимое страницы увеличивалось ровно настолько, чтобы вся высота страницы полностью помещалась в окне. Значение null для left указывает, что текущий параметр должен оставаться без изменений. |
| FitR | `4` | Отображает страницу так, чтобы её содержимое было увеличено ровно настолько, чтобы прямоугольник, заданный координатами left, bottom, right и top, полностью помещался в окне как по горизонтали, так и по вертикали. Если требуемые коэффициенты масштабирования по горизонтали и вертикали различаются, используется меньший из них, при этом прямоугольник центрируется в окне по другой оси. Значение null для любого из параметров может привести к непредсказуемому поведению. |
| FitB | `5` | Отображает страницу так, чтобы её содержимое было увеличено ровно настолько, чтобы её ограничивающий прямоугольник полностью помещался в окне как по горизонтали, так и по вертикали. Если требуемые коэффициенты масштабирования по горизонтали и вертикали различаются, используется меньший из них, при этом ограничивающий прямоугольник центрируется в окне по другой оси. |
| FitBH | `6` | Отображает страницу так, чтобы вертикальная координата top располагалась у верхнего края окна, а содержимое страницы увеличивалось ровно настолько, чтобы вся ширина её ограничивающего прямоугольника полностью помещалась в окне. Значение null для top указывает, что текущий параметр должен оставаться без изменений. |
| FitBV | `7` | Отображает страницу так, чтобы горизонтальная координата left располагалась у левого края окна, а содержимое страницы увеличивалось ровно настолько, чтобы вся высота её ограничивающего прямоугольника полностью помещалась в окне. Значение null для left указывает, что текущий параметр должен оставаться без изменений. |
