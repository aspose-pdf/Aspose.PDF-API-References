## SubmitFormAction.EmbedForm field

Если установлено, запись F в отправленном FDF должна быть спецификацией файла, содержащей встроенный поток файла, представляющий PDF‑файл, из которого отправляется FDF.

```csharp
public const int EmbedForm;
```
