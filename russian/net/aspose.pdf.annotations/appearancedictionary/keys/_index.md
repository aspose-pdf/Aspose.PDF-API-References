## AppearanceDictionary.Keys property

Возвращает ключи словаря. Если у словаря внешнего вида есть подсловаря, то `Keys` содержит значения (N&#x7C;R&#x7C;D).state, где N - normal appearance, R - rollover appearance, D - down appearance и state - имя состояния (например, On, Off для флажков).

public ICollection<string> Keys { get; }
