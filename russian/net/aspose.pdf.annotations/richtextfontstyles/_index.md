## RichTextFontStyles enumeration

Параметры стилизации текстовых фрагментов в RichText.

```csharp
[Flags]
public enum RichTextFontStyles
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| ClearExisting | `1` | Если установлен, очищает все существующие стили перед применением дополнительных. При комбинировании с другими флагами стилей (например, Bold), сначала сбрасывает стили, затем применяет указанные. Без этого флага новые стили добавляются к существующим. |
| Bold | `2` | Опция, указывающая жирный шрифт. |
| Italic | `4` | Опция, указывающая курсив. |
| Underline | `8` | Опция, указывающая подчёркивание. |
