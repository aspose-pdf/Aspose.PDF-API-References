## AnnotationFlags enumeration

Набор флагов, определяющих различные характеристики аннотации.

```csharp
[Flags]
public enum AnnotationFlags
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| Default | `0` | Значение по умолчанию. |
| Invisible | `1` | Если установлен, не отображать Annotation, если она не относится к одному из стандартных типов Annotation и отсутствует обработчик Annotation. Если сброшен, отображать такую неизвестную Annotation, используя поток отображения, указанный в её словаре отображения, если он существует. |
| Hidden | `2` | Если установлен, не отображать и не печатать Annotation и не позволять ей взаимодействовать с пользователем, независимо от её типа Annotation или наличия обработчика Annotation. В случаях ограниченного экранного пространства возможность избирательно скрывать и показывать Annotations может использоваться в сочетании с потоками отображения для отображения вспомогательной всплывающей информации, аналогичной по функции онлайн‑системам справки. |
| Print | `4` | Если установлен, печатать Annotation при печати Page. Если сброшен, никогда не печатать Annotation, независимо от того, отображается ли она на экране. Это может быть полезно, например, для Annotations, представляющих интерактивные кнопки, которые не имеют смысла на печатной Page. |
| NoZoom | `8` | Если установлен, не масштабировать отображение Annotation в соответствии с увеличением Page. Расположение Annotation на Page (определяемое верхним левым углом её прямоугольника Annotation) остаётся фиксированным, независимо от увеличения Page. |
| NoRotate | `10` | Если установлен, не вращать отображение Annotation в соответствии с поворотом Page. Верхний левый угол прямоугольника Annotation остаётся в фиксированном положении на Page, независимо от её поворота. |
| NoView | `20` | Если установлен, не отображать Annotation на экране и не позволять ей взаимодействовать с пользователем. Annotation может быть напечатана (в зависимости от настройки флага Print), но должна считаться скрытой для целей отображения на экране и взаимодействия с пользователем. |
| ReadOnly | `40` | Если установлен, не позволять Annotation взаимодействовать с пользователем. Annotation может отображаться или печататься (в зависимости от настроек флагов NoView и Print), но не должна реагировать на щелчки мыши или менять своё отображение в ответ на движения мыши. Этот флаг игнорируется для widget Annotations; его функция поглощена флагом ReadOnly связанного поля формы. |
| Locked | `80` | Если установлен, не позволять удалять Annotation или изменять её свойства (включая позицию и размер) пользователем. Однако этот флаг не ограничивает изменения содержимого Annotation, например значения поля формы. |
| ToggleNoView | `100` | Если установлен, инвертировать интерпретацию флага NoView для определённых событий. Типичное применение — Annotation, которая появляется только когда курсор мыши удерживается над ней. |
| LockedContents | `200` | Если установлен, не позволять пользователю изменять содержимое Annotation. Этот флаг не ограничивает удаление Annotation или изменения других её свойств, таких как позиция и размер. |
