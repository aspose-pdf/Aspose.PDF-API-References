## RenditionOperation enumeration

Операция, которую следует выполнить при срабатывании действия.

```csharp
public enum RenditionOperation
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| PlayStop | `0` | Если с аннотацией не связан рендеринг, воспроизведите указанный рендеринг, связав его с аннотацией. Если рендеринг уже связан с аннотацией, он будет остановлен, и новый рендеринг будет связан с аннотацией. |
| Stop | `1` | Остановить любой рендеринг, воспроизводимый в связке с аннотацией. |
| Pause | `2` | Приостановить любой рендеринг, воспроизводимый в связке с аннотацией. |
| Resume | `3` | Возобновить любой рендеринг, воспроизводимый в связке с аннотацией. |
| PlayResume | `4` | Воспроизвести указанный рендеринг, связав его с аннотацией. Если рендеринг уже связан с аннотацией, возобновить рендеринг, если он приостановлен. |
| Undefined | `-1` | Операция не определена. |
