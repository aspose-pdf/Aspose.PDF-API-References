## HighlightingMode enumeration

Перечисляет режим подсветки аннотации, визуальный эффект, используемый при нажатии или удержании кнопки мыши внутри её активной области.

```csharp
public enum HighlightingMode
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Без подсветки. |
| Invert | `1` | Инвертировать содержимое прямоугольника аннотации. |
| Outline | `2` | Инвертировать границу аннотации. |
| Push | `3` | Отобразить внешний вид аннотации при нажатии, если он определён. Если внешний вид при нажатии не задан, сместить содержимое прямоугольника аннотации так, чтобы оно выглядело так, как будто оно нажато вниз к поверхности страницы. |
| Toggle | `4` | То же, что Push (рекомендовано). |
