## LineEnding enumeration

Перечисляет стили завершения линии, используемые при рисовании линии.

```csharp
public enum LineEnding
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Без завершения линии. |
| Square | `1` | Квадрат, заполненный внутренним цветом аннотации, если он задан. |
| Circle | `2` | Круг, заполненный внутренним цветом аннотации, если он задан. |
| Diamond | `3` | Алмазная форма, заполненная внутренним цветом аннотации, если он задан. |
| OpenArrow | `4` | Две короткие линии, соединяющиеся под острым углом, образуя открытый наконечник стрелки. |
| ClosedArrow | `5` | Две короткие линии, соединяющиеся под острым углом, как в стиле OpenArrow, и соединённые третьей линией, образуя треугольный закрытый наконечник стрелки, заполненный внутренним цветом аннотации, если он задан. |
| Butt | `6` | Короткая линия в конце, перпендикулярная самой линии. |
| ROpenArrow | `7` | Две короткие линии в обратном направлении от OpenArrow. |
| RClosedArrow | `8` | Треугольный закрытый наконечник стрелки в обратном направлении от ClosedArrow. |
| Slash | `9` | Короткая линия в конце, примерно под 30 градусов по часовой стрелке от перпендикуляра к самой линии. |
