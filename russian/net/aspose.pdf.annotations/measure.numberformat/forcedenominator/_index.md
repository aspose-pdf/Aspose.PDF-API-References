## Measure.NumberFormat.ForceDenominator property

Если FractionDisplayment имеет значение ShowAsFraction, это значение определяет, будет ли дробь сокращена. Если значение истинно, дробь может не быть сокращена.

```csharp
public bool ForceDenominator { get; set; }
```
