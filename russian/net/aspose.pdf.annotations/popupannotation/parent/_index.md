## PopupAnnotation.Parent property

Получает или задаёт родительскую аннотацию, с которой должна быть связана эта всплывающая аннотация. Если эта запись присутствует, записи Contents, M, C и T родительской аннотации переопределят соответствующие записи самой всплывающей аннотации.

public Annotation Parent { get; set; }
