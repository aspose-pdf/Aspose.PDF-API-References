## PrinterMarksKind enumeration

Указывает типы принтерных меток, которые следует добавить в документ.

```csharp
[Flags]
public enum PrinterMarksKind
```

### Значения

| Имя | Значение | Описание |
| --- | --- | --- |
| None | `0` | Указывает, что никаких отметок принтера не следует добавлять. |
| TrimMarks | `1` | Указывает, что следует добавить метки обрезки. |
| BleedMarks | `2` | Указывает, что следует добавить метки вылета. |
| RegistrationMarks | `4` | Указывает, что следует добавить регистрационные метки. |
| ColorBars | `8` | Указывает, что следует добавить цветовые полосы. |
| PageInformation | `10` | Указывает, что следует добавить информацию о странице. |
| All | `1F` | Указывает, что следует добавить все типы отметок принтера. |

## Примечания

Это перечисление имеет атрибут FlagsAttribute, позволяющий выполнять побитовое комбинирование значений его членов.
