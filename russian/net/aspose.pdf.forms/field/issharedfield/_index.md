## Field.IsSharedField property

Свойство для поддержки Generator. Используется, когда поле добавляется в заголовок или нижний колонтитул. Если true, это поле будет создано один раз, и его внешний вид будет виден на всех страницах Document. Если false, отдельное поле будет создано для каждой страницы Document.

```csharp
public bool IsSharedField { get; set; }
```
