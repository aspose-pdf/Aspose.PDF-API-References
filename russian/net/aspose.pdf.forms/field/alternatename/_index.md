## Field.AlternateName property

Получает или задает альтернативное имя поля (альтернативное имя поля, которое должно использоваться вместо фактического имени поля везде, где поле идентифицируется в пользовательском интерфейсе). Альтернативное имя используется как всплывающая подсказка поля в Adobe Acrobat.

```csharp
public string AlternateName { get; set; }
```
