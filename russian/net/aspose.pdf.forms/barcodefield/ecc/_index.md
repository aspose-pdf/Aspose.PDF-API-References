## BarcodeField.ECC property

Получает целочисленное значение, представляющее коэффициент коррекции ошибок. Для PDF417 оно должно быть от 0 до 8. Для QRCode оно должно быть от 0 до 3 (0 для 'L', 1 для 'M', 2 для 'Q' и 3 для 'H').

public int ECC { get; }
