## RadioButtonField.NoToggleToOff property

Получает или задает флаг, позволяющий радиокнопке не иметь выбранного значения. Если `true`, всегда должна быть выбрана ровно одна радиокнопка; выбор уже выбранной кнопки не оказывает эффекта. Если `false`, щелчок по выбранной кнопке снимает её выбор, оставляя все кнопки невыбранными.

```csharp
public bool NoToggleToOff { get; set; }
```

## Примечания

Некоторые PDF‑просмотрщики (включая Adobe Acrobat) могут игнорировать состояние `false` флага.
