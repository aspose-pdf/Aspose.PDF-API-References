## Form.NeedsRendering property

Возвращает значение, указывающее, требуется ли удаление динамической формы XFA из документа. Это свойство было введено для определения, следует ли использовать [`IgnoreNeedsRendering`](../ignoreneedsrendering/) для удаления формы XFA в случаях, когда форма XFA присутствует и `NeedsRendering` равно false.

```csharp
public bool NeedsRendering { get; }
```
