## Form.HasXfa property

Получает значение, указывающее, содержит ли Document XFA форму. Это свойство было введено для определения, следует ли использовать [`IgnoreNeedsRendering`](../ignoreneedsrendering/) для удаления XFA формы в случаях, когда XFA форма присутствует и [`NeedsRendering`](../needsrendering/) равно false.

```csharp
public bool HasXfa { get; }
```
