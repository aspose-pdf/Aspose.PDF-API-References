## Form.IgnoreNeedsRendering property

Если это свойство равно true, значение ключа NeedsRendering будет игнорироваться при конвертации формы XFA в стандартную форму. По умолчанию false.

```csharp
public bool IgnoreNeedsRendering { get; set; }
```
