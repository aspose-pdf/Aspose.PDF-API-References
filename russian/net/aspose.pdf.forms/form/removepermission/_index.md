## Form.RemovePermission property

Если это свойство истинно, словарь "Perms" будет удалён из pdf document после преобразования динамических документов в стандартные. Словарь "Perms" может содержать правила, которые нарушают отображение выбора обязательных полей в Adobe Acrobat reader. По умолчанию значение ложно.

```csharp
public bool RemovePermission { get; set; }
```
