## IconFit.SpreadOnBorder property

Если true, указывает, что внешний вид кнопки должен быть масштабирован так, чтобы полностью помещаться в границах аннотации, не учитывая ширину линии границы.

```csharp
public bool SpreadOnBorder { get; set; }
```
