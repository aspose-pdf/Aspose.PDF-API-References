Предоставляет набор предопределённых экземпляров {@link PrintPaperSource}, представляющих общие источники бумаги. Этот класс не может быть наследован.

## Поля

| Поле | Описание |
| --- | --- |
| [AutomaticFeed](#AutomaticFeed) | Представляет источник бумаги с автоматической подачей. |
| [Cassette](#Cassette) | Представляет кассету бумаги принтера. |
| [Envelope](#Envelope) | Представляет автоматический источник бумаги с подачей конвертов. |
| [FormSource](#FormSource) | Представляет лоток принтера по умолчанию. |
| [LargeCapacity](#LargeCapacity) | Представляет лоток большой ёмкости принтера. |
| [LargeFormat](#LargeFormat) | Представляет лоток для бумаги более крупного формата. |
| [Lower](#Lower) | Представляет нижний лоток принтера. |
| [Manual](#Manual) | Представляет источник бумаги с ручной подачей. |
| [ManualFeedEnvelope](#ManualFeedEnvelope) | Представляет источник бумаги с ручной подачей конвертов. |
| [Middle](#Middle) | Представляет средний лоток принтера. |
| [SmallFormat](#SmallFormat) | Представляет лоток для бумаги меньшего формата. |
| [TractorFeed](#TractorFeed) | Представляет источник непрерывной бумаги с тракторной подачей. |
| [Upper](#Upper) | Представляет верхний лоток принтера, либо лоток по умолчанию, если у принтера только один лоток. |
