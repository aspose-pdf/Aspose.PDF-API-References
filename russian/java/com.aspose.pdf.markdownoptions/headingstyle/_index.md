Определяет доступные стили сериализации для заголовков. Для спецификации см. CommonMark — ATX headings, соответственно CommonMark — Setext headings.

## Поля

| Поле | Описание |
| --- | --- |
| [Atx](#Atx) | Добавлять префикс к заголовкам с помощью "#" |
| [Setext](#Setext) | Подчеркивать заголовки уровней 1 и 2 с помощью "======" соответственно "------". Заголовки Setext доступны только для уровней 1 и 2. Даже если стиль заголовка установлен на Setext, для уровней 3 и выше будет использоваться стиль Atx. |

### Atx {#Atx}
```
public static final int Atx
```

Добавлять префикс к заголовкам с помощью "#"

### Setext {#Setext}
```
public static final int Setext
```

Подчеркивать заголовки уровней 1 и 2 с помощью "======" соответственно "------". Заголовки Setext доступны только для уровней 1 и 2. Даже если стиль заголовка установлен на Setext, для уровней 3 и выше будет использоваться стиль Atx.
