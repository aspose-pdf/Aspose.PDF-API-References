## Классы

| Класс | Описание |
| --- | --- |
| [ValidationMethod](./validationmethod/) | Представляет перечисление, определяющее метод, используемый для проверки сертификата. |
| [ValidationMode](./validationmode/) | Указывает режим проверки для процессов валидации подписи PDF. |
| [ValidationOptions](./validationoptions/) | Представляет параметры проверки цифровой подписи в PDF‑документе. |
| [ValidationResult](./validationresult/) | Представляет результат процесса проверки сертификата. Класс ValidationResult предоставляет информацию о результате проверки сертификата, включая его статус и сообщение, описывающее любые проблемы, возникшие во время проверки. |
| [ValidationStatus](./validationstatus/) | Представляет статус проверки сертификата. Этот перечисление определяет возможные результаты проверки сертификата: - Valid: Указывает, что сертификат был успешно проверен. - Invalid: Указывает, что проверка сертификата не удалась. - Undefined: Указывает, что процесс проверки был неоднозначным или не выполнен. |
