## Классы

| Класс | Описание |
| --- | --- |
| [ExtractedFragmentsProcessorBase](./extractedfragmentsprocessorbase/) | Представляет базовый класс для процессоров извлечённых фрагментов. |
| [IgnoreSpacesFragmentsProcessor](./ignorespacesfragmentsprocessor/) | Представляет класс для обработки текстовых фрагментов в режиме игнорирования пробелов. Этот класс игнорирует все пробельные символы, выделяя отдельные слова как фрагменты. |
| [NormalFragmentProcessor](./normalfragmentprocessor/) | Представляет класс для обработки текстовых фрагментов в обычном режиме. Этот класс учитывает только пробелы внутри фрагментов. |
| [ParseSpacesFragmentsProcessor](./parsespacesfragmentsprocessor/) | Представляет класс для обработки текстовых фрагментов в режиме разбора пробелов. Этот класс распознаёт пробелы между текстовыми фрагментами на основе расстояния между ними. |
