```
public interface ITociElement
```

Представляет элемент, который может выступать в качестве записи оглавления (TOCI) в помеченном PDF‑документе. Этот интерфейс абстрагирует как стандартные элементы TOCI, так и элементы списка (LI), используемые во вложенных структурах оглавления.

```
StructureElement getGetElement()
```
