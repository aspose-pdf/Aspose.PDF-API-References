Стиль окончания линии должен определять форму, используемую на концах открытых подпутей (и штрихов, если они есть) при их обводке.

## Поля

| Поле | Описание |
| --- | --- |
| [ButtCap](#ButtCap) | Окончание «бутт». Обводка должна заканчиваться квадратом в конечной точке пути. Не должно быть проекции за конец пути. |
| [RoundCap](#RoundCap) | Окончание «круг». Полукруглая дуга с диаметром, равным ширине линии, должна быть нарисована вокруг конечной точки и заполнена. |
| [SquareCap](#SquareCap) | Выступающее квадратное окончание. Обводка должна продолжаться за конечную точку пути на расстояние, равное половине ширины линии, и заканчиваться квадратом. |

Окончание «бутт». Обводка должна заканчиваться квадратом в конечной точке пути. Не должно быть проекции за конец пути.

### RoundCap {#RoundCap}
```

```

Окончание «круг». Полукруглая дуга с диаметром, равным ширине линии, должна быть нарисована вокруг конечной точки и заполнена.

### SquareCap {#SquareCap}
```
public static final int SquareCap
```

Выступающее квадратное окончание. Обводка должна продолжаться за конечную точку пути на расстояние, равное половине ширины линии, и заканчиваться квадратом.
