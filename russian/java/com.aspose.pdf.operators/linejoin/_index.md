Стиль соединения линий должен определять форму, используемую в углах обводимых путей.

## Поля

| Поле | Описание |
| --- | --- |
| [BevelJoin](#BevelJoin) | Срезанное соединение. Два сегмента должны заканчиваться окончанием «бутт» (см. 8.4.3.3, "Line Cap Style"), а полученный вырез за концами сегментов должен быть заполнен треугольником. |
| [MiterJoin](#MiterJoin) | Скошенное соединение. Внешние края обводки двух сегментов должны быть продлены до их встречи под углом, как в рамке картины. Если сегменты встречаются под слишком острым углом, определяемым параметром предела скошенного соединения (см. 8.4.3.5, "Miter Limit"), вместо этого следует использовать срезанное соединение. |
| [RoundJoin](#RoundJoin) | Округлое соединение. Дуга круга с диаметром, равным толщине линии, должна быть нарисована вокруг точки, где встречаются два сегмента, соединяя внешние края штрихов обоих сегментов. Эта фигурка в виде куска пирога должна быть заполнена, создавая скруглённый угол. |

### BevelJoin {#BevelJoin}
```
public static final int BevelJoin
```

Срезанное соединение. Два сегмента должны заканчиваться окончанием «бутт» (см. 8.4.3.3, "Line Cap Style"), а полученный вырез за концами сегментов должен быть заполнен треугольником.

### MiterJoin {#MiterJoin}
```
public static final int MiterJoin
```

Скошенное соединение. Внешние края обводки двух сегментов должны быть продлены до их встречи под углом, как в рамке картины. Если сегменты встречаются под слишком острым углом, определяемым параметром предела скошенного соединения (см. 8.4.3.5, "Miter Limit"), вместо этого следует использовать срезанное соединение.

### RoundJoin {#RoundJoin}
```
public static final int RoundJoin
```

Округлое соединение. Дуга круга с диаметром, равным толщине линии, должна быть нарисована вокруг точки, где встречаются два сегмента, соединяя внешние края штрихов обоих сегментов. Эта фигурка в виде куска пирога должна быть заполнена, создавая скруглённый угол.
