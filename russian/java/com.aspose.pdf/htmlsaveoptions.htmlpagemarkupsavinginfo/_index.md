Если свойство SplitToPages у HtmlSaveOptions, то при конвертации PDF в HTML создаются несколько HTML‑файлов (по одному HTML‑файлу на каждую преобразованную страницу). Этот класс представляет набор данных, связанных с пользовательским сохранением разметки одной HTML‑страницы при конвертации PDF в HTML.
