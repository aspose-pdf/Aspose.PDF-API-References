Указывает типы меток принтера, которые будут добавлены в документ. Это перечисление имеет атрибут {@link FlagsAttribute}, позволяющий выполнять побитовые комбинации значений его членов.

## Поля

| Поле | Описание |
| --- | --- |
| [All](#All) | Указывает, что все типы меток принтера должны быть добавлены. |
| [BleedMarks](#BleedMarks) | Указывает, что метки обрезки должны быть добавлены. |
| [ColorBars](#ColorBars) | Указывает, что цветные полосы должны быть добавлены. |
| [None](#None) | Указывает, что метки принтера не должны быть добавлены. |
| [PageInformation](#PageInformation) | Указывает, что информация о странице должна быть добавлена. |
| [RegistrationMarks](#RegistrationMarks) | Указывает, что регистрационные метки должны быть добавлены. |
| [TrimMarks](#TrimMarks) | Указывает, что метки обрезки должны быть добавлены. |
