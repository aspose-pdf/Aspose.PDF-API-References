Перечисляет режимы, которые могут использоваться для сохранения шрифтов, указанных в сохранённом PDF.

## Поля

| Поле | Описание |
| --- | --- |
| [AlwaysSaveAsEOT](#AlwaysSaveAsEOT) | Все упомянутые шрифты будут сохранены и указаны как EOT‑шрифты. |
| [AlwaysSaveAsTTF](#AlwaysSaveAsTTF) | Все упомянутые шрифты будут сохранены и указаны как TTF‑шрифты. |
| [AlwaysSaveAsWOFF](#AlwaysSaveAsWOFF) | Все указанные шрифты будут сохранены и использованы в виде WOFF‑шрифтов. |
| [DontSave](#DontSave) | Все указанные шрифты не будут сохранены. |
| [SaveInAllFormats](#SaveInAllFormats) | Все указанные шрифты будут сохранены (и использованы в CSS) как 3 независимых файла: EOT, TTH, WOFF. Это увеличивает размер выходных данных, но делает вывод совместимым с подавляющим большинством веб‑браузеров. |

### DontSave {#DontSave}
```
public static final int DontSave
```

### SaveInAllFormats {#SaveInAllFormats}
```
public static final int SaveInAllFormats
```

Все указанные шрифты будут сохранены (и использованы в CSS) как 3 независимых файла: EOT, TTH, WOFF. Это увеличивает размер выходных данных, но делает вывод совместимым с подавляющим большинством веб‑браузеров.
