Представляет аннотацию Page Information в PDF‑документе. Эта аннотация содержит имя файла, номер страницы и дату и время создания аннотации. Этот класс в основном используется для добавления метаданных к конкретной странице PDF‑документа, что может быть полезно для целей отслеживания и ссылки. Например, его можно использовать для пометки страниц во время процесса печати или для предоставления дополнительной информации о странице при просмотре документа.
