Определяет стратегии переноса слов

## Поля

| Поле | Описание |
| --- | --- |
| [ByWords](#ByWords) | Перенос слов оборачивает только полные слова. Если полное слово нельзя перенести, предпринимаются попытки использовать произвольное переносное деление. |

| [NoWrap](#NoWrap) | Перенос не выполняется |
| [Undefined](#Undefined) | Будут использованы стратегии переноса для верхнего уровня структуры (ячейка таблицы, абзац и т.д.). |
