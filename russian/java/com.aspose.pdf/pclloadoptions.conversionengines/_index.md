### NewEngine {#NewEngine}

Новый движок конвертации в настоящее время находится в состоянии A-testing. Мы открываем его в публичный API, чтобы получить обратную связь. В настоящее время рекомендуется использовать его только когда старый движок конвертации не может преобразовать документ по некоторым причинам.
