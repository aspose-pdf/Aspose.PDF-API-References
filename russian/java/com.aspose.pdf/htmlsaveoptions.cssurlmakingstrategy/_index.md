Вы можете присвоить этому свойству делегат, созданный из пользовательского метода, который реализует создание URL CSS, указанного в сгенерированном HTML‑документе. F.e. если вы хотите создать CSS, указанный в HTML, например как "otherPage.ASPX?CssID=zjjkklj", то такая пользовательская стратегия должна возвращать "otherPage.ASPX?CssID=zjjkklj".
