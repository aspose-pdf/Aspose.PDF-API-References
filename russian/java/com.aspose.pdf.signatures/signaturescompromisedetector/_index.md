Представляет класс для проверки компрометирующих подписей документа. Детектор проверяет только известные способы компрометации подписей. Проверка не может предоставить 100% гарантию отсутствия компрометации подписи и может дать ложный отрицательный результат для новых, неизвестных методов компрометации, отличных от тестируемых.
