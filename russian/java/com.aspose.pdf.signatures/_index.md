Пакет com.aspose.pdf.signatures предоставляет классы для функций подписи.

## Классы

| Класс | Описание |
| --- | --- |
| [CompromiseCheckResult](./compromisecheckresult/) | Представляет класс для проверки цифровых подписей документа на компрометацию. |
| [InternalHelper](./internalhelper/) |  |
| [SignaturesCompromiseDetector](./signaturescompromisedetector/) | Представляет класс для проверки компрометирующих подписей документа. Детектор проверяет только известные способы компрометации подписей. Проверка не может предоставить 100% гарантию отсутствия компрометации подписи и может дать ложный отрицательный результат для новых, неизвестных методов компрометации, отличных от тестируемых. |
| [SignaturesCoverage](./signaturescoverage/) | Представляет перечисление уровня охвата, предоставляемого цифровыми подписями в документе. |
